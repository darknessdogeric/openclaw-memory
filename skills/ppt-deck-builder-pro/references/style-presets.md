# Style Presets

Use one deck-level `style_preset` before prompt writing.
Do not leave style as a vague adjective cloud.

---

## 📚 Extended Template Library (10 Presets)

### 1. `dark_blue_business` (原有 - 企业深蓝)

Use when:
- the deck is client-facing
- the audience expects enterprise polish
- the user wants a premium blue proposal style

Core traits:
- deep navy (#0a1628) and cobalt blue (#1e40af)
- restrained futuristic atmosphere
- dark glass or stable module zones
- strong hierarchy and calm background

Prompt keywords:
- `deep navy`, `cobalt blue`, `dark glass panels`, `ice blue accents`
- `professional business presentation`, `subtle futuristic`
- `high contrast`, `stable cards`

Avoid:
- cyberpunk overload
- poster-like hero shots
- fake dashboard clutter

---

### 2. `light_consulting` (原有 - 简洁咨询)

Use when:
- the deck is dense
- readability matters more than atmosphere
- the user wants a cleaner consulting style

Core traits:
- light background (white/light gray #f8fafc)
- dark text (#1e293b)
- soft structure lines
- low visual noise

Prompt keywords:
- `clean white background`, `light consulting style`
- `dark readable text`, `soft gray lines`
- `professional document`, `minimalist`

Avoid:
- washed-out low-contrast blocks
- too many thin separators

---

### 3. `whiteboard_handdrawn` (原有 - 白板手绘)

Use when:
- the user explicitly asks for whiteboard, board sketch, founder board, hand-drawn courseware
- the deck should feel like a live explanation
- content benefits from illustration-led teaching

Core traits:
- whiteboard fills entire 16:9 frame
- all four metallic borders visible
- elegant Chinese hard-pen handwriting
- hand-drawn colored marker illustrations

Prompt keywords:
- `full-frame whiteboard`, `all four metallic borders visible`
- `elegant Chinese hard-pen handwriting`
- `hand-drawn colored marker illustrations`
- `no office background`, `zero room background`

Best uses:
- training decks, founder-style explanation
- concept teaching, product mechanism breakdown

---

### 4. `startup_roadshow` 🌟 (新增 - 创业路演)

Use when:
- startup pitch decks
- investor presentations
- tech product launches
- seeking funding

Core traits:
- gradient purple to orange (#7c3aed → #f97316)
- bold large typography
- dynamic energy atmosphere
- geometric shapes and particles
- dark background with glowing accents

Prompt keywords:
- `startup pitch deck`, `venture capital style`
- `gradient purple to orange`, `glowing accents`
- `bold typography`, `dynamic energy`
- `geometric shapes`, `floating particles`
- `modern tech`, `innovative feel`

Best uses:
- Seed/A轮融资路演
- 创始人故事
- 产品发布
- 颠覆性概念介绍

Avoid:

## Plan File Pattern

```json
{
  "style_preset": "startup_roadshow",
  "style_goal": "Venture capital pitch deck with gradient purple-orange, bold typography, and dynamic energy.",
  "style_anchor_strategy": "sample_first_then_full_batch",
  "slides": [
    {
      "slide_number": 1,
      "style_preset": "startup_roadshow",
      "style_notes": "Use gradient purple to orange, bold headlines, dark background.",
      "must_keep_elements": [
        "gradient purple to orange",
        "bold large title",
        "dynamic energy feel"
      ],
      "forbidden_elements": [
        "corporate blue",
        "dull colors"
      ]
    }
  ]
}
```

## Adding Custom Presets

To add your own preset:

1. Create a new section following the pattern above
2. Define core traits and use cases
3. List prompt keywords for image generation
4. Add to Quick Selection Guide
5. Test with a sample page before full generation
