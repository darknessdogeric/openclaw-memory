# Goal Management Skill

高效的目标管理是个人和团队产出的核心保障。

## 核心框架

### 1. OKR 制定

**OKR 结构：**
```
O（Objective）：目标
- 定性的描述
- 有挑战性但可实现
- 鼓舞人心

KR（Key Results）：关键结果
- 定量的指标
- 0-100%可衡量
- 3-5个为宜

关系：O → KR（目标驱动结果）
```

**OKR 制定流程：**
```
Step 1: 明确使命/愿景
- 我/团队的长期方向是什么？

Step 2: 设定目标（O）
- 本季度最重要的一件事是什么？
- 用动词开头（实现/达成/推出）
- 最多3个O

Step 3: 拆解关键结果（KR）
- 如何判断O达成了？
- 每个O对应3-5个KR
- KR必须可衡量

Step 4: 对齐与连接
- 个人OKR → 团队OKR
- 下级OKR → 上级OKR
```

**OKR 示例：**
```
O: 在4月内完成AHL酒店试点部署
KR1: 签署试点合作协议（4月15日前）
KR2: PMS系统对接完成（4月20日前）
KR3: 首月历史数据分析报告（4月30日前）
KR4: AI收益建议采纳率>60%
```

### 2. 项目管理

**项目生命周期：**
```
启动 → 规划 → 执行 → 监控 → 收尾
  ↓
项目管理5大过程组
```

**敏捷冲刺（Sprint）：**
```
2周为一个冲刺周期：
Day 1: Sprint Planning（计划）
Day 2-9: Daily Standup + 执行
Day 10: Review（评审）+ Retrospective（复盘）

关键实践：
- 每日站会：15分钟，同步进度，识别阻塞
- 可视化看板：任务状态一目了然
- 定期回顾：总结改进
```

**任务优先级矩阵：**
```
          紧急
     ┌──────┴──────┐
     │   Do First  │  Quadrant 1
     │  (立即做)   │  Critical
     ├─────────────┤
  不 │             │
  紧 │  Schedule   │  Quadrant 2
  急 │  (计划做)   │  Important
     │             │  but not
     ├─────────────┤  urgent
     │   Delegate  │  Quadrant 3
     │   (委托)    │  Consider
     ├─────────────┤  outsourcing
     │   Eliminate │  Quadrant 4
     │   (删除)    │
     └──────┬──────┘
            │
          重要
```

### 3. 时间管理

**GTD 流程：**
```
1. 收集（Collect）
   - 所有任务/想法放入Inbox
   - 统一收集，不要分散

2. 处理（Process）
   - 每个事项判断：
     □ 可行动？→ Yes → 谁来做？何时做？
     □ 否 → 归档/删除/参考资料

3. 组织（Organize）
   - 项目清单
   - 下一步行动
   - 日历（固定时间）
   - 等待清单

4. 回顾（Review）
   - 每日回顾：当天任务
   - 每周回顾：项目进度，清理Inbox
   - 每月回顾：OKR进度，调整

5. 执行（Do）
   - 按优先级执行
   - 保护专注时间
```

**番茄工作法：**
```
核心：
- 25分钟专注工作
- 5分钟休息
- 4个番茄后休息15-30分钟

操作：
1. 选择任务
2. 设定25分钟倒计时
3. 专注工作
4. 休息5分钟
5. 重复

适用场景：
- 深度工作（写作/编程）
- 不适合：会议/沟通/创意发散
```

### 4. 复盘方法

**KISS复盘法：**
```
K - Keep：保持
- 哪些做得好，下次继续？

I - Improve：改进
- 哪些可以做得更好？

S - Start：开始
- 哪些还没做，但应该开始做？

S - Stop：停止
- 哪些不应该再做？
```

**PDCA循环：**
```
Plan → Do → Check → Act
 ↓                       │
 └───────────────────────┘

持续改进的闭环
```

**项目复盘模板：**
```
1. 目标回顾
   - 原定目标是什么？
   - 实际结果是什么？

2. 亮点分析
   - 做得好的是什么？
   - 成功因素是什么？

3. 不足分析
   - 做得不好的是什么？
   - 原因是什么？

4. 经验总结
   - 规律性认识？
   - 下次怎么做？

5. 行动计划
   - 下一步行动？
   - 谁负责？何时完成？
```
