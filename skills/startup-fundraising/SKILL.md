# Startup Fundraising Skill

创业融资是将商业创意转化为资本支持的系统化工程。

## 核心框架

### 1. 商业计划书结构

**标准BP框架（10页版）：**
```
Page 1: 执行摘要
- 一句话介绍
- 核心数据（市场规模/融资额/预期回报）

Page 2: 问题与痛点
- 目标用户痛点
- 现有方案的不足

Page 3: 解决方案
- 产品/服务如何解决
- 核心价值主张

Page 4: 市场机会
- TAM/SAM/SOM
- 市场趋势
- 竞争格局

Page 5: 商业模式
- 如何赚钱
- 收入结构
- 单位经济学

Page 6: 团队
- 创始人背景
- 核心团队
- 顾问

Page 7: 产品/技术
- 已有成果
- 差异化壁垒

Page 8: 进展与里程碑
- 已完成
- 进行中
- 规划中

Page 9: 融资计划
- 融资金额
- 资金用途
- 预期目标

Page 10: 愿景与联系
- 长期愿景
- 联系方式
```

### 2. 路演技巧

**时间控制：**
```
6分钟版本（OPC）：
- 开篇：15秒（做什么+解决谁的问题）
- 产品：60秒
- 市场：60秒
- 商业模式：60秒
- 团队：60秒
- 进展：60秒
- 融资：60秒
- 结尾：30秒

10分钟版本：
- 按比例扩展，重点突出差异化和数据
```

**路演核心原则：**
```
1. 前30秒定生死
   - 第一句话就要抓住注意力
   - 避免"我们是一个XX领域的YY公司"

2. 用数据说话
   - 市场规模用数字
   - 增长用百分比
   - 竞争优势用对比

3. 团队要可信
   - 创始人背景要量化
   - 团队完整性要体现
   - 顾问要有分量

4. 退出路径要清晰
   - 投资人关心回报
   - 给出想象空间
```

### 3. 估值方法

**早期项目估值：**
```
方法1：市场法
- 参考同类融资案例
- 按用户数/GMV/收入估算

方法2：精髓法
- 创始人背景溢价
- 行业经验溢价
- 创新程度溢价

方法3：双因子模型
估值 = 基础估值 × (1 + 团队系数) × (1 + 市场系数)

中国市场参考：
- 天使轮：¥500万-2000万（占股5-15%）
- Pre-A：¥2000万-5000万（占股5-15%）
- A轮：¥5000万-2亿（占股10-25%）
```

**估值谈判策略：**
```
关键条款：
- 估值（Valuation）
- 投资金额（Investment Amount）
- 股份比例（Equity Stake）
- 稀释后股权（Post-money Stake）

谈判要点：
- 先谈估值还是先谈股份？→ 先谈估值
- 估值重要还是条款重要？→ 条款（清算权/反稀释）
- 怎么判断估值合理？→ 看领投方背书
```

### 4. Term Sheet 解读

**关键条款：**
```
优先清算权（Liquidation Preference）
- 退出时优先获得回报
- 1x清算权：基本保障
- 参与分配：额外收益

反稀释（Anti-dilution）
- 保护投资人免被降价融资稀释
- 全部棘轮：保护最强
- 加权平均：标准条款

董事会（Board）
- 投资人席位
- 重大事项否决权

保护性条款（Protective Provisions）
- 重大融资/并购需投资人同意
- 限制创始人退出

估值 (Valuation Cap vs Discount)
- 上限 vs 折扣
- 优先股转普通股价格
```

### 5. 投资人关系

**投资人分类：**
```
按类型：
- 天使投资人：个人，早期
- VC：机构，早期到中期
- PE：机构，中后期
- 战略投资人：大公司布局

按偏好：
- 财务投资人：看ROI
- 战略投资人：看协同
- 产业投资人：看整合
```

**Outreach策略：**
```
冷启动：
- 通过共同联系人引荐
- 参加路演/创业大赛
- LinkedIn/邮件Cold outreach

暖启动：
- 参加投资人活动
- 对接FA（财务顾问）
- 媒体曝光

材料准备：
- BP（PDF格式）
- 数据room（一页纸摘要）
- 详细材料（随时可发）
```
