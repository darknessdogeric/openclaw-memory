# Term Sheet 条款解读

## 1. 估值条款

```
Pre-money Valuation（投资前估值）：
- 投资人进来前的公司估值
- 决定投资人占股比例

Post-money Valuation（投资后估值）：
- Pre-money + 本轮融资额
- = 投资人占股 / 投资额

稀释计算：
投资人占股 = 投资额 / Post-money估值
```

## 2. 清算优先权

```
1x Non-Participating（非参与分配）：
- 最常见条款
- 投资人优先拿回1倍
- 之后转为普通股

Senior Preferred（优先股）：
- 投资人优先拿回本金+利息
- 通常8-12%年化

Participating（参与分配）：
- 投资人拿回优先后还能按比例分配
- 对创始人最不利
```

## 3. 反稀释条款

```
完全棘轮（Full Ratchet）：
- 投资人按新低价重新计算股份
- 对投资人保护最强
- 创始人最不愿接受

加权平均（Weighted Average）：
- 考虑新旧价格的加权平均
- 公式：[新股价 × (已发行股份 + 新股)] / (已发行股份 + 新股)
- 更公平，常用

Broad-based加权平均：
- 分母包含所有已发行股票+期权
- 更保护创始人
```

## 4. 董事会条款

```
董事会组成：
- 创始人/CEO
- 投资人董事
- 独立董事

控制权分配：
- 创始人控制董事会：理想状态
- 投资人控制董事会：风险
- 势均力敌：需要重大事项一致决
```

## 5. 保护性条款

```
需要投资人同意的重大事项：
- 下一轮融资（可能稀释）
- 出售公司（退出）
- 重大资产出售
- 章程修改
- 发行新股
- 关联交易
```

## 6. 锁定期

```
创始人股份锁定：
- 通常4年
- 第一年锁定
- 之后按月/按年解锁

离开时的处理：
- 已解锁：可保留或回购
- 未解锁：通常回购

回购权：
- 投资人有权要求公司回购股份
- 通常8-10年期限
- 价格 = 投资额 + 利息
```
