# 统计模型详解

## 1. 贝叶斯模型

```
先验概率 P(H)：
- 基于历史数据的号码出现概率
- 例：号码5在100期中出现30次 → P(5)=0.3

似然 L(E|H)：
- 在假设H下，观察到证据E的概率
- 例：号码5连续10期未出现 → E=10期未出

后验概率 P(H|E)：
- 更新后的概率
- P(H|E) ∝ P(H) × L(E|H)

应用：
- 根据最新开奖数据更新号码概率
- 遗漏越多 → 后验概率越高
```

## 2. 泊松分布

```
泊松分布假设：
- 事件独立
- 发生概率恒定
- 任意小时间区间内发生次数期望有限

公式：
P(X=k) = (λ^k × e^(-λ)) / k!

其中λ = 期望发生次数

应用：
- 预测号码在特定期间出现次数
- λ = 历史平均出现率
```

## 3. 组合分析

```
前区35选5：
- 总组合数：C(35,5) = 324,632
- 全组合概率：1/324,632 ≈ 0.0003%

后区12选2：
- 总组合数：C(12,2) = 66
- 全组合概率：1/66 ≈ 1.5%

总概率：
- 一注全中的概率：1/(324,632 × 66) ≈ 1/21,425,712
```

## 4. 遗漏分析

```
遗漏值 = 当前期数 - 最后出现期数

遗漏分类：
- 小遗漏：0-5期
- 中遗漏：6-10期
- 大遗漏：11-20期
- 超大遗漏：>20期

遗漏回补：
- 遗漏大的号码未来出现概率会上升
- 但具体何时出现无法预测
```

## 5. 趋势判断

```
热号：近期出现频率明显高于均值
冷号：近期出现频率明显低于均值
温号：接近历史平均

趋势延续性：
- 热号可能继续热（趋势惯性）
- 冷号可能回补（均值回归）
- 但都只是概率，非确定
```
