# Lottery Analyst Skill

彩票分析是基于统计规律的概率研究。注意：彩票是随机事件，分析仅供娱乐，不构成投注建议。

## 核心框架

### 1. 数据收集

**必须收集的数据：**
```
历史开奖数据：
- 前区5个号码（01-35）
- 后区2个号码（01-12）
- 开奖日期
- 奖池金额

衍生数据：
- 各号码遗漏期数
- 各号码出现频率
- 奇偶比例
- 大小比例
- 和值分布
```

**数据来源：**
```
官网：中国体彩网 (lottery.gov.cn)
数据格式：每期开奖号码 + 日期
更新频率：每周二/四/日
```

### 2. 核心分析方法

**遗漏分析：**
```
遗漏值 = 未出现的期数

大遗漏号：遗漏超过10期的号码
- 这些号码迟早会出现
- 但不知道何时

冷转热信号：
- 长期遗漏号码开始出现
- 表明进入活跃期
```

**频率分析：**
```
出现频率 = 出现次数 / 总期数

高频号码：出现概率 > 3.5%
低频号码：出现概率 < 2.5%

注意：频率只是历史数据，不代表未来
```

**奇偶分析：**
```
前区35选5，奇偶分布：
- 5:0 偶 → 极少出现
- 4:1 偶 → 5%
- 3:2 偶 → 30%
- 2:3 偶 → 35%（最常见）
- 1:4 偶 → 25%
- 0:5 偶 → 5%

后区12选2，奇偶分布：
- 2:0 偶 → 30%
- 1:1 偶 → 50%（最常见）
- 0:2 偶 → 20%
```

### 3. 预测模型（V4.0）

**模型集成方法：**
```
1. 贝叶斯模型
   - 基于先验概率更新后验
   - 适合处理不确定性

2. 泊松分布
   - 模拟号码出现次数分布
   - 假设独立事件

3. 模糊数学
   - 处理边界模糊的概念
   - "热号"的隶属度

4. 熵值法
   - 衡量号码分布的混乱程度
   - 熵高→分布均匀→号码分散

5. 自适应权重
   - 根据预测准确率调整模型权重
   - 历史准确率 → 模型权重
```

**预测流程：**
```
Step 1: 收集最新10期数据
Step 2: 计算各模型预测值
Step 3: 集成各模型结果
Step 4: 应用筛选规则
Step 5: 生成推荐号码
Step 6: 保存预测记录
```

### 4. 号码筛选规则

**必选条件：**
```
1. 覆盖近期热号（出现频率TOP5）
2. 覆盖遗漏回补号（遗漏5-10期）
3. 奇偶比例符合历史分布
4. 和值在合理范围（60-120）
```

**排除规则：**
```
1. 纯奇数/纯偶数（历史出现概率<1%）
2. 5个号码全大连（历史出现概率<1%）
3. 5个号码全小连（历史出现概率<1%）
4. 与上期重复≥4个（概率极低）
```

### 5. 投注策略

**理性投注原则：**
```
1. 娱乐为主，量力而行
2. 每次投注不超过收入的1%
3. 不借钱投注
4. 不影响正常生活
5. 中奖是幸运，不中是常态
```

**投注模式：**
```
保守型：
- 固定号码长期跟
- 适合工薪阶层
- 期望值长期为负

激进型：
- 每期换号研究
- 追热号+守遗漏
- 风险高但不建议

平衡型：
- 基础注数固定（2-5注）
- 部分跟守号
- 部分追热号
```
