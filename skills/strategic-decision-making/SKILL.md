# Strategic Decision Making Skill

战略决策是将博弈论和行为经济学原理转化为可操作策略的专家系统。

## 核心决策框架

### 1. 博弈诊断（第一步）

**五问分析法：**
```
□ 1. 参与者是谁？各自的利益是什么？
□ 2. 游戏的规则是什么？（信息/时间/资源）
□ 3. 各方的最优策略是什么？
□ 4. 均衡在哪里？（纳什均衡/子博弈完美）
□ 5. 我的相对议价能力如何？
```

**博弈类型判断：**
```
合作 vs 非合作：能否强制执行协议
完全 vs 不完全信息：我知道多少对手的信息
零和 vs 正和：蛋糕是固定还是可变大
对称 vs 非对称：各方是否平等
```

### 2. 经典博弈模型速查

| 模型 | 适用场景 | 核心启示 |
|------|----------|----------|
| 囚徒困境 | 价格战/军备竞赛 | 需外部机制打破均衡 |
| 智猪博弈 | 创新竞争/大vs小 | 小玩家应等待/搭便车 |
| 斗鸡博弈 | 实力对决/正面对抗 | 威胁必须可信 |
| 猎鹿博弈 | 战略联盟/合作 | 信任是合作的关键 |

### 3. 决策树分析

```
决策分析流程：

1. 列出所有可行方案
2. 识别每个方案的可能结果
3. 评估每种结果的概率
4. 计算每种结果的收益
5. 构建决策树
6. 计算期望值（EMV）
7. 考虑风险偏好调整
```

**期望值公式：**
```
EMV = Σ (概率_i × 收益_i)

例：接受OTA协议
EMV = 0.7 × 100万 + 0.3 × 60万 = 88万 > 拒绝的70万
→ 应接受
```

### 4. 谈判策略矩阵

```
                        我方优势位置          我方弱势位置
              ┌──────────────────────┬──────────────────────┐
   对方合作   │    协作共赢           │    价值获取          │
              │   (整合利益分配)      │   (要求让步)          │
              ├──────────────────────┼──────────────────────┤
   对方竞争   │    主动让步           │    立场坚守          │
              │   (保持长期关系)      │   (寻找BATNA)        │
              └──────────────────────┴──────────────────────┘
```

### 5. BATNA分析

**BATNA = 最佳替代方案**

```
评估步骤：
1. 识别所有替代方案
2. 评估每个方案的可行性
3. 确定最优替代方案
4. 计算各方案的期望值
5. 确定谈判底线

BATNA越强 → 谈判力越强

例：酒店 vs OTA谈判
- BATNA：其他OTA平台、私域直销
- BATNA强 → 可以要求更低佣金
- BATNA弱 → 被动接受平台条款
```

### 6. 行为偏差识别

**常见决策偏差：**
```
损失厌恶：损失100的痛苦 > 获得100的快乐
→ 应用：强调"避免损失"比"获得收益"更有效

锚定效应：第一个数字影响后续判断
→ 应用：先开价者设定锚点

过度自信：高估自己判断的正确性
→ 应用：听取第三方意见

现状偏见：改变需要更大动力
→ 应用：让不改变显得"损失"
```

### 7. 机制设计检查

```
合同/协议设计检查：

□ 激励兼容：说真话是优势策略吗？
□ 个人理性：参与比不参与好吗？
□ 可执行性：违约能被识别和惩罚吗？
□ 效率：结果是帕累托最优吗？
□ 公平：分配被各方接受吗？
```
