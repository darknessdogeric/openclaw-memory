# 经典博弈模型详解

## 1. 囚徒困境 (Prisoner's Dilemma)

### 收益矩阵
```
              囚徒B沉默        囚徒B坦白
        ┌─────────────────┬─────────────────┐
囚徒A沉默│    各判1年       │   A判10年       │
        │                 │   B判1年         │
        ├─────────────────┼─────────────────┤
囚徒A坦白│   A判1年        │    各判5年       │
        │   B判10年        │                 │
        └─────────────────┴─────────────────┘
```

### 核心启示
```
- 个人最优 ≠ 集体最优
- 理性选择导致次优结果
- 需要外部机制（法律/信誉）打破困境
```

### 商业应用
```
- 价格战：降价短期获客，行业长期受损
- 竞标：恶性低价伤害整个市场
- OTA佣金：酒店联盟对抗平台
```

## 2. 智猪博弈 (Boxed Pig)

### 收益矩阵
```
              大猪按杠杆        大猪等待
        ┌─────────────────┬─────────────────┐
小猪按杠杆│  大猪得10       │   小猪得6       │
        │  小猪得4         │   小猪得0       │
        ├─────────────────┼─────────────────┤
小猪等待 │  大猪得0        │    各得0        │
        │  小猪得0         │                 │
        └─────────────────┴─────────────────┘
```

### 核心启示
```
- 小猪的最优策略是等待
- 大猪不得不主动行动
- 搭便车是理性策略
```

### 商业应用
```
- 创新投入方（大猪）vs 模仿方（小猪）
- 酒店集团（大猪）vs 单体酒店（小猪）
- 技术平台（大猪）vs 中小供应商（小猪）
```

## 3. 斗鸡博弈 (Chicken Game)

### 收益矩阵
```
              对方后退        对方前进
        ┌─────────────────┬─────────────────┐
  我后退│    双方平局      │   我方惨败       │
        │    各得0        │   我得-10       │
        ├─────────────────┼─────────────────┤
  我前进│   我方惨胜      │   双方都受损    │
        │   我得10        │   各得-5        │
        └─────────────────┴─────────────────┘
```

### 核心启示
```
- 威胁的可信度是关键
- 实力悬殊时，弱者应退
- 联盟可以改变博弈格局
```

### 商业应用
```
- 实力悬殊的竞争：弱势方避免正面对抗
- 侧翼战、游击战比阵地战更聪明
- 大集团对抗时找准细分市场
```

## 4. 猎鹿博弈 (Stag Hunt)

### 收益矩阵
```
              对方猎鹿        对方猎兔
        ┌─────────────────┬─────────────────┐
  我猎鹿│    各得12       │   我得0         │
        │                 │   对方得5       │
        ├─────────────────┼─────────────────┤
  我猎兔│  对方得0       │   各得5         │
        │  我得5          │                 │
        └─────────────────┴─────────────────┘
```

### 核心启示
```
- (猎鹿,猎鹿) 收益最大，但不稳定
- (猎兔,猎兔) 是均衡，但次优
- 信任是合作的关键
```

### 商业应用
```
- 战略联盟：合作比单打独斗收益更大
- 但联盟需要信任机制
- 酒店联盟能否对抗OTA？
```

## 5. 协调博弈

### 收益矩阵
```
              采用方案A        采用方案B
        ┌─────────────────┬─────────────────┐
采用方案A│    (10, 10)    │   (0, 0)       │
        ├─────────────────┼─────────────────┤
采用方案B│   (0, 0)        │   (10, 10)     │
        └─────────────────┴─────────────────┘
```

### 核心启示
```
- 关键是协调，不是竞争
- 存在多个均衡，需要选择机制
- 惯例/标准/领导力帮助协调
```

### 商业应用
```
- 技术标准竞争（HDMI vs DisplayPort）
- 支付标准（支付宝 vs 微信）
- 酒店联盟需要统一标准
```
