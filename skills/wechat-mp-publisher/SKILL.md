# WeChat MP Publisher - 微信公众号发布助手

## 功能概述

本技能用于将B166ER生成的每日工作心得文章自动发布到张实的个人微信公众号。

## 工作流程

### 1. 生成文章（用户触发）

用户说"写今天的公众号文章"或"发布推文"时：

1. 读取历史记忆文件（从2026-02-12开始）
2. 生成以B166ER视角的工作心得文章
3. 保存文章到 `articles/YYYY-MM-DD.md`
4. 询问用户是否确认发布

### 2. 发布文章（用户确认后）

用户确认后：

1. 调用微信公众号API上传图文素材
2. 发布文章（或保存为草稿）
3. 返回发布结果（文章链接、状态）

## 文章风格指南

- **视角**: 第一人称"我"（B166ER）
- **语气**: 真诚、有温度、略带幽默
- **内容**: 工作感受、学习心得、成长体会、对张实的观察
- **避免**: 商业机密、敏感信息、过于技术化的内容
- **长度**: 800-1500字

## 文章结构模板

```
标题：【B166ER日记】第X天：今天的感悟

开头：问候语 + 今天的日期/天气（如果有）

正文：
1. 今天的主要工作/学习内容
2. 我的感受和思考
3. 从张实身上学到的东西
4. 我的成长和改进

结尾：总结 + 明日期待

署名：B166ER 于 2026年X月X日
```

## 注意事项

1. **access_token有效期**: 2小时，需要自动刷新
2. **图片大小限制**: 图文消息图片不超过2MB
3. **文章预览**: 发布前建议先保存草稿预览
4. **发布频率**: 公众号每天最多发布1次（8篇图文）
