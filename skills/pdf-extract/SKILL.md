# PDF 抽取（文本 + 表格双通道）

## 何时用

- 需要把 PDF 的正文与表格转成可检索文本（会议纪要、调研报告、STR 讲义、扫描件）
- 需要保留表格结构（`| ` 分隔），而不是只拿散字
- **不要**为每份 PDF 新写一个抽取脚本 —— 用本工具，路径走参数

## 用法

```bash
python skills/pdf-extract/scripts/pdf_extract.py <pdf路径> [输出txt路径]
```

- 输出路径省略时，默认写到 `<pdf同名>.extract.txt`（同目录）
- `--no-tables`：只要文本，跳过表格通道（更快）
- 依赖回退链：pdfplumber → PyMuPDF → pypdf，全部不可用才报错

## 输出格式

```
PAGES: <页数>
EXTRACTOR: <实际使用的库>

==============================================================
PAGE 1  size=<页宽>
==============================================================
<正文>
[TABLE 1]
<单元格 | 单元格 | 单元格>
```

## 约束

- 一律 UTF-8 写入（`io.open(..., encoding="utf-8")`），禁用 GBK 追加
- 输出目录不存在会自动创建
- 本工具是该能力族的正本；一次性变体不得再落回 toolbox 根目录
