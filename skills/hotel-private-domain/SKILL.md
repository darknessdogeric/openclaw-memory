# Hotel Private Domain Operations Skill

酒店私域运营是将公域流量转化为自有资产的核心能力。

## 核心框架

### 1. 会员体系设计

**会员等级金字塔：**
```
           ▲ 钻石/黑金（5%）
          ▲▲▲ 金卡（15%）
         ▲▲▲▲▲ 银卡（30%）
        ▲▲▲▲▲▲▲ 普通会员（50%）

权益设计原则：
- 越高等级，门槛越高，权益越大
- 升级容易，降级困难（损失厌恶）
- 交叉权益（航空/信用卡）增加吸引力
```

**会员价值计算：**
```
CLV（客户终身价值）= ARPU × 留存月数 × 毛利率

例：
- 月均消费500元
- 平均留存24个月
- 毛利率60%
- CLV = 500 × 24 × 0.6 = ¥7,200
```

### 2. 私域引流矩阵

**公域→私域触点：**
```
OTA渠道：
- 订单完成后立即引导
- 短信/随行函邀请
- 差评用户主动回访

门店场景：
- 入住时引导注册
- 前台物料曝光
- 退房时转化

线上公域：
- 抖音/小红书引流
- 搜索引擎投放
- 朋友圈广告
```

**导流诱饵设计：**
```
新客礼包：
- 首次入住立减50元
- 免费早餐升级
- 延迟退房至14:00

复购激励：
- 积分翻倍
- 生日特惠
- 会员日专享价
```

### 3. RFM分层模型

**指标定义：**
```
R（Recency）：最近一次消费距今天数
- R越小，客户越活跃

F（Frequency）：消费频率
- F越大，客户越忠诚

M（Monetary）：消费金额
- M越大，客户价值越高
```

**分层矩阵：**
| 类型 | R | F | M | 运营策略 |
|------|---|---|---|----------|
| 重要价值 | 低 | 高 | 高 | VIP服务，最高优先级 |
| 重要发展 | 低 | 低 | 高 | 提升F，培养忠诚 |
| 重要保持 | 高 | 高 | 高 | 召回，推送优惠 |
| 重要挽留 | 高 | 低 | 高 | 深度召回，分析原因 |

### 4. 企微社群运营

**社群分类：**
```
福利群：发优惠券为主，活跃度高
服务群：解决问题为主，互动深
兴趣群：共同爱好，粘性强
```

**社群运营SOP：**
```
每日：
- 早安问候 + 今日特惠
- 下午茶推荐
- 晚安故事/优惠

每周：
- 周三会员日
- 周末活动预告

每月：
- 会员日大促
- 线下活动
- 积分兑换
```

### 5. 复购提升策略

**复购漏斗：**
```
首次入住 → 复购2次 → 复购5次 → 忠诚客户
   ↓           ↓          ↓         ↓
  100%       40%       20%       10%
```

**提升方法：**
```
触达层面：
- 入住后7天内回访
- 离店后30天推送复购
- 生日/纪念日自动触发

权益层面：
- 复购等级加速
- 积分加倍
- 专属礼遇

体验层面：
- 入住欢迎礼
- 个性化服务
- 问题快速响应
```
