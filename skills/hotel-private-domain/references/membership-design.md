# 会员体系设计详解

## 1. 会员等级设计

```
四档会员体系：

普通会员（注册即得）：
- 注册门槛：无
- 占比：50%
- 权益：基础价格、积分

银卡会员（消费升级）：
- 门槛：年消费≥2000元 或 5晚
- 占比：30%
- 权益：95折、优先入住、免费早餐

金卡会员（高消费）：
- 门槛：年消费≥5000元 或 15晚
- 占比：15%
- 权益：9折、免费升房、延迟退房

钻石会员（忠诚核心）：
- 门槛：年消费≥10000元 或 30晚
- 占比：5%
- 权益：85折、套房升级、专属管家
```

## 2. 积分体系

```
积分获取：
- 消费：100元 = 100积分
- 评价：完成入住评价 = 50积分
- 邀请：成功邀请好友 = 200积分
- 生日：生日当月双倍积分

积分兑换：
- 100积分 = ¥1
- 升级房型：5000积分/次
- 免房：20000积分/晚
- 餐饮券：1000积分/50元
```

## 3. 权益设计原则

```
升级容易，降级困难：
- 升级：消费达标即升
- 降级：年度重新评估
- 保级：提供保级机会

交叉权益：
- 航空公司里程兑换
- 信用卡积分互换
- 景区门票折扣

非价格权益：
- 免费升房（边际成本低）
- 延迟退房（提高体验）
- 专属接待（提高身份感）
```

## 4. 会员招募SOP

```
门店招募：
1. 入住时前台主动推荐
2. 介绍会员权益和升级路径
3. 当场注册即享首单优惠
4. 引导关注公众号/企微

线上招募：
1. OTA订单完成后短信触达
2. 邀请加入会员享专属价
3. 公众号菜单一键注册
4. 小程序新人礼包
```
