# 收益管理核心指标体系

## 1. 三大基础指标

### ADR（平均每日房价）
```
ADR = 客房收入 / 已售房间数

计算示例：
某天收入 ¥45,000，售出75间
ADR = 45,000 / 75 = ¥600

行业参考：
- 经济型：¥150-250
- 中端：¥250-500
- 中高端：¥500-800
- 高端：¥800-1500
- 奢华：¥1500+
```

### OCC（入住率）
```
OCC% = 已售房间数 / 可售房间数 × 100%

计算示例：
可售150间，入住120间
OCC = 120/150 × 100% = 80%
```

### RevPAR（每可售房收入）
```
RevPAR = ADR × OCC%
或
RevPAR = 客房收入 / 可售房间数

计算示例：
ADR ¥600，OCC 80%
RevPAR = 600 × 80% = ¥480

或：
收入¥72,000，可售150间
RevPAR = 72,000/150 = ¥480
```

## 2. 进阶指标

### GOPPAR（每可售房经营毛利）
```
GOPPAR = GOP / 可售房间数

GOP = 客房收入 - 客房直接成本
包括：人工、布草、洗漱用品、能源
不包括：折旧、摊销、总部费用
```

### NRevPAR（每可售房净收入）
```
NRevPAR = (客房收入 - OTA佣金) / 可售房间数

用途：真实反映直销售收入
```

### Conversion Rate（转化率）
```
CTR（点击转化率）= 点击量 / 曝光量
CVR（成交转化率）= 订单量 / 点击量

OTA优化重点：同时提升CTR和CVR
```

## 3. 收益健康度评估

### 横向对标（STR标准）
```
优秀：RevPAR Index > 100（跑赢市场）
及格：RevPAR Index = 80-100
较差：RevPAR Index < 80

RevPAR Index = 我店RevPAR / 竞争群组平均RevPAR × 100
```

### 纵向对标（同比/环比）
```
同比：vs 去年同其
环比：vs 上周/上月
预算比：vs 预算目标

健康标准：
- ADR同比：±5%以内
- OCC同比：±3%以内
- RevPAR同比：±5%以内
```

## 4. 渠道贡献矩阵

| 渠道 | 佣金率 | 流量质量 | 建议占比 |
|------|--------|----------|----------|
| 官网直销 | 0% | 高（精准） | >40% |
| 小程序 | 0% | 高（复购） | >20% |
| 企业协议 | 0-5% | 高（稳定） | 15-25% |
| 携程 | 10-15% | 高（广覆盖） | 15-25% |
| 美团 | 8-12% | 中高 | 10-20% |
| 飞猪 | 8-12% | 中 | 5-10% |

## 5. 预测准确性评估

```
预测误差率 = |实际值 - 预测值| / 预测值 × 100%

优秀：< 5%
良好：5-10%
及格：10-15%
较差：> 15%
```

*核心指标是收益管理的基础，所有策略都围绕这些数据展开*
