# OTA渠道策略

## 1. OTA生态结构

```
携程系：
- 携程旅行（高端/商旅）
- 去哪儿（价格敏感）
- 同程艺龙（下沉市场）

美团系：
- 美团旅行（本地生活延伸）
- 优势：年轻用户/低价策略

阿里系：
- 飞猪旅行（阿里生态内）
- 优势：支付宝/淘宝流量

其他：
- 途牛/马蜂窝（攻略/内容）
- Booking/Agoda（境外游）
```

## 2. 渠道贡献评估

```
评估指标：
1. 订单量占比
2. 间夜量占比
3. 佣金率
4. 转化率
5. 客人质量（是否二次消费）
6. 额外收益（保险/取消险）
```

## 3. 渠道优化策略

```
阶段1：诊断
- 确认各渠道占比
- 分析佣金差异
- 识别机会成本

阶段2：调整
- 提高低佣金渠道优先级
- 优化OTA展示位置
- 差异化各渠道产品

阶段3：监控
- 每周数据分析
- 月度策略复盘
- 季度渠道优化
```

## 4. 携程特牌攻略

```
特牌价值：
- 流量倾斜（+30-50%曝光）
- 搜索排名加权
- 专属标签（金牌/钻石）

冲刺方法：
1. 基础分≥4.5（点评分）
2. 确认不涨价
3. 预付订单占比>30%
4. 无重大投诉
5. 活动参与度
```

## 5. 私域vs OTA平衡

```
目标结构：
直销（官网/小程序）：40%+
企业协议：20%
OTA：25-30%
其他：10-15%

私域价值：
- 佣金0%
- 数据100%自有
- 复购率更高

OTA价值：
- 流量大
- 新客获取
- 品牌曝光
```
