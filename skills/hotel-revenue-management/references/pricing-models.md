# 定价模型参考

## 1. 动态定价模型

### 基础模型
```
P(t) = P_base × D_factor × C_factor × T_factor

其中：
- P_base：基础房价
- D_factor：需求系数（基于入住率预测）
- C_factor：竞争系数（基于竞品价格）
- T_factor：时间系数（基于提前预订天数）
```

### 需求弹性模型
```
价格调整幅度 = 需求弹性系数 × (目标入住率 - 当前入住率)

经济型酒店弹性系数：-1.5 ~ -2.0（弹性大）
高端酒店弹性系数：-0.5 ~ -1.0（弹性小）
```

## 2. 渗透定价模型

### 目的
快速占领市场份额，短期牺牲利润

### 定价策略
```
渗透价格 = 成本 × (1 + 目标利润率)
         = 成本 × 1.1-1.2（低利润率快速扩张）

适用场景：
- 新开业酒店
- 新市场进入
- 竞争对手抢占份额
```

## 3. 分层定价模型

### 容量分层
```
乞丐房（限量10%）：P_base × 0.7
标准房（主力60%）：P_base × 1.0
景观房（20%）：P_base × 1.2-1.3
套房（10%）：P_base × 2.0-3.0
```

### 时间分层
```
早鸟价（提前30天+）：P_base × 0.8
标准价（提前7-30天）：P_base × 1.0
临客价（提前<7天）：P_base × 1.1-1.3
保留房（当日）：P_base × 1.5-2.0
```

## 4. 收益管理定价流程

```
Step 1: 数据收集
├── 历史数据（去年同期）
├── 本期数据（已确认预订）
├── 竞品数据（价格监测）
└── 市场数据（事件/节假日）

Step 2: 需求预测
├── 基础预测（历史平均）
├── 调整因素（同比/环比）
├── 特殊事件（会议/展览）
└── 综合预测值

Step 3: 定价决策
├── 确定目标OCC
├── 计算价格范围
├── 考虑渠道策略
└── 最终定价

Step 4: 执行监控
├── 实时数据跟踪
├── 价格调整触发
└── 效果评估
```

## 5. 中国市场定价特点

### OTA价格博弈
```
酒店定价 > OTA底价：OTA优先展示
酒店定价 < OTA底价：可能被要求上调或下架

建议：
- 保持各渠道价格一致性
- 官网价格不低于OTA
- 设置价格保护条款
```

### 私域价格优势
```
会员专属价：官网价 × 0.9-0.95
企业协议价：官网价 × 0.85-0.90
社群秒杀价：官网价 × 0.7-0.8（限时限量）
```
