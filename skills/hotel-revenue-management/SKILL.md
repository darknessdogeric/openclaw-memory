# Hotel Revenue Management Skill

酒店收益管理是将知识转化为行动的专家系统。核心公式：

```
收入 = ADR × OCC × Rooms
RevPAR = ADR × OCC
```

## 核心工作流

### 1. 收益诊断（接单时必做）

**收益健康检查表：**
```
□ 今日入住率 vs 本周预测
□ ADR vs上周/去年同其
□ 竞品价格带对比
□ 渠道贡献占比
□ 团队客/散客比例
□ 提前预付vs现付比例
□ 取消率趋势
```

**诊断公式：**
```
当入住率>85%：提价空间存在
当入住率<60%：需要促销激活
当ADR低于竞品：检查是否落后定价
当取消率>15%：需要更严格的担保政策
```

### 2. 竞品监控流程

**竞品价格采集（SOP）：**
```
1. 确定竞争群组（5-8家）
2. 设置价格采集时间节点：
   - 平日：14:00 / 20:00
   - 周末：11:00 / 15:00 / 20:00
3. 记录最低价/最高价/均价
4. 计算自家价格位置（低价/中价/高价）
```

### 3. 动态定价策略

**定价决策树：**
```
当需求旺盛（>85% OCC）：
  → 检查是否应提价（参考竞品价格）
  → 调整方式：价格+10%~30%

当需求正常（60-85% OCC）：
  → 维持价格稳定
  → 重点优化渠道转化

当需求疲软（<60% OCC）：
  → 识别原因（竞争/季节/特殊事件）
  → 制定激活方案：
    - 短期：促销套餐
    - 中期：渠道优化
    - 长期：产品升级
```

**价格调整频率建议：**
```
高需求期：每日调整
正常期：每周评估
低需求期：每周2-3次调整
```

### 4. 渠道优化

**渠道贡献评估：**
```
OTA渠道（携程/美团）：
  - 优势：流量大、获客广
  - 劣势：佣金高（10-15%）
  - 策略：控制比例在30%以内

直销渠道（官网/小程序）：
  - 优势：佣金低、数据可控
  - 劣势：流量小
  - 策略：重点发展，比例目标>40%

企业客户：
  - 优势：稳定、提前锁量
  - 劣势：价格折扣大
  - 策略：占比20-30%为健康
```

### 5. 团队绩效考核

**收益经理KPI体系：**
```
一级指标（权重60%）：
  - RevPAR vs 预算达成率
  - ADR vs 预算达成率

二级指标（权重30%）：
  - 入住率达成率
  - 渠道结构健康度
  - 竞品价格位置

三级指标（权重10%）：
  - 系统数据准确率
  - 报告提交及时性
```

## 常用公式速查

```
RevPAR = ADR × OCC%
RevPAR = Total Room Revenue / Available Rooms
Occ% = Occupied Rooms / Available Rooms
ADR = Total Room Revenue / Sold Rooms
GOPPAR = GOP / Available Rooms
双指标法：OCC↑ + ADR↑ = 收益最优
```

## 常见场景处理

**场景1：竞品突然降价**
```
1. 确认是否为长期策略（≥3天）
2. 检查自身入住率水平
3. 若入住率>80%，可不跟进
4. 若入住率<70%，考虑促销反击
5. 分析竞品降价原因（清库存/测试市场）
```

**场景2：大型会议/活动期间**
```
1. 提前30天锁定价格
2. 设置最小停留天数（MinLOS）
3. 要求预付或担保
4. 配套餐饮/宴会提升整体收益
5. 活动后设置追销期
```

**场景3：OTA排名下滑**
```
1. 检查挂牌等级（是否被降级）
2. 分析转化率数据（点击→下单）
3. 确认佣金率是否有竞争力
4. 优化首图和详情页
5. 增加带图评价数量
```

## 中国市场特殊考量

1. **OTA依赖**：携程占比45%+，需平衡直销与OTA
2. **价格一致性**：各渠道价格不宜差异过大（用户会比价）
3. **私域价值**：微信生态完善，会员复购贡献高
4. **大促节点**：618/双11/双12需提前布局
5. **节假日脉冲**：春节/国庆是年度收益关键期
