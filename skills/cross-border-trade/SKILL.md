# Cross-Border Trade Skill

跨境贸易是从中国制造到美国消费者的全链路工程。

**本skill让你能立即上手操作。**

---

## 一、立即开始清单（Day 1必做）

```
□ 注册亚马逊卖家账号
  → amazon.com → Sell → Start Selling → 按步骤填写
  → 需要：营业执照、法人身份证、双币信用卡、收款账户

□ 完成税务信息填写
  → 卖家后台 → 账户信息 → 税务信息
  → 选择：非美国税务居民
  → 填写W-8BEN表格

□ 申请品牌备案（建议尽早）
  → USPTO.gov → 商标查询 → 申请商标
  → 时间：8-12个月（可以先备货，等商标下来再做备案）
  → 费用：$250-500/类

□ 开通ERP或选品工具
  → 卖家精灵/领星/船长 → 注册账号
  → 绑定亚马逊店铺
  → 开始选品调研
```

## 二、选品标准化流程（3天）

### 2.1 选品调研路径

```
Step 1: 确定品类方向
├─ 优先：3C配件/智能家居/户外用品
├─ 避开：带电产品/食品/儿童产品（认证复杂）
└─ 原则：轻小便运、功能差异化、客单价$20-100

Step 2: 市场调研
├─ 工具：卖家精灵 → 选品调研
├─ 输入：核心关键词（如"wireless charger"）
├─ 输出：月销量/竞争度/价格区间/评价分布

Step 3: 竞品分析
├─ 找3-5个Best Seller
├─ 记录：ASIN/售价/评价数/评分/月销
├─ 分析好评：用户喜欢什么？
├─ 分析差评：用户抱怨什么？
└─ 找差异化机会

Step 4: 利润核算
├─ 产品成本：联系工厂询价
├─ 物流成本：空运/海运报价
├─ 亚马逊费用：佣金15%+FBA配送费
├─ 广告预算：预留售价10-15%
└─ 计算毛利率（目标>40%）

Step 5: 最终决策
├─ 毛利率>40%？
├─ 差异化能做吗？
├─ 认证能做吗？
└─ 全部YES → 开始打样
```

## 三、产品上架标准化流程（1-2天/产品）

### 3.1 Listing创建检查表

```
□ 标题（<200字符）
  ├─ 品牌名 +
  ├─ 核心关键词（最重要的2个）+
  ├─ 产品属性（颜色/尺寸/数量）+
  ├─ 产品类型
  └─ 差异化卖点
  
  示例：Anker PowerCore 10000mAh Portable Charger, 20W Fast Charging for iPhone 15/14/13, Samsung Galaxy, and More (Black)

□ 主图（纯白底，1000x1000像素）
  ├─ 产品占85%
  ├─ 正面展示
  └─ 无水印/无文字

□ 副图5-7张
  ├─ 场景图（使用中）
  ├─ 尺寸图
  ├─ 对比图（和旧款/竞品）
  ├─ 细节图
  ├─ 配件图
  └─ 包装图

□ 五点描述（5条）
  ├─ 卖点1：核心功能
  ├─ 卖点2：技术参数
  ├─ 卖点3：使用场景
  ├─ 卖点4：差异化
  └─ 卖点5：服务保障

□ 产品描述（A+内容，如果有）
  ├─ 品牌故事
  ├─ 产品详情
  └─ 质量保证

□ 关键词（后台Search Terms，200字符）
  ├─ 宽泛词
  ├─ 长尾词
  └─ 品牌词

□ 变体（如需要）
  ├─ 颜色变体
  ├─ 尺寸变体
  └─ 数量变体

□ 价格设置
  ├─ 前期低价切入
  └─ 竞品定价参考

□ 库存数量
  └─ 首批发货数量
```

### 3.2 Listing标题模板

```
{品牌名} + {核心关键词} + {产品类型} + {重要属性} + {数量/颜色/尺寸}

模板：
{品牌名} {核心关键词1} {核心关键词2} {产品类型} for {兼容设备/场景} - {重要属性} {数量/颜色}

示例：
BETTEX 20W Fast Wireless Charging Pad, Qi Certified Charger for iPhone 15/14/13/12 Pro Max, Samsung Galaxy S23/S22, AirPods Pro - Ultra Slim Design (Black)
```

### 3.3 五点描述模板

```

☑️ {技术参数}：{详细规格}
```

## 四、广告投放标准化流程（Day 1启动）

### 4.1 新品广告结构

```
【活动1：自动广告】← 新品首选
├─ 竞价：$0.5-1（根据类目调整）
├─ 预算：$20-30/天
├─ 匹配：紧密匹配/扩展匹配/同类商品/关联商品
└─ 目的：获取关键词数据

【活动2：手动精确匹配】
├─ 竞价：$0.6-1.2（略高于自动）
├─ 预算：$15-20/天
├─ 关键词：自动广告跑出的高绩效词
└─ 目的：精准流量

【活动3：竞品ASIN定向】
├─ 竞价：$0.3-0.5
├─ 预算：$10/天
├─ ASIN：Best Seller的ASIN
└─ 目的：抢竞品流量
```

### 4.2 广告优化检查表

```
【每日检查】
□ 点击率>0.5%？
□ 有无无效点击？
□ 预算够用吗？

【每周优化】
□ 否词：点击但不转化的词加入否定
□ 拓词：高绩效词扩展匹配方式
□ 竞价：高ACOS降价，低ACOS提价

【每2周决策】
□ ACOS<25%？→ 维持或提价
□ ACOS 25-35%？→ 优化Listing后观察
□ ACOS>35%？→ 降价或暂停

【每月检查】
□ TACOS<15%？
□ 自然订单占比>50%？
□ 核心关键词排名上升？
```

## 五、FBA发货标准化流程（3-7天）

### 5.1 FBA发货步骤

```
Step 1: 创建FBA shipment
├─ 卖家后台 → Inventory → Manage Inventory
├─ 选择产品 → Actions → Have it fulfilled by Amazon
├─ 填写数量
└─ 继续处理

Step 2: 准备商品
├─ 打印标签（产品标签+FBA标签）
├─ 产品标签：贴在产品上（UPC/EAN）
├─ FBA标签：贴在外箱
└─ 每个产品都要贴

Step 3: 包装要求
├─ 包装完好（运输中不损坏）
├─ 产品独立包装（防混淆）
├─ 外箱干净整洁
├─ 每箱<50磅（否则需分箱）
└─ 箱内产品清单（建议）

Step 4: 发货
├─ 选择shipping method
│  ├─ 小于100件：Small Parcel
│  └─ 大于100件：LTL/FTL
├─ 安排头程物流
│  ├─ 空运：7-10天，快但贵
│  └─ 海运：30-45天，便宜但慢
└─ 追踪号填写到卖家后台

Step 5: 到达FBA仓库
├─ 等待上架（约3-5天）
├─ 查看Manage Inventory状态
└─ Active = 可售
```

### 5.2 FBA发货清单

```
□ 创建FBA shipment
□ 打印产品标签（每个产品）
□ 打印FBA标签（每个箱子）
□ 包装产品（每件独立包装）
□ 装箱（附装箱清单）
□ 安排头程物流
□ 获取追踪号
□ 填写追踪号到卖家后台
□ 确认发货
□ 等待上架
```

## 六、评价获取标准化流程

### 6.1 Vine计划参与步骤

```
Step 1: 确认资格
├─ 产品必须为FBA
├─ 产品必须为全新
├─ 有UPC/EAN（真实条形码）
└─ 产品评价<30条

Step 2: 注册Vine
├─ 卖家后台 → Inventory → Manage Inventory
├─ 选择产品 → Actions → Register in Vine
├─ 确认费用$200/ASIN
└─ 提交

Step 3: 等待样品送出
├─ 约5-7天审核
├─ 审核通过后，样品送出
├─ 等待买家收货
└─ 约30-60天获得评价

Step 4: 评价管理
├─ 监控评价数量和质量
├─ 如有差评，分析原因
└─ 决定是否继续VINE
```

## 七、账号安全检查清单

### 7.1 每日必查

```
□ 账号健康度 → Order Defect Rate < 1%
□ 买家消息 → 24小时内回复
□ 订单缺陷 → A-to-Z/负反馈/信用卡拒付
□ 发货延迟 → Late Shipment Rate < 4%
```

### 7.2 每周必查

```
□ 库存健康度 → 避免断货/滞销
□ Listing状态 → 无被跟卖/被修改
□ 绩效通知 → 账号状况通知
□ 竞品变化 → 价格/评价/排名
```

### 7.3 每月必查

```
□ 税务申报 → 销售税/所得税
□ 存储费 → 长期仓储费检查
□ 退货率 → 原因分析
□ 利润核算 → 各项成本占比
```

### 7.4 防关联检查

```
□ 一套资料 = 一个账号
□ 独立设备/独立IP
□ 独立支付账户
□ 不在同一网络环境下登录
□ 不使用同一浏览器Cookie
```

## 八、常见问题快速处理

### 8.1 Listing问题

```
问题：产品被标记为"adult"或"危险品"
解决：检查关键词/图片，联系卖家支持申诉

问题：Listing被篡改
解决：联系卖家支持，提供证据，要求恢复

问题：被跟卖
解决：发警告信 → Test Buy → 举报违规
```

### 8.2 广告问题

```
问题：高点击低转化
解决：检查主图/价格/评论，优化Listing

问题：高ACOS
解决：降价/提价/否词/优化Listing

问题：花不出去钱
解决：提竞价/放开匹配/检查预算
```

### 8.3 FBA问题

```
问题：FBA上架慢
解决：等待3-5天，超过7天开case问

问题：FBA库存丢失
解决：开case查询，提供证明

问题：退货率过高
解决：分析退货原因，改进产品/描述
```

### 8.4 账号问题

```
问题：账号被锁
解决：提交身份证/营业执照等证明文件

问题：ODR超标
解决：分析缺陷原因，改善产品质量/物流

问题：收到绩效通知
解决：认真对待，按要求整改
```

## 十、核心指标监控表

```
| 指标 | 公式 | 健康值 |
|------|------|--------|
| ACOS | 广告花费/广告销售额 | <25% |
| TACOS | 广告花费/总销售额 | <15% |
| CTR | 点击量/展示量 | >0.5% |
| CVR | 订单数/点击量 | >10% |
| 毛利率 | (售价-成本)/售价 | >40% |
| ODR | 缺陷订单/总订单 | <1% |
| 库存周转 | 30天销量/平均库存 | 30-45天 |
| 好评率 | 5星评价/总评价 | >90% |
| 退货率 | 退货订单/总订单 | <5% |
```
