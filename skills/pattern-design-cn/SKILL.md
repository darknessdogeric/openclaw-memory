## 何时用

- 要给酒店、公区、客房、文创、导视选纹样
- 要查某个纹样叫什么、出自哪朝、编号多少
- 要判断两个纹样能不能放在一起（年代/寓意冲突）
- 要为新纹样命名，或做纹样的衍生设计
- 涉及纹样商业使用时的出处与授权判断

---

## 核心方法（三条）

```
① 朝代一致 —— 同一空间的纹样须属同一或相邻朝代体系
② 寓意适配 —— 题材象征义须与场景、客群、节令匹配
③ 溯源可授权 —— 商业文创用纹样须能说明文物出处与权属
```

**顺序不可颠倒：先定朝代 → 再选母题 → 最后调形式（构图／连续方式／载体）。**

## 用法

```
python skills/pattern-design-cn/scripts/pattern_index.py search 云       # 检索
python skills/pattern-design-cn/scripts/pattern_index.py chapter 几何物语  # 按章列
python skills/pattern-design-cn/scripts/pattern_index.py compose 团花 云   # 组合校验
python skills/pattern-design-cn/scripts/pattern_index.py motifs         # 母题表
python skills/pattern-design-cn/scripts/pattern_index.py structures     # 结构词表
python skills/pattern-design-cn/scripts/pattern_index.py stats          # 规模统计
```

**`compose` 是本技能最有价值的命令** —— 它会告诉你：这个组合是否已存在、命名层是否合规、是否撞上权力象征或吉祥寓意的禁忌。

## 边界（重要）

- **底库是目录，不是内页**：逐条纹样的**寓意、文物出处、图像形态**未收录 → 需查原书或文物
- **`compose` 只在命名层给合规判断**：生成新名不等于形态可用，形态与年代仍须核对
- **"可申请授权" ≠ "已获授权"**：都江堰「文漾都江」88 款纹样 IP 库虽线上可申请，用作商业文创仍须走完授权流程
- 具象图腾（龙／凤／兽面／人物／飞天）带权力象征 → 酒店公共空间慎用
