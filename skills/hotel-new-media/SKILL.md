# Hotel New Media Marketing Skill

酒店新媒体运营是在抖音、小红书、微信等平台建立品牌 presence 的核心能力。

## 核心平台策略

### 1. 小红书 (种草主战场)

**内容类型分布：**
```
探店打卡类：40%
- 9张精修图 + 真实体验
- 地点标签/店铺标签
- 攻略类笔记

vlog记录类：30%
- 入住全流程记录
- 真实感强，有代入感
- 可加BGM增加氛围

攻略干货类：20%
- 城市旅游攻略
- 周末去哪玩
- 亲子/情侣/闺蜜游

促销活动类：10%
- 限时优惠
- 套餐推荐
- 会员日
```

**爆款笔记要素：**
```
标题公式：
- 数字型：周末2天1夜¥499玩转XX
- 冲突型：没想到XX这么便宜还这么好
- 疑问型：XX真的值得住吗？
- 攻略型：本地人整理的XX酒店攻略

封面设计：
- 高清大图
- 文字简洁有冲击力
- 颜色鲜明

内容结构：
- 开篇：吸引点（价格/体验/位置）
- 中间：详细体验+亮点
- 结尾：实用信息+引导
```

### 2. 抖音 (流量爆发)

**内容类型：**
```
门店展示类（60%）：
- 酒店环境展示
- 设施介绍
- 房间 TOUR

体验记录类（30%）：
- 入住 vlog
- 服务体验
- 特色服务

促销引流类（10%）：
- 团购优惠
- 限时特价
- 直播引流
```

**抖音运营 SOP：**
```
发布时间：
- 早7-9点（通勤）
- 中午12-14点（午休）
- 晚18-22点（黄金时段）

发布频率：
- 日更1条（起步）
- 周2-3条（稳定）
- 日更3条+（爆发期）

互动运营：
- 欢迎评论区交流
- 私信及时回复
- 引导关注+收藏
```

### 3. 微信生态

**公众号运营：**
```
内容规划：
- 探店文章（图文）
- 优惠活动
- 会员故事
- 周边攻略

发布频率：
- 周2-3篇
- 固定更新时间

菜单栏设置：
- 预订入口
- 会员中心
- 优惠领取
```

**视频号联动：**
```
内容同步：
- 抖音内容可分发至视频号
- 微信生态内传播

私域导流：
- 公众号 → 视频号
- 视频号 → 社群
- 社群 → 小程序
```

## 达人合作策略

### 合作模式
```
纯佣金（CPS）：无坑位费，按成交付费
- 适合：小博主/尾部KOC
- 风险：低，但效果不稳定

坑位费+佣金：固定费用 + 销售分成
- 适合：腰部达人
- 风险：中

年度合作：打包合作
- 适合：头部达人
- 风险：高，但长期价值大
```

### 达人筛选标准
```
基础指标：
- 粉丝数（不代表质量）
- 互动率（点赞+评论/粉丝）
- 内容质量
- 粉丝画像

核心指标：
- 近30天数据稳定性
- 同类合作效果
- 粉丝转化率

参考数值：
- 互动率 > 5% 优秀
- 3-5% 良好
- < 3% 偏低
```
