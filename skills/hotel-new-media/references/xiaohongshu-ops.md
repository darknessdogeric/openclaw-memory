# 小红书运营详解

## 1. 账号定位

```
定位类型：
- 个人 IP 型：主理人故事
- 门店展示型：酒店环境/服务
- 攻略干货型：旅游攻略+种草
- 促销引流型：优惠信息为主

建议酒店采用混合型：
- 60%种草内容
- 20%干货攻略
- 10%促销
- 10%品牌故事
```

## 2. 爆款笔记公式

```
标题公式：
1. 数字型
   "周末2天1夜 | ¥699住进森林里🌲"
   "被问爆的10家宝藏民宿 | 最后一个绝了"

2. 冲突型
   "没想到成都周边这个小镇这么美！"
   "人均200+的宝藏酒店，服务好到哭😭"

3. 疑问型
   "XX真的值得住吗？住了5次后说实话"
   "亚朵和全季怎么选？深度对比来了"

4. 攻略型
   "本地人整理的XX旅游攻略｜收藏备用"
   "第一次来XX？看完这篇就够了"
```

## 3. 封面设计

```
图片要求：
- 竖图3:4最佳
- 高清无水印
- 明亮清晰
- 有视觉冲击点

文字叠加：
- 标题党但不能虚假
- 突出卖点（价格/体验/位置）
- 颜色与图片对比鲜明
- 字体适中，不过度遮挡
```

## 4. 发布策略

```
发布时间：
- 早7-9点（通勤时间）
- 午12-14点（午休）
- 晚18-22点（黄金时段）

频率：
- 日更1篇（养号期）
- 周3-5篇（稳定期）
- 爆款后可日更2-3篇

互动：
- 评论区及时回复
- 私信24h内回复
- 引导关注+收藏
```

## 5. 关键词布局

```
标题关键词：
- 地点：XX城市/XX景区
- 类型：民宿/酒店/公寓
- 卖点：海景/亲子/网红

正文关键词：
- 自然嵌入
- 包含目的地词
- 包含类型词
- 适度堆砌但不过度

标签：
- 3-5个相关标签
- 地点+类型+品牌
```
