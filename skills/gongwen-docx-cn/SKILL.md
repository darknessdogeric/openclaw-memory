# 中文公文 Word 生成器（GB/T 9704-2012）

## 概述

把 Markdown 转成符合 **GB/T 9704-2012《党政机关公文格式》** 的 Word 文档。**纯文字、无 emoji、无元数据章节**，符合中国政府/国企内部公文的视觉规范。

**核心特征**：中英文字体绑定（`eastAsia` 是关键，否则中文字符会变方块或默认字体）。

## 何时使用

- 需要生成符合党政机关公文格式的 Word 文档
- 需要中英文字体严格绑定（中文用仿宋，西文/数字用 Times New Roman）
- 要求"纯文字"、"不要符号"、"去 emoji"、"无元数据章节"
- 需要表格、代码块、列表的混合内容
- 需要首行缩进 2 字符（约 403225 EMU）的标准段落格式

**不适用于**：
- 需要彩色图表、富文本样式、模板库（用 `powerpoint-pptx` 或专业模板工具）
- 需要 PDF 输出（先转 DOCX 再导出 PDF）
- 非中文场景（用通用 `md-to-docx` 类工具）

## 字体规范（GB/T 9704-2012）

| 元素 | 字体 | 字号 | 用途 |
|------|------|------|------|
| 主标题 | 方正小标宋简体 | 二号（22pt） | 文件标题，居中 |
| 正文 | 仿宋（_GB2312） | 三号（16pt） | 所有段落 |
| 一级标题 | 黑体 | 三号（16pt）| 一、二、三、… |
| 二级标题 | 楷体（_GB2312） | 三号（16pt）| （一）（二）（三）… |
| 三级标题 | 楷体（_GB2312） | 三号（16pt）| 1. 2. 3. … |
| 表格内 | 仿宋 | 五号（11pt）| 表格正文，表头加粗 |

## 排版规范

| 项目 | 数值 | 说明 |
|------|------|------|
| 首行缩进 | 2 字符 ≈ 403225 EMU | 段落首行（非表格） |
| 行距 | 固定 28-30 磅 | 段落与正文 |
| 页边距 | 上 3.7cm / 下 3.5cm / 左 2.8cm / 右 2.6cm | GB/T 9704 |
| 表格 | 黑色 0.5pt 单线边框 | Table Grid 样式 |
| 代码块 | 缩进 2 字符、11pt、行距 1.15 | 不喧宾夺主 |
| 引用 | 左缩进 2 字符、13pt | Markdown `>` 行 |
| 列表 | 纯文字段落（无项目符号） | Markdown `-`/`*` 转纯文字 |

## Eric 个人排版习惯（与公文规范叠加）

- **不使用 emoji**：所有装饰性符号去除
- **不使用元数据章节**：不输出"作者/日期/版本"等头部信息
- **不使用花哨样式**：不输出彩色、边框外阴影、emoji 标识
- **抬头格式识别**：自动识别 `呈：xxx / 拟：xxx / 时间：xxx` 并右对齐
- **落款识别**：自动识别 `产业发展部 / 2026 年 X 月` 等并右对齐
- **删除纯空白行**：跳过无意义空行

## 调用方式

```bash
python scripts/md2docx_gongwen.py <src.md> <dst.docx>
```

或从代码内调用：

```python
from skills.gongwen-docx-cn.scripts.md2docx_gongwen import md_to_gongwen_docx
md_to_gongwen_docx('report.md', 'report.docx')
```

## 输入格式示例（references/sample-input.md）

```markdown
报告标题
呈：邹士勇董事长
拟：产业发展部
时间：2026 年 9 月

一、当前经营情况

（一）营业收入

1. 总体规模
截至 2026 年 8 月 31 日，营业收入 1,000 万元。

2. 同比增长
同比增长 5%。
```

输出为：标题居中方正小标宋二号、抬头右对齐仿宋三号、一级标题黑体三号段前段后 12/6 磅、二级标题楷体三号、三级标题楷体三号、正文仿宋三号首行缩进 2 字符。

## 已知限制

- **不处理彩色图表**（纯文字版式）
- **不嵌入字体文件**（依赖系统已安装方正小标宋简体、仿宋_GB2312、楷体_GB2312、黑体；如缺失请安装）
- **不处理复杂 HTML/MathJax**（仅 Markdown 原生语法）
- **不自动生成目录**（如需要请用 Word 自带功能）
