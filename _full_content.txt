## 八、SKILL接口标准

### 8.1 统一SKILL结构

```yaml
SKILL-{MODULE}-{ID}:
  name: {中文名称}
  description: {功能描述}
  version: "1.0"
  
  input:
    type: {输入类型}
    schema: {输入Schema}
    example: {示例}
    
  output:
    type: {输出类型}
    schema: {输出Schema}
    example: {示例}
    
  prompt: |
    # ROLE: {角色定义}
    # CONTEXT: {背景信息}
    # TASK: {任务描述}
    # OUTPUT: {输出要求}
    
  dependencies:
    - {依赖SKILL列表}
    
  metrics:
    - {性能指标}
```

### 8.2 SKILL编排示例

```
用户入住 → SKILL-CRM-001(画像) → SKILL-CRM-011(生命周期) 
       → SKILL-PRIV-012(优惠券) → SKILL-PRIV-014(场景触达)
```
