## AHL核心特征与政策匹配

```
AHL核心特征                    匹配政策方向                    匹配度
──────────────────────────────────────────────────────────────────
AI大模型应用          →       AI专项、数字化转型              ⭐⭐⭐⭐⭐
文旅产业赋能          →       文旅发展专项、智慧旅游           ⭐⭐⭐⭐⭐
住宿业平台            →       现代服务业、平台经济             ⭐⭐⭐⭐
科技创新属性          →       高新企业认定、研发加计扣除        ⭐⭐⭐⭐⭐
创业阶段              →       创新创业专项、孵化器             ⭐⭐⭐⭐
带动就业              →       稳就业专项、人才专项             ⭐⭐⭐
```
