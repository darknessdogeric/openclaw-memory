## 二、省/国家级（需进一步确认申报通知）

### 6. 高新技术企业认定 ⭐⭐⭐ 最高优先

**认定条件:**
- 成立1年以上
- 自主知识产权（专利/软件著作权等）
- 高新技术产品(服务)收入占比≥60%
- 科技人员占比≥10%
- 研发费用占比符合要求

**认定流程:**
1. 在"高新技术企业认定管理工作网"注册
2. 在线填写《高新技术企业认定申请书》
3. 提交至所属省/市科技部门初审
4. 由省科技厅组织专家评审
5. 公示、颁发证书（有效期3年）

**申报入口:**
> ⚠️ 原"gzfw.chinatorch.gov.cn"已停用，请通过以下方式查找最新申报入口:
> 1. 访问 http://kjj.xiangyang.gov.cn/ → 搜索"高新技术企业认定"
> 2. 或访问 https://zwfw.hubei.gov.cn/ → 搜索"高新技术企业认定"
> 3. 或直接咨询: **0710-3539294**

## 六、快速查找申报入口的方法

### 方法1: 通过政府官网搜索
```
1. 打开 http://kjj.xiangyang.gov.cn/（襄阳市科技局）
2. 点击"通知公告"
3. 搜索: 科技创新券 / 高新技术企业 / 科技型中小企业
4. 打开对应通知，附件中包含申报系统链接
```

### 方法2: 通过政务服务平台
```
1. 打开 https://zwfw.hubei.gov.cn/
2. 选择"法人服务"
3. 输入: 高新技术企业 / 科技型中小企业 / 科技创新券
4. 选择对应申报事项
```

### 方法3: 电话直接咨询 ⭐最有效
```
襄阳市科技局: 0710-3539294（资源配置与重大任务科）
→ 询问: 
  1. "我想申报XX项目，请问在哪里申报？"
  2. "今年的申报入口在哪里？"
  3. "需要准备哪些材料？"
```
