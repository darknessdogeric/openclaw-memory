# 七、在线申报操作指南

## 7.1 国家系统操作流程

```
科技部火炬中心申报流程:
1. 访问: https://fuwu.most.gov.cn
2. 注册账号 (统一社会信用代码)
3. 选择项目类型
4. 填写申报书
5. 上传附件材料
6. 提交至省级科技厅
7. 省级初审通过后推荐至国家
```

## 7.2 四川省系统操作流程

```
四川省科技计划申报流程:
1. 访问: https://kjt.sc.gov.cn
2. 注册法人账号
3. 选择"科技计划项目申报"
4. 填写项目信息
5. 上传商业计划书/技术方案
6. 提交审核
7. 等待评审结果
```

## 7.3 成都高新区操作流程

```
成都高新区申报流程:
1. 访问: https://www.cdht.gov.cn
2. 注册企业账号
3. 选择"创新专项申报"
4. 填写项目信息
5. 上传商业计划书
6. 提交后会有专人联系
```
