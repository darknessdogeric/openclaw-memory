## 第3页: 酒店行业的困境

**这不是你的问题，这是行业结构性问题**

```
□ OTA越来越贵
  → 佣金15-25%，利润被吃掉
  → 客户数据在平台手里，你碰不到

□ 好的收益总监太贵也太稀缺
  → 年薪30万+招不到
  → 来了也可能随时走
  → 靠经验拍脑袋，错过最佳时机

□ 想做私域但没有系统
  → 客人离店就失联
  → 二次触达成本高
  → 会员体系建不起来

□ 服务体验靠人工
  → 24小时响应做不到
  → 员工水平参差不齐
  → 人员流动=经验流失
```

**这些问题的共同根源**:

```
→ 酒店是"信息孤岛"
→ 好的能力都在人脑子里，不在系统里
→ 没有工具能帮我们做决策

我们认为：AI数字员工能解决这个问题
```

## 第7页: 设备部署选项（关键更新）

**灵活选择：不用服务器 or 用服务器**

### 选项1: 零服务器方案（最低配置）

```
适用: 不想动现有IT基础设施

需要:
├─ 能上网的电脑 × 1-2台
├─ 员工手机（微信登录）
└─ 稳定的网络

费用: 0元（云端部署）

限制:
→ 多员工使用依赖各自的账号
→ 某些高级功能可能受限
→ 适合初步尝试
```

### 选项2: 服务器部署方案（推荐）

**如果我们有一台服务器，就能实现多员工共享**

```
适用: 酒店有服务器，或愿意采购一台服务器

服务器要求:
┌─────────────────────────────────────────────────────────────┐
│  推荐配置（入门级）                                          │
├─────────────────────┬───────────────────────────────────────┤
│ CPU                 │ Intel i5 / AMD Ryzen 5 及以上          │
├─────────────────────┼───────────────────────────────────────┤
│ 内存                 │ 16GB 起                               │
├─────────────────────┼───────────────────────────────────────┤
│ 硬盘                 │ 500GB SSD 起                          │
├─────────────────────┼───────────────────────────────────────┤
│ 操作系统             │ Ubuntu 22.04 / Windows Server 2019    │
├─────────────────────┼───────────────────────────────────────┤
│ 网络                 │ 固定IP或内网可访问                     │
├─────────────────────┼───────────────────────────────────────┤
│ 功耗                 │ 约100W/小时                            │
└─────────────────────┴───────────────────────────────────────┘

成本: 入门级服务器约3000-8000元
      可利旧现有服务器（如果有）

效果:
├─ 全酒店员工共享访问
├─ 数据本地存储，更安全
├─ 支持多终端同时在线
├─ 响应速度更快
└─ 适合长期使用
```

**一台服务器 = 多员工共享 + 数据安全 + 性能保障**

```
没有服务器的情况:
  前台A用电脑看数据 → B要用同一台电脑

有服务器的情况:
  服务器放在机房 → 所有员工用自己的电脑/手机访问
  数据集中存储在服务器 → 安全、可追溯、可备份
```

## 第8页: 数据安全保障

**你的数据永远是你的**

```
数据归属:
├─ 酒店经营数据 → 100%归酒店
├─ 客人隐私数据 → 100%归酒店
└─ 我们只用于提供服务，不用于其他目的

技术保障:
├─ 传输加密: HTTPS/TLS 1.2+
├─ 存储加密: AES-256
├─ 权限控制: RBAC三级权限
├─ 操作审计: 全程日志记录
└─ 备份机制: 多副本冗余
```

**权限体系**

```
【管理员】(业主/总经理)
├─ 查看所有数据
├─ 系统配置
└─ 权限分配

【运营者】(前厅/收益经理)
├─ 查看经营数据
├─ 使用AI功能
└─ 查看报表

【员工】(普通员工)
├─ 使用日常功能
├─ 无法导出敏感数据
└─ 无数据删除权限
```

**法律文件**

```
试点期提供:
├─ 《数据处理协议》(DPA)
├─ 《信息安全承诺书》
└─ 《试点合作协议》

试点结束时:
├─ 可要求删除全部数据
└─ 可导出备份
```
