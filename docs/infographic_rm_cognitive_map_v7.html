10大核心收益管理数学模型

① EMSRb保护水平(Belobaba1987)
P(D≥y) = P_{j+1} / P_j
多档最优保护水平·IDeaS/万豪OneYield/希尔顿OnQ/IHG RIRO的算法基石
② Littlewood's Rule(1972起源)
Accept if P₂ ≥ P₁ · P(D₁ ≤ C)
收益管理思想的真正源头·两档票价下接受/拒绝低价预订的最优规则
③ Gallego-Van Ryzin(1994)
p*(t) = θ⁻¹ · ln(α·x(t) / β)
泊松到达+价格敏感函数·高强度连续控制定价·高端度假场景最优解
④ Bid Price机会成本
BP = V_{t-1}(c) - V_{t-1}(c-1)
边际机会成本=多卖1间房的期望价值损失·实时门槛阈值控制方法
⑤ 网络RM线性规划
max Σrᵢxᵢ s.t. Ax ≤ C, x ≥ 0
多元多维约束下的收入最大化·IHG RIRO核心·航空网络RM到酒店的直接衍生
⑥ DP贝尔曼方程
V_t(c) = max{ E[R + V_{t+1}(c)] }
逆向归纳·状态(c容量, t时间)下的最优期望价值·库存分配场景的核心算法
⑦ 超售平衡点模型
OS* = n·(1-π̅_show) - C_deny / C_revenue
边际收益=边际拒绝成本的平衡点·超售量过高会赔偿、过低会浪费的最佳公式
⑧ XGBoost No-Show预测
ŷ = Σf_k(x_i) + Ω(f_k)
梯度提升树·正则化防过拟合·预测精度比传统启发式方法高30-50%
⑨ 渠道净收入优化
Rev_net = Σ(Rev_i - Com_i) · w_i
各渠道净收入×权重的最大化·OTA佣金15-25%下实际到账收入的真实计算
⑩ MNL选择概率模型
P_i = e^{U_i} / Σe^{U_j}
客户在多选项中选i的概率·U_i=消费者对i的效用函数·Choice-Based RM的基础

9大收益管理核心KPI

RevPAR
R = ADR × OCC
每间可售房收入·行业核心指标·四川估160-228元
GOPPAR
GOP / 可售房数
每间可售房毛利润·RM效果的终极度量
TRevPAR
RevPAR+非房/可售房
含餐饮SPA的总收入·中国酒店非房占20-30%
Flow-Through
ΔGOP / ΔRevenue
利润转化效率·目标50-60%·增量收入质量
MPI
本店OCC/竞圈OCC
市场渗透·>100=跑赢竞争圈
ARI
本店ADR/竞圈ADR×100
平均房价指数·与MPI交叉分析
RGI
本店RevPAR/竞圈RevPAR
收入生成指数·RMS最终检验
NRevPAR
(总收入-分销成本)/可售房
扣佣金净收入·OTA佣金影响大
预订提前天数
BkLead=Σ(入住-预订)/n
散客7-14天·团客30-90天
