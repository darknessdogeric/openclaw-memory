## 一、博弈分析四步法

### 框架总览

```
博弈分析 = 玩家识别 → 策略映射 → 均衡分析 → 策略建议

四步:
  1. 玩家识别     (Who)      - 谁是博弈方？各自核心利益？
  2. 策略映射     (Options)  - 各方的可选策略是什么？
  3. 均衡分析     (Balance)  - 当前均衡在哪里？谁会先改变？
  4. 策略建议     (Action)  - 我方最优策略是什么？
```

---

## 二、第一步：玩家识别

### 核心问题

```
谁是玩家？
  → 直接参与者
  → 间接影响者
  → 沉默第三方（可能被动卷入）

各自的核心利益是什么？
  → 显性利益（钱/权/名）
  → 隐性利益（安全/面子/关系）
  → 底线利益（必须保住的核心）
```

### 利益分析矩阵

| 玩家 | 显性利益 | 隐性利益 | 底线利益 |
|------|----------|----------|----------|
| 我方 | | | |
| 对手A | | | |
| 对手B | | | |
| 第三方 | | | |

### 关键问题

```
□ 玩家的真实利益和表面利益一致吗？
□ 谁和谁的利益是一致的？
□ 谁和谁的利益是对立的？
□ 有没有潜在的联盟可能？
□ 各方的底线是什么？
```

---

## 三、第二步：策略映射

### 核心问题

```
各方的可选策略空间是什么？
  → 显性策略（明面上能做的）
  → 隐性策略（私下能做的）
  → 底线策略（被迫才会用的）

策略之间的制约关系？
  → A这样做 → B会如何反应
  → B这样做 → A会如何反应
```

### 策略分析表

| 玩家 | 激进策略 | 温和策略 | 保守策略 |
|------|----------|----------|----------|
| 我方 | | | |
| 对手A | | | |
| 对手B | | | |

### 关键问题

```
□ 对手最可能选择什么策略？（基准策略）
□ 对手可能的意外策略是什么？
□ 我的策略选择如何影响对手的选择？
□ 有没有"让对手先动"的策略？
```

---

## 四、第三步：均衡分析

### 核心概念

```
纳什均衡：
  给定别人的选择，没有人愿意单方面改变策略
  
例子：
  两车相向而行，双方都靠右 → 均衡
  一方靠右，一方靠左 → 不是均衡（靠左的会想改变）
  
打破均衡的条件：
  → 外部冲击（新信息/新力量）
  → 一方先改变（先发优势）
  → 承诺机制（让对手相信我不会变）
```

### 均衡类型

| 均衡类型 | 特征 | 稳定性 |
|----------|------|--------|
| **占优均衡** | 不管别人怎么选，都是最优 | 非常稳定 |
| **纳什均衡** | 给定别人，不愿改变 | 稳定 |
| **混合均衡** | 随机选择，不可预测 | 稳定但脆弱 |
| **僵局** | 双方都不满意但都无法改变 | 表面稳定 |
| **协调博弈** | 需要双方配合才能成功 | 脆弱 |

### 关键问题

```
□ 当前是什么类型的均衡？
□ 均衡稳定吗？谁最想打破？
□ 打破均衡的触发条件是什么？
□ 我方有没有先发优势？
□ 承诺是否可信？
```

## 四、第四步：策略建议

### 核心策略类型

```
1. 混合策略
   定义：随机选择，不可预测
   适用：重复博弈中，让对手猜不透
   操作：不固定策略，让对手无法推断

2. 承诺策略
   定义：让对手相信你会行动
   适用：需要先发优势时
   操作：公开承诺 + 行动证明

3. 逆向归纳
   定义：从终局倒推
   适用：一次性重大决策
   操作：先想结果，再找路径

4. 让步策略
   定义：主动让步，换取长期合作
   适用：重复博弈，重视信誉
   操作：小让步 → 大合作

5. 威胁策略
   定义：声明如果对方X，我就Y
   适用：需要阻止对方行动
   操作：可信威胁 = 能力 + 意愿 + 成本
```

### 策略选择矩阵

| 博弈类型 | 最佳策略 | 禁忌 |
|----------|----------|------|
| **囚徒困境** | 针锋相对/以牙还牙 | 单方面合作 |
| **协调博弈** | 主动示好/建立信任 | 过度强硬 |
| **承诺博弈** | 承诺可信/先发制人 | 空洞威胁 |
| **信息博弈** | 信息隐藏/信号发射 | 信息泄露 |
| **重复博弈** | 合作优先/惩罚背叛 | 一次性博弈思维 |

### 策略行动清单

```
□ 我的最优策略是什么？
□ 备选策略是什么？
□ 如何让对手相信我的承诺？
□ 如果对手不配合，我的应对是什么？
□ 时间维度：短期 vs 长期策略一致吗？
```

## 五、信息博弈专项

### 信息不对称分析

```
我知道的 vs 对手知道的：
  □ 我知道什么对手不知道的？
  □ 对手知道什么我不知道的？
  □ 有什么是双方都不知道的？

信息策略：
  → 隐藏：不透露我知道的
  → 透露：选择性透露我知道的
  → 探测：试探对手知道什么
  → 伪装：让对手以为我知道的比我多
```

### 信号博弈

```
可信信号特征：
  → 成本高（撕毁代价大）
  → 可验证（可以被证实）
  → 一致性（说和做一样）

不可信信号：
  → 空头承诺
  → 成本低/无代价
  → 无法验证
```

## 六、实用博弈模型

### 模型1: 囚徒困境破局

```
困境：个人理性导致集体非理性

破局方法：
  1. 改变收益结构 → 让合作的收益更高
  2. 重复博弈 → 未来的惩罚让背叛不划算
  3. 承诺机制 → 让对方相信你会报复
  4. 外部 enforcement → 第三方强制执行
```

### 模型2: 智猪博弈

```
情况：大猪踩杠杆，小猪等待

小猪策略：等待
大猪策略：接受小猪搭便车，或改变规则

应用：大企业 vs 小企业
  → 小企业：等待/搭便车
  → 大企业：主动创新/承担成本
```

### 模型3: 斗鸡博弈

```
情况：两车相向，谁让谁输

博弈结果：
  → 双方都让：平局
  → 一方让一方冲：让的输
  → 双方都冲：双输

策略选择：
  → 观察对方决心
  → 发出可信信号（我不会让）
  → 找台阶下（先后退但不失面子）
```

### 模型4: 猎鹿博弈

```
情况：两人合作猎鹿可得大收益，单干只能抓兔子

理想：合作猎鹿
风险：对方可能背叛去抓兔子

策略：
  → 建立信任基础
  → 设计激励相容机制
  → 保留单干选项（备选方案）
```

## 七、商业博弈专项

### AHL项目博弈分析

```
主要玩家：
  → 投资人（要回报）
  → 酒店商户（要流量/收益）
  → C端用户（要体验/省钱）
  → 竞争平台（OTA/民宿平台）

核心博弈：
  投资人 vs 管理团队 → 委托代理博弈
  平台 vs 商户 → 渠道博弈
  商户 vs 用户 → 信任博弈
  平台 vs 竞争 → 差异化博弈
```

### 激励相容设计

```
让各方利益一致：
  → 投资人：资本回报 → 股权激励 + 对赌
  → 商户：流量收益 → 按效果付费 + 底薪保障
  → 用户：体验价值 → 会员积分 + 退赔保障
  → 团队：个人成长 → 期权 + 荣誉
```

## 十、博弈论核心原则

### 黄金法则

```
1. 站在对手角度思考
   "如果我是对手，我会怎么选？"
   
2. 承诺要可信
   不可信的承诺等于没有承诺
   
3. 重复博弈优先
   一次性的博弈用混策略，重复博弈用合作策略
   
4. 激励比意愿更重要
   "你希望对手怎么选"不重要
   "对手有什么动机这么选"才重要
   
5. 信誉是长期最优策略
   一次背叛的代价是永远失去信任
```
