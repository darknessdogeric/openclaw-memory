# 酒店/民宿 合作前信息搜集表（免费试点版）

> **版本**: V1.0  
> **合作模式**: 免费试点合作  
> **用途**: 评估合作匹配度 + 设计落地路径  
> **适用**: 所有酒店/民宿（经济型~高端）  
> **填写方式**: 可直接填写、打印后手写、或转为在线表单

我们目前所有合作均以**免费试点**方式进行，不收取任何费用。合作前只需要了解您的基本情况，以便判断我们能否帮到您，以及如何落地。

本表所有信息严格保密，仅用于方案设计参考。

## 快速匹配判断（采集人员用）

| 判断题 | 结果 | 建议 |
|--------|------|------|
| 有没有PMS？ | ☐有 ☐无 | 无PMS，OTA自动化难度大 |
| 核心痛点是否明确？ | ☐明确 ☐模糊 | 模糊需继续沟通 |
| 老板/负责人对AI态度？ | ☐有兴趣 ☐中立 ☐怀疑 | 怀疑者暂缓 |
| 日均OCC是否<70%？ | ☐是 ☐否 | <70%收益管理高度匹配 |
| 多平台手工维护？ | ☐是 ☐否 | 是→OTA自动化高度匹配 |
| 有无会员体系？ | ☐有 ☐无/弱 | 无/弱→私域维护匹配 |
