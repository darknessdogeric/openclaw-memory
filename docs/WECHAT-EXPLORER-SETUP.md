## 🔑 你需要做的（4 步，共 10 分钟）

### 第 1 步：扫码登录（1 分钟）

1. 浏览器打开：**https://down.mptext.top**
2. 看到二维码弹窗
3. 用**电脑端微信**（不是手机）扫码
4. 扫码成功后页面会显示控制台

⚠️ **重要**：必须用电脑端微信扫码，手机端微信扫不出来。

---

### 第 2 步：测试抓取（3 分钟）

1. 登录后，在搜索框输入 **"华住"**
2. 搜索结果中找到"华住集团"官方号 → 添加到列表
3. 点击该公众号 → 看是否能列出文章
4. 选一篇文章 → 抓取 → 导出 markdown 格式
5. **截图保存**（这一步完成后给我截图，我可以帮你确认）

如果一切正常，你应该能在浏览器里看到华住最新的几篇文章标题和摘要。

---

### 第 3 步：抓取并复制 Cookie（2 分钟）— **关键**

抓取成功后，按 F12 打开浏览器开发者工具：

1. 切到 **Network** 标签
2. 刷新页面（或随便点一下触发请求）
3. 找到任意一个对 `down.mptext.top` 或 `mp.weixin.qq.com` 的请求
4. 右键 → **Copy → Copy as cURL (bash)**
5. 把 curl 命令粘贴到一个文本文件里
6. 从中提取出 `Cookie:` 后面那一长串字符
7. **用加密方式发给我**（微信/邮件/Notion 都行）

我拿到 Cookie 后，会自动配置到 `~/.config/wechat_article/credentials.json`（加密存储），之后所有抓取都不需要你再扫码。

---

### 第 4 步：可选 — 元数据抓取（如果想要阅读量/评论）

公众号阅读量、评论数据需要额外配置：

1. 下载 wxdown-service：https://github.com/wechat-article/wxdown-service/releases
2. Windows 用户下载 `wxdown-service.exe`
3. 双击运行（需要管理员权限）
4. 安装 mitmproxy 证书（首次运行会提示）
5. **设置系统代理**为 `127.0.0.1:65000` ⚠️
6. 在电脑微信中打开任意一个目标公众号的文章
7. credentials 自动同步到 down.mptext.top

⚠️ **风险**：系统代理设置会**劫持你所有 HTTPS 流量**。建议：
- 用完立刻关闭 wxdown-service + 还原系统代理
- 或者在另一台电脑/虚拟机上跑 wxdown-service

**我的建议**：前 7 天先不配置元数据，纯标题+摘要足够覆盖 80% 的信号价值。阅读量是 nice-to-have。
