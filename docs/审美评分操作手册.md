# 审美评分操作手册 V1.0

> 版本: V1.0
> 创建: 2026-04-02
> 定位: 让审美判断可执行、可教学、可校准
> 目标: 5分钟内完成一次完整审美评分

---

## 核心框架

```
审美评分 = Σ(维度权重 × 维度得分)

五维度权重:
├─ 气韵生动性 (30%) - 核心，决定性
├─ 和谐统一性 (20%) - 结构性
├─ 细节精致性 (20%) - 执行性
├─ 创新突破性 (15%) - 增量性
└─ 目的达成性 (15%) - 功能性
```

---

## 一、气韵生动性 (30%)

**本质**: 对象是否有"精神"，是否"活"着

### 0-10分评判标准

```
10分 - 神品
定义: 气韵达到极致，仿佛有灵魂
特征:
├─ 看完后久久不能忘怀
├─ 精神被震撼或被洗涤
├─ 开创了一个新的审美范畴
案例:
├─ 王羲之《兰亭序》
├─ 贝多芬《第九交响曲》
└─ 李白《将进酒》

9分 - 逸品
定义: 气韵非凡，超出期待
特征:
├─ 明显感受到创作者的精神境界
├─ 有"这才是真正的XX"的感觉
├─ 技术与精神完美统一
案例:
├─ 莫奈《睡莲》系列
├─ 宫崎骏《千与千寻》
└─ 乔布斯iPhone发布会演讲

8分 - 精品
定义: 气韵充沛，高于一般
特征:
├─ 有明确的方向感和精神意图
├─ 能感受到创作者的用心
├─ 有让人想反复体验的冲动
案例:
├─ 苹果产品设计
├─ 戴森产品设计
├─ 顶级酒店大堂设计

7分 - 佳作
定义: 气韵良好，质感突出
特征:
├─ 有清晰的精神表达
├─ 有方向感但不极致
├─ 能打动普通人
案例:
├─ 好的品牌设计
├─ 有感染力的广告
└─ 精心设计的酒店客房

6分 - 良品
定义: 有气韵，但不突出
特征:
├─ 能看出有精神追求
├─ 但表达不够充分
├─ 普通人觉得还行
案例:
├─ 多数中档品牌设计
├─ 普通精品酒店
└─ 有内容但不出彩的演讲

5分 - 中品
定义: 气韵一般，平平无奇
特征:
├─ 不死板但也不生动
├─ 有功能但没有灵魂
├─ 看完就忘
案例:
├─ 模板化PPT
├─ 功能性文案
└─ 普通酒店标准间

4分 - 下品
定义: 气韵不足，机械感强
特征:
├─ 明显感觉到"做作"
├─ 堆砌元素但没有精神
├─ 让人不舒服
案例:
├─ 过度设计的网页
├─ 炫技但无内容的演讲
└─ 五星级酒店大堂的"土豪感"

3分 - 粗品
定义: 气韵稀薄，呆滞
特征:
├─ 套话连篇
├─ 模板套用
├─ 没有观点
案例:
├─ 政府公文
├─ 商业套话文案
└─ 流水账汇报

2分 - 废品
定义: 气韵全无，死气沉沉
特征:
├─ 完全功能主义
├─ 毫无精神追求
├─ 让人厌烦
案例:
├─ 丑陋的城市规划
├─ 劣质地产广告
└─ 充满错别字的宣传

1分 - 毒害
定义: 虚假、误导、有害
特征:
├─ 虚假宣传
├─ 过度承诺
├─ 审美污染
案例:
├─ 电信诈骗短信
├─ 虚假保健品广告
└─ 恶意营销

0分 - 禁忌
定义: 审美和道德的双重禁忌
案例:
├─ 纳粹美学
├─ 邪教宣传
└─ 儿童色情
```

### 气韵判断三问

```
问1: 有没有方向感?
├─ 这个作品想表达什么?
├─ 它要引导我去哪里?
└─ 如果回答不了 → 3分以下

问2: 有没有精神感?
├─ 这是谁做的? 能感受到他吗?
├─ 他是有感而发还是机械复制?
└─ 如果感受不到人 → 5分以下

问3: 有没有动力感?
├─ 这个作品让你想行动吗?
├─ 它是死的还是活的?
└─ 如果是死的 → 4分以下
```

## 二，和谐统一性 (20%)

**本质**: 各部分是否有机统一，还是机械拼凑

### 0-10分评判标准

```
10分 - 天衣无缝
定义: 整体与部分完美统一，无法增删一字
特征:
├─ 去掉任何元素，整体都会受损
├─ 每个元素都为整体服务
├─ 结构本身就是意义
案例: 《道德经》全文

9分 - 浑然一体
定义: 高度统一，看不出拼接
特征:
├─ 风格、语言、结构完全一致
├─ 细节服从整体
├─ 有机统一
案例: 苹果产品系列

8分 - 结构清晰
定义: 统一性好，层次分明
特征:
├─ 有明确的结构逻辑
├─ 各部分各司其职
├─ 没有明显违和感
案例: 多数优秀PPT

7分 - 基本统一
定义: 大方向统一，有些小问题
特征:
├─ 整体风格一致
├─ 但某些细节略显突兀
└─ 不影响整体

6分 - 勉强统一
定义: 表面统一，实际分裂
特征:
├─ 看起来还行，但经不起细看
├─ 某些部分风格不一致
└─ 专业人士能看出问题

5分 - 各行其是
定义: 各部分独立，缺乏整体感
特征:
├─ 页面之间没有逻辑
├─ 风格跳跃
└─ 元素堆砌
案例: 多数套模板PPT

4分以下 - 混乱
定义: 完全不统一
特征:
├─ 每个部分各唱各的调
├─ 让人眼花缭乱
└─ 毫无整体感
```

### 和谐判断三问

```
问1: 结构清晰吗?
├─ 能不能用一句话说清楚整体?
└─ 如果不能 → 5分以下

问2: 元素协调吗?
├─ 颜色/字体/风格是否统一?
└─ 如果混乱 → 5分以下

问3: 有没有违和感?
├─ 有没有让你"出戏"的元素?
└─ 如果有 → 6分以下
```

## 三，细节精致性 (20%)

**本质**: 执行质量，是否用心

### 0-10分评判标准

```
10分 - 鬼斧神工
定义: 细节极致完美，超出期待
特征:
├─ 每一处细节都经过深思熟虑
├─ 经得起无限放大审视
├─ 细节本身就是艺术品
案例: 百达翡丽手表机芯

9分 - 匠心独运
定义: 细节精湛，彰显用心
特征:
├─ 明显感觉到工匠精神
├─ 每个细节都在正确位置
├─ 经得起专业审视
案例: 劳斯莱斯内饰

8分 - 精心打磨
定义: 细节考究，品质感强
特征:
├─ 没有明显的瑕疵
├─ 细节处理到位
├─ 经得起挑剔
案例: 苹果产品细节

7分 - 认真细致
定义: 细节良好，品质合格
特征:
├─ 没有低级错误
├─ 细节处理用心
└─ 但不是极致

6分 - 基本合格
定义: 细节过得去，但不突出
特征:
├─ 没有明显问题
├─ 但也不够精致
└─ 专业人士能挑出毛病

5分 - 粗糙
定义: 细节粗糙，经不起看
特征:
├─ 有明显的瑕疵
├─ 能看出赶工痕迹
└─ 细节没有打磨
案例: 多数廉价商品

4分以下 - 粗制滥造
定义: 完全不讲究细节
特征:
├─ 满是错误
├─ 偷工减料
└─ 让人不适
```

### 细节判断三问

```
问1: 有没有低级错误?
├─ 错别字/语法错误/色差/像素?
└─ 如果有 → 4分以下

问2: 经得起放大看吗?
├─ 放大10倍后还美吗?
└─ 如果不 → 6分以下

问3: 细节是为整体还是为炫技?
├─ 细节服务于整体?
└─ 如果炫技 → -2分
```

## 四，创新突破性 (15%)

**本质**: 是否有新的东西

### 0-10分评判标准

```
10分 - 开宗立派
定义: 开创了全新的审美范式
特征:
├─ 在此之前不存在
├─ 被人模仿但无法超越
├─ 成为历史标杆
案例: 毕加索《亚维农少女》

9分 - 集大成者
定义: 在前人基础上实现质的飞跃
特征:
├─ 深刻理解了传统
├─ 实现了真正的突破
├─ 重新定义了领域
案例: iPhone重新定义手机

8分 - 突破创新
定义: 有明显的创新点
特征:
├─ 有让人"眼前一亮"的东西
├─ 不是简单模仿
├─ 有自己的独特价值
案例: 戴森吹风机

7分 - 有新意
定义: 有创新的尝试
特征:
├─ 不是完全重复
├─ 有自己的想法
└─ 但不是突破性的

6分 - 微创新
定义: 有一点点新，但不够
特征:
├─ 在已有框架内小改
├─ 没有实质性突破
└─ 但态度可嘉

5分 - 循规蹈矩
定义: 完全按照既有模式
特征:
├─ 没有错误
├─ 但也没有新意
└─ 安全的平庸

4分以下 - 抄袭/倒退
定义: 模仿甚至不如模仿对象
特征:
├─ 明显抄袭痕迹
└─ 或者连模仿都做不好
```

### 创新判断三问

```
问1: 这是第一次看到吗?
├─ 有没有"似曾相识"的感觉?
└─ 如果完全重复 → 5分以下

问2: 它在试图超越什么?
├─ 有没有明确的参照和超越?
└─ 如果没有 → 6分以下

问3: 新的是进步的还是退步的?
├─ 创新是否让作品更好?
└─ 如果为了创新而创新 → -2分
```

## 五，目的达成性 (15%)

**本质**: 是否有效完成了它的目标

### 评判标准

```
这个维度需要先明确"目的是什么"

如果是商业文案:
├─ 10分: 完美传达，打动目标受众，产生行动
├─ 7分: 清晰传达，让人产生兴趣
├─ 5分: 说清楚了，但不打动
├─ 3分: 让人困惑或反感
└─ 1分: 完全误导

如果是设计:
├─ 10分: 美与功能完美统一，让人想拥有
├─ 7分: 美观且实用
├─ 5分: 能用但不够美
├─ 3分: 不美也不好用
└─ 1分: 完全失败

如果是演讲:
├─ 10分: 让人行动，改变想法，记住一辈子
├─ 7分: 让人信服，有收获
├─ 5分: 听完就忘
├─ 3分: 让人昏昏欲睡
└─ 1分: 让人反感
```

### 目的判断三问

```
问1: 创作者想达成什么?
├─ 目标清晰吗?
└─ 如果目标混乱 → 从5分起步

问2: 目标达成了吗?
├─ 受众有反应吗?
└─ 如果没有 → 4分以下

问3: 代价是什么?
├─ 为了目的是否牺牲了美?
└─ 如果牺牲太多 → -2分
```

## 综合评分计算

### 公式

```
总分 = (气韵 × 0.30) + (和谐 × 0.20) + (细节 × 0.20) + (创新 × 0.15) + (目的 × 0.15)

四舍五入到整数
```

### 示例计算

**苹果官网首页**:
```
气韵: 8 (简洁大气，有方向感)
和谐: 9 (极度统一)
细节: 9 (像素级精致)
创新: 7 (不是颠覆性，但有特色)
目的: 9 (让人想购买)

总分 = (8×0.30) + (9×0.20) + (9×0.20) + (7×0.15) + (9×0.15)
     = 2.4 + 1.8 + 1.8 + 1.05 + 1.35 = 8.4 → 8分
```

**政府宣传栏**:
```
气韵: 3 (套话连篇)
和谐: 5 (勉强统一)
细节: 4 (粗糙)
创新: 2 (完全重复)
目的: 4 (让人忽略)

总分 = (3×0.30) + (5×0.20) + (4×0.20) + (2×0.15) + (4×0.15)
     = 0.9 + 1.0 + 0.8 + 0.3 + 0.6 = 3.6 → 4分
```

## 快速评分流程 (5分钟)

```
第1分钟: 整体感受
├─ 第一印象是什么?
├─ 喜欢还是不喜欢?
└─ 直觉打分: ___

第2分钟: 气韵判断
├─ 有方向感吗?
├─ 有精神感吗?
├─ 有动力感吗?
└─ 气韵打分: ___

第3分钟: 结构判断
├─ 各部分协调吗?
├─ 结构清晰吗?
└─ 和谐打分: ___

第4分钟: 细节判断
├─ 经得起放大看吗?
├─ 精致吗?
└─ 细节打分: ___

第5分钟: 调整与确认
├─ 有创新吗?
├─ 目的达成了吗?
├─ 计算总分
└─ 最终打分: ___
```
