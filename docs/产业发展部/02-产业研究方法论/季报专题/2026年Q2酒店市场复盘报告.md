**报告日期**：2026年7月25日（T+25季末复盘）  
**覆盖期间**：2026年4月1日—6月30日  
**数据来源**：文旅部、CHAT/厚海数据平台、STR、携程、Fliggy、木鸟民宿、公开财报

## 一、核心摘要

2026年Q2，中国酒店市场延续复苏态势，但结构性分化加剧。景气指数升至近七个季度高点（-9），入住率指数率先转正，显示需求基本面趋稳。端午假期（Q2末）成为本季最大变量：出游人次1.24亿、旅游收入444.56亿元，数据平稳，但出行模式发生根本性转变——"松弛出游"取代"打卡式远行"，近距化、理性化成为主流消费特征。

**五大收益KPI概览**：

| KPI | Q2 2026表现 | 同比 | 趋势 |
|-----|------------|------|------|
| OCC（入住率） | 约64-66% | +2~3ppts | 🟢 稳步上升，入住率指数转正 |
| ADR（元） | 约¥420-440 | +3~5% | 🟡 复苏但承压，低于疫前水平 |
| RevPAR（元） | 约¥268-285 | +6~8% | 🟢 量价齐升，表现优于ADR |
| MPI（市场渗透指数） | 约98-102 | 趋近基准 | 🟡 一线城市走稳，下沉市场分化 |
| ARI（平均房价指数） | 约92-96 | 仍低于2019 | 🟡 供需再平衡中 |

## 三、偏差分析

### 3.1 ADR复苏幅度偏差

**问题**：Q2 ADR同比+3~5%，低于RevPAR增幅（+6~8%），说明ADR仍是短板。

**根因**：
```
直接原因：新增供给持续入市，稀释整体房价
  → 2025年全年新增9,800家中档以上客房，Q2集中爬坡
  → 新开业酒店为抢市占率，定价偏低，拉低区域ADR均值

结构原因：出行结构转变使低价位产品占比提升
  → "松弛出游"以周边游、短途游为主
  → 目的地平均房价低于长途跨省游
  → 出行模式变化使ADR统计口径出现结构性下压
```

### 3.2 三四线城市分化偏差

**问题**：Q2三四线城市表现分化加剧，非统一高增长。

**根因**：
```
一线现象：有独特IP的县域（古镇/避暑/民俗）大幅跑赢
  → 赣州端午民宿订单+25%，青岛/北京/南京成最热门
  → 缺乏差异化定位的普通县域依然承压

机制原因：消费降级使"特色价值"vs"普通产品"差距拉大
  → 高端度假民宿入住率下滑
  → 平价农家民宿、连锁酒店占比提升
  → 同程低价策略受益，差异化精品跑赢
```

## 四、五大收益KPI深度分析

### 4.1 OCC（入住率）

**全国水平**：约64-66%，同比提升约2-3个百分点

**结构特征**：
- 🟢 入住率指数由负转正（CHAT定义：景气指数体系）
- 🟢 端午假期酒店间夜量同比+30%（Fliggy平台）
- 🟢 Q1全行业RevPAR+8.5%验证需求坚实

**城市分级表现**（估算）：

| 城市等级 | Q2 OCC | 同比 | 主要驱动 |
|---------|--------|------|---------|
| 一线城市 | 72-76% | +2~3ppts | 商旅回暖+广交会 |
| 新一线 | 68-74% | +3~4ppts | 旅游热持续+会展 |
| 二线旅游城市 | 65-72% | +2~4ppts | 端午/避暑需求 |
| 三四线县域 | 55-68% | 分化 | 有IP者强，无IP者弱 |

### 4.2 ADR（平均房价）

**全国水平**：约¥420-440，同比+3~5%

**结构特征**：
- 🟡 复苏但仍低于2019年同期水平（约恢复至95%）
- 🟡 豪华/高端酒店ADR仍然承压（高基数效应+供给增加）
- 🟢 人均预订金额同比+16%（Fliggy），反映消费升级意愿

**关键矛盾**：间夜量增长（+30%）未完全传导至ADR提升，新增供给是主因。

**城市分级ADR表现**（估算）：

| 城市等级 | Q2 ADR | 同比 | 特点 |
|---------|--------|------|------|
| 一线城市 | ¥550-600 | +4~5% | 商旅复苏支撑 |
| 新一线 | ¥400-480 | +3~5% | 旅游+品质升级 |
| 二线旅游 | ¥320-400 | +2~4% | 端午旺季 |
| 三四线 | ¥180-280 | -2~+5% | 分化极大 |

### 4.3 RevPAR（每可售房收入）

**全国水平**：约¥268-285，同比+6~8%

**计算验证**：RevPAR = OCC × ADR  
- Q2 OCC约64-66% × ADR约¥420-440 ≈ ¥269-290  
- 实际约¥268-285，符合估算区间

**核心驱动**：间夜量增长（OCC提升）是RevPAR增长主驱动力，ADR贡献有限。

**季度节奏**：

| 月份 | RevPAR特点 |
|------|-----------|
| 4月 | 清明后淡季，广交会（4月中）单月冲高 |
| 5月 | 五一黄金周强势（参考五一复盘数据：RevPAR+5~7%），节后回落 |
| 6月 | 端午（6月底）稳健，近郊游填充淡季 |

### 4.4 MPI（市场渗透指数）

**定义**：某酒店/集团RevPAR ÷ 市场整体RevPAR × 100

**Q2表现**（估算）：

| 集团/类型 | Q2 MPI | 解读 |
|-----------|--------|------|
| 华住集团 | 约105-110 | 🟢 高于市场均值，加盟模式抗压 |
| 锦江酒店 | 约98-102 | 🟡 基本持平 |
| 首旅如家 | 约90-95 | 🟡 低于均值，经济型占比拖累 |
| 亚朵集团 | 约110-118 | 🟢 品质定位受青睐 |
| 头部集中度 | CR3约42% | 集团化优势持续扩大 |

### 4.5 ARI（平均房价指数）

**定义**：某酒店/集团ADR ÷ 市场整体ADR × 100

**Q2表现**（估算）：

| 集团/类型 | Q2 ARI | 解读 |
|-----------|--------|------|
| 奢华型 | 约180-220 | 供给增加，溢价收窄 |
| 高端型 | 约130-160 | 🟡 竞争加剧 |
| 中高端型 | 约100-120 | 🟢 市场主力，定价稳固 |
| 经济型 | 约55-75 | 低价支撑OCC，ARI承压 |

## 五、季节性因素验证

### 5.1 Q2季节性特征

```
Q2 = 淡旺季过渡期 + 三个节点

4月：清明（1天）+ 广交会（4月中，珠三角专属旺季）
5月：五一黄金周（5天，年度最强假期的第一峰）
6月：端午（3天，非高峰）+ 暑期预热（6月下旬开始）
```

### 5.2 季节性节奏验证

| 预测（基于历史规律） | Q2实际 | 验证 |
|---------------------|--------|------|
| 4月前半为淡季 | ✅ 清明后回调 | 🟢 正确 |
| 广交会期间珠三角冲高 | ✅ 数据验证 | 🟢 正确 |
| 五一是Q2最高峰 | ✅ RevPAR+5~7% | 🟢 正确 |
| 端午是"小五一"但低于五一 | ✅ 间夜量+30%（属强势）| 🟢 基本正确 |
| 6月下旬暑期预热 | ✅ 7月暑期搜索+40% | 🟢 正确预见 |

### 5.3 端午季节性新特征（重要更新）

**新发现**：2026年端午出现历年未见的新季节性规律：

```
1. 出行半径大幅缩短：人均出游半径缩至80公里以内
   → 往年：跨省热门景区（长途）
   → 今年：城市近郊（短途）

2. "松弛出游"成为第一考量：低价奔波取代打卡出圈
   → 往年：请3天假休8天（最远最热）
   → 今年：家门口近郊，拒绝溢价

3. 住宿消费降级：高端民宿OCC下滑，平价产品受益
   → 往年：度假民宿溢价可接受
   → 今年：主动规避节假日民宿翻倍溢价
```

## 八、结论与Q3展望

### 8.1 Q2核心结论

```
1. 景气修复确认：景气指数-9（近7季最高），入住率指数率先转正
2. RevPAR增长稳健：+6~8%，主要由间夜量增长驱动
3. ADR仍是短板：+3~5%，新增供给和出行结构变化双重压制
4. 消费模式转变：松弛出游、近郊化、理性消费成为新常态
5. 城市分化加剧：有IP县域大幅跑赢，普通县域承压
```

### 8.2 Q3（暑期）展望

**有利因素**：
- 暑期旅游旺季（7-8月）搜索热度同比+40%
- 入境游持续回暖（免签政策利好）
- 亲子+避暑需求预计创历史高位

**压力因素**：
- ADR高基数效应（2025年暑期ADR表现较好）
- 新增供给持续入市（Q2新开业酒店爬坡）
- 极端天气风险（台风/洪涝）

**Q3 RevPAR预判**：+5~8%（区间与Q2相同，量稳价承压）
