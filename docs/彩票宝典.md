## 五、博弈论过滤规则

### 5.1 过滤表

| 类别 | 号码 | 处理 | 原因 |
|------|------|------|------|
| 生日高频区 | 01-12 | 降权，只选13+ | 超80%彩民用生日 |
| 7的倍数 | 7,14,21,28,35 | 降权 | 7被视为幸运数 |
| 日期相关 | 26,20,2,6 | 降权 | 2026年26被高频选 |
| 吉祥数字 | 8,6,9 | 降权 | 8在中国文化中吉利 |

### 5.2 最优反人群组合特征

```
✅ 包含13-18之间的低频号
✅ 包含2区(22-28)的热号作为托底
✅ 后区包含大遗漏号(4,6,9,11)
✅ 前区无连号（或有但不是热门连号）
✅ 和值在85-110之间
```

## 九、凯利公式

### 9.1 公式

```
f* = (p × b - q) / b

其中：
- f* = 最优投注比例
- p = 胜率（预估）
- q = 1 - p
- b = 赔率（净赔率 = 赔率 - 1）
```

### 9.2 应用

- 由于彩票胜率极低，采用**分数凯利**（如1/8凯利）
- 严格控制亏损，避免过早清空本金

## 十二、注意事项

1. **彩票是随机事件**：任何预测方法数学上都不比随机选号强
2. **V5.0提升的是期望收益**：不是提升中奖概率，而是降低分红稀释+风险控制
3. **必须先复盘再预测**：每次执行必须完成Step 1-3
4. **官网数据为准**：开奖结果必须以官网为准
5. **持续自进化**：每期预测后记录表现，持续优化模型
