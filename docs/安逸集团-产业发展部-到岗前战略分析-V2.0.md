## 三、竞争格局与生态位

### 3.1 四川省酒店集团竞争图谱（V1.0 升级）

```
第一梯队（全国性）
├─ 锦江国际集团（上海）— "安逸的锦江"仅限四川省内品牌授权，不冲突
├─ 华住集团 — 全季/汉庭/桔子等全面渗透
└─ 首旅如家 — 如家/和颐/建国等

第二梯队（区域性强）
├─ 安逸酒店集团 ★ — 省级国资旗舰，450+酒店，但品牌市场化程度低
├─ 明宇集团 — 四川民营酒店集团，中高端较强
└─ 岷山集团 — 四川老牌酒店集团（Eric 前东家）

第三梯队（单体/连锁）
├─ 亚朵/全季/丽枫等 — 抢占四川中端市场
└─ 大量单体酒店 — 被 OTA 平台绑架
```

### 3.2 安逸集团核心优劣势

| 优势 | 劣势 |
|------|------|
| 省级国资背书+政策资源 | 品牌市场化程度低 |
| 庞大的资产体量（6 万间房） | 458 家酒店分散、管理难度大 |
| 金牛/锦江历史品牌溢价 | "安逸"新品牌尚未建立认知 |
| 整合省直资产的特殊通道 | 国企体制创新速度受限 |
| 30 亿注册资本的资金实力 | 缺乏市场化人才和激励机制 |

### 3.3 中高端生活方式酒店赛道（7/22 吸收的新维度）

**赛道选择依据**：

```
为什么不是顶奢？
  - 顶奢 = Aman/Bvlgari 级别（规模小、客户窄）
  - 安逸国资委背景 = 应服务更广客群

为什么不是中端？
  - 中端 = 标准化为主（如华住系）
  - 安逸巴蜀文化母体深度 = 难以标准化

为什么是中高端？（$150-400 价位 = 集团核心战场）
  - 文化主题酒店的"甜区"
  - 客户愿意为文化付溢价
  - 规模可复制
  - 国资委背景可支撑
  - 与君亭、亚朵、Indigo 直接对标
```

**5 个对手的差异化机会**：

| 亚朵 | ★ | ★★ | ★★★ | ★★★★★ | ★★ |
| 华住 | ★ | ★ | ★★ | ★★★★★ | ★★ |

### 3.4 战略性机会窗口

```
如果安逸集团要实现"从资产管理公司到品牌酒店集团"的跃迁，
则必须解决三个问题：
  1. 品牌市场化 —— "安逸"品牌从 0 到 1（已在 49 页规划中明确）
```
