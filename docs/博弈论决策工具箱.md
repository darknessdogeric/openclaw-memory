## 一、核心决策框架

### 1.1 三问决策法

```
遇到任何决策，先问三个问题：

问题1: 谁是参与者?
├─ 有哪些人和组织会影响结果?
├─ 每个参与者的目标是什么?
└─ 他们知道什么? 不知道什么?

问题2: 利益结构是什么?
├─ 零和游戏? 还是正和游戏?
├─ 合作收益更高? 还是竞争收益更高?
└─ 短期利益 vs 长期利益?

问题3: 什么是均衡?
├─ 如果每个人都很理性，最终会怎样?
├─ 有没有占优策略?
└─ 什么样的结果最稳定?
```

### 1.2 博弈类型识别

```
四象限分类法:

              │ 合作可能  │ 竞争可能
──────────────┼───────────┼──────────
信息对称      │ 协调博弈   │ 零和博弈
(都知道规则)  │ (一起做大) │ (你死我活)
──────────────┼───────────┼──────────
信息不对称    │ 信号博弈   │ 囚徒困境
(有人知道     │ (需要证明) │ (背叛风险)
有人不知道)   │           │
──────────────┴───────────┴──────────

判断方法:
├─ 看是"一起做大"还是"你死我活"
├─ 看信息是否对称
└─ 决定采取什么策略
```

### 2.3 常见情境决策卡

#### 情境1: 谈判定价

```
【情境】
├─ 你要卖一个东西
├─ 对方要买
├─ 价格没标准

【博弈分析】
├─ 类型: 讨价还价(两人零和)
├─ 信息: 双方都知道自己的底线
├─ 时间: 可能一次，也可能多次

【推荐策略】
├─ 不要先出价
├─ 让对方先亮底牌
├─ 锚定效应: 先出价的人设定锚点
└─ 留有余地，不要太极端

【禁忌】
├─ 不要暴露你的实际底线
├─ 不要太急于成交
└─ 不要接受第一个offer(除非足够好)
```

#### 情境2: 合作谈判

```
【情境】
├─ 双方可以合作做大蛋糕
├─ 但要分蛋糕
├─ 蛋糕怎么分?

【博弈分析】
├─ 类型: 合作博弈(正和)
├─ 信息: 都知道合作价值
├─ 时间: 长期关系

【推荐策略】
├─ 争取大份额，但不要吃独食
├─ 建立互惠机制
├─ 先小人后君子
└─ 把丑话说在前面

【禁忌】
├─ 不要让步太多(示弱会招欺负)
├─ 不要一次让步太大
└─ 不要忘记写合同
```

#### 情境3: 竞争定价

```
【情境】
├─ 你和竞争对手抢客户
├─ 价格战是常态
├─ 降价可以赢单，但伤利润

【博弈分析】
├─ 类型: 价格战(可能变成囚徒困境)
├─ 信息: 对方成本是黑箱
├─ 时间: 长期博弈

【推荐策略】
├─ 不要主动发起价格战
├─ 如果对方降价，不要立即跟进
├─ 寻找差异化，避免正面
├─ 建立非价格竞争力
└─ 如果必须降价，一次降到位，然后守价

【禁忌】
├─ 恶性竞争，两败俱伤
├─ 低于成本定价
└─ 永远的价格战心态
```

#### 情境4: 求职谈判

```
【情境】
├─ 你要跳槽
├─ 新公司给了offer
├─ 你想谈更高薪资

【博弈分析】
├─ 类型: 信息不对称
├─ 你知道自己的价值
├─ 公司知道预算上限
├─ 时间: 一次博弈，但影响长期

【推荐策略】
├─ 手里有多个offer时最强
├─ 不要先亮底牌期望薪资
├─ 让他们先出价
├─ 每次要求比offer高10-20%
└─ 谈整体package，不只谈工资

【禁忌】
├─ 只看钱，不看发展
├─ 接受第一个offer(除非很满意)
├─ 威胁要走以获取更多
└─ 情绪化谈判
```

## 三、博弈论思维模型

### 3.1 信誉建立模型

```
核心原理: 在多次博弈中，信誉是最重要的资产

建立信誉:
├─ 言行一致: 说到的要做到
├─ 长期导向: 牺牲短期，换长期信任
├─ 可预测性: 让人能预测你的行为
└─ 惩罚机制: 明确背叛的代价

破坏信誉:
├─ 说谎一次，需要十次真话弥补
├─ 短期利益破坏长期信任
└─ 一旦被认为不可靠，很难恢复
```

### 3.2 信号发射模型

```
核心原理: 信息不对称时，需要发射可信的信号

好的信号(成本高，难以伪造):
├─ 金钱投入(展示承诺)
├─ 时间投入(展示诚意)
├─ 声誉资本(展示信誉)
└─ 第三方认证(展示专业)

坏的信号(成本低，容易伪造):
├─ 口头承诺
├─ 自我宣称
└─ 空头支票

实践:
├─ 谈判时，展示你的替代选项
├─ 求婚时，展示你的投入成本
└─ 商业合作时，展示你的沉没成本
```

### 3.3 逆向归纳模型

```
核心原理: 从终点倒推，从未来倒推现在

方法:
1. 想象最终结局
2. 问: 什么行为导致了那个结局?
3. 重复，直到当前

应用:
├─ 商业: 想象5年后你想成为什么，现在该做什么
├─ 谈判: 想象最坏情况发生，你现在该怎么准备
├─ 竞争: 想象对手最终会怎么做，你现在如何应对
└─ 人生: 想象临终时你后悔什么，现在如何避免
```

## 四、博弈论与AHL应用

### 4.1 AHL vs 酒店

```
【博弈关系】
├─ 酒店是供给方
├─ AHL是平台方
├─ 旅客是需求方
├─ 零和? 还是正和?

【分析】
├─ 如果AHL抢走酒店客人 → 零和
├─ 如果AHL帮酒店获客 → 正和
└─ 关键: AHL的价值主张

【策略】
├─ 强调正和，不是抢客
├─ 展示增量价值
├─ 让酒店看到增量蛋糕
└─ 建立互惠机制
```

### 4.2 AHL vs OTA

```
【博弈关系】
├─ OTA收取高佣金(15-25%)
├─ 酒店利润被压缩
├─ OTA是流量中介

【囚徒困境】
├─ 酒店: 独立vs入驻OTA
├─ 都入驻OTA: 大家都降价保量
├─ 都不入驻: 大家价格稳定
├─ 一方入驻，另一方不: 入驻方获客，不入驻方受损

【AHL的机会】
├─ 成为OTA的替代
├─ 降低佣金，提高酒店利润
├─ 直接连接酒店和旅客
└─ 建立去中心化信任机制
```

### 4.3 试点酒店谈判

```
【博弈分析】
├─ 情境: 试点合作谈判
├─ 类型: 合作博弈(正和)
├─ 信息: 酒店知道需求，你有技术
├─ 时间: 长期关系的开始

【策略】
├─ 先给予，后索取
├─ 展示成功案例(哪怕小)
├─ 强调免费试点，降低风险
├─ 承诺退出机制，降低顾虑
└─ 建立互惠条款

【禁忌】
├─ 不要夸大效果
├─ 不要贬低竞争对手
└─ 不要只顾自己利益
```

## 五、博弈论思维测试

### 5.1 每日一练

```
情境1: 你在闲鱼卖东西
├─ 买家出价是原价的一半
├─ 你的策略是什么?

情境2: 你去相亲
├─ 对方问你的年收入
├─ 你的策略是什么?

情境3: 你在公司开会
├─ 你有一个好主意
├─ 但老板可能不采纳
├─ 你的策略是什么?

情境4: 你发现同事在偷懒
├─ 但他是你朋友
├─ 你的策略是什么?
```

### 5.2 答案分析

```
情境1: 闲鱼卖东西
├─ 分析: 讨价还价博弈
├─ 策略: 不要立即拒绝，提出还价
├─ 锚定效应: "可以，但能否加XX"
└─ 底线: 低于某价不出

情境2: 相亲
├─ 分析: 信息不对称博弈
├─ 策略: 不直接回答，反问对方
├─ 信号: 展示价值，但不炫富
└─ 底线: 如果对方只看钱，说明不合

情境3: 公司开会
├─ 分析: 信号发射博弈
├─ 策略: 先收集信息，了解老板痛点
├─ 联盟: 找支持者，集体提出
└─ 时机: 选择正确时机

情境4: 同事偷懒
├─ 分析: 多人博弈，声誉风险
├─ 策略: 先私下沟通，给机会
├─ 保护: 不立即告状
└─ 底线: 如果影响团队，考虑上报
```
