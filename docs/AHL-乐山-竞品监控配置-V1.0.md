监控参数：
- 监控频率：平日每日2次(08:00/20:00)，节假日每4小时1次
- 监控房型：大床房 + 双床房（标准化）
- 价格字段：挂牌价、最低价、剩余房量
- 预警阈值：

  * 竞品剩余房量 <5间 → 满房预警
  * 竞品价格日变化 >¥50 → 突变预警

## 四、携程房价日历爬取策略

### 目标数据
- 未来14天每日房价（最低价/最高价/均价）
- 未来14天可售房量
- 房型级别价格差异

### 携程页面结构分析

```
携程酒店详情页房价日历URL格式：
https://m.ctrip.com/html5/hotel/hoteldetail/{HOTEL_ID}.html

→ 点击"查看所有价格"进入日历页
→ 日历页URL通常为：
  https://m.ctrip.com/html5/hotel/calendar/{HOTEL_ID}?checkIn=YYYY-MM-DD&checkOut=YYYY-MM-DD

→ 价格数据通过API加载：
  POST https://m.ctrip.com/api/hotel/hoteldetail/calendar
  参数：hotelId, checkIn, checkOut, roomTypeId
```

### 降级方案

若携程页面结构变化（反爬加强），按以下降级顺序：

1. **降级1**：使用携程APP内H5页面（结构不同，反爬较轻）
2. **降级2**：切换到美团同一竞品监控（数据可比）
3. **降级3**：降低频率（每日1次，凌晨3点），减小被封风险
4. **降级4**：手动录入（最坏情况，但保留手动通道）

## 五、数据存储结构

```python
# SQLite竞品价格表
CREATE TABLE competitor_prices (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    hotel_name TEXT,           -- 竞品名称
    ctrip_id TEXT,             -- 携程Hotel ID
    room_type TEXT,            -- 房型
    check_in_date DATE,       -- 入住日期
    price_min INTEGER,         -- 最低价
    price_max INTEGER,         -- 最高价
    price_avg REAL,             -- 均价
    remaining_rooms INTEGER,   -- 剩余房量
    captured_at DATETIME,       -- 采集时间
    source TEXT                 -- 数据来源：ctrip/meituan/manual
);

# 索引
CREATE INDEX idx_hotel_date ON competitor_prices(hotel_name, check_in_date);
CREATE INDEX idx_captured ON competitor_prices(captured_at);
```
