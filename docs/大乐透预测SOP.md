## 标准工作流程 (7步)

### Step 0: 知识库扫描（新增）

**触发**：每次执行预测前必须执行

**操作**：
```
1. 读取 lottery-knowledge-base.md（彩票专业知识库）
2. 检查 memory/ 目录下是否有相关更新
3. 扫描最新一期实际开奖结果
4. 如有必要，读取 finance-securities-knowledge-base.md（金融统计知识）
```

**产出**：
- 确认知识库版本
- 了解最新统计数据
- 准备预测参数

### Step 1: 读取上次预测记录

**操作**：
```
1. 读取 lottery_history/ 目录下最新的 JSON 文件（按文件名排序取最后一个）
2. 提取 last_issue 期号和预测号码
```

**产出**：`last_issue`（上期期号）、`last_predictions`（上期预测）

---

### Step 2: 查询官网实际开奖结果

**操作**：
```
1. 访问中国体彩官网: https://www.lottery.gov.cn/dlt/
2. 或访问历史数据: https://datachart.500.com/dlt/history/newinc/history.php
3. 提取 last_issue 期号的实际开奖号码（前区+后区）
```

**备选方案**（官网访问失败时）：
- 使用 500彩票网历史数据
- 使用已知数据文件作为兜底

**产出**：`actual_front[]`、`actual_back[]`

---

### Step 3: 复盘上次预测

**操作**：
```
1. 逐注对比预测号码 vs 实际开奖
2. 计算每注的前区命中数、后区命中数、总命中数
3. 根据大乐透奖项规则判定每注获奖等级
4. 统计总命中率
```

**奖项规则（超级大乐透）**：

| 奖级 | 命中条件 | 奖金 |
|------|----------|------|
| 一等奖 | 5+2 全中 | 浮动 |
| 二等奖 | 5+1 | 浮动 |
| 三等奖 | 5+0 或 4+2 | 浮动 |
| 四等奖 | 4+1 或 3+2 | 浮动 |
| 五等奖 | 4+0 或 3+1 或 2+2 | 300元 |
| 六等奖 | 3+0 或 2+1 或 1+2 或 0+2 | 200元 |
| 七等奖 | 4+0 或 3+1 或 2+1 或 1+2 或 0+2 | 100元 |
| 八等奖 | 3+0 或 2+1 或 1+2 或 0+2 | 15元 |
| 九等奖 | 2+1 或 1+2 或 0+2 | 5元 |

**产出**：复盘报告（每注命中情况、获奖情况、总体统计）

---

### Step 4: 分析历史规律

**操作**：
```
1. 读取 lottery_history/ 目录下所有历史预测和开奖记录
2. 统计以下规律：
   - 前区热号（近10期出现频率）
   - 前区冷号（近10期未出现或很少出现）
   - 后区热号（近10期出现频率）
   - 后区遗漏追踪（每个号距上次出现的期数）
   - 近期重复号（近3-5期出现过的号）
   - 区域分布规律（前区5个区域的出现规律）
   - 奇偶比例分布
   - 和值范围分布
3. 识别"冷转热"信号（遗漏超过10期突然出现）
4. 识别"趋势反转"信号
```

**产出**：历史规律分析报告

---

### Step 5: 生成下期预测

**操作**：
```
1. 基于 Step 4 的规律分析，生成5注预测号码
2. 应用 V2.0 模型策略：
   - 热号多注覆盖（强热号在多注中出现）
   - 后区遗漏追踪（至少包含1个大遗漏号）
   - 近期重复号权重提升
   - 区域分布动态平衡
   - 冷转热预警捕捉
3. 应用约束条件：
   - 和值范围: 65-130
   - 跨度: 10-34
   - 奇偶比: 2:3 或 3:2 或 4:1
   - 大小比: 2:3 或 3:2 或 4:1
   - 5区至少覆盖4区
   - 连号不超过1组
4. 避免与最近2期完全重复
```

**产出**：`next_issue`（下期期号）、`next_predictions[]`（5注预测）

---

### Step 6: 保存预测结果

**操作**：
```
1. 创建 JSON 文件: lottery_history/prediction_{next_issue}.json
2. 包含字段：
   - issue: 期号
   - generated_at: 生成时间
   - last_issue_review: 上期复盘结果
   - predictions: 5注预测号码
   - model_version: 模型版本
3. 同时更新: lottery_history/index.json（索引文件）
```

**JSON 结构**：
```json
{
  "issue": "26034",
  "generated_at": "2026-03-31 09:24:00",
  "last_issue_review": {
    "issue": "26033",
    "predictions_reviewed": [...],
    "actual": {...},
    "total_hits": {...},
    "prizes": [...]
  },
  "predictions": [
    {"no": 1, "front": [...], "back": [...]},
    ...
  ],
  "model_version": "V2.0"
}
```

## 注意事项

1. **必须先复盘再预测**：每次都必须先完成 Step 1-3，再进行 Step 5
2. **官网查询失败处理**：如果官网无法访问，使用备选数据源，或标记"待确认"
3. **预测结果必须保存**：每次预测后立即保存到 JSON 文件
4. **复盘报告必须存档**：复盘结果保存在 prediction_{issue}.json 的 last_issue_review 字段
5. **禁止凭空编造数据**：开奖结果必须以官网为准，不得假设或推测
