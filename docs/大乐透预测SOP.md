## 标准工作流程 (7步)

### Step 0: 知识库扫描

```
1. 读取 lottery-knowledge-base.md
2. 检查 memory/ 目录下是否有相关更新
3. 扫描最新一期实际开奖结果
```

### Step 1: 读取上次预测记录

```
读取 lottery_history/prediction_{last_issue}.json
```

### Step 2: 查询官网实际开奖结果

```
访问 https://datachart.500.com/dlt/history/newinc/history.php
或 https://www.lottery.gov.cn/dlt/
```

### Step 3: 复盘上次预测

```
逐注对比，计算前区/后区命中数
判定获奖等级，统计总命中率
```

### Step 4: 历史规律分析（量化模块）

```
1. 运行 lottery_v5.py 执行量化分析
2. 计算热冷号、遗漏值、AC值、和值统计
3. 计算赫斯特指数判断随机性深度
4. 构建马尔可夫转移矩阵
```

### Step 5: 生成下期预测（V5.0核心）

**必须运行 Python 脚本**：

```bash
python lottery_history/lottery_v5.py
```

**Layer 1: 特征工程**
- 多维特征：AC值、和值、跨度、奇偶比、大小比、012路
- 遗漏值追踪
- 冷热码映射

**Layer 2: 混合预测引擎**
- 信息熵分析（Shannon Entropy）
- 赫斯特指数（Hurst Exponent）
- 马尔可夫链状态转移

**Layer 3: 组合优化**
- 旋转矩阵（Wheeling System）
- 约束过滤（和值65-130、跨度10-34、奇偶比）

**Layer 4: 博弈论过滤**
| 规则 | 号码 | 处理 |
|------|------|------|
| 生日高频区 | 01-12 | 降权，只选13+ |
| 7的倍数 | 7,14,21,28,35 | 降权或避开 |
| 2026相关 | 26,20,2,6 | 降权 |
| 吉祥数字 | 8,6,9 | 降权 |

**Layer 5: 凯利公式**
- 计算最优投注比例
- 期望收益分析

### Step 6: 保存预测结果

```
lottery_history/prediction_{next_issue}_v5.json
```

### Step 7: 自进化记录

```
更新 .self-improving/memory.md
记录本期预测+实际结果
分析V5.0模型表现
```
