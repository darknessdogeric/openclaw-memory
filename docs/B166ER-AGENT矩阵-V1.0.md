## 任务分层

| 层级 | 任务类型 | 处理方式 | 响应时间 |
|------|----------|----------|----------|
| **L1** | 瞬间任务 (< 1分钟) | 主控直接处理 | 即时 |
| **L2** | 监控任务（定时检查） | cronjob自动化 | 按计划 |
| **L3** | 研究任务（耗时分析） | Researcher subagent | 按需 |
| **L4** | 建设任务（复杂创作） | 主控+ProjectManager | 按需 |
| **L5** | 协调任务（需要判断） | 主控深度参与 | 按需 |

## Subagent使用方式

### 启动Researcher
```bash
# 一次性研究任务
sessions_spawn(
  task="分析最近30天酒店AI领域的重要进展，重点关注Agent技术应用",
  runtime="subagent",
  mode="run"
)
```

### 启动ProjectManager
```bash
# 一次性项目任务
sessions_spawn(
  task="生成AHL试点合作PPT，12页，针对酒店管理者，风格专业商务",
  runtime="subagent",
  mode="run"
)
```

## AGENT协作流程

```
用户请求
    ↓
【主控判断】
├─ L1瞬间 → 直接处理 → 响应用户
│
├─ L2监控 → 已在cronjob → 自动化
│
├─ L3研究 → 启动Researcher → 结果汇报主控 → 响应用户
│
├─ L4建设 → 主控规划 → 启动ProjectManager → 结果汇报主控 → 响应用户
│
└─ L5协调 → 主控深度参与 → 响应用户
```

## 优势

### 1. 主控专注决策
- 不被监控任务打断
- 不被耗时研究拖累
- 专注于需要判断的高价值任务

### 2. 后台自动化
- 定时任务全自动运行
- 开奖自动复盘
- 知识库定期更新
- 技能市场持续监控

### 3. 弹性扩展
- 研究任务多 → 启动多个Researcher
- 项目任务多 → 启动多个ProjectManager
- 按需扩展，不浪费资源

### 4. 隔离稳定
- 子AGENT崩溃不影响主控
- 任务独立，不互相干扰
- 方便调试和优化
