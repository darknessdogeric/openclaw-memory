// What is AHL
AHL 是一个基于 双 Agent 协作 与 区块链智能合约 的去中心化旅行住宿网络。

它用 AI 替代平台 重新定义旅宿交易的信任机制——
房东与租客直接匹配，无需中间商，佣金归零。
01
⚡ AI 智能匹配引擎
双 Agent 驱动——需求 Agent 理解用户，房源 Agent 理解供给。向量语义匹配，准确率超 95%。
Dual-Agent · Vector Search · >95% Match Rate
02
🔐 智能合约信任层
预订、入住、评价全上链。Trustless 机制，无需第三方担保，规则即法律，代码即信任。
Smart Contract · Trustless · On-Chain Escrow
03
🔗 Token 经济激励
AHL Token 连接房东、租客与生态贡献者。持份者共建网络，价值由社区共享，非平台独有。
AHL Token · Stake-to-Earn · Community Governance
