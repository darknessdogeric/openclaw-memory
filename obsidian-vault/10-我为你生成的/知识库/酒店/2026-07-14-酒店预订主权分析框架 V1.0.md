## 一、底层逻辑：预订主权 = 生意主权

### 1.1 核心定理

```
酒店经营的本质不是"卖房间"，而是"卖预订权"。

预订发生的地点，决定了：
  ├─ 定价权在谁手里（你定的价 vs 平台定的价）
  ├─ 客户数据归谁（你的CRM vs 平台的用户画像）
  ├─ 利润归谁（100%收入 vs 扣除佣金后的净收入）
  └─ 客户关系属于谁（你的会员 vs 平台的会员）
```

### 1.2 预订主权分类框架

判断标准不是"客人从哪来"，而是"**预订动作在哪发生**"：

```
┌─────────────────────────────────────────────────────────┐
│              酒店预订主权二分法                            │
├────────────────────────┬────────────────────────────────┤
│   🔴 非自主预订          │   🟢 自主预订                    │
│   (Booking Outside)     │   (Booking Inside)             │
├────────────────────────┼────────────────────────────────┤
│ 预订发生在酒店外部系统    │ 预订发生在酒店内部或直达酒店       │
│ 酒店被动接收订单         │ 酒店主动获取/管理订单             │
│ 客户数据归属第三方        │ 客户数据归属酒店                 │
│ 关系 = 平台↔客人         │ 关系 = 酒店↔客人                │
└────────────────────────┴────────────────────────────────┘
```

### 1.3 渠道主权分类详表

| 渠道 | 预订发生位置 | 主权归属 | 数据归属 | 佣金成本 | 关系强度 |
|------|------------|---------|---------|---------|---------|
| **OTA（携程/美团/飞猪/Booking）** | OTA平台/ebooking/CRS直连 | 🔴 外部 | OTA | 8-20% | 弱 |
| **TMC差旅平台** | TMC系统 | 🔴 外部 | TMC+企业 | 5-10% | 中 |
| **旅行社批发** | 旅行社系统 | 🔴 外部 | 旅行社 | 批发差价 | 弱 |
| **集团CRS中央预订** | 集团系统 | 🟡 半自主 | 集团 | 管理费 | 中 |
| **企业协议客（直销）** | 酒店前台/销售部 | 🟢 内部 | 酒店 | 0-5% | 强 |
| **MICE会议会展（直销）** | 酒店销售部 | 🟢 内部 | 酒店 | 0-5% | 强 |
| **官网/小程序/电话** | 酒店系统 | 🟢 内部 | 酒店 | 0-3% | 最强 |
| **上门散客 Walk-in** | 酒店前台 | 🟢 内部 | 酒店 | 0% | 强 |
| **会员复购** | 酒店CRM | 🟢 内部 | 酒店 | 0-2% | 极强 |

### 1.4 半自主渠道的灰色地带

**集团CRS（中央预订系统）的特殊性**：
- 表面上预订发生在"集团系统"，类似于OTA
- 但集团归酒店管理方控制，系统是管理工具而非第三方平台
- **判断标准**：集团是否向单体酒店收取流量费/佣金？
  - 收佣金 → 视为准OTA（🔴）
  - 不收费/管理费已含 → 视为半自主（🟡）
- 连锁酒店CRS通常贡献 15-30% 预订量，这部分的"自主度"取决于集团-业主关系

## 二、Walk-in散客：被低估的主权堡垒

### 2.1 问题的提出

Eric核心洞察：**很多酒店的门市散客统计严重失真，尤其是交通枢纽型酒店。**

```
表面现象：
  客人走进大堂 → 前台报价 → 客人说"携程上便宜" → 当场掏出手机下单
  PMS记录：携程订单 ❌

实际过程：
  客人是先"上门" → 再"选择渠道" → 最终"OTA下单"
  这本质上是一个Walk-in客户，只是支付通道走了OTA
```

### 2.2 Walk-in失真诊断方法

**2.2.1 当日预订占比法**

```
计算：当日OTA新订单中，"当天入住"的占比

诊断阈值：
├─ 当天预订占比 < 20% → 正常（计划性出行）
├─ 当天预订占比 20-40% → 黄色预警（存在Walk-in转OTA）
├─ 当天预订占比 > 40% → 红色警报（大量上门客流失到OTA）
└─ 交通枢纽酒店 > 50% 几乎必然 → 门市价虚高/前台引导不力
```

**2.2.2 OTA订单下单位置分析**

现代OTA后台可以看到用户的下单地理位置：
```
如果用户GPS显示：
  ├─ 在酒店500m范围内下单 → 高概率原Walk-in客户
  ├─ 在其他城市下单 → 正常远程预订
  ├─ 在本城市但远距离下单 → 正常本地预订
  └─ 在酒店大堂下单 → 100% Walk-in流失
```

**2.2.3 门市价与OTA价差测试**

```
价差诊断：
  门市价 / OTA最低价 - 1 = 价差率

├─ 价差率 < 10% → 健康（Walk-in愿意直接买单）
├─ 价差率 10-20% → 注意（部分客人会犹豫）
├─ 价差率 20-30% → 危险（客人大概率掏出手机）
├─ 价差率 > 30% → 自杀式定价（100%流失到OTA）
```

**实操建议**：门市价不应超过OTA挂牌价的110%，否则就是在帮OTA获客。

### 2.3 Walk-in校正后的真实自主占比

```
校正公式：

真实自主占比 = 
  （协议客 + MICE直销 + 官网/小程序 + 会员复购 + 校正后Walk-in）
  ─────────────────────────────────────────────────
                    总间夜量

其中：校正后Walk-in = PMS记录Walk-in + 当天OTA下单×修正系数

修正系数建议：
├─ 城市商务酒店：0.15-0.25（15-25%的当天OTA下单来自Walk-in）
├─ 交通枢纽酒店：0.30-0.50（30-50%的当天OTA下单来自Walk-in）
├─ 景区度假酒店：0.05-0.15（度假客多提前计划，Walk-in少）
└─ 社区配套酒店：0.10-0.20
```

## 三、量化指标体系：预订主权健康度

### 3.1 核心指标：预订主权率（BSR - Booking Sovereignty Rate）

```
BSR = 自主预订间夜量 / 总间夜量 × 100%

自主预订 = 协议客 + MICE直销 + 官网/小程序/电话 + 校正后Walk-in + 会员复购

BSR的健康阈值：
```

### 3.2 分档阈值标准

| BSR区间 | 状态 | 画像 | 风险等级 |
|---------|------|------|:--------:|
| **≥ 55%** | 🟢 **主权健康** | 生意自己掌控，OTA是补充而非依赖 | 低 |
| **40-55%** | 🟡 **主权均衡** | OTA与自主渠道分庭抗礼，需优化结构 | 中 |
| **25-40%** | 🟠 **主权弱化** | OTA主导，自主渠道薄弱，被动经营 | 中高 |
| **< 25%** | 🔴 **主权丧失** | 完全受制于OTA，利润被抽干，不可持续 | 高 |

### 3.3 不同酒店类型的BSR基准

| 酒店类型 | 健康BSR | 预警BSR | 致命BSR | 关键特征 |
|---------|:------:|:------:|:------:|---------|
| **城市商务酒店** | ≥ 50% | < 40% | < 25% | 协议客+MICE是压舱石 |
| **交通枢纽酒店** | ≥ 35% | < 25% | < 15% | 天然高OTA依赖，Walk-in池大 |
| **景区度假酒店** | ≥ 45% | < 35% | < 20% | OTA不可绕，但会员复购可提升 |
| **会议型酒店** | ≥ 60% | < 45% | < 30% | MICE是绝对主力，自主性天然强 |
| **城市公寓/长住** | ≥ 65% | < 50% | < 35% | 企业协议占比极高 |
| **经济型/中端连锁** | ≥ 40% | < 30% | < 20% | 品牌会员体系+Walk-in组合 |
| **单体民宿** | ≥ 30% | < 20% | < 10% | 天生弱自主，需私域构建 |

### 3.4 辅助指标：利润主权率（PSR - Profit Sovereignty Rate）

BSR只看量，不看质。利润主权率看的是"赚的钱有多少是自主渠道贡献的"。

```
PSR = 自主渠道毛利 / 总毛利 × 100%

单渠道毛利 = 间夜量 × (ADR - 佣金 - 获客成本)

示例：
  协议客：1000间 × (¥500 - ¥0 - ¥5) = ¥495,000 → 自主渠道
  携程：  500间 × (¥500 - ¥75 - ¥10) = ¥207,500 → 非自主渠道
  美团：  300间 × (¥500 - ¥50 - ¥8) = ¥132,600  → 非自主渠道
  
  PSR = 495,000 / (495,000 + 207,500 + 132,600) = 59.3%
  
  即使BSR只有50%（1000/1800），PSR可达59.3%
  因为自主渠道的毛利更高（无佣金）
```

**PSR健康阈值**：

| PSR区间 | 状态 |
|---------|------|
| ≥ 60% | 🟢 利润自主 |
| 45-60% | 🟡 利润均衡 |
| 30-45% | 🟠 利润外流 |
| < 30% | 🔴 利润被抽干（酒店给OTA打工） |

### 3.5 综合主权指数（CSI - Composite Sovereignty Index）

```
CSI = BSR × 0.5 + PSR × 0.3 + 客户数据可控率 × 0.2

客户数据可控率 = 拥有完整联系方式的客户占比

其中：
├─ 协议客/MICE/会员 → 100%可控（有手机/微信/邮箱）
├─ Walk-in → 50%可控（部分登记但不一定有后续触达）
├─ OTA客人 → 0%可控（数据在平台，酒店只有姓和尾号）
└─ TMC客人 → 20%可控（TMC平台有数据，酒店可部分获取）

CSI ≥ 50 → 整体可控
CSI 30-50 → 部分失控
CSI < 30 → 全面失控
```

## 四、渠道依赖度风险诊断

### 4.1 携程依赖度（最核心风险指标）

```
CDI (Ctrip Dependency Index) = 携程间夜量 / 总间夜量 × 100%

├─ CDI < 20% → 🟢 健康
├─ CDI 20-30% → 🟡 需关注（携程是重要但不致命的渠道）
├─ CDI 30-40% → 🟠 风险（携程抽佣足以影响GOP率）
├─ CDI 40-50% → 🔴 危险（携程可以"决定"你的生意）
├─ CDI > 50% → ⚫ 致命（携程是你的老板，不是合作伙伴）
```

**携程依赖度的利润影响**：
```
假设：200间酒店，年均OCC 70%，ADR ¥500

CDI=20% → 携程贡献 10,220间夜 → 佣金支出 ≈ ¥76.7万/年
CDI=30% → 携程贡献 15,330间夜 → 佣金支出 ≈ ¥115万/年
CDI=50% → 携程贡献 25,550间夜 → 佣金支出 ≈ ¥192万/年

从CDI 20%→50%，佣金差距超¥115万/年
这对一家中小型酒店来说，可能就是盈利与亏损的分界线。
```

### 4.2 单一渠道集中度（HHI指数）

采用经济学中的赫芬达尔-赫希曼指数：

```
HHI = Σ(各渠道间夜占比)² × 10000

├─ HHI < 1500 → 🟢 渠道分散，无单一依赖
├─ HHI 1500-2500 → 🟡 适度集中
├─ HHI 2500-4000 → 🟠 高度集中，单一渠道主导
├─ HHI > 4000 → 🔴 极度集中，渠道断供=生意停摆

示例：
  酒店A：协议40%/携程30%/美团20%/其他10%
  HHI = 40² + 30² + 20² + 10² = 3000 → 🟠 偏高

  酒店B：携程55%/美团25%/协议10%/其他10%
  HHI = 55² + 25² + 10² + 10² = 3850 → 🔴 危险
```

### 4.3 佣金侵蚀率（CER - Commission Erosion Rate）

```
CER = 总佣金支出 / 总客房收入 × 100%

├─ CER < 5% → 🟢 佣金健康（自主渠道强大）
├─ CER 5-8% → 🟡 佣金可控
├─ CER 8-12% → 🟠 佣金吃利润
├─ CER 12-15% → 🔴 严重侵蚀
├─ CER > 15% → ⚫ 给平台打工

注：名义佣金率≠实际佣金率
  实际佣金率 = 实际佣金支出 / OTA客房收入
  （因为存在佣金谈判、大促补贴、阶梯佣金等）
```

## 五、预订主权诊断七步法

### Step 1: 拉数据

从PMS导出最近12个月的预订数据，字段：
- 预订日期 / 入住日期 / 渠道来源 / 房型 / 房价 / 佣金 / 客户联系方式

### Step 2: 渠道归类

按照主权二分法对每条预订记录归类：

```
自主预订：
  ├─ 协议客（含RFP/TMC直签/政府定点）
  ├─ MICE直销（非第三方会议公司引荐）
  ├─ 官网/小程序/电话预订
  ├─ Walk-in（含当日OTA下单疑似Walk-in转入）
  └─ 会员直接复购

非自主预订：
  ├─ OTA（携程/美团/飞猪/去哪儿/同程/Booking/Agoda/Expedia）
  ├─ TMC平台（携程商旅/差旅壹号/觅星等非直签）
  ├─ 旅行社批量（包房/切房）
  ├─ 第三方会议公司引荐
  └─ 其他分销平台
```

### Step 3: Walk-in校正

针对"当日OTA预订+入住"的订单：
- 统计当日下单占比
- GPS位置分析（如有数据）
- 应用修正系数（根据酒店类型）

### Step 4: 计算六大指标

| 指标 | 公式 | 当前值 | 健康阈值 | 偏差 |
|------|------|:------:|---------|:----:|
| BSR | 自主间夜/总间夜 | __% | ≥类型基准 | |
| PSR | 自主毛利/总毛利 | __% | ≥50% | |
| CSI | 综合主权指数 | __ | ≥50 | |
| CDI | 携程间夜/总间夜 | __% | <25% | |
| HHI | Σ渠道占比²×10000 | __ | <2500 | |
| CER | 总佣金/总客房收入 | __% | <8% | |

### Step 5: 对标诊断

将六大指标与同类型酒店的基准对比，识别偏离项。

### Step 6: 根因分析

针对每个偏离指标，追问"为什么"：

```
BSR偏低 → 
  ├─ 协议客太少？→ 销售团队弱？城市缺少大企业客户？
  ├─ Walk-in流失严重？→ 门市价虚高？前台无引导激励？
  ├─ 无官网/小程序？→ 数字化投入不足？
  ├─ 会员体系缺失？→ 无复购机制？
  └─ 酒店位置/产品天然吸引OTA客？→ 结构性问题

CDI过高 →
  ├─ 携程独家挂牌（特牌）？→ 被锁定
  ├─ 其他渠道未开通？→ 渠道单一
  ├─ 携程生意通过度投放？→ 花钱买依赖
  └─ 线下客源枯竭？→ 经济下行/城市衰退

CER过高 →
  ├─ 高佣金渠道占比大？→ 国际OTA/携程高星
  ├─ 佣金率谈判不力？→ 体量不够/谈判力弱
  └─ 营销工具（生意通/金字塔）支出过大？→ ROI不对等
```

### Step 7: 制定主权修复路径

```
根据诊断结果，制定3-6-12个月的修复路径：

3个月内（止血）：
  ├─ 门市价调整至OTA价的110%以内
  ├─ 前台Walk-in转化激励（转化1单Walk-in=省1单OTA佣金≈¥50-100，给前台提成¥10-20）
  ├─ 开通微信小程序预订（0佣金）
  └─ 停止ROI为负的OTA推广投放

6个月内（建设）：
  ├─ 建立企业协议客开发团队（1-2名销售）
  ├─ 上线基础会员体系（储值+积分）
  ├─ 开通第二/第三OTA平台（分散携程依赖）
  └─ 所有OTA客人引导加微信（离店后触达）

12个月内（转型）：
  ├─ 自主占比提升至类型基准以上
  ├─ 携程依赖度降至25%以下
  ├─ 会员复购率达到25%+
  └─ 建立MICE直销能力
```

## 六、实战案例：不同类型酒店的诊断

### 6.1 城市商务酒店诊断示例

```
某200间四星级城市商务酒店，年OCC 65%，ADR ¥550

渠道结构（校正前）：
  携程：30% | 美团：18% | 协议客：22% | MICE：10%
  官网：3% | Walk-in：8% | 其他OTA：9%

Walk-in校正：
  当日OTA预订占OTA总量：28%（偏高）
  修正后Walk-in：8% + 30%×(18%+9%)×0.20 = 8% + 2.2% = 10.2%
  修正后协议：22%（不变）
  修正后MICE：10%
  修正后官网：3%

校正后自主占比：10.2% + 22% + 10% + 3% = 45.2%

BSR = 45.2% → 🟡 主权均衡（但偏弱）
PSR ≈ 53% → 🟡 利润均衡（自主渠道利润率高）
CDI = 30% → 🟠 携程依赖偏高
HHI = 30²+18²+22²+10²+9²+10²+1² = 900+324+484+100+81+100+1 = 1990 → 🟡
CER = 11.2% → 🟠 佣金侵蚀偏高

诊断结论：
  - 主权整体均衡但偏弱，携程一家独大
  - 利润层面尚可（协议客+MICE利润率高）
  - 最大问题：无会员复购体系、Walk-in流失严重
  - 优先修复：前台转化机制 + 微信小程序预订
```

### 6.2 交通枢纽酒店诊断示例

```
某150间中端酒店，位于高铁站800m，年OCC 72%，ADR ¥380

典型渠道结构：
  携程：35% | 美团：25% | Walk-in（名义）：15% | 协议客：8%
  飞猪：5% | 旅行社：7% | 其他：5%

Walk-in校正（交通枢纽型，修正系数0.40）：
  当日OTA预订占OTA总量：惊人的45%
  修正后Walk-in = 15% + (35%+25%+5%)×45%×0.40 = 15% + 11.7% = 26.7%

校正后BSR = 26.7% + 8% = 34.7% → 🟠 主权弱化
CDI = 35%（校正前）→ 🟠 携程高依赖

核心问题：
  这家酒店的Walk-in真实占比应该是26.7%，
  但PMS只记录了15%。11.7%的Walk-in客人"被OTA化"了。
  
  按照ADR¥380、年客房数150×365×72%=39,420间夜计算：
  11.7% = 4,612间夜
  这些客人如果走Walk-in → 毛利 = 4,612 × ¥380 = ¥175万
  走OTA（均佣金12%）→ 佣金损失 = 4,612 × ¥380 × 12% = ¥21万/年
  
  这只是Walk-in流失，还不算其他渠道优化空间。

修复重点：
  1. 门市价紧急调整（当前门市价可能是OTA的130-150%）
  2. 前台设置"Walk-in转化奖"（每单奖励¥15）
  3. 大堂放置"扫码直订更便宜"引导牌
  4. 开发周边企业协议客（高铁商圈内商务需求）
```

## 七、方法论哲学：为什么这个框架有效

### 7.1 三个底层原理

**原理1：交易成本理论**
```
预订行为发生的"位置"决定了交易成本归谁。

预订在OTA → 交易成本 = 佣金(8-20%) + 数据成本(不可获得)
预订在酒店 → 交易成本 = 获客成本(远低于佣金) + 数据收益(可沉淀)

减少外部预订→降低交易成本→提升酒店净利润
```

**原理2：客户资产理论**
```
客户的终身价值（LTV）只有在酒店手中才能被充分挖掘：

OTA客户LTV = 1次交易（平台匹配给谁就是谁，无忠诚度）
酒店客户LTV = N次交易 + 推荐裂变 + 餐饮/会议/康乐交叉消费

自主预订占比每提升10%，客户LTV提升约25-40%
```

**原理3：控制权溢价理论**
```
在商业中，控制权永远有溢价。预订控制权 = 酒店经营控制权。

被OTA控制的酒店：
  ├─ 排名算法一动 → 流量腰斩
  ├─ 佣金率一调 → 利润蒸发
  ├─ 独家协议一签 → 丧失谈判力
  └─ 点评规则一变 → 品牌受损

自主控制的酒店：
  ├─ 客户是自己的 → 不惧任何平台规则变化
  ├─ 价格是自己的 → 不受平台比价压制
  ├─ 数据是自己的 → 可以持续优化
  └─ 利润是自己的 → 不需要为平台打工
```

### 7.2 一个残酷的真相

```
中国的单体酒店，真实自主占比普遍在20-35%之间。
这意味着65-80%的生意不掌握在自己手里。

连锁酒店的自主占比稍高（40-55%），因为有品牌会员体系。
但即使是连锁酒店，携程占比30%以上的也比比皆是。

OTA不是敌人，OTA是工具。
但当一个工具掌握了你的命脉，
这就不是工具，而是你的老板。

酒店的终极目标不是"去掉OTA"，
而是让OTA成为"众多渠道之一"，
而非"唯一或主导渠道"。
```

## 八、工具包：快速自检清单

### 8.1 酒店预订主权自检20问

**数据篇（拉PMS报表回答）**：
- [ ] 1. 你的携程间夜占比是多少？（>30%亮红灯）
- [ ] 2. 你的总OTA占比是多少？（>60%亮红灯）
- [ ] 3. 你的Walk-in占比是多少？（交通枢纽酒店<15%大概率失真）
- [ ] 4. 当日OTA预订占OTA总量的比例？（>30%存在Walk-in流失）
- [ ] 5. 总佣金支出÷总客房收入？（>10%在给平台打工）
- [ ] 6. 有完整联系方式的客户占比？（<30%客户资产严重流失）

**渠道篇**：
- [ ] 7. 你有几个OTA渠道？（<3个=渠道单一风险）
- [ ] 8. 你有自有预订渠道吗？（官网/小程序/电话=至少有一个）
- [ ] 9. 你的协议客户占多少？（城市商务<20%严重不足）
- [ ] 10. 你的会员体系有吗？（无=复购全靠运气）

**定价篇**：
- [ ] 11. 你的门市价是OTA价的多少？（>115%=在帮OTA获客）
- [ ] 12. 不同OTA平台的价格一致吗？（不一致=渠道冲突风险）
- [ ] 13. 你有会员专属价吗？（无=会员没有加入动力）
- [ ] 14. 你的Walk-in价格是动态的吗？（固定价=放弃溢价机会）

**运营篇**：
- [ ] 15. 前台有Walk-in转化激励吗？（无=放任客人刷手机）
- [ ] 16. 有企业销售团队吗？（<2人=协议客开发无力）
- [ ] 17. OTA客人离店后有加微信/企微吗？（无=客户一次性）
- [ ] 18. 有私域触达体系吗？（无=沉睡客户永久流失）

**战略篇**：
- [ ] 19. 你知道自己的BSR是多少吗？（不知道=盲飞）
- [ ] 20. 你有3-6-12个月的渠道优化计划吗？（无=被动经营）

**评分**：
- 12个以上✅ → 🟢 主权意识强，在正确轨道上
- 8-11个✅ → 🟡 有意识但执行不足，需要行动计划
- 4-7个✅ → 🟠 渠道结构脆弱，风险较高
- <4个✅ → 🔴 完全被动经营，急需改变

### 8.2 一句话总结

```
预订发生在哪，钱就在哪，权力就在哪，客户就在哪。

OTA可以给你流量，但永远不会给你客户。
OTA可以帮你卖房，但永远不会帮你建立品牌。
OTA可以让你今天满房，也可以让你明天颗粒无收。

掌控预订 = 掌控命运。
这就是酒店经营的第一性原理。
```
