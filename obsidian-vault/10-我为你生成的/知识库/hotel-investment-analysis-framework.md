# 酒店项目投资测算实战框架

> 定位：酒店项目值不值得投？Eric问过这个问题
> 版本：v1.0 | 2026-04-09
> 原则：先给结论+框架，数字是验证，不是起点

---

## 核心判断框架：先问三个问题

**问题1：这座城市的酒店在赚什么钱？**
- 商务驱动（一线城市核心商圈）：稳定但有天花板
- 旅游驱动（景区/古城）：季节性强，爆满和空城交替
- 会议/展览驱动（成都/上海）：高天花板的，但依赖大型活动

**问题2：这座物业的竞争壁垒在哪里？**
- 位置壁垒（核心区唯一性）→ 可持续溢价
- 品牌壁垒（国际品牌/稀缺品牌）→ 溢价但有管理费成本
- 规模壁垒（200间以上才有规模效应）→ 成本优势
- 没有壁垒→ 打价格战，早晚亏钱

**问题3：业主能承受多久不赚钱？**
- 酒店投资回报期5-8年，前2-3年最艰难
- 如果业主资金链紧张，谈判中要优先考虑现金流

## 一、酒店项目财务测算基础

### 1.1 投资构成拆解

**典型中端酒店（150间）投资结构**：

| 科目 | 单方造价 | 总成本 | 占比 |
|------|---------|-------|------|
| 装修+家具 | ¥8-12万/间 | ¥1200-1800万 | 50-60% |
| 加盟费（一次性的） | ¥2000-5000/间 | ¥30-75万 | 2-3% |
| 筹建期间费用 | — | ¥50-100万 | 3-5% |
| 运营资金准备 | — | ¥100-200万 | 5-8% |
| 其他（设计/证照） | — | ¥50-100万 | 3-5% |
| **合计** | **¥10-15万/间** | **¥1500-2300万** | **100%** |

**数据背后的逻辑**：
- ¥10-15万/间的单方造价是2019-2024年的行业均值
- 2024年通胀后，人工+材料让单方造价上涨15-20%
- 低于¥8万/间的，大概率是"省钱型装修"，3年后要翻新
- 高于¥18万/间的，要么是奢华定位，要么是被坑了

**各档次投资参考**：

| 档次 | 间夜均价 | 间数 | 单方造价 | 总投资 |
|------|---------|------|---------|-------|
| 经济型 | ¥150-250 | 80-120 | ¥4-6万 | ¥400-700万 |
| 中端 | ¥300-500 | 100-180 | ¥10-15万 | ¥1200-2000万 |
| 中高端 | ¥500-800 | 120-200 | ¥15-25万 | ¥2000-4000万 |
| 高端 | ¥800-1500 | 150-250 | ¥25-40万 | ¥4000-8000万 |
| 奢华 | ¥1500+ | 80-150 | ¥50万+ | ¥6000万+ |

### 1.2 收入测算模型

**第一步：可售间夜**

```
年可售间夜 = 间数 × 365天 × 理论OCC（通常用75-85%）
```

**但要注意**：
- 新开业酒店前6个月OCC通常只有40-60%（爬坡期）
- 爬坡期收入要单独测算，否则整体回报被高估

**第二步：收入构成**

| 收入项 | 占总收入比 | 中端正常水平 |
|--------|-----------|-------------|
| 客房收入 | 65-75% | 70% |
| 餐饮收入 | 15-25% | 20% |
| 会议/宴会 | 5-10% | 5% |
| 其他（洗衣/停车场） | 3-5% | 5% |

**第三步：GOP计算**

```
总收入
- 运营成本（人工/能耗/易耗品）
= GOP（毛利润）
GOP率 = GOP / 总收入
```

**各档次GOP率参考**：

| 档次 | GOP率参考 | 说明 |
|------|----------|------|
| 经济型 | 35-45% | 人工成本低，但ADR也低 |
| 中端 | 38-48% | 最优区间，规模效应明显 |
| 中高端 | 40-50% | 人工成本占比上升 |
| 高端 | 30-40% | 人工+餐饮占比高 |
| 奢华 | 25-35% | 极度依赖OCC维持GOP |

### 1.3 投资回报测算

**静态回收期（最常用）**

```
静态回收期 = 总投资 / 年净现金流
```

**但"年净现金流"怎么算？**
- 不是GOP，是GOP - 折旧摊销 - 利息 - 所得税
- 实际上：酒店行业通常用"年经营现金流" = GOP - 运营资金净增

**中国市场的经验值**：

| 城市/档次 | 静态回收期参考 |
|----------|-------------|
| 一线城市中高端 | 6-8年 |
| 二线城市中端 | 5-7年 |
| 三线城市经济型 | 4-6年 |
| 弱二线/县域 | 风险过高，不建议 |

**敏感性分析（最重要）**

| 变量 | 对回收期的影响 |
|------|--------------|
| OCC-10% | 回收期延长2-3年 |
| ADR-15% | 回收期延长2-3年 |
| 人工成本+10% | GOP率下降3-5% |
| 能耗+20% | GOP率下降1-2% |

**结论**：对中端酒店来说，**OCC和ADR的敏感性远大于成本**。
这就是为什么"定价策略"比"成本控制"更重要。

## 二、酒店项目尽调清单（Eric能用的实战工具）

### 2.1 物业条件尽调

**必查项（影响投资额）**：
- 物业剩余土地使用年限（>30年才值得投）
- 消防证/特种行业许可证能否办理（有些物业先天不足）
- 结构承重（老楼改酒店经常要加固，加固费¥200-500万）
- 机电现状（老旧程度决定了翻新费用）
- 停车位数量（没有停车位的市区酒店，商务客会流失）

**经验值**：
- 有硬伤的物业，投资额增加30-50%是常事
- 签约前一定要有结构工程师出具报告

### 2.2 市场尽调

**必查数据**：
- 携程/美团 近6个月的OCC/ADR/RevPAR
- 区域内竞争酒店数量+档次分布（步行20分钟内）
- 竞品的STR数据（如果有渠道拿到）
- 城市规划（周边有没有新的竞争物业规划）

**判断方法**：
- 区域内OCC持续>70% → 市场有空间
- 区域内新开业酒店>3家/年在建 → 供给过剩信号
- 竞品评分普遍<4.3 → 可能是蓝海（有差异化机会）

### 2.3 财务尽调

**如果是已有酒店**：
- 过去12个月的P&L
- 近3年的GOP率趋势（判断管理公司能力）
- 应收账款（团客账期是否健康）
- 会员数据（直销占比=酒店自主获客能力）
- 劳动合同（员工是否都有合法缴纳五险一金）

**如果是新项目**：
- 业主的预期和预算（"我想投¥2000万"和"我只能承受¥1500万"完全不同）
- 资金来源（自有资金 vs 贷款比例，贷款>60%就危险）
- 退出预期（5年回收 vs 10年长期持有）

## 三、不同商业模式的财务结构

### 3.1 委托管理模式

**业主承担**：全部投资风险
**管理公司承担**：经营风险（但通常有保底经营收入）

**业主的财务模型**：
```
收入 = GOP × (1 - 激励费比例) - 固定管理费 - 保险/税费
```

**真实案例（强二线城市中端150间）**：
```
年总收入： ¥1800万（OCC75%/ADR380元）
GOP：     ¥720万（GOP率40%）
- 激励费（超额部分15%）：¥30万（假设超额50万）
- 固定管理费：¥20万
= 业主净收入：¥670万
投资回收期：¥2000万 / ¥670万 = 3年（理想情况）
```

**问题**：这个3年回收期是"理论值"，实际上：
- 需要扣除折旧（¥60-80万/年）
- 需要还贷款利息（¥80-100万/年，假设60%贷款）
- 实际回收期：5-7年更现实

### 3.2 特许经营模式（华住为代表）

**业主自己经营，管理公司只输出品牌和系统**

**财务模型**：
```
业主收入 = 总收入 - 运营成本 - 特许费（通常8-12%/间夜）
```

**优势**：
- 没有"管理公司赚太多"的争议
- 业主有完全的经营自主权

**风险**：
- 运营全靠业主自己或聘请店长
- 品质控制依赖业主的执行力

### 3.3 租赁模式

**酒店公司租下物业，自主经营**

**财务模型**：
```
酒店公司 = 租金收入 - 运营成本 - 租金
```

**对业主来说**：
- 风险最低（租金固定，不管经营好坏）
- 收益也最低（通常租金收益率4-6%）

**对酒店公司来说**：
- "二房东"逻辑，赚取租金差价
- 前提是能以更低租金拿到物业，再以市场价出租

## 四、酒店项目谈判的核心条款

### 4.1 新项目签约前必须明确的

**条款1：投资额确认**
- 双方对总投资的认知是否一致
- 预算超支谁承担（行业惯例：超10%以内管理公司承担，以上业主承担）
- 翻牌改造项目的特殊处理

**条款2：筹建期责任划分**
- 管理公司负责：设计审核、筹建管理、开业筹备
- 业主负责：证照办理（消防/特行）、资金拨付
- 工期延误责任：非管理公司原因造成的延误由业主承担

**条款3：保底经营收入**
- 管理公司通常要求：业主承诺保底GOP，低于保底则补足
- 保底计算依据：市场比较法+历史数据
- 保底期限：通常3-5年，之后转为纯激励模式

### 4.2 续约和退出条款

**续约触发点**：
- 通常在合同到期前12-18个月启动谈判
- 续约条件：通常要求新一轮投入（翻新改造）
- 业主权利：续约条件可谈判，但管理公司有优先续约权

**提前退出**：
- 业主违约：通常要赔3-5年管理费
- 管理公司违约：通常要赔业主投资损失+机会成本
- 不可抗力：双方协商，通常各承担50%

## 五、酒店投资决策的自检清单

**开始算数字之前，先过这5关**：

1. **城市关**：这座城市未来3年的商旅/旅游趋势是什么？
2. **位置关**：步行20分钟内的竞品，有几个？它们OCC多少？
3. **壁垒关**：如果华住全季在我旁边开业，我能活下来吗？
4. **资金关**：业主能承受几年不赚钱？（至少3年）
5. **人关**：这条街上，有没有人能把这个酒店管好？

**5关都过，再算数字。**

## 六、酒店投资测算实例

### 实例：强二线城市中端酒店（150间）

**基本情况**：
- 城市：成都（强二线，商务+旅游双驱动）
- 位置：春熙路/太古里商圈边缘
- 档次：中端（对标全季/麗枫）
- 间数：150间
- 物业状态：老写字楼改造（有基本机电，需加固）

**投资测算**：

| 科目 | 金额 |
|------|------|
| 物业租金（5年预付） | ¥400万 |
| 加固+拆改 | ¥300万 |
| 装修+家具 | ¥1500万（¥10万/间） |
| 加盟费（特许） | ¥45万 |
| 筹建+证照 | ¥100万 |
| 运营资金 | ¥150万 |
| **总投资** | **¥2495万** |

**收入测算（运营第3年起，稳定期）**：

| 指标 | 数值 |
|------|------|
| OCC | 75%（行业均值） |
| ADR | ¥380元（对标竞品） |
| RevPAR | ¥285元 |
| 年客房收入 | ¥150×365×75%×380 = ¥1568万 |
| 餐饮+其他 | ¥470万 |
| **总收入** | **¥2038万** |
| GOP（GOP率40%） | ¥815万 |
| 减去：折旧（直线法20年） | ¥110万 |
| 减去：贷款利息（¥1500万×6%/年） | ¥90万 |
| **年净现金流** | **¥615万** |
| **静态回收期** | **¥2495万 ÷ ¥615万 ≈ 4.1年** |

**敏感性测试**：

| 情景 | OCC | ADR | 年净现金流 | 回收期 |
|------|-----|-----|----------|--------|
| 乐观 | 80% | ¥420 | ¥780万 | 3.2年 |
| 基本 | 75% | ¥380 | ¥615万 | 4.1年 |
| 保守 | 65% | ¥340 | ¥420万 | 5.9年 |
| 危险 | 55% | ¥300 | ¥200万 | 12.5年 |

**结论**：
- 这是一个"还不错"的项目，基本面清晰
- 但对OCC敏感——如果区域供给过剩，OCC跌到65%以下，回收期跳到6年
- 如果华住全季在旁边开业，ADR可能从¥380跌到¥340 → 回收期5.9年

**所以核心问题是**：春熙路区域未来3年会不会有新竞品进来？
