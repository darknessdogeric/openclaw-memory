## 核心逻辑：酒店是"时间的朋友"还是"时间的敌人"

**酒店和其他资产不同**：
- 写字楼：地段价值>运营价值，地段升值可以弥补运营低谷
- 住宅：地价升值逻辑，地段对了就对了
- 酒店：**运营价值和资产价值高度绑定**，运营差=资产贬值

**这意味着**：
- 酒店不是"买了放着等升值"
- 酒店是"通过运营创造价值，然后在价值最高点退出"

## 一、酒店资产的生命周期

```
收购/新建 → 爬坡期 → 稳定期 → 成熟期 → 衰退期/翻新 → 退出
   ↓           ↓          ↓         ↓           ↓
  投入       亏损       回本      现金牛      选择：翻新或退出
```

**各阶段的策略**：

| 阶段 | 运营目标 | 财务目标 | 退出时机 |
|------|---------|---------|---------|
| 爬坡期(0-2年) | 快速爬升OCC | 减少亏损 | 不考虑退出 |
| 稳定期(2-5年) | 提升ADR | 开始回本 | 可以谈 |
| 成熟期(5-10年) | 维持OCC/ADR | 稳定现金流 | **最佳退出窗口** |
| 衰退期(10年+) | 止损 | 维持正现金流 | 尽快或翻新 |

**关键洞察**：
> 酒店资产的最佳退出时机是**成熟期的中段**（开业后5-7年），不是现金流最好的时候，而是"想象空间还在"的时候。
> 一旦酒店进入衰退期，买家会要求大幅折价。

## 二、收购/新建阶段：怎么选对标的

### 2.1 收购 vs 新建的选择

| | 收购 | 新建 |
|--|------|------|
| 时间成本 | 6-12个月完成 | 2-4年筹建 |
| 确定性强 | 看到真实数据 | 全是预测 |
| 改造成本 | 加固/拆改不可控 | 建筑成本可控 |
| 起始价格 | 谈判空间大 | 土地价格固定 |
| **适合** | 有改造经验的团队 | 有土地资源的开发商 |

### 2.2 收购标的筛选标准

**非诚勿扰清单**（有任何一个就排除）：

1. ❌ 消防证/特种行业许可证**无法**办理
2. ❌ 物业剩余土地使用年限<25年
3. ❌ 结构需要重大加固（加固费>总投资的20%）
4. ❌ 所在区域未来2年有2家以上同档次在建酒店
5. ❌ 业主有严重的债务纠纷/法律诉讼

**黄金清单**（有越多越好）：

1. ✅ 位置具有稀缺性（核心区唯一在营/唯一有停车位/唯一有景观）
2. ✅ 物业结构适合酒店，不需要大幅改造
3. ✅ 周边竞品OCC持续>70%（市场有空间）
4. ✅ 现有管理合同条款有利（或可提前解除）
5. ✅ 业主有意愿尽快成交（有动力=有议价空间）

### 2.3 收购谈判的关键点

**为什么业主愿意卖？**
- 资金链紧张（最常见）→ 压价机会最大
- 资产重组/甩包袱（国企卖非核心资产）→ 程序复杂但价格合理
- 战略转型（跨界投资者）→ 溢价空间有限
- 家庭原因（继承纠纷/离婚分割）→ 可以压价，但关系复杂

**谈判策略**：
```
知道业主为什么卖 → 知道能压多少价
资金链紧张 → 可以压20-30%
资产重组 → 价格公道但程序复杂
家庭纠纷 → 压价但关系复杂，评估是否值得
```

## 三、运营提升阶段：100天改变一家酒店

### 3.1 接管后的第一个100天

**这是改变酒店命运最关键的时间窗口。**

**第1-30天：诊断期**

目标：搞清楚这家酒店到底怎么了

```
诊断清单：
□ 真实OCC/ADR是多少（不是报表上的，是实际的）
□ 各渠道贡献占比（直销/OTA/协议/团队客）
□ 会员数据（会员复购率/会员生命周期价值）
□ 客户投诉TOP3（不是前台记录的，是实际客人反馈的）
□ 员工状态（士气/流动率/关键岗位稳定性）
□ 上一任管理者留下的最大问题是什么
□ 业主和管理公司的关系（有没有历史积怨）
□ 财务黑洞（有没有隐性债务/欠薪/应付账款）
```

**第31-60天：止血期**

目标：停止流血（止血比输血重要）

```
止血行动清单：
□ 停掉亏损的餐饮（团餐/宴会接不接？接的话怎么定价？）
□ 砍掉无效营销（投了钱没效果的渠道）
□ 重新谈判OTA合同（佣金比例/排名位置）
□ 关键员工留人（店长/前厅经理/厨师长）
□ 安抚核心客户（协议客户/回头客）
□ 财务止血（催应收账款/延付应付款优先级）
```

**第61-100天：重启期**

目标：让市场看到变化

```
重启行动清单：
□ 推出1-2个差异化产品（不是价格战，是价值战）
□ OTA页面重新装修（图片/文案/价格策略）
□ 直销渠道激活（会员权益/协议客户拜访）
□ 服务标准建立（3个最重要触点的体验提升）
□ 团队士气重建（开一次全员大会，讲清楚方向）
```

### 3.2 运营提升的核心杠杆

**中端酒店，OCC和ADR哪个更重要？**

**结论：先OCC，后ADR**

原因：
- OCC低=设备空转=固定成本在吃掉利润
- OCC稳定在70%+后，ADR才有提升空间
- 过早追求ADR会导致OCC进一步下降（价格涨了，客户跑了）

**提升OCC的优先级**：

| 优先级 | 手段 | 见效时间 |
|--------|------|---------|
| 1 | 协议客户激活（本地企业签约） | 1-3个月 |
| 2 | OTA排名优化（算法优化） | 1-2个月 |
| 3 | 团队客房（旅行团/会展团） | 立即 |
| 4 | 长住客（30天+） | 2-4个月 |
| 5 | 散客walk-in | 持续 |

**提升ADR的优先级**：

| 优先级 | 手段 | 操作难度 |
|--------|------|---------|
| 1 | 调整渠道价格梯度（OTA/直销/协议不同价） | 低 |
| 2 | 升级产品（加早餐/下午茶） | 中 |
| 3 | 动态定价（节假日/展会涨价） | 高 |
| 4 | 品牌升级（换牌/重新定位） | 极高 |

## 四、退出阶段：什么时候卖？怎么卖？

### 4.1 退出时机判断

**可以卖的信号**（以下任意一个）：

1. **运营进入成熟期**：OCC稳定在75%+，ADR达到区域标杆，现金流稳定>3年
2. **资产价值处于高点**：区域房价上涨期/品牌刚升级/竞争对手少
3. **自身资源需要重新配置**：有更赚钱的机会需要资金/团队精力
4. **外部买家出价合理**：P/NOI < 8倍（比市场价高10-20%）

**不能卖的信号**：

1. 运营还没稳定（买家会压价30-50%）
2. 区域供给过剩正在加剧（未来2年有3家以上竞品开业）
3. 需要大笔翻新资金（买家会要求折价）
4. 市场整体下行（不是不能卖，是价格不好）

### 4.2 退出渠道选择

**渠道1：整售给机构投资者**（最推荐）

- 适合：成熟期酒店，规模>100间
- 优点：价格最高（机构愿意溢价买稳定现金流）
- 缺点：尽调严格，谈判周期长（6-18个月）
- 价格：通常P/NOI 7-10倍

**渠道2：卖给个人投资者**

- 适合：中小型酒店/单体
- 优点：决策快（个人决策 vs 委员会决策）
- 缺点：价格通常低于机构
- 价格：通常P/NOI 6-8倍

**渠道3：REITs/上市平台收购**

- 适合：连锁酒店，有一定规模（>500间）
- 优点：估值透明，退出快
- 缺点：门槛高，需要符合REITs标准
- 价格：参照上市公司估值

**渠道4：股权转让**

- 适合：有限责任公司股权结构
- 优点：税务优化空间大
- 缺点：买家需要对原股东有信任
- 价格：协商

### 4.3 退出时的价值提升技巧

**在退出前6个月做的事情**：

1. **财务包装**：把报表做得规范（很多单体酒店财务很乱，规范后溢价10-20%）
2. **合同梳理**：把有利条款的管理合同/租约/供应商合同整理清楚
3. **团队稳定**：确保核心团队愿意留任（买家最怕交割后团队跑路）
4. **客户交接**：把重要客户关系移交给买家团队
5. **资产美化**：小修小补（外墙翻新/公区改造），投入不大但溢价明显

## 五、酒店资产管理的核心指标体系

### 5.1 资产层面指标

| 指标 | 计算 | 健康值 |
|------|------|--------|
| GOP率 | GOP / 总收入 | 中端>40% |
| GOPPAR | GOP / 可售间夜 | 中端>¥120 |
| NOI | GOP - 非现金费用 | 正数+增长 |
| RevPAR | OCC × ADR | 区域平均以上 |
| 资产回报率 | NOI / 资产价值 | >6% |

### 5.2 运营层面指标

| 指标 | 计算 | 健康值 |
|------|------|--------|
| 直销占比 | 直销间夜 / 总间夜 | >50% |
| 会员复购率 | 会员复购 / 会员总数 | >25% |
| 客户满意度 | NPS/Guest Survey | >70分 |
| 员工流失率 | 年度离职 / 总人数 | <20% |

### 5.3 市场层面指标

| 指标 | 计算 | 健康值 |
|------|------|--------|
| 市场份额 | 我店RevPAR / 区域RevPAR | >1（跑赢大盘） |
| 竞争指数 | 我店OCC / 竞品OCC | >1 |
| 渠道依赖度 | OTA占比 | <40% |

## 六、Eric的AHL × 酒店资产管理

**AHL在这个框架里的位置**：

```
收购/新建 → 爬坡期 → 稳定期 → 成熟期 → 退出
    ↓
AHL能帮的：
□ 收购前：市场数据/定价测算
□ 爬坡期：OCC提升/OTA优化
□ 稳定期：精细化运营/会员体系
□ 成熟期：资产价值评估/退出方案
```

**AHL真正的机会**：
不是"帮单体酒店活下去"，是"帮单体酒店提升资产价值，然后在最佳时机卖出"。

这才是对酒店业主真正有吸引力的价值主张。
