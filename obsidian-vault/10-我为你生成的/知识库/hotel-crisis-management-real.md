# 酒店危机管理实战手册

> 定位：教科书不教的真实危机处理
> 版本：v1.0 | 2026-04-09
> 原则：不是危机公关话术，是真实决策逻辑

---

## 核心认知：危机处理的两个阶段

**第一阶段：0-30分钟**（黄金30分钟）
- 信息收集 + 内部沟通
- 错误的代价最高

**第二阶段：30分钟-24小时**（决策执行）
- 外部沟通 + 利益相关方管理
- 方向错误的代价最高

---

## 第一类：人身安全事故（最高优先级）

### 场景1：客人在酒店摔倒/受伤

**这是酒店最常见的法律风险。**

```
【0-5分钟】立即响应
□ 确保客人安全（不要移动受伤部位）
□ 立即通知医务室/急救人员
□ 记录现场（拍照+时间戳）

【5-15分钟】医疗处理
□ 120或999（看城市）
□ 联系客人家属（如果客人同意）
□ 保留医疗记录和费用票据

【15-30分钟】上报GM
□ 完整描述事件经过
□ 说明酒店方已知采取的措施

【30分钟-24小时】法律准备
□ 不要承认责任（不是说谎，是等待调查结果）
□ 联系酒店法律顾问/保险公司
□ 记录所有相关人员信息和证词
□ 准备给客人的情况说明

【最重要的原则】
——不要当场承认"是我们的责任"
——但要给客人最好的医疗照顾
——这不矛盾：照顾客人和承认责任是两回事
```

**什么时候GM必须亲自出面**：
- 客人受伤严重（需要住院）
- 客人在媒体/社交媒体上开始发帖
- 客人家属赶到现场

### 场景2：客人财物丢失/被盗

```
【第一步】区分两种情况

情况A：客人自己疏忽（行李在房间被顺手牵羊）
□ 立即报案（110）
□ 协助调查
□ 联系楼层服务员了解情况
□ 联系警方跟进

情况B：酒店安保失职（公共区域被盗）
□ 立即报案（110）
□ 调取监控（这是最关键的证据）
□ 内部排查
□ 联系保险公司

【第二步】法律风险
——酒店对客人财物的责任是有限的
——通常只对"酒店过错造成的损失"负责
——对"客人自身疏忽"免责

【第三步】处理技巧
□ 不要立即谈赔偿金额（让客人先说诉求）
□ 记录丢失物品清单
□ 联系保险公司（理赔由保险处理）
□ 客人情绪安抚（这是酒店能做的）
```

### 场景3：火灾（最可怕的危机）

```
【0-2分钟】启动应急预案
□ 拨打119
□ 启动消防广播（疏散通知）
□ 切断电源/燃气
□ 打开所有消防通道

【2-10分钟】疏散
□ 员工各就各位引导疏散
□ 检查每间客房（敲门确认）
□ 不使用电梯
□ 前往集合点清点人数

【10-30分钟】配合消防
□ 向消防队提供：建筑平面图/被困人员信息/特殊危险品位置
□ 协助救援

【30分钟以上】危机处理
□ 立即联系业主/上级
□ 联系保险公司
□ 安排受伤人员医疗
□ 媒体/家属接待
□ 事后调查报告

【预防】每月至少一次消防演练
——员工知道疏散路线吗？
——员工知道集合点在哪里吗？
——这个问题在半夜凌晨2点也成立吗？
```

## 第二类：食品安全事故

### 场景4：疑似食物中毒（多人同时发病）

**这是酒店最严重的声誉危机。**

```
【0-30分钟】确认
□ 多少人出现症状？（1个人可能是巧合，3个人以上就是事故）
□ 吃了什么？（留样保存）
□ 症状是什么？（呕吐/腹泻/发烧）

【立即行动】
□ 送医（症状严重者）
□ 封存今天的所有食品留样
□ 停止该食品供应
□ 上报卫健委/食药监局（法律义务）

【24-48小时】调查
□ 食品来源追溯
□ 厨房操作记录检查
□ 相关人员健康证检查
□ 实验室检测

【对外沟通】
□ 不要主动接受媒体采访
□ 等待官方检测结果再发布声明
□ 如果确认是酒店责任 → 主动道歉 + 承担医疗费用
□ 如果不是酒店责任 → 有理有据说明

【最重要原则】
——食品安全事故的关键是"不要让事态扩大"
——最坏情况：10个人食物中毒 → 10个人的朋友圈 = 潜在10万曝光
——最好的防御：第一时间发现 + 第一时间处理 + 透明沟通
```

## 第三类：舆情危机

### 场景5：客人发抖音/微博投诉（还没火）

**这是干预舆情的最佳时机。**

```
【发现时机】越早越好
□ 携程/美团差评 → 每天检查
□ 微博/抖音监控 → 关键词：酒店名+投诉
□ 微信群/朋友圈 → 靠员工传递信息

【黄金2小时】回复
□ 私信联系（不是公开回复）
□ 询问具体情况（显示重视）
□ 给出解决方案
□ 邀请私下沟通

【回复模板】
"您好，我是XX酒店的工作人员。看到您的反馈，我们非常重视。
能否私信我们您的联系方式？我们会立即跟进处理。"

【跟进动作】
□ 48小时内必须解决（如果能解决的话）
□ 如果客人坚持公开 → 尊重客人权利，但保持沟通
□ 差评修改 → 解决后邀请客人删除/修改（不是要求，是邀请）
```

### 场景6：媒体曝光（已经发酵）

```
【0-1小时】评估
□ 什么媒体？（央视/地方台/自媒体？影响力天差地别）
□ 什么内容？（事实？还是情绪？）
□ 谁的视角？（客人单方面？还是有多方声音？）

【1-2小时】决策
□ 是否需要回应？
□ 如果需要回应 → 谁来说？（GM/公关总监/业主方？）
□ 如何回应 → 承认+改正 or 解释+澄清？

【回应原则】
□ 承认酒店有责任的部分（不要全盘否认）
□ 说明已经采取的措施
□ 表达歉意（真诚的，不是模板的）
□ 提供后续跟进承诺

【不应该做的】
□ 不要说"临时工干的"（这是火上浇油）
□ 不要威胁客人（这会火上浇油+引发二次曝光）
□ 不要给媒体/博主"封口费"（这会被曝光为贿赂）
```

### 场景7：职业打假人/恶意索赔

```
【识别信号】
□ 多人结伴而行（分散服务人员注意力）
□ 对房间设施/食品安全"特别关注"（提前录像）
□ 索赔金额明确（不是"赔礼道歉"，是"赔钱"）
□ 了解酒店行业规则（知道怎么投诉最有效）

【处理原则】
□ 不卑不亢（不激怒，但也不妥协）
□ 了解真实情况（是酒店真的有问题，还是对方栽赃？）

【如果确实是酒店问题】
□ 承担责任，但按实际损失赔偿
□ 不接受"漫天要价"（要走法律程序就走）
□ 记录沟通过程

【如果是恶意索赔】
□ 联系法律顾问
□ 收集对方行为的证据
□ 报警（如果有威胁/敲诈行为）
□ 行业协会通报（职业打假人通常会收敛）

【最重要的原则】
——不要给"封口费"（这会被当成把柄）
——不要害怕走法律程序（恶意索赔者通常不敢）
```

## 第四类：员工危机

### 场景8：员工打架/性骚扰/盗窃

```
【员工打架】
□ 立即分开双方 + 隔离
□ 报警（如果造成人身伤害）
□ 停职调查（保护客人安全为先）
□ 24小时内做出处理决定
□ 报告业主/总部

【员工性骚扰客人/同事】
□ 立即停职调查
□ 保护受害者（不要二次伤害）
□ 报警（如果是违法行为）
□ 报告业主/总部
□ 配合警方调查

【员工盗窃（客人财物）】
□ 立即停职 + 报警
□ 追回赃物（如有可能）
□ 配合警方调查
□ 报告业主/总部
□ 通知受害者进展
□ 内部排查（是否有多次/多人）
```

### 场景9：员工集体罢工/离职潮

```
【预防永远是第一位的】
□ 工资按时发（这是底线）
□ 核心员工有离职意向 → 立即上报
□ 发现有"串联"迹象 → 立即了解情况

【已经发生时】
□ 立即上报业主/总部
□ 了解诉求（是什么？合理吗？）
□ 与工人代表对话（不要硬碰硬）
□ 寻求政府劳动部门协助
□ 保证客人安全（客人的服务不能停）

【最坏的情况：员工集体离岗】
□ 联系临时工/劳务派遣
□ 联系附近酒店借调
□ GM和核心管理层亲自顶岗
□ 通知已预订客人（是否有取消/改期）
□ 尽快招聘/谈判解决
```

## 第五类：外部危机冲击

### 场景10：自然灾害/疫情

```
【地震/洪水/台风】
□ 客人安全第一（疏散/转移）
□ 配合政府救援
□ 联系业主/保险
□ 记录损失
□ 安排客人退改

【疫情】
□ 配合政府防控（这是强制义务）
□ 客人安抚和退改
□ 员工安全（口罩/消毒/健康监测）
□ 运营调整（关闭部分区域/减少接待）
□ 现金流管理（收入减少但固定成本还在）
□ 与业主沟通（是否需要减免租金/管理费）
```

### 场景11：周边重大事件冲击

```
【酒店周边发生命案/爆炸/火灾】
□ 客人安全撤离（如果是酒店内）
□ 配合警方调查
□ 联系附近兄弟酒店安置客人
□ 舆情监控（等待官方通报）
□ 重新开业评估（需要政府确认安全）

【竞对/自媒体恶意抹黑】
□ 收集证据（截图/录音）
□ 联系律师
□ 平台申诉（删除不实内容）
□ 正面宣传（发布酒店真实情况）
□ 如果对方是竞争对手恶意抹黑 → 法律途径
```

## 危机处理的法律注意事项

```
【永远不要做的】
1. 不要销毁证据（监控记录/食品留样/记录文件）
   ——销毁证据 = 承担全部责任
2. 不要让员工"串供"（统一口径不等于伪造证据）
   ——做伪证 = 刑事责任
3. 不要私下给客人赔钱（要有协议+记录）
   ——私下赔钱 = 没有法律保护
4. 不要接受媒体采访时说"无可奉告"或"我不清楚"
   ——这会显得酒店在隐瞒

【应该做的】
1. 记录一切（时间/地点/人物/事件/处理措施）
2. 保留证据（照片/视频/文件/录音）
3. 按程序上报（不要自己扛）
4. 法律意见（重大事件先问律师再说）
5. 保险理赔（酒店财产险/公众责任险/食品安全险）
```

## 危机预案模板

```
每个酒店都应该有的危机预案清单：

□ 火灾预案（每季度演练）
□ 食物中毒预案
□ 客人受伤预案
□ 盗窃/刑事案件预案
□ 自然灾害预案
□ 舆情危机预案（发现-评估-响应-善后）
□ 员工冲突预案
□ 外部冲击预案（周边重大事件）

每个预案应该包括：
1. 第一响应人（谁第一个到场）
2. 指挥链（谁来决策）
3. 沟通机制（谁对外说/对内说）
4. 资源准备（紧急联系人/供应商/保险公司）
5. 事后处理（调查/改进/记录）
```
