# 📥 30-你写给我的
> **职责**：Eric 写给 B166ER 的输入。
> **author**：eric
> **audience**：b166er

## 你应该在这里写什么？
- **决策记录**：当你做了某个决策，写下来（"我决定供应链工程定价 ¥99"）
- **想法/灵感**：临时感悟、产品点子、行业观察
- **需求/请求**：让我做的事（"帮我写供应链工程详情页"）
- **反馈**：对我的产出的评价（"这个图重做"）
- **私密思考**：不想公开但想让我看到的想法

## 我会怎么用？
每次对话开始时，我会主动读这个文件夹里的所有笔记：
1. **优先级最高**：需求/请求类（我会立刻执行）
2. **次优先**：决策类（我会确认并同步到 Dashboard）
3. **常规**：想法和反馈（我会整合到对应产品/项目笔记）

## 你可以做的事

- ✅ 在这里自由写，不用管格式
- ✅ 写完后我会自动看到，无需通知我
- ✅ 可以随时修改、删除
- ✅ Obsidian 自动保存历史

## 建议的笔记命名
- `YYYY-MM-DD-主题.md`（如 `2026-07-12-D-day应对策略.md`）
- 或者直接 `想法-001.md`、`决策-003.md`

## 我会如何响应

| 你写了什么 | 我的响应 |
|-----------|---------|
| "请帮我写 XXX" | 立即在 `10-我为你生成的/` 写入新文件 |
| "我决定 XXX" | 同步到 Dashboard 的"已决策"区 |
| "我觉得 XXX 不对" | 找到对应文件，加 frontmatter `status: deprecated` |
| 想法/观察 | 整合到相关 KB 或新建主题笔记 |
| 私密思考 | 只有我自己看（不会写入任何共享文件）|
