# 软件操作说明

**软件名称**：宿语AI住宿服务系统 V1.0

---

## 一、系统简介

宿语AI住宿服务系统（代号：AI-Hotel-Language，简称"宿语系统"）是一个面向住宿业的智能对话预订平台。系统以浏览器为入口，用户通过自然语言与AI对话，即可完成住宿咨询、房源推荐和在线预订，无需任何操作培训。

---

## 二、安装配置

### 2.1 环境要求

- Python 3.8+
- Node.js 16+
- npm 或 yarn
- DeepSeek API Key（需自行申请）

### 2.2 后端安装

```bash
# 进入后端目录
cd backend

# 安装依赖
pip install -r requirements.txt

# 配置环境变量
# 复制 .env.example 为 .env，填入以下内容：
# DEEPSEEK_API_KEY=你的API密钥
# DEEPSEEK_MODEL=deepseek-chat
# DEEPSEEK_API_BASE=https://api.deepseek.com/v1

# 启动后端
python main.py
```

后端启动后运行在 http://localhost:5000

### 2.3 前端安装

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 开发模式运行
npm run dev
```

前端启动后访问 http://localhost:5173

### 2.4 一键启动（Windows）

双击运行 `start.bat`，自动启动前后端服务。

## 三、功能操作

### 3.1 C端用户操作

#### 进入系统
打开前端页面，系统默认为C端（消费者）模式。顶部显示"伴"字品牌标识。

#### 对话咨询
在底部输入框输入自然语言描述需求，例如：
- "我想去大理放松几天"
- "有没有洱海边的房间"
- "三人住，价格500以内"

系统会以自然语言回复，并智能推荐匹配的房源。

#### 在线预订
当确定要预订时，说出意向房型，系统自动进入预订流程：
1. 选择房型
2. 确认入住/退房日期
3. 提供姓名和手机号
4. 系统自动创建订单

订单创建成功后显示订单号和状态。

### 3.2 B端房东操作

#### 切换身份
点击右上角菜单 → 选择"切换到房东版"，进入B端房东模式。

#### 房源管理
- 查看当前房源信息
- 管理房源完整度评分
- 接收AI优化建议

#### 房东对话
房东可以AI身份与客户对话，处理客户咨询和预订确认。

## 四、核心功能说明

### 4.1 多级语义理解
系统将用户需求划分为三个语义层：
- **情绪层**：理解用户情绪状态（放松/治愈/安静）
- **感官层**：理解场景感受（海风/阳光/山景）
- **房源层**：理解具体需求（价格/位置/设施）

系统根据语义层次自动匹配最合适的话术和房源推荐。

### 4.2 会话式预订
区别于传统表单预订，用户全程以对话方式完成预订，系统会：
- 自动收集必要信息（房型/日期/联系方式）
- 智能处理暂停/继续/取消语义
- 实时校验信息有效性（手机号格式/日期逻辑）
- 订单创建后自动返回订单详情

### 4.3 智能推荐
系统根据用户描述的预算、人数、位置偏好、风格偏好，对所有房源进行多维度评分，优先推荐匹配度最高的房源，并附带个性化推荐理由。

### 4.4 多轮上下文
系统记忆当前会话的所有对话内容，支持：
- 跨意图的信息继承（预订过程中说"算了"后可以继续闲聊，再回到预订流程）
- 历史偏好保持（下次对话记住用户的偏好）
- 状态一致性（同一个会话中的操作不会互相矛盾）

## 五、常见问题

### 5.1 提示"DeepSeek API Key未配置"
需要在 `backend/.env` 文件中配置有效的 DeepSeek API Key。

### 5.2 前端页面空白
检查后端是否启动在5000端口，以及前端是否启动在5173端口。

### 5.3 预订时提示"房间已被预订"
该日期范围内房间已被其他用户预订，请更换日期或选择其他房型。

### 5.4 手机号校验失败
系统仅支持中国大陆11位手机号（1开头）。
