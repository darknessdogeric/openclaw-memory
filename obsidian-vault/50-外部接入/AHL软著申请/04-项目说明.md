# AI-HOTEL-LANGUAGE-DEMO

AI 住宿业项目，包含前端和后端。

## 目录

- `backend/` Flask 后端
- `frontend/` Vue 前端
- `docs/` 项目资料
- `knowledge_base/` 知识库

## 环境变量

- 复制 `backend/.env.example` 为 `backend/.env`
- 复制 `frontend/.env.example` 为 `frontend/.env`
- 复制根目录 `.env.example` 为 `.env`（仅 legacy demo 需要）

## 运行

- 后端：`cd backend` 后执行 `python main.py`
- 前端：`cd frontend` 后执行 `npm install`，再执行 `npm run dev`

## 说明

- 仓库中不包含本地密钥、数据库、虚拟环境和依赖目录
- 合作伙伴克隆后需要自己配置 API Key
