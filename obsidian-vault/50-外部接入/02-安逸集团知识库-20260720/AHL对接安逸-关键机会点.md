## 🔍 AHL 战略定位回顾

### AHL 的核心定义（基于现有资料）
> "AHL = 安逸酒店集团内的**Agent/Hospitality Layer（智能体/酒店层）**产业互联网孵化项目"
> "通过 AI Agent + 酒店场景 = 集团内的轻资产高价值平台"

### AHL 的三重复合目标
1. **短期**：用集团内场景打磨 AHL 模型（220 万 → 78,752 间管理房间 + 52 家轻资产酒店中找 5-10 家试点）可达性是关键资源）
3. **长期**：从集团内部孵化升级为独立/集团内分拆（2028-2029 目标）

### AHL 与安逸集团的战略契合度

```
AHL 需要      ← →  安逸集团提供
───────────────────────────────
酒店场景      ← →  旗下 (52 家轻资产酒店 + 78,752 间管理房间, 十五五规划口径)
集团背书      ← →  省属国企信誉
数据资源      ← →  PMS/CRS/数字化中台
客户资源      ← →  安逸会 160 万 → 600 万会员
供应链资源    ← →  安逸购全国集采可达
政企关系      ← →  省旅投集团背景合作
```

## ⚠️ 红线（绝对不能踩）

1. ❌ **不成立公司** — 任何对外主体（黄灯/红灯）
2. ❌ **不以安逸干部身份做商业行为** — 严格规避
3. ❌ **不在安逸集团下属酒店推销个人产品** — 利益冲突
4. ❌ **不在朋友圈评价安逸集团业务** — 公开约束
5. ❌ **不主动向安逸集团干部披露 AHL 现状** — 至少前 12 个月内

1. ✅ **私下收集集团需求** — 为 AHL 模型打磨提供数据

3. ✅ **以个人身份参加外部 AI/酒店论坛** — 保持技术敏感度
4. ✅ **以"集团产业发展部负责人"身份研究行业最佳实践** — 包含外部案例等跨境伙伴探索"安逸相关"合作可能** — 但不主动
