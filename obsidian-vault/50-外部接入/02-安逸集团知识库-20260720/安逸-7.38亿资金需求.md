# 安逸"十五五"7.38-8.38 亿元资金需求与"四轮驱动"融资策略

> **核心定位**：这是集团"十五五"全周期的资金底盘——7.38-8.38 亿元看似巨大，但拆解后每个数字都有具体去向。本 note 帮助 Eric 在第一次会议上听懂"为什么是这样融资"。

---

## 💸 资金总需求拆解（7.38-8.38 亿）

```
┌───────────────────────────────────────────┐
│  核心酒店改造       4.08 亿元 (55%)        │
├───────────────────────────────────────────┤
│  停业期间刚性支出   0.88 亿元 (12%)        │
├───────────────────────────────────────────┤
│  战略性发展投资     1.42 亿元 (19%)        │
├───────────────────────────────────────────┤
│  债务优化与流动性   1.00-2.00 亿元 (14-27%)│
└───────────────────────────────────────────┘
```

### 拆解 1：核心酒店改造 4.08 亿元
- 详见 [[安逸-六大旗舰改造-4.08亿]]

### 拆解 2：停业期间刚性支出 0.88 亿元
**这是什么？** 集团旗下部分酒店停业期间仍需支付的费用：
- 员工工资（停岗不下岗）
- 设备维护 + 能源基础费用
- 物业管理费 + 保险
- 法院诉讼费用（如古尔沟债务相关）

**为何有这么大数？**
- 四川宾馆停业 6+ 年 × 持续支出 + 亚丁宾馆/梦温泉停业
- 这部分"刚性"导致集团必须保持流动性

### 拆解 3：战略性发展投资 1.42 亿元
包括：
- 优质酒店标的并购（成都核心商圈 + 文旅目的地）
- 酒管公司并购（轻资产能力补齐）
- 文旅列车（"锦绣天府号"熊猫专列已签 + 继续复制）
- 高原氧舱旅游驿站（317/318 沿线）

### 拆解 4：债务优化与流动性储备 1-2 亿元
包括：
- 古尔沟神峰温泉债务重组（负债 170%+）
- 总府皇冠假日债务重组（负债 185%+）
- **关键功能**：用于偿还到期债务 + 维护流动性

> **Eric 解读**：这部分是"消防水" — 让集团在严酷环境下不爆雷

## 🚀 "四轮驱动"融资策略

### 驱动 1：**内部挖潜与资产盘活**（力争 0.5-1 亿元）

#### 行动 1：亏损企业治理 → 经营性现金流持续改善
- 集采降本 → "安逸购"贡献率继续提升 13.7%
- 单店改善 → 标杆标杆效应 → 100 间酒店小优化也是大数

#### 行动 2：闲置资产盘活 → 转让/出租限期盘活
- 亚丁宾馆、梦温泉、天府山庄
- 目标：回笼资金 0.5-1.0 亿元
- 时间：贯穿整个"十五五"

---

### 驱动 2：**政策性及低成本资金争取**（隐形杠杆）

#### 资金 1：设备更新改造专项再贷款
> "**利率 1.75%**" + 中央财政贴息

- 这是当前最关键的政策窗口
- 6 大旗舰改造都有"设备更新"需求
- 1.75% 利率 vs 商业贷款 4-5% = **每年节约成本 2000 万+**

#### 资金 2：国家级专项奖励
- 国家级文化主题旅游饭店
- 绿色旅游饭店
- 需主动申报 → 应有专人跟进

#### 资金 3：绿色贷款
- 改造方案中纳入绿色建筑 + 节能设计
- 申请商业银行绿色贷款 → 利率优惠

---

### 驱动 3：**市场化融资**（最大杠杆）

#### 资金 4：中长期项目贷款
- 以**改造项目未来经营性现金流**为抵押
- 以**物业资产**为抵押
- 标准商业银行对公贷款模式

#### 资金 5：**"土地作价抵装修"模式** — 最创新
> 与华西集团等省属建设类国企合作，以**低效闲置土地或物业评估作价，抵扣首批酒店改造工程款**

**Eric 解读 — 这是最有意思的部分**：
- 不是"借钱" → 而是"以资源换工程"
- 集团有"低效闲置土地"（亚丁宾馆/梦温泉/天府山庄）
- 华西集团是省属建设类国企（同等政治地位）
- 这是 Eric 可深耕的"非传统融资模式"

**预计置换 6,400 万元现金投资需求** — 这相当于 6 大旗舰改造的 16%

#### 资金 6：供应链金融
- 依托"安逸购"平台开展
- 集采供应商账期延长 → 解决短期资金缺口

#### 资金 7：产业基金
> "联合省旅投集团及社会资本发起设立'**安逸存量资产盘活专项基金**'，作为权益资金支持改造与并购。"

- 这是用基金方式做重资产盘活
- "专项基金"是 Eric 可深度参与的金融工具

---

### 驱动 4：**资本运作与创新工具**（最高级）

#### 资金 8：ABS 资产支持证券
- 对改造后现金流稳定的优质资产
- 以未来经营收益权为基础资产
- **可在 2027-2030 期间发行**

#### 资金 9：类 REITs / CMBS
> "在'十五五'后期，将成熟优质资产组合作为底层资产，研究发行**类 REITs 或 CMBS** 的可行性"

- **关键时间窗**：2030 年以后
- 类 REITs = 不动产投资信托基金（公募 REITs 升级版）
- CMBS = 商业地产抵押贷款支持证券

#### 打通"投融建管退"资本闭环
> "投 → 改造/并购 → 运营 → 证券化 → 再投资"

这是资本运作的最高境界 — 让资金滚动起来

---

## 📅 融资实施三阶段

### 阶段 1：**创新破局**（2026-2027）
- 全力落地"土地作价抵装修"模式
- 同步申请设备更新贴息贷款 + 绿色贷款
- 启动设立存量资产盘活基金

### 阶段 2：**多元铺开**（2028-2030）
- 政策性贷款与市场化项目贷款结合
- 支持第二批改造项目（总府 + 新良大酒店）
- 产业基金资金投入改造及并购
- 探索经营权 ABS 等盘活手段

### 阶段 3：**资本循环**（2030 以后）
- 对成熟优质资产启动类 REITs/CMBS 发行论证
- 培育公募 REITs 资产包
- 形成可持续资本运作闭环

## 🎯 Eric 个人洞察

### 5 个"非传统"融资机会（Eric 可深耕）

1. **碳中和 REITs** — 集团 6 大旗舰改造的"绿色"成色如能做实，可能套用碳中和金融工具
2. **文旅专项基金** — 国家文旅部 + 四川省政府都有文旅基金（如四川文化产业发展基金）
3. **乡村振兴基金** — 安逸·农庄子品牌可申请（赛道 3 重要资金渠道）
4. **成都市文旅消费券** — 跨界引流工具，可贡献现金流
5. **酒店品牌 IPO 路径** — 轻资产平台未来上市（如果有上市规划）

### 风险提示

1. **资产负债率 56.76% → 60% 以下** — 集团对负债率有底线要求，意味着融资规模受限
2. **期限错配风险** — 短期负债不能用于长期投资（专项要求）
3. **国有资产评估/审批/备案** — 所有创新融资必须走完整合规流程
