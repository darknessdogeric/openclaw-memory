# 安逸酒店集团 · 产业发展部 · 部门职责草案（v1.0）

> **用途**：入职前对"产业发展部应该做什么"形成初步框架
> **方法**：基于"产业发展部部长"通用职责 + 集团"1244 战略"提法 + Eric 个人行业经验
> **状态**：草案 — 入职后第一周根据实际组织情况调整
> **生成时间**：2026-07-07
> **使用方式**：作为面谈抓手（与董事长/总经理讨论职责边界）

---

## 一、部门定位

### 1.1 部门核心定位（一句话）
**"集团产业发展的参谋部、研究室、催化剂"** — 为集团"产业做大、做强、做新"提供战略研究、产业拓展、项目孵化支持。

### 1.2 与其他部门的关系

| 部门 | 关系 | 协作模式 |
|------|------|---------|
| 投资发展部 | **互补** | 投发部 = 投资执行 · 产业部 = 投资方向 + 产业研究 |
| 运营管理部 | **支持** | 运营部 = 现有业务 · 产业部 = 未来业务 |
| 战略规划部（如有） | **合并 / 协同** | 产业部承接产业战略研究 |
| 品牌营销部 | **协同** | 共同做产业品牌 |
| 财务部 | **数据来源** | 财务数据 + 产业部做产业财务分析 |
| 人力资源部 | **支持** | 部门编制、招聘、培训 |

### 1.3 "产业"的口径定义

**避免**：
- 局限于"酒店业"内部（太窄）
- 泛泛"产业研究"（太虚）
- 与投资部职能重叠

**建议口径**：
> 围绕"安逸集团主业（酒店 + 住宿 + 餐饮 + 文旅 + 大消费）"的 **"上下游延伸 + 横向跨界 + 资本运作"** 三个方向的产业研究、产业拓展、产业孵化。

具体包括：
- 酒店 + 物业（物业服务、不动产管理）
- 酒店 + 餐饮（连锁餐饮、食材供应链）
- 酒店 + 培训（酒店人才培训认证）
- 酒店 + 文旅（景区托管、文旅项目）
- 酒店 + 大健康（康养、医养、养老）
- 酒店 + 数字（数字化、智能化、AI 应用）
- 酒店 + 资本（REITs、ABS、并购、产业基金）

## 二、核心职责（8 大模块）

### 模块 1：产业研究（占 25%）

**目标**：建立集团产业研究能力，成为集团决策的"参谋部"。

- 1.1 跟踪国家、省、市 与酒店 + 文旅 + 大消费 相关的政策、法规、行业动态
- 1.2 跟踪头部企业（万豪、希尔顿、锦江、华住、首旅、亚朵 等）的战略动向
- 1.3 跟踪资本市场动态（REITs、ABS、产业基金、IPO）
- 1.4 跟踪科技创新动态（AI、数字化、智能化）
- 1.5 撰写《产业研究月报》/《产业研究季报》/ 专项产业研究报告
- 1.6 维护"集团产业研究数据库"（行业数据、政策文件、案例库、竞品档案）

**关键产出**：
- 《产业研究月报》— 每月 1 期，10-20 页
- 《行业季度观察》— 每季 1 期，30-50 页
- 《专项研究报告》— 按需（如医养酒店、数据资产、入境游、REITs）

---

### 模块 2：产业拓展（占 25%）

**目标**：从 0 到 1 拓展新业务、新模式、新合作。

- 2.1 **产业链上下游延伸** — 围绕酒店主业，寻找上下游机会
  - 物业服务（向外部输出）
  - 餐饮连锁（向外部输出）
  - 酒店培训（向行业输出）
  - 供应链（采购联盟）
  - 二手物资处置
- 2.2 **跨产业横向拓展** — 酒店 + 其他产业
  - 酒店 + 文旅（景区 / 度假区托管）
  - 酒店 + 城市更新（旧城改造 / 城市配套）
  - 酒店 + 乡村振兴（民宿集群 / 农文旅）
  - 酒店 + 银发经济（康养基地 / 老年大学）
  - 酒店 + 数字经济（数字孪生酒店 / 文旅元宇宙）
- 2.3 **资本化探索** — 把产业变成资产、变成金融产品
  - 数据资产入表
  - REITs（酒店 REIT / 文旅 REIT）
  - ABS（应收账款 / 物业收益权）
  - 产业基金（与其他投资人合作）
  - 并购重组机会
- 2.4 **外部合作**
  - 与头部企业（万豪、锦江 等）合作机会
  - 与国资体系（蜀道、川投 等）协同
  - 与地市州政府合作
  - 与外部智库 / 咨询公司合作
  - 与高校 / 科研院所合作

**关键产出**：
- 每年 2-3 个新业务孵化项目（从 0 到 1 启动）
- 每年 1-2 个跨产业合作签约
- 资本化项目 1-2 个立项

---

### 模块 3：政府关系与政策资源（占 15%）

**目标**：把"政府关系"从"接待来访"升级为"主动争取政策资源"。

- 3.1 跟踪并争取四川省 / 成都市 / 地市州 的文旅、住宿、餐饮 行业扶持政策
- 3.2 争取省级 / 国家级 试点（智慧酒店、绿色酒店、REITs 试点、乡村振兴示范）
- 3.3 争取财政补贴、税收优惠、产业基金
- 3.4 与省国资委、省旅投、各地市州政府 建立日常沟通机制
- 3.5 主导集团"政策研究 + 政策争取"工作（与办公室 / 战略部协同）

**关键产出**：
- 政策月报（哪些政策与集团相关）
- 政策争取清单（每项金额、申报路径）
- 政府关系档案

---

### 模块 4：行业研究与标杆对标（占 10%）

**目标**：对标头部企业，找到集团差距与机会。

- 4.1 国际酒店集团对标（万豪、希尔顿、洲际、雅高、温德姆）
- 4.2 国内头部对标（锦江、华住、首旅、亚朵、东呈、格林）
- 4.3 央企国企酒店集团对标（首旅、岭南、锦江）
- 4.4 四川省内同行对标（峨眉山股份、九寨沟股份 等）
- 4.5 跨行业标杆对标（迪士尼、Club Med、亚朵 S 酒店、亚朵 X 酒店 等）
- 4.6 形成《标杆企业深度研究》+《集团差距与机会清单》

**关键产出**：
- 每年 4-6 个标杆企业深度研究
- 1 份《标杆对标年度总报告》

---

### 模块 5：产业数据与分析（占 10%）

**目标**：建立集团产业数据资产（与运营部分工）。

- 5.1 行业数据库：STR 报告、中国饭店协会数据、文旅部数据、第三方咨询数据
- 5.2 竞品监控：主要竞品的价格、房态、营销动作
- 5.3 政策库：政策法规、试点机会、申报动态
- 5.4 项目库：潜在项目、合作方、并购标的
- 5.5 数据可视化：BI 看板、月报数据图、行业趋势图

**关键产出**：
- 产业数据库（数据库 + BI 看板）
- 行业数据月报

---

### 模块 6：跨集团协同与项目孵化（占 10%）

**目标**：作为集团内部"跨部门"催化剂。

- 6.1 与省旅投体系其他公司（文旅股份、景区公司 等）协同
- 6.2 与外部企业（同行 / 跨行业）合作项目孵化
- 6.3 牵头或参与集团内跨部门专项工作组
- 6.4 主导"产业孵化基金"或"产业孵化器"筹建（如适用）

**关键产出**：
- 每年 2-3 个跨集团协同项目
- 1 份《产业孵化项目池》

---

### 模块 7：专家网络与外脑（占 5%）

**目标**：建立"产业发展部"的外部专家网络。

- 7.1 行业专家库（行业协会 / 头部企业 / 咨询机构 / 学者）
- 7.2 顶级咨询公司关系（麦肯锡 / BCG / 贝恩 / 罗兰贝格 / 戴德梁行 等）
- 7.3 高校与研究机构（北二外 / 中山大学 / 复旦旅游系 等）
- 7.4 定期专家访谈 / 闭门会 / 高峰论坛
- 7.5 内部学习机制（行业研究内训 / 标杆研学）

**关键产出**：
- 100+ 行业专家库
- 每季度 1 次专家闭门会
- 每年 1-2 次标杆研学

---

### 模块 8：内部组织建设（占 5%，前 3 个月重点）

**目标**：建团队、建体系、建文化。

- 8.1 部门组织架构设计（建议 6-10 人）
  - 产业研究组（3-4 人）
  - 产业拓展组（2-3 人）
  - 数据分析组（1-2 人）
  - 行政助理（1 人）
- 8.2 招聘（产业研究、产业拓展、数据分析）
- 8.3 建立部门工作流程（SOP）
- 8.4 建立部门周报、月报、季报机制
- 8.5 团建

**关键产出**：
- 部门组织架构图
- 部门 SOP 文件
- 部门周报 / 月报 / 季报模板

## 三、关键 KPI 建议（用于 1:1 谈判）

### 任职第一年（2026-2027）

| 指标 | 建议目标 |
|------|---------|
| 产业研究产出 | 12 篇月报 + 4 篇季报 + 4 篇专项 |
| 标杆研究 | 6 个标杆企业深度研究 |
| 产业拓展项目 | 2-3 个新项目立项 |
| 资本化项目 | 1 个数据资产 / REITs 试点立项 |
| 政府政策争取 | 3-5 项政策资源落地 |
| 团队建设 | 6-8 人到位 + SOP 完整 |
| 内部满意度 | 班子 + 相关部门 满意度 ≥ 80% |

### 任职第二年（2027-2028）
- 2-3 个新业务进入实际运营
- 1 个资本化项目落地（数据资产 / REITs / ABS）
- 集团"产业"概念被外部广泛认可
- 团队 8-10 人
- 政府关系进入正循环

### 任职第三年（2028-2029）
- 集团"第二增长曲线"业务占比 ≥ 20%
- 至少 1 个跨产业合作项目规模化
- 团队成熟、形成方法论
- 在行业内有一定话语权（行业协会 / 论坛 / 标准制定）

| 岗位 | 人数 | 核心职责 | 任职要求 |
|------|------|---------|---------|
| 部长（Eric） | 1 | 部门全责 + 对班子 | 行业资深 + 战略视野 + 政府关系 |

| 行政助理 | 1 | 文档 + 会议 + 行政 | 细致 + 沟通 |

## 五、入职后第一年关键动作

### Q1（2026 Q3）
- 完成部门定位与班子共识
- 招聘核心人员（3-5 人）
- 启动 3 个标杆研究

### Q2（2026 Q4）
- 完成第 1 份《产业研究季报》
- 完成 1 个新业务立项
- 启动 1 个资本化项目（数据资产 / REITs 试点）
- 完成 1 项政府政策争取

### Q3（2027 Q1）
- 团队 6-8 人到位
- 完成部门 SOP
- 启动 1 个跨集团协同项目

- 第一个完整年度复盘

- 至少 1 个新业务进入实际运营

## 七、入职面谈"反向"建议

### 你向班子提出的关键问题

| 问题 | 目的 |
|------|------|
| 集团对"产业"的口径是什么？ | 明确职责边界 |
| 产业发展部 vs 投资发展部 的边界？ | 避免内耗 |
| 产业发展部 vs 战略规划部（如有）的边界？ | 同上 |
| 第一年我最应该出哪 3 项成果？ | 抓重点 |
| 我能调动哪些资源（人 / 钱 / 关系）？ | 知己知彼 |
| 班子对我的"红线"是什么？ | 避免踩雷 |
| 我的汇报对象是党委书记、董事长、还是总经理？ | 明确汇报线 |
| 部门编制 / 招聘节奏 由谁定？ | 团队建设 |

### 不主动提
- ❌ 个人 IP / 自媒体 / AHL（**绝对不能提**）
- ❌ 任何暗线业务
- ❌ 改革建议（第一周）
- ❌ 任何对班子成员的负面评价
