## 📊 Excel 使用建议

1. **复制 MD 表格到 Excel** — 直接复制粘贴即可
2. **冻结首行** — View > Freeze Panes > Freeze Top Row
3. **数据验证** — 出租率/RevPAR 等关键字段用 Data Validation 设范围
4. **条件格式** — 出租率 < 50% 标红、净利润 < 0 标橙
5. **数据透视表** — 按城市 / 品牌 / 业态 / 自营加盟 4 个维度做透视
6. **共享** — 不要放在公共共享盘，先在自己账号下维护
