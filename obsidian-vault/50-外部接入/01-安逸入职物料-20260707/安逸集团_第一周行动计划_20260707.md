# 安逸酒店集团 · 第一周（Day 1-7）详细行动计划

> **目的**：把"信息清单"转成 7 天可执行的日程
> **原则**：听、看、学、建 · 不主动提改革 · 不出风头
> **生成时间**：2026-07-07

---

## 🎯 第一周核心目标

1. **完成入职手续** — 心理上"我已经是这里的人"
2. **认识 80% 班子成员 + 关键部门负责人** — 1:1 沟通至少 30 分钟/人
3. **拿到 3 份核心文件** — 公司章程 / 组织架构图 / 三年战略规划
4. **建立工作环境** — 工位、OA 账号、邮箱、内部通讯录
5. **形成第一份"工作笔记"** — 每天整理当天观察

## Day 1（周一 · 入职日）

### 上午（9:00-12:00）
- [ ] 9:00 到集团总部人事部报到
- [ ] 提交：身份证 / 学历证 / 资格证 / 离职证明 / 体检报告 / 照片
- [ ] 签合同（劳动合同 / 保密协议 / 竞业限制 / 党员关系转接）
- [ ] 领取：工牌 / 工位 / 电脑 / 办公用品 / 内部通讯录
- [ ] OA / 邮箱 / VPN 账号开通
- [ ] 加入：党（团）组织 / 工会 / 工作群

### 中午（12:00-14:00）
- [ ] 与人事部对接人 1:1 午餐
  - 了解：集团历史沿革 / 重要历史事件 / 历任领导 / 现任班子背景
  - 询问：是否有"新人指南" / 入职培训 / 导师制度
  - 不问：工资、福利（另走流程问）

### 下午（14:00-17:30）
- [ ] 14:30 与党委书记 + 董事长 见面（**关键**）
  - 听：党委书记对集团工作的要求、对你的期望
  - 听：董事长对产业发展部的工作定位
  - 听：当前最关心的 3 件事
  - 听：组织对你未来 3-5 年的设想
  - **不问**：敏感的人事问题 / 班子内部问题
- [ ] 15:30 与总经理 见面
  - 听：总经理对你工作范围的界定
  - 听：产业发展部与现有部门（投资部 / 运营部 / 财务部）的边界
- [ ] 16:30 走访办公室 / 党委办公室 / 工会 / 后勤

### 晚上（19:00-21:00）
- [ ] **整理第一天工作笔记**
  - 今天认识了谁 · 谁给了什么文件
  - 党委书记/董事长/总经理 各 3 个关键表态
  - 哪些信号需要关注（信息、表情、措辞）
  - 明天第一件事要做什么
- [ ] 把今天收到的所有纸质文件拍照 / 扫描
