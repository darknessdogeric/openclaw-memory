## 七、常见问题处理

### 7.1 超售处理

| 步骤 | 操作 | 负责人 |
|------|------|--------|
| 1 | 立即联系客人 | 人工 |
| 2 | 提供升级或换房 | 人工 |
| 3 | 如无法安排，赔偿首晚房费 | 人工 |
| 4 | 协调附近酒店 | 人工 |
| 5 | 分析超售原因，改进流程 | AHL记录 |

### 7.2 价格一致性维护

| 场景 | 处理方式 |
|------|---------|
| 各平台价格不一致 | 以最低价为准调整 |
| 官网比OTA贵 | 官网做会员价，拉平差距 |
| 大促价格低于平日 | 大促结束后立即恢复 |

### 7.3 拒单处理

```
拒单原因：满房/无房/临时维修

处理流程：
1. 确认拒单原因
2. 联系客人致歉
3. 提供替代方案（升级/换房/推荐附近）
4. 记录拒单原因
5. 分析改善，避免再次发生

注意：携程拒单影响排名，需严格控制
```
