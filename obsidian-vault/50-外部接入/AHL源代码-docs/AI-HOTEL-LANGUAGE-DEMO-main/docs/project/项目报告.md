# AI智能民宿预订系统 - 项目报告

## 📋 项目概述

**项目名称**：AI智能民宿预订系统  
**技术架构**：多智能体架构（Multi-Agent System）  
**开发语言**：Python (后端) + Vue.js (前端)  
**AI模型**：DeepSeek API  
**数据库**：SQLite  
**开发周期**：2024年  

---

## 🎯 项目目标

本项目旨在开发一个智能化的民宿预订系统，通过多智能体协作，为客户和房东提供智能化、个性化的服务体验。系统采用对话式交互方式，让用户通过自然语言即可完成房间查询、预订、支付等全流程操作。

## 🚀 如何启动项目

### 方法一：自动启动（推荐）

#### Windows系统
```bash
# 进入项目根目录
cd ai-homestay-system

# 双击运行启动脚本
start.bat
```

`start.bat` 会自动完成以下操作：
1. 检查Python和Node.js环境
2. 安装后端依赖
3. 安装前端依赖
4. 启动后端服务（端口5000）
5. 启动前端服务（端口8080）
6. 自动打开浏览器访问系统

### 方法二：手动启动

#### 1. 启动后端服务

```bash
# 进入后端目录
cd ai-homestay-system/backend

# 安装依赖（首次运行）
pip install -r requirements.txt

# 启动后端服务
python main.py
```

后端服务将在 `http://localhost:5000` 启动

#### 2. 启动前端服务

```bash
# 打开新的终端窗口
# 进入前端目录
cd ai-homestay-system/frontend

# 安装依赖（首次运行）
npm install

# 启动前端服务
npm run dev
```

前端服务将在 `http://localhost:8080` 启动

#### 3. 访问系统

在浏览器中打开：`http://localhost:8080`

## 📊 数据库设计

### 核心数据表

#### 1. User（用户表）
```sql
- id: 用户ID
- username: 用户名
- email: 邮箱
- password_hash: 密码哈希
- user_type: 用户类型（customer/host）
- created_at: 创建时间
```

#### 2. Room（房间表）
```sql
- id: 房间ID
- owner_id: 房东ID
- name: 房型名称
- description: 房型描述
- price_per_night: 每晚价格
- max_guests: 最大容纳人数
- location: 位置信息
- latitude: 纬度
- longitude: 经度
- created_at: 创建时间
```

#### 3. RoomImage（房间图片表）
```sql
- id: 图片ID
- room_id: 房间ID
- image_url: 图片URL
- display_order: 显示顺序
- created_at: 创建时间
```

#### 4. Order（订单表）
```sql
- id: 订单ID
- user_id: 用户ID
- room_id: 房间ID
- check_in_date: 入住日期
- check_out_date: 退房日期
- total_price: 总价
- status: 订单状态（pending/confirmed/cancelled）
- created_at: 创建时间
```

#### 5. Spot（景点表）
```sql
- id: 景点ID
- name: 景点名称
- description: 景点描述
- latitude: 纬度
- longitude: 经度
- category: 景点类别
```

## 🎯 核心业务流程

### 流程1：房型推荐流程

```
用户输入需求
    ↓
CustomerAgent分析意图
    ↓
提取需求参数（价格、位置、人数等）
    ↓
查询数据库匹配房型
    ↓
返回推荐结果 + 房型图片
    ↓
用户查看推荐
```

### 流程2：预订流程

```
用户选择房型
    ↓
CustomerAgent识别预订意图
    ↓
检查房间可用性
    ↓
收集预订信息（日期、人数等）
    ↓
创建订单（status: pending）
    ↓
引导用户支付
    ↓
PaymentAgent处理支付
    ↓
更新订单状态（status: confirmed）
    ↓
返回预订成功确认
```

### 流程3：支付流程

```
用户确认预订
    ↓
创建支付会话
    ↓
生成支付ID
    ↓
用户选择支付方式
    ↓
PaymentAgent处理支付
    ↓
验证支付结果
    ↓
更新订单状态
    ↓
返回支付成功通知
```

```json
  }

```

## 🐛 已知问题与解决方案

### 问题1：图片加载失败
**现象**：前端显示"图片加载失败"

**原因**：
- 后端服务未正常启动
- 图片文件路径配置错误
- 静态文件服务路由问题

**解决方案**：
1. 确保后端服务正常运行
2. 验证图片文件存在于 `backend/static/imgs/` 目录
3. 检查后端终端调试日志
4. 刷新浏览器缓存（Ctrl + Shift + R）

### 问题2：前端无法连接后端
**现象**：前端显示"Network Error"

**原因**：
- 后端服务未启动
- 端口被占用
- CORS配置问题

**解决方案**：
1. 启动后端服务：`python main.py`
2. 检查端口5000是否被占用
3. 验证CORS配置正确

### 问题3：AI回复缓慢
**原因**：DeepSeek API响应时间较长

**解决方案**：
- 正常现象，等待2-5秒
- 可考虑增加加载提示
- 优化prompt减少token消耗
