```

  ↓

  ↓

  ↓

跃升的本质:
  过去 30 年: 旅游业是"经济议题"
  未来 5 年:   旅游业是"国家战略议题"
  ← 经济议题看 GDP,国家战略议题看的是国际博弈格局
```

### 维度 2: 当下情况（5 个结构性事实）

```
1. 国内旅游: 2025 实测 ≈ 60亿人次/5.7万亿(估算)
   → 已经全球最大国内旅游市场
   → 但增速放缓,需要新的政策推力

2. 入境旅游: 2025 实测 ≈ 1.32亿人次/900亿美元
   → 远低于出境游
   → 急需"重新打开大门"的政策(免签扩大等)

3. 国际博弈: 中美脱钩 + 全球供应链重构
   → 旅游被赋予"讲好中国故事"功能
   → 旅游成为低成本高感度的"国际形象工具"

4. 国内经济: 消费不足成为 GDP 增长短板
   → 旅游是消费升级最强赛道
   → 但需要"释放旅游消费潜力"的政策设计

5. 服务经济: 服务业占比 > 50% (中国 2024)
   → 旅游业是服务业高质量发展的代表
   → 但需要"提质增效"避免粗放

奥卡姆第二刀: 5 个事实能用 1 个不变量解释
  不变量: 中国从"制造立国"转向"服务+文化立国"
  旅游业是后者的核心载体
```

### 维度 3: 原因分析（5 条因果链）

```
原因 1: 国际地缘 → 中国需要软实力输出 → 旅游是最柔软的国际传播
原因 2: 国内消费 → 房地产退出支柱 → 旅游被推上消费支柱位置
原因 3: 文化复兴 → 民族自信 → 文化体验型旅游井喷(国潮、汉服、非遗)
原因 4: 数字化 → AI+大数据 → 旅游业第一个被数字化的服务业场景
原因 5: 中等收入陷阱 → 旅游是避免陷阱的消费升级典型场景

5 条原因收敛到 1 个根因:
  中国模式从"出口+投资"切换到"消费+服务+出海"
  旅游业是这一切换最显性的表征 + 抓手
```

### 维度 4: 未来预判（5 个趋势,5 年尺度）

```
趋势 1: 国内旅游 6.7%/年 CAGR(83 亿 / 5 年净增 23 亿人次)
趋势 2: 入境旅游 7.6%/年 CAGR(1.9亿 / 5 年净增 5800 万人次)
趋势 3: 入境花费 CAGR 10.8%(超过人次增速 = 消费升级)
趋势 4: 酒店业 5 大业态分布将重构(中端+30%/入境+35%/康养+50%/智慧+40%/精品+25%)
趋势 5: 一批"国家级旅游节点城市"会成为新一线(类似 20 年前的国家级新区)

群论视角: 这些趋势是"时间群"下的轨道
Orbit(轨道) = 不管从哪个起点出发,5 年后会到达这个状态
Stabilizer(守恒子群) = 阻碍这些趋势的"惯量":
  体制改革速度 / 地方执行力 / 国际地缘波动
```

### 维度 5: 底层逻辑（最深的 1 个问题: 不变量是什么?）

**群论视角（Klein 纲领）: 在不同变换(政策/经济/技术/国际)下,什么不变?**

```
不变的核心真理:
  服务业占 GDP 比重将持续上升
  → 其中"旅游+文化+餐饮+酒店"复合体是服务业最高频场景
  → 中国文化和资源是世界上最大的"未被数字化旅游资产"(兵马俑+故宫+九寨沟)
```
