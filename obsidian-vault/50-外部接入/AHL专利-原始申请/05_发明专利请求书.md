### 申请流程（个人电子申请）

```
步骤1：注册CEPNet电子申请账号
       → 国家知识产权局专利电子申请网：cponline.cnipa.gov.cn

步骤2：安装CPC电子申请客户端
       → 下载地址：cponline.cnipa.gov.cn

步骤3：制作申请文件
       → 使用CPC客户端编辑，或直接上传已准备好的PDF/Word文件

步骤4：提交申请
       → 在线提交后获取申请号（约1-3个工作日）

步骤5：缴纳官费
       → 收到缴费通知书后15日内完成缴费

步骤6：初审查通知（约1-3个月）
       → 形式审查通过后收到受理通知书

步骤7：公布（约18个月）
       → 申请后满18个月自动公布

步骤8：实质审查（申请后3年内提出）
       → 收到公布通知书后提交实质审查请求书

步骤9：授权或驳回
       → 实质审查通过后下发授权通知书，缴费后获得专利证书
```

### 关键时间节点

| 时间节点 | 说明 |
|---------|------|
| 申请日 | 提交日，确定优先权日 |
| 1个月内 | 缴纳申请费，否则视为撤回 |
