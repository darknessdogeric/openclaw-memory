## 二、88 城市体系 — 完整名单（四川占 5 席，重点关注）

### 第一层：旅游枢纽城市（32 个）— **全国交通+航空+集散中心**

4 直辖市 + 27 省会 + 深圳（唯一非省会进枢纽）

北京、天津、石家庄、太原、呼和浩特、沈阳、长春、哈尔滨、上海、南京、杭州、合肥、福州、南昌、济南、郑州、武汉、长沙、广州、深圳、南宁、海口、重庆、成都、贵阳、昆明、拉萨、西安、兰州、西宁、银川、乌鲁木齐

### 第二层：重点旅游城市（33 个）— **旅游资源最集中的城市**

承德、秦皇岛、大同、呼伦贝尔、大连、吉林、伊春、苏州、无锡、宁波、黄山、厦门、赣州、景德镇、青岛、洛阳、开封、宜昌、张家界、珠海、桂林、三亚、乐山、遵义、大理、丽江、西双版纳、林芝、延安、武威、格尔木、中卫、喀什

### 第三层：特色旅游地（23 个）— **突出差异化，"专而精"**

崇礼、平遥、满洲里、阿尔山、延吉、漠河、常熟、安吉、义乌、武夷山、井冈山、婺源、曲阜、韶山、都江堰、稻城、九寨沟、凯里、香格里拉、敦煌、布尔津、和田、石河子

### **四川占 5 席**（重点！）
- **成都** — 枢纽城市
- **乐山** — 重点城市
- **都江堰 + 稻城 + 九寨沟** — 特色旅游地

安逸酒店集团（四川省旅游投资集团旗下二级子企业）实际控制/参股的酒店不止这些——还有攀枝花/西昌/泸州/宜宾/南充等区域，但 **5 席有官方背书**。

## 三、2030 量化目标 — 经济测算

| 指标 | 2030 目标 | 对比 2024 实测 | CAGR 倒推 |
|------|----------|---------------|---------|
| 国内出游人次 | 83 亿 | 约 60 亿（2024）| ~6.7% |
| 国内出游总花费 | 7.7 万亿元 | 约 5.7 万亿元（2024）| ~6.2% |
| 入境旅游人次 | 1.9 亿 | 约 1.32 亿（2024）| ~7.6% |
| 入境旅游总花费 | 1500 亿美元 | 约 900 亿美元（2024）| ~10.8% |

**最小误差说明**：以上 CAGR 是粗算，实际还需 2025 实测数据点校准。
**数据源**：
- 国内出游：国家文旅部公开数据
- 入境数据：国家移民管理局 + 海关总署

**规划措辞**：

**Eric 的两条业务**：
- **AHL 集团内孵化**：入境游激增带来客源结构变化 → AHL 的 AI Agent 可承接"一键中国行"的国际化需求（多语导览 / 外文预订 / 支付便利）
- **独立酒店境外市场拓展指南**：四川是入境大省（成都-九寨-都都江堰黄金线路），Eric 的境外业务有政策窗口

### 🟡 3. 11 个专项工程 — 可申报的扶持基金方向

| 工程 | 跟 Eric 关系 | 申报优先级 |
|------|------------|-----------|
| 智慧旅游提升行动 | AHL Agent 直接对口 | ⭐⭐⭐⭐⭐ |

| 旅游融合业态培育工程 | 医养酒店（"康养旅游"是 5 大融合业态之一）| ⭐⭐⭐⭐ |
| 旅游产品提质升级 | 整体方向 | ⭐⭐⭐ |

**关键洞察**：智慧旅游 + 入境旅游是 Eric 当前项目组合里**最大的两个政策红利承接点**。

### 🟡 4. 三大产业新动能 — 方法论级影响

- **智能化**：要求搭建**文旅行业大模型**——AHL 的双 Agent + 87 个 SKILL 是天然候选
- **绿色化**：碳中和 / 塑料替代 / 光盘行动 → 酒店业运营成本结构变化
- **融合化**："旅游+"双向赋能 → "酒店+"反向赋能（医养 / 研学 / 冰雪）

**对 Eric 的影响**：
- AHL 的定位从"去中心化协议"升级为"智慧旅游基础设施"
- 集团 / 集团下属酒店的数字化升级需求被这份规划**官方背书**
- Eric 作为产业发展部部长，可以**内部立项**申请集团数字化基金

### 🟡 5. 旅游消费释放 — B 端商家具体行动

**规划措辞**：
- "落实带薪休假、弹性错峰休假"
- "鼓励中小学增设春秋假"
- "推广旅游年卡、跨区域联票、文旅消费券"
- "大力发展夜游、文创市集、房车露营"

**对酒店的影响**：
- 客源碎片化（错峰 + 春秋假）→ 中端酒店周末经济升级
- 联票 / 文创市集 → 酒店可成为"在地文化策展方"
- 夜间经济 → 24h 酒店产品新卖点
