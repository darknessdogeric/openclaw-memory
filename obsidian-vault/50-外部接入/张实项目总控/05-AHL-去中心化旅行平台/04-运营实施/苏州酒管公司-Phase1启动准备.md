### SKILL-001: 酒店基础信息自动采集

**功能描述**: 自动收集酒店基础信息，替代人工Excel录入

**输入**: 酒店ID/名称
**输出**: 结构化酒店信息卡片

**采集字段**:
```json
{

    "酒店名称": "string",
    "品牌": "string",
    "地址": "string",
    "客房数": "number",
    "开业年份": "number",
    "装修年份": "number",
    "联系方式": {
      "总经理": "string",
      "销售经理": "string",
      "前台电话": "string"
    }
  },
  "房型信息": [
    {
      "房型名称": "string",
      "房间数": "number",
      "门市价": "number",
      "面积": "number"
    }
  ],
  "设施信息": {
    "会议室": "boolean",
    "餐厅": "boolean",
    "停车场": "boolean",
    "健身房": "boolean"
  }
}
```

**数据来源**:
- OTA平台抓取（携程/美团/飞猪）

- 已有内部数据库

**AI能力**:
- 网页信息自动抓取
- 信息去重与校验
- 变更自动检测

**人机协作**:
- AI完成90%自动采集
- 人工审核10%关键信息
- 异常标记人工确认

### SKILL-006: 异常数据自动预警

**功能描述**: 自动检测异常数据并预警

**监测指标**:
- 入住率异常（< 30% 或 > 100%）
- 价格异常（低于成本价或高于门市价200%）
- 评价异常（差评率 > 10%）
- 订单异常（取消率 > 30%）
- 渠道异常（某渠道订单突降为0）

**预警级别**:
- 🔴 紧急：立即处理（电话+短信+微信）
- 🟡 重要：当日处理（微信+邮件）
- 🟢 提醒：关注即可（系统通知）

**AI能力**:
- 异常检测算法
- 根因分析
- 处理建议生成
