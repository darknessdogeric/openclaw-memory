## 一、小红书文案生成提示词

### 1.1 酒店种草文案

```markdown
角色: 你是小红书资深酒店种草博主，擅长用真实、生动的语言推荐酒店。

任务: 为以下酒店写一篇小红书种草笔记。

酒店信息:
- 酒店名称: {酒店名称}
- 位置: {城市/商圈}
- 特色: {特色标签，如无边泳池/海景房/禅意设计}
- 价格区间: {价格}
- 目标人群: {情侣/家庭/商务/独自旅行}

要求:
1. 标题要吸引人，使用emoji，带关键词
2. 开头3秒抓住眼球（痛点/惊喜）
3. 正文分3-5点介绍酒店亮点
4. 包含真实体验感的描述
5. 添加相关话题标签（10-15个）
6. 结尾引导互动（提问/征集）
7. 配图建议（5-9张图的建议）
8. 语气真实、亲切，像朋友推荐

格式:
标题: [吸引人标题]
正文: [内容]
话题标签: [标签]
```

- 入住体验: { highlights }

要求:

2. 开头描述第一印象（环境/氛围）
3. 详细介绍房间细节（床品/设施/view）

## 二、抖音短视频脚本提示词

### 2.1 酒店探店脚本

```markdown
角色: 你是抖音酒店探店博主，视频节奏快、信息量大。

任务: 写一个30秒酒店探店视频脚本。

酒店信息:
- 酒店名称: {酒店名称}
- 定位: {高端/中端/特色民宿}
- 核心卖点: {最大亮点}
- 价格: {参考价格}

脚本结构:
【0-3秒】开头钩子（悬念/冲突/好奇）
【3-10秒】酒店外观+位置
【10-20秒】房间亮点展示
【20-25秒】设施/服务介绍
【25-30秒】价格+预订引导

要求:
1. 每3秒一个信息点
2. 使用"家人们""绝了""YYDS"等抖音热词
3. 画面切换提示 [画面: XXX]
4. 背景音乐建议 [BGM: XXX]
5. 字幕文案（每句不超过10字）
6. 引导点赞关注的话术

示例钩子:
- "我在XX发现了一家宝藏酒店..."
- "这家酒店的XX简直绝了..."
- "人均XX住进XX景观房..."
```

### 2.2 民宿故事脚本

```markdown
角色: 你是擅长讲故事的短视频创作者，情感细腻。

任务: 写一个60秒民宿故事视频脚本。

故事主题: {如"逃离城市"/"遇见主理人"/"治愈之旅"}

民宿信息:
- 民宿名称: {民宿名称}
- 主理人: {名字/故事}
- 设计理念: {设计灵感}
- 治愈元素: {如猫/书/茶/风景}

脚本结构:
【0-5秒】情绪铺垫（城市压力/疲惫感）
【5-15秒】来到民宿的第一印象
【15-35秒】与主理人的互动/故事
【35-50秒】在民宿的治愈时刻
【50-60秒】感悟+邀请

要求:
1. 情感共鸣开头
2. 讲述一个具体的小故事
3. 金句文案（适合字幕）
4. 画面与文案匹配
5. 治愈系BGM建议
6. 结尾引发共鸣的话术
```
