## 一、早餐服务SOP

### 1.1 早餐前准备（开餐前30分钟）

**人员准备**:
- [ ] 员工仪容仪表检查（工作服、工牌、口罩、帽子）
- [ ] 洗手消毒
- [ ] 了解当日住客数量（预估用餐人数）
- [ ] 了解VIP客人信息（特殊需求）

**餐厅准备**:
- [ ] 开窗通风/空调温度调节（22-24度）
- [ ] 灯光调节（明亮但不刺眼）
- [ ] 背景音乐（轻音乐，音量适中）
- [ ] 餐桌摆台（餐具、餐巾、调味品）
- [ ] 餐台布置（菜品牌、餐具、夹子）

**设备检查**:
- [ ] 咖啡机开启，咖啡豆/粉充足
- [ ] 热水器开启，热水充足
- [ ] 保温设备开启（粥、汤类）
- [ ] 冰箱温度正常（牛奶、酸奶）
- [ ] 餐具消毒柜工作正常

**物品补充**:
- [ ] 餐具充足（餐盘、碗、筷子、勺子、叉子）
- [ ] 餐巾纸充足
- [ ] 调味品充足（盐、糖、醋、酱油、辣椒酱等）
- [ ] 牙签、牙线（部分酒店）
- [ ] 茶水（绿茶、红茶、咖啡）

---

### 1.2 菜品准备（开餐前15分钟）

**出菜顺序**（一般酒店）:
1. **热菜类**: 炒菜、煎蛋、热狗、培根
2. **主食类**: 粥、面条、米饭、馒头、面包
3. **冷菜类**: 凉菜、沙拉、水果
4. **饮品类**: 牛奶、酸奶、果汁、豆浆
5. **甜品类**: 糕点、面包、果酱
6. **其他**: 小菜、咸菜、坚果

**标准配置**（按档次）:

| 档次 | 菜品数量 | 特色 |
|------|----------|------|
| **经济型** | 10-15种 | 基础中式（粥、馒头、小菜）+简单西式（面包、牛奶） |
| **中端** | 20-30种 | 中西结合，本地特色，现场制作（煎蛋、面条） |
| **高端** | 40-60种 | 丰富多样，现场烹饪，进口食材，特色主题 |
| **奢华** | 60种+ | 全日制餐厅水平，单点+自助，主厨现场 |

**温度控制**:
- 热菜：≥60度（保温灯/加热板）
- 冷菜：≤8度（冷藏展示柜）
- 常温食品：室温展示

---

### 1.3 早餐服务流程

#### 客人进入餐厅

**问候**:
- 微笑问候："早上好，欢迎用餐！"
- 询问房号或出示房卡
- 核对早餐权益（房费是否含早）

**引导**:
- "请问您几位？"
- "请这边坐，靠窗的位置可以吗？"
- 引导入座
- 拉椅子（中高端酒店）

**介绍**:
- "早餐是自助形式，菜品在餐台"
- "饮品这边有咖啡、牛奶、果汁"
- "如果有需要，可以告诉我"

#### 餐中服务

**主动服务**:
- 及时清理桌面空盘
- 询问是否需要咖啡/茶水
- 补充餐巾纸
- 关注特殊需求（如老人、小孩）

**巡台**（每5-10分钟）:
- 观察菜品是否充足
- 观察设备是否正常
- 观察客人需求
- 清理空桌

**特殊情况**:
- 菜品不足：立即补充
- 设备故障：立即处理或引导客人至其他区域
- 客人投诉：立即道歉并解决

#### 客人离席

**送别**:
- "请问您用餐还满意吗？"
- "感谢您的光临，祝您今天愉快！"
- 微笑目送

**清理**:
- 客人离开后3分钟内清理桌面
- 更换桌布/餐垫（如脏污）
- 重新摆台
- 准备迎接下一位客人

---

### 1.4 早餐结束收尾

**时间**: 一般10:00或10:30结束

**收尾流程**:
1. **提前15分钟提醒**: 广播或服务员口头提醒
2. **停止补充**: 最后15分钟不再补充菜品
3. **收盘**: 回收所有餐具
4. **清洁**:
   - 清洁餐台
   - 清洁桌面
   - 清洁地面
   - 清洗餐具
5. **设备关闭**:
   - 关闭保温设备
   - 关闭咖啡机
   - 关闭热水器
6. **垃圾处理**: 分类处理厨余垃圾
7. **安全检查**: 关闭不必要的电源、门窗

## 二、宴会服务SOP

### 2.1 宴会前准备（提前1-7天）

**接单**:
- 了解宴会类型（婚宴/会议/寿宴/宝宝宴）
- 了解人数、时间、预算
- 了解特殊需求（菜品禁忌、场地布置）
- 签订合同，收取定金

**策划**:
- 制定菜单（与客人确认）
- 制定服务方案
- 场地布置方案
- 人员安排

**准备**:
- 食材采购
- 餐具准备（足够数量）
- 场地布置（提前1天）
- 人员培训（服务流程）

---

### 2.2 宴会前1天

**检查清单**:
- [ ] 菜单最终确认
- [ ] 食材到货检查
- [ ] 场地布置完成
- [ ] 音响设备测试
- [ ] 灯光调试
- [ ] 空调温度调试
- [ ] 桌椅摆放完成
- [ ] 餐具消毒完成
- [ ] 人员排班确认

---

### 2.3 宴会当天

#### 开餐前3小时

- 厨房开始准备食材
- 服务员到岗，仪容仪表检查
- 最后检查场地
- 播放背景音乐

#### 开餐前1小时

- 冷菜上桌（婚宴/宴会）
- 餐具最后检查
- 服务员站位
- 管理人员巡视

#### 客人到达

**迎宾**:
- 门口迎宾员引导
- 签到台签到（如有）
- 引导入座
- 上茶/上饮料

#### 宴会进行

**上菜顺序**（中式宴会）:
1. 冷菜（已提前上桌）
2. 汤品
3. 热菜（大菜→炒菜→素菜）
4. 主食（米饭/面条/点心）
5. 甜品
6. 水果

**服务标准**:
- 上菜报菜名
- 分菜服务（高档宴会）
- 及时撤换骨碟
- 及时添加茶水/酒水
- 关注主桌/贵宾

**斟酒服务**:
- 白酒：8分满
- 红酒：1/3杯
- 啤酒：8分满（泡沫2分）
- 香槟：2/3杯

#### 宴会结束

**送客**:
- 协助客人取衣物
- 提醒客人带好随身物品
- 送别至门口
- 感谢光临

**收尾**:
- 清理桌面
- 清点餐具（防止丢失）
- 场地恢复
- 结算账单

## 三、客房送餐服务SOP

### 3.1 接单

**记录信息**:
- 房号
- 客人姓名
- 菜品/饮品
- 数量
- 特殊要求（如不加辣、过敏食材）
- 送餐时间（立即/指定时间）

**确认**:
- 复述订单给客人确认
- 告知预计送餐时间（一般30分钟内）
- 告知价格

### 3.2 准备

**厨房准备**:
- 按订单准备菜品
- 注意保温（热菜）或保鲜（冷菜）
- 检查菜品质量

**餐具准备**:
- 餐盘、碗、筷子、勺子
- 餐巾纸、牙签
- 调味品（如需要）
- 账单

**送餐车/托盘准备**:
- 铺设干净餐巾
- 摆放整齐
- 加盖保温（热菜）

### 3.3 送餐

**敲门**:
- 敲门3下
- 话术："客房送餐服务！"

**进入**:
- 客人开门后，微笑问候
- "您好，您的餐送到了。"
- 询问摆放位置

**摆放**:
- 将餐品摆放在合适位置（写字台/茶几）
- 打开盖子（询问客人是否现在打开）
- 摆放餐具
- 介绍菜品

**确认**:
- "您的餐齐了，请慢用。"
- "如有需要，请拨打送餐电话XXX。"
- "祝您用餐愉快！"

**离开**:
- 告别
- 轻轻关门

### 3.4 收餐

**时间**: 一般客人用餐后1-2小时

**电话询问**:
- "您好，请问您用完餐了吗？我可以来收餐具吗？"

**收餐**:
- 敲门进入
- 收拾餐具
- 清理桌面（如有垃圾）
- 询问是否满意

## 四、餐饮服务通用规范

### 4.1 仪容仪表

- 工作服整洁，无污渍
- 工牌佩戴在左胸
- 头发整齐，帽子佩戴规范
- 口罩佩戴（食品接触时）
- 手部清洁，指甲修剪
- 不佩戴首饰（戒指、手表等，或佩戴在衣服内）

### 4.2 服务礼仪

**站姿**:
- 挺胸收腹，双手自然下垂或交叠于腹前
- 不倚靠墙壁、桌椅
- 不叉腰、抱臂

**走姿**:
- 步伐轻快，不奔跑
- 遇到客人主动让行
- 端托盘时平稳

**语言**:
- 使用礼貌用语："您好"、"请"、"谢谢"、"对不起"
- 声音适中，语速适中
- 不讲方言（除非客人要求）

### 4.3 食品安全

**个人卫生**:
- 上岗前洗手消毒
- 接触食物时戴手套或洗手
- 生病时不上岗（感冒、腹泻等）
- 定期健康检查

**食品处理**:
- 生熟分开
- 食材新鲜，不过期
- 烹饪充分，中心温度≥70度
- 剩菜处理规范（不再上桌）

**餐具消毒**:
- 一客一消毒
- 消毒柜温度≥120度，时间≥15分钟
- 消毒后存放在保洁柜

## 五、投诉处理（餐饮）

### 5.1 常见投诉

| 投诉类型 | 处理原则 | 补偿方式 |
|----------|----------|----------|
| **菜品质量问题**（不熟/异味/异物） | 立即撤换，道歉 | 免单该菜品/赠送菜品 |
| **上菜慢** | 解释原因，催促厨房 | 赠送小食/打折 |
| **服务态度** | 道歉，更换服务员 | 经理道歉/赠送果盘 |
| **菜品与描述不符** | 解释/调换 | 打折/赠送 |
| **账单错误** | 核对，立即更正 | 道歉 |

### 5.2 处理流程

1. **倾听**: 让客人说完，不打断
2. **道歉**: "非常抱歉给您带来不好的体验"
3. **解决**: 立即采取行动（换菜/退款）
4. **补偿**: 适当补偿（根据情况）
5. **跟进**: 确认客人满意
6. **记录**: 记录投诉，分析原因
