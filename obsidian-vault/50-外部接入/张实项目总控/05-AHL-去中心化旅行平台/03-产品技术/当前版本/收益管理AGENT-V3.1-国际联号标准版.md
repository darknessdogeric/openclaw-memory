### 1.2 历史数据分析模型

#### 时序分解模型

```
Y(t) = T(t) × S(t) × C(t) × I(t)
需求 = 趋势 × 季节性 × 周期性 × 随机波动
```

**分析输出**：
- **趋势(Trend)**: 复合年增长率(CAGR)、趋势方向、转折点
- **季节性(Seasonality)**: 年度周期、月度指数、周内模式、节假日影响
- **周期性(Cyclical)**: 商业周期识别、经济指标相关性
- **随机波动(Irregular)**: 异常值识别、特殊事件标记

#### 细分市场历史分析

| 分析维度 | 商务散客 | 休闲散客 | 团体 | 协议 |
|---------|---------|---------|------|------|
| 产量趋势 | 年增长率+12% | 年增长率-5% | 年增长率+8% | 年增长率-3% |
| ADR趋势 | +5%/年 | +8%/年 | +2%/年 | -2%/年 |
| 平均提前期 | 7天 | 21天 | 60天 | 14天 |
| 取消率 | 15% | 25% | 5% | 8% |
| 旺季月份 | 全年平均 | 5-6,9-10 | 3-4,9-11 | 全年平均 |
| 渠道占比 | 直销40% OTA35% | OTA60% 直销25% | 直销80% | 直销90% |

#### 价格弹性分析

```python
价格弹性系数 = (需求量变化%) / (价格变化%)

弹性分类:
- 弹性 <-1: 需求敏感 (降价有利)
- 弹性 =-1: 单位弹性
- 弹性 >-1: 需求不敏感 (涨价有利)

典型弹性值:
- 商务散客: -0.6 (不敏感,可提价)
- 休闲散客: -1.2 (敏感,谨慎涨价)
- 团体: -0.3 (极不敏感)
- 协议: -0.1 (几乎不敏感)
```

## 二、营销日历监控维度深化

### 2.1 三层营销日历体系

```
集团营销日历体系
│
├── 集团统一层 (Corporate Level)
│   ├── S级: 集团品牌战略 (100%统一)
│   ├── A级: 全国大促 (80%统一)
│   └── B级: 区域联合 (50%统一)
│
├── 区域协调层 (Regional Level)
│   ├── 区域联合营销
│   ├── 区域客源市场活动
│   └── 区域竞争应对
│

    ├── 本地市场活动
    └── 竞争差异化活动
```

### 2.2 营销日历监控内容

| 监控维度 | 具体内容 | 更新频率 | 预警规则 |
|---------|---------|---------|---------|
| **集团活动** | 名称、时间、统一策略、单店任务 | 实时 | 未配置提醒 |
| **区域活动** | 区域联促、客源市场活动 | 周 | 参与度低于平均 |

| **竞对活动** | 竞品促销活动 | 日 | 大规模促销 |
| **节假日** | 法定假日、学校假期 | 年 | 30天前提醒 |

### 2.3 营销活动影响评估

```python
def evaluate_campaign_impact(campaign, hotel):
    return {
        # 直接收益影响
        'revenue_impact': {
            'expected_room_nights': 预计增量间夜,
            'expected_adr_change': 预计ADR变化,
            'expected_revenue_lift': 预计收入增长,
        },
        
        # 客源结构影响
        'segment_impact': {
            'target_segments': 目标客群,
            'expected_mix_change': 预计客源结构变化,
        },
        
        # 竞争影响
        'competitive_impact': {
            'price_pressure': 价格压力评估,
            'market_share_impact': 市场份额影响,
        },
        
        # 冲突检测
        'conflicts': 与现有活动/事件冲突,
        
        # 建议行动
        'recommendations': 参与建议/调整建议,
    }
```

```
国际联号标准报表体系
│
├── 战略层 (Strategic)
│   ├── 年度预算与预测报告
│   ├── 年度市场分析报告
│   └── 年度竞争对标报告
│
├── 管理层 (Management)
│   ├── 月度业绩报告 (Monthly Performance Report)
│   ├── 季度复盘报告 (Quarterly Business Review)
│   └── 细分市场深度分析
│
├── 运营层 (Operational)
│   ├── 周度预测与策略 (Weekly Forecast)
│   ├── 日度业绩快报 (Daily Flash Report)
│   └── 日内实时监控
│
└── 专项 (Special)
    ├── 事件影响分析报告
    ├── 竞品价格追踪报告
    ├── 渠道效率分析报告
    └── 团体业务评估报告
```

### 4.2 新增国际联号标准报表

#### A. 月度业绩报告 (Monthly Performance Report)

**报告结构** (对标万豪/希尔顿模板):

| 章节 | 内容 | 数据源 |
|------|------|--------|
| **Executive Summary** | 核心指标达成情况、关键结论 | 汇总数据 |
| **Financial Performance** | OCC/ADR/RevPAR/收入详细分析 | PMS系统 |
| **Competitive Benchmarking** | RGI/MPI/ARI、竞争群对比 | STR报告+爬虫 |
| **Segment Analysis** | 各细分市场表现、趋势 | PMS细分数据 |
| **Channel Analysis** | 渠道占比、效率、成本 | 渠道报表 |
| **Booking Pace Analysis** | 预订进度、Pickup趋势 | CRS系统 |
| **Next Month Strategy** | 下月关键事件、策略、行动计划 | 预测系统 |

#### B. 日度业绩快报 (Daily Flash Report)

**报告内容**:
- Yesterday's Performance (昨日表现)
- Today's Forecast (今日预测)
- 14-Day Outlook (14天展望)
- Competitive Intelligence (竞品动态)
- Recommended Actions (行动建议)

#### C. 团体业务评估报告 (Group Business Evaluation)

**报告维度**:
- 团体请求评估 (Request Evaluation)
- Displacement Analysis (置换分析)
- 历史团体表现 (Historical Group Performance)
- 团体利润贡献 (Group Profitability)
- 战略价值评估 (Strategic Value)

#### D. 渠道效率分析报告 (Channel Efficiency Report)

**分析指标**:
- 渠道收入占比
- 渠道ADR对比
- 渠道佣金成本
- 渠道净ADR (Net ADR)
- 渠道获客成本 (CAC)
- 渠道客人LTV
