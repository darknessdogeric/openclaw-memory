## 一、客户需求深度解读

### 1.1 需求清单分析

| 需求项 | 客户痛点 | 技术实现 | 优先级 |
|--------|---------|---------|--------|

```
苏州酒管公司业务场景:
```

### 4.2 SKILL-P-02: 动态定价 (Dynamic Pricing)

**功能描述**:
AI自动生成最优定价建议，支持一键执行

**定价模型**:
```
最优价格 = 基础价格 × 需求因子 × 竞争因子 × 库存因子 × 时间因子

基础价格: 酒店历史平均ADR
需求因子: AI预测需求强度 (0.8-1.5)
竞争因子: 竞品价格位置 (0.9-1.2)
库存因子: 剩余库存压力 (0.8-1.3)
时间因子: 提前期衰减 (0.9-1.1)
```

**定价策略矩阵**:
| 场景 | 触发条件 | 定价建议 | 执行方式 |
|------|---------|---------|---------|
| **早鸟战略** | 提前>21天，预订<20% | BAR-15% | 自动执行 |
| **尾房清仓** | 入住前<48h，库存>15% | BAR-25% | 自动执行 |
| **会展锚定** | 大型活动前90天 | 阶梯涨价+50% | 建议+确认 |
| **竞品跟随** | 竞品降价>10% | 选择性跟降 | 建议+确认 |
| **周末溢价** | 周五/六，需求>80% | BAR+30% | 自动执行 |

**移动端操作**:
```
定价建议 (手机端)
┌─────────────────────┐
│ 今日定价建议         │
├─────────────────────┤
│ 当前BAR: ¥688       │
│ 建议价格: ¥743 🔥   │
├─────────────────────┤
│ 理由:               │
│ • 竞品涨价12%       │
│ • 预订进度超预期    │
│ • 明日有展会        │
├─────────────────────┤
│ [采纳建议] [调整]   │

```
