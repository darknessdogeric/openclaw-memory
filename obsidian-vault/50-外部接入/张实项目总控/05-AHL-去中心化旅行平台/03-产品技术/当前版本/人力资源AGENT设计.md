## 二、SKILL集群详细设计

### SKILL群1: 智能招聘SKILL群

#### SKILL-001: 智能招聘需求分析

**功能描述**: 分析部门招聘需求，生成岗位画像和招聘策略

**输入**: 
- 部门招聘申请（岗位、人数、到岗时间）
- 历史招聘数据（该岗位历史通过率、留存率）
- 市场人才供给情况

**处理逻辑**:
```
1. 解析岗位JD，提取关键要求（学历、经验、技能）
2. 分析历史数据，确定招聘难点
3. 评估市场人才供给，判断招聘难度
4. 生成岗位画像（理想候选人特征）
5. 制定招聘策略（渠道、周期、薪酬定位）
```

**输出**:
```json
{
  "岗位": "前台接待",
  "需求人数": 2,
  "紧急程度": "高",
  "岗位画像": {
    "硬性要求": ["大专学历", "1年以上经验", "形象良好"],
    "软性要求": ["服务意识", "沟通能力", "应变能力"],
    "优先条件": ["英语口语", "PMS系统经验"]
  },
  "招聘策略": {
    "主渠道": "智联招聘（50%）",
    "辅渠道": "58同城（30%）+ 内部推荐（20%）",
    "薪酬定位": "市场中位值",
    "预计周期": "14天"
  },
  "风险提示": "该岗位近期离职率高，建议关注工作负荷"
}
```

**触发条件**: 部门提交招聘申请时自动生成

#### SKILL-002: AI简历筛选

**功能描述**: 自动筛选简历，匹配岗位需求，排序推荐

**输入**: 
- 收到的简历（PDF/Word/在线简历）
- 岗位要求（SKILL-001生成）

**处理逻辑**:
```
1. 简历解析：提取关键信息（学历、经验、技能、联系方式）
2. 条件匹配：硬性条件筛选（必须满足）
3. 偏好匹配：软性条件打分（优先满足）
4. 综合评分：计算匹配度（0-100分）
5. 排序推荐：高分优先，标注亮点和风险
```

**输出**:
```json
{
  "简历总数": 50,
  "筛选结果": {
    "高度匹配": 5,
    "中度匹配": 12,
    "低度匹配": 18,
    "不匹配": 15
  },
  "TOP5推荐": [
    {
      "姓名": "张**",
      "匹配度": 92,
      "亮点": ["3年前台经验", "英语6级", "洲际酒店背景"],
      "风险": "期望薪资高于预算10%",
      "建议": "优先面试"
    }
  ]
}
```

**触发条件**: 收到新简历时自动筛选，每日汇总推荐

#### SKILL-003: AI视频面试初筛

**功能描述**: 对候选人进行AI视频面试，评估形象和基础能力

**输入**: 
- 候选人简历（已通过初筛）
- 面试题库（岗位相关）

**处理逻辑**:
```
1. 发送面试邀请：短信/邮件发送AI面试链接
2. AI视频面试：
   - 形象评估：五官、着装、仪态
   - 语言表达：清晰度、流畅度、逻辑性
   - 情景问答：3-5个情景问题，评估应变能力
   - 稳定性评估：离职原因、职业规划
3. 综合评分：形象(30%) + 表达(40%) + 应变(30%)
4. 生成报告：评分+评价+建议
```

**输出**:
```json
{
  "候选人": "张**",
  "面试评分": 85,
  "维度评分": {
    "形象气质": 88,
    "语言表达": 82,
    "应变能力": 85
  },
  "AI评价": "形象良好，表达清晰，有服务意识，建议进入下一轮",
  "风险点": "对薪资期望较高，需在二面确认",
  "建议": "通过初筛，安排部门面试"
}
```

**触发条件**: 简历筛选通过后自动发送AI面试邀请

#### SKILL-006: AI陪练教练

**功能描述**: 模拟真实场景，AI扮演客户进行训练

**输入**: 
- 训练场景（入住/退房/投诉/销售）
- 员工角色

**处理逻辑**:
```
1. 场景生成：AI生成真实对话场景
2. 实时互动：员工与AI对话，AI扮演客户
3. 实时反馈：AI实时评价员工表现
4. 评分总结：对话结束后综合评分
5. 改进建议：指出问题，提供改进建议
```

**示例场景**: 客户投诉房间卫生
```
AI（客户）: "你们房间太脏了，床单上有头发！"
员工: "非常抱歉，我立刻安排换房"
AI（实时反馈）: ✓ 道歉及时，✗ 未询问具体需求，建议：询问是否需要升级房型
```

**触发条件**: 员工自主训练或培训作业
