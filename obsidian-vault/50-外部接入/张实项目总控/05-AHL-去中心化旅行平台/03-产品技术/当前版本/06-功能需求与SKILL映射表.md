### 一、数据服务AGENT (Data Service Agent)

### 二、收益管理AGENT (Revenue Management Agent)

#### SKILL-003: 智能调价SKILL

**功能定义**: 基于多因子智能计算建议价格

**调价因子权重**:
| 因子 | 权重 | 数据来源 |
|------|------|---------|
| 竞品价格 | 30% | 携程/美团/飞猪API |
| 满房率 | 25% | PMS系统 |
| 历史同期 | 20% | 数据库 |
| 节假日 | 15% | 节假日数据库 |
| 天气/事件 | 10% | 天气API/事件API |

**调价公式**:
```
建议价 = 基础价 × (1 + 竞品系数×0.3 + 满房系数×0.25 + 历史系数×0.2 + 节假日系数×0.15 + 事件系数×0.1)

其中:
- 竞品系数 = (我方价格 - 竞品均价) / 竞品均值
- 满房系数 = (当前满房率 - 目标满房率) / 100
- 历史系数 = (去年同期RevPAR - 当前RevPAR) / 当前RevPAR
```

**执行策略**:
| 调价幅度 | 执行方式 | 审核要求 |
|---------|---------|---------|
| <10% | 自动执行 | 无需审核 |
| 10-20% | 推送建议 | 一键确认 |
| >20% | 推送审批 | 必须审核 |

#### SKILL-004: 远期铺价SKILL

**功能定义**: 自动生成未来90-180天价格表

**铺价逻辑**:
```
1. 节假日识别
   - 法定节假日: 提前60天启动阶梯定价
   - 当地活动: 提前30天调整
   
2. 阶梯定价策略
   - 早鸟期 (T-60至T-30): 基准价 × 0.85
   - 正常期 (T-30至T-7): 基准价 × 1.0
   - 临门期 (T-7至入住): 基准价 × 1.2
   
3. 异常检测
   - 价格断档检测
   - 价格倒挂检测 (OTA < 官网)
   - 异常低价检测 (< 成本价)
```

**输出**: 每日生成未来180天价格日历
