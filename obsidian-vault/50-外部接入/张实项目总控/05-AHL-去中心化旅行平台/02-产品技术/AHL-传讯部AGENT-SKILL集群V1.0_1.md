> **创建日期**: 2026-03-09
> **版本**: V1.0
> **包含**: 8个SKILL群 / 35个细分SKILL

1. 前期: 策划方案(30天) → 预算审批(7天) → 场地搭建(3天)
2. 执行: 彩排(1天) → 活动当天 → 媒体采访

1. 前期: 客户筛选 → 邀请函设计 → RSVP确认
2. 执行: 签到接待 → 活动流程 → 礼品发放
3. 后期: 感谢信 → 满意度调查 → 跟进转化

**节庆活动** (春节/中秋/圣诞):
1. 提前45天: 方案策划
2. 提前30天: 物料制作
3. 提前15天: 宣传推广
4. 活动期: 执行落地
5. 结束后: 复盘总结

## 三、传讯部SOP标准

### 3.1 视觉内容生产SOP

#### SOP-COM-001: AI图像生成工作流

**适用场景**: 海报、社交媒体配图、概念图

**流程**:
1. **需求明确** (10分钟)
   - 确定图像用途（海报/社交/官网）
   - 明确尺寸要求
   - 确定风格调性
   - 准备参考图

2. **提示词编写** (10分钟)
   - 主体描述
   - 场景环境
   - 风格光线
   - 质量要求
   
   示例:
   ```
   "现代化酒店大堂，挑高设计，大理石地面，水晶吊灯，
    绿植装饰，温馨氛围，自然光从落地窗射入，
    高清摄影风格，4K画质"
   ```

3. **AI生成** (1-5分钟)
   - 使用image-gen工具生成
   - 生成3-5个版本

4. **人工筛选** (5分钟)
   - 选择最佳版本
   - 标记需修改处

5. **后期调整** (15-30分钟)
   - 添加Logo、文案
   - 色彩微调
   - 裁剪适配各平台

6. **品牌审核** (1-24小时)
   - 传讯经理审核
   - 法务审核（如有敏感内容）

7. **发布使用** (即时)
   - 上传素材库
   - 分发使用

**质量检查点**:
- [ ] 品牌VI符合度
- [ ] Logo使用规范
- [ ] 色彩搭配协调
- [ ] 画面清晰度
- [ ] 版权合规性

---

#### SOP-COM-002: 短视频制作工作流

**适用场景**: 抖音、视频号、小红书视频

**流程**:
1. **选题策划** (30分钟)
   - 热点追踪
   - 竞品分析
   - 选题确定
   - 脚本撰写

2. **拍摄准备** (1-2小时)
   - 场景布置
   - 设备调试
   - 人员协调
   - 拍摄清单

3. **现场拍摄** (1-4小时)
   - 按脚本拍摄
   - 多角度取景
   - 备用素材

4. **后期剪辑** (2-4小时)
