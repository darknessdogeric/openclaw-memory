## 三、行政后勤SOP标准

### 3.1 采购管理SOP

#### SOP-ADM-001: 采购申请流程

**适用范围**: 全酒店物资采购

**流程步骤**:
1. **需求提出** (0-4小时)
   - 部门填写《采购申请单》
   - 明确品名、规格、数量、用途、期望到货时间
   - 部门负责人初审

2. **AI审批** (即时)
   - AGENT自动审批规则:
     - 单件<¥500: 自动批准
     - ¥500-5000: 需部门总监批准
     - ¥5000-20000: 需财务总监批准
     - >¥20000: 需总经理批准
   - 超阈值自动转人工审批

3. **供应商比价** (1-24小时)
   - AI自动查询3家以上供应商报价
   - 比价维度: 价格、质量、交期、历史评价
   - 生成《比价报告》

4. **采购执行** (即时)
   - AI生成采购订单
   - 发送给选定供应商
   - 订单编号自动录入系统

5. **到货验收** (到货时)
   - 仓库/使用部门验收
   - 拍照上传系统
   - AI核对数量、规格

6. **入库登记** (验收后2小时内)
   - 系统入库登记
   - 更新库存台账
   - 触发财务应付

**关键控制点**:
- 采购必须有申请单
- 超预算采购需特批
- 验收不合格及时退货
- 发票与订单匹配

**SLA标准**:
- 常规采购: 3个工作日内到货
- 紧急采购: 24小时内到货
- 审批时效: <2小时

#### SOP-ADM-002: 供应商管理

**供应商分级**:
| 级别 | 标准 | 合作策略 |
|------|------|----------|
| A级 | 年采购额>¥10万，评分>90 | 战略合作，优先付款 |
| B级 | 年采购额¥5-10万，评分80-90 | 长期合作，定期评估 |
| C级 | 年采购额<¥5万，评分<80 | 临时合作，备选供应商 |

**评估维度**:
- 价格竞争力 (30%)
- 产品质量 (30%)
- 交付及时性 (20%)
- 售后服务 (20%)

**评估周期**: 季度评估，年度定级

#### SOP-ADM-003: 资产采购入库

**流程**:
1. 采购申请（关联资产预算）

```

示例: XMHT-IT-2026-001
类别代码: IT(电子设备), FD(家具), EQ(设备), VE(车辆)
```
