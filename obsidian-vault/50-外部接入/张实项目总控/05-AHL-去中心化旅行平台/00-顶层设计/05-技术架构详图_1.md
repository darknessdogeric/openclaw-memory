## 二、分层架构说明

### 2.1 用户接入层

| 组件 | 技术选型 | 用途 | 说明 |
|------|---------|------|------|
| Web管理后台 | Vue3 + Element Plus | 管理员操作界面 | 策略审核、数据查看、系统配置 |
| 移动端小程序 | 微信小程序/Taro | 管理人员移动办公 | 接收告警、查看简报、紧急审批 |
| 钉钉/企业微信 | 机器人API | 消息推送 | 异常告警、日报推送、审批通知 |
| 邮件/短信 | SMTP/阿里云短信 | 重要通知 | 关键操作确认、系统故障通知 |
| API Gateway | Kong / APISIX | 统一入口 | 限流、鉴权、路由、日志 |

### 2.2 应用服务层

#### 2.2.1 AI集团指挥中心

| 模块 | 技术选型 | 功能描述 |
|------|---------|---------|
| **数据中台** | Apache Flink + Kafka | 实时数据汇聚、清洗、计算 |
| **策略引擎** | DeepSeek LLM + LangChain | AI策略生成、优化、推理 |
| **监控中心** | Prometheus + Grafana | 系统监控、业务监控、告警 |
| **权限中心** | OAuth2 + JWT | 用户认证、权限控制、审计 |

## 六、安全架构

### 6.1 数据安全

| 层级 | 措施 | 实现方式 |
|------|------|---------|
| 传输加密 | TLS 1.3 | 全站HTTPS |
| 存储加密 | AES-256 | 数据库TDE加密 |
| 密钥管理 | HSM | 阿里云KMS/AWS KMS |
| 数据脱敏 | 正则替换 | 手机号/身份证脱敏 |
| 备份加密 | 客户端加密 | 备份文件加密存储 |

### 6.2 访问控制 (RBAC)

| 角色 | 权限范围 |
|------|---------|
| 超级管理员 | 所有权限 |
| 集团管理员 | 查看所有酒店、配置全局策略、审核大额调价(>20%) |
| 区域经理 | 查看分管区域、审核中等调价(10-20%)、导出报表 |
| 单店店长 | 查看本店、执行小额调价(<10%)、接收告警 |

### 6.3 审计日志

| 操作类型 | 记录内容 | 保留期限 |
|---------|---------|---------|
| 价格调整 | 调整前后、操作人、时间、原因 | 3年 |
| 登录认证 | IP地址、设备、时间、结果 | 1年 |
| 策略变更 | 变更内容、审批人、执行时间 | 3年 |
| 数据导出 | 导出内容、操作人、审批记录 | 5年 |

## 七、技术选型总结

| 类别 | 技术栈 | 选型理由 |
|------|--------|---------|
| **后端框架** | Go / Python FastAPI | 高性能、易于AI集成 |
