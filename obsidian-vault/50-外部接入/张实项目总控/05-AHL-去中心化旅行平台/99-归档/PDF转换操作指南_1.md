# Markdown转PDF操作指南

## 方法一：使用浏览器打印（最简单）

### 步骤：
1. **安装浏览器插件**
   - 安装Chrome浏览器
   - 安装 "Markdown Viewer" 插件 或 "Markdown Reader" 插件

2. **打开MD文件**
   - 用Chrome浏览器直接打开 `.md` 文件
   - 或安装插件后拖拽MD文件到浏览器

3. **打印为PDF**
   - 按 `Ctrl + P` 打开打印对话框
   - 选择 "另存为PDF"
   - 设置：
     * 纸张：A4
     * 边距：默认
     * 背景图形：勾选
   - 点击 "保存"

### 优势：
- ✅ 完全免费
- ✅ 保留Markdown格式
- ✅ 支持中文
- ✅ 可调整页面设置

## 方法二：使用在线工具

### 推荐工具：
1. **Md2Pdf.net**
   - 网址：md2pdf.netlify.app
   - 拖拽上传MD文件
   - 自动转换为PDF
   - 支持中文

2. **Pandoc Online**
   - 使用pandoc转换
   - 支持自定义样式

3. **CloudConvert**
   - 支持多种格式转换
   - 免费额度足够使用

## 方法三：使用Typora（最美观）

### 步骤：
1. **下载Typora**
   - 官网：typora.io
   - 下载免费版

2. **打开MD文件**
   - 用Typora打开 `.md` 文件
   - 会自动渲染为美观的格式

3. **导出PDF**
   - 菜单：文件 → 导出 → PDF
   - 设置页面样式
   - 导出即可

### 优势：
- ✅ 转换效果最佳
- ✅ 支持自定义CSS主题
- ✅ 自动处理表格和代码块
- ✅ 专业的PDF输出

---

## 方法四：使用VS Code + 插件

### 步骤：
1. **安装VS Code**
2. **安装插件**
   - Markdown PDF 插件
   - 或 Markdown Preview Enhanced

3. **导出PDF**
   - 打开MD文件
   - 右键 → Markdown PDF: Export (pdf)
   - 自动生成PDF
