## 四、收益管理知识

### 4.1 RevPAR计算

```
RevPAR = ADR × OCC
    或
RevPAR = 总客房收入 ÷ 可售房总数

示例：
- ADR = ¥320
- OCC = 80%
- RevPAR = ¥320 × 80% = ¥256
```

### 4.2 ADR计算

```
ADR = 总客房收入 ÷ 已售客房数

注意：计算ADR时分母是已售房间数，不是总房间数
```
