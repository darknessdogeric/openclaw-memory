## 三、企业微信对接方案

### 3.1 对接架构

```
AHL服务器 → 企业微信API → 春熙宾馆企微账号
    ↓
AGENT作为"虚拟员工"加入企微群
    ↓
接收指令/发送报告
```

### 3.2 配置步骤

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 创建企业微信自建应用 | 春熙企微管理员操作 |
| 2 | 获取AgentID | 用于接收消息 |
| 3 | 配置消息推送 | 获取Token |
| 4 | 配置回调地址 | 接收企微消息 |
| 5 | 测试消息收发 | 验证通道 |

### 3.3 功能映射

| 企微功能 | AHL对应 | 说明 |
|---------|--------|------|
| 私聊 | AGENT对话 | 可直接提问 |
| 群聊@ | 指令接收 | @AGENT发指令 |
| 推送消息 | 报告发送 | 日报/预警/通知 |
| 小程序 | 数据看板 | 查看运营数据 |

## 四、数据流设计

### 4.1 数据采集

| 数据源 | 采集方式 | 频率 | 存储 |
|--------|---------|------|------|
| 罗盘PMS | API对接 | 实时 | 本地DB |

## 六、运维监控

### 6.1 监控指标

| 指标 | 采集方式 | 告警 |
|------|---------|------|
| 服务存活 | systemd监控 | 服务挂了就告警 |
| CPU使用率 | prometheus | >80%持续5分钟 |
| 内存使用率 | prometheus | >85% |
| 磁盘使用率 | prometheus | >80% |
| API响应时间 | 日志分析 | >3秒 |
| 任务执行成功率 | 任务日志 | <95% |

### 6.2 告警方式

| 级别 | 方式 | 触发条件 |
|------|------|---------|
| P0-紧急 | 企业微信私聊+电话 | 服务完全不可用 |
| P1-严重 | 企业微信群 | 核心功能异常 |
| P2-一般 | 企业微信群 | 非核心功能异常 |
| P3-通知 | 日报汇总 | 日常运行状态 |

### 6.3 日志管理

| 日志类型 | 保留时间 | 用途 |
|---------|---------|------|
| 操作日志 | 永久 | 审计追踪 |
| 错误日志 | 6个月 | 问题排查 |
| 访问日志 | 3个月 | 安全审计 |
| 业务日志 | 1年 | 分析报告 |

## 七、安全配置

### 7.1 网络安全

- 防火墙仅开放必要端口
- 企业微信回调使用HTTPS
- API密钥定期轮换

### 7.2 数据安全

- 数据库加密存储
- 敏感信息（账号密码）加密
- 定期备份（异地）

### 7.3 访问控制

| 角色 | 权限 |
|------|------|
| 管理员 | 全部权限 |
| 运营人员 | 查看报告+手动操作 |
| 客人（企微） | 仅接收通知 |
