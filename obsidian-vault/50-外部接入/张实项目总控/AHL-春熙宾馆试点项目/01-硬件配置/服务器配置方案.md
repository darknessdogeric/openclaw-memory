## 三、关键配置说明

### 3.1 为什么不用太高配置？

AHL AGENT主要依赖：
1. **云端LLM调用**（DeepSeek/Qwen API）- 不占用本地算力
2. **本地数据处理**（Python/Pandas）- CPU要求不高
3. **企业微信对接** - 网络要求为主
4. **定时任务**（cron）- 轻量运行

### 3.2 必须的配置要求

| 要求 | 最低 | 推荐 |
|------|------|------|
| CPU | 4核 | 6核+ |
| 内存 | 16GB | 32GB |
| 存储 | 256GB | 512GB+ |
| 网络 | 100Mbps | 千兆 |
| 操作系统 | Windows 10/11 Pro 或 Ubuntu 22.04 LTS | |

### 3.3 网络要求

| 项目 | 要求 |
|------|------|
| 带宽 | 上行 ≥ 10Mbps（用于API调用） |
| IP | 固定IP或动态域名（DDNS） |
| 端口 | 开放必要端口用于微信回调 |
| 安全 | 防火墙，仅开放必要端口 |
