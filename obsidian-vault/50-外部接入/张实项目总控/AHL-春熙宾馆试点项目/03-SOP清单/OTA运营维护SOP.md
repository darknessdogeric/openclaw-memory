## 二、日常运营SOP

### 2.2 价格监控（每2小时一次）

| 时间 | 任务 | 执行者 |
|------|------|--------|
| 9:00 | 第一次价格检查 | AHL |
| 11:00 | 第二次价格检查 | AHL |
| 13:00 | 午间价格调整 | AHL |
| 15:00 | 第三次价格检查 | AHL |
| 17:00 | 晚间价格调整 | AHL |
| 19:00 | 第四次价格检查 | AHL |
| 21:00 | 夜间价格检查 | AHL |

**价格调整规则**：

| 场景 | 调整幅度 | 说明 |
|------|---------|------|
| 需求 > 85% | +10%~+20% | 溢价策略 |
| 需求 60-85% | 维持或微调 | 稳定策略 |
| 需求 < 60% | -5%~-15% | 促销策略 |
| 竞品降价 > 10% | 跟进调整 | 竞争响应 |
| 展会/重大事件 | +20%~+40% | 事件溢价 |

### 2.3 评价管理（实时）

| 评价类型 | 响应时效 | 处理方式 |
|---------|---------|---------|
| 好评 | 24小时内回复 | 感谢+引导复购 |
| 中评 | 4小时内回复 | 解释+改善承诺 |
| 差评 | 1小时内回复 | 道歉+补偿方案+私下联系 |

**自动回复模板**：

**好评回复**：
```
尊敬的客人，感谢您选择春熙宾馆！[客人姓名]很高兴为您提供愉快的入住体验。
您的肯定是我们的最大动力，期待再次为您服务！
—— 春熙宾馆团队
```

**差评回复**：
```
尊敬的客人，非常抱歉给您带来不愉快的体验。
[具体问题]已记录，我们将立即改进。
如您方便，请联系[电话]，我们希望亲自为您处理。
—— 春熙宾馆店长
```

### 2.4 库存管理（实时同步）
