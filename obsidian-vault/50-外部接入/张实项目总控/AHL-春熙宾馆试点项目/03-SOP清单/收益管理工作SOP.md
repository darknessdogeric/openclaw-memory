- 评价分数/数量
- 房型结构
- 促销活动的

### 2.3 数据校验（均价校正）

| 校正方式 | 说明 | 频率 |
|---------|------|------|
| OTA实际订单均价 | 从PMS订单计算 | 每周 |
| ADR估算校验 | 用携程展示价估算 | 每日 |
| 线下对账 | 与竞品实地对标 | 每月一次 |

**校正公式**：
```
真实ADR = Σ(各平台实际成交价 × 订单数) / 总订单数

ADR估算 = 携程展示价 × 0.9（校正系数）
*校正系数根据历史数据回归计算
```

## 三、需求预测

### 3.1 预测维度

| 预测维度 | 时间粒度 | 方法 |
|---------|---------|------|
| 整体需求 | 未来30天 | 时间序列+回归 |
| 特殊事件影响 | 未来90天 | 事件标签+回归 |
| 节假日需求 | 未来365天 | 历史同比+事件 |
| 竞品影响 | 实时 | 竞品价格差异 |

### 3.2 预测模型输入

```python
demand_features = {

    "hist_occupancy": [0.8, 0.85, 0.75],  # 近3周入住率
    "hist_adr": [320, 335, 310],  # 近3周ADR
    
    # 时间特征
    "day_of_week": 5,  # 周几
    "is_weekend": True,  # 是否周末
    "month": 5,  # 月份
    "quarter": 2,  # 季度
    
    # 事件特征
    "local_events": ["糖酒会", "五一假期"],
    "holiday": "五一",
    "weather": "晴",
    
    # 竞品特征
    "comp_prices": [280, 320, 260],  # 竞品价格
    "comp_occupancy": [0.85, 0.9, 0.8],
    
    # 渠道特征
    "booking_pace": 0.65,  # 预订进度
    "channel_mix": {"ctrip": 0.5, "meituan": 0.3, "direct": 0.2}
}
```

## 四、定价策略

### 4.1 定价模型

```
最优价格 = f(基准价格, 需求弹性, 竞品价格, 库存水位, 特殊事件)

其中：
- 基准价格 = 历史同期价格 × 季节系数
- 需求弹性 = 基于入住率的动态调整
- 竞品价格 = 竞品最低价 × 竞争力系数
- 库存水位 = 剩余房间 / 总房间
- 特殊事件 = 事件溢价系数
```

### 4.2 定价策略矩阵

| 入住率区间 | 市场状态 | 定价策略 | 价格调整幅度 |
|-----------|---------|---------|------------|
| <50% | 淡季/疲软 | 促销为主 | -10%~-20% |
| 50-70% | 平稳 | 优化结构 | -5%~+5% |
| 70-85% | 旺季 | 溢价开始 | +5%~+15% |
| 85-95% | 饱和 | 全面溢价 | +15%~+25% |
| >95% | 爆满 | 最高溢价 | +25%~+40% |

### 4.3 特殊事件定价

| 事件类型 | 影响程度 | 提前量 | 溢价幅度 | 示例 |
|---------|---------|-------|---------|------|
| 全国性节假日 | ★★★★★ | 14-30天 | +30%~+50% | 春节、国庆 |
| 区域性展会 | ★★★★☆ | 7-14天 | +20%~+40% | 糖酒会、车展 |
| 商务活动 | ★★★☆☆ | 3-7天 | +10%~+20% | 大型会议 |
| 周末+好天气 | ★★☆☆☆ | 2-3天 | +5%~+15% | 周末溢价 |
| 恶劣天气 | ★☆☆☆☆ | 1-2天 | -10%~-20% | 台风、暴雨 |

### 4.4 定价决策流程

```
每日定价决策（14:00执行）：
│
├─ Step 1: 获取数据
│   ├─ 今日/明日/未来7天预订进度
│   ├─ 竞品价格（携程/美团/去哪儿）
│   ├─ 未来7天事件/天气
│   └─ 历史同期数据
│
├─ Step 2: 计算最优价格
│   ├─ 需求预测
│   ├─ 竞品价格对比
│   ├─ 库存水位分析
│   └─ 输出各房型建议价格
│
├─ Step 3: 价格确认
│   └─ AHL生成价格方案
│
├─ Step 4: 执行
│   ├─ 更新携程EBK
│   ├─ 更新美团酒店
│   └─ 更新飞猪
│
└─ Step 5: 监控与调整
    └─ 19:00检查执行效果，必要时调整
```

## 五、渠道管理

### 5.1 渠道价值评估

| 渠道 | 订单占比 | 佣金率 | 获客成本 | 优先级 |
|------|---------|-------|---------|-------|
| 携程 | ~50% | 13-15% | 高 | ★★★★★ |
| 美团 | ~25% | 10-12% | 中 | ★★★★☆ |
| 飞猪 | ~10% | 8-10% | 中 | ★★★☆☆ |
| 官网/微信 | ~10% | 0% | 低 | ★★★★★ |
| 协议客户 | ~5% | 0% | 极低 | ★★★★☆ |

### 5.2 渠道优化策略

| 策略 | 目标 | 执行方式 |
|------|------|---------|
| 降低OTA依赖 | 提升直销比例至20%+ | 官网促销、会员权益 |
| 优化佣金结构 | 降低平均佣金至10% | 调整渠道投放 |
| 提升直客价值 | LTV>获客成本 | 会员体系、复购激励 |

### 5.3 渠道库存分配

```
总房量 = 100间

分配逻辑：
├─ 协议客户预留：10%（10间）
├─ 会员/直销预留：10%（10间）
├─ OTA平台：70%（70间）
│   ├─ 携程：35间（50%）
│   ├─ 美团：20间（29%）
```
