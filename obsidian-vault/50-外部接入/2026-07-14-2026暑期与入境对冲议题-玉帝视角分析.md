## 一、五维认知(描述这个议题)

### 1.1 历史沿革

```
时间轴:中国酒店业 10 年趋势

2014-2018: 高速增长期(经济型连锁+OTA 起飞)
  ├─ 酒店间夜量 CAGR 12%+
  ├─ 头部连锁快速扩张(锦江/华住/如家加速)
  └─ ADR 持续上涨

2019-2020: 疫情扰动(2019 ADR 拐点,2020 触底)
  ├─ 2020 RevPAR 暴跌 30%+
  ├─ 大量单体酒店出清
  └─ 政策开始救市

2021-2023: 报复性反弹 + 供给端小跑恢复
  ├─ 2023 单年国内旅游人次 + 70%+(vs 2022)
  ├─ ADR 反弹但服务体验滞后
  └─ 加盟连锁重新扩张

2024: **结构性转折点** ← 关键一年
  ├─ 锦江/亚朵/华住 ADR/RevPAR **首次** 全面下滑
  ├─ 锦江 境内全服务型酒店 RevPAR -10.8%
  ├─ 亚朵 RevPAR -6.77% (ADR 同样下行)
  ├─ 头部连锁 4-6 家归母净利下滑
  ├─ 行业开始提"微利经营"
  └─ 格林酒店入住率连续 3 年下滑(2022→2025 从 76%→69.4%)

2025: 行业全面进入"存量内卷"
  ├─ 头部连锁 入住率虽高(华住 80%+)但 ADR 难提
  ├─ 单房收益几乎不再增长
  ├─ 大量单体酒店 "有客流不盈利"
  └─ **趋势已经形成:不是周期低点,是结构拐点**

2026 上半年至暑期: 问题显性化
  ├─ 5/19 中国旅游日政策密集发布
  ├─ 端午 +6.3%/人均(微涨) / +8.1% 收入(更高,客单提升)
  ├─ 暑期"热度高"(飞猪 +40%, 暑期热度)但**均价低**
  └─ 出现"今天生意差 = 未来五年最好的一年"的说法
```

### 1.2 当下情况(8 个结构性事实)

```
事实 1: 国内酒店 ADR 下行已成定局
  ├─ 锦江 2024 ADR -7.41% (全服务型酒店)
  ├─ 亚朵 2024 ADR -6.77%
  └─ 这不是某家的问题,是行业问题

事实 2: 头部连锁靠规模而非靠提价保住增长
  ├─ 锦江已开业 13,416 家 / 华住 11,147 家 / 首旅 7,002 家
  ├─ 亚朵 1,619 家 / 君亭 452 家
  └─ 但增速在放缓,增量空间有限

事实 3: 体验型/小众型产品旺(高声量)
  ├─ 飞猪暑期热度 +40%
  ├─ 暑期亲子预订 +31%(飞猪)/ +45%(同程)
  ├─ 研学/非遗/小众体验快速增长
  └─ 但**"热度 ≠ 收入"**(热度高但客单低)

事实 4: 出境游恢复(分走国内蛋糕)
  ├─ 2026 暑期出境游订单涨
  ├─ 出境/国内比例约 4:6(2024 数据已变化)
  └─ 国内市场被分流,但收入分得少

事实 5: 入境游实质性起飞
  ├─ 2026 Q1 入境外国人 2133.3 万人次, **+22.3%**
  ├─ 2026 上半年免签入境 1781.5 万人次,**+30.6%**(免签已是主力)
  ├─ 2025 全年入境花费 1311 亿美元,**+39.2%**(消费升级)
  ├─ 2026 预计全年入境 1.7 亿,接近 1.9 亿规划目标
  └─ 入境增长是**真实的**两位数,且消费增速 > 人次增速

事实 6: 中端连锁生存优于两端
  ├─ 经济型连锁(格林/汉庭)靠加盟下沉保住规模,但 ADR 难提
  ├─ 高端连锁(君亭/亚朵/锦江高端)靠升级产品拉提价
  └─ 度假酒店靠资源稀缺性避开内卷

事实 7: 2026 是"政策密集发布期"
  ├─ 旅游强国"十五五"规划(7 月)
  ├─ "扩大消费十五五"规划(7 月 13 日)
  ├─ 入境免签政策持续扩大
  └─ 政策给的是**信心**,不是直接补贴

事实 8: 餐饮+多业态受影响
  ├─ 反"内卷式"竞争(political 风向)
  ├─ 美团/携程等 OTA 转向本地生活
  └─ "客流 +1, 客单 -1, 利润 -2" 是结构现状
```

### 1.3 原因分析(5 条因果链)

```
原因 1: 国内市场结构变化(供给侧过剩 + 需求侧变化)
  ├─ 酒店供给端持续扩张(连锁下沉 + 新店开业)
  ├─ 需求端:消费分级 + 体验分化(高净值要体验,中等收入要性价比)
  ├─ 中间价格带被两端挤压
  └─ 结果:ADR 承压,入住率维稳

原因 2: 出境游回归(分走国内中高端)
  ├─ 2023-2024 期间出境游恢复
  ├─ 高净值家庭 出境比例提升
  └─ 国内高星酒店 ADR 上行乏力

原因 3: 入境游政策的"持续释放期"
  ├─ 2023-2024 免签扩大
  ├─ 2025-2026 支付+签证+退税便利化密集落地
  ├─ 入境游进入"政策红利兑现期"
  └─ 入境游是 5 年来中国旅游业**唯一**两位数增长的细分赛道

原因 4: 政策导向明确(消费立国+服务立国+文化输出)
  ├─ 中央把旅游业作为"对美博弈+对外传播+对内消费"的三重战略载体
  ├─ 入境游是其中**唯一可以快速见效**的部分
  ├─ 国内游需要更长时间结构调整
  └─ 中央在 2026-2027 集中发力的就是入境游

原因 5: AI 周期叠加:国内游效率被算法榨干,增量空间转移到入境游
  ├─ 国内 OTA 算法优化已经极致
  ├─ AI Agent 替代了人工搜索比价
  ├─ 国内游增量 = "流量再分配",不是"流量创造"
  ├─ 入境游 = "全新流量池",且初始算法优化不深
  └─ AI Agent 时代的新战场是入境游
```

## 二、核心议题判断(这个问题对么?)

### 议题 1: "今年暑期'冷'是趋势性信号,还是暂时波动?"

**判断**:是趋势性信号,不是暂时波动

**证据**:
```
A. 时间跨度足够长(2-3 年的下行):
  - 2024 锦江/亚朵/华住 ADR-7%/-10%
  - 2025 格林 入住率连续 3 年下滑
  - 2026 全行业"微利经营"
  - 不是某个时点的问题,是持续 2-3 年的趋势

B. 原因足够结构性:
  - 不是疫情/突发/经济周期
  - 是供给侧过剩 + 需求侧分级 + 出境分流的结构变化
  - 这种结构变化短期内无法逆转

C. 政策方向已经承认:
  - 政策反复强调"提质增效" "避免内卷"
  - 反"内卷式"竞争 政策
  - 这等于承认"量上不去,要靠质"
```

**但"未来五年最好的一年"≠ 持续恶化**

```
修正判断:
  - "今年暑期是最冷的一年" 部分正确 ✓
  - "未来五年更好" 也部分正确 ✓
  - 但准确表述是:"今年是**国内卷化最高峰**,但**入境游增速在加速**"

也就是说:
  "国内卷化顶点"使今年最冷
  + "入境游起飞期"使未来五年还有结构性机会
  = "冷年是相对的,不是绝对的"
```

### 议题 2: "大提入境是不是对冲国内下行?"

**判断**: **是,但不全是** — 是对冲 + 又是长期战略

**证据**:
```
A. 表面对冲逻辑:
  ├─ 国内出游人次增速放缓
  ├─ 国内 ADR 持续下行
  ├─ 入境游人次增速 7.6%
  ├─ 入境游消费增速 10.8%(超过人次增速)
  ├─ 所以"入境是救命稻草"成立
  └─ 这符合"对冲"叙事

B. 但对冲不是政策的全部:
  ├─ 入境游是**长期战略**(2026-2030 5 年规划)
  ├─ 入境游是**国家战略载体**(对美博弈+对外传播)
  ├─ 入境游是**东西部区域均衡**的均衡手段(西部吸引力)
  └─ 政策不只是短期对冲

C. 真正动因:
  ├─ 主因:中国经济模式转向"消费+服务+出海"
  ├─ 次因:国内游存量内卷需新增长极
  ├─ 第三因:对美博弈需软实力输出
  └─ 入境游是"主要战略 + 顺便对冲国内"
```

**最终判断**: "大提入境在时间上和国内下行巧合,但本质是中长期战略,不是短期对冲"

## 六、贝叶斯推理(用证据更新先验)

### 议题 A: "暑期冷"持续多久?

```
先验 P(冷是趋势性)= 50%
证据 E1: 2024 行业 RevPAR -10%/-15%
  P(E1|趋势) = 95%, P(E1|偶然) = 30%, 似然比 = 3.2
证据 E2: 2025 入住率持续下滑(行业普遍现象)
  P(E2|趋势) = 90%, P(E2|偶然) = 30%, 似然比 = 3
```
