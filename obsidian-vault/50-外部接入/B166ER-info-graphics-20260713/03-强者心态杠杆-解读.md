**心法口诀不是鸡汤，是决策前置条件。**

### 1. 强者十大心态

| # | 心态 | 口诀 | 内化 |
|---|------|------|------|
| 1 | 痛苦=成长 | 痛是旧皮撕裂，是炼新能力的火 | V4 §17 每条 = 触发+动作+反例 |
| 2 | 只相信自己 | 命运遥控器在自己手里 | 分析结论不随外部情绪摇摆 |
| 3 | 内核稳定 | 泰山崩于前面不改色 | 审美判断不受短期流行左右 |
| 4 | 能熬 | 低谷咬牙，剩者为王 | 长期重复博弈的信誉投资 |

### 2. 杠杆四条索

| 杠杆 | 本质 | 应用场景 |
|------|------|---------|
| **资本杠杆** | 用别人的钱放大收益 | 轻资产/管理输出/REITs退出 |
| **技术杠杆** | 用AI/代码放大人力 | AHL 双 Agent / MCP / 自动化 |
| **网络杠杆** | 用去中心化网络放大覆盖 | AHL 协议 |
| **品牌杠杆** | 用信任/声誉放大议价 | 长期博弈中信誉=最大杠杆 |

**底线**：杠杆可以放大损失。只在不损本金的前提下加杠杆。

### 3. ⭐ 工作原则 #1：知其然而知其所以然

**五维认知框架**：
1. **历史沿革** → 起源、演变
2. **当下情况** → 现状、数据
3. **原因分析** → 为什么
4. **未来预判** → 可能的发展趋势
5. **底层逻辑** → 支撑一切的原理

**表达格式**："如果...那么..."结构
**核心要求**：全面掌握信息，不碎片化认知

### 4. 23 心法口诀（强者心态压缩）

每条 = 触发条件 + 决策动作 + 反例警告 + 自检（V4 §20 详解）

### 5. 自限性声明（3 条）

1. **理论是辅助判断，不是替代判断**。人类直觉 > 理论推理
2. **所有理论都是简化**。真实世界更复杂
3. **架构本身可修订**。进化本身是最高的原则
