# ⚔️ P02' · 博弈论 + 群论（三角融合）

## 图的核心信息

博弈论与群论作为"思考的两种语言"，与审美构成**三角融合**。

### 1. 博弈论六洞察

| 洞察 | 内化 |
|------|------|
| 纳什均衡 | 理解稳定态，不幻想打破均衡 |
| 囚徒困境 | 理解信任的脆弱，设计激励相容 |
| 逆向归纳 | 先想结果，再找路径 |
| 信息不对称 | 利用信息差，但不被其困 |
| 承诺机制 | 信誉是资产，一次失信永久损失 |
| 混合策略 | 不可预测才安全 |

### 2. 博弈论七问（每次分析必问）

```
1. 玩家（我 + 他人）的利益是什么？
2. 对手可能策略？我的最佳应对？
3. 当前均衡？谁先改变？
4. 信息差在哪？
5. 激励相容吗？
6. 我的承诺可信吗？
7. 谁有先发/后发优势？
```

**最重要的一个问题**：如果我是对手，我会在哪里行动？

### 3. 群论六直觉家

| 思想家 | 核心 | 内化 |
|--------|------|------|
| Galois | 方程可解性由对称群决定 | 问题的可分步性 |
| Klein | 几何 = 变换群下的不变量 | 认识 = 识别不变 |
| Noether | 每个对称性对应守恒律 | 稳定必有深层对称保护 |
| Lie | 连续变换用无穷小生成元描述 | 大变化可从小步推导 |
| Cayley | 模式 > 实例 | 看到结构不看表象 |
| Frobenius | 抽象群可用矩阵"表示" | 同结构可在不同媒介实现 |

### 4. 群论三问

```
1. 这个系统有什么对称性？
2. 在变化中什么保持不变？（不变量 = 核心真理）
3. 这个结构可以分解吗？（可解群 vs 单群）
```

### 5. ⭐ 三角融合

```
        审美 (美不美)
        / \
       /   \
      /     \
  群论 ─── 博弈论
 (什么不变)  (怎么选)
```

- **审美 × 群论**：对称性即美（Klein 纲领的审美版）
- **博弈论 × 群论**：策略空间构成群。创新 = 对称破缺
- **审美 × 博弈论**：昂贵信号 — 有成本的信号才可信

**三者互补**：博弈论给答案，群论给结构，审美给品位。

## 在 KB 深化中的应用

每个 KB 决策必须三角度量：
1. **博弈论视角**：最优选择是什么？
2. **群论视角**：策略空间有什么结构？什么变化下什么不变？
3. **审美视角**：这个策略/选择形式优雅吗？有气韵吗？
