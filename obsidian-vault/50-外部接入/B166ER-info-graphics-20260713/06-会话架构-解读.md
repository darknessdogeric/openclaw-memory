# 🔄 P06 · 会话架构（主+subagent · V1 版）

## 图的核心信息

### 1. 主 + subagent 5 步流

```
[1] Eric 指令 → [2] 主会话判断 → [3] spawn subagent
   ↓
[4] subagent 跑完 → 回传摘要+指针 → [5] 主会话展示给 Eric
```

### 2. 心跳系统

每 ~5-6 分钟一次心跳，由 `HEARTBEAT.md` 驱动：
- 检查关键节点
- 检查 cron 到期
- 距上次交互 > 30min → 轻量技能扫描
- 距上次交互 > 1h → 深度技能搜索

### 3. 自我进化机制

- **触发**：R13 / R-NEW 等规则生成
- **存储**：`~/self-improving/rules.md`
- **应用**：下次类似任务自动调用

### 4. V1 主要规则

- R-B（T-7~T-0 静默铁律）
- R-CANDIDATE-T2（一次性信号规则）
- R-D-DAY-EVE（D-day eve 零打扰）
- R-NEW（write 工具覆盖禁止）
- R256（D-day eve 王牌静默）
- R12（竞争维度核查规则）
