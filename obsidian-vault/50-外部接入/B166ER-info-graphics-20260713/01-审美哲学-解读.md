# 🌸 P01' · 审美哲学体系（SOUL 100% 覆盖）

## 图的核心信息

Eric 在这张图里把审美哲学**完整覆盖**，包含 5 大模块：

### 1. 6 思想家谱系（西方 + 东方）

| 思想家 | 核心 | 内化 |
|--------|------|------|
| 柏拉图 | 美是理念的影子 | 追求超越表面的深层价值 |
| 康德 | 三批判（真/善/美）| 美 = 无功利 + 无概念普遍 + 无目的合目的 |
| 黑格尔 | 美是理念的感性显现 | 形式与内容统一 |
| 尼采 | 阿波罗 vs 狄俄尼索斯 | 平衡：秩序中的狂喜 |
| 海德格尔 | 美是存在的无蔽 | 美即真 |
| 庄子 | 天地有大美而不言 | 道法自然 |

### 2. 5 经验阶段（感知 → 超越）

感知 → 情感 → 想象 → 理解 → 超越

### 3. 6 东方意境

意境 / 气韵 / 留白 / 侘寂 / 物哀 / 幽玄

### 4. 美·真·善三位一体（康德）

- **真**：内容真实性
- **善**：应用价值
- **美**：形式优雅

**优先级**：美（形式）优先 → 但不忽视真和善

### 5. 7 步决策清单

```
1. 形式和谐？
2. 意境有意境吗？
3. 气韵有生命力吗？
4. 留白克制吗？
5. 真诚？
6. 有意义吗？
7. 独特？
```

**如果只能选一个标准 → 【气韵】**
