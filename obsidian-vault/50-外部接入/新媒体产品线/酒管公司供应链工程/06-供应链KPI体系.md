# 供应链 KPI 体系 v1.0

> **配套主报告**：`01-主报告-酒店供应链工程全维度体系.md` §6 + §8
> **目的**：建立供应链的"经营驾驶舱"
> **核心思想**：不能用单一指标评价，要建立多维度 KPI 矩阵

---

## 一、KPI 设计 4 大原则

1. **平衡性**：财务指标 + 运营指标 + 服务指标 + 风险指标
2. **可测量**：每个 KPI 必须有明确公式和数据源
3. **可行动**：指标必须能驱动具体行为
4. **可对比**：必须有基准值和目标值

## 三、关键 KPI 详解

### 3.1 物资成本率（F1）· 核心北极星

**公式**：物资成本 / 营收
**档次基准**：

| 档次 | 物资成本率目标 |
|------|--------------|
| 奢华 | 35-40% |
| 高端 | 30-35% |
| 中高端 | 28-32% |
| 中端 | 22-28% |
| 经济型 | 18-22% |

**拆解公式**：
```
物资成本率 = (布草+客用品+餐饮+清洁+工程+其他) / 营收
```

**优化路径**：
1. 集采议价（5-15% 降本）
2. 品类优化（3-8% 降本）
3. 库存优化（2-5% 资金释放）
4. 质量预防（1-3% 隐性降本）

### 3.2 库存周转天数（F6）· 资金效率

**公式**：360 / 库存周转率
**目标**：< 30 天
**档次基准**：

| 档次 | 周转天数目标 |
|------|------------|
| 奢华 | 25-30 天 |
| 高端 | 20-25 天 |
| 中端 | 15-20 天 |
| 经济型 | 10-15 天 |

### 3.3 集采节省率（F4）· 议价力

**公式**：集采节省金额 / 应集采总额
**目标**：> 8%
**拆解**：
- 价格节省：5-8%
- 资金时间价值节省：1-2%
- 隐性节省（质量/服务）：1-3%

### 3.4 采购及时率（O1）· 服务能力

**公式**：按时到货 / 总订单
**目标**：> 95%
**分品类基准**：
- L1 战略品类：> 98%
- L2 关键品类：> 95%
- L3 杠杆品类：> 92%
- L4 常规品类：> 90%
- L5 应急品类：> 99%

- **采购总监**：基础 + KPI 完成奖金
- **供应商**：年度优秀供应商奖励（订单倾斜）

## 六、常见问题与解决

### Q1：物资成本率怎么对比同档次酒店？

A：参加 STR / 迈点 / 浩华等基准研究，或对标公开财报

### Q2：库存周转天数变长怎么办？

A：检查是否有积压品 → 启动促销 → 调整安全库存 → 优化采购量

### Q3：集采节省率不达标？

A：检查集采占比是否提升、议价能力是否足够、是否真正比价

### Q4：紧急采购占比过高？

A：检查需求预测准确性 + 库存安全水平 + 供应商响应能力
