## 二、按档次分级（5 档）

### 2.1 奢华/精品酒店（5 星 + 顶级品牌）

**供应链特征**：
- 顶级品牌优先，国际品牌占主导
- 注重调性、文化、工艺
- 客户对价格不敏感
- 集采比例适中（70%），保留单店特色

**集采品类**：
- L1 战略：100% 集采
- L2 关键：80% 集采
- L3 杠杆：50% 集采
- L4 常规：30% 集采（单店自决）
- L5 应急：0% 集采（单店处理）

**典型品牌组合**（参见知识库 v1.3）：
- 布草：Frette / Pratesi / Sferra
- 客用品：Acca Kappa / Penhaligon's / Guerlain
- IT：Opera PMS / Infor HMS
- 家具：Poliform / Molteni&C / Giorgetti

**采购策略**：品质 > 品牌 > 价格
**预算指引**：物资成本率 35-40% 营收

---

### 2.2 高端酒店（5 星）

**供应链特征**：
- 国内 + 国际品牌平衡
- 注重标准化 + 客户体验
- 集采比例 80%

**集采品类**：
- L1-L2 战略 + 关键：100% 集采
- L3 杠杆：70% 集采
- L4 常规：40% 集采
- L5 应急：0% 集采

**典型品牌组合**：
- 布草：Downia / Pacific Coast
- 客用品：Aromatherapy Associates / Voya
- IT：瑢软科技 / 蓝海
- 家具：Ashley / Natuzzi

**采购策略**：品质 = 标准化
**预算指引**：物资成本率 30-35% 营收

---

### 2.3 中高端酒店（4 星）

**供应链特征**：
- 国产为主，性价比优先
- 注重效率 + 客户体验
- 集采比例 85%

**典型品牌组合**：
- 布草：康乃馨 / 鸿民 / 斯得福
- 客用品：欧舒丹 / 瑰珀翠
- 清洁：艺康 / 泰华施
- 智能客控：肯特 / 涂鸦智能

**采购策略**：性价比 > 品牌
**预算指引**：物资成本率 28-32% 营收

---

### 2.4 中端酒店（3 星 + 经济型连锁）

**供应链特征**：
- 国产标准品为主
- 注重周转 + 标准化
- 集采比例 90%

**典型品牌组合**：
- 布草：舒棉 / 鑫缘
- 客用品：威露士 / 蓝月亮
- IT：别样红 / 住哲
- 工程：国产空调

**采购策略**：周转 = 王道
**预算指引**：物资成本率 22-28% 营收

---

### 2.5 经济型酒店（2 星 + 单体）

**供应链特征**：
- 极简 + 极致成本
- 标准化 + 单一品牌
- 集采比例 95%

**典型品牌组合**：
- 布草：通用白布草
- 客用品：基本款洗发水
- IT：金天鹅
- 工程：国产基础款

**采购策略**：成本 = 唯一标准
**预算指引**：物资成本率 18-22% 营收

## 三、按品类分级（20 大类 · 5 级）

### 3.1 L1 战略品类（5 类 · 100% 集采）

| 品类 | 集采原因 | 关键供应商特征 |
|------|---------|--------------|

| 智能客控 | 体验差异化 | 技术领先、可定制 |
| IT 系统 | 运营基础设施 | 大厂、稳定 |
| 安防系统 | 合规强制 | 资质齐全 |
| 消防系统 | 合规强制 | 国标认证 |

|------|---------|

| 餐饮原料 | 安全 + 成本 |
| 清洁药剂 | 标准化 |
| 厨房设备 | 大额投入 |
| 工程设备 | 长期资产 |
| 家具软装 | 调性 |

### 3.3 L3 杠杆品类（4 类 · 50% 集采）

| 品类 | 集采原因 |
|------|---------|
| 装饰材料 | 项目化采购 |
| 餐饮器皿 | 标准化程度中等 |
| 员工制服 | 品牌 + 标准化 |
| 会议设备 | 灵活需求 |
| 照明系统 | 项目化 |
| 泳池/SPA | 细分需求 |

### 3.4 L4 常规品类（3 类 · 区域推荐 3 家）

| 品类 | 集采原因 |
|------|---------|
| 办公用品 | 高度本地化 |
| 园林景观 | 高度本地化 |
| 运营用品 | 高度本地化 |

### 3.5 L5 应急品类（即时采购）

- 突发物资
- 紧急维修件
- 不可预测的临时需求

## 四、按区域分级（5 大区）

### 4.1 长三角

**特点**：
- 中国酒店业最发达
- 集采标准化最强
- 供应商最丰富

**重点**：
- 食材本地化（江浙菜）
- 高端品牌资源丰富
- 数字化程度最高

**本地供应链特点**：
- 苏州/无锡：智能制造
- 杭州：互联网 + 酒店
- 上海：国际供应链
- 南京：央企 + 政企

### 4.2 珠三角

**特点**：
- 灵活度高
- 民营经济发达
- 性价比导向

**重点**：
- 食材本地化（粤菜）
- 工程类资源丰富
- 跨境供应链

### 4.3 京津冀

**特点**：
- 国央企关联强
- 政治资源丰富
- 集采严格

**重点**：
- 国央企对接
- 高端资源对接
- 政企客户

### 4.4 成渝

**特点**：
- 性价比导向
- 西部市场中心
- 旅游资源丰富

**重点**：
- 本地供应链整合
- 旅游酒店资源
- 火锅食材本地化

### 4.5 西北/东北

**特点**：
- 弱集采
- 全本地化
- 季节性明显

**重点**：
- 全本地化采购
- 季节性备货
- 应急能力强
