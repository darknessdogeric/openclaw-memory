### 3 公里商圈圈定法速查

```
Step 1: 打开百度地图 → 工具 → 测距

Step 5: 导出为 Excel

```

## 14. 4 大供应商接入 SOP 速查（v3.1 新增）

### 组团社接入流程

```
1. 列出 TOP 20（按客源国 TOP 5）
2. 邮件/LinkedIn 联系采购经理
3. 寄送酒店介绍 + 报价单
4. 拜访或视频会议
5. 草签 11 项标准协议
6. 押金 ¥20 万
7. 试合作 1 个月
8. 转为正式协议
```

### B2B 接入流程

```
1. 注册 siteMinder / D-EDGE 账号
2. 通过 siteMinder 一键接入 Hotelbeds/TBO/Restel
3. 设置净价（与 OTA 散客价 80%）
4. 每天更新房态
5. 自动结算
```

### 包机商接入流程

```
1. 联系包机商销售总监
2. 提供酒店设施 + 区位 + 报价
3. 现场考察（如可能）
4. 协议 + 押金 ¥30 万
5. 提前 3-6 个月签约
6. 包机当日专项服务
```

### 专列商接入流程

```
1. 联系铁路局集团（或携程/中青旅专列频道）
2. 申请加入"专列酒店推荐名录"
3. 报价 + 押金 ¥30 万
4. 提前 6-12 个月签约
5. 多城市停靠协调
6. 专列当日专项服务
```

## 18. 携程商旅（最快接入）操作手册（v3.2 新增）

**接入 5 步**：

1. **访问携程商旅官网**：trip.biz → 注册酒店
2. **提交资料**：
   - 营业执照
   - 酒店中英文介绍
   - 报价单（净价 / 协议价）
   - 服务标准（SLA）
   - 案例
3. **携程 BD 评估**（2-4 周）
4. **签约**（携程标准协议）
5. **API 对接**（1-2 周）

**关键成功要素**：
- 报价要有竞争力（与 OTA 散客价留 8-10% 价差）
- 24h 英语/日语/韩语 客服必备
- 取消政策灵活（24h 前免费）
