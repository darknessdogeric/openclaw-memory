## 一、5 大核心工具类型

### 1.1 SRM（供应商关系管理）

**核心功能**：寻源、准入、绩效、退出、合同、协同
**主流产品**：
- 国产：甄云 SRM / 用友 SRM / 金蝶云 SRM
- 国外：SAP Ariba / Oracle Procurement Cloud / Coupa
- 行业：携程商旅"招采通" / 京东企业购 SRM

**选型建议**：
- < 20 家酒店：用 SaaS 套件（简道云/钉钉宜搭）
- 20-50 家：甄云 SRM
- 50-100 家：用友/金蝶 SRM
- > 100 家：SAP Ariba / Oracle

### 1.2 eProcurement（电子采购）

**核心功能**：申请、审批、订单、收货、对账
**主流产品**：
- 通用：京东企业购 / 震坤行 / 西域 / 史泰博
- 行业：同驿商城 / 锦江 GPP / 华住供应链

**选型建议**：
- 通用物资：京东企业购（最全）
- 酒店专用：同驿商城（最大酒店平台）
- 大客户：定制化解决方案

### 1.3 WMS（仓储管理系统）

**核心功能**：入库、出库、盘点、追溯
**主流产品**：
- 国产：C-WMS / 富勒 WMS / 旺店通
- 国外：SAP EWM / Manhattan / Körber
- 轻量：简道云 + 条码

**选型建议**：
- < 5 个仓库：简道云 + 一物一码
- 5-20 个仓库：C-WMS
- > 20 个仓库：SAP EWM

### 1.4 BI / 数据分析

**核心功能**：采购数据可视化、决策支持
**主流产品**：
- 通用：Tableau / Power BI / Qlik
- 国产：帆软 FineBI / 永洪 / Smartbi

**选型建议**：
- 预算紧：Power BI（与 Office 集成好）
- 国产化要求：帆软 FineBI
- 高级分析：Tableau

### 1.5 SRM 集成层

**核心功能**：API / EDI / 供应商门户
**主流产品**：
- iPaaS：阿里云 iPaaS / 华为 ROMA / Workato
- API Gateway：Apigee / Kong

**选型建议**：
- 云原生：阿里云 iPaaS
- 混合云：ROMA Connect

## 二、酒管公司典型工具栈

### 2.1 小型酒管（< 20 家酒店）

```
钉钉/企微
├── 简道云（采购申请+审批）
├── 京东企业购（标准物资）
├── 同驿商城（酒店专用）
├── Excel/钉钉表格（台账）
└── 钉钉/企微（沟通协同）
```

**预算**：5-20 万/年
**实施周期**：1-2 个月

### 2.2 中型酒管（20-50 家酒店）

```
SaaS 中台
├── 甄云 SRM（供应商管理）
├── 用友/金蝶 Cloud（财务）
├── 同驿商城（酒店专用）
├── 简道云/钉钉（流程审批）
├── C-WMS（仓储）
├── FineBI（数据分析）
└── 阿里云 iPaaS（集成）
```

**预算**：50-150 万/年
**实施周期**：3-6 个月

### 2.3 大型酒管（50-100 家酒店）

```
集成化平台
├── 用友 NC Cloud / 金蝶云苍穹（ERP）
├── 用友/金蝶 SRM
├── 京东企业购（标准物资）
├── 自研 / SAP B1（WMS）
├── 帆软 FineBI / Power BI
├── 钉钉/企微（协同）
├── 钉钉 + RPA（流程自动化）
└── AI 引擎（需求预测/比价）
```

**预算**：200-500 万/年
**实施周期**：6-12 个月

### 2.4 集团型酒管（> 100 家酒店）

```
企业级套件
├── SAP S/4HANA / Oracle ERP Cloud
├── SAP Ariba（采购云）
├── SAP EWM（仓储）
├── Oracle Procurement Cloud
├── 自研 BI + AI 平台
├── 行业 SaaS 集成
├── 区块链溯源平台
└── 数字孪生
```

**预算**：500 万-2000 万+
**实施周期**：12-24 个月

## 三、5 级数字化成熟度路径

| 等级 | 特征 | 推荐工具 | 投资 |
|------|------|---------|------|
| L1 初始 | Excel 表格 | 无 | 0 |
| L2 标准化 | ERP 基础模块 | 用友/金蝶 | 10-50 万 |
| L3 集成化 | SRM + WMS + BI | 行业 SaaS | 50-200 万 |
| L4 智能化 | AI 预测 + IoT | AI 引擎 + IoT | 200-500 万 |
| L5 自治化 | 数字孪生 + 自主决策 | 高级算法 | 500 万+ |

**升级路径**：
```
L1 → L2：基础 ERP 上线
L2 → L3：SRM/WMS/BI 集成
L3 → L4：AI 能力嵌入
L4 → L5：数字孪生 + 自治
```

## 七、关键成功因素

1. **不要重复造轮子**：用成熟 SaaS，自研风险极大
2. **移动优先**：采购员、验收员、仓管员都要能用手机
3. **集成优先**：避免数据孤岛
4. **数据沉淀**：所有交易都要进数据湖
5. **分阶段实施**：从核心场景开始
