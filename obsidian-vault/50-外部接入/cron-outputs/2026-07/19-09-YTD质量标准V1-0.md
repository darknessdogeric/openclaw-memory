# YTD 月度研报质量标准 V1.0

> **制定日期**: 2026-07-25
> **适用范围**: 所有 YTD / 月度 / 季度 / 半年度酒店行业研报
> **维护者**: B166ER (Eric 的 AI 助理)
> **核心原则**: **"敢点名 · 敢排序 · 敢给概率 · 数据严谨 · 方法论可证伪"**

---

## 一、五大质量原则（缺一不可）

### 1.1 数据严谨性（最高优先级）

```
✓ 必须严格区分：
  · 6月单月 vs 1-5月累计 vs 1-6月 H1 vs YoY/MoM
  · 财报披露口径 vs 行业研报口径
  · 平台数据 vs 抽样数据 vs 模型推断

✗ 禁止：
  · 把"1-5月累计"包装成"6月表现"
  · 把"研报推断"包装成"官方披露"
  · 把"单店数据"包装成"集团数据"
  · 把"节假日数据"包装成"常态数据"
```

### 1.2 独立洞察（敢点名）

```
✓ 必须包含：
  · 具体公司点名（哪些活、哪些死、哪些买、哪些卖）
  · 具体概率（不是"可能"，是"65%概率"）
  · 具体时间窗口（不是"未来"，是"Q3-Q4"）
  · 具体数据阈值（如果 X < 0.5 → 触发 Y 结论）

✗ 禁止：
  · "可能/预计/有望"等模糊词
  · "行业整体面临挑战"等无可证伪的废话
  · 永远站在"中庸"立场
```

### 1.3 跨市场对标（必含）

```
✓ 必含 3 类对标：
  · 国际对标：日本/美国/欧洲酒店 REITs 经验
  · 历史对标：2019年（疫情前）/ 2023年（复苏期）/ 2026年（现状）
  · 业态对标：奢华 vs 中端 vs 经济型 跨档次对比

✗ 禁止：
  · 只看中国数据
  · 忽略历史基准
  · 不做跨业态对比
```

### 1.4 定量方法论（必须有）

```
✓ 必含：
  · 至少 1 个定量预测模型
  · 至少 1 张敏感性分析
  · 至少 1 张可证伪条件表

✗ 禁止：
  · 纯定性描述
  · 无可证伪条件的预测
  · 没有数据支撑的"专家观点"
```

### 1.5 质性研究补充（必须）

```
✓ 必含：
  · 至少 3 个管理层 / 行业人观点
  · 至少 2 个酒店 / 物业案例
  · 至少 1 张竞争格局分析

✗ 禁止：
  · 完全信息汇编
  · 缺乏案例支撑
  · 没有"人话"
```

## 二、报告结构标准（13+ 章节）

### 必备章节（不可缺失）

```
1. 执行摘要（10-15 行信号表）
2. 数据口径声明（单月/累计/YoY/MoM 严格区分）
3. 重大事件时间线（本月 ≥5 件大事）
4. 关键指标月度追踪（OCC/ADR/RevPAR/餐饮/出租）
5. 一线城市（北/上/广/深 分城）
6. 准一线城市（≥10 城）
7. 二线 + 下沉市场（统一观察）
8. 酒店细分市场表现（5 维度：档次/位置/客群/经营/新业态）
9. 头部集团综合（内资 5 + 外资 5 + 同比环比 + 分析）
10. 行业基础设施（REITs / OTA / 转让 / 加盟）
11. 餐饮收入分析（全国 + 酒店餐饮细分 + 婚宴）
12. 行业景气指数（CHAT / 浩华）
13. H2 预测（定量 + 敏感性 + 可证伪）
14. 风险提示
15. 核心结论 + 行动建议（敢点名 + 敢给概率）
```

### 加分章节（建议）

```
· 国际对标（日本/美国酒店周期对比）
· 历史对标（2019/2023/2026 三阶段对比）
· 业态对标（跨档次 RevPAR 排序）
· 案例研究（2-3 个酒店/物业案例）
· 管理层访谈（3-5 位行业人观点）
· 投资建议（具体买入/卖出名单）
```

## 三、信号表标准（执行摘要核心）

### 信号表必含 5 列

```
| 信号 | 方向 | 同比 (YoY) | 环比 (MoM) | 置信度 |

· 方向：↑ ↑↑ ↓ ↓↓ → ↘ 等
· YoY：必须含（即使推断也要标"推断"）
· MoM：必须含（即使推断也要标"推断"）
· 置信度：🟢 官方/财报 / 🟡 研报推断 / 🔴 单点样本
```

### 信号表 ≥10 行

```
1. 全国 OCC
2. 全国 ADR
3. 全国 RevPAR
4. 全国餐饮收入
5. 头部集团营收（综合）
6. 头部集团利润（综合）
7. 行业景气指数
8. REITs 进展
9. 入境游表现
10. 节假日窗口表现
11. 重点城市表现
12. 新开业结构
13. 价格战压力
14. 利润承压情况
```

## 四、独立洞察标准（B166ER 专家判断）

### 4.1 必须敢点名的内容

| 类别 | 必须点名 | 不许模糊 |
|---|---|---|
| **集团表现** | "华住是唯一增收增利大型" | ✗ "部分头部表现优异" |
| **REITs 落地** | "华安锦江 6/23 通过 · 锦江 Q4 跟进 70% 概率" | ✗ "REITs 有望加速" |
| **风险企业** | "温德姆大中华区持续承压 · 60% 概率退出" | ✗ "部分外资面临挑战" |
| **死亡名单** | "经济型外资连锁 · 老旧单体酒店" | ✗ "部分单体将出清" |
| **投资建议** | "亚朵零售模式 · REITs 物业 · 头部集团转债" | ✗ "关注优质标的" |

### 4.2 必须敢给的概率

| 概率 | 含义 |
|---|---|
| **>80%** | 几乎必然发生（明确信号） |
| **60-80%** | 高概率（多维证据支持） |
| **40-60%** | 中等概率（信号混合） |
| **20-40%** | 低概率（少数证据） |
| **<20%** | 极小概率（边缘事件） |

### 4.3 必须敢排的序

```
头部集团排序（按 6 月综合表现）：
1. 华住（增收增利+签约稳健）
2. 亚朵（零售曲线+中高端独立）
3. 万豪（高端外资领跑）
4. 凯悦（高端外资亚军）
5. 希尔顿（持续扩张）

承压集团：
1. 温德姆大中华区（外资经济型）
2. 锦江（高基数压制）
3. 首旅（如家品牌老化）
4. 君亭（拐点未确认）
```

## 五、定量方法论（必须有模型）

### 5.1 至少 1 个预测模型

```
示例：价格弹性模型
   ADR 跌幅每 +1% → RevPAR 跌幅 +0.8%
   OCC 涨幅每 +1% → RevPAR 涨幅 +0.5%

示例：REITs 落地概率模型
   头部集团排名 × REITs 申报进度 × 政策窗口期 = 落地概率
```

### 5.2 至少 1 张敏感性分析

```
如果暑期 RevPAR YoY < +5%  → 拐点延后至 2027 Q4
如果暑期 RevPAR YoY +5~15% → 拐点 2027 Q3
如果暑期 RevPAR YoY > +15% → 拐点提前至 2027 Q2
```

### 5.3 至少 1 张可证伪条件

```
预测 1：8 月 RevPAR YoY +8~12%
   成立条件：W27 热度延续 + 七夕单点冲高
   证伪信号：8/15 OCC < 65% / ADR 同比 -5% 以下

预测 2：Q4 REITs 落地 ≥3 单
   成立条件：政策窗口 + 头部集团财报披露
   证伪信号：监管延迟 / 集团财报推迟
```

## 七、质性研究标准

### 7.1 管理层 / 行业人观点

```
· 至少 3 位（来自头部集团高管 / 行业协会 / 投资机构）
· 每位 ≥100 字原话引用
· 明确身份（公司+职位）
· 涉及具体判断（不是泛泛而谈）
```

### 7.2 案例研究

```
· 至少 2 个（酒店案例 + 物业/REITs 案例）
· 每个案例 ≥300 字
· 包含：背景 / 决策 / 数据 / 结果 / 启示
```

### 7.3 竞争格局分析

```
· 至少 1 张 2D 定位图（价格 × 服务深度）
· 头部集团 + 新进入者 + 退出者
· 标出每个玩家的优势/劣势
```
