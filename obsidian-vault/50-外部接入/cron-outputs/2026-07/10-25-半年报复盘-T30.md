## 四、偏差分析（五维归因）

### 4.1 偏差1（最大失算）：ADR 复苏幅度低估

**预测**：+4~6%（Q1 全景报告对 Q2 的预测）  
**实际**：H1 加权 **+2~4%**（持平 ~ 微涨）  
**偏差**：**-1~-2ppts** 系统性低估

**根因**：

```
第一层（直接原因）：新增供给 + 出行结构变化 双重稀释
  → 2025 年全年新增 9,800 家中档以上客房（H1 集中爬坡期）
  → 新开业酒店为抢市场份额，定价偏低，拉低区域 ADR 均值
  → "松弛出游"使近郊游占比提升（ADR 低于跨省长途）

第二层（机制原因）：城市分级不匹配
  → 高线城市供给净增加压制奢华/中高端 ADR
  → 低线城市则 IP 驱动价格走高，但占比不足以扭转大盘

第三层（数据原因）：预测时引用的"分城市预订均价"口径 vs 实际成交
  → 预订口径反映客户预期最高价
  → 成交口径反映 after-cancellation、after-discount 实际值
  → 二者差异 0.92~0.95 折扣系数

第四层（结构性原因）：奢华外资 ADR 表现超过预期
  → 上海奢华 ADR +7% (JLL) 是预测未充分建模的
  → 入境游驱动高端市场
```

**下次预测调整**：
- H2 ADR 预测区间从 +3~5% → +1~3%（基准下调）
- 引入"新开业客房爬坡系数 0.92~0.95"
- 引入"出行结构系数 0.97~0.99"（短途游占比提升压低效应）
- 引入"奢华外资 ADR 突破系数"（视入境游政策利好单独上调）

### 4.2 偏差2（最大惊喜）：端午间夜量 +30% 严重低估

**预测**：+5~8% 间夜量（May 报告平台口径外推）  
**实际**：**+30%** 间夜量（Fliggy 平台）/ 端午民宿订单 +25~54%（木鸟）  
**偏差**：**+22~25ppts** 严重低估

**根因**：

```
第一层（数据样本偏差）：Fliggy 在端午期间的业务份额比预测期估算高
  → 预测时按全国 OTA 平均份额估算，未识别 Fliggy/抖音/小红书在 2026 年新增量

第二层（结构性原因）：H1 消费需求被多方承压释放
  → 春节后 1-4 月压抑需求集中释放
  → 周边游 + 短途游 + Z 世代 + 入境游 共同堆量
  → 人均预订金额 +16%（不是低端堆量，是中等价位堆量）

第三层（"松弛出游"概念性偏差）：
  → 预测框架假设端午低预算会抑制量能
  → 实际"松弛出游"是用同样预算买到更多频次，量能反而增长
```

**下次预测调整**：
- 端午节前平台预订口径加权计算：Fliggy/抖音/小红书权重从 20% → 35%
- "松弛出游"明确建模：端午/暑期/中秋此类"3 天小长假"应该用"低预算 × 高频次"模型
- 节假日量能预测区间整体上修 +5~8pcts

### 4.3 偏差3：餐饮增速不及预期

**预测**（隐含）：与 2025 H1 +5.0% 基本持平  
**实际**：H1 **+2.8%**（国统局官方），较 2025 H1 回落 **2.2pcts**  
**偏差**：**-2.2pcts** 餐饮增速显著回落

**根因**：

```
第一层：消费审慎 + 价格战压制
  → 商品零售仅 +1.1%（价格战常态化）
  → 餐饮作为可选消费 +2.8% 已经是"韧性"表现
  → 实际不及预期 -2.2pcts 但仍高于商品零售 +1.7pcts

第二层：酒店餐饮 vs 社会餐饮分化
  → 酒店餐饮 4 月营收指数 62.1（环比 -7%）
  → 宴会淡季 + 酒店餐饮社会化运营不足
  → 6 月酒店婚宴 +15%（季节性一次性提振）

第三层：份额被社会餐饮挤压
  → "酒店餐饮社会化运营不足"是 H1 持续问题
  → 高性价比社会餐饮（海底捞/太二/区域品牌）截流酒店宴请
```

**下次预测调整**：
- 餐饮 H2 预测从 +5% → +3~4%（基准下调）
- 引入"宴席淡季因子"：4 月/11 月酒店餐饮指数应单独建模
- 酒店餐饮收入预测应与婚宴/会展/差旅三场景分别建模

### 4.4 偏差4：一线城市 RevPAR 复苏强于预期

**预测**：韧性预期（具体区间未明确）  
**实际**：深圳 RevPAR **+12.1%**、广州高端 +5.9%、上海奢华 ADR +7%  
**偏差**：方向正确，深圳 +12.1% 略超预期

**根因**：

```
第一层：深圳表现远超预期
  → 深圳作为科创/互联网中心，2026 H1 商旅需求强劲
  → 广州南站/深圳口岸入境游持续景气
  → 仲量联行将深圳列为 H1 RevPAR 增长第一

第二层：入境游驱动高端 ADR
  → 上海 1-5 月累计入境游客 438 万人次 / +29.1%（JLL）
  → 240h 过境免签覆盖 55 国 + 中俄免签 6/9 生效
  → 奢华酒店成为入境游客主流选择

第三层：供给侧短期错配
  → 上海上半年新增高奢供给约 770 间客房
  → 在强劲需求下供给增量未稀释价格
  → 反而强化了高端市场的"结构性短缺"信号
```

**下次预测调整**：
- 一线城市 RevPAR 预测从 +5~8% → +8~12%
- 单独建模"入境游弹性系数"：免签政策变动应纳入 H1/H2 预测输入
- 奢华酒店 ADR 不应再统一预测为"持平"，应区分一线/二线

### 4.5 偏差5：HCI 指数"峰谷交替"特征未纳入预测

**预测**：未将 HCI 指数纳入框架  
**实际**：HCI 5月 = 101.8（年内次高峰）/ 6月估计 95~100 / 2月 = 105.6（年内最高峰）

**根因**：

```
第一层：方法论缺位
  → 预测框架未引入中国饭店协会 HCI 这一官方权威指数
  → 节假日 "峰" 与节后 "谷" 的交替规律未被建模

第二层：实际数据信号清晰
  → 5月、6月在线预订指数同比 +12.1% / +8.8%
  → 在线预订持续高景气 → 反映间夜量增长
  → 但 ADR 增长 "乏力" → 反映价格战

第三层：HCI "消费审慎化" 文字描述
  → 不仅是数据：消费心态发生根本转变
  → 客户从"提前预订高价房"转向"当日即时预订中价位房"
  → 价格弹性下降，价格战边际效用递减
```

**下次预测调整**：
- 将 HCI 5 月分项指数（房价/入住率/在线预订/餐饮/信心）作为月度研报的"必入信号"
- "消费审慎化"作为一个独立预测变量（年中 4 月、9-10 月、11 月酒店餐饮压力应预判加重）

## 五、季节性因素验证

### 5.1 H1 季节性结构

```
H1 = 一季度 (1-3月) + 二季度 (4-6月)
  H1 季节性核心节点：
```

### 5.3 季节性新发现（H1 新增） 

**发现 1：春假试点 6 天小长假效应**

**发现 2：HCI "峰谷交替"特征**
- 5月 HCI 101.8（节假日高峰）/ 6月 HCI 95~100（节后回落）
- 节后住宿市场回落明显，但消费基础稳健
- **预测含义**：节后 1~2 周需做"节庆回落系数"建模

- **预测含义**：端午/中秋此类 3 天小长假应使用"低预算 × 高频次"模型
