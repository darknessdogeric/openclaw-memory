# AHL项目信息采集清单（通用版）

> 目标：任何酒店项目沟通前，先收集足够信息，再带着针对性问题上门
> 适用：单体酒店/酒店集团/委托管理/加盟等多种合作模式
> 原则：Eric = 倾听者，不是推销员

---

## 使用说明

```
第一步：出发前（远程）
├─ 携程抓取基础数据（评分/房价/点评）
├─ 搜索业主背景（天眼查/新闻/官网）
├─ 搜索竞争环境（商圈数据）
└─ 预填本清单"预填数据"部分

第二步：出发前（最后确认）
├─ 对接人是谁？背景？
├─ 今天的沟通目标是什么？
├─ Eric的角色是什么？（倾听/试探/推进？）
└─ 对方的核心诉求是什么？

第三步：现场（边聊边记）
├─ 按本清单逐项确认+追问
├─ 重点：痛点+决策链+预算
└─ 离开前：约定事项+下一步

第四步：回来后（当天）
├─ 填写"当晚分析"部分
├─ 判断AHL匹配度
├─ 设计针对性方案
└─ 安排后续行动
```
