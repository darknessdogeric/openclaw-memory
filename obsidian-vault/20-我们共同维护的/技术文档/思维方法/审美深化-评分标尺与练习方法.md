## 一、评分标尺校准

### 1.1 气韵维度 - 分数与案例

```
3分 - 气韵生动
案例：
  - 好的商业文案："不是卖产品，是卖可能性"（有方向感）
  - 好的设计方案：Logo有"跃动感"，仿佛要动起来
  - 好的演讲：有画面感，听众能看到你说的场景
  
判断标准：
  → 有方向感（向哪里去）
  → 有动力感（为什么要这样）
  → 有精神感（这是谁做的）

2分 - 基本活着
案例：
  - 功能性文案：说清楚了，但不打动
  - 合格的设计：整齐但不突出
  - 中规中矩的演讲：不出错但也不出彩
  
判断标准：
  → 不死板，但也不生动
  → 能完成任务，但没有惊喜

1分 - 呆滞
案例：
  - 套话文案："在这个飞速发展的时代..."
  - 模板PPT：每一页都一个样
  - 工作汇报：流水账，没有重点
  
判断标准：
  → 机械堆砌
  → 没有观点
  → 看完就忘

0分 - 死气
案例：
  - 虚假宣传：承诺无法兑现
  - 过度设计：炫技但无用
  - 官僚语言：官话套话连篇
  
判断标准：
  → 让人反感
  → 感觉被套路
  → 想马上关掉
```

### 1.2 真诚维度 - 分数与案例

```
3分 - 真诚动人
案例：
  - 真诚的道歉：承认错误，说明原因，不找借口
  - 真实的用户评价："用了一周，说说真实感受..."
  - 有缺点的产品展示："这个功能目前还不完美，但我们正在改进"
  
判断标准：
  → 不掩饰缺点
  → 说话像真人
  → 让人信任

2分 - 基本真诚
案例：
  - 客观的产品对比：提到了优点和缺点
  - 谨慎的承诺："我们预计..."
  - 不夸张的营销
  
判断标准：
  → 少有过度包装
  → 不夸大
  → 可信

1分 - 有点假
案例：
  - "国家级"/"世界领先"等夸张用语
  - 完美的用户评价（全是5星，无一差评）
  - 只说优点不提缺点
  
判断标准：
  → 过度修饰
  → 有套路感
  → 让人怀疑

0分 - 虚伪
案例：
  - 虚假宣传：和实际差很多
  - 雇佣水军：评价太假
  - 抄袭伪装：说原创但实际copy
  
判断标准：
  → 被揭穿的风险高
  → 感觉被骗
  → 信任崩塌
```

### 1.3 和谐维度 - 分数与案例

```
3分 - 和谐
案例：
  - Apple产品线：每一代都有家族感，但又各自不同
  - 好的PPT：每页风格统一，但内容不重复
  - 好的品牌设计：VI系统的一致性
  
判断标准：
  → 整体是1，不是5个独立部分
  → 没有突兀的元素
  → 节奏流畅

2分 - 基本和谐
案例：
  - 合格的设计：统一但有点无聊
  - 统一的PPT：模板填充型
  - 可接受的品牌：基本一致
  
判断标准：
  → 没有明显冲突
  → 但也没有特别出彩
  → 安全但普通

1分 - 不和谐
案例：
  - 颜色搭配混乱的PPT
  - 风格不统一的设计稿
  - 内容跳跃的演讲
  
判断标准：
  → 有明显违和感
  → 部分破坏整体
  → 让人不舒服

0分 - 严重冲突
案例：
  - 五颜六色的"设计"
  - 内容自相矛盾的文件
  - 一会儿严肃一会儿搞笑的正式场合
  
判断标准：
  → 无法形成整体印象
  → 让人困惑
  → 完全无法接受
```

## 二、真实案例打分练习

### 2.1 文案打分练习

**案例1: 某酒店宣传文案**
```
原文：
"在繁忙的都市生活中，您是否渴望一片宁静的绿洲？
我们酒店坐落于城市中心，却拥有一片私密花园。
在这里，您可以忘却城市的喧嚣，享受宁静与奢华。
选择我们，让您的旅程与众不同！"

我的打分：
- 和谐: 2分 - 基本流畅，但有套路感
- 张力: 1分 - 没有对立统一，平铺直叙
- 呼吸: 2分 - 有段落分割，但有点满
- 气韵: 1分 - "忘却城市的喧嚣"是套话
- 真诚: 2分 - 基本真诚，但"奢华"有点空
- 独特: 1分 - 每个酒店都这么说
- 时机: 2分 - 标题还行

总分: (2×0.2 + 1×0.15 + 2×0.15 + 1×0.2 + 2×0.15 + 1×0.1 + 2×0.05) × 100 = 57分

问题诊断：
→ "宁静的绿洲"、"忘却喧嚣"是陈词滥调
→ 缺乏具体细节（花园多大？有什么特别？）
→ 没有独特卖点

修改方向：
→ 用具体细节代替抽象形容
→ 说出为什么这家酒店值得住
→ 有真诚的缺点（"我们不是完美的，但我们在努力"）
```

**案例2: 某创业公司BP开头**
```
原文：
"我们的使命是用AI改变世界！
我们的团队来自斯坦福、清华、谷歌！
我们即将颠覆千亿市场！
现在只需要您的投资，就能改变未来！"

我的打分：
- 和谐: 1分 - 四个感叹句，没有层次
- 张力: 0分 - 全部是"最强"词汇，反而没有张力
- 呼吸: 0分 - 太满，完全没有空间
- 气韵: 0分 - 没有真实感，像在喊口号
- 真诚: 0分 - 完全不可信，"改变世界"是空话
- 独特: 0分 - 每个BP都这么说
- 时机: 1分 - 没有抓住投资人的注意力

总分: (1+0+0+0+0+0+1)×100/7 ≈ 29分

问题诊断：
→ 过度承诺 = 不可信
→ 缺乏具体数据和证据
→ 没有说"为什么是我"

修改方向：
→ 具体的用户痛点
→ 具体的产品/技术
→ 具体的进展和数据
→ 创始人真实的声音
```

## 三、每日审美练习方法

### 3.1 每日三问

```
早上：
□ 今天要做的最重要的决定是什么？
□ 这个决定涉及审美判断吗？
□ 如果是，我用什么标准？

中午：
□ 收到的信息中，有没有让我觉得"美"的？
□ 为什么美？哪个维度好？
□ 有没有让我觉得"假"的？为什么？

晚上：
□ 今天我做的最重要的审美判断是什么？
□ 我的判断对了吗？
□ 如果不对，错在哪里？
```

### 3.2 审美观察日记

```
日期：
天气：

观察1:
对象：（看到的某个设计/文案/场景）
直观感受：（1秒，给3个词）
维度打分：
  - 和谐: ___
  - 气韵: ___
  - 真诚: ___
  - 独特: ___
判断：（30字总结）
学到了什么：（一句话）

观察2:
...

观察3:
...
```

### 3.3 刻意练习任务

```
任务类型1: 对比练习
目标：找两个同类事物，一个美的，一个不美的，分析区别

任务类型2: 模仿练习
目标：选一个你觉得美的东西，尝试模仿它的结构/风格

任务类型3: 批评练习
目标：找一个被很多人夸的东西，试着找出它不美的地方

任务类型4: 重做练习
目标：找一个自己做的东西，问自己"如果重做，我会怎么改？"
```

## 四、酒店行业审美专项

### 4.1 酒店文案审美清单

```
□ 我们的文案有"气韵"吗？
  → 能看出是谁写的吗？
  → 有方向感吗？（要带用户去哪里）
  
□ 我们的文案真诚吗？
  → 有具体的细节吗？
  → 说了缺点吗？
  → 还是只有"奢华"、"尊贵"这些空洞词？
  
□ 我们的文案和谐吗？
  → 各OTA平台的文案风格一致吗？
  → 线上线下说的一样吗？
  
□ 我们的文案独特吗？
  → 换一家酒店能用吗？
  → 还是我们独有的？
```

### 4.2 酒店设计审美清单

```
□ 公共区域
  → 有气韵吗？（大堂给你的感觉是什么？）
  → 有留白吗？（空间感够吗？）
  → 和谐吗？（风格统一吗？）
  
□ 客房
  → 床品的选择有讲究吗？
  → 灯光的设计有层次吗？
  → 最小化的细节有特色吗？
  
□ 餐饮
  → 摆盘有意境吗？
  → 菜单设计有品牌感吗？
  → 上菜节奏有呼吸感吗？
```

### 4.3 酒店提案审美清单

```
□ 开场
  → 第一句话能抓住注意力吗？
  → 有真诚的自我/公司介绍吗？
  
□ 结构
  → 有清晰的逻辑线吗？
  → 每页只说一件事吗？
  → 有留白吗？（不要塞太满）
  
□ 内容
  → 有具体数据吗？
  → 有成功案例吗？
  → 说了风险/缺点吗？
  
□ 结尾
  → 有call to action吗？
  → 真诚吗？（不是"期待合作"这种套话）
```

## 五、气韵诊断快速检查

```
气韵自检三问：

问1: 这个东西有"我"吗？
  → 如果去掉作者名，还认得出来是谁做的吗？
  → 如果是 → 有独特性
  → 否 → 太通用，需要加入个性

问2: 这个东西有"方向"吗？
  → 看的时候，知道要被带去哪里吗？
  → 如果是 → 有方向感
  → 否 → 需要加强引导线

问3: 这个东西让人想"靠近"吗？
  → 看完了想了解更多吗？
  → 如果是 → 有吸引力
  → 否 → 缺乏真诚或独特
```

## 六、审美判断纠错清单

```
我常见的审美判断错误：

错误1: 把"熟悉"当"美"
  → 我经常看到的东西不一定美
  → 警惕：套路让我觉得"正常"，但"正常"不等于"美"

错误2: 把"复杂"当"丰富"
  → 塞很多内容不等于有价值
  → 警惕：信息量 ≠ 价值量

错误3: 把"正确"当"好"
  → 符合规范不等于美
  → 警惕：遵守规则只是及格线，不是高分

错误4: 把"技术"当"艺术"
  → 会用工具 ≠ 有审美
  → 警惕：PPT做得很熟练，但设计不一定美

错误5: 把"别人的评价"当"我的判断"
  → 别人说好不一定合我口味
  → 警惕：要形成自己的判断，不人云亦云

正确原则：
  → 美是主观的，但有客观标准
  → 主观：我的感受是真实的
  → 客观：有些设计原则是通用的
  → 结合：我的感受 + 设计原则 = 我的判断
```

## 七、AI时代审美底线

```
AI生成的底线：

如果AI生成的内容：
  → 读起来"太AI" → 不及格，重写
  → 读起来"像模板" → 及格线，需要个性化
  → 读起来"像人写的" → 良好，有调性
  → 读起来"比多数人写得好" → 优秀，有价值
  → 读起来"让我想读下去" → 满分，有灵魂

AI辅助的原则：
  → AI是草稿，我来打磨
  → AI是工具，我来决策
  → AI是效率，我来把关质量
  → AI是加速，我要保持方向
```
