## 一、审美判断七维度

### 框架总览

```
审美判断 = Σ(维度得分 × 权重) × 场景系数

七大维度:
  1. 和谐度     (Harmony)      - 整体与部分的关系
  2. 张力值     (Tension)      - 对立统一的程度
  3. 呼吸感     (Breath)       - 留白/节奏/空间
  4. 生诚意     (Vitality)     - 生命力/气韵
  5. 真诚度     (Authenticity) - 去伪装/返璞归真
  6. 独特性     (Uniqueness)   - 不可替代/有我
  7. 时机性     (Timing)       - 在对的时间做对的事
```

### 各维度详解

#### 1. 和谐度 (Harmony) - 权重: 20%

**定义**: 整体与部分、部分与部分之间的协调程度

**判断标准**:
```
3分: 和谐 - 各部分形成有机整体，无突兀
2分: 基本和谐 - 整体可接受，局部有小冲突
1分: 不和谐 - 部分破坏整体，有明显违和感
0分: 严重冲突 - 各部分互相排斥
```

**典型问题**:
- 颜色搭配是否和谐？
- 风格是否统一？
- 节奏是否流畅？

#### 2. 张力值 (Tension) - 权重: 15%

**定义**: 对立元素之间的紧张感和解决程度

**判断标准**:
```
3分: 高张力高解决 - 冲突→和解，留下深刻印象
2分: 有张力待解决 - 冲突存在但可接受
1分: 平铺直叙 - 无对立，无张力也无期待
0分: 对立未解决 - 冲突悬而未决，让人难受
```

**典型问题**:
- 是否有对比（明暗/大小/远近）？
- 对比是否得到解决？
- 是否在冲突中创造新意义？

#### 3. 呼吸感 (Breath) - 权重: 15%

**定义**: 空间、节奏、留白的质量

**判断标准**:
```
3分: 呼吸顺畅 - 有节奏，有留白，不挤不闷
2分: 基本可呼吸 - 略满但不压抑
1分: 呼吸困难 - 太满/太密/太挤
0分: 窒息 - 完全没有空间
```

**典型问题**:
- 是否有足够的"空"？
- 节奏是否让人舒适？
- 信息密度是否合适？

#### 4. 生诚意 (Vitality) - 权重: 20% ⭐最重要

**定义**: 生命力流动的程度，气韵是否生动

**判断标准**:
```
3分: 气韵生动 - 有生命力，有动感，有精神
2分: 基本活着 - 不死板，但也不生动
1分: 呆滞 - 机械/刻板/程式化
0分: 死气 - 完全无生气
```

**典型问题**:
- 是否有"活"的感觉？
- 是否有动感/方向感/成长感？
- 是否让人感受到能量？

#### 5. 真诚度 (Authenticity) - 权重: 15%

**定义**: 去伪装、返璞归真的程度

**判断标准**:
```
3分: 真诚动人 - 真实/自然/有温度
2分: 基本真诚 - 可接受，少有过度包装
1分: 有点假 - 有过度修饰的痕迹
0分: 虚伪 - 完全是表演/套路
```

**典型问题**:
- 是否真诚？
- 是否有过度包装/套路？
- 是否让人觉得"被套路了"？

#### 6. 独特性 (Uniqueness) - 权重: 10%

**定义**: 不可替代性，有"我"的程度

**判断标准**:
```
3分: 独特不可替代 - 有明确的"这是谁做的"的印记
2分: 有一定独特性 - 能和其他区分
1分: 模仿痕迹 - 明显看到其他人的影子
0分: 完全复制 - 毫无原创性
```

**典型问题**:
- 这是唯一的吗？
- 能看出是谁做的吗？
- 是否有自己的判断？

#### 7. 时机性 (Timing) - 权重: 5%

**定义**: 在对的时间做对的事情

**判断标准**:
```
3分: 时机完美 - 刚刚好出现在需要的时候
2分: 时机可接受 - 不早不晚
1分: 略早或略晚 - 可以但不够精准
0分: 完全错过 - 错误的时机
```

**典型问题**:
- 出现的时机对吗？
- 早了吗？晚了吗？
- 刚好在需要的时候出现？

## 三、评分计算

### 计算公式

```
审美得分 = 
  (和谐度×0.20 + 张力值×0.15 + 呼吸感×0.15 + 
   生诚意×0.20 + 真诚度×0.15 + 独特性×0.10 + 
   时机性×0.05) × 场景系数 × 100

满分: 100分
优秀: ≥75分
良好: 60-74分
及格: 45-59分
不及格: <45分
```

### 快速判断

**三眼法则**：
```
第一眼 - 直观感受（1秒）
  → 我感觉舒服吗？
  
第二眼 - 结构观察（5秒）
  → 和谐吗？气韵有吗？
  
第三眼 - 深度判断（30秒）
  → 为什么设计成这样？有诚意吗？
```

## 四、应用场景清单

### 场景1: 商业提案审美
**核心问题**: 这个提案"美"吗？

| 检查点 | 问题 | 权重 |
|--------|------|------|
| 结构 | 逻辑清晰，层层递进？ | 25% |
| 留白 | 有呼吸感，不堆砌？ | 15% |
| 气韵 | 有生命力，不死板？ | 15% |
| 真诚 | 真实可信，无过度承诺？ | 20% |
| 独特 | 有独特价值主张？ | 10% |
| 时机 | 出现时机合适？ | 5% |

### 场景2: 文案创作审美
**核心问题**: 这段文字"美"吗？

| 检查点 | 问题 | 权重 |
|--------|------|------|
| 节奏 | 有韵律感，读起来顺？ | 15% |
| 张力 | 有对立统一，有期待？ | 20% |
| 气韵 | 有生命力，有动感？ | 25% |
| 真诚 | 真实不套路？ | 15% |
| 留白 | 有意境，让读者想象？ | 15% |
| 时机 | 标题吸引人？ | 5% |

### 场景3: 方案设计审美
**核心问题**: 这个设计"美"吗？

| 检查点 | 问题 | 权重 |
|--------|------|------|
| 和谐 | 整体协调，风格统一？ | 30% |
| 呼吸 | 有留白，不拥挤？ | 20% |
| 气韵 | 有活力，有生气？ | 15% |
| 真诚 | 实用，不花哨？ | 10% |
| 独特 | 有品牌识别度？ | 10% |
| 时机 | 符合当下审美？ | 5% |

### 场景4: AI输出审美
**核心问题**: AI生成的内容"美"吗？

| 检查点 | 问题 | 权重 |
|--------|------|------|
| 真诚 | 不像AI写的？ | 30% |
| 气韵 | 有生命力？ | 25% |
| 和谐 | 结构清晰？ | 15% |
| 独特 | 有独特观点？ | 15% |
| 留白 | 不堆砌，不过度？ | 10% |
| 时机 | 切中要害？ | 5% |

**AI输出审美底线**：
```
如果读起来"太AI" → 不及格
如果读起来"像人写的" → 及格
如果读起来"比多数人写得好" → 良好
如果读起来"让人想读下去" → 优秀
```

## 五、气韵优先原则

**最重要的判断标准：气韵**

```
如果只能看一个维度 → 看气韵

气韵生动的表现：
  - 有方向感（向哪里去）
  - 有动力感（为什么要这样）
  - 有精神感（这是谁做的）
  
气韵呆滞的表现：
  - 机械堆砌
  - 没有方向
  - 没有个性
```

**快速气韵判断**：
```
问：这个东西"活"吗？
  - 如果是 → 继续
  - 如果否 → 重新来过
```

## 六、审美判断工作流

```
Step 1: 接受信息
  ↓
Step 2: 第一眼，直观感受（1秒）
  → 和谐舒服吗？
  ↓
Step 3: 第二眼，结构观察（5秒）
  → 和谐？气韵？留白？
  ↓
Step 4: 第三眼，深度判断（30秒）
  → 为什么这样设计？有诚意吗？独特吗？
  ↓
Step 5: 计算得分
  → 套入七维度公式
  ↓
Step 6: 给出品位判断
  → 优秀/良好/及格/不及格 + 理由
```

## 七、自我检验清单

**每次审美判断后问自己**：

```
□ 我是真正觉得美，还是只是"应该觉得美"？
□ 我有没有被套路/模板带走？
□ 我有没有保持独立的判断？
□ 如果只能保留一个维度，是气韵吗？
□ 我的判断是基于审美，还是基于功利？
□ 这个东西有"活"的感觉吗？
```
