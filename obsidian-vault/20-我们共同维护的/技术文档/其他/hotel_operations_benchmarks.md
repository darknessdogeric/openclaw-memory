### 3.2 中餐上菜顺序（正式宴会）

```
冷菜 → 汤品 → 热菜(大菜/主菜先上) → 炒菜 → 素菜 → 主食 → 甜品 → 水果
```

**时间控制**:
- 全程不超过90分钟（宴席）
- 冷菜8分钟内上齐
- 热菜间隔6-8分钟
- 最后一道菜不超过60分钟

## 四、收益管理关键公式

### 4.1 核心公式

```
ADR = 总客房收入 ÷ 已售客房数

OCC = 已售客房数 ÷ 可售客房总数

RevPAR = ADR × OCC = 总客房收入 ÷ 可售客房总数

GOP = 总收入 - 经营成本

GOP率 = GOP ÷ 总收入 × 100%
```

### 4.2 ADR估算（反向推算）

```
从OTA展示价反推真实ADR：

真实ADR = Σ(渠道占比 × 渠道净价格)

渠道净价格 = OTA展示价 × (1 - 佣金率)

折扣率参考:
- 经济型: 80%
- 中端: 75%
- 高端: 70%
- 奢华: 65%
```

### 4.3 OCC估算模型

```
综合入住率 = Σ(信号权重 × 信号OCC) × 0.75 + 基线OCC × 0.25

OTA信号: 占40%权重
微信预订: 占25%权重
官网直销: 占20%权重
市场事件: 占15%权重
```

### 4.4 动态定价参考表

| 入住率区间 | 定价策略 | 调整幅度 |
|-----------|---------|---------|
| 0-40% | 促销价 | -15% ~ -25% |
| 40-60% | 折扣价 | -5% ~ -15% |
| 60-75% | 标准价 | 基准价 |
| 75-90% | 溢价 | +10% ~ +20% |
| 90-100% | 超卖溢价 | +20% ~ +50% |

| 酒店档次 | 人房比 | 管理人员比 | 备注 |
|---------|-------|----------|------|
| 经济型 | 0.15-0.20 | 1:50 | 精简高效 |
| 中端 | 0.20-0.25 | 1:40 | 适度配置 |
| 高端 | 0.30-0.40 | 1:30 | 全服务 |
| 奢华 | 0.50-0.80 | 1:20 | 管家服务 |

**人房比计算**:
```
人房比 = 全员人数 ÷ 总客房数

例: 200间客房，人房比0.20
→ 需要员工 = 200 × 0.20 = 40人
```
