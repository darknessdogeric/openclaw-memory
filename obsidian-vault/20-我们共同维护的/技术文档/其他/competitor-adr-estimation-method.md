# 竞品酒店均价（ADR）估算方法

> 整理时间：2026-04-09
> 来源：行业通用方法 + Eric指导

---

## 方法一：官网直销价 + OTA挂牌价 双重加权法 ✅最精确

### Eric标准流程

```
第一步：收集官网直销价/会员价（PC端 + 移动端）
→ 优先抓取：标准大床房、标准双床房的主力价格
→ 会员价/直销价通常比OTA更低但更真实

第二步：收集携程OTA标准房型挂牌价
→ 去掉：无窗房、促销价、套房、特殊房型（花园/街景等）
→ 只保留：主力标准房型（大床/双床普通版）

第三步：确认各来源权重
→ 官网直销：权重50%（更能反映真实直销能力）
→ OTA挂牌：权重50%（反映OTA渠道价格）
→ 除非官网无价格，则OTA权重提高到70-80%

第四步：分别计算两个均价
→ 官网直销均价 = Σ(官网主力房型价 × 权重)
→ OTA挂牌均价 = Σ(OTA主力挂牌价 × 权重)

第五步：加权平均
→ ADR_估算 = 官网直销均价 × 50% + OTA挂牌均价 × 50%

第六步：（可选）减去佣金
→ 如果是给自家估算：OTA部分 × (1 - 0.135)
→ 如果是竞品对比：直接用加权均值
```

### 房型选择原则

```
必须去掉的：
├─ 无窗房/内窗房
├─ 促销价/特惠价/秒杀价
├─ 套房/观景套房
├─ 花园景/街景等溢价房型
├─ 钟点房/午夜房等特殊时段
└─ 标注"销量No.1"等促销标签的低价房型

必须保留的（主力标准房型）：
├─ 精选大床/双床房
├─ 豪华大床/双床房
├─ 商务房/标准间
└─ 有"精选""豪华""高级"等描述的
```

### 示例计算

```
官网直销价：
├─ 精选大床：¥298（会员价）
└─ 豪华双床：¥358（会员价）
官网均值 = (298 + 358) / 2 = ¥328

OTA挂牌价（精选/豪华主力）：
├─ 精选大床：¥342（挂牌）
├─ 精选双床：¥342（挂牌）
├─ 豪华双床：¥422（挂牌）
├─ 阳光大床：¥422（挂牌）
OTA均值 = ¥382

加权估算：
= 328 × 50% + 382 × 50%
= ¥355

（如果需要减去佣金：355 × 0.865 ≈ ¥307）
```

### 适用场景
- 同时有官网和OTA数据时优先使用
- 比单一来源更接近真实成交价
- 如果官网无法访问或无价格展示，则降级为方法二

## 方法二：OTA挂牌价反推法（降级使用）

### Eric标准流程

```
第一步：收集携程标准房型挂牌价
→ 去掉：无窗房、促销价、套房、特殊房型（花园/街景等）
→ 只保留：主力标准房型（大床/双床普通版）

第二步：确认主力房型权重
→ 基于携程页面显示的"销量No.1"、"好评No.1"
→ 销量高的房型权重更高

第三步：计算加权挂牌价
→ ADR_挂牌 = Σ(房型挂牌价 × 权重)

第四步：减去佣金（自家估算时）
→ 佣金取值：12%-15%中间值 = 13.5%
→ ADR_估算 = ADR_挂牌 × (1 - 0.135)
```

### 适用场景
- 无法获取官网价格时使用
- 快速估算竞品ADR
- 无需对方提供内部数据

## 方法三：APR替代法

### 行业术语

```
ADR：Average Daily Rate，已售客房实际均价（需内部数据）
APR：Average Published Rate，公开挂牌价（可从OTA抓取）
```

### APR作为ADR代理变量的逻辑

> "APR代表的是在特定日期在OTA上公开可预订的平均房价"
> 当无法获取实际ADR时，APR是最佳替代指标

### 关键发现

```
研究来源：Web Scraping for Hotel Economic Trends

结论：
- APR与ADR存在正相关
- 但APR通常高于ADR（因为挂牌价含溢价空间）
- 折扣/促销会拉低实际成交价
- 通过追踪APR时间序列，可以捕捉需求变化趋势
```

## 方法四：OTA动态监控法

### 核心思路

```
不是单点抓取，而是持续追踪

抓取频率：
- 旺季：每天抓1次
- 淡季：每周抓2-3次
- 关注：节假日/展会/周末的价格波动

建立竞品价格数据库：
日期 | 房型A价格 | 房型B价格 | 房型C价格
-----|----------|----------|----------
周一 | xxx | xxx | xxx
周二 | xxx | xxx | xxx
...

用途：
- 发现价格规律（周中vs周末）
- 发现活动定价规律（展会期间涨价）
- 对比自家酒店的价格竞争力
```

### 数据来源优先级

```
1. 携程（最高优先级）
   - 房型最全
   - 价格最真实（大部分客人用携程）
   - 标注"销量No.1"等信号

2. 美团
   - 本地客源占比较高
   - 价格通常略低于携程

3. 去哪儿
   - 聚合多家代理
   - 可以看不同代理的价格差异

4. 飞猪
   - 阿里的酒店资源
   - 价格结构可能不同

5. 官网/直订
   - 直接抓取官方挂牌价
   - 不经过OTA，有参考价值
```

## 方法五：RevPAR反推法（需第三方数据）

### 公式

```
ADR = RevPAR / OCC

如果能获取：
- 竞品商圈的平均RevPAR（来自STR/浩华等报告）
- 或同商圈平均OCC（来自公开数据）

则可以反推ADR
```

### 数据来源

```
STR报告（需付费订阅）
- 中国主要城市每周/每月OCC/ADR数据
- 按星级/商圈细分

浩华年度报告
- 中国酒店行业数据
- OCC/ADR平均值
- 市场展望

国家统计局
- 住宿业经营数据
- 不够细分，但有参考价值
```

## 方法六：类比估算法（无任何数据时）

### 适用场景

```
竞品刚开业，无历史数据
新进入一个商圈
```

### 核心逻辑

```
找到同商圈、同档次酒店的ADR

参考公式：
竞品ADR ≈ (自家ADR) × (竞品房价定位系数)

定位系数：
- 更高档：×1.2-1.5
- 略高档：×1.1-1.2
- 同档：×1.0
- 略低档：×0.85-0.95
- 明显低档：×0.7-0.85
```

### 定位系数参考因素

```
1. 位置
   - 地铁距离（每近100米 +3-5%）
   - 商圈核心度（核心+10-15%）

2. 品牌
   - 国际五星：×1.5-2.0
   - 国内连锁高端：×1.2-1.5
   - 连锁中端：×1.0-1.1
   - 单体精品：×0.9-1.1

3. 设施
   - 新装修（3年内）：×1.1-1.2
   - 有特色设施：+5-10%

4. OTA评分
   - 4.8分以上：×1.05-1.1
   - 4.5分以下：×0.95-1.0
```

## 注意事项

```
1. 携程显示的是"起价"而非成交价
   → 需要确认是否为最低价房型

2. 促销价/会员价不等于实际成交价
   → 去掉异常值

3. 季节性波动大
   → 旺季和淡季的ADR可能差30-50%
   → 建议抓取不同时间点的数据

4. 房间数未知时，各房型权重只能假设
   → 最好能获取房间数数据来验证
```
