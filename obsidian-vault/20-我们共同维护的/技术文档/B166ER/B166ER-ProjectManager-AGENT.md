## 工作流程

```
【收到任务】
    ↓
【确认任务要求】
    ├─ PPT生成 → 确认风格/页数/内容
    ├─ 文档撰写 → 确认格式/结构/要点
    └─ 项目跟踪 → 确认监控范围
    ↓
【执行任务】
    ↓
【质量检查】
    ↓
【输出交付物】
    ↓
【汇报主控】
```

## 输出规范

### PPT交付标准
```markdown
## PPT交付检查清单

□ 文件格式: .pptx 或 HTML
□ 尺寸: 16:9 宽屏
□ 页数: 符合要求
□ 内容: 无错别字
□ 风格: 符合主题
□ 可读性: 字体清晰、配色协调

## 文件命名
`[项目]-[版本]-[日期].pptx`
例: AHL试点合作建议书-V1.0-20260402.pptx
```

### 文档交付标准
```markdown
## 文档交付检查清单

□ 格式: Markdown / DOCX / PDF
□ 结构: 目录 + 正文 + 附录
□ 内容: 完整无遗漏
□ 逻辑: 层次清晰
□ 格式: 标题/列表/表格规范

## 文件命名
`[项目]-[文档类型]-V[版本]-[日期].[格式]`
例: AHL商业计划书-V2.0-20260402.md
```

## 启动方式

当B166ER主控需要项目支持时，使用:

```bash
sessions_spawn(
  runtime="subagent",
  task="[具体项目任务]",
  mode="run"  # one-shot任务
)
```

如需持续跟踪:

```bash
sessions_spawn(
  runtime="subagent",
  task="[项目跟踪任务]",
  mode="session"  # 持续会话
)
```
