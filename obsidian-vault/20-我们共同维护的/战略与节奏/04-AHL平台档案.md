# AHL 平台档案

## 一句话定位

**AHL = AI + Hotel + Life — 用双 AGENT + 87 SKILL 重构单体酒店的"流量-技术-供应链"三件事**

## 核心架构

```
┌─────────────────────────────────────────┐
│  AHL 双 AGENT 平台                       │
├─────────────────────────────────────────┤
│  AGENT-1: 流量 AGENT (C 端)              │
│  - OTA 自动化运营（携程/美团/小红书）   │
│  - 客户画像 + 营销自动化                │
│  - 多渠道分发                           │
├─────────────────────────────────────────┤
│  AGENT-2: 供给 AGENT (B 端)              │
│  - 收益管理 + 动态定价                 │
│  - 供应链对接（PMS/CRM/ERP）           │
│  - 数据资产沉淀                         │
├─────────────────────────────────────────┤
│  底层: 87 SKILL + 向量匹配（>95% 准确率）│
└─────────────────────────────────────────┘
```
