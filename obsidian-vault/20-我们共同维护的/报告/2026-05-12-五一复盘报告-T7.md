## 一、核心摘要

### 关键结论

1. **总量稳健增长，增速在高基数下自然回落**：2026年五一假期全国国内出游**3.25亿人次**（同比+3.6%），出游总花费**1,854.92亿元**（同比+2.9%），总量创新高但增速较2025年五一的高基数明显放缓。

2. **酒店呈现"价稳量弱"格局，RevPAR略低于预期**：五一前4天（5月1-4日）酒店行业RevPAR为**187.33元**（同比-0.9%），ADR为**295.98元**（同比+0.9%），OCC为**63.5%**（同比-1.1个百分点）。核心原因：民航出行大幅低于预期（同比-5.7%），长途客源减少直接拖累住宿需求。

3. **结构分化显著：豪华型逆势修复，一线城市韧性突出**：豪华型酒店RevPAR同比**+3.2%**（去年五一为-9.2%），实现从负增长到正增长的转折；一线城市RevPAR同比**+5.2%**，二线城市承压（-0.4%）。

4. **消费行为深度变迁："特种兵"退潮，"度假式"崛起**：单目的地深度游同比+67%，多城市联游-18%；美团"本地酒店度假"订单量同比+124%，平均入住从1.8晚升至2.6晚；飞猪"仅酒店不含景点"用户占比从23%升至41%。

5. **与T-2预测的关键偏差**：中信证券节前预测RevPAR同比+5%左右，实际-0.9%，偏差主要来自民航客流暴跌（-5.7% vs 预测+5.4%）和供给增速超预期（酒店数量同比+21.5%，客房+6.5%）。

### 7.2 偏差核心归因

**第一层：需求端 — 民航超预期暴跌**

这是本次五一最大的"意外变量"。节前交通运输部预测民航+5.4%，实际-5.74%。原因：
- 中东局势导致国际油价飙升，航空燃油附加费从$99/桶翻倍至$209/桶
- 国际航线取消率从3.6%升至7.4%，特别是日本线断崖式下滑（-55.2%）
- 中低收入客群被高票价挤出航空出行市场
- 航空出行大幅减少 → 长途住宿需求下降 → 直接拖累酒店OCC和RevPAR

**第二层：供给端 — 增速超预期**

- 酒店数量同比+21.5%，远超年初预测
- 客房数同比+6.5%，虽增速从年初+7.4%有所收敛，但仍显著高于需求增速
- 经济型酒店数量+23.7%，供给放量对中低端ADR形成持续压制
- 下沉市场（四线及以下+25.4%）是供给扩张主战场

**第三层：结构性变化 — 消费下沉与时长拉长并存**

- 人均消费微降（-0.7%），说明消费金额增长跟不上人次增长
- 入住时长从1.8晚→2.6晚（+44%），意味着单客间夜量增加但日均消费分散
- 小城游（五线城市人次+9.0%）替代部分一线城市住宿需求，整体ADR被下拉

**第四层：T-2预测方法论反思**

中信节前预测RevPAR+5%的核心假设：
- 间夜量同比+6%~+7%（基于铁路+6.5%/公路+6.5%/航空0%加权）
- ADR延续清明+4.6%~节前+7.1%水平
- OCC基本持平

偏差来源：
1. **航空权重低估**：民航实际-5.7%（预测0%），且航空客群是高端住宿的核心客源
2. **ADR预测过于乐观**：节前预订口径ADR显示+6.1%，但实际落地遭遇供给冲击后被稀释
3. **供给影响的时滞**：节前供给增速从+7.4%降至+6.5%，看似收敛，但新增供给对价格的压制效应有累计效果

### 8.3 服务质量事件

| 事件 | 描述 | 处理 |
|------|------|------|
| **到店无房投诉** | 五一假期首日，澎湃"服务湃"收到大量"到店无房""强制取消"等投诉 | 澎湃联合7大OTA推出24小时快速响应机制，涉事平台、酒店各承担50%房费 |

| **峨眉山推搡猴子事件** | 一男性游客在峨眉山雷洞坪推搡路边进食猴子，引发热议 | 景区列入黑名单并通报 |

> **整体评价**：2026年五一假期服务质量整体好于去年，OTA平台响应机制逐步完善，政府监管力度提升。但"到店无房""不可取消霸王条款"仍是行业顽疾。

### 9.2 暑期策略建议

1. **提前锁定亲子客群**：暑期亲子游客占比将超过60%，亲子房、亲子套餐、研学产品需提前上架
2. **高端酒店继续"保价"**：豪华型ADR修复态势明确，不宜跟风降价
3. **下沉市场酒店抓住窗口**：县域高品质酒店暑期预订热度有望同比增长70%+
4. **关注出入境变化**：日本线若恢复，出境游将分流部分高端客源；若持续低迷，国内替代效应延续
5. **赛事/演唱会营销**："跟着赛事去旅行"已验证，暑期演唱会/体育赛事密集，应提前绑定酒店套餐
6. **Q2整体展望**：Q2 QTD RevPAR+6.7%（vs Q1 +3.1%），复苏态势向好；全年酒店景气位居消费高位

## 十、结论与建议

### 10.1 核心教训

1. **"价稳量弱"新常态已至**：酒店行业从"报复性增长"过渡到"结构性分化"，总量增速放缓但质量升级趋势明确。豪华型酒店的逆势修复（-9.2%→+3.2%）证明：**高品质供给不缺需求**。

2. **民航是酒店行业最大的"蝴蝶翅膀"**：本次五一最大的预测偏差来自民航的意外暴跌。航空客群是高端住宿的核心消费力，酒店行业必须将民航运力/票价/国际航线作为核心前瞻指标。

3. **供给端"量价矛盾"深化**：酒店数量同比+21.5% vs RevPAR-0.9%，说明供给扩张速度远超需求增长。行业已从"增量开发"进入"存量整合"阶段，低端市场将面临淘汰赛。

4. **消费者行为变迁加速**："特种兵"退潮、"度假式"兴起的趋势比预期更快。酒店业需要从"卖房间"转向"卖体验+卖时间"。

### 10.2 策略调整建议

| 维度 | 建议 |
|------|------|
| **定价策略** | 豪华/高端"保价稳收"，中档/经济型"以价换量"需谨慎（价格弹性下降） |
| **产品策略** | 打造"酒店即目的地"产品线：连住套餐、在地体验、亲子研学 |
| **渠道策略** | 深耕OTA+赛事/演唱会等"内容渠道"，布局抖音生活服务等新平台 |
| **区域策略** | 一线城市守住品质溢价，下沉市场抓住县域流量红利 |
| **供给策略** | 控制新增速度，聚焦存量翻牌和品质升级 |
| **风险对冲** | 建立民航运力/票价/国际航线监控体系，提前预判出行结构变化 |
| **暑期备战** | Q2 QTD +6.7%趋势向好，暑期是全年最关键窗口，应提前2个月启动营销 |
