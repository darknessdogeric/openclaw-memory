## Layer 3 · Workflow（链式工作流 = 6+）

> 每个 Workflow = 多个 Skill 串成的端到端流程

### 独立酒店境外市场进入 5 步法

- skill: 市场分析 → 客源国画像 → 渠道搭建 → 内容营销 → KOL 合作
- 用时: 4-6 小时
- 产出: 上线第一个境外订单

### OTA 入驻全流程

- skill: 资料准备 → 提交 → 审核跟进 → 上线 → 评价管理
- 用时: 1-2 周
- 产出: 3 大 OTA 同时上线

### 动态定价日常

- skill: 竞品监控 → 数据分析 → 定价策略 → 节假日调价 → 复盘
- 用时: 每日 30 分钟
- 产出: RevPAR +5-15%

### 内容营销周末

- skill: 选题 → 文案 → 配图 → 发布 → 互动
- 用时: 每周 2 小时
- 产出: 4 篇/月平台内容

### 差评处理紧急

- skill: 预警 → 诊断 → 回应模板 → 升级 SOP → 复盘
- 用时: 4 小时内响应
- 产出: 评分回升 +0.2

### KOL 合作全流程

- skill: 筛选 → 邀约 → 接待 → 内容发布 → 效果评估
- 用时: 2-4 周/次
- 产出: 1 个 KOL = 50+ 订单

### Marketplace 飞轮（v2.0 启动）

- **9 plugins 聚合** = AHL Marketplace v1.0
- **公开 skill 贡献**（第三方开发者可发布）—— 飞轮启动
- **跨酒店业主协作**（A 酒店的好实践 → B 酒店用）
- **行业标准参与**（"零碳酒店"等）
- **第三方开发者生态**（类 npm / pip / 微信小程序市场）
- **商业模式**：订阅 / 增值服务 / 数据 / 行业研究

### 飞轮启动条件

- **月活酒店 ≥ 30 家**（阶段二末期）→ 飞轮启动
- **月活酒店 ≥ 100 家**（阶段三）→ 飞轮规模化
