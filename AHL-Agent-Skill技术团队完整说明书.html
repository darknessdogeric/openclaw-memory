五、SKILL技术实现

5.1 SKILL标准规范

SKILL规范:
  
  元数据:
    id: skill_unique_id          # 唯一标识
    name: SKILL名称              # 显示名称
    version: 版本号               # 语义化版本
    category: 分类                # C端/B端/运营
    description: 功能描述         # 一句话说明
  
  接口定义:
    input_schema:                # 输入参数JSON Schema
      type: object
      properties:
        param1: { type: string, description: 说明 }
      required: [param1]
    
    output_schema:                # 输出结果JSON Schema
      type: object
      properties:
        success: { type: boolean }
        data: { type: object }
        error: { type: string }
  
  执行配置:
    timeout: 30                   # 超时时间(秒)
    retry: 3                      # 重试次数
    async: false                  # 是否异步
    cache: true                   # 是否缓存结果

5.2 SKILL实现示例

from ahl_sdk import Skill, SkillContext

class BookingConsultationSkill(Skill):
    """预订咨询SKILL"""
    
    def __init__(self):
        super().__init__(
            id="booking-consultation",
            name="智能预订咨询",
            version="1.0.0",
            category="guest-service"
        )
    
    async def execute(self, context: SkillContext) -> dict:
        # 1. 解析输入
        check_in = context.get_param("check_in")
        check_out = context.get_param("check_out")
        guests = context.get_param("guests")
        preferences = context.get_param("preferences", {})
        
        # 2. 查询可用房态
        available_rooms = await self.query_availability(
            check_in, check_out, guests
        )
        
        # 3. 智能推荐
        recommendations = self.recommend_rooms(
            available_rooms, preferences
        )
        
        # 4. 返回结果
        return {
            "success": True,
            "data": {
                "recommendations": recommendations
            }
        }
