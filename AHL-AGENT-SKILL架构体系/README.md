### 1.2 核心设计原则

| 原则 | 说明 | 实现方式 |
|------|------|----------|
| **双AGENT起步** | 所有业态都从C端+B端双AGENT开始 | 统一基础架构 |
| **按需扩展** | 根据业务复杂度逐步增加运营AGENT | 模块化设计 |
| **分层递进** | 从简单到复杂，从通用到专业 | 渐进式部署 |
| **SKILL复用** | 基础SKILL跨业态复用 | 标准化接口 |
| **数据驱动** | 基于数据持续优化 | 闭环反馈 |

### 2.2 运营AGENT集群（按业态扩展）

| 业态 | 运营AGENT集群 | AGENT数量 | 说明 |

| **度假酒店** | +康乐/活动 | 6-8个 | 增加体验类AGENT |
| **会议酒店** | +宴会/MICE | 6-8个 | 增加会议类AGENT |
| **康养酒店** | +康养/医疗 | 6-8个 | 增加健康类AGENT |
| **服务公寓** | +长住/企业 | 6-8个 | 增加长住类AGENT |

### 2.3 AGENT协作模式

```
协作场景示例: 客人投诉处理

Step 1: C端AI管家接收投诉
    └─> 情绪分析 + 问题分类

Step 2: 触发运营AGENT协作
    ├─> 前厅服务AGENT: 核实情况
    ├─> 客房管理AGENT: 检查房间
    └─> B端AI运营官: 制定方案

Step 3: 协同响应
    ├─> 即时安抚客人
    ├─> 安排房间调整
    └─> 赠送补偿

Step 4: 闭环跟踪
    └─> 满意度回访 + 改进建议
```

## 三、SKILL体系详解

### 3.1 SKILL分层架构

```
Level 1: 基础SKILL (所有业态通用)
├── C端基础: 预订/入住/服务/向导/问题/评价/语言/社交
└── B端基础: 定价/房态/内容/评价/营销/分析/保洁/供应链

Level 2: 进阶SKILL (精品酒店+)
├── C端进阶: 个性化/文化/社区/场景
└── B端进阶: 细分/会员/品牌/渠道

Level 3: 专业SKILL (商务酒店+)
├── C端专业: 商务通道/会议/交通/生活/报销
└── B端专业: 协议开发/维护/账期/市场/团体

Level 4: 业态专属SKILL (按业态定制)
├── 餐饮: 早餐/套餐/宴会/菜单/成本
├── B2B: 雷达/谈判/TMC/RFP/MICE
├── 康乐: SPA/健身/活动/亲子
├── 会议: 会场/设备/茶歇/接待
└── 康养: 健康/康复/餐饮/活动
```

## 五、实施路线图

```

├── 选择1家精品酒店试点

Phase 4 (Month 7+): 规模化推广
├── 复制到同类型酒店
├── 持续优化迭代
```
