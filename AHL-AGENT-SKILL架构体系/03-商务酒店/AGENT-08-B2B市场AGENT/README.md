# B2B市场AGENT - 商务酒店版

> AGENT名称: B2B Market Agent  
> 适用业态: 商务酒店（80-200间房）  
> 核心定位: 企业客户开发、协议管理、TMC对接的智能助手

### 2.2 SKILL 详细设计

#### SKILL-01: 企业客户雷达

```yaml
基本信息:
  id: corporate-radar
  name: 企业客户雷达
  version: 1.0.0
  category: 客户开发

数据来源:
  - 工商注册信息
  - 招聘网站数据
  - 新闻资讯
  - 展会活动
  - 企业官网
  - 社交媒体

筛选维度:
  基础筛选:
    - 行业类型
    - 企业规模（员工数）
    - 地理位置
    - 成立时间
  
  差旅特征:
    - 招聘频率（出差需求指标）
    - 分支机构数量
    - 业务扩张速度
    - 行业差旅特点
  
  意向信号:
    - 新设办公室
    - 业务扩张
    - 融资新闻
    - 展会参展

决策者识别:
  目标角色:
    - 行政/HR负责人
    - 财务负责人
    - 差旅经理
    - 高管助理
  
  信息来源:
    - LinkedIn
    - 脉脉
    - 企业官网
    - 行业活动

输出结果:
  潜在客户列表:
    - 企业名称
    - 匹配度评分
    - 决策者信息
    - 开发建议
    - 优先级排序

示例:
  企业: 某科技公司
  匹配度: 85%
  理由: 
    - 员工500+，年扩张30%
    - 近期融资，业务扩张
    - 有多个分支机构
  决策者: 张总（行政总监）
  建议: 重点跟进，推荐年度协议
```

#### SKILL-02: 协议谈判支持

```yaml
基本信息:
  id: contract-negotiation
  name: 协议谈判支持
  version: 1.0.0
  category: 协议管理

协议类型:
  固定价格协议:
    - 适用: 稳定需求的大客户
    - 特点: 价格固定，预算可控
  
  阶梯折扣协议:
    - 适用: 成长型企业
    - 特点: 消费越多，折扣越大
  
  年度框架协议:
    - 适用: 长期合作客户
    - 特点: 年度预算，季度评估
  
  项目制协议:
    - 适用: 临时性大项目
    - 特点: 项目周期，专项服务

价格策略:
  基准价格: 门市价
  
  折扣体系:
    - 年度消费 < 10万: 9折
    - 年度消费 10-50万: 8折
    - 年度消费 50-100万: 7折
    - 年度消费 > 100万: 面议
  
  附加条款:
    - 免费升级（视房态）
    - 延迟退房
    - 会议室使用
    - 接送机服务

谈判支持:
  - 客户消费预测
  - 竞品协议对比
  - 盈亏平衡点计算
  - 谈判话术建议
  - 让步策略建议
```
