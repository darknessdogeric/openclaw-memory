# 商务酒店 - AGENT+SKILL 架构方案

> 版本: V1.0  
> 适用业态: 商务酒店、连锁酒店（80-200间房）  
> 核心特征: 双AGENT + 完整运营AGENT集群 + B2B市场AGENT，注重效率和协议客户

---

## 一、架构概览


### 1.2 与精品酒店的核心差异

| 维度 | 精品酒店 | 商务酒店 |
|------|----------|----------|
| **核心客群** | 休闲/体验客 | 商务客（占比60%+） |
| **预订特征** | 散客为主 | 协议客+团体（40%+） |
| **服务重点** | 体验设计 | 效率+标准化 |
| **关键指标** | RevPAR | 协议客户留存率 |
| **新增模块** | - | B2B市场AGENT |
| **SKILL总数** | 48个 | 78个 |

## 二、C端 AI旅行管家（商务客专属）

### 2.1 商务客特征与需求

**核心需求**:
- ⚡ 效率至上 - 快速入住/退房
- 📍 位置便利 - 靠近商务区/交通
- 🏢 商务设施 - 会议室/商务中心
- 🚗 交通服务 - 接送/租车
- 📶 稳定网络 - 高速WiFi/办公支持

### 2.2 SKILL 集群（15个SKILL）

#### 基础SKILL（10个，继承自精品酒店）
1. 智能预订咨询
2. 自助入住引导 → **升级为快速入住**
3. 客房服务响应
4. 本地向导推荐
5. 问题快速处理
6. 退房与评价引导
7. 多语言沟通
8. 社交分享助手
9. 个性化体验设计
10. 场景化服务编排

```yaml
  - 实时房态查询
```

```yaml
  - 航班动态跟踪
```

##### SKILL-14: 商务生活支持
```yaml
名称: business-lifestyle
```
