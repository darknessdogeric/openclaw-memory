# 服务式公寓 - AGENT+SKILL 架构方案

> 版本: V1.0  
> 适用业态: 服务式公寓、企业公寓、长住酒店（100-500间房）  
> 核心特征: 双AGENT + 完整运营集群 + 长住管理AGENT + 企业服务AGENT

---

## 一、架构概览

### 1.1 五层AGENT架构

```
┌─────────────────────────────────────────────────────────────┐
│                    AHL 去中心化平台                          │
└─────────────────────────────────────────────────────────────┘
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
        ▼                     ▼                     ▼
┌───────────────┐    ┌───────────────┐    ┌───────────────────────┐
│  C端AI管家    │    │  B端AI运营官  │    │    运营AGENT集群      │
│  (1个)        │    │  (1个)        │    │  (8个核心)            │
└───────────────┘    └───────────────┘    └───────────────────────┘
        │                     │                     │
        ▼                     ▼                     ▼
┌───────────────┐    ┌───────────────┐    ┌───────────────────────┐
│ 12个SKILL     │    │ 15个SKILL     │    │     64个SKILL         │
│ 长住客服务    │    │ 收益+企业     │    │  长住深度运营         │
└───────────────┘    └───────────────┘    └───────────────────────┘
```

### 1.2 运营AGENT集群（8个）

| AGENT | 核心职责 | 长住特色 |
|-------|----------|----------|
| 前厅服务AGENT | 入住退房、日常服务 | 长住客关系 |
| 客房管理AGENT | 客房品质、定期维护 | 周期性清洁 |
| 销售预订AGENT | 预订转化、协议客户 | 长住协议 |
| 市场营销AGENT | 品牌传播、内容营销 | 长住品牌 |
| 餐饮服务AGENT | 餐饮运营、早餐服务 | 长住套餐 |
| **长住管理AGENT** | 租期管理、续租服务 | **长住核心** |
| **企业服务AGENT** | 企业客户、员工服务 | **B2B核心** |
| 生活服务AGENT | 生活配套、便利服务 | 生活支持 |
