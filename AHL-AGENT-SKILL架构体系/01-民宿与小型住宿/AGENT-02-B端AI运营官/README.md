### 2.2 SKILL 详细设计

#### SKILL-01: 智能动态定价

```yaml
基本信息:
  id: dynamic-pricing
  name: 智能动态定价
  version: 1.0.0
  category: 收益管理

定价模型:
  base_price: 基础价格
    - 根据历史数据计算
    - 考虑房型/设施/位置
  
  demand_factor: 需求系数
    - 预订速度
    - 查询转化率
    - 剩余库存
  
  competition_factor: 竞争系数
    - 竞品价格监控
    - 价格定位策略
  
  event_factor: 事件系数
    - 节假日
    - 当地活动
    - 天气因素
  
  time_factor: 时间系数
    - 提前预订天数
    - 连住优惠
    - 淡旺季

定价策略:
  strategy: 价格策略
    - aggressive: 激进（追求入住率）
    - balanced: 平衡（收益最大化）
    - conservative: 保守（追求ADR）
  
  auto_adjust: 自动调整
    - 每日自动调价
    - 事件触发调价
    - 人工确认后生效（可选）

输出结果:
  recommended_prices: 推荐价格
    - date: 日期
    - price: 价格
    - confidence: 置信度
    - reason: 调价原因
  
  forecast: 收益预测
    - occupancy_forecast: 入住率预测
    - revenue_forecast: 收入预测

示例:
  日期: 2026-03-20 (周六)
  基础价格: ¥298
  需求系数: 1.3 (预订较快)
  竞争系数: 1.1 (竞品涨价)
  事件系数: 1.2 (樱花节)
  推荐价格: ¥298 × 1.3 × 1.1 × 1.2 = ¥512
  置信度: 85%
  原因: "周末+樱花节+需求旺盛"
```

#### SKILL-02: 房态智能管理

```yaml
基本信息:
  id: inventory-management
  name: 房态智能管理
  version: 1.0.0
  category: 房态管理

对接平台:
  - 美团民宿
  - 携程民宿
  - 小猪短租
  - Airbnb
  - 自有小程序

核心功能:
  实时同步:
    - 预订产生 -> 同步关闭所有平台房态
    - 取消预订 -> 同步开放房态
    - 价格调整 -> 同步更新所有平台
  
  超售预警:
    - 监控多平台预订冲突
    - 提前预警超售风险
    - 自动建议关房策略
  
  保留房管理:
    - 设置保留房（维护/自用）
    - 批量关房/开房
    - 节假日特殊策略

冲突解决:
  当发生超售时:
    1. 立即通知房东
    2. 提供解决方案:
       - 协调至同品牌其他房源
       - 升级房型并补偿
       - 协助预订附近同等级房源
    3. 自动补偿客人
    4. 记录并分析原因
```
