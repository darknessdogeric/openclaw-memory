# C端 AI旅行管家 - 民宿版

> AGENT名称: Guest AI Concierge  
> 适用业态: 民宿、小型住宿（10-30间房）  
> 核心定位: 客人的24小时私人旅行助手

---

## 一、AGENT 定位

### 1.1 角色定义

**名称**: C端 AI旅行管家 (Guest AI Concierge)  
**代号**: GAC-H01 (Guest Agent Concierge - Hostel v1)  
**形态**: 微信小程序/网页聊天界面  
**工作时间**: 7×24小时在线

### 1.2 核心职责

```
┌─────────────────────────────────────────┐
│         C端 AI旅行管家职责              │
├─────────────────────────────────────────┤
│                                          │
│  1. 预订阶段                             │
│     ├── 咨询接待与需求挖掘               │
│     ├── 房型推荐与报价                   │
│     └── 预订转化与支付引导               │
│                                          │
│  2. 入住阶段                             │
│     ├── 入住指南发送                     │
│     ├── 导航与位置指引                   │
│     └── 自助入住支持                     │
│                                          │
│  3. 住中阶段                             │
│     ├── 客房服务响应                     │
│     ├── 本地向导推荐                     │
│     └── 问题快速处理                     │
│                                          │
│  4. 退房阶段                             │
│     ├── 退房提醒与流程                   │
```

| 02 | 自助入住引导 | 发送指南、导航、入住支持 | 预订确认后 | P0 |

### 2.2 SKILL 详细设计

#### SKILL-01: 智能预订咨询

```yaml
基本信息:
  id: booking-consultation
  name: 智能预订咨询
  version: 1.0.0
  category: 预订服务
  
输入参数:
  check_in_date: 入住日期 (YYYY-MM-DD)
  check_out_date: 退房日期 (YYYY-MM-DD)
  guest_count: 入住人数
  preferences: 偏好 (可选)
    - room_type: 房型偏好
    - budget: 预算范围
    - special_needs: 特殊需求

输出结果:
  recommendations: 推荐列表
    - room_id: 房间ID
    - room_name: 房间名称
    - price: 价格
    - features: 特色
    - images: 图片
  response: 自然语言回复
  booking_link: 预订链接

执行流程:
  1. 解析客人需求
  2. 查询可用房态
  3. 智能匹配推荐
  4. 生成个性化回复
  5. 提供预订入口

示例对话:
  客人: "下周三入住，2个人，有推荐的房间吗？"
  AGENT: "您好！下周三（3月19日）我们有以下房间可选：
          🏠 温馨大床房 - ¥298/晚
          特点：独立阳台、山景、含早
          
          🏠 家庭套房 - ¥458/晚
          特点：两室一厅、适合2-4人、厨房
          
          请问您更倾向于哪种风格？我可以为您详细介绍。"
```

#### SKILL-02: 自助入住引导

```yaml
基本信息:
  id: self-checkin-guide
  name: 自助入住引导
  version: 1.0.0
  category: 入住服务

触发条件:
  - 预订确认后自动发送
  - 入住当天早上提醒
  - 客人询问入住方式

输出内容:
  welcome_message: 欢迎语
  guide_steps: 入住步骤
    1. 到达导航
    2. 获取门锁密码
    3. 房间位置指引
    4. WiFi密码
    5. 注意事项
  map_link: 地图导航链接
  contact: 紧急联系方式

智能门锁集成:
  - 密码自动生成（6位数字）
  - 入住前2小时生效
  - 退房后自动失效
  - 支持临时密码（访客）
```

#### SKILL-03: 客房服务响应

```yaml
基本信息:
  id: room-service
  name: 客房服务响应
  version: 1.0.0
  category: 住中服务

服务类型:
  supplies: 用品补充
    - 毛巾/浴巾
    - 洗漱用品
    - 矿泉水
    - 茶叶/咖啡
  
  cleaning: 清洁服务
    - 日常打扫
    - 更换床品
    - 深度清洁
  
  maintenance: 维修服务
    - 空调问题
    - 热水问题
    - 网络问题
    - 门锁问题
  
  special: 特殊需求
    - 加床
    - 婴儿床
    - 延迟退房

处理流程:
  1. 接收服务请求
  2. 分类与优先级判断
  3. 通知房东/保洁
  4. 跟踪处理进度
  5. 完成后回访确认
```

#### SKILL-04: 本地向导推荐

```yaml
基本信息:
  id: local-guide

推荐类型:

  restaurants: 餐厅推荐
    - 本地特色
    - 口味偏好
    - 价格区间
    - 排队情况
  
  activities: 活动体验
    - 文化体验
    - 户外活动
    - 亲子活动
    - 夜生活

智能推荐:
  - 基于客人画像
  - 实时天气考虑
  - 当前时间适配

```

#### SKILL-05: 问题快速处理

```yaml
基本信息:
  id: issue-resolution
  name: 问题快速处理
  version: 1.0.0
  category: 客诉处理

问题分级:
  L1-轻微: 用品缺失、小问题
    - 自动补偿（优惠券）
    - 快速解决
  
  L2-一般: 设施故障、服务不满
    - 人工介入
    - 补偿协商
  
  L3-严重: 安全/卫生问题
    - 立即升级
    - 紧急处理
    - 退款/换房

处理原则:
  - 5分钟内响应
  - 情绪安抚优先
  - 快速解决方案
  - 补偿适度大方
```

## 三、技术实现

### 3.1 AGENT 架构

```
┌─────────────────────────────────────────┐
│         C端AI旅行管家架构               │
├─────────────────────────────────────────┤
│                                          │
│  输入层                                   │
│  ├── 文本输入 (聊天消息)                  │
│  ├── 语音输入 (语音转文字)                │
│  └── 事件触发 (预订/入住等)               │
│                                          │
│  理解层                                   │
│  ├── 意图识别 (Intent Classification)     │
│  ├── 实体提取 (NER)                       │

│  └── 上下文管理 (Context Management)      │
│                                          │
│  决策层                                   │
│  ├── SKILL路由 (Skill Router)             │
│  ├── 对话管理 (Dialog Management)         │
│  └── 多轮对话 (Multi-turn Conversation)   │
│                                          │
│  执行层                                   │
│  ├── SKILL调用 (Skill Execution)          │
│  ├── API集成 (PMS/OTA/支付)               │
│  └── 数据查询 (房态/订单/客人)            │
│                                          │
│  输出层                                   │

│                                          │

```
