# 会议酒店 - AGENT+SKILL 架构方案

> 版本: V1.0  
> 适用业态: 会议酒店、会展中心配套酒店（200-500间房）  
> 核心特征: 双AGENT + 完整运营集群 + MICE销售AGENT + 宴会服务AGENT

---

### 1.2 运营AGENT集群（8个）

| AGENT | 核心职责 | 会议特色 |
|-------|----------|----------|
| 前厅服务AGENT | 入住退房、礼宾服务 | 团队入住管理 |
| 客房管理AGENT | 客房品质、批量准备 | 会议房预留 |
| 销售预订AGENT | 散客预订、协议客户 | 会议销售支持 |
| 市场营销AGENT | 品牌传播、内容营销 | 会议案例包装 |
| 餐饮服务AGENT | 餐饮运营、茶歇服务 | 宴会餐饮 |
| **MICE销售AGENT** | 会议销售、方案设计 | **会议核心** |
| **宴会服务AGENT** | 宴会执行、现场协调 | **会议核心** |
| 工程技术AGENT | 会议设备、技术支持 | AV设备管理 |

## 二、C端 AI会议管家

### 2.1 会议客人专属SKILL（4个新增）

#### SKILL-09: 会议日程助手
```yaml
功能: 同步会议日程、提醒、导航
输入: 会议注册信息、个人日程
输出: 个性化日程表、提醒通知、会场导航

服务内容:
  - 会议日程同步
  - 分会场导航
  - 演讲提醒
  - 茶歇/午餐指引
  - 社交活动推荐
```

#### SKILL-10: 商务社交匹配
```yaml
功能: 基于行业/兴趣匹配潜在合作对象
输入: 参会者资料、兴趣标签
输出: 推荐联系人、社交建议

匹配维度:
  - 行业相关性
  - 职位层级
  - 兴趣标签
  - 地理位置
  - 过往互动
```

#### SKILL-11: 会议资料助手
```yaml
功能: 会议资料管理、笔记、分享
功能:
  - 资料下载
  - 智能笔记
  - 重点提取
  - 一键分享
  - 会后回顾
```

#### SKILL-12: 团体服务协调
```yaml
功能: 会议团体服务协调、批量需求处理
服务:
  - 团体入住协调
  - 批量用餐安排
  - 交通协调
  - 特殊需求汇总
```
