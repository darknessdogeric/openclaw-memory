## 四、AnYi 工作的核心引用规范

### 4.1 必须遵守的红线

```
[1] 引用源必须可验证 (公开来源)
    - 上市公司财报 / 公告
    - 官方网站 / 政府文件
    - 权威媒体 / 行业报告
    
[2] 不引用未公开数据
    - 不引用 AnYi 内部财务数据
    - 不引用业内未披露的并购金额
    
[3] 不混入个人项目
    - 一切 AHL / 个人创业方向不进入 AnYi 场景
    - 行业讨论通用化, 不绑定任何具体个人 IP
    
[4] 对标 ≠ 模仿
    - 学习方法论, 不复制模式
    - 找差异点, 不比较绝对值
    - 启发思考, 不照搬执行
```

### 4.2 输出时的引用格式

```
行业引用标准格式:
> 数据来源: [公司名称] [年报/公告] [具体页码或章节]
> 行业判断来源: [机构] [报告名] [日期]

AnYi 内部数据:
> 数据来源: AnYi 内部 [汇报文件 / 财务数据] (本 KB 不引用)
> 具体数据查阅: AnYi-KB 内部资料

不允许:
> "据业内人士透露..." (除非有公开报道)
> "据 AnYi 内部..." (本 KB 不引用)
```
