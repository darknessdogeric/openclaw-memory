# AnYi-KB 调用样例

> **目的**：让 Eric 看到我调用 KB 时的标准格式  
> **效果**：每次调用都按此模板，让 Eric 一眼判断"是否到位"

---

## 📊 调用日志的标准格式

每次我调用 AnYi-KB，都会在回复开头加注：

```
📚 AnYi-KB 调用记录
├─ 触发：Eric [动作] → "[Eric 的话/场景]"
├─ 场景识别：[是会议/汇报/决策/对话 中的哪一种]
├─ 角色定位：[Eric 当前是什么角色]
├─ 调用模块：
│   ├─ [模块1] → [关键提取]
│   ├─ [模块2] → [关键提取]
│   └─ [模块3] → [关键提取]
├─ 群论判断：[不变量/变量]
├─ 博弈论判断：[各方利益]
├─ Eric 视角：[为什么对你重要]
└─ 行动建议：[今天/本周/本月]
```

## 🧪 三个调用样例（让 Eric 看到预期效果）

### 样例 1：Eric 问"花园宾馆 IRR 是不是太低"

```
📚 AnYi-KB 调用记录
├─ 触发：Eric 提问 → "花园宾馆 IRR 是不是太低"
├─ 场景识别：决策辅助（关于 6 大酒店改造的关键数据质疑）
├─ 角色定位：产业发展部负责人 / 战略判断者
├─ 调用模块：
│   ├─ 01_集团基础/旗下酒店清单.md → 花园宾馆画像
│   ├─ 01_集团基础/财务基础.md → 6 大酒店改造投资明细
│   ├─ 06_会议专题/.../关键数据卡片.md → 数字核对
│   └─ 02_战略框架/轻重分离.md → 经营性亏损企业治理路径
├─ 群论判断：
│   - 不变量：6 大酒店改造总投资 4.08 亿（不变）
│   - 变量：IRR 测算假设（投资额/回收期/折现率 可调）
├─ 博弈论判断：
│   - 集团视角：3.6% IRR 可作为"经营性亏损企业治理"样板
│   - 花园视角：可能是改造预算过于乐观（股权/历史负债未充分计入）
│   - 班子视角：第一批 4 个项目中最低，可能引起内部质疑
├─ Eric 视角：
│   - 这是 Eric 入职后的"第一个动笔"机会
│   - IRR 重评不否定集团决策，而是提出"风险预警"
│   - 可作为"专业 + 敢碰硬"形象建立
└─ 行动建议：
    - 本周：调取花园宾馆详细可研报告
    - 本月：形成《花园宾馆 IRR 重评报告》v1.0
    - 入职 0-3 个月：在适当场合提出
```

## 🎯 Eric 怎么判断调用是否到位

### ✅ 调用到位的标志
- 我开头有"📚 AnYi-KB 调用记录"
- 包含场景识别 + 调用模块 + 判断 + 行动
- 不只是事实，还有 Eric 视角
- 主动补全 Eric 没问的关联

### ❌ 调用不到位的标志
- 没看到调用日志（说明我没调用）
- 调用了但没给 Eric 视角
- 调用了但没给行动建议
- 没主动补全关联

### 🟡 Eric 可以反馈
- "这次调用过头了" → 我下次更精准
- "这次没调用到" → 我下次更主动
- "这个判断不对" → 我重新调用 + Eric 反馈优先
- "这个数错了" → 我标注 + 寻找准确来源

## 🔄 持续优化机制

### 我的自反思（每周）
- 我调用 AnYi-KB 的频率合理吗？
- 哪些场景没调用到？
- 哪些调用过度了？
- 哪些知识缺失了？
- Eric 没说但他需要什么？

### Eric 的反馈（随时）
- 直接说："这次好/不好"
- 或者标注："这个数错了" / "这个判断不准"

### 知识库更新（实时）
- 每次 Eric 输入 → 我立即处理
- 每个新会议 → 我建专题
- 每个新人物 → 我建画像
- 每个新数字 → 我核验 + 更新

---

**目标**：让 AnYi-KB 成为 Eric 的**第二大脑**，让 Eric 在每个安逸相关场景下都能**瞬间调用**所需知识 + 判断 + 行动建议。

**承诺**：从下次回复开始，每次涉及安逸，我都会主动调用并标注。
