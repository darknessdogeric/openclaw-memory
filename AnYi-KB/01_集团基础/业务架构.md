# 业务架构 — 1+5

> 来源：十五五规划修订稿"第三章四、轻重分离与平台建设"  
> **核心理念**：重资产平台 + 轻资产平台双轮驱动

---

## 🏗️ 1+5 架构总览

```
安逸酒店集团
    │
    ├── 🏛️ 重资产平台
    │   └─ 统筹管理所有自有酒店资产
    │       - 资产盘活
    │       - 资本运作
    │       - 资产价值释放
    │       - 考核：资产收益率 / 资产保值增值率 / 闲置资产盘活率
    │
    └── 🚀 轻资产平台（5 大事业部）
        ├─ 1️⃣ 政务和城市商务酒店事业部
        ├─ 2️⃣ 文化主题酒店事业部
        ├─ 3️⃣ 文旅度假酒店事业部
        ├─ 4️⃣ 锦江宾馆运营事业部（单店）
        └─ 5️⃣ 金牛宾馆运营事业部（单店）
```

---

## 🏛️ 重资产平台

### 战略使命
- "集团资产安全的**压舱石**"
- "价值提升的**发动机**"

### 管理策略：一资一策

| 资产类型 | 代表酒店 | 处置方式 |
|---------|---------|---------|
| **优质资产** | 金牛、锦江、改造后四川宾馆 | 持有 + 委托专业团队运营 |
| **低效闲置** | 亚丁、梦温泉、天府山庄 | 出租/转让/合作开发 |
| **高负债** | 古尔沟、总府皇冠 | 债务重组 + 融资置换 |

### 能力建设
- 组建具备不动产金融、法律、工程背景的专业团队
- 探索成熟优质资产打包发行**类 REITs**
- 打通"投融建管退"资本闭环

### 与轻资产的协同
- 战略协同：重资产标杆为轻资产输出提供品牌信任状
- 交易协同：轻资产获取内部物业须市场化比价
- 考核协同：重资产考核资产收益率；轻资产考核管理规模/GOP
- 风险隔离：人财物独立；轻资产不承担重资产历史债务

## 🚀 轻资产平台（5 大事业部）

### 1️⃣ 政务和城市商务酒店事业部
- **赛道**：政务 + 城市商务
- **核心品牌**：锦江、金牛、锦著
- **核心任务**：
  - 标准化运营
  - 品牌轻资产输出（主力是锦著 2.0）
- **拓展方向**：四川省内地市州 → 周边省份
- **合作模式**：纯托管 / 品牌授权 / 联合改造 / 合资共建

### 2️⃣ 文化主题酒店事业部
- **赛道**：巴蜀文化主题酒店
- **核心品牌**：四川宾馆、花园宾馆、新良酒店
- **核心任务**：
  - 巴蜀文化主题酒店品牌输出
  - 承接集团 "1+N" 战略项目
  - 一店一品一主题
- **特色**：文化赋能是商业模式的核心，不是点缀

### 3️⃣ 文旅度假酒店事业部
- **赛道**：文旅度假
- **核心品牌**：安逸系列（熊猫/美舍/禅茶/锦秀/山屿/星火/非遗/农庄）
- **核心任务**：
  - 统筹集团内外度假酒店的接管、运营、市场拓展
  - 整合景区资源（彝海、孟获城、牛背山、柳江古镇）
  - 围绕大九寨、大峨眉输出"安逸"品牌
- **特色**：发挥省属国企资源统筹优势

### 4️⃣ 锦江宾馆运营事业部
- **类型**：单店运营事业部
- **核心任务**：锦江宾馆单店品质管控 + 效益提升 + 品牌标杆
- **特殊地位**：国宾双核之一

### 5️⃣ 金牛宾馆运营事业部
- **类型**：单店运营事业部
- **核心任务**：金牛宾馆单店品质管控 + 效益提升 + 品牌标杆
- **特殊地位**：国宾馆最高地标

## 📊 4 步实施路径

### 第一步：轻重分离（2026-2027 前期）
- 完成重资产管理平台与轻资产运营平台的拆分
- 实现人、财、业务权责独立
- 市场化激励机制同步配套到位
- **这是所有后续改革的体制前提**

### 第二步：打造标杆（2026-2028）
- 集中资源完成**六大核心旗舰酒店**的焕新改造
- 沉淀可复制、可盈利的"安逸"产品标准与运营体系
- **这是轻资产输出的能力基础**

### 第三步：品牌运营（2027-2030）
- 各细分赛道品牌实现独立专业化运营
- 统一搭建会员、集采、数字化运营中台
- **这是从单店到集团化作战的能力升级**

### 第四步：标准输出（2028-2030）
- 依托成熟的"安逸"标准与标杆模型
- 整合全省国资存量酒店
- 通过委托管理、品牌授权实现规模化轻资产扩张
- **这是规模与效益双提升的价值实现阶段**

## 🎯 五大事业部的赛马机制

- **独立核算**：每个事业部作为独立业务单元
- **差异化考核**：
  - 盈利企业：利润、营收、GOP、RevPAR、现金流
  - 减亏企业：减亏幅度、成本压降、资产盘活
  - 轻资产平台：管理规模、管理费收入、拓展数量、会员发展
  - 重资产平台：资产收益率、闲置盘活率、资产保值增值率
- **考核结果**：与干部任免、薪酬升降、评优评先、编制调整全面挂钩

## 💼 轻资产平台的核心赋能体系（加盟商视角）

> 这是 1+5 架构给外部加盟商的核心卖点

### 1. 品牌赋能
- 安逸品牌授权及全套 VI 应用规范
- 品牌标准体系及运营手册
- 全国性品牌传播及区域营销支持

### 2. 客源赋能
- **安逸会 600 万+会员体系全域导流**
- 中央预订系统（CRS）直连，目标贡献 35%+ 预订量
- 协议客户及政务客源共享

### 3. 运营赋能
- 派驻经安逸认证的专业店长及核心管理团队
- 标准化 SOP 体系及常态化质量巡检
- **AI 收益管理系统**（动态定价、流量优化）
- 系统化员工培训及人才输送

### 4. 成本赋能
- **安逸购**集采平台（核心物资成本降低 10-15%）
- 共享数字化运营平台（降低 IT 投入）
- 规模化能耗管理方案
