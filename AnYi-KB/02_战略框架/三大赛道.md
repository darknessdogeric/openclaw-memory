# 三大核心赛道

> 来源：十五五规划修订稿"第三章 业务发展规划"  
> **战略**：政务商务 + 文化主题 + 文旅度假 = 安逸的三大支柱

---

## 🎯 总览

| 赛道 | 战略角色 | 核心品牌 | 关键举措 |
|------|---------|---------|---------|
| **政务和城市商务** | 现金流基石 + 品牌信任状 | 金牛 + 锦江 + 锦著 | 标准化扩张 |
| **文化主题酒店** | 差异化核心壁垒 | 四川宾馆 + 花园 + 新良 + 深圳川宾 | 一店一品 + 1+N 企地合作 |
| **文旅度假酒店** | 第二增长曲线 | 安逸 + 8 子品牌 | 整合景区 + "住宿+" |

## 1️⃣ 政务和城市商务酒店赛道 — 基石与标准

### 战略角色
- **集团现金流和品牌信任状的基石**
- **轻资产输出的底气来源**

### 核心载体与定位

#### 金牛宾馆
- **定位**：四川最重要的政务接待**国宾馆**
- **功能**：省级重大专项政务接待、大型会议论坛
- **地位**：集团品牌的最高地标
- **远期愿景**：中国一流国宾馆 + 世界知名文化主题酒店
- **风格**：稳运营，做精做深服务品质，维护品牌高度

#### 锦江宾馆
- **定位**：高端城市商务**全服务型**酒店标杆
- **功能**：政企高层接待、高端商务会务
- **地位**：集团对外展示服务实力的核心窗口
- **特殊**：设有"锦江饭店管理公司"独立运营

#### 锦著 2.0
- **定位**：**中端标准商务连锁酒店**
- **地位**：集团面向地市州进行**轻资产扩张的主力品牌**
- **核心特色**：高性价比、便捷高效、标准统一
- **覆盖**：大众商务出行 + 休闲旅游市场

### 发展策略
- **国宾双核稳基础**：金牛、锦江巩固高端政务商务接待核心优势，持续输出国宾服务标准和运营 SOP
- **锦著 2.0 促扩张**：对标行业头部中端品牌，完成产品模型标准化迭代。建立清晰投资回报测算模型，为加盟商提供"算得过账"的合作方案

### 关键举措
1. 提炼并固化**国宾服务标准手册**，作为对外输出的核心软实力
2. 开发**锦著 2.0 标准化产品手册**（设计规范、投资概算、运营 SOP）
3. 建立城市商务赛道的**专业拓展团队**
4. 以四川省内市场为优先，面向地市州快速复制 → 逐步向周边省份辐射

## 2️⃣ 文化主题酒店赛道 — 差异与灵魂

### 战略角色
- **集团差异化竞争的核心壁垒**
- **安逸品牌价值的最高体现**

### 核心载体与定位

#### 四川宾馆（川宾）— 旗舰
- **定位**：**"百年蜀韵·国宾礼遇"**巴蜀文化主题旗舰店
- **地位**：安逸品牌输出的核心样板
- **功能**：四川城市文旅窗口 + 省级政务商务会客厅
- **差异化路线**：历史复原 + 文化再造 + 场景沉浸
- **改造投资**：6,000 万元 / 156 间客房 / 6.2 年回收期 / 12.50% IRR
- **当前状态**：⚠️ 停业 6 年+（危楼 + 权属三权分离）

#### 花园宾馆 — 标杆
- **定位**：**"巴蜀文化家"**主题酒店标杆
- **核心 IP**：老成都街巷文化 + 川剧艺术
- **改造投资**：2,500 万元 / 168 间客房 / 8.1 年回收期 / **3.60% IRR ⚠️**
- **当前状态**：经营性亏损，推进改造

#### 新良大酒店 — 潮玩
- **定位**：**"潮玩成都 X 新生活"**潮流生活方式酒店
- **核心 IP**：大熊猫国潮 + 新天府青年文化
- **改造投资**：10,000 万元 / 345 间客房 / 7 年回收期 / 7.00% IRR

#### 深圳四川宾馆 — 桥头堡
- **定位**：粤港澳大湾区巴蜀文化精品窗口
- **战略意义**：**安逸品牌跨省输出的"桥头堡"**
- **改造投资**：3,400 万元 / 153 间客房 / 6 年回收期 / 9.20% IRR

### 发展策略：系统化实施"一店一品一主题"

将巴蜀文化深度解构为四大维度：

| 文化维度 | 关键词 | 适配酒店 | 核心场景 |
|---------|--------|---------|---------|
| **经典国宾文脉（礼序）** | 古蜀文明（三星堆/金沙）+ 三苏诗词 + 百年官府川菜 + 国宾礼仪 | 四川宾馆 | 三苏文化长廊 + 荣乐园国宴 + 三星堆文创客房 + 三司官宴 |
| **市井烟火民俗（闲适）** | 老成都街巷 + 盖碗茶馆 + 川剧曲艺 + 非遗手作 | 花园宾馆 | 走马街市井记忆展厅 + 老成都坝坝茶 + 川剧戏台 + 寻味老成都 |
| **先锋国潮新潮（新锐）** | 大熊猫国潮 + 新天府青年文化 + 数字交互文创 | 新良酒店 | X-Lounge + 潮蜀青年房 + 潮玩影音房 + 熊猫亲子房 |
| **自然山水康养（意境）** | 蒙顶山茶 + 青城山道家养生 + 峨眉山禅茶 + 温泉康养 | 华龙、国堰、古尔沟 | 都市慢生活茶空间 + 冰雪温泉康养 |

### 旗舰标杆打造路径（"一号工程"）

1. **历史文化深挖**：建店历史 + 接待历史 + 建筑风貌 + 人文故事 → 品牌志 + 空间故事
2. **空间场景重塑**：顶尖专业设计 + "修旧如旧、风貌保留、功能焕新"
3. **体验内容植入**：复古下午茶 + 老川菜宴席 + 非遗手作 + 年代旅拍
4. **品牌传播破圈**：省市文旅联动 + 新媒体平台 + "四川现象级复古酒店 IP"
5. **标准体系输出**：形成"安逸巴蜀文化主题酒店运营手册" → 向全省国资老旧酒店复制推广

### 1+N 企地合作
- **目标城市**：从四川 21 个地级市中筛选 **5 个核心城市**
- **合作对象**：各市州党政接待中心 + 国资招待所 + 城区核心老旧宾馆
- **模式**：合资或托管门店
- **战略意义**：形成区别于全国连锁酒店的核心竞争力

## 3️⃣ 文旅度假酒店赛道 — 增长与生态

### 战略角色
- **集团发挥省属国企资源统筹优势**
- **培育第二增长曲线**的战略空间

### 核心载体与品牌矩阵

```
安逸（主品牌）
├─ 安逸·熊猫（亲子度假）
├─ 安逸·美舍（景区民宿）
├─ 安逸·禅茶（蒙顶山茶文化）
├─ 安逸·锦秀（温泉康养 - 古尔沟）
├─ 安逸·山屿（高原山地 - 牛背山、318/317）
├─ 安逸·星火（红色文化研学 - 彝海）
├─ 安逸·非遗（非遗文化体验）
└─ 安逸·农庄（乡村振兴农文旅融合）
```

### 发展策略

#### 对内盘活存量
统一承接并运营旅投集团体系内：
- 彝海
- 孟获城
- 牛背山
- 柳江古镇
- 其他景区配套酒店

→ 以专业化运营提升资产收益

#### 对外整合资源
通过 **1+N 企地合作** 模式：
- 围绕**大九寨、大峨眉、大贡嘎**等核心片区
- 输出"安逸"度假品牌与管理
- 与地方政府、国企联合投资开发

#### 打造"住宿+"产品
深度联动：
- 景区
- 研学
- 康养
- 赛事
- 专列（熊猫专列）

→ 提高宾客综合消费和停留时间

## 📊 三大赛道的对比

| 维度 | 政务商务 | 文化主题 | 文旅度假 |
|------|---------|---------|---------|
| **战略角色** | 基石 | 壁垒 | 增长 |
| **核心驱动** | 现金流 | 差异化 | 整合力 |
| **投资密度** | 中 | 高 | 中 |
| **品牌力** | 强（国宾双核）| 强（一店一品）| 中（安逸系列）|
| **扩张路径** | 锦著标准化 | 1+N 企地合作 | 景区资源整合 |
| **盈利模型** | 客房 + 会议 | 文化溢价 + 客房 | "住宿+"综合消费 |
| **Eric 切入点** | 锦著 2.0 标准化 | 文化主题旗舰店打造 | 1+N 企地合作示范 |
