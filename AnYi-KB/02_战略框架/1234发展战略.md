# 1234 发展战略 > 来源：十五五规划修订稿"第二章三、1234 发展战略" > **集团核心战略语言**，Eric 入职后必须熟记并能对外宣讲 --- ## 🎯 战略框架总览 ```
1 条主线（高质量发展） +
2 大品牌价值内核（巴蜀生活美学 + 安逸生活方式） +
3 大核心赛道（政务商务/文化主题/文旅度假） +
4 步实施路径（轻重分离 → 打造标杆 → 品牌运营 → 标准输出）
``` --- ## 1️⃣ 一条发展主线 ### 高质量发展
> "以高质量发展为主线，打造高质量标杆项目，实现有利润的营收、有现金流的利润、有品牌价值的规模。" ### 三个"有"
- **有利润的营收** — 不以规模论英雄
- **有现金流的利润** — 不以账面利润论英雄
- **有品牌价值的规模** — 不以数量论英雄 ### Eric 视角
- 这是集团对"过去粗放发展"的纠偏
- Eric 的所有动作都要扣这"三个有"
- AHL 平台的设计也要对标这三个有 --- ## 2️⃣ 两大品牌价值内核 ### 巴蜀生活美学
- **定位**：文化标签
- **作用**：定义安逸品牌的**文化底蕴与审美格调**
- **内涵**：三星堆/金沙、三苏诗词、川菜、川剧、茶文化、道家养生等
- **落地**：植入酒店改造 + 体验内容 + IP 内容矩阵 ### 安逸生活方式
- **定位**：情感承诺
- **作用**：定义消费者在安逸酒店的**独特体验与心灵感受**
- **内涵**：此心安处是吾乡 → "心"的归属感
- **落地**：服务 SOP + 场景体验 + 故事叙述 ### 二者关系
> 二者共同构成了安逸品牌**不可替代的差异化价值**。 > 文化是骨，生活方式是肉。没有文化的"安逸"是空壳，没有生活方式的"巴蜀"是博物馆。 ### Eric 视角
- 这是与浩华"赋能型总部"不同的差异化路径
- 君亭酒店的成功印证"文化主题 + 中高端"的可行性
- AHL 平台可作为"安逸生活方式"的数字化载体 --- ## 3️⃣ 三大核心赛道 ### 赛道 1：政务和城市商务酒店（基石与标准） | 项目 | 内容 |
|------|------|
| **战略角色** | 现金流和品牌信任状的基石 |
| **核心载体** | 金牛宾馆（国宾馆）+ 锦江宾馆（高端商务）|
| **扩张主力** | **锦著 2.0**（中端标准商务连锁）|
| **核心任务** | 稳定基础营收 + 标准化产品实现规模扩张 |
| **关键举措** | 提炼"国宾服务标准手册" + 锦著 2.0 标准化产品手册 | ### 赛道 2：文化主题酒店（差异与灵魂） | 项目 | 内容 |
|------|------|
| **战略角色** | 差异化竞争的核心壁垒 |
| **核心载体** | 四川宾馆（旗舰）+ 花园宾馆 + 新良酒店 + 深圳川宾 |
| **战略抓手** | **1+N 企地合作** + "一店一品一主题" |
| **文化维度** | 经典国宾文脉 + 市井烟火民俗 + 先锋国潮新潮 + 自然山水康养 |
| **关键举措** | 历史文化深挖 + 空间场景重塑 + 体验内容植入 + 品牌传播破圈 | ### 赛道 3：文旅度假酒店（增长与生态） | 项目 | 内容 |
|------|------|
| **战略角色** | 培育第二增长曲线 |
| **核心载体** | 安逸 + 8 大子品牌 |
| **核心任务** | 整合全省文旅景区资源 + 构建"安逸+"特色度假产品体系 |
| **关键举措** | 对内盘活存量 + 对外整合资源 + 打造"住宿+"产品 | ### Eric 视角
- 三个赛道 = 三个独立的"商业单元"
- 每个赛道有不同的成功指标
- Eric 跨业务板块视野是 3 个赛道的"黏合剂" --- ## 4️⃣ 四步实施路径 ### 第一步：轻重分离（2026-2027 前期） **目标**：完成重资产管理平台与轻资产运营平台的拆分 **关键动作**：
- 实现人、财、业务权责独立
- 市场化激励机制同步配套到位
- **这是所有后续改革的体制前提** **Eric 视角**：第一步走稳，后面才能走快。Eric 入职前期要观察集团是否真正完成分离。 --- ### 第二步：打造标杆（2026-2028） **目标**：集中资源完成六大核心旗舰酒店的焕新改造 **关键动作**：
- 沉淀可复制、可盈利的"安逸"产品标准与运营体系
- 第一批：四川宾馆、花园宾馆、深圳川宾、华龙（1.28 亿）
- 第二批：总府皇冠假日、新良大酒店（2.8 亿）
- **这是轻资产输出的能力基础** **Eric 视角**：第一步"分离"是分，第二步"标杆"是合。先分后合，有分有合。 --- ### 第三步：品牌运营（2027-2030） **目标**：各细分赛道品牌实现独立专业化运营 **关键动作**：
- 统一搭建会员、集采、数字化运营中台
- 各赛道品牌矩阵成型
- **这是从单店到集团化作战的能力升级** **Eric 视角**：第三步是"集团中台"建设的关键期。Eric 的 AHL 可在此刻切入。 --- ### 第四步：标准输出（2028-2030） **目标**：依托成熟的"安逸"标准与标杆模型，整合全省国资存量酒店 **关键动作**：
- 委托管理、品牌授权等模式
- 实现规模化轻资产扩张
- **这是规模与效益双提升的价值实现阶段** **Eric 视角**：第四步是"轻资产输出 200 家"目标的实现期。Eric 入职后 1-2 年正处此阶段。 --- ## 📊 三大战略阶段（时间维度） ```
