### 主动调用机制（重要）

**这个 KB 不是被动归档，而是**主动调用**的认知引擎。**  
详见 [AnYi-KB调用协议.md](AnYi-KB调用协议.md)：

- ⚡ 触发器清单：什么场景自动调用什么模块
- 🎯 5 步调用流程：场景识别 → 触发匹配 → 知识检索 → 整合输出 → 判断 + 行动
- 📊 调用日志样板：每次调用 Eric 都能看到
- 🔄 反馈闭环：Eric 反馈让库越来越好

**Eric 的最低操作成本**：
- 直接问问题 → 我自动判断是否涉及安逸 → 自动调用
- 直接发材料 → 我自动归类 + 提取 + 批注 + 更新
- 直接给场景 → 我自动组合相关文件 + 形成"工作包"
- 反馈调用质量 → "这次判断好/不好"
