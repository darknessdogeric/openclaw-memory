常见失败 1: "形式整合 + 实质分散"
- 多个子集团各自为战
- 总部控制力弱
- 数字化各自搭建，互不联通 常见失败 2: "激进裁员 + 文化崩溃"
- 整合后大裁员
- 员工士气跌
- 服务质量下降 常见失败 3: "财务整合 + 品牌失焦"
- 财务统一管理
- 但品牌定位混乱
- 客户认知模糊 常见失败 4: "硬件改造 + 软件忽略"
- 大规模装修升级
- 但员工培训、SOP、服务忽略
- 硬件提升但体验下降
``` ### 6.2 整合的成功要素 ```
成功要素 1: "一把手工程"
- 集团主要领导亲自抓
- 跨部门协同机制
- 例: 首旅收购如家，潘董事长亲任 成功要素 2: "先易后难"
- 先整合财务、采购、营销、IT
- 再整合人力、运营
- 最后做品牌重组 成功要素 3: "保留子品牌"
- 不要把所有子品牌并成一个
- 用"母公司 + 子品牌" 矩阵
- 例: 锦江 = 锦江国际 + 铂涛 + 维也纳 + 卢浮 成功要素 4: "数字化先行"
- 整合初期就上中央 PMS
- 先统一"数据流"，再统一"业务流"
- 这是 AnYi 的最大机会 成功要素 5: "耐心 + 资金"
- 整合需要 3-5 年
- 国资有耐心 + 资金的双重优势
``` ### 6.3 AnYi 整合的具体动作建议 ```

- 统一财务、采购、营销

- 完成 100+ 家酒店平台化 24-36 月 (第三步整合):

- 开始轻资产输出
