## 1. 客房来向细分 · 10 大渠道

### 1.1 本地协议散客 (Local Corporate & Walk-in Transient)
- **定义**：本地企业签协议价 + 散客上门 (walk-in/front desk)
- **行业代码**：BAR / CORPORATE / LOCAL
- **客户画像**：
  - 本地企业员工 (协议价 600-1200 元/晚)
  - 临时到店散客 (前台价 800-1500 元/晚)
  - 本地居民探亲 (协议价 400-800 元/晚)
- **占比**：20-30% (城市商务酒店) / 10-15% (度假酒店)
- **关键指标**：
  - ADR（已含协议折扣）
  - 入住时长 (LOS)
  - 提前预订 (Lead Time) 0-3 天
- **管理工具**：
  - PMS 协议客档案
  - 散客前台价 BAR (Best Available Rate)
  - 散客与协议价价格梯度 (BAR 5-15% 高于协议价)

### 1.2 OTA（在线旅行社）
- **定义**：通过 Booking/Expedia/Trip.com/Agoda/美团/飞猪 等 OTA 平台
- **行业代码**：OTA / WEB (第三方)
- **平台分类**：
  - **国际 OTA**：Booking.com / Expedia / Agoda / Hotels.com / TripAdvisor
  - **国内 OTA**：携程 / 美团 / 飞猪 / 同程 / 去哪儿 / Trip.com
  - **特色平台**：小红书 / 抖音 (内容种草后 OTA 转化)
- **占比**：20-35% (城市) / 35-45% (度假)
- **关键指标**：
  - OTA 间夜占比 (Booking %)
  - OTA 排名 (Search Ranking)
  - OTA 评论数 + 评分 (4.5+ 为优)
  - OTA 佣金 (15-25% 扣除)
- **管理工具**：
  - Channel Manager (Shiji/Cubilis/SiteMinder)
  - Rate Parity (价格一致性)
  - Review Management
  - OTA 经理对接 (PMS 关联)

### 1.3 TMC 商旅（差旅管理公司）
- **定义**：通过携程商旅 / Amex GBT / CWT / BCD Travel / HRG 等
- **行业代码**：TMC / CONS (Consolidated)
- **客户画像**：
  - 大型外资企业（500 强）
  - 央企国企（差旅统采）
  - 上市公司（财务规范化）
- **占比**：10-20% (高端商务酒店)
- **关键指标**：
  - TMC 协议价 (discount 25-40%)
  - 履约率 (RFP 占房晚比例)
  - TMC 月度报表 (Volume + Revenue)
- **管理工具**：
  - TMC 系统对接 (Sabre/Amadeus API)
  - 月度 Price Loading
  - Quarterly Business Review (QBR)

### 1.4 RFP 差旅采购 (Request For Proposal)
- **定义**：企业通过正式 RFP 流程招标酒店
- **行业代码**：RFP / NEG (Negotiated)
- **类型**：
  - 大型外企总部统采（500 强亚太总部）
  - 国央企年度协议
  - 互联网大厂差旅统采
- **占比**：5-15% (高端)
- **关键指标**：
  - RFP 中标率
  - 协议价深度 (Cost-down %)
  - Volume Commitment (年度保证间夜)
  - 续约率 (Year-over-year)
- **流程**：
  - 1 RFP 发出 → 2 多酒店应标 → 3 谈判 → 4 中标 → 5 协议执行

### 1.5 会议宴会 (MICE/Group Block)
- **定义**：MICE 团/婚宴/会议/活动/团队订房
- **行业代码**：GR / GROUP / MICE
- **客户类型**：
  - 学术会议 (医学会/工程师协会)
  - 企业年会 (公司年会/经销商大会)
  - 婚宴 (婚庆公司协议)
  - 奖励旅游 (Incentive House)
- **占比**：10-25% (全服务) / 5-10% (有限服务)
- **关键指标**：
  - 团体订房数 (Room Nights)
  - 团体 ADR (通常 20-40% 折扣)
  - 总活动收入 (宴会 + 房费 + F&B)
- **管理工具**：
  - 销售总监 (DOSM)
  - 宴会销售 (Catering Sales)
  - Group Booking System
  - Banquet Event Order (BEO)

### 1.6 新媒体 (Social/Digital Direct)
- **定义**：通过抖音/小红书/微信/视频号等 KOL/KOC 获客后直接预订
- **行业代码**：SOCIAL / DIRECT
- **客户类型**：
  - KOL 探店 (头部达人 - 万级间夜)
  - KOC 测评 (中腰部 - 千级间夜)
  - 直播间转化 (酒店自播)
  - 内容种草 (POI 笔记 / 视频)
- **占比**：5-15% (新增渠道)
- **关键指标**：
  - 抖音 / 小红书 5 平台粉丝 + 6 月发布
  - 直播间 GMV / UV
  - 内容转化率
- **管理工具**：
  - 千瓜 (小红书) / 飞瓜 (抖音) 数据
  - 自播团队
  - 私域 + 公域组合

### 1.7 会员忠诚度 (Loyalty/Member)
- **定义**：品牌会员直接通过 APP/小程序/官网预订
- **行业代码**：MEMBER / LOYALTY
- **会员体系**（参照外资头部）：
  - 万豪 Marriott Bonvoy
  - 希尔顿 Hilton Honors
  - IHG Rewards
  - 凯悦 World of Hyatt
  - 华住会
- **占比**：15-25% (成熟酒店)
- **关键指标**：
  - 会员活跃率 (Active Member %)
  - 直接预订占比 (Direct Booking %)
  - 会员 ADR 提升 (10-15% vs BAR)
  - 积分兑换率
- **管理工具**：
  - CRS (Central Reservation System)
  - PMS 会员模块
  - APP 推送 + 个性化
  - 升房/早餐等权益

### 1.8 长住 (Long-Stay / Extended Stay)
- **定义**：月/季/年长租客
- **行业代码**：LONG-STAY / EXTENDED
- **客户类型**：
  - 商务长包 (企业 3-12 月)
  - 医疗长住 (陪护家属)
  - 候鸟养老 (雪鸟/过冬)
  - 装修期 (临时居住)
  - 网红直播基地
- **占比**：5-10%
- **关键指标**：
  - 长住率 (Long-Stay %)
  - 长住客单价 (通常 50-70% BAR 折扣)
  - 长住平均时长 (周/月)
- **管理工具**：
  - 长住协议模板
  - 公寓化管理 (含厨房/洗衣)
  - 月度账单 + 复购

### 1.9 政府采购 (Government/Public Sector)
- **定义**：政府采购中心/协议供应商
- **行业代码**：GOV / PUBLIC
- **客户类型**：
  - 公务员差旅
  - 事业单位培训会议
  - 国央企员工差旅
  - 军警协议酒店
- **占比**：3-8% (政治中心/省会城市)
- **关键指标**：
  - 政府采购中标率
  - 协议价 (按月平均价)
  - 履约率
- **管理工具**：
  - 政府采购网备案
  - 国库支付对接
  - 月度开票

### 1.10 机组车组 (Crew Block)
- **定义**：航空公司机组/船员/铁路乘务员协议酒店
- **行业代码**：CREW / AIRLINE
- **客户类型**：
  - 航空公司机组住宿 (过夜航班机组)
  - 船员协议 (海员/船务)
  - 高铁乘务员 (始发站/终点站酒店)
  - 商务车司机协议
- **占比**：2-5% (机场酒店) / <1% (城市酒店)
- **关键指标**：
  - 机组日均房间数
  - 协议价 (通常 200-500 元/晚)
  - 入住时长 (6-12h/房)
  - 续约率 (年度)
- **管理工具**：
  - 机组协议 (年度 RFP)
  - 24h 前台通道
  - 简餐配送

## 3. 收益管理 (Revenue Management) 视角

### 3.1 收益管理核心要素（5 大杠杆）
1. **价格 (Price)** - 动态定价 (BAR + 协议价分层)
2. **库存 (Inventory)** - 房型 / 长度限制 / 提前预订
3. **渠道 (Channel)** - 渠道分销 / 比例控制
4. **客群 (Customer Mix)** - 高价散客 vs 低价团队
5. **时长 (Length of Stay)** - LOS 控制

### 3.2 收益管理 5 大 KPI
1. **RevPAR** (Revenue per Available Room) - 终极指标
2. **ADR** (Average Daily Rate) - 价格指标
3. **OCC** (Occupancy Rate) - 入住率
4. **TrevPAR** (Total Revenue per Available Room) - 总收入指标
5. **GOPPAR** (Gross Operating Profit per Available Room) - 利润指标

### 3.3 渠道优化优先级（按毛利率）
1. **直接预订** (会员/官网) - 25-30% 毛利率
2. **本地协议散客** - 20-25% 毛利率
3. **TMC 商旅** - 15-20% 毛利率
4. **会议宴会** - 10-15% 毛利率（含 F&B 拉动）
5. **OTA** - 5-10% 毛利率（扣 15-25% 佣金）
