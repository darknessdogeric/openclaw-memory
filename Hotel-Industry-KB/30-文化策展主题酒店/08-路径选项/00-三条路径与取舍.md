# 08 · 三条路径：从"想做文化"到"能算账"

> 本篇是本库的**决策出口**。前七篇给事实，这一篇给选择。
> 原则：不给唯一答案，给三条可执行路径 + 取舍规则 + 退出判据。

---

## 0 · 先划掉三件不该做的事

| 不做 | 为什么 | 证据 |
|---|---|---|
| ❌ 做"贴皮主题"（墙纸/道具/换装拍照） | 3–6 个月新鲜感衰减，无复购、无溢价、无资产 | 中国 2005–2015 泡沫；Viceroy 单一母题 6 年后翻牌 |
| ❌ 自建剧场/自建美术馆 | 客流≠利润，重资产必亏 | 只有河南年客流 1,600–1,800 万，仍年亏 5,500–6,300 万 |
| ❌ 签"无退出条款"的 IP 授权 | 到期即归零，撤牌成本高 | 授权合同必设"去 IP 化降级预案"（见 03 篇 12 问） |

---

## 路径 A · 单店策展化（轻档，L2 → L3）

**一句话**：不新建、不大改，在一家存量酒店里装一条"内容生产线"。

| 项 | 内容 |
|---|---|
| 投入 | 单房 30–80 万（含软装、灯光、少量藏品/借展、首年策展） |
| 规模 | 60–150 房；1 家店起步 |
| 收入结构 | 房费溢价 +12%~+20%；非房收入 30% 左右（导览/工坊/餐饮/零售） |
| 回本 | 12 年（模型：5,000 万投入、ADR 600–900） |
| 组织 | 0.5–1 名策展 FTE + 外部策展顾问（季度制） |
| 时间 | 6–9 个月落地，第 2 年看 KPI |
| 对标 | Ace 的驻留制（把选人外包给画廊主）、Arte Luise（每房一艺术家） |

**关键动作**：
1. 选 1 个**有考据**的母题（不是"川西风"，而是具体到某段地方志/某位匠人/某个工艺谱系）。
2. 设**内容日历**：一年 3 次换展，每次 1 位/组艺术家，预算 15–40 万。
3. 建**付费体验**：导览 ¥80–200、工坊 ¥120–480，住客免费/折扣。
4. 申报 **LB/T 064-2017**（文化主题旅游饭店），把内容换成资质。

**Kill 判据**（12 个月内出现即停）：
- 导览参与率 <20%；
- CPI（对同档竞品 ADR）<1.10；
- 内容更新预算被砍到 0。

## 路径 B · 文化主题产品线（中档，品牌化复制）

**一句话**：把 A 验证过的方法，做成 3–5 家可复制的产品线，中央供内容、单店做在地。

| 项 | 内容 |
|---|---|
| 投入 | 单房 80–200 万；3–5 家店 = 3–8 亿 |
| 规模 | 100–200 房/店 |
| 收入结构 | 房费溢价 +20%~+35%；非房 35%~40%；IP 联名分成 |
| 回本 | 12–20 年（生死线是 ADR 基数：ADR 1,600 需 +49%，2,200 只需 +31%） |
| 组织 | 总部 3–5 人内容中心（策展/登记/教育）+ 单店 1–2 人 |
| 时间 | 2–3 年成型 |
| 对标 | 25hours（先写故事文本再设计）、Hoxton（19 店验证"本地化策展"可规模化）、MGallery（"一店一故事"审查制） |

**关键动作**：
1. **中央内容中心**：统一母题库、艺术家库、授权合同模板、布展标准——这是规模化的真正门槛，不是设计。
2. **单店只做 30% 在地**：70% 由中央供给（控制质量与成本），30% 在地（避免千店一面）。
3. **与 1–2 家馆方签长期框架**（非单项目），拿到优先档期与授权费率。
4. 建立**内容资产台账**：图像库、商标、出版物、联名 SKU——这是未来可授权、可入表的资产。

**Kill 判据**：
- 第 2 家店的 ADR 溢价 <15%（说明不可复制）；
- 单店策展成本占比 >10% 且 IP ROI <1；
- 中央内容中心沦为"设计部"（只做软装，不做展期）。

## 路径 C · 馆店一体旗舰（重档，L4）

**一句话**：与一家强馆共建"可住宿的展馆"，双主体核算，争取政府/基金参与。

| 项 | 内容 |
|---|---|
| 投入 | 单房 200 万+；120–250 房 = 3–6 亿 |
| 收入结构 | 房费 +35%~+60%；门票/导览/零售/活动/赞助/补贴多元 |
| 回本 | 15–20 年，**不能按酒店模型算**（按"酒店 + 小型美术馆"双主体） |
| 组织 | 3–5 FTE（策展/登记/修复/教育）+ 馆方派驻
| 时间 | 3–5 年（含审批与文物合规） |
| 对标 | 21c Museum Hotel（馆藏免费开放 + 驻馆策展人）、AlUla（国家主导 + 国际品牌运营）、奈良监狱（公共遗产转酒店） |

**关键动作**：
1. 选**有强 IP 但尚未落地住宿**的馆方（三星堆、金沙、建川博物馆聚落）——中国目前是空位。
2. 合作结构用"**共创策展**"而非"授权贴牌"：共同署名、共同所有、共同分账。
3. 争取**政府文化基金/文旅专项**参与资本结构（这是重档唯一算得平的方式）。
4. 文物/艺术品合规前置（借展、保险、消防、著作权），见 05 篇。

**Kill 判据**：
- 馆方不愿共担内容成本（只想收授权费）；
- 拿不到非门票的多元收入（赞助/补贴/活动）；
- 文物合规无法闭环。

## 路径 D（可选）· 内容能力外溢

**一句话**：不投资产，把"策展方法论 + 内容供给"做成服务/授权，卖给别的酒店。

- 适用：已有 A/B 跑出可复用方法，且不想再加资产。
- 收入：策展服务费、内容订阅、IP 授权分成。
- 前提：必须先有 1–2 家自营样板，否则无人买单。
- 风险：与主业争资源；国企体制内"对外服务"审批复杂。

## 取舍矩阵：什么条件下选哪条

| 你的条件 | 选 |
|---|---|
| 只有 1 家存量店、预算 <1 亿、要 1 年内见效 | **A** |
| 有 3–5 家店、有品牌部、能养 3–5 人内容团队 | **B** |
| 有政府/基金资源、能拿到强馆合作、能等 3–5 年 | **C** |
| 已跑出样板、想轻资产扩张 | **D** |

**三条通用规则**：
1. **先 A 后 B**：没有单店 KPI 验证，不要谈产品线。
2. **内容成本必须单列**：不能塞进"营销费用"，否则第一个被砍。
3. **每个项目立项时写清 Kill 判据**：什么情况下停，比什么情况下做更重要。

## 一页纸结论

- **最稳的起点是 A**（轻档、单店、12 年回本、可验证）。
- **最大的机会是"馆店一体"空位**（中国尚无成熟样本，先做者定义标准）。
- **最大的坑是自建内容重资产**（只有河南的亏损证明客流不等于利润）。
- **最容易被忽略的成本是内容更新的复利**（5 年累计达初始投入 40%~60%）。
- **唯一不会错的动作是**：把"谁策展、策什么、多久换、谁买单"四个问题写进合同。
