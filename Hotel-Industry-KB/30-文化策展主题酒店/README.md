## 一、先读这七条（全库结论浓缩）

1. **"文化主题酒店"混着三种生意**：① 贴皮装饰 ② 主题叙事 ③ 策展运营。前两种会折旧，只有第三种能沉淀资产。全球 31 个样本里，真正到 L4（共创层）的只有 3 个：Ace、21c、Hard Rock。
2. **全球几乎没有"博物馆直营酒店"**。真实机制只有三类：IP 授权/联名、展演联动（沉浸展+住宿打包）、园区共生。**中国"馆店一体"是空位**——谁先做成可复制旗舰，谁定义标准。
3. **账要这么算**：轻档（30–80 万/房）是唯一纯运营可回本的形态（约 12 年）；中档（80–200 万）的生死线是 ADR 基数（ADR 1,600 需 +49% 溢价，2,200 只需 +31%）；重档（200 万+）不能按酒店模型算，必须"酒店 + 小型美术馆"双主体 + 资产退出。
4. **中国需求真实但结构错配**：博物馆 91% 免费开放、2024 年 14.91 亿人次（+15.4%），而文创销售 +63.7%——**二消增速是客流增速的 4 倍**。馆里人满为患不赚钱，馆外缺"过夜 + 付费"的容器。沉浸酒店民宿细分 2019–2023 增长 **+1,480.1%**，全细分第一。
5. **最大的坑是自建内容重资产**：只有河南年客流 1,600–1,800 万，2024/2025 仍分别亏损 6,282 万 / 5,530 万。**客流 ≠ 利润。**
6. **成都的供给现状是"建筑强、内容弱"**：博舍有画廊但展与客房脱钩；安仁民宿群有客流但无策展方；东郊记忆 1,700 万人次的溢出被全季/亚朵吃掉。缺的不是资产，是内容生产线。
7. **酒店场景拿到的是"提成/管理费"，不是商业地产的"保底+扣点"**——后者在酒店场景**未找到公开合同样本**。可引的两条 A 级条款：义乌海洋酒店大堂吧咖啡按月净销售额**阶梯提成 7%/8%/9%/10%**；兰州瑞岭博雅全权委托**管理费 1%→3%/4%/6.5%** + 经营毛利润率不得低于 21% 对赌。分成基数须写成"点位全部可计收入"（门票只作增量），因为公共艺术大量免费兑票。

## 四、纪律（沿用母库）

1. 每条数据/论断有公开来源，URL + 日期 + 可信度；查不到写"未找到公开数据"。
2. 行业推算一律标 ⚠️假设，并给验证方法；未验证的不许上会。
3. 集团内部数据不进本库（属 anyi-ops-kb）；本库只放公开信息与通用方法论。
4. 一手底稿与整理稿分离：底稿可堆料，整理稿必须可读可决策。
