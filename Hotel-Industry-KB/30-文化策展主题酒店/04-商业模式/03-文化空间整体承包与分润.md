# 04-4 · 文化空间整体承包（Concession）与分润机制

> 依据：00-研究底稿/G1（中国承包业态与分润，263 行/30 来源，含 2 条 A 级招标条款）、G2（国际对标与合同结构，199 行/26 来源）、G3（复合文化空间合规红线，269 行/24 来源）
> 场景：酒店释放大堂/会议室 → 咖啡厅 + 策展空间 → 外部运营商整体承包（展览、主题文化聚会、独立/民间/学生艺术家团队展、拍卖）→ 与酒店分润
> 采集：2026-11-01 · 证据分级 A（政府/招标公示/法规原文）· B（媒体）· C（模板/自述，仅供参考区间）

---

## 0 · 六条结论

1. **这个模式在酒店场景是最优解**：酒店零经营风险（不养人、不压库存、不做品控）、闲置/低效空间变成可计收入单元、内容由专业方持续供给（酒店不必自建策展团队）。
2. **但有一个结构风险必须防**：运营商整体承包后，酒店会退化成"收分成的房东"，**客人与内容被运营商截流**。→ 合同必须保留酒店的三样东西：**客人数据（会员）、内容主线否决权、品牌露出强制条款**。
3. **酒店场景拿到的不是"保底+扣点"，而是"提成/管理费"**。商业地产的保底+扣点条款在酒店场景**未找到公开合同样本**（C 级模板不可作费率承诺依据）。
4. **分成基数不能只有门票**：国际案例显示公共艺术大量免费兑票，基数须写成"**点位全部可计收入**"（餐饮 + 文创零售 + 付费活动 + 场地租赁 + 拍卖佣金），门票只作增量。
5. **推荐结构：两层叠加 + 一个池**——底层整包 concession（MAG 覆盖运营商固定成本，超额分成 + 封顶），上层另做内容采购/共同署名。G1 与 G2 独立得出同一结论。
6. **合规是本模式的第一约束**：拍卖须持牌、收费表演进营业性演出审批体系、酒水若具"酒吧"特征触发未成年人禁入、展陈本身即触发消防设计审查、卖作品要逐件授权且**支付方即个税扣缴义务人**。

## 二 · 分润条款（中国两条 A 级样本）

### 2.1 样本一：义乌海洋酒店 · 大堂吧咖啡（2026-05-22 中标公示，A 级）
- 中标方：**上海星巴克咖啡经营有限公司**
- 条款：**按月净销售额阶梯提成 7% / 8% / 9% / 10%**（<30 万 / 30–50 万 / 50–80 万 / ≥80 万）

### 2.2 样本二：兰州新区瑞岭博雅酒店（寰宇酒店）全权委托运营（2026-08-31 成交公示，A 级）
- 中标方：**成都山禾宴亭餐饮管理有限公司**
- 条款：**管理费 1%**（过渡期，月营收 <200 万不计提、首月完整自然月免收）→ 年营收 3800–4100 万 **3%** / 4100–4600 万 **4%** / >4600 万 **6.5%**
- 对赌：**经营毛利润率不得低于 21%**

### 2.3 四种计提基数（含义完全不同）

| 基数 | 优点 | 风险 | 样本 |
|---|---|---|---|
| 营业收入 Gross | 酒店最易核账 | 成本不透明，酒店让利过多 | 兰州瑞岭博雅 |
| **净销售额**（推荐） | 先扣退券/折扣/第三方扣点，对双方公平 | **"净销售"定义必须写死**（含税？含外卖平台佣金？含兑换券核销？） | 义乌星巴克 |
| 毛利润 | 最贴近真实盈利 | 需审账，争议大 | 兰州反设 21% 下限 |
| 净利润 | 酒店几乎零风险 | 运营商必然做高成本，谈判极难 | 未找到公开样本 |

### 2.4 商业地产的"保底+扣点"（参考区间，**酒店场景无公开样本**）
餐饮美食：扣点 **8%–12%**、免租 45–60 天、年递增 3%–5%；时尚零售：扣点 6%–10%、免租 30–45 天；体验娱乐：纯扣点或低保底、10%–15%、免租 60–90 天。零售/餐饮抽成率常见 **5%–15%**；自然断点＝年基本租金÷抽成率；保底与提成**取其高**是行业标准写法。
> ⚠️ 以上为 C 级模板，不得作为费率承诺依据；**保底、押金、淡季保底、退出转让条款在酒店场景均未找到公开样本。**

## 三 · 国际对标（G2）

### 3.1 唯一可引的硬锚点：丹佛机场 concession（2025，A 级公开文件）
**Starbucks / The Cruise Room**：**MAG 1,015,875 美元 或 16% 餐饮 / 18% 酒水营业额分成，取其高，12 年期**。

### 3.2 其他可引参数
| 参数 | 数值 |
|---|---|
| 委托管理 | base **3%–5% 总收入** + incentive **10%–15% 超门槛 NOI** |
| 住宿类租金 | ≈ 营业额 **22%–28%** |
| 百分比租约 | 毛销售额基数 + 审计权 + 公证销售申报 |
| breakpoint | 自然断点（固定租÷费率）vs 人工断点（利于低基本租） |

### 3.3 一个必须知道的反直觉事实
**国际公开案例几乎全是"酒店买内容"，不是"艺术方分酒店收入"**：Peninsula×V&A（2025）、Cape Cadogan×Montague（展至 2025-03）、罗马 Eden×MOD Creative Group（2024-10~11）、Frieze Seoul×新罗（2024-09）、Oak Bay Beach×Madrona（2024-05）、Marriott Art + Seek。
原因：**公共艺术大量是免费兑票**（承亿亚湾艺术节、三亚艺术驻场计划）。
→ **对本项目的直接含义：酒店要拿到的不是"门票分成"，而是"点位全部可计收入"的分成权。** 这是中国酒店相对公共部门的结构性优势——酒店有餐饮、有零售、有场地、有会员。

### 3.4 G2 的结构建议（与 G1 独立吻合）
**底层整包 concession**（MAG 覆盖布展、保险、值守、安保等固定成本，超额分成 + 封顶 cap）+ **上层另做内容采购或策展顾问费** = 两层叠加，比单靠分润稳。

## 四 · 合规红线（G3，七类）

### 4.1 拍卖（最硬）
| 项 | 依据 | 硬约束 |
|---|---|---|
| 经营许可 | 《拍卖法》第十一、十二条 | 须**省级**拍卖业主管部门审核批准；注册资本 ≥100 万 |
| 文物拍卖 | 同法第十三条 | 注册资本 ≥1,000 万 + **文物拍卖许可证**（《文物保护法》第五十四条） |
| 主持人 | 同法第十四条 | 须**拍卖师主持** |
| 公告 | 同法第四十五至四十七条 | 拍卖日**七日前**公告 |
| 预展 | 同法第四十八条 | **不少于两日** → **档期须预留 ≥3 日** |
| 文物陷阱 | 《文物保护法》第九十条第（五）项 | 知假售假、知假拍假、虚假宣传 → **直接吊证** |

> **合同要求：涉及"拍卖"的场次只能由持牌拍卖企业主办；酒店与运营商只能作为场地与服务方，不得代持、不得以"合作拍卖"名义组织无资质拍卖。**

### 4.2 演出与主题文化聚会
- 收费即入**营业性演出**体系：县级审批 3 日；涉外/港澳台省级 20 日；台湾地区报国务院；材料须演出前 3 日（涉外 20 日）递交。
- 舞台看台另需**演出场所合格证明**。
- ⚠️ **展览开幕、艺术家现场表演、驻唱是否必然构成营业性演出，无公开指引 → 须属地文旅部门书面答复**（本专题最高优先级待核项）。

### 4.3 食品与酒水
- 《食品安全法》第三十五条许可制；**酒店自有证不能覆盖运营商独立主体**（挂靠经营连带）。
- 未成年人：空间若具"酒吧"特征 → 触发**禁入义务**（第五十八条、第一百二十条；5 万以下罚款/吊照）；不具"酒吧"特征 → 至少触发禁售与查验证件（第五十九条）。
- → **设计建议：不做"酒吧"，做"茶室 + 咖啡 + 活动酒水"，从空间形态上规避禁入义务。**

### 4.4 艺术品与学生/民间艺术家作品
- 《著作权法》第十条：展览权须**逐件授权委托书**。
- **支付方即个税扣缴义务人**；**票款不得统一收归酒店再分成**（否则酒店成为代扣主体）。
- 文物或高价艺术品的进出与来源合规（见 4.1）。

### 4.5 场地与消防
- 《消防法》（2021）第五十八条：3 万–30 万元罚款。
- 可复用案例：**室内装修及展陈 EPC 工程已被纳入消防设计审查** → **展陈本身即触发审查**。
- 住宿与经营须**防火墙分隔、独立安全出口**。
- → **释放会议室做展览属改变使用性质，属重大前置审批项，必须排在工期最前面。**

### 4.6 预付与储值
《单用途商业预付卡管理办法（试行）》第二十五、二十六条：预收资金余额上限 **40%**（住宿餐饮/零售）、存管比例 **20%/30%/40%**、终止兑付提前 **30 日**公示、余额不足 100 元收现。

### 4.7 酒店的连带责任与"五分离"防线
《消保法》第三十八条 + 《食品安全法》第五十二条 + 最高法司法解释第八条构成三条连带责任路径。
> **核心防线（五分离）：独立持证 / 独立账户 / 独立品牌 / 独立用工 / 独立票据。** 五项只要有一项没分离，酒店就可能被拖进经营主体的责任里。

## 六 · 十八条国际通行条款（谈判骨架）

| 条款 | 通行要点 | 对本项目的建议 |
|---|---|---|
| Term | 初始 3–10 年 + 续约；concession 可 10 年以上 | 5 年起（内容重建成本高） |
| Breakpoint | 自然点 vs 人工点 | **人工断点 + 低基本租**，下行留运营商、上行留酒店 |
| Percentage rent | 按品类分档 | 至少分四档：餐饮 / 文创零售 / 票务活动 / 场地租赁 |
| Guarantee | MAG 与分成"取高"或"可抵扣" | 写明"取高"还是"可抵扣" |
| Cap | 年度/租期分成上限 | **必设**，防爆款年份被摊薄 |
| Renewal | 行权截止日 + 与业绩门槛挂钩 | 续约绑"上年收入 ≥ MAG×X" |
| Assignment | 转让需酒店书面同意 | 允许转租给品牌方/策展联盟，禁止转给无信用主体 |
| Make-good | 退租恢复原状 | 保留布展基座与强电改造（酒店资产），可拆部分归运营商 |
| Insurance | 公众责任 + 财产 + 展品险；运输 seam to seam | 展品险运营商投保、**酒店为附加被保险人** |
| IP | 展览图像可用于酒店营销/OTA；衍生品版权与分成 | 必须写死，否则营销素材不能用 |
| Exclusivity | 限定同楼层/同品类/同期不得引入竞品 | 排他范围别锁死整店 |
| Termination | 违约 / 指标不达标 / 不可抗力 / 便利终止 | 加"连续 N 月低于 X 分成额"的终止权，30–90 天 notice |
| Curator 权 | 主题由谁定、是否需酒店审批 | **策展人 + 酒店品牌双方提名制，酒店保留否决权（安全/合规）** |
| Reporting | 月/季报表、月结、审计权、公证销售申报 | 与酒店 PMS 对账，票务平台佣金单列 |
| 门票与数据 | 票务系统归属、观众数据归属、隐私 | **观众数据归酒店**，运营商不得二次营销 |
| 拍卖专项 | 资质、鉴定、佣金、保管温湿、税费 | **须单列牌照与合规主体，不得由酒店代持** |
| 安全消防噪音时段 | 布展报批、消防荷载、施工时段、噪音上限 | 与 G3 红线逐条对齐 |
| 五分离 | 持证/账户/品牌/用工/票据独立 | **写进合同附件并作为违约解除事由** |
