# G1 空间整体承包业态与分润（酒店文化策展主题 · 第5轮补充调研）

> 版本：v1.0 ｜ 生成日期：2026-11-01 ｜ 范围：中国为主
> 场景锚点：酒店文创改造 → 释放大堂 + 原会议室 → 「咖啡厅 + 策展空间」复合空间 → 外部运营商整体承包 → 与酒店分润
> 铁律：仅公开来源；每条数字/条款附 URL + 年份；查不到写「⚠️未找到公开数据」

## 0. 调研方法与口径

| 项 | 说明 |
|---|---|
| 调研问题 | 酒店把大堂/原会议室整体交给外部运营商做「咖啡厅+策展空间」，酒店侧能拿到什么合同形态与分成结构 |
| 地理范围 | 中国大陆为主（案例含海南、甘肃、陕西、浙江、湖南、上海、北京、广东、江苏） |
| 证据层级 | A=政府/协会/上市公司公告、招投标公示（可直接引用条款）；B=主流媒体报道（引用数字但标注为报道口径）；C=行业模板文/服务商自述（仅作条款参考区间，不作为谈判基准） |
| 关键发现 | **酒店侧最常见的不是「租金」，而是「提成/管理费」**：国酒店公开采购中直接出现按「月净销售额」阶梯提成（7%→10%）与按「营业收入」阶梯管理费（1%→6.5%）；商业地产场景的「保底+扣点」在酒店场景尚未见到公开合同样本（⚠️未找到公开数据） |
| 证据强度自评 | 业态谱系与分润条款：**中高**（有招投标原始条款）；案例表：**中**（多为媒体报道、缺面积与合同金额）；运营商名单：**中**（官网可查，缺酒店合作对接人）；分润率的市场均值：**低**（仅有模板文区间） |
| 未采用 | 未采用无法定位到具体公司/项目的「行业平均分成率」表述；未见官方原文的一律标注⚠️ |

> ⚠️ 全表口径提示：文中「净销售额」「营业收入」「毛利润」三种计提基数在真实合同中含义不同，务必在条款里写死定义与对账方式（详见 §2.1）。

### 2.3 本项目建议锁死的 8 个条款（据上表反推）

1. **计提基数**：优先「月净销售额」，并附书面定义（是否含税/含配送平台服务费/含兑换券核销）。
2. **阶梯比例**：照抄义乌星巴克式 4 档（7/8/9/10%），或按本项目客流规模下调首档。
3. **保底**：设与装修投入挂钩的**月度保底**（免租期覆盖装修投入回收期），并写「提成与保底**取其高**」。
4. **免租期**：装修免租 60–90 天（消防报建 1–2 个月必须覆盖），起算点写「酒店交付合格之日」；开业爬坡期 3 个月按 50% 计。
5. **淡季缓冲**：把保底拆成「基础保底 + 旺季浮动」，或设「淡季月保底按 50% 触发」的开关。
6. **水电物业**：免租期与保底期内水电/物业照收，但列明**分摊比例与抄表口径**；咖啡机/空调/新风为改造重资产，优先由酒店出装修、运营商出设备。
7. **库存与损耗**：咖啡物料归运营商（品牌方供货），艺术品归艺术家/代理方，衍生品库存双方按分成表分担并约定滞销退场责任；**策展布展道具与安保责任归属必须单列**。
8. **退出**：设置双方解除条件（连续 X 月未达保底、重大安全/消防事故、艺术品权属争议），并约定装修投入的剩余价值处置（酒店优先回购设备）。
