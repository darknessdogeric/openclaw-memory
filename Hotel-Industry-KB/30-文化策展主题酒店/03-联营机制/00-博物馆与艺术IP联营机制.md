# 03 · 博物馆 / 美术馆 / 艺术 IP 与酒店的联营机制

> 更新：2026-10-31 ｜ 状态：v1.0

## 0 · 一句话结论

**全球几乎没有"博物馆直营酒店"的成熟样本。** 真实存在的是三种：**IP 授权/品牌联名**（主题套房、主题层、联名餐饮）、**展演联动**（沉浸式数字展 + 住宿打包）、**园区共生**（博物馆所在文旅小镇自建住宿吃客流）。

护城河最深的不是"借个名字"，而是**数字艺术 IP 的「门票 + 住宿」消费动线**：IP 方赚门票与授权费，酒店赚"最近的床"和打包溢价。酒店不持有 IP，就别幻想靠 IP 长期溢价。

## 1 · 十一类机制速查

| # | 机制 | 合同形态 | 谁出什么 | 风险在谁 |
|---|---|---|---|---|
| 1 | 场地租赁 | 固定租金（按㎡/天或年） | 馆方出空间；酒店出装修运营 | 酒店（客流） |
| 2 | 展览输出 | 项目买断 / 固定策展费 | 馆方出策展展品；酒店出场地安保 | 酒店（票房） |
| 3 | 藏品借展 | 借展协议 + 门到门全险 + 押金 | 馆方出藏品押运；酒店出借展费+全险+恒温安保 | 保险/承运 |
| 4 | 策展人共创 | 顾问费 或 收益分成 | 策展人出内容；酒店出制作场地 | 共担 |
| 5 | 巡展合作 | 固定授权费（+票房分成） | 馆方出母版档期；承办方出场地运营 | 承办方（票房） |
| 6 | 教育研学 | 按人次/课程买断 | 馆方出课程导师；酒店出场地招生 | 酒店（招生） |
| 7 | 票务分成 | 营业额抽成 | 馆方出品牌门票；酒店出渠道打包 | 按比例共担 |
| 8 | 文创联名 | 保底授权金 + 销售额分成 | 馆方出商标图像+监修；酒店出生产库存渠道 | 酒店（库存） |
| 9 | 艺术 IP 授权 | 固定费 / 保底+分账 / 买断 | 同上 | 获授权方（品控侵权） |
| 10 | 影像/数字内容授权 | 门票分成 / 授权费+票务分成 | IP 方出版权技术；酒店出空间设备 | 酒店（票房+技术落地） |
| 11 | 驻留艺术家 | 免租工作室 + 材料费，换作品/现场创作 | 艺术方出人；酒店出空间经费 | 共担（产出不确定） |

**授权金三种算法**（行业通用，可信度中）：
1. **保底 + 分成**：保底金 = 预计保底销售额 × 版权金率（预付，不达预期不退，超出按阶梯补差）；
2. **零保底纯分成**：按实际销售额约 10% 一类费率，月结/季结；
3. **一次性买断**：适合短期单次合作。

> 门槛参考：敦煌研究院要求合作方提交营业执照、产品简介、过往案例、含合作时长/内容/品类的策划方案、资源需求清单，审核后才授权。这就是"正规馆方"的谈判起点。

## 2 · 三种可落地模板（按投入从轻到重）

### 模板 A · 轻授权（主题套房 / 主题层 / 联名餐饮）
- **适用**：已有物业要做差异化，零重资产。
- **合同**：保底授权金 + 客房/餐饮销售额分成（版权金率 **5%–10%** 区间参考）；1–3 年 + 续签。
- **双方**：馆方出商标 + 图像 + 设计监修 + 品控；酒店出改造 + 运营 + 市场。
- **退出**：授权期满不续即退，必须写**品牌审计**与**撤牌条款**（否则撤不掉）。
- **对标**：伦敦自然历史博物馆 × Park Plaza London Riverbank 恐龙家庭套房（英国首间此类套房，2 大 3 小）。

### 模板 B · 联营（数字艺术展 / 巡展 + 住宿打包）
- **适用**：与 teamLab、Van Gogh Alive 类 IP 或巡展主办方共享客流。
- **合同**：门票分成（IP 方）+ 酒店房+票打包；或按营业额抽成；**展期制**。
- **双方**：IP 方出内容版权 + 技术团队 + 门票渠道；酒店出空间设备 + 客房 + 分销。
- **退出**：展期结束即终止，可滚动续展。
- **对标**：广州丽思卡尔顿 × teamLab 套餐（1,800 元起含双早 + 门票 2 张，+400 升剧院景观房）；新加坡滨海湾金沙 ArtScience Museum 的"馆+酒店+商场"一体化。

### 模板 C · 共创策展（驻留 / 共创 / 自持 IP）
- **适用**：度假区/文旅小镇自建"IP 住宿群"，最重、护城河最深。
- **合同**：策展人项目费或收益分成；驻留"免租工作室 + 材料费换作品/现场创作"；长期共建需约定 **IP 归属与退出清算**。
- **对标**：无锡拈花湾 27 家禅意主题客栈 + 1 家高端酒店；阿那亚（沙丘美术馆 + 自持酒店，且已规划入沪：美术馆 + 2 家酒店）。
- **警告**：这条路径的失败率最高——它要求"长期养人"，不是一次性工程。

## 3 · 五个必须提前想清楚的风险

1. **IP 主体混淆**（高频踩坑）：梵高画作属公共领域，但"梵高博物馆"商标/品牌授权独立存在；"Van Gogh Alive"是 Grande Experiences 的商业品牌，**与梵高博物馆无隶属**。签约前必须查清"你签的是谁"。
2. **文物出境与借展合规**：跨境借展要走文物进出境审核 + 展览协议，禁止个人携带/邮寄灰色操作。
3. **地缘政治断约**：阿姆斯特丹冬宫分馆 2022 年因俄乌冲突与母馆切割并更名 H'ART Museum——跨国馆方合作有政治风险。
4. **低质联名反噬 IP**：故宫口红"嫡庶之争"、台北故宫要求专家审查是否"辱没品牌"才可挂双品牌——授权乱象会同时伤害双方。
5. **客流动线打架**：住宿动线（安静、私密、消防疏散）与观展动线（人流、嘈杂、安保）天然冲突，必须物理分区 + 错峰。

## 4 · 谈判前必问的 12 个问题

1. 授权主体是谁？（馆方本体 / 下属公司 / 独家代理 / 冒名第三方）
2. 授权标的到底是什么？（商标 / 图像 / 藏品 / 策展能力 / 数字内容）
3. 是否独家？区域、品类、期限各是什么？
4. 保底金多少、版权金率多少、结算周期与审计权？
5. 设计监修与品控流程谁定？否决权在谁手上？
6. 藏品/展品的保险、押运、温湿度、安保责任怎么分？
7. 内容更新义务在谁？（一年几次展期，谁付布展）
8. 谁负责宣传口径？能否使用"官方合作""馆藏级"表述？（广告法红线）
9. IP 到期后的"去 IP 化"降级方案是什么？撤牌成本谁承担？
10. 衍生产品（文创、数字投影、联名餐饮）是否另需授权？
11. 数据与会员归属？谁可以用这批客人的数据？
12. 争议解决地与适用法律？（跨境合作尤其重要）

## 5 · 中国侧的现状（截至 2026-10）

- **故宫**：2019 年文创营业额约 15 亿元；2025-01 申请"餐饮住宿（43 类）"商标；有官方影像授权通道；**但"故宫酒店"未落地**（"故宫角楼咖啡"是餐饮空间，不是酒店）。
- **三星堆**：文创年销售额破 2 亿元、IP 授权收入破千万元、在售 2,700+ 种；是最成熟的"馆方 IP 商业化"样本。
- **敦煌**：数字素材库（ip.e-dunhuang.com）开放商用授权，与腾讯 5 年战略合作（数字藏经洞、虚拟人"伽瑶"）。
- **陕博**：2024-09 与茶百道联名"丝路奇旅"，33 家主题门店。
- **K11 / UCCA / 阿那亚 / 拈花湾**：不是"博物馆授权"，而是**自持艺术资产 + 自建住宿**——这条路的资产归属更干净，但投入更重。
- **苏州涵舍 = 与苏博联营**：⚠️ 公开来源无法证实，按传闻处理。

> **判断**：中国目前"馆方 IP 授权给酒店"的成熟案例极少，多数是"文旅小镇自建住宿 + 博物馆在隔壁"。这意味着**先发者拿得到稀缺合作位**，但也意味着**没有现成合同模板可抄**。
