## 1. 餐饮来向细分 · 4 大渠道

### 1.1 上门客 (Walk-in / Drop-in)
- **定义**：自然到店 / 路过 / 散步入店客人
- **行业代码**：WALK-IN / DROP-IN
- **客户类型**：
  - 商务散客（酒店住客顺便用餐）
  - 周边写字楼白领 (工作餐)
  - 周边居民 (家庭聚餐)
  - 旅游路过客 (景点旁酒店)
  - 出租车/网约车司机 (餐饮聚集地)
- **占比**：30-40% (城市商务酒店) / 20-30% (度假酒店)
- **关键指标**：
  - 上门客客单价 (人均 80-300 元)
  - 高峰时段占比 (12:00-13:30 / 18:00-20:30 占 60%)
  - 转化率 (门口入座率 70%+)
- **管理工具**：
  - 门迎/迎宾培训
  - 等位系统 (Queue Management)
  - 桌台预订 (Walk-in vs Reservation)
  - 招牌菜引导 (Loss Leader Strategy)

### 1.2 协议客户 (Corporate / B2B F&B)
- **定义**：公司与酒店签月度 / 季度 / 年度餐饮协议
- **行业代码**：CORP F&B / B2B / CONTRACT
- **客户类型**：
  - **公司工作餐协议** - 月度 100-500 人次 (人均 50-150 元)
  - **银行 VIP 客户宴请** - 高端餐厅协议
  - **政府接待** - 公务员定点餐厅
  - **航空公司机组餐** - 简餐配送协议
  - **企业年会/答谢宴** - 一次性大型协议
  - **婚宴协议公司** - 婚庆公司返点
- **占比**：25-35% (高端) / 15-20% (中端)
- **关键指标**：
  - 协议客月均消费额
  - 协议客户数 (Active Contracts)
  - 续约率 (Year-over-year)
  - 月度协议收入
- **管理工具**：
  - 销售经理 (B2B Sales)
  - 协议客户档案 (CRM)
  - 月度账单 (Auto-billing)
  - 专属餐饮顾问

### 1.3 新媒体 (Social / KOL / KOC / Live)
- **定义**：通过抖音/小红书/视频号/微信 等新媒体获客
- **行业代码**：SOCIAL / KOL / LIVE
- **客户类型**：
  - **KOL 探店** (头部达人 - 单次万人到店)
  - **KOC 测评** (中腰部 - 长期口碑)
  - **酒店自播** (抖音/视频号直播)
  - **内容种草** (POI 笔记 / 短视频)
  - **外卖配送** (美团/饿了么品牌店)
- **占比**：10-20% (新增渠道)
- **关键指标**：
  - 抖音/小红书 5 平台内容数
  - 直播间 GMV / UV
  - 内容转化率 (看到-到店-消费)
  - 探店合作 ROI
- **管理工具**：
  - 千瓜 (小红书) / 飞瓜 (抖音)
  - 自播团队
  - 内容矩阵 (KOL + KOC + 自创)
  - 私域转化 (企微 + 社群)

### 1.4 会员 (Member / Loyalty)
- **定义**：酒店品牌会员体系内的客户
- **行业代码**：MEMBER / LOYALTY
- **客户类型**：
  - 储值卡会员 (预存 5000-50000 元享折扣)
  - 积分会员 (消费累积积分换权益)
  - 付费会员 (黑卡/钻石卡 - 年费 1000-5000 元)
  - 联名会员 (银行/航司/电信跨品牌)
  - 私域会员 (企微 1v1 顾问)
- **占比**：20-35% (高端酒店) / 10-15% (中端)
- **关键指标**：
  - 会员活跃率 (Active Member %)
  - 储值卡消耗率
  - 会员复购频次 (F&B 月均到店)
  - 会员 LTV (Life-time Value)
- **管理工具**：
  - CRM + 会员 APP
  - 储值卡系统
  - 积分商城
  - 私域 SCRM (企微 + 社群)

## 2. 餐饮渠道占比对照

| 渠道 | 城市商务 | 度假 | 高端奢华 |
|---|---|---|---|
| 上门客 | 30-40% | 20-30% | 20-30% |
| 协议客户 | 25-35% | 5-10% | 25-35% |
| 新媒体 | 10-20% | 15-25% | 5-10% |
| 会员 | 20-35% | 25-40% | 30-50% |
| 住客附带 | (隐含在 1.1) | (隐含在 1.1) | 隐含 |

> 注：餐饮"住客"占比通常 30-50%，按餐厅类型不同
> 高端酒店会员储值卡 + 协议客户 = 60-80% 收入主力
> 中端酒店上门客 + 协议 = 60-70% 收入主力

## 3. 餐饮渠道优化优先级（按毛利率）

1. **会员储值** - 50-70% 毛利率 (零营销成本)
2. **协议客户** - 35-45% 毛利率 (固定客源)
3. **住客附带** - 30-40% 毛利率 (房费已覆盖固定成本)
4. **新媒体 KOL** - 25-35% 毛利率 (有获客成本)
5. **上门客** - 20-30% 毛利率 (有获客不确定性)
6. **外卖配送** - 15-25% 毛利率 (平台扣 15-25%)
