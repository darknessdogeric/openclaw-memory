## 三、四大分类轴（KB 的认知骨架）

### 轴 1：所有制（Ownership）
```
国家（中央）国资     ── 中国旅游集团、首旅集团（部分）
省市级国资          ── 锦江国际（北京/上海）、岭南集团、广州/各地
省市整合型国资      ── 安逸酒店集团（四川/蜀旅）、各地整合
民营 + 上市公司     ── 华住、亚朵、首旅如家（混合所有制）
民营 + 未上市       ── 东呈、格林、开元（部分转国资）
外资（独资 / 合资） ── 万豪、希尔顿、IHG、雅高、凯悦
混合所有制          ── 锦江卢浮、首旅如家、海航酒店（曾）
```

### 轴 2：业务模式（Business Model）
```
重资产（Owner）       ── 自有产权、自建运营，国资典型
轻资产（Operator）    ── 不持有产权，仅管理输出（管理合同）
特许加盟（Franchise） ── 输出品牌 + 系统，业主自负盈亏
品牌输出（Brand License）─ 仅输出品牌，不派人
混合模式（Hybrid）    ── 部分自营 + 部分管理，国际酒管主流
```

### 轴 3：服务等级（Service Level）
```
超奢华       ── 瑞吉、文华东方、半岛、四季、丽思卡尔顿
奢华         ── 柏悦、嘉佩乐、瑰丽、华尔道夫
高端全服式   ── 万豪、希尔顿、皇冠、喜来登、锦江（高端系）
中端全服式   ── 精选品牌（万豪 Courtyard、雅高 Mercure 等）
中端有限服务 ── 桔子水晶、全季、亚朵（高端）、希岸
经济型       ── 汉庭、如家、7天、锦江之星
超经济       ── OYO（曾）、海友
```

### 轴 4：地理与文化（Geo-Cultural）
```
央企全国布局    ── 首旅、锦江、华住
省级国资区域    ── 安逸（川蜀）、岭南（粤）、金陵（苏）
国际全球网络    ── 万豪、希尔顿、IHG
"国家品牌"模式 ── 中旅、首旅的"代表国家"形象
```

## 四、调用方式

### 主要场景
1. **战略制定**：调 03 + 04 + 05 国资/民营/外资对照
2. **模式选择**：调 02 业务模式 + 财务结构对比
3. **对标研究**：调 08 AnYi 对标 + 跨玩家对比
4. **趋势预判**：调 07 未来 + 06 中国特色变量
5. **历史回顾**：调 01 行业史 + 09 参考文献

### 调用命令（建议）
- `Hotel-KB search "topic"` 
- `Hotel-KB map [国资|民营|外资]`
- `Hotel-KB model [业主|管理|特许|品牌|混合]`
- `Hotel-KB compare 安逸 vs 首旅 vs 锦江`（仅基于公开信息）
