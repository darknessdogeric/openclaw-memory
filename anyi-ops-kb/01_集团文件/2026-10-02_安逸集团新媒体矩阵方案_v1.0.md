## 一、战略定位（解决 3 个问题）

### 1. 我们是谁 → **川渝本地最大酒店集团新媒体矩阵**
- 川渝 17 家自营 + 40-60 家锦江系托管

- 私域（安逸订房 + 安逸集市）：**沉淀+复购**
- 增长极：3 个新业务模型（详 §六）

### 3. 凭什么赢 → **双业务矩阵 + 国企合规 + 川渝本地**

## 五、公域→私域跳转设计

### 5.1 跳转链路总图

```
抖音/小红书内容
    ↓  点击链接
抖音/小红书原生小程序（技术：服务商技术对接）
    ↓  ICP 备案后
逸订房会员小程序 OR 逸享市小程序
    ↓  完成下单
公域平台 + 服务商 + 集团 → 自动分账
    ↓  客户进入
会员体系 + 积分 + 复购触达
```

### 5.2 技术要求

| 项 | 标准 |
|---|---|
| ICP 备案 | 商家独立备案（服务商不碰） |
| 分账 | 资金到商家户头，平台+服务商自动分佣 |
| 跳转 | **不影响小红书分佣**逻辑 |
| 数据 | 集团 + 各单店独立后台可见 |
| 国企合规 | **自有定制系统 + 完整源代码**（满足国资委要求） |

### 5.3 转化路径（按业务）

| 业务 | 公域→私域路径 | KPI |
|---|---|---|
| **酒店预订** | 抖音/小红书 → 安逸订房小程序 → 日历房下单 | CTR→CVR→核销率 |
| **餐饮** | 抖音/小红书 → 安逸订房餐饮 → 套餐 | 套餐销量 + 复购 |
| **逸菁逸逸甄选** | 抖音/小红书 → 安逸集市小程序 → 文创+茶+特产 | 新客率 + 客单价 |
| **会员沉淀** | 公域获取手机号 → 客服 → 加企业微信 → 入会 | 入会率 + 复购率 |
| **拼假/会议/婚宴** | 公域 → 集团号 → 客服 → 私域 → B 端转化 | B 端订单 |

## 六、拉出新的增长极（4 大新业务模型）

### 增长极 1｜**酒店 + 文创 + 川茶（安逸甄选矩阵）**
- **机制**：抖音/小红书内容种草 → 安逸集市下单
- **货品**：四川 21 市州地标 + 八马/天福茶叶供应 + 文创 IP
- **目标**：成为**川渝最大的"住+购"一体化平台**
- **渠道合作**：云南易致（云茶垂直）+ 厦门蓝火焰（茶品牌 IP）+ 八马/天福（直供）
- **预期增量**：酒店客源引流转化率 5%，逸菁逸逸 MAU +200%（年化）

### 增长极 2｜**职人/管家 IP 化（个人 IP 矩阵）**
- **机制**：每店培育 1-2 个"职人"（前厅/管家/厨师），抖音账号 IP 化
- **目标**：让员工从"打工人"变"KOC"，**自带流量**
- **案例参考**：杭州云孚里**职人直播**模式（3 个月陪跑，月销 30 万）
- **预期增量**：**单店职人月均 GMV 10-30 万**，40 家托管门店可贡献 **0.5-1 亿/年**

### 增长极 3｜**B 端（婚宴/会议/团建/包栋）矩阵**
- **机制**：公域抖音/小红书精准定向**B 端决策人**
- **品类**：婚宴/会议/团建/包栋/企业协议/包年
- **案例**：硬石酒店**包栋 + 婚宴 + 会议 + 包年**B 端矩阵
- **目标**：**B 端订单占比从当前 30% 提升到 50%**
- **预期增量**：单店年 B 端营收 +200-500 万（4 钻婚宴+2 中型会议 + 包年）

### 增长极 4｜**会员积分互通 + 数据资产沉淀**
- **机制**：酒店消费积分 ↔ 安逸甄选消费积分（互通）
- **数据资产**：客户消费数据 → 安逸数据中台 → 客户画像精准营销
- **目标**：**单客户年消费额 +30%**（交叉购买）
- **预期增量**：复购率 +20pp；会员活跃度 +40%
