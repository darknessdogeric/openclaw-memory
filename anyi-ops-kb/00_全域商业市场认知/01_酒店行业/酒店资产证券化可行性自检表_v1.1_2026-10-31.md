# 酒店资产证券化可行性自检表 v1.0

> **用法**：从第 0 层往下。**第 0 层一票否决** —— 不满足就不必往下做。
> 每条都标了出处与阈值，**阈值来源已注明是「数据支撑」还是「经验判断」**。

---

## 10 分钟快筛（先过这 5 条）

```
□ 1. 逐资产查：收益年期 = min(土地剩余, 建筑物剩余经济耐用年限)？残值设 0？合同有无「原始权益人无偿受让」？
□ 2. 过去三年一期的经营数据是持续下滑的？
□ 3. 酒店是有限服务还是全服务？餐饮占比高不高？（高 → 净利率被拖）
□ 4. 有没有可核验的竞争组（同城同档次）数据可以对标？
□ 5. 你的资产有什么是别人替代不了的？（没有 → 卖不出溢价）
```

## 第 0 层 · 一票否决项（不满足则不进入下一步）

| # | 检查项 | 判定 | 出处 |
|---|---|---|---|
| 0.1a | **收益年期**怎么定的？ | 是否 = min(土地剩余年限, 建筑物剩余经济耐用年限)？**行业通行「孰短原则」** | v1.8（三份原件：华安锦江 P369、中金开元 P126、汇添富 P317）🟢🟢 |
| 0.1b | **土地到期后的残值假设** | 0（审慎）还是 >0？>0 必须有依据文件 | v1.8 🟢🟢 |
| 0.1c | **基金合同有无「原始权益人（或其指定主体）有权无偿受让不动产资产」条款** | 无 → 土地到期时基金要么提前处置、要么清算 = **裸露风险** | v1.8（中金开元 P125-126 原文）🟢🟢 |
| 0.1d | 若未申请续期或未获批准 | **「土地使用权由国家无偿收回」**——法定结果，不可谈判 | v1.8（华安锦江 P185）🟢🟢 |
| 0.2 | 不动产权证是否完整载明土地信息 | 缺失 → 交易所问询高频命中项 | 华安锦江问询（招募书 P17 风险揭示自列）|
| 0.3 | 规划用途与实际用途是否一致；有无临时改用途/临时建筑 | 不一致且临期 → 红灯 | 中金开元问询（温州场地临时改用途 2028 年到期）|
| 0.4 | 食品经营许可/卫生许可/特行许可/消防开业检有效期 | 过期或临期 → 需展期安排 | 华安锦江问询回复 P39 |
| 0.5 | 近三年一期经营数据是否持续下滑 | 下滑 → **预测期首年将被设为零增长** | 戴德梁行报告 P88（引交易所审核关注事项）|
| 0.6 | 历史现金流不足的资产是否已计入 | 若历史经营数据下滑，估值天花板已被锁死 | 同上 |

> **0.1 系列是最重要的一组**：它不是按基金算，是**按单个资产算**。
>
> 中金开元旅业同基金三资产：杭州（2005 年竣工、土地 2043 年到期）收益年期 17.99 年；
> 温州（2022 年、2057 年）31.82 年；嵊州（2022 年、2059 年）33.85 年。
> **收益年期被截到土地到期，所以「土地短」= 估值期短、终值归零、cap 偏高。**
>
> ⚠️ **v1.1 修订说明**：v1.0 的判据是「缺口 = 基金存续期 − 土地剩余年限，> 10 年 = 红灯」。
> **该判据已被 v1.8 推翻** —— 缺口本身不是风险（收益年期已截断，估值里没有那一段），
> 真正的判据是 **0.1c 有没有「无偿受让」条款**。
>
> **★ 修订后的核心认知：**
> 土地年限决定的不是 Cap rate，也不是风险溢价，而是
> **「你能把这段资产合法持有多久、这段现金流的终点在哪」**。

## 第 1 层 · 数据语言（能不能被估值、被对标）

| # | 检查项 | 合格线 |
|---|---|---|
| 1.1 | 有没有 USALI 口径的**三年一期**真实经营数据 | 有，且可追溯 |
| 1.2 | 能否划出**竞争组**（同城、同档次、同类型）| 能，否则比较法失效 |
| 1.3 | 有没有**时间序列**（改造前后 / 周期对比）| 有，否则无法证明改善 |
| 1.4 | 能否拆清各部门收入占比（客房 / 餐饮 / 其他 / 对外出租）| 能。**餐饮占比高是净利率的敌人** |
| 1.5 | 能否说明**收入构成**与客房收入的联动关系 | 若餐饮非同比例联动，须用「绝对值+年度涨幅」测算（已有项目改用此法）|

> **为什么这一层排第 1**：没有可对标的数据语言，资产只能靠故事定价，
> 而故事定价在交易所问询里是站不住的。

## 第 2 层 · 消费者语言（能不能卖出溢价）

| # | 事实 | 含义 |
|---|---|---|
| 2.1 | **评分每变动 0.1 分 → 酒店年营收波动 5%–10%**（华客数据研究院 + 中国饭店协会）| 中文市场，评分是**主战场**不是锦上添花 |
| 2.2 | 5 分制 **+1 分 → ADR +11.2%**（康奈尔酒店学院 + 华客《体验管理的 ROI》）| 同向验证 |
| 2.3 | **80%** Z世代/年轻千禧愿为**独特体验**付溢价；60%+ 投资者视独特性为投资关键 | **溢价来自独特性，不是等级** |
| 2.4 | 行政星级 / 集团档位线 **不产生溢价** | 当门槛与谈判筹码，不当卖点 |
| 2.5 | 渠道标签（携程特牌/金牌等）随平台政策波动 | 当仪表盘看，不当身份 |

**自检**：你的**独特性**一句话能说清吗？当前评分多少？

## 第 3 层 · 定价层（真正的战场）

> **关键实证（v1.2，华安锦江 21 个底层资产实测）**：

```
预测现金流年复合增长率  vs  Cap rate    r = -0.9217   r^2 = 0.8495   ★★ 极强
折现率                 vs  Cap rate    r = +0.4323   r^2 = 0.1869   中等
剩余土地年限           vs  Cap rate    r = +0.2404   r^2 = 0.0578   几乎无（且反号）
评估增值率             vs  Cap rate    r = -0.0147                  几乎无
```

**→ 能动的杠杆只有一个：现金流假设。**

| # | 检查项 | 做法 |
|---|---|---|
| 3.1 | 预测现金流年复合增长率 | **最该争取的谈判点**。历史低基数 + 可验证的改善路径，比压折现率有效得多 |
| 3.2 | 折现率 | 按**城市层级**分档（华安锦江实测：5.50% 一线 / 6.00% / 6.25% / 6.50% / 6.75%），非逐资产拍 |
| 3.3 | 长期增长率 | **别在这使劲**（弹性仅 0.30，是现金流弹性的 1/3.3）|
| 3.4 | 资本化率落点 | 市场坐标：REITs 口径 4.6%–8.7%；大宗交易口径一线 5.70–6.90% / 二线 6.80–7.80%。**两套不可直接比** |
| 3.5 | 改造投入与收益分配 | 改造期算不算现金流、恢复期怎么计租，要提前写进合同 |

## 第 4 层 · 成本与结构（决定分派率）

| 项 | 费率 | 谈判要点 |
|---|---|---|
| 基本管理费 | 总收入 **1.5%–2.5%**（中位 2%）| 可设上限；与许可费可博弈取其一 |
| 奖励管理费 | GOP/AGOP **4%–8%** 阶梯（≤20%→4%，≥50%→8%）| **争取「未达预设 GOP 不支付」** —— 2013 年后新项目已常见 |
| 品牌许可费 | 总收入 **0.5%–1%** 或 客房收入 **3%–5%** | 可设封顶 |
| FF&E 储备金 | 总收入 **1%→2%→3%→第4年起 4%** | 进现金流测算 |
| **餐饮部门利润率** | **仅 15%–25%，且不因档次改变** | **餐饮规模 ≠ 利润**。改造预算应向客房与体验倾斜，不要堆餐饮 |
| 未分配经营开支 | 档次越高占比越高（后台全、人房比高、公共面积大、能源高）| 高档改造要预留这部分 |

## 第 5 层 · 现金流可持续性（穿透 vs 整租）

| 模式 | 机制 | 适合 | 风险 |
|---|---|---|---|
| **穿透** | 项目公司直接取得经营收入与成本，保留经营成果 | 想分享经营改善、且有监督与预算管控能力的业主 | 承担全部经营波动 |
| **整租（固定租金）** | 承租方付固定租金，经营风险归承租方 | 要可预测性 | 收入与房价/入住率脱钩；承租方持续经营能力是前提 |
| **整租（收入分成）** | 固定租金 + 收入分成 | 兼顾可预测与改善分享 | 需明确计租范围 |
| **整租（利润分成）** | 与 GOP/AGOP 挂钩 | 深度绑定 | **成本上升会同时压低业主租金**，需清晰费用定义 |

**自检**：改造期的收租方式、恢复期收益分配，写进合同了吗？业主承担的税费/保险/资本性支出清单？

## 第 6 层 · 退出与对冲（缺口型的唯一出路）

| # | 检查项 | 说明 |
|---|---|---|
| 6.1 | **残值假设是否为 0** | 行业通行「审慎原则」：土地到期后残值设为 0（华安锦江 P369、中金开元 P126）。>0 需有依据 |
| 6.1b | **有无「原始权益人无偿受让」条款** | **这是缺口型资产的真正兜底**（中金开元 P125-126）。无此条 = 裸露 |
| 6.2 | 原始权益人补足承诺**可执行**吗 | 国资背景 / 信用 / 历史兑付记录 |
| 6.3 | 是否按发改委要求「**应予说明**」土地剩余期限短于存续期的情况 | 有披露义务，**不是禁止** |
| 6.3b | **续期/残值补偿的收益归谁** | 原件：「如未来项目公司因建筑物残值获得补偿或土地使用权续期后价值有所提升，前述可能获得的收益归属于投资人所有」（华安锦江 P185）—— 上行期权归投资人 |
| 6.4 | 是否已启动续期申请 | 复星项目已把「提前启动土地使用权续期申请」写入应对措施 |
| 6.5 | 续期不成如何处置 | 清算 / 提前处置 / 资产包转让 / 扩募换资产 |
| 6.6 | 续期成本（补缴土地出让金）由谁承担、计哪个科目、是否进分派测算 | 逐项确认 |
| 6.7 | 「存续期届满可延长」条款是否明确 | 几乎所有 REITs 都有，是缺口的兜底，但兜底也需份额持有人大会表决 |

## ★ 使用纪律（本次研判血泪换来的）

```
1. 引用任何外部报告前，先查作者是不是数据/估值的出具方。
   （本次发现：报告作者 = 4/4 只在审酒店的评估机构 → 是执业观点，不是独立研究）

2. 任何数字都要带口径：分派率给「年份+口径名称+测算基准」；
   资本化率给「首个完整年度+是否加回资本性支出」。
   （同一基金同一年度出现过 4 个分派率读数）

3. 用二手数据构造的判断（尤其反例），必须回原件验证后才能写进结论。
   （本次 v1.3 的「最强反例」因一个未核对的数据点而完全不成立，v1.7 已撤回）

4. 阈值要标明是「数据支撑」还是「经验判断」。
   （本次红线阈值 10 年 = 经验判断，未见监管硬性规定）

5. 谈相关之前先看解释变量的变异度；分清跨项目与项目内。
```

## ★ 样本边界（v1.1 附 · 引用必读）

> 0.1a（孰短原则）与 0.1b（残值=0）**仅在 2/6 只酒店 REITs + 1 只基础设施 REITs 的原件中验证成立**
> （华安锦江、中金开元旅业、汇添富上海地产）。
> 对 华泰紫金华住安住 / 广发海珠城发 / 中金中国绿发 / 国联安复星，**请当作待验证的行业惯例**。
> 
> **0.1c（原始权益人无偿受让权）仍是最有区分度的筛子** —— 它逐基金真实不同，
> 且直接决定「土地到期时基金会不会因资产消失而受损」。
