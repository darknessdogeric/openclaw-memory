## 四、三个可直接使用的估值判据（报告最值钱的部分）

### 判据 1｜土地剩余年限 是酒店 REITs 的第一红线

```
样本平均剩余土地使用年限：25.5 年

极端值：
  杭州开元名都        17.7 年  → 资本化率 8.7%（全部项目最高）
  广州天河美居/全季   ~19 年   → 资本化率 7.2%（一线城市最高）
  济南贵和洲际       (最长)   → 资本化率 5.7%

外部核验补强：华住安住广州项目土地使用权 2045 年到期，
              而基金存续期 32 年 —— 土地年限短于基金存续期
              （锦江项目则与基金 25 年存续期匹配）
```
**→ 可执行判据：土地剩余年限 vs 基金存续期，缺口越大，资本化率越高、估值越被压制。**

## 五、最容易误读的一段（必须记住）

> 报告数据：一线城市交易总额占比 63%(2023) → 55%(2024) → 41%(2025) → **25%(2026.1-7)**；
> 新一线 17% → 18% → 37%；二线 3% → 14% → 22%。

**表面读法**：「投资重心向新一线、二线下沉，是下沉机会」。

**报告自己给出的真相（更该被引用）**：
> 「二线高星级酒店交易的增长，**并非投资热度的提升**，而是受本地商务、消费承载力有限的影响，
> 经营回报不及一线、新一线同类型酒店，**在企业债务压力下集中进入转让、司法拍卖通道**」

**→ 结论：这是「不良处置外溢」，不是「下沉机会」。**
交易总额整体：231.11 亿(2023) → 168.71 亿(2024) → 263.40 亿(2025) → 151.04 亿(2026.1-7)，
单宗均价 5.14 → 3.75 → 3.14 → 2.32 亿元，**持续下滑**。
**量升价跌 + 法拍占比高 = 卖方市场，不是买方市场。**

## 六、对业主/运营方的实操参数（可直接用）

| 费用项 | 计取方式 |
|---|---|
| 基本管理费 | 总收入或经调整总收入的 **1.5%~2.5%**，中位数 **2%** |
| 奖励管理费 | GOP/AGOP 的 **4%~8%**，阶梯：≤20%→4%；20–30%→5%；30–40%→6%；40–50%→7%；≥50%→8% |
| 奖励管理费趋势 | 2000–2013 年开业酒店中位数 6%~8%；**2013 年后开业费率下降，部分项目在未达预设 GOP 时不再支付**（业主谈判主动权提升）|
| 品牌许可费 | 总收入/经调整总收入的 **0.5%~1%**，或客房收入的 **3%~5%** |
| FF&E 储备金 | 总收入：第 1 年 1% → 第 2 年 2% → 第 3 年 3% → **第 4 年及以后 4%** |
| 餐饮部门利润率 | 仅 **15%~25%**，**且不因酒店档次而改变** → 餐饮规模 ≠ 利润 |
| 客房部门利润率 | 高于餐饮；**客房收入占比越高，净利率越高** |
| 未分配经营开支 | 档次越高占比越高（后台全、人房比高、公共面积大、能源高）|

**→ 对改造项目的直接含义：餐饮配套越重，越拉低净收益率；改造时应把预算向客房与体验倾斜，而非堆餐饮。**

## 七、报告给出的三个申报/估值现实（对拟证券化者最要紧）

1. **历史经营数据本身就是估值天花板**：收益预测以「项目近三年一期实际运营数据」为基础；
   **若历史经营数据持续下滑，预测期首年将被设为零增长**。
2. **折现率调整远不如现金流改善有效**：
   > 「折现率、长期增长率等参数调整对估值的影响幅度，**远不及实际经营现金流改善的提升作用显著**」
   → 想抬估值，先修经营，别去谈折现率。
3. **餐饮收入不能按固定比例推算**：部分项目已改用「绝对值叠加年度合理涨幅」测算。

## 十、核心论断的复算结果（v1.1 新增 · 2026-10-31 21:45 追加）

> **触发**：v1.0 把「资本化率与土地剩余年限负相关」标为 🟠（方法上站不住：n=1 基金、因果未分离）。
> 本节用**公开一手文件**（各项目招募书 / 申报稿 / 交易所问询回复）补齐逐资产土地年限，**对该论断做实质复算**。

### 10.1 补齐后的逐资产数据

| 资产 | 土地剩余年限 | 资本化率 | 一手来源 |
|---|---|---|---|
| 杭州开元名都大酒店 | **17.7 年** | **8.7%** | 报告封卷稿 |
| 广州天河美居 & 全季（华住安住）| 土地使用权 **2045 年到期** | 7.2% | 报告封卷稿 + 深交所问询回复 |
| 华安锦江 21 个锦江都城 | **约 23–25 年** | 平均 **5.9%**（预测）| 招募书 / 华泰固收研报 |
| **三亚海棠湾亚特兰蒂斯** | 2054 年到期，**剩余不足 30 年** | **4.6%**（2026）/ 4.96%（2027）/ 5.66%（2028）| 申报材料 |
| 济南贵和洲际酒店 | **40.20 年**（基准日 2026）| 5.7% | 绿发商业 REIT 问询回复 |

### 10.2 复算结论：方向成立，但被严重混淆，且存在决定性反例

按土地年限升序排列：

```
17.7 年    杭州开元名都        -> 8.7%
约 19 年   广州美居 & 全季     -> 7.2%
23–25 年   华安锦江 21 个      -> 5.9%
不足 30 年  三亚亚特兰蒂斯      -> 4.6%   <-- 反例
40.2 年    济南贵和洲际        -> 5.7%
```

**⚠️ 三亚是决定性反例**：土地剩余年限（不足 30 年）**比华安锦江的 23–25 年还短**，
但资本化率 **4.6% 是全样本最低**。若土地年限是主导因子，它应在 8% 以上。

**原因（报告自己给出）**：三亚亚特兰蒂斯是**国内稀缺的滨海文旅度假地标 + 业态高度多样化**
（酒店 + 水世界 + 水族馆），现金流质量与资产稀缺性**压过了土地年限**。

### 10.3 三条混淆因素（因果无法分离）

| # | 混淆 | 证据 |
|---|---|---|
| 1 | **土地年限 与 城市层级 高度共线** | 越下沉的城市土地年限普遍越短、风险溢价要求也越高 → 两因子同向，无法分离 |
| 2 | **土地年限 与 资产稀缺性 反向** | 三亚：土地短但资产不可替代 → cap rate 最低。**土地短 ≠ cap rate 高** |
| 3 | **cap rate 与 现金流质量 / 业态结构 共线** | 亚特兰蒂斯含乐园与水族馆，收入多元；其 cap rate 2026→2028 逐年上升（4.61%→4.96%→5.66%），来自**预测期现金流假设变化**而非土地年限 |

### 10.4 报告内部的表述张力（未解释）

> P62：「同一基金产品项下，布局于新一线与二线城市的同类型酒店资产，
> 在**风险收益定价层面具备较强的趋同性**」——即**同产品内个体差异被抹平**；

### 10.6 修正后的可操作判据（替代 v1.0 判据 1）

```

  闸 1 · 现金流质量与资产不可替代性
         -> 不可替代的资产，土地短也能拿到低 cap rate（三亚 4.6%）
         -> 可替代的普通中端资产，土地短 = 双重扣分

         -> 一线 5.70-6.90% / 二线 6.80-7.80%（大宗交易口径）

  闸 3 · 土地剩余年限（修正项，非主项）

  闸 4 · 业态结构（是否为单一客房收入）
         -> 亚特兰蒂斯：酒店+乐园+水族馆，收入多元 -> 现金流更稳 -> cap rate 更低
```

### 12.4 三条决定性结论

**结论 1｜报告的「负相关」在项目内部不成立，且方向相反**

> 项目内剩余土地年限与 Cap rate 的相关为 **+0.24（弱正）**，分组均值 **5.70% / 5.49% / 5.89% 非单调**。
> **土地年限对项目内部定价没有解释力。**

**结论 2｜土地年限的效应被制度性吸收了**

> 剩余土地年限 23.00–25.23 年，**收益年限被直接设定为 23/24/25 年，与之几乎一一对应**。

> 所以项目内根本观察不到土地效应。**这不是数据问题，是该基金的结构设计。**

**结论 3｜Cap rate 实际由两个「人为设定」的参数决定**

> **预测现金流年复合增长率（r = −0.92，r² = 0.85）** —— 一个强主变量；

### 12.5 ★ 修正后的核心命题（替代 v1.0 / v1.1 的判据 1）

> **土地年限决定的不是 Cap rate，而是「这个项目能不能做」。**

```
土地剩余年限 = 立项门槛 / 否决项（不可谈判）
   -> 硬红线：土地年限 < 基金存续期 -> 续期不确定性，必须进风险揭示

      实证：杭州开元名都 17.7 年，Cap 8.7%（全样本最高）—— 门槛挡住了它

Cap rate = 谈判出来的（两个可谈判参数）
   -> 预测现金流年复合增长率（r^2 = 0.85）  <-- 真正的战场
   -> 折现率（r = +0.43，且按城市层级分档）

因此：过了红线之后，估值谈判的战场是【现金流假设】，不是【土地】。
      而现金流假设是发行人自己写、评估师认可、监管审的 —— 谈判空间在这里。
```

### 14.2 ★★★ 新发现：存续期不是随意的 —— 它暴露了发起人的真实判断

把 6 只基金按「存续期 vs 土地年限」分成两类，规律极其清晰：

```
【类型 A · 贴合型】存续期 ≈ 土地年限
  华安锦江      25 年  vs  23.0-25.2 年土地
  广发海珠城发   22 年  vs  21.0 年土地
  -> 发起人对底层土地有把握，存续期是按土地实际能用的时长设的

【类型 B · 缺口型】存续期 >> 土地年限
  中金开元旅业    34 年  vs  17.7-18.0 年土地     缺口 16 年
  华泰紫金华住安住  32 年  vs  19.0 年土地(广州)   缺口 13 年
  国联安复星      39 年  vs  28 年土地           缺口 11 年
  -> 存续期被显著拉长，意味着估值隐含了「到期后仍可续期或仍有残值」的假设
```

**为什么把存续期设得比土地长？** REITs 的定价逻辑是「到期时的资产残值 + 期间现金流」，
**存续期越长，等于在募集时对土地续期/残值下了更乐观的注**。

**佐证**：国联安复星在申报文件的风险应对措施中明确写有「**提前启动土地使用权续期申请**」，
且特别提示三亚项目「面临土地到期问题、淡旺季波动以及渠道依赖等风险」——
**发起人自己知道土地到期是核心风险。**

### 15.2 ★★ 制度性缓释机制：缺口型基金能存在的结构性原因

华安锦江《上市交易公告书》P5 原文：

> 「存续期限自基金合同初始生效日之日起 **25 年**，本基金在此期间内封闭运作
> 并在符合规定的情形下在上交所上市交易。**存续期届满前，经基金份额持有人大会
> 决议通过，本基金可延长存续期**。否则，本基金终止运作并清算，
> 无需召开基金份额持有人大会。」

**→ 这条条款是全部「缺口型」基金（开元 16 年 / 华住广州 13 年 / 复星 11 年）
在结构上得以成立的制度出口。**

### 15.3 缺口的正确含义（重定义）

```
缺口 = 基金存续期内，底层土地法律基础不确定的那段年份

  华安锦江   土地 23-25 年 / 基金 25 年
             -> 第 23-25 年土地到期，与基金终止几乎同步     缺口 ≈ 0（干净）

  中金开元旅业 土地 17.7-18.0 年 / 基金 34 年
             -> 第 18 年土地到期，第 18-34 年这 16 年
                现金流的法律基础依赖「续期谈判 + 份额持有人大会延长存续期」

  结论：缺口不是「估值高估」，而是「现金流法律确定性的年限缺口」。
```

```

  【黄】缺口 3–10 年   需在风险揭示中看到续期安排
```

## 十六、v1.6 · 缺口型资产的先例与制度依据（2026-10-31 22:10 追加）

> **触发**：v1.5 留下的问题 —— 缺口型基金能不能过会。除了制度条款，**市场有没有先例**？
> 结论：有，而且先例的解法**比我原先设想的更具体**。

### 16.1 ★★★ 先例：江月路项目（基础设施 REITs）

> 土地剩余 **50.68 年** < 基金存续期 **65 年** → **缺口 14.3 年**

**与中金开元旅业的缺口（16 年）几乎同量级。**
→ **缺口型不是中金开元的特例，是行业已存在的结构。**

**该先例给出的解法（关键，我原先没有）：**
> 「若政策支持明确或**原始权益人承诺补足残值差额**，则将**建筑物残值纳入估值**」

```
缺口型资产的定价解法不是「假设续期一定成功」，而是：

  建筑物残值（可确定的终值）  +  原始权益人差额补足承诺（把风险接回原股东）

=> 这把体检表从「风险分级」升级为「风险 + 对冲结构」。
   光看缺口不够，必须同时看：有没有这个结构。
```

### 16.2 ★ 制度依据：发改委的「应予说明」义务

| 层级 | 规定 | 含义 |
|---|---|---|
| 发改委 | 基础设施 REITs **特许经营权/租赁期限上限 20 年**；**「若项目公司土地剩余期限短于基金存续期，相关情况应予说明」** | **不是禁止，是强制披露义务** |
| 交易所 | 中金开元旅业**问询直接命中土地到期**：「土地使用权将在未来 **17 到 34 年**内到期，对 REITs 未来现金流、估值、融资成本构成重大风险」「续期挑战包括**可能的高额土地出让金**、以及**未来政府土地续期政策的不确定性**」；另命中「温州部分场地**临时改用途权限将于 2028 年到期**」| **监管真在审这条，不是形式审查** |
| 地方 | **广州已落地首宗商业用地续期**（按公开土地价格收费、允许提前申请）；但**全国续期框架仍碎片化**，各地费用与程序不统一 | 续期在地方层面正在制度化，但**不能假定全国通行** |

**→ 这正面印证了 v1.5 的结论：未见「不得短于土地年限」的硬性禁止，但存在「必须说明」的强制义务。**
**→ 我的体检表方向正确：** 缺口的处理方式就是**显性化**，这恰好是监管要求的动作。

### 16.3 ★ 红线体检表 v1.6（终版：加第 2 步「对冲结构核查」）

```

第 3 步 · 口径核对
```

```
  土地年限影响 Cap rate / 土地年限是定价因子

原件证明的：
  土地年限决定的是【估值能测多长的边界】，不是【价格水平】

  土地 17.99 年  ->  现金流只测 17.99 年  ->  20 年后资产在估值里等于 0
  土地 33.85 年  ->  现金流只测 33.85 年

  => 土地越短，你的估值期越短、终值越近；
     土地越短，cap rate 就越可能偏高（因为近端现金流占比更大、终值贡献为 0）
     —— 这解释了为什么 <20 年段 cap 显著更高（6.56-8.15%），
        而 >20 年段 cap 无规律（4.61-5.90%）。
```

> **★ 这把 v1.7 的「阈值效应」从统计现象升级成了机制解释：**
> **土地年限 < 20 年不是「风险高所以要加价」，而是「估值期短、终值归零，所以 cap rate 自然高」。**

### 18.3 ★★ 撤回 v1.6 §16.1 中的一句表述

```
v1.6 写法（撤回）：
  「建筑物残值 + 原始权益人补足差额承诺」  <-- "补足差额承诺" 在三份原件中均未找到

原件中的实际机制（三条）：
  1. 残值设为 0（审慎原则）
  2. 原始权益人（或其指定主体）有权【无偿受让】不动产资产
     —— 中金开元 P125-126 原文
  3. 若未来因建筑物残值获得补偿或土地使用权续期后价值提升，
     【前述可能获得的收益归属于投资人所有】 —— 华安锦江 P185 原文
```

> **★★ 这三条合起来，是一个「不对称的期权结构」——比我原先写的强得多：**

```
下行：土地到期 -> 残值 0（已封在估值里）
     且原始权益人有权无偿受让资产 -> 基金不会因「资产被抽走」受损

上行：续期成功 / 建筑物残值补偿 -> 收益归投资人

=> 投资人拿到的是一个【下行已被封住、上行归自己】的期权。
   这不是「风险敞口」，这是被刻意设计出来的结构。
```

### 18.4 ★★ 红线体检表判据的再修订（v1.8 终版）

> **v1.4–v1.7 的判据「缺口 = 基金存续期 − 土地剩余年限，> 10 年 = 红灯」需要推翻重写。**
> 因为：**缺口本身不是风险** —— 收益年期已被截到土地到期，估值里根本没有那一段。

```
第 0 层 · 改成三个必查项（而非一个缺口阈值）

□ A. 收益年期怎么定的？
     查评估报告「收益年期」—— 是否 = min(土地剩余年限, 建筑物剩余经济耐用年限)？
     若是「孰短原则」下的取值 -> 土地到期已被作为估值终点显性处理
     若收益年期 < 土地剩余年限 -> 有额外保守假设，需问清依据

□ B. 土地到期后的残值假设是多少？
     0（审慎）还是 >0？>0 必须有明确依据与依据文件

□ C. 基金合同里有没有「原始权益人（或其指定主体）有权【无偿受让】不动产资产」条款？
     有 -> 土地到期时资产有人收回，基金不因资产消失而受损（缺口已被兜住）
     无 -> 土地到期时基金要么提前处置、要么清算 = 裸露风险

★ 补充必查：若土地使用权到期未申请续期或未获批准 -> 「土地使用权由国家无偿收回」
  （华安锦江 P185 原文）这是法定结果，不是可谈判项

第 6 层 · 对冲结构核查（改写）
  □ 残值假设 = 0 且有原始权益人无偿受让权 -> 下行已封住
  □ 续期/残值补偿的收益是否归投资人（上行期权）
  □ 是否按发改委要求「应予说明」土地剩余期限短于存续期的情况
  □ 续期不成时：清算 / 提前处置 / 资产包转让 / 扩募换资产
  □ 续期成本（补缴土地出让金）由谁承担、计哪个科目、是否进分派测算
```

### 18.6 ★★★ 修订后的核心命题（v1.8 终版）

```
土地年限决定的不是 Cap rate，也不是「风险溢价」，
而是【你能把这段资产合法持有多久、以及这段现金流的终点在哪】。

  收益年期 = min(土地剩余, 建筑物剩余经济耐用年限)   <- 孰短原则
  土地到期残值 = 0                                     <- 审慎原则
  上行（续期/残值补偿）归投资人                        <- 不对称期权

所以：
  - 要【加价】 -> 去谈现金流假设（r^2 = 0.85），不是去谈土地
  - 要【控风险】-> 去查无偿受让权 + 续期安排 + 资质展期，不是去算缺口年数
  - 要【选资产】-> 看收益年期与经营期的匹配度（短债长投是最贵的错配）
```
