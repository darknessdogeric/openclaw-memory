> 🎯 **核心判断 1：成都高端酒店业正从"高速成长期"切换到"存量博弈期"**
> - 需求端（人次 +11.8%、收入 +14.2%）和盈利端（RevPAR 仅 +3.8%）**明显背离**
> - 意味着：**新增供给无法通过"量增"消化，必须靠"价升+坪效"**
> - 传统"客房售卖"模式触及天花板 → **投资回报逻辑从房价拉升转向空间坪效与场景变现能力**

## 2. 成都三 Scale 市场分层现状（2026）

### 2.1 LUXURY（奢华/顶奢）· 成都极稀缺
| 指标 | 值 |
|------|-----|
| 核心已开业顶奢/奢华 | 瑰丽、尼依格罗、瑞吉、富力丽思、香格里拉、群光君悦、茂业 JW、万达瑞华 |
| **春熙路-太古里商圈** | **≥12 家**国际奢华及高端酒店（STR 2025 Q1） |
| **商圈 ADR** | **¥1,280** |
| **商圈 OCC** | **76.3%** |
| **商圈 RevPAR** | **¥977** |
| 全国奢华基准（2026 Q1） | ADR ¥985 / OCC 72.3% / RevPAR ¥712 |
| **成都 vs 全国** | **成都核心商圈跑赢全国**（RevPAR +37%） |
| **在建/已签约** | 丽晶（2026-07-15 签约，2029 Q3 开业，180 间，224m）；Sofitel 太和已开 |
| **待落位空位** | **LXR、Conrad、Park Hyatt、Mandarin Oriental、Rosewood(已开)、半岛** |

> 🎯 **核心判断 2：LUXURY 在成都核心商圈仍有结构性空位**
> - 春熙路-太古里虽然有 12 家，但**没有一个"西南首店级"的顶奢**（瑰丽/尼依格罗是"区域高端"，非"顶奢"）
> - **丽晶 2029 Q3 开业将填补顶奢空位** → 届时市场溢价将被重新定价
> - **窗口期判断：2027-2028 是抢位窗口，2029 后进入残酷竞争**

### 2.2 UPPER SCALE（上奢/高端全服务）· 竞争最激烈
| 指标 | 值 |

| 展示价区间 | ¥850-1,457 |

> - **同档位内卷的唯一差异化是"设计"和"文化"**，不是品牌名

| 5 | **客房面积（均 15.8 ㎡）是硬天花板——超高奢（瑰丽/尼依格罗档）基本不可行** | 单房 60-100K 美元 + 45-80 ㎡ 客房要求 |
