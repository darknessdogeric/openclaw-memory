## 2. 阶段 × 维度 全明细（对应 P02–P13 每张图）

### P01 · 机会研判与改造模式拍板（M0–M3 ｜ S1 战略决策层）

**全链最高杠杆的一个决定。局部与全面、续约与换牌，事后全部成本都由这一步锚定。**

| 维度 | 族 | 该阶段的具体内容 |
|---|---|---|
| **主导方** | 决策侧 | 业主投资决策层；改/不改、局部/全面由其拍板 |
| **合作方** | 决策侧 | 酒店管理方与品牌方（提前给锚点）；造价咨询、市场研究机构 |
| **参与方** | 供给侧 | 业主代表、业主投资与工程团队 |
| **供应商** | 供给侧 | 本阶段几乎不涉及；仅可研与数据服务商 |
| **政策与合规** | 约束侧 | 区域规划与业态准入；土地与消防现状摸底；国有资产投资监管程序 |
| **资金与成本** | 约束侧 | 只做区间，不锁数字；预留改造资本金上限 |
| **资源与区位** | 能力侧 | 区位与客源盘点；存量物业清单、竞品扫描 |
| **品牌与产品** | 能力侧 | 续约 / 换牌 / 自营 三选一；初步倾向与兜底方案 |
| **技术与系统** | 能力侧 | ★ 数据基线：RevPAR/入住率/竞争格局；一切测算的锚从这里开始 |

- **本阶段供应商 / 合作方**：本阶段供应商 0 条 · 真正的供应商清单在 S5–S7 才成形
- **接口**：← 承接：资产线索　 ｜ 　→ 交付：改造模式决议 + 资本金上限
- **关键锚点**：DG1（改/不改、局部/全面）；DG2（续约/换牌/自营）

### P02 · 资产与安全评估（M1–M3 ｜ S2 资产与安全评估层（并行））

**与战略决策并行的一层。品牌能换、物业难换 —— 这一层的结论决定了后面所有数字。**

| 维度 | 族 | 该阶段的具体内容 |
|---|---|---|
| **主导方** | 决策侧 | 业主资产与工程部门 |
| **合作方** | 决策侧 | 结构鉴定与加固顾问；机电专项顾问、消防专项顾问 |
| **参与方** | 供给侧 | 勘察单位；第三方检测（消防/防雷/空气/节能/噪音/水质） |
| **供应商** | 供给侧 | ★ 结构鉴定与碳化/钢筋检测；加固方案设计单位 |
| **政策与合规** | 约束侧 | ★ 土地剩余年限与产权状况；★ 建筑年限与既有结构可靠性；人防与警备区要求 |
| **资金与成本** | 约束侧 | 加固与整体替换的量级摸底；此阶段不定价，只定边界 |
| **资源与区位** | 能力侧 | 土地、楼宇、证照的可得性 |
| **品牌与产品** | 能力侧 | 存量建筑与品牌标准的缺口清单 |
| **技术与系统** | 能力侧 | ★ 冷源 R11 现状、4台变压器与34面低压柜；★ 消防 1996 回路 —— 决定改造量级 |

- **本阶段供应商 / 合作方**：结构鉴定 / 加固设计 / 机电专项 / 消防专项 / 第三方检测 五类顾问进场
- **接口**：← 承接：改造模式决议　 ｜ 　→ 交付：资产可改造边界 + 改造量级
- **关键锚点**：土地年限（REITs 第一红线）；量级（决定预算与工期）

### P03 · 法律与合同（M2–M8 ｜ S3 法律与合同层）

**最容易出现「无牌运营」空窗的一层。两个动作必须同步生效，否则中间期谁都无法承接。**

| 维度 | 族 | 该阶段的具体内容 |
|---|---|---|
| **主导方** | 决策侧 | 业主法务 + 品牌方 |
| **合作方** | 决策侧 | 业主律师、品牌方谈判代表；双品牌切换协调方 |
| **参与方** | 供给侧 | 财务、运营（提供经营假设） |
| **供应商** | 供给侧 | 合同技术协议配套方（PMS / IT） |
| **政策与合规** | 约束侧 | ★ 合同审批与用印；担保、抵押、经营者集中（如涉）；品牌授权资质、外资准入（如涉） |
| **资金与成本** | 约束侧 | ★ 免租期、装修补贴、租金递增；押金、流动资金、储值资金监管 |
| **资源与区位** | 能力侧 | 开业筹备支持承诺；开业流量与会员导入承诺 |
| **品牌与产品** | 能力侧 | 标准落地条款；在地化改造审批权归属 |
| **技术与系统** | 能力侧 | ★ 数据归属与移交条款；★ OTA 点评/会员/系统 —— 换管方从零开始的坑 |

- **本阶段供应商 / 合作方**：合同期内锁定的品牌指定供应商清单，随合同生效
- **接口**：← 承接：资产边界与量级　 ｜ 　→ 交付：生效的双合同 + 预算与工期条款
- **关键锚点**：DG3（品牌选定含不换牌兜底）；DG4（退出旧+签入新 同步生效）

### P04 · 品牌选定与 PIP 谈判（M3–M6 ｜ S4 品牌选定与 PIP 谈判层）

**PIP 是一套强约束技术规范。签下去，就同时拿到了品牌溢价和一张没有自由度的施工图。**

| 维度 | 族 | 该阶段的具体内容 |
|---|---|---|
| **主导方** | 决策侧 | 业主（是否签品牌）+ 品牌方（定标准） |
| **合作方** | 决策侧 | ★ 品牌方技术服务（实证 100 万）；★ 外部奢牌设计审核 300–700 万 |
| **参与方** | 供给侧 | 设计总监 DM、造价 QS、业主代表 |
| **供应商** | 供给侧 | PIP 指定的 FF&E、布草、客控、艺术品品牌 |
| **政策与合规** | 约束侧 | 品牌授权资质与备案；特许经营备案 |
| **资金与成本** | 约束侧 | ★ 加盟费 E1：0–800 万；★ PIP 单房：经济型 $8–15k → 豪华 $33–46k+ |
| **资源与区位** | 能力侧 | 品牌会员池、集团采购、渠道资源 |
| **品牌与产品** | 能力侧 | ★ PIP 约束下的在地化空间 |
| **技术与系统** | 能力侧 | PMS/CRS/中央预订/客控中控；品牌指定与接口要求 |

- **本阶段供应商 / 合作方**：品牌指定供应商成为后续采购的强制清单
- **接口**：← 承接：双合同框架　 ｜ 　→ 交付：品牌定稿 + PIP 技术规范
- **关键锚点**：DG5（品牌选定 + PIP 定稿）；单房成本（经济型 3–4 月 / 豪华 12–18 月）

### P05 · 设计与报建（M6–M9 ｜ S5 设计与报建层）

**方案自由度在品牌约束下被压缩，报批周期在监管排队中被拉长 —— 这一层决定拿不拿得到施工许可。**

| 维度 | 族 | 该阶段的具体内容 |
|---|---|---|
| **主导方** | 决策侧 | 设计方出方案、业主决策、品牌方 PIP 审核 |
| **合作方** | 决策侧 | ★ B 类 21 门类设计；建筑/结构/机电冷暖电给排/消防/智能化 |
| **参与方** | 供给侧 | 设计总监 DM、多专业协调、现场勘察 |
| **供应商** | 供给侧 | 设计院、施工图审查机构 |
| **政策与合规** | 约束侧 | ★ D 类 10 项审批与法定检测；施工图审查、消防设计审查、规划许可变更；人防报批、特种设备、节能、环保、竣工备案 |
| **资金与成本** | 约束侧 | 概算与限额设计；造价优化与方案比选 |
| **资源与区位** | 能力侧 | ★ 在地叙事素材提取；艺术策展、景观、艺术品方向 |
| **品牌与产品** | 能力侧 | ★ 样板房 Mock-up Room；品牌方验收后才允许全面铺开 |
| **技术与系统** | 能力侧 | BIM 深化与碰撞检测；CAS 客控、网络、IPTV 方案 |

- **本阶段供应商 / 合作方**：B 类 21 门类设计 + D 类 10 项审批检测 同时进场
- **接口**：← 承接：品牌与 PIP 定稿　 ｜ 　→ 交付：施工图 + 各项报批受理
- **关键锚点**：DG6（施工许可取得）；B类（21 个设计门类）

### P06 · 采购与招标（M6–M10 ｜ S6 采购与招标层（并行））

**与设计并行。控制价定低，后面只能靠变更签证往上找补 —— 工期和成本同时失控。**

| 维度 | 族 | 该阶段的具体内容 |
|---|---|---|
| **主导方** | 决策侧 | 业主招采部 + 招采代理 |
| **合作方** | 决策侧 | ★ 招采代理 / 招标顾问；造价咨询 QS（全过程成本管理） |
| **参与方** | 供给侧 | 设计（技术标澄清）、监理、业主代表 |
| **供应商** | 供给侧 | ★ 招标形成 C 类 25 项专业分包；★ B 类指定品牌进入采购包 |
| **政策与合规** | 约束侧 | 国资采购程序与公平竞争；招标与合同合规审查 |
| **资金与成本** | 约束侧 | ★ 招标控制价、付款节点、质保金 |
| **资源与区位** | 能力侧 | ★ 交期与产能：布草/艺术品/设备定制周期长 |
| **品牌与产品** | 能力侧 | 品牌方指定清单 vs 业主自主采购边界 |
| **技术与系统** | 能力侧 | PMS/客控/网络招标与系统集成商 |

- **本阶段供应商 / 合作方**：★ C 类 25 项总包与专业分包 + 六大类合作方同步定标
- **接口**：← 承接：施工图与控制价　 ｜ 　→ 交付：中标清单 + 开工令条件
- **关键锚点**：控制价（变更签证的封顶线）；总包费（建安费 ×3%–5%）

### P07 · 施工与改造（M9–M24 ｜ S7 施工与改造层）

**土建、机电、装修、设备同时展开。这一层既是成本黑洞，也是开业日与爬坡质量的决定者。**

| 维度 | 族 | 该阶段的具体内容 |
|---|---|---|
| **主导方** | 决策侧 | ★ 施工总承包 EPC（进度/安全/垂直运输）；监理对结果负责 |
| **合作方** | 决策侧 | 业主代表 OR、造价 QS、设计 DM、第三方检测 |
| **参与方** | 供给侧 | 业主工程部、品牌方督导、物业、酒店工程顾问 |
| **供应商** | 供给侧 | ★ C 类 25 项：拆除渣运、土建砌筑、幕墙门窗、防水；★ 冷源 R11 整体更换、电气 4台变压器+34面低压柜；★ 消防 1996 回路全换并重做报审、给排水、智能化、电梯 9# 整机；★ 公区精装、客房硬装、灯具、家具木作、布草地毯窗饰；★ 艺术品、景观园林、泳池水疗、厨房设备、洗衣房、标识；★ 燃气锅炉更换、电视与治安监控数字化、地下停车场、5G |
| **政策与合规** | 约束侧 | ★ 过程验收与隐蔽工程验收记录；★ 记录决定结算，也决定下一轮改造优先级 |
| **资金与成本** | 约束侧 | ★ 进度款节点与变更签证；★ 供应商账期设计 ＝ 开业后的负债结构 |
| **资源与区位** | 能力侧 | 施工场地与临时设施；工人住宿、街区与夜间施工协调 |
| **品牌与产品** | 能力侧 | 标准落地检查、材料封样与替代审批 |
| **技术与系统** | 能力侧 | ★ 弱电/网络/客房智能化安装与联调；★ 不通就拖爬坡 |

- **本阶段供应商 / 合作方**：★ 全链 25 项专业分包集中进场 · 临时设施与垂直运输同步
- **接口**：← 承接：中标清单与开工令　 ｜ 　→ 交付：实体资产 + 可运行系统
- **关键锚点**：工期（上高端 12–18 月）；账期（★决定开业后负债结构）

### P08 · 验收、开办与硬开业（M24–M30 ｜ S8 开业与运营层）

**实体验收只是其一，开办费才是这一层真正的账单 —— 218 人团队、系统上线、库存、试运营，都是开业前就要花的钱。**

| 维度 | 族 | 该阶段的具体内容 |
|---|---|---|
| **主导方** | 决策侧 | 酒店总经理 + 品牌方（开业支持） |
| **合作方** | 决策侧 | ★ Pre-Opening 顾问 30–300 万；品牌方驻场培训与认证 |
| **参与方** | 供给侧 | 业主工程部、监理、第三方检测、物业 |
| **供应商** | 供给侧 | ★ E 类 12 项开办费；招聘与培训 218 人（80–420 万）、品牌教材；POS/IT/品牌系统上线、开业前库存；开业推广与媒体、试运营 1–2 月（200–580 万）；客人礼品、品牌审计整改、在地艺术家驻地、顾问支持、制服形象 |
| **政策与合规** | 约束侧 | ★ 竣工验收备案与消防验收；特种设备使用登记、员工用工与社保；治安与特种行业许可 |
| **资金与成本** | 约束侧 | ★ 业主停业期成本 F1–F5；保留人工、贷款利息、能耗维持、保险安保、建设期利息 |
| **资源与区位** | 能力侧 | ★ 会员导入、OTA 曝光位、企业协议客户、周边地推 |
| **品牌与产品** | 能力侧 | ★ 开业前品质审计与整改闭环 |
| **技术与系统** | 能力侧 | PMS 上线与数据初始化；房态与渠道打通、会员开卡 |

- **本阶段供应商 / 合作方**：★ E 类 12 项开办费集中支出 · 试运营 1–2 个月
- **接口**：← 承接：完工实体　 ｜ 　→ 交付：可营业酒店 + 三方验收通过
- **关键锚点**：DG7（三方验收通过）；DG8（硬开业 100% 价格）

### P09 · 软开业与爬坡（M30–M36 ｜ S8 延伸）

**爬坡期最容易犯的错，是把开业期的高分当成经营能力，然后被成熟店口径打回原形。**

| 维度 | 族 | 该阶段的具体内容 |
|---|---|---|
| **主导方** | 决策侧 | 酒店总经理（收益管理与爬坡节奏） |
| **合作方** | 决策侧 | OTA 平台、企业协议客户、旅行社、金融 |
| **参与方** | 供给侧 | 渠道经理、收益管理、门店全体 |
| **供应商** | 供给侧 | 布草与客用品补给、食材、维保、能源 |
| **政策与合规** | 约束侧 | 用工结构（外包与派遣）；税收优惠适用、预付卡资金监管、价格公示 |
| **资金与成本** | 约束侧 | ★ 渠道账期与预收款；★ 加盟商预付款沉淀 → 轻资产≠轻负债 |
| **资源与区位** | 能力侧 | ★ 老客回迁：CRM 唤醒 + 协议客户 1v1；翻牌期最关键动作 |
| **品牌与产品** | 能力侧 | 品质巡检、客诉闭环 |
| **技术与系统** | 能力侧 | ★ 收益管理分阶段恢复至全价；软开业 4–8 周、8–9 折 |

- **本阶段供应商 / 合作方**：运营物资 S 类：布草 S-01 / 客房用品 S-02 / 客控 S-06 / IT S-07 / 家具软装 S-09 / 餐饮设备 S-12
- **接口**：← 承接：硬开业　 ｜ 　→ 交付：稳定出租率与 RevPAR
- **关键锚点**：爬坡（0–6 / 6–12 / 12–24 月三段复盘）；复盘（★ 8.6 反向核查）

### P10 · 运营与收益管理（稳态 ｜ 长期）

**资产交付之后的全部日常。行业此时早已不是增量逻辑，而是效率分层逻辑。**

| 维度 | 族 | 该阶段的具体内容 |
|---|---|---|
| **主导方** | 决策侧 | 业主 + 酒店总经理（日常经营） |
| **合作方** | 决策侧 | OTA、协议客户、供应链商、金融 |
| **参与方** | 供给侧 | 门店全体、渠道经理、收益管理 |
| **供应商** | 供给侧 | ★ S 类运营物资六类目；布草/客房用品/客控/IT/家具软装/餐饮设备；业内预留年营收 4–5%（OS&E） |
| **政策与合规** | 约束侧 | 日常消防检查、环保、特种设备年检；预付卡与消费者权益、价格公示 |
| **资金与成本** | 约束侧 | RevPAR / ADR / OCC 三件套；人效与坪效、渠道结构占比 |
| **资源与区位** | 能力侧 | ★ 直销率与会员占比；协议客户续签、区域供需与空置率 |
| **品牌与产品** | 能力侧 | 标准执行与在地化平衡、年度品质审计 |
| **技术与系统** | 能力侧 | ★ 收益管理、CRS、会员 CRM；★ OTA 点评与评分运营 |

- **本阶段供应商 / 合作方**：★ S 类运营物资持续消耗 · 年营收预留 4–5%
- **接口**：← 承接：爬坡完成　 ｜ 　→ 交付：现金流与 RevPAR 稳定
- **关键锚点**：结构（业绩=规模×效率）；OTA（★ 点评资产要运营）

### P11 · 迭代与再投资（按周期 ｜ 周期性）

**弱周期里，改造比新建更划算 —— 但触发条件必须事先写清，否则永远等到不能再等。**

| 维度 | 族 | 该阶段的具体内容 |
|---|---|---|
| **主导方** | 决策侧 | 业主（资本开支决策）+ 管理方（提方案） |
| **合作方** | 决策侧 | 设计与改造方、设备供应商、金融、咨询 |
| **参与方** | 供给侧 | 工程、运营 |
| **供应商** | 供给侧 | ★ 改造施工、材料与设备替换；换硬件，不换壳 |
| **政策与合规** | 约束侧 | 改造期消防与施工报批；特种设备变更与年检衔接 |
| **资金与成本** | 约束侧 | 改造 CAPEX 与回收期测算；是否影响资产化现金流预测 |
| **资源与区位** | 能力侧 | ★ 重改触发信号；同店 RevPAR 连续下滑 / 资产年限过半 / 品牌标准迭代 |
| **品牌与产品** | 能力侧 | 品牌升级、客房换新、客房数与房型调整 |
| **技术与系统** | 能力侧 | 系统升级、自动化与自助化 |

- **本阶段供应商 / 合作方**：改造施工 + 设备替换 —— 换硬件不换壳
- **接口**：← 承接：运营数据与触发信号　 ｜ 　→ 交付：资产价值重置
- **关键锚点**：触发条件（★ 事先写死）；实证（重改门店 RevPAR 明显跑赢新建）

### P12 · 资产化与退出（退出 ｜ 终点亦是起点）

**所有前置决策在这里结算。评估值、现金流预测、土地年限，一环错则全盘错。**

| 维度 | 族 | 该阶段的具体内容 |
|---|---|---|
| **主导方** | 决策侧 | 原始权益人 + 基金管理人 |
| **合作方** | 决策侧 | 券商、交易所、评估机构、会计师、律师、运营管理机构 |
| **参与方** | 供给侧 | 管理方（过渡期安排） |
| **供应商** | 供给侧 | 交接与过渡运维、改造与检测 |
| **政策与合规** | 约束侧 | ★ 交易所问询高频命中土地剩余年限；★ 临时改用途到期（规划许可变更）；国有资产转让程序、债权债务处置、员工安置 |
| **资金与成本** | 约束侧 | ★ 预测现金流年复合增长率（强主变量）；★ cap rate 与分派率预测、存续期设置 |
| **资源与区位** | 能力侧 | 底层资产组合与经营稳定性；规模与区域分布 |
| **品牌与产品** | 能力侧 | ★ 品牌许可期限须覆盖存续期 |
| **技术与系统** | 能力侧 | ★ 数据与会员移交、系统与信息化合规 |

- **本阶段供应商 / 合作方**：运营管理机构（通常即原管理方）与过渡运维
- **接口**：← 承接：可稳定预测的现金流　 ｜ 　→ 交付：资产证券化或整体转让
- **关键锚点**：红线（土地剩余年限）；主变量（预测现金流增长率）

## 3. P14 维度轨迹与耦合关系

| 维度 | 族 | 活跃区间 | 说明 |
|---|---|---|---|
| **主导方** | 决策侧 | 第 1–12 阶段 | 每阶段的拍板方都不同，这是链的真正节奏 |
| **合作方** | 决策侧 | 第 1–12 阶段 | 贯穿，但重心从顾问→品牌→设计→招采→总包 |
| **参与方** | 执行侧 | 第 2–12 阶段 | S2 起才真正进场 |
| **供应商** | 供给侧 | 第 2–12 阶段 | ★ 峰值在 S6–S8：25 项分包＋12 项开办费 |
| **政策与合规** | 约束侧 | 第 1–12 阶段 | ★ 峰值在 S5–S8：报批与验收 |
| **资金与成本** | 约束侧 | 第 1–12 阶段 | ★ 峰值在 S3、S6–S7：合同价与账期 |
| **资源与区位** | 能力侧 | 第 1–12 阶段 | 唯一贯穿且不换人的维度 |
| **品牌与产品** | 能力侧 | 第 1–9 阶段 | S9 后从「选品牌」转为「兑现品牌」 |
| **技术与系统** | 能力侧 | 第 2–11 阶段 | ★ 峰值在 S5–S8：设计→施工→上线 |

**三条跨维度耦合（图中以虚线连接）**

1. **账期 → 负债**：S6–S7 采购与施工阶段设计的供应商账期，直接决定开业后的负债结构与资产化时的现金流表现
2. **系统不通 → 拖爬坡**：S5–S8 设计与施工阶段的弱电、网络、客控、PMS 联调完成度，决定 S9 软开业的起点
3. **年限 → 估值**：S12 资产化阶段，土地剩余年限是评估值与存续期的第一约束

**★ 结构性发现**：资源与区位是**唯一贯穿全程且不换人**的维度 —— 其余维度都会在某一段集中爆发、然后退场。
