# 多套语言并存下的产品定位决策框架 v1.2

> **一句话**：**六套语言里只有两套真正定价 —— 消费者端评分 与 数据机构口径。**
> **中文市场的证据比美国更直接**：OTA 评分**每变动 0.1 分，酒店年营收波动 5%–10%**。

## 二、v1.2 最重要的两个新结论

### 结论 A｜中文市场把「评分即定价」推到了更狠的位置

| | 美国（Cornell）| 中国（华客 + 饭店协会）|
|---|---|---|
| 评分变动 | +1 分（5 分制）| **+0.1 分** |
| 对应影响 | ADR **+11.2%** | **年营收波动 5%–10%** |

**含义**：在中国的平台上，**0.1 分的差距就是 5%–10% 的营收差**。
这不是「锦上添花」，是**主战场**。

### 结论 B｜「只有一套语言」的资产，正在被系统性收割

> **58.2% 的非连锁单体面临客源流失与利润压力**（C5）。
> 而经济型连锁化率只有 **30.86%**、15–29 间房的单体只有 **13.40%**（C6）。

**这正好对上 v1.1 的结论**：
> 单一语言（只有 OTA 分、只有集团档位、什么数据标签都没有）的资产，
> **既没有数据语言（无法被对标与资产化），又没有消费者语言（没有独特性）**，
> **也没有集团语言（不在体系内）** → **三套都缺，只剩平台标签这种最不稳定的语言** → 被收割。

## 三、定位矩阵（v1.2 终版）

| 你的形态 | **定价权语言（必做）** | **门槛语言（要有）** | **仪表盘语言（跟随）** |
|---------|-------------------|------------------|------------------|
| **存量改造 / 翻牌** | 数据口径（改造前后 RevPAR 对比）+ 消费者语言（独特体验，评分每 0.1 分 = 营收 5–10%）| 行政星级（合规）| 携程/美团标签 |
| **文化主题 / 特色产品** | 消费者语言（**独特性 = 主题本身**，最易拿到溢价）+ 数据口径 | 集团/行政（若需）| OTA 内容标签 |
| **区域平台 / 资源整合** | 数据口径（资产定价、REITs 化）+ 消费者语言（区域口碑）| 行政 + 集团（谈判）| 政务语言 |
| **新业态（非标 / 标签组）** | 消费者语言（**80% 愿为独特体验付溢价**）+ 数据口径做翻译层 | 集团体系（**装不下你**）| 携程特牌 / 飞猪钻级 |
| **连锁加盟 / 品牌输出** | 数据口径 + 消费者语言（品牌信任度）| 集团分级（跟大集团谈）| 平台评级 |

## 四、可执行自查表（v1.2）

```
□ 1. 我在【消费者语言】里的独特性是什么？当前评分几分？
     → 0.1 分 = 营收 5-10%，这是最贵的战场
□ 2. 我在【数据语言】里能被对标吗？竞争组是谁？有时间序列吗？
□ 3. 我是不是只被一套语言认？（58.2% 的非连锁单体正因此被收割）
□ 4. 行政 / 集团语言我满足了没有？（门槛，不是卖点）
□ 5. 渠道标签我是当仪表盘在看吗？
□ 6. 如果换成 REIT 资产，我能不能用同一套数据讲清楚？
□ 7. 我把「等级」当卖点，还是把「独特性」当卖点？
□ 8. 我的规模在 30-149 间房之间吗？（连锁化率 61% vs 13% 的分水岭）
```
