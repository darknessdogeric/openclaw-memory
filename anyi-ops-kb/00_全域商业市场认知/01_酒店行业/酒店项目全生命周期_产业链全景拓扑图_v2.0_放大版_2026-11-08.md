## 3. 每阶段资源清单（P02–P15）

### 投研阶段（M0–M6）　→ P02 / P03

**所有后续投入的锚都在这里定。投研阶段不锁定数字，但必须锁死判断口径——否则后面每个数字都没有对照系。**

**【人 · 谁在管】**

- **主导方**：业主投资决策层；集团投资部；总经理办公会
- **合作方 · 专业服务**：市场研究/STR 口径；前期定位顾问；可研编制单位；选址顾问；法律顾问；造价顾问（预可研）
- **参与方**：业主代表；投资经理；财务负责人；运营（提供经营假设）

**【物 · 谁在供】**

- **供应商 · 工程类**：本阶段基本不涉及；仅初勘与物探
- **供应商 · 物资与系统**：本阶段基本不涉及
- **土地与物业**：区位与可达性；客源池分布；可获取物业清单；权属与剩余年限

**【政 · 谁在批】**

- **政府机构 · 审批报建**：自然资源与规划局；发展改革委（立项）；国资监管（投资决策程序）；税务局（税收适用）；文旅局（产业准入）
- **政府机构 · 监管运营**：市场监管（经营范围/住宿登记）；消防救援支队（既有建筑消防现状核查）

**【钱与技 · 谁在撑】**

- **资金**：自有资金/贷款/股东借款/战投；土地与物业获取方式；融资意向与授信；租金与租约条件
- **客源与市场**：商务/休闲/入境需求结构；竞品扫描与价格带；区域供需与空置率
- **品牌与技术系统**：档次与品牌初步意向；自营/委托/特许路径；系统方案方向

- **接口**：← 承接：投资意图　 ｜ 　→ 交付：可行性结论 + 投决口径
- **关键锚点**：**投决门**（改/不改、做什么档、什么位置）；**口径**（数据源与基准锁定）

### 土建阶段（M3–M24）　→ P04 / P05

**土建阶段的主体与机电，决定后面所有工序的起点。隐蔽工程一次做错，后期无法补救 —— 验收记录是最硬的证据。**

**【人 · 谁在管】**

- **主导方**：业主工程部；施工总承包 EPC
- **合作方 · 专业服务**：建筑设计院；结构鉴定与加固顾问；机电专项顾问；消防专项顾问；造价咨询 QS；监理；第三方检测机构；勘察单位
- **参与方**：业主代表；设计管理 DM；品牌方督导（已定品牌时）

**【物 · 谁在供】**

- **供应商 · 工程类**：拆除与渣土外运；桩基与土建砌筑；幕墙门窗与外立面泛光；防水工程；给排水与热水；电气变配电与桥架；冷源主机与末端；智能化弱电主干与网络；电梯采购安装；特种设备（燃气锅炉/压力容器）；道路与市政接口；景观与绿化；临时设施与垂直运输；成品保护
- **供应商 · 物资与系统**：本阶段以隐蔽工程预留为主；点位、井道、管线预埋
- **土地与物业**：施工场地与围挡；工人住宿与生活区；夜间施工与街区协调

**【政 · 谁在批】**

- **政府机构 · 审批报建**：住建局（施工许可）；自然资源和规划（工程规划许可/变更）；人防（警备区报批）；消防救援支队（消防设计审查）；市场监管（特种设备安装告知）；生态环境（环评/排污许可）；城管；节能审查
- **政府机构 · 监管运营**：施工期消防与安全检查；防雷检测机构；第三方检测（消防/空气/节能/噪音/水质）

**【钱与技 · 谁在撑】**

- **资金**：总包合同与付款节点；进度款与质量保证金；建设期利息；变更签证
- **客源与市场**：本阶段不涉及需求；施工期对周边商圈的扰动与补偿谈判
- **品牌与技术系统**：弱电主干与网络管道预埋；客控点位预留；给排水点位与电源预留；管线与井道命名规则

- **接口**：← 承接：投决与设计任务书　 ｜ 　→ 交付：主体结构 + 可运行的机电系统
- **关键锚点**：**隐蔽工程**（★ 验收记录＝结算与后续改造依据）；**账期**（★ 决定开业后负债结构）

### 筹建阶段（M6–M18（与土建并行））　→ P06 / P07

**酒店特有的筹建期 —— 装修、设备、布草、开办、系统全部集中在这里。它不是土建的附属，是酒店最重的一段。**

**【人 · 谁在管】**

- **主导方**：业主筹建办；酒店总经理
- **合作方 · 专业服务**：室内设计（公区/客房）；软装与艺术策展；灯光设计；厨房设计 KDS；泳池与水疗设计；声学设计；动线研究；样板房 Mock-up；Pre-Opening 顾问；收益管理顾问；招采代理
- **参与方**：品牌方督导；设计总监 DM；造价 QS；监理；业主代表

**【物 · 谁在供】**

- **供应商 · 工程类**：精装工程（公区）；装饰工程（客房）；灯光与灯具安装；家具与固定木作；艺术品采购与陈设；布草地毯窗饰；景观与园林工程；泳池与水疗设备；厨房设备采购安装；洗衣房设备；标识标牌制作安装；地下停车场改造；前后庭院与市政界面改造；样板房打制
- **供应商 · 物资与系统**：PMS / CRS / 中央预订；客控 CAS 与智能家居；IPTV 与电视系统数字化；门锁与客控安防；治安监控数字化与集中供电 UPS；布草与客房用品首批采购；食品饮料酒水首批采购
- **土地与物业**：竣工验收备案与消防验收；物业移交与开办条件

**【政 · 谁在批】**

- **政府机构 · 审批报建**：施工图审查（第三方审图机构）；消防设计审查（住建/消防）；节能审查与验收；环保验收（油烟/噪声/排放）；特种设备安装告知与定期检验；防雷检测；城建档案与竣工资料
- **政府机构 · 监管运营**：劳动合同与社保公积金；食品经营许可；治安管理与特种行业许可；税务登记与发票

**【钱与技 · 谁在撑】**

- **资金**：★ 供应商账期设计 ＝ 开业后的负债结构；开业前库存采购；品牌使用费与系统费；装修与设备 CAPEX
- **客源与市场**：企业协议客户预签；旅行社与 OTA 预售；会员预热
- **品牌与技术系统**：品牌标准落地检查与整改；样板房验收；系统部署与接口联调（★ 不通就拖爬坡）

- **接口**：← 承接：主体与机电　 ｜ 　→ 交付：可运营实体 + 可运行系统
- **关键锚点**：**最重一段**（土建与筹建并行推进）；**系统**（★ 联调完成度决定开业起点）

### 筹备阶段（M16–M24）　→ P08 / P09

**筹备期的全部开销几乎都不产生收入，却决定开业第一个月的起点。开办费是开业前就要付的账，不是开业后再说的。**

**【人 · 谁在管】**

- **主导方**：酒店总经理；品牌方（开业支持）
- **合作方 · 专业服务**：品牌方驻场培训与认证；开业前顾问；收益管理顾问；媒体与推广代理；招聘外包机构
- **参与方**：全体员工；业主代表；物业；各供应商

**【物 · 谁在供】**

- **供应商 · 工程类**：缺陷整改与精修；成品保护与深度清洁
- **供应商 · 物资与系统**：开业前库存（餐饮/布草/客用品/酒水）；POS 与品牌系统上线；客人礼品与欢迎用品；制服与员工形象；洗衣与厨房设备调试；补货与周转物资
- **土地与物业**：绿植与公共区域交付；停车与动线；开办条件与钥匙移交

**【政 · 谁在批】**

- **政府机构 · 审批报建**：竣工验收备案；消防验收与投入使用登记；特种设备使用登记；电梯投用
- **政府机构 · 监管运营**：公安特种行业许可；市场监管食品经营许可；人社用工备案；税务发票与资质

**【钱与技 · 谁在撑】**

- **资金**：★ 试运营 1–2 个月的人工与亏损；开业推广费；招聘与培训费；会员预售与储值（受监管）
- **客源与市场**：★ 会员导入；★ OTA 曝光位与排名；企业协议客户 1v1；周边地推；达人探店与内容
- **品牌与技术系统**：开业前品质审计与神秘客；渠道房态打通；会员开卡；试运营定价策略

- **接口**：← 承接：可运营实体　 ｜ 　→ 交付：可营业酒店 + 三方验收通过
- **关键锚点**：**开业门**（品牌/政府/业主三方验收）；**软开**（4–8 周 8–9 折，ADR 恢复 60–70%）

### 运营阶段（长期）　→ P10 / P11

**增量红利结束的周期里，运营不是执行环节，是全部价值所在。RevPAR、ADR、OCC 三件套之外，第四条是成本。**

**【人 · 谁在管】**

- **主导方**：业主；酒店总经理（收益管理）
- **合作方 · 专业服务**：OTA 平台；商务代理与旅行社；协议客户企业；供应链金融；保险经纪；审计与咨询；工会与行业协会
- **参与方**：门店全体；渠道经理；收益管理；人力与培训；工程维保

**【物 · 谁在供】**

- **供应商 · 工程类**：维保与外包工程；电梯/锅炉/冷源维保；幕墙与屋面维护；泳池与园林养护；安保与保洁外包
- **供应商 · 物资与系统**：★ OS&E 六类目：S-01 布草 / S-02 客房用品 / S-06 客控 / S-07 IT / S-09 家具软装 / S-12 餐饮设备；业内预留年营收 4–5%；食材与酒水补给；能源与公用
- **土地与物业**：物业维护与资本开支；租约续期；公共区域与配套

**【政 · 谁在批】**

- **政府机构 · 审批报建**：本阶段基本无新增报建
- **政府机构 · 监管运营**：消防检查；特种设备定期检验；环保排放与油烟；预付卡资金监管；市场监管价格与消保；文旅星级评定与复核；治安与住宿登记；统计与报表

**【钱与技 · 谁在撑】**

- **资金**：RevPAR / ADR / OCC；人效与坪效；渠道结构与佣金；储值与预收款；租金与债务偿还；能耗与成本
- **客源与市场**：★ 直销率与会员占比；协议客户续签；入境需求；竞品价格战与区域供需
- **品牌与技术系统**：标准执行与品质巡检；★ OTA 点评与评分运营；收益管理系统；会员 CRM；数据中台

- **接口**：← 承接：开业酒店　 ｜ 　→ 交付：稳定现金流与 RevPAR
- **关键锚点**：**三件套**（RevPAR / ADR / OCC）；**第四条**（成本结构 —— 决定利润）

### 改造阶段（周期性）　→ P12 / P13

**弱周期里改造比新建划算。但触发条件必须事先写死 —— 否则永远等到不能再等。**

**【人 · 谁在管】**

- **主导方**：业主投委会（CAPEX 决策）；酒店总经理（提方案）
- **合作方 · 专业服务**：设计院（改造）；造价 QS 与全过程成本管理；监理；第三方检测；咨询（估值与收益测算）；品牌方技术审核
- **参与方**：工程；运营；业主代表；财务

**【物 · 谁在供】**

- **供应商 · 工程类**：拆除与渣土；机电整体更换（冷源/电气/消防）；精装与客房硬装翻新；电梯更新；厨房与洗衣设备更新；智能化与客控升级；★ 燃气锅炉更换（排放标准）；电视与监控数字化；地下停车场与市政界面；景观与艺术品更新
- **供应商 · 物资与系统**：布草与客房用品换新；家具软装更新；客控与 PMS 升级；会员数据迁移
- **土地与物业**：★ 重改触发信号；改造后资产重估；施工期动线与客房清整

**【政 · 谁在批】**

- **政府机构 · 审批报建**：住建（改造施工许可/图审）；规划（面积与房量变更）；消防（改造报审）；市场监管（特种设备变更）；节能与环保（改造后复验）
- **政府机构 · 监管运营**：改造期消防与安全；特种设备年检衔接

**【钱与技 · 谁在撑】**

- **资金**：改造 CAPEX 与回收期测算；停业损失与客房清零；是否影响资产化现金流预测
- **客源与市场**：改造期客流影响与过渡定价；老客回迁与预抵；协议客户沟通口径
- **品牌与技术系统**：品牌升级与 VI 更新；系统与自动化改造

- **接口**：← 承接：运营数据与触发信号　 ｜ 　→ 交付：资产价值重置
- **关键锚点**：**触发条件**（★ 同店RevPAR连降 / 年限过半 / 标准迭代）；**实证**（重改门店 RevPAR 跑赢新建）

### 退出阶段（终点亦是起点）　→ P14 / P15

**评估值、现金流预测、土地年限、品牌许可，一环错则全盘错。退出不是终点，是资产定位的最后一环。**

**【人 · 谁在管】**

- **主导方**：原始权益人；基金管理人 / 买方
- **合作方 · 专业服务**：券商与财务顾问；资产评估机构；会计师与审计；律师；基金管理人；运营管理机构；财务顾问 FA
- **参与方**：管理方（过渡期安排）；员工安置；财务

**【物 · 谁在供】**

- **供应商 · 工程类**：交接前整改与状态鉴定；维保移交
- **供应商 · 物资与系统**：数据与会员移交；系统与信息化合规；供应商合约转让或终止
- **土地与物业**：★ 土地剩余年限；★ 临时改用途到期；产权与证照可转移性

**【政 · 谁在批】**

- **政府机构 · 审批报建**：证券交易所（REITs 审核与问询）；国资监管（评估备案与转让审批）；税务（土地增值税/转让税/所得税）；市场监管（主体变更）；商务与文旅
- **政府机构 · 监管运营**：债权债务处置；职工安置的属地协调

**【钱与技 · 谁在撑】**

- **资金**：★ 预测现金流 CAGR（主变量）；★ cap rate 与分派率预测；存续期设置；退出对价与估值倍数；★ 退出不对称
- **客源与市场**：买方对客源与会员的接手意愿；协议客户可转移性
- **品牌与技术系统**：★ 品牌许可期限须覆盖存续期；会员与点评资产归属

- **接口**：← 承接：可稳定预测的现金流　 ｜ 　→ 交付：资产证券化或整体转让
- **关键锚点**：**第一红线**（土地剩余年限）；**主变量**（预测现金流增长率）

5. **人防与城管是土建专属**，运营期基本消失

## 6. P18 资源轨迹与耦合关系

| 资源维度 | 族 | 活跃区间 | 说明 |
|---|---|---|---|
| **主导方** | 人 | 第 1–7 阶段 | 每阶段拍板方都换，但始终有且只有一个人 |
| **合作方 · 专业服务** | 人 | 第 1–7 阶段 | 顾问→品牌→设计→招采→总包→运营→交易 |
| **参与方** | 人 | 第 1–7 阶段 | 贯穿执行，但重心随阶段迁移 |
| **供应商 · 工程类** | 物 | 第 2–7 阶段 | ★ 峰值 土建/筹建/改造 三次 |
| **供应商 · 物资与系统** | 物 | 第 3–7 阶段 | ★ 峰值 筹建/筹备，之后转为持续消耗 |
| **政府机构 · 审批报建** | 政 | 第 1–7 阶段 | ★ 峰值 土建/筹建，退出时再冲一次 |
| **政府机构 · 监管运营** | 政 | 第 1–7 阶段 | ★ 唯一全程不退场的政府角色 |
| **资金** | 钱 | 第 1–7 阶段 | ★ 三次高峰：投决/合同 → 采购施工 → 资产化 |
| **土地与物业** | 物 | 第 1–7 阶段 | ★ 唯一全程且不换人的资源 |
| **客源与市场** | 市 | 第 1–7 阶段 | 投研定结构、运营定深度，中间断档 |
| **品牌与技术系统** | 技 | 第 1–7 阶段 | ★ 从选品牌转为兑现品牌，S9 后形态改变 |

**三条跨资源耦合（图中以虚线连接）**

1. **账期 → 负债**：筹建阶段的供应商账期设计，直接决定开业后的负债结构与资产化时的现金流表现
2. **系统不通 → 拖爬坡**：筹建/筹备阶段的弱电、网络、客控、PMS 联调完成度，决定运营阶段起点
3. **年限 → 估值**：退出阶段的土地剩余年限，是评估值与存续期的第一约束

**★ 结构性发现：土地与物业是唯一全程且不换人的资源** —— 其余每一类都只在一段集中爆发，然后退场。
