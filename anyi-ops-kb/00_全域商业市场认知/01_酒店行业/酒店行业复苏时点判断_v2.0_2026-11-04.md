# 中国酒店行业复苏时点判断 v2.0

> **一句话结论**：**中国酒店业的「复苏」已经发生了，但不在经营端，而在资本端。**
> **经营端（RevPAR 同比转正）大概率落在 2027 年下半年，窗口最宽在 2027H2–2028H1；完整行业性复苏要到 2028 年，且形态是「温和 + K 型分化」，不是 2016 式全面爆发。**
> **供给端出清基本完成的时点 ≈ 2027 年中 —— 这是复苏时点的真正决定变量。**

---

## 0. 先把「复苏」拆成四层，否则是伪问题

| 层 | 定义 | 当前状态 | 我的时点判断 | 置信度 |
|---|---|---|---|---|
| **L1 经营复苏** | 行业 RevPAR 同比转正 | **未转正**，Q3 仍负 | **2027H2（最可能）～ 2028H1** | 🟡🟡 中等偏高 |
| **L2 资本复苏** | 资产交易、REITs、并购定价修复 | **已发生**（2026 年内） | **已到** ✅ | 🟢🟢 高 |
| **L3 供给出清完成** | 新增供给增速收敛至需求增速以下 | 进行中，2027 年中完成 | **2027 年中** | 🟡🟡 中等 |
| **L4 全行业回报修复** | 业主重新愿意开新店、非连锁单体也能活 | 未到 | **2028 年**，且大概率不完整 | 🟡 单源偏低 |

**★ 为什么必须分层**：L2 已经发生（酒店交易额 YoY **+224%**、REITs 破冰、并购估值倍数上行），而 L1 还在负增长。**这两件事同时为真，不矛盾 —— 资产市场永远领先经营 4–6 个季度。** 把"复苏了吗"当成一个问题问，答案必然自相矛盾。

## 2. ★ 推理链：我是怎么得到这个结论的

### 第一步：先定义机制，再定时间（而不是先猜年份）

我从 v1.0 底稿继承了一个核心判断，并认为它在本轮成立：

```
旧范式（增量时代）                  新范式（存量时代）
─────────────────────             ─────────────────────
需求爆发 → 房价涨                  需求平淡 → 房价难涨
供给无序扩张                      供给主动收缩
周期上行 → 全行业普涨              收缩出清 → K 型分化
规模效应决定胜负                    单店效率 + 运营能力分层决定胜负
```

**★ 推论（本回答的立论基础）**：本轮复苏的**时点由供给出清速度决定，不由需求爆发决定**。
→ 这把"什么时候复苏"从一个不可预测的问题（需求何时爆发），转成一个**可跟踪的慢变量问题**（新增供给何时收敛）。
→ **慢变量比快变量可靠** —— 这是全篇方法论的核心。

### 第二步：定位供给出清的时钟

- **2024–2025 是新店开业高峰** → 这批新店在 2026–2028 处于爬坡期，持续吃 OCC 与价格
- **2026 新开业减少 + pipeline 收缩** → 供给增速开始下台阶
- 供给对价格的压制有 **2–4 个季度滞后**（当年增量压价，次年消化完才松）
- **推论：2027 年供给增速显著低于 2024–2025 → 2027H2 价格压力缓解 → RevPAR 同比转正**

### 第三步：用资本端做交叉验证（领先 4–6 个季度）

- 2026 H1 酒店交易额 **+224%**（历史级）
- REITs 破冰 + 中金开元旅业 9 月获批 + 维也纳 PE 翻倍到 14.9x
- **→ 资本端在 2026 年集体转向"买酒店资产"。资本不是买贵了，是在抢一个即将修复的资产类别。**
- **推论：2026 年资本转向 → 领先 4–6 个季度 → 2027 年经营端确认**

### 第三步补强：出现第一个"结构性先行板块"

锦江 Q3：**重改门店 RevPAR +14.9%**，前三季度完成 **500 多家加盟酒店梯度改造**。
**→ 这是本轮最有价值的单一数据：它把"存量翻新"从叙事变成了可验证的经营数据。**
**→ 且它出现在行业最差的时点（Q3 整体 -2%），说明这是能力差异，不是周期红利。**

### 第四步：检验"会不会更早"（我为什么不选 2026 年底）

反对 2027H1 之前复苏的三条硬约束：
1. **Q4 是淡季 + 国庆高基数**：Q4 同比读数会被 2026 国庆（出租率>90%、房价 +3.36%）的高基数压住 → **2026Q4 转正的概率低**
2. **成熟店还在恶化**：首旅成熟店 RevPAR -7.8%、Occ -2.9pct → **存量经营压力尚未触底**
3. **供给仍在爬坡**：2024–2025 开的新店要到 2027 才能全部度过爬坡期
**→ 所以 2027H1 之前转正的概率我给 25–30%。**

### 第五步：检验"会不会更晚 / 中间反复"

三条风险：
1. **价格战重启**：房企与民企甩卖资产 → 激进开店 → 供给重新过剩
2. **宏观消费走弱** → 二次探底
3. **会议与国际商务需求持续疲软**（景气 -46 / -31）→ 若这两块不回，B 端需求就撑不住 RevPAR
**→ 我给「2028 年内未发生/二次探底」约 10%。**

### 第六步：用"最可能错的答案"反向检验

如果我是错的，最可能错在：**把资本端的 +224% 交易额当成需求复苏的证据**。
**→ 但我把它归为 L2（资本复苏）而非 L1（经营复苏），所以即使这个归类错了，L1 的时点判断也不受影响。**
**→ 这也是我为什么坚持四层拆解 —— 它让我的结论对单个信号的误判不敏感。**

## 3. ★ 时点结论（概率区间，不给单点）

| 时点窗口 | 概率 | 触发条件 |
|---|---|---|
| **2026Q4–2027Q1**（经营端提前转正）| **25–30%** | Q4 淡季房价同比仍正 + 四大集团 pipeline 继续收缩 |
| **2027 年内，最可能在 2027H2** | **45–50%** | ① 2026Q4–2027Q1 连续两季 MSI 回升；② 头部同店 RevPAR 转正；③ 成熟店 RevPAR 降幅收窄至 -3% 以内 |
| **2028 年内** | **20–25%** | 供给出清完成但需求端持续平淡 → 温和复苏 |
| **不发生 / 二次探底** | **10%** | 价格战重启 + 宏观走弱 |

**供给出清完成时点（独立判断）：2027 年中。置信度 🟡🟡。**
