# 高桌大椅源流 · 中西两条线 v1.0

> **结论**：**「高桌大椅」有两义，必须拆开 —— 一条是宋代的本土源流，一条才是明末清初的西式传入。**

---

## 一、A 线 · 中式高脚桌 + 高背椅（宋代成型，本土源流）

| 时期 | 关键 | 硬证据 / 说明 |
|---|---|---|
| 汉代 | **胡床 / 马扎** —— 西域传入的**折叠**坐具 | 中国最早的椅子雏形，但是折叠凳，不是高背椅 |
| 唐代 | 有靠背扶手的坐具正式被称为「**椅**」 | |
| **宋代** | **交椅**成熟；**席地而坐 → 垂足坐** 普遍化 | ★ **决定性证据：椅子与高桌普及后，窗棂被抬高**，建筑随坐姿改造 |
| 明代 | **交椅 / 圈椅（罗圈椅）/ 官帽椅** 并称三大椅式 | |
| 明清 | 官帽椅成文士标配；**太师椅**之名源于宋代秦桧 | |

**宋代同步发生的餐饮革命**：从「每人一张矮几」改为「**围坐高桌**」—— 这才是完整的"高桌大椅"形态。

---

## 二、B 线 · 西式 dining table & high chair（明末清初传入）

| 阶段 | 事实 |
|---|---|
| **17 世纪（明末清初）** | 随**西方传教士**（汤若望在华 47 年）与**澳门、广州商船**传入，最早落在**广州、澳门** |
| **18 世纪中叶起（清乾隆前后）** | **广式家具**明确受西方影响，延续至 20 世纪初；**广州十三行**为通道，**粤匠沿一德水道**一带作坊把西式元素融进传统红木家具（酸枝、紫檀等硬木 + 繁雕）|
| **晚明清初** | **苏州、松江**出现西式家具作坊；晚清民国形成受西方影响的「苏式家具」|
| 1793 | 马戛尔尼使团礼品陈列**圆明园**，是中西交流场景（**不直接构成传入证据**）|
| 清宫 | **养心殿**等以传统中式家具为主，西式元素属后期引入 |

---

## 三、反直觉的核心结论

**中国宋代（11–13 世纪）就完成了「高桌 + 高背椅 + 围坐」的整套形态；欧洲要到 16–17 世纪才完成从矮长凳 / 板条到 dining table + chair 的转变。**

所以严格讲：**
- 「高桌大椅传入中国」这个说法**只在 B 线（西式成套家具）成立**
- 而且它传进来时，**中国早就有自己的高桌大椅了**
- 真正被"传入"的是 **西式的成套比例与装饰语汇**（高背、旋木腿、织物坐面），**不是"高脚桌+椅子"这个形态本身**

## 四、空间选型的两条路线（实用）

| 你要的效果 | 该走哪条线 | 具体语言 |
|---|---|---|
| **中式的体面**（书房/宴席/国宾）| A 线 · 宋代以降的低桌高椅秩序 | **案 / 几 + 圈椅 / 官帽椅**；讲究"主位—宾位—侧位"的礼序对称 |
| **西式的松弛**（餐厅 / 大堂 / 会客）| B 线 · 17–18 世纪成套比例 | **长桌 + 高背椅**，但底子用**中式硬木 + 榫卯**（比全西式更耐看）|
