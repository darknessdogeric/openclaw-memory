# 酒店资产四层定价框架 v1.0

> **定位**：`00_全域商业市场认知/02_资本资产金融/` 的**核心方法论**文件
> **用途**：判断任何一笔酒店/文旅资产交易「买贵没」的**强制四层拆解**
> **来源**：2026-10-25 同程收购万达酒管实战（首次完整走通四层）

---

## 0. 为什么需要框架

市场判断一笔交易贵不贵，只用**一个维度**（倍数），必然被操纵：
- 卖方选**盈利最低的一年**做分母 → 倍数偏低 → 显得"公允"
- 媒体只报**可比公司区间** → 不查分母口径
- 没人查**同一标的历史成交价**
- 没人算**买价隐含了多少永续增长**

**四层框架的强制顺序：先倍数 → 再历史 → 再现金流 → 再管道。**
**任何一层没算完，不得下"贵/不贵"的结论。**

---

## 第一层｜可比倍数层

### 1.1 步骤
1. 收集可比公司名单（**必须写出来**）
2. 确认**每个可比公司的分子口径**（EV 定义：是否含净现金/租赁负债）
3. 确认**每个可比公司的分母年份与调整项**
4. 确认标的自身的**分母年份与调整项**
5. **最后才比**

### 1.2 三个必查陷阱

| 陷阱 | 表现 | 破法 |
|------|------|------|
| **分母年份选择** | 用盈利最低年做分母 | **改用"正常化盈利年"**（3–5 年平均或最近完整年）|
| **一次性损益** | 减值/重组/上市费同时压低 EBITDA 与净利 | 明确"是否经调整"，并**同时看未调整数** |
| **可比公司不真可比** | 给了高增长公司的倍数 | **拆开看：倍数 = 增长 + 确定性 + 流动性溢价** |

### 1.3 万达案实战
```
标的自称：9.5× 2023 经调整 EBITDA（🟡🟡 媒体口径）
媒体可比：亚朵 19.8x｜华住 10.5x｜锦江 9.2x｜首旅 7.0x → "9.5x 适中公允"

但标的实际：
  2023 税后净利 2156.3 万港元（异常低点）
  2024 税后净利 1.48 亿港元
  2024 营收 8.9 亿港元

→ 用 2024 实际数重算：
  P/E = 24.97 亿 ÷ 1.36 亿人民币 ≈ 18.4x
  P/S = 24.97 亿 ÷ 8.2 亿人民币 ≈ 3.05x
→ 拿的是亚朵的倍数（19.8x），卖的是锦江的增长（9.2x 那一档）
```

**⚠️ 本层结论**：倍数"公允"的说法，**在分母口径不透明时不成立**。

## 第二层｜历史锚点层

### 2.1 步骤
1. 查**同一标的**（同股权、同范围）的历史成交价与日期
2. 查**同期标的的盈利变化**
3. 算**价格年化涨幅** vs **盈利年化涨幅**
4. 判断：是**资产真增值**（好）还是**估值抬升**（泡沫）

### 2.2 万达案实战
```
2017-08-09  万达酒管 100% 股权注入上市公司 → 作价 7.5 亿元
2025-04-17  同程收购同一标的 100% 股权 → 24.973 亿元
              8 年 3.33 倍，年化 +16.1%
同期盈利：2023 净利 2156 万 → 2024 净利 1.48 亿（6.9 倍）
```

**⚠️ 关键矛盾（本层最有价值的发现）**：
> 卖方 2024 年对万达酒店发展计提**大额减值**（导致 9.89 亿港元亏损），2025 年因"**上年大额减值不再出现**"而扭亏至 17.5–19 亿港元。
> **这意味着：7.5 亿（2017 注入价）是减值前口径，1.48 亿（2024 净利）是减值后口径。两个口径不能同时为真。**
> → **买方买的是减值后的资产，却按减值前的历史价作参照做比较，是错的。**
> → 反过来也要说：**万达当年 7.5 亿卖得极便宜，这本身就是资产价值的证据**。所以"贵"不是全部。

---

## 第三层｜现金流折现层

### 3.1 步骤
1. 取标的**正常化净利**（不是买当年的）
2. 选定**要求回报率**（国资平台通常 ≥10%）
3. **反推买价隐含的永续增长率 g**（这是本层核心动作）
4. **把 g 与行业阶段对照**：增量建设期 vs 存量效率期
5. 跑 **RevPAR −10% / −20% 压力情景**下的 g 是否还成立

### 3.2 反推公式
```
买价 = 正常化净利 × (1+g) / (要求回报率 − g)
```

### 3.3 万达案实战
```
买价 24.97 亿 ｜ 正常化净利 1.36 亿人民币 ｜ 要求回报率 10%

  g=0%  → 合理价 13.6 亿（买价贵 83%）
  g=3%  → 合理价 20.0 亿（买价贵 25%）
  g=5%  → 合理价 28.6 亿（买价便宜 13%）

→ 买回 24.97 亿，标的净利必须 5% 永续复合。

行业阶段对照（2026H1，STR 🟢🟢/🟡🟡）：
  全国 ADR 292 元 +4.7%｜出租率 73.8% −1.2pp｜RevPAR 215.5 元 +4.6%（全靠 ADR）
  头部四大集团 pipeline 减少 → 供给降速，RevPAR 低个位数增长
  2025 国际集团在华全线下滑：万豪大中华区 ADR −0.2%、凯悦 −1.8%、洲际 RevPAR −1.6%
→ 行业已从增量转入存量效率，g=5% 永续是激进假设
```

**⚠️ 本层结论**：**"贵不贵"的真正判据不是倍数，是买价隐含的增长假设是否被行业阶段允许。**

## 第四层｜管道期权层（最容易被忽略）

### 4.1 步骤
1. 找出交易中的**隐含关联管道**（母集团/关联方带来的天然客源、物业、渠道）
2. 评估管道的**行权条件**（是否正在恶化）
3. 评估管道的**可转让性**（换业主后还在不在）
4. 把管道当**看涨期权**估值，而不是当资产

### 4.2 万达案实战
```
隐含管道：万达系自持酒店物业 → 天然优先给万达酒管管

但：
  ① 万达在持续卖物业（2017 卖 77 家；2025 已出售 26 座万达广场）→ 标的物在减少
  ② 万达 2025 商管重组引入 600 亿战投（中东主权基金）→ 母体在重构，管道归属会变
  ③ 物业易主后，业主必然重新比价（同程 vs 华住/锦江/首旅）
→ 管道不是资产，是行权价逐年抬高的看涨期权
```

**⚠️ 本层结论**：**管道是期权，会折损。把它按资产计价就一定高估。**

## 框架总表（可复用）

| 层 | 问题 | 万达案答案 | 结论 |
|---|------|-----------|------|
| 1 可比倍数 | 倍数与可比公司比如何？ | 9.5x 看似公允；实为 18.4x PE | 口径不透明时不可信 |
| 2 历史锚点 | 同一标的历史卖过多少？ | 7.5 亿 → 24.97 亿，8 年 3.33x | 资产真增值，但两口径不可混用 |
| 3 现金流折现 | 买价隐含多少永续增长？ | 需 5% 永续；行业只给低个位数 | **偏贵** |
| 4 管道期权 | 隐含管道在增值还是折损？ | 万达持续卖物业 → 折损 | **偏贵** |

**综合**：账面公允 / 现金流偏贵 / 管道折损 → **期望值 ≈ 0 到略正**。

## 强制动作清单（每次交易分析必做）

```
□ 1. 写下可比公司名单 + 每个的分子分母口径
□ 2. 用"正常化盈利年"重算标的倍数，与可比对齐
□ 3. 查同一标的的历史成交价，算价格年化 vs 盈利年化
□ 4. 反推买价隐含永续增长率 g，与行业阶段对照
□ 5. 跑 RevPAR −10% / −20% 压力测试下的 g 与偿债能力
□ 6. 找出隐含管道，评估行权条件与可转让性
□ 7. 定卖方动机：是"必须卖"（买方有议价优势）还是"想卖好价"
□ 8. 检查有无业绩承诺（无 = 买方独自承担经营风险）
□ 9. 确认买方有独家信息优势（否则为什么要买这个价）
□ 10. 每个数据点挂四档置信度
```
