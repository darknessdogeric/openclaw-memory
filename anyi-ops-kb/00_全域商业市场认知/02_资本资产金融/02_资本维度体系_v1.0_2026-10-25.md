# 酒店资本维度体系 v1.0

> **定位**：知识库 `00_全域商业市场认知/02_资本资产金融/` 三大维度体系之一
> **适用范围**：酒店与文旅资产的**资金侧**——资本结构、融资渠道、投资人、交易结构、估值方法、国资监管、退出路径
> **配套**：`01_资产维度体系`（资产侧）｜`03_金融维度体系`（财务侧）｜`04_四层定价框架`｜`05_信源矩阵扩展KLM`

## 0. 三条铁律

| # | 铁律 | 说明 |
|---|------|------|
| 1 | **资金用途优先于价格** | 国资平台的第一约束是"钱用来干什么、能不能交差"，第二约束才是买得贵不贵 |
| 2 | **倍数必须可复算** | 任何"估值公允"的说法必须给出：分子口径、分母年份、可比公司名单、调整项 |
| 3 | **买方与卖方立场必须先定** | 同一价格，卖方视角与买方视角结论可能完全相反；先定立场再算价格 |

## 1. A 组｜资本结构（9 项）

| # | 维度 | 口径 | 说明 |
|---|------|------|------|
| A1 | 总资产 | 账面 | 集团合并口径 |
| A2 | 总负债 | 账面 | |
| A3 | 资产负债率 | 负债/资产 | **国资平台硬约束**（多在 70%+）|
| A4 | 有息负债 | 短期借款+长期借款+应付债券 | 剔除经营性负债 |
| A5 | 净负债率 | (有息负债−货币资金)/资产 | 真实杠杆 |
| A6 | 授信总额 / 已用 | 银行口径 | 安逸：350 亿意向授信可达性 |
| A7 | 融资成本 | 加权平均利率 | 信用等级决定 |
| A8 | 到期结构 | 1年内到期占比 | 滚动风险 |
| A9 | 现金/短债 | 货币资金/1年内到期有息负债 | 流动性红线 |

**万达案例（🟢🟢 一手 · 2025 公告）**：万达集团把万达酒管 24.97 亿变现，**资金用于向全体股东分红（特别股息每股 46.2 港仙，2025-11-19 派发）**，目标是"去杠杆、减负债、优化资产负债结构"。→ **卖方动机是流动性，不是资产重估。**

## 3. C 组｜投资人视角（9 项）

| # | 维度 | 关注什么 | 门槛 |
|---|------|---------|------|
| C1 | 投资逻辑 | 现金流还是资产升值 | — |
| C2 | 收益来源 | 经营改善 / 资产重估 / 结构升级 | — |
| C3 | 退出路径 | 上市/REITs/并购/股权转让 | 必须**进场就设计好** |
| C4 | 回报要求 | IRR / 现金回报率 | 见 `03_金融维度体系` |
| C5 | 风险承担 | 谁兜底、谁承担周期 | 保底/回购条款 |
| C6 | 决策权 | 董事会席位/一票否决 | 国资基金要求 |
| C7 | 对赌与业绩承诺 | 有无、是否可达 | 绑定管理层利益 |
| C8 | 估值锚 | 投资人用什么倍数给价 | 与卖方预期是否一致 |
| C9 | 资金属性 | 财务投资人 / 产业投资人 / 战略投资人 | 决定能给什么资源 |

**⚠️ 卖方 vs 买方预期差（核心认知）**：
- 卖方要**回笼资金 + 交差**，希望高价、干净、快速
- 买方要**验证质量 + 压低对价**，愿意慢、愿意做尽调
- **当卖方"必须卖"时，买方有议价优势；当卖方"想卖好价"时，买方没有。**
- 万达案：万达引入 600 亿战投（流动性改善）→ 卖方不急 → **议价空间有限**；但同程用 OTA 交易数据做了**质量验证**，等于把自己的信息优势变现了。

## 4. D 组｜交易结构（10 项）

| # | 维度 | 说明 | 关键风险 |
|---|------|------|---------|
| D1 | 股权 vs 资产 | 买股权保留历史责任 | 或有负债/税务风险 |
| D2 | 100% vs 控股 | 少数股权无控制权 | 无法并表 |
| D3 | 分步交割 | 首次付款+期权 | 卖方履约风险 |
| D4 | 对赌/业绩承诺 | 卖方担保未来业绩 | 无承诺=买方全担风险 |
| D5 | 价格调整机制 | Earn-out / 股权质押 | 分期付款设计 |
| D6 | 先决条件 | 审批/尽调/权属 | 交割延期风险 |
| D7 | 交割后过渡期 | 系统/品牌/人员切换 | 品牌与会员流失 |
| D8 | 或有负债承接 | 担保/诉讼/税务 | **易被忽略的大坑** |
| D9 | 员工与社保承接 | 国企改制核心难点 | 稳定运营前提 |
| D10 | 品牌与商标许可 | 是否随交易转移 | **无品牌=买了个空壳** |

**万达案实证**：
- 100% 股权、一次交割、无业绩承诺（🟡🟡 媒体口径，🟠🟠 公告未见业绩承诺条款）
- 交割日由 2025-09-30 **延至 10-31**（"部分先决条件未达成"）→ D6 风险真实发生
- 万达品牌**保持独立发展**，不并入同程品牌体系 → 品牌独立性是交易条件之一
- 万达自持酒店物业**仍由万达持有** → 物业与管理的分离（呼应 `01_资产维度体系` 资产三分法）

## 5. E 组｜估值方法与倍数（10 项）

| # | 维度 | 口径 | 参考区间（2026） |
|---|------|------|------------------|
| E1 | EV/EBITDA | 企业价值/经调整EBITDA | 亚朵 19.8x｜华住 10.5x｜锦江 9.2x｜首旅 7.0x（2023 口径，🟡🟡 媒体汇总）|
| E2 | P/E | 市值/净利 | 酒店股普遍 15–25x |
| E3 | P/S | 市值/收入 | 酒管 2–4x |
| E4 | P/房 | 市值/客房数 | 连锁 30–80 万元/间 |
| E5 | 单店价值 | 交易价/门店数 | 区域差异极大 |
| E6 | 品牌授权倍数 | 授权费/品牌营收 | 3–8% |
| E7 | 管理费倍数 | 管理费收入倍数 | 8–15x |
| E8 | DCF 隐含增长 | 买价反推的永续增长 | **算出来才有意义** |
| E9 | 账面溢价 | 交易价/账面净资产 | 国资红线（须备案）|
| E10 | 历史锚 | 同一标的历次成交 | **最容易被忽略的维度** |

**⚠️ 倍数使用的三个陷阱**：
1. **分母年份选择** —— 用盈利最低的一年做分母 = 倍数天然偏低（万达案：2023 净利 2156 万 vs 2024 净利 1.48 亿，7 倍差）
2. **一次性损益未调整** —— 减值/重组/上市费用会同时压低 EBITDA 与净利，须明确是否"经调整"
3. **可比公司不真可比** —— 亚朵 19.8x 买的是高增长确定性，万达酒管拿同样倍数是"拿了亚朵的价，卖锦江的增长"

## 6. F 组｜国资监管与交易流程（12 项）— 安逸 1244 专项

| # | 环节 | 要求 | 关键风险 |
|---|------|------|---------|
| F1 | 资产评估 | 第三方机构、备案有效 | 基准日与有效期 |
| F2 | 评估备案值 | 交易不得低于备案值 | 溢价过高=未来减值 |
| F3 | 进场交易 | 产权交易所公开挂牌 | 溢价空间受限 |
| F4 | 审计与验资 | 专项审计 | 或有负债 |
| F5 | 决策程序 | 党委会/董事会/股东会 | 分级授权 |
| F6 | 主管部门批准 | 省级国资委/省旅投 | 时间不可控 |
| F7 | 反垄断申报 | 经营者集中 | 附条件批准风险 |
| F8 | 外商投资审查 | 涉外资 | 负面清单 |
| F9 | 国有资产评估备案 | 国资委 | — |
| F10 | 人员安置方案 | 职工代表大会 | 改制核心难点 |
| F11 | 债权债务处理 | 同步划转 | 隐性负债 |
| F12 | 交割与权属变更 | 工商/不动产登记 | 尾款与风险敞口 |

**⚠️ 国资交易的时间成本**：万达案从 4/17 公告到 10/16 交割 = **6 个月**，且延期过一次。→ **任何"快钱"假设在国资体系内都不成立，现金流规划要按 6–12 个月预留。**
