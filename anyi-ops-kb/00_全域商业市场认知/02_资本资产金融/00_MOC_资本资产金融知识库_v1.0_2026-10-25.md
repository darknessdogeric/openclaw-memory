# 资本 · 资产 · 金融知识库 MOC v1.0

> **一句话**：这是知识库从「**行业运行侧**」扩展到「**资本交易侧**」的第一块拼图。
> 01_酒店行业 告诉你**市场在怎么运行**；本库告诉你**一个标的值多少钱、谁在买、钱怎么还、风险在哪**。

---

## 0. 为什么必须建这个库

2026-10-25 分析「同程 24.97 亿收购万达酒管」时暴露的能力缺口：

| 缺什么 | 具体表现 | 后果 |
|--------|---------|------|
| **估值口径判断** | 分不出 9.5x（2023 基数）与 18.4x PE（2024 实际）的差别 | 被"公允"二字带走 |
| **历史价格锚** | 不知道同一标的 2017 年作价 7.5 亿 | 无法分辨"资产增值"与"估值泡沫" |
| **现金流折现** | 不会反推买价隐含的永续增长率 | 算不出"贵"的真正判据 |
| **隐含管道** | 识别不出"万达物业优先给万达酒管管"是期权不是资产 | 把正在折损的期权按资产计价 |
| **国资交易流程** | 不知道进场交易/评估备案/6 个月交割周期 | 现金流规划失真 |

**根因**：A–J 十类信源是**行业运行侧**的，缺 K/L/M 三类**资本交易侧**的。

## 3. 核心方法论：四层定价框架（必读）

> **强制顺序：可比倍数 → 历史锚点 → 现金流折现 → 管道期权。任一层未算完，不得下"贵/不贵"结论。**

| 层 | 核心问题 | 万达案答案 |
|---|---------|-----------|
| 1 可比倍数 | 倍数与可比公司比如何？分母口径是什么？ | 9.5x 看似公允 → 18.4x PE |
| 2 历史锚点 | 同一标的历史卖过多少？价格涨幅 vs 盈利涨幅？ | 7.5 亿 → 24.97 亿，8 年 3.33x；但两口径不可混用 |
| 3 现金流折现 | 买价隐含多少永续增长？行业阶段允许吗？ | 需 5% 永续；行业只给低个位数 → **偏贵** |
| 4 管道期权 | 隐含管道在增值还是折损？ | 万达持续卖物业 → **折损** |

**10 条强制动作清单**见 `04` 文件末尾。

## 4. 与 1244 战略的接口（本库的战略价值）

> **⚠️ 使用限定（2026-10-25 补注）**：本节是**安逸侧内部落地映射**，仅当任务被指定为“安逸线”时启用。
> **本库的通用用法不绑定安逸** —— 资本/资产/金融三维度的分析对象可以是任何酒店集团、任何区域平台、任何并购标的。
> 详见 `IDENTITY.md → Eric 工作规范 v2.0（视角隔离）` 与 `memory/B166ER判准 v1.2 → #51–55`。

1244 的四大业务支柱中，**「酒店资产管理」本质就是资本/资产/金融三体系的业务化**。本库已按 1244 的语言预置了对应维度：

| 1244 表述 | 本库对应 |
|---|---|
| 酒店运营管理（经营面·单店 GOP） | `01` C 组 C7 GOP 率 ｜ `03` A 组 A4 |
| **酒店资产管理（价值面·资产收益率）** | `01` C 组 **C1 资产收益率 / C2 保值增值率 / C3 闲置盘活率** |
| 中央集采（安逸购） | `03` F 组 F5 供应链金融 |
| 特色餐饮（川香楼） | `01` A 组 A4 附属经营面积 |
| **轻重分离改革** | `01` **G 组 9 项专项**（含分离的三个前置条件）|
| 央国企差旅采购（350 亿授信） | `02` A 组 A6 授信 ｜ `03` D 组 D7 担保风险 |
| 会员>600 万 / 复购≥25% / 中央预订≥35% | `01` F 组 F2 会员体系 |
| **业财结合+财务共享体系** | `03` **G 组 10 项专项**（含"业财不统一则两平台报表不可比"的前置警示）|

**⚠️ 两条硬结论已写入维度体系**：
1. **轻重分离的三个前置条件**：权属先清 → 激励先立 → 系统先通（`01` G 组）
2. **业财结合不是锦上添花，是分离的技术底座**（`03` G 组）
