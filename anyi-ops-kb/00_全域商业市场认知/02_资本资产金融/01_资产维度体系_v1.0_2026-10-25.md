## 0. 三条铁律（沿用区域市场维度体系）

| # | 铁律 | 说明 |
|---|------|------|
| 1 | **口径必须标注** | 每个数据点标注「数据期间 / 口径 / 置信度」，跨期比较须同口径 |
| 2 | **资产 ≠ 经营** | 物业资产（重）与管理资产（轻）是两类资产，估值方法、风险特征、变现路径完全不同，**不得混谈** |
| 3 | **不可比即标注** | 无同比 / 无公开基准者标注「未公开」，**不得推算填空** |

**资产三分法（本文的底层结构）**：

```
重资产（物业）        轻资产（管理）         无形资产（品牌/会员/数据）
├─ 现金流靠 RevPAR   ├─ 现金流靠管理费     ├─ 现金流靠溢价与复购
├─ 风险=周期与利率     ├─ 风险=加盟商与品牌   ├─ 风险=心智稀释
├─ 变现=REITs/出售     ├─ 变现=股权/授权     ├─ 变现=品牌授权
└─ 评估=收益法为主     └─ 评估=倍数法为主     └─ 评估=收益分成法
```

## 1. A 组｜资产分类与权属（8 项）

| # | 维度 | 说明 | 关键指标 |
|---|------|------|---------|
| A1 | 资产类型 | 自有/租赁/委托管理/合资 | 各类型门店数与客房数占比 |
| A2 | 产权性质 | 国有/集体/民营/外资/混合 | 产权主体数 |
| A3 | 土地属性 | 出让/划拨/租赁/集体 | 剩余年限、到期处置方式 |
| A4 | 建筑面积 | 地上/地下/附属经营面积 | 总建面与客房面积比 |
| A5 | 证照状态 | 土地证/规划许可/消防/特种设备 | 证照齐备率、临期数量 |
| A6 | 抵押与查封 | 有无抵押/查封/租赁备案 | 抵押余额、权利限制 |
| A7 | 权属集中度 | 同一业主持有的门店数 | 关联交易占比 |
| A8 | 划转与交易历史 | 划转/无偿划转/债转股 | 近 3 年资产变动 |

**安逸映射**：1244 战略的「重资产管理平台」对应 A1/A3/A5/A6 —— 集团管物业、保增值，核心是**A3 土地年限 + A6 权利限制**两个风险位。

## 2. B 组｜资产估值（10 项）

| # | 维度 | 方法 | 说明 |
|---|------|------|------|
| B1 | 收益法估值（DCF） | 未来现金流折现 | 主体方法，WACC/永续增长率敏感 |
| B2 | 成本法 | 重置成本/清算价值 | 资产重、收益差时的下限参考 |
| B3 | 市场法 | 近期成交案例修正 | 流动性差时误差大 |
| B4 | EV/EBITDA 倍数 | 同行可比 | 需剔除一次性损益 |
| B5 | 单房价值 | 每间客房单价 | 区域对比最直观 |
| B6 | 收益倍数 | NOI/资本化率 | 资本化率是市场情绪温度计 |
| B7 | 品牌溢价 | 管理合同溢价 | 品牌对物业价值的溢出 |
| B8 | 评估增值率 | 交易价 vs 账面净资产 | 国资交易的**红线指标** |
| B9 | 评估备案值 | 第三方评估机构 | 实际成交不得低于备案值 |
| B10 | 交易税费承担 | 增值税/土增税/所得税 | 隐性成本常被忽略 |

**⚠️ 核心陷阱（B8）**：评估增值率过高 = 未来减值压力；过低 = 国有资产流失风险。**国资交易必须同时满足「不低于评估备案值」和「有理由」**。

## 3. C 组｜资产运营效率（10 项）

| # | 维度 | 公式/口径 | 说明 |
|---|------|----------|------|
| C1 | 资产收益率 | NOI / 资产原值 | 重资产平台**核心考核**（1244 已定）|
| C2 | 保值增值率 | (期末值−期初值)/期初值 | 1244 已定核心指标 |
| C3 | 闲置盘活率 | 已盘活闲置资产 / 闲置资产总额 | 1244 已定核心指标 |
| C4 | 出租率 OCC | 已售/可售 | 全档位 + 分档位 |
| C5 | 平均房价 ADR | 客房收入/已售房晚 | 与 C4 组合看 RevPAR |
| C6 | 每房收益 RevPAR | 客房收入/可售房晚 | 资产效率的最终表达 |
| C7 | GOP 率 | (收入−运营成本)/收入 | 单店盈利能力 |
| C8 | 资本化率 Cap Rate | NOI/资产市值 | 越高=市场越悲观 |
| C9 | 管理费率 | 管理费/收入 | 轻资产平台的变现效率 |
| C10 | 资产周转率 | 收入/资产总值 | 跨业态对比用 |

**双平台对照（轻重分离的必然产物）**：
```
重资产平台看 C1/C2/C3（资产收益率/保值增值/盘活率）
轻资产平台看 C9（管理费率）+ 门店净增 + 会员规模
```

## 4. D 组｜资产证券化与循环（8 项）

| # | 维度 | 说明 | 门槛参考 |
|---|------|------|---------|
| D1 | 酒店类 REITs | 产权 + 经营权，成熟物业退出 | 需连续运营 ≥3 年、现金流稳定 |
| D2 | CMBS | 酒店物业抵押证券化 | 依赖 LTV 与 DSCR |
| D3 | 类 REITs（酒店资产支持） | 经营权也可证券化 | 中国尚在试点阶段 |
| D4 | 供应链金融 | 应收/预付账款融资 | 依托集团采购/集采平台 |
| D5 | 酒店资产 ABS | 特定收费权/委托管理收益权 | 需可预测现金流 |
| D6 | 基金合作 | 酒店资产基金/战略投资人 | 出资方带渠道或运营能力 |
| D7 | 资产划转 | 国资无偿/有偿划转 | 需评估备案 + 审批 |
| D8 | 债转股/纾困 | 债务化解路径 | 地方国资主导 |

**关键认知**：酒店是**重运营 + 长久期**资产，天然适合 REITs（长久期现金流）。但**中国酒店类 REITs 的核心瓶颈不是资产，是运营稳定性**——一旦 RevPAR 波动，出表与再表都成问题。

## 5. E 组｜资产风险与减值（10 项）

| # | 维度 | 触发信号 | 后果 |
|---|------|----------|------|
| E1 | 商誉/无形资产减值 | 收购溢价过高 + 业绩不达 | 直接吞噬当期利润 |
| E2 | 固定资产减值 | 单店长期亏损 + RevPAR 下行 | 需资产组减值测试 |
| E3 | 土地/无形资产到期 | 划拨地到期无法续 | 经营基础消失 |
| E4 | 证照与合规风险 | 消防/特种设备/环保 | 停业整改 |
| E5 | 抵押与担保风险 | 集团担保链 | 交叉传染 |
| E6 | 关联交易与利益输送 | 同一体系内交易定价 | 审计与合规风险 |
| E7 | 业主集中风险 | 单一业主持有多店 | 续约与议价风险 |
| E8 | 加盟商风险 | 加盟商现金流断裂 | 管理合同中断、品牌受损 |
| E9 | 保险与灾害风险 | 自然灾害/火灾 | 财产与停业双损 |
| E10 | 利率与再融资风险 | 存量债务滚动 | 高杠杆资产被动处置 |

**万达酒管案的实证**：万达酒店发展 2024 年 **9.89 亿港元亏损**（含大额减值）→ 2025 年因「**上年大额减值不再出现**」+ 卖万达酒管而扭亏至 **17.5–19 亿港元**。🟢🟢 一手（公司公告）

> **这条是本知识库最有价值的资产侧教训**：**卖方自己减值过的资产，买方按减值后口径接手；卖方当年注入时的价格（7.5 亿）是减值前口径。两个口径不能同时为真。**

## 7. G 组｜轻重分离与资产运营（9 项）— 安逸 1244 专项

| # | 维度 | 重资产平台 | 轻资产平台 |
|---|------|-----------|------------|
| G1 | 核心定位 | 管物业、保增值 | 做品牌、拓托管 |
| G2 | 考核指标 | 资产收益率 / 保值增值率 / 闲置盘活率 | 管理费收入 / 门店净增 / 会员规模 |
| G3 | 权责边界 | 人 / 财 / 业务独立 | 同 |
| G4 | 资产权属 | 集团持有 | 不持有（输出品牌与系统）|
| G5 | 收益来源 | RevPAR 租金 + 资产升值 | 管理费 + 品牌授权 + 集采 |
| G6 | 激励 | 保值增值挂钩 | 市场化激励 + 跟投 |
| G7 | 交易对手 | 业主 / 资方 | 业主 / 加盟商 / 资方 |
| G8 | 风险敞口 | 资产价格与周期 | 品牌与加盟商质量 |
| G9 | 协同接口 | 统一品牌标准 + 集采 + 会员 | 同 |

**⚠️ 分离的三个前置条件**（缺一即失败）：
1. **权属先清** —— 物业划转与债务出表必须先完成，否则轻重分离只是内部核算分账
2. **激励先立** —— 轻平台无资产=无抵押物，市场化激励需配套跟投/超额分享
3. **系统先通** —— 会员、集采、数字化中台统一，轻平台才不是空壳
