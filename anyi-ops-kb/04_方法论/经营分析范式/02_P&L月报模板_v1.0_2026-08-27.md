```
部门利润 = 部门收入 - 部门支出（人工 + 其他 + 销货成本）
```
**用途**： 评价每个部门的盈利能力 ### 2. Department Profit % 部门利润率
```
部门利润率 = 部门利润 / 部门收入
```
**典型基准**：
- 房务部： 65-75%（高）
- 餐饮部： 10-35%（低，受成本结构影响）
- 其他运营部： 负数（多为支持性部门） ### 3. GROSS OPERATING INCOME 营业毛利润（GOP）
```
GOP = 所有部门利润合计
```
**用途**： 评价酒店整体运营效率（不扣除管理费用） ### 4. GOP Margin 营业毛利率
```
GOP Margin = GOP / 营业总收入
```
**典型基准**：
- 经济型酒店： 30-40%
- 中端酒店： 35-45%
- 高端酒店： 40-50%
- 奢华酒店： 45-55% ### 5. Operating Profit 经营利润
```
经营利润 = GOP - 不可分配费用（A&G / S&M / Property 等）
```
**用途**： 评价扣除管理费用后的真实盈利能力 --- ## 五、关键 P&L 比率（财务健康度） | 比率 | 公式 | 良好基准 | 警戒线 |
|------|------|---------|--------|
| **GOP Margin** | GOP / 总收入 | 35-45% | <30% |
| **人工成本率（房务）** | 房务人工 / 房务收入 | <20% | >25% |
| **人工成本率（餐饮）** | 餐饮人工 / 餐饮收入 | <35% | >45% |
| **食品成本率** | 食品成本 / 餐饮收入 | <40% | >45% |
| **能耗成本率** | 能耗成本 / 总收入 | <8% | >12% |
| **ADR 增长 vs 出租率下降** | 同比比较 | 健康 | 危险 | --- ## 六、月报应用流程（Eric 的标准做法） ```
1. 月末结账（当月最后一天） ↓
2. 数据收集（48 张工作表自动汇总） ↓
3. 制作月报（套用模板） ├─ 实际 vs 预算 → 偏差分析 ├─ 当月 vs 去年 → 同比分析 └─ YTD vs 全年预算 → 进度跟踪 ↓
4. 部门经理 Review（每个部门利润） ↓
5. 总经理 + 财务 Review（GOP 整体） ↓
6. 集团上报（逸集团范式）
``` --- ## 七、与其他月报的关系 ```
经营分析月报（本文件）= 财务层面（P&L） ↓ 联动
经营分析月报（PPT/PDF）= 业务层面（出租率/ADR/客户） ↓ 联动
市场分析月报 = 市场层面（STR 竞争群/细分市场） ↓ 联动
预算调整 = 经营决策（次月预算调整）
