# B166ER 设计 DNA · 主动调用协议

> **编订**：2026-10-10（Eric 反馈"为什么做不到这种"后立刻落地）
> **本质**：从"被动内化" → "主动调用"。不是参考书，是我的本能。
> **范围**：所有 1080×1440 海报、笔记、视觉产物的默认基线。

---

## 一、调色板（默认深蓝紫 · GS V2 范式）

| 角色 | 色值 | 用途 |
|------|------|------|
| 背景主色 | `#0F1729` | 深蓝紫（替代纯黑） |
| 背景渐变中 | `#15203C` | 三段渐变中间色 |
| 背景渐变底 | `#0A1020` | 三段渐变底部 |
| 主文字 | `#E8E8E8` | 高对比白（不要纯白） |
| 强调蓝 | `#5B8FC9` | 数字徽章、关键数据 |
| 强调亮蓝 | `#7DB8E8` | 正文加粗、em 强调 |
| B 标金色 | `#C9A87C` | B 标环形 / 高亮 |

**铁律**：
- 学术/哲学/深度笔记类海报**默认使用这套配色**。
- ❌ 不用纯黑 `#000`（太硬）
- ❌ 不用纯白 `#FFF`（太亮）
- ❌ 不用暖色（红/橙）——破坏学术感

## 二、排版系统（8 栏网格 + 4:1 留白）

| 元素 | 规则 |
|------|------|
| 画布 | 1080×1440（3:4 朋友圈） |
| 边距 | 左/右 80px，顶 150-160px（避 B 标），底 140px（避 B 标） |
| B 标位置 | **左 (64, 54) 24px 圆 + 右 (1016, 1362) 24px 圆** |
| B 标与内容距离 | ≥80px（**绝不重叠**） |
| 顶/底 meta | 紧贴 B 标左右两侧 (left:104px, right:104px) |
| 字号阶梯 | 64 / 36 / 24 / 16 / 14 / 12 / 10（2:1 ~ 1.5:1 比例） |
| 段间距 | 1.5-2 倍行高（28-40px） |
| 主区 layout | `display:flex; flex-direction:column; justify-content:space-between`（**关键！保证均匀铺陈**） |

**铁律**：
- ❌ 不用 `margin: auto` 居中（容易挤一团）
- ✅ 用 `space-between` 让内容**自动**分布
- ❌ 段与段紧贴（视觉挤）
- ✅ 段间留 28-40px 呼吸

## 三、数字徽章（核心卡片化设计）

GS V2 范式精髓：每条要点用 01/02/03 + 数字徽章 + 标题 + 描述

```
┌──────────────────────────────────────┐
│ [01]  叠加态                          │
│       没落地之前，多种命运同时存在。   │
└──────────────────────────────────────┘
```

| 元素 | 样式 |
|------|------|
| 数字徽章 | 32px 圆角，背景 `#5B8FC9` 15% 透明，边框 1.5px `#5B8FC9`，数字 `#5B8FC9` |
| 标题 | 16-18px Noto Sans SC 700 |
| 描述 | 14px Noto Sans SC 400 opacity 0.78 |

---

## 四、字体（默认 Google Fonts + 思源）

| 用途 | 字体 | 字号示例 |
|------|------|---------|
| 大标题 | Noto Serif SC 900 | 64-88px |
| 副标题 | Noto Serif SC 400 | 20-24px |
| 正文 | Noto Sans SC 400 | 15-16px |
| 标签 | Inter 600 + letter-spacing | 10-12px |
| 数字 | Inter 900 | 32-64px |

**铁律**：
- 标题永远用 Serif（思源宋体）
- 正文永远用 Sans（思源黑体）
- 标签永远用 Mono 风 Inter + 大字距
- 数字永远 Inter 900（无衬线粗体）

## 七、Eric 通用偏好（已观察）

- 喜欢深蓝紫
- 喜欢 24-28px B 标（不抢主体）
- 喜欢 4 段均匀分布
- 喜欢主标题 64-88px
- 喜欢思源宋体 + 思源黑体组合
- 喜欢金/青绿点缀色
- **喜欢"宽留白" + "结构清晰"**（最关键）

## 八、反模式（绝对不能出现）

- ❌ 纯黑 `#000` 背景（太硬）
- ❌ 大红色块背景（破坏学术感）
- ❌ 多色混杂（视觉乱）
- ❌ B 标与内容重叠
- ❌ 段与段挤在一起
- ❌ 段间空隙过大（≥60px 视觉割裂）
- ❌ 字号乱序（如 64 → 24 → 48 → 16）
- ❌ 中文不用衬线（用思源宋体才有"高级感"）
- ❌ 数字用衬线（用 Inter 900 才有"力量感"）

---

## 九、自动化应用流程（每次产图时自动执行）

```
Eric 提需求（"做 X 海报/笔记"）
   ↓
自动判断场景类型（哲学/数据/推介/学术/朋友圈）
   ↓
自动套用本 DNA（配色 + 排版 + 字体 + 徽章）
   ↓
仅在用户特定要求时调整（不默认换色/换字体）
   ↓
渲染 → 校对 B 标不重叠 → 输出
```

**不再做的事**：
- ❌ 每次都搜索"之前的范式"（范式已在 DNA 里）
- ❌ 默认用纯黑/纯白（错）
- ❌ 用红色 B 标（太抢眼）
- ❌ 让 B 标和内容重叠

**DNA 一旦被引用，就被内化为本能**——这是 Eric 让我内化设计书的真正目的。
