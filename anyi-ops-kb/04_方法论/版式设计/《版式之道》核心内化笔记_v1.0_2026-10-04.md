## 二、5 大要素详解(可直接应用)

### 1. 视觉秩序

- **留白 ≠ 空白** = 视觉休止符(影响阅读停顿 200ms+)
- **对齐** 是基础中的基础(左对齐 / 居中 / 右对齐 / 网格对齐)
- **尺寸差** = 主信息与次信息的层级区分(2x/3x/1.5x 黄金比例)

### 2. 信息层级

| 层级 | 字号参考 | 字重 | 颜色对比 |
|------|----------|------|----------|
| H1 主标 | 96-120px | Black/900 | 强对比 |
| H2 副标 | 48-64px | Bold/700 | 中对比 |
| H3 区块标题 | 28-36px | SemiBold/600 | 中对比 |
| 正文 | 22-28px | Regular/400 | 弱对比 |
| 注释 | 16-18px | Light/300 | 弱对比 |

(具体数值因画布尺寸而变,**核心是阶梯比 ≈ 2:1**)

### 3. 阅读动线

- **西方**:Z 型(短文)/ F 型(博客/列表)
- **日本**:线性 + 呼吸点(每段一个停顿)
- **海报/封面**:对角线 + 焦点锚定
- **小红书 9:16**:上下垂直流,顶部 1/3 是焦点区

### 4. 字体组合

- **中文 + 英文**:中文用思源宋体 / 微软雅黑,英文用 Helvetica / Inter / Roboto
- **同族原则**:标题用 display font,正文用 text font
- **字号比**:标题 : 正文 ≈ 2.5 : 1 至 3 : 1
- **行距**:中文 1.5-1.7,英文 1.3-1.5
- **字距(中英文)**:标题 -0.02em,正文 0em,小字 +0.02em

### 5. 网格系统

- **8 栏基准网格**(最常用):1080px 画布 → 每栏 135px,间距 0
- **12 栏** 更细(网页):每栏 90px
- **3 栏**(杂志):左标题 / 中图片 / 右正文
- **破格**:90% 守格 + 10% 出格 = 焦点

## 三、5 类认知偏差(自检清单)

| 偏差 | 真相 |
|------|------|
| ❌ "抄风格就够" | ✅ 抄别人的骨架撑自己的肉,要看清规则再拆 |
| ❌ "留白 = 空着" | ✅ 留白是休止符,有"呼吸节拍"功能 |
| ❌ "网格 = 死板" | ✅ 网格是弹性约束,90% 守格 + 10% 出格 |
| ❌ "靠审美感觉" | ✅ 字号阶梯 / 网格坐标 / 字重组合码可量化 |
| ❌ "忽略中文特例" | ✅ 行末禁则 + 标点悬挂是中文排版关键补丁 |

| Eric 现有风格 | 对应书的风格 |

### 5.3 Eric 工作流可立即改进的 5 点

1. **加显式网格标注** — 每个范式画 8 栏网格叠加层,标记每个元素在哪栏
2. **建立字号阶梯表** — 每种画布尺寸一份字号阶梯(1080×1920 / 1080×1440 / 1920×1080)
3. **写中文排版规则卡** — 行末禁则 / 标点悬挂 / 全角半角统一
4. **做"失败对照图"** — 每个范式附 3 张失败版(过挤 / 失衡 / 信息层级混乱)
5. **加 B 标标准化** — 已经做了,继续优化位置 + 大小 + 风格统一

## 六、6 大创意风格 → Eric 应用场景映射

### 风格 01 高级反差感

- **Eric 场景**:品牌侧海报、B 端发布会主题、酒店对外主视觉
- **核心技法**:大字 vs 小字 5x,粗 vs 细,黑白 vs 彩色
- **代表案例**:国庆主海报(红色大字 + 黑色细字)
- **可立即改进**:加"字号阶梯表"对应 1920×1080 画布

### 风格 02 留白空间感

- **Eric 场景**:酒店高端品牌、研究报告封面、内部白皮书
- **核心技法**:>40% 画布留白,字号比 3:1,呼吸点
- **代表案例**:P10 米黄范式
- **可立即改进**:留白从"模糊感觉" → "明确百分比 + 区域"

### 风格 03 复古意象感

- **Eric 场景**:川宾改造、文创项目、民国风活动
- **核心技法**:衬线字体 + 纹样底图 + 暖色系
- **代表案例**:川渝双核报告
- **可立即改进**:加衬线中文字体(思源宋体),统一纹样风格库

### 风格 04 手绘活泼感

- **Eric 场景**:生活方式酒店、亲子、教育
- **核心技法**:手写体 + 不规则排版 + 暖色
- **代表案例**:暂无(待开发)
- **可立即改进**:引入中文手写体作为补充字体

### 风格 05 秩序明净感

- **Eric 场景**:企业报告、PPT 信息页、政务图
- **核心技法**:网格严整 + 字号阶梯 + 留白均匀
- **代表案例**:H1 报告封面
- **可立即改进**:网格显式化(每元素标"栏 N + 像素坐标")

### 风格 06 几何交错感

- **Eric 场景**:时尚、活动视觉、产品发布
- **核心技法**:几何形 + 文字穿插 + 错位
- **代表案例**:暂无(待开发)
- **可立即改进**:建立"几何形 + 文字"叠加模板库
