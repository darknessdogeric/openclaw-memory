## §1 策划五步（项目启动期）

### Step 1 · 战略意图（Why）
- 项目的战略母意图（3 个 Why 刨到底）
- 项目在集团战略中的位置
- 退出路径（IPO / 并购 / 永续经营 / REITs）

### Step 2 · 选址定位（Where + Who）
- 市场层级：全球 → 全国 → 区域 → 州市 → 区县 → 商圈 → 项目
- 客群画像：人口结构 + 收入 + 行为 + 客源结构
- 竞争地图：直接竞争 + 间接竞争 + 替代品 + 潜在进入
- 选址 11 维（详见项目调研范式）

### Step 3 · 产品定位（What）
- **4P**：Product / Price / Place / Promotion
- **4C**：Customer / Cost / Convenience / Communication
- 档次定位：奢华 / 高档 / 中高端 / 中端 / 经济型 / 民宿
- 品牌定位：单品牌 vs 多品牌；高端 vs 大众

### Step 4 · 商业模式（How）
- **BMC 九宫格**：
  - CS 客户细分 / VP 价值主张 / CH 渠道
  - CR 客户关系 / R$ 收入来源 / KR 关键资源
  - KA 关键活动 / KP 重要伙伴 / C$ 成本结构
- **盈利模式**：自营 / 委托管理 / 特许经营 / 租赁 / 资产出售
- **退出路径**：上市 / 并购 / REITs

### Step 5 · 估值与退出（Exit）
- 估值三法：成本法 / 市场法 / 收益法
- KPI 体系：入住率 / ADR / RevPAR / GOP 率 / 人房比 / 投资回收期
- 退出估值：FFO 倍数 / NOI 倍数 / EBITDA 倍数

## §2 定位核心工具

### 工具 A · 五力模型（Porter）

```
供应商议价（Bargaining Power of Suppliers）：高/中/低
买方议价（Bargaining Power of Buyers）：高/中/低
潜在进入（Threat of New Entrants）：高/中/低
替代品（Threat of Substitutes）：高/中/低
现有竞争（Competitive Rivalry）：高/中/低
```

**应用**：项目所在市场的五力决定项目的定价能力与利润率。

### 工具 B · STP（Kotler）

```
S 细分（Segmentation）：按人口/行为/地理/心理
T 目标（Targeting）：评估每个细分 → 选目标
P 定位（Positioning）：在客户心智中占独特位置
```

### 工具 C · 4P + 4C 对照

```
4P（营销者）：Product / Price / Place / Promotion
4C（消费者）：Customer / Cost / Convenience / Communication
映射：Product ↔ Customer｜Place ↔ Convenience｜Price ↔ Cost｜Promotion ↔ Communication
```

### 工具 D · BCG 增长矩阵

```
明星 (Stars)：高份额 + 高增长     → 加注
金牛 (Cash Cows)：高份额 + 低增长 → 收割
问号 (Question Marks)：低份额 + 高增长 → 选择性加注
瘦狗 (Dogs)：低份额 + 低增长     → 撤资
```

**应用**：判断现有项目/产品在矩阵中的位置，决定投资策略。

### 工具 E · 蓝海战略（Kim & Mauborgne）

四步动作框架：

```
1. 消除（Eliminate）：哪些行业内理所当然的因子应被剔除？
2. 降低（Reduce）：哪些因子应远低于行业标准？
3. 提升（Raise）：哪些因子应远高于行业标准？
4. 创造（Create）：哪些行业从未提供的因子应被创造？
```

### 工具 F · 三圈模型（Three Circles of Strategy）

```
谁是我的客户？（Customer）
我的对手是谁？（Competitor）
我何以不同？（Company）
三者重叠处 = 我的不可替代价值
```

## §5 失败模式

1. **战略意图不清** → 项目做着做着变形 → 回到 Why 3 层
2. **选址维度不全** → 用 11 维全覆盖清单，别只做 3 维
3. **客群画像模糊** → 不要「所有人都是客户」，要做 STP 选目标
4. **4P+4C 不对位** → 两套语言必须相互映射
5. **BMC 九格不全** → 9 格都要填，避免空白
6. **五力分析走过场** → 逐项打分（高/中/低 + 证据）
7. **估值三法只选一种** → 至少用两法交叉
8. **退出路径未明** → 起点定终点，IPO/并购/REITs 三选其一
9. **BCG 误判** → 用增长率与市占率两维数据，避免主观
10. **蓝海动作误用** → 四步动作必须配套（消除+降低+提升+创造）
