> **编制时间**：2026 年 9 月 16 日
> **用途**：对集团旗下酒店（或外部对标酒店）开展标准化经营诊断
> **素材来源**（6 份）：
> 1. 重庆丽苑维景国际大酒店《2023 年 1-6 月半年经营情况分析》（14 页 PDF）
> 2. 《丽苑维景 4 月及五一小长假经营分析》（15 页 PPT）
> 3. 《内部对标模版-高星》（4 sheet Excel）
> 4. 《2023 年丽苑维景全年营销日历》
> 5. 《2024 年 5 月经营情况分析》（PPT）
> 6. 《对标-高星-6 月》（4 sheet Excel）
> **诊断对象**：单店（集团旗下任一酒店，或外部对标店）

# 第一部分 诊断框架

## 1.1 五步诊断法

```
第一步  数据核验  →  数据是否完整、口径是否统一、是否存在失真
第二步  指标对标  →  与集团标值（4星/5星）及同档竞对对比
第三步  结构分析  →  收入结构、客源结构、成本结构
第四步  归因诊断  →  区分"市场原因 / 经营原因 / 资源原因 / 机制原因"
第五步  处方建议  →  分层开方（立即/短期/中期），明确责任与节点
```

## 1.2 三大诊断维度

| 维度 | 核心问题 | 关键指标 |
|------|---------|---------|
| **效益维度** | 赚不赚钱？效率如何？ | 收入、利润、GOP、毛利率、人均产值 |
| **结构维度** | 钱从哪来？结构健康吗？ | 客房/餐饮/其他占比、客源结构、渠道结构 |
| **能力维度** | 有没有自主获客能力？ | 会员贡献、官微占比、新媒体转化、复购率 |

## 2.2 收入数据（按板块，含实际/预算/去年同期）

| 板块 | 细项 |
|------|------|
| **客房** | 客房收入、出租间夜数、可出租间夜数 |
| **餐饮** | 餐饮总收入；拆分：餐厅（零点/自助/早餐）、宴会（婚宴/社交/定制餐/场租）、会议餐、外卖、季节性食品 |

| **合计** | 酒店总收入 |

**⚠️ 数据质量红线**（Eric 关注点）：
- 收入必须**按渠道拆分**（不能只报总额）
- 餐饮必须**按业态拆分**（零点/宴会/会议/外卖）
- 宴会必须**区分婚宴/社交/定制餐**
- 会议必须**区分房费/餐费/场租**

## 2.3 客房运营指标

| 指标 | 公式 | 数据来源 |
|------|------|---------|
| 出租率 OCC | 出租间夜 ÷ 可出租间夜 | 系统 |
| 平均房价 ADR | 客房收入 ÷ 出租间夜 | 系统 |
| 每房收益 RevPAR | 客房收入 ÷ 可出租间夜 | 系统 |
| 单房成本 | 房务部成本费用 ÷ 实际出租间夜 | 财务 |
| 每房利润 | （客房收入 - 房务成本）÷ 可出租间夜 | 财务 |

## 2.4 客源结构（**诊断核心，必须细到不能再细**）

```
客房细分市场（按间夜量 × 占比 × 均价 三维度）
├─ 门市散客（前台及预订）
├─ 线上散客
│   ├─ OTA（携程/美团/飞猪/同程...分平台）
│   ├─ OTP（其他第三方）
│   ├─ 新媒体（抖音/小红书/视频号）
│   └─ 微信（官微/小程序）
├─ 会员散客
├─ 商务公司（协议客户）
├─ 会议
│   ├─ 政府会议
│   ├─ 公司会议
│   ├─ 单团
│   └─ 批发商
└─ 长住房
```

**⚠️ 数据质量红线**：
- **新媒体渠道必须单列**（不能并入 OTA）
- **微信/官微必须单列**（区分"会员渠道订房"与"前台 WALK IN"）
- 会议必须区分政府/公司/单团

# 第三部分 核心指标体系与标值

## 3.1 完整指标清单（对标模版口径）

### A. 基础信息
酒店名称 / 酒店规模 / 客房收入占比% / 餐饮收入占比% / 其他收入占比%

### B. 客房指标
客房出租率 / 平均房价 / 单房成本

### C. 核心经营指标
经营毛利率 / 客房毛利率 / 餐饮毛利率 / 餐饮食品成本率 / 餐饮酒水成本率 / 能源费用率 / 预算能耗率 / 人工成本率 / 人房比 / 营利坪效 / 人均产值 / 人均产能 / 每房收益 / 每房利润 / 溢流-营业毛利润

## 3.2 标值对照表（集团内部标准）

| 指标 | **5 星标准** | **4 星标准** |
|------|------------|------------|
| 客房毛利率 | 74.0% | 69.3% |
| 餐饮毛利率 | 23.7% | 14.0% |
| 经营毛利率 | 28.6% | 23.5% |
| 食品成本率 | 40.6% | 43.1% |
| 人工成本率 | 32.9% | 38.0% |
| 人房比 | 0.91 | 0.58 |
| 每房收益 RevPAR | 472 元 | 250 元 |
| 每房利润 | 224 元 | 96 元 |

## 3.3 计算公式（对标模版原文）

| 指标 | 公式 |
|------|------|
| 单房成本 | 房务部成本费用 ÷ 实际出租间夜数 |
| 人均产值 | 营业收入 ÷ 员工人数 |
| 人均产能 | GOP ÷ 员工人数 |
| 营利坪效 | 营业毛利润 ÷ 建筑面积 |

## 3.4 评级规则（对标模版原文）

- **毛利率**：前 15% 为绿色标记，后 15% 为红色标记
- **成本费用率**：前 15% 为红色标记，后 15% 为绿色标记
- **红绿灯**：毛利率高于标值 → 绿灯；低于标值 → 红灯
- 成本费用率高于标值 → 红灯；低于标值 → 绿灯

## 3.5 STR 对标指标（外部对标）

| 指标 | 含义 | 目标 |
|------|------|------|
| MPI（市场渗透指数） | 本店出租率 ÷ 竞争群出租率 × 100 | >100 |
| ARI（平均房价指数） | 本店房价 ÷ 竞争群房价 × 100 | >100 |
| RGI（收入生成指数） | 本店 RevPAR ÷ 竞争群 RevPAR × 100 | >100 |
| 排名 | 竞争群内排名 | 前 3 |

**对标要求**：
- 必须明确**竞争群名单**（酒店名 + 客房数）
- 区分**线上 STR**（国际口径）与**线下 STR**（本地口径）

# 第四部分 诊断分析模块（8 大模块）

## 模块 1｜效益诊断

**分析内容**：
1. 总收入 / 预算 / 去年同期对比（月度 + 累计）
2. 各板块收入达成率（客房/餐饮/其他）
3. 利润总额、GOP、经营毛利率
4. 现金流、营业现金比率

**诊断输出**：
- 收入缺口清单（哪个板块差多少）
- 利润缺口归因（收入不足 vs 成本超标）

**必问问题**：
- 收入缺口是"量"的问题还是"价"的问题？
- 成本超标是刚性上涨还是管控失效？

## 模块 2｜客房收益诊断

**分析内容**：
1. OCC / ADR / RevPAR 三维走势（月/季/年）
2. 与预算、去年同期对比
3. STR 对标（MPI/ARI/RGI + 排名）
4. **"量价关系"判断**：是"以价换量"还是"量价齐跌"还是"量价齐升"

**诊断输出**：
- 收益策略有效性判断
- 竞争群中的相对位置

**典型案例（丽苑维景）**：
- 4 月：OCC 90.48%、ADR 464.62（超预算 26.9%）→ "量价齐升"
- 五一：OCC 68.90%（差预算 22.23pp）、ADR 799.41（超 32.86%）→ "高价低量"
- 结论：节假日在"保房价"与"保出租率"之间选择了保房价

## 模块 3｜客源结构诊断

**分析内容**：
1. 各细分市场间夜量占比 + 均价（三维表）
2. 占比变化趋势（季度对比）
3. 收入达成率（分渠道）
4. **结构健康度判断**：
   - 协议占比是否过高（抗风险差）
   - OTA 占比是否过高（佣金侵蚀）
   - 自有渠道是否过低（自营能力弱）
   - 散客是否在流失

**诊断输出**：
- 客源结构风险清单
- 建议的客源结构目标

**典型诊断逻辑（丽苑维景）**：
> 线上分销占比偏高 5% 左右，应将此部分沉淀转化至线下散客。

## 模块 4｜客户画像诊断

**分析内容**：
1. TOP10 商务散客清单（公司名/间夜/均价/收入）
2. TOP10 会议清单
3. 客户增减变动（新进 / 退出 TOP10）
4. 消费异动原因分析

**诊断输出**：
- 核心客户依赖度（TOP10 占板块比重）
- 客户流失预警

**典型诊断逻辑（丽苑维景）**：
> TOP10 占该板块 40.87%；水泵厂、金美通信、新东方消费增长明显；成都铁路局、长安马自达因"主要需求低价房间，本店团队占房较多且价格提升较高，不能满足其需求"而减少——**说明价格策略与客源结构存在冲突**。

## 模块 5｜会员诊断 ⭐（Eric 核心关注）

**分析内容**：
1. 会员发展量（按部门分解：前厅/市场/餐饮）
2. 发展率（各渠道转化率：散客/团队/餐饮消费）
3. **会员贡献收入占比**
4. **会员复购率**
5. **沉睡会员数 / 活跃率**
6. **金卡续卡率**
7. 会员渠道订房 vs 前台 WALK IN 的博弈

**诊断输出**：
- 会员"数量 vs 质量"判断
- 会员运营短板定位

**典型诊断逻辑（丽苑维景）**：
> 微信订房转化减少原因分析：
> ① 高出租率情况下前台无法全力引导客人扫码注册（**执行冲突**）
> ② 房间紧张时关闭会员渠道订房（**策略冲突**）
> ③ 房价 650 以上时前台直接 WALK IN 以争取高房价奖励（**激励冲突**）
>
> → **三条原因全部指向"激励机制与会员目标不兼容"**——这是诊断的关键洞察。

## 模块 6｜渠道与新媒体诊断 ⭐（Eric 核心关注）

**分析内容**：
1. **公域渠道**：OTA 各平台表现、抖音/小红书/视频号数据
2. **私域渠道**：官微/小程序/社群/朋友圈
3. **闭环链路**：公域获客 → 私域沉淀 → 复购转化 的完整度
4. **自营能力评估**：自有渠道交易额占比 vs OTA 占比
5. **佣金成本**：OTA 佣金占收入比

**诊断输出**：
- 自营能力成熟度评级（强/中/弱/缺失）
- 公域私域闭环断点定位

**诊断工具（参照营销日历框架）**：

| 平台 | 月度动作 | 目标 | 实际 | 缺口 |
|------|---------|------|------|------|
| 美团外卖 | | | | |
| 大众点评 | | | | |
| 心享商城 | | | | |
| 公众号 | | | | |
| 小红书 | | | | |
| 微博 | | | | |
| 朋友圈 | | | | |
| 社群 | | | | |

## 模块 7｜餐饮诊断

**分析内容**：
1. 餐饮收入结构（餐厅/宴会/季节性食品）
2. 宴会细分（婚宴/社交/定制餐/场租）+ 场次 + 桌均
3. 餐厅细分（早餐/自助午餐/自助晚餐/外卖/零点/咖啡）
4. 食品成本率（分餐厅）
5. 部门利润（分餐厅）
6. **渠道对比**：美团 vs 自营渠道 vs 会议 vs 门散

**诊断输出**：
- 餐饮亏损点定位
- 成本超标环节

**典型诊断逻辑（丽苑维景）**：
> 西餐厅半年食品成本率 60.92%（预算 50%，超 10.92pp），部门利润 -34.43%（预算 -24.93%）——**西餐厅是餐饮亏损的核心缺口**。

## 模块 8｜成本效能诊断

**分析内容**：
1. 房务成本费用（分项：人工/宾客用品/运营用品/布草/佣金/能耗）
2. 单房成本、实际出租每房成本
3. 人工成本率、人房比、人均产值、人均产能
4. 能源费用率 vs 预算能耗率
5. 三公经费
6. 营利坪效

**诊断输出**：
- 成本超标项清单
- 效能提升空间

# 第五部分 问题分级与处方

## 5.1 问题分级框架

| 级别 | 定义 | 处理方式 |
|------|------|---------|
| 🔴 **P0 生存级** | 威胁现金流/合规/安全 | 立即处置，报集团 |
| 🟠 **P1 效益级** | 直接影响年度目标达成 | 30 天内出方案 |
| 🟡 **P2 结构级** | 影响中长期竞争力 | 季度内优化 |
| 🟢 **P3 优化级** | 提升空间 | 持续改进 |

## 5.2 归因四象限

| 归因 | 特征 | 处方方向 |
|------|------|---------|
| **市场原因** | 行业整体下行、区域供给过剩 | 调整目标预期 + 强化差异化 |
| **经营原因** | 策略失误、执行不力、管控失效 | 修正策略 + 强化考核 |
| **资源原因** | 硬件老化、无改造资金、人员不足 | 申请资源 + 分期投入 |
| **机制原因** | 激励不兼容、权责不清、流程冗长 | 机制改革 |

> **诊断关键**：多数酒店会归因"市场原因"，需通过数据交叉验证识别真实的"经营原因"与"机制原因"。

# 第七部分 常见数据质量问题清单（诊断时必查）

> Eric 明确关注"数据录入不规范导致数据失真"。以下为常见问题，诊断时须逐项核查。

| # | 常见问题 | 影响 | 核查方法 |
|---|---------|------|---------|
| 1 | 收入未按渠道拆分 | 无法判断渠道健康度 | 要求提供分渠道收入表 |
| 2 | 餐饮未按业态拆分 | 无法识别亏损业态 | 要求提供分餐厅/分业态收入 |
| 3 | 新媒体渠道并入 OTA | 高估 OTA、低估自营 | 要求单列新媒体 |
| 4 | 微信渠道混入"前台散客" | 高估前台销售能力 | 要求区分会员渠道订房 |
| 5 | 只报会员发展量、不报复购率 | 无法判断会员质量 | 要求提供复购数据 |
| 6 | 会议收入未区分房费/餐费/场租 | 无法判断综合消费 | 要求三项分列 |
| 7 | 客户 TOP10 清单缺失 | 无法画像 | 要求提供客户台账 |
| 8 | "经营性利润"与"利润总额"混用 | 横向不可比 | 统一换算口径 |
| 9 | 出租间夜数含免费房/自用房 | 高估出租率 | 核对扣除项 |
| 10 | 预算口径与去年同期口径不一致 | 同比失真 | 要求统一口径 |
| 11 | 成本费用未分固定/变动 | 无法判断刚性 | 要求分列 |
| 12 | 员工数不含外包/派遣 | 人房比失真 | 核对全口径人数 |
