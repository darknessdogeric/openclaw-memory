# 酒店季报范式 v1.0

> **定位**：安逸集团产业发展部季度战略复盘 + 财报分析 + 竞争格局综合季报
> **时点**：季度结束后 15 日内完成（Q1=4/15 前，Q2=7/15 前，Q3=10/15 前，Q4=次年 1/15 前）
> **读者**：Eric + 集团相关领导 + 必要时董事会
> **输入**：信源 v2.0 + 上市公司季报 + 集团季度财务 + 3 个月月报
> **结构**：10 章 + 1 附录（季报比月报多 2 章：财报深度 + 战略复盘）

---

## 一、季报 10 章标准结构

### 第 1 章 · 季度要闻（Executive Summary）

**目的**：1 页让 Eric 看完整个季度的关键变化

| 字段 | 内容 |
|------|------|
| 本季关键词 | 3-5 个关键词 |
| TOP 5 重大事件 | 政策/行业/集团/AI/资本 |
| TOP 5 数据亮点 | 季度 KPI 突破 |
| TOP 5 风险预警 | 政策/市场/竞争/内部 |
| 下季度路线图 | 3-5 个核心战略动作 |

### 第 2 章 · 行业季度趋势

**目的**：从月度 → 季度趋势，看行业基本面

| 子章节 | 内容 | 必用信源 |
|--------|------|---------|
| 2.1 国内季度数据 | 出租率/ADR/RevPAR Q 走势 | 迈点 / 奥维 |
| 2.2 国际季度数据 | STR / Skift / Phocuswright | 同左 |
| 2.3 当季政策密集发布 | P0 政策列表 | 政策追踪 |
| 2.4 当季行业大事件 | M&A / IPO / 资本动作 | TrendRadar |
| 2.5 季度舆情复盘 | 当季热搜 TOP 议题 | TrendRadar |

### 第 3 章 · 上市公司财报深度（核心章节）

**目的**：用 8+4 家上市公司财报做深度对标

| 维度 | 内容 | 必用信源 |
|------|------|---------|
| 3.1 国际 5 家 Q 财报 | 收入/利润/RevPAR/中国区 | MAR/HLT/IHG/H/AC |
| 3.2 国内 5 家 Q 财报 | 收入/利润/RevPAR/新签约 | 华住/锦江/首旅/亚朵/君亭 |
| 3.3 横向对比矩阵 | 收入/利润/GOP/中国区 排名 | 综合 |
| 3.4 我方 vs 行业基准 | MPI/ARI/RGI + 行业 Rank | STR |
| 3.5 关键发现 | 季度最重要的 3 个行业洞察 | 综合 |

### 第 4 章 · 竞争格局深度（季报独有）

## 二、季报数据采集 SOP

```
季度结束前 5 日（Q+0）
  └── 预通知：内部各部门准备季度数据

季度结束后 Day 1-3（Q+1 to Q+3）
  ├── 8+4 家上市公司 Q 财报全采集 → 财报深度分析
  ├── 集团季度财务 → 财务部
  ├── 6 大改造季度进度 → 项目部
  └── 3 个月月报拼装 → 行业趋势

Day 4-7（Q+4 to Q+7）
  ├── Skift / Phocuswright 季报
  ├── Cushman / CBRE 季报
  ├── VC 当季动态汇总
  └── TrendRadar 季度舆情复盘

Day 8-12（Q+8 to Q+12）
  ├── 拼装季报（套用本范式 10 章）
  ├── 战略复盘会（Eric + 部门）
  └── 季度战略行动清单

Day 13-15（Q+13 to Q+15）
  ├── 数据校验（R66 标准）
  ├── 输出 MD + 可选 PDF
  └── 报告归档：anyi-ops-kb/07_战略与改革/季度报告/[YYYY-Qn]/季报_v1.0_YYYY-MM-DD.md
```

## 三、季报与月报/半年报的关系

```
月报（当月 1-5 日完成）× 3
        ↓ 季度边界
季报（当季结束后 15 日内完成）
  ├── 月报×3 趋势汇总
  ├── 季度财报深度分析（独有）
  ├── 季度战略复盘（独有）
  └── 季度竞争格局变化（独有）
        ↓ 半年边界
半年报（半年结束后 30 日内完成）
  ├── 季报×2 + 月报×6 综合
  ├── 行业全景 + 国企治理 + 中长期格局（独有）
  ├── 战略野心校准（独有）
  └── 半年战略复盘 + 下半年路线图（独有）
```

## 四、季报 vs 月报差异表

| 章节 | 月报 | 季报 | 差异原因 |
|------|------|------|---------|
| 月度/季度要闻 | ✓ | ✓（强化） | 季报需含趋势 |
| 行业月度/季度趋势 | ✓ | ✓（强化） | 同上 |
| 国际国内对标 | ✓ | ✓（强化） | 季报含财报 |
| **上市公司财报深度** | ✗ | ✓ **（独有）** | 月度财报信息有限 |
| **竞争格局深度** | ✗ | ✓ **（独有）** | 季度变化才有意义 |
| 集团经营分析 | ✓ | ✓（季度汇总） | 季报多季度累计 |
| 重点项目月度/季度进度 | ✓ | ✓（强化） | 季报含累计支出 |
| 政策窗口 | ✓ | ✓（季度汇总） | 季报含申报进展 |
| AI/Agent 行业 | ✓ | ✓（季度深度） | 季报含 VC 观点 |
| **跨境与国际化** | ✗ | ✓ **（独有）** | 跨境数据季度才有 |
| 行动 + 风险 | ✓ | ✓（战略复盘 + 路线图） | 季报含下季路线图 |
