# 酒店月报范式 v1.0

> **定位**：安逸集团产业发展部月度经营 + 行业 + 战略综合月报
> **时点**：每月 5 日前完成上月月报（数据时点：上月 1 日 - 上月最后一日）
> **读者**：Eric + 集团相关领导（按需脱敏）
> **输入**：信源 v2.0 + 集团经营数据 + 内部政策追踪
> **结构**：8 章 + 1 附录

---

## 一、月报 8 章标准结构

### 第 1 章 · 月度要闻（Executive Summary）

**目的**：1-2 页让 Eric 5 分钟看完当月关键变化

| 字段 | 内容 | 数据来源 |
|------|------|---------|
| **本月关键词** | 3-5 个关键词（如"中国区 RevPAR 反弹""STR 排名跃升"） | 综合 |
| **TOP 3 重大事件** | 政策 / 行业 / 集团内部 | 信源+内部 |
| **TOP 3 数据亮点** | 出租率/ADR/RevPAR 突破或预警 | 经营数据 |
| **TOP 3 风险预警** | 政策 / 市场 / 内部 | 信源+内部 |
| **本月行动建议** | 3-5 条具体动作 | 综合 |

### 第 2 章 · 行业月度趋势

**目的**：从宏观到微观判断本月行业基本面

| 子章节 | 内容 | 必用信源 |
|--------|------|---------|
| 2.1 国内月度数据 | 出租率/ADR/RevPAR + 同比环比 | 迈点 / 奥维 |
| 2.2 国际月度数据 | STR Global / Skift / Phocuswright 月报 | STR / Skift |
| 2.3 当月政策窗口 | 新发布/即将发布的政策 | 政策追踪 |
| 2.4 当月行业事件 | M&A / 重大签约 / 新开业 / 资本动作 | TrendRadar |
| 2.5 行业舆情（新增） | 微博热搜/知乎热议中行业相关议题 | TrendRadar |

### 第 3 章 · 国际国内对标

**目的**：用上市公司财报 + STR 数据看市场地位

| 维度 | 内容 | 必用信源 |
|------|------|---------|
| 3.1 国际酒店集团动态 | Marriott / Hilton / IHG / Hyatt / Accor 当月动作 | 5 家 IR 页面 |
| 3.2 国内酒店集团动态 | 华住 / 锦江 / 首旅 / 亚朵 / 君亭 当月动作 | 5 家 IR 页面 |
| 3.3 STR 排名（区域/档次） | 我方 vs 竞争群 MPI/ARI/RGI | STR |
| 3.4 关键 KPI 横向对比 | 出租率 / ADR / RevPAR / GOP Margin | 8 家上市公司 |

### 第 4 章 · 集团经营分析（核心章节）

**目的**：基于 [[../经营分析范式/01_经营分析框架_v1.0_2026-08-27.md|经营分析框架 v1.0]] 的 15 章节浓缩到月报

| 子章节 | 内容 | 必用数据 |
|--------|------|---------|
| 4.1 酒店收入总览 | 收入 vs 预算 vs 同比 | 集团财务 |
| 4.2 主营收入（客房） | MPI/ARI/RGI 三件套 + 8 大细分市场占比 | 集团 PMS + STR |
| 4.3 主营收入（餐饮） | 早/午/晚 + 渠道 + 食品成本率 | 集团 POS |
| 4.4 经营利润 + 利润率 | GOP / GOP Margin | 集团财务 |
| 4.5 成本率分析 | 人工/食品/能耗 三件套 | 集团财务 |
| 4.6 会员完成情况 | 部门任务 + 渠道 + 时间进度 | 会员系统 |
| 4.7 客诉 TOP N + 礼遇 | 客诉分类 + 应对措施 | 集团 CRM |
| 4.8 行动项闭环 | 上月行动项 + 本月新增 | 内部 |

> 详细 15 章节见 [[../经营分析范式/01_经营分析框架_v1.0_2026-08-27.md]]

## 二、月报数据采集 SOP（每月 1-5 日）

```
Day 1（1 日）
  ├── 8 家国际酒店集团 IR 月度公告（不是财报，是新闻稿）
  ├── 4 家国内酒店集团 IR 月度公告
  └── TrendRadar 扫描当月热搜 TOP 50

Day 2（2 日）
  ├── STR 月度报告（订阅用户）→ MPI/ARI/RGI 计算
  ├── 迈点 + 奥维月度报告 → 国内签约/开业数据
  └── Skift / Phocuswright 月报（季报边界月）

Day 3（3 日）
  ├── 集团内部经营数据（P&L 模板）→ 财务部
  ├── 6 大改造月度进度 → 项目部
  └── 政策追踪周报本月合并 → 政策库

Day 4（4 日）
  ├── AI 行业当月动态 → The Information + 官方博客
  ├── VC 最新动态 → a16z / Sequoia / ARK 官网
  └── LangChain / LlamaIndex 月度更新

Day 5（5 日）
  ├── 拼装月报（套用本范式 8 章）
  ├── 数据校验（R66 标准）
  ├── 输出 MD + 可选 PDF
  └── 报告归档：anyi-ops-kb/07_战略与改革/月度报告/[YYYY-MM]/月报_v1.0_YYYY-MM-DD.md
```

## 三、月报与季报/半年报的关系

```
月报（当月 1-5 日完成）
  ├── 月度趋势判断
  ├── 当月行动清单
  └── 当月风险提示
        ↓ 季度边界月（3/6/9/12）
季报（当季结束后 15 日内完成）
  ├── 月报×3 趋势汇总
  ├── 季度财报 + 战略复盘
  ├── 季度 KPI 校准
  └── 季度行动清单
        ↓ 半年边界月（6/12）
半年报（半年结束后 30 日内完成）
  ├── 季报×2 + 月报×6 综合
  ├── 行业全景 + 国企治理 + 中长期格局
  ├── 战略野心校准
  └── 半年战略复盘 + 下半年路线图
```
