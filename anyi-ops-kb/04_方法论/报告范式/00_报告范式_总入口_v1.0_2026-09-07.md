# 报告范式总入口 v1.0

> **本文件用途**：报告类工作的**唯一入口**，避免每次重复找模板/找信源/找工具

> **Eric 痛点解决**：每次做报告都重新找 → 现在 1 处配置长期使用

## 三、避免重复的 5 条规则（核心原则）

### 规则 1：1 个入口
**永远**从本文件（00_总入口）开始 → 不要直接找 01/02/03

### 规则 2：信源不重复列
所有信源在 `hotel_sources.py` 一处维护 → 报告里只引用 ID，不重复列名

### 规则 3：模板不重复写
每个范式自带模板（Markdown 代码块）→ 复制即可，不用从头写

### 规则 4：归档不重复造
所有报告归档到 `anyi-ops-kb/07_战略与改革/[月/季/半年]报告/YYYY/`

### 规则 5：同步不重复做
使用 `vault_sync.py` 同步到 Obsidian Vault → 1 条命令搞定

## 四、自动化配置（一次性）

### 4.1 月报 cron（每月 1 日 09:00）

```bash
# 添加 Windows scheduled task
schtasks /Create /SC MONTHLY /D 1 /TN "Monthly_Hotel_Report" /TR "python D:\B166ER-OpenClaw\workspace\toolbox\hotel_sources.py --scan-monthly" /ST 09:00
```

### 4.2 季报 cron（每季首月 5 日 09:00）

```bash
schtasks /Create /SC MONTHLY /D 5 /MO 3 /TN "Quarterly_Hotel_Report" /TR "python D:\B166ER-OpenClaw\workspace\toolbox\hotel_sources.py --scan-quarterly" /ST 09:00
```

### 4.3 半年报 cron（1 月 1 日 + 7 月 1 日 09:00）

```bash

```
