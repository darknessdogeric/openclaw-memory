# 酒店半年报范式 v1.0

> **定位**：安逸集团产业发展部半年战略校准 + 行业全景 + 国企治理 + 中长期格局综合半年报
> **时点**：半年结束后 30 日内完成（H1=7/30 前，H2=次年 1/30 前）
> **读者**：Eric + 集团董事会 + 上级单位（省旅投）+ 必要时国资委
> **输入**：信源 v2.0 + 2 个季报 + 6 个月月报 + EHL 年报 + OECD/世行/WTTC 年报
> **结构**：12 章 + 3 附录（半年报是战略级报告，最全面）

---

## 一、半年报 12 章标准结构

### 第 1 章 · 半年要闻（Executive Summary · 战略级）

**目的**：1-2 页让董事会/省旅投 5 分钟看完半年关键变化

| 字段 | 内容 |
|------|------|
| 半年关键词 | 5 个关键词 |
| TOP 10 重大事件 | 政策/行业/集团/AI/资本/国际 |
| TOP 10 数据亮点 | 半年 KPI 突破 |
| TOP 10 风险预警 | 政策/市场/竞争/内部/国际 |
| 下半年战略野心 | 3-5 个核心战略动作 |
| 战略野心校准 | 与全年目标的对齐情况 |

**目的**：从月度→季度→半年，看行业基本面变化

| 2.3 当半年政策密集发布 | P0 政策列表 | 政策追踪 |

## 二、半年报数据采集 SOP

```
H 结束前 5 日（H+0）
  └── 预通知：内部各部门准备半年数据

H 结束后 Day 1-5（H+1 to H+5）
  ├── 8+4 家上市公司 H 财报全采集 → 财报深度分析
  ├── 集团半年财务 → 财务部
  ├── 6 大改造半年进度 → 项目部
  └── 6 个月月报 + 2 个季报拼装 → 行业全景

Day 6-15（H+6 to H+15）
  ├── EHL H 报告（如 7 月发布）
  ├── OECD / 世行 / IMF H 报告
  ├── WTTC / Allianz H 报告
  ├── Saudi Vision 2030 半年进展
  ├── VC 当半年动态汇总
  └── TrendRadar 半年舆情复盘

Day 16-25（H+16 to H+25）
  ├── 拼装半年报（套用本范式 12 章）
  ├── 战略复盘会（Eric + 部门 + 必要时董事会）
  └── 下半年战略行动路线图

Day 26-30（H+26 to H+30）
  ├── 数据校验（R66 标准）
  ├── 输出 MD + PDF
  └── 报告归档：anyi-ops-kb/07_战略与改革/半年报告/[YYYY-Hn]/半年报_v1.0_YYYY-MM-DD.md
```

## 三、半年报与月报/季报的关系

```
月报（当月 1-5 日完成）× 6
        ↓ 季度边界
季报（当季结束后 15 日内完成）× 2
        ↓ 半年边界
半年报（半年结束后 30 日内完成）
  ├── 季报×2 + 月报×6 综合
  ├── 行业全景（独有）
  ├── 上市公司 H 报深度（独有）
  ├── 国企治理国际对标（独有）
  ├── 战略野心校准（独有）
  ├── 医养与新业态（独有）
  └── 下半年战略路线图（独有）
```

## 四、半年报 vs 月报 vs 季报差异表

| 章节 | 月报 | 季报 | 半年报 | 差异原因 |
|------|------|------|--------|---------|
| 月度/季度/半年要闻 | ✓ | ✓ | ✓（强化战略级） | 半年报含战略野心 |
| 行业月度/季度/半年趋势 | ✓ | ✓ | ✓（强化全景） | 半年报含结构变化 |
| 国际国内对标 | ✓ | ✓ | ✓ | 半年报含全年指引 |
| **上市公司财报深度** | ✗ | ✓ | ✓（H 报） | 月度财报信息有限 |
| **竞争格局深度** | ✗ | ✓ | ✓（H 深度） | 季度变化才有意义 |
| 集团经营分析 | ✓ | ✓ | ✓（H 复盘） | 半年报含全年完成率 |
| 重点项目进度 | ✓ | ✓ | ✓（H 累计支出） | 半年报含全年支出预测 |
| 政策窗口 | ✓ | ✓ | ✓（H + 国际对标） | 半年报含 OECD/世行 |
| AI/Agent 行业 | ✓ | ✓ | ✓（H 深度） | 半年报含 AHL H 表现 |
| **跨境与国际化** | ✗ | ✓ | ✓（H 深度 + Eric 机会评估） | 跨境数据 H 才有 |
| **医养与新业态** | ✗ | ✗ | ✓ **（独有）** | 半年报才有的研究项 |
| **战略野心校准** | ✗ | ✗ | ✓ **（独有）** | 半年报必含 |
| 行动 + 风险 | ✓ | ✓（路线图） | ✓（H 路线图） | 半年报含 H2 路线图 |
