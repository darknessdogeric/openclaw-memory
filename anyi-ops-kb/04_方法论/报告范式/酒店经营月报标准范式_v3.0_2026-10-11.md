## 二、五条编制原则

1. **数据先行** —— 任何结论必须有数据支撑，不写无数据的定性描述。
2. **问题导向** —— 每个板块必须回答「差在哪、为什么、怎么办」。
3. **责任闭环** —— 每项措施必须有责任人、时间节点、验收标准。
4. **同口径可比** —— 同比基准、利润口径、面积口径、员工口径必须统一并在页脚注明。
5. **不落空** —— 未采集数据标注「未采集」，不得留空、不得估算、不得以定性替代。

## 三、数据规范前置（编制前必读）

| 规范项 | 要求 |
|--------|------|
| 收入口径 | 按「客房 / 餐饮 / 其他」三大类归集；宴会含餐费与场租须分列 |
| 利润口径 | 「经营性利润」「GOP」「利润总额」必须注明是否含折旧摊销、租赁、能源 |
| 客房口径 | 客房收入按渠道与细分市场双维拆分 |
| 餐饮口径 | 按业态（早餐 / 自助午餐 / 自助晚餐 / 零点 / 外卖 / 咖啡厅）× 渠道（房含早 / 美团 / 自营 / 会议 / 门散） |
| 宴会口径 | 按类型（婚宴 / 社交宴 / 定制餐 / 场租 / 会议餐）分列场次与收入 |
| 会议口径 | 按「房费 / 餐费 / 场租」三分列示，不得只报总额 |
| 渠道口径 | 新媒体单列，不得并入 OTA；微信渠道单列，不得混入前台散客 |
| 会员口径 | 以集团会员系统入库数为准，手工登记未入库不计入 |
| 员工口径 | 含外包与劳务派遣；人房比按全口径计算 |
| 面积口径 | 建筑面积与可经营面积明确区分，全店统一；餐厅面积须拆分 |
| 同比基准 | 默认对比上一年同期；若上年为特殊低谷（如疫情年），须另行注明基准年及理由 |
| 颗粒度 | 半年对半年、单月对单月，不得混比 |
| 数据来源 | 全部标注（PMS / 财务系统 / 手工台账），手工数据须注明 |

## 五、各模块编制规范

### 模块一｜经营总览（P03–P04）

- **目的**：让决策者 1 分钟内掌握全月与累计经营全貌。
- **必填行**：客房收入、出租率、平均房价、每房收益、餐饮收入（含餐厅 / 宴会 / 季节性食品）、其他及杂项收入、租赁收入、营业总收入、利润总额、GOP。
- **必填列**：实际、预算、差额、差异率、去年同期、同比差额、同比率；累计页须加时间进度与进度差。
- **结论栏（三句）**：① 经营定性（达标 / 承压 / 预警）；② 核心缺口（哪个板块差多少、差在量还是价）；③ 核心亮点（哪个板块超多少、可否复制）。
- **常见错误**：只报数不给结论；只报当月不报累计；GOP 与利润总额口径混用。

### 模块二｜客房经营（P05–P07）

- **目的**：诊断客房收益能力与量价策略。
- **必填数据**：核心指标（出租率 / ADR / RevPAR / 出租间夜 / 客房收入 / 可售房总数）；分日型（周一至周日三指标）；分房型（间数 / 出租率 / ADR / RevPAR / 收入占比）；12 个月滚动趋势（图）。
- **结论栏**：① 量价关系（量价齐升 / 以价换量 / 量价齐跌，三选一）；② 缺口归因（量 or 价）；③ 下月收益取向（ADR 优先 or OCC 优先）。
- **红线**：出租间夜须扣除免费房、自用房、维修房；免费房单列说明。

### 模块三｜餐饮经营（P08–P09）

- **目的**：定位亏损业态与成本超标科目。
- **必填数据**：业态 × 渠道收入矩阵（含合计行）；分餐厅成本率（食品 / 酒水 / 人工 / 低耗品）。
- **结论栏**：① 亏损业态定位；② 线上渠道是否「增收不增利」；③ 菜单结构与采购策略调整。
- **红线**：成本率分母须与收入口径一致；跨部门调拨（餐费调房费）须备注并同步调账。

### 模块四｜宴会与会议（P10–P12）

- **目的**：宴会看量与质，会议看综合消费，坪效看空间效率。
- **必填数据**：宴会分类型场次与收入；宴会厅 / 会议室坪效（面积 / 月收入 / 坪效 / 同比）；会议业务三分（房费 / 餐费 / 场租）；竞对厅数量与当月场数。
- **结论栏**：① 缺口集中在哪个宴会类型；② 撞档丢失场次须量化损失金额；③ 下月客资获取计划。
- **红线**：场租与餐费不得混计；面积口径须与实际使用面积一致。

### 模块五｜市场细分与客户（P13–P15）

- **目的**：诊断客源结构、客户集中度与客户质量。
- **必填数据**：细分市场（渠道 × 间夜 × 占比 × 均价 × 收入 × 达成）；商务散客 TOP10（当月 / 上月 / 年累计）；客户分层（战略 / 大 / 中 / 普通 / 潜在）；消费频次（新客 / 回头 / 忠诚 / 沉睡）。
- **结论栏**：① 散客与团队占比变化方向；② TOP10 收入集中度是否过高（风险线建议 >50%）；③ 高价值客户流失预警名单。
- **红线**：客户台账缺失将导致本模块无法出具，属数据不合格。

### 模块六｜渠道与新媒体（P16–P18）

- **目的**：诊断渠道健康度与自营能力。
- **必填数据**：渠道佣金（收入 / 占比 / 实付佣金 / 佣金率 / 合同比例）；新媒体（平台 × 销售额 × 粉丝 × 直播 × 完成率）；前厅渠道（WALK IN / 微信订房）；网络评分（分值 / 分值目标 / 分维度 / 好评差评数）。
- **结论栏**：① OTA 佣金占收入比是否合理；② 公域到私域闭环的断点位置；③ 自营能力成熟度评级（强 / 中 / 弱）。
- **红线**：新媒体不得并入 OTA；微信渠道不得混入前台散客；新媒体文案不得出现微信号 / 二维码 / 加我 / 私域 / 引流 / 支付宝等表述。

### 模块七｜会员与客户价值（P19–P20）

- **目的**：会员「数量」与「质量」双看。
- **必填数据**：分部门会员发展（当月 / 任务 / 完成率 / 累计 / 时间进度）；会员质量（发展量 / 金卡销量 / 消费占比 / 复购率 / 活跃率 / 沉睡数 / 续卡率 / 客单价对比）；宾客满意度（GSS / 低分警示 / 问卷量 / OTA 评分 / 投诉闭环率）。
- **结论栏**：① 数量与质量是否匹配；② 金卡为什么卖不动；③ 下月会员攻坚重点（分解到部门）。

### 模块八｜坪效与人效（P21–P22）

- **目的**：诊断空间与人的产出效率。
- **必填数据**：客房 / 餐饮 / 宴会 / 其他经营面积 / 综合 / GOP 坪效；员工总数 / 人均产值 / 人均 GOP / 人均利润 / 人房比 / 人均服务客房数 / 人工成本率 / 流失率。
- **结论栏**：① 坪效与人效短板；② 人工成本率是否高于行业参照；③ 提升空间测算与用工结构建议。
- **红线**：建筑面积口径须统一；餐厅面积未拆分将导致坪效失真；员工数不含外包将使人效虚高。

### 模块九｜三层对标（P23–P24）

- **目的**：明确相对位置与竞争策略。
- **必填数据**：STR 对标（本店 / 竞争群 / 指数 / 排名）；城市 / 区域 / 行业平均；本区竞对逐店明细（可售房 / 出租房 / 房费收入 / OCC / ADR / RevPAR / MPI / ARI / RGI）。
- **结论栏**：① 三项指数中哪一项拖累 RGI；② 排名变化归因；③ 下月竞争策略。
- **红线**：对标数据须注明来源与期次；估算值须标注「估」。

### 模块十｜成本与效能（P25）

- **目的**：诊断成本刚性与管控成效。
- **必填数据**：人工 / 宾客用品 / 运营用品 / 布草 / 能耗 / 佣金 / 维修保养 / 交通费 / 市场推广费 / 其他，并标注固定 / 变动属性。
- **结论栏**：① 哪一科目超标；② 成本下降是主动管控还是被动随收入下降；③ 固定成本占比与可控成本压降空间。

### 模块十一｜问题清单与下月计划（P26–P29）

- **目的**：形成「报告 → 会议 → 行动 → 验证」闭环。
- **必填数据**：问题清单（问题 / 数据证据 / 级别 / 归因 / 处方 / 责任部门 / 完成节点 / 验收标准）；下月重点工作（类别 × 操作内容 × 节点 × 负责人 × 验收标准）；下月经营预测（指标 × 预测 × 依据 × 置信度）；需集团支持事项。
- **级别**：P0 生存级 / P1 效益级 / P2 结构级 / P3 优化级。
- **归因（六象限）**：市场 / 经营 / 资源 / 机制 / 结构 / 数据。
- **底线**：无数据证据不入清单；无处方不列问题；无责任人 + 无验收标准不进入下月跟踪。

## 七、提交与会议衔接

```
月度经营报告（次月 5 日前提交）
        ↓
集团经营分析会（次月 10 日前召开）
        ↓
问题清单确认 + 集团支持事项落实
        ↓
运营日历调整（下月动作）
        ↓
下月报告验证（含上月预测偏差复盘）
```

**会上必问五问**

| # | 问题 | 指向 |
|---|------|------|
| 1 | 缺口是「量」的问题还是「价」的问题？ | 客房策略 |
| 2 | 亏损业态是哪个？成本失控在哪一科目？ | 餐饮诊断 |
| 3 | 客户 TOP10 有无流失？集中度是否过高？ | 客户风险 |

| 5 | 自营渠道占比是否在提升？OTA 佣金是多少？ | 自营能力 |

## 八、附录 A｜KPI 定义与公式

| 指标 | 公式 |
|------|------|
| 出租率 OCC | 出租间夜 ÷ 可售间夜 |
| 平均房价 ADR | 客房收入 ÷ 出租间夜 |
| 每房收益 RevPAR | 客房收入 ÷ 可售间夜 |
| 总每房收益 TRevPAR | 总收入 ÷ 可售间夜 |
| 每房毛利 GOPPAR | GOP ÷ 可售间夜 |
| GOP 率 | GOP ÷ 营业总收入 |
| 全员劳动生产率 | 营业总收入 ÷ 员工总数（含外包） |
| 人房比 | 员工总数 ÷ 客房总数 |
| 客房坪效 | 客房收入 ÷ 客房建筑面积 |
| 餐饮坪效 | 餐饮收入 ÷ 餐饮经营面积 |
| 宴会坪效 | 宴会收入 ÷ 宴会厅面积 |
| 客户集中度 | TOP10 客户收入 ÷ 客房总收入 |
| 复购率 | 期内二次及以上消费客户数 ÷ 期内消费客户数 |
| MPI（市场渗透指数） | （本店 OCC ÷ 竞争群 OCC）× 100 |
| ARI（平均房价指数） | （本店 ADR ÷ 竞争群 ADR）× 100 |
| RGI（收入生成指数） | （本店 RevPAR ÷ 竞争群 RevPAR）× 100 |

## 十一、附录 D｜配套工具与使用方法

### 生成可编辑 PPTX

```bash
# 1）生成空白标准模版（下发给各酒店填写）
python toolbox/gen_hotel_monthly_report_pptx.py

# 2）按数据生成（自动填表、趋势图自动出数）
python toolbox/gen_hotel_monthly_report_pptx.py data.json

# 3）指定输出路径
python toolbox/gen_hotel_monthly_report_pptx.py data.json out.pptx
```

### data.json 字段说明

| 字段 | 说明 |
|------|------|
| hotel_name | 酒店名称（封面 / 页脚） |
| period | 报告期（如「2026 年 10 月」） |
| trend_months | 趋势图横轴（12 个标签，默认 M-11 … 当月） |
| trend_occ / trend_adr / trend_revpar | 趋势图三条序列（各 12 个数值；只填 occ 与 adr 亦可） |

> 其余表格页在 PPT 中直接填写；如需全量数据驱动，可扩展 `build()` 中对应页面的数据源。

### 环境依赖

```bash
pip install python-pptx
```
