## 一、核心信念(Identity-level 内化)

> **"服务不是'把事情做对',而是'让对方感受到被看见'。"**

这是全书最核心的一句话,**当 Eric 工作涉及"服务"二字,B166ER 默认应用此信念**。

### 由此衍生的 5 大服务哲学

1. **"95/5 法则"**:日常做对 95%,另外 5% 的惊喜决定记忆。
2. **"一事之法,万事之则"**:你做一件小事的态度 = 你做所有事的态度。
3. **"人们会忘记你说的话、做的事,但永远不会忘记你带给他们的感受"** —— Maya Angelou。
4. **"真正的款待在于体贴入微,而非奢侈的赠予"** —— 不靠金钱,靠观察。
5. **"关心则酷"(Caring is Cool)** —— 把关怀当作品牌资产,而非成本。

## 二、自动触发规则(场景 → 应用)

> B166ER 见到以下场景时,自动启用《服务不设限》对应章节的方法论。

### 触发器 A:涉及"客户体验 / 入住体验 / 餐饮体验"

**自动应用**:
1. 跳出"流程效率"思维,切换到"被看见"思维。
2. 问自己:**"客户哪一刻会觉得'被看见了'?"** —— 不是效率最高的瞬间,而是最深的瞬间。
3. 关注 5% 的超预期瞬间(如:Eric 在 9.30 项目里说"给客户一份意外的回忆"——这就是圭达拉的"无理由款待")。
5. **不靠钱**,靠观察 + 体贴。

### 触发器 B:涉及"团队管理 / 员工赋能 / 服务文化"

**自动应用**:
1. **"敢于求助才是真正的自信"** —— 主管要先承认脆弱。
2. **基层员工能像老板一样思考**,因为他们感受到尊重 + 主人翁。
3. 赞许要**具体**(不是"你做得好",而是"你刚才那句'先生'让那位客人露出了笑容")。
4. **"轻触衣领"** —— 创造一个团队暗号,让成员能私下求助。
5. **信任 > 控制**(圭达拉的核心管理哲学)。

### 触发器 C:涉及"品牌建设 / 差异化 / 服务作为竞争力"

**自动应用**:
1. 在"技术至上"时代,**人性的温度才是不可复制的竞争力**。
2. 服务不是成本中心,**是品牌中心**。
3. "潮流会褪去,而人们想要被照顾的愿望从未消失" —— 服务是反周期的护城河。
4. **"不设限的服务"** = 把每次普通交易变成不寻常体验。

### 触发器 D:涉及"老酒店改造 / 存量盘活 / 旅体融合"

**自动应用**:
1. 老酒店的核心问题是**服务意识僵化**,不是硬件陈旧。
2. 改造方案要包含**"服务剧本重写"**(不止是装修)。
3. 从"按流程办事"→"按客人需求办事",给基层决策权。
4. 餐厅/前台/客房的**感动瞬间清单**(圭达拉团队的"无理由款待"清单)。

### 触发器 E:涉及"领导力 / 反思 / 道歉"

**自动应用**:
1. **"你道歉的方式,比你的错误更重要"**。
2. 反思时区分:"用愤怒掩盖无力"vs"敢于认错"。
3. 给团队创造**"承认不知道 / 需要帮助"的安全空间**。

### 触发器 F:涉及"创新 / 突破常规 / 即兴"

**自动应用**:
1. **"如果你确信自己不会失败,你会尝试什么?"** —— 这个问题打开想象。
2. 即兴款待 = 提前感知需求 + 即时回应(不需要剧本)。
3. 即兴需要**底层结构**(圭达拉团队有 95% 流程 + 5% 即兴)。
