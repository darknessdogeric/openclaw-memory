# 第一部分 诊断框架

## 1.1 五步诊断法

```
第一步  数据核验  →  数据是否完整、口径是否统一、是否存在失真
第二步  指标对标  →  与集团标值 / 同档竞对 / 城市平均 / 行业平均对比
第三三步  结构分析  →  收入结构、客源结构、成本结构、坪效结构、人效结构
第四步  归因诊断  →  区分"市场原因 / 经营原因 / 资源原因 / 机制原因"
第五步  处方建议  →  分层开方（立即/短期/中期），明确责任与节点
```

## 1.2 四大诊断维度（v1.1 新增"能力"维度细分）

| 维度 | 核心问题 | 关键指标 |
|------|---------|---------|
| **效益维度** | 赚不赚钱？效率如何？ | 收入、利润、GOP、毛利率、坪效、人效 |
| **结构维度** | 钱从哪来？结构健康吗？ | 收入结构、客源结构、渠道结构、坪效结构、人效结构 |
| **市场维度** | 卖给谁？细分市场是否全覆盖？ | 11 大市场细分维度 |
| **能力维度** | 有没有自主获客/自主运营/自主成本管控能力？ | 会员贡献、官微占比、新媒体转化、复购率、坪效产出比 |

| **餐饮面积坪效** | 餐饮收入 ÷ 餐饮总面积 |
| **宴会坪效** | 宴会收入 ÷ 宴会厅面积 × 场次 |
| **综合坪效** | 总收入 ÷ 总建筑面积 |
| **GOP 坪效** | GOP ÷ 总建筑面积 |
| **人均服务客房数** | 客房数 ÷ 员工总数 |
| **单工时产出** | 营业收入 ÷ 总工时 |

## 模块 9｜市场细分诊断（v1.1 全新）

**分析内容**：

2. 各细分市场的**间夜量/收入/占比/均价/利润率**
3. **交叉分析**（高潜交叉点）
4. 细分市场**风险点**（集中度过高/价格过低）
5. 细分市场**增长机会**（空白点/低渗透点）

**诊断输出**：
- 市场细分完整度评估（11/11 满分，<11 即有盲区）
- 重点细分市场 TOP5 / 潜力细分市场 TOP5

## 模块 10｜坪效诊断（v1.1 全新）

**分析内容**：
1. **客房坪效**：每间房产生的收入（分日型/分房型）
2. **餐饮坪效**：每餐位 / 每㎡餐饮面积产生的收入（分餐厅）
3. **宴会坪效**：每㎡宴会厅面积产生的收入（分类型）
4. **综合坪效**：每㎡建筑面积产生的总收入和 GOP
5. **坪效对比**：与城市平均 / 行业平均对比

**诊断输出**：
- 坪效短板区域（客房坪效低的房型、餐饮坪效差的餐厅、宴会坪效差的厅）
- 坪效提升空间（按提升 10%/20%/30% 测算收入增量）
- 空间利用优化建议（低坪效区改为高坪效用）

## 模块 11｜人效诊断（v1.1 全新）

**分析内容**：
1. **人均产值 / 人均产能 / 人均利润**（分部门）
2. **人房比 / 人均服务客房数**（与标值对比）
3. **分部门人效**（客房人效/餐饮人效/销售人效）
4. **用工结构**（正式/外包/派遣的占比与弹性）
5. **培训与发展成本**（人均培训费）

**诊断输出**：
- 部门人效短板（哪个部门人效最低）
- 用工弹性空间（哪些岗位可以外包/共享）
- 人均产值提升空间（按 10% 提升测算）

## 模块 12｜三层对标诊断（v1.1 全新）

**分析内容**：
1. **自身 vs 自身**（月度/季度/年度趋势）
2. **自身 vs 同档竞对**（MPI/ARI/RGI + 排名）
3. **自身 vs 城市平均**（成都/重庆/北京/上海等）
4. **自身 vs 区域平均**（西部/西南/华东等）
5. **自身 vs 行业平均**（全国 4 星/5 星）
6. **自身 vs 同业态平均**（度假/政务/会议/会展）
7. **自身 vs 头部集团均值**（锦江/华住/亚朵）

**诊断输出**：
- 三层对标雷达图（视觉化）
- 差距定位（相对优势 / 相对劣势）
- 改进优先级
