## §1 核心命题

```
竞争激烈的红海里，利润空间越来越小。
蓝海 = 未被争夺的新市场空间，价值与成本同步跃迁。

经典误区：以为蓝海 = 没有竞争者 = 全新领域。
实际上：蓝海 = 创造新需求，让竞争变得无关。
```

---

## §2 核心工具：4 大方法（M1–M4）

### M1 · 蓝海 vs 红海（基础判断）

```
红海（Red Ocean）
  - 已知市场空间
  - 边界已定
  - 竞争激烈
  - 利润随竞争下降
  - 规则已定

蓝海（Blue Ocean）
  - 未被争夺的市场空间
  - 边界未定
  - 创造新需求
  - 价值与成本同步
  - 规则可重写
```

### M2 · 四步动作框架（核心工具）

```
1. 消除（Eliminate）
   哪些行业内"理所当然"的因子应被剔除？
   例：航空公司过去认为"机上餐食"必备 → 廉价航空消除

2. 降低（Reduce）
   哪些因子应远低于行业标准？
   例：宜家降低家具装配复杂度到极致，顾客自己组装

3. 提升（Raise）
   哪些因子应远高于行业标准？
   例：维珍航空提升娱乐系统，远超行业

4. 创造（Create）
   哪些行业从未提供的因子应被创造？
   例：苹果创造 App Store，行业前所未有
```

### M3 · 价值曲线（Strategy Canvas）

```
横轴：行业竞争因子（如价格 / 服务 / 体验 / 速度）
纵轴：水平高低
两条曲线：
  - 你的曲线（You）
  - 行业平均曲线（Industry Average）

蓝海策略 = 让你的曲线与行业曲线有重大差异
（消除低价值因子 / 创造新价值因子）
```

### M4 · 六条原则（具体做法）

```
1. 重新界定市场边界
   → 看替代行业 / 战略集团 / 买方群体 / 时间趋势
2. 关注非客户（Non-customers）
   → 第一层 soon-to-be / 第二层 refusing / 第三层 unconsidered
3. 超越现有需求
   → 不是"在量上竞争"，而是"创造新需求"
4. 看战略次序
   → 买方体验 / 价格 / 接受度 / 壁垒
5. 跨越吸引力-成本曲线
   → 不是"高价值 = 高成本"，而是"差异化 + 低成本"
6. 打破价值-惯例权衡
   → 重建商业模型
```

## §3 对「安逸酒店」的应用

### 3.1 当前在红海的位置

| 因子 | 行业标准 | 安逸当前 | 改善方向 |
|------|---------|----------|----------|
| 房价 | 中端 200-400 元 | 中端偏上 | **消除** 部分物业软装低效成本 |
| 物业数 | 川内 167 家 | 167 家 | **降低** 单纯追求数量 |
| 客群 | 大众商务 | 商务 | **提升** 文化体验型客群比例 |
| 卖点 | 城市分布 | 多分布于景区 | **创造** "景区+在地文化"独家 IP |
| 渠道 | OTA 依赖 | OTA 重 | **消除** 部分 OTA 依赖（直营+会员） |

### 3.2 蓝海动作（4 步动作）

```
消除（Eliminate）：
  - 标准化物业的硬装修投入（差异化项目才精修）
  - 重物业 OTA 依赖（部分项目转向直营/会员）

降低（Reduce）：
  - 物业扩张速度（聚焦优质而非快速）
  - 部分物业的物业成本（轻资产运营）

提升（Raise）：
  - 景区物业的文化体验（茶艺/中医/在地文化）
  - 直营+会员占比（降低对 OTA 的议价权）

反向（Reverse）：
  - 不再盲目追求"全国连锁" → 聚焦"区域位置即定价权"
```

### 3.3 蓝海案例参考

| 案例 | 四步动作 |
|------|----------|
| 西南航空 | 消除餐食/选座；降低票价；提升点对点频次；创造短途直飞 |
| 任天堂 Wii | 消除高性能；降低价格；提升体感操控；创造家庭娱乐 |
| 宜家 | 消除现场服务；降低装配成本；提升仓储展示；创造 DIY 体验 |

## §4 对「项目策划 5 步」的应用

### Step 2 · 选址定位

```
蓝海选址思维：不只是选区域，是选"竞争弱、位置强"的区域。
  - 五力打分最低的区域
  - 但五力低 = 可能是荒野
  - 真正蓝海 = 有客流但酒店少 = 景区核心位置但供给不足

→ 安逸在 5A/4A 景区的 9 家自有物业 100% 满房 = 蓝海区域
```

### Step 3 · 产品定位

```
价值曲线对比：
  行业曲线：标准连锁酒店 = 标准化 + 中端
  安逸曲线：在地文化 + 中高端 + 景区核心 + 差异化体验
→ 价值差异显著 = 蓝海定位
```

### Step 4 · 商业模式

```
特许经营 → 自营为主：蓝海 = 自有 IP
业主直营 → 集团孵化 + 品牌输出：蓝海 = 品牌矩阵
```

### Step 5 · 估值

```
蓝海定位 → 高溢价
估值倍数：红海 10-15× GOP ｜ 蓝海 15-25× GOP
```

## §5 失败模式

1. 把「无竞争」当蓝海 → 可能是市场不存在
2. 忽略价值曲线差异 → 仍在红海
3. 四步动作不全（只做消除不做创造）→ 半成品
4. 客户不接受新因子 → 价值曲线是「你觉得」，不是「客户觉得」
5. 蓝海策略过于创新 → 教育市场成本过高
6. 把所有项目都当蓝海 → 红海策略有时更稳
