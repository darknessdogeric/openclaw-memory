## §1 核心命题

```
行业利润率 = 五种力量的强度对比
（五力越强 → 利润越低；五力越弱 → 利润越高）

策略 = 定位 + 行动
- 定位：把自己放到五力最弱的角落
- 行动：用价格或战略话改变五力结构
```

## §2 五大力量（4 大方法 M1–M4）

### M1 · 五力打分法

```
1. 供应商议价（Bargaining Power of Suppliers）：高/中/低
2. 买方议价（Bargaining Power of Buyers）：高/中/低
3. 潜在进入（Threat of New Entrants）：高/中/低
4. 替代品（Threat of Substitutes）：高/中/低
5. 现有竞争（Competitive Rivalry）：高/中/低

→ 综合打分：5 × 3 = 15 分；越低越蓝海
```

### M2 · 五力判断依据（每力 4 因素）

| 力 | 高 | 低 |
|---|----|----|
| **供应商议价** | 供应商集中 / 行业前置整合 / 替代少 / 切换成本高 | 供应商分散 / 切换容易 / 同质化 |
| **买方议价** | 买方集中 / 买方信息多 / 产品同质 / 转换成本低 | 买方分散 / 产品差异化 / 转换成本高 |
| **潜在进入** | 行业门槛低 / 规模经济弱 / 资本要求低 | 资本要求高 / 牌照限制 / 规模经济显著 |
| **替代品** | 替代品性能价格更优 / 替代品转化成本低 | 替代品性能弱 / 转换成本高 |
| **现有竞争** | 行业增速慢 / 集中度低 / 退出壁垒高 / 产品同质 | 行业增速快 / 集中度高 / 退出容易 |

### M3 · 三种通用战略

```
1. 成本领先（Cost Leadership）
   - 在所有维度上压低成本
   - 五力中所有低价场景都受用
   - 例：汉庭、如家

2. 差异化（Differentiation）
   - 在关键维度做到行业独特
   - 议价能力增强
   - 例：亚朵

3. 聚焦（Focus）
   - 在窄市场上做深做透
   - 服务特定客群
   - 例：精品民宿
```

### M4 · 五力分析应用步骤

```
Step 1 · 圈定行业边界
  - 替代品行业
  - 上下游行业

Step 2 · 逐力打分（高/中/低）
  - 每力给出 3-5 个证据

Step 3 · 算综合得分（15 分制）
  - 12+ = 红海（利润低）
  - 8-12 = 竞合
  - <8 = 蓝海

Step 4 · 匹配战略
  - 15-12：差异化或聚焦
  - 12-8：组合（成本 + 差异化）
  - <8：聚焦特定细分

Step 5 · 监测变化
  - 每年复测
```

## §3 对「安逸酒店」的应用

### 3.1 五力打分（红海/蓝海判断）

| 力 | 大小 | 证据 |
|---|------|------|
| **供应商议价** | 中 | 物业业主相对分散，但景区物业稀缺 |
| **买方议价** | 中 | OTA 集中度高（携程/美团/同程），议价能力强 |
| **潜在进入** | 低 | 景区核心位置稀缺，资本与牌照门槛高 |
| **替代品** | 高 | 民宿/短租替代；客户选择多 |
| **现有竞争** | 中 | 川内连锁竞争（华住/锦江/亚朵），景区位置区分度高 |

**综合：12 分（偏红海）→ 但景区核心位置低进入威胁 → 局部蓝海**

### 3.2 战略匹配

```
成本领先 → 不适合（安逸集团是中高端定位）
差异化 → 主策略（位置/品牌/在地文化）
聚焦 → 副策略（聚焦景区核心 + 中高端商务/文化客群）
```

## §4 对「项目策划 5 步」的应用

### Step 2 · 选址定位

```
每选一个区域都做五力打分：
  - 高分（红海）→ 谨慎/差异化
  - 低分（蓝海）→ 加注
```

### Step 3 · 产品定位

```
差异化点的选择要规避"五力高"区：
  - 替代品多 → 避开同质赛道
  - 现有竞争激烈 → 找差异化爆点
  - 买方议价高 → 降低 OTA 依赖
```

### Step 4 · 商业模式

```
成本结构 = 供应商议价影响
收入结构 = 买方议价影响
进入壁垒 = 潜在进入威胁的应对
```

### Step 5 · 估值

```
红海项目 → 10-15× GOP
蓝海项目 → 15-25× GOP
五力打分 = 估值倍数的核心依据
```

## §6 失败模式

1. 五力打分走过场 → 每力必须有证据
2. 错把"竞争激烈"当"红海" → 还要看潜在进入与替代品
3. 战略选错（成本领先 vs 差异化 vs 聚焦） → 必须匹配五力打分
4. 不重新评估五力 → 行业变化未跟进
5. 五力分析只看一个区域 → 不同区域五力不同
6. 不看替代品 → 民宿/公寓可能替代酒店
