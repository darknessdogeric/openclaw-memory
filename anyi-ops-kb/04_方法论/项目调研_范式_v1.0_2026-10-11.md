## §2 项目调研标准流程（6 阶段）

### Phase 1 · 需求接收（明确 Why）
- 委托方：投资人 / 资管方 / 品牌方 / 业主方 / 政府
- 调研类型：项目可行性 / 收购尽调 / 战略评估 / 政策合规
- 报告期间与对比期间
- 调研深度：概览 / 中等 / 深入

### Phase 2 · 信源矩阵覆盖
- A 行业协会 + B 国际研究 + C 国内研究 + D OTA + E 官方 + F 本土 + G 财经 + H 券商 + I 上市集团 + J 审计银行
- 必查 11 维，覆盖率 ≥70% 才继续
- 覆盖率不足则启动 Phase 3 补足

### Phase 3 · 数据采集（按四级 SOP）
1. 信源矩阵全网爬取
2. OTA 爬取
3. 其他（财报 / 官方 / 研报原文）
4. 综合推算（兜底）

### Phase 4 · 跨源验证（≥3 源）
- 同一指标 ≥3 个独立信源 → 🟡🟡 多源交叉
- 1–2 源 → 🟠🟠 单源待补
- 一手直采 → 🟢🟢

### Phase 5 · 报告生成
- 项目可行性：11 维 + 财务模型 + 风险
- 区域市场：46 维 + 区域竞争
- 收购尽调：11 维 + 财务尽调 + 法务

### Phase 6 · 质量门控（必过）
- 所有 YoY 基于上年同期
- 粒度匹配
- 同比基准明确（2025 vs 2024 是否低谷）
- 缺失标「未公开」
- 没有编造任何数字

## §4 项目调研 vs 市场调研：区别

| 维度 | 项目调研 | 市场调研 |
|------|----------|----------|
| 对象 | 单个项目/酒店 | 区域/全局 |
| 目的 | 投资决策 | 战略决策 |
| 输出 | 11 维 + 财务模型 | 46 维 + 趋势 |
| 时长 | 1–4 周 | 2–8 周 |
| 风险 | 投资风险 | 市场风险 |
| 典型问题 | 「这个项目投不投」 | 「这个区域值不值得进」 |

## §5 关键问题清单（KYC）

调研开始前，先用 KYC 清单**锁定问题边界**：

```
□ 委托方是谁？诉求是什么？
□ 报告期间？对比期间？
□ 输出格式（PDF / Word / PPT / MD）？
□ 深度（概览 / 中等 / 深入）？
□ 关键决策点（投资 / 收购 / 战略 / 合规）？
□ 必须覆盖的维度（11 维中哪些必查）？
□ 不必覆盖的维度（可放弃）？
□ 信源上限（公开 / 付费 / 内部）？
□ 风险偏好（稳 / 积极 / 极稳）？
□ 交付时间？
```

问「市场现状」 → 市场调研（46 维）

## §7 11 维展开（速查表）

### 1. 政策环境
- 区域产业政策（文旅 / 商贸 / 房地产）
- 土地供应 + 价格
- 税收优惠 + 财政补贴
- 准入门槛（外资 / 民营 / 国有）

### 2. 经济环境
- GDP 总量 / 增速 / 占全省比
- 产业结构（第一/第二/第三产业占比）
- 就业率 / 失业率
- 人均可支配收入 / 消费支出

### 3. 人口结构
- 常住人口 / 户籍人口
- 人口净流入 / 净流出
- 老龄化率（65+）
- 家庭户均规模

### 4. 客源画像
- 客群年龄 / 性别 / 收入
- 客源结构（省内 vs 省外 vs 入境）
- 复购率 / 入住频次
- 客户 LTV

### 5. 交通到达
- 机场吞吐量 / 航线数
- 高铁站数 / 日班次
- 高速里程
- 自驾比例

### 6. 5A/4A 景区
- 区域 5A / 4A 景区数量
- 头部景区年接待量
- 淡旺季客流分布

### 7. 酒店供给
- 在营酒店数（OTA 在售 / 工商注册 / 官方统计 三口径）
- 客房数
- 档次结构
- 连锁化率

### 8. 价格带
- 5 档次价格区间（经济 / 中端 / 中高端 / 高档 / 奢华）
- 同期对比
- 周环比 / 月环比

### 9. 竞品画像
- TOP 10 客户公司 / 集团
- 竞品房价 / 出租率
- 竞品定位 / 品牌

### 10. 客单价
- 人均消费
- 停留天数
- ADR / RevPAR
- 餐饮 / 其他收入

### 11. 财务环境
- 区域上市公司营收 / 利润
- 行业 GOP 率
- 人工成本率
- 能耗占收入比

## §8 失败模式

1. KYC 没做就开始 → 调研范围失控
2. 信源矩阵覆盖不全 → 关键发现来源不达标
3. 跨源验证未达 ≥3 源 → 数据可信度低
4. 结论无数据支撑 → 「我以为」式
5. 口径混用 → 同一指标不同口径混报
6. 时间口径不严 → 7 天对 8 天
7. 数据出处缺失 → 「业内人说」式
8. 编造缺失 → 远比标「未取得」差
9. 风险未写缓解 → 风险报告=风险制造
10. 11 维只做 3 维 → 调研不完整
