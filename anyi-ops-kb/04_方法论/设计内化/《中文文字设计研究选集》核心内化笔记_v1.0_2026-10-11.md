## 二、4 大核心方法（来自 web_search）

### M1 · 中文排版 ≠ 英文排版翻译

```
"中文字体 ≠ 拉丁字体翻译"
"中文软件 ≠ 拉丁软件翻译"
"中文排版 ≠ 拉丁排版翻译"
```

**Eric 海报对应**：用思源黑体 / Noto Sans SC（中文原生无衬线），**不是拉丁字体翻译**

### M2 · 三大中文排版问题

| 问题 | 现状 | 改进 |
|------|------|------|
| **字形与排版的混淆** | 字游工房强调字形设计；排版工坊关注排版逻辑 | 设计师应**两者并重** |
| **拉丁中心软件** | InDesign/Illustrator 等以拉丁文为先 | 中文排版需**自下而上**重新构建 |
| **排版教育缺失** | 高校字体教育偏拉丁 | 中文设计师应**懂中文排版的特殊性** |

### M3 · 中英文字体混排 4 规则

| 规则 | 实操 |
|------|------|
| **字号比** | 中字 ≈ 西字 × 1（中文略大或等大） |
| **基线对齐** | 西文 baseline 必须与中文对齐 |
| **字距协调** | 中文字间 0，西文字间 -0.02em |
| **字族选择** | 中文 + 西文必须是气质匹配的一对（如 Noto Sans SC + Inter）|

### M4 · 中文排版的"传统智慧"（孔雀计划）

| 元素 | 传统做法 | 现代做法（应回避）|
|------|---------|---------|
| **字号** | 等差缩小 |
| **行首** | "二行目"等格式讲究 | 自动忽略 |
| **断行** | 依头汉助避则（避头尾禁则）| 软件算法不完善 |

## 三、对 v10 海报的具体应用

| v10 元素 | 本书启示 |
|---------|---------|
| Noto Sans SC 主字体 | ✅ 中文本土无衬线（Kongque 推荐）|
| Inter 西文字体 | ✅ 与 Noto 气质匹配（信赖 + 现代）|
| 字号 78 / 28 / 22 / 18 / 15.5 | 符合"中文 1.5× 阶梯" |
| 字距 -0.02em / 0 / -0.005em | 符合"中 0、西 -0.02em"原则 |
| 中文海报 vs 中英混排 | Eric 当前纯中文，避开混排问题 |

## 四、对 Eric 海报排版的最终建议

| 决策 | 建议 | 原因 |
|------|------|------|
| **主字体** | Noto Sans SC（保持）| 中文原生无衬线 |
| **西文字体** | Inter（保持）| 与 Noto 气质匹配 |
| **字距** | 大标题 -0.02em / 正文 0 / 引文 -0.005em（保持） | 中文 0 + 西文负字距 |
| **基线对齐** | 全部文本 single baseline | 中文 + 西文必对齐 |
| **是否加西文** | 暂不（纯中文版） | 混排风险高于收益 |
| **将来加西文** | 字号比 1:1，Inter 单字号 | 跨文化设计基础 |

## 五、与 v10 设计 DNA 衔接

```
v10 海报 = 中文排版原生性 + 国际字体混排基础
→ Noto Sans SC（中文）+ Inter（西文）= 中西混排黄金对
```

## 六、维护触发器

- Eric 让做纯中文海报 → Noto Sans SC + Inter
- Eric 让做中英混排 → 字号比 1:1 / 基线对齐 / 字距 0
- Eric 让做"东方风格" → 思源宋体 / Noto Serif SC（中文衬线）
- Eric 让做"科技感" → Inter 单独 / 等宽字体（如 Roboto Mono）
