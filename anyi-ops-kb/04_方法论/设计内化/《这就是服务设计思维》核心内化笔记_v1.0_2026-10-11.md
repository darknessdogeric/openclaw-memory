## 一、核心命题（5 大原则 + 1 个核心心法）

```
"服务应该通过客户的眼睛来体验。"
—— Marc Stickdorn & Jakob Schneider
```

**5 大原则**（Stickdorn & Schneider 提出）：

| 原则 | 含义 | Eric 海报对应 |
|------|------|--------------|
| **以用户为中心** | 每个阶段优先考虑客户需求 | ✅ Eric 海报为"目标受众"设计 |
| **共同创造**（Co-creative）| 让所有利益相关者参与 | ⚠️ Eric 海报应由产业部 + 集团品牌 + 受众代表共建 |
| **顺序性**（Sequencing）| 将交互映射为结构化旅程 | ✅ 标题→副标→段→结尾 流程清晰 |
| **有形化**（Evidencing）| 物理/数字让无形服务可见 | ✅ B 标 + 数字徽章让"理念"可见 |
| **整体性**（Holistic）| 考虑情感/物理/环境所有触点 | ✅ v10 整体克制（深蓝紫 + 留白 = 情感统一）|

## 二、4 大核心方法

### M1 · 服务蓝图 5 要素

```
服务蓝图（前 5 排）+ 客户行为（顶/前一段）
┌──────────────────────────┐
│  客户行为          │ 客户步骤 ←─────┤
│  前台交互          │  可见触点      │
│  前台交互          │  员工反应      │
│  支持过程          │  后台流程      │ ← 不可见但必需
│  支持过程          │  内部依赖      │
└──────────────────────────┘
```

**Eric 海报对应**：每个 B 标 = 前台触点；每段内容 = 客户行为步骤

### M2 · 双钻石模型（Double Diamond）

```
探索（Discover）→ 发散：大量调研 + 同理心
  ↓
定义（Define）→ 收敛：聚焦核心问题
  ↓
发展（Develop）→ 发散：头脑风暴 + 原型
  ↓
执行（Deliver）→ 收敛：测试 + 实施
```

**Eric 海报对应**：
- v9 → v10 探索期：调研 GS V2 + 内部化设计书
- 定义期：聚焦"排版均匀 + 汉茶味"
- 发展期：3 次试改（标题缩小、字号放大、最后自然排版）
- 执行期：v10 上线 = 当前状态
