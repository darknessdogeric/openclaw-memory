## 一、国际主义风格（瑞士风格 / Swiss Style）5 大特征

| # | 特征 | Eric 海报对应 |
|---|------|--------------|
| 1 | **网格构造** | 8 栏网格（来自《网格系统》）|
| 2 | **非对称构图** | 主元素左对齐 / 副元素错落 |
| 3 | **客观摄影** | 不修图、不摆拍（Eric 海报无图，纯文字版）|
| 4 | **清晰事实的文案** | Eric 引用政府文件原文 / 原文浓缩 |
| 5 | **无衬线字体** | Noto Sans SC + Inter |

## 二、4 大核心方法（来自 web_search）

### M1 · 视觉统一通过非对称构图

```
数学网格 + 非对称元素 = 和谐但有节奏
```

**Eric 海报**：标题 78px 在主区左侧，副标 28px 在标题下——非对称但通过网格统一

### M2 · 客观清晰（客观性 > 装饰性）

```
不修饰、不夸张、不感情用事
设计 = 社会有用的事业
```

**Eric 海报**：纯深蓝紫渐变 + 白字 + 金点缀——无情感倾向，事实优先

### M3 · 数学网格 + 字体（国际主义两大基石）

```
网格 = 信息骨架
字体（无衬线如 Helvetica / Akzidenz-Grotesk）= 信息传达工具
```

**Eric 海报**：8 栏网格 + Noto Sans SC（中文无衬线）

### M4 · 极简 + 建构主义

```
# 摒弃装饰
形式 = 几何 + 纯粹（de Stijl 起源）
少即是多
```

## 三、Eric 海报的"瑞士风格"基因检查

| 瑞士风格元素 | Eric 海报 v10 |
|-------------|----------------|
| 网格构造 | ✅ 8 栏（来自《网格系统》）|
| 非对称构图 | ✅ 左对齐为主 |
| 客观摄影 | N/A（纯文字版）|
| 清晰文案 | ✅ 引用 Eric 原文 |
| 无衬线字体 | ✅ Noto Sans SC + Inter |
| 几何纯粹 | ✅ 深蓝紫（无装饰）|
| 少即是多 | ✅ 留白 ≥40% |

**结论**：Eric 海报是**纯文字版国际主义风格**——瑞士风格的现代延伸。

## 四、Eric 海报已应用瑞士风格的部分

| # | 元素 | 瑞士风格规则 |
|---|------|-------------|
| 1 | 整体构图 | 非对称 + 网格统一 |
| 2 | 字体 | Noto Sans SC（无衬线，对应 Akzidenz-Grotesk 精神）|
| 3 | 配色 | 单一主色 + 强调色（无渐变，但深蓝紫渐变也克制）|
| 4 | 留白 | ≥40% |
| 5 | 字号阶梯 | 2:1 比例（78/28/22/18/15.5）|
