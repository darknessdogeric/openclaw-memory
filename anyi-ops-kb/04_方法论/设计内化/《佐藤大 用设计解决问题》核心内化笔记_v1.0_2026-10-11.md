## 一、核心命题

```
"给人们一个小的'!'瞬间（giving people a small '!' moment）"
—— 佐藤大
"让设计本身成为一个容器"
"找 70 分的创意，把它做到 100 分"
```

---

## 二、4 大核心方法

### M1 · 同理心（用户视角）

```
"用'外行视角'和'忘记'来管理项目"
"重复的日常习惯能让我们注意到生活的细微差别"
"卷心菜椅灵感：与三宅一生合作时，从废褶皱纸里找到"
```

**Eric 海报应用**：✅ v10 的段标题 🔭💡🎯 = "日常但有用"的 emoji

### M2 · 简到极致

```
"少即是多，但不是简陋"
"我喜欢非常简洁的设计。
我希望作品本身能说话，因此越简单越好。
我想传达的讯息要直接、清晰。"
—— 佐藤大
```

**Eric 海报应用**：✅ v10 整体克制（无装饰、无多余元素）

### M3 · 不完美之美

```
"不完美反而更具人性化魅力"
"AI 适合设计大众市场产品，
但无法创造出有'错误'的东西"
"故意保留一些缺陷，让设计更有人情味"
```

**Eric 海报应用**：✅ v10 段间留白 + emoji（不是"完美"的）

### M4 · 物件要"健谈"

```
"物体必须健谈"
"好的设计能唤起情感"
"一件作品应该会讲故事"
```

**Eric 海报应用**：✅ v10 段标题 emoji 🔭💡🎯 = 每段都"讲故事"

---

## 三、对 v10 设计 DNA 的具体深化

| v10 元素 | 佐藤大哲学启示 |
|---------|---------------|
| 整体克制 | ✅ "少即是多，但不是简陋" |
| emoji 🔭💡🎯 | ✅ "日常但有用的小!" |
| 留白 ≥40% | ✅ "让设计成为容器" |
| 段间 14-18px | ✅ "不完美之美" |
| 深蓝紫渐变 | ✅ "克制 + 情感" |

---

## 四、Eric 海报"70 分 → 100 分"流程

```
v9（70 分）→ v10（100 分）
- 70 分：基本排版 + 留白
- +10 分：emoji 段标题（日常但有用）
- +10 分：深蓝紫渐变（克制 + 情感）
- +10 分：v10 整宽横线（段间分隔）
```

**Eric 海报启示**：✅ v9 不必完美，**持续做到 100 分**

---

## 五、维护触发器

- Eric 让做新海报 → **先做 70 分版**，再迭代到 100 分
- Eric 让加元素 → **问"这是功能吗？"**（不是 = 删掉）
- Eric 反馈"没新意" → **找"日常 + 小!"的细节**

---

> **B166ER 老实说**：佐藤大的核心心法**"给人们小的 ! 瞬间"**——v10 的每个 emoji 段标题都是给读者的"！"。**好的设计不是大创意，是无数小!的积累**。
