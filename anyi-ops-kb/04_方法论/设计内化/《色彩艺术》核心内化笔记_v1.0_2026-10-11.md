## 二、4 大核心方法

### M1 · 7 大色彩对比（核心心法）

| # | 对比 | Eric 海报应用 |
|---|------|--------------|
| 1 | **色相对比** | ✅ 深蓝紫 vs 白色（h1 标题）|
| 2 | **明暗对比** | ✅ 深底浅字 vs 浅底深字（v10 深蓝紫渐变）|
| 3 | **冷暖对比** | ⚠️ v10 全冷色（蓝紫单一）|
| 4 | **补色对比** | ✅ 深蓝紫 vs 暖金琉璃黄 |
| 5 | **同时对比** | ✅ 蓝紫渐变背景中放明亮 B 标 |
| 6 | **纯度对比** | ✅ 深紫背景 + 鲜亮金色装饰 |
| 7 | **面积对比** | ✅ 标题大字号 + 段间大留白 |

**v10 已覆盖 7/7 对比**——色 / 明暗 / 冷暖 / 补色 / 同时 / 纯度 / 面积

### M2 · 12 色相环

```
黄 / 橙 / 红 / 紫红 / 紫 / 蓝紫 / 蓝 / 蓝绿 / 绿 / 黄绿 / 黄橙 / 红橙
→ 12 色相 = 色彩系统的"原子"
```

**Eric 海报应用**：✅ v10 用"深蓝紫 + 琉璃黄 + 玄色" = 12 色相环中的"蓝紫 - 黄"互补

### M3 · 主观 vs 客观

```
"色彩 = 主观经验 + 客观原理的桥梁"
"歌德研究色彩 → 伊顿研究色彩 → 我们应用色彩"
```

**Eric 海报应用**：✅ 深蓝紫（客观信赖）+ 留白（主观空）+ emoji（主观装饰）

### M4 · 7 大对比与 v10 对应

```
对比 #4（补色） = 深蓝紫（4925）+ 黄（4895）= 黄金分割比
对比 #1（色相） = 蓝紫 + 白 = 强烈
对比 #7（面积） = 标题大 + 段间大留白
```

## 三、对 v10 设计 DNA 的具体深化

| v10 元素 | 伊顿 7 对比启示 |
|---------|---------------|
| 深蓝紫渐变 | ✅ "冷色 + 纯度对比"（深紫 vs 浅紫）|
| 琉璃黄 B 标 | ✅ "补色对比"（蓝紫 vs 黄 = 最强对比）|
| 白色标题 78px | ✅ "明暗对比"（浅 vs 深）|
| 留白 ≥40% | ✅ "面积对比"（内容 vs 空白）|
| 蓝白基调 | ✅ "色相对比"（蓝 vs 白 = 强对比）|

**v10 = 伊顿 7 大对比的完美示范**

---

## 四、Eric 海报"配色法则"4 大建议

```
1. 主色 ≤ 2 色（v10：深蓝紫 + 白）✅
2. 辅色 1-2 色（v10：琉璃黄 + 玄色）✅
3. 同色系 ≤ 3 阶（v10：深蓝紫渐变 3 阶）✅
4. 不混暖冷（v10：全冷蓝紫 + 1 个金点缀）✅
```

## 五、维护触发器

- Eric 让"换颜色" → **7 大对比中找替换**（不是凭感觉）
- Eric 反馈"不协调" → **检查纯度 / 面积对比**
- Eric 反馈"色不对" → **回到 12 色相环**（相邻 = 和谐 / 互补 = 强烈）
