## 一、1 个核心比喻（20 世纪最卓越字型大师 Adrian Frutiger）

```
"喝完汤后，如果你还清楚记得汤匙形状的话，
这支汤匙就是设计不良。"
—— Adrian Frutiger
```

**寓意**：好的字体 = 完美融入设计，**使用后无痕迹**。Eric 海报同理——好的海报让读者记住"内容"，不是"字体"或"排版"。

## 二、5 大字体应用场景（来自商业品牌）

| 字体 | 场景 | 字体性格 |
|------|------|---------|
| **罗马碑文体** | LOUIS VUITTON / GODIVA 商标 | 霸气、历史感 |
| **铜版印刷系草书** | 经典电影《窈窕淑女》标题 | 优雅、古典 |
| **ITC Fenice** | RALPH LAUREN 商标 | 锐利、现代感 |
| **Neue Frutiger** | 蒙纳经典西文字体 | 信赖、人文温度 |
| **手写体** | 酒瓶/旅馆/餐厅（古典细腻）| 精致、细腻 |

## 三、4 大核心方法（Eric 海报可用）

### M1 · 字体与品牌定位匹配

```
"字体显现代感 → 选 ITC Fenice
 字体显历史 → 选 罗马碑文体
 字体显信赖 → 选 Neue Frutiger"
```

**Eric 海报对应**：深蓝紫 + Noto Sans SC = 信赖 + 客观（中信/政府公文气质）

### M2 · 字体性格与产品/场景匹配

| 场景 | 字体推荐 | 理由 |
|------|---------|------|
| 国企政府公文 | 思源黑体 / Noto Sans SC | 客观、信赖 |
| 高端酒店 | Optima / Trajan | 优雅、经典 |
| 互联网产品 | Inter / SF Pro | 现代、清晰 |
| 时尚消费品 | Didot / Bodoni | 锐利、奢华 |

### M3 · 中西文字体混排原则

```
"亚洲人不懂得如何正确使用西文字体，
更不懂得如何将亚洲文字与西文组合在一起。"
—— 小林章
```

**Eric 海报**：纯中文版无此问题，但若加英文（如 "B166ER"），需注意：
- 中英文字号比 ≈ 1 : 0.85-0.95（西文略小）
- 基线对齐
- 字距协调

### M4 · 字体与"时代感"

```
"字体能显现特有的气息与时代感"
```

**Eric 海报**：深蓝紫 + 无衬线 = 现代 + 信赖 + 政府公文气质（与时代合拍）
