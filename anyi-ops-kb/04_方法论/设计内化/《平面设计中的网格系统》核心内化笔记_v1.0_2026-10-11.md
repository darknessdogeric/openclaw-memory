## 一、书的总览

**4 大核心命题**：

| # | 命题 | 一句话 |
|---|------|-------|
| 1 | 网格是治理 | 不是装饰 / 不是限制 / 是"决策架构" |
| 2 | 网格消除决策 | 把"放哪里""多宽"等决策从设计流程中剥离 |
| 3 | 网格创造一致性 | 列 / 行 / 基线 / 边距 = 同源结构 = 系统一致 |
| 4 | 网格不可见 | 工作良好时网格是隐形的，你感受到的是"有序" |

**1 个核心金句**：
> "**The grid system is an aid, not a guarantee. It permits a number of possible uses and each designer can look for a solution appropriate to his personal style. But one must learn how to use the grid; it is an art that requires practice.**" —— Josef Müller-Brockmann

**3 大相关人物（书中常引用）**：
- **Karl Gerstner**：《资本》杂志"移动网格"（recursive division）
- **Josef Albers**：色彩与感知（包豪斯传承）
- **Karl Gerstner / Wim Crouwel**：阿姆斯特丹学派的几何网格

## 二、5 大核心方法（可直接套用）

### M1 · 网格构建 5 步法

```
Step 1  确定画布格式（page format）    → 1080×1440（海）/ 1920×1080（屏）
Step 2  设置边距（margins）             → 外 > 内，下 > 上
Step 3  划分栏数（columns）             → 4 / 6 / 8 / 12 栏（按内容密度）
Step 4  设定水平模块（rows / baseline）  → 行高 = 字号 × 倍数
Step 5  创建栏缝 + 字段矩阵（gutters + fields）→ 12-16px 栏缝
```

### M2 · 网格配置对照表（按内容选择）

| 字段数 | 结构 | 适用场景 |
|--------|------|---------|
| **4 字段（2×2）** | 极简 | 标题页、扉页 |
| **6 字段（2×3 / 3×2）** | 简单 | 小册子、简单编辑 |
| **8 字段（2×4 / 4×2）** | 标准 | **中等复杂度编辑**（Eric 海报默认） |
| **12 字段（3×4 / 4×3）** | 灵活 | 编辑目录、产品画册 |
| **20 字段（4×5 / 5×4）** | 复杂 | 综合出版物 |
| **32 字段（4×8 / 8×4）** | 极复杂 | 报纸（信息密集） |

### M3 · 7 大网格规则（Müller-Brockmann 原文）

| # | 规则 | Eric 海报对应 |
|---|------|---------------|
| 1 | 字段间垂直距离 = 一行 / 两行 / 多行文本 | 段间 14-18px（紧凑） |
| 2 | 水平间距取决于字号和插图大小 | margin-left 64-72px（8 栏网格） |
| 3 | 元素**精确**放入框架（不随意） | 所有边距整数倍 |
| 4 | 字体是空间材料，不是装饰 | 标题字距 -0.02em，正文 0 |
| 5 | 对齐网格 → 清晰、可读、一致 | 顶/底 meta 对齐左右 |
| 6 | 任何长度的文本 = **7-10 字/行** | 中文海报 14-22 字/段 |
| 7 | 网格是辅助，不是保证（需实践） | 灵活套用，不僵化 |

### M4 · 边距 4 原则

| 原则 | 解释 | 实操 |
|------|------|------|
| **外 > 内** | 外边距 > 内栏缝 | margin: 60-72px（外）/ 12-16px（栏缝） |
| **下 > 上** | 下边距 > 上边距（视觉重力感） | bottom: 60px / top: 36px |
| **左右对称** | mirror | left/right 等 |
| **栏缝统一** | gutter / padding 全无 | 12-16px 单一值 |

### M5 · 基线网格（baseline grid）

```
基线 = 字号 × 行距倍数
例：18px 文本 / 行距 1.8 = 32.4px 基线
```

**铁律：基线必须整除页面高度**（否则误差累积，溢出下边距）

## 三、3 类网格（按内容选）

| 类型 | 结构 | 何时用 |
|------|------|--------|
| **单栏** | 1 文本栏 + 边距 | 长文阅读、书籍 |
| **多栏** | 2-6 等宽 / 不等宽栏 | 杂志、报纸、网页 |
| **模块化** | 栏 × 行的交集产生模块 | 复杂出版、控制面板 |

**Eric 海报选择**：**多栏（8 栏）**——1080px / 60px 边距 / 8 栏 ≈ 112.5px/栏 + 12-16px 栏缝

## 四、立刻可用的执行清单（Eric 海报）

```
Step 1  画布 1080×1440，海报主用 8 栏
Step 2  margin 60-72px（外边距）/ 12-16px（栏缝）
Step 3  bottom > top（视觉重力）
Step 4  主元素按栏对齐（左对齐到栏内）
Step 5  段间 = 一行文本 × 1.5-2 倍
Step 6  引文密度 < 7-10 字/段（中文约 14-22 字）
Step 7  网格不可见（工作良好时）
```

## 七、对 Eric 工作的可操作建议

### Eric 海报默认网格（v3-v10 沿用）

```
1080 × 1440 海报
├─ margin 60-72px（外）/ 12-16px（栏缝）
├─ 8 栏 × 100px/栏（≈ 60-80 字/栏）
├─ 三段条对 25/50/25
├─ 元素左对齐到栏内（margin-left = 60 的整数倍）
└─ bottom > top（视觉重力感）
```
