## M1 · 8 栏网格法（来自 01 / 02 / 03）

### 1.1 基础网格（任何 1080×1440 海报）

```
画布  1080 × 1440
边距  60px（顶/底/左/右）
栏数  8 栏
栏宽  112.5px  →  (1080 - 60×2) / 8
栏缝  12px       →  实测用 16px

实际安全区  960 × 1320
每栏 + 栏缝单元  128.5px
```

### 1.2 三段式信息密度

| 区 | 占比 | 内容 |
|----|------|------|
| **顶部 1/4** | 0-25% | 标题 / 副标 / meta |
| **中部 1/2** | 25-75% | 主体 / 卡片 / 段落 |
| **底部 1/4** | 75-100% | 总结 / 落款 / banner |

### 1.3 元素对齐（避 1px 偏差）

- **左对齐**：margin-left 必须等于边距（60px）的整数倍
- **垂直对齐**：top 必须等于边距（38px）+ meta 高度 + kicker line（15px）
- **元素宽**：必须是 8 栏宽（112.5px）或其倍数

## M2 · 字号阶梯与行距（来自 04 / 05 / 06 / 07）

### 2.1 字号阶梯（黄金比例 1.5×）

| 层级 | 字号 | 用途 |
|------|------|------|
| **Hero** | **78px** weight 900 | 大标题（1-2 行） |
| **H2** | **28px** weight 500 | 副标题 |
| **H3** | **22px** weight 700 | 段标题 🔭💡🎯 |
| **Body** | **18px** weight 400 | 正文（line-height 1.8） |
| **Quote** | **15.5px** weight 500 | 引文（line-height 1.7） |
| **Banner** | **24px** weight 700 | 底部结论 |
| **Meta** | **18px** weight 600 | 顶部 meta |
| **Sign** | **18-20px** | 签名 |
| **Label** | **10-11px** Inter | 标签（小元素） |

### 2.2 行距公式

```
正文行距 = 字号 × 1.6 - 2.0
引文行距 = 字号 × 1.7 - 1.9
大标题行距 = 字号 × 1.1（紧凑）
副标行距 = 字号 × 1.35
```

### 2.3 中文字距（不要 0！）

```
大标题（≥48px）：letter-spacing: -0.02em（负）
副标题（22-28px）：letter-spacing: 0
正文（18px）：letter-spacing: -0.01em 或 0
引文（15.5px）：letter-spacing: -0.005em
```

## M3 · 设计的 7 大基础法则（来自 14 / 15 / 16）

### 7 条 Eric 立即可用法则

| # | 法则 | 实操 |
|---|------|------|
| 1 | **对齐**（Alignment） | 所有元素必须有看不见的线对齐（左/中/右） |
| 2 | **接近**（Proximity） | 相关元素靠近，组间距 > 段间距 |
| 3 | **对比**（Contrast） | 大小/颜色/粗细至少 2 个维度对比 |
| 4 | **重复**（Repetition） | 同类元素用同一样式（卡片、徽章、数字） |
| 5 | **层级**（Hierarchy） | 字号/字重/颜色区分主次 |
| 6 | **呼吸**（Breathing Space） | 段间留 1.5-2 倍行高 |
| 7 | **克制**（Restraint） | 一个焦点，不堆元素 |

### 7 法则应用到海报

| 元素 | 应用的法则 |
|------|-----------|
| 顶部 meta（左 dot 大圆点） | 法则 3（对比）+ 4（重复，圆点短促） |
| 标题 78px + 副标 28px | 法则 3（对比 2.8 倍字号差） |
| 段标题 22px + 🔭💡🎯 emoji | 法则 3（对比，emoji 视觉锚点） |
| 段间 14-18px | 法则 2（接近，相关元素靠近）+ 6（呼吸） |
| 整宽横线 | 法则 1（对齐，1px 贯穿） |
| 底部 banner 蓝边 | 法则 3（对比）+ 5（层级） |

## M4 · 空白与克制美学（来自 19 / 20 / 28 / 29 / 30）

### 4.1 原研哉"空"的概念

- 留白不是"空的"——是**信息密度调节器**
- 海报一半以上的面积应该是"安静"的
- 一张大图 / 大字 + 大量留白 > 满版元素

### 4.2 "空"的实操

| 操作 | 比例 |
|------|------|
| 海报留白占比 | ≥40%（v3 实际占 50%） |
| 主元素最大尺寸 | ≤画布 1/3 宽 |
| 一张海报只能有 | 1 个焦点 |

### 4.3 Eric 的"克制"偏好（从 v2-v10 反馈提取）

- ✅ 标题不大（已确认 64-78px 是上限）
- ✅ 数字徽章 32px（不大不小）
- ✅ 字号比例稳定（不要每版差太多）
- ✅ 留白足够（不要挤）
- ✅ 引文不单行也不挤成两行（`text-wrap: balance`）

## 反模式（绝对不要做）

| ❌ 反模式 | ✅ 应该 |
|---------|--------|
| 标题 96px+ | 最大 78px |
| 单行硬塞（white-space: nowrap）| 用 `text-wrap: balance` |
| 内容挤上部 | main 用 `justify-content: space-between` |
| 段间 30px+ | 14-18px（紧凑） |
| 暖色背景 | 永远深蓝紫渐变 |
| 数字徽章 50px+ | 32-42px |
| 引文蓝色字体 | 白色字 + 蓝色左边框 |
| 满版元素 | ≥40% 留白 |
