## 一、核心命题（4 大图文编排原则）

| # | 原则 | 一句话 |
|---|------|-------|
| 1 | **韵律** | 重复 + 间隔 + 渐变 = 视觉流动感 |
| 2 | **留白** | 主动营造的负空间（不是"空的"）|
| 3 | **比例尺度** | 精确控制图片尺寸对比 + 空间占比 |
| 4 | **视觉流程** | Z 字形 + 焦点 + 对比 = 信息传递路径 |

## 二、4 大核心方法（Eric 海报可用）

### M1 · 韵律法（重复 + 间隔）

```
重复元素：等距 / 等大 / 等色
间隔空隙：让节奏"呼吸"
渐变：尺寸 / 明暗 / 朝向 → 视觉流动
```

**Eric 海报**：段标题用 emoji 🔭💡🎯 = 重复元素 + 不同内容

### M2 · 留白 4 原则

| 原则 | 实操 |
|------|------|
| 负空间不是空白 | 主动设计 |
| 疏密对比 | 用密集区对比留白区 |
| 主图"外出血" | 环绕核心 60-80px 留白 |
| 连贯通透 | 多图组合周边留空 |

### M3 · 比例尺度

- 黄金分割（0.618）、三分法 = 图片定位
- 单图放大 vs 系列小图 = 焦点建立
- 建筑师的思维方式：限定的版面里决定视觉优先级

### M4 · 视觉流程 4 步法

```
Step 1  信息按阅读感知次序排列
Step 2  上 → 下 / 左 → 右 的 Z 字形动线
Step 3  左上 + 中上部 = 最佳视域
Step 4  焦点 + 对比 → 引导视线
```
