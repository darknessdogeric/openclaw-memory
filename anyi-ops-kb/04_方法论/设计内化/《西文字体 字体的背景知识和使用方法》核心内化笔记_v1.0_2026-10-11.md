## 二、4 大核心方法（来自赫尔曼·察普夫 Herman·Zapf 推荐）

### M1 · 三组硬指标（光学补偿）

```
x-height（小字母 x 的高度）= 决定字体性格
- 高 x-height（Helvetica）→ 现代、清晰
- 低 x-height（Times）→ 经典、优雅
```

### M2 · 笔画粗细补偿

```
"弯曲线条看起来比直线条细，
因此需要相应增粗来平衡视觉感受。"
—— 小林章
```

**Eric 应用**：v10 海报里的曲线（数字 "75%" / "35%"）已自然补偿视觉

### M3 · 字母构造（基础术语）

| 术语 | 含义 |
|------|------|
| ascender | 上伸部（b d f h） |
| descender | 下伸部（g j p q y）|
| cap height | 大写字母高 |
| x-height | 小写 x 的高 |
| counter | 字母内空白（e、o、a 的洞）|
| terminal | 笔画端（衬线/无衬线）|

### M4 · 西文字体年代特征图谱

```
衬线体（serif）= 经典 / 权威 / 印刷品
无衬线体（sans-serif）= 现代 / 清晰 / 屏幕
装饰体（display）= 个性 / 节制使用
等宽体（monospace）= 代码 / 技术
```

## 三、Eric 海报字体选择矩阵

| 海报调性 | 推荐字体 |
|---------|---------|
| 国企 / 政府 / 公文 | Noto Sans SC（信赖、客观）|
| 高端酒店 / 奢华 | Noto Serif SC（经典、权威）|
| 互联网 / 科技 | Inter（现代、清晰）|
| 文化 / 艺术 | Noto Serif SC + 宋体（人文）|
| 数据 / 科技 | Inter + Roboto Mono（数据感）|

**Eric 当前选择**（v10）：Noto Sans SC（信赖）+ Inter（数字）—— ✅ 国企 + 数据感，完美

## 四、对 v10 设计 DNA 的支撑

| v10 元素 | 本书启示 |
|---------|---------|
| Noto Sans SC 主字体 | 国际可信字体实践 |
| Inter 数字 | 现代信赖 |
| 不用衬线（与 Eric 原 v3 思源宋不同）| 客观 + 现代 + 信赖（与"国企公文"调性匹配）|
| 字距 -0.02em（标题）| 字号越大越需要负字距（视觉补偿）|

## 五、Eric 海报字体自检清单

```
□ 标题：Noto Sans SC ≥48px → 字号 ≥字距 × 2 → OK
□ 正文：14-22 字/行（中文 7-10 字符）→ OK
□ 数字：Inter ≥20px → OK
□ 中西文混排（如有）：西文小 5-10% → OK
□ 字体颜色：白字 + 蓝强调 + 金点缀 → 3 色足矣
□ 不用同类字距大段：至少 8 行
```

## 六、对 Eric 海报的最终建议

| 决策 | 建议 |
|------|------|
| **字体升级** | 维持 Noto Sans SC（v10 比例）—— 已最优 |
| **加西文时** | Inter 替代 Helvetica/思源黑体西文—— 字号小 5% |
| **数据数字** | Inter 900 + tabular-nums（数字等宽）|
| **强调元素** | bold + 数字 + 蓝色——"三个一致原则"|
