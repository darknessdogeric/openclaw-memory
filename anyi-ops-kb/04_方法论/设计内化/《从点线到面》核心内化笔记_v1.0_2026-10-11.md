## 二、3 大核心方法（Eric 海报可应用）

### M1 · 点（Point）

```
"最简洁的自我陈述"
"打破空间平衡的张力"
"沉默与言语的辩证体"
"点的本质是沉默与言语的终极结合"
```

**Eric 海报应用**：✅ B 标 = "点"（24-28px 圆形，张力锚点）

### M2 · 线（Line）

```
"移动点的轨迹"
"水平线 = 平静 / 寒冷 / 支撑"
"垂直线 = 生长 / 温暖 / 行动"
"对角线 = 冷暖兼具 / 张力均衡"
"曲线 = 弹性 / 反传统"
```

**Eric 海报应用**：✅ 整宽横线 = "水平线"（平静 + 分隔）
✅ 段标题排版 = "垂直线"（明确阅读节奏）

### M3 · 面（Plane）

```
"通过线与点的组合构成"
"画布 = 具有内在张力的'活的有机体'"
"决定画面的基本结构框架"
"为构图找到数值化表现"
```

**Eric 海报应用**：✅ 整张海报 = "面"，由 B 标（点）+ 整宽横线（线）+ 文字块（面）组成

## 三、对 v10 设计 DNA 的具体深化

| v10 元素 | 康定斯基 3 要素启示 |
|---------|---------------------|
| B 标 24px | ✅ 点——"打破空间平衡的张力" |
| 整宽横线 | ✅ 线——"水平线 = 平静 + 支撑" |
| 文字块 | ✅ 面——"通过线与点的组合构成" |
| 段间 14-18px | ✅ 张力关系（点与面的呼吸） |
| 深蓝紫渐变 | ✅ "数值化表现"（不是纯色） |

**v10 = 康定斯基 3 要素海报**：点（焦点）+ 线（分隔）+ 面（结构）

---

## 四、Eric 海报"点线面"自查清单

```
□ 每个段落是否有"焦点"（B 标 / 大字号）？
□ 每个段落之间是否有"分隔"（整宽横线 / 段间留白）？
□ 整张海报是否有"结构"（8 栏网格 / 三段条对）？
□ 三要素是否平衡？（点+线+面）
```

---

## 五、维护触发器

- Eric 反馈"太满" → **检查"面"是否过大**（减少文字密度）
- Eric 反馈"没焦点" → **强化"点"**（B 标加大 / 标题加重）
- Eric 反馈"没结构" → **强化"线"**（整宽横线加粗）

---

> **B166ER 老实说**：康定斯基 100 年前讲的"点线面"是 v10 海报的骨架——v10 之所以"有设计感"，是因为它符合"焦点（B 标）+ 流动（文字）+ 分隔（横线）"三要素。**v11 改进方向不是"加东西"，是"让点更明确"**。
