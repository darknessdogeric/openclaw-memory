## 二、4 大核心方法（Eric 海报可立刻应用）

### M1 · 80/20 法则（Pareto Principle）

```
20% 的努力 → 80% 的结果
对 Eric 海报：20% 的版面（标题 + banner）
决定 80% 的视觉印象
```

**Eric 海报应用**：✅ 标题 78px（占视觉重心 20% 的版面）

### M2 · 意元集组（Gestalt Grouping）

```
- 接近（Proximity）：相近 = 同组
- 相似（Similarity）：相似 = 同组  
- 闭合（Closure）：闭合 = 同组
- 连续（Continuity）：连续 = 同组
- 对称（Symmetry）：对称 = 同组
- 共同命运（Common Fate）：同向 = 同组
```

**Eric 海报应用**：
- 段标题 🔭💡🎯 相近 = 同组（4 段视觉单元）
- 整宽横线 = 连续 = 同组（分段）
- 左右对齐 = 对称 = 同组（专业感）

### M3 · 娃娃脸偏见（Baby-face Bias）

```
"可爱 = 良好" 的视觉偏见
人脸比非人脸更易记住
圆形比方形更易接受
```

**Eric 海报应用**：✅ B 标圆形（v3 开始）

### M4 · 奥卡姆剃刀（Occam's Razor）

```
"如无必要，勿增实体"
简单胜过复杂
简单胜过复杂
```

**Eric 海报应用**：✅ v10 整体克制（无装饰、无多余元素）
