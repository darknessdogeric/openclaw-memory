## 二、4 大核心方法（平面设计 4 大时期）

### M1 · 瑞士国际主义（Swiss Style）

```
时间：1950 年代成熟
核心：网格 + 无衬线 + 客观摄影 + 左对齐
代表人物：Müller-Brockmann / Hofmann / Ruder
对 Eric 海报影响：v10 = 瑞士国际主义中文应用
```

**Eric 海报应用**：✅ v10 8 栏网格 + Noto Sans SC（无衬线）+ 左对齐 + 深蓝紫（信赖客观）

### M2 · 包豪斯（Bauhaus）

```
时间：1919-1933
核心：功能 + 工业 + 民主 + 形式追随功能
代表人物：Gropius / Itten / Klee / Albers / Moholy-Nagy
对 Eric 海报影响：v10 的"功能主义"（每个元素都有用）
```

**Eric 海报应用**：✅ v10 段标题 🔭💡🎯 都有功能（视觉引导，非装饰）

### M3 · 国际主义（International Style）

```
时间：1957 年洛克菲勒展
核心：网格 + 无衬线 + 不对称 + 客观
代表人物：Müller-Brockmann / Bill
对 Eric 海报影响：v10 左对齐排版
```

**Eric 海报应用**：✅ v10 = 国际主义中文版（不是装饰，是系统）

### M4 · 数码时代平面设计

```
时间：1990s 后
核心：屏幕 + 动态 + 多终端 + 用户参与
代表事件：Adobe / 苹果 / 印刷革命
对 Eric 海报影响：v10 设计是为屏幕设计，不是为印刷设计
```

**Eric 海报应用**：✅ v10 适合朋友圈屏幕（不是报纸印刷）

## 三、对 v10 设计 DNA 的具体深化

| v10 元素 | 平面设计史启示 |
|---------|---------------|
| 8 栏网格 | ✅ Müller-Brockmann（瑞士网格） |
| Noto Sans SC | ✅ Hofmann 无衬线（瑞士字体）|
| 左对齐 | ✅ 国际主义排版（vs 中文居中）|
| 深蓝紫（信赖）| ✅ 客观 + 现代化色彩 |
| 整宽横线 | ✅ Ruder 网格分隔 |
| 留白 ≥40% | ✅ Hofmann "白的多" |
| 字号 78/28/22/18 | ✅ Müller-Brockmann 字号阶梯 |

**v10 = 中文海报里的瑞士国际主义**

## 五、维护触发器

- Eric 让"改风格" → **先确认：瑞士 / 包豪斯 / 新艺术？**（不是凭感觉改）
- Eric 反馈"太花哨" → **回归国际主义**（左对齐 + 网格 + 无装饰）
- Eric 反馈"像印刷品" → **转数码风格**（参考 v10 = 屏幕展示）

---

> **B166ER 老实说**：v10 不是 Eric 的原创，是 Eric 借用 100 年的设计史"瑞士国际主义"做出的中文海报。**v10 看起来"高级"是因为它站在 1950 年代巨人的肩膀上**。下次 Eric 让"看起来更现代"，不是"加颜色 9 种"，而是"减到 2 色 + 加大留白"——这是 1950 年代的智慧。
