## 一、核心命题

```
UX 度量 = 可观察 + 可量化 + 用于决策
不是"度量耗费时间"——简单的度量可纳入日常评估
不是"度量昂贵"——有价值的数据可低成本收集
不是"不适用新产品"——新产品更需要基线
```

## 二、6 大度量类别（核心框架）

| # | 类别 | Eric 海报对应 | 度量 |
|---|------|---------------|------|
| **1** | **操作绩效类** | 海报加载 / 阅读速度 | 任务成功率 / 完成时间 / 错误率 |
| **2** | **问题类** | 视觉混乱度 | 可用性问题频次 + 严重程度 |
| **3** | **自报告类** | 读者满意度 | 易用性 / 满意度问卷 |
| **4** | **网页导航类** | 滚动深度 / 点击率 | 页面放弃率 |
| **5** | **衍生类** | 综合指标 | 复合度量（如 SUS / NPS）|
| **6** | **行为/生理类** | 注视追踪 | 眼动 / 压力 / 面部表情 |

## 三、4 大核心方法（来自 web_search）

### M1 · 度量必须可量化

```
"UX 度量 = 可观察 + 可量化"
"能转化为数字或计数"
"支持关于用户行为的决策"
```

**Eric 海报对应**：海报"成功" = 行为可量化（24h 扫码率、转发率、收藏率）

### M2 · 6 大常见误区

1. **耗时**：简单度量可 5 分钟集成
2. **昂贵**：低成本方法同样有效
3. **不适用新产品**：新产品最需要基线度量
4. **技术门槛**：基础度量不需技术
5. **量化即数字**：问卷也能量化
6. **只看用户**：也应看行为

### M3 · 6 类度量实操

| 度量类别 | Eric 海报适用？| 如何测？|
|---------|----------------|---------|
| 操作绩效 | ✅ 海报打开速度 | Lighthouse |
| 问题类 | ✅ 视觉问题清单 | 5 人测试 |
| 自报告类 | ✅ 满意度 | 5 分量表 |
| 网页导航 | ✅ 滚动深度 | GA4 |
| 衍生类 | ✅ 综合满意度 | NPS / SUS |
| 行为生理 | ❌ 海报不需要 | 仅适用数字产品 |

### M4 · 度量项目 4 步流程

```
Step 1  目标设定（我们想改变什么行为？）
Step 2  指标选择（用 6 类中哪 1-2 类？）
Step 3  数据收集（5 人测试 / 问卷 / 分析工具）
Step 4  行动（验证假设 / 迭代设计）
```

## 四、对 v10 设计 DNA 的具体深化

| v10 元素 | 度量启示 |
|---------|---------|
| 海报完成 | ⚠️ 不算成功 → 需"行为变化"才算 |
| 设计对比 v9 → v10 | ⚠️ 需度量"哪个更好"——单看美观不算 |
| 朋友圈发布 | ⚠️ 需量化（24h 互动率 / 收藏数 / 转发数）|
| 视觉审美 | ⚠️ 需测试（5 人审美一致性）|

**核心心法**：**"完成" ≠ "成功"**——Lean UX + 度量都强调这个。

## 五、Eric 海报度量实践（3 项）

```
□ 海报上线 24h 后
   → 扫码率 / 收藏率 / 转发率（自报告类）
   
□ 海报 3 个版本对比
   → "哪个版本的转化更高"（操作绩效类）
   
□ 海报用户访谈（5 人）
   → "是否记得核心信息"（问题类）
```

## 六、对 v10 设计 DNA 的最终建议

| 维度 | v10 默认 | 改进方向 |
|------|---------|---------|
| "完成海报" ≠ 成功 | ⚠️ | 加行为度量 |
