## 一、核心命题

```
"数据分析不是'事后报告'，是'事前决策'。"
"数据分析基本步骤 = 分解数据 → 实验 → 优化 → 假设检验 → 沟通"
"假设检验的核心 = 证伪（Falsification），不是证实（Confirmation）"
```

---

## 二、4 大核心方法

### M1 · 数据分析 6 大步骤

```
Step 1  分解数据（Decomposition）
Step 2  实验（Experimentation）
Step 3  优化（Optimization）
Step 4  假设检验（Hypothesis Testing）—— 证伪
Step 5  主观概率（Subjective Probability / Bayesian）
Step 6  沟通（Communication）
```

**Eric 海报对应**：✅ v10 上线后 = 走 Step 6（沟通读者）

### M2 · 假设检验 5 大心法（核心）

```
1. 假设检验的核心是"证伪"，不是"证实"
2. 现实世界是"网络关系"，不是"线性关系"
3. 线性 = 直觉；网络 = 复杂
4. 证据的诊断性 = 证据能否排序假设
5. 假设 ≠ 事实 → 通过不断证伪逼近事实
```

**Eric 海报应用**：⚠️ 我之前假设"v10 比 v9 好"——这是**假设不是事实**。需要 5 人测试**证伪或证实**。

### M3 · 4 大可视化法（Eric 海报可用）

| 方法 | 用途 | Eric 海报对应 |
|------|------|--------------|
| 直方图 | 看频率分布 | 读者年龄/职业分布 |
| 散点图 | 看两个变量关系 | v9 vs v10 评分对比 |
| 折线图 | 看时间序列 | v9 → v10 → v11 演进 |
| 箱线图 | 看分布特征 | 不同人群对 v10 的反应 |

### M4 · 数据分析十大要诀

```
1. 数据分析前先问："要回答什么问题？"
2. 永远假设"数据可能错"
3. 先理解数据再分析
4. 永远用多种方法验证同一结论
5. 简洁胜于复杂
6. 让数据说话，不让假设说话
7. 接受误差
8. 区分相关和因果
9. 假设可以错，结论必须可证伪
10. 沟通 > 复杂分析
```

## 四、Eric 海报可验证假设（Hypothesis）

```
H1: v10 在"哲学信任"感上 ≥ v9（目标行为）
   实验：5 人测试
   证伪：若有 ≥3 人选 v10 < v9，则假设不成立

H2: 顶 + 底 banner 增加"完整感"
   实验：A/B 测试（v10 with vs without banner）
   证伪：若有差异不显著，假设不成立

H3: 段标题 emoji 帮助"扫读"
   实验：5 人测试扫读速度
   证伪：若无差异，假设不成立
```
