## 二、4 大核心方法（设计思考 5 阶段）

### M1 · 同理（Empathize）

```
通过观察、访谈、体验、角色扮演等方式
真正站到使用者的角度
了解其需求、行为、痛点
**而不是只看市场数据**
```

**Eric 海报应用**：✅ v10 是给"哲学型酒店投资人"看的——要理解他们的"思考节奏"

### M2 · 定义（Define）

```
把"同理"阶段收集的洞察重新组合、删去、挖深、组合
"用一句话定义使用者的真正需求"
"水面下的冰山"——把冰山显形
```

**Eric 海报应用**：✅ 3 段内容 = 3 个"用一句话定义"的痛点

### M3 · 发想（Ideate）

```
三不五要：
不打断、不批评、不离题
要延续他人想法、要画图、要疯狂
数量要多、要下标题
```

**Eric 海报应用**：⚠️ v9 → v10 之间的"4 次试改" = 发想过程

### M4 · 原型（Prototype）+ 测试（Test）

```
"做出一个东西，比讨论它要快"
原型不需要精致——草图 + 关键元素
测试 → 学 → 改进 → 测试（循环）
```

**Eric 海报应用**：✅ v9 → v10 → v11（如果做）= 原型+测试双循环

## 四、设计思考 4 大盲点（Eric 警惕）

| # | 盲点 | Eric 海报规避方法 |
|---|------|-------------------|
| 1 | **观察不深入**（只看市场数据）| ✅ 理解 Eric 受众，不靠直觉 |

## 五、Eric 海报 5 阶段设计冲刺

```
Day 1  同理 → 问 Eric："你想改变读者什么行为？"
Day 2  定义 → 5 人测试 v10："看完记住什么？"
Day 3  发想 → 出 v11 草图（3 个版本）
Day 4  原型 → 选定 1 个版本做高保真
Day 5  测试 → 5 人评估 + 微调
```

## 六、维护触发器

- Eric 让做新设计 → **5 阶段设计思考**（不只是"做出来")
- Eric 反馈"看不懂" → **回到同理**（用户角度错了）
- Eric 反馈"没新意" → **重新发想**（3 不 5 要）
- Eric 反馈"不实用" → **测试 5 用户**（而非 Eric 自己）
