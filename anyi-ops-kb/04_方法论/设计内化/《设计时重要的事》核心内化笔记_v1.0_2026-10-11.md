## 一、核心命题

```
"30 年决定设计方向的关键思考"
"设计 = 联系人和环境的媒介"
"物品 = 信息的入口"
"设计 = '翻译'（不是'创造'）"
"好的设计不用太多花招，重内涵，重细节，
还要诚实地与消费者沟通"
"天底下没有无聊的案子——你设想它无聊，它就无聊；
你决心让它有趣，它就有趣"
—— 设计时重要的事——佐藤卓
```

## 四、Eric 海报"7 大日常设计原则"

| # | 原则 | Eric 海报应用 |
|---|------|--------------|
| 1 | "无我" | ✅ 表现国堰，不表现 B166ER |
| 2 | "诚实" | ✅ 数据 = 真实 |
| 3 | "克制" | ✅ 少装饰 |
| 4 | "联系人和环境" | ✅ 海报在朋友圈 = "媒介" |
| 5 | "持久" | ✅ 可发表多年仍有效 |
| 6 | "不为美而美" | ⚠️ 不为好看而好看 |
| 7 | "信息入口" | ✅ 海报是国堰信息入口 |

## 五、维护触发器

- Eric 让"再设计" → **回到 7 大原则**
- Eric 反馈"无聊" → **"决心让它有趣"（不是添加，是态度）**
- Eric 反馈"过度" → **回到"克制"**
