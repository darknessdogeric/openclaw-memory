## 一、核心命题

```
"在书籍日趋多样、程式化的世界里，
成为雨过天晴后的小礼物"
"红黑双色印刷 + 斑驳活字字体 + 泛黄纸张

= 书籍作为物质载体的艺术价值"
—— 翻阅莱比锡——赵清
```

### M3 · "世界最美的书" 5 条标准

```
1. 整体性（书的所有部分都符合一个概念）
2. 网格精确（所有元素都在网格上）
3. 字体恰当（不超过 2 种字体）
4. 色彩克制（不超过 3 色 + 黑）
5. 物质性（纸张/装订与内容匹配）
```

**v10 自检**：
1. ✅ 整体性：深蓝紫主调一致
2. ✅ 网格：8 栏精确
3. ⚠️ 字体：2 种（Noto Sans + Inter）= OK
4. ✅ 色彩：3 色（深蓝紫、白、金）= OK
5. ⚠️ 物质性：数字版 = 自动通过
