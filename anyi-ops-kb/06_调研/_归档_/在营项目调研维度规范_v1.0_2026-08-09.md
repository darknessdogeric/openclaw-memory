## 三、关键指标计算口径（统一规范）

> **目的**：避免 78,752 间管理房间 + 52 家轻资产酒店口径不一，导致数据失真

### 3.1 收入类

| 指标 | 计算公式 | 包含 | 不包含 |
|------|---------|------|--------|
| 客房收入 | 房费净收入 | 含早/不含早/加床/服务费 | 餐饮/会议/其他 |
| 餐饮收入 | 餐厅 + 宴会 + 客房送餐 | 餐费 + 服务费 + 酒水 | 自营零售 |
| 其他收入 | 客房 + 餐饮 以外 | SPA/健身/洗衣/电话/商场租赁 | — |
| **总收入** | 客房 + 餐饮 + 其他 | — | 政府补贴/非经常性损益 |

### 3.2 成本类

| 指标 | 计算公式 | 包含 | 不包含 |
|------|---------|------|--------|
| 客房成本 | 房务部直接成本 | 客房用品/布草/水电/房务员工资 | 餐饮/管理费用 |
| 餐饮成本 | 食品 + 酒水 | 原料成本 + 厨员工资 | 餐具/餐厅装修 |
| 人工成本 | 全员工资 + 福利 + 五险一金 | 基本工资 + 绩效 + 社保 + 公积金 | 外包人员费 |
| 能源成本 | 水/电/燃气/蒸汽 | 实际消耗 | 工程部人员工资 |

### 3.3 比率类

| 指标 | 计算公式 |
|------|---------|
| 出租率 (OCC) | 已售房晚 / 可用房晚 |
| 平均房价 (ADR) | 客房收入 / 已售房晚 |
| 每房收益 (RevPAR) | 客房收入 / 可用房晚 = ADR × OCC |
| 经营毛利率 (GOP 率) | (收入 - 经营成本 - 经营费用) / 收入 |
| 客房毛利率 | (客房收入 - 客房成本) / 客房收入 |
| 餐饮毛利率 | (餐饮收入 - 餐饮成本) / 餐饮收入 |
| 人工成本率 | 人工成本 / 总收入 |
| 人房比 | 员工总数 / 客房总数 |
| 人均产值 | 总收入 / 员工人数 |
| 人均产能 | GOP / 员工人数 |
| 营利坪效 | GOP / 总建筑面积 (元/m²) |
| 单房成本 | 房务部成本 / 实际出租间夜数 |
| 集中采购率 | A+B 类集采品类数 / 总品类数 |
| 直销系统产量占比 | 直销渠道客房收入 / 总客房收入 |
| OTA 占比 | OTA 客房收入 / 总客房收入 |
| 有效会员转化率 | 当年新增会员 / 酒店住店人数 |
| 会员复购率 | 近12月消费>1次的会员 / 总消费会员 |
