### 0.3 核心结论（5 条）

1. **建议推进文化创建 + 局部改造（双轨）**：表层文创投入轻（20-30 万）可快速做，深层改造需另报预算
2. **核心客群重新定位为"入境游 + 政务接待 + 本地客群"三足鼎立**：免签政策红利 + 国企政务基因 + 本地餐饮转化
3. **核心差异化是水文化 IP + 汤池业态 + 最高建筑观景**：稀缺资源，无可替代
4. **核心风险是规模/档次错配（109 间客房做高端度假 → 玉垒山居前车之鉴）+ 轻/重资产权属未明**
5. **不建议立刻做整体翻新**：团队、政策、权属、资金四方面条件未成熟

### 0.4 投资建议

| 阶段 | 建议 | 预算估算 |
|------|------|---------|
| **短期（0-6 月）** | ✅ 推进文化创建（软装 + 水文化 IP + 新媒体矩阵 + 入境渠道）| 20-30 万 |
| **中期（6-12 月）** | ⚠️ 局部改造（亲子房升级 + 户外光彩工程 + 副楼翻新）| 500-1000 万 |
| **长期（1-3 年）** | ⚠️⚠️ 整体改造（视权属 + 团队成熟度）| 2000-5000 万 |

### 0.5 关键风险提示

- 🔴 **轻/重资产权属未明** → 集团正推进轻重分离改革，未签正式管理合同
- 🔴 **玉垒山居前车之鉴** → 200+ 房高端度假酒店停业，警示规模/档次错配
- 🔴 **现金流紧张** → 经营性现金流不足以覆盖日常支出，靠拖欠供应商维持
- 🟡 **入境游依赖政策** → 免签红利可能变化
- 🟡 **本地客群消费习惯不匹配** → 早餐月卡试点未达预期
