## 〇、模板使用指引

### 0.1 模板是什么

这是一份**可直接拿来干活的市场调研工具模板**，融合了三套方法论：

| 来源 | 方法论 | 适用场景 |
|------|--------|---------|
| **外资** | HVS（5 大模块）/ STR（竞争群 MPI/ARI/RGI 三大指数）/ Mews（5 步法）/ CBRE（趋势报告）/ NCHMA Model Content Standards 2025 / HVS H&LA / Kalibri（动态竞对）| 服务于投资人/银行/品牌方的可行性报告 |
| **内资龙头** | 锦江（Wehotel 会员体系）/ 华住（华住会直销 90%）/ 亚朵（A-card + 第四空间）/ 首旅如家（轻重分离）| 品牌矩阵 + 客群细分 + 加盟扩张 |
| **国资可研** | 22 项财务指标体系 / PEST / 三重一大 / 国家发改委可研规范 | 立项审批 + 国资委合规 |

**安逸独创融合**：
- 在地文化挖掘（都江堰水文化 / 花园市井文化 / 川宾巴蜀文化 / 茶山茶马古道）
- 数字体系化（10 维度 + AHL Agent）
- 自营能力（4 维度 + 会员商城 + 新媒体矩阵 + 品牌塑造）

# 第一部分 · 范式与方法论（为什么要这样做）

## 一、市场调研的根本问题

### 1.1 一句话核心命题

> **没有客群画像就没有产品定位，没有市场调研就没有客群画像，没有市场调研就没有投资决策，没有方法论的调研就是盲人摸象。**

### 1.2 市场调研要回答的 7 个根本问题

| # | 问题 | 错误的调研方式 | 正确的方法论 |
|---|------|--------------|------------|
| 1 | **客群是谁？** | 凭感觉、抄模板 | **PMS 历史 + 一线访谈 + OTA 评论三角验证** |
| 2 | **需求是什么？** | 看 OTA 评论 | **细分 8 大客群 + 价格敏感度 + 决策因子** |
| 3 | **竞对是谁？** | 选 5 家类似的 | **STR 标准 5 家同档位（按星级/房量分级）** |
| 4 | **市场容量多大？** | 查行业报告 | **3 年趋势 + 在建供给 + 增长曲线** |
| 5 | **能赚多少钱？** | 拍脑袋 | **ADR/OCC/RevPAR + DSCR/IRR/NPV 多情景** |
| 6 | **风险在哪？** | 走一步看一步 | **PEST + SWOT + 4 大不确定性 + 压力测试** |
| 7 | **该不该投？** | 一把手拍板 | **22 项财务指标 + NPV/IRR/DSCR + 敏感性** |

### 1.3 市场调研失败的 6 大后果（实战教训）

| 失败 | 后果 | 真实案例 |
|------|------|---------|
| 客群判断错 | 产品定位错→设计错→营销错→全盘错 | 古尔沟定位摇摆，3 年累计亏损 6.1 亿 |
| 竞对分析错 | 价格定错→出租率低→收入低 | 嘉州宾馆年均房价 1800-2000 万（错误口径）|
| 容量判断错 | 投资错→投了没人来→亏损 | 都江堰玉垒山居酒店 2026/1/31 停业 |
| 收益预测错 | 财务测算错→投资回收错 | 古尔沟用预付款当收入，虚增 1000 万 |
| 时效数据错 | 用了 1 年前的数据→错过市场变化 | 集团无实时 ADR/OCC 数据 |
| 合规数据错 | 数据未做财务入账口径统一→管理失控 | 26% 佣金 + 5 万元/间亲子房 |

### 1.4 外资 vs 内资 vs 国资方法论的差异（重要认知）

| 维度 | 外资方法论（HVS/STR/CBRE）| 内资龙头（锦江/华住/亚朵）| 国资可研报告 |
|------|---|---|---|
| **服务对象** | 投资人 / 银行 / 品牌方 | 集团内部 + 加盟商 | 国资委 / 集团党委 / 三重一大 |
| **核心目标** | 投资回报（IRR/DSCR/NPV）| 品牌溢价 + 会员流量 | 政策合规 + 经济效益 + 社会效益 |
| **数据来源** | STR + CBRE 数据库为主 | 自有 PMS/CRS + OTA 数据 | 第三方调研 + 政府公开 + 行业报告 |
| **方法论** | 5 大模块（市场基本面/区位/品牌适配/财务/风险）| 4 大体系（客群/产品/渠道/会员）| PEST + 财务 22 项指标 + 风险对策 |
| **产出** | 投资可行性报告 | 品牌定位 + 产品模型 | 可研报告（合规审批用）+ 立项申请 |
| **核心特征** | 独立、客观、可融资 | 体系化、可复制 | 合规、可审计、可追溯 |

**安逸融合策略**：
- **外资**：借鉴 STR 竞争群 + HVS 5 模块 + NCHMA 标准 + DSCR/IRR 财务框架（**应对银行/投资人/品牌方**）
- **内资**：借鉴锦江/华住的客群细分 + 产品模型 + 会员体系（**应对加盟商与连锁扩张**）
- **国资**：执行 PEST + 22 项财务指标 + 三重一大决策程序（**应对国资委/集团党委**）
- **独创**：融入安逸"在地文化挖掘 + 数字体系化 + 自营能力"三大护城河（**应对集团差异化定位**）

## 二、市场调研的 6 大方法论原则

### 原则 1：实时数据原则（外资 HVS/STR 核心）

> **至少采集最近 3 个月的实时数据，不能只看年报**

**外资依据**：HVS / STR / CBRE 报告全部基于最近 3-12 个月的市场表现数据；Mews 明确要求"Smith Travel Research (STR) reports, economic indicators and direct outreach to local tourism bodies"。

**安逸做法**：
- 酒店价格数据每月更新（OTA 实时抓取 + 单店 GM 报价对标）
- 出租率每周更新（PMS 自动导出）
- 行业数据每季度更新（STR 季报 + 迈点月报 + 中国饭店协会年报）

### 原则 2：双验证原则（外资与内资通用）

> **数据 + 访谈双验证，单一来源都不够**

**外资依据**：Mews "Collect data on local demand drivers, existing hotel supply and market performance trends" — 数据 + 一线访谈 + 政府对接三合一。

**安逸做法**：
- 任何关键判断必须有 2 个独立来源验证
- 量化数据（PMS/STR/OTA）+ 定性访谈（GM + 一线员工 + 关键客户 + 物业周边居民/商户）

### 原则 3：分价格段原则（外资 HVS/STR 核心）

> **不能只看平均 ADR，要看分价格段表现**

**外资依据**：HVS 报告必做"穿透率分析（Penetration Analysis）"——按价格段分层建模。

**安逸做法**：
- ADR 分 5-7 个价格段分析（300以下 / 300-500 / 500-800 / 800-1200 / 1200+）
- 客群分层（商务 / 度假 / 会议 / 协议 / 长住 / 散客 / 团购 / 入境）

### 原则 4：趋势重于绝对值原则（外资 Mews/HVS）

> **看 3 年趋势，不只看当下绝对值**

**外资依据**：Mews "Based on historical data, tourism statistics, and economic indicators, project the total demand for hotel rooms in the market. Account for growth trends, planned developments, and economic forecasts"。

**安逸做法**：
- 3 年趋势图 + 未来 3 年预测（产能扩张/政策窗口/客群变化）
- 不要因为 1 年差数据就否定项目

### 原则 5：机会洞察原则（安逸独创 + 外资借鉴）

> **调研不仅要回答"是什么"，更要回答"还有什么未被发现的"**

**外资借鉴**：HVS "Highest and Best Use Evaluation" — 不仅分析现有市场，更评估"最高最佳用途"。

**安逸做法**：
- 专项做"市场机会空白分析"（10-30 个潜在机会点）
- 发现"未被满足的细分需求"（如入境游客、银发康养、入境游学）

### 原则 6：集团标准化原则（国资 + 内资通用）

> **调研输出必须与集团标准化对接（会员/CRS/财务/采购/新媒体）**

**国资依据**：22 项财务指标 + PEST 分析 + 三重一大决策程序
**内资借鉴**：锦江 Wehotel + 华住华住会 + 亚朵 A-card 的会员对接

**安逸做法**：
- 调研报告里预留"集团标准化对接建议"模块
- 数据格式符合集团 PMS/CRS/RMS 接口

## 三、市场调研的 7 大避坑指南（外资 + 内资 + 安逸实战综合）

| # | 避坑 | 错误做法 | 正确做法 |
|---|------|---------|---------|
| 1 | **不要"凭感觉"判断客群** | GM 凭经验说"我们客群是商务客" | 用 PMS 历史数据 + 一线访谈 + 第三方调研，三方验证 |
| 2 | **不要选错竞对** | 选了完全不同档位的酒店做竞对 | 按 STR 标准：星级/无星级按房量，选 5 家同档位 |
| 3 | **不要用陈旧数据** | 用了 1 年前的数据 | 至少采集最近 3 个月的实时数据 |
| 4 | **不要只看平均值** | 只看竞对平均 ADR | 分价格段分析（300以下/300-500/500-800/800+）|
| 5 | **不要"调研一次就完"** | 调研完就归档 1 年后再看 | 每季度更新关键数据，调研是持续过程 |
| 6 | **不要"少样本推总体"** | 拿 3 个月的出租率推全年 | 至少 12 个月数据 + 季节性分析 |
| 7 | **不要"忽略财务口径"** | 只算收入不算成本 | 算 GOP、EBITDA、NOI、GOP Margin 全口径 |

## 四、市场调研与其他阶段的衔接

```
市场调研（阶段 1.1）
   ↓ 输出 7 大维度
项目定位（阶段 1.2）+ 功能配套模型
   ↓ 输出客群画像 + 产品定位
投资测算（阶段 1.3）
   ↓ 输出 IRR / NPV / DSCR
人力资源（阶段 1.4）
   ↓ 输出组织架构 + 人员编制
设计 + 文创（阶段 1.5）
   ↓ 输出设计任务书 + 在地文化元素
   ↓ 关键门控 G2：项目定位决议（领导班子审批）
```

**核心方法论洞察**：市场调研是"上游错误源"，**上游错则下游全错**。定位错了，后面所有环节全错。

# 第二部分 · 7 大维度执行框架（怎么干）

> **本框架融合外资 HVS 5 大模块 + 安逸 12 维度 165 项 + 内资可研报告 22 项指标 + 国资 PEST**
> **7 个维度都做 = 完成市场调研全部工作**
> **每个维度都附：调研清单 + 调研方法 + 调研输出 + 工具清单**

## 维度 1：项目物业踏勘与现状评估（外资 HVS "Site & Location Review" + 安逸维度 1）

### 1.1 调研清单（30+ 项）

| 子类 | 关键调研项 | 数据点要求 | 工具/方法 |
|------|----------|----------|----------|
| **位置** | 物业在城市/区域的位置、距 CBD 距离、距机场/高铁站车程 | 精确坐标 + 车程分钟数 | 高德地图 + Google Earth |
| **面积** | 总建面、客房面积、餐饮面积、会议室面积、停车场面积 | 平方米，精度到个位 | 物业资料 + 实测 |
| **结构** | 建筑结构、楼层、改造空间、动线规划可行性 | 建筑年代 + 承重 + 净高 | 建筑图纸 + 工程评估 |
| **设施** | 现有设施状态（客房/餐饮/会议/工程系统）| 设备清单 + 使用年限 + 故障率 | PMS + 工程部 + 实地 |
| **交通** | 公共交通可达性、停车位数量、周边交通拥堵 | 公交线路/地铁站/停车位 | 高德 + 实地 |
| **景观/视野** | 房间景观、噪音、夜景 | 每层景观房比例 | 实地 + 实拍 |
| **周边 3 公里** | 商业环境、餐饮配套、娱乐设施、医院 | 业态分布 + 距离 | 高德 POI + 实地走访 |

### 1.2 调研方法（外资 HVS "Accessibility & Proximity to Demand Generators"）

**A. 实地踏勘（必须 3 次）**
- 第 1 次：白天工作日（看通勤 + 商务客群）
- 第 2 次：周末（看休闲 + 度假客群）
- 第 3 次：夜间（看夜景 + 安全 + 噪音）

**B. 物业资料收集**
- 建筑图纸（总平 / 平面 / 立面 / 剖面 / 结构 / 水电）
- 设施清单（设备名称 / 型号 / 出厂年 / 报废期）
- 历史经营数据（PMS 历史 2-3 年）

**C. 权属与法律**
- 房产证 / 土地证
- 抵押 / 查封情况
- 租赁 / 合作合同
- 消防 / 安全 / 卫生许可

### 1.3 调研输出（必备交付物）

**《物业评估报告》** — 包含位置图、面积分布图、设施状态清单、权属状态、改建可行性评估

| # | 工具 | 用途 |
|---|------|------|

## 维度 2：客群画像研究（外资"Target Demographics" + 安逸维度 1）

### 2.1 客群细分 8 大类型（融合外资 + 内资 + 安逸在地客群）

| # | 客群类型 | 占比参考 | 调研重点 |
|---|---------|---------|---------|
| 1 | **商务散客** | 20-35% | 行业分布、出差频次、ADR 接受度、决策因子 |
| 2 | **商务协议客户** | 15-25% | 协议公司数、复购率、平均房价、年度消费 |
| 3 | **会议团队** | 10-20% | 会议类型（MICE）、季节性、团队规模、餐饮需求 |
| 4 | **度假休闲客** | 10-30% | 停留时长、人均消费、季节性、目的地偏好 |
| 5 | **本地居民** | 10-20% | 餐饮 / 婚宴 / 会议 / 健身房 / 茶饮 |
| 6 | **入境游客** | 5-15% | 来源国、语言、预订渠道、文化偏好 |
| 7 | **长住客** | 5-10% | 行业、人均消费、停留时长 |
| 8 | **散客（含 OTA / 直销）** | 20-40% | 渠道分布、价格敏感度、决策路径 |

### 2.2 调研方法（"PMS 历史 + 一线访谈 + 客群三角验证"）

**A. 数据来源（量化）**
- **酒店 PMS 历史数据**（最真实，反映实际入住客群）
- **OTA 评论分析**（了解需求痛点 + 价格预期）
- **携程/同程/去哪儿/Booking** 订单数据
- **第三方调研公司**（浩华 / HVS / 迈点 / EHL）

**B. 访谈验证（定性）**
- **单店 GM 深度访谈**（最懂一线）
- **一线员工座谈**（前台/餐饮/客房/销售）
- **关键客户访谈**（协议客户/会员客户）
- **物业周边居民/商户访谈**（了解本地客群）

**方法论原则**：**数据 + 访谈双验证** — 单一来源都不够。

### 2.3 调研输出

**《客群画像报告》** — 包含 8 大客群描述、来源结构、消费习惯、价格敏感度、需求洞察、决策路径

### 2.4 工具清单

| # | 工具 | 用途 |
|---|------|------|

## 维度 3：竞对分析（外资 STR/HVS 核心 + 安逸维度 7）

### 3.1 竞对挑选原则（外资 STR 标准 + 安逸落地）

> **按分级分类对标 — 有星级按星级，无星级按房量；5 家左右（STR 标准）**

| 类型 | 挑选标准 | 数量 |
|------|---------|------|
| **有星级酒店** | 同星级（五星找五星）、同城优先、同档位品牌兼顾 | 3-5 家 |
| **无星级酒店** | 按房量分级：≥200房 / 100-199房 / <100房 | 3-5 家 |
| **混合市场** | 1-2 家"略高" + 1-2 家"略低"，了解差异化机会 | 4-5 家 |

**关键洞察**（外资 MMCG 实战）：
- **不要选"完全相同"的竞对** — 也要选 1-2 家"略高 / 略低"的，了解差异化机会
- **不要选"不同城市"的竞对** — 同城优先，跨城市只做参考
- **每家竞对必须有 3 个月以上的实时数据** — 不能只看年报
- **不要遗漏"影子供给"** — STR 短租 / BTR/SFR / 会员俱乐部 / 公共营地

### 3.2 STR 三大指数（外资核心方法论）

| 指数 | 公式 | 含义 | 诊断策略 |
|------|------|------|---------|
| **MPI**（市场渗透率指数）| 主体出租率 / 竞对群出租率 × 100 | 市场份额 | =100 公平份额，>100 抢份额 |
| **ARI**（平均房价指数）| 主体 ADR / 竞对群 ADR × 100 | 价格定位 | =100 公平定价，>100 溢价 |
| **RGI**（每房收益指数）| 主体 RevPAR / 竞对群 RevPAR × 100 | 综合竞争力 | =100 公平份额，>100 强 |

**诊断策略矩阵**（外资 MMCG）：
- **高 MPI + 低 ARI** = 低价抢市场（underpricing）
- **低 MPI + 高 ARI** = 高价丢市场（overpricing）
- **高 MPI + 高 ARI** = 强势（强差异化）
- **低 MPI + 低 ARI** = 弱势（需重定位）

### 4.3 需求预测方法（外资 HVS 标准化）

**HVS 标准需求预测模型**：

```
市场总需求（房间夜）= Σ(各客群细分需求 × 季节系数)
   = 商务散客需求 + 商务协议需求 + 会议需求 + 度假需求 + ...

各客群需求 = 客群基数 × 人均房间夜 × 平均停留天数 × 渗透率

渗透率 = 该客群入住本类型酒店的比例（历史数据）
```

**需求侧量化**：基于历史数据 + 增长率 + 经济指标，预测市场总房间夜需求量。

**供给侧量化**：现有酒店 + 在建酒店 + 筹建酒店 = 未来 3 年总供给。

**缺口分析**：需求增长 vs 供给增长 = 市场缺口（机会 or 过剩）

## 维度 5：财务可行性与投资测算（外资 HVS/Mews 核心 + 国资 22 项指标）

### 5.1 投资估算（外资 HVS CAPEX 模型）

**总投资 = 建设投资 + 流动资金**

```
建设投资：
  ├─ 土地获取成本（如有）
  ├─ 前期工程费（规划设计 / 勘察 / 报批报建）
  ├─ 建筑安装工程费（土建 / 装饰装修 / 设备安装）
  ├─ 设备购置费（客房 / 餐饮 / 康乐 / 办公）
  ├─ 基础设施配套费
  ├─ 工程建设其他费用
  ├─ 基本预备费（5-10%）
  ├─ 涨价预备费（2-5%）
  └─ 建设期利息（如有融资）

流动资金：
  └─ 铺底流动资金（流动资金的 30%）
```

### 5.2 资金筹措方案（国资合规）

**资本结构**：自有资金 / 银行贷款 / 其他融资（股权 / 债券 / REITs）的构成及比例

| 来源 | 比例 | 利率 | 期限 |
|------|------|------|------|
| 自有资金 | 30-40% | — | — |
| 银行贷款 | 50-60% | 4-6% | 5-10 年 |
| 其他融资 | 0-20% | — | — |

**资金使用计划**：分年度 / 分阶段的资金投入计划（建设期 1.5-3 年）

### 5.3 收入预测（外资 3 大参数）

```
客房收入 = 客房数 × 365 × OCC × ADR
餐饮收入 = 餐厅面积 × 翻台率 × 人均消费 × 365
会议收入 = 会议室面积 × 场租 + 配套服务
其他收入 = 婚宴 + SPA + 健身 + 停车场 + 新零售

总收入 = 客房 + 餐饮 + 会议 + 其他
```

**3 大参数（外资 STR 标准）**：

| 参数 | 含义 | 调研方法 |
|------|------|---------|
| **ADR**（平均房价）| 已售房间均价 | 基于客群价格敏感度 + 竞对价格 |
| **OCC**（出租率）| 已售房间 / 可售房间 | 基于市场需求 + 季节性 + 竞对表现 |
| **RevPAR** | ADR × OCC | 综合推算 |

**非房收入占比**：餐饮 20-40% + 会议 5-15% + 其他 5-10%

### 5.4 成本预测（外资 HVS OPEX 模型）

```
总成本费用 = 营业成本 + 营业费用 + 管理费用 + 财务费用 + 税金

营业成本（直接成本）：
  ├─ 客房成本（人工 + 易耗品 + 洗涤 + 折旧）
  ├─ 餐饮成本（食材 + 酒水 + 厨房）
  └─ 其他成本

营业费用（间接成本）：
  ├─ 人工成本（15-22%，最大可变成
  ├─ 能耗（5-8%）
  ├─ 维修保养（2-4%）
  ├─ 营销推广（3-6%）
  ├─ 管理费（3-6%）
  └─ OTA 佣金（3-8%）
```

# 第六部分 · 总结

## 一、核心结论

1. **市场调研 = 7 大维度**（物业/客群/竞对/容量/财务/风险/SWOT）— 完整、可复制、可进化
2. **6 大方法论原则** — 实时数据 + 双验证 + 分价格段 + 趋势 + 机会洞察 + 集团标准化
3. **5 大要素 + 2 大补充**（物业/客群/竞对/容量/收益 + 风险/SWOT + PEST/在地文化）= **7 大维度**
4. **22 项财务指标** — 国资标准 + 外资 HVS/DSCR/IRR/NPV 体系
5. **STR 三大指数**（MPI/ARI/RGI）— 外资核心方法论

7. **3 套应用变体** — 精品 / 精选 / 4 星全服务
8. **25-50 天调研周期** — 4 大阶段 25 步骤
