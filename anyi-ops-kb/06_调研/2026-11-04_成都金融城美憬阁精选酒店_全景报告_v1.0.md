## 2. 产品全景

### 2.1 母题：「误入荔枝林」

- **一层**：**四川本地百年荔枝树**栽种于酒店一层（雅高官方原文）
- **七层**：**「憬园」** —— 可欣赏川西园林自然景观；荔香餐厅即位于七层
- 室内基调：**青绿山水为底，点缀荔枝红、雪山白**
- 在地体验：**M Moment · 蜀绣珠饰扇 DIY**（可住客参与的文化体验）
- 品牌理念：**「每家酒店，一段故事」** + 「画廊灵感」打造的入住体验

**★ 判断**：这套叙事是**可复制的**。它不是"装修得好看"，而是「一个在地物象（荔枝）贯穿建筑、景观、餐饮、体验」的完整闭环 —— 与你锦著体系正在做的「在地文化标准包」是同一类命题，**但它比锦著多做了一步：把在地物象同时变成了餐饮命名（荔香/荔辰）与体验产品（蜀绣）**。

### ★ 4.1 三个判断

**① 4.9 分 / 255 条 / 开业仅 3 个月 —— 这是异常高的起点**
2026-08-24 启幕 → 11 月初即积累 255 条携程点评。**点评产出速度约 25 条/天**，对一家 155 间房的新店而言，说明：
- 雅高会员体系与渠道势能极强
- **评分资产新鲜度极高，但也意味着** —— 首批住客多为尝鲜与活动客，**评分的"存量厚度"还没有建立**。用你我在天阅那条项目的判断逻辑：**3 个月内的高分是流量红利，不是复利资产。**

**② ★★ Booking 侧是零资产 —— 这是全场最值钱的一块空地**
所有 OTA 竞对在 Booking 都有历史点评沉淀（天阅 317 条、锦著 41/8 条、大魔方 5,332 条），而这家**一条都没有**。**新店 + Booking 空白 = 评分可在半年内建立主导权**。
**★ 若这是你委托业务的候选标的，Booking 侧的「先占位」价值是这张牌里最实在的一张** —— 同样的钱，先占 Booking 比先占携程便宜得多（Booking 无点评累积优势，且当前无沉没资产要护）。

**③ ★ 三站评分不同步，说明两站还没打通**
携程 4.9 / 255 条 与 Booking 0 条 —— **如果 OTA 是同一后台管理，这个差距说明 Booking 侧的运营动作根本没做**，或者 Booking listing 是后开的、尚未做评论引导。
**★ 可验证的动作**：Booking 上给客人提供「写点评」入口的位置通常在房卡/离房卡/邮件 —— 查一下门店这三处是否放了 Booking 入口。**这是今天就能落地、且成本几乎为零的一步。**

## 6. ★ 市场端：一个必须写进报告的风险

**2026 上半年成都甲级写字楼市场（戴德梁行）**

| 指标 | 读数 |
|---|---|
| 新增供应 | 近 **20 万㎡**，**全部位于金融城商务区** |
| 全市甲级总存量 | 升至 **354 万㎡** |
| 平均租金 | 同比 **-10.62%**，至 **80.04 元/㎡/月** |
| **空置率** | 升至 **35.67%**（+5.4pct）；另一口径 **36.7%** |
| 净吸纳量 | 3.7 万㎡，同比 +37%，但环比 **-11%** |

**★ 判断（这条比酒店本身更重要）**：
1. **这家酒店的目标客群（金融城商务客、企业差旅、政务会奖）所依附的写字楼底座正在扩张 + 租金下跌 + 空置率 36.7%。** 短期利好 —— 新增 20 万㎡甲级意味着**新增办公人群 = 新增商务住宿与会议需求**；但中期隐忧 —— **租金跌 10.62%、空置率飙到 36.7%，意味着企业正在缩减与迁移办公面积**，而这恰恰是**"区位型商务酒店"最依赖的客源基础**。
2. **★ 对它自身：美憬阁选在需求扩张的时点进场，是对的**（写字楼新增 → 差旅与会议需求增量），但**它的护城河不能建立在"金融城 CBD"这四个字上** —— 因为同片区的铂悦高空 5,332 条、大魔方系已把"金融城"这个心智占满了。
3. **★ 它真正的护城河是「金融城 + 荔枝林 + 亲子 + 套房面积」** —— 一个**目的地型**（staycation/亲子/微度假）而非**区位型**（纯商务过夜）产品。**点评里高频出现的"staycation""不赶高铁""专程入住一次"，正是这个定位的证据。**

### 7.2 ★ 三条可直接落地的建议

**① 签约结构建议：不做固定基数，做「基础费 + 增量分成 + OTA 资产专项」**
- 新店无 RevPAR 基数 → 固定比例管理费基数缺乏对价基础
- **建议：基础管理费取低（覆盖派驻成本为限），主体收入挂在「相对经营基线的增量分成」**
- 基线取「开业后前 6 个月实际值」，而非行业均值

**② ★★ 第一件事不是管运营，是「把 OTA 资产补齐」**
- Booking 侧 **0 条点评、0 评分、地址/距离字段错误（行政区、地铁、机场距离三处）** → **这是零成本、且能立刻转化的动作**
- **且这是只有委托管理方能做的事** —— 业主品牌方（雅高）通常不做中国区单店的 OTA 精细运营
- **→ 这正好是「饭店管理公司的委托业务」在该项目上最清晰的切入口：先用 OTA 资产补齐建立信任，再谈运营接管。**

**③ ★ 定价锚点建议：用「同址竞对」的点评量做反向标定**
- 同在 1777 号 4 栋的锦都嘉玺只有 7 条 → 物业更差、点评更少
- 大魔方系 5,332 / 1,454 条 → 走量路线
- **美憬阁若两年内把点评做到 1,000+ 条，即在同址完成对铂悦高空的"数量级超越"（255 → 1,000 vs 5,332 差距收窄）**
- **→ 可设为一个可量化的委托 KPI：24 个月内 TripAdvisor/携程点评数 ≥ 1,000 条、Bing 好评 ≥ 4.8** —— 这比"营收提升 X%"更难被稀释、也更可验证

### 7.3 ★ 一条必须提醒的风险

**★ 雅高已与华住交叉持股 10%，且华住成雅高 5 品牌在华/台/蒙独家加盟商（Ibis 宜必思等），5 年新增 350–400 家。**
**→ 意味着：与雅高体系合作的窗口，可能是"品牌方缺中国区精细化运营能力"的窗口 —— 但一旦华住的体系进场补上这一环，这个缺口就消失。**
**→ 你方若以委托管理切入该类项目，卖点必须是「华住体系补不了的那部分」：本地化在地叙事 + 存量单体改造 + 国资/属地资源的运营能力。** 这三样恰好是你在安逸体系里正在建的东西。
