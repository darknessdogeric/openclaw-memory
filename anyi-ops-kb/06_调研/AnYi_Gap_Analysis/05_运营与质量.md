# 运营与质量 — AnYi 有什么 / 没什么

## ✅ AnYi 有什么（部分公开 + 行业典型）

### E1. 国宾馆服务标准
- 金牛宾馆、锦江宾馆均为**国宾级服务标准**
- 是 AnYi 的核心差异化
- 樊星（锦江）+ 涂晓宇（金牛）两位副总直接管

### E2. 国资酒店整合管理
- 整合了原省直机关 + 省属国企的酒店资源
- 输出**统一的服务 SOP**
- 公开宣示"打造集团化作战能力"

### E3. 行业评级地位
- **中国饭店集团 60 强第 7**（全服务酒店）
- **中国文旅企业 500 强**
- **成都市服务业企业百强**

- 可研报告里有 2015-2019 数据：
  - 2015: 营收 1,862 万 / ADR 425.61 元 / OCC 58.57% / RevPAR 249.28
  - 2016: ADR 396.98 / OCC 45.23% / RevPAR 179.55
  - 2017: ADR 329.35 / OCC 66.90% / RevPAR 220.34
  - 2018: ADR 336.19 / OCC 71.98% / RevPAR 241.99
