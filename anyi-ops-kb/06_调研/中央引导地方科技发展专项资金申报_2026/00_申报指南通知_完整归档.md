## 三、申报资格要求

### 3.1 申报单位要求

| 类型 | 要求 |
|------|------|
| **牵头单位** | ① 独立法人资格；② 注册地四川省境内；③ 科技型企业或事业单位；④ 良好场景开放基础和产业化条件 |
| **企业资质（满足任一）** | ① 2025 年度营业收入 **≥ 2000 万元**；② 2022-2025 有 **2 轮及以上股权融资 ≥ 1 亿元** |
| **事业单位资质** | 资金筹措能力 + 应用场景培育/开放能力 |
| **合作单位** | 境内外注册的科研院所/高校/科技型企业 |
| **诚信要求** | 无省级科技计划项目限制申报记录 |
| **联合申报** | 需签订**加盖法人公章的协议**作为附件 |

### 3.2 项目负责人要求

| 要求 | 内容 |
|------|------|
| **出生时间** | 1969/8/31 以后出生（中科院/工程院院士除外）|
| **职称/学历** | **副高级及以上**或**博士学位** |
| **限项规则** | 2026 年度同一申报人新申报项目 ≤ 2 个 |
| **承担现状** | 目前承担中央引导地方专项的项目负责人**不得牵头申报** |
| **离岗/兼职** | 高校/科研院所科技人员离岗/兼职创新创业可作为负责人（人事关系所在单位统一报送名单）|

### 3.3 经费要求

| 项 | 要求 |
|----|------|
| **申请财政经费** | ≤ **300 万元**/项目 |
| **自筹:财政** | **≥ 3:1** |
| **自筹证明材料** | 二季度财务季报/银行对账单/存款证明/银行授信证明（任一） |

## 四、申报流程（6 步）

| 步骤 | 内容 | 系统操作 |
|------|------|---------|
| 1 | **身份获取** | 牵头单位管理员 + 项目负责人登录系统注册/实名认证 |
| 2 | **项目指南查看** | "文档下载"—"指南查看" |
| 3 | **申报书填报** | 在线填报 + 上传附件 + 盖章页扫描上传 |
| 4 | **申报书修改** | 截止时间前可自主撤回修改 |
| 5 | **牵头单位审核** | 牵头单位在线审核提交 |
| 6 | **推荐单位审核/汇总/报送** | 推荐函 + 项目汇总表（在线打印）报科技厅 |

⚠️ **不受理牵头单位直接报送** — 必须经推荐单位
