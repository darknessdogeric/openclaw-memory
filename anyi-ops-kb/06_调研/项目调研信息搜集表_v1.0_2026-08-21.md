## 一、设计原则

### 1.1 信息搜集表的定位

```
完整调研流程(3 阶段):
  ┌─────────────────────────────────────────────────────────────┐
  │ 第一阶段: 信息搜集 ← 本表(28 项,0.5-1 天)                │
  │  - 快速扫描项目基础运营状况                                │
  │  - 识别明显异常/机会点                                      │
  │  - 决定是否进入深度调研                                    │
  └─────────────────────────────────────────────────────────────┘
                              ↓ (判断有价值则进入)
  ┌─────────────────────────────────────────────────────────────┐
  │ 第二阶段: 深度调研 (v2.0 规范 200 项,3-5 天)              │
  │  - 5 大方向 × 5 大层级 = 200 项全维度                       │
  │  - 现场访谈 + 数据验证                                      │
  └─────────────────────────────────────────────────────────────┘
                              ↓
  ┌─────────────────────────────────────────────────────────────┐
  │ 第三阶段: 报告输出 (v2.0 详表 200 项,1-2 天)               │
  │  - 调研档案 20-30 页                                         │
  │  - Gap 分析 + 战略建议                                       │
  └─────────────────────────────────────────────────────────────┘
```

| **G** | 渠道结构 2 项 | 2 项 | OTA 占比 + 自营体系占比 |
| **合计** | | **28 项** | |

## 二、28 项指标数据字典 ⭐⭐⭐⭐⭐

### A. 收益核心 3 大指标

| 指标名称 | 计算公式 | 单位 | 数据来源 | 备注 |
|---------|---------|------|---------|------|
| **开房率(OCC)** | 已售客房数 / 可售客房数 | % | PMS | 行业基准:商务 65-75%/度假 50-65%/中端 75-85% |
| **均价(ADR)** | 客房收入 / 已售客房数 | 元 | PMS | 行业基准:经济型 150-300/中端 300-500/中高端 500-900/高端 900+ |
| **每房收益(RevPAR)** | 客房收入 / 可售客房数 (= ADR × OCC) | 元 | PMS | 行业基准:经济型 100-200/中端 200-350/中高端 350-600/高端 600+ |

### B. 收入结构 5 项

| 指标名称 | 计算公式 | 单位 | 数据来源 | 备注 |
|---------|---------|------|---------|------|
| **当期营业收入(对比预算)** | 当期实际营收 vs 预算 | 元 | 财务报表(月/季/年) | 注明**达成率 %** vs 预算 |
| **全年营业收入** | 当年累计营收(预测年化) | 元 | 财务报表 | — |
| **历史最高营业收入** | 历史最高年度营收 | 元 | 历史档案 | 用于评估**潜力空间** |
| **餐饮收入** | 餐饮部门营收 | 元 | POS + 财务报表 | 含早餐/正餐/宴会/酒吧等 |
| **客房收入** | 客房部门营收 | 元 | PMS | — |
| **非房收入** | 营收 - 客房 - 餐饮 | 元 | 财务报表 | 含会议/婚宴/水疗/零售等 |

### C. 财务核心 2 项

| 指标名称 | 计算公式 | 单位 | 数据来源 | 备注 |
|---------|---------|------|---------|------|
| **GOP**(毛利润) | 营收 - 经营成本(不含折旧/利息/税) | 元 | 财务报表 | 行业基准:GOP率 25-40% |
| **现金流** | 经营现金流净额 | 元 | 财务报表 | 经营性现金流入 - 流出 |

### D. 成本结构 3 项

| 指标名称 | 计算公式 | 单位 | 数据来源 | 备注 |
|---------|---------|------|---------|------|
| **人工占比** | 人工成本(工资+社保+福利) / 总营收 | % | 财务报表 | 行业基准:经济型 18-25%/中端 22-28%/高端 28-35% |
| **能耗占比** | 能耗成本(水/电/燃气) / 总营收 | % | 财务报表 + 能耗台账 | 行业基准:6-12%(高端酒店偏高) |
| **租金占比(如有)** | 租金成本 / 总营收 | % | 租赁合同 + 财务报表 | 仅租赁物业填写,自有物业填 0 或 N/A |

### E. 物理资产 7 项

| 指标名称 | 内容 | 单位 | 数据来源 | 备注 |
|---------|------|------|---------|------|
| **客房数量** | 可售客房数 | 间 | 档案 | — |
| **餐位数** | 全酒店总餐位数 | 位 | 档案 | 含早餐厅/中餐厅/宴会厅/包间 |
| **功能区域** | 主要功能区分布 | 项 | 档案 | 列出明细:客房/餐饮/会议/健身/泳池/水疗/婚宴/其他 |
| **营业面积** | 总建筑面积 | m² | 档案 | 包含所有区域 |
| **客房面积** | 客房总面积 | m² | 档案 | 不含走廊 |
| **餐饮面积** | 餐饮总面积 | m² | 档案 | 含厨房+餐厅 |
| **公共区域面积** | 大堂/走廊/会议室/健身房等 | m² | 档案 | = 营业面积 - 客房 - 餐饮 - 后勤 |

### F. 运营效率 5 项

| 指标名称 | 计算公式 | 单位 | 数据来源 | 备注 |
|---------|---------|------|---------|------|
| **人员情况** | 全职 + 兼职员工数 | 人 | HR | — |
| **人房比** | 员工数 / 客房数 | — | HR + PMS | 行业基准:经济型 0.3-0.5/中端 0.5-0.8/高端 1.0-1.5 |
| **人效** | 总营收 / 员工数 | 万元/人 | 财务 + HR | 行业基准:经济型 30-50/中端 50-100/高端 100-200 |
| **能效** | 总能耗 / 总面积 | kWh/m² | 能耗台账 + 档案 | 行业基准:100-300 kWh/m²(高端偏高) |
| **坪效** | 总营收 / 总面积 | 万元/m² | 财务 + 档案 | 行业基准:0.5-3.0 万元/m²(地段差异大) |

### G. 渠道结构 2 项

| 指标名称 | 计算公式 | 单位 | 数据来源 | 备注 |
|---------|---------|------|---------|------|
| **散客市场OTA占比** | OTA 渠道收入 / 散客收入 | % | PMS + 渠道报表 | 行业基准:30-60% (头部集团压到 20-30%) |
| **散客自营体系(会员+新媒体)收入占比** | (会员 + 新媒体)收入 / 散客收入 | % | 自营渠道报表 | 行业基准:10-30%(头部集团 40%+) |
