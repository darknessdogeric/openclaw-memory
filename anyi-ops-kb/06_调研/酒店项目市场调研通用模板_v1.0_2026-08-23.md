## 〇、模板使用说明

### 0.1 本模板是什么

这是一份**可直接套用的酒店项目市场调研通用模板**，融合：
- **外资方法论**：HVS（5 大模块）/ STR（竞争群 MPI/ARI/RGI 三大指数）/ Mews（5 步法）/ CBRE / NCHMA Model Content Standards 2025
- **国内方法论**：PEST / SWOT / 22 项财务指标体系 / 国家可研报告规范
- **行业基准**：头部酒管（锦江/华住/亚朵/万豪/希尔顿）实践

**模板由 5 大部分构成**：

| 部分 | 内容 | 解决问题 |
|------|------|---------|
| **第一部分** | 调研内容清单（7 大维度）| **调研什么** |
| **第二部分** | 调研方法与渠道（信源矩阵）| **怎么调研** |
| **第三部分** | 结论形成方法（5 大模板）| **结论怎么得出** |
| **第四部分** | 报告结构模板（50 页）| **交付物格式** |
| **第五部分** | 实施 SOP（25 步骤）| **怎么推进** |

### 0.2 何时使用

| 触发场景 | 调研深度 | 周期 |
|---------|---------|------|
| 新建酒店立项前 | 深度调研 | 40-60 天 |
| 存量改造评估 | 深度调研 | 30-50 天 |
| 委托管理 / 品牌输出评估 | 标准调研 | 20-30 天 |
| 加盟评估 | 轻量调研 | 10-20 天 |
| 收购尽调 | 深度调研 | 40-60 天 |

### 0.3 使用 4 步法

```
第 1 步：明确项目类型与调研深度
```

## 维度 3：竞对分析

### 3.1 竞对挑选原则

> **按 STR 标准：5 家左右，按星级或房量分级**

| 类型 | 挑选标准 | 数量 |
|------|---------|------|
| **有星级酒店** | 同星级、同城优先、同档位品牌兼顾 | 3-5 家 |
| **无星级酒店** | 按房量分级：≥200房 / 100-199房 / <100房 | 3-5 家 |
| **混合市场** | 1-2 家"略高" + 1-2 家"略低" | 4-5 家 |

### 3.2 STR 三大指数（外资核心方法论）

| 指数 | 公式 | 含义 | 诊断策略 |
|------|------|------|---------|
| **MPI** | 主体出租率 / 竞对群出租率 × 100 | 市场份额 | =100 公平份额，>100 抢份额 |
| **ARI** | 主体 ADR / 竞对群 ADR × 100 | 价格定位 | =100 公平定价，>100 溢价 |
| **RGI** | 主体 RevPAR / 竞对群 RevPAR × 100 | 综合竞争力 | =100 公平份额，>100 强 |

**诊断矩阵**：
- 高 MPI + 低 ARI = 低价抢市场
- 低 MPI + 高 ARI = 高价丢市场
- 高 MPI + 高 ARI = 强势
- 低 MPI + 低 ARI = 弱势（需重定位）

### 3.3 竞对分析维度（每家 ≥10 个数据点）

| 维度 | 调研内容 |
|------|---------|
| 基础信息 | 星级、房量、开业时间、所属集团、品牌 |
| 客群结构 | 商务/度假/会议比例 |
| 价格策略 | ADR、季节性价格、会员价 |
| 经营表现 | 出租率、ADR、RevPAR（最近 3 个月）|
| OTA 表现 | 携程/美团评分、订单量、评论数 |
| 新媒体 | 抖音/小红书粉丝数、内容更新频率 |
| 特色产品 | 主题房、餐饮特色、IP 联名 |
| 优劣势 | 他们的强项、弱点 |
| 机会点 | 我们差异化空间 |

### 3.4 关键输出

《竞对分析报告》— 5 家竞对的 STR 对比表 + 三大指数诊断矩阵 + 差异化机会清单

## 维度 4：市场容量与需求预测

### 4.1 调研清单

| 维度 | 关键问题 |
|------|---------|
| **市场规模** | 城市/区域酒店市场规模（客房数/营收）|
| **增长趋势** | 最近 3 年增长率、驱动因素 |
| **供给端** | 在建/筹建酒店、未来 3 年供给增长 |
| **需求端** | 客源结构 + 商旅/休闲/入境 占比 |
| **政策事件** | 大型活动、政策变化、节庆赛事 |

### 4.2 PEST 宏观环境

| PEST | 调研内容 |
|------|---------|
| **P 政治** | 国家/省/市文旅政策、土地政策、税收政策、招商政策、入境免签 |
| **E 经济** | GDP / 人均可支配收入 / 产业结构 / 旅游收入 / 外资投资 |
| **S 社会** | 人口结构 / 消费习惯 / 文化偏好 / 旅游趋势 |
| **T 技术** | 智慧酒店 / AI 应用 / OTA 平台 / 数字化趋势 |

### 4.3 HVS 需求预测模型

```
市场总需求（房间夜）= Σ(各客群细分需求 × 季节系数)

各客群需求 = 客群基数 × 人均房间夜 × 平均停留天数 × 渗透率

需求增长 vs 供给增长 = 市场缺口（机会 or 过剩）
```

### 4.4 关键输出

《市场容量与机会报告》— 市场规模、增长趋势、供给预测、PEST 分析、需求缺口

## 维度 5：财务可行性与投资测算

### 5.1 投资估算

```
总投资 = 建设投资 + 流动资金

建设投资：
  ├─ 土地获取成本（如有）
  ├─ 前期工程费（规划设计 / 勘察 / 报批报建）
  ├─ 建筑安装工程费（土建 / 装饰装修 / 设备安装）
  ├─ 设备购置费（客房 / 餐饮 / 康乐 / 办公）
  ├─ 基础设施配套费
  ├─ 工程建设其他费用
  ├─ 基本预备费（5-10%）
  ├─ 涨价预备费（2-5%）
  └─ 建设期利息（如有融资）

流动资金：
  └─ 铺底流动资金（流动资金的 30%）
```

### 5.2 资金筹措方案

| 来源 | 比例 | 利率 | 期限 |
|------|------|------|------|
| 自有资金 | ___% | — | — |
| 银行贷款 | ___% | ___% | ___年 |
| 其他融资（股权/债券/REITs）| ___% | ___% | ___年 |

### 5.3 收入预测（3 大参数）

```
客房收入 = 客房数 × 365 × OCC × ADR
餐饮收入 = 餐厅面积 × 翻台率 × 人均消费 × 365
会议收入 = 会议室面积 × 场租 + 配套服务
其他收入 = 婚宴 + SPA + 健身 + 停车场 + 新零售

总收入 = 客房 + 餐饮 + 会议 + 其他
```

| 参数 | 含义 | 调研方法 |
|------|------|---------|
| **ADR** | 平均每日房价 | 基于客群价格敏感度 + 竞对价格 |
| **OCC** | 出租率 | 基于市场需求 + 季节性 + 竞对表现 |
| **RevPAR** | ADR × OCC | 综合推算 |

### 5.4 成本预测

```
总成本费用 = 营业成本 + 营业费用 + 管理费用 + 财务费用 + 税金

营业成本（直接成本）：
  ├─ 客房成本（人工 + 易耗品 + 洗涤 + 折旧）
  ├─ 餐饮成本（食材 + 酒水 + 厨房）
  └─ 其他成本

营业费用（间接成本）：
  ├─ 人工成本（15-22%）
  ├─ 能耗（5-8%）
  ├─ 维修保养（2-4%）
  ├─ 营销推广（3-6%）
  ├─ 管理费（3-6%）
  └─ OTA 佣金（3-8%）
```

### 5.6 财务评价标准

| 指标 | 阈值 | 说明 |
|------|------|------|

- 所有数据必须标注：来源 / 采集时间 / 数据口径 / 责任人

1. **实时数据原则**：价格/出租率 ≤ 3 个月，行业趋势 ≤ 12 个月
2. **双验证原则**：每个关键判断 ≥ 2 个独立来源
3. **分价格段原则**：ADR 分 5-7 个价格段，客群分层
4. **趋势重于绝对值原则**：看 3 年趋势，不只看当下
5. **机会洞察原则**：发现未被满足的细分需求
6. **标准化原则**：数据格式符合集团/行业接口

## 7 大避坑指南（贯穿全程）

1. 不要"凭感觉"判断客群 → 用 PMS 历史 + 访谈 + 调研三角验证
2. 不要选错竞对 → 按 STR 标准选 5 家同档位
3. 不要用陈旧数据 → 至少采集最近 3 个月实时数据
4. 不要只看平均值 → 分价格段分析
5. 不要"调研一次就完" → 每季度更新关键数据
6. 不要"少样本推总体" → 至少 12 个月数据 + 季节性
7. 不要"忽略财务口径" → 算 GOP/EBITDA/NOI 全口径

# 第七部分 · 模板应用指引

## 一、不同项目类型的应用差异

| 项目类型 | 调研深度 | 周期 | 重点维度 | 特殊要求 |
|---------|---------|------|---------|---------|
| **新建酒店** | 深度 | 40-60 天 | 维度 2/3/4 重点 | PEST + 选址分析更深入 |
| **存量改造** | 深度 | 30-50 天 | 维度 1/3/5 重点 | 现有客群保留 + 增量 |
| **委托管理** | 标准 | 20-30 天 | 维度 5/6 重点 | 业主方尽调 |
| **品牌输出** | 标准 | 20-30 天 | 维度 3/5 重点 | 加盟商评估 |
| **加盟评估** | 轻量 | 10-20 天 | 维度 5/6 重点 | 投资回报测算 |
| **收购尽调** | 深度 | 40-60 天 | 全部 7 大维度 | 法律 + 财务尽调并重 |

## 二、模板裁剪建议

| 项目预算 | 模板裁剪 |
|---------|---------|

| 30-80 万 | 标准 7 大维度 |
| 80-150 万 | 深度 7 大维度 + 在地文化挖掘 |
| >150 万 | 全维度 + 第三方报告采购 + 长期跟踪 |
