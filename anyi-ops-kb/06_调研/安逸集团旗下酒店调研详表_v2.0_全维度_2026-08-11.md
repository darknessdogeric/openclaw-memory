## 一、设计原则

### 1.1 全维度版与 v1.0 的关系

```
v1.0 (109 项)              ← 仅经营方向(运营 + 营销)
运营细化 v1.0 (94 项)        ← 仅经营方向的细化
                          ⇩
v2.0 (200 项) ⭐ 全维度版    ← 经营 + 工程安保 + 物业产权 + 数字化 + 人资 + 坪效人效

v2.0 设计逻辑:
  - 横向: 5 大方向(经营/工程安保/物业产权/数字化/人资)
  - 纵向: 5 大层级(基本信息 → 运营现状 → 管理体系 → 绩效结果 → 战略前瞻)
  - 调研深度: 2-3 小时勾选用 70 项核心(标记 ★), 其余 130 项按需深挖
```

### 1.2 5 大方向 + 1 补充

| 方向 | 涵盖维度 | 项数 | 服务场景 |
|------|---------|------|---------|
| **A. 经营方向** | 客房/餐饮/前厅/收入成本/营销(OTA/会员/新媒体/异业/预算/销售/客源) | ~75 项 | 调研运营总监/营销总监/财务 |
| **B. 工程安保方向** ⭐ | 设备设施/工程管理/安全合规/应急预案 | ~30 项 | 调研工程总监/安全部 |
| **C. 物业权属及产权方向** ⭐ | 物业权属/产权证照/资产价值 | ~20 项 | 调研集团资产部/总经办 |
| **D. 数字化系统和体系方向** ⭐ | 信息化系统/智能化与 AI/数字化体系 | ~25 项 | 调研 IT 总监/数字化部 |
| **E. 人资方向** ⭐ | 组织架构/人员配置/培训绩效/薪酬福利/人才梯队 | ~35 项 | 调研人力资源部 |
| **F. 坪效人效** ⭐ 补充 | 单位面积产出/单位人力产出 | ~10 项 | 调研运营 + 人资交叉 |
| **合计** | | **~200 项** | |

### 1.3 标注约定

- **★** = 部门人员 2-3 小时现场必调研项
- *斜体* = 按需深挖项 (Eric 反馈后调整必选/可选)
- 标值参考 = 来自 KPI v1.1 (中酒致胜之道 + 财务对标)
