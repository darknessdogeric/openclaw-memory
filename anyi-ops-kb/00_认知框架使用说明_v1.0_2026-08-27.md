## 一、决策树（5 步）

```
Q1: Eric 是在问"我是谁/怎么做/为什么"？
   ├─ 是 → 查 SOUL.md（性格/价值观/方法论）
   └─ 否 ↓

Q2: Eric 是在给"具体任务/具体问题/具体人"？
   ├─ 是 → 查 MEMORY.md（主公认知 + Eric 个人偏好）
   └─ 否 ↓

Q3: Eric 是在说"具体业务事实/数据/项目/合作"？
   ├─ 是 → 查 anyi-ops-kb（业务知识库）
   └─ 否 ↓

Q4: Eric 推送了新文件/新材料？
   ├─ 是 → 归档到 anyi-ops-kb 对应目录 + 更新 00_总览
   └─ 否 ↓

Q5: Eric 给出了新的范式/规则/指令？
   ├─ 是 → 写入 SOUL.md（如属认知方法论）或 MEMORY.md（如属 Eric 直接相关）
   └─ 否 → 当前任务已闭环，整理沉淀
```

## 二、10 个具体场景的调用路径

### 场景 1：Eric 问"你怎么思考这件事？"

**调用 SOUL.md**。
- 例： "你怎么理解共在式自我实现？"
- 例： "遇到冲突时你用什么决策框架？"
- 关键章节： 底层人格特质（审美/博弈论/群论）+ V2.4 哲学加固

### 场景 2：Eric 推送了新的 PDF / .docx

**调用 anyi-ops-kb**。
- 步骤 1： 读取文件
- 步骤 2： 用 R66 校验（时序/一致/源头/可调用性）
- 步骤 3： 复制/摘要到 anyi-ops-kb 对应目录
- 步骤 4： 更新 `00_安逸集团知识库总览.md`（v2.x）
- 步骤 5： 如有红绿灯/保密项变更 → 更新 SOUL V2.4 范式规则

### 场景 3：Eric 问"安逸的数据/项目/战略"

**调用 anyi-ops-kb**。
- 入口： `anyi-ops-kb/00_安逸集团知识库总览.md` v2.x
- 子目录按主题：
  - `02_项目/<项目名>/`
  - `07_战略与改革/`
  - `06_调研/`
- 红绿灯： 对外材料必须先剥离安逸/旅投具体信息

### 场景 4：Eric 给范式指令（如"纳入知识库"、"基础认知"、"分层架构"）

**调用 SOUL.md**（范式规则层）。
- 步骤 1： 评估该指令是否属"认知方法论"
  - 是 → 写入 SOUL V2.4 范式规则
  - 否（如属 Eric 个人偏好/特定业务）→ 写入 MEMORY.md

### 场景 5：Eric 推送了"指导性结论"（如"那条主线"）

**调用 MEMORY.md + anyi-ops-kb**。
- 步骤 1： 在 MEMORY.md 加入"主公当前关注的主线"
- 步骤 2： 在 anyi-ops-kb 中标记该主线对应的核心文件
- 步骤 3： 未来接 Eric 提问时，优先查阅这条主线

### 场景 6：Eric 让我"提炼/总结/归纳"

**调用 anyi-ops-kb**。
- 步骤 1： 列出相关主题下所有已归档文件
- 步骤 2： 按 R66 校验（数据准确/源头可溯）
- 步骤 3： 写摘要到对应项目目录
- 步骤 4： 更新总览文件

### 场景 7：Eric 问"和 XX 公司的合作/合同"

**调用 anyi-ops-kb + MEMORY.md**。
- anyi-ops-kb： 找具体合作方的协议、会议纪要
- MEMORY.md： 查 Eric 在该合作上的指令历史（如"不主动提及""红线）

### 场景 8：Eric 让我"做调整/重写/优化"

**调用 anyi-ops-kb**。
- 步骤 1： 读取现有文件
- 步骤 2： 按 Eric 新指令调整
- 步骤 3： 新版本归到原位置（带版本号 v2.0 / v3.0 ...）
- 步骤 4： 旧版本可保留（Eric 说"已被vX取代"的可删除）
- 步骤 5： 更新总览的"已沉淀文件清单"

### 场景 9：Eric 让我做"对外材料"（发言稿/PPT/信息图）

**调用 anyi-ops-kb + 红绿灯清单**。
- 步骤 1： 查 anyi-ops-kb 中的核心数据
- 步骤 2： 应用红绿灯（剥离安逸/旅投具体信息）
- 步骤 3： 用 R66 自检
- 步骤 4： 输出 Word/PPT/PNG 到桌面（按 Eric 习惯）
- 步骤 5： 如可能，加水印（按 R12 规则）

### 场景 10：Eric 提出"哲学/美学/认知"问题

**调用 SOUL.md**。
- 例： "为什么审美是 AI 难以企及的？"
- 例： "你对博弈论怎么理解？"
- 关键章节： 哲学加固（V2.4）/ 审美哲学 / 博弈论 / 群论 / 强者心态
