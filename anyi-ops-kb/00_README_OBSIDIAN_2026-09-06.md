## 一、Obsidian 使用说明（v1.0）

### 1.1 什么是 Obsidian 化

Obsidian 是一款基于 Markdown 的本地知识管理工具，核心特性：
- **双向链接**：`[[文件名]]` 自动建立知识图谱
- **MOC**（Map of Content）：地图页（索引页）
- **frontmatter**：文件元数据（YAML）
- **tags**：标签分类
- **本地化**：所有文件在本地，无需联网

本知识库采用 Obsidian 范式组织，但不强制要求 Eric 用 Obsidian 软件打开——所有 `.md` 文件都可以在任何编辑器中阅读，Obsidian 链接语法（`[[ ]]`）不会破坏其他工具的渲染。

### 1.3 必含 frontmatter（v1.0 标准）

每个文件头部必须包含：

```yaml
---
title: [文件名]
version: [v 编号]
date: [YYYY-MM-DD]
author: B166ER
related: [关联文件路径列表（双向链接用）]
tags: [主题标签]
trust_tier: [战略级/战术级/参考级]
---
```

### 1.4 双向链接规范

| 类型 | 语法 | 示例 |
|------|------|------|
| 同目录引用 | `[[文件名]]` | `[[01_酒店月报范式_v1.0_2026-09-06.md]]` |
| 跨目录引用 | `[[路径/文件名\|别名]]` | `[[../../00_MOC_OBSIDIAN_2026-09-06.md\|顶层 MOC]]` |
| 章节锚点 | `[[文件#章节]]` | `[[信源体系_v2.0#领域-1-酒店行业-国际第三方研究]]` |
| 反向链接 | 自动生成 | 通过 Obsidian 自动建立 |

### 1.5 Tags 分类体系

```yaml
# 一级 Tag
- 信源: 标识信源身份（STR / Skift / 迈点 / 奥维）
- 报告: 标识报告类型（月报 / 季报 / 半年报 / 周报 / 日报）
- 领域: 标识业务领域（酒店国际 / 酒店国内 / AI战略 / 国企改革 / 跨境）
- 项目: 标识项目归属（新启航酒旅 / 花园宾馆 / 6大改造 / 国堰宾馆）
- 时点: 标识时点绑定（日 / 周 / 月 / 季 / 半年）
- 优先级: 标识优先级（P0 / P1 / P2）
- 合规: 标识红绿灯（黄灯 / 绿灯 / 红灯）
- 范式: 标识版本与类型（v1 / v2 / 范式 / 模板）
- 类型: 标识文件类型（README / MOC / 分析 / 报告 / 模板 / SOP）
```

## 三、工作流程（Eric 视角）

### 3.1 日常使用

```
1. Eric 进入知识库 → 阅读 00_MOC_OBSIDIAN_2026-09-06.md（顶层索引）
2. 按 MOC 找到所需主题的入口
3. 进入主题二级 MOC（如花园宾馆 MOC）
4. 阅读具体文件
5. 通过 [[ ]] 双向链接跳到关联文件
6. 通过 tags 过滤同类文件（如 #月报 #6大改造）
```

### 3.2 anyi 写入流程

```
1. 收到 Eric 输入 → 5 秒内判断归类（信源/报告/项目/范式/政策）
2. 写入对应目录 → 添加 frontmatter + tags + 双向链接
3. 更新相关 MOC（如新增项目需更新顶层 MOC）
4. 报告归档路径
```

### 3.3 报告生成流程

```
1. Eric 触发（如"出本月月报"）
2. anyi 启动月度 SOP（参考信源 v2.0 第四章）
3. 按信源 → 报告绑定采集数据
4. 套用月报/季报/半年报范式
5. 输出报告 → 归档到 07_战略与改革/报告/[YYYY-MM]/
6. 更新 MOC 报告目录
```
