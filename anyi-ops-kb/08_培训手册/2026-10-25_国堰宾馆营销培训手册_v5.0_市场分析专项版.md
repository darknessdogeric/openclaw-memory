## 模块 1：深度营销的本质

### 1.1 从"推销"到"吸引"

酒店营销已经历三个阶段：

| 阶段 | 特征 | 酒店心态 |
|------|------|---------|
| **1.0 渠道时代** | 依靠旅行社、会议公司、协议单位 | "客户会来" |
| **2.0 OTA 时代** | 携程美团成为流量入口，酒店被动等待平台分配 | "花钱买排名" |
| **3.0 内容时代** | 抖音小红书种草，口碑驱动决策，评价成为信任锚点 | "让客户主动找来" |

国堰目前处于 **2.0 向 3.0 过渡阶段**：携程 1228 条点评是 2.0 资产，但内容平台布局几乎为零（无独立小红书账号，抖音未见活跃账号）。

**核心认知升级**：在内容时代，酒店卖的不再是"房间"，而是"值得分享的体验"。一个客人愿意发朋友圈的汤池体验，价值远超一张 200 元的优惠券。

### 1.2 国堰营销的两个主战场

| 战场 | 定位 | 核心指标 | 当前状态 |
|------|------|---------|---------|
| **OTA（携程/美团/Trip.com/Booking.com）** | 交易转化主阵地 | 排名、点评数、转化率 | 携程 4.6/1228，Trip.com NO.15，Booking.com 刚上线 |
| **内容平台（小红书/抖音/视频号）** | 口碑种草主阵地 | 笔记/视频数、爆款率、粉丝量 | 几乎为零，无独立账号 |

两个战场的逻辑不同：**OTA 负责成交，内容平台负责制造需求**。没有内容平台的持续种草，OTA 流量就是无根之水。

## 模块 17【新增】：国堰宾馆营业日报表深度解读

### 17.1 日报表的核心逻辑（基于锦宾样本）

锦宾国际营业日报表是安逸集团旗下酒店的标准日报表格式，国堰应参照以下字段结构填写：

**第一部分：收入总览**
```
营业收入合计 = 客房收入 + 餐饮收入 + 会议及场地收入 + 其他收入
```

| 字段 | 国堰应关注 | 正常值 | 预警信号 |
|------|-----------|--------|---------|
| 客房收入占比 | 客房/总收入 | 50-70% | <40%（副楼占比过高）|
| 餐饮收入占比 | 餐饮/总收入 | 20-35% | >40%（客房弱）|
| 其他收入 | 停车/汤池/商品 | 5-10% | <3%（汤池未充分变现）|

**第二部分：客房统计分析（核心三指标）**

| 指标 | 正确计算公式 | 国堰当前值（参考）| 预警线 |
|------|------------|---------------|-------|
| **出租率** | 出租间夜 ÷ 可供出租间夜（不含维修/自用/免费房）| **37.05%** (1-8月) | <50% 红 / <40% 红 |
| **平均房价（ADR）** | 房租收入 ÷ 出租间夜（不含免费房/Dayuse）| ¥261（周报）| <¥240 红 / <¥200 红 |
| **RevPAR** | ADR × 出租率 | ¥146.61（周报）| <¥130 黄 / <¥100 红 |

**⚠️ 国堰特殊注意事项**：
- 主楼（109 间）和副楼（69 间）应分开统计 ADR，否则副楼低价（¥269）长期拉低全店 ADR
- 副楼定位为"引流产品"，但引流客人复购率低，建议设置副楼月度上限（不超过总间夜的 40%）

### 17.2 价格倒挂的五大类型（基于比武大会四向核查诊断报告）

**类型一：会员价 ≥ OTA 价**
- 判断：会员价比携程/美团还高 → 会员无忠诚度
- 国堰风险点：会员权益不足，金卡仅 8 折，与 OTA 促销价接近
- **红线**：会员价必须 < OTA 价 5%+

**类型二：协议价 ≥ 散客价**
- 判断：协议公司价格比前台现付还高 → 协议客户流失
- 国堰风险点：政务协议客户价格体系不清
- **红线**：协议价 < 前台挂牌价 10-15%

**类型三：散客价 ≥ 节假日临时价**
- 判断：前台 Walk-in 价格低于 OTA 闪购价
- 国堰风险点：节假日调价滞后（OTA 节假日涨价但前台不涨）
- **红线**：节假日期间前台价与 OTA 同步调整

**类型四：官网灵活价 ≥ OTA 价**
- 判断：官网直销价高于 OTA 价
- 国堰当前：无官网直销体系（待建立）
- **建议**：官网价格 = OTA 最低价（保护直销渠道）

**类型五：套餐打包价 < 单项相加价**
- 判断：含早+含温泉的套餐价格 < 单独购买之和
- **这是合理设计**，但要注意不要出现套餐价比单房更低的情况

### 17.3 国堰日报表应设置的预警线

| 预警指标 | 计算公式 | 计算频率 | 黄线（行动）| 红线（立即处理）|
|---------|---------|---------|-----------|-------------|

**第一类：价格倒挂**

- 处置：立即核查所有在售房型价格层级（门市 > OTA > 会员 > 协议）

**第二类：数据口径不一致**
- 典型表现：出租率分母用"客房总数"而非"可供出租间夜"；免费房计入出租
- 国堰风险点：锦宾样本已揭示该问题，国堰可能同样存在
- 处置：统一规范——Dayuse 和免费房不计入出租间夜

**第三类：会员体系名存实亡**
- 典型表现：会员数量多但复购率极低；金卡完成率远低于目标
- 国堰数据：会员 68% 完成 / 金卡仅 49% 完成
- 根因：会员权益不足以驱动复购意愿
- 处置：重新设计会员分层权益，重点激活金卡

**第四类：餐饮毛利率严重偏低**
- 国堰数据：餐饮毛利率约 5%（行业正常值 30-50%）
- 根因：后厨成本高 + 上座率不足 + 定价偏低
- 处置：专题分析餐饮各品类（散客/会议/宴会）的毛利率

**第五类：目标设定脱离实际**
- 典型表现："收入增长 20%"的目标 vs 实际 -1.98%（国堰 1-8 月）
- 处置：目标设定必须基于市场容量和竞争群数据，不能拍脑袋

## 模块 22【重点新增】：入境客源开发（Inbound）

### 22.1 市场判断：入境游进入"政策 + 需求"双轮驱动

**政策端**：国家持续扩大单方面免签、过境免签范围。成都口岸已实施 **240 小时过境免签**；2026 年全国入境游订单保持两位数增长，**俄罗斯入境增速居首（约 +173%），英国、加拿大、马来西亚均超 +50%**（2026 国庆数据）。

**需求端**：境外游客正从"打卡式观光"转向"沉浸式文化体验"，对**温泉、非遗、在地生活方式**需求快速增长；同时，**中式慢旅、传统美学**成为欧美及东南亚高端客群的新偏好。

**国堰的机会窗口**：都江堰是**世界文化遗产 + 世界灌溉工程遗产 + 世界自然遗产（青城山-都江堰）**所在地，"三遗之城"是全球级目的地；而都江堰**具备入境接待标准的中高端酒店供给不足**，高端温泉酒店更是稀缺。

> **判断**：入境客源不是"锦上添花"，而是国堰未来 3 年**毛利率最高的增量赛道**。

### 22.2 国堰的 Inbound 资产盘点

| 资产 | 竞品有无 | Inbound 价值 |
|------|---------|-------------|
| 11 个汤池（含中药特色） | 大型竞品有温泉，规模不及 | 中式温泉康养是入境核心卖点 |
| 都江堰城区最高建筑（观景） | 竞品无 | "City + Snow Mountain" 视野 |
| 铜板浮雕 + 石根雕馆藏 | 竞品无 | 文化叙事素材 |
| 党政接待基因 + 党校分校 | 竞品无 | 安全与规范背书 |
| 锦绣天府号专列（80% 外籍客历史数据） | 竞品无 | **独家 Inbound 通道** |
| 都江堰南桥店位置（景区腹地） | 部分竞品有 | 步行可达景区 |

**当前短板（必须补齐）**：
1. Booking.com **仅 8 条点评** —— 国际信任度不足；
2. **无 TripAdvisor 页面** —— 全球最大点评平台缺位；
3. **无英文套餐产品** —— 只有裸房价，无打包；
4. **无双语全流程服务 SOP** —— 接机、点餐、温泉引导缺标准。

## 模块 24【重点新增】：RFP 采购应答（MICE / 政企）

### 24.1 什么是 RFP

**RFP（Request for Proposal，需求建议书）**是客户（政府、国企、企业、会展主办方）为会议、住宿、宴会等采购需求，向多家酒店发出**招标 / 询价文件**，酒店据此提交**报价 + 方案**参与竞争。

> **对国堰的意义**：RFP 是**批量、稳定、低佣金**的客源入口 —— 一次中标，往往带来年度或系列订单，且**不经过 OTA 佣金**。

### 24.2 国堰可承接的 5 类 RFP

| 类型 | 典型客户 | 国堰优势 | 客单价量级 |
|------|---------|---------|-----------|
| **① 政府会议定点** | 党政机关、事业单位 | **党政定点单位 + 党校分校（独家）** | 中高 |
| **② 国企差旅协议** | 省属 / 市属国企 | 旅投体系内协同 | 中 |
| **③ 大型会展** | 糖酒会 / 西博会 / 车展 | 都江堰区位 + 会议设施 | 高 |
| **④ 企业年会 / 团建** | 民企 / 外企 | 温泉 + 观光组合 | 中高 |
| **⑤ 培训 / 研学** | 党校 / 高校 / 机构 | 教学 + 住宿 + 温泉 | 中 |

### 24.3 采购信息渠道（抓单入口）

| 渠道 | 说明 |
|------|------|
| **中国政府采购网 / 四川政府采购网** | 政府会议、培训定点采购公告 |
| **国企采购平台**（如各省属集团采购平台） | 国企差旅、会议招标 |
| **招标信息平台**（千里马 / 中国招标投标公共服务平台） | 综合招标信息 |
| **携程商旅 / 同程商旅平台** | 商旅酒店库招募 |
| **会小二 / 会唐网** | 会议场地询价（MICE） |
| **旅投体系内协同** | 集团内会议、活动优先对接 |
| **主动 BD** | 当地政府办 / 机关事务局 / 大型企业行政部 |

> **动作**：设专人**每日监测**采购公告关键词："都江堰 会议""温泉 会议""培训 住宿"。

### 24.4 投标资质清单（提前备齐）

| 资质 | 状态 |
|------|------|
| 营业执照 | 已有 |
| 特种行业许可证（旅馆业） | 已有 |
| 消防安全检查合格证 | 已有 |
| 食品经营许可证 | 已有 |
| 卫生许可证 | 已有 |
| 星级 / 钻级评定 | 已有 |
| **党政机关会议定点饭店资质** | 已有（**核心壁垒**） |
| 近三年业绩证明 | 需整理 |
| 财务审计报告 | 需财务配合 |

### 24.5 投标文件标准结构

1. **商务部分**：公司简介 / 资质证照 / 业绩案例 / 团队
2. **技术部分**：场地介绍（会议室面积 / 客房数 / 餐厅容量）/ 服务方案 / 应急保障
3. **报价部分**：房型阶梯价 / 餐标 / 会议场租 / 打包价
4. **增值部分**：温泉体验 / 观光安排 / 双语服务（差异化）

> **差异化打法**：把"**温泉 + 水文化 + 党政接待基因**"作为技术部分的加分项 —— 竞品难以复制。

### 24.6 报价策略

| 策略 | 适用 | 要点 |
|------|------|------|
| **阶梯报价** | 大批量会议 | 按间夜数分档（≥50 / ≥100 / ≥200 间夜）递减 |
| **淡季包场** | 冬季（11-3 月） | 用温泉优势低价包场，填补淡季 |
| **打包价** | 会议 + 温泉 | 会议+温泉+餐饮打包，提升总价 |
| **保底 + 浮动** | 长期协议 | 设最低消费，超出部分优惠 |

**红线**：报价**不得低于成本线**，且**不得破坏门市价体系**（避免价格倒挂）。

### 24.7 述标话术（3 分钟版）

> "各位评委好。国堰宾馆是**都江堰党政机关会议定点饭店**，也是**城区最高建筑**，拥有 **11 个温泉汤池**。我们不仅能提供标准会议服务，还能为您安排**温泉康养 + 都江堰水文化体验**，让会议兼具效率与人文。我们的报价采用**阶梯优惠**，大批量采购性价比更高。欢迎实地考察。"

### 24.8 中标履约与复购

- **履约**：设专属客户经理，会前对接 / 会中驻场 / 会后回访；
- **复购**：会后 30 天回访，推动"年度协议"；
- **转介**：满意客户转介绍同系统单位。

## 模块 25【重点新增】：TMC 商务差旅合作

### 25.1 什么是 TMC

**TMC（Travel Management Company，差旅管理公司）**为企业客户统一管理差旅预订，代表企业与酒店谈**协议价**，并把酒店纳入其**商旅酒店库**。酒店进入 TMC 库后，可稳定获得**商务散客 + 差旅订单**。

### 25.2 国内主流 TMC 清单

| TMC | 背景 | 国堰对接价值 |
|-----|------|-------------|
| **携程商旅** | 携程旗下 | 大客户差旅主入口 |
| **同程商旅** | 同程旗下 | 区域企业差旅 |
| **腾邦国际** | 老牌商旅 | 企业协议 |
| **中航服（CAS）** | 航空系统 | 央企差旅 |
| **国旅运通（CITS American Express）** | 合资 | 外企差旅 |
| **BCD Travel / CWT / Amex GBT** | 国际 | 外企 / 跨国公司 |

### 25.3 国堰 TMC 合作路径

第一步：报名成为 TMC 供应商（提交资质 + 房型 + 报价）
第二步：提供协议价（商务客专属，通常为门市价 5-7 折区间）
第三步：签约（年度协议 / 季节协议）
第四步：上架 TMC 平台（企业客户可搜到）
第五步：持续履约 + 季度价格复核

### 25.4 协议价设计

| 房型 | 门市价 | 建议协议价 | 说明 |

| 主楼双床房 | ¥398 | ¥328 | 双人出差 |
| 套房 | ¥688 | ¥558 | 高管 |

**原则**：协议价 **低于门市价**、**低于 OTA 均价**；含早；可提供**延迟退房至 14:00**。

### 25.5 商旅服务标准（区别于旅游客）

## 强化模块 22：入境客源（Inbound）深耕版

> 基于 v3.0 模块 22，强化 4 个新维度

### 22.A 144 小时过境免签政策激活 (2026 国家级红利)

**政策**:
- 2026 年 1 月 1 日起, **54 国**持普通护照人员来华可免签过境 144 小时
- **成都**是 144 小时过境口岸之一 (天府机场)
- 入境口岸: 北京/上海/广州/成都/重庆 等 20+ 口岸

**对国堰的机遇** (量化):
- 54 国免签客流 → 成都入境 → 都江堰一日游/过夜游
- 估算: 成都年入境游客 200 万+, 30% 过境 → 60 万+ 潜在客户
- 假设 5% 在都江堰过夜 → **3 万+/年新增 Inbound 客源**

**激活路径** (3 个月启动):

| 时点 | 动作 | 责任 |

### 23.A 携程酒店排名 7 大因子 (2026 最新算法)

**算法本质**: 携程 = 转化率 × 质量分 × 竞争力 × 距离 × 库存 × 价格 × 服务

| 因子 | 权重 | 国堰当前 | 提升动作 | 目标 |
|------|------|---------|---------|------|
| **1. 转化率** (CVR) | 30% | 4.5% (估算) | 优化详情页 + 套餐设计 | 6%+ |
| **2. 质量分** (评分 × 点评数 × 评语深度) | 20% | 4.6 × 1228 | 1000+ 优质点评 + 5.0 分评论 | 4.7 × 2000 |
| **3. 竞争力** (同商圈比价) | 15% | 中游 (¥269-700) | 优化副楼套餐, 主楼价格拉满 | 上游 |
| **4. 距离** (中心区距离) | 10% | 都江堰景区核心 (5A) | 突出"5A 景区"标签 | + |
| **5. 库存** (房态/可订性) | 10% | 待核 | 全库存开放, 24h 自动同步 | 100% |
| **6. 价格** (BAR/平均) | 10% | ¥261 vs 同商圈 -10% | 主副楼分价, 副楼动态 | 稳中提 |
| **7. 服务** (点评/订单确认速度) | 5% | 24h 确认 (达标) | 保持 + 旺季 4h | 保持 |

**核心公式**:
```
携程排序 = 转化率 (30%) × 质量分 (20%) × 竞争力 (15%) × 距离 (10%) × 库存 (10%) × 价格 (10%) × 服务 (5%)

## 模块 35【新增】：都江堰市场深度分析

### 35.1 三个必须先纠正的市场认知

在讲国堰怎么做之前，先把"都江堰市场到底有多大、增长有多快、竞争有多密"三件事讲准。培训现场最常见的错误，是拿"全国县域酒店预订量第 20 位"这类宏观排名去对标国堰的经营动作，结果方向全错。

**纠正一：都江堰不是"旅游大市"，是"住宿供给极度分散的县域市场"。**

按都江堰市文广体旅局口径，2026 年上半年全市住宿业营业额 **10.5 亿元**（R1），年化约 21 亿元。这个数字在全国县域里不算小，但**它是由 700 余家民宿、农家乐、大量小体量酒店共同分食的**。

反推全域客房数（R3，公式与参数见 35.2）：约 **1.3 万 — 1.7 万间**，中值取 1.5 万间。

**纠正二：都江堰的入境客增长极快，但增长的是"人次"不是"间夜"，更不是国堰的订单。**

**纠正三：国堰在全域里的位置，比"区域分不到流量"这个判断更复杂，也更值得讲。** 详见 35.5。

### 35.2 全域住宿供给测算（R3 推断，公式公开）

**测算路径**：

```
2026H1 全市住宿业营业额        10.5 亿元（R1，文广体旅局）
÷ (1 - 非房收入占比 30%)        → 客房收入约 7.35 亿元
÷ 全域平均房价 ADR 280 元（R3）  → H1 可售间夜约 262 万间夜
÷ 182 天（2026H1）              → 全域可售房约 14,400 间
```

**敏感性区间**（非房占比 25%—35%、ADR 250—320 元）：

| 非房占比 | ADR 250 | ADR 280 | ADR 320 |
|---|---|---|---|
| 25% | 17,308 间 | 15,453 间 | 13,522 间 |
| 30% | 16,154 间 | **14,423 间** | 12,620 间 |
| 35% | 15,000 间 | 13,393 间 | 11,719 间 |

**结论区间：全域可售房约 1.2 万 — 1.7 万间，中值 1.5 万间。**

**培训口径说明**：此为估算值，用于建立"供给密度"直觉，**不可对外引用为统计数字**。如需精确值，应向都江堰市文旅部门调取《国民经济和社会发展统计公报》或住宿业台账。

**这个数字意味着什么**：国堰 235 间客房，占全域房量仅 **1.5%—1.7%**。**在供给端，国堰根本不是"抢不到流量"的问题——它连区域大盘的零头都不到，但它拿到的营收份额却远高于此。** 详见 35.5。

### 35.3 客流结构分析（R1 公开统计数据）

#### 35.3.1 总量与假日峰值

**2026 年春节假期**（都江堰市文旅局）：

| 景区/场景 | 接待游客 | 备注 |
|---|---|---|
| **全市 A 级景区合计** | **101.66 万人次** | 8 天假期 |
| 青城山—都江堰景区 | 62 万人次 | 核心 IP，占 61% |
| 灌县古城 | 32.2 万人次 | 免费开放城区 |
| 熊猫谷 | 12.52 万人次 | |
| 中华大熊猫苑 | 6.06 万人次 | |
| 青城后山 | 4.86 万人次 | |
| 成都热雪奇迹（冰雪） | 2.15 万人次 | 新兴场景 |

**读数要点**：
1. **核心景区只占 61%，全域旅游已不是"一个景区打天下"**。灌县古城 32.2 万 + 熊猫谷 12.5 万 + 大熊猫苑 6.1 万，合计已超 50 万。
2. **"成都热雪奇迹"等新场景在春节档期就能贡献 2.15 万人次**——都江堰已具备冬季产品的客流基础，国堰的"淡季没客"不能只怪天气。
3. **景区与市区客流存在明显落差**——国堰在都江堰城区（观景路中段），距景区有一定距离，**这意味着国堰天然承接的是"过夜客"而非"当日客"**，这既是劣势（错过大量不过夜客流），也是优势（过夜客的房价承受力远高于当日客）。

#### 35.3.2 入境客：增速最猛、且与国堰完全脱节

### 35.5 国堰在都江堰全域中的真实位置（R2 反算，本次培训最关键的一段）

**这是 v5.0 相对 v4.0 最重要的修正。** v4.0 讲"国堰在区域里垫底、区域流量分不到"，这个判断方向对但不完整。补上供给和营收两端后，真相更清楚，也更扎人。

**反算第一步：拆国堰自己的收入结构**

| 项目 | 数值 | 计算 |
|---|---|---|
| 可售间夜（1-8 月） | 57,348 | 236 间 × 243 天 |
| 出租间夜（1-8 月） | 21,247 | 57,348 × 37.05% |
| 客房收入（推算） | **461.05 万** | 21,247 × ¥216.99 |
| 实际总营收 | 954.30 万 | R1 实际 |
| **非房收入（餐饮/会议/温泉等）** | **493.25 万** | 954.30 − 461.05 |
| **非房收入占比** | **51.7%** | 493.25 ÷ 954.30 |

**这个 51.7% 极其重要，它推翻了一个常见认知。**

v4.0 记录"商品销售 −38%、其他收入 −85%、二销几乎断流"，容易让人以为国堰是"客房为主、二销为辅、二销垮了"。**但实际结构恰恰相反：国堰的客房只贡献 48.3%，餐饮、会议、温泉等非房业务贡献了过半。**

**这意味着**：国堰**从来不是一个卖房间的酒店，而是一个卖"景区度假综合体验"的酒店**——客人来这里泡温泉、吃饭、开会、住宿打包消费。**这是它的商业模型本相，只是过去没人把这个模型讲明白。**

**反算第二步：算全域平均房价，与国堰对比**

| 项目 | 数值 |
|---|---|
| 全域年化住宿业营收 | 约 21.0 亿元（R1 × 2） |
| 其中客房收入（非房 30%） | 约 14.7 亿元 |
| 全域年可售间夜 | 1.5 万间 × 365 ≈ 547.5 万间夜 |
| **全域平均房价** | **约 268 元**（R3） |
| 国堰 1-8 月 ADR | **216.99 元**（R1） |
| **差距** | **国堰低于全域均价 19.1%** |

**反算第三步：算营收密度——本模块的核心结论**

| 维度 | 国堰 | 全域 | 比值 |
|---|---|---|---|
| 客房数 | 235 间 | 约 15,000 间 | **1.57%** |
| 占全域住宿业营收比（国堰年化 1,431 万 ÷ 21 亿） | — | — | **约 6.8%** |

> **国堰以全域 1.57% 的房量，贡献了约 6.8% 的住宿业营收——营收密度是房量占比的 4.3 倍。**
>
> **结论（一）：国堰不是"经营差"，是"产能利用差"。**
> 如果国堰的经营效率真如外界想象般糟糕，它拿不到 4.3 倍于自身权重的营收份额。**它是一家在都江堰属中上游的单体酒店，问题是 235 间房里有太多是空的。**

> **结论（二）：那 51.7% 的非房收入，正是解药，也是枷锁。**
> 餐饮会议温泉贡献过半，说明**都江堰的度假客确实愿意为"度假体验"付费**——市场验证成立。**国堰要做的不是把客房做成酒店，而是把 51.7% 的非房收入结构做成 70%、80%。** 这条路的天花板比"把 ADR 从 217 拉到 380"更现实，也更符合国堰的产品本相。

> **结论（三）：把 ADR 拉到全域均价就是及格线，不是目标。**
> 国堰 ADR 216.99 vs 全域 268，**补齐这一档 = 客房收入 +109.5 万/年**（21,247 间夜 × ¥51.5）。这是"不输"的底线，不是"赢"的水平。

### 35.6 淡旺季结构与价差规律（R1 公开报价 + R3 推断）

**都江堰区域 4-5 星 1-8 月 ADR ¥380-450，暑期 OCC 85%+**（v4.0 已有数据，R1 来自区域竞品实测）。

**国堰自身 1-8 月 ADR ¥216.99，对区域均价的 47%—57%**。这个价格倒挂是本次培训要反复讲的核心矛盾。

**但必须给学员一个更完整的参照系**——不能只跟都江堰比，还要看同为"世界遗产+温泉"的景区型市场的价差规律（详见模块 38）。这里先给结论：

| 市场 | 淡季价格 | 旺季价格 | 淡旺季倍数 |
|---|---|---|---|
| 稻城亚丁·香格里拉镇 | 100-200 元 | 400-800 元 | **2—4 倍** |
| 稻城亚丁·亚丁村 | 约 400 元 | 600-1200 元 | 1.5—3 倍 |
| 九寨沟·沟口民宿 | 80-160 元 | 100-300 元 | 1.3—1.9 倍 |
| 九寨沟·沟口高端度假酒店 | — | 800-1200 元 | — |
| **都江堰·国堰（1-8 月实际）** | **217 元** | 区域 380-450 元 | **1.75—2.07 倍** |

**培训要点**：**景区型酒店的淡旺季价差是结构性的，2—4 倍是常态。** 这意味着：

1. **国堰当前 1-8 月的 ¥217，不是一个"定价错误"，而更接近于"淡季价"**。问题不是旺季没拉上去，而是**淡季的价撑不住产品成本**。
2. **经营策略应当是"拉平而非拉高"**——把淡季价格从 217 提到 280-320（而非一步拉到 380-450），配合淡季产品（温泉+餐饮+会议+康养）做组合销售，比在旺季跟竞品拼价格更可持续。
3. **淡季才是培训要抓的主战场。** 旺季大家都满房，差别在价格；**淡季大家都在 20%-40% 出头，差别在谁能把客拉进来并卖出去。** 8 个月里真正决定全年的是这 8 个月。

## 模块 36【新增】：成都 + 都江堰 + 青城山 三地联动市场分析

### 36.1 为什么必须做三地联动

国堰是都江堰的酒店，但它的客人来源在成都、竞争视野在青城山。**只看都江堰市内的竞争，是拿错了坐标系。**

三地的关系不是并列的，是**有明确分工的一条链**：

```
成都（1,300 万人口消费腹地 + 航空/铁路枢纽 + 本地休闲客）
  │  高速约 70km / 车程 1.5 小时
  ▼
都江堰（世界遗产核心 + 城区生活配套 + 国堰所在 / 青城山前山 30km）
  │  车程约 45 分钟
  ▼
青城山（道教圣地 + 天然温泉 + 前山景区 + 怡然目的地）
```

**国堰的三个身份**：
1. **都江堰城区的度假型酒店**（对都江堰 700 家民宿 + 城区酒店的竞争）
2. **青城山前山的温泉竞品**（对青城豪生、青城山云栖合院、逸扉温泉的竞争）
3. **成都 1.5 小时圈的周末度假产品**（对成都周边短途目的地的竞争）

**培训开场第一问**：国堰到底在跟谁抢？**答案是三个都在抢，而且三个战场上的对手完全不同。** 很多经营动作失败，是因为拿 A 战场的打法去打 B 战场。

### 36.2 成都：客源腹地，不是竞争对手

**成都侧对国堰的意义是"客源"**。

**关键数据（R1 公开统计）**：
- 2026 年成都酒店行业**入境客人同比增长 58%**
- 中旅集团旗下成都瑞景酒店**境外客人占比已达 40%**，且以欧美散客为主，通过 Booking、Agoda、Trip.com 预订

**这两个数字连起来看，结论很直接**：

> **成都不缺入境客供给，且已经证明入境客能撑起一家酒店的 40% 房量。**
> **问题不在成都，在于入境客到都江堰这一段，断了。**

**国堰在成都方向的机会点**：

| 路径 | 现状 | 可行动作 |
|---|---|---|
| 成都—都江堰 2 天 1 晚周末产品 | 散客自发为主，无产品化 | 与成都 OTA/旅行社做固定班期周末套餐 |
| 成都周边游的"第三晚延伸" | 大量客人 2 日游后返程 | 做"都江堰加一晚"延长产品 |
| 成都本地康养/疗休养客群 | 安逸已具备疗休养资质 | 成都工会、企业疗休养市场定向拓客 |
| 入境客过境延伸 | 无 | 借锦绣天府号 80% 外籍客流（v4.0 记录）做"成都—都江堰"入境延伸 |

### 36.3 都江堰：过夜客的承接地

**都江堰对国堰的意义是"住宿承接"，但必须看清一个结构性事实**：

2026 春节 8 天假期，全市 A 级景区接待 101.66 万人次，**其中核心景区 62 万人次**（R1）。

**住宿转化逻辑**：
- 灌县古城 32.2 万人次——**免费开放城区，天然不过夜**
- 熊猫谷 12.52 万、大熊猫苑 6.06 万——**半日游为主，转化率极低**
- 青城后山 4.86 万——**当日往返**
- 成都热雪奇迹 2.15 万——**有住宿需求（冰雪+温泉是过夜强驱动）**
- 核心景区 62 万人次——**一日游为主**

> **都江堰的客流结构，对住宿业其实是"偏轻"的。** 百万级人次里，真正具备过夜意愿的是：过夜游团队、自驾亲子家庭、康养度假客、冰雪客。
>
> **这解释了为什么"都江堰旅游人次全国靠前"和"都江堰酒店难做"可以同时成立。** 培训中必须把这层逻辑讲透——**学员如果以为"游客多=酒店好做"，方向就会错。**

**国堰的应对方向**：把"过夜客"细分出来做产品，而不是等散客。
- **一日游客** → 转化为"半日游 + 汤池 + 简餐"短时消费（不占房，占汤池和餐饮）
- **过夜客** → 完整产品
- **冰雪/冬季客**（成都热雪奇迹 2.15 万人次已证明存在）→ 冬季温泉+雪+火锅产品

### 36.4 青城山：真正的对手和真正的资源

**青城山对国堰有双重身份**——既是竞品战场，也是客源走廊。

**竞品侧（R1 Trip.com 实测数据）**：

| 酒店 | 平台收藏数 | 评分 | 评价数 | 特色 |
|---|---|---|---|---|
| 都江堰青城豪生国际酒店 | **30,330** | 9.5/10 | 538 | 60 英亩生态温泉、室内儿童乐园、金黄银杏景观 |
| 青城山云栖合院酒店 | 14,961 | 9.1/10 | 300 | 免费泡温泉 |
| 青城山逸扉温润度假酒店 | — | — | — | **78 间客房**，Hyatt 旗下 URCOVE，步行至青城山 5 分钟 |

**这三个数字，国堰必须正视**：
1. **青城豪生 30,330 收藏、538 条评价**——是国堰 1,228 条点评的 2.7 倍
2. **逸扉只有 78 间房**（比国堰少 157 间），却是 Hyatt 旗下——**说明在青城山这个市场，房间少不代表赢**
3. **豪生主打"60 英亩生态温泉 + 室内儿童乐园"**——这正是家庭亲子和康养两大客群的核心钩子，与国堰的 11 个汤池**正面重叠**

**资源侧**：
- 青城山距都江堰城区约 30 公里，车程 45 分钟（R3）
- 国堰本身有天然/自有汤池资源，**这是青城山前山竞品的共同短板**——前山酒店多依赖"引汤入店"，资源掌控力弱

**培训落点**：
> **在青城山战场，国堰拼的不是房间数，是"资源掌控 + 城区配套"。**
> 逸扉 78 间房、豪生 60 英亩，都是重资产大投入；**国堰的杠杆是"城区成熟配套 + 11 个汤池 + 235 间成熟客房 + 176 间可灵活分层的双楼"**。
> **青城山前山竞品解决的是"住得远"，国堰解决的是"住得近、吃得好、泡得久"。** 这条差异化必须在培训中讲透，否则学员只会去比房间数和装修。

### 36.5 三地客源半径与产品梯度设计

**距离与时间（R3 公路里程常识估算）**：

| 路段 | 距离 | 车程 | 客群行为特征 | 适配产品 |
|---|---|---|---|---|
| 成都 → 都江堰 | 约 70km | 约 1.5h | 周末 2 晚、周末 1 晚 | 周末度假 2 晚产品、团队大巴 |
| 成都 → 青城山前山 | 约 90km | 约 1.5h | 一日游为主、过夜偏少 | 当日游+加一晚延伸 |
| 都江堰 → 青城山前山 | 约 30km | 约 45min | 同城跨区、一日游 | 联票/联营套餐 |
| 都江堰 → 峨眉山 | 约 130km | 约 2h | 周末 2 天 | 跨市联游（需与峨眉山酒店谈） |

**建议的产品梯度设计**：

### 38.3 三条跨市场规律（本次培训要提炼的核心）

#### 规律一：景区型酒店的淡旺季价差是结构性的，1.3—4 倍

| 市场 | 倍数 | 成因 |
|---|---|---|
| 九寨沟沟口民宿 | 1.3-1.9× | 门票制刚性、承载量封顶，客流波动被门票调节 |
| 都江堰 | 1.75-2.07× | 门票不强制、客流受天气和假期驱动 |
| 稻城亚丁 | 2-4× | 高原限流、免票放大波动、住宿供给少 |

> **结论一：国堰淡旺季价差 1.75-2.07 倍，处于同类市场的中位。**
> **所以"淡季 25%-30%、旺季 85%+"的剧烈波动，不是国堰特有，而是景区型酒店通病。**
> **但——通病不等于免责。** 九寨沟淡季民宿 80-160 元仍能维持经营，靠的是"低价+长住+淡季产品"；**国堰淡季价格 217 元不低，客人却没有——这就是真问题。**

#### 规律二：门票政策是景区酒店房价的最大放大器

**稻城亚丁的实证**（R1）：
- 2026 年 8 月 1 日至 10 月 31 日景区免收 146 元门票
- 免票期内住宿需求上涨 50%-100%
- **实测同一酒店从淡季 249 元涨至旺季 1,600 元**
- 有游客总结："**免掉的 146 元门票，大概率被上涨的 300 元房费找补回来**"
- 国庆极端节点：套房从 866 元涨至 3,023 元，**涨幅超 240%**

> **结论二：都江堰/青城山目前没有门票减免政策（2026 年全年 144 小时/240 小时过境免签是针对入境客的，不是门票政策）。**
> **这意味着都江堰的房价弹性，只能靠自己产品做出来——国堰没有"政策红利"可等。**
> **反向机会**：都江堰景区正在打造"一码游"、外宾服务中心、41 币种结算，**这是入境客的政策红利期，国堰是这条链上唯一没动的酒店。**

#### 规律三：高端度假酒店靠"不可替代的资源"而非"更大的房间"

| 案例 | 不可替代资源 | 结果 |
|---|---|---|
| 稻城亚丁 | **弥散式供氧 + 地暖**（抗高反） | 溢价 30%-50%，精品旺季超 2,000 元 |
| 稻城亚丁 | 亚丁村景观房（正对仙乃日雪山） | 1,500-2,000 元/晚 |
| 稻城亚丁 | **供氧优先级高于景观朝向** | 客人主动选择逻辑：安全 > 风景 |
| 峨眉山七里坪 | 距市中心 35km 的温泉资源 | 4 星 260 间，2009 年建仍在售 |
| 峨眉山悦榕庄 | 悦榕养修体系 + 双遗产地 | 2026 年新开，抢占高端度假 |

> **结论三：客人为"不可替代的安全与体验"付溢价，顺序是 安全 > 体验 > 风景。**
> **国堰的不可替代资源是什么？** 11 个汤池（含中药特色）、176 间双楼、观景楼、党政接待资质。**其中"含中药的 11 个汤池"是真正对标"供氧"的东西——都是"解决一个身体问题"。**
> **但目前国堰在卖 ¥178/次 的汤池，没有把它包装成"疗效"。** 稻城亚丁把供氧做成溢价理由，国堰把中药汤池做成溢价理由，是同一套逻辑。

### 38.4 都江堰 vs 峨眉山：同省同文化圈的直接比较

**这一组比较对国堰最刺痛，也最有指导意义。**

| 维度 | 都江堰 | 峨眉山 |
|---|---|---|
| 世界遗产 | 世界文化遗产（都江堰）+ 自然遗产（青城山） | 世界文化与自然双遗产 |
| 悦榕庄 | — | **2026 年新开业**（世界双遗产地麓） |
| 度假品牌入驻 | 温德姆豪生、希尔顿系、朵兰达 | 悦榕庄、峨眉山温泉山庄群 |
| 门票 | 不强制，城区免费 | 需购票 |
| 国堰对应酒店 | 国堰宾馆 | **峨眉山七里坪温泉酒店**（4 星 260 间，2009 年建，距市中心 35km） |

> **国堰 235 间 vs 七里坪 260 间——房量几乎相同。**
> **但七里坪 2009 年建、4 星标准、纯温泉度假定位，在峨眉山这个成熟度假市场活到今天。**
> **这个对照说明：景区酒店的生命力来自"与景区绑定的纯度"，而不是"在城里"或"离景区近"。**
>
> **国堰的隐忧：国堰是"都江堰城区的酒店"，不是"青城山的酒店"。** 客人来都江堰，订房时会搜"青城山温泉酒店"——**国堰在这条搜索路径上天然吃亏**，除非它主动把"青城山前山 30 分钟 + 城区配套"这个组合标签打出去。

### 38.5 景区型酒店的三个结构性风险（国堰需提前防范）

**风险一：门票政策变动**
稻城亚丁的免票期证明了——**门票政策可以在 3 个月内重塑整个市场的房价曲线**。都江堰若未来推出本地市民免票、淡季免票或全域免票，**国堰 217 元的淡季房价将首当其冲**。

**风险二：供给无序扩张**
九寨沟沟口、稻城亚丁香格里拉镇都出现过"淡季价 80-100 元的民宿冲击酒店"的阶段。**都江堰民宿已破 700 家，精品化后新增 180 余家**（R1）——**如果精品民宿继续放量，国堰 217 元的淡季价将面临直接挑战**。这也是《都江堰市民宿及农家乐建设提升导则》出台的背景。

**风险三：不可逆的季节性资产老化**
稻城亚丁的教训：淡季 100-200 元的住宿市场，**会逼着酒店在淡季做低价、低维护经营**；等旺季再想提价、提服务时，设施已老化。**国堰 2017 年装修、已 9 年，正是这个风险的具体形态。**

### 38.6 景区横向对标小结（一页纸）

```
