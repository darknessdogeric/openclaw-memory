## 第 1 部分 · 公域-私域新媒体运营的总体框架

### 1.1 什么是公域-私域新媒体运营

**公域** — 酒店无法直接掌控的外部互联网平台（如携程、美团、抖音、小红书等）。流量属于平台，酒店需要持续付费或运营获取。

**私域** — 酒店可以直接触达、不需付费、可重复利用的自有客户池（如小程序、企业微信、社群、会员体系）。

**新媒体运营** — 通过内容生产（图文/短视频/直播）+ 社交互动 + 数据驱动，实现"公域获客→私域沉淀→复购裂变"的完整闭环。

### 1.2 为什么酒店需要这套体系

1. **降低分销依赖** — 直销替代分销，减少 OTA 佣金（通常 10-15%）
2. **沉淀客户资产** — 客户从"过客"变为"会员"，可重复触达
3. **提升复购率** — 私域复购成本 < 公域获客成本 1/3
4. **增强抗风险** — 不依赖单一渠道，平台政策变化影响小
5. **全业态联动** — 客房/餐饮/宴会/SPA/文创互通，提升单客价值

### 1.3 安逸集团三平台架构（核心）

```
              ┌────────────────────────┐
              │   安逸会（会员中枢）    │
              │  5 档会员 + 跨店积分     │
              │  企微 SCRM + CRS       │
              └────────┬───────────────┘
                       │
        ┌──────────────┼──────────────┐
        ▼              ▼              ▼
  ┌──────────┐   ┌──────────┐   ┌──────────┐
  │ 客房业态 │   │ 餐饮业态 │   │ 文创业态 │
  │ 安逸商城 │   │ 安逸商城 │   │ 安逸集市 │
  └──────────┘   └──────────┘   └──────────┘
```

**三平台角色**：
- **安逸会** = 私域沉淀层（会员中枢 + 数据中台）
- **安逸商城** = 房+非房自营平台（客房/餐饮/SPA/会议室/伴手礼）
- **安逸集市** = 文创+周边平台（餐饮外卖/茶饮/文创 IP/伴手礼）

## 第 2 部分 · 公域引流：5 大新媒体渠道

### 2.1 小红书（种草 + 文旅）

**客群定位**：文旅人群、女性、年轻消费群体

**内容形态**：
- 酒店打卡笔记（房间/餐厅/公共空间/周边景色）
- 文旅攻略（本地必玩/必吃/必打卡）
- 主题活动（季节限定/节日活动/特色体验）

**引流动作**：
- 文末挂安逸会小程序链接
- 评论区回复引导私聊
- 关键词布局（城市+酒店类型+特色）

### 2.2 抖音本地生活 + POI

**客群定位**：本地客群、即时消费决策人群

**内容形态**：
- 短视频（房型介绍/特色展示/15 秒入住体验）
- 直播（限时套餐/秒杀/讲解）
- POI 页面（地址+团购券+评价）

**引流动作**：
- 短视频挂团购券（美团/抖音）
- 直播间挂安逸会入会引导
- POI 详情页引导"加入会员享专属价"

### 2.3 视频号（品牌 + 中老年）

**客群定位**：商务客、中老年消费群体、品牌信任型客户

**内容形态**：
- 品牌故事（酒店历史/服务理念/员工故事）
- 服务展示（前台接待/客房布置/餐饮出品）
- 客户证言（会员故事/复购体验）

**引流动作**：
- 视频号关联公众号（内容沉淀）
- 视频号直播（私域流量转化）
- 视频号小店（直接下单）

### 2.4 直播（实时 + 转化）

**客群定位**：价格敏感型、即时决策型

**内容形态**：
- 房型实景直播
- 餐饮制作直播（厨房/餐厅）
- 套餐秒杀直播
- 文创集市直播

**引流动作**：
- 直播间挂安逸会小程序
- 直播间下单直接绑定会员身份
- 直播预告通过社群/朋友圈预热

### 2.5 微信生态（公众号 + 社群 + 企业微信）

**客群定位**：私域会员、复购客户、忠诚客户

**内容形态**：
- 公众号（品牌内容/活动推送/会员福利）
- 社群（每日问候/优惠活动/UGC 互动）
- 企业微信（1v1 客户管理/标签化运营）

**引流动作**：
- 公众号菜单栏入会引导
- 社群新人礼包（首单优惠/专属服务）
- 企业微信 SOP 自动化（欢迎语/标签/分群）

## 第 3 部分 · 私域沉淀：安逸会的工具利用

### 3.1 5 档会员体系

| 档位 | 升级门槛 | 核心权益 |
|------|---------|---------|
| **银卡**（普通会员）| 免费注册 | 9 折订房 + 延退 1h + 生日券 |
| **金卡**（悦享会员）| 年消费 3,000 元 或 入住 10 房晚 | 8.5 折订房 + 升房 1 次 + 免费早餐 |
| **白金**（尊享会员）| 年消费 8,000 元 或 入住 25 房晚 | 8 折订房 + 升房 2 次 + 行政酒廊 + 免费 SPA |
| **钻石**（至臻会员）| 年消费 20,000 元 或 入住 50 房晚 | 7.5 折订房 + 升房 4 次 + 接送服务 + 私人定制 |
| **集团 VIP**（战略协议）| 年消费 50 万+ 或 央国企集团协议 | 协议价 + 全国通用 + 集团客户经理 1v1 |

### 3.2 跨店积分通兑机制

**核心规则**：
- **100 积分 = 1 元**（抵房费/商城/集市）
- **积分获取**：消费 1 元 = 1 积分
- **积分生命周期**：3 年（促活，避免沉睡）
- **跨店通用**：积分可在安逸集团任一酒店+商城+集市使用

**特殊场景积分**：
- 评价晒图：+50 积分/次
- 邀请好友：+500 积分/人
- 生日福利：+1000 积分

### 3.3 企微 SCRM 自动化触达

**三层触达 SOP**：

```
第一层（入住前）
  预订确认 → 入住提醒 → 行程关怀 → 升房邀请

第二层（入住中）
  入店问候 → 房间服务 → 餐饮推荐 → 活动推送 → 满意度调研

第三层（离店后）
  T+1: 感谢信 + 入住小记 + 商城体验券
  T+7: 积分到账提醒 + 商城新品推荐
  T+30: 沉睡用户激活（消费券 + 主题推荐）
  T+90: 深度沉睡用户召回（情感化关怀）
  T+180: 流失用户唤醒（明信片 + 节日礼）
```

### 3.4 数据画像与智能推荐

**统一会员 ID** = 关键基础设施
- 一个 ID 打通三平台（安逸会+商城+集市）行为数据
- 一个画像支撑全集团个性化
- 一个积分账户跨平台通用

**画像维度**：
- 基础属性（年龄/性别/职业/来源城市）
- 消费行为（消费频次/客单价/房型偏好）
- 兴趣偏好（餐饮/活动/景点/伴手礼）
- 生命周期（新手/活跃/沉睡/流失）

## 第 4 部分 · 全业态转化：安逸商城 + 安逸集市

### 4.1 客房业态（核心引流）

**商品形态**：
- 单房型销售（标间/大床/套房）
- 套餐组合（客房 + 早+延退 + 升房）
- 跨店通兑券（3 晚通兑/5 晚通兑）
- 主题套房（亲子/商务/婚宴/团建）

**转化路径**：
- 外部 OTA 导流 → 安逸会员价 → 跨店积分
- 新媒体种草 → 直播间下单 → 自动入会
- 协议客户 → 直连平台 → 协议价结算

### 4.2 餐饮业态（堂食 + 外卖 + 宴会）

**堂食**：
- 早午晚自助（住客 + 外部客）
- 单点餐厅（商务宴请/家庭聚餐）
- 下午茶/酒吧（轻奢场景）

**外卖**：
- 美团/饿了么（公域引流）
- 自有小程序（私域沉淀）
- 团购券（堂食 + 外带 + 住宿组合）

**宴会**：
- 婚宴（场景化套餐 + 安逸集市伴手礼）
- 会议宴会（会场 + 餐饮 + 住宿打包）
- 团建聚会（活动 + 餐饮 + 客房组合）

### 4.3 非房业态（SPA + 会议室 + 伴手礼）

**SPA**：
- 单次体验券（公域引流）
- 月卡/季卡（私域复购）
- 住宿 + SPA 套餐（跨业态组合）

**会议室**：
- 半日/全日会场
- 会议套餐（会场 + 茶歇 + 午餐 + 投影设备）
- 培训年会（多日住宿 + 会议 + 餐饮打包）

**伴手礼**：
- 客房用品组合（枕头/床品/洗漱用品）
- 当地特产（食品/茶饮/调味品）
- 文创小件（书签/明信片/香薰）

### 4.4 文创业态（安逸集市）

**核心定位**：川蜀生活方式集合

**三条产品线**：
1. **国堰水文化** — 都江堰主题茶礼、水文化绘本、青城山道茶
2. **三国文化** — 蜀锦书签、武侯主题茶饮、蜀汉主题香薰
3. **巴蜀旗舰** — 川味零食礼盒、蜀绣小件、川茶精选、非遗手作

**转化路径**：
- 酒店客房（场景化体验 → 扫码购买）
- 餐厅餐后（伴手礼套餐推荐）
- 宴会活动（定制伴手礼）
- 线上商城（7×24 小时下单）
- 异业合作（机场/景区/加油站）

## 第 5 部分 · 循环迭代：从公域到私域的可持续循环

### 5.1 内容生产可持续性

**核心原则**：**不要用主营产品引流**

**引流内容分类**：
- **攻略类** — 本地玩什么/怎么玩/季节限定
- **故事类** — 酒店历史/员工故事/会员故事
- **体验类** — 客房体验/餐饮体验/活动体验
- **种草类** — 文创开箱/伴手礼/特色产品

**生产节奏**：
- 小红书：每周 3-5 篇
- 抖音：每周 2-3 条短视频 + 1 次直播
- 视频号：每周 1-2 条
- 公众号：每周 1-2 篇

### 5.2 客户转化可持续性

**8 条引流逻辑**：

1. **客房分销** — 住店客人二次入住引导加入安逸会
2. **协议客户** — 销售人员和前台引导加入
3. **上门散客** — 前台工作人员直接引导
4. **餐饮消费** — 外卖/团购券直接加入安逸会
5. **外卖订单** — 折扣和活动诱导加入
6. **商城集市** — 下单直接加入（积分双向流通）
7. **新媒体矩阵** — 小红书/抖音/视频号/直播挂小程序
8. **厅面客人** — 点单系统直接加入

### 5.3 复购裂变可持续性

**复购触发器**：
- 积分到期前 30 天提醒
- 生日月专属礼包
- 升档前引导（差 N 房晚/差 M 元升级）
- 老客户专属活动（VIP 试吃会/会员答谢晚宴）

**裂变机制**：
- 邀请好友注册：双方各得 500 积分
- 老带新入住：老客户得 1000 积分，新客户得首单优惠
- 朋友圈分享：分享后截图得 50 积分
- UGC 征集：晒图/视频/评价得 100-500 积分

## 第 7 部分 · 5 种错误模式与 6 个步骤

### 7.1 5 种常见错误模式

数字化线上运营对于酒店经营的趋势和重要性不言而喻。现阶段，各单体酒店、各酒店集团都纷纷开始组建团队，摸索并转型。但是真正把问题弄明白的比较少，因为并没有将整个体系置于线上思维统一思考。基本有以下几种方式：

1. **花钱找代运营** — 其结果是自己的平台没有搭建起来，核心权益账号变成没有流量的死号。

2. **自有团队边学边干** — 只要搭建起来就可以了。由于缺乏体系化运营及维护，导致权益账号很快变成死号。

3. **公私域割裂** — 只做公域新媒体引流或只做私域会员商城，缺乏"公域→私域→复购"的完整链路。结果是公域流量进不来，私域会员不活跃。

4. **简单的新媒体** — 抖音，视频号都有做，但是还是缺乏承载体（安逸会+安逸商城+安逸集市）以及相应产品经理予以支撑，所以只有品宣效应，变现困难。

5. **直播电商直奔目的** — 在没有培养足够的目标私域的时候，一味地卖货，要么刷数据，要么没有销量。

### 7.3 安逸策略：低投入 + 小步快跑

以安逸集团各酒店现有的情况，采取的策略是**低投入 + 专业人才带领自有专门运营人员 + 酒店多部门配合的小步快跑**。将大营销思路贯穿其中。目的性是非常明确的。

### 7.4 一句话总结

> **安逸公域-私域新媒体运营 = 公域引流（5 大新媒体渠道）→ 安逸会沉淀（5 档会员+跨店积分）→ 安逸商城+安逸集市转化（客房+餐饮+非房+文创）→ 复购裂变 → 公域再获客。**
>
> **这是安逸集团未来 3-5 年酒店全业态自营能力的核心抓手。**
