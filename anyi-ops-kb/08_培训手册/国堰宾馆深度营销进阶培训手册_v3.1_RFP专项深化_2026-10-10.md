### 模块 24A：国央企采购专项（最高权重）

#### 24A.1 采购画像

- 计划性强（年初预算 / 季度执行 / 月度招采）
- 预算刚性（财政拨款 / 国资预算）
- 合规要求高（反四风 / 公开透明 / 招投标法）
- 季节性明显（人大政协两会 / 主题教育 / 党建培训）
- 决策链长（行政办 → 机关事务局 → 财务 → 纪检 → 分管领导）

**采购方式 5 类**：
- 公开招标（>50 万元项目法定）
- 邀请招标（≥3 家潜在供应商）
- 单一来源（独家 / 续签 / 应急）
- 定点采购（党政机关会议定点饭店）
- 框架协议（年度总包 + 单次调用）

#### 24A.2 三类国央企及其特点

| 类型 | 典型代表 | 决策特征 | 国堰切入 |
|------|---------|---------|---------|
| **央企**（国务院国资委） | 中石油、中石化、国铁、中建、中行、国家电网、中国移动 | 体量大、议价强、定点规律、跨区域流动 | 总部招采难，进**省级分公司** + **驻当地机构** |
| **地方国企**（省/市国资委） | 省旅投、市城投、省铁投、四川发展、川投集团 | 与国堰**同系统**（安逸集团 → 省旅投集团 → 省国资委） | **最强**地缘优势，可走系统内协同 |
| **政府机关** | 省/市/县政府办、机关事务局、党校、人大政协、政协 | 政策性会议、培训、调研、接待 | **党政定点资质** 直接接入 |

#### 24A.3 采购信息渠道（每日监测）

| 渠道 | 类型 | 监测频率 |
|------|------|----------|
| 中国政府采购网（www.ccgp.gov.cn） | 政府 | **每日** |
| 央企电子采购平台（央企各自门户） | 央企 | **每日** |
| 四川政府采购网 | 政府 | **每日** |
| 成都市政府采购网 | 政府 | **每日** |
| 政采云、比比招标、剑鱼标讯 | 第三方 | **每日** |
| 都江堰市政府办 / 机关事务局 | 主动 BD | **每周 1 次拜访** |
| 旅投体系内协同（安逸集团 / 锦江饭店公司） | 内部 | **实时** |

**关键词组合**："都江堰 + 会议 / 培训 / 接待""温泉 + 会议""党政 + 都江堰""党校 + 培训"。

#### 24A.4 国堰核心优势（5 个差异化）

1. **党政机关会议定点饭店资质** —— 金钥匙，竞品难以复制；
2. **党校分校** —— 教育系统独家资源（一般酒店不具备）；
3. **省旅投 → 安逸 → 国堰 三级国资背景** —— 天然信任背书；
4. **11 个汤池 + 178 间客房** —— 满足 100-200 人中型会议；
5. **都江堰区位** —— 距成都 50 分钟，避开中心城区拥堵 + 自然疗愈场景。

#### 24A.5 流程 SOP（5 步）

1. **每日监测**：专人对接采购公告，关键词过滤；
2. **标前对接**：找到经办人，探口风 / 了解真实需求 / 介绍国堰优势；
3. **编制投标文件**：商务（资质+案例）+ 技术（场地+服务）+ 报价（房型+餐标+场租）+ 增值（温泉+水文化）；
4. **述标（5 分钟）**：开头点题（党政定点+温泉+水文化）、中段案例（过往接待+集团背书）、结尾报价（阶梯优惠）；
5. **履约 + 复购**：专属客户经理驻场，会后 30 天回访，推动年度协议。

#### 24A.6 报价策略（国央企特化）

| 策略 | 适用 | 要点 |
|------|------|------|
| **协议价（年度框架）** | 省/市机关事务局长期合作 | 量价稳定、复购率高 |
| **阶梯折扣** | 大批量会议（100-200 间夜） | 100-200 间夜分档 |
| **节日包场** | 春节、十一、党代会期间 | 专属包场方案，含接机/晚餐 |
| **培训套餐** | 党校 / 主题教育 | 含早 + 教学场地 + 温泉 + 拓展 |

**红线**：
- 报价**不得低于成本线**；
- 不得破坏门市价体系（避免价格倒挂）；
- 不得违反"反四风"——不超标准接待（住宿 / 餐饮 / 用酒）。

#### 24A.7 关键能力（培训点）

- **政企关系**：专人长期对接（每周 1 次拜访），与机关事务局建立长期关系；
- **标书编制**：参考都江堰党校分校 / 锦江宾馆案例，准备"模块化"投标模板（按场景换内容）；
- **述标演练**：3 分钟话术 + PPT，每季度内部演练一次；
- **合规意识**：发票规范（电子发票+增值税专用发票）、接待标准（住宿 / 餐饮 / 用酒）、反四风红线；
- **危机响应**：重大会议/接待出问题，30 分钟内到场，2 小时内出补救方案。

#### 24A.8 国央企季节性日历（重点招采节点）

| 月份 | 节点 | 招采类型 |
|------|------|---------|
| 1-2 月 | 年终总结 / 党建培训 | 培训 + 团建 |
| 3-4 月 | 人大政协两会 / 春训 | **大型会议** |
| 5 月 | 五四 / 主题党日 | 党建 + 团建 |
| 6-8 月 | 年中会议 / 暑期培训 | 培训 + 会议 |
| 9-10 月 | 中秋国庆 / 接待 | 接待 + 会议 |
| 11-12 月 | 年终考核 / 主题教育 | **大型培训** |

#### 24A.9 KPI（国央企专项）

| 周期 | 任务 | KPI |
|------|------|-----|
| **90 天** | 监测员 + 2 次拜访 | 中标 ≥1 单 |
| **180 天** | 协议客户 ≥2 家 | 会议收入 +30% |
| **365 天** | 年度协议 ≥5 家 | 政企收入占总营收 **≥15%** |

### 模块 24B：头部公司差旅采购专项

#### 24B.1 采购画像

- **量大稳定**：年订单量大（千间夜级），可预测
- **线上化**：通过 TMC 平台下单为主
- **议价能力强**：年度协议价折扣通常 5-7 折
- **决策链清晰**：行政总监 → 采购部 → CFO
- **Travel Policy 严格**：限价、限区域、限品牌

**采购方式**：
- TMC 集中采购（携程商旅 / 同程商旅 / 腾邦等）
- 战略集采（年度协议价）
- 招投标（大型团建/会议）
- 散单预订（紧急差旅）

#### 24B.2 头部公司类型

| 类型 | 典型代表 | 差旅特点 |
|------|---------|---------|
| **互联网大厂** | 阿里、腾讯、字节、美团、拼多多、京东 | 大量高频、年轻客群、关注体验 |
| **金融** | 工行、建行、招行、平安、中国人寿 | 高净值、协议价空间大、年度大单 |
| **新能源/科技** | 比亚迪、宁德时代、华为、小米 | 制造业差旅、产学合作 |
| **大型民企** | 海尔、美的、格力 | 全国销售网络差旅 |
| **国央企头部**（已部分归 24A） | 国家电网、中石油 | 总部招标 + 省级分公司议标 |

#### 24B.3 TMC 平台（主入口）

| TMC | 背景 | 国堰对接价值 |
|-----|------|-------------|
| **携程商旅** | 携程旗下 | 大客户差旅主入口、流量最大 |
| **同程商旅** | 同程旗下 | 区域企业差旅优势 |
| **腾邦国际** | 老牌商旅 | 企业协议 |
| **汇联易 / 在行商旅** | SaaS 差旅管理 | 中型企业 |
| **滴滴企业版** | 出行 + 酒店联动 | 临时差旅 |

#### 24B.4 国堰优势（5 个针对头部公司）

1. **都江堰区位**：成都 50 分钟车程，**本地差旅首选**；
2. **温泉差异化**：商务客 + 1 天温泉的"差旅+康养"组合（竞品难复制）；
3. **会议空间**：可承接 50-200 人中型年会/团建；
4. **价格段匹配**：¥328-558 协议价符合中端商务预算；
5. **发票规范**：电子发票 + 增值税专用发票能力（财务对账友好）。

#### 24B.5 落地路径（4 步）

1. **报名 TMC 供应商**：提交资质（营业执照、星级、特种行业许可证等）+ 协议价（详见 25.4）；
2. **上架 TMC 平台**：通过携程商旅/同程商旅审核后，企业客户可在 TMC App / PC 端搜到国堰；
3. **BD 走访头部公司**：重点拜访成都 IFS / 太古里 / 高新科技园 / 金融城 / 国企写字楼，**对接行政总监或采购**；
4. **年度协议签订**：与 2-3 家头部公司签订年度差旅协议，约定间夜量、协议价、结算方式。

#### 24B.6 协议价设计（商务特化）

| 房型 | 门市价 | 建议协议价 | 含早 | 延退 |
|------|--------|-----------|------|------|
| 副楼标准间 | ¥269 | ¥229 | 是 | 14:00 |
| 主楼大床房 | ¥398 | ¥328 | 是 | 14:00 |
| 主楼双床房 | ¥398 | ¥328 | 是 | 14:00 |
| 套房 | ¥688 | ¥558 | 是 | 14:00 |

**原则**：协议价**低于门市价**、**低于 OTA 均价**；含早；可延退；电子发票。

#### 24B.7 BD 重点拜访名单（成都区域）

| 区域 | 重点客户类型 | 拜访频次 |
|------|-------------|---------|
| **成都 IFS / 太古里** | 跨国/外资/金融 | 每月 1 次 |
| **高新南区（天府软件园）** | 互联网/科技/创业 | 每月 1 次 |
| **金融城** | 银行/保险/证券 | 每月 1 次 |
| **经开区** | 制造业/汽车 | 每月 1 次 |
| **总部基地** | 国企西南区域 | 每月 1 次 |

#### 24B.8 KPI（头部公司专项）

| 周期 | 任务 | KPI |
|------|------|-----|
| **90 天** | 签约 TMC ≥2 家 | 上架携程商旅 + 同程商旅 |
| **180 天** | 协议客户 ≥3 家 | 商务间夜占比 ≥5% |
| **365 天** | 协议客户 ≥6 家 | 商务间夜占比 **≥10%** + 头部公司专题合作 ≥2 家 |

5. **申请加入外资企业商会**：如中国欧盟商会 / 中国美国商会 / 中国日本商会，成为会员酒店。

## 模块 27【v3.1 更新】：融合路线图 RFP 三线

### 国央企线
- **90 天**：监测员就位 + 2 次政府办/机关事务局拜访 / 中标 ≥1 单
