## 二、7 步处理 SOP

```
[1. 接收音频]
  ↓
[2. 跑 VibeVoice-ASR-7B]
  • 支持 60 分钟单遍
  • 输出原始转写
  ↓
[3. 说话人识别（Who）]
  • 基于声纹 + 上下文
  • 输出 Speaker 列表
  ↓
[4. 时间戳标注（When）]
  • 段级时间戳
  • 输出 UTC+8 时间
  ↓
[5. 内容提取（What）]
  • 议题 + 决策 + 行动项
  • 输出结构化 JSON
  ↓
[6. 输出双格式]
  • JSON（结构化数据 + 编程接口）
  • Markdown（会议纪要 + 行动项清单）
  ↓
[7. 数据档位标注]
  • 🟢 微软官方 VibeVoice 性能
  • 🟡 实际识别准确率（待测）
  • 🔴 说话人自动识别的准确率（依赖声纹清晰度）
```

## 三、工具栈

| 工具 | 用途 | 备注 |
|---|---|---|
| **VibeVoice-ASR-7B** | 长语音转写（60 分钟单遍）| **首选** |
| VibeVoice-ASR-Streaming | 流式识别 | 边输入边转写 |
| VibeVoice-ASR-BitNet | **CPU 边缘推理** | **4.62GB → 1.58GB** 实时 RTF<1，无需 GPU |
| VibeVoice-Realtime-0.5B | 实时 TTS | 300ms 首字节延迟 |
| VibeVoice-TTS-1.5B | 长语音合成（90 分钟/4 说话人）| ⚠️ **微软主动下架**（2025-09-05），谨慎使用 |

## 七、注意事项（合规与伦理）

| 风险 | 应对 |
|---|---|
| **AI agent 边界**：不能录音（需麦克风+OS权限）| 永远只处理 Eric 已上传的文件 |
| **隐私**：录音可能含敏感对话 | 自动识别敏感词，提示 Eric |
| **数据安全**：录音文件不上传公网 | 本地处理（VibeVoice 支持本地部署）|
| **准确性**：VibeVoice-ASR-7B 在 60 分钟长语音下精度约 85-95% | **关键数字（金额/日期/人名）必须 Eric 核对** |
| **说话人识别**：依赖声纹清晰度 | 标注"🟡 待 Eric 核对"，不直接定论 |
