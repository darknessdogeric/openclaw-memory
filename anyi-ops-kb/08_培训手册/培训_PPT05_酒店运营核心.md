## 第 38 章 · 收益管理（Revenue Management）

### 38.1 什么是收益管理？

> **收益管理就是在对的时间、以对的价格、把对的房间、卖给对的客人。**

收益管理（Revenue Management，简称 RM）起源于 1970 年代的美国航空业。当时美国航空（American Airlines）面临一个核心问题：飞机起飞后，空着的座位就永远卖不出去了——就像酒店的客房过了今晚就清零。

美国航空开发了世界上第一个计算机收益管理系统（DINAMO），通过分析历史数据预测每个航班的需求，动态调整每个座位的价格。这个系统让美国航空一年增收数亿美元。

1980 年代末，万豪酒店集团把航空业的收益管理方法论引入酒店业，开发了酒店行业的第一个收益管理系统（Marriott's Demand Forecast System）。从此，"收益管理"成为酒店行业的核心能力。

### 38.2 酒店为什么需要收益管理？

酒店有两个独特的商业特性，使收益管理成为必需：

1. **产品易腐性（Perishability）**：航空座位今天不卖明天还能卖。酒店房间今天不卖就永远没了——"当晚清零"。
2. **固定成本极高**：无论今晚住 1 个客人还是 100 个客人，空调费、前台工资、贷款利息基本不变。多卖一间房的边际成本很低（主要是布草洗涤和客用品），但边际收入就是实打实的利润。

> **关键公式**：多卖一间房的利润 ≈ ADR -（布草洗涤费 + 客用品成本 + OTA 佣金）≈ ADR - 50 元。
> 假设 ADR = 400 元，多卖一间房的贡献利润约 350 元。一年如果通过收益管理多卖出 1000 间夜，就是 35 万元纯利润。

### 38.3 收益管理的四大杠杆（详解）

| 杠杆 | 内容 | 实操举例 |
|------|------|---------|
| **定价** | 动态调价——不同日期、不同时段、不同客源不同价格 | 同一间标准大床房：周二晚 ¥450 → 周五晚 ¥780 → 糖酒会期间 ¥1280 |
| **库存** | 控制不同渠道的房间分配 | 酒店有 100 间房：40 间给携程（佣金 15%）、20 间给美团（佣金 10%）、30 间给会员直销（0% 佣金）、10 间留 Walk-in |
| **客源结构** | 不同客源类型给不同价格 | 商务协议价 600 元、旅游团队价 350 元（要 20 间起订）、OTA 散客价 500 元、会员价 450 元 |
| **时长控制** | 限制最少入住天数 | 国庆节："连住 2 晚起订"；淡季周一："住 1 晚也可以" |

**定价的实操逻辑**：

酒店收益管理不是"随便涨价"——是一门平衡术：

```
价格太高 → 入住率下降 → RevPAR 不一定增加
价格太低 → 入住率上升但收入下降 → RevPAR 也不一定增加
收益管理的目标：找到那个让 RevPAR 最大的价格点
```

**库存管理的"置换分析"（Displacement）**：

假设你只剩 5 间房，有一个旅行团想订 5 间（每间 300 元），你卖不卖？

- 如果卖了，你就不能接散客了
- 散客可能愿意付 500 元/间
- 所以你要计算：5×300 < 你可能卖出的散客房数×500
- 如果预测散客需求旺盛（如周五晚上），应该拒绝团客
- 如果预测散客需求疲软（如周二），应该接受团客

这就是"Displacement Analysis"——每接受一个低价格的预订，等于"挤掉"了一个潜在高价格预订的机会。🧮

### 38.4 动态定价的科学——现代酒店怎么定价？

现代酒店的定价不是"老板拍脑袋"，而是基于 100+ 个变量实时计算的。大型集团（万豪、华住）的收益管理系统每 15 分钟自动调价一次。

**核心变量**：

| 变量类别 | 具体内容 |
|---------|---------|
| 历史数据 | 去年同一天/同一周/同一月的入住率和 ADR |
| 近期趋势 | 未来 7/14/30/90 天的预订进度（Pace Report）——预订在加速还是减速？ |
| 竞争价格 | 周边竞品酒店（comp set）今天的 BAR（最优公开价）是多少？ |
| 城市事件 | 演唱会、大型展会、考试季、体育赛事——这些会带来需求脉冲 |
| 天气 | 台风/暴雨→出行取消→需求下降。晴天→出游增加→需求上升 |
| 航班/高铁 | 到达航班数量、高铁到站量——客流的先行指标 |
| 渠道表现 | 携程/美团/官网的浏览量和转化率 |
| 特殊日期 | 节假日、周末、展会——系统自动预设高价 |

> **AI 定价的威力**：华住/万豪的 AI 系统可以在竞争对手调价后 15 分钟内自动响应——比如万豪降价了 50 元，隔壁华住的系统会自动计算"我该降多少或不降？"并在 15 分钟内完成调整。一个收益经理可以管理 5-10 家酒店的定价，而 AI 可以同时管理 500 家。

### 38.5 收益管理的关键术语

| 术语 | 英文 | 含义 |
|------|------|------|
| 超售 | Overbooking | 接受预订超过实际房间数（赌有人取消/no-show）。如果赌错了要"walk"客人（安排到别家酒店+赔钱） |
| 入住天数 | LOS (Length of Stay) | 入住天数控制——周末可能要求 2 晚起 |
| 最优公开价 | BAR (Best Available Rate) | 当日无任何限制条件的公开最优价格——是所有折扣价的锚点 |
| 需求日历 | Demand Calendar | 标注全年的需求高峰（展会/节假日）和低谷——定价和营销的规划基础 |
| 置换分析 | Displacement | 接受一个低价预订会"挤掉"多少高价预订机会？ |
| 进度报告 | Pace Report | 未来特定日期的预订进度 vs 去年同期——如果预订落后，就要考虑降价 |
| 竞品组 | Comp Set | 竞争对手组合——通常是同地段、同档次、同规模的 5-8 家酒店 |
| 间夜 | Room Night | 一个房间被占用一晚 = 1 间夜——酒店业最基本的计量单位 |

> **类比**：收益管理就是酒店版的"动态调价网约车"。下雨天打车贵是 surge pricing；展会期间酒店涨价是 Revenue Management。滴滴的定价算法和万豪的收益管理系统——原理一模一样。都是"供需实时匹配+价格动态调整"。

### 38.6 收益管理的工作流程

```
预测需求（未来 90 天）
    ↓
制定定价策略（哪些日期涨价/降价）
    ↓
分配渠道库存（OTA 给多少间/官网留多少/协议客户多少）
    ↓
监控预订进度（每天检查未来 30 天的 Pace）
    ↓
实时调价（根据预订速度和竞争动态调整）
    ↓
复盘分析（每周/每月分析实际 RevPAR vs 预测）
```

**一个收益经理的典型一周**：
- **周一**：分析上周数据，对比预测 vs 实际
- **周二**：调整接下来 30 天的定价策略
- **周三**：参加集团收益管理例会，对齐大区策略
- **周四**：处理未来 90 天的大型活动（展会/演唱会）定价预案
- **周五**：更新周末定价，准备下周的预测报告

> ⭐ **安逸集团的收益管理现状和机会**：安逸目前没有全集团统一的收益管理系统。很多酒店还是"店长凭经验定价"——旺季不敢涨（怕卖不掉）、淡季瞎打折（自己打自己）。建立集团统一的收益管理中心 + AI 动态定价系统是当务之急——这直接关系到 6 大酒店改造后能不能把 RevPAR 做上去。

| **旅行社包房** | 批发价（通常50%折扣） | 批量保底——不管好不好卖都付钱 | 利润极低，几乎是"填房" | 旅行社 |
| **GDS** | 约10%（通过GDS预订） | 覆盖全球旅行社和差旅管理公司 | 技术接入成本高 | GDS |
| **批发商（如Hotelbeds）** | 批发价 | 覆盖全球旅行社网络 | 价格低 | 批发商 |

### 39.3 OTA 对酒店业的三大影响

**影响一：定价权的转移**

OTA 出现之前，酒店自己定价格，客人要么接受要么不住。OTA 出现之后，消费者可以直接比价——"携程上 A 酒店 400 元、B 酒店 380 元"——酒店失去了信息不对称带来的定价权。

更可怕的是，OTA 还要求"价格一致性"条款：你在携程上卖 400 元，就不能在自己的官网上卖 350 元——否则携程会给你降排名甚至下架。

**影响二：客户关系的断裂**

在 OTA 时代，客人从携程订房→携程拥有客人的手机、邮箱、历史预订记录。酒店只收到了"一个订单"——不知道客人是谁、以前来过没有、喜欢什么房型。

这对酒店的复购营销是致命的：你没办法给"上次住过的客人"发优惠券，因为你不认识他。

**影响三：比价文化盛行**

OTA 鼓励"比价"——客户在携程搜完去美团比价，然后选最便宜的。这让酒店陷入了"囚徒困境"：
- 如果我降价→竞争对手也会降价→大家价格都更低→都没赚到钱
- 如果我不降价→客人都去竞争对手那里了→我更没赚到钱
- **最终结果：所有人都降了价，所有人的利润都更薄了**

### 39.4 酒店的应对策略

**策略一：建会员体系（最根本的解法）**

会员体系的本质是：**用积分和权益"锁定"客户**——让他下次直接找你订，不再去 OTA。

- 华住会 2.7 亿会员 → 中央预订率 >60% → 年省 OTA 佣金数十亿元
- 万豪旅享家 2 亿+ 会员 → 最强的抗 OTA 护城河
- ⭐ 安逸会 160 万 → 600 万（2030 目标） → 降低 OTA 依赖

**策略二：会员最低价保证（BRG）**

万豪/希尔顿都有"Best Rate Guarantee"政策：如果你在别的地方找到比官网更低的价格，我们不仅匹配那个价格，还额外给你折扣或积分。

这向消费者传递一个信号：**"官网一定是最便宜的，去 OTA 不会更便宜"**——逐渐改变消费习惯。

**策略三：差异化产品**

OTA 只能卖"标准化的房间"。如果你能提供 OTA 上没有的体验——"住四川宾馆送三星堆门票""金牛宾馆国宾导览"——这些只有通过官方渠道预订才能享受，你就能把客户从 OTA 拉回来。

**策略四：精准的渠道管理**

不是"不上 OTA"，而是"聪明地上 OTA"：
- 旺季（不缺客人）：减少 OTA 房源、提高 OTA 价格
- 淡季（需要客流）：增加 OTA 房源、用 OTA 吸流量
- 周末 vs 工作日：动态分配渠道库存

> **一流酒店的渠道策略**：OTA 占 20-30%（获取新客）+ 会员直销占 50-60%（老客复购）+ 协议客户占 10-15%（稳定基础）+ Walk-in + 其他。

### 39.5 携程 vs 美团 vs 飞猪——三大 OTA 的差异化

| 维度 | 携程 | 美团 | 飞猪 |
|------|------|------|------|
| 核心用户 | 商旅/中产/高星酒店用户 | 年轻用户/本地生活/中低星 | 阿里生态用户/年轻人 |
| 高星酒店 | ✅ 最强 | ⚠️ 在追赶 | ⚠️ 份额第三 |
| 佣金率 | 10-15% | 8-12% | 8-12% |
| 核心入口 | 携程APP | 美团APP（外卖+酒店） | 淘宝/支付宝 |
| 特色功能 | 携程商旅 | 本地生活联动（吃+住） | 信用住（免押金免查房） |
| 国际化 | 收购 Trip.com/Skyscanner | 几乎没有 | 阿里全球生态 |

> **对安逸的参考**：安逸旗下酒店在各 OTA 的渠道分配应该根据酒店类型来定——金牛宾馆（国宾/政务/高星）主攻携程高端频道；锦著2.0（中端连锁）可以在美团上获取年轻客流。不要一视同仁。

### 39.6 ⭐ 安逸集团的 OTA 佣金支出估算

假设安逸酒店板块年营收 56,291 万元，OTA 渠道占比约 40%（行业国企酒店典型值），平均佣金率 12%：

> OTA 佣金年支出 ≈ 56,291 万 × 40% × 12% ≈ **2,700 万元/年**

如果安逸会中央预订率能从现在的水平提升到 35%（2030 目标），OTA 占比降到 25%：

> OTA 佣金年支出 ≈ 56,291 万 × 25% × 12% ≈ **1,689 万元/年**

**年节省 OTA 佣金 ≈ 1,000+ 万元**——这就是建会员体系的财务价值。

## 第 40 章 · 会员体系

### 40.1 酒店会员体系的价值

> 会员体系是酒店集团最核心的无形资产。

**为什么会员体系这么重要？**

1. **降低获客成本**：拉一个新客人的成本是让老客人复购的 5-7 倍
2. **减少 OTA 依赖**：会员走官网预订，酒店不付佣金
3. **数据资产**：会员行为数据 → 精准营销 → 提升 RevPAR
4. **品牌忠诚度**：万豪白金会员如果出差去一个城市有万豪和希尔顿可选，99% 选万豪

### 40.3 ⭐ 安逸会

安逸集团的安逸会目前有 160 万会员，目标 2030 年达到 600 万。核心挑战：
- 品牌知名度不够 → 会员增长慢
- 非安逸酒店不能用安逸会积分 → 使用场景有限
- 数字化水平不足 → 会员体验待提升

## 第 41 章 · 服务质量

### 41.1 SOP（标准操作程序）

> SOP 是酒店管理的"宪法"——把每一个动作标准化，确保不管是谁在做，客人都能得到一致的体验。

**一个标准的客房清洁 SOP 可能包含 30+ 步骤**：
1. 敲门三次，每次间隔 3 秒，"Housekeeping!"
2. 进门后先检查是否有客人遗留物品
3. 开窗通风
4. 撤除脏布草
5. 清理垃圾桶
6. 铺床（床单四角 45 度折角，被芯不外露）
7. 清洁卫生间（镜子无指印、马桶消毒、地漏无异味）
8. 补充客用品（矿泉水/茶包/洗漱用品）
9. 吸尘（从里到外，角落不漏）
10. 自检

> **类比**：SOP 就是"酒店版的麦当劳操作手册"——全世界的麦当劳汉堡都是一个味道，因为操作流程完全一样。

### 41.2 神秘客（Mystery Shopper）

酒店集团会请第三方公司的人假扮普通客人入住，根据标准检查清单打分。高分奖励、低分整顿。这是保持服务品质的硬手段。

### 41.3 点评管理

在 OTA 时代，携程评分 4.8 vs 4.3 可能是 20% 入住率的差距。酒店必须专人回复每一条差评、改进每一个被投诉的问题。

> **一句差评的杀伤力**：社交媒体研究显示，一个差评会阻止 30 个潜在客户预订。10 个好评可以抵消 1 个差评的负面影响。

## 第 42 章 · 酒店供应链

### 42.1 一家酒店需要采购什么？

| 品类 | 内容 | 年采购额（假设 200 间客房） |
|------|------|--------------------------|
| 布草 | 床单、被套、枕套、毛巾、浴巾 | 50-100 万元 |
| 客房用品 | 牙刷、牙膏、拖鞋、洗浴用品、矿泉水 | 30-50 万元 |
| 食品饮料 | 早餐食材、酒水、零食 | 200-500 万元（有餐厅的酒店） |
| 清洁用品 | 清洁剂、消毒剂、洗衣液 | 10-20 万元 |
| 能源 | 水、电、天然气 | 100-200 万元 |
| 办公用品 | 纸张、打印耗材 | 5-10 万元 |

### 42.2 集采的意义

> 假设一家酒店买床单 50 元/条，100 家酒店一起买可以谈到 35 元/条。**省 30% × 100 家 = 一年省 150 万元。**

这就是集团集采的价值——**规模效应转化为成本优势**。

### 42.3 ⭐ 安逸购

安逸集团的"安逸购"集采平台 2024 年销售额 4,000 万元，节约率 13.79%。对比锦江全球采购平台（年交易额数十亿），安逸购还有巨大增长空间。

## 第 43 章 · 酒店人才

### 43.1 酒店的人才金字塔

```
        ┌──────────┐
        │ 总经理(GM)│  ← 对酒店全部经营结果负责
        ├──────────┤
        │ 部门总监  │  ← 房务总监 / 餐饮总监 / 市场销售总监 / 财务总监 / 工程总监 / 人事总监
        ├──────────┤
        │ 部门经理  │  ← 前台经理 / 客房经理 / 餐厅经理 / 宴会经理 / 行政管家
        ├──────────┤
        │ 主管/领班 │  ← 前台主管 / 客房领班 / 餐厅领班
        ├──────────┤
        │ 一线员工  │  ← 前台接待 / 客房服务员 / 餐厅服务员 / 礼宾 / 厨师 / 维修工
        └──────────┘
```

### 43.2 酒店人才的核心痛点

1. **薪酬偏低**——中国酒店一线员工平均月薪（地级市）3000-5000 元
2. **流失率高**——行业平均年流失率 30-40%
3. **晋升慢**——从服务员到经理通常需要 5-8 年
4. **社会地位感知偏低**——很多人觉得"服务员"不是好工作

### 43.3 ⭐ 安逸的人才挑战

安逸作为国企，有"铁饭碗"的优势（稳定），但市场化激励不足。安逸 1234 战略提出的**"三项制度改革"**——人事、劳动、分配——就是针对这个痛点。

雷迪森的做法（经理层契约化 + 项目跟投 + 超额利润分享）是安逸可以学习的方向。

## 第 44 章 · 酒店财务

### 44.1 酒店的收入从哪来？

以一家典型四星级全服务酒店为例（200 间客房）：

| 收入来源 | 占比 | 说明 |
|---------|------|------|
| 客房收入 | 55-65% | 酒店的核心收入 |
| 餐饮收入 | 25-35% | 含早餐、正餐、宴会、客房送餐 |
| 会议宴会 | 5-10% | MICE 收入 |
| 其他收入 | 3-5% | SPA、停车、洗衣、电话、迷你吧 |

### 44.2 酒店的成本去哪了？

| 成本类别 | 占收入比例 | 说明 |
|---------|----------|------|
| 人工成本 | 25-35% | 酒店是劳动密集型行业 |
| 食品饮料成本 | 8-15%（但只对应餐饮收入，实际是餐饮收入的 25-35%） | |
| 客房消耗品 | 3-5% | 布草洗涤、客用品 |
| 能源 | 5-8% | 水电气——酒店是耗能大户 |
| 市场销售费 | 3-6% | OTA 佣金、广告、销售人员提成 |
| 维修维护 | 2-4% | |
| 管理费 | 3-8%（如果请了管理公司） | |
| 折旧摊销 | 10-20%（主要影响净利润，不影响 GOP） | |

### 44.3 酒店的利润有多薄？

| 维度 | 数据 |
|------|------|
| 酒店行业平均净利润率 | 5-10%（好的年份）/ 亏损（差的年份） |
| 管理公司毛利率 | 60-70% |
| 经济型酒店投资回收期 | 3-5 年 |
| 五星级酒店投资回收期 | 10-15 年（甚至更长） |

> **行业真相**：大多数全服务五星级酒店本身不赚钱——赚钱的不是酒店，是管理公司。这就是为什么全世界的酒店集团都在拼命做"轻资产"。

⭐ **安逸集团的现实**：安逸 2025 年酒店板块营收 56,291 万元，但利润为 **-6,843 万元**——亏损面接近 50%。这不是安逸独有的问题，是国企老酒店的通病。但这也是 6 大酒店改造 + 轻重分离的紧迫性所在。
