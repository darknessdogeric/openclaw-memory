### 39.2 三条对标结论

**结论一：国堰的 RevPAR 对标的是"经济型"，不是"中端"。**

```
国堰 102.63  vs  锦江经济型 99.80   -> 高 2.8%   ← 实际对标在这
国堰 102.63  vs  锦江有限服务型 146.66 -> 低 30.0%
国堰 102.63  vs  锦江中端 159.09     -> 低 35.5%
国堰 102.63  vs  锦江全服务型 238.06 -> 低 56.9%
```

**这个结论比"比区域低三分之一"更刺耳**：国堰挂着**四星**，但 RevPAR 表现对应的是**经济型**产品。**这与 v4.0 的"产品-身份错位"判断完全吻合，且现在有了全国尺度的坐标。**

**结论二：价格不低，量不足。**

```
国堰 ADR 266.80  vs  锦江有限服务型 229.44  -> 高 16.3%
国堰 OCC 38.47%  vs  锦江 63.92%            -> 低 25.5 pp
国堰 OCC 38.47%  vs  华住 79.80%            -> 低 41.3 pp
```

**国堰的房价在全国中端连锁里已经偏高，但出租率只有它们的六成。**
**这把"提价"这条路基本关上了——问题不是卖不出价，是卖不出量。**

**结论三：国堰没有跑输大盘，短板在绝对水平，不在趋势。**

```
国堰 RevPAR 同比       +2.94%   ← 优于锦江有限服务 +0.46%
                               ← 优于锦江中端 -1.02%
                               ← 优于锦江全服务 -1.94%
                               ← 优于首旅成熟店 -6.10%
华住中国               +1.10%   ← 同向
```

**行业 H1 2026 的共性是"收入微增、利润大涨、房价承压、出租率托底"**——锦江靠出租率修复把 RevPAR 托起来，华住 ADR 298 元连续四个季度正增长。**国堰是"出租间夜 +8.98% 换 ADR -5.35%"，量增价跌，与行业同向。**

> **培训必须讲清这一条，否则学员会误以为国堰在崩盘。**
> **国堰的问题不是"掉队了"，是"一直在这个位置"——2025 年同期 RevPAR 约 99.70，2026 年 102.63，两年基本原地踏步。**
> **这恰恰是十五五规划说的"轻重分离、以重育轻"要解决的真问题：不是短期经营失血，是资产效率长期锁定在低位。**

### 39.3 用行业平均校准区域基准（v5.1 的关键方法论修正）

v5.0 用"都江堰区域 4-5 星 ADR 380-450、OCC 65-72%"作为对标基准（S-04，信源待补，评分 50-60）。**本模块提供独立校验路径**：

```
区域基准隐含 RevPAR = 380 × 65% ≈ 247 元 （低端）
                  = 450 × 72% ≈ 324 元 （高端）
```

**与全国基准并排看**：

| 参照系 | RevPAR | 国堰 102.63 的位置 |
|---|---|---|
| 锦江经济型 | 99.80 | 略高 |
| **国堰** | **102.63** | — |
| 锦江有限服务型 | 146.66 | 低 30% |
| 锦江中端 | 159.09 | 低 36% |
| 都江堰区域 4-5 星（低端） | 247 | 低 58% |

**方法论要点**：**区域基准与集团基准给出的是两条独立的判断路径**。区域基准（都江堰度假目的地属性）说"国堰应达到 247-324"；集团基准（全国度假/中端连锁属性）说"国堰应在 100-160 区间"。**两条路径给出的答案相差 2-3 倍——这就是为什么区域基准必须补源。**

**培训建议口径（当前）**：**以集团基准（锦江中端 159.09）为近期可达目标，以区域基准（247-324）为中期理想目标，改造方案按集团基准做投资回报测算**——因为投资回报必须用保守值。

**补源后可解决**（见模块 40 补源清单第 2 项）：调取都江堰市文旅部门住宿业台账或厚海（Horwath HTL）区域数据，可将区域基准升至 R1，届时测算区间收敛。

## 模块 40【v5.1 新增】：数据可信度评分体系与 90% 达标路径

> **本模块回应一个方法论问题**：酒店行业没有通行精确数据，单店数据尤其稀缺。**怎么办？**
> Eric 的判断是：**拼广度**——用信源矩阵 58 维度 × 13 大类尽可能多的独立信源交叉，再结合专业算法（乘法分解、区间反解、闭合校验）和市场平均（上市集团财报），得出最接近真实的结论。
> 本模块把这个方法**变成可执行、可验收、可对外交代的制度**：每个数据点打分、每个结论标分、每个缺口列补源动作。

### 40.5 三条方法论沉淀（v5.1 新增，可复用于其他单体酒店）

**方法论一：拿到任何平台的同比字段，先做三元组自洽性检验。**

```
RevPAR 同比 = (1 + 出租率相对变化) × (1 + ADR 相对变化) − 1
```

国堰本期实测：RevPAR +2.94%、ADR −5.35% → 反解出租率应为 **+8.77%（上升）**，与平台显示的 +6.76% 同向，差异源于显示值四舍五入。
**若不做这一步，就会把"出租率同比上升"误读成"下降"，整个诊断方向反了。**（v5.1 初稿即踩此坑，已修正。）

**方法论二：平台图表先判口径，再读数。**

三步法：
1. **先找可交叉验证的等式**——本手册用了三组：分项加总=总营收；ADR=客房收入÷间夜；RevPAR=ADR×出租率；出租率=间夜÷房量。**四组全过，才说明口径可信。**
2. **再判单位与周期**——渠道明细表经三重验证为"日均"口径，不是区间合计。
3. **最后核对合计行**——发现平台合计行存在公式错位（出租率位置显示的其实是合计 ADR）。

**方法论三：区间用反解锁定，不靠猜。**

拿到 1-8 月"1月1日-24日"的截图时，用 `间夜 ÷ 出租率 ÷ 房量` 反解天数：**297 天**——与 OTA 实测 235 间吻合；若按 24 天反推需 2,912 间房，不成立。**同一份数据，区间错判会让所有结论错 12 倍。**
