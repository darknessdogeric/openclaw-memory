## 一、核心运营指标（一页读懂）

| 指标 | 缩写 | 公式 | 什么含义 | 行业基准 |
|------|------|------|---------|---------|
| 入住率 | OCC | 售出房数 ÷ 可售房数 | 今晚住了多少人 | 2024 中国平均 58.8% |
| 平均房价 | ADR | 客房收入 ÷ 售出房数 | 每间卖了多少钱 | 2024 中国平均 ¥200 |
| 每间可卖房收入 | RevPAR | 客房收入 ÷ 可售房数 = OCC×ADR | 核心竞争力指标 | 2024 中国同比下降 5% |
| 经营毛利 | GOP | 总收入 - 直接运营成本 | 酒店运营赚了多少 | — |
| 人房比 | — | 员工数 ÷ 客房数 | 养了多少人 | 奢华 1.5-3.0 / 经济型 0.15-0.25 |
| 净利润率 | — | 净利润 ÷ 总收入 | 综合赚钱能力 | 行业平均 5-10% |

## 五、中国酒店业关键时间线

| 年份 | 事件 |
|------|------|
| 秦汉 | 驿站制度建立——最早的官方住宿体系 |
| 1846 | 礼查饭店（上海）——中国第一家外资酒店 |
| 1929 | 和平饭店——"远东第一楼" |
| 1949 | 锦江饭店成立——新中国最重要的涉外饭店 |
| 1979 | 改革开放——合资酒店时代开始 |
| 1983 | 白天鹅宾馆（广州）开业——第一家自主设计五星级 |
| 1983 | 金陵饭店（南京）——中国第一高楼（当时） |
| 1988 | 上海静安希尔顿——大陆第一家希尔顿 |
| 1997 | 锦江之星——中国第一个经济型连锁品牌 |
| 2002 | 如家成立——经济型连锁第一波 |
| 2005 | 7天、汉庭成立——经济型连锁第二波 |
| 2006 | 如家纳斯达克上市——中国第一家海外上市酒店 |
| 2013 | OTA 时代开启——携程崛起，酒店利润被挤压 |
| 2015 | 首旅私有化如家（150 亿）——国企混改标志性事件 |
| 2015-2016 | 锦江收购铂涛+维也纳——中国酒店巨头格局形成 |
| 2020-2022 | 疫情冲击——单体酒店大规模倒闭，连锁化加速 |
| 2023-2026 | 恢复+AI 化——华住华小AI、万豪阿里AI合作 |
| 2025.12 | 酒店 REITs 政策破冰——发改委 991 号文 |
| 2026 | 安逸十五五规划发布——轻重分离+品牌输出 |
