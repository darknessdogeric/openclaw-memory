## 第 54 章 · 安逸集团全貌

### 54.1 一句话定位

> **安逸酒店集团是四川省属国有酒店资源整合运营的核心平台，以"巴蜀文化主题酒店"为差异化定位，正从"负重前行"走向"破局新生"。**

**三层官方定位**（来自安逸集团 1234 战略文件）：
1. **开创者与领导者**：中国巴蜀文化主题酒店细分赛道的开创者和领导者
2. **核心平台**：四川省国有酒店资源整合运营的核心平台
3. **生活体验创造者**：为全球宾客创造基于巴蜀文化的安逸生活方式体验

**远期的官方愿景**：
> "建成国内一流、国际知名的综合性酒店集团。"

### 54.2 所有权结构（谁管安逸？）

```
四川省国资委
     │
     ▼
四川省旅游投资集团（省旅投）
     │
     ├── 安逸酒店集团
     ├── 其他子公司
     └── ...
```

**关键理解**：
- 安逸是省旅投的二级子企业，没有独立上市
- 重大投资需要报省旅投层面审批——安逸本身没有投资决策权
- 经理层以上人事权在党委——属于"党委管理干部"
- 三重一大（重大决策、重要人事任免、重大项目安排、大额资金运作）必须经党委会审议

> ⭐ **对产业发展部（Eric 团队）的实操影响**：
> - 6 大酒店改造的投资决策需要走省旅投立项审批流程

- "400 余个注册商标有注册无应用"：安逸手里有一堆品牌 IP，但都躺在商标局文件里——没有变成消费者能感知的品牌体验
- "亏损面接近 50%"：[R66 2026-07-31 纠错] 安逸 56 家管理酒店中，约 28 家在亏损——其中古尔沟最严重（资产负债率 >170%）。167 家数字是 1234 战略远期目标。

## 第 56 章 · ⭐ 轻重分离改革——安逸集团的"一号工程"

### 56.1 一句话理解

> **轻重分离就是把"管房子的"和"管酒店的"分开——前者盯着资产增值，后者盯着运营利润。两者互不拖累，通过市场化管理合同合作。**

### 56.2 为什么要做轻重分离？（安逸的特有痛点）

安逸集团当前的核心问题用两个数字就能说明：

- [R66 2026-07-31] **酒店数 56 家（2026.6 在管）**，但**亏损面近 50%**；167 家是 1234 战略远期目标
- **资产总额 35.51 亿元**，但**年利润 -6,843 万元**

这背后的根源是：安逸大部分酒店是"自有自营"模式——自己拥有物业、自己经营。这种模式的问题：

| 问题 | 具体表现 |
|------|---------|
| **资产负担重** | 35.51 亿资产 → 大量资金沉淀在折旧/维护/利息上 |
| **运营效率低** | 没有人房比考核、没有 GOP 考核、没有退出机制 |
| **人员冗余** | 国企特有的"大锅饭"——人房比偏高 |
| **品牌弱** | 所有精力都在"保住资产"，没人管"建品牌" |
| **扩张慢** | 每新开一家酒店要花几亿投资——扩张极慢 |

### 56.3 轻重分离怎么做？

**目标架构**（来自安逸 1234 战略）：

```
改革前（现状）:                     改革后（目标）:
┌─────────────────┐        ┌──────────────────────────────┐
│  安逸酒店集团     │        │       安逸酒店集团              │
│  56 家管理酒店（自营 17 + 轻资产 39）│   →    │                                          │ [R66 2026-07-31]
│  自己管自己的资产  │        │  ┌──────────┐ ┌───────────┐ │
│  人/财/业务混在   │        │  │重资产平台 │ │轻资产平台  │ │
│  一起            │        │  │(管物业)  │ │(管运营)   │ │
└─────────────────┘        │  │          │ │5大事业部  │ │
                            │  │考核：     │ │考核：      │ │
                            │  │资产收益率│ │GOP/管理费 │ │
                            │  │保值增值率│ │会员增长   │ │
                            │  │闲置盘活率│ │品牌影响力 │ │
                            │  └──────────┘ └───────────┘ │
                            │       ↕ 市场化管理合同         │
                            └──────────────────────────────┘
```

**核心逻辑**：
- 重资产平台把物业"租"给轻资产平台运营（或者"租"给外部的万豪/洲际运营）
- 轻资产平台用安逸品牌管理这些物业，也可以去管别人的酒店
- 两个平台各有各的考核指标，互不拖累

### 56.5 改革的关键配套机制（"不能只拆分，不改制"）

轻重分离如果只做"物理拆分"（两个公司），不做"机制改革"（市场化运营），就会走上华天酒店的老路——拆分完了还是老样子。

安逸 1234 战略提出的配套改革：

**1. 三项制度改革**（人事/劳动/分配）
- 人事：经理层聘任制——不再是"铁饭碗"，签业绩合同
- 劳动：市场化用工——能进能出
- 分配：业绩导向薪酬——多赚多分

**2. 职业经理人制度**
- 5 大事业部负责人实行职业经理人制度
- 对标市场薪酬（不是参照国企级别工资）
- 年度考核+任期考核，不合格解聘

**3. 店长负责制**
- 每个门店的店长（总经理）对 GOP 和 RevPAR 负责
- 给店长授权：定价权、用人权、一定的采购权
- 超额利润分享：门店 GOP 超额部分，店长和团队可以分

**4. 四独立原则**（重资产平台 vs 轻资产平台）
- 资产独立：各自名下的财产归属清晰
- 财务独立：各自独立核算、独立纳税
- 人员独立：各自的员工/编制/薪酬体系
- 业务独立：各自有独立的经营范围和考核指标

### 56.6 改革的三大风险

| 风险 | 具体表现 | 应对措施 |
|------|---------|---------|
| **改革速度太慢** | 方案讨论了 3 年还没拆分——走向华天老路 | 设定硬性时间节点（2026年底前必须完成拆分方案） |
| **拆而不改** | 两个平台建了，但还按老机制运行——"换汤不换药" | 配套机制（三项制度+职业经理人+店长负责制）同步推进 |
| **人才跟不上** | 市场化运营需要市场化人才——安逸现有的管理团队可能不适应 | 外部招聘+聘任制+专业培训（雷迪森的"项目跟投"可以吸引市场化人才） |

### 56.7 我们是哪个板块？

➤ **产业发展部（Eric 带领的团队）在轻重分离中的角色**：

- **不是重资产平台**（不管物业持有）
- **不是轻资产 5 大事业部**（不直接管酒店运营）
- **而是贯穿两个平台的"协调+推动+赋能"机构**

具体职责：

1. **改造协调**：推进 6 大酒店改造（第一批 1.33 亿 / 第二批 3.43 亿）——这是我们看得见、摸得着的核心工作
2. **投资测算**：每项改造/新项目的经济可行性分析——这是蒋抒伶的主战场
3. **制度设计**：参与轻资产管理输出办法、三项制度改革方案的起草——这是团队战略价值的体现
4. **数字化推动**：协调安逸集团数字化中台建设——这是肖润宇的发力方向
5. **一线对接**：与旗下酒店运营团队沟通协调——这是阿都榈玺的强项
6. **品牌输出**：推动"1+N 企地合作"模式落地——对接四川省内地市州的国资酒店整合

> **一句话**：产业发展部是安逸集团从"[R66 2026-07-31] 56 家管理酒店（含自营 17 + 轻资产 39）"走向"200+ 家轻资产输出"的**发动机**——我们不是螺丝钉，我们是变革的推动者。
