> **编订**：B166ER | 2026-07-23
> **用途**：根据 Eric 的任务输入，自动判断走哪条 SOP

---

## 任务识别决策树

```
Eric 输入
    │
    ▼
[Q1] 是单店还是地区？
    │
    ├── 单店 → 走 single_store SOP（v5，6 步）
    │
    ├── 地区 → [Q2]
    │
    └── 多个地区对比 → [Q3] 多区域对比分析 SOP

[Q2] 地区分析的目的是什么？
    │
    ├── A. 项目可行性（已有具体项目）→ region + single_store 双路径
    │
    ├── B. 市场全景（无具体项目）→ region-only
    │
    ├── C. 政府/合作（招商引资） → region + 政策合规重点
    │
    └── D. 战略并购 → region + 退出 + REITs 重点

[Q3] 多区域对比的目的是什么？
    │
    ├── A. 投资选址（哪个地区最好）→ 5 维评分对标
    │
    ├── B. 品牌进驻（哪个地区优先） → 分级 + 时间窗口
    │
    └── C. 战略研究（行业全景） → 多区域汇总数据
```

## 风险偏好决策树

```
Eric 风险偏好
    │
    ▼
[Q4] 什么风险偏好？
    │
    ├── 极稳 ⭐ → 不做 / 二手收购 / 推迟到 2027
    │
    ├── 稳 ✅ 默认 → 中端精品 8-15 间 + 280 万 + 修正后 5-6 年回收
    │
    └── 积极 ⚠️ → 高端 / 温泉+康养 / 350-500 万 + 3-4 年回收
```

## 关键约束决策树

```
[Q5] 投资规模上限？
    │
    ├── ≤300 万 → 单店 8-12 间 + 稳态投资 SOP
    │
    ├── 300-800 万 → 单店 12-25 间 + 中端
    │
    └── ≥1000 万 → 多物业组合 / 品牌化
```

```
[Q6] 物业获取方式？
    │
    ├── 国有出让 → 物业 A 路径（合规，融资易）
    │
    ├── 集体租赁（≤20 年）→ 物业 B 路径（合规但融资难）
    │
    └── 既有改建 → 物业 C 路径（消防难，成本中等）
```

```
[Q7] 客群定位？
    │
    ├── 旅居康养（北方候鸟） → 路径 B（长住 + 私域）
    │
    ├── 亲子家庭 → 路径 A（温泉+主题房）
    │
    ├── 自驾散客 → OTA 驱动（标准产品）
    │
    ├── 商务/会务 → 区位优势项目
    │
    └── 数字游民 → 长住 + 工位 + 高速网络
```

## 行业景气决策树

```
[Q9] 当前行业景气度？
    │
    ├── 上升期 → 可积极投资（2023 时期）
    │
    ├── 平稳期 → 稳态投资（2024 时点）
    │
    ├── 衰退期 → 极稳 / 不做（2025-2026 现状）⚠
    │
    └── 复苏期 → 提前布局（如 2026-2027 预测）
```

**2024 全国 RevPAR -9.7%** → 当前=衰退期 → 默认"极稳"或"稳"
**浩华 2024 Q4 指数 -37** → 景气底部
**2027 预测触底回升** → 若等得起，可推迟

## 综合决策矩阵

将 Q1-Q9 的答案组合起来，决定最终方案：

| Q1 | Q4 | Q9 | 推荐路径 |
|----|----|----|---------|
| 单店 | 稳 | 衰退 | 单店 SOP + 极稳 SOP |
| 地区 | 稳 | 衰退 | 地区 SOP + 项目可行性 |
| 地区 | 积极 | 上升 | 地区 SOP + 完整决策树 |
| 多区 | — | 衰退 | 多区域对比 SOP + 5 维评分 |

**弥勒案例**：
- Q1 = 地区（弥勒）
- Q4 = 稳
- Q9 = 衰退（2024 全国 RevPAR -9.7%）
- → 路径：**地区 SOP + 项目可行性（v4）**
- → 决策：**5 个约束条件 + 280 万 + 12 间 + 5-6 年回收（修正后）**

## 决策树的局限

- ❌ 不能替代实地 DD
- ❌ 不能预测政策突变
- ❌ 不能保证 OCC 推算 100% 准确

**决策树+5 维矩阵 ≠ 投资保证**——但能**降低决策风险到可控范围**。
