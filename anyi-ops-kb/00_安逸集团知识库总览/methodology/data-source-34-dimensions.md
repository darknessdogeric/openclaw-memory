# 34 维度信源规范 v2.0（**分层方法论**）

> **核心原则（Eric 2026-07-23 明确）**：
> **默认 = 国家级数据源**。**没有做具体省份/城市/地区分析时，不需要区域级数据源**。
> **只有 Eric 明确要求做具体地区，才逐级下沉到省市县数据**。
> 
> **编订**：B166ER | 2026-07-23

---

## 一、分层原则（默认 = 国家级）

| 层级 | 触发条件 | 数据源范围 |
|------|---------|-----------|
| **L0 国家级（默认）** | 行业级报告 / 全国分析 | A 国家级 + B + C 全国 + D + E 国家 + G |
| **L1 省级** | Eric 要求"分析某省" | + A 省级 + E 省级 |
| **L2 州市级** | Eric 要求"分析某州市" | + A 州市级 + E 州市级 |
| **L3 县区级** | Eric 要求"分析某县区" | + A 县区级 + E 县区级 |

**核心规则**：
- ❌ L0 任务**禁止**下沉到 L1/L2/L3 数据
- ✅ L1/L2/L3 任务**必须**包含上层（L0 + 当前层 + 下层）
- ✅ L1 报告需"全国背景 + 省级数据"
- ✅ L2 报告需"全国 + 省级 + 州市级"
- ✅ L3 报告需"全国 + 省 + 州市 + 县区"

## 四、按层启动的决策树

```
Eric 输入任务
    │
    ▼
[Q1] 是否指定具体地区？
    │
    ├── 否 → 仅用 L0 国家级（30 个信源）→ 全国级报告
    │
    └── 是 → [Q2] 具体哪一层？
            │
            ├── 省 → L0 + L1 省级（+4 个）
            │
            ├── 州市 → L0 + L1 + L2 州市级（+8 个）
            │
            └── 县区 → L0 + L1 + L2 + L3 县区级（+12 个）
```

**修正**：行业级报告**只用 L0**，明确标注"全国级"
