## 五、安逸甄选项目 · 茶/文创/伴手礼新媒体运营商

### 5.1 项目定位（从 22:45 内化笔记）

- **货品**：四川文创 + 土特产（茶/伴手礼/食品）
- **载体**：安逸集市小程序 + 全域抖音/小红书/视频号
- **核心需求**：
  1. 品牌人格化（区别于酒店业的理性）
  2. 内容创意（情感/文化/调性）
  3. 供应链整合（从产地到物流）
  4. 私域沉淀（公众号 + 视频号）

### 5.2 茶/文创/伴手礼赛道 5 家头部服务商

| 服务商 | 区位 | 适配 | 关键差异 |
|---|---|---|---|
| **厦门蓝火焰影视** | 福建（茶产区）| **茶品牌首选** | 深度服务过**安溪铁观音/八马茶业/天福茶叶/华祥苑**；茶文化内容策划强 |
| **云南易致网络科技** | 云南（茶产区）| **云茶垂直** | 茶叶品牌从 0 到 1 冷启动；春茶季/双 11/ 年货节营销 |
| **杭州微念品牌** | 杭州 | 顶级 IP 打造 | 文化 IP 运营标杆（**李子柒 IP**）；适合长远品牌化路线 |
| **杭州如涵文化** | 杭州 | 消费品 IP 矩阵 | 200+ 达人，消费品/美妆/家居强；适合大量内容矩阵 |
| **北京微播易** | 北京 | 全行业**巨量引擎官方** | 5 万+ 客户，AI 智能投放；适合大规模曝光 + 效果投放 |

### 5.3 推荐匹配（安逸臻选选型）

| 优先级 | 选型路径 | 推荐 |
|---|---|---|
| **茶 + 文创** | ⭐ **厦门蓝火焰**（福建茶产区深度）+ ⭐**云南易致**（云茶垂直）| 茶赛道头号齐全，产地直供 + 内容创意强 |
| **品牌 IP 化** | 杭州微念（李子柒模型）| 中长期品牌建设，**适合打造"安逸甄选"类似李子柒 IP** |
| **内容矩阵 + 规模曝光** | 北京微播易 | 大规模广告投放 + 多平台联动 |

### 5.4 关键建议

- **茶品类**：优先厦门蓝火焰（福建产区+已服务八马/天福/华祥苑等头部品牌）+ 云南易致（云茶）
- **品牌 IP 化**：微念模式（李子柒）适合长期——安逸甄选若想做成"旅游+特产文化 IP"，微念模式是参考标杆
- **性价比**：成都本土有 3 家服务商（梵栖/云帆/锦呈/橙意）值得对比 — 但规模/品牌力较弱
