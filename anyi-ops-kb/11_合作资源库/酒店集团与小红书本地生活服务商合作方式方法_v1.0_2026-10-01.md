## 二、合作 5 大要点（复用框架）

### 2.1 收费模式（国企特批调整）

| 项 | 行业标准 | 国企特批 |
|---|---|---|
| 推荐官入门 | 299 元 | 维持 |
| 合伙人入门 | 3.8 万元 | **免去**（国企属性） |
| 单店仅开店 | 2,000+ 元 | **降至 ~1,000 元**（成本价）|
| 开店+运营 | 8,000+ 元 | 折扣 |
| 集团整体扣点 | 协商 | **必须低于单店 1-2 个点**（说服力核心）|

### 2.2 集团留存比例

**核心说服逻辑**：集团合作必须比单店合作**成本明显更低**，才能推动单店交账号给集团统筹。

| 留存位置 | 建议比例 |
|---|---|
| 集团整体留存 | **≥ 50% 后台分佣** |
| 单店自留 | 30-40% |
| 服务商跟进分佣 | 10-20% |
| 平台扣点 | 5-7%（酒店类目）|

### 2.3 技术对接（最优方案）

```
小红书集团号（入口）
    ↓  点击预订
小红书小程序（交易）
    ↓  完成支付，自动分账
安逸自有会员小程序（私域沉淀）
    ↓  完成订单 / 复购 / 会员
商家后台（资金到账）+ 自在云分佣
```

**关键技术点**：
- 商家**独立 ICP 备案**
- 资金到商家户头，平台 + 服务商自动分账
- **跳转不影响小红书分佣**逻辑
- 满足**国资委数据安全**诉求（自有定制系统）

### 2.4 运营模式（行业标准）

| 项 | 约定 |
|---|---|
| 收费 | **底价 + 月度运营费 + 销售分成** |
| 核销率 | **≥ 20%**（避免刷数据）|
| 日历房 | 直接下单，**无核销问题**（按实际订单计）|
| 责任分工 | **集团搭框架，单店可自营或委托**，集团无运营能力 |

## 三、合作 4 大方向

### 方向 1｜集团统筹型新媒体矩阵
- 集团 + 单店 双层架构
- 抖音 + 小红书同步搭建（视频号单店自营）
- 矩阵账号联动做活动

### 方向 2｜公域→私域沉淀
- 小红书 → 自有会员小程序（保留小红书分佣逻辑）
- 满足国企数据安全 + ICP 备案合规
- 餐饮板块若技术不支持，运营方加微信拉群补充

### 方向 3｜多账号矩阵架构
- 集团号 + 每家酒店子账号
- 同一酒店客房/餐饮可分账号（垂类运营）
- 集团联动 / 节假日活动 / 全矩阵互动

### 方向 4｜关联业务接入（如安逸甄选 / 茶业等零售品牌）
- 同步接入其他业务平台
- 抖音同步矩阵（若服务商不承接，找撮合运营商）

## 四、合作推进 5 阶段时间线（标准化）

| 阶段 | 时长 | 关键动作 |
|---|---|---|
| **1. 初步沟通** | T | 双方介绍 + 业务匹配 + 需求理解 |
| **2. 需求对齐** | T+1-2 周 | 集团提需求（成本/私域/运营）；服务商出方案 |
| **3. 方案输出** | T+3-4 周 | 服务商按 N 家店规模出完整方案 |
| **4. 汇报审批** | T+5-6 周 | 集团内部管理层汇报 → 决策 |
| **5. 上线运营** | T+7-10 周 | 分批上线 → 跟上年底 + 春节旺季 |

## 五、合作 8 大风险与应对

| 风险 | 应对策略 |
|---|---|
| 集团统筹扣点不显著低于单店 | 合同锁定 + 年度动态议价 |
| 公私域跳转技术障碍 | 运营手段补充（拉群、加微信）|
| 数据安全 | 全栈定制系统 + 完整源代码 |
| 单店配合度低 | 给 1-2 个月适应期 + 自愿参与 |
| 安逸甄选三方协议 | 与川商投联合提前签 |
| 抖音平台无服务商 | 集团撮合 + 备选运营商 |
| 核销率不达标（<20%） | 调整扣点 + 优先日历房（免核销）|
| 服务商换人风险 | 锁定期 2 年 + 交接条款 |
