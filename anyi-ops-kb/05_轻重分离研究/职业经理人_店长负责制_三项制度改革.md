## 1. 一句话定位

> **"以职业经理人（店长负责制）为总抓手 → 推进轻重资产分离 → 系统深化三项制度改革" — 这是集团改革的"一体三面"。**

**逻辑链**：
```
店长负责制（单店经营授权）
       ↓
轻重分离（重资产管物业 / 轻资产做品牌）
       ↓
三项制度改革（人事 / 劳动 / 薪酬）
```

---

## 2. 改革战略意义（三层逻辑）

### 2.1 顶层政策对接

| 文件 | 核心要求 |
|------|---------|
| 《中共中央国务院关于深化国有企业改革的指导意见》（中发〔2015〕22号）| 商业类国企推行职业经理人制度 + 任期制和契约化管理 + 市场化选人用人 + 差异化薪酬 |
| 国企改革三年行动 / 新一轮深化提升行动 | 人事/劳动/分配三项制度改革作为国企改革**核心攻坚任务** |
| 省国资委 / 省旅投集团 | 通过职业经理人制度，**市场化运营盘活重资产、拓展轻资产托管业务** |

### 2.2 战略意义

- **党管人才 + 市场化经营** 的有机融合制度载体
- **打通市场化选人用人全链条**的核心突破口
- **支撑轻重资产分离**的运营根基（改革目标 = 重资产管物业、保增值；轻资产做品牌、拓托管）
- **三项制度改革一体化落地**的总枢纽

### 2.3 现实紧迫性

| 现状问题 | 改革对应 |
|---------|---------|
| 行政化管理权责受限、激励偏弱 | 店长负责制 → 下放门店经营自主权 |
| 轻重资产混营 → 核算模糊 | 轻重分离 → 独立分账核算 |
| 人员结构老化、人效偏低 | 三项制度改革 → 市场化进出 |
| 薪酬平均化 | 差异化薪酬 + 增量利润提成 |

## 3. 总体改革实施逻辑

> **"先建店长负责制、再分轻重资产板块、同步落地三项制度改革"** — 递进实施路径

```
第一步：标准化职业店长管理体系搭建（前置基础）
   ↓
第二步：明确轻重资产经营主体、授权边界、差异化考核规则
   ↓
第三步：以独立运营单元完成轻重资产组织/人事/财务全维度分置
   ↓
第四步：打通"管理人员能上能下、员工能进能出、收入能增能减"完整机制
```

## 4. 核心实施举措（**4大模块**）

### 4.1 模块一：顶层设计组织架构

#### 4.1.1 轻资产平台 = **"大运营中心"**

| 维度 | 内容 |
|------|------|
| 性质 | 集团设立 + 联合下属轻资产管理公司组建 |
| 统筹范围 | 品牌建设、标准化运营、托管加盟、数字化营销、店长全周期管理 |
| 核心定位 | 店长选聘/委派/考核/薪酬/退出**唯一主体** |
| **不参与** | 重资产企业物业持有、改造、资产评估等资产管理工作 |

#### 4.1.2 重资产平台 = **下属子公司（独立法人）**

| 维度 | 内容 |
|------|------|
| 形态 | 自有物业酒店设立独立法人子公司 |
| 角色 | 国有资产运营实体 |
| 核心职责 | 不动产、设备管理、**资产保值**、物业改造运维 |
| 人事权 | 子公司董事长/总经理由**集团党委统一任免考核** |
| **班子不参与** | 门店经营、销售、加盟拓店等市场化业务 |

#### 4.1.3 两级经营权责清晰界定

| 角色 | 权责边界 |
|------|---------|
| **重资产子公司负责人** | **仅**统筹：物业管护 + 基建改造 + 资产估值 + 后勤保障 |
| | **不得干预**：客房、前厅、营销、收益管理等一线经营 |
| **轻资产平台店长** | 门店经营**第一责任人**，**全权负责**：出租率/营收利润/会员运营/OTA管理/人员绩效分配/营销落地 |
| | 独立签订**经营契约**，接受轻资产平台全周期考核 |

#### 4.1.4 财务独立分账

- **单店 = 独立核算单元**
- 重资产板块折旧、改造费用**单独列支**
- 门店营收、人力、营销费用**单独核算**
- 精准测算**轻资产真实盈利**
- 为差异化薪酬、增量激励提供**数据支撑**

---

### 4.2 模块二：店长负责制标准化制度

#### 4.2.1 分层分类市场化选聘（**双通道引才**）

| 通道 | 对象 | 路径 |
|------|------|------|
| 外部行业公开遴选 | 成熟职业店长 | 解决人才梯队断层问题 |
| 内部骨干竞聘 | 现有青年骨干 | 打通专业转管理晋升通道 |
| 动态后备店长库 | 储备人才 | 开设青年骨干专项培养计划 |

**任职资格差异化**：
- 重资产物业管理人员 vs 轻资产店长
- 两类岗位**任职资格分别设置**

#### 4.2.2 全周期契约化管理

| 要素 | 内容 |
|------|------|
| **协议形式** | 统一签订聘任协议 + 三年任期业绩责任书 |
| **考核指标分类** | 重资产岗位 = 资产保值/物业运维；轻资产店长 = 营收/出租率/会员/拓店/增量利润 |
| **下放经营权限** | 人员调配 + 绩效分配 + 小额营销费用审批 |
| **退出机制** | 年度考核不合格 / 任期评价不称职 → 依规**市场化退出** → 打破"干部能上不能下"壁垒 |

#### 4.2.3 市场化退出机制（**三类通道**）

1. 末位淘汰
2. 到期不续聘
3. 履职失责解聘

**配套制度**：
- 离任审计
- 竞业约束
- 人员分流制度
- 形成管理人才**良性流动循环**

---

### 4.3 模块三：以店长负责制牵引三项制度一体化改革

#### 4.3.1 人事制度改革（管理人员能上能下）

- 所有店长、区域运营负责人**竞争上岗**
- 搭建"**管理+专业**"双通道

| 通道 | 路径 |
|------|------|
| **管理序列** | 储备店长 → 门店店长 → 区域总监 |
| **专业序列** | 收益、OTA、品牌拓展、客户服务 |

- 店长考核机制延伸至**门店中层**
- 落实**末位调整、降职转岗、待岗培训**
- **破除身份固化**

#### 4.3.2 劳动用工改革（员工能进能出）

- 人力成本**总额管控**下，店长**自主开展**：
  - 全员绩效考核
  - 岗位优化
  - 末位分流
- 前台、客房、销售推行**固定合同+弹性灵活用工**
- 建立集团统筹、门店落地的**分层培训体系**

#### 4.3.3 薪酬分配改革（收入能增能减）

**差异化薪酬体系**：
- 向轻资产店长、核心运营岗倾斜
- 店长薪酬构成 = **基础工资 + 年度绩效 + 增量利润提成**
- **轻资产门店超额提成比例更高**
- **业绩升降直接联动薪酬**

**门店内部绩效分配权下放** → 杜绝平均主义

**专项激励**（针对轻资产拓店）：
- 拓店成效突出 → 专项奖励
- 项目分红
- 长效正向激励

## 5. 统筹保障（5大支撑）

### 5.1 党的全面领导
- 集团党委统筹改革全局
- 对**改革方案、店长制度、薪酬调整等重大事项**严格把关
- 基层党组织做好政策宣讲与职工思想引导
- **守住国有资产保值底线**

### 5.2 专项工作组织架构
- 成立**主要领导牵头、多业务部门参与**的三项制度改革暨轻重资产分离领导小组
- 明确部门分工
- 建立**定期调度、督办机制**
- 层层压实改革责任

### 5.3 政策宣讲与职工权益保障
- 职代会、专题座谈解读改革政策
- 落实**"三个区分开来"**（宽容改革创新失误）
- 依法保障**劳动合同、薪酬、分流安置权益**

### 5.4 监督风控体系
- 落实店长**年度、离任经济责任审计**
- 平衡**经营放权与国资管控**
- 建立**经营损失追责机制**
- 构建**事前规范、事中监管、事后问责**全链条风险防控体系
- **严防国有资产流失风险**

### 5.5 考核督办闭环
- 将**轻重资产分置进度、店长制度落地、三项制度改革成效**纳入门店负责人年度考核
- 设置**专项权重**
- 定期督办复盘
- 推进滞后主体**约谈扣分**
- 以考核倒逼改革落地
