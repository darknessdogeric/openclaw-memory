## 〇、关于本意见性质的说明

**各部门、各位同仁**:

《四川花园宾馆有限责任公司关于花园宾馆改造项目立项的请示》(川花园〔2026〕26号)已抄送本部门。

本部门作为集团内承担产业发展战略研究与子公司经营观察的职能部门,就立项请示中涉及**战略定位、客源结构、对标体系、功能布局、风险管控**等方向性问题,形成如下研判意见和建议。

**本意见性质说明**:

1. **本意见为产业发展部的研究意见** —— 仅供立项决策参考,各部门可在各自职权范围内独立判断
2. **本意见不替代各方的最终判断** —— 集团董事会、集团分管副总、花园宾馆公司均可在各自职权范围内独立决策
3. **本意见不替子公司做改造方案设计** —— 具体方案由花园宾馆公司结合实际情况制定
4. **本意见中的"建议"按方向性重要性排列** —— 战略级建议优先,执行级建议次之,参考建议再次

## 一、产业发展部对立项的整体判断

### 1.1 立项倾向:**倾向支持立项**

**理由**:

- 安全隐患解决具有紧迫性(消防系统使用 20 年、变压器使用 33 年)
- 经营亏损不可持续(2025 年 GOP 率 -8.9%,账面亏损 315 万元)
- 物业区位价值未充分实现(春熙路—太古里核心商圈)
- 项目符合集团"提质增效三年行动"总体方向

### 1.2 立项的更高期待

本部门同时认为,本项目**具备超出"单店扭亏"的战略价值**:

- **集团"中高端精选"赛道品牌化的可能起点** —— 花园宾馆物业稀缺,具备成为集团"中高端精选"旗舰样板店的潜力
- **春熙路商圈安逸系酒店分级分类的前置铺垫** —— 本项目改造经验可作为集团酒店分级分类的实践起点
- **AHL 战略协同的可能样板** —— 9 类客群 × 5 年龄段画像 + STR 标准对标法则,可与 AHL AI 客户画像系统对接

**建议**:如项目立项,建议在立项请示补充材料中体现上述"超出单店改造的战略价值",提升项目在集团层面的战略权重。

## 二、对立项请示内容的研究意见

### (一)战略级建议(优先关注)

#### 1. 核心定位建议:**"中高端精选有限服务"**

**立项请示现状**:定位为"中高端商旅主题酒店(携程四钻)"。

**本部门观察**:

- "中高端精选有限服务"(Select-Service)是中高端赛道的细分定位
- 与"中高端全服务酒店""中高端有限服务"在产品组合、服务标准、运营模式上均有显著差异
- 同档可参考品牌:亚朵 3.0、桔子水晶 3.0、美居、希尔顿欢朋、中旅睿景等

**建议**:在改造方案中明确"**中高端精选有限服务**"定位,并给出"精选"的具体落地标准(客房精选 / 服务精选 / 餐饮精选 / 文化精选 / 智能化精选等 3-5 项)。

#### 2. 战略目标建议:**集团品牌化起点 + 商圈分级分类前置铺垫**

**立项请示现状**:战略目标为"花园宾馆单店扭亏改造"。

**本部门观察**:

- 安逸集团旗下酒店超 167 家,品牌矩阵覆盖多个赛道,但**"中高端精选"赛道的旗舰品牌尚未明确确立**
- 春熙路商圈可能存在多家安逸旗下/相关酒店,**分级分类现状有待梳理**
- 花园宾馆物业区位稀缺(春熙路核心 + 33 年产权沉淀),具备品牌旗舰潜力

**建议**:

- 战略目标从"单店扭亏"升维为"**安逸集团中高端精选赛道品牌化起点**"
- 将本项目作为"**春熙路商圈安逸系酒店分级分类的前置铺垫**"
- 在改造方案中预留"**可复制、可输出、可作为集团分级分类标准**"的产品设计接口

#### 3. 同定位竞对调研建议:**不低于 5 家**

**立项请示现状**:列示 6 家竞品,但**仅深度分析 2 家(林恩国际酒店、春熙宾馆)**,且均为老旧单体酒店。

**本部门观察**:

- 立项请示的对标深度不足以支撑改造方案的产品/服务/价格定位
- "同定位"竞对应满足:同档次(中高端精选有限服务)+ 同区位(成都春熙路或同等城市核心商圈)+ 同物业类型(老酒店改造 / 单体酒店 / 200 间左右规模)+ 同客群(商旅 + 新媒体 + 会议 + 政务)

**建议调研的 5 家同定位竞对清单**:

| # | 竞对酒店 | 调研价值 |
|---|---------|---------|
| 1 | **成都太古里大慈寺亚朵酒店** | 同档次龙头(RevPAR ¥459 vs 花园宾馆 ¥103) |
| 2 | **中旅成都睿景酒店** | "中高端精选有限服务"直接对标 + 服务中岛模式 |
| 3 | **成都春熙路希尔顿欢朋酒店** | 同档出租率天花板(93%) |
| 4 | **成都春熙太古里漫心酒店** | 华住系中高端线 |
| 5 | **成都太古里春熙林恩国际酒店** | 老旧单体改造对标 |

**可选第 6-8 家**(作为对照参考):桔子水晶 / 美居 / 春熙宾馆。

**调研维度**:产品定位 / 核心产品 / 公共区域 / STR 运营指标 / 客源结构 / 改造投入 / 品牌矩阵 / 关键学习项(各至少 3 项可借鉴 + 3 项需避免)。

**调研成果建议**:**《同定位竞对深度调研报告》(不少于 50 页)**,含 5 家竞对横向对比表、SWOT 矩阵、差异化定位建议等。

#### 4. STR 标准对标法则建议:**建立 3 年目标路径**

**立项请示现状**:未引入 STR 标准对标法则,测算口径"IRR 15%"较为乐观。

**STR 法则简介**(国际通用酒店收益管理对标体系):

| 指数 | 公式 | 解读 |
|------|------|------|
| **MPI**(Market Penetration Index)市场渗透指数 | (本酒店入住率/竞争组平均入住率)×100 | >100 = 市场份额领先 |
| **ARI**(Average Rate Index)平均房价指数 | (本酒店 ADR/竞争组平均 ADR)×100 | >100 = 价格优势 |
| **RGI**(Revenue Generation Index)收入生成指数 | (本酒店 RevPAR/竞争组 RevPAR)×100 | **RGI ≈ MPI × ARI / 100** |

**以立项请示 2025 数据 vs 春熙路商圈同档竞品均值的测算**:

| 指数 | 2025 测算 | 解读 |
|------|-----------|------|
| MPI | **51** | 市场份额严重落后 |
| ARI | **63** | 价格严重落后 |
| **RGI** | **32** | **综合收入仅同业三分之一**(亏损根因之一) |

**建议**:

- 建立**STR 标准对标季度考核机制**(纳入花园宾馆公司总经理年度 KPI 参考)
- **3 年目标**:**RGI ≥ 100**(MPI ≥ 100 + ARI ≥ 100)
- 给出**改造后 3 年 STR 路径表**(2027 → 2028 → 2029 → 2030):
  - 改造当年(2027):RGI ≥ 50
  - 改造稳定年(2028):RGI ≥ 72
  - 改造目标年 1(2029):RGI ≥ 86
  - **改造目标年 2(2030):RGI ≥ 100 ✅**
  - 改造目标年 3(2031):RGI ≥ 113
- 路径表需配套**客源结构 / ADR 提升 / 产品升级 / 运营优化**四象限驱动措施

#### 5. 物业产权与报规报建建议:**取得锦江区规划局预沟通意见**

**立项请示现状**:副楼 1492.25 ㎡ 为办公用途、8F 棋牌室为搭建、自认"银行贷款途径存在较大不确定性"。

**本部门观察**:

- 副楼办公性质改造为客房涉及"改变建筑使用性质",**报规报建存在不确定性**
- 8F 棋牌室"搭建"为违建嫌疑,改造后保留需明确法律风险
- 方案二(组合借款)银行路径基本不可行(划拨用地 + 产权分散 + 副楼性质不符)

**建议**:

- **副楼 1492.25 ㎡ 报规报建预沟通意见**(2026 年 9 月底前取得锦江区规划局书面意见)
- **8F 棋牌室处理**:建议拆除或调整功能,而非"不做改动"
- **融资方案**:建议只走方案一(集团内部借款 3000 万元),方案二作为预案而非首选
- **改造工程**:建议放弃"白图"做法,确保合规

### (二)执行级建议(立项后深入论证)

#### 6. 客源结构建议:**按 9 类 × 5 年龄段细化**

**立项请示现状**:"协议(政务)60% / 散客30% / 其他10%"三分类,且无年龄段维度。

**建议客源细分标准**(9 类 × 5 年龄段):

**9 类客群**:

| # | 客群类型 | # | 客群类型 |
|---|---------|---|---------|
| 1 | 门散(到店无预约散客) | 6 | 商务会议团队 |
| 2 | 商务协议散客 | 7 | 政务会议团队 |
| 3 | 政务协议散客 | 8 | 旅行社团队 |
| 4 | OTA 散客 | 9 | **新媒体团队**(KOL/综艺/直播/网红打卡) |
| 5 | 会员散客 | | |

**5 个年龄段**:A1 00 后 / A2 95 后 / A3 85-94 后 / A4 75-84 后 / A5 65 后

**每类客群建议配六维画像**:占比目标 / 主要年龄段 / 客单价 / 主要渠道 / 复购率 / 对应功能区。

#### 7. 协议客源回流数据建议:**按三类分述**

**立项请示现状**:2025 年协议公司实际占比 44.89%,4 年间腰斩,改造后回流到 60% 的数据支撑缺失。

**建议分三类论证**:

- **商务协议散客**:存量企业协议清单 + 拟激活数量 + 回流率假设
- **政务协议散客**:省委组织部/省科技厅等存量政府客户清单 + 拟签新协议数量 + 回流率假设
- **政务会议团队**:剧院式会议厅 405 ㎡ 拟承接会议清单 + 政务接待协议

#### 8. 年龄层客群聚焦 → 功能定位布局建议

**建议**(年龄段 → 功能区映射示例):

| 年龄段 | 占比(估) | 对应功能区 |
|--------|---------|-----------|
| A1 00 后 + A2 95 后(35%) | 拍照/打卡/社交 | 顶层旗舰场景 + 1F 花艺商业 + 开放式卫浴拍照 + 屋顶酒吧 |
| A3 85-94 后(30%) | 商务效率/品质 | 商务会议设施 + 标准客房 + 简餐 + 健身房 |
| A4 75-84 后(20%) | 性价比/实用 | 传统客房(可选) + 中餐包间 + 茶坊 |
| A5 65 后(15%) | 政务/稳重 | 剧院式会议厅 + 高级套房 + 政务接待专区 |

## 三、关于改造方案设计的边界说明

### 3.1 本意见的原则

| 原则 | 内容 |
|------|------|
| **定位驱动** | 先定"中高端精选有限服务"定位,再定功能,再定设计 |
| **客源驱动** | 9 类客群 × 5 年龄段画像 → 功能区需求 → 设计落地 |
| **对标驱动** | ≥5 家同定位竞对调研 → 取长补短 → 差异化设计 |
| **STR 驱动** | 3 年 RGI ≥ 100 目标 → 客单价提升路径 → 产品/服务升级 |
| **品牌驱动** | 作为集团"中高端精选"品牌旗舰 → 可复制可输出 → 设计标准化 |

### 3.2 本意见不涉及的领域

以下内容**由花园宾馆公司结合实际情况自主决定**,本意见不替其设计:

- 具体改造金额、工程预算、单方造价
- 具体施工方案、工期节点、物料设备选型
- 具体运营方案、人员编制细节、营销执行细节
- 具体品牌视觉系统、空间设计方案

以上内容由花园宾馆公司委托设计单位、集团工程管理部、成本管理部、财务部、品牌管理部分别负责。

## 四、关于"5 家以上同定位竞对"调研的具体建议

### 4.1 调研方式建议

- **实地暗访**:每家竞对至少 2 晚住宿体验(以普通客人身份)

### 4.2 调研成果建议

形成**《同定位竞对深度调研报告》(不少于 50 页)**,含 §二.3 所列内容。

### 4.3 调研时限建议

**2026 年 9 月底前完成**,与立项补充论证同步推进。

## 七、产业发展部对若干关联事项的观察

### 7.1 立项请示中已具备较好基础的方面

- **项目必要性论证**(安全隐患 / 经营亏损 / 物业价值):基础扎实
- **工期计划**(2027 年 6 月 1 日开业):节点合理
- **人员安置方案**(全员考核上岗,核定 78 人):思路清晰

### 8.2 STR 标准对标法则简表(供参考)

```
MPI(Market Penetration Index) = (本酒店入住率 / 竞争组平均入住率) × 100
ARI(Average Rate Index) = (本酒店 ADR / 竞争组平均 ADR) × 100
RGI(Revenue Generation Index) = (本酒店 RevPAR / 竞争组 RevPAR) × 100
数学关系:RGI ≈ MPI × ARI / 100
目标参考:RGI ≥ 100(MPI ≥ 100 + ARI ≥ 100)
```
