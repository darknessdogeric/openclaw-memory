# 政策雷达体系 v2.0 · 设计说明

> **一句话定位**：把"国家—省—市—21市州"四级文旅政策的**十五五方向**与**资金支持**，做成一张可月度更新、可随时巡览、可复制到其他省份的雷达网。

---

## 一、为什么要升级（v1.1 → v2.0）

| 维度 | v1.1（2026-08-16） | v2.0（本版） |
|------|-------------------|-------------|
| 核心目的 | 抓**补贴申报**线索 | **政策校准战略** + 争取资金（双轨） |
| 政策类型 | 偏资金/奖补类 | **十五五规划纲要 + 专项规划 + 年度任务 + 资金 + 试点** |

| 更新节奏 | 周报（未持续） | **月度节拍（自动化）** |
| 复用性 | 未范式化 | **范式内核：可复制到其他省/地区** |
| 呈现 | 文档 | **三视图（全景图/机会清单/跟踪台账）+ 巡览入口** |

**v1.1 保留资产**：5层站点、关键词清单、监控源清单、申报画像、关系图谱、AHL政策Agent模块定位。

## 二、体系内核：四层 × 双轨 × 三视图

```
┌─────────────────────────────────────────────────────────────┐
│                    政策雷达 v2.0                            │
├─────────────────────────────────────────────────────────────┤
│  四层雷达网（空间维度）                                       │
│  L1 国家   → 国务院/文旅部/发改委/财政部/商务部/体育总局        │
│  L2 省级   → 四川省/省文旅厅/省发改委/省财政厅                  │
│  L3 市级   → 成都市/市文广旅局/市发改委                         │
│  L4 市州   → 21个（5大经济区）                                 │
├─────────────────────────────────────────────────────────────┤
│  双轨内容（性质维度）                                          │
│  轨A 战略校准轨：十五五规划纲要·专项规划·政府工作报告·重点任务   │
│      → 回答"我们做的事，政策支不支持？"                         │
│  轨B 资源争取轨：财政资金·补贴·试点·示范·荣誉·项目清单          │
│      → 回答"政策给的钱和牌子，我们能不能拿？"                    │
├─────────────────────────────────────────────────────────────┤
│  三视图（呈现维度）                                            │
│  ① 全景图：四级政策一张图（十五五方向 + 资金）                   │
│  ② 机会清单：可争取项 × 责任主体 × 窗口期 × 金额                │
│  ③ 跟踪台账：在申报/待申报/已获得                              │
└─────────────────────────────────────────────────────────────┘
```

## 四、月度更新机制（自动化）

### 4.1 节拍

```
每月 1 日    雷达扫描（四级政策新增/修订/失效）
每月 3 日    机会清单更新（可争取项 + 窗口期提醒）
每月 5 日    月度政策简报（推送 + 入库）
每季度末     范式校准（方法论迭代 + 复用评估）
```

### 4.2 触发方式

- **automation（本系统调度器）**：月度定时任务，扫描 → 生成简报 → 入库
- **变动预警**：窗口期临近（申报截止前 7 天）主动提醒
- **人工补充**：Eric / 蒋抒伶随时投喂政策文件 → 自动归档入四级库

### 4.3 检视巡览入口

- `00_政策雷达总览.md`（一页看全四级 + 本月变动）
- `05_周报月报/`（历史简报留痕）
- KB 检索（关键词：政策/十五五/申报/资金）

## 五、范式内核：可复制到其他省/地区

### 5.1 复制的三步

```
第一步【定层级】   按目标地区行政层级建 L1-L4 骨架
第二步【定源】     填充各级文旅主管机关官网 + 政策发布平台
第三步【定节拍】   挂载月度自动化 + 三视图模板
```

### 5.2 可复制性设计

| 设计点 | 如何做到"换省即用" |
|--------|------------------|
| 目录结构 | 层级命名通用（L1国家/L2省级/L3省会/L4市州），不写省名 |
| 采集字段 | 统一模板，与地区无关 |
| 关键词清单 | 分"通用词"+"地方词"两层，通用词跨省复用 |
| 监控源 | 按"类型"（省级文旅厅/市级文广旅局/发改委）而非具体机构名 |
| 自动化 | 调度脚本参数化（省份 + 市州清单可配置） |

**目标复用对象**：云南、重庆、贵州、陕西（西南文旅竞争省）→ 支撑集团"标准输出"战略。
