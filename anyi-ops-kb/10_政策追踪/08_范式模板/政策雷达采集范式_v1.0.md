# 政策雷达采集范式 v1.0（换省即用）

> **一句话**：把"某省四级文旅政策"变成"可巡览、可月度更新、可争取资金"的雷达网，且换一个省只需换参数、不换方法。

---

## 一、范式三要素（换省只需改这三处）

```
① 层级骨架   → 固定不变（L1国家 / L2省级 / L3省会+都市圈 / L4地市州）
② 采集字段   → 固定不变（14 字段模板，见第三节）
③ 参数配置   → 换省时改：省份名 + 地市州清单 + 各级主管机关官网
```

**核心洞察**：政策雷达的"结构"是通用的，"源"是地方的。复制时**只换源，不换结构**。

---

## 二、层级骨架（通用）

| 层级 | 定义 | 典型主管机关（类型化，换省即映射） |
|------|------|--------------------------------|
| **L1 国家** | 中央部委 | 国务院 / 文旅部 / 发改委 / 财政部 / 商务部 / 体育总局 |
| **L2 省级** | 省（自治区/直辖市） | 省人民政府 / 省文旅厅 / 省发改委 / 省财政厅 |
| **L3 省会** | 省会城市 / 都市圈核心 | 市政府 / 市文广旅局 / 市发改委 |
| **L4 地市州** | 下辖全部地级行政单元 | 各市州政府 / 文旅局 / 发改委 |
| **L5 招标采购** | 项目级（可选） | 公共资源交易中心 / 政府采购网 |

## 三、采集字段模板（14 字段 · 通用）

| # | 字段 | 说明 |
|---|------|------|
| 1 | 政策名称 / 文号 | 全称 + 官方文号 |
| 2 | 层级 | L1/L2/L3/L4 |
| 3 | 发布机关 | 具体部门 |
| 4 | 发布时间 / 生效 / 失效 | 时效管理 |
| 5 | 政策类型 | 规划纲要 / 专项规划 / 年度任务 / 资金 / 试点 / 荣誉 |
| 6 | **核心方向（原文摘录）** | 与酒店/文旅相关的关键表述 |
| 7 | **资金 / 支持** | 有无、额度、形式（奖补/贴息/以奖代补/基金/要素） |
| 8 | 申报条件 | 门槛（体量/资质/所有制/地域） |
| 9 | 申报窗口期 | 时间节点 |
| 10 | 对标动作 | 我方（酒店集团）可做什么 |
| 11 | 关联项目 | 具体项目挂钩 |
| 12 | 来源链接 | URL（可追溯） |
| 13 | 数据等级 | 🟢官方 / 🟡媒体 / 🔴估算 |
| 14 | 采集时间 | 月度版本标记 |

## 四、更新机制（通用）

```
每月 1 日   雷达扫描（四级新增/修订/失效）
每月 3 日   机会清单刷新（可争取项 + 窗口期）
每月 5 日   月度简报（推送 + 入库）
每季末      范式校准（方法迭代 + 复用评估）
```

**变动预警**：申报截止前 7 天主动提醒。
**人工汇入**：随时投喂政策文件 → 自动归档入对应层级。

## 六、复制到新省的操作步骤（SOP）

```
Step 1  建目录
        L1_国家 / L2_<省> / L3_<省会> / L4_市州（按该省经济区/地市清单）
Step 2  定源
        填充：省文旅厅官网 + 省发改委 + 省财政厅 + 各市州文旅局官网
        （用"类型"检索，而非记具体网址）
Step 3  采数据
        按 14 字段模板，逐层采集十五五政策
Step 4  挂节拍
        复用月度自动化脚本，替换"省份参数"
Step 5  出视图
        复用全景图 / 机会清单 / 简报模板
Step 6  交叉比对
        新省政策 × 已建省政策 → 找"政策洼地"与"竞争态势"
```

**预计工时**：新省从零到"可巡览"约 2-3 天（含人工核验）。

## 八、战略延伸（为什么值得范式化）

1. **对内**：集团跨省扩张（如云南/重庆）时，政策雷达可**即时铺开**，降低异地试错成本。
2. **对外**：政策雷达本身可作为 **AHL 平台的"政策 Agent"** 产品，向同业输出（订阅制）。
3. **对战略**：政策"洼地"识别 → 指导"轻重分离"中轻资产落点的选择。
