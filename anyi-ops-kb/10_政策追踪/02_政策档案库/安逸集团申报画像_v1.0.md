## 五、申报方向(13 类 · 按金额预期排序)

| **国企改革专项** | 国资委 | 国企身份 | 🟢 高 |

## 七、关系图谱定位

```
省级: 文旅厅 / 财政厅 / 国资委 / 发改委
   ↓ (省级专项)
市级: 成都市文旅局 / 财政局 / 国资委 / 发改委 + 各区
   ↓ (市级 + 区级配套)
市州: 16 个市州文旅局 / 财政局
   ↓ (属地化 + 振兴专项)
协会: 四川省旅游协会 / 酒店用品协会 / 文化创意协会
   ↓ (行业资源 + 项目推荐)
关系人: 各厅局对接人 + 集团内部(集团-文旅厅对口部门)
```
