## 七、关系建设方法(给蒋抒伶的 SOP)

### 7.1 首次接触 SOP

```
1. 通过协会 / 同行 / 老领导介绍 → 拿到联系方式
2. 蒋抒伶 第一次电话/微信:自我介绍 + 询问诉求
3. 蒋抒伶 第一次拜访:送集团资料 + 了解部门重点工作
4. Eric 第二次拜访:提出具体合作 + 邀请来访
5. 季度复盘:送项目成果 + 维系关系
```

### 7.2 拜访前准备清单(每次)

- [ ] 集团近期动态 1 页(无废话)
- [ ] 拜访对象的公开发言 / 文章(读过)
- [ ] 1-2 个具体合作提案
- [ ] 时间控制:Eric 拜访 ≤ 60 分钟,蒋抒伶 ≤ 30 分钟

### 7.3 拜访后 SOP

- [ ] 24h 内发感谢微信
- [ ] 一周内发拜访纪要(用 anyi-ops-kb/meetings/ 模板)
- [ ] 关键承诺 30 天内兑现
- [ ] 季度复盘:发节日祝福 + 邀请出席活动
