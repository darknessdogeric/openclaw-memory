## 一、四档节奏(实时 / 日 / 周 / 月)

### 1.1 实时触发 (7×24)

| 触发条件 | 响应动作 | SLA |
|----------|----------|-----|
| TrendRadar 命中一级关键词 + 四级资金词 | **红色预警推送** | 1h 内 |

| 周末窗口预警 | MD | Eric 个人微信 |

**日报模板**:

## 三、决策树(从信号到申报)

```
信号捕获 (TrendRadar / Web Fetch / 关系人)
   ↓
Q1: 金额是否 ≥ 50 万?
   ├─ 否 → 归档 (P3)
   └─ 是 ↓
Q2: 国企 / 安逸画像是否可申报?
   ├─ 否 → 归档(但记录"未来资格培育点")
   └─ 是 ↓
Q3: 申报截止 ≤ 7 天?
   ├─ 是 → P0 红色推送 + 立即启动
   └─ 否 ↓
Q4: 金额是否 ≥ 100 万 + 截止 ≤ 30 天?
   ├─ 是 → P1 橙色推送 + Eric 拍板
   └─ 否 → P2 黄色收录 + 周报重点
   ↓
Eric 拍板(投入产出 / 战略匹配 / 关系可达)
   ├─ 申报 → 立项 → 03_申报跟踪/
   └─ 不申报 → 归档 + 备注
```

## 四、触发器配置(写入 TrendRadar / 通知系统)

### 4.1 TrendRadar 关键词触发规则

```
[P0 红色] 集团级关键词 + 资金词 OR 金额 ≥ 1000 万
[P1 橙色] 集团级 / 市级关键词 + 资金词
[P2 黄色] 赛道关键词 + 资金词
[P3 绿色] 全部其他命中
```

### 4.2 Web Fetch 触发规则

```
L1-L3 站点: 实时抓取(每 6h)
L4 市州站点: 每日抓取(8:00)
L5 招标: 实时抓取(每 4h)
L6 行业: 每日抓取(8:00)
```

### 4.3 Tavily 搜索触发规则

```
手动触发(政策名称核实 / 申报指南查询)
自动触发(每日 1 次全网搜索 "四川省+文旅+补贴"+ 当前日期)
```
