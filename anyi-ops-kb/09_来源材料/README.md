## 四、B166ER 工作原则（R264 协议强化）

### 1. 不再创建同名 KB
- 不再创建 `anyi-ops-kb/` 同名或类似名称的文件夹
- 所有新安逸工作统一进入 `anyi-ops-kb/`

### 2. 不复制外部原始文件
- 不将 `Desktop/安逸相关文件/` 任何文件复制到 anyi-ops-kb
- 不将 `Desktop/安逸集团_入职物料_20260707/` 任何文件复制到 anyi-ops-kb
- 引用通过路径指针

### 3. 不修改 AnYi-KB 旧 KB
- 旧 KB 自 7/30 起停止更新
- 任何修改需求 → 先迁入新 KB，再在旧 KB 标注"已迁移"
- 旧 KB 不删除（保留作为历史快照）

### 4. 不在 Desktop 文件夹写入任何 B166ER 产出
- Eric 的 Desktop 是 Eric 个人工作区
- B166ER 产出统一进入 `anyi-ops-kb/`

### 5. 来源材料变更追踪
- Eric 添加新文件到 Desktop → 在 `09_来源材料/` 对应指针文件中追加新文件索引
- Eric 修改 AnYi-KB 旧 KB 文件 → 不修改，但通过对比发现差异时记录

## 六、维护时间表

### 日常维护
- 每次 B166ER 输出引用外部来源 → 在对应指针文件追加记录
- 每次 Eric 修改/添加外部文件夹 → 在对应指针文件更新
