## 三、双跑纪律（三条，硬性）

1. **判「不存在 / 未证实 / 已失效」之前，桌面与 KB 必须都查过。** 只查 KB 得出的「查无此件」不成立 —— 11-06 桌面扫描正是靠这一条抓出「抖音后台授权已完成」（KB grep 零命中但原件在桌面）。
2. **台账（量化清单 / 工作汇报）是进度事实源，评审意见是判断。** 两者冲突时以原件为准；口径冲突要显性化，不要择一。
3. **引用 KB 结论必须带副本与日期**〔主副本·目录·日期〕；引用桌面原件必须带路径与 mtime。无标注的引用视为不可采信。
