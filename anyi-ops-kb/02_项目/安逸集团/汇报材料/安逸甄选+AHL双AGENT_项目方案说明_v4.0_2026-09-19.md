# 第一章 这是什么——AHL 不是 SaaS，是范式革命者

## 1.1 一句话定位

**AHL 是四川省国资文旅行业首个 AI 垂系 Agent 平台。**

它做的事情只有一件：**让客人用 AI 直接找到对的商家，让商家用 AI 直接找到对的客人**——中间不抽水，不抽佣，不囤数据。

## 1.2 它解决什么问题

客人今天找酒店、找景区、找特产、找餐厅的路径：

```
现状：
  客人 → 打开 OTA 平台 → 搜索 → 比价 → 看评价 → 选 → 下单 → 钱到平台 → 平台抽 10-15% → 剩 85-90% 到商家

AHL 模式：
  客人 → 对 AI 说出需求 → AI 直接匹配 → 客人下单 → 钱 100% 到商家 → 平台收 TOKEN 计量费（≈电费）
```

**0% 佣金**。客人付的钱 100% 到商家。平台只收一笔按"握手次数"算的"电表费"。

## 1.3 为什么是"现在"

集团十五五规划修订稿明确指出：

> "数字化建设处于起步阶段，中央预订率和直销占比远低于行业头部水平。标准化运营体系尚未建立……'十五五'期间必须以能力建设为重心。"

**核心判断**：AHL 解决的正是集团最薄弱的两个能力——**数字化与标准化运营**。这正是 1244 战略"4 大战略行动"中"行动四·数智品牌赋能行动"的核心技术抓手。

- 零售 · 特产 ← **安逸甄选在这里**

**关键洞察**：B 矩阵**不只服务于酒店**——而是面向**整个吃住行游购娱**的所有实体。这是 AHL 不同于其他酒店 AI 工具的核心。

## 3.3 TOKEN 经济——类比电表电网

```
TOKEN 就是 Agent 经济的「电费」
AHL 是那块标准化电表

类比电费：电网不靠卖电赚差价，只按度计量
TOKEN 不靠抽佣赚差价，只按握手次数计量

每次握手（C Agent 与 B Agent 对话）消耗 TOKEN
所有 TOKEN 经 AHL 协议层标准化记账流转

## 5.2 第一步：MVP——从最小切入口开始

**为什么从酒店 + 安逸甄选开始？5 条判断标准**：

```
1. 可控性     集团直营 / 控股 · 数据可直接对接

3. 可推广     跑通后扩展到其他业态
4. 资源现成   旅投系场景 + 商投系供给已就位

```

```

客户 3 项：差评响应 48h→30min / OTA 依赖 -5~10pct / 私域会员 +5 万

**双闸门机制**：6 个月末达标率 ≥60% / 12 个月末 ≥70%——不达标就减速，不硬撑。
