# 第一章 这是什么——AHL 不是 SaaS，是范式革命者

## 1.1 一句话定位

**AHL 是四川省国资文旅行业首个 AI 垂系 Agent 平台。**

它做的事情只有一件：**让客人用 AI 直接找到对的商家，让商家用 AI 直接找到对的客人**——中间不抽水，不抽佣，不囤数据。

## 1.2 它解决什么问题

客人今天找酒店、找景区、找特产、找餐厅的路径：

```
现状：
  客人 → 打开 OTA 平台 → 搜索 → 比价 → 看评价 → 选 → 下单 → 钱到平台 → 平台抽 10-15% → 剩 85-90% 到商家

AHL 模式：
  客人 → 对 AI 说出需求 → AI 直接匹配 → 客人下单 → 钱 100% 到商家 → 平台收 TOKEN 计量费（≈电费）
```

**0% 佣金**。客人付的钱 100% 到商家。平台只收一笔按"握手次数"算的"电表费"。

## 1.3 为什么是"现在"

集团十五五规划修订稿明确指出：

> "数字化建设处于起步阶段，中央预订率和直销占比远低于行业头部水平。标准化运营体系尚未建立……'十五五'期间必须以能力建设为重心。"

AHL 解决的正是集团最薄弱的两个能力——**数字化与标准化运营**。这是 1244 战略"4 大战略行动"中"行动四·数智品牌赋能行动"的核心技术抓手。

# 第三章 引入外部力量来运作 ⭐ 深化

## 3.1 为什么需要外部力量

集团现状（Gap Analysis 06 - 数字化与技术）：

```
短板：
  - 192 万中标的运营中台是自研还是基于成熟 SaaS？任后向集团信息部核实
  - AI 在酒店运营中的具体应用（收益管理 / 智能客服 / 智能客房）未公开
  - 完整数字化转型 Roadmap 未公开
  - 中央预订率目标 35%（华住 50%+、万豪 50%+）
  - 自研技术团队规模未公开（华住技术中心 1000+ 人）
```

**集团无法自建 AHL 的原因**：

```
1. 专业能力不足：AHL 需要 AI 工程师 / 算法工程师 / 大模型训练能力
   → 集团 200+ 项酒店业务已满负荷
2. 时间窗口紧：AHL 范式革命窗口期 5-7 年（2025-2031）
   → 自建团队需 1-2 年筹备，错过窗口期
3. 试错成本高：AI 模型训练需大量数据 + 行业 Know-how
   → 内部试错将浪费 6-12 个月最佳时间
```

**结论**：AHL 必须走"**自研治理 + 外部运作**"双轨模式。

# 第六章 它怎么落地——三步走 + 同构分形

## 6.1 同构分形架构

```
LEVEL 01 · 单店（最小 MVP）

LEVEL 03 · 四川省文旅体系（最终愿景）
  全产业也是完整闭环：跨业态握手 · 全产业链 TOKEN

小到单店，大到四川文商旅 —— 同一种解法
```

## 6.2 第一步：MVP——从最小切入口开始

**为什么从酒店 + 安逸甄选开始？5 条判断标准**：

```
1. 可控性     集团直营 / 控股 · 数据可直接对接
2. 可验证     验证 ROI 模型与 TOKEN 流转
3. 可推广     跑通后扩展到其他业态
4. 资源现成   旅投系场景 + 商投系供给已就位
5. 政策合规   不涉及外部主体复杂合规
```

**MVP 选型**：

```
酒店（场景）：60 余家管理酒店（含自营 + 受托）
安逸甄选（商品）：与商投集团联合（双集团合作方案已落地）

→ 最小闭环：酒店（场景）+ 安逸甄选（商品）
```

**8 项 KPI 闸门**：

```
效率 2 项：数据收集 2h→10min / 报表 人工→自动
业绩 3 项：OCC +5% / RevPAR +5% / ADR +3%
客户 3 项：差评响应 48h→30min / OTA 依赖 -5~10pct / 私域会员 +5 万
```

**双闸门机制**：6 个月末达标率 ≥60% / 12 个月末 ≥70%——不达标就减速，不硬撑。

## 6.3 第二步：旅投系多业态（2028/1-2030/12）

