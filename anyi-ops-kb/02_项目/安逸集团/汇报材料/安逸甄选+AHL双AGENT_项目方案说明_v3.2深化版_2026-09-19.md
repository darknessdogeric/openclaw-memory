# 第一章 这是什么——AHL 不是 SaaS，是范式革命者

## 1.1 一句话定位

**AHL 是四川省国资文旅行业首个 AI 垂系 Agent 平台。**

它做的事情只有一件：**让客人用 AI 直接找到对的商家，让商家用 AI 直接找到对的客人**——中间不抽水，不抽佣，不囤数据。

## 1.2 它解决什么问题

客人今天找酒店、找景区、找特产、找餐厅的路径：

```
现状：
  客人 → 打开 OTA 平台 → 搜索 → 比价 → 看评价 → 选 → 下单 → 钱到平台 → 平台抽 10-15% → 剩 85-90% 到商家

AHL 模式：
  客人 → 对 AI 说出需求 → AI 直接匹配 → 客人下单 → 钱 100% 到商家 → 平台收 TOKEN 计量费（≈电费）
```

**0% 佣金**。客人付的钱 100% 到商家。平台只收一笔按"握手次数"算的"电表费"。

# 第二章 业态纵深——酒店/景区/车船舟马怎么用 AI 匹配客人 ⭐ 深化

## 2.1 核心原则：商家的"持续特点输出 + 运营提升"是核心

集团"十五五"规划修订稿明确指出：

> "无文化不溢价，但文化必须转化为产品体验。消费者对差异化体验的需求持续增长，具有在地文化特色的酒店产品可以获得显著溢价。但纯粹的概念叙事无法支撑定价权，文化必须系统融入空间设计、服务流程和产品细节，成为可被消费者真实感知的体验内容。"

**AHL 的核心使命（深化）**：
- 不是"做营销"——而是"**让每个商家的运营特点被 AI 持续识别 + 持续输出 + 持续提升**"
- 商家不需要"会做营销"——AI Agent 自动把商家的特点"翻译"给对的客人
- 商家持续做好自己的事（房间清洁 / 菜品质量 / 景区维护 / 列车服务），AI 自动讲故事

## 2.2 酒店业态：72 个 SKILLs 持续输出

酒店是"住"的载体。AI Agent 要把酒店的"特点"持续识别出来——**不是 1 次性的营销文案，而是每天持续的特点输出**。

```
酒店运营特点（被 AI 持续识别）              持续输出给客人

1. 房间特色
   ├─ 房间面积 18㎡ vs 竞品 25㎡ → 客人画像是"商旅 1 晚"
   ├─ 卫生间 3㎡ vs 竞品 5㎡ → 自动匹配"对面积不敏感"客群
   └─ 早餐品种 8 vs 竞品 15 → 自动推荐"不重餐"客群

2. 服务特色
   ├─ 退房 30 秒 vs 竞品 5 分钟 → 突出"效率优先"
   ├─ 行李员 24 小时 vs 竞品 仅日间 → 突出"凌晨到达"
   └─ 洗衣 1 小时 vs 竞品 24 小时 → 突出"商旅 1 晚+洗衣"

3. 周边特色
   ├─ 距地铁 200 米 → 自动推荐"无车商旅"
   ├─ 距商圈 800 米 → 自动推荐"出差+购物"
   └─ 距机场 30 分钟 → 自动推荐"晚班机"

4. 文化特色
   ├─ 金牛宾馆的国宴级餐饮 → 突出"蜀味文化"
   ├─ 锦江宾馆近 70 年川菜 → 突出"川菜文化"
   └─ 安逸巴蜀文化定位 → 突出"巴蜀文化"
```

**AHL 的能力**：每天自动识别酒店 P0-P3 运营特点 + 自动翻译成客人语言 + 自动精准匹配 + 72 个 SKILLs 持续优化。

## 2.3 景区业态：4 大线路 + 营地驿站

集团旅投系有 20+ 个自然山域型景区：

```
核心布局（旅投系景区资源）：
```

## 2.4 车船舟马业态：未来大空间 ⭐ 深化

**这是 Eric 16:56 特别强调的**：车船舟马是商投系+旅投系共同缺失的环节，但四川旅游资源非常丰富：

```
车船舟马业态的 4 大子类：
  ├─ 列车：锦绣天府号（"安逸号"熊猫专列，2024 年开行 24 趟，营收 5619 万，上座率 96.85%）
  ├─ 自驾：租车 / 房车 / 自驾营地（318 / 317 黄金线）
  ├─ 船：嘉陵江 / 长江三峡 / 岷江 / 大渡河水上旅游
  └─ 马：高原牧场骑马 / 草原营地骑马 / 文化体验
```

**AHL 对车船舟马的支持**：

| 业态 | 运营特点 | AI 持续识别 + 输出 |
|------|---------|------------------|
| **列车（锦绣天府号）** | 24 趟/年、5619 万营收、96.85% 上座率 | 自动按沿途景区推荐 + 沿途特产组合包 |
| **自驾** | 318 黄金线自驾营地 | 自动按车型 + 经验 + 沿途推荐 |
| **船** | 嘉陵江 / 三峡 / 大渡河 | 自动按季节 + 水位 + 客群推荐 |
| **马** | 高原骑马 / 草原营地 | 自动按季节 + 体格 + 经验推荐 |

**关键洞察**：车船舟马是 **"住 + 游" 之间的连接器**——客人不可能只住酒店不移动，也不可能只去景区不流动。AHL 通过车船舟马业态把"住"和"游"**真正串联起来**，形成完整旅程。

## 2.5 业态互导：每家商家都是其他业态的入口

AHL 的核心价值不仅是"商家 + 客人匹配"——更是**"业态互导"**。

```
客人在「住」环节发现新需求：
  ├─ 住安逸酒店 → Guest Agent 推荐九寨沟门票
  ├─ 住安逸酒店 → Guest Agent 推荐沿途餐饮
  ├─ 住安逸酒店 → Guest Agent 推荐下一晚酒店（不同品牌）
  └─ 住安逸酒店 → Guest Agent 推荐返程列车（锦绣天府号）

客人在「游」环节发现新需求：
  ├─ 逛九寨沟 → Guest Agent 推荐沿途川菜
  ├─ 逛泸定桥 → Guest Agent 推荐当晚住宿
  └─ 逛孟获城营地 → Guest Agent 推荐返程租车

客人在「行」环节发现新需求：
  ├─ 乘锦绣天府号 → Guest Agent 推荐沿途景区
  ├─ 乘锦绣天府号 → Guest Agent 推荐沿途美食
  └─ 乘锦绣天府号 → Guest Agent 推荐返程酒店
```

**AHL 跨业态跨商家的本质**：让每一家酒店、每一个景区、每一列列车都成为其他业态的"自然流量入口"——而不是孤立运营。

# 第三章 商贸大类——安逸臻选如何通过 AHL 结合到文旅场景 ⭐ 深化

## 3.1 商贸大类的定位

集团"十五五"规划 1244 战略中"4 大业务支柱"是**酒店运营 / 酒店资产 / 中央集采 / 特色餐饮**——这些都是**内部业务**。

但**安逸臻选**是 **外部商贸**——是**与商投集团联合的"商品销售"业务**。

```
安逸集团（重资产 + 内部业务）        商投集团（轻资产 + 外部商贸）
├─ 酒店运营                          ├─ 红旗连锁（4,000+ 门店）
├─ 酒店资产                          ├─ 曙光汇（760 万会员）
├─ 中央集采                          ├─ 天府菜油（70 亿品牌）
├─ 特色餐饮                          ├─ 糖酒公司（茅台/五粮液/郎酒）
└─ AHL（数字化赋能）                  └─ 供应链（30 万亩土地 / 130 万主体）

                    ↓ 联合 ↓

                    安逸臻选
                    （商贸大类）
                    ├─ 四川特色农产品
                    ├─ 文旅文创
                    └─ 旅行消费品
                    通过 AHL 嵌入文旅场景
```

**关键理解**：**安逸臻选不是"安逸集团的项目"**——是**"安逸集团 + 商投集团联合的商贸业务"**。AHL 是把双方联合的"商品"嵌入到"安逸 + 旅投的文旅场景"中的**技术连接器**。

## 3.2 商投的"商品力" + 旅投的"场景力" = 商贸大类

```
商投"商品力"（已有 30 万亩土地流转 / 130 万主体服务 / 数千 SKU）：
  ├─ 天府菜油（70 亿品牌价值）
  ├─ 红旗连锁 4,000+ 门店
  ├─ 曙光汇 760 万会员（央行支付牌照）
  ├─ 糖酒公司（茅台 / 五粮液 / 郎酒 经销）
  └─ 三文鱼（2 架波音 777-8F 法罗群岛直采）
  └─ 商投供应商池（200+ 头部供应商）

旅投"场景力"（已有 100+ 酒店 + 20+ 景区 + 5 旅行社 + 300 万会员）：
  ├─ 60 余家酒店（自营+受托）
  ├─ 20+ 自然山域景区（318 / 317 / 雅西 / 羊卓雍措）

联合 → 安逸甄选：
  - 商投提供"商品"（低成本 + 高品质）
  - 旅投提供"场景"（高客流 + 高复购）

```

## 3.3 安逸臻选通过 AHL 嵌入文旅场景的 5 种方式

**方式 1：扫码即入口**
```
客人入住安逸酒店
  → 房间内"安逸甄选"二维码
  → 扫码 → 看到"商品故事 + 景区介绍 + 旅游攻略 + 属地文化 + 复购入口"
  → 客人 AI 自动判断"这个客人对什么感兴趣"
  → 推荐"这个商品 / 这个景区 / 这家餐厅"
  → 客人扫"红包免填地址" → 下单 → 商品直接寄回客人家

```

```
  客人逛九寨沟 → Guest Agent 推荐返程沿途酒店
  → 客人预订 → 酒店通过 AHL 支付流通 TOKEN 给景区
  → 双方双赢

场景 3：住 → 行
  客人住安逸酒店 → Guest Agent 推荐锦绣天府号下一班
  → 客人购票 → 列车通过 AHL 支付流通 TOKEN 给酒店
  → 双方双赢

场景 4：行 → 住
  客人乘锦绣天府号 → Guest Agent 推荐抵达成都后酒店
  → 客人预订 → 酒店通过 AHL 支付流通 TOKEN 给列车
  → 双方双赢

场景 5：住 → 购

  → 客人扫码 → 商品通过 AHL 直达客户家
  → 酒店获引流分成，安逸甄选获新客

场景 6：购 → 复购
```

```
  - 文化 IP 的新挖掘
```

**第二层：AI 自动识别**
```
AHL Host Agent 持续监控：
  ├─ 客户评价（OTA + 自有渠道）
  ├─ 客诉工单
  ├─ 销售数据
  ├─ 入住/到访/购票数据
  └─ 员工反馈
自动发现"这个酒店最近的服务特色变了" → 翻译给客人
```

**第三层：客人反馈**
```
客人 AI Agent 持续学习：
  ├─ 客人对什么感兴趣（停留时长、点击率、购买率）
  ├─ 客人的痛点（差评、客服投诉）
  └─ 客人的推荐（朋友推荐、口碑传播）
```

# 第十一章 它需要注意什么——合规与红线

## 11.1 五条合规底线

| 底线 | 内容 | 应对 |
|------|------|------|
| 🔴 不成立新公司（试点期）| AHL 不另设法人 | 产业发展部下设 AHL 项目组 |

| 🔴 TOKEN 不融资 / 不上市 / 不进金融交易所 | 严守"虚拟货币监管"红线 | TOKEN 仅在生态内流通 |
| 🟡 不主动提"安逸集团"营销 | 公开宣传弱化安逸身份 | 试点用"垂系 Agent 行业研究"等中性词 |
| 🟢 数据与关联交易合规 | 严格按《数据安全法》《个人信息保护法》| 集团法务部介入 |

## 11.2 商投系供应链合规边界

| 合作方 | 可合作范围 | 红线 |
|--------|---------|------|
| 红旗连锁 | 商品供货 + 物流合作 | 不在安逸旗下酒店直接开店 |
| 曙光汇 | 会员体系互通 | 不持有安逸客户数据 |
| 天府菜油 | 商品采购 | 不参与安逸直营运营 |
| 糖酒公司 | 酒水联营 | 不与安逸旗下酒店发生直接商业关系 |

## 11.3 三重一大合规路径

```
第一步（重大投资决策）：安逸集团董事会 → 安逸酒店集团发文
第二步（跨集团）：旅投集团董事会 → 四川省旅游投资集团发文
第三步（省级）：省政府专题会议 → 四川省政府发文
```

## 11.4 v3.2 特别强调：安逸臻选商贸合作的合规性

```
问题：安逸集团与商投集团联合做"安逸甄选"是否合规？

合规边界：
  - 不成立新公司：联合公司阶段再设
  - 不以干部身份做商业：商投系商家直接对接集团
  - 关联交易：需要集团法务部介入 + 公开透明定价
  - 资金结算：经第三方（如银联/支付宝）分账

合规操作：
  - 商品采购：按市场化定价
  - 销售分成：基于 TOKEN 消耗和效果
  - 数据归属：归安逸集团
  - 资金归集：经合规通道
```
