# 第一章 战略定位——从产品项目到省级入口

## 1.1 时代背景

每一次范式革命都伴随信息分发方式的根本性变化：

```
1990s    Web 1.0  信息找人    存活 15 年
2000s    Web 2.0  人找信息    存活 10 年
2010s    移动互联网  中心化入口  存活 5 年
2020s+   AI 时代    Agent 协议  正在压缩
```

**核心洞察**：2024 年 LLM 元年之后，**住宿业 + 文旅业**的"AI 范式革命"窗口期约 **5-7 年**。错过这一窗口，2028 年后被市场淘汰的概率大幅提升。

## 1.2 从"安逸甄选项目"到"省级文旅入口"的跃迁

```
v1.0 思路：安逸甄选（新零售项目）+ AHL（AI 工具）
            ↓ Eric 15:28 指示
v2.0 思路：把 AHL 架构推向吃住行游购娱一体化
        → 安逸甄选是切入点之一
        → 酒店、景区、线路、产品、业态都是网络节点
        → 用现有旅投资源（场景）+ 商投资源（供给）搭建省级 AI 入口
```

**本质命题**：不是做一个"新零售项目"，而是建一个**省级文旅 AI 入口**——安逸甄选、安逸酒店、未来景区/餐饮/线路等，都是这个入口的第一个客户和第一个场景。

## 1.3 范式跃迁——从货架经济到 TOKEN 经济

### 三种经济的对比

```
1. 货架 SHELF
   位置 = 流量
   抽水者：房东 / 平台
2. 匹配 MATCH
   算法 = 撮合
   抽水者：OTA · 抽佣 10–15%
3. 直接 DIRECT
   协议 = 握手
   抽水者：无 · 0% 佣金
4. TOKEN 算力 = 价值
   计量：每一次握手
```

**两种经济的本质差异**：

| 维度 | 货架经济 · OTA 时代 | TOKEN 经济 · AHL 时代 |
|------|------------------|------------------|
| 交易路径 | 客人 → 平台货架 → 商家 | 客人 ⇄ 商家 · Agent 直接握手 |
| 平台角色 | 抽水者 · 抽佣 10–15% | 计量者 · 只收 TOKEN 费 |
| 数据归属 | 沉淀在平台 · 跨店孤岛 | 归属商家 · 回流喂养模型 |
| 客户关系 | 客户归属平台 | 客户归属商家 |
| **抽水比例** | **10-15%** | **0%**（客人付的钱 100% 到达商家）|

**关键洞察**：客人付的钱 **100% 到达商家**；平台收入 = TOKEN 计量费 + 限时技术服务费。**交易规模越大，平台越不需要碰交易本身**。

# 第五章 TOKEN 经济循环——核心商业模型

## 5.1 TOKEN 经济循环全景

```
1 · 握手
   C Agent 与 B Agent 直接对话 · 消耗 TOKEN

2 · 计量
   AHL 协议层标准化计费 · 按算力计价

3 · 流转
   TOKEN 流向算力与服务方 · 收益归属

4 · 喂养
   数据回流反哺 Agent 进化 · 精度提升
```

**每一次循环同时完成三件事**：
- 计费变现
- 数据喂养
- AI 迭代

**客人互动越频繁 → 握手越多 → TOKEN 流转越快 → 模型越准。**

## 5.2 平台「三不」原则（合规底线）

```
不抽佣       交易 100% 直达商家
不卖流量     位置不再是商品
不占客户     客户与数据归商家
```

**类比电费**：电网不靠卖电赚差价，只按度计量。**TOKEN 就是 Agent 经济的「电费」，AHL 是那块标准化电表**。

## 5.3 双轨制收费 + 远期纯 TOKEN 费

| 轨道 | 当前（2026/9-2028/6）| 中期（2028/6-2030/6）| 远期（2030/6+）|
|------|---------------------|---------------------|-----------------|
| **订阅费** | 70% | 40% | **0%** |
| **TOKEN 费** | 30% | 60% | **100%** |
| **技术服务费** | 限时收取 | 到期归零 | 无 |

**关键创新**：
- 扫码红包免填地址（**流失率减半**）
- 扫码即传播（**客户成为分销节点**）
- 扫码 = 入口（产品介绍 + 游玩攻略 + 属地文化 + 复购入口）

## 9.3 AI 版的"有价值"

| 价值层 | 传统 | AI 版 |
|--------|------|------|
| 产品价值 | 一件商品 | 商品 + 故事 + 文化 + 攻略 |
| 服务价值 | 销售员介绍 | AI 7×24 个性化推荐 |
| 情感价值 | 纪念品 | 专属回忆 + 复购入口 |

# 第十二章 风险与退出

## 12.1 四类风险矩阵

| 风险类型 | 概率 | 影响 | 应对策略 |
|---------|------|------|---------|

| 第三步市州利益博弈 | 高 | 高 | 省级标准 + 政府背书 |
| 关键人才流失 | 中 | 高 | 股权激励 + 事业平台 |

## 12.2 三步退出与降级机制

```
MVP 失败（6 个月末）：
  达标率 < 60% → 削减阶段 1 预算 50%
  达标率 < 70% → 暂缓第二步

第二步失败：
  跨业态转化 < 5% → 暂缓全面覆盖
  旅投董事会可随时终止

第三步失败：
  省级试点失败 → 转为"集团内自用"，不强行全省推广
```
