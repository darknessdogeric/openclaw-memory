# 第三章 痛点与目标——"安逸甄选"的 AI 重构

## 3.1 文旅特产消费四大断点

客人在四川待了五天，在特产上花的钱，可能不到一顿饭的价钱。

```
看见 → 信任 → 挑选 → 带走 → 复购
   ↓       ↓       ↓       ↓       ↓
 不敢买   不知道买什么  不便寄   难复购
```

| 断点 | 现状 | 客户损失 |
|------|------|---------|
| **不敢买** | 缺统一品牌与可信背书，担心价格虚高、品质参差 | 临门一脚被按下去 |
| **不知道买什么** | 全省好物分散各市州，无成体系场景导购 | 选择困难放弃购买 |
| **不便寄** | 大件小件都得自己拎 | 复购率 15-20%（OTA）vs 华住 83% |
| **难复购** | 离店后无回访入口 | 一次成交即结束 |

## 3.2 "好传好玩"在 AI 架构下的实现逻辑

| 命题 | 传统实现 | AI 实现（AHL 重构）|
|------|---------|---------------------|
| **好玩** | 集齐抽奖（线下玩法）| Guest Agent 个性化推荐 + 集齐抽奖 + 实时玩法 |
| **好传** | 平安喜乐礼物红包 | 扫码红包免填地址 + 裂变推荐 + UGC 触发 |
| **有价值** | 二维码扫产品介绍 | 扫码 = 入口：产品介绍 + 游玩攻略 + 属地文化 + 复购入口 |

**关键创新：扫码红包免填地址**

```
传统流程：扫码 → 填地址 → 犹豫 → 放弃（流失率 50%+）
AI 流程 ：扫码 → 自动填地址（已实名）→ 直接下单（流失率减半）
```

**预计减少一半以上消费流失**——这是「安逸甄选」AI 重构后最大的转化率提升。

## 3.3 终极目标

```
客人 AI 匹配 → 直达产品 → 付费直达商家
        ↓              ↓           ↓
    客户数据归属     产品可追溯    商家可复购
        ↓              ↓           ↓
       三头在外变三头在内：客户关系 / 定价权 / 数据归属
```

# 第五章 TOKEN 经济循环——核心章节

## 5.1 TOKEN 定性声明

> **TOKEN = 集团统一的 AI 服务计量与结算单位**
> **1 TOKEN = 1 元服务额度（锚定法币）**
> **不上链 · 不公开发行 · 不可交易炒作**
> **仅在合作协议框架内记账流转**

**合规底线**：
- ❌ 不向公众发行 TOKEN
- ❌ 不融资
- ❌ 不进入金融交易所
- ❌ 不流向自然人交易

| **远期** | 36 月+（2030/6+）| **0%** | **100%** | **纯 TOKEN 费 = 纯词元费用** |

**Eric 远景**：未来可能就是纯 TOKEN 也就是词元费用。

**这意味着**：
```
远期模式：客户按需调用 → 按 TOKEN 消耗付费 → 无固定订阅门槛
好处：低门槛接入 → 客户粘性 → 网络效应 → 数据厚度
风险：TOKEN 价格波动 → 需锚定法币控制
```
