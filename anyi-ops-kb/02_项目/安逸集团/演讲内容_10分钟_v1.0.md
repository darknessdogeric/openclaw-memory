**讲稿（110 字）**

### 第 3 页｜痛点：四个断层（70 秒）

**PPT 呈现**

```
从"看见"到"复购"的路上，客人走了四次

01 不敢买　　景区与途中商品缺统一品牌与可信背书，
　　　　　　担心价格虚高、品质参差、真伪难辨

02 不知道买什么　全省好物分散各市州，缺成体系的场景导购

03 不方便　　买完难以便捷寄递，大件小件都要自己拎

04 难复购　　离店后没有回访入口，一次成交就结束
```

**讲稿（270 字）**

我先把问题讲透。

第一个断层是"不敢买"。景区的特产店、途中的服务区，缺少统一品牌和可信背书。客人担心三件事：价格是不是虚高、品质是不是参差、真伪是不是难辨。购买冲动往往在临门一脚被按下去。

第二个断层是"不知道买什么"。全省好物分散在各个市州，商品种类繁多，但没有成体系的场景导购。客人想带点本地特色，反而无从下手。

第三个断层是"不方便"。买完以后难以便捷寄递，大件小件都得自己拎着走。

第四个断层是"难复购"。离店之后没有回访入口，一次成交就结束了，复购无从谈起。

四个断层叠加的结果是：客人在四川待了五天，在特产上花的钱，可能不到一顿饭的价钱。

### 第 4 页｜破局：从卖商品到做机制（45 秒）

**PPT 呈现**

```
把产品重新打造，让产品好玩、好传、有价值

好玩　　用"集齐抽奖"思维做产品组合
　　　　（参考七个葫芦娃、熊猫家庭等爆款逻辑）

好传　　用"平安喜乐"等礼物红包模式，让产品自带传播属性

有价值　线下产品加二维码，扫码看产品介绍、游玩攻略、
　　　　景区介绍、属地文化

再往前一步：连锁化经营
　　统一模式 · 统一选品 · 统一品质 · 统一门店形象
```

**讲稿（170 字）**

破局的思路是把产品重新打造，做三件事。

第一，让产品更好玩。用"集齐抽奖"的思维做产品组合，参考近期爆火的七个葫芦娃、熊猫家庭这类逻辑，把单件商品变成系列化的收集品。

第二，让产品好传播。用"平安喜乐"这类礼物红包的模式，让产品自身带传播属性。

第三，让产品更有价值。线下产品加二维码，扫码可以看产品介绍、游玩攻略、景区介绍、属地文化，把一件商品变成一个入口。

在此之上再往前一步，是做连锁化经营：统一模式、统一选品、统一品质、统一门店形象，做成一个可复制的连锁品牌。

### 第 7 页｜总纲：一主线两抓手三安全线（40 秒）

**PPT 呈现**

```
一条主线

```

**讲稿（130 字）**

整体框架是一条主线、两个抓手、三道安全线。

一条主线，是以旅投、商投两家集团协同为主轴，把文旅场景优势和商贸供应链优势拧成一股绳。

两个抓手。第一个是做强供应链，用统一的选品、准入与晋级机制组织货源，让商品稳定、优质、可持续地供得上。第二个是打造新消费场景，把门店体验、内容传播和线上线下互动串成闭环，让游客看得见、尝得到、带得走。

三道安全线是商品品质、物流履约和资金结算，贯穿业务全程。

### 第 8 页｜供应链：30 进 10 留 3（60 秒）

**PPT 呈现**

```
把分散货源，组织成可控可复购的供应链

01 统一供给池　　各市州、行业协会与供应商的产品汇入推荐池，
　　　　　　　　经资质、检测、授权与标签审核进入白名单

02 数据晋级　　　30 个候选 → 10 个重点做陈列与内容测试
　　　　　　　　→ 3 个复购与贡献可验证的种子商品

03 三层货盘　　　高动销常温品　店内现货
　　　　　　　　展示型商品　　样品扫码＋区域仓发
　　　　　　　　长尾短保商品　线上下单＋产地直发

04 动态退出　　　无订单、低复购、触投诉红线或供货失稳的商品
　　　　　　　　按时效退出，货架留给真正被市场接受的产品
```

**讲稿（170 字）**

供应链怎么组织？四步。

第一步，统一供给池。各市州、行业协会与供应商的产品先汇入推荐池，再经资质、检测、授权与标签审核进入白名单。

第二步，数据晋级。从三十个候选商品里跑出十个重点，做陈列与内容测试；再从十个里沉淀出三个复购与贡献可验证的种子商品。用真实订单决定商品去留，而不是靠关系。

第三步，三层货盘。高动销的常温品做店内现货；展示型商品只放样品，客人扫码后从区域仓发；长尾短保商品只做线上下单、产地直发。这样门店库存压力最小，品类覆盖最全。

第四步，动态退出。无订单、低复购、触碰投诉红线或者供货不稳的商品，按时效退出，让货架始终留给真正被市场接受的产品。

### 第 9 页｜场景：一店四用（60 秒）

**PPT 呈现**

```
门店不是特产超市，而是体验、内容与交付前台

一店四用
　主题展示先吸引 → 品鉴成交建立信任
　→ 内容直播向外扩散 → 扫码寄递以轻库存完成交付

一次到店走完"看、尝、买、寄、复购"
　每一步都能识别来源，把体验转化为可归因的真实订单

双码体系
　一店一码　记录门店与活动
　一品一码　挂上资质与故事

归因规则：以扫码后 30 天为归因窗口
　　　　　让离店后的复购仍能回溯到门店与场景
```

**讲稿（170 字）**

场景怎么做？核心是改变门店的定位。门店不是特产超市，而是体验、内容与交付的前台。

一店四用：主题展示先把人吸引进来，品鉴成交建立信任，内容直播向外扩散，扫码寄递用轻库存完成交付。

客人在一次到店里，走完"看、尝、买、寄、复购"五个动作。每一步都能识别来源，把体验自然转化为可归因的真实订单。

配套是双码体系。一店一码，记录门店与活动；一品一码，挂上资质与故事。物流和复购走同一入口，签收净单再纳入归因。

建议归因窗口设为扫码后三十天，这样客人离店之后的复购，仍然能回溯到具体门店和场景，用内容持续激活会员复购。

### 第 10 页｜安全线一：品质（40 秒）

**PPT 呈现**

```
以可核验的规则兜住品质，而非口头承诺

进入前 · 授权与主体核验
　供应商提交经营资质、品牌授权与来源说明
　产地与主体先核验，杜绝来路不明的产品
　食品与文创重点品类分层设定准入清单

上架前 · 检测与标签规范
　重点品类送第三方检测
　标签、保质期与宣称用语统一规范
　临期与短保商品明确处理规则

出售后 · 全程追溯与追责
　每批商品来源可查、去向可追、责任可究
　质量投诉即触发红线，问题商品快速下架、召回、追责
```

**讲稿（130 字）**

安全线第一条是品质。做法是用可核验的规则兜住品质，而不是靠口头承诺。

进入前，供应商必须提交经营资质、品牌授权与来源说明，产地和主体先经核验，食品与文创重点品类还要分层设定准入清单。

上架前，重点品类送第三方检测，标签、保质期与宣称用语统一规范，临期与短保商品明确处理规则，不合格或信息不全的商品不上架。

出售后，每批商品做到来源可查、去向可追、责任可究。质量投诉即触发红线，问题商品按机制快速下架、召回并追责，形成品质闭环。

### 第 11 页｜安全线二三：物流与结算（40 秒）

**PPT 呈现**

```
物流可托付，结算分账清

安全线二 · 物流履约有标准
　按品类匹配仓配方案，常温与生鲜分线履约
　明确发货时效、妥投标准与区域配送责任
　破损、丢件、错发设清晰赔付与售后 SLA
　签收后以净单口径核算，退货退款可冲销归因

安全线三 · 结算分账分得清
　分客群、分交易主体、分账核算
　订单、退款与结算同账追踪、口径统一
　成本、税费、账期口径一致，资金占用可视可控
　靠真实签收与经营质量验收，不靠账期堆积和补贴制造繁荣
```

**讲稿（130 字）**

安全线第二条是物流。按品类匹配仓配方案，常温与生鲜分线履约，明确发货时效、妥投标准和区域配送责任。破损、丢件、错发都设清晰的赔付与售后标准。签收后以净单口径核算，退货退款可冲销归因。

安全线第三条是结算。各类业务分客群、分交易主体、分账核算，订单、退款与结算同账追踪、口径统一。成本和税费账期口径一致，资金占用可视可控。

一句话概括这两条线：靠真实签收和经营质量验收，不靠账期堆积和补贴数据制造表面繁荣。
