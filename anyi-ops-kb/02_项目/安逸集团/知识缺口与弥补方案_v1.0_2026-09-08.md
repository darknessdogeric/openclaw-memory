## 一、文章 7 个关键信号

### 信号 1：**"十五五"规划纲要将"盘活存量"纳入重要原则**

> "十五五"规划纲要将盘活存量纳入经济社会发展必须遵循的重要原则

- **意义**：这是 H2 2026 → 2027 政策主线
- **对安逸**：6 大酒店改造 = 天然的"盘活存量"标杆项目，应该主动对接政策
- **窗口期**：2026 H2 + 2027 全年

### 信号 2：**"立园满园"——四川省"产业园区提质增效"专项**

- 四川省"立园满园" = 清理低效闲置产业用地
- 安逸集团酒店物业 = 天然的"低效资产"（部分物业老旧）
- **机会**：安逸可作为"省旅投旗下盘活存量示范单位"

### 信号 3：**创新金融工具盘活存量**

> 要用好用活政策工具，准确把握政策要求，善于运用创新金融工具盘活存量资产

- **REITs** = 创新金融工具的核心
- 华安锦江 21 家（6 月获批） = 四川省首单酒店 REIT
- **建议**：6 大酒店可分批 REIT 化（总府皇冠 / 新良 / 国堰）

### 信号 4：**撮合交易、价值发现——平台化思维**

> 推动平台功能从"信息展示"向"撮合交易、价值发现"延伸

- **价值**：构建酒店资产交易平台（不是单一公司，而是"撮合者"）
- **机会**：安逸集团可作为"西部酒店资产交易平台"运营方

### 信号 5：**数据体系——类型全覆盖、标准全统一、内容可共享**

- 完整的数据中台 = AI/数字化机会
- 已有：**酒店之家 MSI/PCI/HCI 体系** + **STR 全球基准** + **浩华 HTL 调研**
- **建议**：安逸集团可作为"西南区域酒店数据中台"试点

### 信号 6：**规范化、市场化、专业化——9 字方针**

- 规范化 = 合规（党委会 / 三重一大 / 国资监管）
- 市场化 = 退出机制（REITs / 转让 / 资产证券化）
- 专业化 = 头部酒店集团经验（华住/锦江/首旅/亚朵）

### 信号 7：**市级协调机制 + 工作专班——长期机制**

- 成都市级协调机制 = 直接对接窗口
- **建议**：安逸集团主动申请加入"市盘活存量工作专班"
