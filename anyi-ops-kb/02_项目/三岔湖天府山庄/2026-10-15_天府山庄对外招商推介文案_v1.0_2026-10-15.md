# 成都东部新区 · 三岔湖天府山庄

## 国家级湖岛文旅资产 · 寻战略合作方

**主推语**：**"在世运会赛场旁，88.8 亩湖心岛群，邀您共启下一个成都文旅封面项目。"**

> 一份由四川省旅投集团 100% 控股的稀缺湖岛文旅资产，承载"东进战略 + 世运遗产 + 成渝双城"三重政策红利。
> 我们不接受单纯的财务投资者 —— 我们寻找**有内容运营能力、有产业资源、有品牌势能**的战略合作方，共建"东进第一文旅品牌"。

---

## 一、一句话定位

> **天府山庄 = 三岔湖 88.8 亩 3 岛湖心岛群 + 6,354.99 ㎡ 现有建筑 + 双世运 + 双机场区位。** 是成都东部新区目前**唯一尚未规模开发的湖心岛型文旅资产**。

**关键判断**：项目位于"成渝双城经济圈"和"成都东进战略"双战略交汇处，是成都"东进"轴线上的"东进第一文旅岛"。

### 2. 资源 — 三岔湖核心湖区 3 岛

- **三岔湖**：成都平原最大的人工湖，**水面 27 平方公里** (≈ 杭州西湖 4 倍)
- **水质长期保持 Ⅱ 类标准**，可游泳、垂钓、皮划艇
- **水域开阔、水流平缓、水位稳定** — 适合水上运动全业态
- **周边有桃花岛、马鞍山、世运会赛场** (金熊猫 + EWAVE 已运营)

### 3. 政策 — 4 重红利叠加

## 三、合作模式（3 选 1，可组合）

> 我们**不强求单一大体量投资**, 接受"小切口切入 + 渐进放大"模式, 也接受"整岛开发"。

### 模式 A：水上运动 + 研学基地 (推荐, 启动快)

| 项 | 内容 |
|---|------|
| 标的 | 107 号岛 (37,951.25 ㎡) 或 6/7 号半岛 |
| 投资 | 对方出资码头 + 基础设施小配套 (200-500 万级) |
| 运营 | **对方获得运营权**, 安逸提供场地 + 品牌背书 |
| 收益 | 经营分成模式 (70:30 偏运营方起步) |
| 时间 | **1-3 个月可启动** |
| 关键合规 | 微投资 (不超 60 万) 不触发东部新区过会; 跳过成都总规等待 |
| 案例 | 三岔湖已投运: **金熊猫奥飞** (蔡劲秋, 皮划艇/桨板/赛艇) + **EWAVE** (尾波冲浪) |

**目标客户**：水上运动俱乐部 / 体育旅游公司 / 研学营地

### 模式 B：精品酒店 + 文旅综合体 (中体量, 中期)

| 项 | 内容 |
|---|------|
| 标的 | 6/7 号岛半岛 + 主楼 (5,122.99 ㎡) |
| 投资 | 1-2 亿 (中高端酒店改造 + 文旅配套) |
| 模式 | 合资公司 / ROT 改造运营 / 品牌联营 |
| 关键 | 需 60 万以上改造审批 (东部新区过会 + 等成都总规落地) |
| 时间 | 1-2 年 |
| 关键卖点 | 世运会 IP + 双世界遗产 (都江堰/青城山) 联动 |

**目标客户**：锦江/华住/中旅/丽呈等头部酒店集团

### 模式 C：整体收购 / 资产重组 (大体量, 长期)

| 项 | 内容 |

| 标的 | 3 岛全部 (88.8 亩 + 6,354.99 ㎡) |

1. **湖心岛唯一性** — 三岔湖 27 平方公里水域中, 6/7/107 号岛是**仅有的 3 块整岛资源**, 其他皆为半岛或岸线

3. **东进战略第一站** — 成都"东进"轴线最近的整岛文旅资产, 错过无补
4. **集团级背书** — 四川省旅投集团 100% 控股, 安逸酒店集团统一运营, 品牌 + 流量 + 资源 三重赋能
