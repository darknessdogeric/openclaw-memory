# 一句话定位

> **天府山庄 = 成都东部新区三岔湖 88.8 亩 3 岛湖心岛群 + 世运会水上项目赛场 + 双世界遗产联动。**
> **我们提议：成都体育学院 + 成都东部集团 + 安逸酒店集团 三方共建 "水上运动产业基地"，分近/中/远三阶段推进，最终形成"国际户外运动康养产业园区"远期愿景。**

## 一、为什么是现在 — 3 重战略机遇叠加

### 1.1 世运会遗产（2025 短期窗口）

- **2025 世运会水上项目赛场所在地** (动力冲浪板/索道滑水/尾波冲浪/尾波滑水)
- 三岔湖已投运 2 家水上运动中心: **金熊猫奥飞** (蔡劲秋, 600 ㎡ 码头+500 ㎡ 艇库) + **EWAVE** (尾波冲浪)
- **世运遗产 = 流量 + 设施 + IP 三重资产** — 但**"赛事结束后如何持续运营"是当前最大空白**

### 1.2 东进战略（中长期红利）

- 成都"东进"轴线核心区, 天府奥体公园"体教融合 + 体育消费"整体布局
- 东部集团花 **2 亿元** 现金从省上买下三岔湖**水面运营权** — 基础设施已就位
- 国家推动"高质量户外运动目的地"建设 (成都+雅安首批**近 1 亿**补贴)

### 1.3 体院搬迁（人才窗口）

- **成都体育学院东部新区校区 2026 启用** — 与本项目直线距离 **约 2 公里**
- 体院"水上运动"方向筹建中 (继教学院 + 运动休闲学院 + 运动训练学院 + 运动医学健康学院)
- 体院 12 个培养单位, 教练员/会议培训需求稳定 (年规模 100+ 团)

**三窗口叠加 = 项目"动起来"的最佳时点**。错过 = 等下一个世运周期 (4 年) + 体院新校区磨合期 (3-5 年) + 东进政策窗口 (2-3 年)。

## 二、项目核心 — 3 岛 88.8 亩湖心岛群

> (此处预留项目区位图 / 航拍图 / 平面图)

### 2.1 区位

- **三岔湖 6 号岛 + 7 号岛 + 107 号岛**, 简阳市三岔湖
- 距成都 **50 公里** / 距天府机场 **8 公里** / 距东部新区核心区 20 公里
- 3 岛位于三岔湖**湖心**位置 — **视野开阔、安静独立、湖景第一排**

### 2.2 资源

- **三岔湖**: 水面 **27 平方公里** (≈ 杭州西湖 4 倍), 水质 **Ⅱ 类**, 水流平缓
- **1500 米 × 200 米 训练水域** (龙舟国家队标准)
- **半岛 50+ 亩** 适合码头/艇库/办公
- 周边联动: 都江堰/青城山双世界遗产 + 桃花岛/马鞍山世运赛场 + 简阳城区

### 2.3 现状

- **资产**: 88.8 亩国有建设用地 + 6,354.99 ㎡ 现有建筑 (5,122.99 ㎡ 有产权证, 1,232 ㎡ 构筑物)
- **权属**: 2024 年完成作价出资, 100% 国有, 集团 100% 控股
- **状态**: 2022 年起停业, 2024 年完成国有化合规
- **历史**: 原省人大办公厅培训中心 (1980 建筑, 2017-2020 装修)

## 三、合作框架 — 3 方 × 3 阶段

### 3.1 三方主体

| 方 | 角色 | 核心资源 |
|---|------|----------|
| **安逸酒店集团** (省旅投 100% 控股) | **资产方 + 运营托管方** | 88.8 亩 + 6,354.99 ㎡ + 安逸品牌 + 56 家酒店导流 |
| **成都体育学院** | **教学 + 人才 + 赛事方** | 师资 + 课程 + 12 个培养单位 + 龙舟冠军队 + 水上运动方向筹建中 |
| **成都东部集团** (远期参与) | **政策 + 市政配套 + 产业资金方** | 东进战略落地 + 简阳/东部新区协调 + 2 亿买下的水面运营权 |

### 3.2 三阶段渐进

> **核心逻辑：先用体院"已有家底"小切口启动 → 用运营方能力放大 → 远期拉东部集团做大项目**

| 阶段 | 时间 | 抓手 | 输出 |
|------|------|------|------|
| **近期 (立刻可做)** | 2026 Q4 | 体院**继续教育学院** 牵头 — 承接教练员培训/小型会议培训 (年规模 100+ 团) | 盘活闲置资产, 解决"用起来"政绩观 |
| **中期 (1-3 年)** | 2027-2029 | 体院**二级学院**办"水上运动方向" + **龙舟/皮划艇/桨板** 已开课课程 | 形成稳定培训规模, 培养师资 |
| **远期 (十五五)** | 2030+ | 体院**教务处**申报"**水上运动本科专业**" + 东部集团拉入 148.8 亩二期 | 系统化本科人才培养基地, 国际户外运动康养产业园 |

> (此处预留三方合作架构图 / 阶段推进甘特图)

### 3.3 远期愿景 — 国际户外运动康养产业园区

- **一期**: 天府山庄 88.8 亩 (盘活)
- **二期**: 体院新校区旁 **148.8 亩** 闲置商业用地 (原成都文旅集团撤退)
- **园区分工**:
  - 运动休闲 + 经管学院 → **户外运动**板块
  - 运动医学健康学院 + 附属体育医院 → **运动医养康养**板块
- **总愿景**: "**国际户外运动康养产业园区**" (运动度假主题) — 5-10 年成型

## 四、各方角色定位 (4 大原则)

### 4.1 原则 1: 各方做自己擅长的事

| 方 | 做 | 不做 |
|---|----|------|
| 安逸 | 资产盘活 + 酒店商业配套 + 品牌赋能 + 文旅客源导入 | 教学 + 师资培养 + 赛事运营 |
| 体院 | 教学 + 课程研发 + 师资派驻 + 赛事 IP 导入 + 学生实习 | 资产改造 + 商业运营 |
| 东部集团 | 政策落地 + 市政配套 (供水/排污/码头) + 产业资金 | 教学 + 商业运营 |

### 4.2 原则 2: 品牌保留

- **保留"安逸"主品牌** (不强制改变酒店品牌)
- **联名挂牌** "成都体育学院 + 安逸酒店集团 教学实践基地"
- 不引入外来连锁品牌 (不挂丽呈/全季等)

### 4.3 原则 3: 资产稳定

- 资产权属 **不发生转移** (仍属省旅投/安逸集团)
- 改造权 + 运营权 **可以分阶段授权**
- 合同期 2-3 年起, **可续可退**

### 4.4 原则 4: 风险共担

- 微投资 ≤ 60 万 — 不触发东部新区过会审批
- 试错周期 6-12 个月 — 6 个月 KPI 不达 → 自动终止, 关闭接口
- 退出机制明确 — 客史数据归还, 安逸保留基础设施所有权

- 6 个月 KPI 复盘: 客流/营收/课程/赛事 — 决定是否扩到中期

## 六、战略意义 (对各方)

### 6.1 对成都体育学院

- **"近水楼台"**: 校区距水域 2 公里, 全国体育院校少有的**湖心岛型水上运动基地**
- **学科建设**: 水上运动方向筹建 + 远期本科专业申报 — 差异化竞争力
- **赛事 IP**: 已有龙舟国家队基础 (全国第三 + 中华龙舟冠军), 可孵化自有赛事品牌

### 6.2 对安逸酒店集团

- **"盘活资产"**: 解决 88.8 亩 / 6,354.99 ㎡ 闲置问题, 避免"十五五"资产处置退出
- **"品牌延伸"**: 从"酒店"延伸到"水上运动产业基地" — 第二增长曲线
- **"政企协同"**: 与体院 + 东部集团 建立长期战略合作, 接入体教融合大生态
- **"远期"**: 148.8 亩二期 = 国际户外运动康养产业园 = 集团 56 家中**唯一**的湖心岛型旗舰

### 6.3 对成都东部集团

- **"世运遗产盘活"**: 三岔湖已投 2 亿买水面, 缺的是"内容", 本项目=内容补位
- **"东进战略具象化"**: 天府奥体公园"体教融合 + 体育消费"整体布局=本项目
- **"政策示范"**: 校地企三方合作=成都"东进"战略的样板工程
- **"远期"**: 148.8 亩二期 + 简阳/东部新区协调 = 区域产业升级

### 6.4 对四川省 / 甘孜阿坝凉山联动

- 海螺沟冰川 / 达古冰川 / 稻城亚丁 — 可与天府山庄形成"**成都近郊 + 川西高原**"双 IP 矩阵
- 体育+旅游+文化+康养=四川省"文旅+百业"战略落地
