## 二之二、计价口径变更：按客房计价（11-16 15:58 Eric）

费用口径由“按设备台数与逐项合价”改为**按单房计价**，便于与门店沟通与分摊。

**单房综合单价构成**（附件1 第六章）

| 费用构成 | 计算方式 | 单房单价（元/间） |
|---|---|---|
| 设备购置 | 设备含税单价 ÷ 单台覆盖客房数（按适用档位） | 约100—150 |
| 上门安装调试 | 1,800元/店 ÷ 该店实际客房数 | 约5—18 |
| 短信认证套餐（首年） | 0.05元/条 × 每间夜认证次数 × 年入住率 | 约13 |
| **首期综合单价** | 以上三项合计 | **约130—170** |
| 次年起服务费 | 服务费单价 ÷ 单台覆盖客房数 | 约15—23 |

**分档价目与覆盖规模**：小规格（小型单体，约60间覆盖）10,000元/台、服务费1,500；标准规格（中型，约150间）19,800、3,000；增强规格（较大型，约275间）29,800、4,500；高并发规格（大型，约400间）59,800、9,000。

**预估**：试点5店 首期约 **13—17万元**、次年约 **1.5—2.3万元/年**、五年约 **19—28万元**；全域在营56家（约1万间）首期约 **130—170万元**、次年约 **15—23万元/年**、五年约 **190—260万元**。

**分摊**：按各店实际客房数 × 适用档位对应单房单价，分摊明细（店别客房数、适用档位、单房单价、分摊金额）作为合同附件。

## 二之三、按《招标及采购管理办法（2026年修订）》修订（11-17）

依据文件：川旅投发〔2026〕147号《四川省旅游投资集团有限责任公司招标及采购管理办法（2026年修订）》（扫描件，44页，经OCR提取条款）。

### 办法要点（与本项目直接相关）

| 条款 | 要点 |
|---|---|
| 第六条 | 指定"数字旅投"平台为招标采购线上管理平台，办理报批与报备 |
| 第十四条 | 招标限额：服务类单项50万元以上须公开招标；生产经营货物类100万元；行政办公货物类50万元；工程类（施工400万／设备材料200万／服务100万）。达限额可用邀请招标（4种情形） |
| 第十五条/第十六条 | 限额以下可询比采购／竞价采购（需求清晰、标准化程度高、潜在供应商不少于3家；竞价以价格竞争为主） |
| 第十七条 | 谈判采购：技术复杂需谈判确定方案；需求明确但有多种实施方案；符合资格条件供应商仅2家；联合研发原创 |
| 第十八条 | 直接采购8种情形（含第五项有效供应商仅1家、第七项集团下属全资控股企业主业范围内可提供） |
| 第十九条 | 单项5万元以下货物／服务：向不少于3家合格供应商询价比价、形成书面比价记录，完成招采立项后可直接实施；同一标的不得拆分规避 |
| 第二十一条 | 招采立项方案内容：项目概况、选择的采购方式及原因、控制价设定依据（市场询价记录／历史采购数据／成本分析报告／第三方专业意见之一）；总部审批权限：10万以下报总经理、10万以上20万以下报董事长、工程类及达"两会一层"权责清单限额按总部决策程序 |
| 第二十二条 | 要件审查：20万元以下由分管领导+招采分管领导+首席合规官+总经理审批；20万—200万由招标领导小组常务副组长专题会；200万以上由组长专题会 |
| 第二十三条 | 结果审批：依法必招按中标候选人评定分离机制；非依法必招由采购发起部门分管领导、首席合规官、总经理、董事长确认 |
| 第二十四条 | 每年2月末前上报年度招标采购计划；每季度30日前报完成情况备案 |
| 第二十六/二十七/二十八条 | 子企业项目报审与备案情形及备案材料清单 |
| 第三十八/三十九条 | 按合同约定验收、评价质量价格服务、验收合格后结算；"谁采购、谁留痕"，采购档案保存不少于15年 |
| 第四十/四十一条 | 设立公开投诉渠道；收到异议投诉3个工作日内启动调查、受理后30个工作日内出具书面调查报告 |
| 第四十三条 | 任何单位个人不得干涉干扰招标采购活动 |

### 本项目据此的采购方式结论

- 试点（首期约13—17万元，服务类单项低于50万元限额）→ **谈判采购**（第十七条第一、二款）
- 手机短信认证套餐等单项估算价5万元以下 → 按第十九条向不少于3家合格供应商询价比价并形成书面记录，完成招采立项后实施
- 全域推广（约130—170万元，达服务类50万元限额）→ **公开招标**（第十四条第四项），依法必招按中标候选人评定分离机制
- 控制价设定依据＝本次询价的分档价目与单房综合单价换算（即"市场询价记录"，第二十一条）
