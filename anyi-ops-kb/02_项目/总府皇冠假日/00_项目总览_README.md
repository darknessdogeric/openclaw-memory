### 三项硬约束（机电为必做项，轻改方案不成立）
- 🔴 **三年 43 次爆管，原因 100% 为"老化"**（2024 年 6 次 / 2025 年 17 次 / 2026 年 20 次）
- 🔴 **2026 年 7 月消防报警联动系统全面瘫痪**（主机回路板烧毁；线路为 1996 年敷设，绝缘值严重不达标）
- 🔴 **中央空调为 R11 淘汰冷媒离心机**（1996 年，约克 4 台，1,230KW）+ 542 台 FCU 1996 年 → 换机组必换冷媒系统，空调是整体换不是修
- 🔴 **配电三硬伤**：变压器 1996 年；二楼咖啡厅厨房开关无配件直连投运；1,600KW 发电机仅 0.8m³ 油箱（原储备油箱被市政拆除）

## 🏛 国资委投资测算口径适配与合规论证路径 (2026-11-03 18:55)

> **完整文件**: `总府皇冠改造_国资委投资测算口径适配与合规论证路径_v1.0_2026-11-03.md`（44.7 KB）+ 桌面 Word（63.8 KB）
> **触发**: Eric "如果还是总府皇冠假日酒店，那么就是需要符合国资委现有的投资测算口径。但是如果是换洲际其他品牌以及其他非洲际奢牌的时候，怎么符合投资测算呢？需要怎样才能满足国资委的口径呢？如果不满足现有口径又有什么办法呢去证明其必要性和可行性呢？"

### ⭐⭐ 核心答案
**换牌能不能满足国资口径，关键不在"收益够不够好"，而在"交易结构能不能把品牌溢价与现金流改善变成可确权的所有者权益增值"。**

### 四套口径
| 口径 | 依据 | 对三路径的含义 |
|---|---|---|
| A 投资项目 | 国资委令34号 | 🔴 **禁止类标准含"达不到投资项目最低预期收益"→ IRR 不达标可能直接不能上会** |
| B 资产评估 | 国资委令12号 | ✅ 改建/扩建/技术改造**应当评估**；核准制与备案制 |
| C 资产证券化 | 酒店 REITs 估值准则 | ⭐⭐⭐ **禁止乐观改善假设 + 大额改造支出不予纳入测算 → 制度上强制"先改造、后评估"** |
| D 保值增值考核 | 《国有资本保值增值结果评价规程》 | ⭐ 保值增值率 =（年末国家所有者权益÷年初国家所有者权益）×100%；**考核的是权益不是利润** |

### ⭐ 换牌后不符合口径的四个机理
① **品牌不是国资的资产** → 溢价无法直接确权｜② **收益被合同切割** → 须用业主可分配现金流｜③ **特许费费用化** → 资产+X、利润−Y｜④ 🔴 **IRR 达不到 = 禁止类**

### ⭐⭐ 六条适配路径
1. ⭐ **换评估方法**（评估增值率替代 IRR）—— 实证：华安锦江 21 个酒店资产平均增值率 **68.26%**，最高 225.80%、**最差 −29.81%（可为负仍有先例）**；单房价值均值 54.6 万/间 → 总府 402 间约 **2.19 亿**参照
2. ⭐⭐ **换交易结构**（SPV 穿透 + 引入外部投资人 + 长期可评估特许合同）★ 关键在合同结构不在收益水平
3. ⭐⭐⭐ **拆两期投资**（一期刚性义务论证 / 二期资产增值论证）★ 集团制度明文支持分期
4. ⭐⭐ **改用"不改造的代价"**（法律责任 + 贬值 + 失去入池资格 + 2029 机会成本 + 折旧刚性）
5. ⭐⭐ **序列安排**：改造先行 → 跑稳定期 → 以实际数据做基准
6. ⭐ **政策资金降低国资出资比例**（REITs / 200 亿基金 / 补 30% / 城市更新）

### ⭐ 关键先例（必须引用）
**《福州美伦大饭店评估报告书》(2006-07-31 公开原件)**：将饭店**无形资产（品牌与客户关系）**用**收益现值法**纳入评估，依据是特许经营协议中的"**系统和专有商标**" → ⭐⭐ **换牌后品牌可入国资评估，但需四个前提**：合同期限 ≥ 收益年期 / 费率机制可预测 / 基准日与合同有效期一致 / 品牌方同意用于评估披露

### ⭐ 五段式论证模板（IRR 不达标时）
① 刚性义务 ② 资产保值增值的必要性 ③ 机会成本（2029 窗口）④ 政策与战略契合 ⑤ 兜底方案（分期 + 止损 + 合同保护 + 外部投资人 + 评估复核）
