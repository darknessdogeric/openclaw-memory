## 酒店项目调研范式 v1.0（12 大维度）

### 维度 1：项目设施设备基本情况 ⭐⭐⭐⭐⭐

| 子项 | 数据点 | 来源工具 |
|------|--------|----------|
| 客房 | 总数/类型/面积/床型/楼层/景观 | OTA + 官网 + 实地 |
| 餐饮 | 餐厅数/餐位/菜系/特色/包间 | OTA + 官网 + 美团 |
| 会议 | 数量/面积/容量/设备 | OTA + 官网 + 销售对接 |
| 休闲 | SPA/汤池/健身/泳池/茶楼 | OTA + 官网 + 实地 |
| 其他 | 婚宴/草坪/停车场/交通 | OTA + 官网 |

**调研深度**：每类至少 10 个数据点

### 维度 2：经营实体相关情况 ⭐⭐⭐⭐⭐

| 子项 | 数据点 | 来源工具 |
|------|--------|----------|
| 公司 | 股东/股权/注册资本/法人/成立时间 | **天眼查/启信宝/企查查** |
| 组织 | 管理层/员工数/部门架构 | 内部 + LinkedIn |
| 经营数据 | 入住率/RevPAR/营收/ADR | **Eric 内部** + 行业报告 |
| 资质 | 营业执照/特种行业/消防/卫生 | 国家政务服务网 |

**R161 数据专项**：精确值/单位/时点/来源 4 项必备

### 维度 3：均价体系 ⭐⭐⭐⭐⭐

| 子项 | 数据点 | 来源工具 |
|------|--------|----------|
| 客房 | 不同房型/不同渠道/不同时段/含早/不含早 | **携程/美团/飞猪/Booking/Agoda** |
| 餐饮 | 人均/套餐/婚宴/会议餐 | 美团 + 销售对接 |
| 汤池/SPA | 单次/套餐/会员价 | 美团 + 抖音 |
| 婚宴/会议 | 桌均价/会议报价 | 销售对接 |

**R161 数据专项**：必须抓实时价格（不要用历史价格）

### 维度 4：产品体系 ⭐⭐⭐⭐⭐

| 子项 | 数据点 | 来源工具 |
|------|--------|----------|
| 客房产品 | 类型 + 卖点 | OTA + 官网 |
| 餐饮产品 | 主题宴/特色菜/招牌 | 美团 + 抖音 + 小红书 |
| 主题产品 | 汤池/SPA/艾灸 | 美团 + 抖音 |
| 文创产品 | 已有文创/周边 | 小红书 + 抖音 |
| 营销套餐 | 各渠道套餐对比 | **携程 + 美团 + 抖音 + 飞猪** |

### 维度 5：历史沿革和当前状态 ⭐⭐⭐⭐⭐

| 子项 | 数据点 | 来源工具 |
|------|--------|----------|
| 建成时间 | 原始开业年 | **官网 + 历史新闻 + 历史房价** |
| 历次翻修 | 翻修年/范围/投入 | 官网 + 新闻 |
| 经营变迁 | 隶属变化/品牌变化 | 工商资料 + 新闻 |
| 现任管理层 | 总经理/营销总监/房务总监 | LinkedIn + 内部 |
| 当前经营状态 | 在营/装修/停业 | **实时 OTA 房态** |

### 维度 6：酒店分级分类 ⭐⭐⭐⭐⭐

| 子项 | 数据点 | 来源工具 |
|------|--------|----------|
| 官方星级 | 几星 | 文旅局公告 |
| 行业类型 | 商务/度假/会议/主题/精品 | 行业分类标准 |
| 客群定位 | 商务/亲子/老年/入境 | OTA + 内部 |
| 行业地位 | 全国百强/区域龙头/特色酒店 | 中国饭店协会 + 行业报告 |

### 维度 7：周边分级分类竞对 ⭐⭐⭐⭐⭐

| 分类 | 同区域 | 数据点 |
|------|--------|--------|
| **直接竞对**（同区域同档次）| 都江堰其他四星 | 价格/评分/产品/营销 |
| **高端竞对**（5 星/豪华）| 都江堰皇冠假日等 | 同上 |
| **经济型竞对** | 都江堰如家/汉庭 | 同上 |
| **替代品** | 民宿/客栈/公寓 | 同上 |
| **距离** | 距酒店 X 公里 | 高德地图 |

**R161 数据专项**：每个竞对至少 10 个数据点

### 维度 8：SWOT 分析 ⭐⭐⭐⭐⭐

```
S (Strengths 优势):
- 资产优势（区位/规模/历史/资质）
- 产品优势（汤池/SPA/餐饮特色）
- 品牌优势（"安逸"集团品牌 + 国堰 22+ 荣誉）
- 团队优势（管理层 + 员工）

W (Weaknesses 劣势):
- 经营劣势（入住率/RevPAR/价格 vs 竞对）
- 产品劣势（装修老化/数字化弱）
- 渠道劣势（OTA 评分 vs 竞对）
- 营销劣势（新媒体弱 vs 新酒店）

O (Opportunities 机会):
- 政策机会（入境免签 + 文旅专项）
- 行业机会（主题酒店趋势 + 文化 IP 红利）
- 合作机会（成铁 / 自如 / 新中体 / 美团 / 李白酒店）
- Eric 部门资源（AHL / 数据 / 行业人脉）

T (Threats 威胁):
- 竞对威胁（青城豪生 / 皇冠假日 / 新华国际 等）
- 行业威胁（酒店过剩 / OTA 佣金高）
- 政策威胁（合规风险）
- 内部威胁（管理层 / 退休 / 部门协作）
```
