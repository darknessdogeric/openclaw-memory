## 一、为什么从"五板块"收敛为"四板块"（关键判断）

9/23 Eric 现场提出的**五大板块**（品牌重塑 / 在地文化改造 / 策展联营 / 新零售 / 数字化穿透）是**想法层**——覆盖一个文创酒店该有的所有想象。

10-24 Eric 提出的**四大板块**是**投资层**——每一块都要对应明确的改造范围、预算归属和责任方。收敛发生三处：

| 变化 | 五板块（9/23）| 四板块（10/24）| 含义 |
|---|---|---|---|
| **新零售** | 独立板块 | **并入「文创策展联营」** | 新零售不是独立工程，是策展与文创的商业闭环出口 |
| **文创改造** | 覆盖全店的想象 | **收窄为「公区 + 国堰楼客房 + 博观楼 + 汤池」** | 改造范围锁定主楼系统，**求是楼（副楼/球室楼）不动** |
| **IP** | 散落在文创里 | **提级并入「品牌重塑」** | IP 是品牌资产，不是文创副产品 |

**🟢 收窄的工程依据（三重咬合）**：
1. **客房数**：凡驰 9/24 原文"你把现在主楼改增加了九间房，现在是一百七十六" → **176 = 主楼改造后**（主楼现状 167 + 9）
2. **求是楼状态**：球室楼/求是楼刚完成翻新，浅原木休闲风，9/24 品牌VI会明确"不会动内部软装，仅统一替换 VI 标识" → 不进改造范围
3. **Eric 10-24 口径**：改造范围明文 = 公区 + 国堰楼客房 + 博观楼 + 汤池 → **没有求是楼客房**

→ **三大口径互证，范围锁定，无需再问。**

## 三、板块① 品牌重塑 + IP 打造

| 项 | 内容 |
|---|---|
| **主商标** | 1 个（方案一方向：方正稳重 · 竹笼马叉结构变形 · 承载文化 · 政企高级感）|

**🟢 战略含义（此前未在任何 KB 文件中出现）**：

- 品牌重塑与文创策展两个板块在此处咬合：**三字经是文化 IP，三大已注册商标是商业 IP**

### 3.4 硬约束（9/24 品牌VI会 · Eric 6 条）

1. 品牌名 **≤4 字**
2. **不走字母组合**（攀钢 PG 反例）
3. 具象关联"堰"与"水"，**不表现治水动作**，只表达"顺势而为"
4. **2–3 款色系**可选
5. 单店辨识度 + 集团归属**双层架构**
6. 全年龄段靠**体系**（视觉+产品+服务+推广）不靠单个 logo

### 3.5 🟢 Eric 选 LOGO 的顺序原则（本板块方法论核心）

> "**我的形象能不能推出来是靠我未来的运营推出来的，而不是我的 logo 把我的运营带起来了。**"
> "应该先想清楚未来产品往哪走、传播路径怎么走，**倒推**回来选设计，而不是先看哪个好看就选哪个。"

→ **定位与客群 → 产品与传播路径 → 主商标**。三个 logo 方案（方正 / 字母 / 葫芦）中，**主商标选一，葫芦等作内容元素与衍生元素**。

### 4.2 投资优先级链（不可颠倒）

```
① 隐蔽工程（管线+机电）占总投 20–30%  ← 集团专项
   ↓
② 动线优化（功能排布）
   ↓
③ 硬装改造
   ↓
④ 软装更新
   ↓
⑤ 文创活动（通过持续活动逐步放大，前期不重投）
```

**🟢 Eric 原话**："你说文创投入 40% 可能多了，我们更多通过活动逐渐放大。改造首先要解决最基础的问题。"

### 4.3 已定盘的空间决策（9/23–9/24）

| 区域 | 决策 |
|---|---|
| 一层 | **取方案三**（保留承重柱）—— 主楼裙楼分开结构，拆柱有结构风险 |
| 婚宴动线 | 客人习惯**正门迎客**，无法全导后侧 → 正门区域统筹婚宴与住客动线（待优化）|
| 全日制餐厅 | 现方案 500㎡ / 131 人 / 取餐 23 m；**Eric 提出迁至顶楼**（700㎡，200–300㎡ 健身洗衣，释放二楼给宴会厅，一楼留给策展联营）|
| 早餐厅硬指标 | **明档 8–9 m**（四星标准，现方案不足）· 独立小厨房解决上下水与噪音 |
| 厨房 | 一楼宴会厅**无传菜梯** + 分餐区不足 → 重规划后场；厨房按规范**双通道**（食品安全 + 消防）|
| 客房 | 过道**房门内凹** + 卫生间**半开放式**（洗手台迷你吧外放）+ 木地板配块毯 + 双床可拼接；**改造后主楼 176 间** |
| 客房后场 | 每层设工作间，**2–3 层共用消毒间**，探索布草井；8/11/13 楼布局差异分别处理 |
| 博观楼 | 首层茶咖 + 艾灸 SPA（动静分流）/ 二层棋牌 / 三层**改对内景观**（三楼主看居民楼）；外挂电梯 24–25 万待定 |
| **博观楼 + 汤池** | **整合为独立经营单元** —— 入口调整到博观楼，园林动线分流，统一管理降人力，解决浴衣客人穿行主楼 |
| 灯光 | 现全白光直射无分层 → 独立板块，照度模拟（桌面 306 lm / 地面 400–105 lm）|
| 园林 | 叠水优化 + **风雨廊**（雨天连通）+ **路口昭示性**（成都方向开车易开过）|
| 汤池 | **不能叫"温泉"**（是烧的，涉欺诈）→ 独立经营 |

### 4.4 边界与禁止项

- ❌ 不大拆大建，不动原基装，只调空间格局
- ❌ **保留原承重柱**（主楼与裙楼结构分开，拆除有风险）
- ❌ 副楼**风格可不统一，动线必须统一**
- ❌ 客房"整体动但轻量化"—— 卫生间必改，其他轻改
- ❌ 空间自由度优先 —— 减少固定装饰占用（原大堂可旋转隔断门取消）
- ✅ **运营前置** —— 运营团队提前进设计阶段
- ✅ **边经营边改** —— 分阶段施工不影响营业

## 六、板块④ 数智化穿透（底座）

### 6.1 定位（Eric 9/13–9/24 口径）

> "**数字化穿透不是锦上添花的配套工程，而是超级单店突破的先决条件。**"
> "文创改造只能停留在视觉装饰层面，文化策展联营难以形成商业闭环，新媒体矩阵无法完成从内容到客户的转化，新零售难以形成场景化销售与库存闭环。"

**🟢 Eric 9/15 定位**：数字化穿透 = 超级单店五大板块中的**第 4 板块**（主供应商 **石基**，框架由石基搭，合作方与 AHL 可参与）

### 6.2 技术架构

```
集团绿云体系（基础统一层，持续发挥）
        +
石基全栈（高端全服式补充深度能力）
        ↓
集团 AI 中台（多体系并行 → 统一会员/财务/决策/运营管控）
```

**🟢 Eric 口径**："数字化穿透这一块由石基出整体方案，框架是他们搭……未来通过 AI 智能化手段把整个体系整合。"

### 6.3 颗粒度（当前最大问题）

报表科目设计完整但**录入覆盖率仅约六成**，七类科目全空：
团队类（会议/政府/系列团/一次性/机组）· 会员分层（注册/银/金/铂金）· 政务与差旅类（政府散客/差旅协议/全球采购/积分兑换/特别折扣）—— 全零

**🟢 对国堰的直接后果**：会议收入同比 +30.56%，但团队用房与散客用房无法区分 → **无法判断会议业务对出租率的实际贡献**。
