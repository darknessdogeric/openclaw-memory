## 0 · 结论先行

1. **这两件事应该当成一笔交易谈，不该分两笔。** 它们共用大堂空间、同一批客人、同一条叙事；分开谈会拿到两份固定成本，却没有两份收入。中国现成范式是 **上海金茂君悦 × 上海博物馆「博观悦取」**（文创 + 咖啡复合文化空间）。
2. **咖啡厅在国堰的定位必须改：它是「引流入口 + 文创货架 + 研学集散台」，不是利润中心。** 按公开模型，咖啡厅占酒店总营收 2%–9%（中位 4%–7%）。国堰 2030 目标总收入 1.8 亿，咖啡厅即使做到中位也只能贡献 720–1,260 万——**指望它扛 65% 的其他收入，在算术上不成立**。
3. **国堰该争取的不是「找一个策展人」，而是「像半岛 × V&A 那样签一份多年期馆方协议」**：馆方出内容、委约新作、策展人挂名，酒店出空间并付固定费。**这是全球唯一被验证的「馆方主动型」结构。**
4. **咖啡谈判的筹码不在费率，在设备与系统的所有权。** 瑞幸/库迪/挪瓦都把定价权、线上店铺、系统收归总部。先问「三年后这间咖啡厅还是不是我的」，再谈抽成。
5. **结算口径决定生死**：内部结算（场地 + 人工内部摊）→ A 档 10–20㎡ 平衡点 ≤10 杯/日、可做；独立全成本 → 平衡点跳到 33–50 杯/日，必须拿到品牌方零投入条款（挪瓦方案 B：设备免费但所有权归品牌）。
6. **策展联营自身回不了本**（门槛：年增量收入 ≥ 一次性投入 × 1.2 ÷ 门店级利润率；220 万投入需年增量 754 万）。它必须与客群换质、会员、复购一起算，否则就是纯成本。

## 一 · 咖啡点位在国堰的三种结构

### 结构 A · 自营（最像「装修后的咖啡吧」）
- **做法**：酒店自聘咖啡师、自采购、自出品；大堂吧 + 轻文创展示区。
- **收费**：无外部抽成，但**全部成本自担**（人工、损耗、水电、淡季闲置）。
- **公开失败样本**：48 元拿铁 × 200 杯/天 ≈ 营业额不足 1 万，却要养挑高 8 米空间与全职服务员；联名快闪定制托盘吃掉大半利润并推高客诉率。
- **判断**：不建议。国堰没有餐饮班底，且淡旺季差极大。

### 结构 B · 品牌店中店（推荐）
- **做法**：引入成熟咖啡品牌的**店中店**（2–4㎡ 起投，可放大到 20–40㎡），品牌方出产品、设备、供应链与线上店铺；酒店出空间、场景与客流动线。
- **收费锚点（挪瓦公开方案）**：起投 4.98 万；**方案 B 设备免费用但所有权归品牌**；服务费 5%（限时免）；保证金 5,000 元；**日均 120 杯 → 月收 2.52–3.6 万 → 毛利 50%+ → 回本 3–4 个月 → 5 年累计毛利 75–108 万**；日均 200 杯 → 回本 2–3 个月 → 5 年 126–180 万。
- **酒店侧要争到的三条**：① 设备与系统归属条款写清 ② 淡季免租/保底豁免 ③ 会员与储值归属（客人储值归谁）
- **对标国堰的量**：176 间房、ADR 目标 340、OCC 65%；喆啡案例（130 间房、ADR 330、OCC 80%、大堂 300㎡）大堂咖啡 + 半自助餐**月营收 20 万**。国堰客流结构相近但 OCC 更低，**首年合理区间：月 8–15 万、年 100–180 万**（占 2030 总营收约 0.6%–1%）。
- **判断**：推荐的咖啡主结构。**但要点在「店中店 + 文创货架」，不是「咖啡厅」。**

### 结构 C · 复合文化空间（真正的重点）
- **做法**：咖啡 + 文创零售 + 策展微型展 + 导览/研学报名，四合一放在同一空间，对非住客开放收费。
- **收费**：咖啡走品牌分成；文创零售走自有毛利（进货价 ×2.5–3.5，联名款 ×4）；导览/工坊 80–480 元/人场；研学 3,000–8,000 元/人。
- **中国范式**：上博 × 金茂君悦「博观悦取」；亚朵 A.T.HOUSE（100 间客房放艺术家作品复刻品，**住客可带走**——本质是零售分成安排）。
- **国堰现成条件**：方案里已有「大堂吧（堰文化 + 文创元素，收费咖啡酒吧）+ 轻文创展示区（无会议时陈列、有会议时切换）」——**这就是结构 C 的骨架**，只差把它变成一个统一经营单元与统一结算。
- **判断**：这才是国堰真正该做的，咖啡只是其中的引流器。

### 三个结构的比较

| | A 自营 | B 品牌店中店 | C 复合文化空间 |
|---|---|---|---|
| 现金投入 | 中（设备 + 人工） | 低（4.98 万起，可分期） | 中（叠加文创与展陈） |
| 酒店承担风险 | 全 | 低 | 中（文创库存） |
| 对非房收入贡献 | 低 | 低 | **高（多收入线共用一套客流）** |
| 与「治水」主线的耦合 | 弱 | 弱 | **强（堰工竹编/川西茶事可直接作工坊）** |
| 可复制到其他店 | 弱 | 中 | **强（SOP 化）** |

## 二 · 策展联营的年度合同结构（国堰版）

### 2.1 建议采用的形态：共创 + 委托混合

| 组件 | 对手方 | 合同形态 | 期限 | 酒店付费 |
|---|---|---|---|---|
| 年度策展顾问 | 馆方策展人 / 外部策展顾问 | 顾问协议 | 1 年起，可续 | 固定年度顾问费（市场无公开价，需谈） |
| 借展（微展 + 巡展） | 都江堰水利博物馆等 | 借展协议 | 按展期 | 借展费（公开样本 DKK 1,000/件量级）+ 保险 + 运输 + 押运差旅 + 布展 |
| 驻留艺术家 | 外部艺术家 / 院校 | 驻留协议 | 3–6 个月 | 换宿 + 津贴（公开样本 3,000 美元/人 × 3 个月） |
| 主题空间授权 | IP 方 | 授权协议 | 1–3 年 | 保底金 + 分成（博物馆 IP 6%–12%） |
| 票务/课程分成 | 景区 / 研学方 | 打包或分成协议 | 按季结算 | 0 或保底 |

### 2.2 一年 180–250 万的内容预算怎么花（对应 L3 最低可行）

| 科目 | 金额 | 说明 |
|---|---|---|
| 文化主理人 / 策展 1 名 | 25–40 万 | **必须有专人**，否则退回 L2 |
| 借展与共创（保险 + 运输 + 押运 + 布展） | 50–80 万 | 借展费本身很低，成本大头在这五项实报实销 |
| 2 次主展的布展施工 | 40–70 万 | 施工占展览总预算 20%–35% |
| 工坊与文创开发（堰工竹编 / 川西茶事 / 李冰隐名文创） | 30–50 万 | 与咖啡区共用空间 |
| 仓储与恒温恒湿 | 10–20 万 | 约 155–465 元/㎡/年 |
| 导览与研学课程开发 | 15–30 万 | 一次开发可复用于 N 店 |
| 外部顾问与差旅 | 10 万 | 采购、谈判、监修 |
| **合计** | **180–300 万** | 建议先批 180–250 万 |

### 2.3 一条不该忽略的时间约束
借展提前期 **4–12 个月**（Willumsens 要求提前 4 个月；行业指引 6–12 个月），且**合同签订后取消要承担馆方已发生成本**。
→ **如果 2027 年内要开第一次主展，谈判必须在 2026 Q4 就启动**，否则第一年只能做自营内容（工坊 + 文创 + 数字展）。

## 三 · 谈判条款清单（可直接照着问）

### 3.1 策展联营（10 条）

| # | 条款 | 我方要的 |
|---|---|---|
| 1 | 年度展次下限 | 书面写明**每年 ≥2 次主展**，未达如何补偿 |
| 2 | 选题权 | 共同选题，我方有一票否决（避免与「治水」主线冲突） |
| 3 | 排期承诺 | 馆方档期锁定，我方不再被临时取消（取消成本谁担） |
| 4 | 素材授权范围 | 作品图像可用于客房宣传/OTA/文创的**明确授权范围与期限** |
| 5 | 衍生品归属 | 文创开发权归谁、利润怎么分（**无行业公开比例，必须谈**） |
| 6 | 署名规则 | 双方 logo 使用场景、文案审核权（QCA 模式可参照） |
| 7 | 保险与运输 | seam-to-seam 全程保、恒温运输、押运差旅谁付（**默认借展方付**） |
| 8 | 费用上限 | 年度内容总支出封顶，超出如何审批 |
| 9 | 去 IP 化降级 | 授权到期后的**免费去 IP 化方案**（保留装置、撤掉标识）与费用责任 |
| 10 | 采购形式 | 走**年度框架协议采购**（贵州两则公开公告为范式：三平台披露 + 按类拆标段 + 选两家供应商 + 免费招标文件），而非一事一议 |

### 3.2 咖啡外包（10 条）

| # | 条款 | 我方要的 |
|---|---|---|
| 1 | 设备与系统归属 | **三年后是我的还是品牌方的**；品牌退出时设备作价与迁移 |
| 2 | 会员与储值 | 客人储值归属、会员积分互通、我方能否拿到消费数据 |
| 3 | 定价权 | 是否有调价权/限定价区间（瑞幸模式是总部全权，门店无调价权） |
| 4 | 房租与抽成 | 明确是「固定租金 + 营业额提成」还是「阶梯毛利分成」；**国际惯例 percentage rent 8%–15% 营业额**，中国酒店点位无公开费率，需谈 |
| 5 | 淡季保底 | 淡旺季系数 >3.5 的季节性点位，保底须有豁免或折算 |
| 6 | 水电物业分摊 | 按营业额比例还是计量；**店中店争取 0 额外租金 0 额外人工** |
| 7 | 装修归属 | 期末装修归属或补偿；翻牌补贴（挪瓦 2 万）归属 |
| 8 | 供应链 | 是否强制统一采购、能否兼容本地非遗茶事（**堰主题需要例外条款**） |
| 9 | 退出与转让 | 合同期满与提前解约的保证金退还（瑞幸/喆啡均有「期满无息返还」样本） |
| 10 | 与文创/展陈的物理边界 | 咖啡区与文创货架、展区的动线与结算是否打通（**结构 C 的成败在此**） |

### 3.3 共同（5 条）

| # | 条款 | 我方要的 |
|---|---|---|
| 1 | 内容排他 | 策展方与咖啡品牌在「治水/堰文化」叙事上的**联合审稿权** |
| 2 | 数据归集 | 消费与参观数据回流集团（会员体系是集团级资产） |
| 3 | 品牌联合 | 双方 logo、双方文案、联名发布节奏 |
| 4 | 安全与合规 | 消防疏散（工坊明火/道具）、食品经营许可、演出许可前置 |
| 5 | 退出后的降级方案 | 授权/合作到期后，装置与陈列如何留用（避免再花一次改造费） |
