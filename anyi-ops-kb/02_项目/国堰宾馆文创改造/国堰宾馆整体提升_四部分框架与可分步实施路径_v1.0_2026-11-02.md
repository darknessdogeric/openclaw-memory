## 〇 · Eric 口径要点与三点判断

### 口径要点（逐条落库）

1. 找这些合作方，主要目的是**看他们能覆盖国堰该做哪些方向事项**；各家**各有所长**，**不必然使用**，最终**还是要招采**；其前期方案可作为**步骤参考指引**。
2. 国堰宾馆属于**主题文化改造**（不是主题文化赋能）→ 应该是 **改造 ＋ 赋能**。
3. 不排除**集团没有多余的钱**，或**领导暂不考虑改造** → 那就**品牌重塑 ＋ 文创先行**。
4. 整体提升分**四部分**：① 品牌重塑（含 IP，**IP 包可分拆**）② 主题文化改造（**重投入部分**）③ 文化策展联营 ④ 数字一体化（**选投部分**）。
5. 这四部分分别代表项目的 **产品、内容、市场营销、体系化能力**。
6. 最终需**与国堰团队充分对接后，由国堰团队形成整体提升方案**。
7. 方案的**各细分项可单独实施、分步实施** → 做到有的放矢，同时**整体资金压力、进度压力、尤其集团决策压力都不大**。

### 三点判断

**① 这不是降低标准，是把决策拆小。**
集团真正怕的不是钱多，是**一个 3,600 万、周期长、不可逆的大包**——一旦否决，前功尽弃。拆成四个可单独立项的包之后，每个包都能被单独否决而不影响其余：**决策压力从"一次押注"降为"分次择时"**。

**② 四种能力与四个部分是"交叉覆盖"，不是一对四**（Eric 2026-11-02 14:17 更正）。

| 部分 | **产品** | **内容** | **市场营销** | **体系化能力** |
|---|---|---|---|---|
| ① 品牌重塑（含 IP，IP 包可分拆）| ● **定义产品是什么** | | ● **提供叙事与传播素材** | |
| ② 主题文化改造（重投入）| ● **把产品做出来（产品向）** | | | |
| ③ 文化策展联营 | | ● **内容生产与场景** | ● **引流与变现** | |
| ④ 数字一体化（选投）| | | | ● **独家承担** |

**读法（四个"不是"）**

- **产品 = ① ＋ ②**：① 定义"国堰卖什么"，② 把它做成可交付的产品。**缺 ① → 产品没有叙事；缺 ② → 品牌停在图纸上**
- **内容 = ③**：② 把内容做成**空间**（静态载体），③ 把内容做成**运营**（动态载体）—— **互补，不重叠**
- **市场营销 = ① ＋ ③**：① 说"是什么"，③ 说"怎么让人知道、怎么把人带来、怎么变现"
- **体系化能力 = ④ 独家**：能不能复制、能不能管住

**"改造 ＋ 赋能"的分界（据此重新表述）**

- **改造 = ②（产品向）**：把文化做进空间硬件与产品结构 → 重投入、周期长、不可逆
- **赋能 = ① ＋ ③（内容与市场营销向）**：把文化做成叙事、内容与运营 → 轻投入、可先行

**🔑 由此推出的新判断（本次更正的最大价值）**

> **情景 B（品牌重塑 ＋ 文创先行）不是"缩水版"。**
> 按能力覆盖看，①＋③ 覆盖了**产品定义、内容、市场营销三层**，只欠"硬件兑现"。
> 所以"集团没钱或领导暂不考虑改造"时走 B，**能力上并不残缺**。
> **但 B 的天花板是"品牌与流量"，不是 RevPAR** —— 硬件是 ADR 抬升的载体，这两条路不能混着汇报。

**③ "改造 ＋ 赋能"是国堰与"赋能型酒店"的分水岭。**
赋能型 = 把既有文化贴到一间普通酒店上（成本低、见效快、但没有壁垒）；改造型 = 把文化做进空间硬件与产品结构里（成本高、周期长、但形成不可复制性）。
→ 所以 **② 是重投入且不可替代**，**④ 是选投**，**①③ 是轻投入可先行**。三者的顺序不是偏好，是**依赖关系**。

### 4.1 🔑 招采口径提示（避免"方案先行"变成"指定"）

**各家方案只能作为需求说明与实施步骤的参考，不得作为需求本身。**

1. 以本框架的 **四部分 × 步骤包** 为需求清单重新表述，**不引用任何一家的原方案作为需求**（避免被指"量身定做"）
2. 以**步骤包**为最小采购单元，允许**拆分招标**（品牌可与 IP 分开招，策展可与新媒体分开招）
3. 要求投标方对**步骤包**报价，而非对"整体方案"报价
4. **国堰团队在框架内形成整体提升方案**，采购按其方案的分项执行
5. 所有涉及国资的合作，按 8/14 文化母体方案参考方洽谈纪要要求 **"资源嫁接 ＋ 兜底保障（履约保证金／第三方信用兜底）"**
6. 涉及艺术品与文创销售：**逐件授权委托书、支付方即个税扣缴义务人、票款不得收归酒店再分成**
