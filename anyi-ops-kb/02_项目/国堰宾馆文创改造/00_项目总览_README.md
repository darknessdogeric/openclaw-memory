### 2.3 工程与投资（硬约束）

| # | 约束 |
|---|---|
| 1 | **投资优先级链**：隐蔽工程 → 动线 → 硬装 → 软装 → 文创活动（文创靠活动逐步放大，前期不重投）|
| 2 | **隐蔽工程占总投 20–30%**，由集团专项推进（夏总负责），**不在经营层方案范围** |

## 三、品牌重塑（当前第一优先级）

### 3.1 三个 LOGO 方案（9/24 品牌VI会）

| 方案 | 形态 | 风格 | 适配 | 状态 |
|---|---|---|---|---|
| **一** | 方正稳重（竹笼马叉结构变形）| 文化承载多 · 国企高级感 | 政企政务 · 主商标 | 🟢 **Eric + 经营团队均倾向** |
| **二** | 字母组合（GY）| 现代简约 | 创意基点浅 | 🟡 Eric 不赞同（攀钢 PG 反例）|
| **三** | 葫芦造型 | 轻松 Q 版 | 文创周边 / 盲盒 / 手办 | 🟡 作**内容元素与衍生元素**，不作主商标 |

**🟢 两条定调**：
> "**商标是商标，运营元素是运营元素。主商标选一个，其他都可作内容元素。**"
> "**我的形象能不能推出来是靠未来的运营推出来的，不是 logo 把运营带起来。**" → 先定产品与传播路径，再倒推设计。

### 3.2 品牌名与视觉硬约束

- 名称 **≤4 字**（Eric："超过四个字就是个烂品牌"）
- **不走字母组合**；须具象关联"堰"与"水"，但**不表现治水动作**，只表达"顺势而为"
- 需 **2–3 款可选色系**（适配球室楼浅原木休闲风不突兀）
- 集团标识在便签/信封等 → **置于页脚等角落，主视觉突出单店品牌**
- "标识可几十年不变，**视觉体系十年一翻新**"
- 完整视觉体系含工装 / 工牌 / 信笺 / 信封 / 全色系

### 3.3 品牌架构（待落地）

```
旅投集团
└─ 安逸酒店集团（母品牌 / 集团 IP）
   ├─ 国堰（主品牌 · 主 LOGO）
   │  ├─ 餐饮子品牌（如"宴府"）· 独立 LOGO + 独立账号
   │  └─ 文创子品牌 · 独立 LOGO · 线上商城
   └─ 集团其他 7–8 个待梳理品牌 → 同一方法论逐个做
```

**🟢 Eric 核心逻辑**："**单点突破，小步试错，风险也最小，接受度最高。**" · "我有一个基础标准，然后我的在地文化植入可以一地一策。"

## 八、方法论沿用

1. **文化先行，不是空间先行**
2. **钱花在客人可感知处**（卫生间 · 床 · 早餐厅）
3. **重设计轻装修**
4. **运营前置**
5. **模块拆分 + 菜单式报价**，不用一锤子买卖
6. **谋定而后动**（多团队多轮 → 定方向 → 再申请预算深化）
7. **R66 数据纪律**：转写件 ≠ 原始事实；**疑问 ≠ 结论**；双源对齐；标档位
