## 0 · 结论先行（六条）

1. **这个模式是国堰文化主题酒店的最优解**，理由不是分润多，而是**它把"自建内容生产线"这件事外包了**。自建 L3 内容预算 180–250 万/年（主理人 + 借展 + 布展 + 仓储 + 课程开发），承包后酒店只付 MAG + 分成（首年约 30–55 万），且布展、保险、值守、安保、采购、库存全在运营商侧。**首年净省 120–200 万，同时免掉策展团队编制与库存风险。**
2. **但必须防一个结构风险**：运营商整体承包后，酒店会退化成"收分成的房东"，**客人与内容被截流**。→ 合同必须锁死酒店的三样东西：**观众/消费数据归酒店、内容主线否决权、品牌露出强制条款**。
3. **合同形态建议：双合同打包 + 一个保底池 + 一个分成池**——咖啡走"品牌联营"（有品牌流量与供应链），策展运营走"文化空间承包"（有内容与活动），两份合同共用同一个保底池与分成池，避免重复收租与内部扯皮。
4. **分润比例直接照抄义乌星巴克的四档结构**（7% / 8% / 9% / 10%，按月净销售额），并加**兰州瑞岭博雅式的毛利润率下限对赌**（21%）+ **MAG 取高** + **封顶 cap**。
5. **空间不要一次释放最大的。** 国堰有 3 个会议室（500 / 188 / 700 ㎡）与多功能厅 40–750 ㎡，MICE 是国堰的真生意（10 个会议空间 + 500 人餐厅 + 150 车位）。建议**首期只释放大堂文化区（约 150–200 ㎡）+ 188 ㎡ 会议室**，500/700 ㎡ 保留给 MICE。**MICE 与文化空间在时间上互补**（工作日 MICE、周末与夜间文化活动），全给文化空间等于自断一条腿。
6. **合规里有两个必须提前解决的问题，不能靠猜**：① **"展览开幕/驻唱是否构成营业性演出"没有公开指引，必须拿都江堰文旅的书面答复**；② **会议室改成展陈属改变房屋用途，且展陈本身即触发消防设计审查**——这两项要排在工期最前面。

## 二 · 合同结构：双合同打包

### 2.1 两份合同的关系

| | 合同 A：咖啡/轻食（品牌联营） | 合同 B：策展与文化空间（文化空间承包） |
|---|---|---|
| 模式 | 品牌店中店 / 品牌联营 | 整体承包（承租+经营） |
| 运营商 | 连锁咖啡品牌或其点位服务商 | 文化运营公司 / 艺术空间运营商 |
| 经营内容 | 咖啡、甜点、轻食 | 展览、主题文化聚会、艺术家群展、拍卖、工坊、零售 |
| 分成池 | **共用**：两者的可计收入合并计算 | 同左 |
| 保底池 | **共用**：一个 MAG | 同左 |
| 结算 | 同一份月报、同一套 POS 对账、同一份审计 | 同左 |

> **为什么必须打包**：分开谈 = 酒店在同一块地上收两次钱，运营商之间互相踩（咖啡占道、展览撤展、动线冲突），最后两边都说酒店不配合。**一个池子、一个运营主体、一个对账单，是这个模式能不能跑通的命门。**

### 2.2 分润条款（建议照抄的两条 A 级样本）

| 条款 | 公开样本 |
|---|---|
| 阶梯提成 | 义乌海洋酒店大堂吧咖啡（2026-05-22 中标公示）：上海星巴克中标，**按月净销售额 7% / 8% / 9% / 10%**（<30 万 / 30–50 万 / 50–80 万 / ≥80 万） |
| 管理费 + 对赌 | 兰州瑞岭博雅酒店全权委托运营（2026-08-31 成交公示）：成都山禾宴亭中标，**1%（过渡期，月营收 <200 万不计提、首月免收）→ 3% / 4% / 6.5%**（按年营收档位）+ **经营毛利润率不得低于 21%** |
| 国际锚点 | 丹佛机场 Starbucks/The Cruise Room（2025 公开文件）：**MAG 1,015,875 美元 或 16% 餐饮 / 18% 酒水营业额分成，取高，12 年期** |

**国堰建议写法**：
1. **计提基数 = 月净销售额**，并附书面定义：是否含税、是否含外卖/配送平台服务费与佣金、是否含兑换券核销、是否含第三方联营分润、是否含代收代付。
2. **阶梯比例照抄四档 7/8/9/10%**，按本项目客流规模可下调首档（建议首档 6%、末档 9%），但结构不变。
3. **保底（MAG）**：首年设 **1.0–1.5 万/月**，覆盖酒店在公共区投入（文化区软装 + 会议室改造 + 基座强电）的回收期；第二年降至 0.5 万/月，第三年归零转纯抽点。
4. **"取高"还是"可抵扣"必须写明**：建议 **可抵扣**（对运营商更友好，谈判阻力小），但配合 CAP。
5. **CAP 封顶**：年度分成上限，建议不高于当年该点位净销售额的 12%（超过即说明运营商在本 hotel 赚太多，谈判上可要求降分成或加内容义务）。
6. **毛利润率下限**：建议 **不低于 21%**（兰州样本值），低于则酒店有权暂缓支付分成直至整改——这是防"做高成本做低利润再要分成"的对冲条款。

**与自建对比（首年）**

| | 自建 L3 内容 | 整体承包 |
|---|---|---|
| 酒店现金支出 | 180–250 万 | 24.6–72 万 |
| 策展团队编制 | 1–2 人 | 0 |

| **净节省** | — | **约 110–200 万/年** |

**必须同时说清的三句话**：
1. 这个点位年分成 25–72 万，**在国堰 2030 年"其他收入 1.17 亿"里占 0.2%–0.6%**——**它不是主收入，是入口**。
2. 它的真实价值是三件事：**① 释放空间从低效变正收益；② 替代自建内容成本（首年省 110–200 万）；③ 持续产出 UGC 与媒体内容**（对标成都天府 111：美术馆引流让园区客流从 146 万做到 810 万/年、美术馆观众占 27.6%）。
3. **观众数据归酒店 → 会员转化**是它对集团最大的隐性价值。若数据被运营商拿走，这个模式就只剩"收租"。

## 四 · 酒店必须锁死的三样东西（防被截流）

| # | 条款 | 具体写法 |
|---|---|---|
| 1 | **观众与消费数据归酒店** | 票务/POS/小程序数据实时回流酒店会员系统；运营商不得二次营销、不得导出；合同到期数据留存权归酒店 |
| 2 | **内容主线否决权** | 策展主题由"运营商提名 + 酒店品牌提名"双轨产生，酒店保留**合规与品牌否决权**（涉政、涉宗教、涉低俗、破坏治水主线的题材一律可否）；酒店可指定"治水/堰文化"框架下的必做主题 |
| 3 | **品牌露出强制条款** | 运营空间须使用酒店品牌标识（"XX 酒店 × XX 文化空间"联合署名）、酒店会员权益在空间内可用、房价/房券可兑换空间消费；**否则不予准入** |

> 附加：运营商不得另设同名或近似品牌（防"店中店做大了把酒店的客人截走"）；排他条款限定在**同楼层/同品类/同期**，不锁死整店。

## 六 · 合规前置（最高优先级三项）

| # | 事项 | 依据 | 动作 |
|---|---|---|---|
| **1** | **"展览开幕 / 艺术家现场表演 / 驻唱 / 主题文化聚会"是否构成营业性演出** | 营业性演出管理条例：县级审批 3 日、涉外与港澳台省级 20 日、台湾地区报国务院；材料演出前 3 日递交；看台另需演出场所合格证明 | **开业前取得都江堰市文旅部门书面答复**（无公开指引，不能靠猜）。若认定为营业性演出 → 所有收费活动进审批流程，档期提前 3 周以上 |
| **2** | **会议室改展陈属改变房屋用途 + 展陈本身即触发消防设计审查** | 《消防法》第五十八条（3 万–30 万罚款）；已有"室内装修及展陈 EPC 工程被纳入消防设计审查"的案例；住宿与经营须防火墙分隔、独立安全出口 | 与装修报建同批次提出；**排在工期最前面**；空间分区图与疏散方案先行 |
| **3** | **拍卖只能由持牌拍卖企业主办** | 《拍卖法》第十一、十二条（省级审批、注册资本 100 万）、第十三条（文物拍卖 1000 万 + 文物拍卖许可证）、第十四条（拍卖师主持）、第四十八条（预展不少于两日）、四十五至四十七条（拍卖日七日前公告）；《文物保护法》第九十条第（五）项（知假售假/知假拍假/虚假宣传 → 吊证） | **建议第一批不引入拍卖**；第二年引入时必须由持牌方主办、档期预留 ≥3 日、**酒店不得代持、不得以"合作拍卖"名义组织** |

**其余四项（写进合同附件）**：
- **食品酒水**：酒店自有证不能覆盖运营商独立主体（挂靠连带）→ 运营商独立持证；**空间形态上不做"酒吧"**，做"茶室 + 咖啡 + 活动酒水"，规避未成年人禁入义务（5 万以下罚款/吊照）；至少落实禁售与查验证件。
- **学生与民间艺术家售卖**：展览权须**逐件授权委托书**；**支付方即个税扣缴义务人**；**票款不得统一收归酒店再分成**。
- **预付储值**：若做会员储值，适用单用途商业预付卡办法（预收资金余额上限 40%、存管比例 20/30/40%、终止兑付提前 30 日公示）。
- **酒店连带三条路径**（消保法第三十八条 + 食品安全法第五十二条 + 最高法司法解释第八条）→ 核心防线 **"五分离"：独立持证 / 独立账户 / 独立品牌 / 独立用工 / 独立票据**，五项有一项没分离，酒店可能被拖进经营主体责任。**建议写成合同附件，并作为酒店单方解除事由。**

## 七 · 谈判条款清单（18 条国际通行版 + 6 条本项目补充）

**国际通行版**：Term 期限（建议 5 年起）｜Breakpoint（人工断点 + 低基本租）｜Percentage rent 分档（餐饮/零售/票务/场地至少四档）｜Guarantee（写明取高或可抵扣）｜**Cap 封顶（必设）**｜Renewal（与业绩门槛挂钩）｜Assignment（转让需书面同意）｜Make-good（保留布展基座与强电改造）｜Insurance（展品险运营商投保、酒店为附加被保险人）｜IP（展览图像可用于酒店营销与 OTA）｜Exclusivity（限同层/同品类/同期）｜Termination（连续 N 月低于 X 分成额可终止，30–90 天 notice）｜Curator 权（双提名 + 酒店否决）｜Reporting（与 PMS 对账，平台佣金单列）｜门票与数据（观众数据归酒店）｜拍卖专项（牌照与合规主体单列，不得由酒店代持）｜安全消防噪音时段。

**本项目补充 6 条**：
1. **单一运营主体**：两份合同由同一主体或同一联合体承接，避免内部扯皮。
2. **一个池子一个对账单**：保底池、分成池、结算周期、发票主体三者统一。
3. **扣点基数书面定义**：含税/平台佣金/兑换券/代收代付逐项写死。
4. **内容义务量化为 KPI**：每月 ≥2 场活动、每季 ≥1 次换展、每年 ≥1 场 N 长尾活动（如拍卖/艺术家驻留），未达即扣减 MAG 或触发解除。
5. **空间释放与 MICE 的排他条款**：文化活动不得占用 MICE 档期；双方共用动线的时段规则与噪音上限。
6. **表演/酒水审批的前置配合义务**：运营商负责取得许可，酒店配合出具场地证明；未取得许可的节目不得排期。
