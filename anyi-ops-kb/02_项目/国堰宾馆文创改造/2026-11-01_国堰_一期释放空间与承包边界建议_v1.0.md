# 国堰宾馆 · 一期释放空间与承包边界建议 v1.0

## 0 · 结论

**一期释放：一层的「大堂吧 + 轻文创展示区」+ 原小会议室（场景 6 非遗手作工坊所在，188 ㎡）**，合计约 230–250 ㎡。
**不释放**：500 ㎡ / 700 ㎡ 大会议室与多功能厅（留给 MICE）、博观楼 + 汤池（已定独立经营单元）、大堂纵深艺术客厅与包间（接待与私密功能不动）、问水厅与铭刻墙（酒店品牌面）。

**但比"放哪个区域"更重要的一件事是：承包边界必须是经营边界，不是物理边界。**
大堂是酒店的脸面，不能整体交给运营商。**建议只把"可计价的经营位"交出去，把"品牌面"留在酒店手里。**

## 一 · 为什么是这两个位置（不是另选）

### 1.1 与十场景体系天然对齐（不需要重新设计）
| 场景 | 落位（10-24 挂接表） | 本次角色 |
|---|---|---|
| 场景 4「砌鱼嘴，安羊圈」 | 公区·一层大堂（鱼嘴分水装置 + **鱼嘴造型吧台/接待台** + 客流四六分流） | **分水吧 = 咖啡吧台**。它本来就同时承担"吧台"与"分流"两职，咖啡落在这里零额外结构成本 |
| 场景 6「笼编密，石装健」 | 公区（**原小会议室**） | **非遗手作工坊 = 复合文化空间主厅**。文化母体方案参考方原案已把工坊放在原小会议室，与 Eric 说的"释放一个会议室"完全对上 |
| 场景 5「立涓闸，留漏罐」 | 公区·大堂纵深（主接待→艺术客厅→私密雅间 + **对市民免费开放的公益水文文化角**） | **过渡带 + 免费引流口**。免费角带来客流与媒体，收费区在旁边 |
| 场景 9「岁勤修，预防患」 | 博观楼 + 全店运营（**季度焕新策展：春放水/夏研学/秋天府艺术/冬祈福**） | **现成的内容日历**，直接作为承包运营商的 KPI 基准 |
| 场景 10「遵旧制，毋擅变」 | 公区 + 客房（在地文脉轻量展陈 + **美院驻留** + 治水典籍/老照片复刻） | 微缩展与驻留的落点 |

> **场景 9 已经在方案里写好了季度策展日历**——这正是知识库 L3 所要求的"内容日历"。承包谈判时不必再设计，直接作为运营商的内容义务条款写进合同（每季 ≥1 次换展、每月 ≥2 场活动、四时主题对齐"春放水/夏研学/秋天府艺术/冬祈福"）。

### 1.2 为什么是小会议室而不是 500 / 700 ㎡
| 理由 | 说明 |
|---|---|
| MICE 是国堰的真生意 | 10 个会议空间（最大 740 ㎡）+ 500 人餐厅 + 150 车位；全季/亚朵在都江堰已因景区客流"一房难求" |
| **时间互补** | MICE 吃工作日与白天；文化空间吃傍晚、夜间与周末。**分区才能同时吃两拨客流；全给文化空间等于自断一条腿** |
| 改造与审批成本 | 500/700 ㎡ 改造与消防审查体量大；小会议室体量可控、可先跑通再复制 |
| 可复制性 | 小会议室的体量正好装下"微型展 + 2 个工坊 + 零售 + 报名台"，**这个 250 ㎡ 单元可以原样复制到锦江、古尔沟、嘉州** |

### 1.3 面积分配（188 ㎡ 原小会议室，扣墙体与疏散通道后可用约 170–180 ㎡）
| 功能 | 面积 | 说明 |
|---|---|---|
| 微型展 / 借展区 | 70–80 ㎡ | 可容 30–40 件 + 1 组装置；按展陈标准做承重、温湿度与灯光 |
| 非遗工坊 2 位 | 36–40 ㎡ | **可移动隔断**——展期结束后转为零售与活动空间（对应场景 6"笼编密"的手作体验，也是研学的动手环节） |
| 文创零售 | 25–30 ㎡ | 堰工竹编 / 川西茶事 / 李冰隐名文创 / 卧铁寻宝集印兑换 |
| 导览·研学报名台 + 讲解等候 | 15 ㎡ | 也承担票务与"住店即享"套餐核销 |
| 库房 / 恒温恒湿库 + 办公 | 12–15 ㎡ | 文创库存 + 布展周转；恒温恒湿约 155–465 元/㎡/年 |

**大堂侧**：分水吧吧台与出品区 + 外摆座位（按 9-23 已定"左侧靠窗设大堂吧 + 轻文创展示区，无会议时陈列、有会议时切换"）；轻文创展示区就是**可撤展的弹性位**，承托季度焕新。

## 二 · 承包边界（本次最关键的一张图）

### 2.1 边界原则
**交出去的是"可计价的经营位"，留下的是"酒店的品牌面"。**

| 区域 | 归属 | 运营商可做什么 |
|---|---|---|
| 分水吧（咖啡/轻食/酒水） | **运营商经营** | 出品、定价、招人、供应链、POS |
| 轻文创展示区 | **运营商经营（可撤展）** | 零售 + 换展布撤 + 活动 |
| 原小会议室 188 ㎡ | **运营商整体承包** | 展览、工坊、活动、零售、报名、办公库房 |
| 大堂主视觉墙 / 问水厅（场景 1） | **酒店品牌面** | 运营商只提供内容与制作，署名与品牌规则由酒店定 |
| 品牌铭刻墙（场景 2） | **酒店品牌面** | 运营商不得改动 |
| 艺术客厅 / 私密雅间（场景 5） | **酒店经营** | 运营商可提供内容与活动，不得占有 |
| 公益水文文化角（场景 5） | **酒店品牌面 · 免费开放** | 运营商可运营（引流），**不计费**；开放义务写进合同 |
| 500 / 700 ㎡ 会议室与多功能厅 | **酒店 MICE** | 运营商不得占用档期；可做"文化主题会务"联合产品 |
| 博观楼 + 养真汤池 | **独立经营单元** | 不并入承包区，避免交叉结算 |

### 2.2 三条边界规则（写进合同附件）
1. **不可侵占**：不得占用接待区、铭刻墙、艺术客厅、包间及 MICE 档期。
2. **品牌露出强制**：空间须以"XX 酒店 × XX 文化空间"联合署名出现；酒店会员权益可用、房券可兑换空间消费；否则不予准入。
3. **公益义务**：公益水文文化角须保持对市民免费开放；运营商可运营引流但不收费，合同须写明开放频次与时段。

## 三 · 三个连带决定（这个区域决定的必然结果）

| # | 连带项 | 说明 |
|---|---|---|
| 1 | **改造范围与预算表要同步改** | 分水吧 + 小会议室原属"公区 500 万"内；咖啡设备与布展属"策展联营 180–250 万"或咖啡点位 30–80 万（见 11-01 承包方案） |
| 2 | **MICE 与文化空间要排一张档期表** | 两边共用大堂动线与电梯；噪音与时段上限需提前约定 |
| 3 | **"有会议时切换"要写成运营规则** | 轻文创展示区在 MICE 档期收起，须有明确的收撤时间与责任人（否则布撤成本吃掉分成） |

## 四 · 需 Eric 核实的一件事

**"原小会议室"到底是哪个面积。** 内部 8-10 纪要记国堰会议室 3 个：**500 ㎡ / 188 ㎡ / 700 ㎡**（官网口径多功能厅 40–750 ㎡），"小会议室"按字面应为 **188 ㎡**，但需以图纸确认。若实际最小的一间不是 188 ㎡（比如是 40–90 ㎡ 那档），则本方案的分区逻辑要重排——**建议以图纸锁定后再定**。

---

## 五 · 结论一句话

**放"分水吧 + 原小会议室"这两处，因为它们是十场景体系里本来就要做的两处（场景 4 吧台、场景 6 工坊），不是新增；放它们的真实收益不是那点分成，而是——它把运营商的经营行为关进一个可画边界的盒子里，同时把酒店的脸面（问水厅、铭刻墙、艺术客厅）和 MICE 的产能完整留在自己手里。**
