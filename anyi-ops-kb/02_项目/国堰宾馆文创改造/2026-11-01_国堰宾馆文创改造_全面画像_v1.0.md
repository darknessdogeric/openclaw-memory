### 4.2 三者其实是一件事的三种语言
- 华可的**十场景** = 空间层（每个场景对应一处空间、一个产品、一条运营规则）
- 梵尺的**道养潮** = 品牌层（对外的文化主张与客群语言）
- 波浪的**四 IP 与 VI** = 商品层与识别层

> **它们不是三套打架的方案，是一套方案的三个层次。** 问题出在：挂接表把华可十场景"挂到"梵尺四大板块上（B166ER 推演，未经华可确认），而两边的编号体系不同 → 出图时容易各说各话。

### 4.3 融合建议（建议 Eric 拍板）
1. **对外品牌语法用「道·养·潮」**（三字，朗朗上口，直接对应客群与空间气质，梵尺已出全套色彩与 IP）
2. **空间设计任务书内部结构用《治水三字经》十场景**（每句 → 一处空间 → 一条运营规则，颗粒度比道养潮细）
3. **产品与商品层用四 IP + 六字诀**（波浪已报价落地）
4. **在挂接表上加一列「道养潮归属」**：十场景逐条标注归"道/养/潮"哪一线 → **一次性解决两套语法打架**，这是 10-24 挂接表自己留下的缺口（"未经华可确认…否则两套语法打架"）
5. **母题禁改项**：三字经原文只在 2 处出现（铭刻墙 + 传承守正展陈），其余用"意"不用"字"（10-24 反硬贴检查）

## 五 · 空间与业态体系（梵尺 10-31 定稿）

### 5.1 顶层结构
- 定位：**"沉浸式生态旅居体验综合体"**——为旅客呈现文化且多元的生活方式
- 品牌释义：国 = 国家水脉、治国之道、国企担当；堰 = 导水、守水、润水
- 空间策略：以水为形、以文化为魂，灌注水系联动营造空间，沉浸式地域文化基底整合设计

## 十一 · 全面画像下的五个判断（我）

1. **这栋楼的真正资产是三样，不是"文化"**：党校教学点位（政务客刚需与政治信用）、灵岩河滨河的**城市界面**（不是深山隐逸）、397㎡ 可展可会的**弹性产能**。文化只是把这三样变现的手段。
2. **两套文化语法必须先合并再出图**，且合并成本很低——给十场景加一列"道养潮归属"即可。但**必须现在做**：出图一旦按两套语言分头推进，改的成本远高于现在加一列。
3. **3,600 万里真正稀缺的不是钱，是"策展执行"这 50 万。** 按本库成本表：50 万 ≈ 一场主题展 + 3–5 款打样 + 一年月度活动 = **L2（内容点缀）**；做成 L3（联动层）需 180–250 万/年。**建议：总额不动，把客房分期降档省出的 200–300 万转成年度内容预算**，并把"承包运营商"作为 3.0 的放大器——**一层的 397㎡ + 大堂吧 + 文创区已经具备整体承包的物理条件**（演展中心双模 + 后台现成 + 入口第一动线零售）。
4. **投资的真实矛盾在 MICE 与展演的档期，不在钱。** 397㎡ 双模意味着两种收入模式抢同一块地 → 合同要写：分成基数排除 MICE 场租与会议餐饮、酒店 MICE 优先权与触发责任、转换窗口与频次上限、档期损失补偿。**这一条不写，招商价格一定谈不下来。**
5. **对外只讲一句话**：从"努力招待所"到"能放松睡觉的地方"（波浪 10-13 语）——即**都江堰唯一能把文化住下来的酒店**。文化主题酒店不是把酒店变成博物馆，是**把城市的文化变成住客的一晚**。
