## 二、五项核心要求（Eric 2026-09-28 校正后）

### 1. 定位为文创改造
不是普通装修改造。核心是把"千年治水智慧"转化为可体验、可消费、可传播的内容产品。

### 2. 优先做文化挖掘
**文化先行，不是空间先行。** 先把在地文化（都江堰治水／堰文化）挖透，再谈空间设计。
配套动作：文化点位提炼、文化资产梳理、六感体验体系（视听嗅味触意）。

### 3. 要有贯穿主线的文化主题
**单一 IP 主线贯穿全场景**，不杂、不硬贴。
- 主线：**水文化 / 堰文化**（都江堰治水）
- 表达原则：**润物细无声**的沉浸式表达，不刻意堆砌文化符号
- 工程语言：反复使用"马叉木"元素做结构变形，色彩围绕水文化提炼

### 4. LOGO 可以改（R66 校正）
**LOGO 属于品牌重塑范围，可以改。**
已讨论三个方案方向：
| 方案 | 风格 | 适配 |
|---|---|---|
| 方案一 | 方正稳重 | 政企接待定位 |
| 方案二 | 字母组合 | 现代简约 |
| 方案三 | 葫芦造型 | 轻松有趣，适合文创周边 |

配套要求：
- 品牌名称**不超过四个字**（记忆度原则）
- 建议结合都江堰水文化／治水理念做**具象设计**，不走纯字母组合
- 需提供 **2–3 款色系**，适配球室楼已完工的浅色原木休闲风
- 子品牌（餐饮、文创）可单独设计 LOGO，用"主 LOGO + 子品牌"覆盖全年龄段

### 5. 品牌重塑后须能适配未来地市州划转类似资产承接
**这是项目的终极使命。**
- 模式：**基础通用标准（集团 SOP）+ 在地文化定制 = 可复制产品模型**
- Eric 原话口径："我有一个基础标准，然后我的在地文化植入可以一地一策"
- 承接对象：省内各地市州国资楼堂馆所划转资产
- 品牌架构须梳理清楚：国堰宾馆 ↔ 安逸集团 ↔ 旅投集团 的层级关系（既保单店辨识度，又明确归属）

## 五、品牌与 VI 配套要求

| 项 | 要求 |
|---|---|
| 品牌定位核心 | 先明确"我是谁"，所有内容生产与渠道选择围绕定位展开 |
| 客源分类 | 由 3 类调整增加**入境客**为独立大类（东南亚、港澳台为主，欧洲占比上升）|

| IP 商业化 | 手办、盲盒、文创周边、月饼；未来可 IP 授权 |
| 球室楼 VI | 刚装修完不动软装，**仅统一替换 VI 标识** |
| 现有 VI 问题 | 信笺信封全用安逸集团标识，与国堰暖色调不匹配，需调整呈现位置 |
| 报价方式 | **模块拆分 + 菜单式报价**，明确各模块服务深度 |
| 服务周期 | 集团偏好**共建共创长期服务**，不接受一锤子买卖 |
| 时间节点 | 10月完成方案调整与报价 → 11月集团审批（过三会）→ 下半年启动实施 |
