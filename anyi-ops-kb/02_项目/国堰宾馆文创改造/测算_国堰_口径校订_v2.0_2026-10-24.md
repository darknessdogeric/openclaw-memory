## 二、两处脚本级错误（均已实跑取证）

### 错误 1：人工成本被重复计扣（影响量级：IRR 差 23pp）

**脚本逻辑**（`toolbox/hotel_irr_calc.py` L198，修正前）：
```python
profit_before = gop_net - annual_depreciation - property_tax - property_insurance \
                - machine_insurance - rent_actual - p['labor_cost_annual']
```

**问题**：`gop = total_revenue * gop_rate`（`gop_rate` = 行业基准 GOP 率，**已含部门直接成本，其中已含人工**），脚本在利润端**又扣了一次** `labor_cost_annual`（国堰取 800 万/年）。

**财报决定性证据**（2026 年 1–8 月，单位元）：

| 行 | 科目 | 本年累计 |
|---|---|---|
| R11 | 营业成本 | 6,399,654.49 |
| R24 | 税金及附加 | 9,183.55 |
| R25 | 销售费用 | 844,220.09 |
| R26 | 管理费用 | 3,204,152.96 |
| R28 | 财务费用 | 616,987.30 |
| | **合计 = 营业总成本** | **11,074,198.39** ← 与财报 1,107.42 万**精确闭合** ✅ |

**人工成本归属**（收入成本费用明细表）：
- 人工成本合计（1–8 月）= **4,581,110.08**（占收入 48%）
- 其中客房成本人工 890,671.11 + 餐饮成本人工 1,682,792.66 + 其他成本人工 71,612.94
- **全部落在营业成本/管理费用之内**
- 而 **GOP 654,775.97（65.48 万）是营业总成本之下的层级** → **GOP 已是"扣完人工"的口径**

→ 脚本在 GOP 之后再扣一次人工 = **重复计扣**。

**修正**：新增开关 `labor_in_gop`（默认 `False` = 保持脚本历史行为，川宾/花园/新良既有结果**一字不变**；国堰用 `True`）。

### 错误 2：租金把"1–8 月累计"当成"年"

| 源 | 数值 | 性质 |
|---|---|---|
| 收入成本费用明细表 · 租赁费（1–8 月累计）| **147.27 万元** | 🟢 财报原件 |
| 8-10 现场调研纪要（Eric 亲历）| **每年 200 多万** | 🟢 Eric |
| 全量情报简报 10-17 | 场地年租金 **200+ 万元** | 🟢 会议 |
| **年化推算**（147.27 × 1.5）| **≈ 220.9 万/年** | ✅ **与 200+ 万口径吻合** |
| 10-14 测算采用 | 147 万/**年** | 🔴 **把 8 个月数当全年数，租金少计约 74 万/年** |
| 测算 v12.0 采用 | 1,473 万/年 | 🔴 与"200+ 万"差 6.7 倍，同源单位错误 |

→ 校订口径取 **租金 221 万/年**。

### 附带发现：人工基数取低
10-14 用 `labor_cost_annual = 800 万`（估算 30–40 人）；财报实际 **458.11 万 / 8 个月 → 年化 687 万**。基数差 113 万，但因属重复计扣，一并修正后不影响结论。

**三档一字不差复现** → 证明 10-14 的数字确实是脚本跑出来的，只是口径错了。

3. 4000 万档在**任何** GOP 率下都难以过 3.5% 门槛（ADR320 口径）
4. 5000 万档在 ADR320 口径下**全区间为负** → **5000 万方案在 Eric 自己的假设下不成立**

## 五、四个投资档的最终判断

| 档位 | ADR600/OCC70%（A3 修正）| ADR320/OCC65%（B3 修正）| 判断 |
|---|---|---|---|
| **3000 万** | IRR 28.61% · 3.4 年 · NPV +3,664 | IRR 6.93% · 6.7 年 · NPV −151 | ✅ **唯一稳健档**。两套假设下 IRR 均过门槛，NPV 仅微负 |
| 4000 万 | IRR 20.48% · 4.2 年 · NPV +2,736 | IRR 1.80% · 8.9 年 · NPV −1,087 | 🟠 强假设下成立，现实假设下不达标 → **需靠 GOP 率而非降价来救** |
| 5000 万 | IRR 15.01% · 5.0 年 · NPV +1,809 | IRR −1.76% · NPV −2,029 | 🔴 **10-14 报告"不回本"的结论需推翻**（A3 口径下正收益），但 **B3 口径下仍不成立** |

**🟢 核心建议（供 Eric 拍板）**：
1. **投资额锁 3000 万**，不报 4000/5000。理由：① 两套假设下只有 3000 万过 3.5% 门槛；② 4000/5000 的正收益完全依赖"ADR 达 600"（真实 ¥216.99 的 2.8 倍），不可作为上会承诺；③ 预留 1000 万隐蔽工程专项由集团另走口径，不混在经营层测算里。
2. **上会口径从"投多少"换成"GOP 率目标"**：把 **GOP 率 6.86% → 30%** 作为改造承诺指标写进考核（这是唯一能让 IRR 过门槛的杠杆）。
3. **ADR/OCC 目标要分层承诺**：ADR 从 ¥216.99 → ¥320（+47.5%）可承诺；OCC 从 37% → 65%（+28pp）需以营销投放和外部 IP 联动为前提，**不单独承诺**。
4. **租金口径统一为 221 万/年**（财报 8 个月年化，与"200+ 万/年"一致），并同步修正 v12.0 中的 1,473 万。
