## 一、决策摘要与请示事项

### 1.1 一页结论

| 项 | 结论 |

| **必要性** | 成立。国堰是集团"旗舰标杆""轻重分离""数智品牌赋能""特色餐饮"四个战略动作**同时压在一个单体上的唯一样本**；不改造，四项都无法验证 |
| **可行性** | 成立。四星级挂牌与涉外资质是稀缺资产；区位与会议宴会设施齐备；**区域内尚无"有文化主张的中高端全服式"占位者** |

3. **⚠️ 当前实际经营落在标准级（中端）**：ADR ¥216.99、OCC 37.05% —— **这是错位，不是市场限制**。
4. **⚠️ 房量与市场结构的匹配校验**：县域市场同类酒店客房普遍**不超过 200 间**，国堰可售 236 间高于县域通例 → **这是结构性负担，也是本次"重设计轻装修"而非"重装修"的原因**：钱要花在功能区位与会务承载上，不是房间数量上。

### 4.4 品牌与在地文化的绑定原则

| 原则 | 说明 |
|---|---|
| **只建一根柱** | 不做熊猫（泛滥）、不做道教（多家）、不做宋文化（有对标）—— **只做治水** |
| **品牌与内容互为载体** | 品牌 IP 是内容的表达形式，内容是品牌的兑现形式；两者不分离规划 |
| **显性给 4 处，隐性铺满** | 显性文化装置 ≤4 处（让人拍到），其余以材质、灯光、声音、气味、动线隐性铺满（让人住到）；三字经原文只在 2 处上墙 |
| **在地文化是取舍不是加法** | 三套文化语法（场景体系／品牌 IP 体系／内容产品体系）必须先合并，否则出图打架 |

# 第四篇　收益与分销

## 八、收益管理与定价机制

### 8.1 定价铁律

> **一切报价、协议价、套餐价，锚定 R1 实际 ADR（266.80 元），不是门市价 488 元。**
> 现状成交/门市 = **54.7%**（折扣深度约 45%）。以门市价为锚的折扣设计全部是虚的。

### 8.2 六项必留机制（先有口径，再上系统）

| # | 机制 | 内容 | 现状 |
|---|---|---|---|
| 1 | **房态与库存唯一口径** | 同一房态只有一个权威来源 | 缺失 |
| 2 | **价格与折扣决策规则** | 谁在什么条件下可以改价、改多少 | 缺失 |
| 3 | **渠道分配与配额** | 各渠道可售量与价格下限 | 缺失 |
| 4 | **提前期与最小入住** | 短提前期与长住政策 | 缺失 |
| 5 | **协议与团队锁房** | 协议价与团队配额 | 缺失 |
| 6 | **超售与拒售规则** | 风险处置预案 | 缺失 |

**🔵 与数字化的关系**：**顺序不可倒 —— 先有业务口径，再上系统。** 上系统但不建口径，只会把混乱固化。

### 8.3 数据口径治理（四维精分）

| 维度 | 拆分方式 | 当前状态 |
|---|---|---|
| **客源** | 团队 / 散客 | 集团数据尚不能精分 → **细分客源数据参考价值不高** |
| **渠道** | 自营 / 第三方 | 同上 |
| **市场** | 公开市场 / 非公开市场 | 同上 |
| **客房指标** | OCC / ADR / RevPAR | ✅ **有且有效，是本报告唯一量化基础** |

**🟢 治理顺序**：先统一这四个维度的口径 → 客源与渠道分析才有意义 → 渠道管理岗才有考核依据。**在口径统一之前，任何以"中介占比""散客占比"为依据的决策都不可靠。**

### 8.4 收益管理节奏

| 周期 | 动作 | 责任 |
|---|---|---|
| **每日** | OCC、ADR、RevPAR 与渠道结构复盘，出当日价格与库存动作 | 收益管理岗 |
| **每周** | 滚动调整未来 30 天日历定价与渠道配额，清理折扣过深的渠道 | 收益管理岗 ＋ 渠道管理岗 |
| **每月** | 校准产品与价格策略：哪条产品线卖不动、哪个渠道该砍、哪类房型该提价 | 收益管理岗 ＋ 运营 |
| **每季** | 房型结构与价格梯度复盘（与产品标准同步）| 产发部 ＋ 运营 |

| **G0** | 品牌名与架构定稿 | 是否进入 VI 与 IP 制作 | 停，回退定位与命名 |
| **G1** | 隐蔽工程 10 项分项清单与总投资估算出具 | 是否启动重投入 | **停**，保留第一与第三节奏 |

| **G3** | 3 个月渠道与餐饮毛利复盘 | 机制是否有效 | 换机制不换预算 |
| **G4** | 2027 Q1 合规答复与消防审查 | 展陈与表演类内容能否落地 | 收费表演不进第一批；只释放大堂文化区 |

**🟢 G1 是全案最重要的一道门**：**在这里停下，损失仅为设计费；越过去，3,600 万就是沉没成本。**
