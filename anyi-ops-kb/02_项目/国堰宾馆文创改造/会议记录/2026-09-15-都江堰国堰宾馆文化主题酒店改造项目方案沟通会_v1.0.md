## 四、文化锚点与 IP 体系设计(合作方提案)

### 4.1 为什么选"堰"作为唯一性 IP

**区域竞品文化锚点对比**:

| 文化锚点 | 区域内酒店 |
|---------|----------|
| **道教文化** | 多家 |
| **青城山文化** | 多家 |
| **熊猫文化** | 泛滥 |
| **"堰"文化** | **国堰独家,全球独有** |

**Eric 高度认同**:🟣"我选你们不是因为我跟龚老板认识,我是看到蜀源馆是怎么做起来的,一步一步在关注。"

### 4.2 治水三字经理念

| 三字经 | 转移应用 |
|-------|---------|
| **生套餐** | 服务姿态 + 内容 |
| **雨水分水** | 因势利导 + 动态平衡(动线 + 服务理念)|
| **贴身件** | 专业化管理体系 + 标准化 |
| **守正字** | 文化根基 + 守正创新 + 顺势而变 |

→ **形成符合都江堰在地特质的"经营哲学"**,可植入酒店 SOP。

### 4.3 "守堰人"熊猫 IP 设计

| 元素 | 取材 | 应用 |
|------|------|------|
| **基础形象** | 熊猫 | 全场景应用 |
| **冠束** | 束发冠 | 文化连接器 |
| **腰带** | 流水织金纹样 | 与治水文化呼应 |
| **警示** | 竹笼治水 | 不与普通熊猫 IP 同质化 |
| **道具** | 马叉 + 净水壶 | 与酒店主题相关 |

**关键**:可申请外观专利 + 全套商标 + 打造独家 IP。

### 4.4 沉浸式"千年守堰"故事主线

客人到店 → 代入"当代守堰人"角色 → 溯源承责 + 养心焕心 → 完整体验闭环

→ **打破传统酒店"仅提供住宿+餐饮"的单一属性**。

### 4.5 主题符号(马叉治水元素)

- 应用到餐具 + 印刷品 + 导视系统 + 全场景
- 支撑四川省主题文化酒店申报
- **四川 2024 唯一一个国家级家庭艺术申报**(巴中项目) 用了同一套主题符号系统

## 五、酒店公共空间改造初步方案

### 5.1 一楼改造重点

| 区域 | 改造内容 | Eric 关键判断 |
|------|---------|--------------|
| **入口长城浮雕** | **保留**作为镇店之宝 | "那个浮雕还不能丢,虽然和都江堰关系不大,但有历史渊源" |
| **大堂吧(进门右手边)** | 改造为文创售卖 + 艺术展览 + 接待功能 | "如果旁边就是会议室,大堂吧就废了,没人坐。**功能区域可以重新摆**" |
| **中庭雨棚下方** | 中心艺术品(马叉治水场景)+ 投影技术 | 解决"视觉元素杂乱、像农家乐"现状 |
| **廊道** | 微型博物馆化 + 玻璃展罩 + 介绍牌 | 让小朋友觉得"贵,不能摸,艺术品" |
| **三楼 Q 空间** | 三折屏全息投影 + AR 交互 | 解决都江堰水利工程"水下巧思看不见"难题 |

### 5.2 二楼改造重点

| 痛点 | 现状 | Eric 要求 |
|------|------|----------|
| **早餐厅问题** | **没有独立早餐厅**,点位随场景变动 | 客人从电梯出来"找不到早餐"是最大反馈 |
| **大包间稀缺 + 中小包间利用率低** | 5:5 餐房比,大包间使用率高 | **通过文化主题包装提升包间营收能力** |
| **动线混乱** | 客人上楼需绕行才能找到功能区 | **重新规划客人与员工动线** |
| **二楼大会议室外院** | 柱子限制婚宴 | 一楼会议室无柱子,但会议量大 |

### 5.3 客房改造策略(轻量化)

**Eric 明确**:
> "客房一定要整体动,但要轻量化,卫生间必改,其他装饰装修轻改"

**方案**:236 间客房**不全改**,**选取数十间**打造水文化主题房(水纹灯光 + 特色软装)。

### 5.4 十一楼行政酒廊重构

| 原状态 | 改造方向 |
|-------|---------|
| 行政楼层普遍荒废 | 改造为"宴官书房"共享空间 |
| 使用率极低 | 结合道教康养理念 |
| 老酒店行政楼层问题 | **共享客厅概念**(代价是减少客房数)|

**Eric 解释**:
> "中国大部分酒店没搞懂外资品牌的经营商业逻辑,行政楼层是客房溢价的主要支撑。行政楼层荒废是因为执行颗粒度不够细。"

### 5.5 副楼(球室楼)问题

| 现状 | 问题 |
|------|------|
| 党校培训基地,装成"全季风格" | 简化处理 |
| 客人网上看主楼图,实际入住副楼 | 产品差异导致落差 |
| **风格可不统一,动线必须统一** | Eric 明确态度 |

### 5.6 博观楼 + 汤池(未规划完整)

| 区域 | 现状 | Eric 要求 |
|------|------|----------|
| **博观楼** | 婚宴配套,顶层有露台,底下两层 | **大有文章可做**,独立建筑 |
| **汤池** | 临时挖的,**没独立核算** | 不能叫温泉(是烧的),**应独立经营**(目前是送的) |

**Eric 关键判断**:
> "博观楼有大文章可做,因为它是独立建筑,顶层还有露台。"
> "汤池不能叫温泉(是烧的),这个有严格要求,否则就是欺诈。"

## 七、投资节奏与落地路径(合作方提案 + Eric 调整)

### 7.1 投资规模

| 项 | 数值 | 备注 |
|----|------|------|
| **总投资** | **4000 万左右**(上限 5000 万)| "10 年租赁期内可回本" |
| **Eric 案例参照** | 上海中旅停业 5 年老酒店,投入 2000 万改造完成 | 标杆 |

### 7.2 三阶段投资节奏(合作方原方案)

| 阶段 | 时长 | 投资占比 | 核心动作 |
|------|------|---------|---------|
| **第一阶段** | 半年 | **40%** | 1-2 个文化小空间 + 文创打样 + 首期研学 + 主题雅集 |
| **第二阶段** | 半年 | **45%** | 全区域文化场景落地(会议 + 餐厅 + 客房 + 工区 2.0) |
| **第三阶段** | 一年 | **15%** | 标准化 SOP 手册 + 运营手册 + 样板店定型 |

### 7.3 Eric 关键调整:投资优先级重新排序

**Eric 原话**:
> "你说文创投入 40% 可能多了,我们更多通过活动逐渐放大。改造首先要解决最基础的问题:隐蔽工程 → 动线 → 硬装 → 软装 → 文创活动。"

**调整后的优先级链**:
```
1. 隐蔽工程(管线 + 机电) ← 最基础,占 20-30%
2. 动线优化(功能排布) ← 解决功能区摆布问题
3. 硬装改造(基于动线)
4. 软装更新
5. 文创活动 → 通过持续活动逐步放大(而非前期重投)
```

### 7.4 隐蔽工程投入比例

**Eric 明确**:4000-4500 万投资中,**20-30% 花在隐蔽工程**(管线、机电) — 这是基础前提。

## 八、Eric 输出的集团层面项目定位(🟢 最权威)

### 8.1 总体定位

> **全服四星 + 在地文化主题 + 车展联营联合体的综合性展示酒店**,面向全年龄段客群。

| 维度 | 定位 | 备注 |
|------|------|------|
| **星级** | 保留四星,**不冲击五星**(不具备条件)| 全服标准可向五星靠 |
| **品牌** | "国堰宾馆" — **国字头注册品牌**,独一无二 | 再注册不到 |
| **客群** | **全年龄段**(不局限单一群体)| 政务 + 商务 + 研学 + 亲子 + 入境 |
| **运作模式** | 文创改造 + 联营车展 + 新媒体矩阵 + 新零售 + 数字化穿透 = **五大板块** | "超级单店"概念 |

### 8.2 集团层面使命(双重)

#### 使命 1:承接省内各地市州国资楼堂馆所划转的样板品牌

**Eric 原话**:
> "国字头注册品牌,具有独一无二性。在未来,我们安逸集团承接省内大部分国有资产下属的楼堂馆所的划转,在一些比较有标志性的地方,可能会把这个牌子拿去承接地市州的相关产业。"

**含义**:
- 国堰宾馆是**样板店**
- 文化植入(在地适配性)+ 标准体系(基础通用性)= 可复制产品模型
- 未来省内其他国资楼堂馆所改造 → 用"国堰模式"

#### 使命 2:政务 BU 核心载体

**Eric 原话**:
> "它现在是我们党校的培训中心,所以它有政治使命。因为大部分国资都在设置政务 BU,政务型酒店事业部,它以后可能就是金牛宾馆体系的——金牛是五星高档,国堰是四星(或第四周)档次的。"

**含义**:
- **金牛宾馆 = 五星高档 + 高端政务接待**
- **国堰宾馆 = 四星/第四周 + 文化主题 + 政务/会议/培训**
- **两者形成"高低搭配"覆盖不同层级政务接待**

### 8.3 产品模型可复制性

**Eric 完整表述**:
> "在酒店行业来说,我有一个基础标准,然后我的在地文化植入可以一点一亿。"

**结论**:
- **基础通用标准**(集团 SOP 体系)
- **在地文化定制**(每个项目独特)
- = **可复制产品模型**

→ 这是集团"地市州拓展"的核心抓手。
