## 三、设计方方案要点（华可都市文旅）

### 3.1 一楼：三大板块 + 10 个堰文化主题点位

**三大功能板块**：① 接待 ② 文创/文化输出 ③ 会议

**动线重构（核心）**：
- 入口即"**四六分水**"分流 —— 住客走中间动线、会议客人走侧面动线、员工动线集中后侧，**完全避免动线交叉**
- 原大堂旋转楼梯**加建移出到建筑外侧**（幕墙包裹），解决拥堵
- 原大堂卫生间拆除扩大，打通入口→端景视线；挑空区设主题文化灯形成视觉中心
- 两个**异形接待台（鱼嘴概念）**，可双向服务，背面兼作服务台
- 左侧靠窗设**大堂吧**（堰文化 + 文创元素，收费咖啡酒吧）+ 轻文创展示区（无会议时陈列、有会议时切换）

**10 个主题点位**：① 拜水都江堰（入口堰坝水景）② 四六分水前厅 ③ 堰关怀待客厅 ④ 李冰都江堰（文创点位）⑤ 鱼嘴接待 ⑥ 门厅卧铁"三字经"艺术装置 ⑦ 迎宾竹编装置 + 生态堰坝景观 ⑧ 挑空"水从天降"主题灯具 ⑨ 端景墙治水文化艺术装置 ⑩ 过道堰文化历史 + 文创售卖点（含康养内容）

**新增功能**：小会议室 → **非遗手作体验空间**；原健身房 → **数字艺术多媒体体验空间**；预留**临展布展空间**（策展属性）

### 3.2 二楼：早餐厅固定化

- 原早餐厅位置不固定 → 固定蓝色区域为早餐厅
- 拆除挑高区原有栏杆，改隔断围合（消除走道干扰一楼）
- 早餐厅面积约 200–300 ㎡，餐位 **86 → 104–105**
- 设布菲台 + 明档，可灵活分割或转为包间
- 家具存放空间移至负一楼 → 负一楼新增 1 个包间，最终预留 **5 个包间**

### 3.3 十一楼：行政层重做（被否后转客房）

- 原案：整合左侧 3 间客房 → 燕文化书吧 / 卡座茶台 / 艺术展台 / 小型沟通会议区 / 疗愈冥想空间
- **🟢 Eric/集团否决理由**：十一楼改公共空间**坪效极低、经济价值很小**
- **两个替代方向**：① 恢复为客房提升坪效 ② 早餐厅整体移到十一楼顶楼（景观优势）→ 牺牲少量客房换体验
- Eric 判据："现有 236 间客房对县域市场足够，**通过提升均价替代单纯增加客房数量**"

### 3.4 色彩与材质（堰文化提取）

**主色调**：火焰灰 · 暖石褐 · 马茶木色 · 珠江碧 · 浪白夜蓝
**材质母题**：反复使用**马叉木元素做结构变形**
**分空间应用**：宴会厅水元素 / 包间融入治水三字经与治水工具 / 灯具用马叉结构 + 竹篓元素 / 客房延续蓝绿调 / 博观楼设**二郎茶坊**

### 3.5 产品体系与客源重构

**六字诀产品线**：吃 · 住 · 行 · 玩 · 拍 · 买 · 学
主题客房 / 互动剧目 / 打卡点 / 堰主题晚宴 / 马从宴语文创 / 水文化研学产品

**策展联营**：联合**四川省美术家协会**定向创作 → **季季大展 · 月月小展**
- 春：放水文化节展览 ｜ 夏：清水研学季 + 小小堰工夏令营 + 水科普互动展 ｜ 秋：天府艺术节（美术院校驻留/摄影/美食展）｜ 冬：退休文化季

**文创新零售**：大堂/客房文创展示 + 客房扫码小程序购文创菜品与文创餐具 + 伴手礼；对接**华可优米电商平台** + 川商投货源 + 旅投场景

**客源五源结构**（从单一 → 五源）：科普研学 / 亲子家庭 / 文化旅行 / 入境游 / 自驾游 —— 稳定存量、扩大增量、建立自主渠道

### 3.6 三阶段实施与投入

| 阶段 | 内容 |
|---|---|
| 第一阶段 | 主楼外观改造 + 园区空间改造 + 文创 1.0 + 美院入驻 + 首批研学课程落地 |
| 第二阶段 | 全部文化空间呈现 + 自主文创开发 + 研学体系完善 + 主题文化 SOP 初稿 |
| 第三阶段 | 主题 SOP 定稿 + 运营手册定稿 + 样板店验收 → **启动集团品牌重塑** |

**预估总投入约 1000 万，第一阶段约 70%（主要用于装修改造）**

## 四、经营团队当场提出的四类硬伤（方案被实质修正）

| # | 硬伤 | 修正方案 |
|---|---|---|
| 1 | **连廊串联副楼影响消防车通行**（国堰为高层建筑 + 消防重点单位）| 连廊改**架空高架**，保证足够高度与宽度，不占用车道，消防车与大巴车均可通行；**同时强化酒店入口辨识度**（解决"从成都方向开车过来看不到酒店招牌，容易开过"）|
| 2 | **早餐厅面积不足**（236 间客房早餐需求）| 电梯楼梯区域 + 千禧厅旁包间一并划入早餐厅；一楼锦绣厅调整为灵活综合厅；包间数由集团代表确认"现有包间数量可满足商务需求" |
| 3 | **一楼餐饮杂物间被取消，缺储物空间** | 预留办公室调整为餐饮杂物间；二楼保留原杂物间；艾灸室移至负一楼；大堂大型壁画移至博观楼或入口走廊；按四星标准保留贵宾室，避开客人动线交叉 |
| 4 | **十一楼坪效过低** | 恢复客房 或 早餐厅移顶楼（见 3.3）|

**其他经营端要求**：
- 客房做**开放式卫浴**提升空间利用率；卫生间做**通场大面台**（满足女性客群置物）
- 本次改造**必须同步含灯光、园林、弱电三个板块**：弱电解决网络分散需重复连接 → 一体化网络；灯光做照度设计，改变平光无氛围；园林纳入博观楼整体考虑，求是楼刚完成无需调整，**三栋楼外立面剥落严重需同步修复**
