| 数据点 | 数值 |
|---|---|

## 五、国堰改造初案（凡驰 · 经营层面口径）

| 项 | 数值 / 内容 |
|---|---|
| **改造定位** | 都江堰**山水道养文化度假酒店** |
| **核心原则** | 不搞大拆大建；**轻改造撬动品牌升级**；钱花在用户感知处 |
| **经营层面预算** | **300–400 万**（+ 品宣 50 万）|
| **周期** | 3–4 个月，**10 月下旬启动施工**，分阶段不影响营业 |
| **预算分配** | **50% 投入大厅与庭院**（大厅改造约 120 万 + 氛围重塑约 60 万 + 庭院改造约 60 万）|
| **大堂改造** | 单一功能 → **六大功能区**：接待区 / 水文化展示区 / 文创咖啡区 / 茶道静心区 / 文旅服务区 / 川史展览区 |
| **停留时间目标** | 从 **5 分钟 → 30–60 分钟** |
| **氛围四维** | 视觉 / 听觉（古琴）/ 嗅觉（草木檀香）/ 色彩 |
| **主题客房** | 水文化 · 道养 · 林盘院落 **三种主题房型**，首批试点 **2 间** |

**⚠️ 口径边界（重要）**：本场明确 **"隐蔽工程、机电设备更新由集团层面专项推进，夏总整体负责，不在本次经营层面方案讨论范围"**。因此 300–400 万 ≠ 项目总投资。

## 六、营销传播方案（品宣 50 万 · 对接新媒体统筹板块）

| 6 个月目标 | 抖音总曝光 3000 万 · 涨粉 3 万；公众号涨粉 8000 · 视频号涨粉 1 万；总曝光 5000 万 · UGC 500 篇 · 等效广告价值 500 万+ · **ROI ≈ 1:5.5** |

## 七、经营端痛点（经营团队提出）

| 痛点 | 细节 |
|---|---|
| **最大宴会厅** | 层高不足 + 柱子遮挡 → **高端会议流失主因** |
| **大堂** | 面积大但功能单一，基本不产生收益 |
| **早餐厅** | 不固定，与婚寿宴厅混用 → 菜品变冷、体验差 |
| **会议室** | 建成多年、硬件陈旧需升级 |
| **客源结构** | ① 会议（客房+餐饮+会展最大收入）② OTA（大假收入）③ 协议客户 ④ 上门散客 ⑤ 旅行社 |
| **餐饮** | 已有注册品牌 **"夜映水席"** 主题宴，缺主题包间场地；主力包间陈旧 |
| **非房** | 盘活汤池、延伸特色体验产品、打造差异化餐饮产品吸本地客群 |

**🟢 Eric 现场总结**：
> "**我们做改造不是为了做出一个漂亮的东西，一切都是为了后续的经营服务。**"
> "都江堰县域星级酒店普遍是**小客房大餐饮**，公共区域的优化是本次改造的核心。"

## 八、🟢 品牌重塑的战略定性（本场最重要）

> "安逸集团接下来会持续推进**品牌重塑**，本次国堰宾馆改造是**品牌重塑的单点穿透项目**。国堰宾馆作为全服务酒店，覆盖全年龄段客群，核心是**稳固存量同时寻找增量**。"

**（9/23 13:29 场补充）**："项目是安逸集团**品牌重塑的试点**，包含**品牌重塑、在地文化改造、策展联营、新零售、数字化穿透**五个核心部分。"

**五板块正式定型（9/23 场 Eric 表述）**：
```
1. 品牌重塑
2. 在地文化改造（堰文化 / 水文化主线）
3. 策展联营
4. 新零售
5. 数字化穿透
→ 最终做单点突破，形成可复制的标准
```

**🟢 Eric 存量改造定调**：
> "中国酒店行业已经进入**存量时代**，存量改造不建议大拆大建，尽量在不动原有基装的前提下调整空间格局，控制改造成本，实现经营提升。"
> "**过去十年十五年标准化的红利吃尽了**，现在再做标准化非常困难，**差异化是我们需要深耕的方向**。"
> "**在地文化挖掘是核心护城河，这是外地团队比不了的。**"
> "**运营前置** —— 什么叫运营前置？没几个人搞得懂。"
> "**很多酒店改造你是很容易把酒店装出来的，但是运营怎么办？这个才是最重要的。**"
> "**运营团队是最了解运营现状的，实践出真知。**"
