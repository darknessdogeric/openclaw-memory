## 一、核心结论

> **本场是空间方案的定盘场。** 三个关键决策落地：① 一层**保留承重柱（方案三）**，因主楼与裙楼结构分开、拆柱有结构风险；② **全日制餐厅拟迁至顶楼**（Eric 现场提出，取消部分顶楼客房，释放二楼给宴会厅，一楼预留策展联营空间）；③ **博观楼 + 汤池整合为独立经营单元**（入口调整、独立接待、园林动线分流、浴衣客人不再穿行主楼）。同时明确了**"国"与"宴"的文化释义**、**"道/养/潮"三条文化主线**、**六感体验体系**。

## 四、现状痛点（设计方梳理）

**硬件老旧 · 空间低效 · 文化零散 · 品牌缺位 · 经营客群单一**

**可拓展客群**：商务政务接待 / 研学旅居 / 旅行度假 / 康养疗愈 / 文旅体验 / **海外高端考察客群** → 打造都江堰对外文化展示窗口

**企业底蕴**：扎根都江堰 20 余年 · 国资委党校分校三个重要教学点之一 · 四川省旅游安全二级达标首家单位 · 长期研学帮扶山区贫困群体

## 五、"道 / 养 / 潮"三条文化主线（核心结构）

| 主线 | 对应 | 空间风格 | 材质色彩 |
|---|---|---|---|
| **道** | 治水哲学 · 讲座教学 · 商务接待 · 研学团体 | 庄重克制、有秩序感 | 深色木纹石材、暖灰基调 |
| **养** | 道养文化 · 汤池 / 艾灸 / 药膳 · 康养度假 | 温润松弛、有包裹感 | 亚麻布艺竹编、暖黄草木色 |
| **潮** | 年轻客群 · 文化爱好者 | 轻盈有趣、具在地感 | 浅色木材、自然光 + 潮流点缀 |

**🟢 Eric 在 9/23 场的补充**：堰文化主线 + 党校属性 → 兼顾政务审美 + **都江堰治水廉洁文化**，契合党校培训需求。

**空间定位**：**以水为形，以文为脉** —— 从自然、文化、艺术、科技四维升级；提取水的不同形态用于吊顶、地面、灯光、软装、艺术装置。

## 七、文创开发（借鉴亚朵模式）

- 针对**道 / 潮**不同主题开发：联名房卡 · 伴手礼 · 限定礼包
- 衍生产品：**家纺、日用品、洗护用品**
- 借鉴**亚朵模式**开发自有品牌衍生产品，强化品牌认知

**三阶段落地**：
```
1.0  让客人感知变化
2.0  完成研学产品、文创经营落地（不影响现有运营）
3.0  文化 IP 对外输出 → 有文化、有记忆、有溢价的本地名片 → 可持续盈利与资产增值
```

## 八、空间方案要点

### 8.1 户外总平

- 依托现有两个主出入口**新增环形落客车道**，重新规划停车场
- 车位 **86 → 80**（减 6），新增大量绿化 + 生态康养池叠水景观
- 球室楼↔博观楼**园林内部动线保持连通**（未做阻断）
- 入口景观：原中央大型水景观 → 调整至一、二区域中间，**缩小为椭圆都江堰微景观**，预留拍照与行架搭建空间 + 大巴转弯停靠动线

### 8.2 一层三方案对比（🟢 决策：取方案三）

| 方案 | 内容 | 结论 |
|---|---|---|
| 方案一 | 保守：仅改造下半大厅，保留上部会议室；主入口改弧形落客车道；大堂挑空；多功能厅重规划；入口壁画改水木主题投影 | — |
| 方案二 | 大幅：原会议室改**宴会厅**，扩宽主动线分流，**440 ㎡ / 230 人** | — |
| **方案三** | **保留承重柱**，加隔断层可分多个小会议室 / 整体打开作宴会厅，预留更衣室·化妆间·储藏室，空间利用率最高 | ✅ **采纳** |

**🟢 采纳理由**（Eric + 结构专业判断）：主楼与裙楼为**分开结构**，原有承重柱**不可随意拆除，拆除存在结构风险**。

**🟢 遗留问题**：婚宴客人习惯**从正门进入迎客**，无法全部引导至后侧 → 正门区域需统筹规划婚宴与住客动线，待后续优化。

### 8.3 二楼全日制餐厅（现状讨论）

- 方案：原区域全部拉通，**500 ㎡ / 131 人**；牺牲 1 个包间位新增小厨房做明档
- 取餐区总长 **23 m**（15 m 常规 + 4 m 双岛台，可另增设备餐台）
- 🟢 **经营方修改意见**：
  - 明档长度不足 → **四星级标准需 8–9 m 明档**
  - 明档需预留采光给就餐客人，调整布局
  - 需满足**全天运营**（早/中/晚 + 下午茶），挖掘本地散客营收
  - 一楼宴会厅**无传菜梯**、分餐区不足 → 重新规划后场分餐区与传菜动线
  - 厨房须按规范设**双通道**（食品安全 + 消防）

### 8.4 客房改造

| 项 | 要求 |
|---|---|
| 过道 | 直线型 → **房门内凹**，增加层次感与开阔感 + 提升开门私密性 + 门牌灯光 |
| 卫生间 | 改**半开放式**，洗手台/迷你吧外放，干湿分离 |
| 观景房 | 方案一：压缩卫生间做半开放式；**方案二：进一步压缩卫生间，浴缸移到弧形玻璃观景位**，夹丝玻璃半隐私，"更出片" |
| 地面 | **木地板 + 块毯**组合（兼顾档次与防潮，块毯可随时更换）|
| 房型 | 四星标间**床宽 1.35 m**；部分双床**可拼接大床**的灵活房型 |
| 后场 | 每层设工作间，**2–3 层共用消毒间**；探索布草井；一楼布草收发间（通风干燥 + 与收货平台分离）|
| 楼层差异 | 8 楼已有工作间；11 楼 / 13 楼布局不同；13 楼有 3 个套房 → 需区分调整 |
| **客房数** | 改造后主楼总房数**可增加 9 间 → 176 间**（167 + 9）|

### 8.5 博观楼

| 楼层 | 功能 |
|---|---|
| 首层 | 茶咖区（座位重排 + 组合大吧台，可办读书会/插花/焚香、宴请休息等候区）+ 多功能休闲区（动静分流）+ 艾灸 SPA 区 |
| 二层 | 保留棋牌包间 |
| 三层 | 棋牌包间 + 功夫茶室 + **新增户外露台**（原拟打造灵岩山、青城山最佳观景点 → **经营方指出三楼主要看到居民楼，调整为对内景观**：增加构筑物、凉亭、文化元素，做成可使用的文化空间）|
| 外挂电梯 | 预计投资 **24–25 万**，需评估收益与空间占用，**暂不确定** |

### 8.6 🟢 Eric 现场提出：全日制餐厅迁至顶楼

> 取消顶楼部分客房，利用顶楼观景优势打造**日咖夜酒**聚合空间；可容纳**健身 + 自助洗衣**；释放二楼空间给宴会厅；一楼预留**策展联营**公共空间。

**讨论细化**：顶楼单层约 **700 ㎡** → 200–300 ㎡ 做健身 + 洗衣，其余做全日制餐厅；**健身房因噪音问题可调整至 8 楼或 11 楼**。

**空间自由度原则**：减少固定装饰占用 —— 原大堂可旋转隔断门占用空间，**建议取消**。

### 8.7 🟢 博观楼 + 汤池整合为独立经营单元

- 原球室楼入口**调整到博观楼**
- 通过园林景观规划实现动线分流，**统一管理、降低人力成本**
- 解决**浴衣客人穿行影响其他客人体验**的问题
- 汤池与茶楼原已留连通门 → 打造"汤池 + 茶楼"互动产品包，延伸体验内容、**增加非房收入**
- 外部设独立接待入口，无需绕经主楼（需现场勘测后确定布局）

### 8.8 园林与外立面

- 现有区域已有同类景观，**不重复设置**
- 叠水景观需优化宽度
- 解决**雨天主楼↔博观楼无遮挡** → 考虑增设**风雨廊**
- **三栋楼外立面剥落严重**，需同步修复
- **路口昭示性**：从成都方向开车过来看不到酒店招牌，容易开过 → 需优化

### 8.9 灯光（独立板块）

- 现状：**全部白光直射光源，未做灯光分层设计**
- 要求：通过不同色温营造空间氛围感
- 需做**照度模拟**：桌面照度 **306 流明**、地面平均照度 **400–105 流明**（原文如此）
- 导示牌、门牌设计搭配灯光

## 九、🟢 Eric 品牌拓展与推进节奏

> "国堰品牌未来将拓展到其他地市州项目，因此需要**提炼可复制的品牌主线**…保证品牌调性统一的同时适配不同项目。"
