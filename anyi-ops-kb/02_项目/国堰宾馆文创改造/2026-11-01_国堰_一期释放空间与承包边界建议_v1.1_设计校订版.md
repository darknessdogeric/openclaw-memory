### 1.2 「演展中心」的官方定位（空间与文化策略方案参考方 P61 原文）
> 集展览、文化交流功能于一体，可承接**小型画展、艺术展演、主题沙龙、产品推介及会务活动**。**活动式展板及预留吊顶轨道。**
> 文创售卖：依托都江堰本土文化 IP，开发系列主题文创产品，将山水、熊猫、古堰元素转化为可带走的文化纪念载体，拓展酒店二次消费场景。

> **这与 Eric 说的「展览、线下主题文化聚会、独立/民间/学生艺术人和团队展览、拍卖」几乎完全重合。** 设计方已经把最关键的两件事做进去了：**可变展陈（活动式展板 + 吊顶轨道）** 与 **演出/活动后台齐备（备餐间 + 家具库 + 音控室 + 化妆间）**。

### 1.3 业态策划（空间与文化策略方案参考方 P59/P63/P64）

## 二 · 一期承包范围（校订后）

### 2.1 建议：**主楼一层，一个经营体，不跨楼**

| 交出去 | 面积 | 运营商的经营内容 |
|---|---|---|
| **9 演展中心 397㎡** | 397 | 展览、独立/民间/学生艺术家团队展、主题文化聚会、产品推介、拍卖（首批不做） |
| **7 大堂吧** | 约 40–60 | 咖啡、甜点、酒水（茶席形态，非「酒吧」） |
| **3 文创区** | 约 30–50 | 文创零售 + 导览/研学报名台 |

**合计约 470–510㎡，全部在主楼一层，动线连续。**

### 2.2 为什么一期**不**含博观楼书咖
| 理由 | 说明 |
|---|---|
| **两栋独立建筑，中间是庭院步行道** | 一期就跨楼 = 两套后勤、两条客流、一套管理半径；而且「咖啡→展→零售」的叙事线会断 |
| 空间连续性优先 | 文化体验的价值在一条动线里完成（文创区→大堂吧→水幕墙→演展中心），跨楼就把这条线切断 |
| 客群不同 | 博观楼是康养客群（汤池、中医亚健康）+ 散客场景，与主楼的政务/研学/年轻文创客群不同频 |
| 内部已定独立经营 | 汤池须独立核算，不与承包区混算 |

→ **博观楼书咖列为二期**：一期跑通「一栋楼一个经营体」的模型，二期再把书咖作为运营商的**自选第二个点位**（或独立招标），并以「客群互补」而非「面积相加」作为二期理由。

### 2.3 大堂本体（6）不交给运营商，但咖啡可以交给它
大堂是**不可外包的门面**：所有客人（含政务客、研学团队）的第一印象，也是酒店的自有品牌资产；水幕墙（8）与木雕摆件（2）是主视觉。
→ **建议**：大堂接待、等候、水幕墙、木雕摆件、主视觉留酒店；**只把 7 大堂吧这一块可经营位交出去**（或酒店自营咖啡、运营商供产品与内容，二者分成）。
→ **若 Eric 坚持「整个大堂交给运营商统一经营」**：合同必须加四条——① 酒店品牌露出强制 ② 酒店保留接待区、等候区、主视觉与全部导视 ③ 第三方经营不得影响酒店服务动线与政务接待动线 ④ 食品安全、消防、营业性演出三项许可由运营商独立持证（不可挂靠酒店）→ **这四条正是 G3 的「五分离」**。

## 三 · 五个必须向设计方与运营提出的问题（从这份提案里读出来的新事实）

| # | 问题 | 为什么必须问 |
|---|---|---|
| **1** | **397㎡ 多功能厅改演展中心，MICE 会议容量从 961㎡ 降到 564㎡（-41%）**。谁给对冲方案？ | 国堰是**国资委党校分校三个教学点位之一**（提案 P15），政务会务与干部培训是它的资质优势与政治敏感点。最大的一间会议厅改作展陈，班次与政企大单的承接能力下降，必须有替代方案与排期规则 |
| **2** | **「艺术展演」是否构成营业性演出？** 397㎡ 空间做收费表演，需「演出场所合格证明」+ 县级审批 3 日（涉外/港澳台省级 20 日）；而「小型画展、主题沙龙、产品推介、会务」里哪些不需要审批？ | **须都江堰文旅书面答复**。这一条决定档期长度、审批成本，以及运营商的排期自由度；也决定「拍卖/驻唱」类内容能不能进 |
| **3** | **两套文化语法并存，必须上会前统一**：空间与文化策略方案参考方提案用「道 / 养 / 潮」三主线 + 品牌架构（母品牌 + 道国堰宴 / 图艾康养 / 有幸遇见 / 少年国学院 四 IP）；内部 10-24 挂接表用文化母体方案参考方《治水三字经》十场景。挂接表自己就写了「未经文化母体方案参考方确认…否则两套语法打架」 | 不统一，设计方出图与运营商内容会各说各话。**建议以空间与文化策略方案参考方的道/养/潮为对外品牌语法，把《治水三字经》降级为「空间设计任务书的内部结构」**，避免两套都对外 |
| **4** | **「活动式展板 + 预留吊顶轨道」= 展陈可变、可换展不拆墙** → 合同要写清：展陈装置由运营商投入、拆装与保管归其、酒店提供吊挂与电力条件；换展频次下限（每季 ≥1 次） | 这是承包模式的经济学基础——**把固定装修换成可变装置**。这条不写死，运营商会减少换展、空间退化成一次性布景 |
| **5** | **房数疑团结论**：提案 P14 写「客房合计 **236 间**」（主楼 + 求是楼两大组团）；10-28 方案按「国堰楼 **176 间**」、测算按 236 间 | **236 = 总房数，176 = 主楼（改造范围）**，此前「四个房数」的矛盾可结。IRR 与 ADR 测算须统一用「可售房」口径并注明 |

## 四 · 三个对招商与谈判有用的利好

| 发现 | 价值 |
|---|---|
| **现状痛点第一条是「共空间利用率低、复用性差」** | 397㎡ 从会议室改成演展中心，本身就是「复用性」的答案：**可变展陈让它白天/夜间/工作日/周末都能用**。这正是承包模式成立的经济学基础，可以直接写进招商 RFI 的问题陈述 |
| **文创区（3）在主入口第一动线，文创售卖区（10）在博观楼一层** | 零售有两个现成的高曝光点位：住客动线 + 对外动线。文创零售不需要额外引流成本 |
| **后台齐备**：备餐间（11）紧邻演展空间；家具库（19）、音控室（18）、化妆间（20）在其侧后方 | **运营商接手几乎不需要另建后台**——这是招标谈判中最值钱的一条，要在 RFI 里写明「提供既有后台支持」，换运营商的零后台成本 |

## 五 · 一期谈判条款（针对本设计的增量条款，叠加 11-01 承包方案的 18+6 条）

| # | 条款 | 写法 |
|---|---|---|
| 1 | **经营位定义** | 逐项写明：9 演展中心 397㎡ + 7 大堂吧 + 3 文创区；附平面图编号，不得越界占用 4/5/6/8/10 |
| 2 | **后台提供** | 酒店提供备餐间共用、家具库/音控室/化妆室使用权、吊挂与电力条件；运营商自投展陈装置并自行保管 |
| 3 | **换展义务** | 每季 ≥1 次主展、每月 ≥2 场活动（对齐场景 9 的「春放水/夏研学/秋天府艺术/冬祈福」）；未达扣减 MAG 或触发解除 |
| 4 | **MICE 档期优先** | 演展中心档期须让位党校培训班与政企大单；约定年度 MICE 保留档期（建议 ≥60 天） |
| 5 | **营业性演出前置** | 运营商负责取得演出许可与「演出场所合格证明」；未取得许可的节目不得排期；酒店配合出具场地证明 |
| 6 | **拍卖** | 首批不引入；第二年引入须持牌拍卖企业主办、档期预留 ≥3 日、酒店不得代持 |
| 7 | **形态约束** | 大堂吧按「茶席 + 咖啡 + 活动酒水」做，不做「酒吧」（规避未成年人禁入义务）；酒水售卖时段与范围写入合同 |
| 8 | **数据归属** | 票务、POS、会员储值数据实时回流酒店会员体系；运营商不得二次营销 |
| 9 | **品牌露出** | 联合署名「国堰宾馆 × XX 文化空间」；酒店会员权益可用、房券可兑换；不得另设近似品牌 |
| 10 | **去 IP 化降级** | 合作到期后的撤展与复原责任、装置归属、酒店优先回购条款 |
| 11 | **二期选择权** | 博观楼书咖为二期自选点位；一期运营商享有同等条件优先参与权（但不得以优先权压低一期条件） |

## 六 · 结论

**放主楼一层这一处：397㎡ 演展中心 + 大堂吧 + 文创区，一个经营体、动线连续、后台现成。**
**先不放博观楼**（两栋独立建筑，中间是庭院；一期跨楼会断叙事、增后勤），留作二期自选点位。
**大堂本体留给酒店**——它是可以外包的内容场，不是可以外包的门面；咖啡交出去，接待区、等候区、水幕墙、主视觉不交。
**但要先解决两件事**：397㎡ 改演展后 MICE 少 41% 的对冲方案，以及「艺术展演是否构成营业性演出」的属地书面答复。
