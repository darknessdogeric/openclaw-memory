# 集团旗下酒店价格倒挂诊断报告 v1.0

> **编制时间**：2026 年 9 月 17 日
> **触发**：Eric 14:23「看看有哪些酒店价格倒挂了」
> **定义**：价格倒挂 = 同一房型同一日期，会员价 / 协议价 / 散客门市价 / OTA 价之间出现非合理价差（高忠诚度客群价格 ≥ 低忠诚度客群价格）
> **方法**：基于全网公开价对比（携程/Trip.com/官方/官方 APP）+ 集团内部安逸荟会员体系 + 行业研究报告 + 头部集团公开数据

## 一、什么是价格倒挂（标尺）

### 1.1 五种价格层级（按酒店行业通行惯例）

| 层级 | 名称 | 价格关系 | 用途 |
|------|------|---------|------|
| 第一层 | 官网灵活价 | 基准价（100%）| 临时散客 |
| 第二层 | OTA 零售价 | 较官网低 5%-10%（含佣金后平台补贴）| 比价客群 |
| 第三层 | 会员价 | 较官网低 8%-15% | 高频忠诚客 |
| 第四层 | 企业协议价 | 较散客低 15%-20% | 商务团队 |
| 第五层 | 供应商批发价 | 较散客低 20%-30% | 差旅管理公司 |
| 第六层 | 渠道大促补贴 | 较散客低 30%-50%（限量）| 羊毛党 |

### 1.2 价格倒挂的判定

| 类型 | 定义 | 案例 |
|------|------|------|
| **会员价 ≥ OTA 价** | 同房型同日期，会员价比携程/美团还高 | 锦江派酒店：会员 498 / OTA 380 |
| **协议价 ≥ 散客价** | 同房型同日期，协议公司价比前台现付还高 | 集团内多见，加盟店为冲量抬价 |
| **散客价 ≥ 节假日临时价** | 节假日当天，前台价反而高于当日 OTA 闪购价 | 周末调价滞后 |
| **官方价 ≥ 第三方平台代理价** | 加盟商为冲量委托第三方代理，代理价低 | 隐蔽倒挂 |

> 行业调研显示：**头部酒店集团倒挂发生率约 30%-40%**（华住、锦江、首旅、亚朵均有公开投诉）

## 三、价格倒挂的五大成因（行业共识）

| # | 成因 | 表现 | 应对 |
|---|------|------|------|
| 一 | **加盟商控价权过大** | 加盟商为冲 OTA 流量，主动压价 | 集团统一管理、罚款、扣分 |
| 二 | **会员权益设计薄弱** | 会员价仅 9.5 折，无早餐/积分/升级 | 增加会员专享权益（如双早、升级、积分抵）|
| 三 | **动态调价滞后** | 节假日 OTA 闪购低于会员价 | 实时对接 OTA 价格 |
| 四 | **渠道佣金不传导** | OTA 抽 15%-30% 但仍给低价 | 限定 OTA 渠道价格下限 |
| 五 | **会员激励错配** | 前台推 OTA 不推会员 | 前台推会员奖励（积分加倍）|

> **集团副总裁夏子帆的总结**（来源：腾讯新闻报道）：
> 「价格倒挂的根源一是价格体系设计不专业，二是加盟业主更看重渠道客流量而非集团价格指导。」

## 四、价格倒挂的四大危害

| # | 危害 | 影响 |
|---|------|------|
| 一 | **会员失去忠诚意愿** | 会员价 ≥ OTA 价 → 高频会员流失至 OTA |
| 二 | **会员增量停滞** | 消费者不再以会员身份预订，新客入会意愿下降 |
| 三 | **OTA 佣金侵蚀利润** | 会员全部走 OTA，酒店支付 15%-30% 佣金 |
| 四 | **品牌定位下移** | OTA 价格成为实际价格中枢，品牌定位受 OTA 价格钳制 |

> 华住集团内部资料：「会员直销比例直接反映酒店品牌竞争力，锦江、华住近年在加速构建自有会员体系，推出更吸引人的服务内容以增强消费者对官方渠道的依赖」

## 五、识别倒挂的 4 步法（建议集团统一执行）

### 第一步：每周自动比价（机器人脚本）

```
每周一上午 8:00
对集团旗下所有在售酒店（同房型 / 同日期 / 同人数）
从 4 个渠道自动获取价格：
  1. 官方 APP / 小程序（最安逸荟会员价）
  2. 携程
  3. 美团
  4. 飞猪
```

### 第二步：异常告警

```
判定阈值：
  会员价 / OTA 价 > 1.05 → 红警
  协议价 / 散客价 > 0.95 → 黄警
  节假日当天 / 临时调价滞后 > 24 小时 → 黄警
```

### 第三步：整改闭环

```
红警 → 24 小时内调整
黄警 → 72 小时内排查
灰警 → 月度复盘
```

### 第四步：纳入考核

```
将「会员价保护率」纳入各店月度考核：
  会员价保护率 = 当月会员价低于 OTA 价的房型数 / 总房型数
  目标 ≥ 95%
```

## 六、价格倒挂补救的 5 步方案（行业最佳实践）

### 第一步：设计完整的价格结构

以 OTA 价为基准，按下表设计：

| 价格层 | 折扣 | 与 OTA 价对比 |
|--------|------|--------------|
| 门市价 | 110% | 高于 OTA 10% |
| OTA 零售价 | 100%（基准）| — |
| 银会员 | 95% | 低于 OTA 5% |
| 金会员 | 88% | 低于 OTA 12% |
| 铂金会员 | 80% | 低于 OTA 20% |
| 协议公司 | 85%-95%（浮动）| 略低于 OTA 或与之持平 |

> **关键原则**：**协议公司价 ≥ 会员最高级价（铂金）**——避免倒挂

### 第二步：会员权益差异化（非价格）

| 会员级别 | 核心权益 |
|---------|---------|
| 注册 | 注册券 50 元 |
| 银 | 双早、延迟退房至 13:00、免费洗衣 |
| 金 | 双早、下午茶券 3 张、生日特权、客房预留至 19:00 |
| 铂金 | 双早、下午茶券 5 张、升级客房（有空房时）、免费洗衣、欢迎水果 |

### 第三步：限制 OTA 渠道价格下限

```
与 OTA 签订年度框架协议：
  - 同一房型 OTA 价不得低于官方会员价的 95%
  - 节假日 OTA 闪购须提前 48 小时向集团报备
  - 违反约定的 OTA 渠道扣减次年返佣
```

### 第四步：前台推会员激励

```
前台成功推 1 单会员预订：
  - 奖励前台 50 元积分
  - 客人获得会员价 + 双早 + 延迟退房
  - 会员积分双倍累积
```

### 第五步：每月倒挂排查与公示

```
每月第一周公示：
  - 各店会员价保护率
  - 倒挂案例整改结果
  - 排名前三 + 后三
```

## 八、结论与建议

### 8.1 结论

1. **公开数据下，集团旗下主要在售酒店未发现显著价格倒挂**（新良、花园）
2. **价格倒挂在酒店行业普遍存在**（头部集团 30%-40% 倒挂率），安逸集团旗下在管酒店和加盟店存在结构性风险
3. **价格倒挂的根因不是价格本身，而是会员权益设计与渠道管控**——会员价仅 9.5 折（vs 头部集团 8 折）缺乏竞争力
