## 六、含残值的全周期 IRR（8 年经营 + Y12 末退出）

> **关键洞察**: 经营性 IRR 10.5% 不含退出价值;加入 Y12 残值后,全周期 IRR 跃迁至 **18-22%**

### 6.1 持续经营口径（含 Y12 永续价值）

```
NPV = -3,893 + Y1-Y8 现金流折现 + Y9-Y12 现金流折现 + Y12 末永续价值折现

Y1-Y8 累计现值 @ 10% = +198 万（v1.4 已算）
Y9-Y12 累计现值 @ 10%:
  Y9: 750/1.749 = 429
  Y10: 750/1.921 = 390
  Y11: 670/2.111 = 317
  Y12: 587/2.320 = 253
  累计: 1,389 万
Y12 永续价值现值 @ 10% = 9,400/2.32 = 4,053 万

NPV = -3,893 + 198 + 1,389 + 4,053 = +1,747 万
IRR ≈ 18-20%
```

### 6.2 REITs 退出口径（Y12 末打包退出）

```
NPV = -3,893 + Y1-Y8 现金流折现 + Y9-Y12 现金流折现 + Y12 末 REITs 退出价值折现

Y1-Y12 累计现值 @ 10% = 198 + 1,389 = 1,587 万
Y12 REITs 退出价值现值 = 11,280/2.32 = 4,862 万
- 焕新投资现值 = -1,500/1.749 (Y7) = -858 万

NPV = -3,893 + 1,587 + 4,862 - 858 = +1,698 万
IRR ≈ 18-19%
```
