## 二、核心战略定位升级（v1.1 新增）

### 2.1 花园宾馆的"三重定位"

> **如果**要让花园宾馆成为安逸集团未来的"标杆项目"，**那么**它必须**同时具备三重身份**：

```
安逸·花园宾馆 = 三重定位（v1.1 新增）
═══════════════════════════════════════════════════════════════

定位 1：安逸·精选系列的第 1 号店（v1.0 已锚定）
   └─ 集团生活方式品牌的原型店
   └─ 为后续"安逸·精选"系列输出提供模板

定位 2：安逸集团拓展国资体系存量项目改造的重要方向（v1.1 新增 ⭐⭐⭐）
   └─ 不是单店改造，而是集团未来改造其他国资存量酒店的"母版"
   └─ 必须考虑"国资适配性"——政务接待+国企差旅+轻资产输出+品牌沉淀
   └─ 1234 战略第三步"品牌运营"+第四步"标准输出"的具体载体

定位 3：春熙路核心商圈的"市井街巷生活方式"酒店
   └─ 利用走马街+花花食堂+花文化的稀缺资源
   └─ 与新良大酒店"政务商务"形成差异化
```

### 2.2 关键战略意义

> **"集团内没有现成的对标"** —— 安逸集团目前没有类似项目（国资存量酒店改造 + 中高档有限服务精选生活方式），**这意味着花园的对标必须从跨集团找（亚朵 S/喆啡/voco/英迪格）+ 安逸国资属性共同决定**。

## 三、客源录入规范修正（v1.1 重构）

### 3.1 v1.0 录入规范问题

**v1.0 假设**：协议公司 43.9% 是真实占比
**v1.1 修正**：协议公司 43.9% 包含**真正的协议客户 + 协议下的会议团队 + 协议下的散客（混录）**

**问题本质**：
- PMS 系统默认"协议公司"市场码，录入员习惯性归类
- 政府会议走协议价，被记入"协议公司"而非"会议团队"
- 散客通过协议渠道预订（如政府/大客户介绍），被记入"协议公司"
- **真正长期协议客户可能只占 25-30%，而非 43.9%**

### 3.2 重新拆解（按"客户性质"重新分类）

**应重新拆解为 4 个客户性质分类**：

```
花园宾馆客源应按"客户性质"重新分类（v1.1 重构）
═══════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────┐
│  真实客户性质                v1.0 错录      v1.1 正确拆解     │
├─────────────────────────────────────────────────────────────┤
│  长期协议客户（真正协议）    协议公司混入     25-30%（独立）   │
│  协议下的会议团队            协议公司混入     5-10%（独立）   │
│  协议下的散客                协议公司混入     8-12%（独立）   │
│  旅游团队（真正的）          旅游团队         12-18%（收缩）   │
│  中介渠道（OTA）             中介渠道         12-15%（持平）   │
│  上门散客                    上门散客         5-8%（持平）     │
│  中央会员                    中央会员         1.7%（保留）     │
│  会议团队                    会议团队         0.5%（独立）     │
│  商务日房                    商务日房         0.1%（独立）     │
│  新媒体                      0%               0%（空白）       │
└─────────────────────────────────────────────────────────────┘
```

### 7.2 国资存量改造方法论原型（v1.1 新增）

> **如果**花园要成为"安逸集团拓展国资体系存量项目改造的重要方向"，**那么**它必须提供**3 个可复用的方法论**：

```
   ├─ "中高端有限服务精选生活方式酒店" = 国资存量改造的核心赛道
```
