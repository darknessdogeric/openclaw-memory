# 关于新启航《安逸甄选电商运营平台项目实施方案（宣讲稿）》的评审意见

编制：安逸酒店集团产业发展部
时间：2026年11月2日
评审对象：四川新启航酒旅企业管理有限公司《安逸甄选电商运营平台项目实施方案（宣讲稿）》，共31页
用途：供集团层面就合作方方案的采纳、修改与分工决策参考

---

# 一、总体判断

**结论：方向可取，结构需改，落地时序须重排。**

宣讲稿在载体选择、验证节奏、供应商准入、商品档案、风险管控、同行借鉴六个方面质量较高，可直接吸收。但在运营主体定位、主战场排序、分配机制、品牌层级、授权链条五处与集团已定口径存在结构性错配，其中主战场排序错配将直接导致集团《近期重点工作量化清单》12月31日节点无法达成。跨境业务、点位货架与代销协议、商品硬规则、数据维度对接四项关键内容在方案中完全缺失。

建议处理方式：**采纳其执行颗粒度，替换其商业结构**——即由我方提供口径与边界，由新启航提供运营方案细节，双方按集团量化清单节点重新排布时序。

# 三、值得吸收的八点

1. **九十天验证加条件具备后起算**：不预设时间起点、以授权名单预算技术条件为前提，这个表述比按日历推进更稳，与集团11月30日节点可对齐。
2. **供应商准入四步法**：同规格比价、核资质验样品、小批试单、合格后上架，并要求上架前写清配送区域库存与售后，可直接写入合作方管理办法。
3. **统一商品档案**：规格图片资质、成本价格销售方、库存可售区、时效运费售后、保质期包装逐项建档，既支撑礼盒拆单，也是现场与代发双轨的前提。这条与我方数据框架的商品字段完全同向。
4. **六类风险周检查与异常处置原则**：质量授权、缺货退款、价格库存、资金对账、数据权限、扩张投入六类；异常先停新单、已接订单继续履约，属可直接吸收的风控机制。
5. **门店码唯一归属与导购费用核销**：门店码只归一家门店，按真实订单核导购费用、退款扣回、月度核对。这条可直接写入点位协议，解决码权与费用归属两个争议点。
6. **福利与自费双账分离、权益不兑现不转让**：合规意识较强，可作为集团其他福利类项目的范式推广。
7. **电商运营中心不以部门名义独立收款**：把收款开票责任与实际交易安排绑定，是国企电商项目的关键合规点。
8. **同行只取机制不取数字**：明确不引入未经核实的收入或转化数字，与我方方法论一致，建议保留该表述。

# 四、结构性错配五处（建议作为修改前置条件）

## 1. 运营主体被写成独家，与多运营商生态冲突

宣讲稿第4页与第19页把新启航定位为平台承接主体与品牌授权对象，语义接近独家承接。集团口径为新启航是外部运营商之一，保持非独家并在12月31日前接入不少于三家运营商。建议将相关表述统一改为受托运营方，平台权益与账号归承载主体，避免后续引入第二家运营商时被动。

## 2. 主战场倒置，集团12月31日节点将落空

宣讲稿把集团福利集采放在首期主线，把文旅延伸整体推迟至2027年一季度研究审议。而集团量化清单要求12月31日前完成私域上线可下单可结算、线下点位不少于10家、运营商不少于三家、品牌完成注册、中旅三渠道各上架不少于一个单品。两者不能同时成立。

建议：把**酒店点位铺货与个人零售**作为二销首期主线，福利集采定位为并行的集团集采线、单独核算不占二销指标；文旅延伸不再整体推迟，仅基地建设与体验类项目走2027年一季度审议。

## 3. 分配机制与酒店无关，与已定口径直接矛盾

宣讲稿第14页为净利润率保底15%、集团与新启航各取可分配净收益5%、不另收平台服务费。按此设计，酒店在点位经营中不参与收益分配，这与10月22日会议确定的零租金加代销分账、酒店分得二至三个点直接矛盾，也使酒店缺乏配合动因。

另需注意：集团量化清单中新启航门店接入一行仍写公园店首期租金已到账，而10月22日会议确定线下点位不执行点位租赁。**租金与代销分账两种模式须先统一**，否则协议、结算与数据口径会同时失据。

建议：按零租金加代销分账二八或三七、酒店分得二至三个点重构；平台服务费按成交额比例计提而不按净利润比例；取消净利润保底条款，改为供货差价与服务费的确定性计提；品牌授权费按1至2年免费培育期后另计。三层收益分账须在协议附表中分层列示。

## 4. 品牌层级缺位，安逸甄选被窄化为电商平台品牌

宣讲稿通篇只有安逸甄选一个品牌，且定位为电商运营平台，茶叶主品牌汉茶风华完全缺席。这与我方双品牌结构不符，也会让茶叶商品缺少品牌归属与出口叙事。

建议：汉茶风华承担茶叶品类与文化叙事，安逸甄选承担跨品类综合零售与跨境；两者均以安逸开头、并行注册第三十五类。

## 5. 授权链缺中间层

宣讲稿第19页为集团直接授权新启航品牌、门店、商品与数据，缺少茶业公司这一承载环节。集团口径是集团商标全部授权茶业公司、由其开展二次授权并统一管理运营商。直接授权会造成品牌权属与数据权属同时外流，且后续多运营商接入时链条无法复用。

建议：改为集团授权茶业公司、茶业公司授权运营商两级结构，新启航取得的是运营服务授权而非品牌所有权。

# 五、遗漏四项（须补入方案）

1. **跨境业务完全缺失**：建议按12月31日节点补入试点一个品类、外部运营商一家到位、毛利率口径确认三项目标；品类以非食品类文创优先，茶类走中东与中亚大宗渠道。
2. **点位货架与代销协议缺失**：标准版3至4平方米、特殊版20平方米两档规格；协议以公共区域商品代销与销售分成合作协议命名，明确不构成合资合伙或租赁；每个点位附点位清单与结算附表。
3. **商品硬规则缺失**：首期上架不少于50个单品、覆盖不少于5个品牌、同一品牌在机场限10款；标准版建议六成茶礼、两成五茶食特产、一成五文创茶宠，特殊版必须多品牌组合。
4. **数据维度与度量口径未对接**：宣讲稿有商品档案与运营报表，但缺集团侧需要的度量口径。建议至少补入：实际销售额、铺货量、团费嵌入单量、入境渠道单量、货架面积与坪效基准、资金在途与结算周期；并明确结算资金经商家账户中转、代销对账与审计权条款。

# 六、修改建议清单

## 零级（须改，否则后续返工）

1. 运营主体表述改为受托运营方，明确平台权益与账号归承载主体，保持非独家并写明不少于三家运营商的扩展计划。
2. 首期主线调整为酒店点位铺货与个人零售；福利集采单列为集团集采线，单独核算不占二销指标。
3. 分配机制改为零租金加代销分账，按二八或三七；平台服务费改按成交额计提；取消净利润率保底条款；品牌授权费按免费培育期后另计。
4. 补入汉茶风华，恢复双品牌结构；安逸甄选定位为跨品类综合零售品牌。
5. 授权链改为集团授权茶业公司、茶业公司二次授权运营商两级结构。

## 一级（须补）

6. 补入跨境业务三项目标与非食品文创优先的选品逻辑。
7. 补入点位货架两档规格与代销分账协议范式，含点位清单与结算附表、审计权条款、门店码归属与导购费用核销。
8. 补入商品硬规则：不少于50个单品、不少于5个品牌、同品牌限10款、每档价格带不超过6至8款。
9. 补入数据度量口径对接与每周数据周报格式，含实际销售额与铺货量两项必报。

## 二级（建议）

10. 明确租金模式与代销分账模式的取舍结论，修订量化清单中相应表述。
11. 直播基地与空间运营先取得场地产权与使用授权，再讨论独立核算，避免资产与收益边界争议。
12. 福利人数与预算口径注明不得进入二销考核基线，避免两套数字被合并引用。

# 七、下一步建议

1. 先以本评审意见与新启航对齐，形成宣讲稿修改版，重点是零级五条；建议不由我方代改，避免运营方方案失去可执行性。
2. 修改版定稿后，按集团量化清单节点重新排布时序，并同步修订其中与租金模式相关的一行表述。
3. 同步起草两份配套文件：点位协议范式与货品分工单账目规则；以及首期数据周报模板。
4. 视修改版质量，决定是否形成集团层面的正式任务书，回应宣讲稿第27页启动审议的四问：谁来签、先做哪批、钱怎么走、投入多少。
