## 一、三条博弈判断

**1. 天然不对等 —— 对方的筹码是存量，我们的成本是增量。**
对方已装好的屏、已建好的货架位，边际成本≈0；我们 3 万间接入是**高成本增量**（布线、网络、机房、调试、培训、客诉兜底）。若按"资源对资源"平价互换，必然吃亏 → **必须要保底条款（曝光量 + 转化数据 + 分成），不能只要"位置"**。

**2. 独家筹码在规模，不在单店。**
3 万间一次性给 = 对方拿到全国性网络，估值跃迁；分批给 = 节奏权永远在我们手里。
→ 最佳结构：**分批投放 + 排他条款 + 里程碑对赌**。

**3. 股权锚点被打破。**
提案原话："客房资源 5000 间以上 → 可获赠 2% 股权"。我们有 **3 万间，是锚点的 6 倍**。
线性外推 ≈ 12%，但股权不能线性算（要按对方收入贡献定价）。正确打法是：**用 3 万间重新定价** —— 更高比例 / 分期授予 / 与铺设进度挂钩的里程碑授予 / 业绩对赌 + 回购触发。

## 二、对方资源清单（谈之前必须拿到，缺一不进入排他谈判）

| # | 必取项 | 为什么 |
|---|---|---|
| 1 | 已装机酒店名单 · 家数 · 屏数 · **开机率/日活** | 判断我们换到的是"真流量"还是"僵尸屏" |
| 2 | 商品展示位**形式**：开机画面 / 首页推荐 / 分类页 / 购物车弹窗 | 决定我们商品能不能"卖"，而不只是"露脸" |
| 3 | **排他性**：能否同时给别家（尤其同业酒店） | 非排他 = 我们只是买了个广告位，价格应按广告牌价，不按资源置换算 |
| 4 | 屏上**空置率**与当前占位品牌 | 空置位 = 对方零成本，议价必须打折 |
| 5 | 结算方式：纯曝光 / 曝光+转化分成 / **保底** | "只给位置不给分成" = 一次性价值，不可续 |
| 6 | 期限 · 续约权 · **能否随屏幕内容迁移** | 我们自己的屏也要能同步挂我们的货架 |
| 7 | **数据回传**：曝光 / 点击 / 成交 / 客群 | 没有回传 = 无法向集团证明价值，第二年续不了 |
| 8 | 合规：广告主资质 · 虚假宣传 · 价格标示 · 商品质量责任 | 屏在酒店公共区，商品出事 = 酒店背锅 |

## 三、三种对价方案

**A｜纯资源互换**（位置 ⇄ 位置）
最省事，但价值不可计量、集团内部无法立项 → **不单独使用**。

**B｜资源互换 + 保底条款（推荐）**
我方分批给 3 万间入口；对方给 N 家酒店 · X 万次/月**保底曝光 + 转化数据回传 + 佣金分成**，且我们的商品进**首页/推荐位**（非仅广告位）；**未达保底可折抵或补差**。

**C｜房量换股权（后手）**
原锚点 5000 间 = 2%；以 **3 万间**重新定价，目标显著高于 12% 线性值，或"分批授予 + 里程碑 + 对赌/回购"；**须先过资产评估与国资审批**。

## 四、节奏建议

1. 先取第二节 8 项（尤其 1 / 3 / 4）—— **不取齐不进入排他**
2. 圈 2 家试点店（网络好、房价弹性大）跑 3 个月，用真实数据谈"我们到底值多少"
3. 3 万间分 3 批：**2–3 千间验证 → 1 万 → 3 万**，每批附带排他与对赌
4. 合同写死：**我方屏幕可同步挂我方货架**（否则我们只是替对方做渠道）

## 五、连带影响（需同步给工程 / 财务 / 运营）

- **工程**：3 万间弱电施工界面与工期（布线/网络/机房/调试/培训/客诉兜底）→ 工程部出量
- **财务**：弱电**不进"隐蔽工程"预算口径**（与装修分开立项、独立核算）
- **运营**：我们换到的货架上**上架什么商品**（集团农副产品 / 文创 / 文旅产品 / 特产 / 自有服务）→ 这决定这笔交换对我们是否有独立价值
- **合规**：客房屏幕采集的入住行为数据归酒店；客人数据不得进入对方私域；广告与商品在公共区展示的责任划分

## 五点五、市场面校验（2026-10-30 补）

- **行业变现率是少数派**：全国约 2070 万间客房，智能化改造约 38%，其中能实现"可量化增收"的不超过 15% 🟠🟠 → 对方的营收承诺不能当既定事实入账
- **"电视卖茶/特产"已被做过**：杰龙先创 × 藤县饭店已实现智慧屏特产商城 + 房号送货 + 快递寄回家，**功能无稀缺性**；我们能卖的只有 3 万间连锁的会员/复购/信用/履约
- **对方存量货架可能不值钱**：大景官网案例几乎全是散点高端单体酒店（非连锁网络）🟡🟡 → 可能拿 3 万间集中入口换零散屏位，**必须核单店屏数×开机率×展示位形式**
- **封闭生态代价放大**：杰龙公开警告封闭生态致后续采购溢价超 50% 🟠🟠 → 3 万间规模下，开放接口/数据可导出必须写死
