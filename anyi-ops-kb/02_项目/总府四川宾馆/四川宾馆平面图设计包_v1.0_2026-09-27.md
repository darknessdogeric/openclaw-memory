# 总府四川宾馆 · 平面图设计包

## 一、设计依据与说明

### 1.1 真实数据（来自可研 + 鉴定报告 + 平面图反推）

| 项 | 数值 | 来源 |
|---|---|---|
| 总建筑面积 | 12,155 ㎡ | 7.13 可研 §1.2.3 |
| 地上建筑 | 11,115 ㎡（4-5 层）| 同上 |
| 半地下 | 1,040 ㎡ | 同上 |
| 东西向总长 | **81.7 m** | 可研三层平面图反推（22 道横向轴线累积 +1.5%）|
| 南北向总宽 | **33.0 m** | 同上（7 道纵向轴线累积）|
| 建筑结构 | 西楼 1961 砖混（I 区）+ 南楼 1988（II 区）| 鉴定报告 SIBR/R/F2020-016 |
| 安全鉴定 | I 区 Dsu / II 区 Csu / III 区 Dsu，**三区抗震均不满足**| 鉴定报告 |
| 客房 | 现 156 间（暗房率 20%）→ 改造目标 145 间（**暗房率 0**）| 可研 §5.3 + Eric 9/27 指令 |

### 1.2 设计原则（Eric 9/27 13:43 指令）

1. **1F 不能有客房**，必须用作聚合空间
2. **方案 A**: 1F = 早餐厅 80座 + 包间 ×3 + 大堂
3. **方案 B**: 1F = 策展空间（600㎡）+ 日咖夜酒（300㎡）+ 大堂；早餐厅迁至 4F 顶楼
4. 客房层仅 2-4F（3 层），共 **145 间无暗房**
5. 砖混结构，**不严格缩到 125 间**（≤ 150 间即可）
6. **总投入 ≤ 5,000 万含加固**（按 Eric 早先指令）
