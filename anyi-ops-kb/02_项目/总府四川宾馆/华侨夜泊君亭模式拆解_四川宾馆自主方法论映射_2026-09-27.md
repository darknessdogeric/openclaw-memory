# 华侨夜泊君亭模式拆解 · 四川宾馆"自己干"方法论映射

> **纠偏说明**：上一版可研把"方向四"写成了"与君亭合作"。Eric 明确纠正——**不是合作，是学它的模式，四川宾馆自己做**。本文聚焦：拆解华侨夜泊君亭作为"古建改造项目"的三条核心方法论，映射到四川宾馆自主经营。

## 一、先回答：华侨夜泊君亭到底"做对了什么"

北京华侨饭店 → 华侨夜泊君亭，本质是一个 **"古建危房 → 文化精品酒店"** 的改造项目。它给四川宾馆的最大启示，不是"贴君亭的牌子"，而是下面三件事：

| 维度 | 华侨夜泊做了什么 | 四川宾馆能不能照做 |
|---|---|---|
| **改造方式** | 不拆墙、不并房，保留梁思成设计的建筑语汇 | ✅ 能，且川宾同样是危房+文化建筑 |
| **模式** | "城人事美"文化内容运营，而非卖房间 | ✅ 能，川宾有70年国宾文化 |
| **投资回报概念** | 高溢价摊薄成本，而非靠出房率堆规模 | ✅ 能，但需验证成都市场承接力 |

## 二、改造方式（怎么改）

### 2.1 华侨夜泊的改造方式

🟡 数据（来源：百科 + 官网 + 一财）

| 项 | 做法 | 本质 |
|---|---|---|
| **承重结构** | **保留原建筑承重结构**（不拆墙、不并房） | 176 间房量不变 |
| **建筑语汇** | 保留歇山式屋顶、飞檐翘角、金漆彩画、雕花窗棂、王府规制门厅 | 古建是"资产"不是"包袱" |
| **庭院改造** | 把部分庭院改造为**玻璃穹顶景观中庭** | 用现代手法激活老空间 |
| **客房装修** | 22㎡-46㎡ 四种房型，以"胡同景观/庭院花园景观"为卖点 | 卖景观+文化，不是卖面积 |
| **文化植入** | 700 余幅启功/李可染名家字画作为软装 | 文化是可触摸的硬件 |
| **功能取舍** | 只保留 1 间餐厅 + 1 间贵宾厅 + 170㎡会议室，**不设大规模宴会** | 功能克制，聚焦精品 |

### 2.2 映射到四川宾馆（自己干）

🟢 自主设计

| 华侨夜泊做法 | 四川宾馆对应做法 |
|---|---|
| 保留承重结构（危房加固后不拆墙） | ✅ 176 间保留，加固 1,500 万外部承担，**不拆墙不并房** |
| 保留建筑语汇 | ✅ 保留川派建筑元素（雕花窗棂、垂花门、竹编、青砖灰瓦） |
| 庭院改玻璃穹顶中庭 | ✅ 北翼外租区庭院 → 玻璃穹顶**文化聚合中庭** |
| 客房卖景观 | ✅ 客房面向中庭/北翼庭院，卖"巴蜀庭院景观" |
| 文化软装 | ✅ 川宾收藏的巴蜀书画/非遗物件作为软装 |
| 功能克制 | ✅ 1 间精品川菜餐厅 + 3 间包间 + 1 个文化聚厅，不设宴会厅 |

> **核心启发**：华侨夜泊证明了一件事——**"危房 + 古建"不是改造的障碍，而是改造的资本**。四川宾馆 70 年国宾历史 + 危房，与北京华侨饭店 70 年侨史 + 王府规制建筑，是同一个逻辑。

## 三、模式（怎么运营）

### 3.1 华侨夜泊的模式：从"卖房间"到"文化内容运营"

🟡 数据（来源：君亭年报 + 一财吴启元访谈）

君亭把"夜泊君亭"品牌的模式定义为：

> **"通过'城人事美'的探索，立足当地城市故事、建筑人文故事、生活美学、环境美学进行再创作，再生城市历史文化建筑，酒店身份转化为文化内容运营者，创造温度不失质感的文旅生活。"**

拆解成四个字：

| 字 | 含义 | 四川宾馆对应 |
|---|---|---|
| **城** | 城市故事 | 成都·春熙路·总府街 70 年 |
| **人** | 建筑人文故事 | 梁思成式建筑 → 川宾国宾接待史 |
| **事** | 生活美学 | 巴蜀慢生活、茶、川菜 |
| **美** | 环境美学 | 庭院、园林、竹编、青砖 |

**关键模式特征**：
1. **酒店身份 = 文化内容运营者**（不是住宿运营商）——文化是产品，房间是载体；
2. **一店一品**（每个店都是独一无二的文化项目，不可复制）——这是它敢卖 1000+ 元的底气；
3. **产品内容精选、文化精选、服务内容精选**——"精选"而非"全服务"，砍掉宴会厅、砍掉大会议，聚焦几样做到极致。

### 3.2 映射到四川宾馆（自己干）

🟢 自主设计

| 君亭模式要素 | 四川宾馆自己干的做法 |
|---|---|
| 文化内容运营者 | 把"巴蜀文化 + 国宾历史"做成**可体验的产品线**（非遗展示、川菜、茶、书画） |
| 一店一品 | 四川宾馆就是"四川国宾文化旗舰"这唯一的品，不做第二家 |
| 精选而非全服务 | 砍掉宴会厅/大会议，聚焦"精品客房 + 精品川菜 + 文化聚合区"三件事 |
| 城人事美 | 城=成都，人=国宾史，事=巴蜀生活美学，美=庭院园林 |

> **核心启发**：华侨夜泊卖 1000+ 元，不是靠硬件豪华，是靠**"文化的稀缺性 + 不可复制性"**。四川宾馆的"70 年国宾史 + 巴蜀文化"是同样稀缺、同样不可复制的资产。**这才是自己能干的、且别人抢不走的模式。**

## 四、投资回报概念（怎么算账）

### 4.1 华侨夜泊的投资回报概念

🟡 数据（来源：君亭年报 + 券商深度报告 + 吴启元访谈）

| 概念 | 君亭怎么表达 | 数据佐证 |
|---|---|---|
| **高溢价摊薄成本** | 单房租金/折摊绝对值高，但溢价能力强 → 摊薄后净利率高 | 成都 Pagoda 净利率 **19.8%**（2023 H1） |
| **高坪效设计** | 提高每平方米产出，而非堆房间数 | 单房年收入 26.1 万（vs 全季 15.9 万） |
| **供应链降本** | 自建供应链平台，缩短回报周期 | 机电/FFE/OSE 集中采购 |
| **品牌溢出** | 文化品牌让房价溢出硬件价值 | 华侨夜泊改造后房价超 1000 元 |
| **投资回报稳健** | 4 年回本，GOP 60-70% | 君亭/观涧/尚品三档产品均 4 年回本 |

**华侨夜泊的具体回报数据**：

🟡 数据（来源：一财吴启元圆桌 + 券商）

| 指标 | 数据 |
|---|---|
| 改造后房价 | **超 1000 元**（改造前约 250-360 元） |
| 开业 3 个月 OCC | **75-80%** |
| 开业 3 个月 RevPAR | **约 580** |
| 对比：锦江中心酒店改造 | 年净利 1300-1400 万，外宾率 68% |

### 4.2 映射到四川宾馆（自己干）——回报概念重算

🟢 自主测算（复用川宾自有数据，不套君亭品牌费）

> **关键区别**：华侨夜泊是"君亭直营，品牌费内部化"。四川宾馆自己干，**没有品牌费、没有管理费分成**，利润全部归自己。这比"贴牌"更优。

| 概念 | 华侨夜泊 | 四川宾馆自己干 |
|---|---|---|
| 品牌费/管理费 | 内部化（君亭自营） | **0（自主品牌，无分成）** |
| 房价目标 | 1000+ 元 | **600-800 元起步，2-3 年冲 800-1000** |
| OCC 目标 | 75-80% | 70-76%（春熙路商圈中位） |
| 非房占比 | 餐饮+庭院（约 20%） | **30-37%（文化聚合 + 精品川菜 + 外租）** |
| 单房年收入 | 18-22 万 | **20-26 万**（120 间口径） |

### 4.3 四川宾馆自己干的投资回报（自主口径重算）

🟢 自主测算（数据源：`四川宾馆_5000万自投自建测算_v1` + `精品酒店自主方案模型_v2`）

**口径修正**：去掉"与君亭合作"的品牌费/管理费后，自主口径如下：

| 房价 | 房间数 | 综合收入 | 非房占比 | GOP率 | 年税前利润 | 静态回收期 | IRR |
|---|---|---|---|---|---|---|---|
| 600 元 | 120 | 3,030 万 | 37% | 55% | 576 万 | 8.7 年 | 约 7% |
| 650 元 | 120 | 3,283 万 | 37% | 55% | 624 万 | 8.0 年 | 约 9% |
| 700 元 | 120 | 3,536 万 | 37% | 56% | 728 万 | 6.9 年 | 约 11% |
| 800 元 | 120 | 4,041 万 | 37% | 58% | 880 万 | 5.7 年 | 约 15% |

> **关键结论**：四川宾馆自己干（不贴君亭牌、不付品牌费），**在 120 间 / 房价 700 元的自主口径下，回收 6.9 年、IRR 11%**。这比"贴牌"更优（贴牌要扣品牌费+管理费），也比"拆墙合并到 35-42㎡"的 9.4-18 年更优（因为保留 176 间/120 间出房率更高、投资更省）。

## 六、结论：四川宾馆"自己干"的最终方案

🟢 综合判断

> **四川宾馆不需要"与君亭合作"，而是学华侨夜泊的三条方法论，自己干。**

**最终方案**（一页纸）：

| 项 | 内容 |
|---|---|
| **方向** | 自主经营（不贴牌、不合作） |
| **改造方式** | 学华侨夜泊：危房加固（外部承担）+ 不拆墙 + 保留川派建筑语汇 + 庭院改玻璃穹顶文化中庭 |
| **房间数** | **120 间**（176 间中保留 120 间做精品，56 间腾给文化聚合区/餐饮/公区） |
| **模式** | 学华侨夜泊："巴蜀文化 + 国宾历史"做成可体验产品线，一店一品，精选非全服务 |
| **投资回报概念** | 学华侨夜泊：高溢价摊薄成本 + 高坪效 + 供应链降本 + 自主品牌零品牌费 |
| **投资** | 5,000 万（加固外担）+ 客房控价 |
| **房价目标** | 600-700 元起步，2-3 年冲 800 元 |
| **回收期** | 6.9-8.7 年（700-600 元档） |
| **IRR** | 11-15% |

**三个前置条件（不变）**：
1. 加固 1,500 万必须外部承担（城市更新专项/文旅专项/锦弘承担）；
2. 精品餐饮交合作方投入（集团收租或分成）；
3. 房价必须站上 650 元（600 元档 IRR 仅 7%，接近资金成本）。
