# 四川宾馆 · 战略投资口径测算（品牌培育逻辑）

> **口径切换**：前几版是"纯财务投资"口径（要求单店 IRR ≥ 8%），本版切换到"战略投资"口径——四川宾馆的回报 = **单店利润 + 品牌资产 + 全国川办复制母版 + 政务接待公信力**，单店 IRR 可接受 3.5%-8%（战略价值补足）。

---

## 一、先厘清：四川宾馆的战略价值（为什么值得"战略投资"）

🟢 集团品牌规划（2026-09-13 双店联动分析）

| 价值层 | 内容 | 四川宾馆独有性 |
|---|---|---|
| **名称资产** | "四川宾馆"四字 = 全省唯一 + 权威性 + 历史性 | 一个省只能有一个，排他性最强 |
| **网络资产** | 全国川办附属宾馆 = 现成品牌网络 | 无需从零选址、从零建设 |
| **政务资产** | 政务接待质量/保密要求 = 品牌公信力来源 | 市场化品牌无法获得 |

> **核心判断**（集团品牌认知 v1.6）："四川宾馆"是集团现有品牌资产中**势能最高的一个名号**，被定位为**旗舰品牌**。

**这就是为什么不能用"纯 IRR 8%"来衡量它**——它是母版，单店慢一点没关系，关键是先立起来、跑通、可复制。

## 三、核心答案：投资回报最低可以做到几年？

### 3.1 结论：**最低 8-9 年，现实可行 9.4 年**

🟢 测算（方案D + 三杠杆全用）

| 杠杆 | 动作 | 效果 |
|---|---|---|
| **① 租金重谈** | 25%分成 → 15%分成或固定500万 | 年省租金 200-300 万 |
| **② 加固外担** | 1,500万加固由外部承担 | 投资从 6,000+ 压到 5,700 |
| **③ 川菜合作方** | 川菜装修引入合作方（省600万）| 投资再降到 5,100 |

**三个杠杆全用 → 方案D（700元精品）回本压缩到 8.4 年，年利润 608 万。**

### 3.2 回本速度的边界

🔴 测算发现

> 即便三个杠杆全用，四川宾馆**单店回本最快也就 8-9 年**，压不下来了。
>
> 因为成都市场 ADR 现实只有 600-700 元（Pagoda君亭660、华侨夜泊北京700），撑不起更快的回本。**这就是"战略投资"的意义——单店慢，但它是全国川办复制的母版。**

## 五、最终结论（战略投资口径）

### 5.1 直接回答 Eric 两个问题

**问题1：投资回报最低可以做到几年？**

> **8-9 年**（三杠杆全用 + ADR 700 元）。这是四川宾馆在成都市场现实房价下的单店回本极限。

**问题2：各方案优劣？**

| 排序 | 方案 | 一句话 |
|---|---|---|
| 🥇 | **D 自主精品（700元）** | 回本9.4年最快 + 战略价值最高（唯一能当母版）|
| 🥈 | C 锦江优化 | 温和改良，治标不治本 |
| 🥉 | B 锦江原版 | 能保品牌，撑不起旗舰 |
| ❌ | A 外租 | 财务最稳，但放弃品牌 |

### 5.2 战略投资的完整逻辑链

```
四川宾馆的"回本" = 单店 9.4 年（现金流）
                  + 品牌资产（"四川宾馆"四字，全省唯一）
                  + 母版价值（复制到全国川办宾馆）
                  + 政务公信力（市场化品牌拿不到）
                  + 川菜产品线源头（拉出安逸餐饮线）

所以单店 IRR 4-5% 是可以接受的——
因为品牌资产 + 母版 + 政务 + 餐饮线，才是这个项目真正的"投资回报"。
```

### 5.3 三个必须落地的前提（不变）

1. **租金重谈**：25% → 15% 或固定 500 万（否则一切免谈）
2. **加固外担**：1,500 万加固由外部承担
3. **房价站上 700 元**：对标 Pagoda 660 / 华侨夜泊北京 700，这是成都可达的天花板
