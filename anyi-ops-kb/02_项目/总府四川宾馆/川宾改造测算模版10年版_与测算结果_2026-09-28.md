# 川宾改造测算模版（10年标准版）与测算结果

## 一、模版结构（六个部分）

参照丽苑 6-12 楼测算表（2023 V1.3）的结构，规范化如下：

| 部分 | 内容 |
|---|---|
| 一、基础假设 | 房间数、可出租间夜数、阶段、ADR系数、OCC系数、峰值ADR、峰值OCC、当年ADR、当年OCC、RevPAR |
| 二、收入测算 | 客房收入、非房收入占比、非房收入、总收入 |
| 三、成本测算 | 客房直接成本（30.5%）、非房直接成本（40%）、人工、税金及附加、成本合计、GOP、GOP率 |
| 四、非经营费用 | 折旧摊销、房产税、财产及机器保险、贷款利息、租金 |
| 五、利润与现金流 | 利润总额、所得税、净利润、加折旧摊销、现金流入、现金流出、净现金流、累计净现金流 |
| 六、折现与评价 | 折现率、折现因子、净现金流现值、累计折现、IRR、NPV、静态回收期、动态回收期 |

### 核心公式（与丽苑表一致）

- 现金流入 = 净利润 + 折旧摊销
- 净现金流 = 现金流入 − 投资（Y0）
- 房产税 = 投资额 × 0.7 × 1.2%
- 财产及机器保险 = 投资额 × (0.035% + 0.045%)
- 客房直接成本率 30.5%（已含低耗品3.5% + 能耗7% + 洗涤3% + 维修3% + 销售3% + OTA8% + 管理3%）
- 非房直接成本率 40%

## 四、结论

### 4.1 三条分界线

| 分界 | ADR / OCC | IRR | 判断 |
|---|---|---|---|
| **保底线**（过国资委最低门槛 3.5%）| ADR 580 / OCC 72% | 4.0% | 勉强可行 |
| **合格线**（过合理门槛 8%）| **ADR 650 / OCC 75%** | **11.7%** | 好项目 |
| **优质线** | ADR 700 / OCC 78% | 17.0% | 优秀 |

### 4.2 关键判断

**第一，ADR 650 + OCC 75% 是"合格线"。** 低于这条线（如 ADR 600 / OCC 72%，IRR 5.8%），项目只能算"勉强可行"，NPV 为负。

**第二，GOP 率约 52-55%。** 峰值年 GOP 1,974 万元，其中租金 729 万元拿走了 37%，折旧摊销 615.5 万元拿走 31%——**这两项固定费用合计占 GOP 的 68%**，是收益的最大侵蚀项。

**第三，基准情景下 5.4 年回本、IRR 11.74%、NPV 866 万元。** 这已经是一个财务上站得住的项目，前提是 ADR 能站上 650、OCC 能站上 75%。

**第四，OCC 比 ADR 更重要。** 从敏感性看，OCC 每提高 3 个百分点，IRR 提升约 2 个百分点；ADR 每提高 20 元，IRR 提升约 1.6 个百分点。**提升入住率的杠杆更大。**

### 4.3 与锦江 7.13 方案的对比

| 项 | 锦江 7.13 | 本次测算（基准）|
|---|---|---|
| 房间 | 165 | 165 |
| ADR | 520 | 650 |
| OCC | 85.6% | 75% |
| 回收期 | 11 年 | 5.4 年 |
| IRR | 4.06% | 11.74% |

**差异来源**：锦江方案 ADR 只按 520 元测算（偏低），且非房收入仅约 100 万元（无餐饮无文化）。本次测算 ADR 650 元 + 非房占比 20%，收益结构明显更优。
