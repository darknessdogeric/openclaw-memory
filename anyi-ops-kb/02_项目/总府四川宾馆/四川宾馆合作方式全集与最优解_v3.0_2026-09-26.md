# 四川宾馆合作方式全集分析与最优解 v3.0

**操盘主体**：四川总府实业有限公司（安逸 100% 全资；账面净资产 **-2.56 亿**，已批 2 亿贷款锁死 15 年现金流）
**项目**：成都总府街 31 号 · 12,155 ㎡ · **C/D 级危房** · 停业 7 年
**产权**：锦弘集团（2025/11 由安逸划转回）
**规划定位**：巴蜀文化旗舰 + 全国川办母版 + 餐饮产品线源头

---

## 一、模式全集（三族七式 + 资本运作补充）

| 族 | 式 | 一句话 |
|----|----|--------|
| **甲族·租赁（不自投）** | 甲1 | 按市场行情固定租金出租 |
| | 甲2 | 保底租金＋增量分成出租 |
| **乙族·引进品牌（自投）** | 乙1 | 委托管理——业主投资持有，品牌方管理 |
| | 乙2 | 品牌加盟/特许——业主投资，用他方品牌自营 |
| **丙族·自投自营** | 丙1 | 自建"四川宾馆"品牌＋自主经营 |
| **丁族·资本运作（补充）** | 丁1 | 合资/联营（共投共营） |
| | 丁2 | 整体转让（出售变现） |
| | 丁3 | 股权合作引入战投 |
| | 丁4 | 资产证券化（REITs/CMBS） |

---

## 二、逐式七问

### 甲1 · 按市场行情固定租金出租

| 问 | 答 |
|----|----|
| **必要性** | 中——停业 7 年零产出、危房须排险，止血成立；规划三重定位必然落空 |
| **业主（锦弘）投入** | 物业使用权/产权；不投改造 |
| **安逸/总府投入** | 近乎零资金；投入谈判与渠道 |
| **所需能力** | 资产评估、租赁谈判、合同管理 → **已具备** |
| **优势** | 现金流确定｜不投入｜不担经营风险｜管理最简 |
| **劣势** | 收益封顶｜品牌与规划定位落空｜15 年锁定 |
| **十五五契合** | **低**（三重定位全部落空） |
| **风险** | 危房条件压制租金水平（**租不出好价**）｜承租方稀缺｜长租锁定 |

### 甲2 · 保底租金＋增量分成出租

| 问 | 答 |
|----|----|
| **必要性** | 中——同甲1，但对上行收益保留分享权 |
| **业主投入** | 同甲1 |
| **安逸/总府投入** | 同甲1（近乎零资金） |
| **所需能力** | 同甲1 + **分成审计监督** |
| **优势** | 下行有保底、上行有分成，比甲1 更优 |
| **劣势** | 品牌让渡不变；分成执行难监督 |
| **十五五契合** | **低** |
| **风险** | 分成基数难核实｜承租方经营不佳时分成归零 |

### 乙1 · 委托管理（业主自投，品牌方管理）

| 问 | 答 |
|----|----|
| **必要性** | **中高**——业主保留资产与品牌载体，只把"运营能力"外包 |
| **业主投入** | 改造资金（危房加固 + 装修，**约 5,000-8,500 万**） |
| **安逸/总府投入** | **改造资金**（若无自有资金需融资）+ 改造与资产管理 |
| **所需能力** | 业主需"**资产管理 + 改造管理**"→ **已具备**；经营能力由管理方提供 |
| **优势** | ①**品牌可自持**（可用"四川宾馆"品牌委托）②借外部运营能力③比自营门槛低 |
| **劣势** | 管理费侵蚀利润｜业主与管理方目标可能不一致 |
| **十五五契合** | **中高**（若委托自有品牌，可满足三重定位中的"产品模型"与"母版"） |
| **风险** | 管理费刚性｜**危房+文化主题的合适管理方稀缺** |

### 乙2 · 品牌加盟/特许（业主自投，他方品牌）

| 问 | 答 |
|----|----|
| **必要性** | 中——快速开业、借品牌与客源 |
| **业主投入** | 改造资金；安逸/总府：资金 + 自主运营 |
| **所需能力** | **业主需自营能力**（加盟后自己经营）→ **目前不具备** |
| **优势** | 品牌+系统+客源现成｜开业快｜门槛低于自建品牌 |
| **劣势** | 品牌归他方｜加盟费+持续费｜中端产品与规划文化定位不符｜餐饮产品线难承接 |
| **十五五契合** | **低-中** |
| **风险** | 高投入 + 收益天花板｜字号稀释 |

### 丙1 · 自建"四川宾馆"品牌＋自主经营

| 问 | 答 |
|----|----|
| **必要性** | **最高**——规划三重定位（旗舰/母版/餐饮源头）**唯一载体** |
| **业主投入** | 物业；安逸/总府：**改造 8,500 万**（含加固 1,500 万） |
| **所需能力** | 品牌塑造／文化策展／精品运营／精品餐饮 → **目前均不具备** |
| **优势** | 品牌自有并增值｜可复制全国川办｜单房产出高 64%（26.1 万 vs 15.9 万）｜非房收入 37% |
| **劣势** | 投入最大｜**基准回收期 22.8 年 > 15 年租期**｜能力与人才缺口大 |
| **十五五契合** | **最高** |
| **风险** | 资金压力（主体已资不抵债）｜能力不足｜人才缺口｜加固超支｜品牌培育不确定 |

### 丁1 · 合资/联营（共投共营）

| 问 | 答 |
|----|----|
| **必要性** | 中——分担资金与风险 |
| **投入** | 双方按股比出资（可按股比分摊改造资金） |
| **能力** | 合资治理、国资审批 → **部分具备** |
| **优势** | 共担风险｜可引入专业运营方持股绑定 |
| **劣势** | 决策效率低｜国资合资审批链条长 |
| **契合** | 中（可作为丙1 的资金实现方式） |
| **风险** | 国资与外部股东的目标冲突｜管控难度 |

### 丁2 / 丁3 / 丁4（处置与融资）

| 式 | 必要性 | 优势 | 劣势/风险 | 契合 |
|----|--------|------|-----------|------|
| 丁2 整体转让 | 低 | 一次性变现、摆脱包袱 | 丧失资产与品牌｜**危房折价严重** | 冲突 |
| 丁3 股权合作引战投 | 中 | 引资金、引专业方 | 股权稀释｜国资程序复杂 | 中 |
| 丁4 资产证券化 | 中 | 融资工具，不改经营 | **停业+危房无稳定现金流，不满足入池条件** | 中（远期） |

## 四、关键约束（决定一切的一条）

> **回收期 vs 租期**：丙1 在现行租金条件下回收期 **22.8 年**，而租期仅 **15 年**——**投资尚未收回，租约已到期**。这条不解决，丙1 在数学上不成立。

**三条解锁路径**（叠加后回收期 → 5.3 年）：

| 路径 | 效果 |
|------|------|
| ① 租金降至 ≤30 元/㎡/月（或以历史建筑/城市更新/文化项目名义申请减免） | 22.8 → **11.8 年**（<15 年 ✅） |
| ② 加固成本外部承担（成都城市更新与历史建筑活化专项 / 省级文旅专项 / 或产权方锦弘） | → **8.6 年** |
| ③ 文化区与餐饮引入合作方承担投入（收租或分成） | → **5.3 年** |

## 五、最优解

### 5.1 结论

> **主选：丙1 的"能力外包版" = 自投 + 自有品牌"四川宾馆" + 委托专业运营（乙1 的管理结构）**

即：**品牌自持（丙的魂）＋ 运营外包（乙的手）＋ 投入分期（丁1 的钱）**。

### 5.2 为什么是它

| 决策问题 | 该方案的答案 |
|----------|-------------|
| 必要性 | 规划三重定位**只能由自有品牌承载** → 必须自持品牌 |
| 能力缺口 | 品牌/文化/餐饮/精品运营**目前均不具备** → 必须外借运营 |
| 资金约束 | 主体已资不抵债 → **自投需分期 + 引入合作方分担 + 政策资金** |
| 租期约束 | 回收期须 < 15 年 → **必须先解租金与加固** |
| 与规划契合 | **高**（品牌自持 + 母版可复制 + 餐饮产品线可拉出） |

**一句话**：**用别人的手，做自己的品牌。**

### 5.3 落地路径（三步）

| 步 | 动作 | 目的 |
|----|------|------|
| **第一步（前置·必做）** | ① 出具结构加固方案与造价 ② 与锦弘重谈租金/租期 ③ 申请加固政策资金 | 把"22.8 年 > 15 年"的数学障碍拆掉 |
| **第二步（主体·主选）** | 自投改造 + 自有品牌"四川宾馆" + 委托专业运营方管理 | 品牌自持、能力外包 |
| **第三步（进阶）** | 运营成熟后收回自营；模型复制到全国川办 | 走向规划"标准输出" |

### 5.4 兜底与备选

| 情形 | 备选 |
|------|------|
| 租金/加固谈不成、资金无着落 | **甲2（保底+增量分成租赁）**——止血，但放弃品牌 |
| 有资金但找不到合适运营方 | **丙1 全自营**（须先补品牌与运营能力） |
| 集团决定不做品牌 | **甲1/丁2**（处置路线） |

### 5.5 不推荐

- **乙2 品牌加盟**：与"品牌自持 + 文化主题"双重冲突，且业主自营能力不具备
- **丁2 整体转让**：危房折价、且与规划正面冲突
