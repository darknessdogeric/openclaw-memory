# 四川宾馆三大方向对比分析

> **分析框架**：每个方向回答四问——**好处/坏处 · 需要什么资源支撑 · 必要性具不具备 · 组织架构与能力要什么**。
> **判断基准**：安逸酒店集团现状 + 十五五规划。

---

## 〇、结论先行

| 方向 | 财务可行性 | 战略契合度 | 建议 |
|------|-----------|-----------|------|
| **一、直接租赁** | 中（利差可能为0） | ❌ **背离** | 不作主选 |
| **二、引进品牌（华住/全季）** | ❌ 结构性不成立 | ⚠️ **不匹配** | 仅作兜底（须重设条件） |
| **三、自主品牌** | ✅ **可成立（有三前置条件）** | ✅ **完全契合** | **主选** |

**一句话**：四川宾馆在十五五规划里被赋予的是"**巴蜀文化旗舰 + 全国川办母版 + 餐饮产品线源头**"三重身份——这三个身份，**只有自有品牌能承载**；租赁和引进品牌都会把这三重身份让渡出去。

## 一、事实底座（先对齐口径）

### 1.1 项目本体

| 项 | 内容 |
|----|------|
| 位置 | 成都市锦江区总府街31号（春熙路—太古里商圈核心） |
| 建筑面积 | 12,155 ㎡（酒店自持 10,484 + 外租 1,671） |
| 建筑年代 | 西楼 1961 / 南楼 1988；**经鉴定 C 级、D 级危房** |
| 现状 | 2019/5 因重大安全隐患停业（**已 7 年**） |
| 权属脉络 | 2022/10 划转安逸 → **2025/11 再划转回锦弘集团** |
| 现行方案 | 安逸**向锦弘租赁经营**：15年租期，**25%营收分成 或 50元/㎡/月保底**（取高，约 729 万/年） |

### 1.2 集团现状（安逸）

| 维度 | 现状 |
|------|------|
| 规模 | 56 家（自营 17 + 受托管理 39） |
| 2026 目标 | 103 家 · 利润 ≥ -5,000 万 · 营收 5.2 亿 |
| **能力短板** | **尚未完成品牌梳理、没有品牌培育、没有品牌模型**；不具备独立打造五星/超高端能力 |
| 2030 目标 | 轻资产管理 >200 家 · 营收 >9 亿 · 利润 >5,000 万 |

### 1.3 十五五规划对四川宾馆的定位（关键）

> "**中高端精品酒店**。承担**巴蜀文化旗舰酒店的产品模型验证**，是集团**以巴蜀文化定义城市酒店体验的品牌载体**。并且**可复制到全国各地川办宾馆**。作为**四川文化在地展示窗口**。将深圳四川宾馆项目改造纳入整个四川宾馆品牌体系建设。具备**米其林、黑珍珠等级精品餐饮**配套。**由此拉出安逸集团餐饮产品线**。"

并属"**前3·自有品牌旗舰**"（3+3 分组第一位）。

## 二、方向一：直接租赁

> **含义**：安逸不经营，将物业（或经营权）出租给第三方，收取租金（差），不投品牌、不担经营。

### 2.1 好处

| # | 好处 |
|---|------|
| 1 | **现金流确定、无经营风险**——固定租金落袋 |
| 2 | **不占用改造资金**（由承租方投）——对资金紧张的集团是"止血" |
| 3 | **管理成本最低**——不新增运营团队 |
| 4 | 快速结束"停业 7 年零收入"状态 |

### 2.2 坏处

| # | 坏处 | 说明 |
|---|------|------|
| 1 | **收益上限被锁死** | 二房东模式下（安逸租入25%→转租），**利差极可能为 0**（全季分析已证：四项档位三项利差为零） |
| 2 | **品牌资产让渡** | "四川宾馆"六十年国字号招牌被他人使用，**稀释而非积累** |
| 3 | **与十五五战略正面冲突** | 规划要"轻重分离→打造标杆→品牌运营→**标准输出**"；直接租赁让安逸**从"输出方"沦为"二房东"** |
| 4 | **丧失"全国川办母版"** | 规划的核心诉求是"可复制到全国川办"，租赁后**无模型可复制** |
| 5 | **丧失餐饮产品线** | 规划要"由此拉出餐饮产品线"，租赁后**无餐饮资产** |
| 6 | **15年锁定，弹性尽失** | 租约长期锁定，未来想做品牌也无法收回 |

### 2.3 需要的资源与支撑

| 类别 | 内容 |
|------|------|
| 权属 | 与锦弘的租赁关系理顺（关联方定价需第三方评估+集团审议） |
| 市场 | 租赁行情、承租方资信 |
| 法务 | 长租合同、危房安全责任划分（**关键：加固责任归谁**） |
| 财务 | 租金现金流测算 |

### 2.4 必要性

- **对"资产盘活"**：有必要（停业资产止血）
- **对"品牌战略"**：**不必要，且为负**——十五五规划的三大身份全部落空

### 2.5 组织架构投入与能力

| 项 | 内容 |
|----|------|
| 组织投入 | **几乎为零**（资产部 + 财务部即可） |
| 需具备能力 | 资产评估、租赁谈判、合同管理 |

### 2.6 小结

> 方向一是"**资产处置思维**"，不是"**产业发展思维**"。它适合"退出处置类"资产（规划已明确天府山庄/亚丁宾馆等），**不适合被规划明确列为"自有品牌旗舰"的四川宾馆**。

## 三、方向二：引进品牌（华住/全季等）

> **含义**：引入外部品牌（华住全季），借其品牌/会员/系统/管理，安逸作为业主或联营方。

### 3.1 好处

| # | 好处 |
|---|------|
| 1 | 借品牌势能 + 会员 + 系统，**开业快** |
| 2 | 管理输出成熟，**降低运营能力要求** |
| 3 | 集团**不需自建品牌**，培育期风险转移 |
| 4 | 华住有同商圈存量改造先例（桔子春熙路店，出租率80%+） |

### 3.2 坏处（知识库已有深度研判）

| # | 硬伤 | 数据 |
|---|------|------|
| 1 | **经济结构不成立** | 全季分成 **25%** = 安逸付锦弘 **25%**；四项档位**三项净利差为 0**，固租下限也为 0——安逸**承担全部风险而无利差** |
| 2 | **收益预测不可信** | 全季预测客房 RevPAR 400/460 元；华住系周边四店实测均值 **329.2 元**（高估 21.5%~39.7%）；华住自家桔子春熙路实盘 **350 元** |
| 3 | **加固成本未列明** | 报价 3,000/3,600万**未说明是否含 D 级危房加固**（刚性前置，金额巨大） |
| 4 | **战略不匹配** | 全季=中端有限服务，与规划"全服务/强文化主题/精品餐饮"三处不符 |
| 5 | **品牌稀释** | 保留"四川宾馆"字号但植入标准化中端产品 → **稀释六十年国宾资产** |
| 6 | **餐饮产品线落空** | 全季精选服务不设独立餐饮体系 |
| 7 | **身份倒置** | 安逸从"品牌输出方"变成"品牌承载方" |

### 3.3 需要的资源与支撑

| 类别 | 内容 |
|------|------|
| 谈判 | 经济结构重设（分成比例/固租水平/加固归属） |
| 标准 | 品牌标准与建筑条件的对齐 |
| 法务 | 15年长约、退出条款 |

### 3.4 必要性

- **短期**：有一定必要（快速盘活）
- **战略上**：**不必要**——与十五五"品牌塑造 + 标准输出"方向相反

### 3.5 组织架构投入与能力

| 项 | 内容 |
|----|------|
| 组织投入 | 品牌合作对接岗（1人） |
| 需具备能力 | 品牌合作谈判、标准对接、合同管理 |

### 3.6 小结

> 方向二的知识库结论是"**集团层面不具备可行性**"（经济结构+收益预测+战略三项硬伤）。**可保留接触作为兜底**，但须先重设：①分成显著高于25%或固租≥60元/㎡；②加固由品牌方承担；③改固定租金由品牌方担险。

## 四、方向三：自主打造"四川宾馆"品牌

> **含义**：安逸自主打造"四川宾馆"品牌，自主经营精品酒店（向锦弘租赁物业）。

### 4.1 好处

| # | 好处 |
|---|------|
| 1 | **品牌资产自有**——"四川宾馆"成为集团可复制母版 |
| 2 | **支撑轻资产输出**——"没有品牌矩阵，就没有轻资产扩张的入场券" |
| 3 | **文化旗舰载体**——六十年国宾史 + 历史建筑 + 川派文化，**三项独占优势** |
| 4 | **拉出餐饮产品线**——精品川菜（米其林/黑珍珠目标）成为集团餐饮源头 |
| 5 | **单房年收入高**——26.1万 vs 全季15.9万（高64%） |
| 6 | **非房收入占比高**——37% vs 全季8% |
| 7 | **资产与客户资源全归集团** |
| 8 | 完全契合十五五"1234"（文化主题赛道 + 品牌运营 + 标准输出） |

### 4.2 坏处与风险

| # | 坏处 | 数据 |
|---|------|------|
| 1 | **投入大** | 8,500 万（含加固1,500万） |
| 2 | **回收期长（基准）** | **22.8 年**（现行租金条件下不具备商业合理性） |
| 3 | **能力要求高** | 品牌塑造 / 文化策展 / 精品运营 / 餐饮，四项集团均薄弱 |
| 4 | **人才缺口** | 需品牌总监、文化策划、精品餐饮主理等专业人才 |
| 5 | **危房加固风险** | C/D 级危房，加固为刚性且金额待测 |
| 6 | **品牌培育风险** | 从0到1打造高端精品品牌，成功率不确定 |

### 4.3 需要的资源与支撑（**关键：三前置条件**）

| 前置条件 | 路径 | 效果 |
|----------|------|------|
| **① 租金重谈** | 压降至 30元/㎡/月以内；或以历史建筑保护/城市更新/文化项目名义申请减免 | 回收期 22.8 → **11.8 年** |
| **② 加固成本外部承担** | 成都市城市更新与历史建筑活化专项 + 省级文旅专项（**政策雷达已覆盖**）+ 或物业方锦弘承担 | 投入 8,500 → 7,000 万，回收期 → **8.6 年** |
| **③ 文化区与餐饮引入合作方** | 参照国堰"超级单店"模式，合作方承担装修投入，集团收租或分成 | 投入 → 5,025 万，回收期 → **5.3 年** |

**三条件叠加后**：投入约 5,025 万、年税前利润约 950 万、**回收期约 5.3 年**——**优于全季方案任何档位**。

其余支撑：资金（政策+自有）、专业人才、文化策展伙伴、精品餐饮伙伴。

### 4.4 必要性

**完全具备**，四条理由：
1. **规划明确赋身份**——四川宾馆是"前3自有品牌旗舰"第一位
2. **战略唯一载体**——"全国川办母版"只能靠自有品牌
3. **品牌矩阵缺口**——集团"没有品牌模型"，此项目是全集团品牌化的"从0到1"
4. **单店突破逻辑**——十五五战略"以单店突破促进品牌重塑"，四川宾馆正是单店突破样本

### 4.5 组织架构投入与能力

| 层级 | 投入 |
|------|------|
| 集团 | 品牌产品中心（品牌标准/文化IP/餐饮产品线）；**品牌总监**（外聘） |
| 项目 | 精品酒店运营团队（120间，人房比目标≤0.5）+ 文化策展岗 + 精品餐饮主理 |
| 能力 | ①品牌塑造 ②文化挖掘与策展 ③精品酒店运营 ④精品餐饮管理 ⑤空间内容运营（文化聚合区） |
| 新增岗位（产业部） | 品牌总监（外聘）+ 品牌运营专员（内部培养）+ 产业联动专员 |

### 4.6 小结

> 方向三**商业逻辑成立，战略上唯一自洽**，但**必须先解决三项前置条件**（租金、加固、合作方），否则基准回收期 22.8 年不可行。

## 六、结合十五五规划的战略判断

十五五"1234"战略的"**4**"是：**轻重分离 → 打造标杆 → 品牌运营 → 标准输出**。

```
方向一（直接租赁）：轻重分离 ✗ → 卡在第一步，永远到不了"标准输出"
方向二（引进品牌）：轻重分离 ✓ → 打造标杆 ✗（标杆是别人的）→ 标准输出不可能
方向三（自主品牌）：轻重分离 ✓ → 打造标杆 ✓ → 品牌运营 ✓ → 标准输出 ✓
```

**推论**：三个方向中，**只有方向三能走完十五五规划的"四步路径"**。方向一卡在第一步，方向二走到第二步就断了。

**再叠加"单店突破"逻辑**：十五五把"单店突破"作为品牌重塑的抓手。四川宾馆作为**前3自有品牌旗舰的第一位**，是这个逻辑的首发样本——**如果这个样本用租赁或外牌做，整个"单店突破→品牌重塑"的链条就断了**。

## 七、建议

### 7.1 主选：方向三（自主品牌），但先解三前置

| 步骤 | 动作 | 责任 |
|------|------|------|
| 1 | **先出结构加固方案与造价**（全部测算的基础） | 工程口 + 第三方 |
| 2 | **与锦弘重谈租金**（目标 ≤30元/㎡/月，或申请减免） | 集团 + 法务 |
| 3 | **申请加固资金**（成都城市更新/历史建筑专项 + 省级文旅专项） | 产业发展部（政策雷达已覆盖） |
| 4 | **文化区 + 餐饮引入合作方**（负担投入，集团收租/分成） | 产业发展部 |
| 5 | 三条件落地后再定投资决策 | 集团 |

### 7.2 备选：方向二（仅兜底，须重设条件）

- 分成显著高于 25%，或固租 ≥60 元/㎡/月
- **加固由品牌方承担且不计入装修投资**
- 改固定租金、由品牌方担险

### 7.3 不用：方向一

- 除非集团战略上决定**放弃"四川宾馆"品牌与"川办母版"诉求**——但这与十五五规划直接冲突。

### 7.4 政策雷达的衔接

> 方向三的"前置条件②（加固资金）"与"前置条件①（租金减免）"，**已在本轮建成的政策雷达中锁定对应政策入口**：
> - 成都市城市更新与历史建筑活化专项
> - 省级财政文旅发展专项资金（竞争立项）
> - 《推动住宿业高质量发展的措施》（升级改造 ≤投入10%，最高10万）
> - 国家文旅产业发展示范区（**2026-09-30 备案窗口**）
>
> 建议：**把四川宾馆的租金/加固申请，作为政策雷达"机会清单"的首批实战案例**。
