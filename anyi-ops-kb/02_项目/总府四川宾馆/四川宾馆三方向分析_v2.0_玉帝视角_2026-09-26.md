# 四川宾馆三方向分析（玉帝视角 · 中立版）v2.0

> **视角声明**（本版与前版的根本差别）：
> 1. **不带预设立场**——不预设哪个方向"更优"，只陈述三方向各自的条件、代价与成立前提；
> 2. **操盘主体 = 四川总府实业有限公司**——不是安逸酒店集团本部；
> 3. **不使用"安逸二房东"框架**——不把问题简化为"租入再转租的利差"。
>
> 判断权保留给决策者。本文件只做一件事：**把三个方向的真实条件摊开**。

---

## 一、事实底座

### 1.1 操盘主体：四川总府实业有限公司

| 项 | 事实 | 来源 |
|----|------|------|
| 股权 | 安逸酒店集团 **100% 全资**子公司（成都） | 安逸集团家底 v1.1/v1.2 |
| 定位 | "总府酒店相关"（持总府片区资产，含总府皇冠假日等） | 同上 |
| 财务（2022末） | 资产 40,951.35 万；负债 66,504.88 万；**资产负债率 162.40%**；**净资产 -25,553.53 万** | 资本运营调研报告2023 |
| 盈利 | 2022 营收 5,064.35 万，净利润 **-2,254.20 万**（多年连续亏损） | 同上 |
| 有息负债/资产 | 135.96% | 同上 |
| 融资空间 | **可通过贷款置换获得增量融资约 2.5 亿元** | 同上 |
| 已批事项 | **向兴业银行申请 2 亿元经营性物业贷款**（旅投总经会 8-8 决议）；用于贷款置换股东借款+九鼎融资 | 安逸集团治理结构认知 |
| 约束 | **2 亿贷款锁死 15 年现金流**；**已资不抵债 → 任何业务调整触发"三重一大"** | 同上 |
| 并表状态 | **未并表**（负债巨大，合并将使集团资产负债率升至 50% 以上） | 同上 |

> **这一栏是三个方向共同的"重力场"**：操盘主体账面资不抵债、且新增 2 亿贷款锁定 15 年现金流——**任何方向的可行性，都要先过"现金承受力"这一关**。

### 1.2 项目本体

| 项 | 事实 |
|----|------|
| 位置 | 成都市锦江区总府街 31 号（春熙路—太古里商圈核心） |
| 建筑面积 | 12,155 ㎡（酒店自持 10,484 + 外租 1,671） |
| 建筑年代 | 西楼 1961 / 南楼 1988；**鉴定为 C 级、D 级危房** |
| 停业 | 2019/5 因重大安全隐患停业（**已 7 年**） |
| 权属 | 2022/10 划转安逸 → **2025/11 再划转回锦弘集团**（产权在锦弘） |
| 现行租赁口径 | 15 年租期；**25% 营收分成 或 50 元/㎡/月保底**（取高，≈729 万/年） |

### 1.3 商圈与市场（客观数据）

| 指标 | 数据 |
|------|------|
| 供给 | 半径 2km 内 **371 家**酒店（经济型134/中档112/高档95/豪华30）；**中档 112 家最饱和** |
| 四星中位 ADR | 2023 约430 → 2024 约390 → 2025 约360（**三年 -16%**） |
| 四星出租率 | 75-82% → 72-78% → 70-76%（**三年 -6pt**） |
| 四星 RevPAR | 约340 → 约305 → 约274（**三年 -19%**） |
| 华住系周边四店 | 客房 RevPAR 实测均值 **329.2 元**（汉庭285/宜必思293/全季385/桔子353.7） |
| 五星本土品牌 | 总府皇冠假日、锦江宾馆 ADR 约 640-680 元 |

### 1.4 十五五规划对该项目的既定定位

> "中高端精品酒店……承担**巴蜀文化旗舰酒店的产品模型验证**……**可复制到全国各地川办宾馆**……**四川文化在地展示窗口**……具备**米其林、黑珍珠等级精品餐饮**配套……**由此拉出安逸集团餐饮产品线**。"（属"前3·自有品牌旗舰"）

> **注意**：这是**规划文本的既有表述**，是本次分析的一项"输入条件"，而不是分析结论。三方向与该定位的匹配程度**高低不同**，但"是否必须服从规划"本身，也是决策者可决定的事项。

## 二、方向一：直接租赁

> **含义**：总府实业不自行经营，将物业（或经营权）出租给第三方，收取租金。

### 2.1 好处

| # | 好处 |
|---|------|
| 1 | **现金流形态最简单**——固定租金，可预测 |
| 2 | **经营风险外部化**——不承担客房/餐饮/文化的运营波动 |
| 3 | **不占用改造资金**——装修由承租方投入，对"资不抵债 + 2亿贷款锁现金流"的主体，压力最小 |
| 4 | **管理复杂度最低**——无需组建运营团队 |
| 5 | 迅速改变"停业 7 年零产出"状态 |

### 2.2 坏处

| # | 坏处 |
|---|------|
| 1 | **收益封顶**——租金受市场行情约束；若承租方经营好，超额收益不归本方 |
| 2 | **品牌资产不积累**——"四川宾馆"招牌由他人使用，六十年国宾资产**只被消耗、不被增值** |
| 3 | **规划定位落空**——"产品模型验证""全国川办母版""餐饮产品线源头"三项无法实现 |
| 4 | **租约锁定**——15 年期内无法回收自主经营 |
| 5 | 危房安全责任划分需前置厘清（C/D 级危房，承租方通常要求免租期+加固责任明确） |

### 2.3 需要的资源与支撑

| 类别 | 内容 |
|------|------|
| 权属 | 与锦弘的租赁关系（或产权安排）先理顺 |
| 市场 | 租赁行情、承租方资信（**谁愿意租一栋 C/D 级危房 15 年**） |
| 法务 | 长租合同、安全责任、加固责任归属 |
| 财务 | 租金现金流测算；对 2 亿贷款的还款安排影响评估 |

### 2.4 必要性

- **对"资产止血"**：成立
- **对"规划的三重定位"**：不成立
- **判断要点**：这取决于决策者是否接受"**放弃四川宾馆的品牌诉求，换取确定性现金流**"

### 2.5 组织架构投入与所需能力

| 项 | 内容 |
|----|------|
| 组织投入 | 极小（资产/财务口径即可） |
| 所需能力 | 资产评估、租赁谈判、合同管理、安全责任管理 |

## 三、方向二：引进品牌（华住等）

> **含义**：引入外部品牌方（华住/全季等），由品牌方输出品牌、系统、管理与客源。

### 3.1 好处

| # | 好处 |
|---|------|
| 1 | **开业速度快**——品牌方有成熟改造与开业流程 |
| 2 | **能力门槛低**——不需自建品牌、自建体系、自建客源 |
| 3 | **风险分担**——改造投入与经营风险可由品牌方分担（视谈判） |
| 4 | 有同商圈先例可参照（桔子春熙路店，出租率 80%+） |

### 3.2 坏处（知识库既有研判）

| # | 问题 | 数据 |
|---|------|------|
| 1 | **经济结构需重设** | 全季方案分成 25% 与集团付锦弘 25% 相同；四项档位**三项净利差为 0**（该结论的前提是原"二房东"口径；改由总府实业操盘后，**须按新的主体口径重算**） |
| 2 | **收益假设偏高** | 全季预测客房 RevPAR 400/460 元；华住系周边四店实测均值 **329.2 元**（高 21.5%~39.7%）；华住自家桔子 350 元 |
| 3 | **加固成本未列** | 报价 3,000/3,600 万未说明是否含 D 级危房加固 |
| 4 | **产品档次差异** | 中端精选服务 vs 规划"强文化主题 + 精品餐饮" |
| 5 | **品牌资产归属他方** | 保留字号但植入标准化产品，是否"稀释"取决于产品设计 |
| 6 | **餐饮产品线难承接** | 精选服务品牌通常不设独立餐饮体系 |

### 3.3 需要的资源与支撑

| 类别 | 内容 |
|------|------|
| 谈判 | 分成/固租结构、改造投入分担、加固责任 |
| 标准 | 品牌标准与危房建筑条件的适配 |
| 法务 | 长约、退出、字号使用条款 |

### 3.4 必要性

- **短期**：成立（最快盘活）
- **对"规划三重定位"**：不成立
- **判断要点**：取决于决策者是否接受"**用品牌自主权，换开业速度与低能力门槛**"

### 3.5 组织架构投入与所需能力

| 项 | 内容 |
|----|------|
| 组织投入 | 小（品牌合作对接岗） |
| 所需能力 | 品牌合作谈判、标准对接、合同管理 |

## 四、方向三：自主打造"四川宾馆"品牌

> **含义**：总府实业（或集团）自主打造"四川宾馆"品牌，自主经营。

### 4.1 好处

| # | 好处 |
|---|------|
| 1 | **品牌资产自有并增值** |
| 2 | **可复制**——"全国川办母版"，为轻资产输出提供母版 |
| 3 | **单房产出高**——自主方案单房年收入 26.1 万 vs 全季 15.9 万（+64%） |
| 4 | **非房收入占比高**——37% vs 全季 8% |
| 5 | 餐饮产品线可由本项目拉出 |
| 6 | 与十五五规划**完全一致** |

### 4.2 坏处

| # | 坏处 |
|---|------|
| 1 | **投入最大**——8,500 万（含加固 1,500 万）；对资不抵债主体构成压力 |
| 2 | **回收期长（基准）**——**22.8 年**，现行租金条件下不具商业合理性 |
| 3 | **能力缺口**——品牌塑造 / 文化策展 / 精品运营 / 精品餐饮，四项集团均薄弱 |
| 4 | **人才缺口**——需品牌、文化策划、精品餐饮等专业人才 |
| 5 | **危房加固风险**——C/D 级，金额待专业测算 |
| 6 | **品牌培育不确定性**——从 0 到 1 打造高端文化品牌，成功率不保证 |
| 7 | 改造期 12 个月+，期间无收入 |

### 4.3 需要的资源与支撑（三条前置变量）

| 前置变量 | 路径 | 对回收期的影响 |
|----------|------|---------------|
| ① 租金条件 | 压至 ≤30 元/㎡/月；或按历史建筑保护/城市更新/文化项目申请减免 | 22.8 → **11.8 年** |
| ② 加固成本 | 外部承担（成都市城市更新与历史建筑活化专项 / 省级文旅专项 / 或产权方锦弘） | → **8.6 年** |
| ③ 文化区+餐饮投入 | 引入合作方承担投入，本方收租或分成 | → **5.3 年** |

> 三条件叠加后：本方实际投入约 5,025 万、年税前利润约 950 万、回收期约 **5.3 年**。
> **三者均为"变量"而非"既成事实"——是否可谈成，决定本方向的成立与否。**

### 4.4 必要性

- **对"规划三重定位"**：成立（三重定位只能由自有品牌承载）
- **对"资产止血"**：不成立（投入大、回收慢）
- **判断要点**：取决于"**规划定位是否作为硬约束**"，以及三前置变量能否谈成

### 4.5 组织架构投入与所需能力

| 层级 | 投入 |
|------|------|
| 集团 | 品牌产品中心（品牌标准 / 文化IP / 餐饮产品线）；品牌总监（外聘） |
| 项目 | 精品酒店运营团队（120 间，人房比目标 ≤0.5）+ 文化策展岗 + 精品餐饮主理 |
| 能力 | ①品牌塑造 ②文化挖掘与策展 ③精品酒店运营 ④精品餐饮管理 ⑤空间内容运营 |

## 五、三方向中立对比矩阵

| 维度 | 一、直接租赁 | 二、引进品牌 | 三、自主品牌 |
|------|-------------|-------------|-------------|
| 改造资金由谁出 | 承租方 | 视谈判（品牌方为主） | 本方（可引入合作方分担） |
| 本方现金压力 | **最低** | 中 | **最高** |
| 收益形态 | 固定租金（封顶） | 分成/租金（有天花板） | 经营利润（无封顶） |
| 收益确定性 | **高** | 中 | 低（培育期） |
| 回收期 | 取决于租金行情 | 视结构，可能不成立 | 22.8 年 → 优化后 5.3 年 |
| 品牌归属 | 无 | 他方 | **自有** |
| 能力门槛 | 低 | 低-中 | **高** |
| 组织投入 | 极小 | 小 | 大 |
| 与规划三重定位 | 不匹配 | 不匹配 | **匹配** |
| 与"全国川办母版" | 不可实现 | 不可实现 | **可实现** |
| 风险特征 | 低风险低收益 | 中风险中收益 | **高风险高潜在收益** |
| 对总府实业资不抵债的缓解 | 立即缓解 | 中期缓解 | 短期加重、长期改善 |

## 六、决策取决于哪些变量（把判断权交回）

三个方向都不是"绝对正确"，各自成立与否取决于以下**前置变量**：

| 变量 | 若取 A 值 | 若取 B 值 |
|------|----------|----------|
| **① 规划定位是否硬约束** | 是 → 只剩方向三 | 否 → 三者可比 |
| **② 租金能否重谈** | 能降至 ≤30 元/㎡ → 方向三可行 | 不能 → 方向三回收期 22.8 年 |
| **③ 加固资金能否外部承担** | 能 → 方向三压力大减 | 不能 → 方向三投入 ≥8,500 万 |
| **④ 总府实业现金承受力** | 可承受 5 年以上培育期 → 方向三 | 不可承受 → 方向一/二 |
| **⑤ 集团是否愿投入品牌能力** | 愿（品牌总监/文化团队）→ 方向三 | 不愿 → 方向二 |
| **⑥ 是否有合适承租方** | 有且条件优 → 方向一有吸引力 | 无 → 方向一空谈 |
| **⑦ 品牌方能否给出合理结构** | 分成显著>25% 或固租≥60 元/㎡ → 方向二可用 | 不能 → 方向二空转 |

## 七、小结

> **方向一** = 确定性现金流，代价是放弃品牌与规划定位；
> **方向二** = 速度与低门槛，代价是品牌自主权与部分收益；
> **方向三** = 品牌与规划一致，代价是资金、时间、能力与风险。
>
> **三者不是"对错"关系，是"取舍"关系。** 取舍的关键，是上表七个变量的取值——**这些变量的取值，不在本文件，而在决策者手上。**
