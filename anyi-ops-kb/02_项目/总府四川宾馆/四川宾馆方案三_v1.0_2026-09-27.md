## 三、1F 功能排布 · 方案 A vs B

### 方案 A：1F = 早餐厅 + 包间 ×3 + 大堂（标准酒店型）

```
┌─────────────────────────────────────────────────────────────────┐
│ 1F 西翼                         │       1F 东翼                  │
│ ┌──────────────────────────┐   │   ┌──────────────────────┐   │
│ │    包间×3（每间约80㎡）    │   │   │      大堂 + 接待       │   │
│ │    含独立备餐间           │   │   │   （约 400㎡）        │   │
│ └──────────────────────────┘   │   │                       │   │
│ ┌──────────────────────────┐   │   └──────────────────────┘   │
│ │    早餐厅 80座            │   │   ┌──────────────────────┐   │
│ │    翻台 2.5 次/天          │   │   │   公用通道 + 卫生间    │   │
│ │    （约 600㎡）            │   │   │   + 后勤入口            │   │
│ └──────────────────────────┘   │   └──────────────────────┘   │
│ ┌──────────────────────────┐   │   ┌──────────────────────┐   │
│ │   厨房 + 备餐（200㎡）    │   │   │   文创/商品售卖（200㎡）│   │
│ └──────────────────────────┘   │   │   （小规模）            │   │
│                                │   └──────────────────────┘   │
└────────────────────────────────────────────────────────────────┘
```

**特点**：
- 早餐厅是酒店刚需，1F 解决最实用
- 包间×3 可独立外卖 / 散客外摆
- 1F 无需垂直运输，客流引导自然

### 方案 B：1F = 策展空间 + 日咖夜酒 + 大堂 + 包间×2（目的地型）

```
┌─────────────────────────────────────────────────────────────────┐
│ 1F 西翼                         │       1F 东翼                  │
│ ┌──────────────────────────┐   │   ┌──────────────────────┐   │
│ │   策展空间（600㎡）        │   │   │      大堂 + 接待       │   │
│ │   含可变展墙+灯光装置      │   │   │   （约 300㎡）        │   │
│ │   定期举办巴蜀文化展/非遗   │   │   └──────────────────────┘   │
│ └──────────────────────────┘   │   ┌──────────────────────┐   │
│ ┌──────────────────────────┐   │   │   日咖夜酒（300㎡）     │   │
│ │   包间×2 + 小型会议室      │   │   │   含咖啡+酒+轻食       │   │
│ │   （每间约 60㎡）           │   │   │   全天营业，目的地客流   │   │
│ └──────────────────────────┘   │   └──────────────────────┘   │
│ ┌──────────────────────────┐   │   ┌──────────────────────┐   │
│ │   文化展示+商品售卖（400㎡）│   │   │   公用通道 + 卫生间    │   │
│ │   含川剧/蜀绣/茶艺/文创     │   │   │   + 后勤入口            │   │
│ └──────────────────────────┘   │   └──────────────────────┘   │
└────────────────────────────────────────────────────────────────┘

4F 顶楼（方案 B 特有）：
┌──────────────────────────┐
│   早餐厅 60座（迁至此处）   │  ←  含小型自助档口 + 简餐
│   翻台 2.0 次/天            │
├──────────────────────────┤
│   包间×2（小型，60㎡/间）   │
└──────────────────────────┘
```

**特点**：
- 1F 形成"酒店门面 + 目的地"双重身份
- 策展+咖啡+商品售卖创造独立营收（外延客流）
- 早餐厅迁至 4F，增加垂直运输压力
- 配套投资 +150 万

## 十一、与原方案对比（核心结论）

| 维度 | 原方案（165 间含 1F） | **方案三 A（145 间 1F 全非房）** | 变化 |

## 十二、三个必须锁定的条件

| 优先级 | 条件 | 效果 |
|--------|------|------|
| **①** | **1F 全部非房（无客房）** | 非房收入从 100 → 1,600 万元 |
