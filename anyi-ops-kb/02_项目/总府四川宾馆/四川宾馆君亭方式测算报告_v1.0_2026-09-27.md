## 四、君亭方式测算（加精品川菜包间 + 文化聚厅）

### 4.1 产品配置（vs 锦江方案）

| 项 | 锦江7.13 | 君亭方式 |
|---|---|---|
| 房间数 | 165 间 | **120 间**（拆墙 3改2/2改1）|
| 单房面积 | 24-28㎡ | **35-42㎡** |
| 精品川菜包间 | ❌ 无 | ✅ **3包间 + 主餐厅** |
| 文化聚厅 | ❌ 无 | ✅ **策展+茶空间+活动（1800㎡）** |
| 非房收入 | ~4%（仅会议室26万+外租76万）| **30%+**（川菜566万+文化300万+外租75万）|
| ADR 目标 | 520 | 650-800 |
| 对标 | 中端 | Pagoda 660 / 华侨夜泊 1000 |

### 4.2 投资构成（君亭方式）

| 项目 | 金额（万）|
|---|---|
| 结构加固（外部承担）| 0 |
| 客房装修（120间×22万）| 2,640 |
| 精品川菜装修 | 600（可合作方投入）|
| 文化聚厅装修 | 700 |
| 大堂公区装修 | 500 |
| 机电消防智能化 | 500 |
| 电梯更新 | 200 |
| 开办费 | 260 |
| 不可预见费 | 300 |
| **合计** | **5,700**（川菜合作方投入后可降至 5,100）|

### 4.3 核心发现：租金是生死线

🔴 测算发现（关键）

**在"25%营收分成"租金结构下，君亭方式反而更差——这是反直觉但致命的一点。**

原因：君亭方式减房（165→120）+ 加非房（川菜+文化聚厅），在"25%营收分成"下：
- 减房 → 客房收入下降；
- 加非房 → 综合收入上升 → **租金分成（25%）也同步上升**；
- 结果：多赚的非房收入，被租金分成吃掉大半，而客房收入的下降无法弥补。

| 租金口径 | ADR 700 / OCC 78% 的 IRR | 判定 |
|---|---|---|
| **现行 25% 分成 + 729万保底** | **-4.9%** | ❌ 不可行 |
| **重谈 15% 分成 + 500万保底** | **4.8%** | ⚠️ 过最低门槛，未过8% |
| **固定租金 500万/年** | **4.8%** | ⚠️ 同上 |
| 固定 500万 + ADR 800/OCC 78% | **9.9%** | ✅ 过合理门槛 |

## 六、最终结论

### 6.1 直接回答 Eric 的三个问题

**问题1：按君亭方式（加精品川菜包间+文化聚厅）怎么测算？**

> 加川菜包间（3间+主餐厅，年约566万）+ 文化聚厅（年约300万），非房占比从锦江的~4%提到30%+，但**必须同时减房到120间**（拆墙3改2/2改1），把单房面积从24-28㎡提到35-42㎡，ADR才有空间从520提到700-800。

**问题2：能否符合国资委要求？**

> **能，但有前提**。核心卡点是租金：现行"25%营收分成"下，加非房反而更亏（IRR -4.9%）。**必须把租金重谈到15%分成或固定500万/年**，同时ADR站上800元，IRR才能到9.9%、过合理门槛8%。

**问题3：投资回报如何？**

> 投资5,700万（川菜合作方可降至5,100万），在"租金重谈+ADR 800"下：**IRR 9.9%、回收6.7年**——优于锦江方案的4.06%/11年。

### 6.2 一句话总结

> **君亭方式能救活四川宾馆，但真正的关键不是"加川菜包间+文化聚厅"本身，而是"重谈租金"。**
>
> 因为现行"25%营收分成"租金，会让"加非房收入"变成"给业主加租金"——多赚的钱被抽走。只有把租金从"25%分成"改成"15%分成或固定500万"，加川菜+文化聚厅的溢价才能落到自己口袋，项目IRR才能从4%跳到10%。
