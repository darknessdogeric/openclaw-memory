## 1. 合资公司基本情况

### 1.1 股权结构

- **50:50 股权**： 安逸 + 锦江各占 50%
- **董事长**： 由安逸方派出（苏部长）
- **总经理**： 锦江方后续确认
- **新公司刚成立**： 所有制度可重新制定，市场化机制可直接纳入体系

### 1.2 参考案例

- **贵旅合资公司**： 去年已落地，联合品牌选取度假品牌"云居"作为共创品牌（前面加属地合作方前缀）

## 2. 联合品牌 vs 共创品牌（核心区分）

| 维度 | 联合品牌 | 共创品牌 |
|------|---------|---------|
| **品牌原型** | 锦江现有成熟品牌（力生/凯迪亚德/力博等）| 全新打造独立品牌 |
| **VI 体系** | 尊重原有 VI 体系与运营标准 | 完整独立 VI 体系 |
| **品牌露出** | 仅在名称前加"安逸"前缀 | 全新命名，全套 VI |
| **品牌话语权** | 锦江方 | 安逸方 |
| **落地速度** | 快速（1-2 个月可见）| 长期（3-12 个月）|
| **核心诉求** | 1+1>2，会员互通+平台共享 | 满足安逸 2025-2027 三年行动规划品牌孵化要求 |

## 7. 利润分成与退出机制

### 7.1 利润分成（设计原则）

```
总管理费收入 100%
   ↓
剔除设计/工程/筹建/系统 等专项成本
   ↓
剩余管理费按 六四 分成
   ↓
安逸方最终获得 30%
锦江方获得 70%（含设计/工程等自营）
```

### 7.2 退出机制

- 提前预设项目分歧与合作终止的退出规则
- 明确存量门店处置方式
- 涉及账和税的问题（投资人打款到合资公司还是外部）

- **预算**： 50 万营销费用预算

### 9.2 安逸茶山（蒙顶夜话活动）

- **9 月下旬落地** "蒙顶夜话"主题活动
- 邀请网红 IP **李伦**（李雷）到场分享
- **GMV 可追溯**的宣传效果（解决传统硬广审计痛点）
- **财务口径纠正**： OTA 15% 佣金应进客房成本，不是营销费用

### 9.3 安逸茶山现状

| 维度 | 现状 | 优化方向 |
|------|------|----------|
| 位置 | 蒙顶山 4A 级景区 | - |
| 运营 | 新媒体+OTA 全部外包 | 收回自营或战略合作伙伴 |
| 品牌 | 定位混乱（高端民宿/精品酒店多个）| 统一"安逸茶山"单一 IP |
| 小红书 | 点赞极低 | 通过新媒体活动提升曝光 |

### 9.4 重庆两江酒店模式（重要参考）

- **核心做法**： 资产授权代管模式
- **快速整合**： 180 家门店进入中国饭店集团前 30 行列
- **关键优势**： 无需划转资产、梳理股权，大幅降低整合难度
- **安逸借鉴方向**： 通过轻资产平台承接所有门店运营职能，剥离历史资产包袱
