> 拓展方向分三档：**【P0 紧急】 / 【P1 季度内】 / 【P2 战略级】** ### 1. 成都总府皇冠假日酒店（头部资产 · 城市商务标杆） **定位**：集团第一现金牛、城市商务标杆、合资品牌（假日品牌）
**数据画像**：周营收 142.13万（榜首）/ 出租率 92.86% / ADR 420.42元 / RevPAR 388.06 / 会员占比 **45%** **核心问题**：餐饮+会议 = 50.95万（占35%），结构已较健康。**但**客房同比 -7.05万 / 会议 -6.48万（小幅下滑） **拓展方向**：
- **【P2 战略级】做"集团数字化旗舰店"** — 集团目前没有真正意义上的"数字化标杆店"。总府的会员占比45%已具备数据基础。可作为 AHL 集团内试点的首家"AI Agent 落地店"（智能客服/动态定价/能耗管理/智能选品）
- **【P1 季度内】做大成都商务客的天花板** — 与平安四川分公司战略合作落地后，**争取成都政企差旅的第一接口**（基线已现：会员45%是集团最高）
- **【P1 季度内】短视频"住酒店+成都攻略"内容化** — 周报已规划但需加速，做成抖音/小红书**集团 S+级案例** --- ### 2. 古尔沟华美达酒店（文旅度假 · 严重亏损资产） **定位**：高山温泉度假、避暑旺季导向
**数据画像**：周营收 61.81万（不错）/ 出租率 **54.37%** / ADR 586.14元 / RevPAR 288.59 / **客房同比 -65万** ⚠️ **核心问题**：
1. 资不抵债 **181.74%**（715定稿明确）
2. 季节性极度（仅 6-9 月旺季，其余月份现金流断裂）
3. 周报中"日历房均价 1150元 vs 平均房价 586元" — **50%折扣也卖不满** → 真正的"假性旺"
4. 客源依赖东电职工春秋游 + 重庆地接社（**单一客源高风险**） **拓展方向**：
- **【P0 紧急】立即启动"破产保护 + 重整"评估**（投资和资产部主责，产发部协同）
- **【P0 紧急】冬季疗愈产品开发** — 当前 8 月已有 54%入住率，**真正的痛点是 11月-4月**。建议： - 温泉+中医康养（结合锦弘中医药？） - 温泉+滑雪（鹧鸪山步行可达） - 温泉+藏羌文化沉浸
- **【P1】黄龙/九寨过夜中转客的分流协议** — 黄龙九寨旺季酒店均价 1500-2500元仍满房，古尔沟是天然的"价格梯度承接者"
- **【P1】会员金卡淡季"包月住"** — 卖断会员淡季权益，对冲现金流
- **【P2 战略级】与阿坝州/甘孜州政府谈"扶贫+生态"补贴** — 政府背书是集团护城河之一，古尔沟是最佳试点 --- ### 3. 新良大酒店（城市商务 · 轻重分离试点） **定位**：城市商务、集团轻重分离改革试点、写字楼招商
**数据画像**：周营收 63.15万 / 出租率 **95.02%** / ADR 269.14 / RevPAR 255.73 / **会议 0 万** ⚠️ / 餐饮 1.5万 **核心问题**：
1. **会议完全空白**（出租率95%但会议收入0）— 周报说有5个会议，但收入为零 = 会议转化失败
2. 写字间招租推进中（应该是核心增量）
3. 负一楼柴油储罐整改（合规风险） **拓展方向**：
- **【P0 紧急】会议转化率归零问题** — 95%入住率但会议0 = 销售没抓"住客的会议潜力"。建议： - 租客入住时强制推送"会议房特惠包" - 写明"5 场会议 → 0 收入"的根因，是没签合同？还没接待？还是会议类型与酒店不匹配？
- **【P0 紧急】写字间招商是核心战场** — 配合集团"轻重分离"，把非核心楼层改成长租办公，吸引科技/律所/咨询公司（楼下密集）
- **【P1】联合集团其他酒店做"新良=集团销售总部"角色** — 利用其地理位置和高入住，承担销售指挥调度
- **【P2 战略级】配合 715定稿"轻重分离试点"** — 把部分楼层改成"长短租公寓 + 酒店"混合业态，对冲酒店淡旺季 --- ### 4. 深圳四川大厦（城市商务 · 餐饮强项 · 跨境门户） **定位**：深圳福田商务、川菜出川桥头堡、跨境资本对接窗口

1. **出租率 99.45% 但 ADR 148 = 走量不挣钱** 的典型
