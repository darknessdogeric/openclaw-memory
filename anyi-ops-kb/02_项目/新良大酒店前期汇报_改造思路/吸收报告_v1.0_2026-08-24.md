## 三、三大改造模式对比（核心命题）

### 模式（1）：外部品牌 — 双品牌精选服务

| 维度 | 英迪格（Indigo）| 逸衡（Even）|
|------|----------------|--------------|
| **品牌定位** | 高端设计驱动型精品酒店 | 中端健康生活方式酒店 |
| **集团** | 洲际集团 | 洲际集团 |
| **特色** | "一地一故事"、非标化、成都文化融合 | 健康生活方式、调性差异化 |
| **适用空间** | 塔楼 + 裙楼个别楼层公区 | 裙楼 |
| **客房数** | 约 200 间（需"三改二"）| 约 200 间 |
| **外立面** | 需大幅改造 | 需新增电梯 2 部 |
| **暗房问题** | — | 需开小天井解决 |
| **配套** | 全日餐厅 + 多功能厅 + 健身房 | — |
| **总投资** | **粗估 8000 万元+（不含一次机电）** | 未明确 |
| **优势** | 溢价天花板最高、竞品少 | 与周边连锁形成差异化 |
| **风险** | 投资大；酒店+写字间电梯混用问题阻碍大 | 工程改造复杂 |

### 模式（2）：自有品牌 — 简配版英迪格

| 维度 | 内容 |
|------|------|
| **价格定位** | 500-600 元（高于全季，低于 VOCO；避开 400-500 红海）|
| **品牌调性** | 深度挖掘成都在地文化元素，简配版/性价比版"英迪格" |
| **品牌策略** | 策划全新子品牌（沿用"安逸新良大酒店"难度太大）|
| **业态** | 抛弃传统全服务，不照抄精选/有限服务，深入研究主流消费者 |
| **优势** | 满足集团品牌战略、免品牌使用费、可成样板店 |
| **弊端** | 品牌策划+设计要求极高；回报不确定性大；需长期耐心培育 |

### 模式（3）：联合品牌 — 合资项目公司

| 维度 | 内容 |
|------|------|
| **合作对象** | 国内相对二线的品牌 |
| **投资模式** | 成立合资项目公司，**对方控股主导投建**（设计+施工）|
| **运营模式** | 利用对方成熟运营体系 |
| **收益模式** | **双重回报**：物业稳定租金 + 项目公司股权分红 |
| **优势** | 短工期、低造价、高品质、稳定收益+风险收益 |
| **前提条件** | 产权相对清晰（与原大股东部分区域模糊需协商）|

### 三模式综合对比

| 维度 | 外部品牌 | 自有品牌 | 联合品牌 |
|------|---------|---------|---------|
| **投资大小** | 大（8000万+）| 待测算 | 较小 |
| **回报确定性** | 高 | 中-低 | 高 |
| **品牌战略匹配** | ❌（不自创品牌）| ✅（强匹配）| 部分 |
| **工程复杂度** | 大（外立面）| 中 | 小（对方主导）|
| **运营难度** | 低 | 中-高 | 低 |
| **集团战略价值** | 中 | 高 | 中-高 |
| **风险** | 投资大+品牌方对价高 | 品牌策划要求极高 | 需协商产权 |

## 四、Eric 行业基因 + 现有知识库的关键洞察补充

### 4.1 与 Eric 既有认知的契合

#### 4.1.1 Eric 7/19 战略规划专家座谈里的"5 大能力诊断"

| Eric 7/19 诊断 | 新良现状 | 一致性 |
|----------------|---------|--------|
| 品牌效应 ❌ 没有 | 新良地处春熙路-太古里，但品牌识别弱，被连锁品牌挤压 | ✅ |

| 数字化 ❌ | 未提数字化系统 | ✅ |
| 体制机制 ❌ | 报告明确"国企属性全方位压倒酒店行业属性"是"绝大部分国企酒店状态不佳的根本之弊" | ✅ **Eric 自述** |

#### 4.1.2 Eric 8/13 战略规划专家座谈里的两大核心建议

- **轻重分离 + 数字化先行 = 同步进行**
- **品牌是重资产不是轻资产**（颠覆认知）

**对接到改造方案**：
- "品牌是重资产" → 自有品牌模式（模式 2）需要长期培育，不应是首选
- "轻重分离" → 联合品牌模式（模式 3）的"稳定租金 + 股权分红"恰好契合轻重分离逻辑
- "数字化先行" → 任何改造方案都应预留智能化线槽、网关、传感器（避免坑 12）

### 4.2 与 AHL 战略的对接

### 4.4 报告未提及但 Eric 应关注的潜在问题

#### 4.4.1 数据真实性校验

报告呈送 2026/5，但2025 年营收 3,434 万 vs 2024 年 4,637 万，下滑 26%。Eric 在丽苑 RGI 从第三→第一的关键是"数据精准"，此处建议：

> **核查 2025 财务数据的真实性**：
> - 营业收入 3,434 万（含物业租金 731 万）
> - 剔除物业租金后，纯酒店收入仅 2,704 万
> - 占比 79% 是酒店，21% 是物业
> - **物业收入稳定 → 酒店收入持续下滑 → 改造紧迫**

#### 4.4.2 报告未深入的关键点

| 缺失点 | 影响 |
|--------|------|
| **未提及现有客户结构**（OTA/协议/会员比例）| 无法判断改造对客群的影响 |
| **未提及数字化现状**（PMS/CRS/CRM）| 无法判断 AHL 接入的起点 |
| **未提及员工激励与流失率** | 国企酒店普遍存在人员老化问题 |
| **未提及 5 楼桑拿区、KTV 闲置的具体原因** | 改造可盘活的空间未量化 |
| **未提及装修标准**（如三星/四星标准的具体差距）| 影响改造预算精度 |
| **未提及与华住/锦江/亚朵在同商圈的对比数据** | 改造方向的竞争差异化依据不足 |

#### 4.4.3 报告中的"风险盲点"

- **未提及产权纠纷的法律风险**（7/23/24/27/28 楼产权未交割）
- **未提及品牌方谈判的实际进展**（仅推荐英迪格/逸衡，未提是否已接触）
- **未提及三种方案的财务测算对比**（投资额 vs IRR vs 投资回收期）
- **未提及改造期间的经营影响**（酒店停业 vs 部分停业 vs 不停业）
- **未提及员工安置方案**（改造后人员可能优化）
