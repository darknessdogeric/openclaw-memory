帆书·李蕾讲经典是**内容生产方**，提供 IP / 课程 / 用户 / 传播力。

## 五、"对等"的 5 条核心原则

1. **价值对等**——不是预算对等，而是**内容价值与场景价值的对等**
2. **品牌对等**——双方 LOGO 并列署名，**无主次之分**
3. **数据对等**——双方共享用户画像，**而非单方导流**
4. **传播对等**——联合 PR / 联合媒体 / 联合 KOL，**不抢话语权**
5. **退出对等**——任何一方退出，**IP 资产按贡献比例分配**
