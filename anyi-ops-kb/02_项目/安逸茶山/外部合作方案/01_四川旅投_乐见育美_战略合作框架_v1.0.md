## 二、合作内容（七大方向）

### 方向 1: 书香文化酒店标杆打造（与茶山项目直接相关）

- **书香酒店共建**: 乙方提供客房"听书角"设计、公共阅读空间规划、文化沙龙区运营方案
- **空间升级**: 旗下核心酒店、景区游客中心联合打造"帆书阅读空间"
- **产品创新**: "听书+住宿+在地文化体验"复合型产品（**"住书香酒店·听巴蜀故事"系列套餐**）

### 方向 2: 酒店管理人员培训

- 中高层: 领导力、服务创新、数字化运营、客户体验设计
- 一线: 文化素养、服务礼仪、沟通技巧、创新思维
- 体系建设: 帆书企业读书会模式

### 方向 3: 文旅研学 + 两岸三地交流

- 巴蜀文化主题研学（历史探秘、非遗体验、红色教育、科技创新）
- 蓉港、蓉台文化交流（"港澳台青年巴蜀文化研学行"）
- 入境研学（中国科技研学·巴蜀篇）

### 方向 4: B 端客户联合运营

- "巴蜀文化企业家论坛""书香企业家沙龙"
- **"安逸商学院"共建**（与安逸品牌体系耦合）
- "蓉企出海/蓉品出海"主题内容

### 方向 5: 景区景点运营赋能

- 景区文化内容植入（文化驿站、扫码听书导览）
- **AI 伴游+帆书讲解**（与 AHL 平台契合度极高）
- 校企联动（港城大成都研究院、川大文学院、四川旅游学院）

### 方向 6: 巴蜀文化旅游走廊共建（核心 IP）

- **双 IP 体系**：
  - "**小金乌**"（蜀·太阳神鸟）— 温暖/好奇/爱幻想/仰望星空
  - "**小虎哥**"（巴·白虎图腾）— 豪爽/仗义/热血/爱探险
- **品牌 SLOGAN**: "跟着小金乌和小虎哥，飞越三千年"
- 三大篇章:「溯源·双星记」「在场·双城记」「未来·双界记」

### 方向 7: "书卷里的中国"等项目合作

- 城市巡讲落地（成都/重庆/广元/宜宾等节点城市）
- 一城一主题（"书卷里的成都·天府之国的千年书香"等）
- 文化活动联合开发（"巴蜀文化阅读季""企业家读书会"等）

## 三、产品体系（三大篇章）

### 篇章一: 溯源·双星纪（过去）

- 前置音频:「小金乌的时光笔记」+「小虎哥的探险日志」（每期 3-5 分钟）
- 前置短视频: 双 IP 历史探秘（抖音/小红书/视频号周更）
- 在地手绘地图: 扫码即听对应讲解
- 在地研学线路: "小金乌的考古日记"（三星堆+金沙 2 天 1 晚）+ "小虎哥的巴山探险"（罗家坝+巴山大峡谷 3 天 2 晚）
- 在地文化驿站: 蜀文化区设"小金乌驿站"，巴文化区设"小虎哥驿站"

### 篇章二: 在场·双城记（现在，**产业回报最集中**）

- 前置种草内容:「小金乌严选·蜀味」+「小虎哥严选·巴味」
- 核心产品: 3-7 天全链路服务包"**双 IP 行囊**"（电子路书 + 双 IP 音频导览 + 实体手账本 + 手绘地图 + 严选食宿清单）
- 在地城市巡讲:「书卷里的中国」
- 在地严选食宿: "有故事"的非网红餐厅 + 旅投旗下文化主题酒店
- 双 IP 文化市集: 川渝居民互动互通

### 篇章三: 未来·双界记（未来，**对接科幻产业政策**）

- 联合科幻创作: "巴蜀未来"主题内容（"如果三星堆文明延续到了今天？""一百年后的成都是什么样子？"）
- 成都科幻馆深度体验一日游
- 想象力工作坊: 青少年"你写/画的小金乌/小虎哥未来故事"
- 时空胶囊计划: "给一百年后巴蜀的一封信"

## 四、运营流程: 三层漏斗转化模型

```
第一层: 线上种草（广）— 帆书 APP 音频 + 抖音/小红书/视频号
   ↓ 用户点击"巴蜀行囊"产品入口
第二层: 在地服务（深）— 文化驿站 + "双 IP 行囊" + 严选商家
   ↓ 城市巡讲现场转化
第三层: 深度转化（长）— 研学/企业定制/年度"巴蜀文化护照"
```
