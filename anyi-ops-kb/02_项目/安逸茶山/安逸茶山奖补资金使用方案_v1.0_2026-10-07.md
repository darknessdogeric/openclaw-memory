# 安逸茶山奖补资金使用方案 v1.0

> **会议时间**：2026-10-08 16:30（明天）
> **奖补总额**：**1200 万元**（省文旅厅文旅融合专项）
> **主体公司**：四川蒙顶山茶业有限公司
> **使用约束**：定向茶业公司，不可挪用（须先与咨询公司核对可使用科目边界）
> **核心思路**（Eric 2026-10-07 15:46）：
>
> ① **安逸礼物线侧 + 新媒体矩阵**（品牌打造 / 商标注册 / 酒店线下点位 / 跨境电商合作 / 景区租赁）
> ② **茶山活动找客群**（市场化精准定位 · 数据驱动 · 活动 A/B 测试）

## 一、预算结构（1200 万 · 5 大科目）

| # | 板块 | 金额（万）| 占比 | Eric 思路对应 |
|---|---|---|---|---|
| **A** | **安逸礼物品牌与商标** | **120-150** | 10-12.5% | ① 品牌 + 商标注册 |
| **B** | **酒店线下场景打造** | **150-200** | 12.5-16.7% | ① 各酒店点位 + 装修 + 物料 + 联营筹备 |
| **C** | **新媒体矩阵与电商合作** | **200-250** | 16.7-20.8% | ① 新媒体矩阵 + 电商（跨境尤其）+ 代运营合作 |
| **E** | **茶山客群定位与传播** | **300-350** | 25-29% | ② 茶山活动 · 主题与客群验证 |
| **F** | **租赁 / 场地 / 启动储备** | **80-120** | 6.7-10% | ① 酒店或景区租赁启动费 |
| — | **合计** | **850-1070** | **71-89%** | **预留 130-350 万作为「二期项目 / 政策复评配套」资金池** |

> **重要原则**：**1200 万不全花完**。奖补有"专账专户 / 3 年节奏"要求，账面留 10-30% 是合理的"二期 + 复评"配套（避免被追责）。

### 板块 E · 茶山客群定位与传播（300-350 万 · Eric 思路重点）

> Eric 关键句：「茶山景区缺乏的是市场认知，以及明确的客群定位。所以需要相当的人气聚集和传播效应。除了新媒体矩阵的搭建以外，线下的活动是必不可少的。拉出主题和主线，找到精准客群。这个主题和主线不能拍脑袋，而是通过各种类型的活动面向不同人群去做数据比对。然后找出关键匹配客群，并且将整个景区和酒店的运营资源往这个方向深入贯穿。比如可以做读书会，独立音乐人音乐会，茶道养生的线下召集等等，面向不同年龄段做活动，看哪个效果最好。」

**这是 Eric 整套思路的核心**：**不是先确定主题，而是用 A/B 测试跑出主题**。

#### E1 · 主题矩阵（4 大主题 · 同期 / 错峰运行）

| # | 主题 | 目标人群 | 活动形式 | 周期 | 投资（万）|
|---|---|---|---|---|---|
| **E1-1** | **茶山读书会** | 25-45 岁文艺青年 / 中产 | 名家领读 + 茶山夜话 | 全年 4-6 期 | 70-80 |
| **E1-2** | **独立音乐人茶山音乐会** | 20-35 岁音乐爱好者 | 民谣/独立音乐 + 茶山露营 | 全年 2-3 期 | 70-80 |
| **E1-3** | **茶道养生线下召集** | 35-60 岁养生人群 | 茶道体验 + 中医养生 + 山居 | 全年 4-6 期 | 60-70 |
| **E1-4** | **家庭茶山研学营** | 5-12 岁亲子家庭 | 茶园参观 + 手工制茶 + 自然教育 | 寒暑假 4 期 | 50-60 |
| **预留 / 调整** |  |  |  |  | 50-60 |
| **合计** |  |  |  |  | **300-350** |

#### E2 · 6 个月数据驱动决策框架

```
T+0月（启动）：4 大主题同步启动同期 A/B 测试
  ↓
T+1-2月（数据收集）：每主题记录 5 个核心指标
  - 报名转化率（曝光→报名）
  - 到场率（报名→现场）
  - 客单价（消费/客）
  - 二次传播率（UGC 帖子数/客）
  - 复购/复访率（30 天内回访率）
  ↓
T+3月（数据分析）：跨主题对比，找出 TOP 1-2 主题
  ↓
T+4-6月（资源聚焦）：把 TOP 主题资源放大 8-10 倍
  - 联合景区/酒店/餐厅/MICE 资源做联动
  - 上升为「安逸茶山」年度 IP
  ↓
T+7-12月（品牌固化）：沉淀品牌资产 + 二期申报材料
```
