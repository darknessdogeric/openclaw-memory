## 四、此次洽谈要谈什么

### （一）核心主张

**建议业主方不采用特许经营路径，而由业主方将经营管理整体委托给锦江饭店管理公司，由旅投侧提供客源支持，形成三方酒管合作模式。**

### （二）两种模式对比

| 维度 | 特许经营（业主方现意向） | 委托经营（我方建议） |
|---|---|---|
| 运营主体 | 业主自建团队 | 锦江饭店管理公司派驻团队 |
| 经营风险 | 业主承担全部经营风险 | 业主按约定支付管理费，经营风险由管理方按合同分担 |
| 管理费构成 | 品牌使用费（版税）约营业收入的 3%—8% | 基本管理费约营业收入 2%—4%，另设奖励管理费约营业利润（GOP）的 5%—10%，另有系统使用费与营销费 |
| 品牌方角色 | 品牌标准输出与系统支持 | 同上，并需就转委托管理出具品牌方同意 |
| 业主方获得 | 品牌与系统，不承担经营输出 | 品牌、成熟运营体系、客源导入，且不必自建团队 |
| 旅投角色 | 无 | 客源支持（协议客户、差旅合作、集团体系内流量） |

### （三）三方分工主张

| 方 | 角色 | 投入 | 获得 |
|---|---|---|---|
| 港恒悦（成都）商贸有限公司 | 资产与投资主体 | 物业投入、改造与开办资金、支付管理费用 | 品牌、运营体系、客源、稳定收益 |
| 安逸酒店集团 / 锦江饭店管理公司 | 运营与管理输出方 | 派驻管理团队、运营标准与 SOP、培训与督导、OTA 与直销体系 | 管理费与奖励管理费、品牌输出样板、集团体系内案例 |
| 四川旅游投资集团 | 资源与客源支持方 | 客源导入与政企客户资源 | 集团体系内轻资产案例、西部市场影响力 |

### （四）本次沟通希望达成的三项具体成果

1. **取得业主方对"委托经营管理"路径的书面意向**，明确业主方是否接受由锦江饭店管理公司承担运营输出，并同意以该路径继续推进与雅高的品牌合作谈判。
2. **就三方合作框架形成初步分工共识**，明确客源支持的具体形式与量化口径（协议客户导流、集团差旅协议、会员互导、联合营销活动等），避免停留在原则性表述。
3. **确认下一步工作节点**：业主方提供产权与授权文件、雅高品牌授权路径的书面意见、财务与经营数据（RevPAR / 入住率 / 平均房价 / 渠道结构）、以及物业管理方的配合承诺，形成双方确认的推进时间表。

### （五）谈这个方案对业主方为什么更有利

1. **不必自建团队**：新店开业期正是团队搭建与运营体系磨合最耗时的阶段，委托管理可直接承接开业期的爬坡风险。
2. **不必承担经营试错成本**：委托管理下，业主方按管理费付费，经营结果与管理方绩效挂钩，风险边界清晰；特许经营下全部经营风险由业主自担。
3. **客源支持是特许经营拿不到的**：旅投侧的政企客户资源与集团差旅协议，是业主方自行谈判难以获得、且不可替代的部分。
4. **体系与资产分离**：业主方保留资产与收益权，不承担运营团队的人力与管理成本。

## 五、谈判分工与口径提示

### （一）人员分工建议

| 角色 | 建议承担 | 关注点 |
|---|---|---|
| 主谈 | 产业发展部负责人 | 合作模式主张、三方分工、业主方意愿确认 |
| 运营口径 | 锦江饭店管理公司代表 | 委托管理可行性、收费结构建议、派驻方案 |
| 客源口径 | 集团相关业务口 | 客源支持的具体形式与量化边界，不作超范围承诺 |
| 记录 | 项目组 | 纪要、待核事项清单、下一步时间表 |

### （二）口径提示

1. **先确认主体关系，再谈模式**。业主方与物业开发方的法律关系、授权链条未明前，不宜就合同条款作实质承诺。
2. **不在会上承诺具体收费数字**。管理费基数、奖励管理费比例、爬坡期安排，需在取得业主方经营数据与物业条件后测算再定。
3. **客源支持要给形式，不给空头承诺**。明确以何种机制、多大规模、由哪一级机构对接，避免形成无法兑现的预期。
4. **同步摸清雅高态度**。品牌方对转委托管理的接受度决定方案是否成立，应尽早取得雅高书面意见。
5. **注意品牌区分**。本项目品牌为雅高 MGallery Collection（美憬阁精选，高端精选线），与美居（Mercure）、美爵（Grand Mercure）、诺富特（Novotel）为不同品牌线，不可混用；同理，集团内部品牌授权亦须与委托管理合同在期限、费用与终止条件上相互衔接。

## 六、风险提示

1. **需求端下行**：金融城甲级写字楼空置率升至约 35.67%，租金同比下降 10.62%。短期新增办公人口带来需求增量，中期需关注企业办公面积调整对商务住宿与会议需求的影响。
2. **同址竞争密集**：同在 1777 号的大魔方铂悦高空酒店线上点评 5,332 条、锦都嘉玺与本项目同栋，客源获取与点评资产争夺存在直接竞争。
3. **品牌方态度是前提**：雅高已与华住交叉持股并取得多个品牌在华独家加盟权，其中国区精细化运营投入存在变数，这既是我方切入的窗口，也是窗口关闭的风险。
4. **业主方为民营且成立时间较短**，其经营能力、资金安排与履约能力需在合作条款中设置相应保障。
5. **开业初期评分波动风险**，建议将 OTA 资产建设纳入委托管理首年重点动作。
