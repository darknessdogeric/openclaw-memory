## 四、待规范环节（10 类）

> **核心发现**：合同体系较为完整（特别是 C1 + C3），但**实操层面仍有 10 类待规范环节**需要在运营中持续补充协议或 SOP。

### 4.1 风险类（需重点关注）

| # | 环节 | 现状 | 风险 |
|---|------|------|------|
| **W1** | **铁路方原因导致变更的风险传导** | C1 明确"铁路方原因导致取消/变更，安逸不承担违约责任"，但**对心已远的连带影响**未明确传导机制 | 铁路方临时变更可能导致心已远大额损失，且无法向安逸求偿 |
| **W2** | **履约保证金使用边界模糊** | C1 允许扣减用于"违约/舆情/维护稳定/质量安全" | 扣减边界宽泛，**易引发争议**（什么算"维护稳定"）|
| **W3** | **银行账户"动态满额"操作** | C1 第 6 条要求保证金"即时动态满额" | 实操如何做到"即时"补足？需内部审批流程规定 |
| **W4** | **"空窗期"列车闲置收益分配** | C3 提到"空闲期开行须双方协商并另行签订协议" | 实际闲置多久？收益如何分配？**空白** |

| # | 环节 | 现状 | 待规范 |

| **S2** | **客用品（卧具/装饰）更新标准** | C3 要求"采购、维修、更新"由安逸负责 | **更新频次/质量标准**未明确 |

## 五、关键风险提示（Eric 重点关注）

### ⚠️ 风险 1：安逸担保责任过重

```
✅ 看似安逸只收 1000 万/年 + 转让品牌 → 轻松
⚠️ 实际安逸承担：
   - 5500 万综合服务费（10 年，C3）
   - 全部舆情责任背书（哪怕是心已远引发的，安逸品牌受损）
   - 5 项保证金扣除触发条件（边界模糊）
   - 政策风险全归安逸（铁路方原因导致取消，安逸免责，但品牌受损由安逸承担）
```

### ⚠️ 风险 2：心已远实际承担过重

```
✅ 心已远看似收益全归自己
⚠️ 实际承担：
   - 履约保证金 1100 万（保证金超过 10 年运营综合服务费 10%）
   - 经营风险全担（即使不赚钱也要支付 1000 万/年）
   - 30% 违约金（舆情/用工/转包）
   - 列车物资采购 + 维护（车上物品）
   - 安全主体责任（铁路方原因导致的安全事故也归心已远）
```

### ⚠️ 风险 3：银创角色尴尬

```
C2 中银创是 45% 大股东
但：
   - 不直接面对成铁集团（安逸出面）
   - 不直接面对心已远（安逸出面）
   - 仅享有知情权 + 重大事项一致决策权
   - 收益按投资比例分（但安逸抽成 1 亿综合服务费后才分）

→ 银创的"投资-回报"链路复杂，需要厘清
```

### ⚠️ 风险 4：国央企合规风险

```
C1 + C2 + C3 + C4 涉及：
   - 安逸集团党委书记 + 董事长 + 总经理 + 班子成员会签
   - 国资委三重一大决策（涉及 5500 万 + 1 亿大额支出）
   - 安全生产主体责任（心已远违约，安逸品牌连带）
   - 舆情管理（国央企最敏感）

→ 安逸必须把合同涉及的"三重一大"决策记录完整
```

## 七、合同优化建议（4 条）

### 优化 1：增设"心已远运营评价机制"

```
现状：C1 没有对心已远运营能力的定期评估
建议：增设"安逸集团对心已远年度运营评价"
   - 满意度（旅客/媒体/政府）
   - 财务健康度（收入/利润/现金流）
   - 运营规范度（合规/安全/服务）
   - 评价结果与履约保证金扣除挂钩
```

### 优化 2：明确"铁路方原因"的损失分担机制

```
现状：C1 铁路方原因导致取消/变更，安逸免责，但心已远独自承担
建议：增设"共同保险机制"
   - 铁路方原因导致的损失，安逸/心已远/成铁三方按比例分摊
   - 或购买列车运营保险
   - 或建立应急基金
```

### 优化 3：明确"首发活动"后续标准

```
现状：C4 是单次活动合同，没有"常态化首发活动"机制
建议：建立"列车首发活动 SOP"
   - 每次新线路首发按统一模板
   - 媒体邀请清单标准化
   - 安全预案标准化
   - 费用基准标准化
```

### 优化 4：明确"品牌使用边界"

```
现状：C1 说"本项目外商业用途须另行协议"
建议：尽快签订《"锦绣天府号"品牌授权使用细则》
   - 允许的衍生产品（如文创、出版物）
   - 不允许的擦边使用（如未经授权的衍生品）
   - 品牌价值评估与补偿
```
