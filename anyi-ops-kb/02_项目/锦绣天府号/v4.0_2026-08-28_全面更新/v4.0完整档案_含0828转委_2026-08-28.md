```

   ├─ 转委托期限变更
   ├─ 新增/变更运营方
   └─ 或解除的

甲方应书面通知乙方
   ↓
本确认书所涉的运营管理委托事宜
   根据甲丙双方运营合作协议的履行情况而对应变更或解除

```

   转委安排对甲乙丙三方均发生效力

   ├─ 依托旅游列车开展的一切经营活动具有相关经营资质
   └─ 经营行为均符合国家法律法规及铁路行业规定

责任承担：
   ├─ 丙方在运营过程中引发的：
   │   ├─ 交易纠纷
   │   ├─ 安全责任事故
   │   ├─ 知识产权争议
   │   └─ 社会舆情风险
   │   → 由丙方承担最终责任
   │
   └─ 如乙方依据《旅游列车服务协议》向甲方主张权利的
       → 甲方承担相应责任后
       → 有权向丙方全额追偿 ⭐
