## 二、十五五战略规划（核心）

### 2.1 战略主线

**一核引领 + 五化驱动**

| 维度 | 内容 |
|------|------|
| 一核 | 以品牌为核心引领 |
| 五化 | 标准化运营（前提/标准筑基）、集约化管理（手段/集约提效）、连锁化拓展（模式/连锁拓局）、规模化经营（结果/规模变现）、数智化能力（底座/数智赋能） |

### 2.2 业务架构（3+1）

- **基石业务：轻重协同** — 自持型酒店业务（优化提升）/ 政务酒店管理业务（精耕/差异化突围/聚焦发展）/ 中高端酒店管理业务（规模复制）
- **第二曲线业务：餐饮突围** — 打造特色化餐饮（能力沉淀 → 优化提升 → 聚焦发展）

### 2.3 6 个核心能力

产品研发能力、会员运营能力、细节服务能力、精细运营能力、投资整合能力、数智化能力贯通

### 2.4 5 位一体战略保障

党建统领 / 组织重塑 / 资源配置 / 人才强企 / 统筹发展和安全

## 三、数智化整体架构（7 层纵向 + 5 层横向）

### 3.1 纵向 7 层

| 层级 | 名称 | 核心内容 |
|------|------|---------|
| 1 | 边缘物联（感知层） | 环境监测传感器、水电计量、智能窗帘、智能照明、空调集控、智能门锁、RCU 客房控制、消防报警、安防监控、电梯控制、楼宁智能控制、具身智能机器人 |
| 2 | 数据层（云边协同的智能硬件底座） | 边缘网关、本地应急保障、边缘规则引擎、缓存同步、自治运行、企微/邮箱消息触达、动态资源更新、应用版本发布 |
| 3 | 规划层（智慧中台） | 业务中台 / 数据中台 / 物联中台 / 智能引擎 四大中台 + 集成中枢（PMS/CRS/CRM/财务/HRMS 适配层） |
| 4 | 决策层 | 价格与收益管理系统、客流预测、智能能耗优化、双通路系统、指标管理平台、可视化大屏 |
| 5 | 审查层（治理与迭代） | 项目治理、版本迭代、效果评估 |
| 6 | 执行层（场景应用） | 客诉预警、向见知识库、图像质检、技能工具、能耗分析、经营报表自动化 |
| 7 | 反馈层 | 运营管控、品质管理、巡检 SOP、风控合规、全生命周期管理、视频会议、供应链采购、宴会销售、工程保修、合同档案 |

### 3.2 横向 5 层支撑

| 层 | 核心职能 |
|----|---------|
| 安全与合规 | 数据安全 / 行业合规 / 隐私保护 / 风险防控（数据采集-存储-使用全流程合规） |
| 集成与接口 | 内部接口（OA/CRM/财务系统对接）/ 外部集成（OTA、支付、公安、银行） |
| 权限与运营支撑 | 角色权限（前台无定价权，管理层通过大屏查看）/ 运维监控 / 故障告警 |
| 标准与规范 | 数据标准 / 服务标准 / 接口规范 / 技术规范（避免各层级各自为政） |
| 治理与迭代 | 项目治理 / 版本迭代 / 效果评估 / 成本控制 |

### 3.3 中台核心定位

业务中台 + 数据中台 + AI/IoT 中台 + 集成中枢。中旅的核心定位是**"存量系统的能力转换器"**——只做能力封装、数据打通、标准统一三件事，不替代现有系统。

## 五、自研 vs 第三方路径对比（关键判断）

中旅明确选择**"自研 + 敏捷开发"**路径，并给出了与第三方研发的全维度对比：

| 对比维度 | 自研 + 敏捷 | 依赖第三方 |
|----------|-----------|-----------|
| 全项目周期 | **1 个月**（核心功能上线） | 6-18 个月 |
| 周期压缩 | **80%** | — |
| 迭代效率 | 2-4 周/次 | 1-6 个月/次 |
| 应急需求 | **1-3 天**闭环 | ≥1 个月 |
| 紧急变更 | **3 天**落地 | 需重走全流程 |
| 成本 | 轻量化优化 3 天落地 | 超支延期风险高 |
| 技术掌控 | **100% 自主可控** | 乙方主导，强供应商绑定，卡脖子风险 |
| 业务直连 | 直面一线真实需求 | 多层级传递失真 |
| 合规 | 严守国企合规红线 | 需走外部流程 |
| 长期成本 | 持续优化 | 持续上溢 |

中旅的判断逻辑：**自研 + 敏捷是强合规、多审批环境下数字化高效落地的最优路径**。这一判断对安逸集团尤其相关——安逸作为省属国资二级公司，同样面临强合规与多审批约束。

## 六、组织架构（总部）

### 6.1 总部"强运营、赋能型"定位

按"敏捷前台、强大中台、集约后台"思路，打破过往双线并行。

### 6.2 总部 19 个一级单元

| 板块 | 单位 |
|------|------|
| 党口（4） | 党委会、董事会、党群工作部、纪委办公 |
| 总部职能（6） | 办公室、战投企管部、人力资源部、财务部、审计部、法务风控部 |
| 监督（2） | 巡察办公室、安全监管部 |
| 4 大中心（中台） | 品牌产品中心、科技信息中心、会员运营服务中心、供应链管理中心 |
| 5 大 BU（前台） | 高端品牌 BU、精选品牌 BU、政务服务 BU、资产管理 BU、餐饮业务 BU |
| 子品牌 | 雅阁酒店（维景、维景国际、睿景、旅居、维景迎宾） |

### 6.3 关键判断

中旅总部 19 个一级单元中，**4 大中心（中台）+ 5 大 BU（前台）+ 子品牌**的结构，与本集团 2026 年战略调整建议中提出的"四大中台能力中心 + 前中后台分离"思路**高度一致**。

## 七、市场对标分析（与华住、锦江对比）

### 7.1 整体架构对比

| 维度 | 中旅酒店 | 华住集团 | 锦江国际 |
|------|---------|---------|---------|
| 架构理念 | 一中台、双终端、全链路数字大脑 | 全自研云原生架构，4 大中台 + 双终端 + 全链路 | 一中心三平台（全球创新中心 + 全球会员/运营/供应链平台） |
| 中台核心 | 能力转换器（适配层封装 + 不改老系统） | 全业务能力复用底座（基于中台重建） | 全球多品牌协同能力中枢 |
| 整合路径 | 适配层封装 → 数据打通 → 标准统一 → 分阶段下线 | 直接全自研替换 | 适配层 + 温和整合 |
| 5 套 PMS / 3 套 CRS 并存 | 是（需整合） | 否（统一 WinPMS） | 是（需整合） |

### 7.2 终端入口对比

| 维度 | 中旅 | 华住 | 锦江 |
|------|------|------|------|
| C 端 | 心享会 APP/小程序（宾客全周期） | 华住会，会员超 2.1 亿，会员间夜占比超 76% | 锦江酒店，会员超 1.8 亿，会员间夜占比超 67% |
| B 端 | 繁星 APP/PC（全场景工作台） | 华通 APP | 锦江运营通 APP |

### 7.3 自研外采边界

| 集团 | 自研范围 | 外采范围 |
|------|---------|---------|
| 中旅 | 智慧中台、双端 APP、AI 场景化应用、低代码平台 | 云资源、大模型算力、成熟 PMS/CRS 套件、智能硬件 |
| 华住 | **100% 核心能力全自研**（PMS/CRS 核心系统无供应商绑定） | 基础算力、智能硬件 |
| 锦江 | 中台架构、AI 引擎、全球运营/会员/供应链平台 | 基础算力、智能硬件、区域化成熟套件 |

### 7.4 关键对比判断

- **华住最激进**：100% 自研，从底层重构实现全链路统一。前提是新系统能完全替代老系统。
- **锦江最稳健**：全球多品牌并购后温和整合，先适配层打通数据，再分步替换。
- **中旅最务实**：明确不替代老系统，只做能力转换——这是"国企合规 + 多审批环境"下的现实选择。

## 八、与本集团（安逸）的对照关系

### 8.1 直接对应

| 中旅做法 | 安逸对应安排 | 借鉴程度 |
|---------|------------|---------|
| 总部 19 个一级单元 + 4 中心 + 5 BU | 集团总部 + 4 大中台能力中心 + 前中后台分离 | **高度一致** |
| 中台定位：能力转换器（不改老系统） | AHL 协议层（适配 PMS/CRS 等存量系统） | **高度一致** |
| 自研 + 敏捷路径 | AHL 集团内 MVP → 2030 全面覆盖 | **一致** |
| 心享会 + 繁星双端 | 安逸会（C 端）+ 员工工作台（B 端） | **方向一致** |
| 5 化驱动（标准化/集约化/连锁化/规模化/数智化） | 1234 战略 + 1（数智化） | **高度一致** |
| 轻重协同 3+1 | 轻重分离 + 6 大改造 + 1 个国堰 | **高度一致** |
| 数智化"先做适配层、不改老系统" | 数智化建设先打通 PMS/CRS 再造新系统 | **核心方法论一致** |

### 8.2 安逸可重点借鉴的 4 点

**第一，明确数智化建设路径选择。** 中旅已经走过这条路：先做适配层和能力封装（不改老系统），数据打通后再分阶段下线。安逸可以避免"全自研替代"的激进路径，也避免"长期并行"的拖延路径。

**第二，明确中台四中心的职能边界。** 品牌产品中心 / 科技信息中心 / 会员运营服务中心 / 供应链管理中心——可作为安逸"4 大中台能力中心"的具体职能参考。

**第三，明确自研与外采的边界。** 中旅的边界是"智慧中台、双端 APP、AI 应用、低代码平台"自研，"云资源、大模型、成熟套件、智能硬件"外采。这一边界可作为安逸 AHL 平台建设时的决策参考。

**第四，明确合规与效率的平衡方法。** 中旅选择自研敏捷，理由是"严守国企合规红线"。这一逻辑对安逸作为省属国资二级公司完全适用。

### 8.3 安逸与中旅的差异点（不可直接套用）

- 中旅是央企（中国旅游集团旗下），资源充裕，可全自研或大规模自研
- 安逸是省属二级公司，资源受限，自研比例应更低，更多采用"适配层封装 + 核心模块自研"
- 中旅 2025 年会员 1000 万（近），中高端定位
- 安逸现有会员约 30 万（粗估），数字化基础更薄，需更长的过渡期
- 中旅有现成的雅阁体系、安逸有锦江饭店管理公司体系——但盘子都远比中旅小
