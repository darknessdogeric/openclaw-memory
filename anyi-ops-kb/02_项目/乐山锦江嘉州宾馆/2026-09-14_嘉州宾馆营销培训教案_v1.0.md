## 二、模块 1:营销思维转变(1.5 小时)

### 1.1 学习目标

- 理解酒店营销的本质 —— 不是卖房间,而是**卖场景**
- 区分"传统营销思维"与"现代营销思维"
- 认识嘉州宾馆的核心资源(诊断报告 Part 5.1)

### 1.2 核心内容

**1.2.1 三句话讲清楚酒店营销**

- 第一句:**酒店不是卖房间,是卖"在地体验的入口"**
- 第二句:**酒店不是等客户,是"创造客户来的理由"**
- 第三句:**酒店不是一次买卖,是"终身关系运营"**

**1.2.2 传统营销 vs 现代营销 对比表**

| 维度 | 传统营销(嘉州现状) | 现代营销(嘉州目标) |
|------|------------------|------------------|
| 视角 | 我们有什么卖什么 | 客户需要什么我做什么 |
| 渠道 | 协议 + OTA | C/B/G 三端 + 会员 |
| 价格 | 一口价 | 动态定价 |
| 产品 | 客房 + 餐饮 | 客房 + 餐饮 + 体验 + 文化 |
| 客户关系 | 一次性交易 | 会员终身价值 |
| 数据 | 财务数据为主 | 行为数据 + 画像 + 预测 |
| 营销团队 | 销售部独立 | 全员营销 |

**1.2.3 案例分享(15 分钟)**

- **案例 1**:亚朵酒店"住宿+零售"模式(2025 零售 36.71 亿,占总 37.5%)
- **案例 2**:锦江嘉州本地竞对华邑酒店的"3-5 月领跑"经验
- **案例 3**:某区域同档次酒店从协议占比 80% 降到 50% 的转型案例

### 1.3 学员演练(30 分钟)

## 六、模块 5:价格策略与收益管理(1.5 小时)

### 1.1 学习目标

- 理解酒店收益管理的基本逻辑
- 掌握动态定价的方法
- 拒绝"价格战陷阱"

### 1.2 核心内容

**1.2.1 嘉州的"价格战陷阱"**

> 7月降价 12% → 入住率反降 12% → RevPAR 暴跌 23%

**为什么降价失败?**
1. 价格不是散客决策的核心因素(产品+体验+渠道更重要)
2. 降价损害品牌调性
3. 协议客户更敏感,降价反而触发"比价"心理
4. 真正的杠杆是产品力和渠道力

**1.2.2 收益管理四要素**

```
收益(Revenue) = 出租率(OCC) × 平均房价(ADR) × 可售房数
```

| 杠杆 | 收益管理动作 |
|------|------------|
| **OCC < 60%** | 提升产品力+渠道力(不是降价)|
| **60% < OCC < 80%** | 微调价格 + 优化客群结构 |
| **OCC > 80%** | 提价 + 提升高端房占比 |
| **特殊时段**(节假日/会议)| 提前锁价 + 协议价上浮 |

**1.2.3 动态定价模型(简化版)**

| 因素 | 加价 | 降价 |
|------|------|------|
| **提前预订天数** | 长程预订降价 | 短程预订加价 |
| **竞争对手价格** | 高于竞对 | 低于竞对 |
| **客户类型** | 散客加价 | 协议微调 |
| **入住天数** | 长住降价 | 短住保留 |
| **附加服务** | 含早加价 | 不含早降价 |

### 1.3 学员演练(45 分钟)

```

   ↑                                              ↓
   └──────────── 宾客忠诚 ←──────────────────────┘
```

**1.2.2 嘉州网评现状**

| 平台 | 当前分 | 行业基准 | 差距 |
|------|--------|---------|------|
| 携程 | 4.79 | 4.85+ | -0.06 |
| 同程 | 4.80 | 4.85+ | -0.05 |
| 去哪儿 | 4.90 | 4.85+ | +0.05 ✅ |
| 美团 | 4.70 | 4.85+ | -0.15 🔴 |
| 华客 CSI | 96.96 | 95+ | ✅ |

**提升目标**:3 个月内所有平台均达到 4.85+

**1.2.3 网评运营 5 大动作**

1. **入住前提醒**(小程序推送,引导好评)
2. **退房前 3 分钟服务**(前台主动问"这次入住体验怎么样?")
3. **差评 1 小时响应**(立即致歉 + 解决方案 + 跟进入住)
4. **好评激励**(赠送下次入住券/小礼品)
5. **每周网评复盘会**(前厅部每周一)

**1.2.4 服务标准化 6 大场景(嘉州专项)**

| 场景 | 标准动作 | 时长 |
|------|---------|------|
| 入住接待 | 3 句话 + 1 杯茶 + 引导至房间 | 5 分钟 |
| 客房巡房 | 每日 2 次(中午 + 晚上)| 3 分钟/次 |
| 餐饮上菜 | 15 分钟内首道菜 + 嘉州故事介绍 | 全程 |
| 退房告别 | 3 句话 + 会员邀请 + 下次预约 | 3 分钟 |
| 投诉处理 | 倾听 + 致歉 + 立即方案 + 24h 回访 | 全程 |
