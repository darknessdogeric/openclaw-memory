## 四、三大核心痛点

### 4.1 数字化运营滞后
- 无自主小程序点餐,扫码跳转第三方平台
- 会员依赖前台人工登记
- 安逸集市、会员二维码曝光点位不足
- 自助采购、自动入会功能未落地
- 增加员工与财务人工工作量

### 4.2 新媒体流量转化不足
- 抖音账号客房、餐饮**业务混营**(流量标签混乱)
- 私域粉丝沉淀薄弱
- 新媒体外包月预算上限 11,000 元
- 线上 4.9 分但**粉丝基数低**

### 4.3 集团统筹短板
- 国营老宾馆**独立分散**(集团统筹不足)
- 运营标准不统一
- 急需建立川内过境酒店**对标体系**(乐山 + 都江堰互通经验)

## 五、优化提升方向(4 大维度)

### 5.1 渠道与客源分层拓展

#### 1. 政企差旅攻坚
- 依托本地电网完成国网上商旅入库
- 联动乐山电信、移动内部推荐入库**央企差旅采购**
- 把握 **7-11 月国企采购窗口期**

#### 2. 疗休养业务深挖
- 重点对接省内机关、省属国企
- 挖掘省内疗休养订单

#### 3. 入境与新媒体客群运营
- 针对入境游客打造**酒店历史文化展示墙**
- 拆分双抖音垂类账号(**云上餐饮号 + 嘉州客房号**)
- 小红书、抖音主打"**宅酒店**"年轻客群
- 突出江景、投影房型优势
- 搭建抖音粉丝群完成**公域转私域闭环**

#### 4. 价格与存量会员运营
- 优化房价梯度
- 客房手卡、电梯、大堂增设安逸会员二维码
- **自助入会**

### 5.2 产品与硬件精细化优化

| # | 方向 | 关键动作 |
|---|------|----------|
| 1 | 客房微改造 | 套房淋浴间高台张贴**安全提示标识**;试点全场景智能客控加装线路板 |
| 2 | 餐饮提质增效 | 菜品滤油小份盛装;套餐搭配硬菜+特色小菜;赠送小菜**合规引导客评**;**早餐厅+自助餐分渠道单独核算** |
| 3 | 空间资产盘活 | 闲置区域分段对外出租;西楼餐饮区加快评估流程,优先匹配轻餐饮业态 |
| 4 | **文化 IP 打造** | **深挖嘉州画派、三江历史、红色接待沿革**;常态化每月 1-2 场公益文化活动;联动打造安逸旗下酒店联动短视频 |

### 5.3 数字化与集团标准化建设

| 行动 | 内容 |
|------|------|
| 集团统筹 | 完善安逸集市自助下单、会员自动入会功能;全域铺设商品、会员二维码 |
| **对标机制** | **对标都江堰国堰宾馆建立 STR 数据对标机制**;统一统计口径;按月复盘出租率、RevPAR 等核心指标 |

### 5.4 集团统筹整合要求

- 安逸集团需强化总部统筹职能
- **破解旗下国营老宾馆独立分散、运营标准不统一问题**
- **国企酒店不可照搬民企单一化、扁平化运营模式**
- 需兼顾政务、旅游、家庭多元客群
- **建立川内同类型过境酒店对标体系**
- 乐山、都江堰宾馆**互通运营经验、共享渠道资源**

## 六、文化 IP 战略机会(新发现!)

| 资产 | 内容 |
|------|------|
| **嘉州画派** | 中国重要画派之一(可深挖) |
| **三江历史** | 乐山三江汇流独特资源 |
| **红色接待** | 1953 年乐山地委招待所历史 |

→ 可作为安逸集团"在地文化主题酒店"的标杆之一
