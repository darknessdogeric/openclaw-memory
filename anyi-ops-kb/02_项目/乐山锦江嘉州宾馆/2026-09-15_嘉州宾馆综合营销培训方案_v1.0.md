## 第一章 方案总览

### 1.1 一句话定位

> **以嘉州宾馆真实经营数据为锚,以 8 大营销痛点为靶,以 8 大培训模块为药,以 30/60/90 天评估为证,系统性提升嘉州团队营销能力,推动 2026 年 4 季度经营业绩反弹。**

### 1.2 为什么必须做这次培训

**外部压力**(来自诊断报告):

| 压力 | 数据 |
|------|------|
| 9 月营收断崖式下滑 | 93 万 vs 去年 154 万,**-39.52%** |
| 7 月累计利润深亏 | -425 万(虽同比减亏,但仍处亏损区间) |
| 会议市场几乎消失 | -73.95% |
| 散客营收完成度仅 | 48.31% |
| 会员完成度 | 54.62% |
| 金卡售卖完成度 | **32.05%** |

**内部能力短板**(8 大痛点):

1. 渠道结构性失衡(协议 68.4% + OTA 1.2%)
2. 数字化基础空白(无独立小程序)
3. 餐饮占比仅 26% + 产品结构混乱
4. 散客营收完成度不足 50%
5. 新媒体严重滞后(抖音混营)
6. 客源过度依赖政务协议
7. 价格战陷阱(降价 12% 反降 12% Occ)
8. 应收账款集中(冷莉 79%)

**关键判断:** 嘉州不是"做不好",而是"没做好"。**资源不少,营销引擎缺失。**

### 1.3 培训目标

**目标 1(认知层)**:让全体员工"看见"嘉州真实经营数据,共识 8 大痛点,形成"我们要改变"的共同意愿。

**目标 2(能力层)**:让前厅/销售/餐饮/客房/管理层各自掌握 3-5 项可立即使用的营销技能(入会话术、抖音运营、动态定价、客户分层运营等)。

**目标 3(业绩层)**:30 天后散客营收完成度从 48% 提升到 70%+,60 天后会员完成度从 54% 提升到 80%+,90 天后 OCC 恢复至 60%+。

### 1.4 培训三大原则

| 原则 | 含义 |
|------|------|
| **诊断先行** | 用嘉州自己的数据说话,不空谈 |
| **行动导向** | 每个模块结束给出"嘉州 30 天行动清单" |
| **业绩对赌** | 培训效果与营销 KPI 直接挂钩 |

### 2.2 7大 SWOT 总结

#### 优势 (S)
1. 70+ 年历史沉淀(1953 乐山地委招待所)

1. 竞对低价抢量(华美达 ADR 303)
2. 品牌酒店下沉(中端市场挤压)

### 4.1 模块 1:营销思维转变(1.5 小时)

#### 学习目标
- 理解酒店营销的本质 — **不是卖房间,是卖场景**
- 区分"传统营销思维"与"现代营销思维"
- 认识嘉州宾馆的核心资源

#### 核心内容

**三句话讲清楚酒店营销**:
- 酒店不是卖房间,是卖"在地体验的入口"
- 酒店不是等客户,是"创造客户来的理由"
- 酒店不是一次买卖,是"终身关系运营"

**传统营销 vs 现代营销 对比表**:

| 维度 | 传统营销(嘉州现状) | 现代营销(嘉州目标) |
|------|------------------|------------------|
| 视角 | 我们有什么卖什么 | 客户需要什么我做什么 |
| 渠道 | 协议 + OTA | C/B/G 三端 + 会员 |
| 价格 | 一口价 | 动态定价 |
| 产品 | 客房 + 餐饮 | 客房 + 餐饮 + 体验 + 文化 |
| 客户关系 | 一次性交易 | 会员终身价值 |
| 数据 | 财务数据为主 | 行为数据 + 画像 + 预测 |
| 营销团队 | 销售部独立 | **全员营销** |

**案例分享**(15 分钟):
- 亚朵酒店"住宿+零售"模式(2025 零售 36.71 亿,占总 37.5%)

### 4.5 模块 5:价格策略与收益管理(1.5 小时)

#### 学习目标
- 理解酒店收益管理的基本逻辑
- 掌握动态定价的方法
- 拒绝"价格战陷阱"

#### 核心内容

**嘉州的"价格战陷阱"**:
> 7月降价 12% → 入住率反降 12% → RevPAR 暴跌 23%

**为什么降价失败**:
1. 价格不是散客决策的核心因素
2. 降价损害品牌调性
3. 协议客户更敏感,降价反而触发"比价"心理
4. 真正的杠杆是产品力和渠道力

**收益管理四要素**:
```
收益(Revenue) = 出租率(OCC) × 平均房价(ADR) × 可售房数
```

| 杠杆 | 收益管理动作 |
|------|------------|
| OCC < 60% | 提升产品力+渠道力(不是降价)|
| 60% < OCC < 80% | 微调价格 + 优化客群结构 |
| OCC > 80% | 提价 + 提升高端房占比 |

## 第八章 风险控制与应急预案

### 8.1 风险识别与应对

| 风险 | 触发条件 | 应对方案 |
|------|---------|---------|
| **培训组织风险** | 学员到场率 < 80% | 提前 1 周签到承诺 + 集团通报 |
| **讲师水平风险** | 学员满意度 < 3.5 分 | 备用讲师 / 课后补讲 |
| **落地执行风险** | 30 天行动清单完成度 < 50% | 周例会追踪 + 集团督办 |
| **业绩反弹风险** | 培训后 60 天指标未改善 | 重新诊断 + 二轮培训 |
| **核心人员流失** | 关键人员离职 | 培训资料录屏 + 多副本 |
| **资金风险** | 培训预算超支 | 控制在 6 万以内 |

### 8.2 应急预案

**情景 1:培训当天突发不可抗力**
- 应对:延期 1 周,所有预约重排,提前 48 小时通知
- 备份:线上同步培训(ZOOM/腾讯会议)

**情景 2:学员抵触情绪强烈**
- 应对:管理层先开 30 分钟沟通会,统一思想
- 关键话术:"嘉州的资源不缺,缺的是把资源变成客户的能力"

**情景 3:培训效果不达预期**
- 应对:60 天复盘后启动"二轮培训"聚焦薄弱模块
- 邀请外部讲师(中旅/华住)加强

### 8.3 培训成功的关键

1. **集团支持**:董事长或分管副总出席培训启动会
2. **嘉州管理层以身作则**:店总全程参与,中层干部必须到
3. **培训与考核挂钩**:未参加培训的部门负责人扣月度绩效
4. **培训后必须有行动**:30 天行动清单与季度奖金挂钩
5. **持续跟进**:集团每 30 天派人督导
