## 四、核心营销痛点(8 大诊断)

### 4.1 ⭐⭐⭐ 痛点 1:营销渠道结构性失衡——过度依赖协议,OTA 几乎放弃

**数据证据:**
- 公司协议价占 68.4%(过度单一渠道)
- 网络分销仅 1.2%(9月)
- 7月 OTA 渠道 -123 间

**问题诊断:**
协议客户是基本盘没错,但协议客户萎缩+OTA 不做=收入崩塌。**当务之急不是放弃协议,而是要重塑"协议+OTA+会员+散客"四轮驱动。**

**核心行动建议:**
1. **OTA 全面重做**:不是 0.78 万的现状,应做到 10 万+(占 15%)
2. **抖音本地生活**:把云上餐厅+客房打包成"乐山两日游"产品
3. **会员体系深度激活**:金卡权益重新设计,提升复购

### 4.2 ⭐⭐⭐ 痛点 2:数字化基础几乎是空白——会员依赖前台人工,无独立小程序

**数据证据:**
- 无自主小程序点餐,扫码跳第三方
- 会员依赖前台人工登记
- 自助采购、自动入会功能未落地
- 月均会员注册 1,864 远低于目标

**问题诊断:**
前台是会员转化的唯一节点,但前台的话术、激励、能力都没有到位。这是"用最贵的人力做最便宜的转化"。

**核心行动建议:**
1. **全员营销话术标准化**(3 句话入会)
2. **前台入会激励**(每单 5-10 元即时激励)
3. **金卡权益重设计**:权益升级 + 价值可视化
4. **全员 KPI 绑会员**:从部门负责人到一线员工

### 4.3 ⭐⭐⭐ 痛点 3:餐饮占比仅 26%,且产品结构混乱

**数据证据:**
- 9月餐饮收入 24.69 万,占总 26.4%(目标 30-40%)
- 厨房产品过多过杂:常备 25 套+零点菜单,出餐效率低
- 茶坊 -95.73%(几乎归零)
- 会议 -73.95%(几乎归零)

**问题诊断:**
餐饮是酒店的"非房收入"金矿,但乐山嘉州的餐饮:
- 产品太多 = 备餐成本高、出餐慢
- 网红化不足 = 嘉州味道套餐只在乐山本地有认知,缺乏"为吃而来"的客流
- 茶坊/会议基本放弃 = 错过非房收入机会

**核心行动建议:**
1. **菜单革命**:9 月起精简菜单(已规划),保留点击率 TOP 50%
2. **云上餐厅网红化**:江景资源是独一份的,做成"必打卡"地标
3. **早餐突围**:抓住本地散客+住店客双客群
4. **宴会重启**:婚宴/会议市场不能放弃,要专门团队

### 4.4 ⭐⭐ 痛点 4:散客营收完成度仅 48%,意味着过半任务"无着落"

**数据证据:**
- 7月散客营收 15.46 万 / 目标 32 万 = **48.31%**
- 上门散客 -409 间(转化为会员)
- 9月政府散客 +64.19%(逆势)

**问题诊断:**
散客是酒店最健康的客源(高利润、低维护),但嘉州严重依赖协议(68.4%)。**散客下降的根本原因是酒店没有"为散客设计的产品"——产品还是协议客户的副产品。**

**核心行动建议:**
1. **散客专属产品**:针对家庭/年轻客群的"乐山两日游"产品包
2. **周末散客价 vs 协议价差异化**:周末散客价不超过协议价上限,反而能激活
3. **亲子房型打造**:已有但未强化,主题房+服务配套
4. **大学生客群专项**:考试房、考研房、长租月卡

### 4.5 ⭐⭐ 痛点 5:新媒体严重滞后——抖音账号混营,粉丝基础薄弱

**数据证据:**
- 抖音账号客房、餐饮业务混营(流量标签混乱)
- 私域粉丝沉淀薄弱
- 新媒体外包月预算上限 11,000 元
- 线上 4.9 分但粉丝基数低

**问题诊断:**
**抖音已经成为酒店"种草-预订-复购"主战场**,但嘉州完全没发力:
- 账号定位不清(业务混营)
- 内容质量不高(外包给 1.1 万预算团队)
- 直播带货几乎空白(只做了几次)

**核心行动建议:**
1. **双账号矩阵**:云上餐饮号 + 嘉州客房号(已规划,但未落地)
2. **内容工厂模式**:每周 3-5 条短视频(客房探店+餐饮种草+城市玩法)
3. **直播常态化**:每周 1-2 次,逐步做到每周 4 次
4. **预算结构调整**:11,000 元外包费不够,应考虑内部团队

### 4.6 ⭐⭐ 痛点 6:客源结构过度依赖政务协议——抗风险能力弱

**数据证据:**
- 协议单位 7月 -176 间,被政府批量入住托底
- 会议市场几乎消失
- 7月会议收入 -73.95%

**问题诊断:**
协议客户占比 68.4% 是双刃剑——稳定但脆弱。**一旦政府接待减少/反腐趋严,营收立即崩塌。**

**核心行动建议:**
1. **协议结构优化**:协议客户数 +20%,但单客户占比 -10%
2. **疗休养市场**:已有省总工会基地资质,但目前承接量有限
3. **央企差旅**:已完成国网入库,下一步对接电信/移动
4. **团餐+旅行社**:成都核心客源地深耕

### 4.7 ⭐ 痛点 7:价格策略被动——降价 12% 反降 12% Occ

**数据证据:**
- 7月客房降价 12% 但入住率反降 12%
- RevPAR 暴跌 23%
- 9月 ADR ¥436 vs 7月 ¥386(已部分恢复)

**问题诊断:**
**价格战是失败的**——降 12% 没能拉动入住率,说明:
- 价格不是散客决策的核心因素
- 降价损害品牌调性
- 真正的杠杆是产品力+渠道力

**核心行动建议:**
1. **价格策略转向价值策略**:不降价,提价值(加早餐/加服务/加权益)
2. **动态定价模型**:基于 OCC/ADR/竞对实时调整
3. **价格分层**:协议价、散客价、OTA 价、会员价四套价格体系

### 4.8 ⭐ 痛点 8:应收账款集中风险——冷莉一人占 79%

**数据证据:**
- 应收账款总额 149 万
- 冷莉一人占 79%(其中 70%+ 逾期)
- 累计回款率 91.78%(同比下降 0.93pp)

**问题诊断:**
**应收账款本身不是营销问题,但它挤占了营销预算**——资金被占用,营销投入必然受限。

**核心行动建议:**
1. **专项催收小组**:针对 150 天+ 逾期账款
2. **新签协议付款条款优化**:缩短账期,降低集中度
3. **每月营销预算与回款挂钩**:回款率不达标,营销预算冻结

## 五、营销定位建议

### 5.1 核心定位

> **"乐山嘉州宾馆 = 乐山双世界遗产入口的城市文化会客厅"**

不是"老牌三星级酒店",不是"乐山嘉州商务酒店"。

定位三要素:
- **地域**:乐山(双世界遗产所在地)
- **客群**:文化体验者 + 政务接待 + 商务+疗休养
- **价值**:城市稀缺资源(江景+文化IP+老牌政务接待)

### 5.2 客群分层策略

| 客群 | 占比目标 | 营销策略 |
|------|---------|---------|
| **C 端散客**(家庭+年轻+文旅)| 40% | OTA + 抖音 + 小红书 + 私域 |
| **G 端政府协议**| 30% | 关系维护 + 政务产品 + 央企差旅 |
| **B 端企业协议+疗休养+团队**| 20% | 旅行社 + 工会 + 大型企业 |
| **会员复购**| 10% | 会员体系 + 老客激活 |

### 5.3 产品组合

| 产品 | 定位 | 价格带 |
|------|------|--------|
| 嘉州江景套房 | 必打卡旗舰 | ¥800-1,200 |
| 嘉州文化主题房 | 差异化 | ¥500-800 |
| 嘉州味道套餐 + 云上餐厅 | 非房核心 | ¥200-500 |
| 周末乐山两日游产品 | 引流款 | ¥600-900/2 晚 |
| 亲子主题房 | 周末高频 | ¥500-700 |
| 疗休养/团建套餐 | 政企团购 | 按人数报价 |
