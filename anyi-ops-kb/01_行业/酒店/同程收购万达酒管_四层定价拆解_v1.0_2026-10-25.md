# 同程 24.97 亿收购万达酒管 —— 四层定价拆解

> **分析日期**: 2026-10-25
> **触发**: Eric「同程收购万达酒管这个事。感觉买贵了。分析分析这个事情呢。」
> **框架**: 知其然知其所以然（五维）+ 博弈论 + 群论（对称性/不变量）+ 存量翻新判断框架
> **信源**: 同程旅行/万达酒店发展公告、财新、新华网、证券时报、界面新闻、百度百科、STR、观点网

## 0. 结论先行

> **"买贵了"这个直觉是准的，但市场给的理由（9.5x EV/EBITDA 落在可比中位 → 公允）技术上没错、实质上选错了分母。**
>
> - 换成 2024 年实际盈利，静态 **PE 18.4x / PS 3.05x** —— 这才是真实价格
> - 折现到现金流：买价隐含 **5% 永续复合增长 + 10% 回报率**，而行业正从增量转向存量效率
> - 三条硬伤：**规模经济不成立**（204 家 vs 华住 1.2 万家）、**管道在漏水**（万达一边卖酒管一边卖物业）、**高端是逆风资产**（2025 国际集团在华全线下滑）
> - 但**不算买错**：同程用 OTA 交易级数据验标的质量，付"账面合理价"拿走"信息不对称"红利。这是买方独家优势换来的折价，不是运气。
>
> **一句话**：**账面公允，战略必需，风险自担。期望值接近 0 到略正——这就是"感觉买贵了"的来源。**

## 2. 四层定价拆解

### 第一层：可比倍数 —— 技术上没错，分母选错

9.5x EV/EBITDA 用的是 **2023 年**（净利仅 2156.3 万港元的异常低点）的**经调整** EBITDA。

换 2024 实际盈利：
```
营收 8.9 亿港元 ≈ 8.2 亿人民币  →  P/S = 24.97 / 8.2  =  3.05x
净利 1.48 亿港元 ≈ 1.36 亿人民币 →  P/E = 24.97 / 1.36 = 18.4x
净利率 16.6%（轻资产特许经营，合理且不低）
```

**亚朵拿 19.8x 是市场给"高增长 + 高确定性"的溢价。万达酒管拿同样量级的价格，却卖锦江级别的增长与确定性。**

### 第二层：历史锚点 —— 7.5 亿 vs 24.97 亿

| | 2017-08 | 2025-04 | 倍数 |
|---|---|---|---|
| 万达酒管 100% 股权 | 7.5 亿 | 24.97 亿 | **3.33x / 8 年** |
| 标的净利 | （低基数）| 2156万 → 1.48亿 | 6.9x |

**如果 2023 净利 2156 万是"真实现状"，7.5 亿是白菜价；如果 1.48 亿是"正常化盈利"，那 24.97 亿已经在为 2024 年的改善付全价。**
卖方 2024 年计提大额减值、2025 年因"减值不再出现 + 卖资产"而扭亏 —— **说明万达自己也认为 1.48 亿是减值后口径，而 7.5 亿是减值前口径。这两件事不能同时为真。**

### 第三层：现金流折现 —— 真实价格

买 1.36 亿人民币净利，花 24.97 亿。设回报率 10%：

| 永续增长假设 | 合理价值 | 对 24.97 亿 |
|---|---|---|
| 0% | 13.6 亿 | **贵 83%** |
| 3% | 20.0 亿 | **贵 25%** |
| 5% | 28.6 亿 | 便宜 13% |

→ **买回 24.97 亿，标的净利必须以 5% 复合、永续、10% 回报率。**
→ 而行业正在从增量建设转向存量效率，2026H1 出租率还在 **−1.2pp**，四大集团 pipeline 在减。
→ **在 pipeline 收缩的池子里抢 5% 永续增长，价格战概率不低。**

### 第四层：管道期权折损 —— 最被忽略的一层

同程 24.97 亿里有一部分买的是「万达系物业优先给万达酒管管」这个隐含预期。

**但：**
1. 万达正在**持续卖物业**（2017 卖 77 家，2025 卖 26 座广场）
2. 万达系物业**必然重新比价**（同程 vs 华住/锦江/首旅）
3. 物业易主后，管理合约要重新谈

→ **管道不是资产，是行权价逐年抬高的看涨期权。**
→ 而且卖方正在亲手拆掉这份期权的标的物。

### 定价结论表

| 视角 | 判断 |
|---|---|
| 可比 EV/EBITDA（2023 基数）| 公允（9.5x 落在中位）|
| 可比 PE（2024 实际）| **偏贵（18.4x）** |
| 现金流折现 | **偏贵（需 5% 永续增长）** |
| 历史锚点 | 相对 7.5 亿已充分定价，**资产自身在增值** |
| 管道期权 | **正在折损** |

## 3. 博弈论：为什么同程敢买

### 玩家与筹码

| 玩家 | 利益 | 筹码 |
|---|---|---|
| 万达酒店发展（卖）| 变现去杠杆 + 甩掉管理业务 | 需现金；已引入战投，**非急售** |
| 万达集团（母公司）| 减债 + 继续卖广场 | 2025 卖 26 座广场 |
| 同程（买）| 补高端拼图 + 物业管道 + 协同 | OTA 数据 + 会员 + 流量 |
| 万达系/第三方业主 | 酒店交给谁管 | **决定管道是否兑现** |
| 华住/锦江/首旅/亚朵 | 守份额 | 规模优势 |
| 洲际/万豪/凯悦 | 国际品牌 | 加速下探中端（佳阁换牌 80 万）|

### 三个关键判断

**① 卖方是不是被逼着卖？—— 不是。**
万达集团整体在减资产（卖广场、卖酒店），但 2025 万达商管重组引入 **600 亿战投**（中东主权基金）→ 流动性在改善。交易从 4/17 拖到 10/16（延至 10/31）并设"先决条件" → **卖方没有急于成交的姿态。这更像一次精心设计的资产腾挪，议价空间有限。**

**② 同程的独家信息优势 —— 这才是这单真正的便宜来源。**
同程是 OTA，**能拿到每一家万达酒管酒店的真实预订量、间夜、房价、评分**（只要这些店在同程卖房）。
万达自己披露的"204 家高端店"的真实成色，**同程能用交易级数据反查**。
→ **同程不是买了一个品牌，是买了一份"确定性"。它付账面合理价，拿走了信息不对称红利。**
→ 这也解释了为什么无业绩承诺仍然敢买：**它不依赖卖方背书，它自己有数据。**

**③ 没有业绩承诺 = 卖方不背书。**
- 解读 A：万达自己不认为未来能增长，所以不签
- 解读 B：买方不需要（自己有数据）
- → 对买方都是「**短期无减值压力、长期无保护**」：2026 一旦不及预期，减值直接砸在同程报表上

**④ 同程的战略焦虑（为什么非买不可）。**
住宿业务已占 OTA 收入 33%（54.5/164.7），是第二曲线；但原有品牌（艺龙/美程/珀林/花间堂）**全在中低端，缺高端 = 缺房价天花板**。2026 中报主题直接写"靠酒管构建第二曲线"。
→ 它买的不是收益，是**品牌结构的天花板**。这是**战略必要性溢价**——最容易解释，也最容易失控。

## 4. 群论：什么变了，什么没变

**不变量**：酒店管理公司的价值 = 品牌势能 × 业主议价力 × 系统效率 × 会员转化 × **门店密度**。
**这笔交易一项都没改变，只是换了个股东。**

**对称性破缺（万达酒管 vs 华住）**：
- 华住 1.2 万店 → 采购议价力、系统成本摊销、会员规模效应
- 万达酒管 204 家纯特许 → 这五项里**只有"品牌势能"和"会员转化"（同程补的）能打**
- → **规模上永远追不上；"九大品牌矩阵"看着是资产，实际是战略资源的分散化**

**可分解性（最大的信息风险）**：
204 家店可以拆成「**真高端**（撑得住 800+ ADR / 高消费场景）」和「**挂名高端**（实为中端）」。
同程的 OTA 数据能拆，**但它买的是整包**。
→ **如果 204 家里有相当比例是后者，9.5x 是按"高端管理平台"给的价，实际经营是"中端物业"。这是 18x PE 的核心风险来源。**

**轨道**：
`OTA 流量 → 高端品牌 → 万达物业管道`。这条轨道能否走通，只看两个数：**门店净增** 和 **RevPAR**。

- 2025-10 才交割 → 2025 全年只并表 Q4 约 2.5 个月 → **2026 中报是首个完整并表半年，2027-03 年报才是完整验证年**
- 2026 中报已出：半年营收增至百亿，主题即「靠酒管与入境游构建第二曲线」

### 5.2 必须盯的 6 个指标

| # | 指标 | 基准 | 红线 |
|---|---|---|---|
| 1 | 在营门店数 | 222（2025-06）| 2026 年底 < 250 = pipeline 未兑现 |
| 2 | 签约待开业 | 406（2025-06）| 掉头 = 最坏信号 |

### 5.3 三情景

| 情景 | 概率 | 路径 |
|---|---|---|
| **上行** | 30% | 会员导流 + 万达系物业续约 + **滑雪/度假的非客房收入**（餐饮/会议/温泉）打开第二曲线。高端客人的**场景消费**才是 204 家店真正的价值锚——**不是 RevPAR，是非房费收入**，而这恰恰是同程自己造不出来的 |

## 6. 给 Eric 的可操作输出

### 6.1 四层酒店资产定价框架（可复用于任何并购/腾挪）

1. **可比倍数层** —— EV/EBITDA，**分母必须用"正常化盈利年"，不是最低点年**（万达案的核心陷阱）
2. **历史锚点层** —— 同一标的历史成交价 × 年化 vs 同期盈利增长 → 分辨"资产真涨"还是"估值抬升"
3. **现金流折现层** —— 买价隐含多少永续增长 → 与行业阶段（增量/存量）对照
4. **期权折损层** —— 把"隐含关联管道"当看涨期权，评估行权条件是否在恶化

### 6.2 安逸自查（4 个数）

1. **我们的 RevPAR 是涨是跌？** 行业基准 215.5 元（+4.6%），但**出租率 −1.2pp**，增长全靠 ADR
2. **我们的门店是真高端还是混合？** 混合结构拿不到品牌溢价
3. **我们的 pipeline 在增还是在减？** 四大集团都在减
4. **我们的会员复购率在哪一档？** 连锁 35% vs 单体 15%

### 6.3 竞争与机会

- **竞争**：同程拿下万达品牌 + OTA 流量后，在**文旅目的地的区域市场会与安逸直接竞争**（万达系店在云南/长白山/三亚等密度高）。建议把"区域高端/度假市场的管理权归属"作为战略变量，别等管道被锁死才反应。
- **机会**：万达系物业持续出售 → 市场上会出现「**高端物业 + 无合适管理方**」的资产包。对安逸（区域国资平台 + 存量翻新判断框架）来说，这是「**轻改 + 换牌 + 区域品牌**」的机会窗口，而不是捡便宜物业。**洲际佳阁 80 万轻改 / 两个月开业**这个数字，对存量翻新的投资回报模型有直接参照价值。
