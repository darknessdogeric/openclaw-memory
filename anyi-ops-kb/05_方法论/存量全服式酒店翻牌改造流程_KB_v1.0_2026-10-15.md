## 1. 战略决策层 (M0-M3, 决策前 12-18 个月)

### 1.1 翻牌 7 大判断信号

| 信号 | 临界 | 紧迫度 | 翻牌方向 |
|------|------|------|---------|
| 国际品牌合同到期 (≤3 年) | 5 年内 | 🔴 高 | 立即决策 |
| 同商圈 5 家新国际品牌抢客 (2023 成都案例) | 已发生 | 🔴 高 | 差异化定位 |
| ADR 5 年跌 30%+ (皇冠 800→488) | 30% | 🟠 中 | 重新定位 |
| 携程评分 ≤4.8 (落后竞品 0.1+) | 0.1 差 | 🟠 中 | 体验提升 |
| OCC 长期 < 70% | 70% | 🟠 中 | 客源换血 |
| 硬件老旧 (15+ 年未翻新) | 15 年 | 🔴 高 | 强制翻新 |
| 集团资产负债率 > 75% | 75% | 🟡 需评估 | 出售 vs 翻牌 |

### 1.2 翻牌的 3 种模式 (非互斥)

| 模式 | 投入 | 工期 | 翻牌期不停业 | 适配物业 | 代表案例 |
|------|------|------|--------------|----------|----------|
| **轻改造快翻牌** | 10万级 | **20 天不停业** | ✅ 是 | 合约即将到期 + 硬件达标 + 快速切换 | 关键 20 天 |
| **经营整改型** | 小额硬件 + 重经营 | 1-3 月 | 边经营 | 区位 OK + 经营粗放 + 闲置资产 | 上海百万石 (RevPAR+21.9%) |

### 1.5 翻牌 4 步决策树

```
第 1 步: 合同到期窗口
  ├─ 3 年内到期 (如总府皇冠 2029-9-27) → 立即决策
  └─ >3 年到期 → 暂缓, 监控信号

第 2 步: 战略契合度
  ├─ 集团 15五要求"擦亮招牌" → 保留国际 5 星 (选项 A/B)
  └─ 集团 15五要求"退出处置" → 出售或换自有 (选项 D/锦宾国际)

第 3 步: 资金可行性
  ├─ 1.5-2 亿可筹 (翻牌) → 选 LXR/Conrad
  ├─ 1 亿可筹 → 选 Park Hyatt/索菲特
  ├─ 0.5-1 亿可筹 → 选 W 酒店
  └─ 0 元 → 出售

第 4 步: 法律风险评估
  ├─ IHG 5 年未终止 = 集团谈判主动权
  ├─ 翻牌成本 1,500-2,500 万 (估) < 10 年抽佣 6,000-8,000 万
  └─ CIETAC 仲裁 1-2 年风险 vs 庭外和解 0.5-1 年
```

## 2. 法律与合同层 (M2-M8, 谈判 + 解约 3-6 个月)

### 2.1 现行管理合同审查清单

| 必查 | 关键问题 | 工具 |
|------|---------|------|
| 合同总期限 + 续约条款 | 到期日? 续约机制? 自动续约? 6 个月前决策? | OCR PDF + 法务 |
| **翻牌 / 提前终止条款** | 是否允许? 违约金? 通知期? 60 天 vs 90 天? | 关键 |
| 抽佣结构 | License Fee % + IMF 阶梯 + System Fund + Tech Fee | 算 10 年总成本 |
| **PIP (Property Improvement Plan) 条款** | 翻新义务时间表? 已逾期 5 年是否有违约责任? 80 万 IHG Technical Service Fee | 关键 |
| 转让条款 (Assignment) | 品牌方可否转让给关联公司? (如总府实业的 HICL→IHG Shanghai) | 关键 |
| 争议解决 (Dispute Resolution) | CIETAC 仲裁? 地点? 法律适用? | 关键 |
| 自动终止条款 | 不续约 = 自动终止? 无违约责任? | 关键 |
| 客史数据归属 | 客史 PII 归谁? 续约时归业主? 终止时怎么办? | 关键 |
| 商标使用 | "Crowne Plaza" 商标 IP 归属? 终止后能否用? | 关键 |
| 团队留任 | 高管 (GM) 留任义务? 员工转让? | 关键 |
| 装修期条款 | 装修期管理费是否减? (停业期 AGR=0 → License Fee=0) | 关键 |
| 续约谈判窗口 | 到期前 6 个月必须开始谈 | 倒推时间表 |

### 2.6 客史数据迁移条款

| 项 | 业主权利 | 品牌方义务 |
|---|---------|----------|
| **数据所有权** | 业主 100% 拥有 | 仅使用, 不可导出 |
| 物理存放 | 业主服务器 | 仅 API 接口访问 |
| 品牌会员 | 不强制并入新品牌 | 老客可自主选择 |
| 数据迁移 | 业主可保留 | 新品牌不强制老客 |
| PII 保护 | 个保法 + 数据安全法 | 品牌方违约责任 |

### 2.7 团队劳动关系转移

| 层级 | 处理 | 补偿 |
|------|------|------|
| **GM (总经理)** | **100% 留任** (新品牌继续任) | 加薪 5-10% |
| 部门经理 | 80% 留任 (核心运营) | 加薪 3-5% |
| 普通员工 | 95%+ 留任 (服务连续性) | 法定补偿 N+1 |
| 培训师 | 100% 留任 | 新品牌认证培训 |

**关键**: GM 是翻牌成败核心。上海静安希尔顿→昆仑案例, **GM 95% 留任是 30 年来最成功的翻牌之一** (换牌后 101 天 100% 满房)。

| **E. 集团内拆借** | 内部利率 | 1-3 年 | 短期 | 集团内转账风险 |

**总府皇冠推荐**: **A (银行 4,000 万) + B (国资委专项 2,000 万) + 自有 1,000 万 = 7,000 万** = 改造 1.5 亿的 47%, 剩余 8,000 万由翻牌分手费 + 营收现金流。

### 3.5 10 年总拥有成本 (TCO) 模型


|------|------|--------|----------|------------|----------------|
| A 续 IHG | 1.8 亿 | 0 | 7,400 万 | 7.4 亿 → IRR 17% | 0 (基准) |

| D 出售 | 0 | 0 | 0 | 7,000 万 (一次性) | -2.4 亿 |
