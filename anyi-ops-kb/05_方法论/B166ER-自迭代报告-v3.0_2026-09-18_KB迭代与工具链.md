### 2.2 工具 2: `toolbox/kb_tools/kb_semantic_search.py`

**技术**:sentence-transformers + all-MiniLM-L6-v2(已下载 90MB 模型)

**索引参数**:
- 总文档块:**14,740**(约 580 个文件,每文件 500 字块)
- 索引文件:16 MB (documents.pkl) + 21 MB (embeddings.npz)
- 索引耗时:7 分钟
- 模型维度:384

**用法**:
```bash
# 索引(已建)
python kb_semantic_search.py index

# 检索
python kb_semantic_search.py search "你的问题"

# 统计
python kb_semantic_search.py stats
```

## 3. 4 项 KB 改进

### 3.1 跨 KB 引用机制
- 任何报告涉及安逸,必须用相对路径引用 `anyi-ops-kb/...`
- 反之,任何项目报告引用行业知识,必须用 `universal-kb/02_酒店行业/...`

### 3.2 统一版本号规范
- 文件名后缀 `_vX.Y_YYYY-MM-DD.md`
- 旧版 → `_归档_/` 子目录
- MOC 标注"当前权威版"
