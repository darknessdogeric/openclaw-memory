### 1-5 分评分标准 (通用)

| 分 | 含义 | 决策影响 |
|---|------|---------|
| **5** | 显著优势, 强烈推荐 | 改变方向 |
| **4** | 优势明显, 值得推进 | 加分 |
| **3** | 中性, 无影响 | 不改变 |
| **2** | 劣势, 需要补偿 | 减分 |
| **1** | 显著劣势, 不推荐 | 一票否决 |

### 总分公式

```
总分 = Σ(各维度分数 × 维度权重) × 20 = 0-100 分
例: 维度 A 4 分 × 0.20 + 维度 B 3 分 × 0.08 + ... = X / 100
```

**决策门槛**:
- **75+ 分** = 推荐
- **60-74 分** = 可行
- **45-59 分** = 需补偿
- **<45 分** = 不推荐

## 📋 公式库 (10+ 关键公式)

### F1: 10 年 TCO

```
TCO = 投资 + 分手费 + Σ(10 年抽佣) + 停业期损失 + 安置成本
TCO = 投资 + 分手费 + 10 × 年均营收 × 抽佣率 + 18-24 月 × 月停损 + 员工 × 安置系数
```

### F2: 10 年累计抽佣

```
抽佣 = 10 × [(License 2-3%) + (IMF 4-8% × GOP率) + (System 1-2%) + (Tech 0.5-1%)] × 年营收
例: 7,400 万 × 8% × 10 年 = 5,920 万
```

### F3: 月停业损失

```
月停损 = 房间数 × ADR × OCC × (1 + 配套 30-45%) × 30
例: 402 × 488 × 0.72 × 1.35 × 30 = ¥5.7M / 月
```

### F4: 静态回收期 (Payback Period)

```
回收期 = 初始投资 / 年均增量现金流
例: 1.5 亿 / (8,000 万 - 7,400 万) = 25 年 → 太长, 不推荐
```

### F5: 动态回收期 (Discounted Payback)

```
累加 Σ(年增量现金流 / (1+r)^t) ≥ 初始投资
r = 折现率 (WACC, 通常 8-10%)
```

### F6: NPV (净现值)

```
NPV = -初始投资 + Σ[(年现金流) / (1+r)^t], t=1..10
若 NPV > 0: 投资可行
若 NPV < 0: 投资不可行
```

### F7: IRR (内部收益率)

```
NPV = 0 时的折现率 r
通常: IRR > WACC 8-10% → 投资可行
5 星国际品牌翻牌: 实际 IRR 7-17% (按 1.5-2 亿投资测算)
```

**适用**:

**适用**:
- 集团战略要求"自有旗舰"

- 接受 3-5 年培育期
- 集团资金可筹 1-1.5 亿

**适用**:
- 集团战略明确"退出处置"
- 评估价 ≥ 7,000 万
- 收购方有 (锦江/华住/万豪)
- 不需要品牌沉淀

**操作模板**:
1. 国资评估 (7,000 万-1 亿)

5. 完成转让 + 集团回笼资金

**适用**:
- 集团想保留产权 + 借品牌运营
- 资产重, 但运营差
- 资金紧, 不愿大投资

5. 3-5 年后视情况续约或回购

### 场景 6: 混合模式 (场景 F)

**适用**:
- 主品牌 + 软品牌 (双品牌策略)

5. 双会员体系切换

**适用**:
