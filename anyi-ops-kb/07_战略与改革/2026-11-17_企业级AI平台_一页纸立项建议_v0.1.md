## 一、为什么现在做

集团降本空间已近极限（2026 年 1–8 月人工成本同比压降 7.86%、财务费用压降 2,565 万元），收益端成为唯一突破口。AI 是收益端唯一可规模化的杠杆：行业数据显示采用 AI 收益管理后 RevPAR 平均提升 10%–15%，而行业 AI 投入绝大多数用于省钱、收入侧几乎无人做透。集团已具备四块资产底子——AI-RMS 立项（2026-11-05）、数字化中台二期（2026-11-12）、酒店智能网关（2026-11-16）、AHL 垂系 Agent 平台 BP（2026-08-14）。**缺的不是项目，是一张总图。**

## 三、方案要点（三句话）

1. **一个底座、四层架构**：算力层 → 模型层（商用 API 轨 + 私有模型轨 + 路由器）→ Agent 运行时层 → 应用层；横向贯穿身份权限、数据分级、成本计量、审计留存。
2. **算力用云租，不自建**：训练与批处理一律按量云租（4090 约 ¥1.0–2.5/小时，单次微调 ¥5–125）；内网只保留 1 张推理起步卡。**TCO 算式显示：集团当前规模下自建机房年成本 ¥2–3 万 vs 云租包月 ¥0.84 万，自建不划算。**
3. **微调不是起点**：内部办公的能力瓶颈是知识检索与系统对接（RAG + 工作流），不是模型智力；微调只用于领域算法、蒸馏降本、窄任务、格式适配四处。

## 四、90 天与三年

- **90 天**：底座最小可用（网关+路由+计量+权限+审计）→ 三个首发场景（制度知识问答、会议纪要待办、材料起草）→ 敏感场景切本地轨 + 首个蒸馏/微调试点 → 算力决策 + 对外产品包打样。
- **2027**：AI 中台基座 + AI-RMS 旗舰应用 + 对外收益能力包开始交付（轻资产服务费按受托项目营业收入 1.5%–2%，已写入 11-05 请示）。
- **2028+**：智能网关 + AI 运维一体包；AHL 平台化。

## 六、请示事项（建议表述）

1. 同意以本方案作为集团 AI 与数据中台的**总体架构与并轨规则**，明确 AI-RMS／数字化中台二期／智能网关／酒店行业 AI 平台四项立项均在本架构下复用同一底座，不重复列支。
2. 同意 2027 年在"AI 与数据中台"模块内调剂并申请专项合计 ¥17–41 万元（不含人力），其中算力与 API 按月计量、按量列支、严禁年包干。
3. 同意算力采用**云端租赁为主**、内网保留最小推理节点的技术路线，并授权按利用率 60% 触发式评估自建。
4. 明确 AI 能力对外收费主体与内部结算价机制（内部使用同样计价、对外交付优先），以保障对外产能。
5. 明确平台产品岗与算力运维岗的人员来源。
