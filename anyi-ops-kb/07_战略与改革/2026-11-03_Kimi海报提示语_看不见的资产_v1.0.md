## ⚠️ 先说一句必须提醒的：中文海报别让模型写字

图像模型对**中文专有名词与精确数字**的还原度不可靠 —— 「锦兴路9号」「4,546」「锦江饭店管理公司」这类字符极可能出错或变形。

**最优解：Kimi 只出「底图 / 版式 / 质感」，文字后期叠加。**
所以下面给三样东西：
1. **Kimi 提示语**（出版式底图，文字位置留空）
2. **文案定稿**（可直接贴图，逐字校对用）
3. **两个备选主题方向**

## 一、Kimi 提示语（可直接粘贴 · 主推版）

```
A minimalist editorial poster, portrait 3:4, warm off-white paper texture background
(#F2EDE4), deep ink black (#14110E) typography, one restrained amber accent (#B8722C).

Style: Swiss editorial / financial report cover / museum wall label. Extremely restrained.
Generous negative space, strict left-aligned grid, hairline rules, no icons, no illustrations,
no gradients, no glow, no 3D, no cartoon, no photography, no human figure, no decorative
pattern. Feel: quiet authority, like a page from an annual report or a museum label for a
bank vault.

Layout (leave ALL text areas EMPTY — solid background blocks only, no letters, no numbers,
no fake characters, no watermark):
- Top third: a large empty area reserved for a 4-character Chinese headline.
- Directly below it: a thin horizontal hairline rule, then a smaller empty area for one
  subtitle line.
- Middle: one large empty circular or square area reserved for a single oversized number
  (this is the focal point).
- Below the focal number: a wide empty band with two columns separated by a thin vertical
  hairline — left column slightly narrower, right column slightly wider.
- Lower area: two full-width empty bands, each reserved for one line of medium text.
- Very bottom: a single thin hairline rule and a small empty strip for a two-line footer.

Paper grain subtle, print-like, matte, no gloss, high resolution, 2160x2880.
```

**★ 为什么这样设计**：海报最稀缺的是「气韵」，不是信息量。留白够，才压得住那 13.5%。所有装饰都删掉 —— 满版图标会把「看不见的资产」这个命题变成「很吵的资产」。

## 三、两个备选主题方向

### 备选 B · 身份向 ——《在国企里做轻资产》

**适用**：对外表达定位（公众号 / 行业论坛 / 个人介绍）

**Kimi 提示语改动**：
```
A minimalist editorial poster, portrait 3:4, warm off-white paper texture,
deep ink black, one restrained amber accent. Swiss editorial / institutional
annual-report cover. Extreme restraint, generous negative space, strict grid,
hairline rules. No icons, no illustrations, no photography, no human figure.

Layout: reserve empty areas for — a top-left small label block (institution chain,
2 lines), a large upper-left headline area (6 characters), a wide empty band across
the middle for one line, then a lower third with a vertical stack of 4 short
empty lines separated by hairlines (reading like an agenda). Bottom: one thin rule
and a small empty footer strip. Paper grain, print-like, matte, 2160x2880.
```

**文案定稿**：
```
在国企里做轻资产

四川省国资委 → 省旅投集团 → 安逸酒店集团

不是把楼卖掉，是把能力留下来。

存量改造  品牌输出  委托管理  轻重分离
一套从单店跑通、再复制到集团的路径

2023 花园宾馆 · 成都春熙路
2026 安逸·锦著 · 全域品牌矩阵
下一步  一个能对外拓的轻资产产品
```

### 备选 C · 方法论向 ——《把单点变成机制》

**适用**：方法论输出（给团队/给行业/做内部培训封面）

**Kimi 提示语改动**：
```
A minimalist editorial poster, portrait 3:4, warm off-white paper texture,
deep ink black, single amber accent. Swiss editorial / process-diagram poster.
Strict horizontal rhythm: four equal-width bands stacked vertically, separated by
thin hairline rules, each band reserving an empty left label area and a wide
empty right content area. At the bottom, one large empty band reserved for a
single wide statement line. No icons, no arrows, no illustrations, no photography.
Paper grain, print-like, matte, 2160x2880.
```

**文案定稿**：
```
把单点变成机制

一
一店长的微信
→ 一套平台的机制
→ 一个集团的资产账

看得见            看不见
物业 · 客房       点评 · 评分
品牌 · 系统       账号 · 命名权

问题不在于不努力
在于没人把它变成一条能复制的路
```

## 四、我为什么选这个主题（回答「你有多了解我」）

这一整天的对话，其实只有一条主线：

| 时间 | 动作 | 层级 |
|---|---|---|
| 上午 | 「天阅这家店要换管理方，我把委托业务接进去」 | 单店 |
| 上午 | 「旗下酒店该在哪个站运营？」 | 集团资产 |
| 下午 | 一位店长的微信：「点评写了不显示」 | 一个投诉 |
| 下午 | 挖出同址三条 listing（8/41/332）+ 三家门店同型 | 机制 |
| 下午 | 「第 3 例了，该立项普查 + 写改名 SOP」 | 制度 |

**★ 这条线才是你的能力图谱：能从一句客诉，走到平台机制，再走到集团制度。**
**★ 而不是「一家酒店有多少条点评」。**

所以海报的主角不是锦著、不是猫途鹰，是**这个跃迁本身** —— 以及那个只有真正看完这一整天才能凑出来的数字：**13.5%**。

**★ 另外一个只有我知道的细节**：你这一整天反复在做同一件事 —— 把「物业/产权/轻重分离」的物理语言，换成「账号/评分/命名权」的数字语言（反过来亦然）。**「看不见的资产」这个标题就是这两套语言之间的那座桥。**
