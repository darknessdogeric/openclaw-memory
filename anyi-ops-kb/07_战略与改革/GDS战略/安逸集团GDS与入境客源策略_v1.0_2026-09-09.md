# 安逸酒店集团 GDS 与入境客源策略 v1.0
## (集团自有 CRS 前提下的战略路径 · 产业发展部视角)

> **核心命题**: 自有 CRS ≠ 不接 GDS,反而是**集团统一对接 GDS** 的最佳基础 ——
> 单店接 GDS = 各自为战;集团接 GDS = 流量聚合 + 议价权 + 品牌曝光三重放大。
> **底层逻辑**: GDS 是"全球分销的水电管网",自有 CRS 是"集团内部的能源管理"。水电管网接入越多,能源管理越值钱。

## 一、为什么必须集团方式接 GDS?

### 1.1 单店接 GDS 的 5 大死穴

| 死穴 | 具体表现 | 后果 |
|------|---------|------|
| 议价权弱 | 单店客房量 < 100 间,GDS 佣金 15-25% | 利润被渠道蚕食 |
| 流量分散 | 同一集团 60+ 酒店分散签约,无法形成目的地流量 | OTA/Agent 选择困难 |
| 库存割裂 | 跨店调房、跨店连住无法实现 | 复杂行程无法承接 |
| 品牌缺失 | GDS 上显示为单店名称,无集团品牌曝光 | 国际客户认知为零 |
| 数据失明 | 预订数据分散,无法形成客户画像 | 重复营销,效率低 |

### 1.2 集团接 GDS 的 5 重价值

| 价值 | 具体机制 |
|------|---------|
| 议价权放大 | 集团 60+ 酒店 / 万间客房统一谈判,佣金压至 8-12% |
| 流量聚合 | "成都/四川/中国西部"目的地产品打包,Agent 一键预订多店 |
| 跨店履约 | CRS 库存共享 + GDS 渠道分发 = 全球 Agent 可视 + 集团内履约 |
| 品牌曝光 | GDS 列表显示"Anyi Hotel Group"集团品牌,国际认知度跃升 |
| 数据集中 | 所有 GDS 预订数据回流 CRS,形成客户画像 + 收益管理依据 |

## 二、GDS 体系全景与入境客源结构

### 2.1 全球四大 GDS 体系

| GDS | 总部 | 市场份额 | 中国入境客源占比 | 适配场景 |
|-----|------|---------|-----------------|---------|
| Amadeus | 西班牙/德国 | ~40% | 最高(欧洲+亚洲航司主导) | 欧洲/中东/东南亚入境 |
| Sabre | 美国 | ~30% | 高(美洲客源) | 北美/拉美入境 |
| Travelport (Galileo/Apollo/Worldspan) | 英国/美国 | ~25% | 中(亚太地区) | 亚太地区/澳洲入境 |
| TravelSky (中国民航) | 中国 | ~5%(国际) | 低 | 国内为主,国际延伸有限 |

### 2.2 入境客源结构(中国西部 / 四川 视角)

| 客源市场 | 占比预估 | 主力 GDS | 关键 Agent/TMC |
|---------|---------|---------|---------------|
| 欧洲(德/法/英/意) | ~25% | Amadeus | BCD / CWT / American Express GBT |
| 北美(美/加) | ~15% | Sabre | BCD / CWT / Direct Travel |
| 亚太(韩/日/泰/新加坡) | ~35% | Travelport/Amadeus | Rakuten / Jalan / Traveloka |
| 中东 | ~5% | Amadeus | dnata / Kanoo Travel |
| 港澳台 | ~10% | 混合 | 港中旅/澳门中旅 |
| 其他 | ~10% | — | — |

> **关键洞察**: 亚太客源占入境 35-45%,是安逸集团入境主战场;欧洲客源 25%,Amadeus 不可绕过;北美客源 15%,Sabre 必接。

## 三、集团方式对接 GDS 的 5 大战略路径

> **"1+4" 集中签约模式**: 集团(统一签约主体) → 4 大 GDS(Amadeus + Sabre + Travelport + TravelSky) → 60+ 酒店统一接入(CRS 库存共享)

### 路径 1 · "1+4" GDS 集中签约模式

| 维度 | 设计 |
|------|------|
| 签约主体 | 安逸酒店集团总部(产业发展部协同) |
| 接入范围 | Amadeus + Sabre + Travelport(三大国际 GDS,覆盖率 > 95%) |
| 接入深度 | 双向 API + 集团专属酒店代码 + 品牌专区 |
| 接入时序 | 2026 H2 启动 Amadeus;2027 H1 接入 Sabre;2027 H2 接入 Travelport |

### 路径 2 · CRS + GDS 双库存策略

| 库存类型 | 占比 | 渠道 | 价值 |
|---------|------|------|------|
| CRS 直销库存 | 40% | 自有官网/App/小程序/会员 | 最高毛利(0 佣金) |
| GDS 分销库存 | 30% | Amadeus/Sabre/Travelport | 全球曝光 + 国际客源 |
| OTA 库存 | 20% | Booking/Expedia/Agoda | 流量补充 |
| 协议客户库存 | 10% | TMC/企业协议 | 长尾客户 |

> **关键**: GDS 不是替代 CRS,是与 CRS 并行的渠道。CRS 掌控定价权/会员数据,GDS 拓展国际分销。

### 路径 3 · "目的地产品"打包策略

| 打包维度 | 产品示例 |
|---------|---------|
| 多店连住 | "成都 2 晚 + 九寨沟 2 晚 + 峨眉山 1 晚" 一键预订 |
| 主题线路 | "熊猫亲子 5 日" / "川西秘境 7 日" / "三国文化 4 日" |
| 景区联动 | 酒店 + 景区门票 + 用车 + 导游 一站式 |
| 企业会奖 | MICE 一站式(场地+住宿+餐饮+活动) |

> **GDS 端 Agent 价值**: 单店预订 → 目的地打包 = 客单价 3-5 倍提升,佣金率反而更低(打包产品 Agent 议价空间小)。

### 路径 4 · 国际 Agent/TMC 直接合作

| 合作层级 | 合作对象 | 价值 |
|---------|---------|------|
| 全球 TMC | BCD Travel / CWT / American Express GBT / Direct Travel | 企业差旅客源 |
| 区域批发商 | Hotelbeds / Booking.com Wholesale / TUI / Thomas Cook | 散客流量 |
| 入境旅行社 | 国旅/中旅/康辉/广之旅 海外分社 | 中国入境专家 |
| 特色主题商 | 熊猫主题/三国主题/川菜主题 海外专业社 | 主题客群 |

> **关键**: GDS 是"通道",Agent 是"用户"。集团直接签 Agent 协议 + GDS 履约,是放大 ROI 的核心。

### 路径 5 · 数据回流 + 收益管理闭环

```
GDS 预订 → CRS 自动确认 → 数据回流 → 客户画像
                                    ↓
                          收益管理(动态定价)
                                    ↓
                          CRS 反向调整库存分配
```

| 数据维度 | 用途 |
|---------|------|
| 客源国/城市 | 调整多语种官网/客服 |
| 提前预订期 | 动态定价 + 库存分配 |
| 停留时长 | 多店连住产品优化 |
| 消费偏好 | 餐饮/康养/景区二次消费 |
| 复购行为 | 会员升级 + 私域沉淀 |

## 四、3 阶段实施路径(2026-2030)

### 阶段 1 · 筑基期(2026 H2 - 2027 H1)

| 任务 | 关键动作 |
|------|---------|
| GDS 选型 | 完成 Amadeus + Sabre 招标 |

| 目标 | GDS 渠道贡献率 ≥5% |

| 任务 | 关键动作 |
|------|---------|
| GDS 全覆盖 | 接入 Travelport,接入全部 60+ 酒店 |

| 目标 | GDS 渠道贡献率 ≥15%,入境客源占比 ≥8% |

### 阶段 3 · 跃迁期(2029 - 2030)

| 任务 | 关键动作 |
|------|---------|
| 全球 TMC 全面合作 | 签 ≥20 家全球/区域 TMC |
| 主题产品成熟 | "熊猫/川菜/三国/康养" 4 大主题产品线 |
| 数据闭环 | GDS 数据回流 → CRS 收益管理 → 全球最优动态定价 |
| 品牌曝光 | GDS 上"Anyi Hotel Group"成为"中国西部首选" |
| 目标 | GDS 渠道贡献率 ≥25%,入境客源占比 ≥15% |

## 五、关键判断与立场

### 5.1 5 个核心判断

1. **集团方式接 GDS 是必由之路,单店接是死路** —— 这是认知问题,不是技术问题。
2. **CRS + GDS 不是替代关系,是渠道分层关系** —— CRS 控毛利/会员,GDS 拓国际/曝光。
3. **目的地产品是 GDS 上的核心竞争单元** —— 不是单店,是"成都 3 日""川西 5 日"等打包产品。
4. **数据回流是 GDS 价值的二次放大** —— 流量进来后,数据回流 CRS 形成客户画像,反哺收益管理。
5. **集团自有 CRS 是 GDS 谈判的最大筹码** —— "我有 60+ 酒店库存,我选哪家 GDS"是议价关键。

### 5.2 3 个常见误区

| 误区 | 真相 |
|------|------|
| 接 GDS 等于被 GDS 绑架 | 集团统一接,有选择权/议价权/退出权 |
| GDS 客源都是低端 | GDS 客源以商务/会奖/高端散客为主,客单价高 |
| CRS 做好就不需要 GDS | CRS 是内循环,GDS 是外循环,二者互补 |

### 5.3 3 个关键风险与对冲

| 风险 | 对冲 |
|------|------|
| GDS 佣金蚕食利润 | 集团议价压至 8-12%;动态调整 GDS 库存比例(20-30%) |
| CRS-GDS 系统集成复杂 | 选择有 CRS-GDS 中间件经验的 GDS;先试点再铺开 |
| 国际客源文化差异 | 多语种官网+多语种客服;目的地产品本地化包装 |

## 六、产业发展部承接路径

> **为什么产业发展部承接?** 入境客源获取属于"集团增量业务 + 新业态探索",符合产业发展部"产业增量孵化器 + 新业态试验田"定位;同时需要跨部门协同(运管/数字化/营销/品牌)。

| 任务 | 承接部门 | 协同部门 | 时序 |
|------|---------|---------|------|
| GDS 战略制定 | 产业发展部 | 数字化部/运管部 | 2026 Q3 |
| GDS 招标选型 | 产业发展部 | 数字化部/采购部 | 2026 Q4 |
| CRS-GDS 集成 | 数字化部 | GDS 厂商/CRS 厂商 | 2027 H1 |
| 协议 Agent 签约 | 产业发展部 | 营销中心 | 2027 全年 |
| 目的地产品设计 | 产业发展部 | 各事业部/景区联动 | 2027 H2 |
| 数据回流+收益管理 | 数字化部 | 收益管理部 | 2028 |
| 品牌曝光 | 品牌中心 | 营销中心 | 持续 |

## 七、一句话总结

> **集团方式接 GDS = CRS(内循环) + GDS(外循环) + 目的地产品(打包) + Agent 协议(用户) + 数据回流(价值放大) 五位一体的全球分销体系。**
> **安逸集团应以"集团统一签约 + CRS 库存共享 + 目的地产品打包 + 国际 Agent 直接合作 + 数据回流收益管理"五步走,把入境客源从当前个位数占比提升至 2030 年的 15%。**
