## 0. 一句话判断

**这单的战略价值不在管理费，在"第一家非关联样板"。** 单店测算下来管理费收入约 96–114 万，人力派驻成本 107–150 万 —— **基本不赚钱**。但它是锦江饭店管理公司第一次把委托管理业务接到**民营存量单体**上，而不是集团内部或国资平台。

**建议：内部立项定性为「标杆样板 + 产品验证 + 团队练兵」，不按利润中心考核。** 若按利润中心算，这单不成立。

## 1. 交易结构判断：这是民营盘，不是花园

| | **花园宾馆项目（已跑通）** | **天阅（本次标的）** |
|---|---|---|
| 业主性质 | 国资（旅投下属） | **民营**（四川興眾投资 / 麦田旅业集团）|
| 交易逻辑 | 轻重分离，业主定"经营方缴费"机制 | 市场化委托管理 |
| 定价机制 | **显性化**：不低于市场真实租赁价 80%（200万 → ≥160万/年）| 可用**阶梯 + 绩效**，不必显性化固定租金 |
| 品牌 | 新创「安逸花园酒店」，全新在地文化主题 | 现有「麦田天阅 / Skytel」，**已有 10 年资产** |
| 增值逻辑 | 在地文化社交空间（合规政企活动）| **过境 + 政企会议**（南站 = 铁路枢纽 + 高新区）|
| 目标客群 | 仅面向国有平台公司 | **民营存量单体**（新客群）|

**★ 关键差异**：花园是"品牌从零起、机制从零建"；天阅是"**换脑不换壳**"—— 存量 OTA 资产、存量客群、存量会员、存量设施全部在，接管方要接的是**运营能力**。
**★ 但也有一个反向差异**：花园是国资，业主会主动要求你兜底机制；天阅是民营，业主更可能**只买管理服务、不愿为品牌溢价买单**。所以费率结构必须做减法。

#### 约束一：OTA 评分资产（10 年复利）的归属与保护 —— 最易被忽略、损失最大

- **9.2 分 / 317 条（Booking）+ 4.8 分 / 970 条（携程）+ 192 张图 + 19 篇达人探店内容** —— 这是天阅最值钱的资产，也是最容易在换牌中归零的资产。

- **★ 且已发现平台侧资产分裂**：同一家在 Booking 上挂着**两条 listing** ——
  - 「麦田天阅酒店(近火车南站）」在**特色酒店**区，起价 **S$66.87**
  - 「Skytel Hotel Chengdu-City Center」在**经济型/低价酒店**区，起价 **S$78.61**
  - 两者评分点评数完全一致（9.2 / 317 条），但**价格基准不一致、分类错位**（四星店被归入经济型）。
  - → **签约前必须先做 OTA 资产清理与归一**，这是给业主的第一个"见面礼"，也是签约前的技术前提。
- **合同必须写**：① 品牌切换后 OTA 主体不变、评分延续；② 若因平台政策重置，管理方减免当期管理费作为对价；③ 会员/客史/协议客户数据交割清单作为合同附件。

#### 约束二：锦著/锦宾国际在成都的认知度为 0，而对手评分普遍更高

同价带：漫心 10.0、桔子水晶 9.7、亚朵 9.7、亚朵轻居 9.5 —— **全部高于天阅 9.2**。
→ **第一年不可能靠品牌，只能靠管理与营销。**
→ 品牌费必须**与效果挂钩**（建议：按评分/出租率达标分两年释放），不能一次性收足。

#### 约束三：位置是真实弱项，而它是管理方改不动的

- 携程口径：**铁路南站步行 1.2–1.3km / 20 分钟**（Booking 写 500m 是到站房，不是到店）。

### ★ TripAdvisor 两站实测（本轮核心发现）

**两个站是同一份数据，不���两套点评池** —— 同一 property ID 贯穿两域：

| | URL | 读数 |
|---|---|---|
| `.com`（国际）| `tripadvisor.com/Hotel_Feature-**g297463-d7007456**-zft1-Skytel_Hotel_Chengdu.html` | **4.1 / 5 泡泡**，16 条点评，**#92 Best Value（334 家成都带酒吧酒店中）** |
| `.cn`（中文）| `cn.tripadvisor.com/Hotel_Review-**g297463-d7007456**-Reviews-Skytel_Hotel_Chengdu-Chengdu_Sichuan.htm` | 同一 ID，16 条点评 / 10 张游照 / 4.1 分（中文站展示为「麦田天阅酒店(成都)」）|

→ **g297463 = Chengdu geo，d7007456 = property。两站共用同一 property 与同一点评库。**
→ **所以 TripAdvisor 的资产 = 16 条点评 / 4.1 分，两个站之间不存在"双库不一致"风险，但也意味着换牌时该资产是全平台最脆弱的一份。**

### ★ 为什么 4.1 分是天阅最被低估的风险

1. **TripAdvisor 是 Google 酒店信息卡（Knowledge Panel）三大来源之一**（与 Booking、Agoda 并列）→ **4.1 分会直接外溢到 Google 搜索结果**，而这是国际客源的默认决策入口。
2. **对照 Booking 9.2 / Trip.com 9.6 —— 差距 5 分档**。同一物业在不同平台评分悬殊，通常源于**平台用户结构**（TripAdvisor 国际自由行客更挑剔、更愿写长评），也暴露**国际内容运营几乎空白**。
3. **天阅的境外客源是真实存在的** —— Booking 317 条点评里可见马来西亚、法国、英国、澳大利亚、意大利、瑞典客人。**这些客人做决策时最常用的平台恰恰是天阅评价最少、分数最低的那个。**
4. **16 条点评 ≈ 没有内容资产可继承**。在委托管理合同里，TripAdvisor 是**唯一"接过来也带不走什么"的平台** → 所以它反而是**管理方最该主动投入的渠道**（成本极低、增量明确）。

## 3. 三种交易结构（给选项）

| | **结构 A：单一委托管理合同**（品牌内含）★推荐 | 结构 B：品牌授权 + 委托管理 双合同 | 结构 C：纯管理输出（不动品牌）|
|---|---|---|---|
| 签约方 | 锦江饭店管理公司 | 安逸（品牌方）+ 锦江饭店管理公司 | 锦江饭店管理公司 |
| 总费率 | **3.5–4.5% 营收 + 奖励 ≤5% GOP** | 名义 7–8%，实操必须互抵 | 2–3% + 奖励 |
| 换牌 | 换（可谈保留 OTA 主体）| 换 | 不换 |
| 签约难度 | ★★ 低 | ★★★ 高（两份合同谈两份钱）| ★ 最低 |
| 品牌溢价分享 | 内部结算 | 清晰 | 无 |
| 合规风险 | 低（一份合同）| 中（两份合同期限/终止须互不冲突）| 低 |
| 何时用 | **默认** | 业主强势且看重集团背书 | 业主只要人、不想动品牌 |

**★ 推荐 A 的三条理由：**
1. **业主是民营，费率敏感** —— 一份合同讲清一个总价，比两份合同好谈；
2. **规避品牌授权模板第 14.7 条风险** —— 两份合同解约不同步时，品牌会被强制"摘除"，而委托管理合同还在执行 → 经营与品牌撕裂；
3. **锦江饭店管理公司本就是"管理公司"**，其价值主张是"管理 + 品牌"，一份《委托管理合同》内含品牌使用更匹配其身份。

**《品牌授权合同模板》使用说明第 3 条已明确**：「如同时委托甲方或其指定方经营管理，应另签《委托管理合同》，两份合同的期限、费用、终止条件须互相衔接、避免冲突」—— 结构 A 正是这句话的最简解法。

### 4.4 ★ 结论（必须直说）

> **单店委托管理在 172 间的四星中端店上，管理方基本不赚钱，甚至微亏。**

**所以这单的战略价值必须换四个口径来记：**
1. **产品验证** —— 首次验证「锦著/锦宾国际 + 委托管理」在西部民营存量市场的可复制性（首个非关联样板）；
2. **练兵场** —— 172 间、18 层、9 房型、47 项设施，是完整的单店运营训练场；
3. **新客群入口** —— 打开"民营存量单体"这条线（不是国资、不是自有资产）；
4. **SOP 沉淀** —— 花园模式（轻重分离 + 品牌输出 + 在地增值）的民营版复制。

**内部立项建议**：定性为「战略样板 + 产品验证」，按里程碑考核（改造完成 / 出租率达标 / 评分回升 / 首单会员规模），**不按利润中心考核**。

### 4.5 ★ 增值收入的机会点（不靠房费）

天阅有会议厅 + 多功能厅 + 24h 前台 + 服务口碑（点评"服务质量 394 条"高频夸前台）。
**南站片区的真实需求结构**：商旅过境（高铁 + 机场）+ 早班 + 政企培训 + 会议。
→ **可打包「过境 + 政企会议」双场景产品**：场地 + 餐饮 + 会议服务 + 差旅服务费，靠非房费收入补管理费缺口。
→ 花园的"在地文化社交空间"**不能直接移植**（天阅不是社交目的地），但其**"合规政企社交空间"内核**可以 —— 南站=铁路枢纽+高新区，企业培训与政企活动需求真实存在。

| # | 条款 | 建议口径 | 为什么 |
|---|---|---|---|
| 1 | **总费率** | 3.5–4.5% 营收（含品牌使用）+ 奖励 ≤5% GOP | 对民营四星中端店，7%+ 不可接受 |

| 4 | **改造投资归属与承诺** | 业主承担 ≥X% 且 12 年房龄设备清单化；改造未完成不得据此扣管理费 | 不写这条就不接 |

| 8 | **品牌费与效果挂钩** | 品牌费分两年释放，挂钩出租率/评分达标 | 约束二：锦著在成都零认知 |
| 9 | **委托期限** | ≥5 年，且与业主经营权期限、改造投资回收期匹配 | 用授权模板第 2.4 条逻辑 |
| 10 | **治理内核** | 附件：店长三年任期业绩责任书 + 市场化退出机制（对标《店长负责制》）| 集团现成制度，不新建 |
| 11 | **退出过渡** | 品牌摘除期限、数据移交、在店宾客与已接受预订处理、违约金上限 5% | 授权模板第 14.5–14.7 条 |
| 12 | **合规与用印** | 用印主体（安逸 vs 锦江饭店管理公司）、派驻人员劳动关系主体、三重一大审批路径 | 见 §7 尽调 D 类 |

**另需明确写入**：管理方**不向业主保证固定收益**（这是委托管理对民营业主的最大价值 —— 零保底），但**须承诺管理动作与经营目标**（出租率/RevPAR/评分/会员规模）。

## 6. 尽调清单（48 项 / 4 类）

**A. 业主与资产（12）** ① 产权证/租约（剩余年限、租金、递增）② 土地性质、可否餐饮/改造 ③ 消防验收与特种设备 ④ 抵押/查封/权属争议 ⑤ **现有委托管理合同（期限、终止条款、竞业限制）** ⑥ **业主换管理的真实动因** ⑦ 决策链与签批人 ⑧ **12 年房龄设备台账与更换史** ⑨ 近 3–5 年财报 + 审计 ⑩ 应收/预收/供应商欠款 ⑪ 员工花名册、工龄、社保、**经济补偿金测算** ⑫ 债权债务清单

**B. 经营数据（12）** ⑬ 近 24 个月分月 OCC/ADR/RevPAR ⑭ 房型级销量与收益 ⑮ 渠道结构（OTA 佣金率/直销/协议客户）⑯ 各 OTA 评分与趋势（携程/美团/Booking/飞猪）⑰ 会员体系与复购 ⑱ 会议/餐饮收入结构 ⑲ 客源结构与客单价 ⑳ 竞对月度数据（同带 8–10 家）㉑ 员工流失率与人工成本 ㉒ 采购成本与供应商 ㉓ 能耗成本 ㉔ 上次评分波动事件

**C. 管理与品牌（12）** ㉕ **格兰云天合同的排他期与竞业** ㉖ 格兰云天撤出时的员工承接义务 ㉗ 麦田/天阅品牌授权关系与到期 ㉘ 品牌视觉/物料/系统归属 ㉙ **OTA 店铺主体与评分继承路径（携程 hotelId 1200139）** ㉚ 会员数据归属与交割方式 ㉛ 现有品牌标准手册完整性 ㉜ 锦著/锦宾国际授权可行性 ㉝ **店长人选与外部招聘难度** ㉞ 团队梯队（有无第二梯队）㉟ 培训体系 ㊱ 质检/督导/神秘访客能力

**D. 合规（12）** ㊲ **集团体系与民营业主合作的内控审批路径** ㊳ 是否触发三重一大/董事会审批 ㊴ 品牌授权需否集团法务与品牌部会签 ㊵ 廉洁与利益冲突 ㊶ **合同用印主体** ㊷ 关联交易认定 ㊸ **派驻人员劳动关系主体** ㊹ 劳务派遣/外包合规 ㊺ 消防与安全责任划分 ㊻ 保险（公众责任险/雇主责任险）㊼ 数据合规（会员数据跨境）㊽ 退出时设备与品牌资产处理
