# 一、集团管控及运营提升的相关改进

## （一）当前管控的四大根本性缺失（问题诊断）

安逸集团当前最致命的问题，不是"哪一家酒店经营不好"，而是**集团缺乏一套统一的、可穿透的、标准化的管控体系与运营体系**。具体表现为四大根本性缺失：

### 1. 业财脱节、数据口径不一致（第一缺失）

**典型案例：古尔沟酒店。** 2024 年至 2025 年，古尔沟实际年收入从约 5000 万元下滑至不足 3000 万元，但集团报表显示为 4000 万元。其原因是酒店将 OTA 运营权整体外包给第三方，以换取 3000 万元预付款，并将该预付款**直接计入当期收入**，而非按财务准则"以实际发生入账"。这使得业绩指标表面上达标，实际经营能力却在被持续侵蚀。

这一案例暴露出三个层面的问题：

| 层面 | 问题 | 后果 |
|------|------|------|
| **财务入账** | 预付款当收入、远期消费计成本、开办费全部做应收 | 数据失真，公说公有理、婆说婆有理 |
| **业务外包** | 外包佣金高达 26%，亲子房合作 5 万元/间（行业已降至 6 千元甚至免费，携程主题房不要钱） | 单店成本虚高，全年损失近 300 万元 |
| **合同条款** | 签底价而非浮动比例价，且未经集团审核 | 造成"坑"需 2-2.5 年才能填平 |

**同类问题延伸：** 黄龙宾馆同样存在"收入计发生、还是计合同"的入账口径不清问题；茶山、华龙等酒店也不同程度存在经营外包行为。

**根因判断：** 这不是下属酒店的问题，而是**集团的问题**。集团没有给出统一的运营口径和财务口径，没有建立"业财结合、双重审核"的约束机制。当整体经营外包发生时，既没有运营口审核其合理性（26% 佣金是否合理），也没有财务口审核其合同条款（底价还是浮动价）。

### 2. 数据体系分散、颗粒度粗糙（第二缺失）

集团目前有 PMS、CRS、CRM 三大系统 + 集采系统，但：

- **没有 RMS（收益管理系统）**，也没有财务共享（只有结算中心）；
- 数据大看板只能看到客房数据，**看不到餐饮数据、上座率、颗粒度、维度**；
- 多套系统并行（锦江宾馆抓一个数据要翻找半天），各酒店统计口径不一致；
- 市场码、市场细分码过于粗糙，在全服务酒店基本不适用；
- 无统一的市场细分代码字典，出租率、平均房价、每房收益的计算方式未对标国际口径。

**后果：** 集团"遇到事情解决事情、遇到问题解决问题"，没有统筹规划；下级执行上级工作时各自为政，全维度数据缺失，灰色地带和特殊操作空间无法封堵。

### 3. 自营能力缺失、无营销与运营日历（第三缺失）

集团层面**看不到任何一家酒店的营销日历和运营日历**。我们发了大量朋友圈、做了大量广告，但不成体系——这些内容基本是"内部人在看"，外部客人根本刷不到、看不到。

**典型案例：新疆饭店。** 其在地客群运营极为扎实：专门的新媒体团队，线上直播售卖 + 线下实体活动并行；本地会员沉淀接近 1000 人（反复筛选、复购后沉淀）。当被问"你们有多少本地会员"时，对方不加思索、精确报数——而**安逸集团目前问不出这个问题**。

**反证我们的自营潜力：** 黄总到古尔沟后，用我们的商城做了一款特价产品，**马上卖了 6 万张**。我们不是没有自营的工具和方法，关键是"去做"。

### 4. 品牌与产品标准化缺失（第四缺失）

**没有品牌矩阵，就没有产品标准化；没有产品标准化，管理就乱如麻，各酒店不会为相关指标负责，指标也细化不下去。** 这是当前最根本的问题。

具体表现：

- 品牌部职能缺失，没有一体化的品牌宣传（目前一体化品牌宣传已延展到新媒体收入）；
- 自有品牌缺乏清晰市场路径，新媒体运营"重带货、轻沉淀"；
- 过度依赖外部联名蹭流量，忽视自有品牌建设；
- 各酒店品宣（节气海报、活动海报、卖房海报）零星、无营销日历统筹；
- 品牌是集团核心资产，应置于重资产端、授权轻资产开展工作，但目前职责不清。

## （二）大运营体系重构（运营提升的主干）

针对上述缺失，集团应系统重构"大运营体系"，将营销运营、餐饮、工程、安保等板块纳入统一管理，并明确各子项的标准与责任。

### 1. 收益管理体系（数据规范的基础）

- 全服务酒店均设立收益管理岗位；有限服务（经济型）酒店由集团代管或一人代管多家；
- 采用 STR 行业标准对标方法，按星级（无星级按房量）选取 5 家左右竞对，核心跟踪 **RGI（每房收益指数）**，拆解房价、出租率等维度的优化方向；
- 统一统计口径：**仅过夜房计入出租率，钟点房只计营业收入不计入出租率**，剔除经济型酒店统计口径干扰；
- 市场码、市场细分码做细到可落地（详见附件 1 价格代码字典维度）。

### 2. RFP / 热点采购体系（差旅集约化的抓手）

- 建立集团级 RFP（热点采购）体系，除企业差旅外，覆盖相关活动、联动及业务合作，并落地到旗下酒店；
- **以集团为单位统一部署与大企业（尤其央企）的 RFP 签约工作**——当前所有央企都在推行差旅集约化，我们是国企，应引导旗下酒店承接差旅客人（平安洽谈即此逻辑）；
- 大客户体系配置 1-2 人专职负责，协议单位与会员体系结合，构成对抗 OTA、降低 OTA 占比的直营手段；
- 把握每年 7-11 月国央企差旅采购窗口期，自主申请加入省属、市属国企差旅采购库。

### 3. OTA 与旅行社体系（第三方渠道管控）

- 集团统筹做 CRS 直连，由集团收单后分配订单到各单店，并考核各单店集团直连订单占比；
- 现阶段采用混合模式（单店可独立与 OTA 合作，集团同时做直连输送），未来向"全直连"过渡；
- 明确 OTA 挂牌、全渠道、境外渠道（Trip.com / TripAdvisor 等）的开通标准与指导；
- OTA 与旅行社同属第三方中间商，需放在一起统筹系列团对接（下半年即热点采购季与系列团采购季）。

### 4. 新媒体矩阵（第二增长线）

新媒体必须与品牌绑定、统一部署形成矩阵。以中旅酒店为对标参照：

> 中旅集团已对下属酒店下达年度新媒体收入考核：**年度 GMV 1-2 亿元，核销率 30%**（即实际营收 3000-3600 万元），预算按集团 30%、下属酒店 70% 拆分。这一模式是 Eric 2021 年在重庆带团队试点、2022 年向集团汇报时摸索出来的，恰逢抖音 2022 年启动本地生活业务。

**新媒体矩阵的核心逻辑：**

- 集团号 + 单店号形成矩阵（50 余家酒店 = 50 余个矩阵号，同步宣发）；
- 品宣号 + 卖货号分离，集团官号既做品宣也做带货；
- 新媒体是"传统媒体的单点化"——传统媒体需中介方投放、花钱，新媒体可自己发送、还可盈利；
- 各店宣发物料元素必须经集团品牌部审核，品牌部每日检查，杜绝负面信息；
- 新媒体即酒店管理公司的"第二增长点"（对应亚朵"第四空间"、安逸集市新零售）。

### 5. 会员、商城与社群体系（公域转私域的闭环）

- 将安逸商城、安逸集市、会员体系整合为一个板块，由 1-2 人专职跟进；
- 商城是"让酒店自己去卖"的载体：产品集合后卖给前厅、客房、餐饮上门客人；运管中心负责指导；
- 安逸集市回归"酒店自有产品售卖 + 会员自动转化"核心定位，采用无固定入驻费、按成交抽佣模式，完善产品分佣机制，逐步向旗下酒店开放入驻；
- 单店建立单店社群，用商城和会员体系运营社群、让会员反复购买，形成 CRM 正向飞轮；
- **核心命题：新媒体从公域抓取客人 → 社群转化 → 点击商城购买 → 自动成为安逸会会员**，沉淀在酒店自身会员体系。

### 6. 餐饮体系（全服务酒店的差异化核心）

- 全服务酒店必须建立餐饮点单系统（目前只有 POS 点位、无订单系统，客人被迫跳转美团小程序、拱手让客）；
- 点单系统覆盖大堂吧、售卖小产品等餐饮归口产品，实现"一屏点单、在地销售"；
- 单店点单系统挂在自己的会员入口或订房系统入口；
- 生活方式酒店必须设餐饮入口 + 专人管理（即"酒店产品经理"）；
- 单店能耗管控、日常成本管控纳入大运营（能源费用率对标，见附件 1）。

### 7. 分级分类与标准制定（标准化的前提）

- 因无品牌建设，先建"酒店分级分类内部制度"：按房间数量 + 星级双维对标；
- 针对分级分类制定全套标准（人员配比、组织架构、经营范式、考核标准、业务范畴），而非仅 SOP；
- 全服务与有限服务分别对标（全服务看人员配置，不能单看人房比）；
- 制定统一合规的财务标准（与运营方式无关），出具营销运营、餐饮、工程、安保各板块标准。

### 8. 集采平台优化

- 当集采平台价格高于酒店本地价格时，允许酒店采用本地商家并纳入集采平台体系；
- 以"给单店的价格"作为议价依据，集团价格应更优，推动供应体系迅速扩大；
- 规避现有流程冗长、价格虚高、供应商难以匹配的困扰。

### 9. 经营例会制度

- 集团层面按季度 / 半年 / 全年召开经营分析会，展示各部门及旗下酒店阶段工作，抽取 2-4 位总经理汇报（含最优与欠佳）；
- 酒店自身每月召开经营分析会，呈报集团但集团不参与（收益管理核心要素）；
- 经济型酒店合并汇报，优秀酒店单独汇报（经验分享）。

## （三）品牌塑造与新媒体运营矩阵（重点补课：两大缺失）

Eric 明确指出，当前最需补课的是**品牌塑造**和**新媒体运营矩阵**两大缺失。本小节将外部对标资料的维度"脱敏提炼"，作为例证有机融入。

### 1. 品牌矩阵的缺失与重建

**现状：** 我们目前能对外宣传的只有"皇冠假日"——但那是别人的品牌。集团没有自己的品牌矩阵，就无法输出标准化产品，管理必然松散。

**重建路径：** 在打造项目过程中逐步梳理品牌。以两大标杆项目为起点：

| 品牌定位 | 代表项目 | 产品模型 |
|---------|---------|---------|
| **有限服务·中高端精选（生活方式）** | 花园宾馆 | 市井街巷生活方式，400-450 元 |
| **有限服务·精品（生活方式）** | 四川宾馆 | 巴蜀文化精致生活方式，600-800 元 |
| **四星全服务·标杆** | 都江堰国堰宾馆 | 水文化主题全服务，全年龄段 |
| **四星全服务·政务商务** | 新良大酒店 | 政务商务，承接园区政商客源 |

**品牌部归属原则：** 品牌是集团核心资产，应置于重资产端、授权轻资产开展工作。品牌部负责搭建新媒体矩阵、审核各店宣发物料、每日检查各店发布内容。

### 2. 新媒体运营矩阵的架构

**外部资料维度脱敏提炼（营销日历维度）：** 参照成熟酒店集团全年营销日历，一张完整的营销日历需覆盖以下维度（脱敏后）：

| 维度类别 | 具体子项 |
|---------|---------|
| **时间维度** | 阳历、阴历、星期、节气、法定节假日、特殊班休调整、其他节日 |
| **客群触点** | 客房礼遇、餐饮部活动、前厅部活动、宴会活动 |
| **商务动作** | 商务活动（扫楼拜访、RFP 联系）、协议续签计划 |
| **线上矩阵** | 美团外卖、大众点评、心享商城、公众号、小红书、微博、朋友圈、社群 |
| **事件捕捉** | 社会性热点、各种考试、会议会展及周边酒店会议信息、店庆/集团庆 |

**对标启示：** 一套营销日历是"到什么时间节点该做什么事、该涨多少价"的统一安排，收益管理与营销日历充分契合。当前集团层面"看不到任何一家酒店的营销日历"，这是必须补齐的能力。

**新媒体矩阵落地要点（结合三家调研纪要的实践）：**

- **国堰宾馆**：正式启动小红书（借 AI 工具降低内容生产门槛），抖音逐步转向自营，核心目标从卖房转向本地私域粉丝积累，通过社群转化餐饮、宴会等高价值消费，规避本地酒店低价内卷；每月不少于 2 篇产品内容；行政酒廊改造为新媒体直播室（复用场地与直播基础）。
- **花园宾馆**：开通小红书主打区位引流；新媒体调整"直接带货"偏差，先沉淀粉丝再做转化。
- **嘉州宾馆**：拆分双抖音垂类账号（云上餐饮号 + 嘉州客房号），通过小红书、抖音主打"宅酒店"年轻客群，突出江景、投影房型，搭建抖音粉丝群完成公域转私域闭环。

### 3. 外部对标维度的系统脱敏提炼（融入运营阐述）

**（1）价格代码字典维度（28 类市场/价格代码）**

一套完整的集团价格代码字典是收益管理与数据统一的基石。外部资料中成熟酒店集团的字典涵盖 28 个 Sheet，脱敏后可提炼为**市场代码（5 级）+ 价格代码（28 类）**双体系：

| 市场大类 | 代表价格代码 | 含义 |
|---------|------------|------|
| 散客类 | RAC / RES / CTI / TPA / WEB / COO | 前台、预订部、服务中心、微信、官网、异业合作 |
| 促销类 | PRO / SEL / SOC | 季节大促、自营社群推广、新媒体推广 |
| 线上分销 | OTA / OTP / WEM | 在线旅游平台、分销平台、自媒体平台 |
| 协议类 | LRA / NLA / GOV / LSR | 本地协议、全国协议、政府采购、长住 |
| 会议团队 | MTC / MET / MGM / TSR / ADH / ALO / ACW | 公司会议、展会、政府会议、系列团、一次性团、误机团、机组 |
| 内部房 | HSE / COM | 内用房、免费房 |
| 集团价 | 集团差旅、员工福利 | 差旅价（BAR 含双早 7 折）、员工价（5 折） |

**落地价值：** 这套字典解决了"市场码、细分码、价格代码是否充分、是否统一"的问题，是数据穿透和收益管理标准化的直接抓手（详见附件 1）。

**（2）对标排名表维度（27 项经营指标）**

外部资料中的"酒店经营指标对标排名表"按五星 / 四星分档、按月 / 年累计，覆盖 27 个维度。脱敏提炼如下：

| 指标类别 | 具体维度 |
|---------|---------|
| **基础信息** | 酒店规模（房量） |
| **收入结构** | 客房收入占比、餐饮收入占比、其他收入占比 |
| **客房指标** | 出租率、平均房价、单房成本 |
| **核心经营** | 经营毛利率、客房毛利率、餐饮毛利率 |
| **餐饮成本** | 食品成本率、酒水成本率 |
| **能耗** | 能源费用率、预算能耗率 |
| **人力** | 人工成本率、人房比 |
| **效能** | 营利坪效、人均产值、人均产能 |

**落地价值：** 这套对标表解决"人防比、坪效、人效"的统一核算问题（坪效由财务部核算、人效由人力部处理、最终财务部出表），并可作为全集团对标的标准模板（详见附件 1）。

**（3）STR 收益对标维度（MPI / ARI / RGI）**

外部半年经营分析展示了标准的 STR 对标体系：**MPI（出租率指数）、ARI（房价指数）、RGI（每房收益指数）**，配合竞争群（5 家左右同档位酒店）排名。国堰宾馆调研已明确"采用 STR 行业标准对标，选取周边 4-5 家同档次酒店，核心跟踪 RGI，拆解房价、出租率维度优化方向"。

**（4）细分市场与会员发展维度**

外部半年经营分析中的市场细分结构（门市散客、商务公司、线上散客 OTA/OTP、新媒体、微信、会议政府、会议公司、批发商、长住房）与会员发展渠道（散客、团队、餐饮消费）转化率，正是集团"市场细分码做细"的直接参照。

---

## （四）考核体系重构（管控落地的抓手）

### 1. 现状问题

- 考核有元素和维度，但**权重占比太低，无法细化，相当粗放**；
- 因轻重资产未分离，总经理既背资产考核又背经营考核，净利润率考核权重过大，压缩经营考核权重；
- 总经理经营考核维度"非常少、非常窄"，各自为政，未与集团形成合力。

### 2. 改进方向

- 实现轻重资产分离；
- 考核设置时将资产与经营权重分开：董事长 / 旗下公司董事长 / 统筹副总加大资产与历史遗留问题权重；总经理加大运营权重、放宽考核维度；
- 建立全集团 KPI 维度框架（7 大类 30 项，详见附件 3），区分重资产（自营）与轻资产（托管/授权/咨询）两套标准；
- 全集团数据报表由财务部出，运营细分项数据接口由运营部门出，保证口径一致、有序专业。

---

## （五）集团管控的核心结论

> **集团管控与运营提升的抓手，不是"发更多红头文件、设更多岗位、下更多命令"，而是：**
> 1. **业财结合**——运营口 + 财务口双重审核，杜绝外包失控、数据失真；
> 2. **数据统一**——市场码 / 价格代码 / 对标维度 / 统计口径全面标准化；
> 3. **自营能力**——收益管理 + 新媒体矩阵 + 会员商城 + 营销日历四大支柱；
> 4. **品牌标准**——以标杆项目沉淀品牌矩阵与产品标准，让管理有依据、指标可细化。

# 二、以数字化和 AI 化的持续投入建设解决集团管控问题

## （一）核心命题：以数字化替代文件与人治

**Eric 的核心判断：** 集团管控问题，**不能靠红头文件、人治和命令解决，而要靠数字体系的完备性、穿透性、数据统一来解决。** 这是"非常非常重要的第一步"。

当前集团大部分工作是**人治、手工操作**，效率极低，缺的是一个"系统化整合"的工具。以下三个事实足以说明：

1. **省旅投产业联动协议无法落地。** 陈部长提出"与各省级酒旅平台 / 旅投平台建立产业联动、形成统一折扣价"——这个想法很好，但**现在做不到**。即便签了协议（双方人员互访享受特定价格），它也毫无意义，因为执行不下去：必须依靠各级手工执行，任何一个环节出偏差就无法执行。
2. **改造后能否"接得住"的灵魂拷问。** 集团改造出一个酒店后，运营团队能不能接得住？靠什么去接？目前整个市场体系运转靠系统化，我们还在以人力驱动。即便有了新规定、新执行标准，怎么让它执行落地？——答案只能是个性化（数字化）体系的完善。
3. **数据散、无穿透。** 有大屏看板和各种系统，但数据非常散，无法通过一个体系看到完整数据，业财未结合，无法形成合力。

## （二）数字化建设的实施路径

### 1. 数据体系统一与穿透

- 打通业财数据，实现"一个体系看到完整数据"；
- 建设财务共享中心（目前只有结算中心，没有共享）；
- 制定统一的市场码、细分码、价格代码字典（详见附件 1）；
- 统一出租率、平均房价、每房收益的计算口径（对标国际一线标准）。

### 2. 单店个性化基础重塑（石基单店突破）

- 已联系**石基**，愿意为集团做单店突破的系统化构建（而非推翻原有系统重做，成本更低）；
- 将 PMS、CRM、RM、CRS + 餐饮 POS 点位与点单系统全面结合，纳入一个体系运转；
- 数据颗粒度细化到餐饮上座率、能耗、成本等维度，封堵灰色地带。

### 3. AHL 垂系 Agent 平台（AI 化的抓手）

- AHL 平台是集团"数字化护城河"在单店的落地载体，改造酒店的弱电智能化必须与 AHL 对接；
- AI/Agent 辅助收益管理（AI RM）、市场洞察、质检预警、红绿灯自动判定；
- 对标万豪：其 RM 系统每年为集团创造 3 亿元收入——先在自己酒店循序渐进建立，再对外拓展收费。

### 4. 数字化中台与自动考核

- KPI 红绿灯自动判定（月度 13 项追踪、年度 17 项追踪，见附件 3）；
- 集采、会员、CRS、财务共享、新媒体五大对接的标准化；
- 从"靠人盯"转向"靠系统跑"，大幅降低人工成本的同时保证执行落地。

## （三）核心结论

> **数字化与 AI 化不是"锦上添花"，而是"治本之策"。** 只有实现数据体系统一、业财结合、系统化管控，集团才能真正实现从"红头文件、人治、命令"到"标准流程、系统执行、数据穿透"的转变，也才能在未来与外部系统化单位对接时不至于无法接入。

# 三、集团存量酒店项目改造的先后顺序调整

## （一）715 定稿的原改造顺序

按 715 定稿，拟改造酒店 6 家，分两批：

| 批次 | 酒店 | 原定位 |
|------|------|--------|
| 第一批 | 四川宾馆（正在决策）、花园宾馆、深圳四川宾馆 | 四川宾馆准五星旗舰店；花园宾馆四星"安逸·花园宾馆"；深圳川宾四星省外拓展 |
| 第二批 | 皇冠假日酒店、新良大酒店、华龙酒店 | 皇冠五星（锦宾国际 / 或国际品牌）；新良四星（安逸·新良 / 或拆分）；华龙高档商务"安逸·锦著" |

6 家改造投资约 4 亿元，停业期间刚性支出约 7500 万元，第一批约 1.33 亿元、第二批约 3.43 亿元；改造后净利润预计 1675 万元，IRR 6.6%-24.6%（四川宾馆因市场化租金仅 4.06%）。

## （二）调整后的先后顺序及原因

**Eric 的核心判断：** 集团目前没有能力直接打造高星级全服务酒店，也没有五星级品牌，应"先练手、先带团队、先建标准、再上规模"。据此，改造顺序应调整为"以能力建设为序"：

### 调整后的优先级排序

| 优先级 | 酒店 | 定位 | 调整理由 |
|-------|------|------|---------|
| **P0（先行）** | 都江堰国堰宾馆 | 四星全服务·水文化标杆 | 团队最完整、风险可控、投资较小（改造 3000-5000 万）、全服务项目全生命周期练兵 |
| **P1（同步）** | 花园宾馆 | 有限服务·中高端精选（生活方式）| 位置极好、可大面积复制、沉淀"精选"品牌标准与数字体系标准 |
| **P2（缓推）** | 四川宾馆 | 有限服务·精品（生活方式）| 巴蜀文化题材太大、无先例，慢工出细活，不宜抢跑 |
| **P3（调整）** | 新良大酒店 | 四星全服务·政务商务 | 体量大、动静大，承接园区政商客源，与花园差异化，不拆分为宜 |
| **P4（后续）** | 华龙酒店 | 高档商务 | 经营外包问题需先治理，改造后置 |
| **P5（暂缓/外部合作）** | 总府皇冠假日 | 五星 | 集团无五星能力，暂缓，寻求国际品牌 / 第三方合作解决 |

### 调整的核心逻辑（原因阐述）

1. **能力先行，而非投资先行。** 集团现在做五星、四星改造都"没有这个能力"，应先通过一个项目把团队、经验、标准锻炼出来。
2. **国堰宾馆是唯一"能力闭环"的项目。** 其团队是集团内经营能力、团队意识、市场意识最完备、最强的团队，通过这次改造可把团队提升到"项目管理"高度——不只懂经营，还会做项目、能以项目眼光看酒店。且国堰位于世界名片都江堰，改造后即是安逸集团"世界名片所在地的标杆项目"。
3. **花园宾馆是唯一"可复制"的项目。** 它不缺客人，缺的是产品、宣传和宣发。以它为蓝本打造"有限服务·中高端精选生活方式酒店"，可复制到整个体系及未来拓展；同时沉淀品牌标准与数字体系标准。
4. **四川宾馆题材过重。** 打"巴蜀文化载体"题材太大、没有先例，现团队做不出来，应先用国堰练手、花园沉淀，再慢慢做四川宾馆。
5. **新良与花园必须差异化。** 两者位置近、原本都想承接政务客源，若都做政务会形成同质化恶性竞争。花园转向市井街巷生活方式，新良承接园区政商客源与政务会议，各自清晰。
6. **皇冠假日暂缓。** 集团没有能力把一家五星级酒店从头做到尾并持续运营，也无五星品牌，应暂缓、寻求第三方（国际品牌 / 有影响力品牌）合作。

## （三）每家酒店的市场定位与产品模型

### 1. 生活方式酒店的产品模型（通用基准）

生活方式酒店是当前坪效最大的产品模型：房间 150 间左右（120-200 间），总面积约 2000㎡，功能配置：

- 早餐厅、大堂及前台、生活化潮流化吧台、文创 / 多功能空间（基本在一个平层解决）；
- 100-150㎡、可容纳 100 人的多功能会议室（小型会议 + 小型餐饮宴会）；
- 1-3 个中餐包厢；
- 空间动线简洁（只提供早餐、精致简餐），弱化前台、公共区域留给客人；
- 剩余空间最大化做出房率。

### 2. 六家酒店的具体定位与产品模型

| 酒店 | 市场定位 | 产品模型 | 价格区间 | 核心差异化 |
|------|---------|---------|---------|-----------|
| **都江堰国堰宾馆** | 集政务、商务、旅游于一体的全年龄段四星全服务酒店 | 全服务 + 水文化主题（五改文创 + 文创周边）| 现有均价，改造后提升 | 水文化 IP（铜板浮雕、石根雕馆藏）、汤池、政务接待基因、世界名片目的地 |
| **花园宾馆** | 中高端有限服务精选·生活方式酒店 | 有限服务精选（街区市井文化 + 书店文化 + 精致化"小食堂"）| 400-450 元（RevPAR 目标 339-400 元）| 春熙路核心位置、市井巷子文化、樊登/帆书书店植入、9 包间减至 3 个 |
| **四川宾馆（川宾）** | 中高端有限服务精品·生活方式酒店 | 有限服务精品（巴蜀文化深度主题）| 600-800 元（介于四星与五星之间）| 巴蜀文化精致生活方式、独立早餐厅（不与皇冠共用）、空间聚合 + 文创植入 |
| **新良大酒店** | 四星全服务·政务商务酒店 | 全服务（300 多间房，不分拆）| 维持现有档次 | 承接园区政商客源 + 政务会议，与花园差异化，避免同质化竞争 |
| **华龙酒店** | 高档商务 | 商务全服务（先治理经营外包）| 维持现有档次 | 治理外包、回归自营后改造 |
| **总府皇冠假日** | 五星（暂缓）| 寻求国际品牌 / 第三方合作 | 维持五星 | 集团无五星能力，暂缓自建，外部合作解决 |

### 3. 通过改造完成品牌与产品重塑

改造的深层目的，是**通过两个产品模型的落地，完成品牌与产品的重塑**：

- **一个"精品"、一个"精选"**：川宾精品（复制谨慎、不铺开），花园精选（可大面积铺开）——高低搭配，形成生活方式品牌的两种变体；
- **一个"四星全服务标杆"**：国堰宾馆，沉淀全服务体系标准与项目管理能力；
- 由此沉淀出"安逸"产品标准与运营体系，为后续"品牌运营、标准输出"（四步战略第三步、第四步）奠定基础。

# 四、安逸集团最终的三大核心市场竞争力

结合以上管控、数字化、存量改造的系统梳理，安逸集团在市场上立足的**三大核心护城河**如下：

## （一）数字体系化的个性化方案解决能力

**内涵：** 独一无二的数字能力，包括 AI 能力，需从现在开始打造，是未来与人合作、业务拓展时"穿透一切"的能力。

**构成：**

- 统一的数字体系（业财结合、财务共享、市场码 / 价格代码 / 对标维度标准化）；
- 单店个性化基础重塑（PMS/CRM/RM/CRS + 餐饮点单系统一体化）；
- AHL 垂系 Agent 平台（AI RM、AI 质检、红绿灯自动判定）；
- 数字化中台 + 全面预算管理（颗粒度细化到每一收入维度）；
- 未来对外输出收益管理（对标万豪 RM 系统年创收 3 亿元）。

**为什么是护城河：** 当整个市场体系靠系统化运转，而同行仍以人力驱动时，数字体系的完备性、穿透性、统一性，就是"谁能接得住项目、谁能系统化对接、谁能封堵灰色地带"的决定性能力。

## （二）在地文化的挖掘及酒店空间构建能力

**内涵：** 从改造单店、做成"超级单店"（超级体量或超级 IP）开始，在地文化挖掘是安逸的核心护城河之一。

**构成：**

- 各酒店的在地文化资源禀赋（脱敏提炼）：

| 酒店 | 在地文化 |
|------|---------|
| 都江堰国堰 | 水文化（千年水哲学）、铜板浮雕、石根雕馆藏、青城山道家文化 |
| 花园宾馆 | 街区市井文化、走马街巷子文化、书店文化 |
| 四川宾馆 | 巴蜀文化、政商精致生活方式 |
| 乐山嘉州 | 嘉州画派、三江历史、红色接待沿革 |
| 茶山 | 茶马古道起点、茶叶文化、川康文化 |
| 古尔沟 | 景区 + 在地度假文化 |

- 文化挖掘前置：在项目建设之初即融入（地理位置 + 酒店历史的挖掘）；
- 引入文化 / 文创合作伙伴到实际场景（樊登 / 帆书书店、前景盛和 / 研筑舍 / 华可文旅 / 蜀源创意等）；
- 线下场景活动 + 线上直播 + 特定时段活动统一进行，积累并吸引本地客群；
- 设计单位 + 文创单位联合介入（设计承载文化），避免"装修完再加文化"。

**为什么是护城河：** 在地文化是"不可复制、难以被 AI 替代"的差异化能力，它决定了酒店的独特 IP 与品牌存活度——本地客群对你的认知程度，直接决定品牌存活。

## （三）成体系的自营能力

**内涵：** 目前缺失但必须回归构建的能力。作为酒店集团与管理公司，只有具备自营能力才能拓展项目、别人才愿合作。

**构成：**

- **自营工具**：会员体系、安逸商城、安逸集市、餐饮点单系统、社群化运营工具、新媒体矩阵；
- **自营闭环**：新媒体（公域）→ 社群（转化）→ 商城（复购）→ 会员（沉淀）；
- **回归自营**：抛弃第三方运营模式（古尔沟、茶山经营外包的反面教训），收回 OTA 运营权；
- **考核倾斜**：考核维度向"自营能力"倾斜（直销占比、会员转化、复购率、新媒体 GMV 等）；
- **第二增长线**：新媒体矩阵（对标中旅 1-2 亿 GMV、核销率 30%）、新零售（安逸集市）。

**为什么是护城河：** 自营能力即"你能触达客户的能力"。古尔沟用自营商城一款产品卖出 6 万张，证明我们具备自营潜力；缺的是体系化的执行。成体系的自营能力一旦建立，将形成"会员持续增加、购买持续复购"的正向飞轮，是对抗 OTA 侵蚀、实现自我造血的根基。

## （四）三大竞争力的内在统一

> **数字体系化的个性化方案解决能力**（管得住、接得住、算得清）
> **在地文化的挖掘及酒店空间构建能力**（做得出、立得住、叫得响）
> **成体系的自营能力**（触得达、转得化、复得购）

三者不是孤立的：**在地文化**赋予产品灵魂，**自营能力**赋予产品生命力，**数字体系**赋予产品穿透力与可控性。三力合一，才是安逸集团区别于同行的、可持续的核心竞争力。
