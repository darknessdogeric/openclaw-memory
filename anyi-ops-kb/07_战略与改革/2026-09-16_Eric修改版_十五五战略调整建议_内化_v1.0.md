## 二、Eric 修改版的核心战略意图

### 2.1 6 大改造的真实"3+3"分组

```
第一组（自有品牌旗舰，3 家）
├── 四川宾馆（四川宾馆品牌）→ 巴蜀文化旗舰 + 川办全国连锁母版 + 餐饮产品线
├── 花园宾馆（安逸花园）→ 生活方式精选 + 在地文化聚合空间
└── 国堰宾馆（国堰宾馆品牌）→ 高端全服 + 文旅融合 + 数智化穿透试点

第二组（专业化合作，3 家）
├── 新良大酒店 → 双品牌（外资中高端 + 自有潮牌）
├── 总府皇冠假日 → 国际联号 + 资产债务重组
└── 华龙酒店 → 锦著 2.0 母版 + 三方联合品牌
```

**重要变化**：
- 国堰宾馆升格为旗舰项目（不再是"运营改善类"）
- 深圳四川宾馆并入"四川宾馆品牌体系"（不再是独立项目）
- 新良大酒店明确"外资中高端 + 自有潮牌"双品牌（潮牌而非全服务品牌）
- 总府皇冠假日明确"国际联号 + 资产债务重组"双主线

### 2.2 集团品牌矩阵的双主线

```
安逸集团整体品牌定位
├── 安逸系列（自有品牌）
│   ├── 安逸花园（花园宾馆改造后的子品牌）
│   ├── 国堰宾馆（独立品牌）
│   └── 其他安逸子品牌
└── 锦江系列
    └── 锦江子品牌（外部授权使用）
```

### 2.3 国堰宾馆 5 大融合板块

| 板块 | 内容 | 责任部门 |
|------|------|---------|
| 文创改造 | 水文化主题空间营造 | 投资和资产部主责 |
| 文化艺术策展联营 | 文化策展 + 酒店联营 | 产业发展部参与 |
| 新媒体矩阵 & 新零售 | 集团新媒体 + 文创零售 | 运营管理中心 |
| 全域数智化穿透 | AHL 集团中台落地试点 | 数智化推进组 |
| 高端全服式品牌验证 | 对标五星全服务产品线 | 产业发展部 |
