摘要（1 页）

背景

安逸集团当前面临"三个不匹配"核心短板（资产与战略需求、产品与资产价值、机制与市场竞争），急需通过数字化手段实现集团赋能。集团"十五五"规划明确"1234"战略路径（一条主线/两大品牌/三大赛道/四步实施），其中第四步"全方位市场化"必须以体系化数字能力为底座。

核心命题

AHL 不是单一产品试点，而是集团数字化基础设施——通过垂系 Agent 网络，让集团 167 家酒店 + 旅投旗下多业态 + 协议合作酒店组成"数据喂养"正反馈循环，最终实现： - 集团对单店赋能 + 管控双闭环 - 安逸品牌力软升级（不靠品牌加盟，靠"垂系 Agent 服务"差异化吸引业主） - 旅投旗下多业态横向联动（住酒店→买景区票→坐天府号列车→消费餐饮） - 集团创新创收（向行业输出"垂系 Agent 服务" SaaS 模式）

政策契合度

  • 国家：国务院国资委数字化转型 + 文旅融合战略 + 数据要素流通
  • 四川省："文化强省旅游强省" + 国有资本布局优化 + 数字经济
  • 成都市："国际消费中心城市" + 文商体旅融合 + 住宿业高质量发展
  • 监管合规：三重一大决策程序 + 关联交易合规 + 数据安全法 + 个人信息保护法

给董事长的 3 条核心建议

  1. 试点先行：2026/9-2027/12 完成 1-2 家内部 MVP 验证（建议总府川宾 + 总府皇冠联动项目）
  2. 集团统筹：AHL 试点由集团产业发展部牵头，避免子公司分散建设
  3. 独立预算：建议第一年投入 800-1,200 万（不到集团年度营收 0.1%），单设 AHL 专项预算

1.3 AHL 项目本质重新定义

关键洞察（基于 Eric 7/27 深度阐述 + B166ER 战略沉淀）：

AHL 不是再造一个 OTA，是再造一个"触达层"——让酒店拥有自己的关系链资产。

AHL = 三层架构：

L1 数据层    → 客户需求数据（用户主动表达 + Agent 语义理解）
L2 触达层    → 垂系 Agent 网络（精准匹配 + 主动推送）
L3 关系层    → 关系链资产（本地小B + 跨酒店互喂）

AHL 的真正护城河：数据喂养的网络效应——一个酒店 Agent 触达 → 数据反馈 → Agent 更精准 → 触达成本下降 → 更多酒店加入 → 更多数据喂养 → 正反馈循环。

对集团的核心价值： - AHL 不是"做一个新产品"——AHL 是集团数字化基础设施 - AHL 试点成功 = 集团获得未来 5-10 年差异化竞争力 - AHL 试点失败 = 集团数字化滞后，未来被市场淘汰

第三章 九大问题诊断与 AHL 解决方案（核心）

问题 1：集团向下属单店赋能及管控

现状与痛点： - 167 家酒店分散在多个城市，集团总部"看得见但管不着" - 单店经营数据靠人工报表，滞后且不准确 - 集团能力（收益管理 / 客户分析 / 采购 / 培训）难下沉到单店 - 单店遇到问题只能靠"电话指挥"，效率低

AHL 解决方案： | 维度 | 具体动作 | |------|---------| | 数据回流 | Agent 自动采集单店经营数据（入住率 / ADR / 客户画像）回流集团中枢 | | 能力下沉 | Agent 把集团收益管理建议实时推送给单店店长 | | 统一管控 | 集团通过 Agent 看到所有单店实时经营仪表盘 | | 应急响应 | Agent 自动预警经营异常（如 ADR 持续下滑）→ 集团介入 |

政策契合： - 国资委"国企数字化转型"+ 四川省"国有资本布局优化"

合规检查： - Agent 数据采集涉及客户隐私，需符合《个人信息保护法》 - 建议：数据脱敏 + 客户授权 + 集团数据合规审查

预期效果（3 年）： - 集团对单店数据可见度从"周报滞后"提升到"实时可见" - 单店收益管理建议接受率 ≥60% - 集团应急响应时间从"天级"缩短到"小时级"

问题 2：安逸品牌力不足，业主单位不接受

现状与痛点： - "安逸"品牌在中高端酒店市场认知度低（远不如华住/亚朵/锦江） - 业主单位（持有物业方）不愿接受"安逸"品牌加盟 - 即使签约，业主也常要求"换牌" - 品牌拉力不足导致集团轻资产输出受阻

AHL 解决方案： - 不推"安逸"品牌，推"垂系 Agent 服务" - Agent 的差异化能力（精准触达 / 收益优化 / 客户复购）让业主看到实际增值收益 - 业主接受的不是"安逸"品牌，而是"安逸的 AI 能力"

政策契合： - 文旅融合 + 中高端酒店升级 + 服务业模式创新

合规检查： - 不是品牌加盟（合规风险低），是技术服务合作 - 建议：AHL 服务按"技术服务费"模式定价，避免被认定为"加盟"

预期效果（3 年）： - 业主单位接受合作率从 ~20% 提升到 ~50% - 协议合作酒店从 0 家 → 30-50 家 - 集团轻资产管理酒店目标（Eric 任后）：103 家（2026）→ 130 家（2028）

问题 3：旅投旗下及安逸旗下多业态横向联动

现状与痛点： - 旅投集团旗下业态分散（酒店 / 景区 / 餐饮 / 交通 - 锦绣天府号等） - 各业态会员体系孤立，客户无法跨业态享受服务 - 集团内协同弱，每个业态"各自为政" - 数据不流通，无法形成"客户全旅程"视图

AHL 解决方案（三层联动架构）：

L1 数据层    → 统一客户 ID（打通酒店 + 景区 + 餐饮 + 交通）
L2 触达层    → Agent 主动推送（住酒店 → 推荐景区票 → 推荐天府号行程 → 推荐餐饮）
L3 关系层    → 跨业态关系链资产（一个客户在多个业态的消费轨迹）

应用场景示例： - 客户 A 入住总府川宾 → Agent 推送"成都周边景区联票" - 客户 B 在九寨沟游玩 → Agent 推送"下榻安逸酒店享 8 折" - 客户 C 预订天府号列车 → Agent 推送"沿途酒店 + 餐饮"

政策契合： - 四川省"文商体旅融合发展战略" + 成都市"国际消费中心城市"

合规检查： - 涉及集团内关联交易（不同业态之间互相引流），需走合规审议 - 建议：制定《集团内业态联动管理办法》，明确分润机制

预期效果（3 年）： - 跨业态客户转化率 ≥15% - 客户全旅程价值提升 2-3 倍 - 集团内协同收入贡献 ≥ 3,000 万/年

问题 4：迅速扩充受众群体（会员联动）

现状与痛点： - "安逸汇" 会员体系起步晚（目标 600 万，实际远低于此） - OTA 替代率低（中央预订占比 < 10%，远低于 Eric 任后 25% 目标） - 私域流量薄弱（公众号 / 小程序 / APP 用户活跃度低） - 客户获取成本高，OTA 佣金 15-25% 持续侵蚀利润

AHL 解决方案： - Agent 作为统一会员接口：让客户在不同业态（酒店 / 景区 / 餐饮）无缝切换 - 会员数据资产沉淀到集团：所有 Agent 互动数据归属集团 - 私域流量池：通过 Agent 把 OTA 客户转化为"安逸汇"会员

目标路径：

2026/12: 安逸汇会员 600 万 (集团目标)
   ↓ Agent 加速转化
2027/12: 安逸汇会员 800 万
   ↓ 跨业态联动
2028/12: 安逸汇会员 1,200 万 (含景区/餐饮/交通客户)

政策契合： - 国务院"数据要素流通" + 国资委"国企数据资产管理"

合规检查： - 客户数据归属：必须明确为"安逸集团"统一管理 - 数据使用：符合《数据安全法》《个人信息保护法》 - 数据资产化：可申请四川省数据资产入表试点（合规创新）

预期效果（3 年）： - 安逸汇会员从 0 增长到 1,200 万 - 中央预订占比从 <10% 提升到 25%+（Eric 目标） - 私域流量价值沉淀 5-8 亿（会员资产估算）

问题 5：安逸集团自身在此项目上创新创收

现状与痛点： - 集团收入单一（管理费 + 营收分成 + 部分租金收入） - 缺乏创新收入来源，2025 年净亏 -6,843 万元 - 传统酒店业增长见顶，必须找到第二曲线

AHL 解决方案： - 集团可向行业输出"垂系 Agent 服务"（SaaS 模式） - 不直接做酒店管理，而是把 AHL 的 AI 能力作为"技术服务"对外销售 - 按调用量 / 效果分成，避免重资产投入

潜在创收模式：

模式 计费方式 3 年收入估算
A. Agent 调用费 0.5-1 元/次调用 年 1,000-2,000 万
B. 效果分成 Agent 带来订单流水的 5-10% 年 2,000-5,000 万
C. SaaS 订阅 5-10 万/酒店/年 100 家酒店 × 8 万 = 800 万/年
D. 数据增值服务 行业报告 / 客户画像 年 500-1,000 万
合计 — 年 4,300-8,800 万

政策契合： - 国务院"数字经济"+ 国资委"国企新业务培育"

合规检查： - 需明确是新业务还是子公司业务（建议：集团新业务部，便于管控） - 不与上市公司同业竞争（AHL 定位"技术服务"而非"酒店管理"） - 与非国资业主合作需走合规审查（避免利益输送嫌疑）

预期效果（3 年）： - 集团创新收入贡献 ≥5,000 万/年 - 集团收入结构多元化（创新收入占比从 0 提升到 8%+）

问题 6：轻重资产分离助力

现状与痛点： - 集团重资产改造周期长（6 大酒店改造 + 总府川宾等） - 轻资产输出能力弱（管理酒店 78,752 间，但轻资产管理输出占比低） - 重资产项目投入大、回报慢，难以快速规模化

AHL 解决方案： - AHL 让"轻资产输出"具备差异化卖点——不是传统酒店管理公司，而是"AI 赋能酒店运营" - AHL Agent 可以让一个轻资产管理的酒店达到"垂系 Agent 网络"的客户触达效果 - 这是传统酒店管理公司做不到的

轻重分离路径：

[重资产路径] 6 大酒店改造 (金牛/锦江/新良/华龙/深圳川宾/花园 + 总府川宾)
            → 周期 2-3 年, 单店投入 4,000-8,000 万
            → 改造后接入 AHL Agent, 提升入住率/复购率

[轻资产路径] 协议合作酒店 (业主单位提供物业, 集团输出 AHL + 管理)
            → 周期 6-12 个月, 单店投入 200-500 万 (集团端)
            → Agent 即插即用, 快速复制

政策契合： - 国务院"国有资本布局优化" + 湖北省酒店集团轻重分离标杆案例

合规检查： - 轻重分离涉及资产剥离 / 资产重组，触发三重一大 - 建议：参考湖北省酒店集团 2020-2023 改革路径（已完成轻重分离，经营门店突破 230 家）

预期效果（3 年）： - 轻重资产分离完成（2027 年底） - 轻资产管理酒店从 0 增长到 100+ 家 - AHL 成为轻资产管理的"标准组件"

问题 7：行业影响力

现状与痛点： - 安逸集团在酒店行业默默无闻（中高端酒店排名不入榜） - 缺乏行业话语权，难以参与行业标准制定 - 行业活动出席度低，被视为"地方国资老酒店"

AHL 解决方案： - AHL 试点成功 → 行业首发 → 形成"成都模式" / "安逸模式" - 可申请行业标准制定（垂系 Agent 在酒店业的应用标准） - 行业大会发声 + 案例发布 + 媒体曝光

行业影响力建设路径：

2027/Q1: AHL 试点 1-2 家 → 行业首发案例（成都酒店行业论坛）
2027/Q3: AHL 拓展到 5-10 家 → 申请四川省酒店业 AI 应用试点
2028/Q1: 30-50 家酒店 → 申请行业标准制定（垂系 Agent 酒店应用标准）
2028/Q3: 跨地域拓展 → 全国酒店业创新案例
2029: 行业标准发布 → 安逸成为"酒店业 AI 第一梯队"

政策契合： - 四川省"文化强省旅游强省" → 安逸成为成都酒店业标杆 - 成都市"国际消费中心城市" → 安逸代表成都酒店业发声

合规检查： - 行业活动出席需集团审批 - 行业标准制定需走专业机构（行业协会）路径

预期效果（3 年）： - 行业媒体曝光 ≥10 篇/年 - 行业论坛主旨演讲 ≥3 次/年 - 申请行业标准 1-2 项

问题 8：重资产方向存量改造

现状与痛点： - 6 大酒店改造 + 总府川宾/皇冠 等存量改造，周期长（每个 2-3 年） - 改造期间收入中断，改造后需要"快速恢复 + 提升" - RevPAR 比同地段竞品低 30%+，改造后能否提升是核心问题

AHL 解决方案： - 改造后立即接入 AHL，用 AI 能力提升入住率/复购率 - 改造期可作为"重资产改造+轻资产运营"样板 - AHL Agent 帮助新开业酒店"3 年爬坡到稳态"（缩短爬坡期）

存量改造 + AHL 联动：

改造项目 改造时间 AHL 接入计划
总府四川宾馆 2026/7-2027/5 改造期内完成 AHL 接入准备，2027/5 开业即上线
总府皇冠假日 联动项目 与总府川宾同步接入，共享 Agent
6 大酒店改造 2026-2028 滚动 改造一批、接入一批
其他存量酒店 滚动 按集团统筹安排

政策契合： - 《成都市城市更新条例》（历史建筑活化）+ 《锦江区设备更新补贴》（2026/12/31 到期）

合规检查： - 既有改造项目 + 新增运营服务（合规边界清晰） - 不涉及关联交易

预期效果（3 年）： - 总府川宾改造后 3 年达到 RGI ≥90%（vs 同地段市场均值） - 6 大酒店改造后 RevPAR 提升 20-30% - "改造 + AHL" 成为集团样板方法论

问题 9：整个集团体系化数字化运作

现状与痛点： - 集团没有统一数字化平台，各业态数据孤岛 - 缺乏统一的"客户 ID""门店 ID""产品 ID" - 数字化决策能力弱（依赖经验和人工报表） - 集团总部"看不见一线"

AHL 解决方案： - AHL 是集团数字化"底座"——Agent 既是客户触达工具，也是数据采集入口 - 通过 Agent 自然形成"统一客户 ID + 统一门店 ID + 统一产品 ID" - 数据沉淀到集团数据中台，支撑集团决策

集团数字化底座架构：

[客户触达层] AHL Agent 网络
   ↓ 数据回流
[数据中台] 集团统一数据平台
   ├─ 客户数据 (1,200 万会员 + 行为轨迹)
   ├─ 门店数据 (167 家 + 协议合作酒店)
   ├─ 产品数据 (房型 / 套餐 / 服务)
   └─ 经营数据 (入住率 / ADR / RevPAR)
   ↓ 数据应用
[决策支持] 集团 BI + AI 决策
   ├─ 收益管理建议
   ├─ 客户分层运营
   ├─ 单店经营预警
   └─ 战略决策支持

政策契合： - 国务院"国企数字化转型" + 国资委"对标世界一流管理提升"

合规检查： - 集团级数据资产管理需符合《数据安全法》 - 客户数据归属集团，使用需客户授权 - 可申请四川省数据资产入表试点

预期效果（3 年）： - 集团数字化覆盖从 <30% 提升到 90%+ - 决策周期从"周级"缩短到"日级" - 数据资产估值 ≥5 亿（合规入表）
