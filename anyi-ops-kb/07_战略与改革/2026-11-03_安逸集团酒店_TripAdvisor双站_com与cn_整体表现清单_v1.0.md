## 0. 必读：这份表里的「两个站」是什么关系

**先纠正一个可能的误解：这不是两份数据，是同一份资产的两个前端。**

| 事实 | 证据 |
|---|---|
| 两站共用同一 property ID 与同一点评池 | 天阅实证：`.com/Hotel_Feature-**g297463-d7007456**-zft1-Skytel_Hotel_Chengdu.html` 与 `.cn/Hotel_Review-**g297463-d7007456**-Reviews-Skytel_Hotel_Chengdu-Chengdu_Sichuan.htm` → **ID 完全一致**，均为 16 条点评 / 4.1 分 |

## 3. ★ 七个结构性发现

### 发现 1 ★ 双挂牌已经发生（不只是 Booking，猫途鹰也有）

| 物业 | 主 listing（有效） | 影子 listing（空壳/另一物业）|
|---|---|---|
| **安逸·新良** | `d455955` = 556 条 / 4.6 分 / 中文名「安逸·新良大酒店」 | `d34008514` = **0 条** / 4.6 分 / 英文名「CHENGDU XINLIANG HOTEL (CHUNXI ROAD TAIKOO LI)」 |
| **天阅** | `d7007456` = 16 条 / 4.1 / Skytel Hotel | `d1884916` = **3 条** / 4.0 / TIANYUE HOTEL (Motel) · 郫都区 |
| **锦江宾馆** | `d304961` = 8,827 条（主楼）| 东楼 = 47 条 / **5.0 分** 独立 listing |

**★ 后果**：同一物业两套评分、两套照片、两套评论 —— 权重被稀释，SEO 指向分散。
**★ 关键修正**：上一轮我说「郫都区那家是 Tavily 幻觉」—— **撤回这个撤回**。`.com` 侧确实存在独立的 `d1884916` Tianyue Hotel（3 条 / 4.0），**同名双店是真实的**，我上一轮纠正过头了。

### 发现 2 ★ 跨站排名不可直接比（分母口径差 3 倍）

| 物业 | .cn 排名池 | .com 排名池 | 差异 |
|---|---|---|---|
| 四川宾馆 | #99 / **4,367** | #97 / **1,456** | 分母差 **3.0 倍** |
| 锦江宾馆 | #8 / 4,367 | #7 / 4,364 | 一致 |
| 安逸158 顺城 | #1,252 / 4,367 | #1,385 / 1,488 | 不一致 |

**→ 结论**：TripAdvisor 的「城市酒店总数」随索引快照与筛选口径变化（本次跨 5 个查询就出现 1,450 / 1,456 / 1,488 / 4,263 / 4,364 / 4,367 六种分母）。**排名只能同站纵向比（谁比谁强），不能跨站横向比。** 唯一稳定可跨站的是**评分与点评总数**。

### 发现 3 ★ 点评资产的归属是三分态，不是两分态

| 状态 | 物业 | 点评量 | 含义 |
|---|---|---|---|
| **✅ 完全在手** | 花园 1,221 / 新良 556 / 四川宾馆 298 / 国堰 12 | ~2,100 条 | 账号控制权在安逸 → 可累积、可迁移、可授权 |
| **⚠️ 在品牌方** | 总府皇冠假日 4,546 | 4,546 条 | 账号在 IHG → **换牌时随品牌走，安逸拿不走** |
| **⚠️ 已剥离** | 四川锦江宾馆 8,827 + 东楼 47 | 8,874 条 | 2026/1 已划转省旅投 → **与安逸无关** |

**★ 全集团 TripAdvisor 点评总量 ≈ 15,500 条，但安逸真正可支配的只有约 2,100 条（13.5%）。**
**★ 而独立品牌里最大的那家（皇冠假日 4,546）恰恰不在自己手里。**

### 发现 4 ★★ 「锦江」品牌名存在撞名风险（战略级）

- **四川锦江宾馆**：8,827 条 / 4.9 分 / #8 of 4,364 —— **2026/1 已剥离至省旅投**
- 但它叫「锦江」，且是成都 TripAdvisor 排名前十的物业
- **安逸旗下同时有「锦江饭店管理公司」（旗下：锦江饭店五星 / 锦宾国际四星 / 锦著中端）**

**→ 若安逸以「锦江」系品牌对外做品牌输出或委托管理，将与省旅投体系下这家 8,827 条点评、4.9 分、成都 #8 的在先物业正面撞名。**
**→ 这条必须在十五五品牌矩阵定稿前解决**：要么避开「锦江」前缀对外拓展，要么先与省旅投确认品牌授权边界。

### 发现 5 ★ 英文品牌名有六种写法（阻碍国际搜索聚合）

| 写法 | 物业 |
|---|---|
| **ANYEE**（全大写）| Garden / YunQi / Wellness Resort |
| **Anyee**（首字母大写）| Xinliang Grand / Guoyan / 大邑 Anyee Hotel |
| **Anyue** | 安悦酒店（成都武侯祠店）|
| **An-e** | 安逸158 新鸿 / 人民公园 |
| **Anyi** | 安逸158 顺城 |
| **Anyi 158 Chain** | 攀枝花 |

**→ 同一母品牌在 TripAdvisor 上以 6 种英文拼写存在 → 国际搜索引擎无法把它们聚合成一个品牌实体，品牌搜索权重被稀释。**
**→ 且与 Booking/Agoda 上的「Skytel」「Tianyue」等第三方挂牌名进一步碎片化。**

### 发现 6 ★ 已关停资产仍在 OTA 留痕，并带「负分」

- **安逸158 新鸿店**：2.8 分「一般」，**#1,454 / 4,367**（成都倒数区间）
- **安逸158 顺城店**：3.0 分「一般」，**#1,385 / 1,488**
- **安悦酒店(武侯祠)**：0 条但页面在线

**→ 这些是 2026/6/30 已全部闭店的资产。OTA 上的低分页面仍在被国际客检索到并留下第一印象，同时集团品牌在 OTA 侧是「有实体、无正面」的形态。**

## 6. 建议的三件事（按投入产出排序）

1. **★ 先解「未认领」** —— ANYEE 云栖、ANYEE 康养、凯宾酒店三家未认领。认领是**零成本、立即生效**的动作，直接解锁点评回复 + 描述编辑 + 图片上传。**这是投入产出比最高的一步。**
2. **★ 统一英文品牌名** —— 6 种写法收敛为 1 种（建议 `ANYEE`），并同步 Booking / Agoda / 携程侧。**这是低成本、高杠杆的品牌基建。**
3. **★ 处理双挂牌 + 关停留痕** —— 新良的 `d34008514` 空壳 listing、锦江东楼独立 listing、158 系已闭店页面的低分，三类都需要 OTA 侧处置（合并/标注/下线）。

**另建议单独升级为集团议题**：与省旅投就「锦江」品牌在 OTA 与对外品牌输出上的边界做一次确认（见发现 4）。
