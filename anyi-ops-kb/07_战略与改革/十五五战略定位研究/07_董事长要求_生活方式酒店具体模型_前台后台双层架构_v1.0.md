> --- ## ⭐ 一句话核心模型 > **每个安逸生活方式酒店 = 1 个在地文化"前台"(非标空间) + 1 套集团"后台"(标准化专业支撑)。前台负责"看得见的体验", 后台负责"看不见的成本与品质"。空间永远是平台, 模块永远是产品, 文化永远是 IP, 内容永远是流量。** **本模型的明确定位 (Eric 9:13 校准)**: 这不是集团十五五规划的"战略模型", 而是**未来生活方式酒店的"类型方向"**——为改造 1-2 家标杆酒店提供"模块化组件库",后续按项目需求从中取用组合。复制不是 1:1 复制,**是在 6 大模块中找合适的功能板块进行组合**后得到项目模型。 展开三层: ```
┌──────────────────────────────────────────────────────┐
│ 第一层 · 前台 (酒店空间, 非标, 看得见) │
│ ├─ 1 个主话题 (在地文化的核心叙事) │
│ ├─ 1 个主厨 IP (在地食材 + 在地技艺) │
│ ├─ 3-5 个模块产品 (博物馆/画廊/手作/书店/剧场) │
│ └─ 客房 80-150 间 (在地主题 + 标准化基座) │
├──────────────────────────────────────────────────────┤
│ 第二层 · 中台 (集团能力, 半标准, 半共享) │
│ ├─ AHL 数字化平台 (PMS/CRS/Agent, Eric 已有沉淀) │
│ ├─ 集团收益管理 RM (统一调度, 不养在单店) │
│ ├─ 集团品牌矩阵 (5 类品牌, 差异化定位) │
│ ├─ 集团会员体系 (160 万会员共享) │
│ └─ 集团培训体系 (前台人员标准化输出) │
├──────────────────────────────────────────────────────┤
│ 第三层 · 后台 (专业化支撑, 完全标准化, 共享) │
│ ├─ 集团集采 (客用品/食品/工程, 降本 8-15%) │
│ ├─ 集团供应链 (在地特色产品全国调配) │
│ ├─ 集团工程 (改造方案 / 维护标准) │
│ ├─ 集团财务共享 (单店财务外包给集团) │
│ └─ 集团法务/合规 (单店审批合规标准化) │
└──────────────────────────────────────────────────────┘
``` **集团核心职责**:
- ❌ 不养专家 → 用专家 (文化艺术/文创/博物馆 各领域头部 IP 合作)
- ❌ 不做单店运营 → 做中台赋能 + 品牌输出 + 资源调配
- ✅ 做平台运营商 (前中后台之间的"连接器") --- ## 一、模型骨架:前台+后台双层架构 (深化) ### 1.1 为什么必须是"前台+后台"?(回应主席 8/14 第 6 段) 主席原话:
> "就是每一个酒店空间只是一个前台呃, 一个平台, 那后面呢, 你每个模块儿都是有专业化的来做。这样子呢, 就是把非前面看起来是非标台呃, 都是标准化的连锁化的来支撑。这样子既能体现出你空间的一个特色, 同时呢, 又可以调动各类专业的力量和这个压减我们的相关的成本啊, 这种模式你筹划一下。" **核心洞察**: 这是 Eric 8/13 行业访谈"数字化先行"的实体店版本 + 8/13 柏樾洽谈"数字化小合伙人平台"的延伸 ```
行业对标:
| 模型 | 代表 | 共同点 |
|---------------|---------------------|---------------------------|

| 数字化小合伙人 | Eric 8/13 提出 | 平台聚合碎片化专业能力 |
| 数字化先行 | Eric 8/13 行业访谈 | 数字化是品牌能力的根基 |
| 亚朵模式 | Eric 8/13 行业访谈 | App 标准化 + 技术反哺运营 |

| 松赞环线 | 国内标杆 | 在地文化前台 + 共享服务后台 |
| 亚朵 S 旗舰 | 国内标杆 | 书店+摄影+属地前台+集团后台 |
``` ### 1.2 前台非标 vs 后台标准的边界 | 维度 | 前台 (酒店做) | 后台 (集团做) | 中台 (集团+外部) |
|------|--------------|--------------|----------------|
| **空间设计** | 在地非标 (每个酒店不同) | 集团设计规范/标准 | 集团+外部设计机构 |
| **客房产品** | 在地主题房型 (30%) | 标准房型 (30%) + 套房标准 (20%) | 集团 SKU 库 |
| **餐饮产品** | 主厨 IP + 在地食材 (1+1) | 标准化供应链/食品安全 | 集团餐饮研发中心 |
| **公共空间** | 博物馆/手作/书店 (在地内容) | 家具/灯光/声学标准 | 集团+在地文化机构 |
| **人员** | 总经理+在地文化代表 | 标准化 SOP+培训 | 集团人力资源中心 |
| **营销** | 在地内容/IP 故事 | 集团品牌+会员 | 集团营销中心 |
| **收益** | 单店定价权 (在地季节) | 集团 RM + 中央预订 | 集团收益管理部 |
| **工程** | 在地材料/工艺 | 集团工程标准+集采 | 集团工程部 |
| **数据** | 单店客户体验 | 集团数据中台 + AHL | AHL 平台 |
| **合规** | 单店证照 | 集团法务共享 | 集团法务部 | → **前台保留 60-70% 的差异化能力, 后台集中 80-90% 的标准化能力** (Eric 8/13 "调动各类专业力量 + 压减成本" 的精确落地) ### 1.3 集团 vs 单店的成本分割(模型财务基础) ```
传统酒店集团成本结构 (标杆数据):
├─ 房租/折旧: 25-30%
├─ 人工: 30-35% (单店全配置)
├─ 食材物料: 18-22%
├─ 能源工程: 8-10%
├─ 营销: 5-8%
└─ 其他: 5% 本模型成本结构 (目标):
├─ 房租/折旧: 25-30% (维持)
├─ 人工: 22-28% (集团共享降 8-10pp)
├─ 食材物料: 14-18% (集团集采降 4pp)
├─ 能源工程: 8-10% (集团工程降本)
├─ 营销: 5-8% (内容驱动自然流量降本)
└─ 其他: 5-7% 人工节省来源 (单店 vs 集团共享):
├─ RM 收益管理: 1-2 人/店 → 集团 3-5 人/10 店 (节省 60%)
├─ 数字化/AHL: 1-2 人/店 → 集团 5-8 人/10 店 (节省 65%)
├─ 培训: 0.5 人/店 → 集团 2-3 人/10 店 (节省 70%)
├─ 工程: 0.5 人/店 → 集团 3-5 人/10 店 (节省 65%)
├─ 财务: 0.5 人/店 → 集团共享中心 (节省 70%)
├─ 法务: 0.2 人/店 → 集团共享中心 (节省 85%)
└─ 合计: 单店减少 4-5 人 → 10 店减 40-50 人 → 年省 800-1500 万
``` --- ## 二、客房配置模型 ### 2.1 客房总规模与体量 **黄金体量(对应 Eric 8/13 行业访谈的国际/国内对标)**: ```
体量: 1.5-2.0 万 ㎡ (建筑面积)
客房数: 80-150 间 (中位数 120 间)
房均面积: 35-55 ㎡ (中高端生活方式)
单房投资: 35-50 万 (改造) / 50-80 万 (新建)
``` **为什么是 80-150 间?**
- ✅ < 80 间: 单房成本过高, 后台共享难摊销
- ✅ 80-150 间: 国际/国内生活方式品牌标准体量 (voco/嘉悦里/Moxy/嘉轩/松赞/亚朵 S)
- ❌ > 150 间: 服务半径变长, 前台在地体验感被稀释 ### 2.2 客房四级产品结构 ```
┌─────────────────────────────────────────────────┐
│ 一家生活方式酒店客房分级 (120 间总规模) │
├──────────┬──────────┬──────────┬────────────────┤
│ 标准房 │ 主题房 │ 套房 │ 工作室套房 │
│ (30%) │ (40%) │ (20%) │ (10%) │
│ 36 间 │ 48 间 │ 24 间 │ 12 间 │
├──────────┼──────────┼──────────┼────────────────┤
│ 集团集采 │ 在地设计 │ 在地+升级 │ 长江老河豚模式 │
│ 标准化 │ 主题化 │ 体验化 │ 客房+工作室一体│

│ │ 1200 │ 2500 │ (含主厨餐/手作) │

``` | 类型 | 间数 | 占比 | 客均面积 | 价格区间 | 核心配置 | 集团标准化 |
|------|-----|------|---------|---------|---------|----------|
| **标准房** | 36 | 30% | 28-35 ㎡ | ¥500-800 | 床+卫浴+写字+在地元素点缀 | ✅ 100% 集采 |
| **主题房** | 48 | 40% | 35-45 ㎡ | ¥800-1200 | 在地文化主题墙画/家具/陈设/茶席 | 🟡 30% 集采 |
| **套房** | 24 | 20% | 55-75 ㎡ | ¥1500-2500 | 客厅+卧室+在地升级(主厨餐/手作/书房) | 🟡 20% 集采 |
| **工作室套房** | 12 | 10% | 75-120 ㎡ | ¥3000+ | 客房+工作室一体(艺术家/主厨驻店) | 🟢 全在地定制 | **关键设计**: **A. 标准房(30%) - 集团标准化基座**:
- 全集团统一 SKU 库 (床品/卫浴/家具/客用品)
- 在地元素仅作"点缀" (挂画/茶席摆件/在地书)
- 目标: 入住率最高的"基本盘", 用规模摊销后台成本 **B. 主题房(40%) - 在地文化核心**:
- 每个酒店不同主题 (国堰=水文化, 安逸茶山=茶文化, 总府=三国文化, 雅安=藏羌文化)

- 主题"换皮不换骨": 墙画/家具/灯光/陈设可更换, 客房格局不变
- 目标: 溢价主来源, 客群到访驱动力 **C. 套房(20%) - 体验升级**:
- 含主厨餐 / 手作体验 / 书房茶席
- 集团"主厨 IP 库"输出 (主厨可跨店走场)
- 集团"手作 IP 库"输出 (陶艺/扎染/茶道)
- 目标: 高 ADR, 高 NPS, 转介绍核心 **D. 工作室套房(10%) - 长江老河豚样板**:
- 客房 + 工作室 一体空间 (皇冠假日吴长江案例的升级版)
- 艺术家/手作人/茶人/作家可短期驻店 (1 周-1 月)
- 客人可观摩创作过程, 购买原创作品
- 集团"驻店 IP 计划" (类似 Airbnb 体验但更深度)
- 目标: 内容营销核心 (艺术家自带流量) ### 2.3 客房功能区创新 ```

| **客房送餐** | — | — | 5-10% | 标准化菜单 | ### 3.2 主厨 IP 体系 (集团共享) **主厨 3 层架构**: ```
[集团层]
├─ 集团餐饮总监 (1 人, 把控 10+ 店主厨质量)
├─ 主厨人才库 (20-30 名签约主厨)

``` **主厨 IP 化的 5 个动作**: 1. **名字 IP 化**: 每个酒店主厨有独立品牌名 (如"老河豚"工作室模式)

3. **驻店故事化**: 主厨背景/手艺/在地渊源做成故事传播
4. **媒体共创**: 与美食纪录片/小红书/抖音合作
5. **客座走场**: 主厨跨店走场, 增加话题度 ### 3.3 在地食材供应链 (集团集采) ```
[集团集采层 (60-70%)]
