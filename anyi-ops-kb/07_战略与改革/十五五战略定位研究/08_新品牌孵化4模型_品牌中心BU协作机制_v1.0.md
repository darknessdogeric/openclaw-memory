## ⭐ Eric 10:22 核心洞察

```
品牌中心的核心职能 = "推新品牌" + "管现有品牌" (双重角色)

[推新品牌] = 品牌 + 产品模型 + 运营模型 + 财务模型 (4 模型)
[管现有品牌] = 标准化品牌运营 (品牌策略/视觉/Slogan/品控)

→ 单一部门搞不定 → 必须 BU 协作 (4 BU + 4 中台/共享中心 联动)
→ 必须有"跨 BU 协调机制" (PMO + 品牌经理制度)
```

## 🎯 新品牌 4 大模型框架 (Eric 10:22 拍板)

### 4 模型详细定义

| 模型 | 内容 | 输出 | 主导 | 协作 |
|------|------|------|------|------|
| **品牌模型** | 品牌定位/视觉/Slogan/客户承诺/差异化 | 品牌手册 + VI + 主张 | 品牌产品中心 (8 人) | 4 BU 客户洞察 |
| **产品模型** | 客房/餐饮/公共空间/人员/摆放/经营 (本模型 6 大模块) | 产品 SOP + 设计规范 + 经营手册 | 在地文化生活方式 BU ⭐ | 旗舰 BU + 政务 BU |
| **运营模型** | BU 协作 + 集团共享服务 (RM/培训/品控/会员/营销) | 运营手册 + 共享服务协议 | 运营管理中心 (共享 53 人) | 4 BU 单店运营 + AHL |
| **财务模型** | IRR/GOP/回收期/客单价/投资强度/收入结构 | 财务测算 + 投资回报分析 | 财务共享中心 (27 人) | 4 BU + 中台 数据 |

### 4 模型不是"4 阶段",而是"4 维度"

```
旧认知: 4 模型 = 4 阶段 (品牌 → 产品 → 运营 → 财务) 顺序推进

新认知 (Eric 10:22): 4 模型 = 4 维度 (并行推进, 相互制约)
├─ 品牌模型定义"做什么"
├─ 产品模型定义"怎么做"
├─ 运营模型定义"谁来执行"
└─ 财务模型定义"赚不赚钱"

→ 4 模型必须**并行**而不是顺序
→ 任何一个模型不通过 = 整个新品牌不通过
```

## 🏛️ 跨 BU 协作机制设计 (核心架构)

### 机制 1:**新品牌项目委员会 (PMO)** ⭐⭐⭐⭐⭐

```
新品牌项目委员会 (PMO, 常设)
├─ 主席: 品牌管理公司总经理
├─ 委员 (4 + 4 + 1):
│ ├─ 4 个 BU 总经理 (在地文化/旗舰/政务/新业态)
│ ├─ 4 个中台/共享中心负责人 (品牌产品/数字化/在地文化/财务)
│ └─ 1 个品牌经理 (常设执行)
├─ 运作机制:
│ ├─ 季度评审 (战略层: OKR + 关键决策)
│ ├─ 月度执行 (BU 间协调 + 资源调配)
│ └─ 周报同步 (执行层对齐 + 进度)
└─ 输出:
 ├─ 新品牌孵化 OKR (季度滚动)
 ├─ 4 模型完整方案
 └─ 试点 + 标杆 + 复制推广节奏
```

### 机制 2:**品牌经理制度** ⭐⭐⭐⭐⭐

```
品牌经理 (Brand Manager) = 跨 BU 项目经理
├─ 角色定位:
│ ├─ 不属于任何单一 BU (跨 BU 角色)
│ ├─ 对新品牌孵化全流程负责
│ ├─ 协调 4 BU + 4 中台/共享中心
│ └─ 直接向品牌管理公司总经理汇报
├─ 关键能力 (4 模型对应):
│ ├─ 品牌策略 (品牌产品中心 8 人支持)
│ ├─ 产品设计 (本模型 6 大模块)
│ ├─ 运营协调 (4 BU 协作 + 共享服务)
│ └─ 财务测算 (财务共享中心支持)
├─ 编制:
│ ├─ 每个新品牌 1 个品牌经理
│ ├─ 集团新品牌孵化储备 2-3 个品牌经理
│ └─ 总编制 ~3 人 (精简)
└─ 关键产出:
 ├─ 新品牌 4 模型方案
 ├─ 试点酒店落地
 ├─ 标杆验证 + 复制推广
 └─ 品牌组合管理 (新品牌 + 现有品牌协同)
```

## 💡 Eric 10:22 揭示的 3 个关键洞察

### 洞察 1 — 中旅方案隐藏的"协调难题"

```
中旅 4 BU 化 = 业务单位独立运营
但 BU 之间没有横线沟通机制

推出新品牌 = 跨 BU 项目
→ 必须有协调机制

安逸集团 v1.4 必须补充: 跨 BU 协作层 = PMO + 品牌经理
```

### 洞察 2 — "推新品牌" 与 "管现有品牌" 是两套能力

```
[管现有品牌] = 标准化
├─ 品牌策略
├─ 视觉/Slogan
├─ 品控/审计
└─ 培训/SOP

[推新品牌] = 项目化
├─ 4 模型并行
├─ 跨 BU 协调
├─ 试点 + 复制
└─ PMO 治理

→ 必须分开,否则品牌中心被"双重角色"撕裂
→ 品牌产品中心 (8 人) = 管现有品牌
→ 品牌经理 (2-3 人) + PMO = 推新品牌
```

### 洞察 3 — 4 模型正好对应 4 中心 (中台+共享)

| 4 模型 | 4 中心 (中台/共享) |
|--------|---------------------|
| 品牌模型 | 品牌产品中心 (中台, 8 人) |
| 产品模型 | 在地文化中心 (中台, ~5 人) |
| 运营模型 | 运营管理中心 (共享, ~14 人) |
| 财务模型 | 财务集约中心 (共享, 27 人) |

**这就是为什么 BU 协作可行** — 每个模型都有对应的中台/共享中心能力,品牌经理是协调者,不是执行者。

```
├─ 改造标杆 1: 花园宾馆 (8/4 已立项)
├─ 改造标杆 2: 国堰宾馆 (8/8 v5.0 调研)

├─ 模块组合复制 (本模型 v1.2 逻辑)
├─ 推广到其他存量/改造项目
└─ 品牌授权给轻资产方
```
