## 摘要（1 页）

### 背景

安逸集团当前面临"三个不匹配"核心短板（资产与战略需求、产品与资产价值、机制与市场竞争），急需通过数字化手段实现集团赋能。集团"十五五"规划明确"1234"战略路径（一条主线/两大品牌/三大赛道/四步实施），其中**第四步"全方位市场化"必须以体系化数字能力为底座**。

### 核心命题

AHL 不是单一产品试点，而是**集团数字化基础设施**——通过垂系 Agent 网络，让集团 (52 家轻资产酒店 + 78,752 间管理房间, 十五五规划口径) + 旅投旗下多业态 + 协议合作酒店组成"数据喂养"正反馈循环，最终实现：
- 集团对单店**赋能 + 管控**双闭环
- 安逸品牌力**软升级**（不靠品牌加盟，靠"垂系 Agent 服务"差异化吸引业主）
- 旅投旗下**多业态横向联动**（住酒店→买景区票→坐天府号列车→消费餐饮）
- 集团**创新创收**（向行业输出"垂系 Agent 服务" SaaS 模式）

### 政策契合度

- 国家：**国务院国资委数字化转型 + 文旅融合战略 + 数据要素流通**
- 四川省：**"文化强省旅游强省" + 国有资本布局优化 + 数字经济**
- 成都市：**"国际消费中心城市" + 文商体旅融合 + 住宿业高质量发展**
- 监管合规：**三重一大决策程序 + 关联交易合规 + 数据安全法 + 个人信息保护法**

### 给董事长的 3 条核心建议

1. **试点先行**：2026/9-2027/12 完成 1-2 家内部 MVP 验证（建议总府川宾 + 总府皇冠联动项目）
2. **集团统筹**：AHL 试点由集团产业发展部牵头，避免子公司分散建设
3. **独立预算**：建议第一年投入 800-1,200 万（不到集团年度营收 0.1%），单设 AHL 专项预算

## 第一章 计划背景与战略定位

### 1.1 集团当前战略态势

**"三个不匹配"是核心短板**（《安逸十五五高质量发展规划》自我诊断）：

| 短板 | 具体表现 | 数据 |
|------|---------|------|
| **资产与战略需求不匹配** | 规模偏小 / 质量不优 / 效益薄弱 | 资产总额仅 35.51 亿元，2025 年净亏 -6,843 万元，闲置面积近 50% |
| **产品与资产价值不匹配** | 硬件老化 / 文化缺失 | RevPAR 比同地段竞品低 **30%+** |
| **机制与市场竞争不匹配** | 激励不活 / 效率不高 / 运营粗放 | 钖州公与市场脱节，决策链条长，会员运营未精准分层 |

**核心结论**：传统"重资产 + 粗放管理"路径已走到尽头，必须以"数字化能力 + 轻重分离"双轮驱动。

### 1.2 "1234"战略与 AHL 试点的呼应

集团"十五五"1234 战略：

```
"1" 一条主线    → 高质量发展（彻底退出低效同业竞争，全部新增投资与存量升级做"中高端"）
"2" 两大品牌    → 宸屿生活美学（文化标杆）+ 安逸生活方式（情感承接）
"3" 三大赛道    → 城市商务 / 文化主题 / 文旅度假
"4" 四步路径    → 轻重分离 → 打造标杆 → 品牌经营 → 全方位市场化
```

**AHL 试点与 1234 战略的映射**：

| 战略路径 | AHL 试点对应 |
|---------|------------|
| **轻重分离** | AHL 提供"垂系 Agent"差异化能力，让轻资产输出有竞争力 |
| **打造标杆** | AHL 试点选择总府川宾 + 集团内标杆项目，形成示范效应 |
| **品牌经营** | AHL 不强推"安逸"品牌，强推"垂系 Agent 服务"，避免品牌拉力不足 |
| **全方位市场化** | AHL 是集团数字化底座，无此则"市场化"是空话 |

### 1.3 AHL 项目本质重新定义

**关键洞察（基于 Eric 7/27 深度阐述 + B166ER 战略沉淀）**：

> AHL 不是再造一个 OTA，是**再造一个"触达层"**——让酒店拥有自己的关系链资产。

**AHL = 三层架构**：
```
L1 数据层    → 客户需求数据（用户主动表达 + Agent 语义理解）
L2 触达层    → 垂系 Agent 网络（精准匹配 + 主动推送）
L3 关系层    → 关系链资产（本地小B + 跨酒店互喂）
```

**AHL 的真正护城河**：**数据喂养的网络效应**——一个酒店 Agent 触达 → 数据反馈 → Agent 更精准 → 触达成本下降 → 更多酒店加入 → 更多数据喂养 → 正反馈循环。

**对集团的核心价值**：
- AHL 不是"做一个新产品"——**AHL 是集团数字化基础设施**
- AHL 试点成功 = 集团获得**未来 5-10 年差异化竞争力**
- AHL 试点失败 = 集团数字化滞后，未来被市场淘汰

### 1.4 计划的核心目标

**3 年试点路径（与 AHL 自身 5 阶段路径对齐）**：

| 阶段 | 时间 | 动作 | 验证指标 |

## 第三章 九大问题诊断与 AHL 解决方案（核心）

### 问题 1：集团向下属单店赋能及管控

**现状与痛点**：
- 78,752 间管理房间 + 52 家轻资产酒店分散在多个城市，集团总部"看得见但管不着"
- 单店经营数据靠人工报表，滞后且不准确
- 集团能力（收益管理 / 客户分析 / 采购 / 培训）难下沉到单店
- 单店遇到问题只能靠"电话指挥"，效率低

**AHL 解决方案**：
| 维度 | 具体动作 |
|------|---------|
| **数据回流** | Agent 自动采集单店经营数据（入住率 / ADR / 客户画像）回流集团中枢 |
| **能力下沉** | Agent 把集团收益管理建议实时推送给单店店长 |
| **统一管控** | 集团通过 Agent 看到所有单店实时经营仪表盘 |
| **应急响应** | Agent 自动预警经营异常（如 ADR 持续下滑）→ 集团介入 |

**政策契合**：
- 国资委"国企数字化转型"+ 四川省"国有资本布局优化"

**合规检查**：
- Agent 数据采集涉及客户隐私，需符合《个人信息保护法》
- 建议：数据脱敏 + 客户授权 + 集团数据合规审查

**预期效果（3 年）**：
- 集团对单店数据可见度从"周报滞后"提升到"实时可见"
- 单店收益管理建议接受率 ≥60%
- 集团应急响应时间从"天级"缩短到"小时级"

---

### 问题 2：安逸品牌力不足，业主单位不接受

**现状与痛点**：
- "安逸"品牌在中高端酒店市场认知度低（远不如华住/亚朵/锦江）
- 业主单位（持有物业方）不愿接受"安逸"品牌加盟
- 即使签约，业主也常要求"换牌"
- 品牌拉力不足导致集团轻资产输出受阻

**AHL 解决方案**：
- **不推"安逸"品牌，推"垂系 Agent 服务"**
- Agent 的差异化能力（精准触达 / 收益优化 / 客户复购）让业主看到**实际增值收益**
- 业主接受的不是"安逸"品牌，而是**"安逸的 AI 能力"**

**政策契合**：
- 文旅融合 + 中高端酒店升级 + 服务业模式创新

**合规检查**：
- 不是品牌加盟（合规风险低），是技术服务合作
- 建议：AHL 服务按"技术服务费"模式定价，避免被认定为"加盟"

**预期效果（3 年）**：
- 业主单位接受合作率从 ~20% 提升到 ~50%
- 协议合作酒店从 0 家 → 30-50 家
- 集团轻资产管理酒店目标（Eric 任后）：103 家（2026）→ 130 家（2028）

---

### 问题 3：旅投旗下及安逸旗下多业态横向联动

**现状与痛点**：
- 旅投集团旗下业态分散（酒店 / 景区 / 餐饮 / 交通 - 锦绣天府号等）
- 各业态会员体系孤立，客户无法跨业态享受服务
- 集团内协同弱，每个业态"各自为政"
- 数据不流通，无法形成"客户全旅程"视图

**AHL 解决方案（三层联动架构）**：

```
L1 数据层    → 统一客户 ID（打通酒店 + 景区 + 餐饮 + 交通）
L2 触达层    → Agent 主动推送（住酒店 → 推荐景区票 → 推荐天府号行程 → 推荐餐饮）
L3 关系层    → 跨业态关系链资产（一个客户在多个业态的消费轨迹）
```

**应用场景示例**：
- 客户 A 入住总府川宾 → Agent 推送"成都周边景区联票"
- 客户 B 在九寨沟游玩 → Agent 推送"下榻安逸酒店享 8 折"
- 客户 C 预订天府号列车 → Agent 推送"沿途酒店 + 餐饮"

**政策契合**：
- 四川省"文商体旅融合发展战略" + 成都市"国际消费中心城市"

**合规检查**：
- 涉及集团内**关联交易**（不同业态之间互相引流），需走合规审议
- 建议：制定《集团内业态联动管理办法》，明确分润机制

**预期效果（3 年）**：
- 跨业态客户转化率 ≥15%
- 客户全旅程价值提升 2-3 倍
- 集团内协同收入贡献 ≥ 3,000 万/年

### 问题 4：迅速扩充受众群体（会员联动）

**现状与痛点**：
- "安逸汇" 会员体系起步晚（目标 600 万，实际远低于此）
- OTA 替代率低（中央预订占比 < 10%，远低于 Eric 任后 25% 目标）
- 私域流量薄弱（公众号 / 小程序 / APP 用户活跃度低）
- 客户获取成本高，OTA 佣金 15-25% 持续侵蚀利润

**AHL 解决方案**：
- **Agent 作为统一会员接口**：让客户在不同业态（酒店 / 景区 / 餐饮）无缝切换
- **会员数据资产沉淀到集团**：所有 Agent 互动数据归属集团
- **私域流量池**：通过 Agent 把 OTA 客户转化为"安逸汇"会员

**目标路径**：

```
2026/12: 安逸汇会员 600 万 (集团目标)
   ↓ Agent 加速转化
2027/12: 安逸汇会员 800 万
   ↓ 跨业态联动
2028/12: 安逸汇会员 1,200 万 (含景区/餐饮/交通客户)
```

**政策契合**：
- 国务院"数据要素流通" + 国资委"国企数据资产管理"

**合规检查**：
- 客户数据归属：必须明确为"安逸集团"统一管理
- 数据使用：符合《数据安全法》《个人信息保护法》
- 数据资产化：可申请四川省数据资产入表试点（合规创新）

**预期效果（3 年）**：
- 安逸汇会员从 0 增长到 1,200 万

**避免分散**：不允许各子公司/各业态独立建设 AHL
**统筹内容**：
- 统一客户 ID 设计
- 统一数据中台架构
- 统一 Agent 标准
- 统一合规审查

**统筹价值**：
- 避免重复建设
- 数据流通共享
- 跨业态协同

### 建议 3：独立预算

**预算来源**：集团信息化专项 + 集团经营预算
**预算金额**：3 年合计 1,600-2,200 万
**预算管理**：单设 AHL 专项，季度审计，年度评估
**预算退出机制**：若阶段 0 不达预期，阶段 1 预算削减 50%；若阶段 1 不达预期，阶段 2 暂缓

**预算价值**：
- 不冲击集团核心业务预算
- 独立审计便于评估
- 灵活退出降低风险
