## 关键结论速读

### 一句话总结（7 份区域 + 2 视角）

1. **全国**：13 天超长窗口 + 奔县游顶流 + 中端韧性 + 量价均超预期 + 头部分化
2. **一线城市**：北京量价齐升 +30-55%；深圳过夜客流全国第二
3. **新一线城市**：成都提前订全国第 1；武汉江景房售罄；西安消费季启动
4. **下沉市场**：县城 +35% 同比；跨省客 70%；"反向旅游"已死
5. **西部+东北**：西部 +20% 至 +50%；东北"温和"反向避险
6. **成都单列**：酒店提前订热度 +75%；川西环线自驾 +50%
7. **四川省**：餐饮 +3%；二级城市数据缺口明显
8. **集团向**：亚朵 +44% 增速冠军；华住承压；国际酒店上调中国敞口
9. **行业向**："以价换量" 共识 + 中端领跑 + 奔县游结构变化
