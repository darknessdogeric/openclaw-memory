## 六、方案核心商业逻辑 ⭐

### 6.1 高 NOI × 低 Cap Rate = 估值最大化

```
核心洞察：服务式公寓估值逻辑的本质在于"风险溢价套利"
- 酒店运营复杂度高 → 周期波动大 → Cap Rate 7.3%
- 公寓类资产现金流稳定 → Cap Rate 6.5%
- 服务式公寓在保持酒店级 NOI 的同时享受公寓类 Cap Rate
- 估值提升 68%
```

### 6.2 三类业态对比（每间房·年）

| 业态类型 | 每间房年 NOI | RevPAR | Cap Rate | 估值（100 间）|
|---------|------------|--------|---------|-------------|
| **成都传统酒店** | 30,000 元 | ≈180 | 7.3% | **4,100 万** |
| 成都长租公寓 | 17,500 元 | 60-90 | 6.5% | 2,700 万 |
| **服务式公寓（自如资管）** | 30,000 元 | ≈120 | 6.5% | **6,900 万** |

### 6.3 关键估值逻辑

```
酒店估值 = NOI / Cap Rate = 30,000 / 7.3% = 4,100 万（100 间）
公寓估值 = NOI / Cap Rate = 30,000 / 6.5% = 6,900 万（100 间）

估值差额 = 6,900 - 4,100 = 2,800 万 = +68%

→ 通过业态改造（酒店→服务式公寓），同样 NOI 但 Cap Rate 更低
→ 资产估值提升 68%
→ 这是存量酒店盘活的核心方法论
```

## 八、退出路径与收益分配

### 8.1 三级退出体系

```
Pre-REITs（自如运营孵化）
   ↓ 积累标准化运营数据 + 稳定现金流
持有型不动产 ABS（部分退出，验证资产信用）
   ↓ 分散风险 + 市场预热
公募 REITs（最终退出，实现 40-60% 流动性溢价）
```

### 8.2 三方收益分配

| 主体 | 收益 |
|------|------|
| **四川旅投** | 资产估值提升（NOI × Cap Rate）+ 资产增值 + REITs 退出流动性溢价 40-60% |
| **合资公司** | 基础管理费（NOI × 6%）+ 超额分成（NOI >5% 部分分段累进：5.0-6.5% 提 10%、6.5-8.0% 提 15%、8.0%+ 提 20%）|
| **投资者** | REITs 份额投资 + 目标收益率 5-7% |

### 8.3 REITs 市场背景（2026.6 数据）

- 86 只公募 REITs，总规模超 2,300 亿
- **消费类 REITs 较 2024.3 基期 +65.6%**（涨幅最大）
- 保租房 +40.1%
- 产业园 -11.6%（跌）
- 仓储 -7.4%（跌）

**消费类 REITs 表现最优，与服务式公寓资产属性高度匹配**

## 十、对安逸集团的影响 ⭐⭐⭐ 关键议题

### 10.1 资产重合的可能性

> **如果四川旅投的 6 处资产中有部分实际是安逸集团现有资产**（如"四川宾馆""花园宾馆"可能业主不同），那么这个方案可能涉及：

1. **业主变更或合作重组**
2. **安逸现有资产被纳入 REITs 池**
3. **安逸集团作为合作伙伴进入合资公司**
4. **安逸集团被四川旅投吸收或被边缘化**

### 10.2 三种可能情景

| 情景 | 对安逸的影响 |
|------|------------|
| **A：四川旅投资产与安逸无重合** | 安逸可作为合作伙伴参与（轻资产模式）|
| **B：四川旅投资产是安逸现有资产** | 安逸需重新谈判租赁关系/分成模式 |
| **C：资产属同一物业但不同业主记录** | 需澄清权属关系，可能涉及法律/历史问题 |

### 10.3 安逸集团的潜在机会

- ✅ **轻资产输出**：安逸可作为"运营合作方"进入合资公司（参照雷迪森/金陵模式）
- ✅ **资管输出**：安逸"产业发展部"可参与项目全过程服务
- ✅ **战略协同**：1234 战略"轻重分离"与本方案高度契合（轻资产平台 + REITs 退出）

### 10.4 安逸集团的潜在风险

- ❌ **资产被边缘化**：如果四川旅投/自如/御昇华台联合运营，可能不需要安逸参与
- ❌ **业主话语权**：安逸作为可能的业主，需提前协调与四川旅投的分工
- ❌ **REITs 估值压力**：如果安逸资产被纳入 REITs，需达到估值 6,900 万/100 间（vs 现在酒店 4,100 万/100 间）的标准
