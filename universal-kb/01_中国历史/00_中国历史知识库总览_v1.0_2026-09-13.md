## 一、KB 范围定义

### 1.1 涵盖范围

```
时间维度: 上古(神话时代/三皇五帝) → 史前 → 夏商周 → 春秋战国 → 秦汉 → 三国两晋南北朝 → 隋唐五代 → 宋元明清 → 民国 → 中华人民共和国

空间维度: 中国历史疆域演变(汉地 / 边疆 / 朝贡体系 / 现代疆域)

内容维度: 政治 / 经济 / 文化 / 思想 / 科技 / 军事 / 社会 / 民族 / 外交 / 地理 / 制度 / 法律
```

### 1.2 不涵盖范围
- ❌ 中国以外的历史(单独 KB:世界历史)
- ❌ 当代时政评论(超出历史范畴)
- ❌ 个人项目偏好(不假设 Eric 立场)
- ❌ 集团内部数据(不绑定任何集团)

### 1.3 5 维认知(每个主题都按此结构)

```
1. 历史沿革 → 起源、演变、发展历程
2. 当下情况 → 该主题在 KB 中的现状、最新学术成果
3. 原因分析 → 为什么会这样(根因)
4. 未来预判 → 可能的研究方向、史料挖掘方向
5. 底层逻辑 → 支撑一切的原理和规律
```

## 八、限制与免责

### 8.1 历史观点的客观性
中国历史部分问题存在学术争议(如:
- 五德终始说 vs 历史循环论
- 资本主义萌芽问题
- 农民战争性质评价
- 民族关系评价
- 历史人物功过评价)

**处理原则**:
- 罗列主流学术观点,不强行选边
- 标注信源等级(正史/学术专著/通俗读物)
- 涉及敏感事件标注"学术争议中"
- 不假设 Eric 立场

### 8.2 史料的可信度
- 不同时代正史的客观性有差异(实录/起居注/正史/野史)
- 标注史料等级,优先正史 + 学术专著
- 考古发现可补充/修正正史(待补"考古专题")

### 8.3 意识形态敏感话题
- 涉及政治制度(如科举/封建/资本主义萌芽等)
- 涉及民族关系(如华夷之辨/民族融合)
- 涉及宗教(如三武灭佛/宗教冲突)
- 涉及对外关系(如朝贡体系/近代不平等条约)

**处理原则**:罗列学术观点,标注争议,不强行选边。
