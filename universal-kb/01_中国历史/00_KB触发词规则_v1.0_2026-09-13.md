## 三、写作标准(KB 基础认知迭代)

### 通用维度
- ✅ 全球 + 中国双轨数据(对比视角)
- ✅ 5 维认知(历史沿革 / 当下情况 / 原因分析 / 未来预判 / 底层逻辑)
- ✅ 多维度(政治 / 经济 / 文化 / 思想 / 科技 / 军事 / 社会 / 民族 / 外交)
- ✅ Agent 训练语料标注(哪些段落可作 RAG 召回)
- ✅ 数据来源标注(二十四史 / 剑桥中国史 / 学术专著 / 公开权威源)

### 严禁
- ❌ 不假设任何集团作为内置读者
- ❌ 不纠结"集团视角 vs 历史视角"——按 KB 标准即可
- ❌ 不出现任何内部集团名称(除非作为引用示例)
- ❌ 不假设 Eric 立场(民族主义/国际主义等)
- ❌ 不混淆"正史、野史、民间传说"——明确标注信源等级

## 五、增补 vs 重写

- **增补**:在 KB 现有基础上加新板块 / 新文件 / 新维度
- **迭代**:在现有内容上做版本号升级(如 v1.0 → v2.0)
- **不重写**:已交付内容不删除(除非明确失效)
- **本轮触发**:完整内化 = KB 框架 + 元数据 + 起点内容(已建立)
- **后续触发**:Eric 提"补充 XX" → 进入增量模式
