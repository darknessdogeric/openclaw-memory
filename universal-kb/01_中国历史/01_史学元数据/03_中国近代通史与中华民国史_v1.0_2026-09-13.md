## 一、为什么把这两套书放在一起

| 书名 | 覆盖时段 | 关系 |
|------|---------|------|
| 《中国近代通史》 | 1840—1949（110 年） | **通**：打通晚清-民国-近代 |
| 《中华民国史》 | 1912—1949（民国时期） | **专**：聚焦民国 |

两者互为补充：前者立框架，后者填细节。

## 二、《中国近代通史》

| 项目 | 内容 |
|------|------|
| 全称 | 《中国近代通史》 |
| 主编 | 张海鹏（中国社会科学院学部委员） |
| 出版 | 社会科学文献出版社 |
| 规模 | 10 卷，约 555 万字 |
| 修订版 | 2024 年发布 |
| 时间框架 | 1840（鸦片战争）→ 1949（中华人民共和国成立） |

### 2.1 学术突破

**① 打通三个传统分野**

```
传统分期:
  晚清史 (1840-1911)  |  民国史 (1912-1949)  |  现代史 (1949- )

本书分期:
  近代通史 (1840-1949)  ← 一个整体
```

- 打通"晚清史 + 民国史"
- 打通"近代史 + 现代史"
- 首次完整覆盖 1840-1949 整个 110 年

**② 学科意义**

- 构建新的中国近代史学科框架
- 被称为该领域 70 多年学科建设的**集大成之作**

### 2.2 十卷结构（示意）

| 卷 | 大致内容 |
|----|---------|
| 第 1 卷 | 近代中国进程的开端（1840-1864） |

| 第 3 卷 | 中法战争、甲午战争与民族危机 |
| 第 4 卷 | 戊戌变法与义和团运动 |
| 第 5 卷 | 清末新政与辛亥革命 |
| 第 6 卷 | 民国初年与北洋政府 |
| 第 7 卷 | 国民革命与南京国民政府建立 |
| 第 8 卷 | 抗日战争（上） |
| 第 9 卷 | 抗日战争（下）与战后 |
| 第 10 卷 | 解放战争与中华人民共和国成立 |

> 注：具体分卷名称与断限以 2024 修订版为准，上表为示意。

## 三、《中华民国史》

| 项目 | 内容 |
|------|------|
| 全称 | 《中华民国史》（多卷本） |
| 主持 | 中国社会科学院近代史研究所 |
| 出版 | 中华书局 |
| 规模 | 36 册 |
| 编纂启动 | 1956 年首次列入规划 |
| 正式立项 | 1971 年（周恩来总理指示） |
| 全部出齐 | 2011 年（辛亥革命百年） |
| **编纂历时** | **55 年（1956-2011）** |

### 3.1 体系构成

《中华民国史》系列实际包含三大部分：

| 部分 | 内容 |
|------|------|
| 中华民国史（正编） | 12 卷，政治军事主线 |
| 中华民国史大事记 | 逐年逐月大事 |
| 中华民国史人物传 | 人物传记 |

### 3.2 评价特点

- 对部分历史人物有**创新性评价**
- 例如对蒋介石在抗日战争中的地位和作用予以肯定
- 突破此前单一叙事框架

### 3.3 使用注意

- 官方立场与学术立场的平衡
- 涉及国共关系、抗战、内战，需并读多方史料
- 与台湾地区、海外学界的民国史研究互为参照

## 四、近代史分期争议（重要）

| 分期方案 | 断限 | 依据 |
|---------|------|------|
| **传统主流** | 1840—1919 | 以五四运动为界（旧民主主义→新民主主义） |
| **扩大方案** | 1840—1949 | 以中华人民共和国成立为界（《中国近代通史》采用） |
| **台湾学界** | 1840—1912 | 以清朝结束为界（近代=晚清） |
| **西方学界** | 1600/1800—1949+ | "early modern / modern China"框架 |

**说明**：这是**学术分期争议**，不同框架服务于不同问题意识。本 KB 采用 1840-1949 为主框架，并在具体章节标注其他分期的差异。

## 五、近代史关键节点（时间轴锚点）

| 年份 | 事件 | 意义 |
|------|------|------|
| 1840 | 鸦片战争 | 近代史起点 |
| 1842 | 南京条约 | 第一个不平等条约 |
| 1851-1864 | 太平天国 | 内部大动荡 |
| 1861-1895 | 洋务运动 | 自强求富 |
| 1894-1895 | 甲午战争 | 洋务破产，民族危机深化 |
| 1898 | 戊戌变法 | 制度改革尝试 |
| 1900 | 义和团与八国联军 | 庚子国变 |
| 1901 | 辛丑条约 | 半殖民地深化 |
| 1901-1911 | 清末新政 | 最后自救 |
| 1911 | 辛亥革命 | 帝制终结 |
| 1912 | 中华民国成立 | 共和肇建 |
| 1915-1916 | 袁世凯称帝失败 | 共和观念确立 |
| 1919 | 五四运动 | 思想启蒙高潮 |
| 1921 | 中国共产党成立 | 新政治力量 |
| 1926-1928 | 北伐 | 名义统一 |
| 1931 | 九一八事变 | 局部抗战开始 |
| 1937-1945 | 全面抗战 | 民族存亡之战 |
| 1945-1949 | 解放战争 | 政权更替 |
| 1949 | 中华人民共和国成立 | 近代史终点 |

## 七、使用规范

```
🟢 权威源: 《中国近代通史》《中华民国史》+ 官方档案
🟡 参考源: 剑桥中国史系列、海外中国学研究
🔴 慎用: 立场鲜明的通俗读物、回忆录(需交叉验证)
```

**敏感议题处理原则**：
- 涉及国共关系、抗战、内战 → 并列多方史料，标注立场
- 涉及外国势力 → 并读中方与外方档案
- 不做单一叙事，不强行选边
