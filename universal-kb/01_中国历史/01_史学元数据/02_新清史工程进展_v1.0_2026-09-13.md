# 新清史工程进展与清史研究现状

> KB: 中国历史知识库 | 分卷: 史学元数据 02 | 版本: v1.0 | 日期: 2026-09-13
> 信源等级: 🟢 正史级 + 🟡 学术专著

## 一、工程概况

| 项目 | 内容 |
|------|------|
| **正式名称** | 国家清史纂修工程（通称"新清史工程"） |
| **启动** | 2002 年，经中共中央、国务院批准 |
| **性质** | 重大国家文化学术工程 |
| **主持机构** | 国家清史编纂委员会 |
| **核心任务** | 编纂一部体例完备的大型《清史》 |
| **参与规模** | 汇集全国数十家高校与科研机构、数百位学者 |
| **当前状态** | 书稿编纂基本成形，**尚未通过最终审查** |

> ⚠️ **术语辨析**：此处"新清史工程"指中国官方的清史纂修工程，与英语学界"New Qing History（新清史）"学派是**两个不同概念**（见第五节）。

## 二、进展节点

| 时间 | 事件 |
|------|------|
| 2002 | 中央批准启动国家清史纂修工程 |
| 2002-2004 | 成立编纂委员会，确定体例与篇章结构 |
| 2004 起 | 各卷陆续进入撰写阶段 |
| 2010s | 主体书稿完成度提升，进入通稿与审改阶段 |
| 2023 | 点校本《清史稿》修订工程启动，纳入"十四五"规划 |
| 2025-03 | 中国社会科学院清史研究中心成立，继续推进 |
| 至今 | 书稿仍未通过最终审查、未正式出版 |

**2025 年定调**（官方表述）：要造就一支"党信得过、靠得住、用得上"的清史研究国家队。

## 三、基础性工作

### 3.1 档案整理

| 类别 | 规模 | 说明 |
|------|------|------|
| 清代档案整理 | 累计约 206 万件 | 中国第一历史档案馆为主 |
| 少数民族档案翻译 | 约 720 余万字 | 满文、藏文、蒙古文等 |
| 满文档案 | 大量 | 清代核心行政文书语言之一 |

### 3.2 点校本《清史稿》修订

- 2023 年启动，纳入国家"十四五"规划
- 任务：全面版本校勘、标点修订、文本比对
- 《清史稿》原为民国 1914-1927 年赵尔巽等编，1928 年刊印，536 卷
- 质量参差，史实错误与体例问题较多 → 修订必要

### 3.3 相关史料体系

| 史料 | 规模/价值 |
|------|----------|
| 清实录 | 4,400+ 卷，历朝实录 |
| 清史稿 | 536 卷（民国修） |
| 大清会典 | 康熙/雍正/乾隆/嘉庆/光绪五朝 |
| 方志 | 各省府县志 |
| 档案 | 宫中档、军机处录副、内阁大库等 |
| 满文老档 | 入关前史料 |
| 域外史料 | 朝鲜《李朝实录》、日本、俄国档案中的清代记载 |

## 四、《清史》编纂的难点

### 4.1 史料体量

- 现存清代档案约 2,000 万件（册）量级
- 远超此前任何朝代
- 多语种（汉、满、蒙、藏、维吾尔等）

### 4.2 时段特殊性

清朝是**中国传统王朝向现代国家转型**的关键期：
- 前期：传统王朝鼎盛（康雍乾）
- 中期：白莲教、太平天国、外患频仍
- 后期：洋务、变法、新政、立宪、革命
- 末端：与民国衔接（1912 清帝退位）

### 4.3 叙事张力

| 张力 | 说明 |
|------|------|
| 王朝叙事 vs 革命叙事 | 清史如何与辛亥革命、民国史衔接 |
| 民族关系 | 满汉、满蒙、满藏、满回等关系的评价 |
| 近代化评价 | 洋务/戊戌/新政的成效与局限 |
| 边疆治理 | 新疆、西藏、蒙古、东北、台湾的治理评价 |
| 中外关系 | 朝贡体系 → 条约体系 |

### 4.4 与前代正史的差异

- 二十四史：多为后朝为前朝修史（易代修史）
- 《清史》：本朝（延伸至当代）为前朝修史，且处"民族国家"话语下
- 因此争议更多，审定更审慎

## 五、"新清史"概念辨析（重要）

| 名称 | 指向 | 性质 |
|------|------|------|
| **国家清史纂修工程** | 中国官方《清史》编纂 | 中国国家学术工程 |
| **New Qing History（新清史）** | 1990s 起英语学界一个学派 | 学术流派 |

**"新清史"学派**（英语学界，罗友枝、柯娇燕、欧立德等为代表）要点：
- 强调清朝的"内亚性"（Inner Asian）而非纯"汉化"
- 重视满文档案与满洲认同
- 主张以"帝国"框架理解清朝

**中国学界反应**：
- 部分学者吸收其史料贡献（满文档案的运用）
- 部分学者批评其"去中国化"倾向
- **属学术争议领域，本 KB 并列陈述，不选边**

## 七、阅读与研究建议

### 7.1 入门路径

```
1. 《清史稿》(了解框架,注意其讹误)
2. 戴逸《简明清史》(中国学者通史视角)
3. 剑桥中国晚清史/剑桥中国清代前期史(西方视角)
4. 清实录选编(一手史料选)
5. 专题论著(按兴趣:制度/边疆/外交/经济)
```

### 7.2 使用注意

- 《清史稿》不等于《清史》，**新编《清史》尚未出版**
- 引用清代史实时，优先：档案 > 实录 > 会典 > 清史稿
- 涉及边疆、民族、中外关系，务必标注史料来源与学术立场
