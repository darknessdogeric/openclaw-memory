## 一、什么是"二十四史"

二十四史 = 中国古代 24 部纪传体正史的合称，上起传说中的黄帝（《史记》），下至明末崇祯（《明史》），共约 3,300 卷，约 4,000 万字。

**"正史"名义的来源**：
- 《隋书·经籍志》首立"正史"类，专收纪传体史书
- 清乾隆年间钦定二十四史，编入《四库全书》史部正史类 → 正式确立"二十四史"名目

## 三、版本源流

### 3.1 中华书局点校本（1958-1978）—— 现代通行本

- 顾颉刚、唐长孺、王仲荦等主持标点校勘
- 以百衲本等为底本，参校众本
- **目前学术界引用最广的版本**
- 时代局限：个别校勘有可商之处

### 3.2 点校本修订工程（2005 年起）

已出版修订本：《史记》《旧五代史》《新五代史》《辽史》《魏书》《南齐书》《宋书》《隋书》《金史》《梁书》《陈书》《北齐书》《周书》《南史》《北史》《明史》等。

仍在推进：《汉书》《后汉书》《三国志》《晋书》《旧唐书》《新唐书》《宋史》《元史》等。

### 3.3 其他重要版本

| 版本 | 时代 | 特点 |
|------|------|------|
| 百衲本 | 1930s 商务印书馆 | 影印宋元旧本，校勘价值高 |
| 武英殿本 | 清乾隆 | 官刻，通行但经改字 |
| 四库全书本 | 清乾隆 | 有删改（尤其涉及华夷表述） |
| 汲古阁本 | 明末毛晋 | 十七史合刻 |
| 金陵书局本 | 清同治 | 五局合刻二十四史 |

### 3.4 引用规范建议

```
🟢 学术引用 → 中华书局点校本(修订本优先)
🟡 一般查阅 → 中华书局点校本(原版)
🔴 网络检索 → ctext.org 等,须核对纸本
```

## 四、体例结构

纪传体 = 本纪 + 志 + 表 + 列传

| 部分 | 内容 | 示例 |
|------|------|------|
| **本纪** | 帝王编年大事 | 《史记·秦始皇本纪》 |
| **志** | 典章制度专篇 | 《汉书·食货志》《隋书·经籍志》 |
| **表** | 年表/世系表/人物表 | 《史记·十二诸侯年表》 |
| **列传** | 各类人物传记 | 《史记·货殖列传》 |

**局限**：
- 以帝王将相为中心 → 下层社会记载少
- 以政治军事为主 → 经济文化比重低
- 各史体例不一 → 有的缺表（《三国志》《梁书》），有的缺志

## 六、使用本 KB 时的引用规则

1. **优先正史原文**（🟢），其次学术专著（🟡）
2. 引用格式：`《书名》卷X·篇名`
3. 争议处标注学术派别
4. 考古材料可修正文献（甲骨文证商王世系、里耶秦简补秦制、敦煌文书补唐史）
5. 网络资料仅作线索，不作权威源
