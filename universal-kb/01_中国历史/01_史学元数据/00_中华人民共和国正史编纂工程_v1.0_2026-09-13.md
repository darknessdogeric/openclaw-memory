## 一、为什么这是"史学元数据"

中国历史 KB 的核心载体是**正史**。但正史本身是一部"被编纂的历史",有编纂主体、编纂过程、版本源流。

理解正史编纂工程 = 理解"我们今天读到的中国历史"是怎么来的 = 史学史 / 史料学的核心问题。

本文件汇总**中华人民共和国成立后官方主导的三大正史编纂工程**,作为中国历史 KB 的元数据。

## 二、清史编纂:国家工程,仍在进行

### 2.1 国家清史纂修工程概况

| 项目 | 内容 |
|------|------|
| **启动时间** | 2002 年 |
| **决定主体** | 中共中央 + 国务院 |
| **性质** | 重大国家文化学术工程 |
| **核心任务** | 编纂一部大型《清史》 |
| **主持机构** | 国家清史编纂委员会 |
| **参与规模** | 汇集全国众多学者 |

### 2.2 编纂进展(截至 2025 年)

- 主体编纂工作已持续近 20 年
- 书稿尚未通过最终审查
- 2025 年 3 月成立中国社会科学院清史研究中心,继续推进

**2025 年定调**:强调要"造就一支党信得过、靠得住、用得上的清史研究国家队"

### 2.3 相关基础工作

| 项目 | 内容 | 时点 |
|------|------|------|
| **点校本《清史稿》修订工程** | 全面版本校勘、标点修订、文本比对 | 2023 年启动,纳入"十四五"规划 |
| **清代档案整理** | 累计整理约 206 万件 | 持续 |
| **少数民族档案翻译** | 满、藏、蒙古等少数民族档案翻译 720 余万字 | 持续 |

### 2.4 《清史》编纂的复杂性

- 清朝史料浩繁(现存档案约 2000 万件/册)
- 涉及民族关系(满汉/满蒙/满藏/中央与边疆)
- 涉及近代转型(从传统王朝向现代国家转型)
- 涉及晚清与民国衔接(政治史/外交史/思想史)
- 涉及革命叙事与王朝叙事的张力

## 三、中国近代通史:体系成熟,成果丰硕

### 3.1 《中国近代通史》概况

| 项目 | 内容 |
|------|------|
| **全称** | 《中国近代通史》 |
| **修订版发布** | 2024 年 |
| **全书规模** | 10 卷 / 共 555 万余字 |
| **主编** | 张海鹏(中国社会科学院学部委员) |
| **出版机构** | 社会科学文献出版社 |

### 3.2 时间框架

```
传统近代史: 1840(鸦片战争) → 1919(五四运动)
本书扩展:   1840 → 1949(中华人民共和国成立)
```

**学术意义**:
- 首次完整覆盖 1840-1949 整个近代时期(110 年)
- 打通传统"晚清史 + 民国史"分野
- 打通"近代史 + 现代史"分野
- 构建全新中国近代史学科框架
- **该领域 70 多年来学科建设的集大成之作**

### 3.3 主要研究机构

- 中国社会科学院近代史研究所(主导)
- 各大高校历史系
- 各省社会科学院

## 四、中华民国史:历时数十载,已成经典

### 4.1 《中华民国史》概况

| 项目 | 内容 |
|------|------|
| **全称** | 《中华民国史》(多卷本) |
| **编纂启动** | 1956 年(首次列入规划) |
| **正式立项** | 1971 年(周恩来总理指示) |
| **主持机构** | 中国社会科学院近代史研究所 |
| **出版机构** | 中华书局 |
| **全书规模** | 36 册 |
| **全部出齐** | 2011 年(辛亥革命百年纪念) |

### 4.2 编纂特点

- 历时 55 年(1956-2011)
- 评价有所创新和突破(如肯定蒋介石在抗日战争中的地位和作用)
- 是民国史研究的集大成之作

### 4.3 与《中国近代通史》的关系

- 《中华民国史》:专注 1912-1949 民国时期
- 《中国近代通史》:覆盖 1840-1949 整个近代
- 两者互为补充,前者专,后者通

## 五、三大工程的整体意义

### 5.1 时间线串联

```
1956   ─── 《中华民国史》编纂首次列入规划
1971   ─── 《中华民国史》正式立项
2002   ─── 国家清史纂修工程启动
2011   ─── 《中华民国史》36 册全部出齐
2023   ─── 点校本《清史稿》修订工程启动
2024   ─── 《中国近代通史》修订版发布
2025   ─── 中国社会科学院清史研究中心成立,清史纂修继续推进
```

### 5.2 学术体系意义

| 维度 | 价值 |
|------|------|
| **史料** | 累计整理清代档案 206 万件 + 翻译少数民族档案 720 万字 |
| **史学** | 构建 1840-1949 完整近代史框架 |
| **评价** | 突破传统叙事,对部分历史人物有创新评价 |
| **方法** | 形成"国家工程 + 学术机构 + 学者参与"的中国式正史编纂模式 |

### 5.3 与二十四史的关系

```
二十四史(传统正史):
- 时间跨度: 黄帝 → 明(约 4000 年)
- 数量: 24 部
- 编纂主体: 历朝官方 + 后世整理

中华人民共和国正史工程(现代正史):
- 覆盖: 清史(待完成) + 近代史(已完成) + 民国史(已完成)
- 编纂主体: 国家 + 学术机构 + 学者
- 特点: 学术化 + 公开化 + 持续修订
```
