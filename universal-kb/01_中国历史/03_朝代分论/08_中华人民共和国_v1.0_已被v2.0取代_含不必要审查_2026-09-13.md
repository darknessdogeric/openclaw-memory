## 一、分期与时间轴

### 1.1 按制度—经济演进的分期（本卷框架）

| 分期 | 起止 | 制度—经济主线（仅陈述事实） |
|------|------|------------------------------|
| **一、建国与过渡期** | 1949–1957 | 新民主主义经济 → 社会主义改造；土地改革；第一个五年计划；1954 年宪法 |
| **二、探索与曲折期** | 1958–1977 | 人民公社化；计划经济体制全面建立；三线建设；国民经济调整 |
| **三、改革开放起步期** | 1978–1992 | 家庭联产承包责任制；经济特区；有计划的商品经济；计划与市场双轨 |
| **四、市场经济体制确立期** | 1993–2001 | 社会主义市场经济体制目标确立；财税、金融、国企改革；加入 WTO |
| **五、全面发展期** | 2002–2012 | 全面深化改革的前期铺垫；加入 WTO 后外贸高速增长；城镇化加速；社会保障体系扩展 |
| **六、新时代期** | 2013– | 全面深化改革；供给侧结构性改革；脱贫攻坚完成；新发展格局；"一带一路" |

🟡 分期为学术通行的制度—经济分段方式，非唯一标准；不同研究对第二、三期的内部再分存在差异。

## 二、宪法与法律制度沿革

### 2.1 四部宪法

| 宪法 | 通过时间 | 主要制度内容（陈述性） |
|------|---------|------------------------|
| **1954 年宪法** | 1954 年 9 月 | 第一部社会主义类型宪法；确立人民代表大会制度、民族区域自治制度 |
| **1975 年宪法** | 1975 年 1 月 | 在特定历史条件下制定，条文大幅简化 |
| **1978 年宪法** | 1978 年 3 月 | 部分恢复 1954 年宪法的制度安排 |
| **1982 年宪法** | 1982 年 12 月 | **现行宪法**；重新确立国家机构的制度框架 |

🟢 四部宪法的通过与文本见《中华人民共和国宪法》历次版本（全国人民代表大会公布）。1949–1954 年间，《中国人民政治协商会议共同纲领》起临时宪法作用。

### 2.2 现行宪法的历次修正

| 修正案 | 年份 | 涉及的主要制度内容 |
|--------|------|--------------------|
| 第一次 | 1988 | 私营经济的法律地位；土地使用权可以依照法律的规定转让 |
| 第二次 | 1993 | "社会主义初级阶段"表述；"国家实行社会主义市场经济" |
| 第三次 | 1999 | "依法治国，建设社会主义法治国家"；基本经济制度表述 |
| 第四次 | 2004 | "国家尊重和保障人权"；私有财产保护；"三个代表"重要思想入宪 |
| 第五次 | 2018 | 国家机构相关制度调整；"习近平新时代中国特色社会主义思想"入宪 |

🟢 修正案内容见全国人民代表大会历次公布文本。

### 2.3 人民代表大会制度

- **1954 年**第一届全国人民代表大会召开，制度正式确立；此前由中国人民政治协商会议第一届全体会议代行职权 🟢。
- 全国人民代表大会为最高国家权力机关，行使立法权；其常设机关为全国人大常委会 🟢。
- 人大代表选举实行间接选举与直接选举相结合的分层结构 🟢。
- 地方各级设人民代表大会与人民政府 🟢。

### 2.4 政治协商制度

| 阶段 | 事项 |
|------|------|
| 1949 | 中国人民政治协商会议第一届全体会议召开，通过《共同纲领》，代行全国人大职权 |
| 1954 | 全国人大召开后，政协作为统一战线组织继续存在 |
| 1993 | 宪法修正案将"中国共产党领导的多党合作和政治协商制度将长期存在和发展"写入序言 |

🟢 见《中国人民政治协商会议章程》与宪法序言。

### 2.6 法律体系的形成

| 阶段 | 主要立法里程碑 |
|------|---------------|
| 1950 年代 | 《婚姻法》（1950）、《宪法》（1954）等基础法律出台 |
| 1979 | 刑法、刑事诉讼法、选举法等七部法律一次通过 |
| 1980 年代 | 《民法通则》（1986）、《行政诉讼法》（1989） |
| 1990 年代 | 《公司法》《合同法》《行政处罚法》《刑法》修订等 |
| 2000 年代 | 《物权法》（2007）、《行政许可法》（2003） |
| 2010 | 官方宣布"中国特色社会主义法律体系形成" 🟢 |
| 2011 年后 | 《民法典》编纂（2020 年通过，2021 年施行）🟢 |

🟢 立法年份见全国人民代表大会及其常委会公布的法律文本。

### 2.7 司法与监察体制沿革

| 年份 | 制度节点 |
|------|---------|
| 1949–1954 | 最高人民法院、最高人民检察署设立（1954 年改称最高人民检察院）|
| 1954 | 宪法确立人民法院、人民检察院的组织地位 |
| 1979 | 恢复人民法院与人民检察院的正常工作；《人民法院组织法》《人民检察院组织法》通过 |
| 1982 | 宪法规定人民法院、人民检察院依法独立行使审判权、检察权 |
| 1989 | 《行政诉讼法》通过，行政诉讼制度建立 |
| 1995 | 《检察官法》《法官法》通过，职业化制度建设 |
| 2003 | 《行政许可法》（2004 年施行），行政程序规范 |
| 2014 | 司法体制改革试点推进（法官员额制等）|
| 2018 | 国家监察委员会设立，监察体制调整（宪法修正案配套）|

🟢 机构沿革见《中华人民共和国人民法院组织法》《人民检察院组织法》及宪法相关条文。

| 层级 | 形式 |
|------|------|

| 地方性法规 | 省、自治区、直辖市等人大及其常委会制定 |

## 三、经济体制变迁

### 3.1 土地制度的三次大变动

| 阶段 | 时间 | 制度内容 |
|------|------|----------|
| 土地改革 | 1950–1952（1953 年基本完成） | 废除封建土地所有制，将土地分配给农民个体所有；《土地改革法》（1950）🟢 |
| 农业合作化 | 1953–1956 | 从互助组→初级农业生产合作社→高级社；1956 年底基本完成 🟢 |
| 人民公社化 | 1958–1983 | 1958 年起推行"政社合一"的人民公社；1983 年后实行政社分开，公社体制终止 🟢 |
| 家庭联产承包责任制 | 1978 年起 | 1978 年安徽等地出现包产到户；1982–1984 年在全国推广，土地集体所有、家庭承包经营 🟢 |
| 土地承包关系稳定 | 1984 年起 | 第一轮承包期 15 年；1993 年后明确再延长 30 年；2002 年《农村土地承包法》颁布 🟢 |

### 3.2 计划体制的建立与调整

| 阶段 | 制度形态 |
|------|----------|
| 1953–1957 | 第一个五年计划；统购统销；生产资料计划调配 |
| 1958–1960 | 计划指标大幅提高；人民公社化 |
| 1961–1965 | 国民经济调整期（"八字方针"）；部分恢复自留地与集市贸易 |
| 1966–1976 | 计划经济体制延续，三线建设推进 |
| 1978 后 | 指令性计划逐步缩减，指导性计划与市场调节比重上升 |

### 3.3 所有制结构变迁

| 时期 | 所有制格局（陈述性） |
|------|--------------------|
| 1949–1952 | 国营经济、合作社经济、个体经济、私人资本主义经济、国家资本主义经济并存（《共同纲领》表述）|
| 1956 后 | 公有制（全民所有制、集体所有制）占绝对主体 |
| 1978 后 | 个体经济恢复；1988 年宪法确认私营经济；1999 年宪法修正案表述为"公有制为主体、多种所有制经济共同发展" |
| 2000 后 | 混合所有制、股份制改革推进；民营经济规模扩大 |

### 3.4 改革开放的制度节点

| 年份 | 节点 |
|------|------|
| 1978 | 十一届三中全会，工作重心转向经济建设 🟢 |
| 1980 | 经济特区设立（深圳、珠海、汕头、厦门）🟢 |
| 1984 | 十四个沿海港口城市开放；《关于经济体制改革的决定》提出"有计划的商品经济" 🟢 |
| 1988 | 海南建省并设经济特区；"沿海地区经济发展战略" |
| 1990 | 上海浦东开发开放 🟢 |
| 1992 | 十四大提出"建立社会主义市场经济体制" 🟢 |
| 1993 | 十四届三中全会通过《关于建立社会主义市场经济体制若干问题的决定》；宪法修正案写"社会主义市场经济" |
| 1994 | 分税制财政管理体制改革；汇率并轨；外贸体制改革 |
| 1999 | 国有企业改革与"抓大放小"、股份制改造推进 |
| 2001 | 加入世界贸易组织（12 月 11 日生效）🟢 |
| 2003 | 国务院国资委成立；国有资产管理体制改革 |
| 2013 | 十八届三中全会《关于全面深化改革若干重大问题的决定》🟢 |
| 2015 | 供给侧结构性改革提出 |

## 九、学术讨论（并列观点，不选边）

### 9.1 改革路径：渐进 vs 激进

⚠️ **学术争议**
- **观点A（渐进论）**：主流研究认为中国改革采取"增量改革""双轨制""摸着石头过河"的渐进路径，先在体制外培育增量（乡镇企业、特区、个体私营），再渐进改造存量，降低了转轨成本（林毅夫、罗纳德·科斯等中外学者均有相关论述）。
- **观点B（结构条件论/非意图论）**：部分学者（如巴里·诺顿等在综述中归纳的立场）指出，渐进过程本身包含多次"突变式"制度替换（如 1994 分税制、1990 年代国企改制），且改革路径受初始条件、财政压力与外部环境约束，"渐进"更多是事后叙事。
- **折中**：多数研究承认路径存在阶段差异——1980 年代偏增量，1990 年代偏存量重构。

### 9.2 乡镇企业的作用

⚠️ **学术争议**
- **观点A**：乡镇企业在 1980–90 年代吸收了大量农村剩余劳动力，推动了农村工业化与地方财政增长，是渐进转轨的关键载体。
- **观点B**：乡镇企业具有产权模糊、政企不分的过渡性特征，其在 1990 年代后期的改制与收缩，说明其制度生命力有限，作用是阶段性的。
- 两派共同承认其历史地位，分歧在**长期制度意义**。

### 9.3 民营经济的角色

⚠️ **学术争议**
- **观点A**：民营经济在就业、税收、创新与出口中占比高（官方与学术统计口径均显示"56789"式结构，具体比例随年份变动），是市场化改革的主要受益者与推动者。
- **观点B**：研究强调民营经济的成长高度依赖地方政府竞争、金融资源配置与政策不确定性，其发展轨迹并非线性，受宏观周期与制度环境显著影响。
- 分歧主要在**因果关系方向**（民营经济推动市场化，抑或市场化条件催生民营经济）。

### 9.4 区域发展差异

⚠️ **学术争议**
- **观点A（要素集聚论）**：沿海地区因区位、政策试点与外资流入形成集聚效应，区域差距在 1990 年代扩大，符合发展经济学的一般规律。
- **观点B（政策配置论）**：差异与 1978 年后开放政策的梯度安排、财政与投资资源配置密切相关，政策变量不可忽视。
- **政策事实（陈述性）**：2000 年后陆续实施西部大开发（2000）、振兴东北（2003）、中部崛起（2006）等区域战略；2010 年代后区域差距的扩大速度出现变化 🟡（具体测度存在不同结论）。

### 9.5 人口政策的社会经济影响

⚠️ **学术争议**
- **观点A**：计划生育政策显著降低了生育率，缓解了人口对资源与就业的压力，为 1980–2010 年的高速增长提供了"人口红利"条件（部分经济学研究持此论）。
- **观点B**：研究指出该政策加速了人口老龄化与出生性别比失衡，长期看对劳动力供给、养老与家庭结构产生持续影响；亦有学者质疑"人口红利"归因于单一政策的因果强度。
- **共同事实**：总和生育率自 1970 年代起持续下降，2020 年第七次普查为 1.3 左右（官方公布口径）🟢；人口政策自 2013 年起逐步调整。

### 9.6 其他讨论议题

| 议题 | 观点并列 |
|------|---------|
| 1978 年前的工业化成就 | 观点A：建立了独立完整的工业体系与基础设施；观点B：代价与结构失衡同样显著 🟡 |
| 三线建设的评价 | 观点A：改善工业布局、增强国防能力；观点B：投资效率低、区位成本高 🟡 |
| 国企改革效果 | 观点A：提升效率、扭亏为盈；观点B：伴随下岗与资产处置问题 🟡 |
| 出口导向模式的可持续性 | 观点A：融入全球分工的比较优势路径；观点B：外部依赖与结构脆弱性 🟡 |
| 城镇化速度与质量 | 观点A：规模空前的城镇化进程；观点B：户籍—公共服务—土地制度之间的张力 🟡 |
