## 一、为什么需要方法论层

任何历史叙述都是"**史料 + 解释框架**"的产物。同一组史料，用不同框架会得出不同结论。

本 KB 的原则：
- **史实层面**：尽可能贴近史料（考古 + 文献 + 档案三重印证）
- **解释层面**：并列不同框架，不假装有唯一答案

## 二、史料学（Source Criticism）

### 2.1 史料分类

| 类别 | 定义 | 举例 | 可信度 |
|------|------|------|--------|
| **实物史料** | 无文字的物质遗存 | 遗址、墓葬、器物、建筑 | 高（但解释空间大） |
| **出土文献** | 考古发现的文字材料 | 甲骨文、金文、简牍、敦煌文书 | **高**（未经后世改动） |
| **传世文献** | 历代传抄刊刻的文献 | 二十四史、诸子、文集 | 中（有传抄改动） |
| **档案** | 官方行政原始记录 | 明清档案、民国档案 | **高**（但含官方立场） |
| **方志** | 地方志书 | 各省府县志 | 中（地方视角，质量参差） |
| **碑刻** | 石刻文字 | 墓志、功德碑 | 高（但多溢美） |
| **口述** | 口头回忆 | 回忆录、访谈 | 低-中（记忆偏差） |
| **报刊** | 近代新闻 | 申报、大公报 | 中（需辨析立场） |
| **域外文献** | 外国人所记 | 朝鲜实录、日本僧记、西人游记 | 中（外部视角，含偏见） |

### 2.2 四步辨伪法

```
1. 外证(外部考证)  → 该文献在其他独立来源中是否被提及/印证?
2. 内证(内部考证)  → 文献自身是否自相矛盾? 语言/制度/职官是否合于所标年代?
3. 版本学         → 版本源流是否清晰? 有无后世增改?
4. 二重证据法     → 出土材料与传世文献是否互相印证?(王国维首倡)
```

### 2.3 关键方法论概念

| 概念 | 提出者 | 内容 |
|------|--------|------|
| **二重证据法** | 王国维 | 地下新材料与纸上材料互证 |
| **古史辨（疑古）** | 顾颉刚 | "层累地造成的中国古史"——古史越晚记载越详细 |
| **走出疑古时代** | 李学勤 | 考古发现支持部分古史记载可信 |
| **三重证据法** | 饶宗颐等 | 文献 + 考古 + 人类学/民俗学材料 |
| **史源学** | 陈垣 | 追溯每个史实的原始出处 |

### 2.4 **"疑古 vs 信古"之争**

- **观点 A（疑古派）**：先秦文献多经后世改造，"三皇五帝"系统是战国秦汉逐步层累建构的；夏朝缺乏当时文字自证
- **观点 B（信古/走出疑古）**：甲骨文证实《史记·殷本纪》商王世系基本可靠，说明司马迁有可靠来源；考古（二里头等）支持夏文化存在
- **（学术争议：观点 A vs 观点 B）**
- 本 KB 处理：传说时代一律标注 ⚠️，商以前标"传说/待考"

### 2.5 史料陷阱（常见错误）

| 陷阱 | 说明 |
|------|------|
| 以后世概念套古代 | 如用"民族国家""封建"直接对应古代制度 |
| 以孤证立论 | 单条史料推出大结论 |
| 数字迷信 | 古代军队人数、人口数字多为夸张，需交叉验证 |
| 胜利者叙事 | 正史多成于后朝，含合法性建构 |
| 时代错置 | 把晚出的记载当作当时实录 |

## 三、中国史学传统

### 3.1 史官制度

| 时期 | 形态 |
|------|------|
| 先秦 | 史官（左史记言、右史记事）；"书法不隐"传统 |
| 汉 | 太史令；起居注 |
| 唐 | 设史馆，宰相监修（官修制度化）；起居注、日历、实录 |
| 宋 | 实录院、国史院、会要所 |
| 明清 | 翰林院、起居注馆、实录馆、方略馆 |

### 3.2 史书体例

```
纪传体（以人为主）→ 二十四史
编年体（以时为主）→ 春秋、资治通鉴
纪事本末体（以事为主）→ 通鉴纪事本末
典志体（以制度为主）→ 通典、文献通考
方志体（以地为主）→ 各省府县志
史评体（以论为主）→ 史通、文史通义
```

### 3.3 史学名著

| 书名 | 作者 | 地位 |
|------|------|------|
| 史通 | 刘知幾（唐） | 第一部史学理论专著 |
| 文史通义 | 章学诚（清） | "六经皆史"，史学理论高峰 |
| 廿二史札记 | 赵翼（清） | 比较史学典范 |
| 十七史商榷 | 王鸣盛（清） | 考据 |
| 观堂集林 | 王国维 | 二重证据法实践 |

### 3.4 近现代史学流派

| 流派 | 代表 | 特点 |
|------|------|------|
| 古史辨派 | 顾颉刚 | 疑古 |
| 史料学派 | 傅斯年 | "史学即史料学" |
| 新考据 | 陈垣、陈寅恪 | 史源学、以诗证史 |
| 唯物史观派 | 郭沫若、翦伯赞、范文澜 | 社会形态分期 |
| 社会经济史 | 梁方仲、傅衣凌 | 明清经济 |
| 年鉴学派（影响） | 布罗代尔等 | 长时段、总体史 |
| 新文化史 | 海外中国学 | 日常生活、微观史 |

## 四、历史哲学：解释框架

### 4.1 传统框架

| 框架 | 内容 | 代表 |
|------|------|------|
| **循环论** | 治乱循环、五德终始 | 邹衍、孟子"一治一乱" |
| **正统论** | 谁代表正统 | 历代争论（蜀汉 vs 曹魏等） |
| **进化论** | 从低级到高级 | 严复引入天演论后 |
| **唯物史观** | 生产力—生产关系—上层建筑；五种社会形态 | 马克思主义史学 |
| **现代化范式** | 从传统社会向现代转型 | 战后美国中国学 |
| **革命史范式** | 以阶级与革命为线索 | 中国近代史主流（20 世纪） |
| **中国中心观** | 从中国内部逻辑理解中国 | 柯文（Paul Cohen） |
| **内亚史观** | 重视草原/内亚维度 | 拉铁摩尔、新清史 |

### 4.2 关键争论

**① 中国历史分期之争**

- **观点 A（五种社会形态说）**：原始→奴隶→封建→资本主义萌芽→半殖民地半封建→社会主义
- **观点 B（质疑分期）**：五阶段论是欧洲经验的外推，中国"封建社会"与欧洲 feudalism 不同质；分期本身是分析工具而非史实
- **（学术争议：观点 A vs 观点 B）**

**② 唐宋变革论**

- **观点 A（内藤湖南）**：唐宋之间是根本性变革（贵族政治→君主独裁、庄园→佃户、中世→近世）
- **观点 B（批评者）**：变革是渐进的，唐宋连续性大于断裂；"近世"起点说不成立
- **（学术争议：观点 A vs 观点 B）**

**③ 大分流（Great Divergence）**

- **观点 A（彭慕兰）**：1800 年前江南与英格兰发展水平相当，分流源于煤与新大陆的偶然因素
- **观点 B（黄宗智等）**：明清中国陷于"内卷化"（过密化），劳动生产率未实质提高，早已落后
- **（学术争议：观点 A vs 观点 B）**

**④ 资本主义萌芽**

- **观点 A**：明中后期江南已有资本主义萌芽（雇佣劳动、工场手工业）
- **观点 B**：该概念是后设框架，中国经济发展路径不同，不需以"萌芽未成长"解释
- **（学术争议：观点 A vs 观点 B）**

**⑤ 后现代史学挑战**

- **观点 A**：历史叙述是文本建构，不存在完全客观的"如实直书"
- **观点 B**：史料约束是真实的，不能因叙述性而否认史实的存在（否则滑向虚无）
- **（学术争议：观点 A vs 观点 B）**

## 五、本 KB 的使用原则

```
1. 史实层: 尽量贴史料,考古+文献+档案互证
2. 数字层: 古代数字标"估算/学界争议",近代数字给出处
3. 解释层: 并列框架,不假装唯一答案
4. 人物评价: 列不同学术评价,不做道德裁判
5. 敏感议题: 并列多方史料与学术观点,不选边
6. 传说 vs 信史: 传说一律标 ⚠️
```

**引用格式建议**：
```
🟢 《史记》卷六《秦始皇本纪》
🟡 陈寅恪《隋唐制度渊源略论稿》
🔴 通俗读物(仅作线索)
```
