## 一、经济史分期总纲

```
先秦      → 井田与贡赋的贵族经济，货币初现
秦汉      → 编户齐民 + 小农 + 官营专卖的经济帝国
魏晋南北朝 → 人口锐减、庄园化、货币经济倒退
隋唐      → 均田-租庸调盛期 → 两税法转型，南北经济格局翻转前夜
宋元      → 商业化、货币化、城市化高峰；经济重心南移完成
明清      → 白银化、赋役货币化、人口爆炸；总量领先而人均趋紧
近代      → 条约口岸、被动工业化、传统经济解体
现代      → 计划经济 → 改革开放 → 世界第二大经济体
```

| 时期 | 大致年代 | 一句话经济特征 | 制度关键词 |
|------|---------|---------------|-----------|
| 先秦 | 前 11 世纪–前 221 | 贵族领主制下的小农与井田贡赋，货币与城市初兴 | 井田、贡助彻、刀布圜钱 |
| 秦汉 | 前 221–220 | 编户齐民、重农抑商、盐铁官营，形成统一经济空间 | 名田制、上计、均输平准、五铢钱 |
| 魏晋南北朝 | 220–589 | 战乱致人口锐减、货币经济退化、豪族庄园与依附关系 | 屯田、占田、户调、庄园 |
| 隋唐 | 581–907 | 均田-租庸调由盛转衰，中唐两税法开启赋税货币化 | 均田制、租庸调、两税法、飞钱 |
| 宋元 | 960–1368 | 商业化与货币化高峰，纸币诞生，经济重心南移完成 | 二税、商税、交子、市舶、行省 |
| 明清 | 1368–1912 | 白银货币化、赋役折银、人口爆炸，总量领先人均趋紧 | 一条鞭法、摊丁入亩、市镇、商帮 |
| 近代 | 1840–1949 | 条约口岸、被动工业化，传统经济结构解体与重组 | 海关、洋务企业、法币、民族工业 |
| 现代 | 1949– | 计划经济奠基 → 改革市场化 → 全球第二大经济体 | 土改、合作化、承包制、市场化 |

🟡 分期逻辑见各朝代分论；本节仅为索引，不预设"进步史观"或"停滞论"立场。

**分期的底层逻辑**：中国经济史的一条主轴，是国家、地主与自耕小农三方围绕土地与人身控制展开的长期博弈。国家要赋税与兵源，地主想占有劳动力与剩余产品，小农则要在有限的土地上维持一家生计。三股力量的消长，直接决定一个朝代赋役的轻重、市场的开闭、人口的增减。当国家控制有力、赋役简明之时，小农经济相对稳定，商品交换随之活跃；当土地兼并加剧、正赋之外加派不断之时，小农破产流亡，户籍紊乱，财政与统治秩序同步崩坏。于是出现一种反复的结构：新朝轻赋安民而户口滋长，中期兼并加速而税基流失，后期加派横征而民变四起，终以改朝换代重新分配土地告一段落。这一循环并非简单的重复，每一轮都在货币化程度、市场网络、技术水平上留下累积的痕迹。理解这一结构，是理解后面各专题彼此关联的共同前提。

## 二、土地制度史

### 2.1 主线时间轴

| **名田制/授田** | 秦汉 | 按爵位名占田，军功授田 | 🟢《汉书·食货志》《商君书》 |
| **限田/王田** | 西汉末–东汉 | 董仲舒"限民名田"、王莽"王田" | 🟢《汉书·食货志》 |

| **均田制** | 北魏–唐前期 | 按丁口授田，露田桑田 | 🟢《魏书·食货志》《唐律疏议》 |
| **租佃制** | 唐宋以降 | 均田瓦解，地主-佃户契约关系 | 🟡 各断代经济史 |

| **土地革命→承包制** | 1930s–今 | 土改→集体化→家庭承包→三权分置 | 🟢 政策文献 |

### 2.2 关键节点

- **均田制（北魏 485 年始行）** 🟢：国家将无主荒地按丁口授予，受田者承担租调。其前提是**战乱后荒地多、国家掌握土地**。唐中期人口增长、土地兼并加剧，均田名存实亡，遂有 780 年**两税法**（"唯以资产为宗，不以丁身为本"）🟢《旧唐书·杨炎传》。
- **租佃制与人身依附** 🟡：均田瓦解后，土地买卖自由化，地主-佃户关系成为主导；宋代租佃契约普遍化，佃户人身依附较部曲为轻——这是"唐宋变革论"经济面的核心论据之一（详见第九节）。
- **明清赋役货币化** 🟢：一条鞭法（1581 全面推广）与摊丁入亩（1723 全国推行）使**赋役折银、人头税废除**，土地成为唯一主要税基，农民对国家的劳役义务大幅松弛。

### 2.3 学术争议：井田制是否存在？

- **观点 A（信古派/经典解读）**：井田制是西周实存的土地制度，"方里而井，井九百亩"为核心，田制与村社、贡赋绑定。代表：部分传统经学与早期经济史著作。
- **观点 B（疑古派/现代实证）**：井田制是战国儒者对理想化田制的追述甚至建构，缺乏同期金文与考古直接证据，"井"或为计量与水利单位而非耕作者共有制。代表：20 世纪疑古思潮与实证经济史学。
- 折中看法：井田制的"实存内容"与"理想化描述"需分层看待，可能**存在类似村社共有与定期分配的实践，但非孟子的整齐蓝图** 🟡。
- **（学术争议：观点 A vs 观点 B）**

### 2.5 土地制度史的底层逻辑

历代土地制度的反复调整，本质上是在回应两个无法同时满足的要求：一是保证国家有稳定可征的税基与可用的兵源，二是保证耕者有其田而不至于大批破产。授田与均田试图用行政手段把土地与丁口重新绑定，其成立条件是国家掌握大量无主荒地，一旦人口增殖、土地买卖恢复，行政分配便无法阻止事实上的私有与集中。限田、王田、占田之类的方案，也多因触动既得利益而难以持久。真正的长期趋势，是土地的私有化与买卖自由化不断加深，国家逐步放弃直接分配土地，转而承认既成事实并以赋税方式向土地要收入。两税法由税人转向税地，一条鞭法与摊丁入亩由征役转向征银，都是这一趋势的制度表达。与此同时，赋税的基础从人转向地、从实物转向货币，客观上松开了国家对农民人身的直接控制，为劳动力的流动与市场的扩张腾出了空间。土地制度的每一次松动，既是国家能力的调整，也是社会结构的重塑。

### 3.4 农业与人口互动的底层逻辑

中国传统农业的产出增长，长期依赖三条路径：开垦新的耕地、提高单位面积产量、增加单位土地的劳动投入。前两条受自然条件与技术水平限制，第三条则可以近乎无限地延伸，代价是劳动的边际报酬不断下降。人口增长既是农业发展的结果，又是推动其继续扩张的压力：人口多则劳动力廉而开垦与精耕有利可图，精耕又能在短期内供养更多人口，于是形成自我强化的循环。这个循环在土地充裕、社会安定、技术有所进步的阶段表现为繁荣，在耕地耗尽、灾害频仍、赋役加重的阶段则迅速转为危机。清代的处境正处在两种趋势的临界点上：一方面，垦荒、复种与美洲作物的推广带来了粮食总量的显著增加，使数亿人口得以维持；另一方面，人均耕地持续下降，劳动力价格低廉到不利于节省劳动的机械技术，形成一种以劳动密集替代技术突破的发展方式。人口史因此不是简单的多寡问题，而是理解技术选择、市场形态与社会结构的枢纽。

### 3.5 马尔萨斯约束之争

- **观点 A（马尔萨斯式约束有效）**：清代人口增长落后于耕地与产出增长，人均粮食与生活水平长期徘徊于生存线，形成"高水平均衡陷阱"（Elvin 伊懋可提出）。代表学者：伊懋可、黄宗智（"过密化"/"内卷化"）。
- **观点 B（约束被突破/生活水平有改善）**：彭慕兰等认为 18 世纪中国与西欧人均水平**大体相当**，不存在先天的马尔萨斯困境；人口增长与市场扩张、分工深化可并存。代表学者：彭慕兰（Kenneth Pomeranz）、李伯重。

### 4.2 关键技术与产业

- **盐铁专卖** 🟢：汉武帝元狩年间推行盐铁官营（《史记·平准书》《汉书·食货志》），开国家垄断战略物资之先河；后世"榷盐"成为财政支柱。
- **丝织与瓷器** 🟡：唐宋以降，丝、瓷是最重要的出口品，构成"白银—丝瓷"世界贸易循环的供给侧。
- **矿冶** 🟡：宋代煤铁使用扩大（学界对"宋代铁产量"有高估争议，见第九节）。
- **工匠制度** 🟢：唐代"番匠"、宋代"当行"、明代"匠籍"与嘉靖后的"以银代役"，反映国家对工匠人身控制的松弛，是手工业民营化的制度前提。

### 4.3 近代民族工业

| 类型 | 代表 | 时代 |
|------|------|------|
| 洋务官办 | 江南制造总局、福州船政局、汉阳铁厂 | 1860s–1890s 🟢 |
| 官督商办 | 轮船招商局、开平矿务局、上海机器织布局 | 1870s–1890s 🟡 |
| 民族资本 | 张謇大生纱厂、荣氏面粉纺织 | 1895 后 🟡 |

- **张謇**（1853–1926）🟡：状元实业家，南通大生纱厂，地方自治与"实业救国"路径的代表。
- **"短暂春天"（1912–1919）** 🟡：一战期间外资压力减轻，民族纺织、面粉业快速发展，但战后回落——学界对其"黄金期"程度有量化争议（估算）。
- **工业结构失衡** 🟡：轻工业为主、重工业与内陆薄弱，是近代工业化的结构性特征。

### 4.4 手工业演进的底层逻辑

手工业长期呈现官营与民营并存的双轨格局。官营部门依靠国家权力集中最好的工匠、原料与市场，承担的是政治与军事需求，其产品往往不计成本，也难以形成持续的技术改进动力。民营部门则在市场的缝隙中生长，一旦国家放松管制、赋役折银、匠籍松弛，民间资本与技艺便迅速扩张，江南丝织、景德镇陶瓷、佛山与汉口的冶铁都是例证。手工业的兴衰因此高度依赖两条线索：国家专卖与管制的松紧，以及市场特别是海外市场的需求。明清时期匠籍制度瓦解、以银代役推行，等于把工匠从国家的直接支配下释放到市场，这是民营手工业得以繁荣的制度前提。近代民族工业的兴起，延续的正是民营部门在外部冲击下重组与升级的路径，其轻工业偏重、重工业与内陆薄弱的失衡，也多能从传统手工业的分布与资本禀赋中找到根源。

### 4.5 现代工业化

| 阶段 | 特征 |
|------|------|
| 1953–1957 | 一五计划，156 项重点工程，重工业奠基 🟢 |
| 1958–1978 | 大跃进与三线建设，波动与布局调整 🟢 |
| 1978–2001 | 市场化改革、乡镇企业、外资进入 🟢 |
| 2001–今 | 入世后成为"世界工厂"，制造业规模全球第一 🟢 国家统计局 |

### 5.4 市场扩张的底层逻辑

### 6.2 纸币与通胀史

- **交子** 🟢：北宋真宗年间起于四川民间（铁钱笨重所致），1023 年官设益州交子务，为世界最早官方纸币。
- **元代纸币** 🟢：以银为本位发行，初期信用良好，后期因军费与赏赐滥发致恶性通胀，是元亡的经济背景之一。
- **明代宝钞** 🟢：明初发行大明宝钞，因不设准备金、滥发而信用崩溃，终被白银取代——**纸币失败正是白银货币化的推力** 🟡。
- **法币与会金圆券** 🟢：1935 年法币改革（白银国有化）→ 抗战及内战通胀 → 1948 金圆券 → 恶性通胀，为近代金融秩序崩溃的终点。

|------|------|------|

| 交子务、便钱务 | 宋 | 纸币发行、汇兑 |
| 票号 | 清（晋商） | 异地汇兑、官款存放 |
| 钱庄 | 明清–民国 | 存贷、货币兑换 |
| 官银钱号、银行 | 清末–民国 | 新式银行（中国通商银行 1897）|

### 6.4 货币金融的底层逻辑

货币形态的演变，反映的是交换规模与财政需要之间的张力。在交换有限、国家控制力强的时代，货币多用贱金属，甚至退回谷帛，货币经济随之退化；当跨区域贸易与财政支出扩张，对轻便、可远距离流通的支付手段的需求便急剧上升，纸币于是应运而生。交子起于四川，正是因为铁钱笨重而商旅不便；元代以银为本位发行纸钞，初期信用良好，后期滥发贬值；明初宝钞失败，市场转而信任白银。这表明纸币能否成立，取决于发行约束与信用基础，而非技术本身。白银依赖海外输入，则把中国的货币供给与全球贸易绑在一起，一旦外银流入减少，国内便出现通货紧缩，财政与债务随之承压。近代法币改革的失败，同样是财政赤字最终吞噬货币信用的老问题的重演。

## 七、财政与赋税

### 7.1 税制演进主线

```
贡助彻(先秦) → 初税亩(前594) → 编户赋役(秦汉) → 户调制(魏晋)
→ 租庸调(唐前期) → 两税法(780) → 二税+商税(宋) → 一条鞭法(1581)
→ 摊丁入亩(1723) → 近代关税/厘金 → 现代分税制(1994)
```

| 税制 | 时间 | 征收基准 | 意义 |
|------|------|---------|------|
| 初税亩 | 前 594 | 按亩 | 承认土地私有 🟢《左传》 |
| 编户赋役 | 秦汉 | 人丁 + 田 + 口 | 编户齐民税制 🟢《汉书·食货志》 |
| 户调制 | 曹魏–晋 | 户 | 战乱后简化征收 🟢 |
| 租庸调 | 唐前期 | 丁身为主（田租+户调+力役） | 与均田配套 🟢《唐六典》 |
| **两税法** | 780 | **资产（田亩）为主**，分夏秋两征 | 由"税人"转向"税地/税财" 🟢《旧唐书》 |
| 二税+商税 | 宋 | 田 + 商 | 商税成为重要财源 🟢《宋史·食货志》 |
| 一条鞭法 | 1581 | 田亩，折银 | 赋役合并、货币化 🟢《明史·食货志》 |
| 摊丁入亩 | 1723 | 田亩 | **人头税基本废除** 🟢《清史稿·食货志》 |
| 关税/厘金 | 1850s– | 进出口与过境 | 近代新财源，厘金争议大 🟡 |
| 分税制 | 1994 | 中央/地方划分 | 现代财政体制 🟢 |

### 7.2 财政国家形成（学术视角）

- **主张"早熟财政国家"**：宋代已有高度货币化的税收结构（商税、专卖、纸币），国家财政能力接近"财政国家"雏形 🟡。
- **主张"贡赋制帝国"**：直至明清，财政仍以田赋为主、以维持统治而非公共品供给为导向，与近代欧洲"财政-军事国家"路径不同 🟡。
- **（学术争议：观点 A vs 观点 B）**

### 7.3 财政赋税的底层逻辑

历代赋税改革反复遇到同一个难题：如何在不动摇统治基础的前提下，把不断增加的开支摊到真实的税源上。人头税简便却抑制生产、加剧隐匿；土地税公平却依赖清丈与登记，执行成本高且易遭豪强抵制。从租庸调到两税法，从一条鞭法到摊丁入亩，走向大致相同：由税人转向税地，由实物转向货币，由繁复转向简明。每次成功的改革都在短期内改善了财政、松开了人身束缚；每次失败的加派则在长期内耗尽民力、加速王朝危机。财政因此不是技术问题，而是国家与社会之间分配关系的集中体现。宋代商税与专卖收入的上升，说明财政已开始分享商业繁荣；近代关税与厘金则暴露了主权受损后税源的畸形结构。

### 7.4 财政与王朝周期

- 田赋长期轻（"轻徭薄赋"为理想），**正赋之外加派**（明末三饷、清摊派）往往是王朝崩溃的财政诱因 🟡。
- 宋代"冗兵冗官冗费"与明清"宗禄、河工、军费"构成财政刚性支出 🟡。

### 8.3 对外贸易的底层逻辑

中国的对外贸易长期在两种逻辑之间摆荡：一种是以政治与安全为先的朝贡逻辑，把贸易当作怀柔与秩序的工具，宁可厚往薄来也不愿民间自由通商；另一种是以利税与民生为先的市场逻辑，承认海外需求能带动产地繁荣、增加税收。唐以前以陆路为主，重心在西；宋以后政治与经济重心南移，海路成为主渠道，市舶司的收入甚至构成重要财源。明代把贸易收归朝贡，用海禁压制民间海商，结果走私与倭患并起，最终不得不在隆庆年间部分开关。清代以广州一口通商管理外贸，把巨大而活跃的海外需求压缩在十三行这一狭窄通道。1842 年之后条约口岸体系的确立，并不是中国主动融入世界，而是被强制纳入以不平等条约为基础的贸易秩序。近代外贸因此既是增长的窗口，也是主权与经济结构受制的入口，这一双重性贯穿整个近代经济史。

### 8.4 朝贡贸易与白银流入

- **朝贡体系** 🟡：贸易与外交合一，"厚往薄来"，政治象征意义高于经济收益。
- **白银流入** 🟡：明中叶后经**马尼拉大帆船贸易**（西班牙自墨西哥运银至马尼拉，换中国丝瓷）与**日本白银**大量流入，中国经济与全球白银流动深度绑定（量化规模为**学界估算**，各家差异大）。
- **后果** 🟡：白银货币化支撑赋役折银，但也使财政易受白银供给波动冲击（晚明白银输入减少与通货紧缩的关联，**量化存争议**）。

## 九、学术争议（并列盘点，不选边）

### 9.1 资本主义萌芽问题

- **观点 A（萌芽论）**：明中叶以后江南丝织、棉纺出现雇佣劳动、包买商支配、手工工场，已具"资本主义性质"的萌芽。代表：侯外庐、傅衣凌、吴承明等。
- **观点 B（质疑论）**：所谓"萌芽"多为家庭副业与商业资本，缺乏技术革命与产权/法律条件，用欧洲"资本主义"概念套中国史为**后设框架**。代表：部分海外学界与反思派。
- **（学术争议：观点 A vs 观点 B）**

### 9.2 唐宋变革论中的经济面

- **观点 A（内藤湖南/宫崎市定"唐宋变革论"）**：唐宋之间发生社会性质转变——贵族政治→君主独裁，均田→租佃，身份制→契约制，经济上商业化、货币化、城市化大发展，为"近世"开端。
- **观点 B（质疑"变革"幅度）**：变革是渐变而非断裂，宋以后仍有强烈的国家干预与身份秩序，将宋定为"近世"是以欧洲分期为准的比附。
- **（学术争议：观点 A vs 观点 B）**

### 9.3 大分流：彭慕兰 vs 黄宗智

- **观点 A（彭慕兰《大分流》2000）**：18 世纪中国江南与英格兰在生活水平、市场、要素价格上**相当接近**；真正的分流源于英国煤矿-新大陆的"意外优势"与中国"生态-资源困境"的差异，而非文化或制度本质不同。
- **观点 B（黄宗智"过密化/内卷化"）**：明清江南经济是**没有发展的增长**——劳动投入增加而边际报酬递减，家庭化生产阻碍了资本化，与西欧路径判然有别。
- **（学术争议：观点 A vs 观点 B）**

### 9.4 明清 GDP 估算争议

- **观点 A（麦迪森 Maddison 等）**：1820 年中国 GDP 总量约占世界 1/3（**估算**），总量世界第一而人均低下；此后占比持续下滑。
- **观点 B（其他学者质疑）**：总量占比与方法（购买力平价、农场价格、前现代产出折算）高度敏感，1/3 等数字误差极大；部分研究主张占比被高估，另有主张人均被低估（如彭慕兰、李伯重对江南的估算）。
- **（学术争议：观点 A vs 观点 B）**
- ⚠️ 所有明清 GDP/人均数字均为**估算**，引用必须带学者与方法，严禁当作精确统计。

### 9.5 长期停滞论 vs 动态变迁论

- **观点 A（停滞论/循环论）**：中国传统经济陷入"王朝循环"与"高水平均衡陷阱"，无内生突破，近代落伍有结构必然性。
- **观点 B（动态变迁论）**：中国早有市场扩张、技术进步、产权与契约演进，是**动态的、多路径的**变迁，停滞论是西方中心叙事。
- **（学术争议：观点 A vs 观点 B）**

| 宋代铁产量 | 空前高（部分旧估算极高） | 旧估算严重虚高，需重估 🟡 |
| 美洲作物与人口 | 玉米番薯是人口爆炸关键 | 仅辅助因素，主因是垦荒与和平 🟡 |
| 白银流入规模 | 巨量支撑中国经济 | 规模被夸大，估计区间极宽 🟡 |
| 科举与经济增长 | 促进社会流动 | 锁定人力资本于功名，抑制技术投资 🟡 |

### 10.3 估算方法

- **人口学方法**：册载校正、增长率回推、生命表（何炳棣、葛剑雄等）🟡。
- **国民账户法**：产出/支出折算、购买力平价（麦迪森等）🟡。
- **价格史方法**：粮价序列、要素价格比较（彭慕兰、王国斌等）🟡。
- **计量史学**：回归与序列分析（清代粮价、市场整合度）🟡。
- ⚠️ **一切古代经济数字的精度上限由史料本身决定**；报告输出时须显式标注数据档位（财报口径 / 市场口径 / 推算口径），详见 `~/self-improving/rules.md` R297。

### 10.4 常见误用与纠错

引用经济史数字时，最常见的错误有四类。一是把估算当实录，将学者基于模型与有限资料得出的口径直接写成确定性事实，忽略了区间与方法差异。二是把官修册报当现代统计，户口、田亩的册载数字受隐匿、折户与统计口径变动影响，前后并不严格可比，摊丁入亩前后的户口数据尤须谨慎。三是把游记与笔记当史料主体，马可·波罗等记述生动但夸大与传闻较多，只能用于参证而不能单独支撑数量结论。四是把总量与人均混为一谈，中国长期总量领先而人均水平偏低，用总量排名替代生活水平判断会得出误导性结论。正确处理方式是：凡是数字，先问从哪里来、用什么方法得出、区间有多宽；凡是结论，先问是否已并列相反观点；凡是涉及比较，先确认比较的口径在两边是否一致。

### 10.5 使用本模块的三条纪律

1. **区分"看什么制度"与"信什么数字"**：制度沿革（如一条鞭法年份）多用 🟢，数量结论多用 🟡 并带"估算"。
2. **争议并列，不选边**：本库在学术争议上只列观点 A/B 及代表学者，不作裁决。
3. **交叉引用**：经济面与政治、思想、科技互为条件，参见各朝代分论同名节。
