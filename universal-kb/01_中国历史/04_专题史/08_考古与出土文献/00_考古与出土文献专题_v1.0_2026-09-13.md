## 一、为什么考古层独立成卷

传世文献经过传抄、编纂、选择性保存。**考古与出土文献是"未被后世改动"的第一手证据**，常能：
- 印证文献（甲骨文证商王世系）
- 修正文献（简牍补秦制细节）
- 提出文献没有的新问题（区域文化差异）

王国维"**二重证据法**"（地下新材料 + 纸上材料互证）是本卷方法论基础。

## 二、史前考古（旧石器—新石器）

| 阶段 | 代表遗址 | 年代（约） | 要点 |
|------|---------|-----------|------|
| 旧石器早期 | 元谋人、蓝田人、北京人 | 170万—20万年前 | 直立人阶段 |
| 旧石器中期 | 丁村、许家窑 | 20万—5万年前 | 早期智人 |
| 旧石器晚期 | 山顶洞、峙峪 | 5万—1万年前 | 晚期智人，出现埋葬与装饰 |
| 新石器早 | 裴李岗、磁山、河姆渡 | 前7000—前5000 | 农业起源（粟/稻） |
| 新石器晚 | 仰韶、大汶口、龙山、良渚、石家河 | 前5000—前2000 | 聚落、玉器、城址 |

**重要发现**：
- **良渚古城**（浙江余杭，前3300—前2300）——大型水利系统 + 玉琮玉钺 → 早期复杂社会（2019 列入世界遗产）
- **石峁古城**（陕西神木，前2300—前1800）——巨型石城，北方早期国家线索
- **陶寺遗址**（山西襄汾）——观象台 + 大墓 → 可能与"尧都"相关（**学术争议**）

**学术争议**：
- 观点 A：中国文明"多元一体"，各区域并行发展后汇聚
- 观点 B：中原中心论，周边为次生
- （学术争议：观点 A vs 观点 B）

## 三、夏商周考古

### 3.1 二里头与夏

| 项 | 内容 |
|----|------|
| 遗址 | 河南偃师二里头 |
| 年代 | 约前1750—前1530（学界有分歧） |
| 要素 | 大型宫殿基址、青铜器作坊、绿松石龙形器 |
| 争议 | 是否即"夏都"？**观点 A**：二里头＝夏文化晚期；**观点 B**：二里头＝早商，夏尚未确证 |

### 3.2 殷墟与商

- **殷墟**（河南安阳，前1300—前1046）：甲骨文 15 万余片、宫殿宗庙、王陵、青铜器
- **甲骨文**：证《史记·殷本纪》商王世系基本可靠 → 商史为**信史**
- 妇好墓：唯一未盗掘的商王室墓

### 3.3 周代考古

- **周原**（陕西岐山扶风）：先周与西周早期，青铜器窑藏（大盂鼎、毛公鼎等）
- **琉璃河**（北京房山）：燕国始封地
- **晋侯墓地**（山西曲沃）：晋国世系
- 金文（青铜器铭文）：西周制度第一手材料

## 六、考古学方法与争议

### 6.1 基本方法

```
地层学（层位关系）→ 相对年代
类型学（器物形态演变）→ 相对年代序列
碳十四测年 → 绝对年代
科技考古（同位素、DNA、残留物分析）→ 生计与人群
```

### 6.2 **夏商周断代工程**（1996—2000）

| 项 | 内容 |
|----|------|
| 目标 | 为夏商周建立精确年代框架 |
| 成果 | 提出武王克商年（前1046）等关键年代 |
| **争议** | **观点 A**：综合多学科，推进显著；**观点 B**：部分年代推定依据不足，测年误差与方法受质疑 |
| 后续 | 中华文明探源工程（2001—）继续 |

### 6.3 其他争议

| 议题 | 观点 A | 观点 B |
|------|--------|--------|
| 中国文明起源 | 中原中心、单一起源 | 多元一体、多中心并行 |
| 二里头性质 | 夏都说 | 早商都说 |
| 商代社会性质 | 奴隶制说 | 早期国家/封建说 |
| 考古与文献关系 | 以文献为纲 | 以考古为本位（"考古学文化"不等于族属） |

## 七、考古发现的 KB 使用规则

1. 考古材料 = 🟢 一级信源（未经后世改动）
2. 但**考古解释**同样有学派差异 → 标注争议
3. "考古学文化"与文献中的"族名"**不能简单等同**（如"二里头文化"≠必然"夏族"）
4. 出土文献可修正传世文献，但不必然取代
5. 所有待定问题标"待考"
