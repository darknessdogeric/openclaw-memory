## 一、总纲：分期、谱系与格局

### 1.1 民族史分期主线

| 期 | 时段 | 结构性变化 | 主体族群互动 | 关键制度 |
|----|------|-----------|-------------|---------|
| 一 | 先秦 | 华夏认同萌生，"五方之民"格局 | 华夏—东夷/南蛮/西戎/北狄 | 分封、朝贡、会盟 |
| 二 | 秦汉 | 中原帝国与草原帝国对峙格局定型 | 汉—匈奴/百越/西南夷/西域诸族 | 和亲、设郡、属国、都护 |
| 三 | 魏晋南北朝 | 第一次大规模胡汉融合 | 五胡—汉—南方诸族 | 胡汉分治、部族制 |
| 四 | 隋唐 | 多极并立、羁縻体制成熟 | 唐—突厥/吐蕃/回鹘/南诏/渤海 | 羁縻府州、都护府、和亲 |
| 五 | 宋辽金元 | 多政权并立到超大规模整合 | 契丹/女真/党项/蒙古/汉 | 南北面官、猛安谋克、四等人制 |
| 六 | 明清 | 疆域整合与治理制度化 | 满蒙藏回汉苗等 | 盟旗、驻藏大臣、改土归流 |
| 七 | 近代 | "中华民族"概念与民族国家建构 | 中华诸族 vs 帝国主义 | 五族共和、民族识别（延至当代） |

🟡 分期框架参照中国民族史通行的"王朝—族群"叙述传统，但分期本身即存在争议（详见第九节）。

### 1.2 语言谱系（含争议标注）

| 语系/语族 | 主要民族（历史与当代） | 争议标注 |
|-----------|---------------------|---------|
| 汉藏语系·汉语族 | 汉族、回族（汉语）、部分白族 | 汉藏语系内部谱系树有争议 |
| 汉藏语系·藏缅语族 | 藏族、羌族、彝族、纳西、景颇、土家 | — |
| 汉藏语系·壮侗语族 | 壮族、傣族、布依、侗、黎 | 侗台语系归属有争议 |
| 汉藏语系·苗瑶语族 | 苗族、瑶族、畲族 | — |
| 阿尔泰语系·突厥语族 | 突厥诸部、回鹘、维吾尔、哈萨克、柯尔克孜、撒拉 | **"阿尔泰语系"为假说，学界有支持与否定两派** |
| 阿尔泰语系·蒙古语族 | 室韦—蒙古、达斡尔、土、东乡、保安 | 同上 |

### 1.3 华夏/汉族的形成

| 观点 | 核心主张 | 代表学者/文献 |
|------|---------|--------------|
| **A. 一元论（单线起源）** | 华夏起于中原一源（黄河中游），向外扩散同化四夷；汉族为华夏单线扩大 | 传统正史叙述、早期"中原中心"史观 🟢 |
| **B. 多元论（多源汇聚）** | 史前文化"满天星斗"，华夏是多个文化区长期互动汇聚的结果 | 苏秉琦"区系类型"说、费孝通"多元一体格局" 🟡 |

🟢 "华夏"作为自称，最早见于《尚书·武成》"华夏蛮貊，罔不率俾"（今传本真伪有争议，待考）。"汉"作为族称较晚，一般认为源于汉王朝国号，魏晋后渐成族称。

### 1.4 三个反复出现的结构主题

1. **农牧分界与互动**：长城—草原—绿洲—高原的生态梯度，塑造了"农耕—游牧"长期互动（🟡 拉铁摩尔"边疆形态"说）。
2. **"华夏边缘"的伸缩**：谁是"华夏"随政治与文化需要而变动（🟡 王明珂）。
3. **族称的可变性**：同一族称在不同时代指涉不同人群（如"匈奴""突厥""回鹘""蛮""番"），使用时须注明时代与语境。

## 二、先秦的民族格局

### 2.1 "五方之民"与华夏中心观

🟢 《礼记·王制》："中国戎夷，五方之民，皆有性也，不可推移。东方曰夷，被发文身……南方曰蛮，雕题交趾……西方曰戎，被发衣皮……北方曰狄，衣羽毛穴居。"——这是**后世理想化的分类框架**，非先秦实际族群清单，须区别对待。

🟢 《春秋》"尊王攘夷"、孔子"微管仲，吾其被发左衽矣"（《论语·宪问》）——"华夷之辨"兼具政治与文化两义。

🟡 **关键辨析**：先秦"戎狄蛮夷"多为方位泛称与政治标签，而非严格族群分类；同一人群可因政治关系变动而在"华夏/夷狄"间移动。

### 2.2 东夷

| 名称 | 分布 | 要点 |
|------|------|------|
| 莱夷 | 今山东半岛 | 与齐、鲁互动，春秋被齐所并 🟢 |
| 淮夷 | 淮河流域 | 西周多次征伐，《诗经·鲁颂·泮水》"淮夷攸服" 🟢 |
| 徐夷（徐方） | 淮泗间 | 西周中晚期强盛，徐偃王传说 🟢/🔴 |
| 九夷 | 泛指东方诸部 | 《论语·子罕》"子欲居九夷" 🟢 |
| 商奄 | 山东曲阜一带 | 周公东征所平 🟢 |

🟡 考古上，大汶口—龙山—岳石文化区与"东夷"存在关联性讨论，但文化—族属对应不可直接等同（待考）。

### 2.3 南蛮与百越

| 名称 | 分布 | 要点 |
|------|------|------|
| 三苗 | 长江中游 | 《尚书·舜典》"窜三苗于三危"，与屈家岭—石家河文化关联讨论 🟢/🟡 |
| 荆蛮/楚蛮 | 江汉 | 楚人自称"我蛮夷也"（《史记·楚世家》）🟢 |
| 濮 | 江汉—西南 | 楚、巴、蜀间的诸部 🟢 |
| 百越（於越、闽越、南越、西瓯、骆越等） | 东南沿海至岭南 | "百越"为概称，内部差异大 🟢 |
| 巴、蜀 | 四川盆地 | 巴蜀文化，秦并巴蜀（前316）🟢 |

🟡 **争议**：楚、秦是否为"华夏"——传统叙事以楚国为"蛮夷"，现代研究强调楚文化的独立性与多元性（见 9.1）。

### 2.4 西戎

| 名称 | 分布 | 要点 |
|------|------|------|
| 犬戎 | 陇东、陕北 | 前771 灭西周于骊山 🟢 |
| 姜戎 | 晋南 | 与晋通婚，"姜戎氏" 🟢 |
| 义渠 | 陇东 | 秦昭王时（前272 前后）灭之，置陇西、北地、上郡 🟢 |
| 大荔、绵诸、乌氏、朐衍 | 陇西 | 《史记·匈奴列传》所列"西戎八国" 🟢 |
| 羌 | 河湟 | 与西戎关系密切，秦汉后成为独立族群范畴 🟢 |

### 2.5 北狄

| 名称 | 分布 | 要点 |
|------|------|------|
| 猃狁（猃允/荤粥） | 陕晋北部 | 《诗经·小雅·采薇》"靡室靡家，猃狁之故" 🟢 |
| 赤狄、白狄、长狄 | 太行—河北—山西 | 春秋时赤狄潞氏最强，白狄建中山国 🟢 |
| 林胡、楼烦 | 晋北、内蒙中南部 | 赵武灵王"胡服骑射"（前307 前后）所对 🟢 |
| 东胡、山戎 | 燕山南北 | 燕、齐所伐 🟢 |
| 匈奴（早期形态） | 阴山—河套 | 《史记》将其谱系上溯至"淳维"（存疑，待考）🟢/🔴 |

### 2.6 先秦民族格局小结

| 维度 | 表现 |
|------|------|
| 政治 | 分封、会盟、朝贡、征伐并存；"夷夏"关系高度政治化 |
| 经济 | 农牧、渔猎、采集交错互补；盐、马、铜料为交换大宗 |
| 文化 | 礼制、文字（汉字系）逐步扩散；"夷夏"文化边界可跨越 |
| 观念 | "华夷之辨"与"用夏变夷"并存，为后世留下两条相反的思想资源 |

### 2.7 先秦族群互动的考古线索

| 考古文化 | 区域 | 与文献族群的关联讨论 |
|---------|------|-------------------|
| 二里头文化 | 豫西晋南 | 与"夏"的关联为主流讨论方向，族属仍无定论 |
| 殷墟文化 | 豫北 | 商；甲骨文有"羌方""土方""鬼方"等方国记载 🟢 |
| 三星堆—金沙 | 成都平原 | 蜀；与中原互动并存，具显著地方性 🟡 |
| 吴城—大洋洲 | 赣江流域 | 与"百越/虎方"的关联讨论 🟡 |
| 夏家店下层/上层 | 辽西 | 与"东胡/山戎"关联讨论，上层或与"北狄"相关 🟡 |
| 中山国墓葬 | 河北平山 | 白狄所建，出土器物显示高度华夏化，兼存北方因素 🟢 |

🟡 考古文化与文献族属的对应关系存在方法论争议：一派主张可谨慎对应，一派主张文化传播与族属认同不可等同（待考）。

🟢 秦置桂林、象郡、南海三郡（前214）。秦末赵佗建南越国（前204–前111）。汉武帝元鼎六年（前111）平南越，置九郡。闽越、东瓯先后内徙。🟢《史记·南越列传》。

### 3.5 羌与护羌校尉

🟢 汉武帝设护羌校尉（前111 前后）。东汉羌乱频繁（107–118、140–145、184 等），耗费巨大，被认为是东汉衰亡诱因之一（🟡 学界有不同评估，待考）。

### 3.6 秦汉民族治理的制度工具箱

| 制度 | 内容 | 性质 |
|------|------|------|
| 和亲 | 以宗女、财物结姻 | 外交/政治 |
| 设郡 | 直接郡县化（如河西四郡、岭南九郡） | 直接统治 |
| 属国 | 内附部族"因其故俗"而治，设属国都尉 | 间接统治 |
| 都护 | 西域都护府统辖诸国 | 军事监护 |
| 校尉 | 护羌校尉、护乌桓校尉 | 边务专管 |
| 质子/侍子 | 诸国遣子入侍 | 政治控制 |
| 册封 | 授印绶、王号 | 名分笼络 |

🟢《后汉书·百官志》记属国"稍有分县，治民比郡"。🟡 学界普遍视之为后世**羁縻制度**的早期形态。

### 3.7 秦汉边疆治理的空间层次

| 层次 | 形态 | 实例 |
|------|------|------|
| 核心郡县 | 编户齐民，直接统治 | 河西四郡、岭南九郡 |
| 内属部族 | 属国都尉，"因其故俗" | 五属国（安置匈奴降众）|
| 羁縻外邦 | 册封、质子、互市 | 西域诸国、南匈奴 |
| 都护监护 | 军事监护、交通保障 | 西域都护府 |
| 边塞屯戍 | 亭障、烽燧、屯田 | 居延、敦煌汉简所见 |

🟢 居延汉简、敦煌汉简为第一手边塞行政文书。🟡 该"同心圆"结构被多数学者视作中华帝国边疆治理的原型。

## 四、魏晋南北朝的民族大融合

### 4.1 "五胡"及其来源

| 族群 | 主要支系 | 建立政权 |
|------|---------|---------|
| 匈奴 | 南匈奴、屠各、铁弗、卢水胡 | 汉赵（前赵）、夏 |
| 鲜卑 | 慕容、拓跋、宇文、段部、乞伏、秃发、吐谷浑 | 前燕/后燕/南燕、代/北魏、北周、南凉、西秦 |
| 羯 | 杂胡（族属有争议） | 后赵 |
| 氐 | 略阳氐、仇池氐 | 前秦、后凉、成汉（巴氐） |
| 羌 | 姚氏羌 | 后秦 |

🟢 崔鸿《十六国春秋》（辑本）；🟢《晋书·载记》。🟡 "五胡"为概称，实际参与的族群远多于五。

### 4.2 十六国到北朝：胡汉关系的三种模式

| 模式 | 说明 | 代表 |
|------|------|------|
| 胡汉分治 | 胡人掌军事、汉人掌民政，双轨并行 | 后赵"单于台"—尚书台 🟢 |
| 全面汉化 | 行汉制、习汉文、与汉士族合作 | 前秦苻坚、北魏孝文帝 🟢 |
| 部族本位 | 保留部落兵制，排斥汉化 | 北魏六镇集团、北齐高氏 🟡 |

### 4.3 北魏孝文帝改革（汉化的标杆）

| 措施 | 年代 | 内容 |
|------|------|------|
| 班俸禄、均田制 | 484–485 | 汉式官僚与土地制度 🟢 |
| 迁都洛阳 | 494 | 脱离平城部族势力 🟢 |
| 禁胡服、断北语 | 494–495 | 朝堂改汉服、汉语 🟢 |
| 改姓氏 | 496 | 拓跋→元，独孤→刘，丘穆陵→穆等 🟢 |
| 定族姓、通婚 | 496 后 | 门阀化，与汉人高门联姻 🟢 |

🟢《魏书·高祖纪》《资治通鉴》卷一三八至一四〇。

### 4.4 六镇之乱与关陇集团

🟢 正光五年（524）六镇起义。🟡 陈寅恪提出"关陇集团"说：西魏—北周—隋—唐统治核心由武川镇军人集团与关陇汉人豪族融合构成，是理解隋唐政权性质的关键。

### 4.5 融合的多条路径

| 路径 | 说明 |
|------|------|
| 血缘 | 通婚、收养、赐姓 |
| 制度 | 军制（府兵制）、行政（三长制）、土地（均田制） |
| 语言 | 汉语成通用语，鲜卑语渐衰 |
| 宗教 | 佛教石窟（云冈、龙门、敦煌）成多族共同信仰载体 |

### 4.6 南方的族群

🟢 山越（孙吴征讨）、俚僚（岭南）、蛮（荆雍）、獠（川黔）。🟡 南方"汉化"多以编户、军屯、移民方式推进，节奏慢于北方（唐长孺等研究）。

### 4.7 南北朝族群迁徙与人口重组

| 迁徙方向 | 主体 | 影响 |
|---------|------|------|
| 北人南迁 | 汉人士族与流民 | 江南开发、侨州郡县、南方汉化加速 |

🟡 有学者估计此期人口损失与迁徙规模空前，但可靠统计缺乏，具体数字宜谨慎（待考）。

## 九、学术争议（完整并列，不选边）

### 9.1 华夏/汉族的形成：一元 vs 多元

| | 观点A：一元/单线论 | 观点B：多元/汇聚论 |
|--|------------------|------------------|
| 核心主张 | 华夏起于中原一源，经同化扩张形成汉族；四夷为外缘 | 史前多文化区并存，华夏是多源长期互动整合的产物 |
| 证据 | 正史谱系叙述、礼制与文字的连续性 | 考古区系类型、聚落与器物多元性 |
| 代表 | 传统正史观、早期中原中心史观 🟢 | 苏秉琦"满天星斗"；费孝通"多元一体"；王明珂"华夏边缘" 🟡 |

### 9.2 "民族融合"叙事的学术评价

| | 观点A：融合论 | 观点B：征服/压迫论 |
|--|--------------|------------------|
| 主张 | 中国民族史主线是不断融合，形成多元一体 | 融合常伴随征服、迁徙、压迫，史实中冲突与不平等不可淡化 |
| 证据 | 制度并轨、通婚、语言文化互渗 | 屠城、掠口、等级制（如四等人制、满汉之防）、反抗起义 |
| 代表 | 中国民族史主流教科书叙述 🟡 | 部分社会史、边疆史研究者；新清史部分论述 🟡 |
| 批评 | 被批"融合"一词掩盖暴力与强制 | 被批忽视长期文化整合的实际成果 |
| 备注 | 学界多数认为应"分层看待"：不同时期、不同地域差异极大 |

### 9.3 新清史：内亚帝国论 vs 汉化论

| | 观点A：内亚帝国论（新清史） | 观点B：汉化论 |
|--|--------------------------|--------------|
| 主张 | 清是内亚普世帝国，皇帝以多重身份（汗/皇帝/文殊菩萨）分别统治满蒙藏回汉；满人认同长期保持 | 清延续并深化中原王朝制度，满人逐步汉化，清=中国王朝 |
| 证据 | 满文档案、藏文与蒙文文献、木兰秋狝、盟旗、藏传佛教护持 | 科举、六部、实录编纂、汉人士大夫政治、雍正《大义觉迷录》 |
| 代表 | 罗友枝（Evelyn Rawski, 1996 AAS 主席演讲）、柯娇燕（Pamela Crossley）、欧立德（Mark Elliott）🟡 | 何炳棣（Ho Ping-ti, 1998 回应）、黄培等 🟡 |
| 批评 | 被批低估汉制整合力，或隐含分裂史观 | 被批以汉族中心视角抹平满人主体性与内亚资源 |
| 备注 | 该争论自 1990 年代延续至今，中国学界回应亦多元 |

### 9.4 中国民族史分期：五阶段论 vs 中国学界修正

| | 观点A：苏联五阶段论 | 观点B：中国学界修正 |
|--|-------------------|-------------------|
| 主张 | 原始—奴隶—封建—资本主义—社会主义，各族均须走此序列 | 各民族社会发展极不平衡，"跳跃式""跨越式"常见，不宜一刀切 |
| 证据 | 经典理论范式；部分民族有奴隶制痕迹 | 大量民族志显示长期处于部落、村社、农奴制等多种形态 |
| 代表 | 20 世纪 50–70 年代中国民族史研究主流 🟡 | 1980 年代后的调整与反思 🟡 |
| 批评 | 被批"削足适履"、生搬硬套 | 被批弱化了理论解释力与比较框架 |
| 备注 | 现行研究多采用"多元发展路径"，五阶段论多作参考框架 |

### 9.5 蒙古帝国与元朝的性质

| | 观点A：中国王朝论 | 观点B：内亚/世界帝国论 |
|--|-----------------|---------------------|
| 主张 | 元是中国王朝序列一环，忽必烈行汉法、建元号、修《宋史》 | 元是大蒙古国的中国部分，其统治资源、合法性含大量内亚成分 |
| 证据 | 《元史》、行省制、科举（1315 恢复）、汉法与儒臣 | 怯薛、达鲁花赤、四等人制、藏传佛教国师制、蒙古文文书 |
| 代表 | 中国传统史观与主流教科书 🟢/🟡 | 内亚史视角、部分海外研究 🟡 |
| 附带争议 | "四等人制"是否有成文法：有说为明文制度，有说系后人概括（待考） | — |

### 9.6 "中华民族"概念的建构性

| | 观点A：近代建构论 | 观点B：古已有之论 |
|--|-----------------|-----------------|
| 主张 | "中华民族"是 20 世纪初引入现代民族主义后的政治建构 | 中国自古有"华夏—天下"共同体意识，族际一体性有其历史根基 |
| 证据 | 1902 年梁启超首用；此前无该词；概念与"民族国家"输入同步 | 《春秋》"华夷之辨"、历代"天下一统"、"炎黄子孙"谱系认同 |
| 代表 | 部分民族主义研究、葛兆光等对"中国"观念史的研究 🟡 | 顾颉刚"中华民族是一个"；传统史观 🟡 |
| 批评 | 被批否定历史连续性 | 被批混淆"文化认同"与"现代民族"两个层次 |
| 备注 | 两说可并存：概念为近代建构，但其思想资源与认同基础有更长的历史 |

### 9.7 边疆史观：中原中心 vs 内亚/边疆中心

| | 观点A：中原中心史观 | 观点B：内亚/边疆中心史观 |
|--|-------------------|----------------------|
| 主张 | 以中原王朝为主轴，边疆是"被开发""被纳入"的对象 | 边疆与内亚有自身历史逻辑，非中原的附属脚本 |
| 证据 | 正史体例、郡县推进序列、汉文文献主体 | 游牧社会自主发展、草原—绿洲网络、非汉文文献 |
| 代表 | 传统纪传体史书、20 世纪主流教科书 🟢/🟡 | 拉铁摩尔《中国的亚洲内陆边疆》（1940）、罗新、姚大力等 🟡 |
| 批评 | 被批忽视边疆主体性 | 被批可能低估中原制度与文化的整合作用 |
| 备注 | 近年趋势是"多中心互动"，但两派张力仍在 |
