# 全域信源体系建设方案 v2.0

> **v2.0 升级说明**：v1.0（2026-08-14）已完成 11 大领域 × 50+ 信源的框架；v2.0 在原基础上**完成三大升级**：
> 1. **报告闭环**：信源不再孤立，每个信源明确对应到月报/季报/半年报的哪个章节
> 2. **执行 SOP**：v1.0 的"月度追踪 SOP"具象化成可触发的扫描任务清单（按周/月/季节奏）
> 3. **Obsidian 友好**：引入 frontmatter + tags + 双向链接，沉淀为可浏览的知识图谱
>
> **覆盖**：11 大领域 × 60+ 核心信源（含 TrendRadar 整合 9 平台/18 RSS 源）
> **R66 标准**：每个信源标注数据等级 + R66 校验要求 + 报告归属章节

---

## 一、设计哲学

### 1.1 三大核心问题

```
Q1: Eric/产业发展部 当前最需要什么样的市场信号？
A1: 月报（高频日常决策）+ 季报（战略复盘）+ 半年报（趋势与格局）

Q2: 为什么必须做"信源 → 报告"闭环？
A2: 信源孤岛 = 数据再多也没用；只有"信源×时点×场景"三绑定，才能形成决策链

Q3: 为什么引入 Obsidian？
A3: Obsidian = 双链 + MOC + frontmatter = 知识图谱化 = Eric 跨设备随时调用 = 任何报告都能"溯源 + 串联"
```

### 1.2 体系三原则

```
原则 1 · 战略匹配：每个信源必须支撑具体决策场景（不是"听起来好"）
原则 2 · 时点节奏：日报 / 周报 / 月报 / 季报 / 半年报 5 级时点明确绑定
原则 3 · 数据可核：🟢 A/B / 🟡 C/D 分级，决策级必标 R66 校验 + 报告归属
```

## 三、报告闭环（v2.0 核心）

### 3.1 信源 → 报告 映射

```
[信源] ── 时点过滤 ── [报告章节]
   ↓
日级数据（STR/Skift Daily/Bloomberg/微博热搜）
   ↓
   ├──→ 周报：政策追踪周报 / AI 工程师周报 / 国际酒店速递
   ↓
月级数据（迈点/奥维/EHL 月报/BCG/财报披露/RGI/MPI）
   ↓
   ├──→ 月报：经营分析 + 行业趋势 + 对标 + 政策窗口
   ↓
季级数据（Phocuswright/上市公司财报/UNWTO/Cushman）
   ↓
   ├──→ 季报：战略复盘 + 竞争格局 + 趋势 + 季度 KPI 校准
   ↓
半年级数据（EHL 年报/OECD/世行/沙特/WTTC/Allianz）
   ↓
   └──→ 半年报：行业全景 + 国企治理 + 中长期格局 + 战略野心校准
```

### 3.2 5 级时点 × 报告体系（详细绑定见 [[04_报告体系总图_信源矩阵→月报→季报→半年报_v1.0_2026-09-06.md]]）

| 时点 | 触发节奏 | 报告类型 | 核心信源 |
|------|----------|---------|---------|
| 日 | 每日 | 国际酒店速递 / AI 商业内幕 | Bloomberg / The Information / 微博热搜 |
| 周 | 每周一 | 政策追踪周报 / AI 工程师周报 | TrendRadar / LangChain / 36 氪 / Hacker News |
| 月 | 每月 5 日前 | 酒店月报 | 迈点 / 奥维 / STR / RGI/MPI 计算 / 中旅对标 |
| 季 | 季度财报披露后 15 日内 | 酒店季报 | 上市公司财报 / Skift / Phocuswright / Cushman |

## 四、月度追踪 SOP（v2.0 具象化）

### 4.1 每月第 1 周（5 日前完成）· 月报输入采集

```
□ Day 1（1 日）
  ├── 8 家国际酒店集团 Q 财报 → anyi-ops-kb/04_情报/财报追踪/[季度]/[公司].md
  ├── 4 家国内酒店集团 Q 财报 → 同上
  └── TrendRadar 扫描当月热搜 TOP 50（去重聚合）

□ Day 2（2 日）
  ├── STR / Skift / Phocuswright 月度报告 → 第三方洞察/
  ├── 迈点 / 奥维月度报告 → 国内酒店月度/
  ├── EHL 当月 Insights（如有）→ EHL 归档/
  └── 中国旅游研究院季度报告（如季度边界）→ 政策环境/

□ Day 3（3 日）
  ├── 3 大 VC（a16z/Sequoia/ARK）最新动态 → AI 战略洞察/
  ├── UNWTO / WTTC 月度数据 → 跨境旅游追踪/
  └── OECD / 世行 国企治理更新 → 国企改革参考/

□ Day 4-5（4-5 日）
  ├── 拼装月报 → [[01_酒店月报范式_v1.0_2026-09-06.md]] 模板
  ├── 数据校验（R66 标准）
  └── 输出月报（MD + 可选 PDF）
```

□ 季报月 1-15 日
