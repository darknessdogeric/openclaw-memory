## 一、定义

**景区投融资** = 景区项目从启动、运营、扩张到退出的全周期资本运作。

## 二、9 大投融资工具

| # | 工具 | 阶段 | 适用规模 | 优势 | 劣势 |
|---|------|------|---------|------|------|
| 1 | **政府财政** | 启动期 | 1-100 亿 | 公益性强 | 资金有限 |
| 2 | **银行贷款** | 建设期 | 千万-百亿 | 资金量大 | 利率 + 担保 |
| 3 | **产业基金** | 扩张期 | 亿级 | 灵活 | 收益分成 |
| 4 | **PPP** | 大型项目 | 10 亿+ | 风险共担 | 周期长 |
| 5 | **EOD** | 生态导向 | 10 亿+ | 政策资金 | 模式复杂 |
| 6 | **ABS** | 成熟资产 | 亿级 | 盘活存量 | 增信要求高 |
| 7 | **REITs** | 成熟资产 | 亿级 | 退出渠道 | 收益稳定但低 |
| 8 | **M&A 收并购** | 扩张 / 退出 | 千万-百亿 | 快速规模化 | 整合难 |
| 9 | **战略投资（VC/PE）** | 早期 / 成长 | 千万-亿 | 资源 + 经验 | 股权稀释 |

## 三、重资产 vs 轻资产（核心分类）

### 3.1 重资产模式

```
特点：
├─ 自有土地 + 物业 + 设备
├─ 投资大（亿元级）
├─ 回报期长（5-15 年）
├─ 资产沉淀大
└─ 适合：主题公园 / 度假区 / 山岳景区

典型：
├─ 古北水镇：70 亿
├─ 上海迪士尼：340 亿
├─ 复星亚特兰蒂斯：110 亿
└─ 长隆：累计投入 200+ 亿
```

### 3.2 轻资产模式

```
特点：
├─ 租赁 / 委托 / 品牌输出
├─ 投资小（千万级）
├─ 回报期短（1-3 年）
├─ 资产沉淀少
└─ 适合：文化院落 / 演艺 IP / 管理输出

典型：
├─ 酒店集团：华住/锦江（管理输出）
├─ 主题娱乐：迪士尼品牌授权
├─ 景区管理：华侨城轻资产管理输出
└─ 演艺 IP：宋城"千古情"模式
```

## 四、国内景区 REITs 现状（关键板块）

### 4.1 已上市景区 REITs（截至 2026）

| REITs | 标的资产 | 发行规模 | 收益率 |
|-------|---------|---------|-------|
| **华夏越秀高速** | 高速公路 | 21 亿 | 6%+ |
| **华夏中国交建** | 高速公路 | 93 亿 | 5%+ |
| **国金中国铁建** | 高速公路 | 47 亿 | 5%+ |
| **中航首钢绿能** | 垃圾发电 | 13 亿 | 5%+ |
| **华安张江光大** | 园区物业 | 14 亿 | 4%+ |

**文旅景区 REITs 仍处于探索期**：
- 2024 年首单文旅 REITs 上市尝试
- 主要瓶颈：景区营收稳定性 / 现金流可见性 / 季节性
- 头部候选：乌镇/古北水镇/长白山部分资产

### 4.2 文旅 REITs 难点

```
1. 营收季节性（现金流不稳定）
2. 维护成本高（设施老化/安全压力）
3. 政策依赖（保护/准入清单）
4. 评估难（无形资产占比高）
5. 退出渠道（产权 vs 经营权）
```

## 五、EOD 模式（生态导向开发）

**定义**：以生态保护为前提，整合产业、城市、景观，实现生态价值转化。

**典型案例**：
- **湖南怀化**：沅江流域生态廊道
- **江西赣州**：山水林田湖草沙
- **浙江安吉**：余村"两山"实践

**对景区意义**：
- 政策资金（中央预算 + 地方配套）
- 跨周期（10-30 年）
- 适合生态资源型景区

## 七、投融资决策框架（5 步法）

```
Step 1 · 投资测算（重/轻资产选择）
Step 2 · 资金组合（自有 + 债权 + 股权 + 政策）
Step 3 · 退出路径（IPO/REITs/转让/分红）
Step 4 · 风险分配（与合作伙伴/政府/银行）
Step 5 · 治理结构（决策权 / 监督权 / 收益权）
```

## 八、失败模式归纳

```
投融资失败 5 大模式：
├─ 投资高估（实际投入远超预算）
├─ 收入低估（运营后客流/价格低于预期）
├─ 现金流断裂（淡季/疫情/政策变化）
├─ 退出失败（IPO/REITs 无法落地）
└─ 政策依赖（补贴取消后盈利难）
```
