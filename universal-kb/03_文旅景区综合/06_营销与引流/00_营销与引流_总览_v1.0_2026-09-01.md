## 一、定义

**营销** = 景区品牌建设、产品包装、价格策略、渠道管理的综合
**引流** = 将目标客户从认知→兴趣→决策→行动→分享的全链路触达

## 二、5 大营销渠道

| 渠道 | 现状 | 占比趋势 | 头部玩家 |
|------|------|---------|---------|
| **OTA**（携程/美团/飞猪） | 主流 | 30-40% | 携程系 / 美团 |
| **小红书** | 增长最快 | 15-25% | 小红书 |
| **抖音/快手** | 内容获客 | 15-25% | 抖音 |
| **微信/视频号** | 私域 | 10-15% | 腾讯系 |
| **线下/旅行社** | 传统 | 10-15% | 各地旅行社 |

## 三、营销策略 6 大模块

### 3.1 品牌定位
- **核心理念**：差异化 + 独特价值
- **传播语**：3-7 字 + 强记忆
- **视觉系统**：VI / SI / IP 形象

### 3.2 内容营销
- **种草内容**：小红书 / 抖音 / B 站
- **直播带货**：抖音 / 视频号
- **短视频**：15-60 秒
- **KOL/KOC 合作**：头部 + 腰部 + 素人

### 3.3 价格策略
- **门票价格**：基础票 + 套票 + 联票 + 年卡
- **季节性定价**：旺季 / 淡季 / 平季
- **动态定价**：基于预订/库存/天气
- **会员定价**：年卡 / 季卡 / 月卡

### 3.4 渠道策略
- **OTA 直签**：携程、美团、飞猪、同程
- **分销代理**：线下旅行社 + 团购
- **私域直销**：公众号 + 小程序 + 视频号
- **跨界合作**：酒店 + 餐饮 + 交通

### 3.5 事件营销
- **主题节庆**：春花朝 / 夏夜游 / 秋丰收 / 冬灯会
- **明星代言**：流量 + 信任
- **IP 联名**：跨界 / 爆款
- **公益营销**：环保 / 助农 / 文化

### 3.6 数字营销
- **SEO/SEM**：搜索引擎
- **程序化广告**：DSP / DMP
- **数据中台**：用户画像 / 行为分析
- **A/B 测试**：创意 + 文案 + 落地页

## 四、引流漏斗模型

```
曝光（Impression）
├─ 信息流广告 / KOL 内容 / 自然搜索
    ↓ 5-10% CTR
访问（Visit）
├─ 落地页 / OTA 详情页 / 小程序
    ↓ 10-20% 转化率
预订（Booking）
├─ 下单 / 支付
    ↓ 80-90%
到访（Visit）
├─ 实际入园
    ↓
复购 + 推荐（Repeat）
```

## 五、典型案例

### 5.1 成功：乌镇互联网大会
- **策略**：借势顶级 IP（互联网大会）
- **效果**：年客单价 +30% + 商务客占比 +50%

### 5.2 成功：西安大唐不夜城
- **策略**：抖音爆款（不倒翁小姐姐）
- **效果**：日均客流 +200% + 全国知名度

### 5.3 成功：洪崖洞（重庆）
- **策略**：夜景 + 抖音二次创作
- **效果**：单日客流破 10 万

### 5.4 失败：某古城营销
- **失败原因**：依赖传统 OTA + 缺乏内容运营
- **后果**：年客流连续下滑

```

├─ 价格战（破坏品牌）
├─ 缺乏数据（凭感觉投放）
└─ 短期化（一次性活动）
```
