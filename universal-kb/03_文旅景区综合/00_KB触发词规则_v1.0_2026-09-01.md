## 二、KB 定位（不可违反）

### 2.1 服务对象（多方位）

```
独立文旅景区综合 KB 服务对象
├─ B166ER 自身（景区类项目深度分析 + Agent 训练）
├─ Eric 个人战略（文旅投资 + AHL + 跨集团 + 个人决策）
├─ 未来第三方（景区咨询 / 项目尽调 / 投资决策）
└─ 任何调用者（需要文旅景区知识的场景）
```

### 2.2 不绑定原则

- ❌ **不绑定任何集团**（华侨城/复星/长隆/宋城/海昌/迪士尼/华侨城/...）
- ❌ **不绑定任何项目**（不是狮子山/某古城/某度假区附属）
- ❌ **不绑定任何当前工作场景**（不是安逸集团当前任务附属）
- ❌ **不绑定任何时间点**

### 2.3 失败案例是核心价值

Eric 23:34 原话：**"成功的失败的，比比皆是"**

**KB 的核心价值不只是成功模板，更是失败教训库**。

每板块必须包含：
- ✅ 成功案例（标杆）
- ✅ 失败案例（教训）
- ✅ 头部 + 中部 + 尾部玩家

## 三、写作标准（KB 基础认知迭代标准）

### 3.1 必含维度

| 维度 | 标准 |
|------|------|
| **景区类型覆盖** | 山岳/湖泊/古城古镇/主题公园/度假区/温泉/海岛/沙漠/草原/森林/文化遗址/红色旅游/乡村/工业遗产/城市公园 |
| **运营模式覆盖** | 公司化/特许经营/PPP/EOD/REITs/委托管理/品牌输出 |
| **投融资覆盖** | 重资产/轻资产/REITs/ABS/产业基金/PPP/EOD/政策资金 |
| **营收结构覆盖** | 门票/二消（餐饮/住宿/演艺/文创/旅拍/婚庆/研学/手作/科技体验）|
| **玩家覆盖** | 国内头部（华侨城/复星/长隆/宋城/海昌/中青旅/曲江）+ 国际（迪士尼/环球/六旗/默林/华纳）|
| **政策覆盖** | 世界遗产/5A/古城保护条例/特许经营条例/环评/林地/水域/消防 |

### 3.2 必含结构（每篇）

- **定义 + 业务边界**（与邻近概念区分）
- **5 维认知**（历史/当下/原因/未来/底层逻辑）
- **全球 + 中国双轨**（头部玩家对照）
- **成功 + 失败案例对照**
- **关键指标 / 行业基准**
- **R66 核对状态**（来源 / 时点 / 一致性）

### 3.3 失败案例标注（v1.0 新增）

每篇必须包含「失败案例」专章：

```
## 失败案例

| 案例 | 类型 | 失败原因 | 教训 |
|------|------|---------|------|
| ... | ... | ... | ... |

> **失败模式归纳**：成功 = 难以预测，失败 = 模式可循
```

### 3.4 Agent 训练语料标注

每篇文件末尾应标注：
```
## RAG 召回标注
- 召回关键词：[关键词1] [关键词2] ...
- 适用问题类型：[事实型] [分析型] [决策型]
- 数据时点：[YYYY-MM]
- 置信度：[高/中/低]
- 是否含失败案例：[是/否]
```

### 3.5 禁用模式

- ❌ 不写"对XX集团的价值"
- ❌ 不假设任何集团作为内置读者
- ❌ 不纠结"集团视角 vs 行业视角"
- ❌ 不出现任何内部集团名称（如无必要）

## 四、增补 vs 重写

### 4.1 三种更新方式

| 方式 | 触发场景 | 操作 |
|------|---------|------|
| **增补** | 加新板块 / 新文件 / 新维度 | 新建文件，路径符合 KB 结构 |
| **迭代** | 在现有内容上做版本号升级 | 文件名加 v1.x 或 v2.0 |
| **不重写** | 已交付内容仍有效 | 仅在顶部加 note，不改正文 |

### 4.2 版本号规范

```
v1.0  → 首次交付
v1.x  → 小幅更新
v2.0  → 重大升级
v3.0+ → 跨代升级
```
