## 一、定义

**核心 KPI** = 景区运营的关键绩效指标，用于评估经营效果 + 决策依据
**评估** = 基于 KPI 的多维度综合评价体系

## 二、4 大类 KPI 体系

### 2.1 流量类 KPI

| KPI | 定义 | 行业基准 | 关键性 |
|-----|------|---------|--------|
| **年接待量** | 全年游客人次 | 山岳 200-500 万 / 古城 2000 万+ | ⭐⭐⭐⭐⭐ |
| **日均接待量** | 全年日均 | 山岳 5000-15000 / 古城 5-10 万 | ⭐⭐⭐⭐ |
| **旺季日峰** | 旺季单日 | 山岳 1.5-3 万 / 古城 20-40 万 | ⭐⭐⭐⭐ |
| **淡旺季比** | 旺/淡 比值 | 山岳 5-10 / 度假区 2-3 | ⭐⭐⭐ |

### 2.2 营收类 KPI

| KPI | 定义 | 行业基准 |
|-----|------|---------|
| **年营收** | 全年总收入 | 山岳 5-30 亿 / 古城 50-200 亿 |
| **客单价（人均消费）** | 总营收/接待量 | 山岳 200-500 / 古城 500-1500 |
| **门票依赖度** | 门票收入/总营收 | 健康 < 50% / 危险 > 80% |
| **二消占比** | 二消/总营收 | 健康 50%+ / 危险 < 30% |
| **GOP 率** | GOP/营收 | 健康 35-50% / 危险 < 20% |
| **EBITDA 率** | EBITDA/营收 | 健康 25-40% / 危险 < 10% |
| **净利润率** | 净利/营收 | 健康 15-25% / 危险 < 5% |

### 2.3 体验类 KPI

| KPI | 定义 | 行业基准 |
|-----|------|---------|
| **NPS（净推荐值）** | 推荐者%-贬损者% | 健康 50+ / 优秀 70+ |
| **OTA 评分** | OTA 平台综合分 | 健康 4.5+ / 优秀 4.8+ |
| **复购率** | 年内复购游客/总游客 | 健康 15-30% |
| **停留时长** | 游客平均停留 | 半日票 3-5h / 一日票 6-10h / 多日 2-5 天 |
| **舆情指数** | 媒体/社交平台评价 | 正面 80%+ |
| **投诉率** | 投诉/接待量 | 健康 < 0.1% |

### 2.4 运营类 KPI

| KPI | 定义 | 行业基准 |
|-----|------|---------|
| **员工人均产值** | 营收/员工数 | 健康 30-80 万 |
| **安全事件率** | 安全事件/接待量 | 0 |
| **服务响应时效** | 客服响应时长 | 健康 < 30 秒 |
| **设备完好率** | 完好设备/总设备 | 健康 95%+ |
| **消防安全** | 消防演练频次 | 月度 |
| **能源消耗** | 单位接待能耗 | 持续下降 |

## 四、KPI 评估模型

### 4.1 平衡计分卡（BSC）应用

```
财务维度 ── 营收 / 利润 / ROI / GOP
客户维度 ── NPS / 复购 / 客单价 / 满意度
内部流程 ── 安全 / 效率 / 标准化
学习成长 ── 员工 / 创新 / 文化
```

### 4.2 评估频率
- **年度**：董事会 / 战略评估
- **季度**：经营分析会
- **月度**：KPI 看板
- **每日**：流量 + 安全 + 服务
- **实时**：舆情 + 设备

## 五、KPI 失败模式

```
失败模式 5 类：
├─ 单一 KPI 崇拜（只看接待量/客单价，忽视长期）
├─ KPI 造假（数据失真）
├─ KPI 失衡（重流量轻利润）
├─ KPI 错位（与战略脱节）
└─ KPI 不作为（评估后无行动）
```
