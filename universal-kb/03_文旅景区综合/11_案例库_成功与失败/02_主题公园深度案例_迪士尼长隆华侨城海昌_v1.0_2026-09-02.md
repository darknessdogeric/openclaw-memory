## 一、上海迪士尼（全球顶级 IP + 本土化标杆）

### 1.1 基本信息
| 维度 | 数据 |
|------|------|
| 投资 | 约 **340 亿 RMB**（迪士尼 43% + 申迪集团 57%） |
| 开业 | 2016-06-16 |
| 占地 | 390 公顷 |
| 定位 | 迪士尼全球第 6 家 / 中国唯一 |
| 关键 IP | 米奇 / 漫威 / 星球大战 / 加勒比海盗 |

### 1.2 关键数据（2024-2025）
- 年接待量：1000-1300 万人次（疫情前高峰）
- 客单价：600-1000 元（含门票 + 园内消费）
- 年营收：100-150 亿（估算）

### 1.3 核心成功因素

1. **顶级 IP**：百年积累，授权体系成熟
2. **巨额投资**：340 亿打造极致体验
3. **持续更新**：每年新增主题区/项目
4. **本土化**：融入中国元素（十二朋友园 / 春节主题）
5. **唯一性**：中国境内唯一迪士尼（稀缺性）

### 1.4 对标启示
- 主题公园是 **IP + 重资产 + 持续投入** 的综合能力
- 没有 IP 基础不要轻易做主题公园

## 二、长隆（民营主题公园龙头）

### 2.1 基本信息
| 维度 | 数据 |
|------|------|
| 控股 | 长隆集团（苏志刚家族，民营） |
| 开业 | 1989（香江野生动物世界）|
| 资产 | **累计投入 200+ 亿** |
| 项目 | 广州 + 珠海横琴 + 清远 |
| 关键 IP | 自有动物 IP + 海洋主题 |

### 2.2 核心项目
- **广州长隆**：野生动物世界 + 欢乐世界 + 水上乐园 + 飞鸟乐园 + 长隆酒店
- **珠海长隆**：海洋王国（全球最大海洋主题）+ 长隆飞船酒店
- **清远长隆**（在建）

### 2.3 财务估算
- **年接待量**：4000+ 万人次（广州 + 珠海合计）
- **年营收**：100+ 亿（估算，未上市无公开数据）
- **净利率**：20%+

### 2.4 核心成功因素

1. **动物/海洋 IP 差异化**：与迪士尼 IP 错位
2. **粤港澳大湾区深耕**：25+ 年单一区域深耕
3. **酒店 + 主题综合**：客房与主题公园一体
4. **家族企业长期投入**：代际传承稳定
5. **生态运营**：动物繁殖/保护 + 旅游 + 教育的产业链

### 2.5 风险点
- 单一民企决策风险
- IP 持续更新能力
- 二三线城市扩张风险（清远长隆进度）

## 三、华侨城（央企主题公园集团）

### 3.1 基本信息
| 维度 | 数据 |
|------|------|
| 控股 | 华侨城集团（央企，归属国务院国资委）|
| 上市 | 华侨城 A（000069.SZ）+ 华侨城 H |
| 主营 | 主题公园 + 地产 + 文旅综合体 |
| 关键 IP | 欢乐谷 + 玛雅海滩 + 锦绣中华 + 世界之窗 |

### 3.2 资产规模
- 全国主题公园 8+ 家（欢乐谷连锁）
- 文旅城/度假区 20+ 个
- 累计投资千亿级

### 3.3 营收结构
- 主题公园：营收 100+ 亿
- 地产：营收 500+ 亿（正在去地产化）
- 文旅综合：营收 100+ 亿
- 整体集团营收：800+ 亿（2024）

### 3.4 战略转型（2025-2026）
- **去地产化**：减少房地产业务
- **转型文旅运营商**：聚焦主题公园 + 文旅综合体
- **挑战**：负债高 + 营收下滑

### 3.5 核心特征
- **央企背景**：政策资源 + 长期投入能力
- **连锁化**：欢乐谷可复制模型
- **国央企代表性**：与文旅部 / 地方政府合作密切

### 3.6 对标启示
- 主题公园可连锁化（欢乐谷模式）
- 但去地产化是央企转型必由之路
- 国央企市场化能力是关键挑战

## 四、海昌海洋公园（港股 · 海洋主题）

### 4.1 基本信息
| 维度 | 数据 |
|------|------|
| 上市 | 海昌海洋公园（02255.HK）|
| 项目 | 上海 + 大连 + 青岛 + 成都 + 重庆 + 苏州 + 武汉 + 长沙 + 烟台 + 郑州 |
| 定位 | 海洋主题 + 主题公园连锁 |
| 关键 IP | 海洋动物（虎鲸/鲸鲨）+ 极地 |

### 4.2 财务数据（关键警示）

| 指标 | 2024 | 2025 | 同比 |
|------|------|------|------|
| **总营收** | 18.2 亿 | 15.5 亿 | **-14.8%** |
| **主题公园收入** | — | 14.8 亿 | 95.4% 占比 |
| **毛利** | 4.19 亿 | 3.04 亿 | -27.5% |
| **毛利率** | 23.0% | 19.6% | -3.4pp |
| **净亏损** | **-7.50 亿** | **-9.84 亿** | 亏损扩大 |
| **总资产** | — | 108 亿 | — |
| **总负债** | — | 56.5 亿 | 净负债率 171.2% |

### 4.3 关键事件
- **2025-10 融创星海（融创系）认购 51 亿新股**——控制权变更
- 融创系（孙宏斌）入主海昌
- 试图扭亏

### 4.4 失败教训（Eric 强调：失败案例才是 KB 真正价值）

#### 教训 1：**重资产 + 同质化**
- 10+ 项目分布于二三线
- 海洋主题 IP 不强（vs 长隆海洋王国）
- 单店投资大，但客流不足

#### 教训 2：**IP 不足**
- 海洋主题可复制性弱于迪士尼 IP
- 没有独家 IP（虎鲸有动物保护争议）
- 持续投入更新能力不足

#### 教训 3：**扩张过快**
- 2017-2020 集中开业 7 个项目
- 负债率 171%（2025）
- 单店亏损 + 高负债 → 现金流断裂

#### 教训 4：**门票依赖 95.4%**
- 主题公园收入 14.8 亿 / 总收入 15.5 亿 = 95.4%
- 二消占比仅 4.6%（远低于行业 20-30%）
- 收入结构最不健康的主题公园集团

### 4.5 对标启示
- 主题公园是"重资产 + 强 IP + 高负债"组合
- 任何一环出问题就崩盘
- 海昌案例是"主题公园最危险的失败模式"

## 六、对狮子山项目的启示

### 6.1 主题公园核心能力
- **IP 是护城河**：没有 IP 不要做主题公园
- **重资产需匹配流量**：海昌 10 项目分布过广 → 失败
- **二消要 > 30%**：海昌 4.6% 是不健康的关键

### 6.2 狮子山应避免
- 不要做"主题公园"模式（无 IP + 无重资产能力）
- 不要做"海洋动物"等敏感 IP
- 不要连锁化（无连锁能力）

### 6.3 狮子山可借鉴
- **IP 塑造**：万古楼 IP 可深耕（纳西文化 + 古城最高点）
- **二消**：海昌 4.6% 是反面案例，狮子山 PDF 目标 20-50% 是合理
- **持续更新**：主题内容每季度更新（vs 海昌老化）
