## 一、为什么必须有失败案例

**Eric 原话**：「关于这种景区文旅综合体项目现在全国很多，成功的失败的。。。比比皆是」

成功案例：
- 网上都有（公开宣传 + 营销文）
- 看 A 复制 B（看似简单，但实际不可复制）

失败案例：
- 没人愿意说（利益相关方掩盖）
- 但是**教训最珍贵**（避免踩坑）
- **这才是 KB 的真正护城河**

## 四、失败模式归纳（8 大类）

```
1. **投资高估型**
├─ 投资 50-100 亿
├─ 实际客流/二消远低预期
├─ 现金流断裂
└─ 案例：楼观台 / 多个 PPP

2. **同质化型**
├─ 业态与周边完全重叠
├─ 缺乏 IP 差异化
└─ 案例：二三线主题公园 / 同质化温泉

3. **流量漏斗失效型**
├─ 区域大盘客流 2000 万+
├─ 景区仅 19 万
└─ 案例：狮子山（古城 2417 万 vs 狮子山 19 万）

4. **保护约束型**
├─ 世界遗产 / 5A / 自然保护地
├─ 业态扩张受限
└─ 案例：核心区扩张被否决

5. **团队能力型**
├─ 国企市场化能力不足
├─ 委托管理失控
└─ 案例：多个国企项目

6. **季节性失控型**
├─ 旺 5 个月 / 淡 7 个月
├─ 淡季全关 + 现金流断裂
└─ 案例：山岳 / 草原 / 海岛

7. **政策依赖型**
├─ 靠补贴生存
├─ 补贴取消后亏损
└─ 案例：多个文化景区

8. **安全/舆情型**
├─ 安全事件（玻璃桥 / 索道）
├─ 舆情危机（差评 / 媒体）
└─ 案例：网红项目安全事件
```

## 五、典型成功模式归纳

### 5.1 乌镇模式
```
├─ 中青旅主导（统一规划）
├─ 持续投入（10+ 年）
├─ IP 持续塑造（互联网大会）
├─ 文化深度（江南水乡）
└─ 客源多元化（观光 + 会奖 + 度假）
```

### 5.2 长隆模式
```
├─ 重资产投入（200+ 亿）
├─ 海洋 + 动物 IP
├─ 多业态组合（酒店 + 演艺 + 餐饮）
├─ 区域化深耕（粤港澳）
└─ 持续更新（10+ 年）
```

### 5.3 拈花湾模式
```
├─ 灵山 IP 输出
├─ 禅意主题（差异化）
├─ 高端定位（客单价高）
├─ 文化深度（场景化）
└─ 一站式度假
```

### 5.4 故宫文创模式
```
├─ 顶级 IP（故宫）
├─ 年轻化（电商 + 跨界）
├─ 高频更新（每年 100+ SKU）
├─ 多渠道（线上 + 线下）
└─ 高溢价（5-10 倍加价）
```
