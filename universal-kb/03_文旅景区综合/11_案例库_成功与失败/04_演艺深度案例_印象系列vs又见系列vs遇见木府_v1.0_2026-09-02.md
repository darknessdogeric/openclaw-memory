## 一、印象系列（张艺谋 / 王潮歌）

### 1.1 起源与结构
- **创始**：张艺谋 + 王潮歌 + 樊跃
- **首演**：印象·刘三姐（2003，广西阳朔）
- **运营**：观印象艺术发展有限公司（张艺谋团队）→ 三湘印象（A股 000863）
- **模式**：实景演出（山水为背景）

### 1.2 主要项目（10+）

| 项目 | 地点 | 投资 | 开业 |
|------|------|------|------|
| **印象·刘三姐** | 桂林阳朔 | 1.6 亿 | 2003 |
| **印象·丽江** | 丽江玉龙雪山 | 1.7 亿 | 2006 |
| **印象·西湖** | 杭州西湖 | 1 亿 | 2007 |
| **印象·大红袍** | 武夷山 | 1.5 亿 | 2010 |
| **印象·普陀** | 舟山 | 2 亿 | 2010 |
| **印象·海南岛** | 海南 | — | 2009 |
| **印象·武隆** | 重庆武隆 | 2 亿 | 2012 |
| **印象·阿诗玛** | 云南石林 | — | 2013 |

### 1.3 关键数据（估算）
- **印象·丽江**：年营收 1.5 亿（2024-2025 估算）
- **印象·刘三姐**：年营收 1+ 亿
- **整个系列**：年营收 5-8 亿
- **门票**：180-280 元
- **每年观看人次**：200-300 万

### 1.4 核心成功因素
1. **张艺谋 IP**：顶级导演 + 强 IP
2. **山水实景**：真实场景震撼感
3. **民族文化**：地域特色 IP 化
4. **持续演出**：每晚 1-2 场
5. **联动景区**：与景区形成 "白天观光 + 晚上演艺" 闭环

### 1.5 关键风险
- 创始人 IP 不可复制（张艺谋已年迈）
- **重投资 + 维护成本高**
- 部分项目运营不佳（海南岛、武隆、普陀等）
- 设备老化 + 演员流失

## 二、又见系列（王潮歌 · 沉浸式创新）

### 2.1 起源与结构
- **创始**：王潮歌（独立于张艺谋）
- **首演**：又见平遥（2013，山西平遥）
- **模式**：沉浸式演出（观众移动 + 多场景）
- **运营**：观印象（北京）

### 2.2 主要项目

| 项目 | 地点 | 投资 | 开业 |
|------|------|------|------|
| **又见平遥** | 山西平遥 | 1.5 亿 | 2013 |
| **又见五台山** | 山西五台山 | 1.2 亿 | 2014 |
| **又见敦煌** | 甘肃敦煌 | 1.8 亿 | 2016 |
| **又见马六甲** | 马来西亚 | — | 2018 |
| **又见红霞** | 山西 | — | 2019 |
| **只有河南** | 河南郑州 | — | 2021 |

### 2.3 关键数据
- **又见平遥**：年营收 1+ 亿（估算），门票 298 元
- **只有河南**：2024 年票房 + 收入 1.5 亿+（估算）
- 整体又见系列年营收 5-10 亿

### 2.4 模式创新 vs 印象系列
```
印象系列 = 山水实景 + 观众坐看
又见系列 = 沉浸空间 + 观众移动 + 多场景

优势：
├─ 室内演出（不受天气影响）
├─ 灵活场地（可大可小）
├─ 沉浸感强
└─ 文化深度

劣势：
├─ 演员成本更高（多场景）
├─ 排演复杂
└─ 复制难度大
```

### 2.5 核心成功因素
1. **王潮歌个人 IP**：与张艺谋齐名
2. **沉浸式创新**：差异化形态
3. **文化深耕**：每个项目深度文化挖掘
4. **平遥模式**：戏剧 + 旅游 + 古城的完美结合
5. **只有河南**：21 世纪新地标（建业集团投资）

## 三、遇见木府（丽江 · 古城内演艺）

### 3.1 基本信息
| 维度 | 数据 |
|------|------|
| 位置 | 丽江古城木府 |
| 投资 | 数千万级（最小干预保护原则） |
| 开业 | 2022-2024 持续升级 |
| 模式 | 沉浸式夜游 + NPC + 演艺 |
| 关键 IP | 徐霞客 + 木氏土司 + 380 年前的丽江 |

### 3.2 核心特点（重要 · 与狮子山对照）

```
"遇见木府" 5 大独特之处：
├─ 小投资（数千万 vs 印象系列 1.5+ 亿）
├─ 古城保护（设备现搭现拆，符合世界遗产约束）
├─ 文化深度（380 年历史 + 徐霞客 IP）
├─ 沉浸式（NCP 互动 + 5 大区域）
└─ 流量转化（木府年 100+ 万游客）
```

### 3.3 商业模式
- **门票**：与木府联票
- **单场时长**：60-90 分钟
- **每天演出**：1-3 场
- **设备投入**：现搭现拆（不破坏古城风貌）

### 3.4 成功因素
1. **最小干预保护**：完全符合世界遗产要求
2. **木府 IP**：丽江古城核心文化 IP 之一
3. **徐霞客文化**：与历史名人深度结合
4. **白天的木府 + 夜晚的遇见**：时空错位体验
5. **可复制性**：模式可输出到其他古城

### 3.5 对狮子山的关键启示

**直接对应**：
- 狮子山（万古楼）vs 木府 = 同片区古城 IP
- 狮子山可借鉴"遇见木府"模式：
  - 小投资 + 最小干预
  - 沉浸式 + 文化 IP
  - 白天的狮子山 + 夜晚的演艺
- 万古楼 IP（纳西文化 + 古城最高点）= 可深度运营

## 五、对狮子山项目的核心启示

### 5.1 演艺是文旅综合体最高效业态
- **客单价高**（门票 200-300 元）
- **二消转化强**（观众停留 + 餐饮 + 周边）
- **IP 沉淀深**（可消费的文化内容）

### 5.2 狮子山的演艺策略建议

#### 路径 A · 借鉴"遇见木府"模式（推荐）
```
├─ 投入：千万级
├─ 模式：万古楼夜游 + NPC + 沉浸式
├─ IP：纳西文化 + 古城最高点
├─ 保护：现搭现拆（符合世界遗产要求）
├─ 流量：木府 100 万 / 狮子山 19 万的转化
└─ 风险：低（投资小 + 易调整）
```

#### 路径 B · 借鉴"又见平遥"模式（深度）
```
├─ 投入：1-2 亿
├─ 模式：大型沉浸式剧场
├─ IP：纳西史诗 + 茶马古道
├─ 挑战：选址 + 投资 + 团队
└─ 风险：中（投资大 + 周期长）
```

#### 路径 C · 借鉴"印象系列"模式（重资产）
```
├─ 投入：1.5-2 亿
├─ 模式：万古楼实景演出
├─ 挑战：古城保护约束
├─ 不可行：违反世界遗产最小干预
└─ 风险：高
```

### 5.3 最优建议

**路径 A + 部分 B**：以"遇见木府"模式为主，控制投资 3000-5000 万，先验证模型。
