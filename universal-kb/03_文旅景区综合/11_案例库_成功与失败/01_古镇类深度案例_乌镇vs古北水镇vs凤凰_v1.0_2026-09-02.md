## 一、乌镇（中青旅控股 · 央企 + IP 标杆）

### 1.1 基本信息
| 维度 | 数据 |
|------|------|
| 控股 | 中青旅控股（600138.SH，央企光大集团旗下） |
| 开业 | 东栅 2001 / 西栅 2007 |
| 资产 | 投资累计 30+ 亿 |
| 定位 | "度假乌镇、文化乌镇、会展乌镇"三位一体 |
| 关键 IP | 世界互联网大会永久会址 + 戏剧节 + 木心美术馆 |

### 1.2 财务数据（2024-2025）

| 指标 | 2024 全年 | 2024H1 | 2025H1 | 同比 |
|------|----------|--------|--------|------|
| **接待量** | 743.38 万 | 382.75 万 | 192.97 万 | -10.91% |
| **营收** | 16.81 亿 | 8.59 亿 | 4.28 亿 | -8.15% |
| **净利** | 2.95 亿 | 1.53 亿 | 0.89 亿 | -20.36% |
| **净利率** | 17.5% | 17.8% | 20.8% | +3pp |

**结构拆解（2024）**：
- 东栅 213.05 万（28.7%）
- 西栅 530.33 万（71.3%）—— **西栅是核心利润中心**

### 1.3 核心成功因素

1. **统一规划 / 央企背景**：中青旅主导，避免短期化
2. **持续投入 25 年**：IP 持续塑造（戏剧节/木心/乌镇互联网大会）
3. **多元收入结构**：观光 + 文化 + 会展 + 度假 + 研学
4. **文化深度**：江南水乡 + 互联网科技跨界
5. **政企合作**：桐乡市国资占股支持

### 1.4 2025 承压原因（关键洞察）
- 7 月南方降水 → 周边市场竞争加剧
- 2025H1 营收同比 -8.15%
- **单店模式的天花板显现**

## 二、古北水镇（中青旅 + 乌镇模式异地复制）

### 2.1 基本信息
| 维度 | 数据 |
|------|------|
| 控股 | 中青旅 + IDG 资本 + 乌镇旅游 |
| 开业 | 2014 |
| 资产 | **投资 70 亿**（10 倍于乌镇）|
| 定位 | 司马台长城脚下 + 京津冀短途休闲 |
| 关键 IP | 司马台长城 + 京郊度假 |

### 2.2 财务数据（2024）

| 指标 | 2024 全年 | 2024H1 | 同比 |
|------|----------|--------|------|
| **接待量** | 129.84 万 | 60.04 万 | -11.50% |
| **营收** | 5.55 亿 | 2.75 亿 | -21.72% |
| **净利** | 持续承压 | 持续承压 | — |

### 2.3 失败教训（Eric 强调：失败案例才是 KB 真正价值）

#### 教训 1：**异地复制的规模陷阱**
- 乌镇模式（30 亿投资）在江南水乡可行
- 古北水镇（70 亿投资）在京郊市场**流量严重不足**
- 单店投入增加 130% / 但接待量只有乌镇的 17.5%

#### 教训 2：**资源 IP 不对等**
- 乌镇有互联网大会永久会址（持续流量）
- 古北水镇只有司马台长城（季节性 + 京郊可替代）
- 京津冀周边游有古北水镇/古北长城/承德/张家口等多竞品

#### 教训 3：**客单价难以提升**
- 京郊客群对价格敏感
- 高端度假产品卖不上价
- 经营弹性不足

#### 教训 4：**重资产 + 季节性**
- 70 亿重资产
- 京郊冬冷夏热，季节性极强
- 折旧 + 利息吞噬利润

### 2.4 中青旅 2024 应对
- 启动"光之城"等沉浸式项目
- 2024H2 获评北京市首家国家级旅游度假区
- 抢抓入境市场（"长城脚下见非遗"）
- 但**持续承压难以根本扭转**

## 三、凤凰古城（湘西 · 老牌古城标杆）

### 3.1 基本信息
| 维度 | 数据 |
|------|------|
| 控股 | 凤凰县人民政府 + 沱江公司 |
| 开业 | 2001 年正式开发旅游 |
| 资产 | 县属国企运营 |
| 定位 | 沈从文 IP + 苗族文化 + 沱江泛舟 |
| 关键 IP | 沈从文 + 黄永玉 + 苗族风情 |

### 3.2 财务数据（估算）
- 年接待量：1500-2000 万人次（疫情前高峰 1800 万）
- 主要收入：门票（148 元套票）+ 船票 + 客栈 + 餐饮

### 3.3 成功因素
- **沈从文 IP**：稀缺、深度、可消费
- **沱江泛舟**：天然差异化
- **苗族文化**：民族文化体验

### 3.4 失败教训（关键）

#### 教训 1：**2013 围城收费事件**
- 强行收取"进城费" 148 元
- 引发游客抵制 / 网络舆情
- 6 年后（2019）才撤销
- **教训**：政府强行收费破坏 IP

#### 教训 2：**过度商业化**
- 沱江两岸酒吧同质化
- "艳遇之都"标签稀释文化 IP
- 失去原有文化调性

#### 教训 3：**保护与开发的平衡**
- 古建筑保护压力
- 商业化挤压原住民
- 改造难度大于乌镇（中青旅没有主导）

### 3.5 与乌镇对照

| 维度 | 乌镇 | 凤凰 |
|------|------|------|
| **主导方** | 中青旅（央企） | 县政府 |
| **统一规划** | ✅ 强 | ❌ 弱 |
| **资本投入** | 30+ 亿 | < 10 亿 |
| **IP 塑造** | 互联网+戏剧 | 沈从文（未被深度运营）|
| **年接待** | 743 万 | 1500+ 万 |
| **年营收** | 16.81 亿 | 估算 5-8 亿 |
| **客单价** | 226 元 | 估算 30-50 元 |

**关键洞察**：**凤凰客流是乌镇 2 倍，但营收只有 1/3**——同片区古城 IP 价值差距巨大。

## 四、对比提炼（对狮子山项目的核心启示）

### 4.1 三案例对照

```
乌镇   = 统一规划 + 央企 + IP 持续 + 多元收入
古北水镇 = 异地复制 + 流量不足 + 70 亿重资产 → 持续承压
凤凰   = 流量大 + 客单价低 + IP 未深度运营 + 商业化失控
```

### 4.2 古镇成功 5 大共性

1. **统一规划**：单一主体强主导（央企/头部民企）
2. **持续投入**：至少 10 年以上深耕
3. **IP 塑造**：差异化、可消费的独特文化
4. **多元收入**：观光 + 文化 + 会奖 + 度假 + 研学
5. **运营专业**：专业团队 / 不是政府机关式运营

### 4.3 古镇失败 5 大共性

1. **政企不分**：政府主导但市场化能力弱
2. **过度商业化**：酒吧街 / 同质化
3. **强行收费**：破坏游客体验（如凤凰 2013）
4. **保护失衡**：商业挤压原住民
5. **IP 不持续**：缺乏持续运营

### 4.4 对狮子山的启示

```
狮子山 vs 乌镇 vs 凤凰：
├─ 主导方：丽江古城发展公司（国企），市场化能力待验证
├─ 资源 IP：万古楼 + 古城最高观景台（差异化有，但 IP 塑造弱）
├─ 客单价：35 元门票 vs 乌镇 226 元（差距 6 倍）
├─ 流量：古城 2417 万 vs 狮子山 19 万（转化率 0.79%）
└─ 核心问题：流量漏斗失效 + 客单价低 + 缺乏 IP 深度运营

→ 狮子山要走乌镇路径（IP 塑造 + 多元收入）
→ 不能走凤凰路径（依赖流量但客单价低）
```
