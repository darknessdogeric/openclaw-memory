## 一、流量漏斗失效定义

**流量漏斗失效型失败**：
- 区域大盘客流大（千万级）
- 项目实际客流小（数万级）
- 转化率 < 1%（行业健康 5-15%）
- 客流漏斗在每个环节都流失

## 二、狮子山（自我对照 · 核心案例）

### 2.1 漏斗分析

```
丽江古城 2025 接待：2417.77 万人次
├─ 古城日均：6.6 万人次
├─ 狮子山日均：520 人次
└─ 转化率：0.79%（行业健康 5-15%）

狮子山漏斗 4 大断点：
├─ 认知（Awareness）：< 5%（游客不知道有狮子山）
├─ 兴趣（Interest）：< 50%（知道但无兴趣）
├─ 决策（Decision）：< 30%（有兴趣但未决策）
└─ 行动（Action）：< 70%（决策但未行动）

总转化：5% × 50% × 30% × 70% ≈ 0.5%（实际 0.79%）
```

### 2.2 漏斗失效原因

#### 原因 1：认知度低
- 狮子山在万古楼 IP 之外知名度弱
- 大部分游客不知道有狮子山景区
- 没有强势的景区 IP

#### 原因 2：兴趣度低
- 古城区已有大量景点（木府/四方街/大研花巷/狮子山夜游）
- 狮子山不是"必游"清单
- 缺乏差异化吸引

#### 原因 3：决策成本高
- 门票 35 元 + 爬山 30 分钟
- 时间成本高（vs 木府更近）
- 信息获取不便

#### 原因 4：行动不便
- 北门通道利用率低（自驾游客比例低）
- 东门通道需爬石阶（体力成本）
- 木府后门通道需要买木府票

### 2.3 PDF 方案尝试解决

| 引擎 | 措施 | 预期效果 |
|------|------|---------|
| **北门摆渡车** | 购票后免票/优惠 | 提升北门通道 |
| **古城商户联合推广** | 消费达额赠票 | 提升认知度 |
| **OTA 分销** | 与携程美团合作 | 提升可见度 |
| **住宿+狮子山套餐** | 与酒店民宿合作 | 提升打包购买 |

**评估**：
- 措施完整但效果待验证
- 关键问题：能否让 2417 万客流中 1-2% 转化为狮子山游客？

## 三、5 大类似案例对照

### 案例 1 · 大理古城双廊镇

**基本信息**：
- 区位：云南大理
- 大盘：年接待 1500+ 万（大理古城）
- 双廊：年接待 50 万
- 转化率：3.3%

**流量漏斗结构**：
```
大理古城 1500 万 → 双廊 50 万
├─ 认知：80%（双廊知名度高）
├─ 兴趣：30%（部分有兴趣）
├─ 决策：50%（环洱海路线）
└─ 行动：50%（最终到访）
```

**成功因素**：
- 双廊知名度（电影"心花路放"）
- 环洱海路线必经
- 海景稀缺资源
- 客栈文化聚集

**乌镇成功因素**：

## 五、对狮子山的核心启示

### 5.1 现状判断

```
狮子山当前漏斗：
├─ 认知：< 5%（极低）
├─ 兴趣：< 50%
├─ 决策：< 30%
├─ 行动：< 70%
└─ 总转化：0.79%

要达到 5% 转化（行业健康）：
├─ 古城 2417 万 × 5% = 120 万 → 提升 6 倍
└─ 古城 2417 万 × 1% = 24 万 → 提升 25%
```

### 5.2 重点突破环节

**优先级**：
1. **认知度（最薄弱）**：古城游客知道有狮子山的 < 5%
2. **行动便利（次薄弱）**：北门通道利用率低
3. **兴趣度（中等）**：差异化定位
4. **决策成本（中等）**：价格策略

### 5.3 具体建议

#### 建议 1：认知度突破（首选 · 投资小效果大）

```
├─ 抖音/小红书 KOL 合作（预算 50-100 万）
├─ 万古楼主题短视频内容
├─ "丽江古城最高观景台" 反复强调
└─ 古城入口广告（合作商户）
```

#### 建议 2：与丽江其他景区联动

```
├─ 与木府联票（互相导流）
├─ 与古城商户联合推广（已规划）
├─ 与丽江股份合作（玉龙雪山）
└─ 与束河/白沙古镇联动
```

#### 建议 3：北门通道重新定位

```
├─ 现状：自驾 / 摆渡车为主，利用率低
├─ 建议：打造"北门 VIP 通道"
│  ├─ 北门专享精品体验
│  ├─ 高端餐饮
│  └─ 独家观景
└─ 目标：从低利用率 → 高净值通道
```

#### 建议 4：错峰定价 + 淡季激活

```
├─ 旺季：保持 35 元 / 限量限流
├─ 淡季：5-15 元 / 错峰激活
└─ 夜间：差异化定价（夜游项目）
```

### 5.4 关键判断

**狮子山的核心问题不是产品问题，而是认知问题**。

即：
- 现有产品（万古楼 + 观景）不差
- 核心问题：游客不知道 / 不知道值得来
- **PDF 方案对"产品"投入多（118 万硬件），对"认知"投入不够**

**建议**：
- **增加营销预算**：从 100-150 万/年 → 200-300 万/年
- **聚焦认知度突破**：抖音/小红书 KOL + IP 塑造
- **联动现有景区**：与木府联票 + 古城商户联动
