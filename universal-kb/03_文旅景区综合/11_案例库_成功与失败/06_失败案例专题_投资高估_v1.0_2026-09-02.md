## 一、失败模式定义

**投资高估型失败**：
- 实际投资 > 预算（2-10 倍）
- 实际客流 < 预测（50-70%）
- 实际收入 < 预期（30-50%）
- 现金流断裂 + 持续亏损
- 退出失败

## 二、5 大典型案例

### 案例 1 · 西安楼观台（文化景区）

**基本信息**：
- 时间：2010-2015
- 投资：约 50 亿
- 类型：道家文化 + 老子文化主题景区

**失败原因**：
1. **投资严重高估**：实际投入远超预算
2. **客流严重不足**：年接待 < 100 万（预期 500 万）
3. **持续靠补贴**：运营 5 年入不敷出
4. **文化 IP 弱**：道家文化难以商业化
5. **选址偏远**：远离客源市场

**教训**：
- 文化 IP 必须可消费
- 投资必须匹配客流
- 选址决定成败

---

### 案例 2 · 某沙漠景区 PPP（大型项目）

**基本信息**：
- 时间：2014-2018
- 投资：50 亿（PPP）
- 类型：沙漠 + 文化 + 度假

**失败原因**：
1. **PPP 政策变更**：政府付费能力下降
2. **客流严重低预期**：年接待 < 50 万（预期 300 万）
3. **社会资本退出**：投资方撤资
4. **区域消费能力不足**：当地人均 GDP 低
5. **运营亏损**：每年净亏 1+ 亿

**教训**：
- 客流测算必须保守
- 区域消费能力必须评估
- PPP 退出机制必须明确

---

### 案例 3 · 某山地景区 PPP

**基本信息**：
- 时间：2015-2020
- 投资：40 亿（PPP）
- 类型：山地 + 索道 + 度假村

**失败原因**：
1. **政策变更**：环保政策收紧，索道建设被叫停
2. **协调失败**：多方利益冲突
3. **投资方退出**：央企退出
4. **项目烂尾**：部分建成但无法运营

**教训**：
- 政策风险必须评估
- 多方协调机制必须完善
- 央企退出风险必须预案

---

### 案例 4 · 海南某大型海洋主题公园

**基本信息**：
- 时间：2010-2018
- 投资：约 30 亿
- 区位：海南

**失败原因**：
1. **投资超预算**：从 20 亿飙到 30 亿
2. **IP 不足**：缺乏独家 IP（vs 长隆海洋王国）
3. **客流不及预期**：年接待 < 100 万（预期 300 万）
4. **主题老化**：8 年未重大更新
5. **设备维护成本高**：年维护成本 1 亿+
6. **持续亏损**：10 年累计亏损 10+ 亿

**教训**：
- 主题公园必须有 IP
- 持续更新是关键
- 设备维护成本吞噬利润

---

### 案例 5 · 某大型实景演艺

**基本信息**：
- 时间：2014-2019
- 投资：约 3 亿
- 类型：山水实景演艺（与印象系列类似）

**失败原因**：
1. **张艺谋 IP 不可复制**：没有导演 IP 支撑
2. **演员流失**：核心演员 3 年内流失 50%
3. **客流持续下滑**：年接待从 30 万 → 5 万
4. **复购极低**：< 2%
5. **运营亏损**：每年净亏 2000 万
6. **2020 疫情**：彻底停摆

**教训**：
- 创始人 IP 不可复制
- 演员流失是演艺最大风险
- 复购率低 = 一次性收入

## 三、失败模式 8 大规律

### 3.1 投资高估 5 大原因

```
1. **建设成本失控**
├─ 设计变更（30-50%）
├─ 材料涨价（20-30%）
├─ 隐性成本（5-15%）
└─ 实际投资 2-3 倍预算

2. **规划过度乐观**
├─ 客流预测 2-5 倍实际
├─ 收入预测 2-3 倍实际
└─ 客流天花板低估

3. **竞争低估**
├─ 周边同类项目
├─ 同片区竞争
└─ 替代品出现

4. **政策风险**
├─ 保护约束收紧
├─ PPP 政策变化
└─ 环保要求提升

5. **运营复杂度低估**
├─ 团队能力不足
├─ 季节性冲击
└─ 营销成本低估
```

### 3.2 财务失败 5 大信号

```
🔴 信号 1：投资超预算 30%+
🔴 信号 2：客流 < 预期 50%
🔴 信号 3：客单价 < 预期 30%
🔴 信号 4：二消占比 < 10%
🔴 信号 5：净利率 < 0% 持续 1 年
```

### 3.3 5 大避免策略

```
1. **投资测算保守**
├─ 投资上浮 30%（应急金）
├─ 客流打 5 折（保守预测）
└─ 客单价打 7 折

2. **分阶段投资**
├─ Phase 1：MVP（最小可行产品）
├─ Phase 2：验证模型后再扩张
└─ Phase 3：复制扩展

3. **多渠道融资**
├─ 自有 + 银行 + 政策 + 战略投资
├─ 避免单一融资渠道
└─ 保留备用融资渠道

4. **退出预案**
├─ REITs（成熟后）
├─ 股权转让（部分退出）
├─ 战略联盟（合作退出）
└─ 资产剥离（止损）

5. **运营绑定**
├─ 引入头部运营方（华侨城/复星）
├─ 管理团队股权激励
└─ 长期利益绑定
```

## 四、对狮子山的核心启示

### 4.1 狮子山现状

```
狮子山 PDF 投资预算：
├─ 硬件投入：118.34 万
├─ 装饰配套：200-300 万/年
├─ 广告投入：100-150 万/年
└─ 日常维护：50 万/年

实际投资可能：
├─ 硬件投入：500-1500 万（保守上浮 4-12 倍）
├─ 全周期投入：2000-5000 万（5 年）
└─ 现金流压力：中等
```

### 4.2 与失败案例对照

```
狮子山 vs 楼观台：
├─ 投资：120 万 vs 50 亿 → 规模差异巨大
├─ 客流：19 万 vs 100 万 → 狮子山略好
├─ 文化 IP：万古楼（可消费） vs 道家文化（难消费）→ 狮子山略好
└─ 结论：狮子山风险远小于楼观台

狮子山 vs 沙漠 PPP：
├─ 投资：120 万 vs 50 亿 → 规模差异巨大
├─ 区位：丽江成熟旅游区 vs 沙漠偏远区 → 狮子山优势明显
└─ 结论：狮子山不存在沙漠 PPP 类风险
```

### 4.3 狮子山风险评估

**总评**：**狮子山不属于"投资高估型"高风险项目**。

理由：
1. **PDF 投入保守**：118 万 vs 类似项目实际 500-1500 万 → 反而是低估
2. **区位优势**：丽江成熟旅游区
3. **IP 较清晰**：万古楼可消费
4. **运营方稳定**：古城发展公司国企背景

**真正的风险**（详见其他失败案例专题）：
- 同质化（古城内咖啡/文创饱和）
- 流量漏斗（转化率 < 0.79%）
- 团队能力（国企市场化能力）
