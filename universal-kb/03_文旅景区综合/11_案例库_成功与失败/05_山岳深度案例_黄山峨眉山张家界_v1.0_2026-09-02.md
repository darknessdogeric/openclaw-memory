| 维度 | 数据 |
|------|------|
| 上市 | 黄山旅游（600054.SH）|
| 控股 | 黄山市国资委（皖南国资）|
| 资源 | 黄山风景区 + 太平湖 + 花山谜窟 |
| 业务 | 索道 + 酒店 + 餐饮 + 客运 + 旅游服务 |

### 1.2 财务数据（2024-2025 估算）

| 指标 | 估算值 |
|------|--------|
| 年接待 | 350+ 万人次 |
| 年营收 | 25+ 亿 |
| 净利率 | 20%+ |
| 毛利率 | 50%+ |
| 索道收入占比 | 40%+ |

### 1.3 核心成功因素

1. **黄山 IP 顶级**：世界文化与自然双重遗产
2. **索道龙头**：云谷/太平/玉屏三条索道，垄断性资源
3. **综合业态**：索道 + 酒店 + 餐饮 + 客运
4. **季节平衡**：春夏秋冬四季均有特色（春花/夏凉/秋色/冬雪）
5. **国企稳定**：长期投入 + 政策支持

### 1.4 关键风险
- **索道老化**：3 条索道超 20 年，需持续投资更新
- **客流天花板**：承载量限制
- **单一 IP 依赖**：完全靠黄山

## 三、张家界（A 股 · 山岳型警示案例）

### 3.1 基本信息
| 维度 | 数据 |
|------|------|
| 上市 | 张家界（000430.SZ）|
| 控股 | 张家界市国资委 |
| 资源 | 张家界国家森林公园（武陵源）+ 天门山 |
| 业务 | 环保客运 + 索道 + 酒店 + 旅游服务 |

### 3.2 财务数据（关键警示）

| 指标 | 2023-2024 |
|------|-----------|
| 年接待 | 600+ 万人次（疫情后强劲） |
| 年营收 | 5+ 亿（2023）|
| 净利率 | **-5%（亏损）** |

### 3.3 核心警示

#### 警示 1：客流 ≠ 利润
- 张家界客流 600 万 >> 黄山 350 万
- 但张家界营收 5 亿 < 黄山 25 亿
- **客单价张家界只有 80 元，远低于黄山 700 元**
- **流量大但客单价低 = 利润薄**

#### 警示 2：过度依赖门票/索道
- 张家界核心收入 = 环保客运（55%）+ 索道
- 二消极弱
- 与狮子山（门票 93%）类似

#### 警示 3：保护约束最强
- 世界自然遗产 + 国家级风景名胜区 + 国家地质公园
- 经营限制最多
- "三索道" + "一线天" 等受限

#### 警示 4：竞争同质化
- 黄山 / 峨眉山 / 张家界 / 武当山 / 五台山...
- 山岳型景区同质化竞争
- 张家界缺乏独特 IP

### 3.4 与狮子山对照（重要）

```
张家界 ≈ 放大版狮子山：
├─ 资源：山岳自然 IP（vs 狮子山古城观景 IP）
├─ 客流：600 万（vs 狮子山 19 万）
├─ 营收：5 亿（vs 狮子山 20.31 万）
├─ 客单价：80 元（vs 狮子山 35 元）
├─ 二消占比：极低（vs 狮子山 7%）
├─ 净利：亏损（vs 狮子山亏损）
└─ 教训：山岳型客单价低 + 二消弱 → 持续承压
```

## 六、对狮子山的核心启示

### 6.1 山岳型景区是"流量大、客单低、二消弱"代表
- 张家界 600 万客流 / 80 元客单价 → 持续亏损
- 黄山 350 万客流 / 700 元客单价 → 20% 净利
- **客单价决定盈利能力**

### 6.2 山岳型景区的差异化路径
- **黄山模式**：自然 IP + 高端化
- **峨眉山模式**：佛教文化 + 综合业态
- **张家界模式**（不推荐）：依赖门票/索道 → 持续承压

### 6.3 狮子山的关键启示

```
狮子山 vs 张家界（放大版）：
├─ 资源：古城观景 IP（vs 山岳自然 IP）
├─ 客流：19 万（vs 600 万）
├─ 营收：20.31 万（vs 5 亿）
├─ 客单价：35 元（vs 80 元）
├─ 净利：亏损（vs 亏损）

差异：狮子山客单价更低（35 vs 80 元）
        张家界有索道垄断（狮子山无）
        狮子山在古城内（保护约束类似）

狮子山要走黄山路径（客单价 700+）
        不能走张家界路径（依赖单一收入）
```
