## 一、定义

**运营模式** = 景区所有权 / 经营权 / 收益权 / 治理结构的分配方式
**治理** = 决策机制 / 监督机制 / 激励机制 / 风险管理

## 二、9 大运营模式

| # | 模式 | 适用场景 | 优势 | 劣势 |
|---|------|---------|------|------|
| 1 | **公司化直营** | 政府全资 / 国企 | 公益属性强 / 长期稳定 | 市场化弱 / 效率低 |
| 2 | **特许经营** | 政府所有 + 民间运营 | 引入专业团队 / 效率高 | 短期化风险 |
| 3 | **PPP（公私合营）** | 政府 + 社会资本 | 风险共担 / 投资大 | 周期长 / 协调成本 |
| 4 | **EOD（生态导向开发）** | 生态 + 产业 + 城市 | 政策资金支持 | 模式复杂 |
| 5 | **REITs（不动产投资信托）** | 成熟景区资产证券化 | 退出渠道 / 资产盘活 | 收益稳定但天花板低 |
| 6 | **委托管理** | 业主 + 管理公司 | 轻资产 / 快速复制 | 控权弱 |
| 7 | **品牌输出** | 头部品牌 + 区域资源 | 品牌溢价 | 品质管控难 |
| 8 | **股权合作（合资）** | 双方股权 + 共同运营 | 利益绑定 | 治理复杂 |
| 9 | **平台分成** | 流量平台 + 景区 | 引流强 / 转化弱 | 利润薄 |

## 四、治理结构 5 大要素

### 4.1 决策机制
- **党委/董事会**：重大决策（投融资/股权变更）
- **管理层**：日常运营（KPI 导向）
- **专业委员会**：收益管理 / 营销 / 安全

### 4.2 监督机制
- **监事会**：财务 + 合规
- **审计**：年度 + 专项
- **纪检**：国央企特殊

### 4.3 激励机制
- **管理层股权激励**（市场化）
- **超额利润分成**
- **KPI 奖金**

### 4.4 风险管理
- **财务风险**：现金流 / 应收账款
- **安全风险**：消防 / 舆情 / 疫情
- **政策风险**：保护条例 / 准入清单

### 4.5 利益相关者
- **政府**：保护责任 + 税收
- **社区**：原住民利益 + 拆迁
- **游客**：体验 + 安全
- **员工**：待遇 + 发展
- **股东**：回报

## 五、丽江古城"三回归"模式（Eric 23:34 关键对照）

```
"三回归"（丽江古城 2025-2026 改革）：
├─ 机构职责回归主业（保护管理 → 古管局）
├─ 属地责任回归地方（地方事务 → 古城区政府）
└─ 经营主体回归市场（运营 → 古城发展公司）
```

**借鉴价值**：
- 保护 / 经营分离
- 属地责任清晰
- 公司化运营释放市场化空间
- 适合世界遗产类景区

## 六、失败模式归纳

```
运营失败 5 大模式：
├─ 政企不分（决策低效 / 责任不清）
├─ 过度依赖单一品牌方（合同到期风险）
├─ 委托管理失控（品质/价格管控失能）
├─ 国企市场化能力不足（团队/激励）
└─ 短期化经营（特许期到期前过度商业化）
```
