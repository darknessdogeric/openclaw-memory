## 五、5 大对标模型

### 5.1 重资产自营型（华侨城 / 长隆）
- **特点**：自有土地 + 物业 + 持续投入
- **优势**：长期稳定 + 品牌沉淀
- **劣势**：投资大 + 周期长 + 退出难

### 5.2 IP 输出型（迪士尼 / 默林）
- **特点**：IP 授权 + 主题公园
- **优势**：轻资产 + 高溢价
- **劣势**：依赖 IP 持续塑造

### 5.3 综合型（乌镇 / 玉龙雪山）
- **特点**：多业态组合（索道 + 酒店 + 演艺 + 文创）
- **优势**：抗风险 + 多元收入
- **劣势**：管理复杂

### 5.4 演艺 IP 型（宋城）
- **特点**：演艺为核 + 主题公园延伸
- **优势**：高复制 + 持续更新
- **劣势**：依赖内容

### 5.5 度假酒店型（Club Med / 亚特兰蒂斯）
- **特点**：客房 + 餐饮 + 体验
- **优势**：高客单价
- **劣势**：季节性 + 重资产

## 七、对标方法论

### 7.1 5 维对标

```
1. 资源禀赋：自有 IP / 区位 / 资源类型
2. 运营模式：自营 / 委托 / IP 输出
3. 营收结构：单一 vs 综合
4. 投资强度：轻 vs 重
5. 抗风险能力：现金流 / 多元化
```

### 7.2 标杆选择

```
对标目标选择：
├─ 同类型景区（如乌镇 vs 凤凰）
├─ 同区域景区（华东 vs 西南）
├─ 同投资规模（如 50 亿 vs 50 亿）
├─ 同营收规模（如 5 亿 vs 5 亿）
└─ 同发展阶段（如初期 vs 成熟）
```
