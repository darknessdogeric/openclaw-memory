## 一、定义

**营收结构** = 景区各项收入来源的占比与组合
**二消（二次消费）** = 游客在景区内除门票外的所有消费

## 二、营收结构 12 大模块

```
景区营收 = 主营业务收入 + 其他业务收入
├─ 主营业务
│  ├─ 门票收入
│  ├─ 二消收入
│  │  ├─ 餐饮（团餐/小吃/特色餐厅）
│  │  ├─ 住宿（景区内酒店/民宿/营地）
│  │  ├─ 交通（索道/游船/电瓶车/接驳）
│  │  ├─ 演艺（剧场/夜游/沉浸式）
│  │  ├─ 文创（IP衍生品/手作/纪念品）
│  │  ├─ 旅拍（拍照/写真/视频）
│  │  ├─ 婚庆（目的地婚礼/婚拍）
│  │  ├─ 研学（课程/营队/定制）
│  │  ├─ 体验（手作/采摘/运动/赛事）
│  │  └─ 科技体验（VR/AR/AI/沉浸式）
│  └─ 商务（会议/团建/包场）
├─ 其他业务
│  ├─ 品牌输出（IP授权/管理输出）
│  ├─ 租金收入（场地/商铺）
│  └─ 政府补贴
```

**关键洞察**：
- **山岳型**：索道 + 门票 + 客运（重资产）
- **度假型**：酒店 + 餐饮 + 体验（重资产）

- **古城古镇**：门票 + 二消 + 文创（最依赖 IP 塑造）

## 四、二消提升路径（核心）

### 4.1 业态升级
- 单一观光 → **复合业态**（咖啡/茶/手作/演艺/夜游）
- 大众消费 → **分众消费**（亲子/银发/Z世代/高净值）
- 同质化 → **差异化**（IP 塑造 + 文化独有）

### 4.2 体验延伸
- **延长停留**：3 小时 → 1 天 → 2 天（住宿 + 夜游）
- **季节延伸**：旺季 → 全季（温泉/滑雪/室内项目）
- **客层延伸**：观光 → 旅居 → 定居（康养/旅居）

### 4.3 收入倍增
- **客单价提升**：从 100 元 → 500 元
- **复购提升**：年卡 / 季卡 / 会员
- **联票**：景区 + 酒店 + 餐饮

## 六、营收结构失败模式（Eric 强调）

```
失败模式 5 类：
├─ 93% 依赖门票（单一营收 = 高风险）
├─ 二消低（同质化 + 缺 IP）
├─ 季节性失控（淡季营收断裂）
├─ 流量漏斗失效（区域大盘客流未转化）
└─ 重资产过载（折旧 + 利息吞噬利润）
```

## 七、典型对标

### 7.1 成功：乌镇
- **结构**：酒店 + 餐饮 + 演艺 + 会奖 + 互联网大会
- **优势**：统一规划 + IP 持续塑造 + 文化深度
- **年营收**：20+ 亿 / 净利率 20%+

### 7.2 成功：复星亚特兰蒂斯
- **结构**：客房 + 水世界 + 餐饮 + 演艺
- **优势**：高端定位 + 单一项目集中投入
- **年营收**：15+ 亿 / 净利率 15%+

### 7.3 失败：某沙漠景区
- **结构**：90% 门票 + 10% 简单二消
- **失败原因**：客流量低 + 季节性强 + 二消弱
- **后果**：年亏损 5000 万+
