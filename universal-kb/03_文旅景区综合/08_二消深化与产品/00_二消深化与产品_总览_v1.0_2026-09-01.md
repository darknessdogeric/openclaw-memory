## 一、定义

**二消深化** = 在景区内除门票外的消费业态设计与产品开发
**产品** = 满足游客差异化需求的体验/商品/服务

## 三、二消深化路径（4 阶段）

```
Stage 1 · 业态补齐（0-12 月）
├─ 餐饮 / 咖啡 / 文创等基础业态
└─ 目标：填补空白 + 满足基本需求

Stage 2 · 体验升级（12-24 月）
├─ 演艺 / 夜游 / 手作等体验业态
└─ 目标：增加停留 + 提升客单价

Stage 3 · IP 塑造（24-36 月）
├─ 文创 IP / 旅拍 / 婚庆等高溢价业态
└─ 目标：建立差异化 + 提升品牌价值

Stage 4 · 生态闭环（36-48 月）
├─ 住宿 / 研学 / 度假等深度业态
└─ 目标：从观光到旅居到生活方式
```

## 四、典型产品模型

### 4.1 旅拍（最热的二消）
- **客单价**：500-5000 元
- **关键能力**：服装 + 道具 + 摄影 + 后期 + 场景
- **代表**：丽江（2000+ 主体 / 10 亿产值）

### 4.2 目的地婚礼
- **客单价**：1-10 万
- **关键能力**：场地 + 仪式 + 摄影 + 餐饮 + 住宿一站式
- **代表**：巴厘岛 / 普吉岛 / 三亚

### 4.3 沉浸式演艺
- **客单价**：100-500 元
- **关键能力**：IP + 演员 + 科技 + 内容
- **代表**：又见平遥 / 印象丽江 / 遇见木府

### 4.4 文创 IP
- **客单价**：30-500 元
- **关键能力**：IP 设计 + 生产 + 渠道 + 营销
- **代表**：故宫文创 / 苏州博物馆 / 敦煌

### 4.5 研学
- **客单价**：200-2000 元
- **关键能力**：课程 + 导师 + 基地 + 安全
- **代表**：敦煌研究院 / 三星堆 / 黄山研学

## 五、产品设计 5 维法

```
1. 客群：谁（亲子/银发/Z世代/高净值/企业）
2. 场景：什么地点（观景台/古宅/山谷/夜场）
3. 内容：什么体验（文化/运动/美食/艺术）
4. 价格：什么档次（大众/中端/高端）
5. 渠道：什么方式（现场/在线/包价）
```

## 六、关键能力要素

### 6.1 业态组合能力
- **互补性**：业态间不冲突
- **协同性**：互相导流
- **层次性**：高低档次搭配
- **节奏性**：日间/夜间搭配

### 6.2 招商能力
- **品牌库**：头部品牌 + 区域品牌
- **租金模式**：固定 / 分成 / 保底 + 分成
- **考核机制**：KPI + 末位淘汰

### 6.3 内容运营能力
- **持续更新**：每月新内容
- **季节调整**：春夏秋冬差异化
- **节日营销**：24 节气 + 主题节

## 七、失败模式（Eric 强调）

```
二消失败 5 类：
├─ 同质化（古城内 60 家咖啡直接竞争）
├─ 缺乏 IP（没有差异化锚点）
├─ 服务标准低（拉低景区整体形象）
├─ 价格混乱（互相杀价）
└─ 季节性失衡（淡季全关）
```
