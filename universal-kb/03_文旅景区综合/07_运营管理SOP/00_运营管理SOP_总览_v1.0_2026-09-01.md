## 一、定义

**运营管理 SOP** = 景区日常运营的标准化作业程序 + 应急响应 + 服务标准

## 二、9 大运营模块

### 2.1 接待能力管理
- **客流承载量测算**：瞬时/日承载量
- **预约 / 分时入园**：错峰 + 体验
- **限流 / 应急预案**：超载时管理

### 2.2 动线设计
- **入园动线**：购票 → 检票 → 入口
- **游览动线**：核心 → 辐射 → 出口
- **应急动线**：紧急疏散通道

### 2.3 票务与闸机
- **电子票务**：二维码 / 人脸
- **闸机管理**：进出记录 + 防伪
- **检票效率**：人均 < 10 秒

### 2.4 讲解服务
- **人工讲解**：持证 + 多语种
- **电子讲解**：APP / 微信小程序 / 智能音箱
- **AI 讲解**：智能识别 + 个性化

### 2.5 环境卫生
- **日常清洁**：厕位比 + 保洁频次
- **垃圾分类**：干湿分离 + 可回收
- **绿化养护**：园林 + 景观

### 2.6 安全管理
- **消防**：监控 + 演练 + 设备
- **治安**：巡逻 + 监控 + 报警
- **医疗**：急救站 + AED
- **特种设备**：索道 / 缆车 / 游乐设备 / 电梯

### 2.7 应急响应
- **自然灾害**：地震 / 暴雨 / 雪灾
- **事故**：踩踏 / 坠落 / 火灾
- **公共卫生**：疫情 / 食物中毒
- **舆情危机**：差评 / 投诉 / 媒体

### 2.8 培训与人员
- **员工培训**：入职 + 在职 + 晋升
- **服务标准**：仪容 / 仪表 / 礼仪
- **绩效考核**：KPI + 奖金

### 2.9 服务质量
- **客户满意度**：NPS / 投诉率
- **神秘客**：第三方暗访
- **服务补救**：投诉处理

## 三、SOP 编制框架

```
每个 SOP 必含：
├─ 适用范围
├─ 责任部门 / 责任人
├─ 操作步骤（编号）
├─ 时间要求（时长 / 频次）
├─ 标准 / 基准
├─ 异常处理
└─ 记录表格
```

## 四、关键 SOP 模板

### 4.1 索道 / 缆车 SOP
- 启动 / 停运标准
- 故障应急
- 安全检查频次

### 4.2 餐饮 SOP
- 食品安全（HACCP）
- 食材采购 + 储存 + 加工
- 餐具消毒

### 4.3 客房 SOP
- 客房清洁标准（11 项）
- 客用品配置
- 工程维护

### 4.4 演艺 SOP
- 演员 / 舞台 / 灯光 / 音响
- 安全预案
- 观众管理

### 4.5 旅拍 SOP
- 摄影师资质
- 服装 + 道具管理
- 客户隐私

## 五、与酒店 KB 联动

- **酒店 KB SOP** ↔ 文旅 KB SOP（客房/餐饮/工程/安保通用）

## 六、失败模式

```
运营失败 5 类：
├─ SOP 缺失（无标准化）
├─ SOP 与现实脱节（执行力差）
├─ 应急响应慢（出事才反应）
├─ 培训不足（员工能力差）
└─ 安全疏忽（隐患排查不彻底）
```
