## 一、定义

**保护** = 对景区资源的法定保护（世界遗产/文保单位/生态/林地/水域）
**法规** = 约束景区运营的法律法规 + 政策 + 标准

## 二、5 大保护层级

### 2.1 世界文化遗产
- **国际公约**：《保护世界文化和自然遗产公约》（UNESCO）
- **管理要求**：完整性 + 原真性 + 最小干预
- **影响业态**：所有改造需 UNESCO 评估
- **代表**：丽江古城 / 平遥古城 / 莫高窟

### 2.2 国家 5A 级景区
- **国家标准**：《旅游景区质量等级的划分与评定》GB/T 17775
- **管理要求**：12 大类 212 项标准
- **影响业态**：服务 + 环境 + 管理
- **复核**：每 3 年一次

### 2.3 文物保护单位
- **法规**：《文物保护法》（2024 修订）
- **分级**：国家级 / 省级 / 市级 / 县级
- **管理要求**：分级保护 + 修缮审批
- **影响业态**：文物保护范围限制商业

### 2.4 自然保护地
- **法规**：《自然保护区条例》/《风景名胜区条例》
- **分级**：国家级 / 省级 / 市级
- **管理要求**：核心区 / 缓冲区 / 实验区分级管控
- **代表**：张家界 / 黄山 / 张家界 / 武陵源

### 2.5 林地 / 水域 / 草原
- **法规**：《森林法》/《水法》/《草原法》
- **管理要求**：使用许可 + 补偿
- **影响业态**：建设受限

## 四、4 大政策保护机制

### 4.1 经营项目准入清单
- **机制**：分级管理（扶持/倡导/不鼓励/禁止）
- **丽江古城示例**：
  - **扶持**：文化院落 + 特色手作
  - **倡导**：民宿 + 咖啡 + 文创
  - **不鼓励**：低端商铺
  - **禁止**：16 类（网吧、电子玩具、建筑材料等）

### 4.2 总量控制
- **客流承载量**：核心区 / 缓冲区上限
- **建设规模**：总建筑面积上限
- **商业网点**：业态比例限制

### 4.3 联审联管
- **机制**：多部门联合审批 + 监管
- **丽江古城示例**：古管局 + 文旅局 + 公安 + 消防 + 食药

### 4.4 巡查整改
- **机制**：年度专项巡查 + 整改通报
- **影响**：项目立项 + 运营调整

## 五、世界遗产的特别约束

### 5.1 完整性约束
- **不得**：拆建 / 改变风貌 / 破坏肌理
- **可做**：修缮 + 整治 + 活化利用

### 5.2 原真性约束
- **不得**：伪造 / 仿古 / 重建
- **可做**：修旧如旧 + 真实修复

### 5.3 最小干预约束
- **不得**：过度商业化 / 过度旅游化
- **可做**：保护优先 + 适度开发
