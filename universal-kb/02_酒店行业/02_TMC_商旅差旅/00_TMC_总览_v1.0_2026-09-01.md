## 一、定义与业务边界

**TMC** = **T**ravel **M**anagement **C**ompany（商旅管理公司）

**核心定义**：为企业提供差旅出行全流程管理服务的第三方公司，业务覆盖：
```
商旅全流程
├── 政策制定（T&E Policy）
├── 机票预订（含 GDS/直连）
├── 酒店预订（含 RFP 协议价）
├── 用车/接送（机场/会议）
├── 火车票/高铁票
├── 签证/护照服务（国际差旅）
├── 差旅审批流程（OA 集成）
├── 差旅报销（T&E Expense）
├── 差旅数据分析（Dashboard）
├── 24/7 客服支持
└── 安全与风控（含商旅保险）
```

> **与 OTA 区别**：OTA 面向 C 端散客 / TMC 面向 B 端企业协议客户（GRM 全球协议价）。

## 三、全球与中国市场

### 3.1 全球 TMC 市场
- **2024 全球规模**：约 **$540 亿美元**
- **增速**：年均 5-7%（疫情后复苏期）
- **头部集中度**：CR4 ≈ 45%（CWT/Amex GBT/BCD + Egencia）

### 3.2 中国 TMC 市场
- **2024 中国规模**：约 **3000-3500 亿 RMB**
- **增速**：年均 12-15%（央国企集采加速）
- **头部集中度**：携程商旅市占 50%+，CR3 ≈ 65%

### 3.3 中国 TMC 三大特征
1. **央国企集采驱动力强**（80% 央国企已集采差旅）
2. **数字化领先**（移动 App 渗透率 >70%）
3. **酒店端议价权强**（携程商旅对酒店的"压价"能力强）

## 五、TMC 与酒店的关系（核心）

### 5.1 三种合作模式

| 模式 | 酒店角色 | 利润分配 | 适用 |
|------|---------|---------|------|
| **协议价（Net Rate）** | 卖给 TMC 的价格 | TMC 加服务费卖给企业 | 央国企主流 |
| **佣金模式（Commissionable Rate）** | TMC 不赚差价 | TMC 收酒店 8-15% 佣金 | 外资/外企主流 |
| **混合模式（Mix & Match）** | 不同客户不同模式 | 按合同定 | 大客户个性化 |

### 5.2 酒店从 TMC 获客的关键

1. **进入 TMC 协议价体系**（RFP 招标）
2. **Last Room Availability（LRA）承诺**（保障商旅客源）
3. **Quarterly Volume Rebate**（季度返佣 3-8%）
4. **Net Rate 比例**（协议价 vs BAR 比例）
5. **数据直连**（Channel Manager / PMS API）
6. **中央发票能力**（一票一结）

### 5.3 酒店与 TMC 谈判核心条款

```
1. Net Rate vs BAR 比例（通常 Net Rate 占 70-90%）
2. Last Room Availability（LRA）条件
3. Volume Rebate 阈值（达标/不达标）
4. Booking Window（提前预订时长 vs 当日订房）
5. Cancel & No-show 政策
6. 双轨定价（散客 vs TMC 价差）
7. 数据共享范围（汇总 vs 明细）
8. SLA（服务等级承诺）
```

## 六、关键概念词典

| 概念 | 全称 | 含义 |
|------|------|------|
| **GDS** | Global Distribution System | 全球分销系统（Amadeus/Sabre/Travelport） |
| **GRM** | Global Rate Management | 全球价格管理（酒店协议价系统） |
| **GBT** | Global Booking Tool | 全球预订工具（Concur/TripSource） |
| **T&E** | Travel & Expense | 差旅与报销 |
| **SLA** | Service Level Agreement | 服务等级承诺 |
| **LRA** | Last Room Availability | 最后一间房保障 |
| **CRS** | Central Reservation System | 中央预订系统 |
| **PMS** | Property Management System | 酒店管理系统 |
| **CM** | Channel Manager | 渠道管理器 |
| **RFP** | Request For Proposal | 招标方案请求（与板块 03 联动） |

## 七、央国企差旅对接（Eric 直接战场）

### 7.1 央国企差旅采购的特点

| 维度 | 特点 |
|------|------|
| **采购方式** | 集中采购（集采）+ 框架协议 |
| **合规要求** | 三重一大 / 公开招标 / 反腐红线 |
| **结算方式** | 月结 / 季结 / 半年结 |
| **决策链** | 行政副总 + 财务 + 纪检 + 业务部门 |
| **核心痛点** | 标准化难 / 票面合规 / 增值税专用发票 / 反腐审计 |
| **首选 TMC** | 央国企自建（铁旅/心已远）+ 携程商旅 |

### 7.2 Eric 8/16 起在推的央国企差旅对接

| 对接方 | 类型 | 进度 |
|--------|------|------|
| **平安四川** | 央企（金融） | 8/16 洽谈 |
| **中国铁旅** | 央企（铁路） | 锦绣天府号合作 |
| **心已远** | 央企（旅游） | 锦绣天府号合作 |
| **重庆文旅** | 地方国企（文旅） | 8/16 谈判 |
| **中央政务平台** | 政府 | 待跟进 |

### 7.3 央国企差旅对接的「三步走」

```
S0 摸底（1 个月）
├─ 集团内部差旅需求梳理（出行量/目的地/频次/季节性）
└─ 56 家酒店哪几家适合做商旅首选

S1 试点（2-3 个月）
├─ 选 2-3 家央国企（铁旅/平安/某省国资）
├─ 走标准 RFP 流程（参见 03_RFP 板块）
└─ 试点酒店首选协议价

S2 平台化（6-12 个月）
├─ 集团商旅中台上线（参考中旅经验）
├─ 与 2-3 家 TMC 形成战略合作
└─ 数字差旅 + 财务集成 + 反腐合规
```
