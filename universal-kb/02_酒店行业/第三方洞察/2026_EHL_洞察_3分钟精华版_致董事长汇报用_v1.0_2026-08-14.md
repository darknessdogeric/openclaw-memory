```
一线城市（T1）：拼效率 + 无感入住 + 智能体验
二三线城市（T2/T3）：拼在地文化 + 微度假 + 体验设计
```
**对应安逸资产**：
- T1 类：总府皇冠假日 / 花园宾馆 → 标准化运营
- T3 类：锦江亚丁 / 古尔沟华美达 / 国堰 / 安逸茶山 → 文创主题酒店 IP 孵化 ### 框架 2：AI 融入服务设计（不是加在运营上）
> **"不是'加个智能音箱'，而是'重新设计服务交付流程'"** **对应 AHL 平台定位**：
- 不是"加 PMS / 加智能客服"
- 而是"重构酒店运营的 AI 中台"
- 产业发展部应主导：AHL 是 AI 服务设计基础设施，不是运营工具 ### 框架 3：内容渠道 > 流量
```
搜索渠道（OTA）vs 内容渠道（抖音/小红书）
→ 2024 年抖音/小红书成为酒店主要流量入口
→ 体验型内容（短视频/直播）驱动预订决策
```
**对应酒店品牌运营**：
- 单店必须配：抖音号 + 小红书号 + 直播能力
- 集团层做：内容矩阵 + 品牌内容运营 SOP --- ## 🟢 可对标（1 个标杆案例） ### 案例：松赞酒店（SONGTSAM）
