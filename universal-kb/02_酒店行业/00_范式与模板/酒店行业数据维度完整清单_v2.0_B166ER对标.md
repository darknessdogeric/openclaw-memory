## 信源矩阵操作工具

```bash
# 看完整 61 个信源
python toolbox/hotel_sources.py --list

# 按类别扫描（如只看 A 类行业协会）
python toolbox/hotel_sources.py --category A

# 按优先级筛选
python toolbox/hotel_sources.py --priority high

# 自动月度扫描 + 生成报告
python toolbox/hotel_sources.py --scan-monthly
```
