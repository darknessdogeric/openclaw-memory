```
中旅酒店 (CTG Hotels & Resort) 总部
├─ 后台:62 人 (传统行政, 维持)
```

## 🎯 中旅方案的核心改革逻辑(本轮)

### 改革 1:**前台 BU 化**(范式转移)

```
旧架构: 集团总部 → 各酒店单店
新架构: 集团总部 → 4 个 BU → 各酒店单店

4 个 BU:
├─ 中高端 BU (中旅睿景品牌运营)
├─ 政务 BU (政务接待酒店运营)
├─ 自持 BU (轻资产管理输出) → 中旅正在去重资产化
└─ 餐饮 BU (餐饮品牌运营)

BU 的核心功能:
├─ 品牌运营 (在中台下放)
├─ 经营决策 (单店业绩负责)
├─ 营销策略 (品牌+新媒体驱动)
└─ 客户运营 (会员体系下沉)
```

### 改革 2:**中台精简 + 数字化下沉到共享**

```
旧架构: 中台 40 人 (品牌13+供应链9+会员11+数字化7)
新架构: 中台 28 人 + 共享中心 +12 (IT 开发)

总能力不变(40 人 → 28 中台 + 12 IT = 40 人),
但 IT 能力**下沉到共享**,服务所有 BU

逻辑: 
├─ 品牌/产品 (策略层) → 中台保留 8 人 (精简)
├─ 数字化 (技术层) → 共享 IT 开发 12 人 (下沉)
└─ 会员/供应链 (运营层) → BU 化或下沉
```

### 改革 3:**后台不动 + 战略强化**

```
后台 62 人不变 (传统行政必须稳定):
├─ 办公室 -3 (精简)
├─ 战略发展部 +1 (强化)
├─ 巡察办公室 +1 (强化纪检)
├─ 纪委办公室 +1 (强化纪检)
└─ 其他不变

逻辑: 后台=管控核心,不能动;但需要"强化战略+强化纪检"
```
