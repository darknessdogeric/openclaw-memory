---

## 摘要

1. **核心问题**:v2.0 给出 5 项核心基因检查表,但**操作化不足**——什么是"独特设计"?"强叙事"?"业主独立"? 缺乏可量化判定。
2. **本报告**把 5 项核心基因拆为 **17 个可量化子项**,每项 0-5 分,总分 25 分;设定三条阈值(>20 纯 / 15-20 准 / 10-15 边缘 / <10 不算)。
3. **10 个品牌实测**:Aman/松赞/大乐之野/桔子 3.0/亚朵/全季/汉庭/voco/Pagoda 君亭/璞隐,展示判定流程。
4. **特别修订**:Eric 10:52 反馈后,**Pagoda 君亭/璞隐/YUNIK 重新归位**为生活方式(中端精品)——说明"主题浮于表面"判定不准确,关键看**是否有清晰叙事**。

## 第一章 5 项核心基因的操作化(17 个子项 × 0-5 分)

### 1.1 基因 1:规模/独特性(0-5 分,权重 15%)

| 子项 | 0 分 | 1-2 分 | 3-4 分 | 5 分 | 评分 |
|------|------|--------|--------|------|------|
| 1.1 单店最大客房数 | >500 间 | 200-500 | 100-200 | <100(中高端),<80(高端),<60(奢华) | |
| 1.2 客房数标准差(品牌内) | 全部统一(模板化) | 80% 集中 | 60% 集中 | 1 店 1 设计(差异大) | |
| 1.3 物业类型多样性 | 全部写字楼/综合体 | 写字楼+少量度假 | 含部分历史/度假 | 度假/历史/地标为主 | |

**评分规则**:
- 中端档位:客房 <200 得 5 分;200-300 得 3 分;300+ 得 1 分
- 奢华档位:客房 <80 得 5 分;80-150 得 3 分;150+ 得 1 分

### 1.2 基因 2:体验/文化叙事(0-5 分,权重 25%)

| 子项 | 0 分 | 1-2 分 | 3-4 分 | 5 分 | 评分 |
|------|------|--------|--------|------|------|
| 2.1 是否有清晰"品牌故事" | 无/模糊 | 模糊主题 | 明确主题(人文/自然/历史) | 多层故事(文化+历史+在地) | |
| 2.2 是否"1 店 1 设计" | 标准模板 | 微调(同模板) | 主题在店间有差异 | 完全独立设计 | |
| 2.3 IP 联名/快闪活动 | 无 | 偶尔 | 定期主题活动 | 长期 IP 矩阵(如亚朵 IP) | |
| 2.4 主题/品牌传播调性 | 商务/经济型 | 标准化(中端精选) | 主题鲜明(文化IP/度假) | 强叙事(独立度假/亚朵IP) | |

**评分规则**:
- 关键判断: **没有清晰故事的连锁标准品牌** → 0-1 分
- 主题酒店(如夜泊君亭"城人事美")→ 3-4 分
- 强叙事(如 Aman/松赞/Aman 故事) → 5 分

### 1.3 基因 3:设计/空间独特(0-5 分,权重 20%)

| 子项 | 0 分 | 1-2 分 | 3-4 分 | 5 分 | 评分 |
|------|------|--------|--------|------|------|
| 3.1 是否有"设计师执刀" | 集团标准化设计 | 集团标准+微调 | 单店定制设计师 | 知名设计师(Jean-Michel Gathy/如恩/Madison Cox) | |
| 3.2 公区面积占比 | <15% | 15-30% | 30-50% | >50%(社交/策展型) | |
| 3.3 "1 店 1 设计"执行 | 0%(标准) | <30% | 30-70% | >90% | |
| 3.4 与在地文化融合 | 标准连锁 | 装饰层融入 | 主题层融入 | 故事/材料/活动/在地全链条 | |

**评分规则**:
- 关键判断: **集团品牌旗下标准化门店** → 1-2 分
- 主题酒店但设计在集团间可复用 → 2-3 分
- 单店定制设计师 + 在地文化深度融合 → 4-5 分

### 1.4 基因 4:客群情感连接(0-5 分,权重 20%)

| 子项 | 0 分 | 1-2 分 | 3-4 分 | 5 分 | 评分 |
|------|------|--------|--------|------|------|
| 4.1 目标客群定位 | 商旅+性价比 | 商务+部分体验 | 体验型(度假/文化/IP) | 高净值度假/Z世代/数字游民/银发 | |
| 4.2 复购率/IP 关注度 | <10% | 10-30% | 30-50% | >50%(亚朵 A 卡 57% 复购) | |
| 4.3 客群"在场"互动(社交/活动/共创) | 无 | 偶尔 | 定期社群活动 | 长期社群运营(亚朵 IP 矩阵/松赞管家) | |
| 4.4 客单价与品牌定位匹配度 | 低价引流 | 性价比 | 中端精品 | 高端/奢华情感溢价 | |

**评分规则**:
- 关键判断: **目标商旅+性价比客群为主** → 0-1 分
- 主题客群(电竞/文化/设计) → 3-4 分
- 高净值度假/数字游民/银发/特定文化粉丝 → 5 分

### 1.5 基因 5:运营独立性或软品牌定位(0-5 分,权重 20%)

| 子项 | 0 分 | 1-2 分 | 3-4 分 | 5 分 | 评分 |
|------|------|--------|--------|------|------|
| 5.1 业主性质 | 集团自营 | 集团委托管理 | 集团品牌+业主经营 | 完全独立业主/家族 | |
| 5.2 集团标准化执行度 | 集团 100% 标准 | 集团 70%+ | 集团 30-70% | 集团 <30% 或软品牌 | |
| 5.3 品牌是否"故事载体" | 集团品牌本身即定位 | 集团品牌叠加业主故事 | 软品牌(业主故事为主) | 独立品牌(无集团) | |

**评分规则**:
- 关键判断: **集团标准品牌(华住/锦江旗下常规品牌)** → 1-2 分
- 软品牌(挂靠 SLH/Autograph/Tapestry)→ 3 分
- 完全独立业主 + 独立品牌 → 5 分
- **特例**: 亚朵/华住集团内的"主题品牌"(A.T.House/夜泊君亭)虽是集团旗下,但**每店独立运营**→ 4 分

## 第二章 总分判定阈值与决策矩阵

### 2.1 总分阈值

| 总分 | 判定 | 含义 |
|------|------|------|
| **22-25** | ⭐⭐⭐ **纯生活方式** | 5 项基因全部满足,无可争议 |
| **17-21** | ⭐⭐ **准生活方式** | 4 项满足,核心基因稳固 |
| **12-16** | ⭐ **边缘生活方式** | 3 项满足,需要补充判定 |
| **7-11** | ❌ **不算生活方式** | 通常 2 项满足,中端标准化 |
| **<7** | ❌❌ **明确不属** | 1 项或 0 项,经济型/标准化 |

### 2.2 决策矩阵(按总分 + 档次定位)

| 总分 | 落入档次 | 归位 | 备注 |
|------|---------|------|------|
| ≥17 + 奢华(¥1,500+) | L1 | 象限 1 奢华度假 | 高端独立度假品牌 |
| ≥17 + 高端(¥800-1,500) | L2 | 象限 2 本土独立 / 象限 3 设计驱动 | 含软品牌高端 |
| ≥17 + 中高端(¥400-800) | L3 | 象限 5 中端精品 + 部分象限 3 | 含软品牌中高端 |
| ≥17 + 中端(¥200-450) | L4 | 象限 5 中端精品(非标中端) | 极少(亚朵轻居/桔子基础部分店) |
| 12-16 + 任何档次 | - | **边缘** | 需说明哪项缺失,可作为过渡带 |
| <12 + 中端及以下 | - | ❌ **明确不属**(中端标准化) | 不入报告 |

## 第六章 方法论使用指南(Eric 后续用)

### 6.1 判定流程

```
1. 拿到一家新酒店品牌
2. 评估 17 个子项 × 0-5 分 = 总分
3. 看总分对应阈值:
   - ≥22: ⭐⭐⭐ 纯生活方式
   - 17-21: ⭐⭐ 准生活方式
   - 12-16: ⭐ 边缘生活方式
4. 看档次(价位段)归入对应象限
5. 对边缘品牌(12-16),看哪项基因缺失最多,决定其归位
```

### 6.2 常见陷阱

| 陷阱 | 反例 |
|------|------|
| 看到"主题酒店"标签就以为是生活方式 | "音乐主题酒店"vs 真正的音乐节主题社区酒店 |
| 看到集团品牌就以为不算 | 亚朵/君亭集团内的"主题品牌"(A.T.House/夜泊)仍算 |
| 看到"小而精"就以为算 | <80 间但纯标准化连锁(如部分小桔子店)不算 |
| 看到"高 ADR"就以为算 | 五星级商务连锁(¥1,500+)不算(高价位但无生活方式基因) |
| 看到"独立运营"就以为算 | 业主独立但集团品牌(如如家精选)不算 |

### 6.3 边缘品牌的处理

对于 12-16 分的"边缘品牌",采用**附加判定法**:
- 加问: "这家酒店在 OTA 上的**点评关键词**是什么?"
- 加问: "这家酒店有**官网/公众号/小红书品牌账号**吗? 推送什么内容?"
- 加问: "这家酒店是否进入**SLH/Design Hotels/Autograph 软品牌**?"

如果**点评关键词是设计/故事/体验**(而非位置/价格/干净),**内容运营有特色**,**进入软品牌集合** → 升级为生活方式
否则 → 维持"边缘/中端标准化"判定
