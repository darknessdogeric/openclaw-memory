## 一、定义与四大业务

**MICE** = **M**eetings + **I**ncentives + **C**onferences + **E**xhibitions / **E**vents

| 业务 | 中文 | 核心场景 | 酒店典型收益贡献 |
|------|------|---------|---------------|
| **Meetings** | 会议 | 企业例会 / 部门会 / 培训会 / 战略会 | 会议室租金 + 餐饮 + 客房 |
| **Incentives** | 奖励旅游 | 高绩效员工海外/国内游 | 团队客房 + 体验消费 |
| **Conferences** | 大会 | 行业大会 / 学术大会 / 政企大会 | 会议包 + 大规模客房 + 展位 |
| **Exhibitions/Events** | 展览 / 活动 | 展会 / 发布会 / 婚礼 / 庆典 | 场地 + 搭建 + 餐饮 |

> **关键洞察**：MICE 客单价是散客的 **3-10 倍**，但销售周期更长、客户决策链复杂（BD 销售线对接）。

## 三、市场规模与趋势

### 3.1 全球与中国
- **全球 MICE 市场**（2024 估算）：约 **$1.2 万亿**（含企业差旅+会议），中国占比 12-15%
- **中国 MICE 市场**（2024 估算）：约 **2.5-3 万亿 RMB**（含企业会议/会奖/展览）
- **增速**：年均 8-10%（疫情后强劲复苏，2024 同比+15%）

### 3.2 五维趋势

| 维度 | 趋势 | 对酒店的影响 |
|------|------|------------|
| **需求结构** | 大型集中会议 → 分散小型 + 混合会议 | 灵活空间 + 数字平台需求 |
| **客群** | 千禧一代进入决策层，Z 世代参会 | 体验化、个性化、社群化 |
| **技术** | 混合会议常态化、AI 翻译/同传、VR 参会 | 投入数字基建 + 软件订阅 |
| **可持续** | ESG 硬指标，绿色会议认证 | 节能会场 + 零塑料 + 碳中和方案 |
| **目的** | 单纯开会 → 团建+激励+企业文化融合 | 体验型消费占比上升 |

## 五、酒店 MICE 业务模式

### 5.1 三种典型模型

| 模型 | 收入结构 | 适用酒店 | 优势 | 劣势 |
|------|---------|---------|------|------|
| **会议型酒店** | 场租 25% + 客房 50% + 餐饮 20% + 其他 5% | 大型综合酒店 | 客单价高 / 一次性规模大 | 季节性强 / 运营重 |
| **MICE 度假村** | 客房 60% + 体验 25% + 餐饮 15% | 度假酒店 / 温泉酒店 | 二次消费高 / 满意度高 | 复购率低 |
| **有限服务型 MICE** | 客房 70% + 会议室 25% + 简餐 5% | 中端有限服务 | 灵活 / 投资轻 | 单价低 / 体验薄 |

### 5.2 关键岗位
- **会议销售总监**（DOSM 兼任）
- **会议经理**（C&E Manager）
- **宴会服务经理**（Banquet Manager）
- **会议服务专员**（Event Coordinator）
- **AV 主管**（兼任）

## 六、关键指标体系

| 指标 | 定义 | 行业基准 |
|------|------|---------|
| **会场面积 / 客房数** | ㎡/间 | 1:5 - 1:10 |
| **宴会厅人均面积** | ㎡/人 | 1.2-1.8 |
| **多功能厅比例** | 可分割会场/总会场 | ≥50% |
| **AV 设备投入** | 占改造投资比例 | 5-10% |
| **会议团队人均消费** | 元/人/天 | 1500-5000（按档次） |
| **会议客户 ADR 倍率** | 会议 ADR/散客 ADR | 0.9-1.3 |
| **会议客户复购率** | 年度复购/总客户 | 30-50% |
| **会议收入占比** | 会议总收入/酒店总收入 | 25-40% |
