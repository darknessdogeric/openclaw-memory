## 第一章 政府官源:文化和旅游部 + 国家统计局

### 1.1 信源明细

| 类别 | 内容 |
|-------|------|
| **机构** | 文化和旅游部 + 国家统计局 |
| **依据** | 《旅游饭店星级的划分与评定》(GB/T 14308-2010) |
| **法定** | 🟢 行政强制力(国标 + 部级评定) |
| **发布** | 《文化和旅游部统计公报》(年度,通常 6 月发布) |

### 1.2 采集方法

1. **酒店自愿申报** + 省市旅游集团 → 提交评定申请
2. **专家现场评审** — 5+ 项硬件门槛,实地打分
3. **前台挂牌** — 颁发国家级星标牌匾
4. **5 年复核** — 到期复核,达不到降级或摘牌

### 1.3 覆盖度(精确数字)

| 指标 | 2024 末 | 2025 末 | YoY |
|------|--------|--------|------|
| **星级饭店总数** | **7,716 家** | **7,586 家** | **-1.68%** |
| **四星饭店** | 2,300 家 | - | - |
| **五星饭店** | 831 家(2026.2) | 822 家(2025.1) | - |
| **整体营收** | 1,557.3 亿元 | 1,448.0 亿元 | **-7.02%** |
| **平均房价 ADR** | 371.7 元/间夜 | 360.2 元/间夜 | **-3.09%** |
| **平均出租率 OCC** | 49.2% | 46.8% | **-4.88%** |

### 1.4 水分评估

| 维度 | 评估 |
|------|------|
| **数据真实性** | 🟢 **极高**(国家信用背书 + 专家现场评审) |
| **覆盖率** | 🔴 **极低** — 7,586 家 vs 37.5 万家 = **仅 2.02%** |
| **时效性** | 🟡 中(年度公报 + 季度补充) |
| **覆盖偏差** | **严重失明** — 98% 酒店(35 万家)完全无数据 |
| **下降趋势真实** | 🟢 真实(三年四连降,2025 关闭 34 万间客房) |

### 1.5 关键发现

1. **覆盖问题**:7,586 家 vs 37.5 万家酒店 = **98% 酒店无任何官方数据**
2. **下架问题**:2025 末比 2024 末减少 130 家 = **-1.68%**(摘牌 > 评上)
3. **下降问题**:**营收 -7.02% / ADR -3.09% / OCC -4.88%** — **三年四连降**,反传统认知(旅游业在复苏,酒店业没复苏)
4. **口径问题**:**全国 2,238 家高星级酒店采用石基信息系统** — **石基"实际市场覆盖率"应高于 78%(高星级)**
5. **地理分布不均**:全国 831 家五星级中,**北京 57 / 天津 7 / 河北 26 / 山西 12 / 内蒙古 12**

### 1.6 修正建议

1. **扩大强制范围**:从"自愿申报" → "**全国 37.5 万家持牌酒店强制披露**"
2. **从星级评审 → 数据评审**:参考酒店接入数据平台 = 享受税收/平台降佣优惠
3. **数据公开口径**:季度发布,**只公开汇总指数**,不公开单店
4. **第三方审计**:四大会计师事务所审计(类似上市公司审计)

2. **数据口径**:**CHA 报告本质上是"OTA 视角的酒店业"** — 与 STR(数据真实但<10%覆盖)形成鲜明对比
3. **指标创新**:**2026 年首次发布"中国住宿业消费指数(HCI)"** = "ADR 指数 / OCC 指数 / 在线预订指数 / 酒店餐饮营收指数 / 信心指数"5 项指数,来源依然 OTA+调研
4. **2026 报告新增**:**品牌价值评估指数**(8 维度 200 品牌首批成员)

1. **公开 PMS 数据比例**:报告应明确标注"OTA 估算法 vs PMS 直采 vs 调研"三类数据的占比
2. **扩大调研样本**:从 110 家 → 1,100 家(10 倍)
3. **公开方法论**:CHA 报告应公开"OTA 反推模型"的输入变量
4. **独立审计**:引入四大会计师事务所审计数据生产流程

## 第三章 中国旅游饭店业协会 CTGA

### 3.1 信源明细

| 类别 | 内容 |
|-------|------|
| **机构** | 中国旅游饭店业协会 CTGA(China Tourist Hotel Association) |
| **性质** | 1986 成立,行业自律组织 |
| **覆盖** | 主要覆盖**星级旅游饭店** |
| **关系** | 与 CHA 并存(后者是综合饭店协会) |

### 3.2 与 CHA 的差异(核心)

| 维度 | CHA(中国饭店协会) | CTGA(中国旅游饭店业协会) |
|------|---------|---------|
| **成立时间** | 1994 | 1986 |
| **主管单位** | 民政部 / 国资委 | 民政部 |
| **覆盖重心** | 综合性饭店(含连锁) | **星级旅游饭店** |
| **主要成员** | 大型集团 + 单体酒店 | **星级饭店为主** |
| **报告权威性** | 🟡 连锁+OTA 估算法 | 🟡 **文旅部授权但更新慢** |
| **数据方法** | OTA 大数据 + 调研 | **酒店上报 + 复核** |
| **口径问题** | 🟡 含连锁+部分单体 | 🟡 **仅星级(2%)** |

### 3.3 覆盖度

| 指标 | 数值 |
|------|------|
| **协会会员数** | ~1,500+ 家(主要为星级饭店) |
| **覆盖酒店占比** | **远低于 CHA**(因星级仅 2%) |
| **数据更新频率** | 年度 + 季度 |

### 3.4 水分评估

| 维度 | 评估 |
|------|------|
| **数据真实性** | 🟡 中(星级饭店必报,但**口径限制**) |
| **覆盖率** | 🔴 **仅覆盖有星级 7,586 家中的一部分** |
| **与 CHA 分裂** | 🔴 **核心问题**:两个协会的同一指标常常数据不同 |
| **可对照性** | 🔴 **不可交叉对照**(Eric 关注的核心问题) |

### 3.5 关键发现

1. **Eric 核心论断**:"**中国旅游饭店业协会的星级酒店数据,和中国饭店协会的非星级酒店的数据,口径并不一致**" — **确认**
2. **2026 合并趋势**:第十五届中国饭店文化节上,**CHA 联合 9 项报告**(含 STR 数据) — 但 CTGA 仍独立发布
3. **历史顽疾**:**两个协会并存 40 年**,数据口径**至今未统一**

### 3.6 修正建议

1. **推动协会合并**:CTGA 整体并入 CHA(参考日本旅馆协会统一口径)
2. **建立统一数据标准**:在文化和旅游部主导下,出台"中国酒店业数据上报国家标准"
3. **数据公开**:两份数据均公开方法论 + 原始数据(便于第三方核对)

## 第四章 STR(Smith Travel Research)

### 4.1 信源明细

| 类别 | 内容 |
|-------|------|
| **机构** | STR(Smith Travel Research) |
| **背景** | 1985 美国宾州兰开斯特,2019 被 CoStar 以 **$4.5 亿美元**收购 |
| **中国业务** | STR China |
| **报告** | STAR(Smith Travel Accommodations Report)月度 |
| **方法** | **直接 PMS 数据采集** |

### 4.2 采集方法(独特性)

1. **酒店自愿加入**:酒店将 PMS 数据授权给 STR
2. **直采 PMS 系统**:STR 直接读取 PMS 中的 OCC/ADR/RevPAR,**不是估算**
3. **数据真实度**:**几乎无水分**(系统直采,无手动填报误差)
4. **MPI / ARI 指标**:STR 发明了 **市场渗透指数(MPI)和平均房价指数(ARI)**

### 4.3 中国覆盖度(关键 — Eric 论断实证)

| 维度 | 评估 |
|------|------|
| **STR 重点客户** | 万豪 / 希尔顿 / 洲际 / 雅高 / 凯悦 / 华住 / 锦江 / 首旅 / 亚朵 / Aman / 松赞 / 裸心 / 等 |
| **国际品牌覆盖率** | 🟢 高(基本全部接入) |
| **本土头部** | 🟢 高(华住/锦江/首旅/亚朵 已接入) |
| **国内中端** | 🟡 中(部分城市便捷/桔子) |
| **国内单体** | 🔴 **几乎不覆盖**(网络效应不足) |
| **覆盖家数估** | **8,000-10,000 家**(推算) |
| **占总市场** | **2.7-3.3%**(以 37.5 万家计) |
| **占客房数** | **5-10%**(推算,头部集团房间占大头) |

### 4.4 水分评估

| 维度 | 评估 |
|------|------|
| **数据真实性** | 🟢 **最高**(PMS 直采,无主观) |
| **样本偏差** | 🔴 **严重偏差**(只覆盖头部,不能代表全国) |
| **Eric 关键洞察** | "**用了等于零**" — 网络效应不足 |
| **外推全国** | 🔴 **不可外推**(头部 vs 单体经营差异巨大) |

### 4.5 STR 中国 2025 关键数据

| 指标 | 数值 | 来源 |
|------|------|------|
| **2025 H1 中国酒店 RevPAR** | **同比 -5%** | STR |
| **高端酒店 RevPAR** | -2%~-4% | STR |
| **中端及以下 RevPAR** | -6%~-8% | STR |
| **奢华酒店 ADR** | -10%(以价换量) | STR |
| **整体入住率 OCC** | 65-70% | STR |
| **整体 ADR** | ¥400-500 | STR |

### 4.7 STR 全球地位

- **全球最大酒店数据公司**
- STAR 报告覆盖全球 90+ 国家,2,100+ 物业
- 福布斯旅游指南 2025 评级全球酒店 — **STR 数据是其重要支撑**
- **美国酒店业的"官方数据"** — 中国没有类似机构

### 4.8 修正建议

1. **降低接入门槛**:STR 单店接入费大幅降低(中国版 STAR Mini)
2. **网络效应机制**:接入 STR 的酒店获得"对标报告"价值(必须保证接入基数)
3. **本土合作**:STR 与绿云/石基战略合作 → 通过 PMS 间接覆盖中小酒店
4. **政府背书**:推动 STR 中国数据被国家统计局采纳为"国家数据补充"

### 7.7 抖音 OTA 入局(2023+)

- 2023.5 上线酒店日历房
- 2024.7 佣金从 4.5% → 8%(与行业持平)

### 7.8 关键发现

1. **数据霸权**:**携程 70% GMV / 8,000 BD / 14,000 客服** = **数据 = 定价权 = 利润**

3. **反垄断痛点**:2025.7 国家市监总局立案 → 携程"调价助手"本质是**数据优势变现**

### 7.9 修正建议

1. **数据强制披露**:要求 OTA 公开**酒店间夜分布**(避免"线上 70%"夸大)
2. **取消调价助手**:国家市监总局强制禁止(类似欧盟 DMA)

## 第十二章 综合修正建议(给 Eric / 给行业)

### 12.1 数据生态重建 5 步走

1. **第一步(1 年)**:行业协会(CHA)牵头成立"中国酒店数据透明联盟",**强制披露 OCC/ADR/RevPAR**

3. **第三步(3 年)**:PMS 数据强制接入(石基 + 绿云 + STR) → 形成"中国酒店业数据平台"
4. **第四步(4 年)**:推动两个协会(CHA + CTGA)合并 → **统一口径**
5. **第五步(5 年)**:打破 OTA 数据霸权 → 携程 70% GMV 必须强制数据互通

### 12.2 Eric 实操建议

基于你的 AHL/医养业务:

1. **数据透明 + 私域会员** = AHL 差异化(参照华住反 OTA 思路)

### 12.3 给中国旅游饭店业协会(CTGA)+ CHA 的建议

4. **酒店私域激励**:对接自有会员系统的酒店享受降佣优惠

### 12.5 给独立咨询机构的建议

1. **公开方法论**:独立咨询机构应公开数据来源 + 模型 + 样本
2. **多源交叉**:CHA + STR + 浩华 + 绿云 联合发布交叉验证报告
3. **审计引入**:独立审计咨询机构数据生产流程
