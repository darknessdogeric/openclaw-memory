## 摘要(Eric 核心论点)

1. **Eric 论断实证**:"全行业没有一个统一数据源" — **确认**
2. **数据源 7 大派别**:
   - 政府官源(文旅部 + 国家统计局)→ 法规级,**但仅覆盖有星级酒店的 7,586 家(占 2%)**
   - 行业协会(中国饭店协会 CHA / 中国旅游饭店业协会 CTGA)→ 手动填报,水分大,**口径分裂**
   - PMS 直采(STR/绿云/石基)→ 数据真实,**但 STR 国内覆盖率估 <10%(主要外资+头部)**
   - OTA 平台(携程/美团/飞猪/抖音)→ 流量大,但**只有线上数据**(线下估)
   - 头部集团财报(华住/锦江/亚朵/首旅/万豪/希尔顿)→ 真实,但**仅覆盖上市集团**
   - 独立咨询(浩华/中研普华/迈点)→ 推算+调研,方法论不透明
   - 学术/媒体(行业大会、自媒体)→ 二三手数据,水分最高
3. **核心矛盾**:**2% 酒店有官方星级 vs 98% 全靠平台算法打分** — 数据主权争议
4. **解决路径**:PMS 数据联盟 + 政府强制数据 + 第三方独立审计(三项缺一不可)

## 第三章 三个根本矛盾

### 3.1 矛盾 1:**2% vs 98%**

- **有官方星级的酒店**:7,586 家 = **2.02%**
- **98% 酒店"无官方数据"** — **依赖平台算法或推算**
- 后果:Eric 看任何"全国酒店平均数据" → **97% 的真实状态是黑的**

### 3.2 矛盾 2:**真实 vs 覆盖**

| 数据源 | 真实度 | 覆盖度 | Eric 总结 |
|-------|-------|-------|----------|
| STR / 财报 | 🟢 **极高** | 🔴 **极低** | "**真实但小样本**" |
| 政府官源 | 🟢 高 | 🔴 极低(2%) | "**权威但失明**" |
| OTA / 行业协会 | 🟡 估算法 | 🟡 中 | "**覆盖广但水分大**" |

**无单一数据源能同时实现 "真实 + 覆盖广"** —— **这就是行业数据困局的根本原因**。

### 3.3 矛盾 3:**OTA 与酒店业的利润剪刀差**

- **携程 2025 H1 净利 91.94 亿** = 日均 5,000 万
- **北京住宿业 H1 收入 -7.3%,利润 -92.9%**
- → **OTA 通过强制调价 + 高佣金(12-20% 甚至 30%)** 从酒店业"吸血"
- → 2025.7 国家市监总局对携程反垄断立案
- → **数据控制权 = 定价控制权 = 利润分配权**

## 第四章 解决方案:数据主权的 3 条路径

### 4.1 路径 1:**PMS 数据联盟 + 政府授权**

**思路**:借鉴国际经验(欧洲 HotelStars 联盟 + 美国 STR 模式)

| 要素 | 中国本土方案 |
|------|------------|
| **数据源** | 绿云 + 石基 + 携程 + 浩华(已有) |
| **标准化** | 成立"中国酒店数据联盟" + 国务院授权 |
| **覆盖** | 通过石基覆盖 78% 高星级 + 绿云覆盖 9.8% 中端 |
| **样本框架** | **强制 PMS 数据接入** + 单体酒店自愿(享受税收优惠) |
| **公开口径** | 季度发布行业指数(类似 STR 美国 STAR) |
| **参照** | 国家医疗保障局"国家医保信息平台" |

### 4.2 路径 2:**政府强制数据 + 第三方独立审计**

| 要素 | 方案 |
|------|------|
| **强制口径** | 要求所有持牌酒店(包含单体)季度填报关键指标(OCC/ADR/RevPAR) |
| **审计** | 第三方会计师事务所(类似四大会计师事务所)审计数据 |
| **公开** | 数据**只公开汇总指数**,不公开单店 |
| **激励** | 填报酒店获得**税收优惠 / 平台降佣 / 贷款贴息** |

### 4.3 路径 3:**去携程化 + 数据主权回归**

- 华住季琦 2024 内部文:"**部分门店过于依赖 OTA**"
- 要求**自有会员占比提升至 85%** — 这是头部集团的觉醒
- 路径:**大型连锁集团自建私域 + 会员系统 + 数据中台**
- 缺点:**不解决单体酒店问题**(单体酒店依然依赖 OTA)
- 补充:**行业协会牵头建立"酒店数据中台"**

## 第六章 数据失明的 5 个盲区(98% 酒店的真相)

### 6.1 盲区 1:**35 万家单体酒店的真实经营**

- **4 大集团仅 ~3.6 万家** = 连锁集团覆盖 ~10%
- **剩下的 33.9 万家单体/小连锁酒店** = Eric 说"**数据更水分更大**"
- 这些酒店的 OCC/ADR/RevPAR 完全**依赖区域代表+问卷+推算**
- **真实数据 = 黑箱**

### 6.2 盲区 2:**独立连锁品牌(华住/亚朵等之外)**

- 100+ 地方连锁品牌(桔子水晶/桔子/星程/城市便捷/锦江系区域品牌/...)
- 单店 50-200 家
- 加入 CHA/CTGA 体系,但**数据填报不严格**

### 6.3 盲区 3:**度假酒店 / 民宿 / 客栈**

- **民宿/客栈约 8-15 万家**(全国)
- **完全脱离 CHA/CTGA 数据体系**
- OTA(携程/美团)有部分数据,但**线下不开放**
- **度假酒店**(如 Aman/松赞/裸心)→ 个位数级,**PMS 数据不并网**

### 6.4 盲区 4:**灰色 / 非法住宿**

- 日租/短租公寓 / 民宿 / 招待所 → 估计 **20-30 万家未纳入统计**
- Eric 说"国家星级仅 2%, 其余全被算法'调'了" → 灰色住宿是这 98% 的一部分

### 6.5 盲区 5:**线下线下数据不对等**

- Eric 关键洞察:"**OTA 全部都是线上数据,没有线下数据**"
- **线下真实数据完全封闭** — 即使有 PMS 直采(STR/绿云/石基),也只覆盖**头部**

## 第七章 数据生态重建的 3 条建议(给 Eric / 给行业)

### 7.1 短期(1-2 年):**行业自律 + 数据透明**

- 行业协会(CHA)牵头成立"中国酒店数据透明联盟"
- 强制披露 OCC/ADR/RevPAR 三项基础指标
- 与第三方会计师事务所合作(类似四大会计师事务所审计)
- 公开数据但**只公开汇总指数**,不公开单店

### 7.2 中期(3-5 年):**PMS 数据强制接入 + 政府授权**

- 借鉴欧洲 HotelStars 模式:**酒店等级评定与数据接入绑定**
- 国家文旅部强制 PMS 数据接入**国家酒店数据平台**
- 公开**国家酒店指数**(类似 STR 美国 STAR 报告)
- **绿云 + 石基 + 携程** 各贡献一个数据通道

### 7.3 长期(5-10 年):**第三方独立数据机构 + 行业去 OTA 化**

- 成立**中国酒店数据协会**(CHA 之外)
- 摆脱 OTA 数据控制(目前携程系 70% GMV 形成数据霸权)
- 建立**酒店业"信息主全"**:酒店保有自己的数据所有权

## Eric 一句话速答

> **"中国酒店行业最大的问题,就是全行业没有一个机构能把数据统计清楚。"**
>
> **数据源 7 大派别,各占山头**:
> 1. 政府官源(2% 覆盖)/ 2. 行业协会(水分大)/ 3. STR(真实但<10%)/ 4. OTA(70% 携程系 GMV 估算法)/ 5. 头部集团财报(10% 覆盖)/ 6. 独立咨询(推算)/ 7. 学术媒体(二手)
>
> **核心矛盾**:**2% 官方星级 vs 98% 算法打分**;**真实 vs 覆盖不可兼得**;**OTA 与酒店业利润剪刀差**(携程 H1 91.94 亿 vs 北京住宿利润 -92.9%)
>
> **解决路径**:**PMS 数据联盟 + 政府授权强制接入 + 第三方独立审计**(三者缺一不可)
>
> **短期 Eric 可做**:作为 AHL 平台,在数据透明 + 私域会员上做差异化,摆脱对 OTA 估算法的依赖。
