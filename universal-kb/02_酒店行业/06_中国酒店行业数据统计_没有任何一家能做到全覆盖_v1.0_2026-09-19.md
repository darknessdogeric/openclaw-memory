## 摘要(核心结论)

**中国酒店行业 37.5 万家酒店的真实经营数据,目前没有任何一个数据源能做到全覆盖。**

| 数据源 | 覆盖度 | 失明度 | Eric 论断 |
|--------|--------|--------|----------|
| **政府官源**(文旅部 + 国家统计局) | 🔴 7,586 家 = **2.02%** | **97.98% 失明** | "国家星级仅 2%" |
| **行业协会 CHA + CTGA** | 🟡 ~60% | 🟡 手动填报 + **口径分裂 40 年** | "水分更大" |
| **STR**(PMS 直采) | 🔴 **<10%** | 🟢 真实但极窄 | "用了等于零" |
| **绿云 PMS** | 🟡 **16.3%** 客房 | 🟢 中端为主 | - |
| **石基 PMS** | 🟡 **78% 高星级 / <15% 总市场** | 🟢 高端独大 | - |
| **OTA 平台**(携程 + 美团 + 飞猪 + 抖音) | 🔴 **仅线上**(GMV 70%) | 🟢 **线下完全失明** | "OTA 没有线下数据" |
| **上市公司财报** | 🔴 **36,165 家 = 10%** | 🟢 最真实但极窄 | - |
| **独立咨询 + 学术媒体** | 🟡 ~24%(浩华) | 🔴 方法论不公开 + 二手 | "水分更大" |

**总论**:中国酒店行业数据生态 = **"政府官源失明 + 行业协会分裂 + PMS 数据孤岛 + OTA 数据霸权 + 上市集团封闭 + 咨询推算"** —— 没有任何一个数据源能同时实现 **"真实 + 覆盖广 + 可比 + 时效"** 四要素。

## 第三章 三大根本矛盾

### 3.1 矛盾 1:**2% 真实 vs 98% 失明**

- **有官方星级的酒店**:7,586 家 = **2.02%**
- **98% 酒店"无官方数据"** — **依赖平台算法或推算**
- 后果:Eric 看任何"全国酒店平均数据" → **97% 的真实状态是黑的**

### 3.2 矛盾 2:**真实 vs 覆盖 不可兼得**

| 数据源 | 真实度 | 覆盖度 | Eric 总结 |
|-------|-------|-------|----------|
| STR / 财报 | 🟢 **极高** | 🔴 **极低** | "**真实但小样本**" |
| 政府官源 | 🟢 高 | 🔴 极低(2%) | "**权威但失明**" |
| OTA / 行业协会 | 🟡 估算法 | 🟡 中 | "**覆盖广但水分大**" |

**无单一数据源能同时实现 "真实 + 覆盖广"** —— **这就是行业数据困局的根本原因**。

### 3.3 矛盾 3:**OTA 与酒店业的利润剪刀差**

- **携程 2025 H1 净利 91.94 亿** = 日均 5,000 万
- **北京住宿业 H1 收入 -7.3%,利润 -92.9%**
- → **OTA 通过强制调价 + 高佣金(12-20% 甚至 30%)** 从酒店业"吸血"
- → 2025.7 国家市监总局对携程反垄断立案
- → **数据控制权 = 定价控制权 = 利润分配权**
