## 一、三种价格模型（核心）

### 1.1 Net Rate（净价模式）

**定义**：酒店给 TMC/企业一个净价，TMC/企业加服务费卖给差旅人。

**公式**：
```
员工支付价 = Net Rate + TMC 服务费（5-15%）
酒店实收 = Net Rate
```

**适用场景**：
- 央国企差旅集采（主流）
- 大流量协议客户
- 客户希望掌握定价权

**优势**：
- TMC 议价权强（推得动）
- 客户感知清晰（员工看价 + 服务费）

**劣势**：
- 酒店让利较大（15-25% vs BAR）
- 利润空间薄

---

### 1.2 Commissionable Rate（佣金模式）

**定义**：酒店保留 BAR 价格，TMC/企业从酒店拿 8-15% 佣金。

**公式**：
```
员工支付价 = BAR
酒店实收 = BAR × (1 - 佣金比例)
```

**适用场景**：
- 外资/外企差旅（欧美主流）
- 高端酒店
- 客户希望保留酒店完整品牌价值

**优势**：
- 酒店保价（保护 BAR 体系）
- 利润率高（佣金是纯利）

**劣势**：
- TMC 推不动（员工看价无优势）
- 落地难（中国市场不主流）

---

### 1.3 Mix & Match（混合模式）

**定义**：不同客户/不同场景用不同模型，按合同定制。

**典型组合**：
```
一线城市 + 高端酒店     → Net Rate（占比 60-70%）
二三线城市 + 中端酒店   → Commissionable（占比 30-40%）
特殊时段 + 节假日       → Net Rate + 溢价（特殊条款）
```

**适用场景**：
- 大客户谈判（年度合作额 1 亿+）
- 复杂需求集团
- 头部央国企

**优势**：
- 灵活（按场景定价）
- 兼顾各方利益

**劣势**：
- 复杂（管理成本高）
- 系统支持要求高

## 二、12 项核心商务条款

### 条款 1 · Net Rate 比例（占 BAR 的 65-85%）
- **谈判要点**：Net Rate 价格 / BAR 折扣率
- **行业基准**：央国企差旅 Net Rate 通常是 BAR 的 70-80%
- **反制策略**：用"协议量承诺"换更高折扣

### 条款 2 · Last Room Availability（LRA）触发条件
- **标准承诺**：满房前 24 小时保障客户预订
- **触发条件**：客户级别 + 预订时段 + 提前窗口
- **例外条款**：旺季高峰 / 特殊活动 / 灾害期间

### 条款 3 · Volume Rebate 阈值
- **定义**：达标后返佣（季度/年）
- **阈值设计**：阶梯式（如 1 万间夜 3% / 3 万间夜 5% / 5 万间夜 8%）
- **结算周期**：季度结算 / 年度结算
- **反制**：与条款 7 结算账期联动

### 条款 4 · Booking Window（提前预订窗口）
- **标准要求**：提前 3-7 天（享最优价）
- **当日订房**：保留 10-15% 当日库存 + 加价 10-20%
- **长期预订**：提前 30 天可享 Net Rate +5% 折扣

### 条款 5 · Cancellation / No-show 政策
- **标准政策**：18:00 前免费取消 / 当日 50% / No-show 100%
- **企业客户**：可谈判更宽松（18:00 前免费取消延至 22:00）
- **特殊场景**：航班延误 / 临时改期

### 条款 6 · 餐饮/会场附加服务定价
- **早餐**：含早/不含早差 30-50 元/人
- **会议场地**：免费/折扣/市价（按客户级别）
- **行政酒廊**：含行政酒廊权益（套房/白金卡以上）

### 条款 7 · 增值税专用发票
- **必备**：央国企硬需求
- **一票一结 vs 月结**：按合同定
- **开票主体**：酒店方直接开（非集团代开）

### 条款 8 · 结算账期
- **标准**：月结 30 天
- **可谈判**：月结 60 天 / 90 天（央国企常态）
- **惩罚条款**：延迟付款利息 + 滞纳金

### 条款 9 · 违约责任与争议解决
- **酒店违约**：LRA 未保障 / 价格未兑现 → 罚款 + 赔偿
- **客户违约**：拖欠账款 / 取消超额 → 违约金
- **争议解决**：协商 → 仲裁 → 法院（合同定）

### 条款 10 · 数据保密条款（NDA）
- **保密范围**：客户差旅数据 / 价格体系 / 商业条款
- **保密期限**：3-5 年（合同结束后仍有效）
- **违约责任**：赔偿 + 终止合作

### 条款 11 · 反腐合规条款（央国企特殊）
- **禁止商业贿赂**：明示禁止 + 报告机制
- **审计配合**：接受年度审计 + 反腐检查
- **反腐败条款**：员工行为准则 + 违规上报

### 条款 12 · 续签/退出机制
- **续签条件**：KPI 达标 + 满意度 + 价格优势
- **退出条件**：任一方提前 30-90 天书面通知
- **过渡期**：3 个月过渡 + 数据交接

## 三、价格谈判博弈论视角

### 3.1 三方博弈

```
酒店（议价能力：弱-中）
  ├─ 价格底线 = 边际成本 + 合理利润（≥15%）
  └─ 让利空间 = 5-15%（vs BAR）

TMC（议价能力：强）
  ├─ 推 Net Rate 让员工看价优势
  └─ 收酒店佣金（5-15%）

企业（议价能力：中-强）
  ├─ 集采批量 + 长期承诺
  └─ KPI 评估 + 续约挂钩
```

### 3.2 谈判 5 大策略

**酒店侧**：
1. **不降到底线**：保留 BAR 体系完整
2. **用 Volume 换 Rate**：批量承诺换折扣
3. **用 SLA 换 Rate**：服务质量保障换价格让步
4. **用案例换 Rate**：央国企案例换溢价能力
5. **用灵活条款换总体**：在小条款让利，换主条款优势

**客户侧**：
1. **总成本论**：不只是房价，含餐饮/会场/服务
2. **KPI 导向**：用数据说话
3. **长期承诺换价格**：年度合作换最优价
4. **多家比价**：用竞争压价
5. **反腐红线**：明示拒绝商业贿赂

基于 Eric 8/16 起在推央国企差旅对接，**建议分三步**：

- 集团 GRM 中台上线
