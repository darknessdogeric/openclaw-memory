## 一、央国企差旅 RFP 的 7 大特点

### 1.1 决策结构：三重一大

**含义**：重大事项决策权、重要干部任免权、重大项目投资决策权、大额度资金使用权 —— 集中在党委会/董事会。

**对 RFP 的影响**：
- RFP 不是采购部决定，而是**党委会/总经理办公会**决定
- 决定因素：合规 > 政治 > 经济
- 价格不是唯一决定因素

### 1.2 采购方式：集中采购 + 框架协议

**特点**：
- 全集团/全省/全市统采（而非分公司分散采购）
- 框架协议（通常 2-3 年）
- 集中议价 + 集中结算

**优势**（对酒店）：
- 单笔大（年度 1-5 亿）
- 长期稳定（2-3 年）
- 标杆效应（央国企案例）

**劣势**（对酒店）：
- 利润薄（Net Rate 折扣大）
- 合规严（接受反腐审计）
- 结算长（60-90 天）

### 1.3 资质门槛：严格

| 门槛 | 标准 |
|------|------|
| 注册资本 | ≥ 1000 万（部分要求 ≥ 5000 万） |
| 成立年限 | ≥ 5 年（部分 ≥ 10 年） |
| 央国企案例 | ≥ 3 个（部分 ≥ 5 个） |
| 资质证书 | ISO 三体系 + 行业许可 |
| 财务要求 | 3 年无亏损 + 银行资信 AA 及以上 |

### 1.4 评标严格：综合评分法为主

**典型 100 分分配**（与板块 03 总览一致）：
```
商务报价 30 分
技术方案 25 分
资质与案例 20 分
服务方案 15 分
综合印象 10 分
```

### 1.5 反腐红线：零容忍

**对酒店的要求**：
- 严禁商业贿赂（明示禁止）
- 严禁"打擦边球"（礼品/餐饮/旅游）
- 公开透明（所有谈判邮件留痕）
- 员工行为准则 + 上报机制

**审计要求**：
- 年度审计 + 专项审计
- 反腐检查 + 纪检巡查
- 第三方审计（部分）

### 1.6 结算长：60-90 天常态

| 账期 | 行业占比 |
|------|---------|
| 月结 30 天 | 20% |
| 月结 60 天 | 40% |
| 月结 90 天 | 30% |
| 季结/半年结 | 10% |

**影响**：
- 现金流压力
- 财务成本上升
- 需要应收账款管理

### 1.7 续约机制：年度评估

**评估指标**：
- KPI 达成率（≥ 95%）
- 客户满意度（NPS ≥ 70）
- 价格优势（vs 市场）
- 系统稳定性（≥ 99.9%）
- 应急响应（响应时效 ≤ 2 小时）

## 二、央国企差旅 RFP 评分体系详解

### 2.1 商务报价（30 分）—— 不是最低价中标

**评分方法**（典型）：
- 基准价 = 最低有效报价
- 得分 = (基准价 / 投标价) × 30
- 但**高于基准价 10% 以上扣分**

**关键洞察**：极低价策略不灵（会被认为"质量不能保证"），合理报价 + 价值附加更有效。

### 2.2 技术方案（25 分）—— 数字化能力加分

**评分细则**（典型）：
| 子项 | 分值 | 关键能力 |
|------|------|---------|
| 系统能力 | 8 分 | PMS/CRS/GDS 直连 |
| 数字化 | 6 分 | App/小程序/Dashboard |
| API 集成 | 5 分 | 与企业 OA/差旅系统对接 |
| 数据安全 | 3 分 | ISO 27001 + 等级保护 |
| 创新性 | 3 分 | AI/智能化亮点 |

### 2.3 资质与案例（20 分）—— 央国企案例优先

**评分细则**：
| 子项 | 分值 | 关键证明 |
|------|------|---------|
| 资质证书 | 5 分 | ISO + 行业许可 + 信用 |
| 财务状况 | 5 分 | 3 年审计 + 银行资信 |
| 央国企案例 | 8 分 | 数量 + 规模 + 行业相关 |
| 团队配置 | 2 分 | 项目负责人经验 |

**关键洞察**：**没有央国企案例 = 直接扣 8 分 = 致命伤**。

### 2.4 服务方案（15 分）—— SLA 具体度

**评分细则**：
| 子项 | 分值 | 关键证明 |
|------|------|---------|
| SLA | 6 分 | 12 项 SLA 具体承诺 |
| 客服 | 4 分 | 24/7 + 多通道 |
| 应急 | 3 分 | 预案 + 演练 |
| 培训 | 2 分 | 客户培训计划 |

### 2.5 综合印象（10 分）—— 答辩 + 关系

**评分细则**：
| 子项 | 分值 | 关键点 |
|------|------|--------|
| 答辩表现 | 5 分 | 现场答辩（部分 RFP） |
| 合作意愿 | 3 分 | 高层对接 + 长期承诺 |
| 文档质量 | 2 分 | 标书完整度 + 美观度 |

## 三、5 大陷阱

### 陷阱 1 · 最低价中标陷阱

**现象**：以为价格最低就能中标

**真相**：
- 央国企评委会担心"低价 = 低质量"
- 极低价会被扣"合理性"分
- **应对**：合理报价 + 价值附加（增值服务/差异化）

### 陷阱 2 · 关系陷阱

**现象**：以为走关系就能中标

**真相**：
- 央国企反腐审计严（"三重一大" + 纪检 + 审计署）
- 走关系一旦曝光 = 双方都完蛋
- **应对**：用实力说话 + 透明谈判 + 邮件留痕

### 陷阱 3 · 案例陷阱

**现象**：没有央国企案例

**真相**：
- 没有央国企案例 = 直接扣 8 分 = 致命伤
- **应对**：
  - 选 1-2 个标杆项目（如地方政府会议接待）
  - 包装成"准央国企案例"
  - 与央国企背景公司合作（合资/分包）

### 陷阱 4 · 资质陷阱

**现象**：注册资本/年限/资质不够

**真相**：
- 这些是**否决项**（资质不全 = 直接淘汰）
- **应对**：
  - 提前 6 个月准备资质升级
  - 联合体投标（与大型酒店集团联合）
  - 选择性投标（避开超资质要求的项目）

### 陷阱 5 · 条款陷阱

**现象**：合同条款苛刻（结算长/违约金高）

**真相**：
- 央国企合同条款是"国家模板"（不可改）
- 但执行有弹性（结算可谈）
- **应对**：
  - 接受条款 + 谈判执行细节
  - 用 SLA 兑现换条款弹性
  - 长期合作换短期让步

## 四、安逸集团切入央国企差旅 RFP 的路径

### 4.1 SWOT 分析

```
S（优势）
├─ 国资背景（信任背书）
├─ 西南区域优势（成都/重庆/川南）
├─ 与四川旅投/省国资委内部协同
└─ 56 家酒店全国覆盖（部分）

W（劣势）
├─ 集团无统一 CRS/GRM（关键短板）
├─ 无央国企差旅标杆案例
├─ 数字化能力弱于头部民营
└─ 反腐合规流程长

O（机会）
├─ 央国企差旅集采加速（80% 已集采）
├─ 西南政经中心（成都党政会议密集）
├─ 与铁旅/心已远等央企级 TMC 有合作基础
└─ 四川旅投其他子公司内部协同

T（威胁）
├─ 头部酒店集团竞争（华住/锦江/亚朵）
├─ 国际品牌（万豪/希尔顿/雅高）
└─ 携程商旅市占 50%+
```

### 4.2 三步走策略

**S0 · 资质补齐（Month 1-3）**
- 集团 ISO 三体系认证升级
- 央国企案例包装（找标杆项目）
- 集团 CRS/GRM 中台立项

**S1 · 试点央国企（Month 3-9）**
- 选 1-2 家试点：四川本地国资 + 央企西南分支
- 切入路径：政府会议接待 → 差旅集采
- 用 Mix & Match 模型 + 长期合作承诺

**S2 · 平台化扩张（Month 9-18）**
- 集团差旅中台上线
- 接入 2-3 家 TMC 战略合作
- 复制到 10+ 央国企客户

## 五、典型央国企差旅 RFP 流程图

```
央国企差旅需求识别
    ↓
采购部立项（行政副总 + 财务）
    ↓
委托 TMC 或自建（80% 委托携程商旅）
    ↓
内部预算编制（财务审批）
    ↓
RFP 文件起草（TMC + 法务 + 采购）
    ↓
三重一大审批（党委会/总经理办公会）
    ↓
公开发布（中国政府采购网 / 公司官网）
    ↓
资质预审（淘汰不合格）
    ↓
投标响应（45-90 天）
    ↓
评标委员会评标（5-7 人，3-7 天）
    ↓
中标候选人公示（5-7 天）
    ↓
谈判 + 合同签订（30-60 天）
    ↓
系统对接（GDS/直连）
    ↓
试运行 + 全面上线
    ↓
季度回顾 + 年度评估
```
