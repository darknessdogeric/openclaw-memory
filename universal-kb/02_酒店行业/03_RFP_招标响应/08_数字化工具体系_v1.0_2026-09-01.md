## 一、为什么需要数字化工具体系

### 1.1 现状痛点
- RFP 响应周期长（5-15 天起草）
- 团队能力差异导致标书质量参差
- 重复劳动（80% 内容是模板化的）
- 数据收集耗时长（案例/资质/数据）
- 校对工作繁重（合规/数字/条款）

### 1.2 数字化的 5 大价值
1. **提效**：起草时间从 15 天 → 5 天
2. **标准化**：质量稳定不依赖人
3. **智能化**：自动识别风险点
4. **可复用**：标书模块化沉淀
5. **可追溯**：历史项目经验复用

## 二、工具体系架构（5 层）

```
┌─────────────────────────────────────────────────────────┐
│ Layer 5 · 决策层（智能推荐 + 风险预警）                  │
├─────────────────────────────────────────────────────────┤
│ Layer 4 · 校对层（合规/数字/条款自动校对）              │
├─────────────────────────────────────────────────────────┤
│ Layer 3 · 生成层（标书/价格/SLA 自动生成）              │
├─────────────────────────────────────────────────────────┤
│ Layer 2 · 拆解层（RFP 智能拆解 + 需求匹配）              │
├─────────────────────────────────────────────────────────┤
│ Layer 1 · 数据层（资质/案例/价格/SLA 知识库）            │
└─────────────────────────────────────────────────────────┘
```

## 三、Layer 1 · 数据层

### 3.1 酒店资质库
```
- 营业执照（动态有效期）
- 特种行业许可
- ISO 认证
- 行业认证（星级/绿色/碳中和）
- 财务报表（3 年）
- 银行资信证明
```

### 3.2 案例库
```
- 央国企案例（脱敏）
- 政府会议案例
- 企业会议案例
- 会奖旅游案例
- 标杆客户案例
- 失败案例（含教训）
```

### 3.3 价格库
```
- BAR 价格体系
- Net Rate 协议价
- Volume Rebate 阶梯
- 历史报价记录
- 行业基准价格
```

### 3.4 SLA 库
```
- 12 项 SLA 模板
- 行业基准 SLA
- 历史 SLA 履行记录
- 应急响应 SLA
```

### 3.5 合同库
```
- 央国企合同模板
- 政府合同模板
- 企业合同模板
- 历史合同条款
- 偏差表模板
```

---

## 四、Layer 2 · 拆解层

### 4.1 RFP 智能拆解
**输入**：RFP 文档（PDF/Word）
**输出**：结构化拆解清单

**功能**：
```
1. 章节自动识别（10 大章节）
2. 评分权重自动提取
3. 否决项自动识别
4. 关键日期自动提取
5. 联系人信息提取
```

### 4.2 需求匹配
**输入**：拆解清单 + 酒店能力清单
**输出**：匹配度报告

**功能**：
```
1. 能力覆盖率计算（15 项必备能力）
2. 缺口自动识别（哪些能力需补）
3. 风险等级评估（高/中/低）
4. 投标建议（投/不投/慎投）
```

---

## 五、Layer 3 · 生成层

### 5.1 标书自动生成
```
- 公司资质部分（自动填充 + 校对）
- 技术方案（按 RFP 章节生成）
- 商务方案（价格 + SLA 自动生成）
- 合同条款（按 RFP 要求生成）
- 偏差表（自动填写）
```

### 5.2 价格智能生成
```
- 行业基准比对
- 历史相似项目报价参考
- 利润空间提示
- 风险价格警告（极低价/极端高价）
```

### 5.3 SLA 智能生成
```
- 按 RFP 要求生成对应 SLA
- 行业基准比对
- 集团 SLA 标准对齐
- 履约能力评估
```

---

## 六、Layer 4 · 校对层

### 6.1 合规校对
```
- 反腐条款完整性
- 资质文件有效性
- 案例脱敏合规
- 数据准确性
```

### 6.2 数字校对
```
- 房间数/覆盖城市/案例数量
- 价格计算（Net Rate/Volume Rebate）
- SLA 量化指标
- 财务数据一致性
```

### 6.3 条款校对
```
- 合同条款无歧义
- 偏差表完整填写
- 反腐条款明示
- 结算条款清晰
```

---

## 七、Layer 5 · 决策层

### 7.1 投标决策推荐
```
- 赢率评估（基于历史 RFP 中标率）
- 利润空间评估
- 战略价值评估
- 综合推荐（投/不投/慎投）
```

### 7.2 风险预警
```
- 资质风险
- 价格风险
- 案例风险
- 条款风险
- 反腐风险
```

### 7.3 复盘智能分析
```
- 中标关键因素识别
- 失败原因诊断
- 改进措施推荐
- 案例库自动更新
```
