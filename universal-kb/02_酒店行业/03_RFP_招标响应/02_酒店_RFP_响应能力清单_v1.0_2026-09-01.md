## 二、A · 资质与合规（4 项）

### A1 · 营业执照 + 特种行业许可
- **标准**：营业执照副本（盖章）+ 特种行业许可证（旅馆业）
- **证明文件**：原件扫描 + 复印件
- **风险点**：许可过期/经营范围不符 → 直接淘汰

### A2 · 合规记录
- **标准**：3 年内无重大行政处罚
- **证明文件**：信用中国截图 + 国家企业信用信息公示系统截图
- **风险点**：失信被执行人 / 重大税收违法 → 直接淘汰

### A3 · ISO 体系认证
- **标准**：ISO 9001（质量）+ ISO 14001（环境）+ ISO 45001（职业健康）
- **证明文件**：认证证书 + 年度监督审核记录
- **加分项**：ISO 27001（信息安全）/ ISO 31000（风险管理）

### A4 · 行业资质
- **标准**：星级评定（4 星及以上）/ 绿色饭店 / 碳中和认证
- **证明文件**：证书 + 牌匾照片
- **加分项**：中国饭店协会会员 / ICCA 会员 / PCMA 会员

---

## 三、B · 系统与平台（4 项）

### B1 · 中央预订系统（CRS）
- **标准**：覆盖集团所有酒店的中央预订 + 实时房态
- **证明文件**：CRS 截图 + 集成酒店清单
- **关键功能**：实时房态 / 实时价格 / 中央库存管理 / 会员识别

### B2 · PMS 集成
- **标准**：每家酒店有专业 PMS（Opera Cloud / 绿云 / 别样红 / 石基）
- **证明文件**：PMS 软件著作权 + 部署清单
- **关键功能**：客房管理 / 入住管理 / 账务管理 / 报表

### B3 · GDS/Channel Manager 直连
- **标准**：至少接入 2 家 GDS（Amadeus/Sabre/Travelport）
- **证明文件**：GDS 接入证明 + Channel Manager 截图
- **关键功能**：双向实时直连 / 价格同步 / 订单同步

### B4 · API 集成能力
- **标准**：有标准 API 文档 + 集成案例
- **证明文件**：API 文档 + 3 个集成案例
- **关键场景**：企业 OA / TMC 系统 / 差旅 App / 报销系统对接

---

## 四、C · 商务与服务（4 项）

### C1 · 全球/全国协议价体系（GRM）
- **标准**：有全球协议价管理系统 + 覆盖至少 30 个城市
- **证明文件**：GRM 系统截图 + 覆盖城市清单
- **关键功能**：协议价配置 / 客户识别 / 价格例外 / 返佣计算

### C2 · Last Room Availability（LRA）
- **标准**：有 LRA 政策 + 系统支持
- **证明文件**：LRA 政策文档 + 系统截图
- **关键承诺**：满房前 24 小时承诺 LRA / 价格与库存双重锁定

### C3 · 24/7 多语言客服
- **标准**：400 电话 + 微信 + 邮件 + APP 四通道
- **证明文件**：客服 SLA 文档 + 客服值班表
- **关键能力**：中文 + 英文双语（央国企涉外要求）

### C4 · 应急响应能力
- **标准**：有应急预案 + 演练记录
- **证明文件**：应急预案文档 + 2 次/年演练记录
- **关键场景**：断电 / 疫情 / 突发事故 / 系统故障

---

## 五、D · 数据与洞察（3 项）

### D1 · 月度/季度差旅数据报告
- **标准**：自动生成 Dashboard（月/季/年）
- **证明文件**：Dashboard 截图 + 报告模板
- **关键指标**：间夜数 / ADR / 入住率 / 城市分布 / 节约率

### D2 · 节约率/合规率/首选率分析
- **标准**：有 3 项核心 KPI 计算逻辑
- **证明文件**：KPI 计算公式文档 + 历史数据
- **关键洞察**：客户差旅优化建议（酒店首选调整/预订窗口优化）

### D3 · 续约/退出的数据支撑
- **标准**：有续约评估模型 + 历史案例
- **证明文件**：续约评估报告模板 + 3 个历史案例
- **关键模型**：ROI 计算 / 客户满意度 NPS / 续约预测

## 七、安逸集团自检（Eric 视角）

基于 56 家酒店现状，B166ER 给出的快速自检结论：

| 能力项 | 安逸集团现状 | 差距 |
|--------|------------|------|
| A1-A2 资质合规 | ✅ 全部具备 | 无 |
| A3 ISO | ⚠️ 部分具备 | 集团级认证 |
| A4 行业资质 | ⚠️ 头部具备 | 中端酒店欠缺 |
| B1 CRS | ❌ 集团无统一 CRS | **关键短板** |
| B2 PMS | ⚠️ 多家系统并存 | **需整合** |
| B3 GDS | ❌ 未接入 | **关键短板** |
| B4 API | ⚠️ 头部酒店具备 | **需扩展** |
| C1 GRM | ❌ 无集团 GRM | **关键短板** |
| C2 LRA | ⚠️ 无明确政策 | **需建政策** |
| C3 24/7 客服 | ⚠️ 各自为政 | **需集团中台** |
| C4 应急 | ✅ 有预案 | 无 |
| D1 Dashboard | ⚠️ 单店有 | **集团 Dashboard 缺** |
| D2 KPI | ❌ 集团层无 | **需建模型** |
| D3 续约评估 | ❌ 无 | **需建模型** |

**关键判断**：安逸集团当前 RFP 响应能力约 **55-65 分**（不及格线），需重点建设：
1. 集团 CRS / GRM 中台（最高优先级）
2. GDS/Channel Manager 接入（必做）
3. Dashboard + KPI 模型（必须）
4. 集团 24/7 客服中心（建议）

## 八、能力建设路径（12 个月）

```
Month 1-2 · 立项 + 选型
├─ RFP 中台需求梳理

├─ CRS 中台上线（先覆盖头部 10 家）

└─ 集团 Dashboard v1.0

Month 7-9 · 系统对接
├─ GDS 接入（Amadeus/Sabre）
├─ Channel Manager 部署
└─ API 文档 + 集成测试

Month 10-12 · 试点 + 推广
├─ 选 3-5 家央国企试点 RFP
├─ 集团客服中心建设
└─ 全面覆盖 56 家酒店
```
