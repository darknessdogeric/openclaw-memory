## 一、SOP 总览（6 阶段）

```
S1 拆解（30 分钟）→ 拆解 RFP 文档
S2 立项（1-3 天）→ 内部立项 + 团队组建
S3 起草（5-15 天）→ 标书撰写
S4 校对（1-2 天）→ 三轮校对
S5 提交（1 天）→ 装订 + 提交
S6 复盘（中标/未中标都做）→ 改进
```

---

## 二、S1 · 拆解 RFP（30 分钟）

### 2.1 输入
- RFP 原始文档（PDF/Word）
- 评估表（如有）

### 2.2 输出
- 《RFP 拆解清单.md》

### 2.3 拆解 6 大模块

```
1. 项目基础信息
   ├─ 招标编号/项目名称/招标方
   ├─ 投标截止时间/答疑时间/开标时间
   └─ 联系人/联系方式

2. 资质门槛（否决项）
   ├─ 注册资本/年限
   ├─ 资质证书要求
   └─ 央国企案例要求

3. 评分体系
   ├─ 总分构成
   ├─ 各部分权重
   └─ 通过分数线

4. 技术要求
   ├─ 系统能力要求
   ├─ 服务方案要求
   └─ 数字化要求

5. 商务要求
   ├─ 价格模型
   ├─ SLA 要求
   ├─ 案例要求
   └─ 团队要求

6. 合同条款
   ├─ 协议期
   ├─ 结算条款
   ├─ 违约责任
   ├─ 反腐条款
   └─ 续签/退出条款
```

### 2.4 B166ER 工具价值（未来）

```
- 输出结构化拆解清单

```

## 三、S2 · 立项（1-3 天）

### 3.1 决策树
```
是否投标？
├─ 否决项不达标（资质/案例/年限） → 不投
├─ 利润空间 < 5% → 慎重考虑
├─ 资源紧张（团队/时间） → 慎重考虑
└─ 满足条件 → 投标
```

### 3.2 立项输出
- 《项目立项书》
  - 项目背景
  - 决策依据（赢率/利润/战略价值）
  - 团队配置
  - 时间表
  - 预算（人天 + 物料）
  - 风险预案

### 3.3 团队配置（标准）

```
总负责人（1 人）：销售总监 / GM
├─ 商务组（2-3 人）：收益经理 + 销售经理
├─ 技术组（2-3 人）：IT 主管 + 系统工程师
├─ 法务组（1 人）：法务
├─ 财务组（1 人）：财务经理
├─ 投标专员（1-2 人）：标书撰写 + 美化
└─ 集团层协调（1 人）：集团高管
```

---

## 四、S3 · 起草（5-15 天）

### 4.1 章节分工
| 章节 | 主笔 | 配合 | 工期 |
|------|------|------|------|
| 公司资质 | 投标专员 | 法务 | 1 天 |
| 技术方案 | 技术组 | IT | 3-5 天 |
| 商务方案 | 商务组 | 收益 | 3-5 天 |
| 实施计划 | 总负责人 | 全员 | 2 天 |
| 合同条款 | 法务 | 商务 | 2 天 |
| 整体校对 | 投标专员 | 全员 | 2 天 |

### 4.2 写作规范
- 每段 3-5 行
- 关键数据加粗
- 用图表代替文字（流程图/对比表）
- 价值导向（不是罗列能力）
- 数据说话（每个能力点配数据/案例/认证）

### 4.3 价值主张提炼（核心）
- **酒店价值主张 = 3 条**：
  - 区位优势（覆盖城市/便利性）
  - 价格优势（Net Rate 折扣 + Volume Rebate）
  - 服务优势（SLA + 案例 + 数字化）

---

## 五、S4 · 校对（1-2 天）

### 5.1 三轮校对

**第一轮：部门校对**
- 商务组校对商务部分
- 技术组校对技术部分
- 法务校对合同条款
- 投标专员汇总

**第二轮：法务校对**
- 法务全文校对（合规风险）
- 反腐条款确认
- 合同条款核对

**第三轮：集团层校对**
- 总负责人终审
- 集团高层签字
- 装订 + 盖章

### 5.2 校对清单
```
□ 资质文件齐全且在有效期内
□ 数据准确性（房间数/星级/覆盖城市）
□ 价格符合集团定价策略
□ SLA 具体量化
□ 案例脱敏完整
□ 合同条款无歧义
□ 偏差表完整填写
□ 附件齐全 + 盖章
□ 文档美观（统一字体/字号/格式）
□ 排版无误（页码/目录/章节）
```

## 六、S5 · 提交（1 天）

### 6.1 提交方式
- 电子投标（加密 U 盘 + 邮箱）
- 纸质投标（盖章版 + 副本）
- 密封 + 按时提交（截止前 1 小时）

### 6.2 提交清单
```
1. 投标函（盖章版）
2. 投标文件（正本 1 份 + 副本 N 份）
3. 电子版（U 盘 + 邮件）
4. 法定代表人授权书
5. 保证金（现金/保函）
```

### 6.3 注意事项
- 截止时间前 1 小时提交（避免意外）
- 提交后确认（电话确认 + 邮件确认）
- 留底（电子版 + 纸质版）

## 七、S6 · 复盘（中标/未中标都做）

### 7.1 中标复盘
```
1. 关键成功因素
   - 哪些能力得分高？
   - 哪些条款被接受？
   - 哪些承诺被采纳？

2. 复盘总结
   - 经验沉淀（写入手册）
   - 客户关系维护
   - 系统对接推进

3. 续约规划
   - 季度回顾机制
   - 续约策略
```

### 7.2 未中标复盘
```
1. 失败原因分析
   - 拆解评分（哪部分失分最多）
   - 对比中标方差异
   - 客户反馈（如有）

2. 改进措施
   - 能力补齐（短/中/长期）
   - 流程优化
   - 团队培训

3. 关系维护
   - 感谢招标方
   - 表达后续合作意愿
   - 关注下次机会
```

### 7.3 复盘输出
- 《RFP 复盘报告.md》
- 沉淀到案例库 / 知识库
