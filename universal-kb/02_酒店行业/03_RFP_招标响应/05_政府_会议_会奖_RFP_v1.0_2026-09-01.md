## 一、三类 RFP 横向对比

| 维度 | 政府 RFP | 会议 RFP | 会奖 RFP |
|------|---------|---------|---------|
| **发起方** | 政府机关/事业单位 | 企业/协会/学术组织 | 企业 HR/销售总监 |
| **采购内容** | 单一/多项目 | 单一会议 | 团建/奖励旅游 |
| **规模** | 中-大 | 中-大 | 中-小 |
| **决策周期** | 3-12 个月 | 1-6 个月 | 1-3 个月 |
| **合规要求** | 极高（政府采购法） | 中-高 | 中 |
| **公开程度** | 强制公开（中国政府采购网） | 部分公开 | 不公开 |
| **核心痛点** | 合规 > 价格 > 服务 | 方案 + 案例 + 价格 | 体验 + 性价比 |
| **酒店角色** | 接待服务方 | 会议承办方 | 目的地服务商 |

## 二、政府 RFP（政府采购）

### 2.1 适用法规
- **《政府采购法》**
- **《政府采购实施条例》**
- **《中央预算单位政府集中采购目录及标准》**
- **地方采购法规**（各省/市有差异）

### 2.2 采购方式 6 种

| 方式 | 适用场景 | 限额 |
|------|---------|------|
| **公开招标** | ≥ 200 万（工程）/ ≥ 200 万（货物/服务） | 强制 |
| **邀请招标** | ≥ 200 万但有特殊要求 | 邀请 3+ 家 |
| **竞争性谈判** | 招标失败/技术复杂/紧急 | 谈判 3+ 家 |
| **竞争性磋商** | 政府购买服务/复杂需求 | 磋商 3+ 家 |
| **单一来源采购** | 只能从唯一供应商采购 | 公示 + 审批 |
| **询价** | 规格统一 + 价格为主 | 3+ 家报价 |

### 2.3 政府 RFP 关键条款

```
1. **资质门槛**（严）
   - 注册资本 ≥ 100 万
   - 行业资质（旅游业/酒店业）
   - 无重大违法记录

2. **价格评审**（合理低价）
   - 评标基准 = 最低有效报价 × (1 + K)
   - K = 行业平均利润率（5-15%）
   - 低于基准价的 80% = 废标

3. **履约保证金**
   - 通常 5-10% 合同金额
   - 验收后无息退还

4. **验收条款**
   - 甲方组织验收（纪检 + 审计 + 业务部门）
   - 不合格 = 整改 + 扣款 + 终止

5. **反腐条款**（极严）
   - 禁止商业贿赂（明示）
   - 公开举报渠道
   - 重大违规 = 列入黑名单 + 追究法律责任
```

### 2.4 实战陷阱

| 陷阱 | 应对 |
|------|------|
| 低价中标 + 验收严 | 不打价格战，价值导向 |
| 流程漫长（6-12 个月） | 提前规划现金流 |
| 反腐审计严 | 邮件留痕 + 透明谈判 |
| 验收刁钻 | 用 SLA 量化承诺 |

## 三、会议 RFP

### 3.1 会议 RFP 的 4 种典型

| 类型 | 规模 | 周期 | 决策方 |
|------|------|------|--------|
| **企业会议**（年会/季会/培训） | 50-500 人 | 1-3 个月 | 行政部 + 财务 |
| **学术会议** | 100-2000 人 | 3-6 个月 | 学会秘书处 |
| **行业大会** | 500-5000 人 | 6-12 个月 | 协会 + 主承办方 |
| **政府会议** | 50-1000 人 | 3-12 个月 | 政府机关 |

### 3.2 酒店会议 RFP 必备能力

```
1. **会议场地**
   - 主会场（≥ 500 人）
   - 分会场（≥ 5 个）
   - 多功能厅（可分割）
   - AV 设备（LED 屏/音响/同传）

2. **客房能力**
   - 房间数 ≥ 客房总量 80%
   - 多种房型（标间/大床/套房）
   - 快速入住/退房流程

3. **餐饮能力**
   - 自助餐厅 ≥ 300 座
   - 宴会厅 ≥ 500 座
   - 茶歇服务能力

4. **服务能力**
   - 会议管家（Event Manager）
   - AV 技术人员
   - 24/7 服务支持
   - 多语种接待

5. **位置与配套**
   - 机场/高铁可达性
   - 周边餐饮/景点
   - 停车能力
```

### 3.3 会议 RFP 评分体系（典型）

```
总分 100 分
├─ 会议方案（30 分）—— 主题/流程/讲师/体验
├─ 场地与设施（25 分）—— 面积/AV/客房/餐饮
├─ 团队与案例（20 分）—— 团队经验/同规模案例
├─ 价格（15 分）—— 总预算/单价
└─ 综合印象（10 分）—— 答辩 + 文档
```

## 四、会奖 RFP（奖励旅游 RFP）

### 4.1 定义与特点

**定义**：企业为高绩效员工/客户提供的旅游奖励，是企业人才保留与激励工具。

**特点**：
- 客单价高（人均 1-10 万）
- 体验导向（不只是看场地）
- 决策周期短（1-3 个月）
- 决策者：HR + Sales（业务驱动）

### 4.2 头部会奖旅游集团（国内）

| 集团 | 优势 |
|------|------|
| **众信旅游** | 欧洲线 + 大型集团客户 |
| **凯撒旅游** | 高端定制 + 上市公司 |
| **春秋旅游** | 包机 + 大众会奖 |
| **携程会奖** | 流量 + 一站式 |
| **新中体**（Eric 8/7 合作） | 体旅融合会奖（Eric 已立项） |

### 4.3 会奖 RFP 的关键能力

```
1. **目的地策划**
   - 多目的地组合（如海南+泰国+日本）
   - 当地体验（文化/美食/探险）
   - 季节性考虑

2. **行程设计**
   - 商务 + 休闲平衡
   - 高端体验（米其林/私人定制）
   - 团队建设活动

3. **接待服务**
   - 全程陪同（领队 + 当地导游）
   - VIP 服务（高管特别安排）
   - 应急响应（医疗/突发）

4. **结算灵活**
   - 团队打包价
   - 个性化增订
   - 透明账目
```

## 五、安逸集团切入点

### 5.1 政府 RFP
- **切入点**：四川省/成都市政府会议接待（已有总府川宾经验）
- **优势**：国资背景 + 区位优势
- **建议**：先做四川省内政府会议 → 扩张到成都都市圈

### 5.2 会议 RFP
- **切入点**：
  - 总府皇冠假日（IHG 国际品牌，高端会议）
  - 国堰宾馆（文创主题，可做主题会议）
  - 乐山锦江嘉州宾馆（区域会议）
- **建议**：集团层 MICE 销售线总监（参照 8-13 Eric 自述缺位）

### 5.3 会奖 RFP
- **切入点**：
  - 与新中体合作（Eric 8/7 已立项）
  - 古尔沟华美达（度假型会奖）
  - 三国文化主题酒店（文化体验型会奖）
- **建议**：差异化定位（不像传统旅游集团，靠"主题体验"取胜）

## 六、三类 RFP 的成本收益对比

| 类型 | 单笔均价 | 利润率 | 决策周期 | 合规风险 |
|------|---------|--------|---------|---------|
| 政府 RFP | 中-高 | 5-15% | 长 | **极高** |
| 会议 RFP | 高 | 15-25% | 中 | 中 |
| 会奖 RFP | 极高 | 20-35% | 短 | 中 |

**博弈论建议**：
- 政府 RFP：保品牌 + 不求利润（合规优先）
- 会议 RFP：主营战场（利润 + 规模）
- 会奖 RFP：高利润但量小（差异化定位）
