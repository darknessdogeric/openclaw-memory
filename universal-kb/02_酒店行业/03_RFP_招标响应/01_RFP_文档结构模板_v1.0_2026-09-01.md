## 一、RFP 文档 10 个标准章节

```
1. 封面（招标编号/项目名称/投标方/日期）
2. 投标函（Letter of Bid）
3. 目录
4. 公司资质（资质/财务/合规）
5. 技术方案（系统/服务/数字化）
6. 商务方案（价格/SLA/案例）
7. 实施计划（时间表/团队/里程碑）
8. 合同条款（响应 + 偏差表）
9. 附件（营业执照/认证/案例 PDF）
10. 保密声明 + 法定代表人签字盖章
```

## 二、章节详解 + 必含内容

### 2.1 封面
```
[招标编号]                  RFP-XX-2026-XXX
[项目名称]                  XX 集团 2026-2028 年度差旅酒店采购
[投标方]                    XX 酒店管理集团
[日期]                      2026-XX-XX
[联系方式]                  销售总监 + 手机 + 邮箱
```

### 2.2 投标函（Letter of Bid）
- 已阅读并理解招标文件全部内容
- 同意招标文件所有条款（除非偏差表说明）
- 投标有效期 90 天
- 不存在关联公司、母子公司、利益冲突
- 法定代表人签字 + 公章

### 2.3 目录
- 章节 + 页码 + 索引（5 级标题）

### 2.4 公司资质（4 子项）
| 子项 | 内容 |
|------|------|
| 资质文件 | 营业执照 / 税务登记 / 银行开户 / 行业许可 |
| 财务证明 | 3 年审计报告 / 银行资信证明 |
| 合规证明 | 无重大行政处罚 / 信用中国截图 |
| 行业认证 | ISO/星级/绿色饭店/碳中和 |

### 2.5 技术方案（5 子项）
```
1. 集团介绍（成立时间/规模/酒店数/员工数/地域覆盖）
2. 系统能力（PMS/CRS/GDS/Channel Manager/API 集成）
3. 服务方案（24/7 客服/SLA/应急响应/培训）
4. 数字化能力（App/小程序/数据看板/电子发票）
5. 安全与合规（数据安全/网络安全/反腐合规）
```

### 2.6 商务方案（5 子项）
```
1. 报价单（Net Rate / Commissionable / Volume Rebate）
2. SLA（服务等级承诺 12 项）
3. 案例库（3-5 个央国企差旅案例脱敏）
4. 团队介绍（项目负责人/客户经理/支持团队）
5. 合作承诺（响应时效/季度回顾/年度评估）
```

### 2.7 实施计划（4 子项）
```
1. 时间表（签约 → 系统对接 → 试运行 → 全面上线）
2. 团队配置（销售/收益/IT/财务/客服）
3. 里程碑（4-6 个节点 + 验收标准）
4. 风险管理（识别 5-8 个风险 + 应对方案）
```

### 2.8 合同条款（响应 + 偏差表）
- 完整响应招标方合同模板
- 偏差表（必须接受 / 谈判项 / 不接受项 三档）
- 每一项合同条款给出响应（接受/部分接受/不接受）

### 2.9 附件
```
A. 营业执照副本（盖章）
B. 法定代表人身份证（盖章）
C. 银行开户许可证
D. 行业许可（特种行业）
E. ISO 认证（9001/14001/45001）
F. 星级证书（适用酒店）
G. 央国企案例（脱敏）
H. 系统截图（CRS/PMS/API）
I. 财务报表（3 年）
J. 反腐合规声明
```

### 2.10 保密声明 + 签字盖章
- 保密期限（3-5 年）
- 法定代表人签字 + 公司公章

## 三、文档长度建议

| 章节 | 页数 |
|------|------|
| 封面 + 投标函 + 目录 | 3 页 |
| 公司资质 | 10-15 页 |
| 技术方案 | 30-50 页 |
| 商务方案 | 20-30 页 |
| 实施计划 | 10-15 页 |
| 合同条款 + 偏差表 | 15-20 页 |
| 附件 | 30-50 页 |
| **合计** | **120-180 页** |

> **关键洞察**：央国企 RFP 标书普遍在 150-200 页，**低于 100 页会被认为准备不充分**。

## 四、撰写风格指南

### 4.1 三原则
1. **简洁清晰**：每段 3-5 行，关键数据加粗
2. **数据说话**：每个能力点配数据/案例/认证支撑
3. **价值导向**：不是罗列能力，而是回答"对客户的业务价值"

### 4.2 常见错误
| 错误 | 后果 |
|------|------|
| 用大量通用模板语言 | 评分委员会会跳过 |
| 报价模糊（不写具体数字） | 直接被淘汰 |
| 案例不足（少于 3 个） | 技术评审扣分 |
| SLA 不具体 | 服务评估无依据 |
| 合同偏差过多 | 商务评审扣分 |
