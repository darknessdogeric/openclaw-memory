## 一、定义与三大请求文件

### 1.1 三个易混淆的概念

| 文件 | 全称 | 用途 | 关键问题 |
|------|------|------|---------|
| **RFI** | Request For Information | 信息请求（市场摸底） | 贵司能力如何？ |
| **RFP** | Request For Proposal | 方案请求（招标） | 请提供解决方案 + 报价 |
| **RFQ** | Request For Quotation | 报价请求（采购） | 请报价（明确规格） |

> **本板块聚焦 RFP**：因为酒店行业最重要的招标响应就是 RFP（央国企差旅/会议/会奖/团建/政府接待）。

### 1.2 酒店行业 RFP 的三类典型

| 类型 | 发起方 | 酒店场景 | 决策周期 |
|------|--------|---------|---------|
| **差旅 RFP** | 企业 TMC / 企业行政 | 全国/全球协议价 | 6-12 个月 |
| **会议 RFP** | 企业 / 政府 / 协会 | 单次会议或全年框架 | 1-6 个月 |
| **会奖 RFP** | 企业 HR / 销售总监 | 团建/奖励旅游 | 1-3 个月 |
| **政府/央国企 RFP** | 采购中心 | 政府采购 / 央国企集采 | 3-12 个月 |

## 二、RFP 招标 8 阶段流程

```
S1 需求识别（Month 1-2）
├─ 企业识别差旅/会议/采购需求
├─ 内部立项（财务/业务/法务审批）
└─ 委托 TMC 或自建采购

S2 预算编制（Month 2-3）
├─ 估算差旅量/会议次数/总预算
├─ 内部预算审批
└─ 形成采购预算包

S3 招标文件起草（Month 3-4）
├─ 内部 + TMC + 法务共同起草
├─ 包含资质/技术/价格/SLA/合同模板
└─ 内部审 + 上级审批（央国企走三重一大）

S4 RFP 发布（Month 4）
├─ 公开招标（中国政府采购网 / 公司官网 / 邀请函）
├─ 资质预审（淘汰不合格供应商）
└─ 答疑（Q&A 公开化）

S5 投标响应（Month 4-6）
├─ 酒店收到 RFP → 内部立项
├─ 商务条款起草（协议价/返佣/SLA）
├─ 标书撰写（资质/案例/方案/报价）
├─ 内部审批（酒店层 + 集团层）
└─ 提交（电子/纸质/密封）

S6 评标（Month 6-7）
├─ 评标委员会组建（5-7 人）
├─ 资质评审 / 技术评审 / 商务评审
├─ 现场答辩（部分 RFP）
└─ 综合评分排名

S7 谈判（Month 7-8）
├─ 与中标候选谈判（条款细化）
├─ 反腐合规（央国企特殊）
└─ 合同起草 + 法务审核

S8 签约 + 履约（Month 8+）
├─ 签订主协议 + SLA + 价格附件
├─ 系统对接（GDS/直连/CRS）
├─ 季度复核（Volume Rebate 计算）
└─ 续签/退出评估
```

## 三、酒店 RFP 响应能力清单（8 项必备）

### 3.1 资质与合规
1. **营业执照 + 特种行业许可**（酒店必备）
2. **合规记录**（无重大行政处罚）
3. **ISO 体系认证**（9001/14001/45001）
4. **行业资质**（星级评定/绿色饭店/碳中和认证）

### 3.2 系统与平台
5. **中央预订系统（CRS）** + PMS 集成
6. **GDS/Channel Manager 直连能力**（Amadeus/Sabre/Travelport）
7. **API 集成能力**（与企业 OA/差旅系统对接）
8. **电子发票 + 一票一结**（央国企硬需求）

### 3.3 商务与服务
9. **全球/全国协议价体系**（GRM）
10. **Last Room Availability（LRA）保障**
11. **24/7 中英双语客服**（央国企涉外要求）
12. **应急响应能力**（断电/疫情/突发）

### 3.4 数据与洞察
13. **月度/季度差旅数据报告**（DASHBOARD）
14. **节约率/合规率/首选率分析**
15. **续约/退出的数据支撑**

> **重要洞察**：很多酒店输在"系统直连能力"和"数据报告"上 —— 这是头部酒店集团 vs 区域酒店的护城河。

## 四、价格策略与商务条款（核心战场）

### 4.1 三种价格模型

| 模型 | 含义 | 优势 | 劣势 |
|------|------|------|------|
| **Net Rate** | 酒店给 TMC 净价，TMC 加服务费卖给企业 | TMC 议价权强 | 酒店让利较大 |
| **Commissionable Rate** | TMC 收酒店 8-15% 佣金 | 酒店保价 | TMC 推不动 |
| **Mix & Match** | 不同客户/不同场景用不同模型 | 灵活 | 复杂 |

### 4.2 商务条款 12 项核心

```
1. Net Rate 比例（占 BAR 的 65-85%）
2. Last Room Availability（LRA）触发条件
3. Volume Rebate 阈值（季度/年）
4. Booking Window（提前预订窗口）
5. Cancellation / No-show 政策
6. 餐饮/会场附加服务定价
7. 增值税专用发票条款
8. 结算账期（月结30天/60天/90天）
9. 违约责任与争议解决
10. 数据保密条款（NDA）
11. 反腐合规条款（央国企特殊）
12. 续签/退出机制
```

## 五、央国企 RFP 实战（核心战场）

### 5.1 央国企 RFP 的 7 大特点

| 特点 | 描述 |
|------|------|
| **三重一大** | 重大事项决策权在党委会/董事会 |
| **公开招标** | 政府采购网必须发布 |
| **资质门槛** | 注册资本/资质/案例/年限 |
| **评标严格** | 综合评分法 / 最低评标价法 |
| **反腐红线** | 不得有利益输送 |
| **审计严格** | 接受审计署 + 内审 + 第三方审计 |
| **结算长** | 月结 60-90 天常态 |

### 5.2 央国企差旅 RFP 评分体系（典型）

```
总分 100 分
├─ 商务报价（30 分）      ← 价格不是唯一
├─ 技术方案（25 分）      ← 系统能力/数字化
├─ 资质与案例（20 分）    ← 央国企案例优先
├─ 服务方案（15 分）      ← SLA / 客服 / 应急
└─ 综合印象（10 分）      ← 答辩表现 / 合作意愿
```

### 5.3 央国企 RFP 的常见陷阱

1. **最低价中标陷阱**（价格不是关键，但要合理）
2. **关系陷阱**（反腐审计严，不能走关系）
3. **案例陷阱**（无央国企案例直接淘汰）
4. **资质陷阱**（注册资本/年限不够直接淘汰）
5. **条款陷阱**（结算账期/违约条款吃利润）

## 七、酒店 RFP 响应 SOP（B166ER 工作流）

```
Step 1 · 拆解 RFP（30 分钟）
├─ 通读 RFP 全文，标注硬指标
├─ 拆解：资质/技术/价格/SLA/合同
├─ 输出《RFP 拆解清单.md》

Step 2 · 内部立项（1-3 天）
├─ 决策：是否投标？
├─ 组建响应团队（销售/收益/法务/IT/财务）
└─ 排期与分工

Step 3 · 起草标书（5-15 天）
├─ 资质部分：营业执照/许可/认证
├─ 技术部分：系统/数字化/集成
├─ 商务部分：价格/SLA/案例
├─ 合同部分：谈判 + 法务审核

Step 4 · 校对 + 提交（1-2 天）
├─ 三轮校对（部门/法务/集团）
├─ 装订 + 盖章 + 密封
└─ 按时提交（电子+纸质）

Step 5 · 答辩 + 谈判（视情况）
├─ 准备答辩 PPT（30-50 页）
├─ 模拟答辩（5 轮内部演练）
└─ 现场答辩 + 商务谈判

Step 6 · 复盘（中标/未中标都做）
├─ 中标：合同签订 / 系统对接 / 季度回顾
└─ 未中标：原因分析 / 改进 / 关系维护
```

## 八、对安逸集团的价值（Eric 视角）

### 8.1 现状盘点
- 集团 56 家酒店 —— RFP 响应能力参差不齐
- 总府皇冠假日（IHG 系统）/ 总府川宾（自有系统） —— 头部
- 其他中端 / 经济型 —— RFP 响应能力弱

### 8.2 战略机会
- **机会 1**：整合集团 56 家酒店形成"集团 RFP 响应能力"
- **机会 2**：央国企集采加速，集团介入可吃下大客户
- **机会 3**：与 TMC 战略合作（携程商旅/铁旅/心已远）锁定头部客户

### 8.3 建议切入点（三个阶段）

| 阶段 | 时间 | 目标 |
|------|------|------|
| **S0 评估** | 1 个月 | 评估 56 家酒店 RFP 响应能力 + 集团 RFP 平台架构 |
| **S1 试点** | 2-3 个月 | 选 3-5 家央国企差旅 RFP + 1-2 个会议 RFP 试点 |
| **S2 平台化** | 6-12 个月 | 集团 RFP 中台 + 标准化标书 + 央国企案例库 |
