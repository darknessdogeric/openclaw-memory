## 第一部分：行业总览（Executive Summary）

### 1.1 核心结论

> **弥勒是云南省"旅居康养+艺术度假"赛道的核心标的，是云南旅游"非传统目的地"赛道的最大新增量；酒店市场处于"金字塔结构上半段品牌化加速"阶段，**AHL 应聚焦"民宿品牌化托管 + 温泉中端连锁 + 旅居康养预订"三大场景切入。

**三大核心判断**：

1. **市场能级**：2024 年接待游客 1,779.3 万人次（+18.21%），旅游总花费 217.4 亿元（+15.56%），相当于**云南全省 10 亿人次的 1.78%**（份额高于 GDP 占比 1.2%）；增速远超云南全省及全国大盘
2. **结构断层**：754 家宾馆 + 1,200 家民宿构成"金字塔底"，**国际品牌仅 2 家**（雅高美憬阁 + 雅高巨人雅阁），**中高端连锁品牌空缺**（华住/锦江/亚朵在弥勒几乎未铺开）
3. **AHL 三大切入点**：
   - 🔴 民宿品牌化托管（1,200 家民宿，**国家丙级以上仅 6 家** = 0.5%）
   - 🟠 温泉中端连锁（温泉分散经营，未连锁化）
   - 🟡 康养旅居预订平台（旅居客占商品房销售 46.5%，分时换住空间巨大）

## 第二部分：宏观环境分析（Macro Environment）

### 2.1 经济环境
**云南全省（迈点研究院 2024 报告口径）**：
- 前三季 GDP 增速**低于全国水平**，总量在西部地区第 3
- 但弥勒例外：**连续 27 年红河州第一**，人均突破 10 万元
- 弥勒 2024 财政收入增速 **+26.5%**，全州第一
- 烟草产业为核心支撑（弥勒是云南烟草重镇）

### 2.2 政策环境
**国家层级**：党的二十大提出"文旅深度融合"
**省级**："旅居云南"标杆城市建设（2024 年启动）
**州市级**：
- 红河州"十四五"旅游业发展实施方案（2022）：培育高质量旅游市场主体
- "京滇携手·共筑康养梦"——2025-03 北京座谈会
- "有一种叫云南的生活·在弥勒样样好"

**地方政策动作**：
- 七城同创 + 滇中花园幸福城
- 创业担保贷款 1,700 万+ 助力康养旅居
- 红黑榜机制（季度文旅服务质量）
- 2024 年入库项目总投资 19.25 亿元
- 2025 年新签约项目计划总投资 28.23 亿元

### 2.3 社会趋势（关键洞察）
**关键变化**：
1. **"反向旅游"兴起**：大城市居民从大理/丽江/版纳外溢，**选择弥勒/建水/蒙自等小城深度游**
2. **"候鸟式旅居"爆发**：北方避寒+南方避暑，弥勒年均温 18.8℃，是"冬暖夏凉"标杆
3. **"健康焦虑"消费**：温泉+康养+中医养生需求激增
4. **"亲子+银发"双客群**：东方甄选/小红书推荐引爆

## 第五部分：运营表现（Operational Performance 核心章节）

### 5.1 OCC/ADR/RevPAR 推算（基于 Eric ADR 估算方法）

> **方法论**：使用 Eric 的"OTA 挂牌价 + 官网直销价双重加权法"反推 ADR，叠加行业基准推算 OCC。

#### 5.1.1 ADR 推算（基于 OTA 实际抓取）

**美憬阁（雅高）**：
- 携程挂牌价（筑瑶大床房）：¥999 起/晚（含双早+门票+旅拍）
- 携程原价：¥1,448
- 雅高臻享卡会员价（谱旋豪华大床房）：¥2,488/2 晚 = ¥1,244/晚
- **ADR 推算**：套餐加权 ~¥1,150（含早套餐扣减 ~15%） ≈ **¥1,000-1,200**
- **STR 档次归属**：Luxury 边缘 / Upper Upscale 高位

**湖泉酒店系**：
- 平日挂牌：¥466-8,888（黄金周一价）
- 中端房型（标准大床/双床）：~¥500-800
- 抖音团购（湖泉印象）：¥992 → ¥538/2 晚（淡季促销价）
- **ADR 推算**：加权均价 **~¥600-800**
- **STR 档次归属**：Upscale 中位

**湖泉天邑**：
- 基础挂牌价：**¥1,800+**
- **STR 档次归属**：Upper Upscale 高位

**巨人雅阁（雅高）**：
- 携程挂牌：**¥300-400**
- **STR 档次归属**：Upper Midscale 高位

**鑫甲玉泉温泉**：
- 携程挂牌：**¥200+**
- **STR 档次归属**：Upper Midscale 中位

**经济型酒店/民宿**：
- 携程挂牌：¥150-300
- **STR 档次归属**：Midscale

#### 5.1.2 OCC 推算（基于节假日售罄+OTA 评分反推）

**核心依据**：
- 2025 五一 101.94 万游客（+36.41%），云南全省五一酒店 OCC 平均 >85%
- 红河州酒店订单量涨幅云南前 5
- 节假日美憬阁"抢兑房券"现象（携程 6,020 条"超棒"点评）
- **节假日美憬阁/湖泉天邑 OCC 接近 100%**

**推算结果**（按档次）：
| 档次 | 节假日 OCC | 平日 OCC | 全年 OCC |
|------|----------|---------|----------|
| 美憬阁（高端） | 90-100% | 50-65% | 65-75% |
| 湖泉酒店系 | 85-95% | 45-60% | 60-70% |
| 中端连锁（巨人雅阁/258） | 75-85% | 40-55% | 55-65% |
| 经济型/民宿（1,200家） | 60-75% | 25-40% | 35-50% |
| **全市推估** | **75-85%** | **35-50%** | **45-55%** |

#### 5.1.3 RevPAR 推算

| 档次 | ADR（推算） | OCC（推估） | **RevPAR** |
|------|-----------|------------|-----------|
| 美憬阁 | ¥1,100 | 70% | **¥770** |
| 湖泉酒店系 | ¥700 | 65% | **¥455** |
| 中端连锁 | ¥350 | 60% | **¥210** |
| 经济型/民宿 | ¥200 | 40% | **¥80** |
| **全市加权推估** | ~¥350 | ~50% | **~¥175** |

**对比基准**：
- 云南全省 2024 五一酒店平均 OCC >85%
- 大理/丽江/版纳热点 OCC >95%
- **弥勒推估 OCC < 大理丽江**，但 RevPAR 低于大理丽江（因 ADR 较低）

## 附录 A：数据采集与验证方法（OTA 采集 SOP）

### A.1 Eric 标准 ADR 估算方法

**方法一：官网直销价 + OTA 挂牌价 双重加权法（最精确）**：
```
ADR_估算 = 官网直销均价 × 50% + OTA挂牌均价 × 50%
（去掉的房型：无窗房、促销价、套房、特殊房型）
```

**方法二：OTA 挂牌价反推法（降级使用）**：
```
ADR_估算 = ADR_挂牌 × (1 - 0.135)  // 佣金扣除
```

**方法四：OTA 动态监控法**（用于跟踪）：
- 旺季每天抓 1 次，淡季每周 2-3 次
- 关注节假日/展会/周末价格波动

### A.2 携程 EBK 后台数据导出 SOP（5 分钟搞定）

### C.3 共轭类（Equivalence Classes）

**从客户视角**：候鸟康养、自驾游、亲子、银发、商务——**5 类不可相互替代**，每类对应不同产品/价格/渠道策略。

**从酒店视角**：高端艺术（美憬阁）、中端商务（巨人雅阁）、温泉度假（湖泉系）、民宿集群（1,200 家）——**4 类不可替代**。

### C.4 轨道（Orbits）

**客户从"过夜→连住→旅居→置业"的轨道演进**：
```
一日游（80%）→ 过夜游（20%）→ 周末度假 → 长住旅居 → 异地置业
```
**关键洞察**：AHL 可切入"连住→长住"转化节点（旅居康养预订平台）。

### C.5 可分解性（Decomposability）

**AHL 三大场景的"正规子群"结构**：
```
G_弥勒酒店 = G_民宿 × G_连锁 × G_康养

G_民宿 = 国家丙级 → 区域品牌 → 集群化
G_连锁 = 经济 → 中端 → 中高端

```
