### 2. 【历史沿革】通胀定义权之争的谱系

这不是新问题。美联储的通胀衡量方法一直是政治性选择：

```
1970s   Arthur Burns时代：使用整体CPI → 低估核心趋势
1979-87 Paul Volcker时代：关注核心CPI → 成功驯服通胀但制造了双底衰退
2000s   Greenspan转向核心PCE → 剔除食品能源，更"平滑"
2012    Bernanke正式将PCE作为2%目标
2020    Powell转向"平均通胀目标制"（FAIT）→ 允许通胀超调
2026    Warsh提案：用截尾平均PCE取代核心PCE

每一次度量变更 = 政策空间的重新定义
Warsh的"截尾平均"实质：将油价冲击定义为"暂时性极端值"予以剔除
→ 降息门槛大幅降低
→ 但风险：若油价持续高位15个月以上，"截尾"就变成了"掩盖"
```

达拉斯联储截尾平均PCE当前读数为2.4%，而核心PCE为3.2%，核心CPI年化7.3%。这个差距本身就说明问题——**通胀压力的分布高度不均匀**，主要集中在能源和住房，其他领域通胀已回归常态。

### 5. 【底层逻辑】

**定义权即政策权。**

Warsh的截尾平均PCE提案不是技术修正，是**对"通胀"这个经济最核心概念的定义权争夺**。如果成功，效果等同于在没有降息的情况下降低了有效政策利率——因为市场会自行将"新通胀读数2.4%"定价，推动实际利率下降。

更深的逻辑：
```
通胀 = 货币现象（Friedman）
通胀 = 预期的自我实现（Lucas/Sargent）
通胀 = 度量工具的选择（Warsh的赌注）
```

这第三层逻辑是Warsh的独创：**通过改变尺子来改变温度。**

风险在于：如果截尾平均PCE掩盖了真实的输入型通胀压力（油价），那么当截尾平均也开始上升时（即油价冲击扩散到更广泛的价格），Fed将面临比现在更糟糕的双输局面。

- RMB：6.9081（YTD +1.2%）

**政策动态**：
- 5/21 国务院常务会议：研究统一大市场建设 + 讨论《中国人民银行法（修订草案）》

- 财政部-央行联合工作组第四次组长会：推动离岸人民币国债市场

### 原因分析

**PPI跳升的根因**：不是中国内需过热，是**输入型**——全球油价$107传导到石油开采（+双位数）、有色金属（+双位数）等上游行业。这不是好事——如果上游涨价无法传导到下游（CPI仅1.2%），意味着制造业利润空间被挤压。

**出口超预期的根因**：可能包含"抢出口"效应（中美休战窗口期的前置订单） + "转口贸易"（经过第三方国家）。可持续性存疑。

**房地产修复的结构性**：量升但价不升——上海二手房4月2.87万套（10年新高），但价格仍在筑底。这是典型的"以价换量"修复模式。

### 预判（3个月）

- **PPI将继续上行**（油价高位+基数效应），6-8月可能触及3.5-4%，可能触发政策关注
- **央行降准概率上升**——MLF 6000亿操作表明流动性管理精细化，但全面降准50bp可能在Q3落地
- **人民币面临升值压力**——6.9081已经升了1.2%，如果Warsh框架推动美元走弱，RMB可能触及6.7
- **房地产市场**：一线城市"量升价稳"延续，但二三线传导仍需12-18个月

### 底层逻辑

中国的宏观策略是**时间换空间**——用适度宽松的货币政策+精准的结构性工具，在外需不确定（中美关系）和内需未完全恢复之间维持平衡。PPI跳升带来的输入型成本压力，是当前最大的外部灰犀牛。

## 🟡 重要关注三：OTA反垄断——携程面临解体风险，窗口在扩大

### 当下情况

- BBC中文（5/28）深度分析：攜程遭遇中國反壟斷調查，**花旗预计罚款高达49亿元**
- 路透引述野村分析：**携程可能被要求剥离同程网业务**（持股>20%）
- 调查核心：①"大数据杀熟"（老客户价格更高）— 全球OTA通病 ②"二选一"排他条款 — 限制酒店在竞品平台低价销售 ③ 搜索排名规则不透明
- 携程市场份额：中国OTA GMV的70%（交银国际）→ 携程App用户约2.14亿+同程2.85亿=实质支配
- 全球对标：Booking.com 2024年被欧盟DMA定义为"守门人"——禁止"最优惠价格"条款，Hotrec发起集体诉讼
- 国际OTA在携程被查期间可能获得相对竞争优势——Booking/Expedia在入境游市场的份额可能上升

### 原因分析

**携程为什么被查？**
三重不满叠加：
1. **消费者不满**：同一酒店不同账号价格差近一倍（新华社此前报道）
2. **酒店业不满**：佣金率过高（携程毛利率81%），实质形成双向价格挤压
3. **监管意志**：2020年阿里/美团反垄断后，数字平台治理是中央意志的延续

**携程81%毛利率**（港大雷骁教授分析）意味着什么？意味着每100元酒店收入中，携程拿走81元作为毛利润。作为对比，全球酒店平均GOP率（经营毛利率）约35-40%。携程比酒店更赚钱——这不是一个健康的生态。

### 预判（3个月）

| 情景 | 监管结果 | 对行业影响 | 概率 |
|------|---------|-----------|------|
| 🟢 | 罚款20-40亿元+行为整改+限制排他条款（不剥离） | OTA渠道成本下降2-5%，酒店议价权提升 | 50% |
| 🟡 | 罚款+剥离同程股权+开放数据接口 | 渠道碎片化开始，AHL/抖音等新平台受益最大 | 35% |
| 🔴 | 罚款+剥离+高管追责+强制开放算法 | 中国OTA格局根本性改变，AHL窗口全面打开 | 15% |

### 对AHL的战略含义

**这是AHL诞生以来最大的结构性机遇。**
- 如果携程被剥离同程 → OTA市场二强格局被打破 → 新连接协议（AHL-LLM）有了生存空间
- 如果"二选一"被禁止 → 酒店可以在AHL和携程同时上线 → AHL获取供给端阻力大幅降低
- 如果算法透明度被要求 → AHL的去中心化/透明匹配叙事获得监管背书

**但风险也需清醒认识：**
- 抖音/美团/飞猪同样是巨头，OTA碎片化的受益者不一定轮到AHL
- AHL需要在监管窗口关闭前（预计6-12个月）跑出最小可行网络
