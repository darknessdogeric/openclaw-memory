## 二、分项偏差归因（深度分析）

### 2.1 需求端偏差归因

#### 2.1.1 民航：本次最大偏差（🔴 方向错误）

| 归因层次 | 因素 | 影响权重 | 机制 | 数据佐证 |

| **第二层：周期分流** | 春假前拓出行周期 | ⭐⭐⭐⭐ 25% | 浙江/山东/湖南/辽宁等省春假将出行周期前拓至4/28，分流五一正假期 | 4月底客流数据（需补充） |

## 三、分档次实际表现

### 3.1 推算方法说明

> ⚠️ 以下ADR/OCC/RevPAR数值为「方向性推算值」，推算逻辑：
> 1. 以节前预测（基于酒店之家4/20当周预订口径ADR同比）为基准
> 2. 以同程/携程/去哪儿/美团平台方向性数据（预订热度/四星增幅/县域增速）为方向约束
> 3. 以交通部最终出行数据（民航-5.74%/铁路+4.6%/公路+3.51%）为需求端约束
> 4. 以浩华Q2景气指数（-9）和供给增速（+6.5%）为行业基准
> 5. 交叉验证后输出推算区间
>
> **推算置信度**：🟡中（±2-4ppts），待酒店之家周报/券商研报替换为🟢精确值。

### 3.3 分档次深度分析

#### 经济型（ADR ¥200-350）

```
RevPAR ████████ +1.5~2.5%  ← 低于预测，供需双向挤压
```

**低于预测的归因**：
- 供给端：县域品质酒店+76%形成"升维竞争"——住客愿意多花50-100元住更好的
- 需求端：下沉市场价格敏感客群比例高，ADR弹性弱
- 结构性："高铁+落地租车"模式使自驾刚需住宿需求被分流至中档

#### 中档型（ADR ¥350-600）⭐⭐ 最大赢家

```
RevPAR ████████████ +6.0~7.5%  ← 符合甚至略超预测上限
```

**超预期的归因**：
- 亲子家庭首选（59%出行占比）→ 家庭联通房/亲子房溢价明显（+50%热度）
- 跳城游中间站定位 → 60%旅客2-3城串联，中档是"跳城"标准配置
- 县域品质酒店+76%的主体就是中档连锁 → 下沉市场供给品质化=中档化
- 替代游客群"愿意花更多但不奢侈"的心态 → 中档是性价比最优解
- 票根经济→赛事/演出周边中档酒店溢价+70~390%

#### 高档型（ADR ¥600-1,200）

```
RevPAR ██████████ +3.5~5.5%  ← 符合预测，实质性修复中
```

**结构性修复信号**：
- 海外替代游核心承接层 → 云南+89%/四川+80%的跟团游以高档住宿为主
- 三亚亚龙湾+47%预订热度验证
- 但民航-5.74%拖累长线高档 → 部分高端客群因高价机票放弃出行
- 入境高净值客群（俄+120%/土耳其+367%）补充高端需求

#### 豪华型（ADR ¥1,200+）

```
RevPAR ███████ +1.0~3.0%  ← 符合预测，滞后修复
```

**滞后修复的核心矛盾**：
- 出境替代效应+入境高净值是正推动
- 但民航高票价挤出边际高端客→长线豪华目的地承压
- 一线城市豪华酒店商务客五一归零→纯度假客群不足以填满
- 县域高星酒店消费占比首超一线→豪华消费在"下沉"，但ADR低一档
