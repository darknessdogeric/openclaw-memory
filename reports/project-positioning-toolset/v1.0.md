## 写在前面：为什么需要这个工具集

行业现存三套分级体系，但都有明显局限：

| 体系 | 来源 | 局限 |
|------|------|------|
| **星级评定 (1-5星)** | 1988 年国家标准 | 静态、单维度、2010 年后已淡化 |
| **OTA 分级 (经济/舒适/高档/豪华)** | 携程/美团 | 偏 C 端感知，不反映投资模型 |
| **行业惯用分级 (有限服务/全服务)** | 国际品牌 | 以服务深度为主，忽略物业和区位 |

**核心问题**：单维度分级无法描述真实项目 — 一个"A 级物业 + 中端品牌 + 三线城市"的项目，与一个"B 级物业 + 中端品牌 + 一线城市"的项目，可能投资逻辑完全相反。

**本文方法论**：用**五轴矩阵** + **地域差异因子** + **内外资博弈模型** + **新物种预判框架**，建立可决策的分级分类体系。

## 二、项目阶段分类（6 阶段模型）

| 阶段 | 名称 | 项目状态 | 关键判断问题 |
|------|------|---------|------------|
| **P0** | 拿地前 | 仅有地块/意向地块 | 这块地**该不该拿**？**做什么**？ |
| **P1** | 拿地后规划 | 已拿地，已签租约/已购物业 | **怎么设计**？**挂什么品牌**？ |
| **P2** | 筹建期 | 已开工/正在筹建 | **施工调整**？**运营前置**？ |
| **P3** | 开业筹备 | 即将开业/试运营 | **如何定价**？**如何定位客群**？ |
| **P4** | 运营期 | 已开业运营中 | **如何调改**？**如何提升**？ |
| **P5** | 翻新/退出 | 老化物业/资产处置 | **翻新/转让/证券化**？ |

### 不同阶段判断重点差异

```
P0 拿地前      → 物业评估(T1) + 市场评估(T2) = 决定"做不做、做什么"
P1 拿地后规划  → 物业(T1) + 市场(T2) + 客群(T3) + 业态(T4) = 完整定位
P2 筹建期      → 业态匹配(T4) + 投资验证(T5) = 锁定产品+财务闭环
P3 开业筹备    → 客群定位(T3) + 业态匹配(T4) = 营销策略
P4 运营期      → 翻新改造(T6) = 周期性调改
P5 翻新/退出   → 翻新改造(T6) + 退出评估(T7) = 资产处置
```

## 三、32 项判断指标库 (DB1)

每个项目定位由 **32 项核心指标** 构成。指标分 6 组，每组有明确的数据来源和判断标准。

### 组 A：物业指标 (8项)

| 编号 | 指标 | 数据来源 | 判断标准 | 权重 |
|------|------|---------|---------|------|
| **A1** | 区位能级 | 第一财经新一线 / 国家统计局 | S=北上广深 / A=新一线 / B=省会 / C=地级市 / D=县级 / T=旅游目的地 | 15% |
| **A2** | 商圈类型 | 实地调研+政府规划 | 6 类：CBD/景区/交通枢纽/产业园区/居住区/度假区 | 10% |
| **A3** | 地段稀缺性 | 1 公里内稀缺资源评分 | 1-10 分（边缘=1-3 / 次中心=4-6 / 核心=7-8 / 唯一=9-10） | 15% |
| **A4** | 周边竞品密度 | OTA 爬虫+实地调研 | 同业态 3km 内酒店数：<5=稀缺 / 5-15=适中 / >15=红海 | 10% |
| **A5** | 物业硬件评分 | 专业物评团队评估 | 1-100 分（结构/机电/装饰/消防） | 10% |
| **A6** | 单方造价 | 工程预算 | 800-5,500 元/㎡（按业态） | 5% |
| **A7** | 可改造性 | 建筑师评估 | 1-10 分（结构改动灵活度） | 10% |
| **A8** | 物业剩余年限 | 土地证/租约 | <10 年=短期 / 10-20 年=中期 / >20 年=长期 | 5% |

### 组 B：市场指标 (8项)

| 编号 | 指标 | 数据来源 | 判断标准 | 权重 |
|------|------|---------|---------|------|
| **B1** | 城市 GDP | 国家统计局 | 城市能级基准 | 5% |
| **B2** | 人均可支配收入 | 国家统计局 | 决定客单价承受力 | 5% |
| **B3** | 客源结构 | 酒店之家/STR/调研 | 商旅/度假/会议/政务比例 | 10% |
| **B4** | ADR 天花板 | OTA 数据+市场调研 | 按区位×业态分级参考表（见下文） | 15% |
| **B5** | OCC 基准 | 酒店之家/STR | 按区位×业态分级参考表 | 10% |
| **B6** | RevPAR 基准 | B4×B5 | 派生指标 | - |
| **B7** | 渗透率 | 客房数/常住人口 | 0.5-3% 为健康 | 5% |
| **B8** | 增长率 (近3年 CAGR) | 历史数据 | <3%停滞 / 3-8%稳定 / >8%高速 | 10% |

### 组 C：客群指标 (6项)

| 编号 | 指标 | 数据来源 | 判断标准 | 权重 |
|------|------|---------|---------|------|
| **C1** | 主要客群画像 | 实地调研+竞品分析 | 8 类客群分布比例 | 10% |
| **C2** | 客单价承受力 | 竞品 ADR+调研 | 心理价位区间 | 10% |
| **C3** | 复购特征 | OTA 评价+会员数据 | 商旅高频 / 度假低频 | 5% |
| **C4** | 渠道偏好 | OTA 订单结构 | OTA / 直销 / 协议比例 | 5% |
| **C5** | 在地客群占比 | 调研 | 异地客/本地客比例 | 5% |
| **C6** | 客群迭代趋势 | 行业研究 | 新客群 (Z 世代/数字游民等) 增速 | 5% |

### 组 D：财务指标 (5项)

| 编号 | 指标 | 数据来源 | 判断标准 | 权重 |
|------|------|---------|---------|------|
| **D1** | 总投资预算 | 自有资金+融资 | 总投资 = 物业+筹建+开业筹备+流动资金 | 10% |
| **D2** | 单房投资 | D1/客房数 | 经济≤15 万 / 中端 15-25 万 / 中高端 25-40 万 / 高端 40-70 万 / 奢华>70 万 | 10% |
| **D3** | 目标 IRR | 业主战略 | 经济型 8-10% / 中端 10-15% / 中高端 12-18% / 高端 8-12% / 奢华 6-10% | 10% |
| **D4** | 投资回收期 | 财务模型 | 5-8 年（成熟期）/ 8-12 年（培育期） | 5% |
| **D5** | 退出方式规划 | 业主战略 | REITs / 整体出售 / 经营贷 / 长期持有 | 5% |

### 组 E：政策指标 (3项)

| 编号 | 指标 | 数据来源 | 判断标准 | 权重 |
|------|------|---------|---------|------|
| **E1** | 土地性质 | 国土证 | 商住 / 商业 / 综合 / 旅游 | 必备 |
| **E2** | 规划条件 | 规划局 | 容积率/限高/限业态 | 必备 |
| **E3** | 当地酒店政策 | 文旅局 | 特种行业许可/限价/补贴 | 必备 |

### 组 F：战略指标 (2项)

| 编号 | 指标 | 数据来源 | 判断标准 | 权重 |
|------|------|---------|---------|------|
| **F1** | 业主战略意图 | 业主自述 | 短期套利/中期持有/长期资产 | 必备 |
| **F2** | 风险承受度 | 业主自评 | 保守/中性/激进 | 必备 |

## 五、6 阶段工具详细设计

### T0：项目阶段自测卡

**使用方法**：回答 10 个问题，自动判定项目阶段。

```
Q1: 项目当前是否有合法物业？  否→P0 | 是→Q2
Q2: 物业是自有还是租赁？      自有且长期→Q4 | 租赁>10 年→Q3
Q3: 是否已签订租约？          否→P0 | 是→P1
Q4: 是否已完成规划设计？      否→P1 | 是→Q5
Q5: 是否已开工建设？          否→P1 | 是→P2
Q6: 是否已完成施工？          否→P2 | 是→Q7
Q7: 是否已开始试运营？        否→P3 | 是→Q8
Q8: 是否已正式开业？          否→P3 | 是→Q9
Q9: 开业运营是否满 3 年？     否→P4 | 是→Q10
Q10: 是否计划翻新/退出？     否→P4 | 是→P5
```

### T1：物业评估卡（适用 P0/P1）

**输入**：32 项指标中的 A 组（8 项物业指标）

**输出**：
- 物业分级 (A+/A/B+/B/C/D)
- 物业适合的业态范围
- 物业改造建议

**评估流程**：
```
1. 区位能级 → 锁定区位大坐标 (S/A/B/C/D/T)
2. 商圈类型 → 锁定商圈小坐标
3. 地段稀缺性 → 评分 (1-10)
4. 周边竞品密度 → 判断市场容量
5. 物业硬件评分 + 可改造性 → 评估工程量
6. 单方造价 → 评估投资额
7. 物业剩余年限 → 评估持有策略
8. 综合输出物业分级
```

**输出模板**：
```
【物业评估卡】 物业名称：______  日期：______

一、区位大坐标：____（S/A/B/C/D/T）
二、商圈小坐标：____（CBD/景区/交通枢纽/产业园区/居住区/度假区）
三、综合分级：____（A+/A/B+/B/C/D）
四、推荐业态范围：____（从最高到最低）
五、改造难度：____（低/中/高）
六、单房投资建议：____ 万元
七、特别提示：____
```

### T2：市场评估卡（适用 P0/P1）

**输入**：32 项指标中的 B 组（8 项市场指标）

**输出**：
- ADR/OCC/RevPAR 基准
- 市场健康度评级（优/良/中/差）
- 市场天花板警告

**评估流程**：
```
1. 城市 GDP + 人均可支配收入 → 评估市场基本盘
2. 客源结构 → 锁定主战场
3. ADR 天花板 + OCC 基准 → 锁定经营预期
4. 渗透率 → 判断市场饱和度
5. 增长率 → 判断市场趋势
6. 综合输出市场健康度
```

**健康度评级标准**：

| 评级 | 标准 |
|------|------|
| **优** | 增长率>8% + 渗透率<1.5% + ADR 达标率>90% |
| **良** | 增长率 3-8% + 渗透率 1.5-2.5% + ADR 达标率 70-90% |
| **中** | 增长率 0-3% + 渗透率 2.5-3% + ADR 达标率 50-70% |
| **差** | 增长率<0% 或 渗透率>3% 或 ADR 达标率<50% |

### T3：客群定位卡（适用 P0/P1/P3）

**输入**：32 项指标中的 C 组（6 项客群指标）

**输出**：
- 主客群（1-2 类）
- 次客群（1-2 类）
- 客单价区间
- 渠道策略

**8 类客群定位锚点**：

| 客群类型 | 锚点 | 关键场景 |
|---------|------|---------|
| **商务精英** | 城市 CBD 高端酒店 | 高频出差+身份认同 |
| **商旅白领** | 城市中端连锁 | 高频出差+性价比 |
| **度假家庭** | 旅游目的地 | 周末/小长假 |
| **度假情侣** | 旅游目的地/精品酒店 | 纪念日/蜜月 |
| **MICE 会议** | 城市高端+大宴会 | 会议/培训/婚宴 |
| **长租/医养** | 城市中端+适老化 | 短期过渡/术后康复 |
| **Z 世代/电竞** | 城市中端+IP | 周末聚会/赛事 |
| **数字游民** | 旅游目的地+网络 | 远程办公 |

### T4：业态匹配卡（适用 P1/P2/P3/P5）

**输入**：T1 + T2 + T3 输出

**输出**：
- 推荐业态（1-3 个候选）
- 推荐品牌策略（自主/加盟/合资/管理）
- 内外资博弈建议

**匹配算法**：
```
Step 1: 取物业分级 (T1) → 锁定候选业态区间
Step 2: 取市场天花板 (T2) → 锁定候选业态上限
Step 3: 取客群定位 (T3) → 锁定候选业态锚点
Step 4: 取财务约束 (D1-D5) → 锁定候选业态投资可行性
Step 5: 输出业态推荐 (交集)

举例：
物业 A + 市场 B + 客群 商旅 → 推荐 中端-中高端
物业 C + 市场 C + 客群 商旅 → 推荐 经济-中端
物业 A+ + 市场 T + 客群 度假 → 推荐 高端-奢华
```

### T5：投资验证卡（适用 P1/P2/P3）

**输入**：T4 推荐业态 + D 组财务指标

**输出**：
- 财务可行性评级（通过/警告/不通过）
- 优化建议

**验证流程**：
```
Step 1: 取 T4 推荐业态 → 锁定单房投资区间
Step 2: 计算预计 RevPAR = ADR × OCC（用 T2 基准）
Step 3: 计算 GOP PAR = RevPAR × GOP 率（按业态 35-50%）
Step 4: 计算静态投资回收期 = 总投资 / 年 GOP
Step 5: 计算 IRR（10 年期）
Step 6: 与 D3 目标 IRR 对比
Step 7: 输出评级
```

**评级标准**：
| 评级 | 标准 |
|------|------|
| **通过** | 静态回收期≤8 年 + IRR≥目标 |
| **警告** | 静态回收期 8-12 年 + IRR 接近目标 |
| **不通过** | 静态回收期>12 年 或 IRR<目标 80% |

### T6：翻新改造卡（适用 P4/P5）

**输入**：运营数据 + A 组物业指标 + C 组客群指标

**输出**：
- 改造策略（轻改/中改/重改）
- 改造预算
- 调改后业态定位

**改造分级**：
```
轻改（单房投资 3-8 万）：
  - 软装更新 + 局部硬装
  - 适用：硬件评分 70-85 分
  - 业态不变 / 客群不变

中改（单房投资 8-20 万）：
  - 硬装翻新 + 局部机电更新
  - 适用：硬件评分 50-70 分
  - 业态不变 / 客群微调

重改（单房投资 20-50 万）：
  - 全拆重装 + 机电全换
  - 适用：硬件评分 < 50 分
  - 业态可升级 / 客群重定位
```

### T7：退出评估卡（适用 P5）

**输入**：T5 + T6 输出

**输出**：

- 退出方式推荐
- 估值区间

**退出方式决策树**：
```
是否在核心城市一线/新一线？
  ├─ 是 → REITs 可行性？
  │    ├─ 高 → REITs 退出（估值溢价 20-40%）
  │    └─ 低 → 整体出售
  └─ 否 → 整体出售/股权转让

物业剩余年限是否>15 年？
  ├─ 是 → 整体出售更优
  └─ 否 → 股权转让或经营贷置换
```

## 附录：核心方法论原则

```
如果...那么...
- 如果你要做项目定位 → 先定区位，再定物业，再定业态，最后定品牌和新物种
- 如果你要判断内外资 → 看客群是否需要国际背书 + 回报是否支持外资标准 + 未来是否需要全球客源
- 如果你要预判新物种 → 三轴模型检验（功能融合+技术驱动+资产模式）
- 如果你要投资决策 → 五轴坐标 + 地域势能 + 内外资博弈 + 新物种权重 = 完整判断
```

**三个关键认知**：

1. **五轴独立，但叠加生效** — 任何一个项目都是五轴的乘积，不是单轴的判断
2. **地域改变势能，不改变分级** — 同样"中端"，在 S 级和 C 级的打法完全不同
3. **新物种的本质是"功能融合"** — 住宿+？的"？"决定了新物种的颠覆性

> **分级分类是简化论工具，不是行动地图。**
> 工具用对了 → 简化决策 → 提高效率
> 工具用错了 → 自我束缚 → 错失新物种
