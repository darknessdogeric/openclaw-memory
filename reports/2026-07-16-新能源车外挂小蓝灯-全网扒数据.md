## 一、这是什么？三分钟速读

| 类别 | 内容 |
|------|------|
| **官方名称** | 自动驾驶标志灯（ADS，Autonomous Driving Status Lamp），国标曾命名"自动驾驶信号灯" |
| **俗称** | 小蓝灯 / 智驾小蓝灯 / ADB 蓝灯 / 智驾灯 / 智驾指示灯 |
| **装在哪** | 车头/车尾/后视镜/车顶 4 个常见位置，颜色蓝绿（4500-5000K）或黄（部分厂商） |
| **官方功能** | 标识车辆**正在运行辅助驾驶/L2-L3 自动驾驶**，提示其他道路参与者（小蓝灯亮起 = 这台车的驾驶主体可能是 AI 不是人） |
| **外挂版** | 淘宝/拼多多/抖音/京东上的"假智驾灯"，**没有真实智驾功能，仅亮蓝光**，让车"看起来"开着智驾 |
| **价格带宽** | 装饰灯套件 ¥30-103；官方后装 399-1388 元；车载小店改装 ¥100-300（工时另算） |

| **L1 通用装饰** | 通用车小蓝灯 / 不接车机 / 假亮 | ¥50-103 | 淘宝/京东 | 老车主/便宜心态 |
| **L2 半正版** | 数字旮旯（接车机/米家）/ 蔚来原厂后装 | ¥399-998 | 京东/品牌官方 | 老车主 / 智驾爱好者 |
| **L3 官方后装** | 蔚来 ET9 1388 / 小鹏硬件 OTA 899 | ¥800-1388 | 品牌官方（OTA 软件配合） | 重度智驾用户/已购车主 |

**关键观察**：
1. **价格带宽跨度 50 倍**（¥30 ↔ ¥1388），意味着不同档位的认知和价值锚完全不一样
2. **接车机的"半正版"成新主流**（数字旮旯模式）：价格下探到 ¥399，但还接车机/米家，体验更接近官方
3. **官方后装也分高低**：蔚来 ET5 系列 998、ET9 1388，因为车型越新/越贵，要走车机校验流程

从社交媒体评论抽样看，受众对"外挂小蓝灯"的态度分裂成 4 派：

- 后装"装 X"派的反对声音存在但**不是主流**

## 七、合规雷区：这条数据线必须独立标红

| 时间 | 监管动作 | 关键条款 |
|------|---------|---------|
| **2025.04** | 公安部道路交通安全研究中心发文 | "**产销'智驾神器'导致重大事故最高可判死刑**"（《刑法》第146条） |
| **2025.04.18** | 公安部公众号"交通言究社"再发 | 虚假宣传自动驾驶最高 2 年有期徒刑 + 罚款广告费 5-10 倍 |
| **2025.05** | 工信部 + 安徽高速 SU7 事故 | 强制要求"智驾"改名"辅助驾驶"（小米率先执行） |
| **2024** | 比亚迪参与起草的《智能网联汽车灯光信号标准》（草案） | 建议色温 4500-5000K，与转向灯明显区隔 |

**评估**：
- 公安部已经把"智驾神器"作为专门打击对象（不是意外事件，是个品类）
- 当前**"小蓝灯"作为合规智驾指示灯是合规的**（按国标草案规定范围内合法）
- **"外挂假小蓝灯"处于灰色地带** —— 卖方不被监管但买方实际使用可能涉及"误导其他道路参与者"
- 目前没有任何事故案例将责任归到"装了假灯的车主"上 → **法律真空**
