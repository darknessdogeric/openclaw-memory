### STR方法论核心偏差特征（已知，需在校准中扣除）

```
STR的四大结构性偏差（中国市场）：
  
  1. 同店偏差（Same-Store Bias）
     → 剔除新开业酒店 → 排除增量供给的ADR稀释效应
     → 结果：STR的ADR增速 > 全市场ADR增速（+50~80bps）
  
  2. 品牌化偏差（Branded Bias）
     → 品牌连锁RevPAR增速 > 独立酒店RevPAR增速
     → 结果：STR的RevPAR增速 > 全市场RevPAR增速（+30~50bps）
  
  3. 高线偏差（Tier Bias）
     → 高线城市超配 → 下沉市场（+18~35% RevPAR增速）权重不足
     → 结果：STR的RevPAR增速 < 全市场RevPAR增速（-50~100bps）
  
  4. 高档偏差（Class Bias）
     → 高档/豪华超配 → 2026五一高档/豪华增速落后中档
     → 结果：STR的RevPAR增速 < 全市场RevPAR增速（-30~50bps）
  
  净校准方向：偏差1+2向上，偏差3+4向下 → 净效应≈相互抵消，STR≈全市场
```

### 2.2 STR视角的核心再归因

#### 2.2.1 民航偏差（🔴 维持方向错误评级，STR无修正）

## 附录A：STR方法论深入（收益管理者必读）

### A.1 STR在中国市场的覆盖盲区

```
STR中国样本酒店的"看不见的市场"：

  1. 三四线城市独立酒店（~15万家，STR覆盖率<20%）
     → 2026五一增速最快的市场（+18~35% RevPAR）
     → STR严重低估

  2. 县域精品民宿/非标住宿（~8万家，STR覆盖率<5%）
     → 2026五一+92%爆发增长
     → STR完全看不见

  3. 经济型独立酒店（~20万家，STR覆盖率<30%）
     → 下沉市场价格敏感客群的主阵地
     → STR数据偏品牌连锁，ADRR偏高

  这意味着：仅靠STR判断中国酒店市场，你会系统性低估：
    · 下沉市场的增速
    · 非标住宿的供给弹性
    · 经济型酒店的价格竞争强度
    · 县域消费升级的速度
  
  正确做法：STR（品牌酒店对标）+ 酒店之家（全市场覆盖）+ OTA（消费行为）
```

### A.2 STR数据的正确用法（收益管理6原则）

| 原则 | 做法 | 错误做法 |
|------|------|---------|
| 1. 同业对标 | 用STR做同档次/同区域酒店RevPAR Index | 用STR绝对值判断市场整体 |
| 2. 趋势判断 | 用STR的环比/同比方向确认趋势 | 用STR的绝对值做投资决策 |
| 3. 发现分化 | 用STR分档次/分城市发现K型分化 | 假设STR代表全国 |
| 4. 下沉补充 | STR + 酒店之家 + OTA = 三源三角验证 | 依赖单一数据源 |
| 5. 口径标注 | 引用STR数据时标注"同店/品牌酒店" | 混用STR和酒店之家数据不做口径说明 |
| 6. 空杯心态 | STR是工具不是神谕 | 盲信STR而不理解其方法论局限 |
