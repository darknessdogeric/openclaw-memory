## 一、私域会员体系全景

### 1.1 私域概念定义

```
┌─────────────────────────────────────────────────────────────────┐
│                      私域流量体系                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  【公域流量】                                                   │
│  定义: 平台拥有的、需要付费购买的流量                           │
│  特点: 一次性、需持续付费、不归酒店所有                        │
│  渠道: 携程/美团/抖音/百度/小红书                            │
│  成本: CAC (Customer Acquisition Cost) 100-500元/人             │
│                                                                 │
│  【私域流量】                                                   │
│  定义: 酒店自主拥有、可免费多次触达的流量                      │
│  特点: 自主性、免费触达、持续经营、资产化                    │
│  渠道: 企业微信/社群/小程序/APP/会员系统                     │
│  成本: CRC (Customer Retention Cost) 约为CAC的1/5-1/10        │
│                                                                 │
│  【核心差异】                                                   │
│  ┌────────────────┬──────────────────────────────────┐      │
│  │     维度       │        公域    vs    私域         │      │
│  ├────────────────┼──────────────────────────────────┤      │
│  │  归属权       │    平台所有    vs  酒店自有      │      │
│  │  触达成本     │    每次付费    vs  免费多次      │      │
│  │  数据掌控     │    平台封闭    vs  完整掌握      │      │
│  │  客户关系     │    弱关系      vs  强关系       │      │
│  │  长期价值     │    低          vs  高(LTV)       │      │
│  └────────────────┴──────────────────────────────────┘      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 二、会员体系设计

### 2.1 会员等级体系

#### 会员等级设计原则

| 原则 | 说明 |
|------|------|
| 消费门槛递增 | 等级越高，进入门槛越高 |
| 权益价值匹配 | 等级越高，权益越丰厚 |
| 升级有感 | 每次升级要让会员感受到价值提升 |
| 降级保护 | 设置保级条件，避免会员流失 |

#### 典型酒店会员等级

```
会员等级金字塔

                    ▲
                   /│\           钻卡/黑卡
                  / │ \          占比: 3-5%
                 /  │  \         权益: 全免+专属服务+优先权
                /───┼---\        年消费: 5万+
               /    │    \        年消费: 2-5万
              / 金卡 │     \
             /  占比│      \       占比: 10-15%
            /  8-12%│       \      权益: 升房+早/晚+行政待遇
           /        │        \     年消费: 1-2万
          /  银卡   │         \
         /   占比   │          \     占比: 20-25%
        /   15-20% │           \    权益: 92折+早餐
       /────────────┼─────────────\   年消费: 0.5-1万
      /   普通会员  │             \
     /    占比     │              \    占比: 55-65%
    /    入会门槛  │               \   权益: 积分+生日礼
   /_____________________________\  年消费: <0.5万
```

#### 会员权益设计

| 等级 | 价格权益 | 服务权益 | 专属权益 |
|------|----------|----------|----------|
| **普通** | 官网价 | 积分10元=1分 | 生日礼物 |
| **银卡** | 95-98折 | 积分2倍+早餐 | 延迟退房 |
| **金卡** | 92-95折 | 积分3倍+早+晚 | 升房+优先 |
| **钻卡** | 88-92折 | 全行政待遇 | 专属管家+免押 |

│  ├── 生日献礼: +500积分(生日当月)                            │

## 五、RFM模型与会员分层

### 5.1 RFM模型

```
┌─────────────────────────────────────────────────────────────────┐
│                       RFM模型                                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  【Recency (最近一次消费)】                                      │
│  定义: 上次消费距今时间                                         │
│  价值: 越近越好，说明会员活跃                                   │
│  评分: R越大分越高 (近1月=5分, >1年=1分)                       │
│                                                                 │
│  【Frequency (消费频率)】                                      │
│  定义: 一定周期内的消费次数                                    │
│  价值: 越频繁越有价值                                          │
│  评分: F越大分越高 (年10次+=5分, 1次=1分)                     │
│                                                                 │
│  【Monetary (消费金额)】                                        │
│  定义: 总消费金额或平均消费                                     │
│  价值: 越高越有价值                                            │
│  评分: M越大分越高 (年消费2万+=5分, <2000=1分)                 │
│                                                                 │
│  【RFM综合评分】                                                │
│  高R高F高M = 核心会员 (价值最高，重点维护)                      │
│  高R高F低M = 活跃会员 (潜力会员，提升消费)                      │
│  高R低F高M = 高价值沉睡 (召回重点)                              │
│  低R高F高M = 即将流失 (紧急召回)                               │
│  低R低F低M = 低价值会员 (减少运营投入)                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────────────┐

│                                                                 │
│  【质量指标】                                                   │
│  ├── 首访率: 首访/注册 = 40-60%正常                           │
│  ├── 复购率: 复购/总会员 = 20-30%正常                       │
│  ├── 升级率: 升级/应升级 = 30-40%正常                         │
│  └── 流失率: 流失/总会员 = 10-15%/年                         │
│                                                                 │
│  【价值指标】                                                   │
│  ├── ARPU: 会员人均收入 = 年GMV/会员数                        │
│  ├── LTV: 会员生命周期价值 = ARPU×平均生命周期                │
│  ├── LTV/CAC: 价值投入比 > 3为健康                           │
│  └── 会员GMV占比: 会员GMV/总GMV = 40-60%正常              │
│                                                                 │
│  【运营指标】                                                   │
│  ├── 触达率: 触达成功/发送 = 80%+正常                        │
│  ├── 打开率: 打开/触达 = 15-25%正常                           │
│  ├── 转化率: 转化/打开 = 3-5%正常                             │
│  └── 客诉率: 客诉/总订单 = <0.5%正常                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 7.2 指标计算公式

| 指标 | 公式 | 目标值 |
|------|------|--------|
| 会员活跃率 | 月活会员÷总会员×100% | 25-35% |

| 会员ARPU | 会员年消费÷会员数 | 3000+元 |
| 会员LTV | ARPU×平均生命周期(3年) | 9000+元 |
| 首访转化率 | 首访会员÷注册会员×100% | 40-60% |
| 流失预警率 | 流失会员÷总会员×100% | <15%/年 |
| 会员GMV占比 | 会员GMV÷酒店GMV×100% | 40-60% |
| 获客成本CAC | 获客投入÷新会员数 | <100元 |
