## Part 2：地域差异矩阵 — **"相同分级在不同地域的不同打法"**

这是你之前问的关键点。**相同分级分类 ≠ 相同打法**，因为地域改变了所有维度：

### 矩阵推演：分级 × 地域 = 真实落地打法

| 分级\地域 | 一线S | 新一线A | 省会B | 地级市C | 旅游目的地 |
|---------|--------|---------|-------|---------|-----------|
| **奢华** | 外资碾压<br>(丽思/瑞吉) | 内外资拉锯<br>(本土奢华崛起) | 几乎无市场 | 不存在 | 度假奢华<br>(松赞/安麓) |
| **高端** | 万豪/希尔顿/凯悦 | 万豪+本土高端共存 | 本土高端为主 | 极少存在 | 国际度假村 |
| **中高端** | 外资中端+本土挑战 | 亚朵主场+外资中端 | 本土中高端 | 不存在 | 主题度假 |
| **中端** | 维也纳/麗枫/全季 | 全季/亚朵主战场 | 本土中端 | 本土+经济型升级 | 经济型度假 |
| **经济** | 汉庭/如家 | 本土连锁 | 本土连锁 | 本土+单体 | 经济型+民宿 |

### 地域差异的5个核心变量

```
1. 客单价天花板     → 决定能开什么级别
2. 物业成本         → 决定回报率临界点
3. 客源结构         → 决定业态选择
4. 文化适配度       → 决定设计和服务调性
5. 政策环境         → 决定能不能做、怎么做
```

### 关键洞察：地域改变"势能"，不改变"分级"

> **同一栋物业、同一套产品，在成都和襄阳的"势能"完全不同。**
> 
> **成都太古里旁边的"中端" → 实际经营可达到新一线中高端的 ADR**
> **襄阳中心广场的"中端" → 实际经营只能维持中端ADR**
> 
> 这就是为什么**远途Vhotel项目能在成都跑通模型，在襄阳未必**——不是产品不行，是势能差。

## Part 3：内外资差异的博弈论分析

### 5个关键博弈场景

| 维度 | 外资优势 | 内资优势 | 博弈结论 |
|------|---------|---------|---------|
| **标准化** | 全球SOP，强约束 | 灵活迭代，但约束弱 | 外资胜在"下限"，内资胜在"上限可能" |
| **会员体系** | 全球1.5亿+会员 (万豪Bonvoy) | 国内单点突破 (华住会) | 外资胜在国际客源，内资胜在国内下沉 |
| **本土化** | 文化适配弱，决策链长 | 本土理解深，迭代快 | 内资在"中端及以下"完胜 |
| **设计标准** | 全球设计公司背书 | 设计院本土化+性价比 | 外资在"高端及以上"领先 |
| **资本/退出** | REITs渠道成熟 | 国内REITs刚起步 | 外资在资产证券化上领先 |

### 博弈论结论：内外资在不同分级的纳什均衡

```
一线S级 + 奢华/高端    → 外资占优 (高净值客群认可)
一线S级 + 中端         → 内外资胶着
新一线A + 高端         → 内外资拉锯 (本土奢华崛起)
新一线A + 中端         → 内资主导 (亚朵/全季主场)
B级及以下              → 内资垄断 (外资下沉难)
```

### 群论视角：内外资的"对称群"差异

```
外资品牌 = 单一变换群下的复制 (例如希尔顿 = 全球统一SOP × 地域微调)
内资品牌 = 多重变换群下的变形 (例如华住 = 经济型×中端×高端×奢华 全品牌线)

结果：内资品牌的"对称性"低于外资，但"适应性"远高于外资
→ 这就是为什么华住能从汉庭做到花间堂 (覆盖全分级)
→ 万豪能从万怡做到丽思 (但仍是同一变换群)
```

## 写在前面：为什么现有分级体系都不够用？

行业现存三套分级体系，但都有明显局限：

| 体系 | 来源 | 局限 |
|------|------|------|
| **星级评定 (1-5星)** | 1988年国家标准 | 静态、单维度、2010年后已淡化 |
| **OTA分级 (经济/舒适/高档/豪华)** | 携程/美团 | 偏C端感知，不反映投资模型 |
| **行业惯用分级 (有限服务/全服务)** | 国际品牌 | 以服务深度为主，忽略物业和区位 |

**核心问题**：单维度分级无法描述真实项目 — 一个"A级物业+中端品牌+三线城市"的项目，与一个"B级物业+中端品牌+一线城市"的项目，可能投资逻辑完全相反。

**本文方法论**：用**五轴矩阵**+**地域差异因子**+**内外资博弈模型**+**新物种预判框架**，建立可决策的分级分类体系。

## 一、五轴分级分类矩阵

任何酒店项目可在以下五个独立轴上定位，每一轴都有清晰的判断标准。

### 轴 1：物业分级 (Property Grade) — "在哪做、物业什么条件"

按位置稀缺性 + 物业条件客观分级：

| 级别 | 定义 | 单方造价参考 | 关键特征 |
|------|------|------------|---------|
| **A+** | 城市CBD核心 / 5A景区核心 / 城市地标 | 3,500-5,500 元/㎡ | 地段稀缺性 >> 物业本身 |
| **A** | 城市核心商圈 / 4A景区核心 | 2,500-3,800 元/㎡ | 客流稳定，溢价空间大 |
| **B+** | 新一线核心 / 省会核心 | 2,000-3,000 元/㎡ | 上升期，需12-24月培育期 |
| **B** | 省会次级 / 地级市核心 | 1,500-2,200 元/㎡ | 性价比战场，本土品牌主战场 |
| **C** | 成熟居住区 / 经济百强县 | 1,200-1,800 元/㎡ | 价格敏感，标准化优先 |
| **D** | 边缘区位 / 下沉市场 | 800-1,500 元/㎡ | 经济型连锁生存空间 |

**判断标准**：地段稀缺性 (40%) + 物业硬件条件 (30%) + 周边配套成熟度 (30%)

---

### 轴 2：业态分级 (Service Depth) — "做什么档次的产品"

按服务深度分级（国际通用）：

| 业态 | 服务深度 | 客房:员工比 | 关键模块 | ADR区间 |
|------|---------|------------|---------|---------|
| **经济型 (Limited Service)** | B&B | 1:0.15-0.20 | 床+早餐+独立卫生间 | 150-300元 |
| **中端 (Select-Service)** | 精选服务 | 1:0.25-0.35 | +24h健身+简易早餐厅+小会议 | 300-500元 |
| **中高端 (Upscale Select)** | 增强精选 | 1:0.40-0.50 | +全日制餐厅+行政酒廊+小宴会 | 500-800元 |
| **高端 (Full-Service)** | 全服务 | 1:0.60-0.80 | +多餐厅+SPA+大宴会+康体 | 800-1,500元 |
| **奢华 (Luxury)** | 顶级全服务 | 1:1.00-1.50 | +管家+米其林+私人定制 | 1,500-5,000+元 |

**判断标准**：服务模块数量 (40%) + 客需满足度 (30%) + 单房投资额 (30%)

---

### 轴 3：品牌分级 (Brand Tier) — "挂什么品牌的牌子"

按品牌溢价 + 集团背书分级：

| 级别 | 国际品牌 | 国内品牌 | 品牌溢价倍数 |
|------|---------|---------|-------------|
| **奢华** | 丽思卡尔顿 / 瑞吉 / 四季 / 华尔道夫 | 安麓 / 诺金 / 松赞 / 柏联 | 3-5倍 |
| **高端** | 万豪 / 希尔顿 / 凯悦 / 洲际 / 索菲特 | 君亭 / 禧玥 / 花间堂 | 2-3倍 |
| **中高端** | 万怡 / 美居 / 希尔顿花园 / 福朋 / 智选假日 | 亚朵 / 美仑 / 维景 / 锦江都城 | 1.5-2倍 |
| **中端** | (外资下沉品牌) | 全季 / 桔子 / 麗枫 / 维也纳 / 凯里亚朵 | 1.0-1.3倍 |
| **经济** | (极少) | 汉庭 / 如家 / 7天 / 锦江之星 / 城市便捷 | 0.7-1.0倍 |

**判断标准**：品牌历史 (30%) + 会员体系规模 (30%) + 市场认知度 (40%)

---

### 轴 4：区位分级 (City Tier) — "在哪个城市/商圈"

按城市能级 + 商圈类型分级：

| 级别 | 城市 | 商圈类型 | 市场特征 |
|------|------|---------|---------|
| **S** | 北京 / 上海 / 广深 | CBD / 城市地标 | 外资+本土奢华共存 |
| **A** | 新一线 (成都/杭州/武汉/西安/南京/重庆/苏州/天津) | 城市核心 | 内外资拉锯，本土崛起 |
| **B** | 省会 / 计划单列市 | 城市核心 | 本土高端+外资中端 |
| **C** | 地级市 | 城市核心 | 本土品牌主导 |
| **D** | 县级市 / 经济百强县 | 城市核心 | 经济型+本土中端 |
| **T** | 旅游目的地 | 景区 / 海岛 / 度假区 | 度假酒店主场 |

**判断标准**：GDP (30%) + 客流结构 (30%) + ADR天花板 (40%)

---

### 轴 5：客群分级 (Customer Segment) — "卖给谁"

按消费动机 + 消费力分级：

| 客群 | 核心动机 | 价格敏感度 | 关键体验点 | 占比 |
|------|---------|-----------|-----------|------|
| **商务精英** | 效率+身份 | 低 | 早餐速度/办公空间/隐私 | 15% |
| **商旅白领** | 效率+性价比 | 中 | 位置/早餐/网络 | 30% |
| **度假家庭** | 体验+情感 | 中 | 亲子设施/活动/景观 | 15% |
| **度假情侣** | 浪漫+仪式感 | 中低 | 设计/私密/在地体验 | 10% |
| **MICE会议** | 功能+效率 | 低 | 宴会/会议室/AV | 10% |
| **长租/医养** | 实用+情感 | 中 | 无障碍/医疗/餐饮 | 5% |
| **Z世代/电竞** | 社交+娱乐 | 中高 | 设备/网络/IP氛围 | 10% |
| **数字游民** | 自由+连接 | 中高 | 网络/工位/社群 | 5% |

**判断标准**：消费动机 (40%) + 客单价 (30%) + 复购特征 (30%)

### 五轴交叉定位 (5D Matrix)

任何一个项目都可在五轴上得到一个唯一的"五维坐标"：

```
示例 1：成都太古里亚朵S酒店
  物业 = A+ | 业态 = 中高端 | 品牌 = 中高端 | 区位 = A | 客群 = 商旅+度假

示例 2：襄阳某全季酒店
  物业 = B | 业态 = 中端 | 品牌 = 中端 | 区位 = C | 客群 = 商旅

示例 3：上海外滩W酒店
  物业 = A+ | 业态 = 奢华 | 品牌 = 奢华 | 区位 = S | 客群 = 商务精英+度假
```

**五维坐标决定了项目的真实打法** — 三个项目因为坐标不同，投资逻辑、运营策略、营销打法完全不同。

## 二、地域差异的核心方法论

### 核心命题：相同分级 ≠ 相同打法

**为什么地域改变一切**：

| 变量 | 影响 | 量化差异示例 |
|------|------|-------------|
| **客单价天花板** | 决定能开什么级别 | 一线S级奢华 ADR 3,000元 vs 地级市C级奢华 ADR 800元 |
| **物业成本** | 决定回报率临界点 | 一线A级单方造价 4,000元/㎡ vs D级 800元/㎡ |
| **客源结构** | 决定业态选择 | 旅游城市T级度假 > 70% vs 工业城市C级商旅 > 70% |
| **文化适配度** | 决定设计和服务调性 | 日式禅意在一线 vs 在西北县城 |
| **政策环境** | 决定能不能做、怎么做 | 海南康养政策 vs 北京康养政策 |

### 矩阵推演：业态 × 区位 = 真实落地打法

| 业态 \ 区位 | 一线 S | 新一线 A | 省会 B | 地级市 C | 旅游目的地 T |
|------------|--------|---------|-------|---------|-------------|
| **奢华** | 外资碾压<br>(丽思/瑞吉) | 内外资拉锯<br>(本土奢华崛起) | 几乎无市场 | 不存在 | 度假奢华<br>(松赞/安麓/嘉佩乐) |
| **高端** | 万豪/希尔顿/凯悦 | 万豪+本土高端共存 | 本土高端为主 | 极少存在 | 国际度假村 |
| **中高端** | 外资中端+本土挑战 | 亚朵主场+外资中端 | 本土中高端 | 不存在 | 主题度假 |
| **中端** | 维也纳/麗枫/全季 | 全季/亚朵主战场 | 本土中端 | 本土+经济型升级 | 经济型度假 |
| **经济** | 汉庭/如家/7天 | 本土连锁 | 本土连锁 | 本土+单体 | 经济型+民宿 |

### 关键判断：地域如何改变"势能"

**势能 = 同业态在目标地域的实际经营能级**

```
一线S级中端 (北京国贸全季) → 实际经营达中高端 ADR
三线C级中端 (某地级市全季) → 实际经营只能维持中端 ADR

势能差异的根本原因：
1. 客源结构差异 (商务 vs 度假 vs 政务)
2. 替代品密度 (周边竞品密度)
3. 流量入口差异 (OTA vs 直销 vs 协议客户)
```

**方法论推论**：在做项目定位时，**先定地域 → 再定物业 → 再定业态**，不能反过来。

## 三、内外资博弈的方法论

### 五个博弈维度

| 维度 | 外资优势 | 内资优势 | 量化对比 |
|------|---------|---------|---------|
| **标准化 (SOP)** | 全球统一SOP，下限高 | 灵活迭代，但约束弱 | 外资下限 > 内资上限 (在奢华及以上) |
| **会员体系** | 全球1.5亿+会员 (万豪Bonvoy) | 国内1亿+ (华住会) | 外资胜国际客源，内资胜国内下沉 |
| **本土化** | 文化适配弱，决策链长 | 本土理解深，迭代快 | 内资完胜 (中端及以下) |
| **设计标准** | 全球设计公司背书 | 设计院本土化+性价比 | 外资胜 (高端及以上) |
| **资本/退出** | REITs渠道成熟 | 国内REITs刚起步 | 外资胜资产证券化 |

### 内外资博弈的纳什均衡

按业态分级的纳什均衡分布：

```
一线S级 + 奢华/高端    → 外资占优 (高净值客群认可国际品牌)
一线S级 + 中端         → 内外资胶着 (本土品牌竞争力强)
新一线A + 高端         → 内外资拉锯 (本土奢华崛起)
新一线A + 中端         → 内资主导 (亚朵/全季主场)
B级及以下              → 内资垄断 (外资下沉难，回报不支持)
```

### 博弈论方法论结论

**判断一个项目的内外资打法，要看三个问题**：
1. 这个项目的客群是否需要"国际背书"？（是→外资优势，否→内资可考虑）
2. 这个项目的回报模型是否支持外资标准？（否→内资更适配）
3. 这个项目未来是否需要全球客源？（是→外资会员体系不可替代）

## 四、品牌策略方法论

### 同一分级下不同品牌的"群结构"差异

以**中端市场**为例 (行业内最竞争的红海)：

| 品牌 | 母集团 | 核心定位 | 群结构特征 | 迭代速度 |
|------|-------|---------|-----------|---------|
| **全季** | 华住 | 东方美学+克制 | 单品牌×多区域复制 | 中 (5年一代) |
| **亚朵** | 亚朵 | 生活方式+IP | 单品牌×深运营 | 中高 (3年一代) |
| **维也纳** | 锦江 | 欧式+性价比 | 多品牌矩阵 | 高 (1-2年一代) |
| **麗枫** | 锦江 | 薰衣草+女性 | 单品牌深耕 | 中 |
| **桔子** | 华住 | 设计+潮 | 单品牌深耕 | 中高 |
| **欢朋** | 希尔顿 | 国际标准中端 | 单一变换群复制 | 慢 |

### 群论方法论结论

**判断一个品牌策略，要看三个维度**：

```
1. 变换群数量 (单品牌 vs 多品牌矩阵)
   - 单品牌 = 集中资源，但抗风险弱
   - 多品牌 = 分散风险，但资源稀释

2. 变换群深度 (浅复制 vs 深运营)
   - 浅复制 (外资标准) = 标准化高，但缺乏在地认同
   - 深运营 (内资本土) = 在地认同强，但复制难度大

3. 变换群迭代速度
   - 慢迭代 (外资) = 资产稳健，但易被新物种颠覆
   - 快迭代 (内资) = 资产灵活，但品牌资产积累弱
```

### 品牌策略的选择框架

| 项目坐标 | 推荐策略 |
|---------|---------|
| 一线S + 奢华/高端 | 外资豪华品牌 (丽思/瑞吉/华尔道夫) |
| 一线S + 中高端 | 国际中端 (希尔顿花园/福朋) 或 自主高端 (亚朵) |
| 新一线A + 中高端 | 自主中高端 (亚朵/美仑) > 加盟外资 |
| 新一线A + 中端 | 成熟中端品牌 (全季/麗枫) > 自主 |
| B级及以下 + 中端 | 成熟本土品牌 (维也纳/全季) > 自主 (回报不支持) |

## 五、新物种预判框架

### 新物种判断的三轴模型

判断一个新酒店业态是否是"新物种"，看三个维度是否同时满足：

```
轴 A：功能融合 (住宿 + 什么？)
轴 B：技术驱动 (AI / 装配式 / 数据 / 区块链？)
轴 C：资产模式 (订阅 / 产权分割 / REITs / 共享？)
```

**三轴都满足 → 颠覆性新物种**
**两轴满足 → 改良型新物种**
**一轴满足 → 营销概念，不算物种**

### 已出现的新物种 (2018-2025)

| 物种 | 功能融合 | 技术驱动 | 资产模式 | 本质创新 | 局限 |
|------|---------|---------|---------|---------|------|
| **电竞酒店** | ✓ | ✗ | ✗ | 住宿+娱乐融合 | 政策风险，生命周期短 |
| **帐篷营地/Glamping** | ✓ | ✗ | ✗ | 住宿+自然+仪式 | 重资产，季节性强 |
| **装配式酒店** | ✗ | ✓ | ✗ | 工厂预制+现场组装 | 单方造价高，审美局限 |
| **公寓酒店** | ✓ | ✗ | ✓ | 住宿+居住模糊 | 二级市场割裂 |
| **IP主题酒店** | ✓ | ✗ | ✗ | 住宿+IP情感 | IP生命周期决定生死 |
| **集装箱酒店** | ✓ | ✓ | ✗ | 装配+潮流 | 单房造价高，保温差 |

## 八、底层逻辑收束

**分级分类的本质是认知工具，不是行动地图。**

```
工具用对了 → 简化决策 → 提高效率
工具用错了 → 自我束缚 → 错失新物种
```

**三个关键认知**：

1. **五轴独立，但叠加生效** — 任何一个项目都是五轴的乘积，不是单轴的判断
2. **地域改变势能，不改变分级** — 同样"中端"，在S级和C级的打法完全不同
3. **新物种的本质是"功能融合"** — 住宿+？的"？"决定了新物种的颠覆性

**最后的方法论原则**：

> **如果...那么...**
> - 如果你要做项目定位 → **先定区位，再定物业，再定业态，最后定品牌和新物种**
> - 如果你要判断内外资 → **看客群是否需要国际背书 + 回报是否支持外资标准 + 未来是否需要全球客源**
> - 如果你要预判新物种 → **三轴模型检验 (功能融合+技术驱动+资产模式)**
> - 如果你要投资决策 → **五轴坐标 + 地域势能 + 内外资博弈 + 新物种权重 = 完整判断**

## 二、项目阶段分类（6 阶段模型）

### 阶段定义

| 阶段 | 名称 | 项目状态 | 关键判断问题 |
|------|------|---------|------------|
| **P0** | 拿地前 | 仅有地块/意向地块 | 这块地**该不该拿**？**做什么**？ |
| **P1** | 拿地后规划 | 已拿地，已签租约/已购物业 | **怎么设计**？**挂什么品牌**？ |
| **P2** | 筹建期 | 已开工/正在筹建 | **施工调整**？**运营前置**？ |
| **P3** | 开业筹备 | 即将开业/试运营 | **如何定价**？**如何定位客群**？ |
| **P4** | 运营期 | 已开业运营中 | **如何调改**？**如何提升**？ |
| **P5** | 翻新/退出 | 老化物业/资产处置 | **翻新/转让/证券化**？ |

### 不同阶段判断重点差异

```
P0 拿地前      → 物业评估(T1) + 市场评估(T2) = 决定"做不做、做什么"
P1 拿地后规划  → 物业(T1) + 市场(T2) + 客群(T3) + 业态(T4) = 完整定位
P2 筹建期      → 业态匹配(T4) + 投资验证(T5) = 锁定产品+财务闭环
P3 开业筹备    → 客群定位(T3) + 业态匹配(T4) = 营销策略
P4 运营期      → 翻新改造(T6) = 周期性调改
P5 翻新/退出   → 翻新改造(T6) + 退出评估(T7) = 资产处置
```

## 三、32 项判断指标库 (DB1)

每个项目定位由 **32 项核心指标** 构成。指标分 6 组，每组有明确的数据来源和判断标准。

### 组 A：物业指标 (8项)

| 编号 | 指标 | 数据来源 | 判断标准 | 权重 |
|------|------|---------|---------|------|

| **A3** | 地段稀缺性 | 1公里内稀缺资源评分 | 1-10分 (边缘=1-3 / 次中心=4-6 / 核心=7-8 / 唯一=9-10) | 15% |

| **A7** | 可改造性 | 建筑师评估 | 1-10分 (结构改动灵活度) | 10% |

### T0：项目阶段自测卡

**使用方法**：回答10个问题，自动判定项目阶段。

```

Q5: 是否已开工建设？          否→P1 | 是→P2
Q6: 是否已完成施工？          否→P2 | 是→Q7
Q7: 是否已开始试运营？        否→P3 | 是→Q8
Q8: 是否已正式开业？          否→P3 | 是→Q9
Q9: 开业运营是否满3年？       否→P4 | 是→Q10
Q10: 是否计划翻新/退出？      否→P4 | 是→P5
```

### T1：物业评估卡 (适用 P0/P1)

**输入**：32项指标中的 A 组 (8项物业指标)

**输出**：
- 物业分级 (A+/A/B+/B/C/D)
- 物业适合的业态范围
- 物业改造建议

**评估流程**：
```
1. 区位能级 → 锁定区位大坐标 (S/A/B/C/D/T)
2. 商圈类型 → 锁定商圈小坐标
3. 地段稀缺性 → 评分 (1-10)
4. 周边竞品密度 → 判断市场容量
5. 物业硬件评分 + 可改造性 → 评估工程量
6. 单方造价 → 评估投资额
7. 物业剩余年限 → 评估持有策略
8. 综合输出物业分级
```

**输出模板**：

```
【物业评估卡】 物业名称：______  日期：______

一、区位大坐标：____ (S/A/B/C/D/T)
二、商圈小坐标：____ (CBD/景区/交通枢纽/产业园区/居住区/度假区)
三、综合分级：____ (A+/A/B+/B/C/D)
四、推荐业态范围：____ (从最高到最低)
五、改造难度：____ (低/中/高)
六、单房投资建议：____ 万元
七、特别提示：____
```

### T2：市场评估卡 (适用 P0/P1)

**输入**：32项指标中的 B 组 (8项市场指标)

**输出**：
- ADR/OCC/RevPAR 基准
- 市场健康度评级 (优/良/中/差)
- 市场天花板警告

**评估流程**：
```
1. 城市GDP + 人均可支配收入 → 评估市场基本盘
2. 客源结构 → 锁定主战场
3. ADR天花板 + OCC基准 → 锁定经营预期
4. 渗透率 → 判断市场饱和度
5. 增长率 → 判断市场趋势
6. 综合输出市场健康度
```

**健康度评级标准**：

| 评级 | 标准 |
|------|------|
| **优** | 增长率>8% + 渗透率<1.5% + ADR达标率>90% |
| **良** | 增长率3-8% + 渗透率1.5-2.5% + ADR达标率70-90% |
| **中** | 增长率0-3% + 渗透率2.5-3% + ADR达标率50-70% |
| **差** | 增长率<0% 或 渗透率>3% 或 ADR达标率<50% |

### T3：客群定位卡 (适用 P0/P1/P3)

**输入**：32项指标中的 C 组 (6项客群指标)

**输出**：
- 主客群 (1-2类)
- 次客群 (1-2类)
- 客单价区间
- 渠道策略

**8 类客群定位锚点**：

| 客群类型 | 锚点 | 关键场景 |
|---------|------|---------|
| **商务精英** | 城市CBD高端酒店 | 高频出差+身份认同 |
| **商旅白领** | 城市中端连锁 | 高频出差+性价比 |
| **度假家庭** | 旅游目的地 | 周末/小长假 |
| **度假情侣** | 旅游目的地/精品酒店 | 纪念日/蜜月 |
| **MICE会议** | 城市高端+大宴会 | 会议/培训/婚宴 |
| **长租/医养** | 城市中端+适老化 | 短期过渡/术后康复 |
| **Z世代/电竞** | 城市中端+IP | 周末聚会/赛事 |
| **数字游民** | 旅游目的地+网络 | 远程办公 |

### T4：业态匹配卡 (适用 P1/P2/P3/P5)

**输入**：T1 + T2 + T3 输出

**输出**：
- 推荐业态 (1-3个候选)
- 推荐品牌策略 (自主/加盟/合资/管理)
- 内外资博弈建议

**匹配算法**：
```
Step 1: 取物业分级 (T1) → 锁定候选业态区间
Step 2: 取市场天花板 (T2) → 锁定候选业态上限
Step 3: 取客群定位 (T3) → 锁定候选业态锚点
Step 4: 取财务约束 (D1-D5) → 锁定候选业态投资可行性
Step 5: 输出业态推荐 (交集)

举例：
物业 A + 市场 B + 客群 商旅 → 推荐 中端-中高端
物业 C + 市场 C + 客群 商旅 → 推荐 经济-中端
物业 A+ + 市场 T + 客群 度假 → 推荐 高端-奢华
```

### T5：投资验证卡 (适用 P1/P2/P3)

**输入**：T4 推荐业态 + D 组财务指标

**输出**：
- 财务可行性评级 (通过/警告/不通过)
- 优化建议

**验证流程**：
```
Step 1: 取 T4 推荐业态 → 锁定单房投资区间
Step 2: 计算预计 RevPAR = ADR × OCC (用 T2 基准)
Step 3: 计算 GopPAR = RevPAR × GOP率 (按业态 35-50%)
Step 4: 计算静态投资回收期 = 总投资 / 年GOP
Step 5: 计算 IRR (10年期)
Step 6: 与 D3 目标 IRR 对比
Step 7: 输出评级
```

**评级标准**：
| 评级 | 标准 |
|------|------|
| **通过** | 静态回收期≤8年 + IRR≥目标 |
| **警告** | 静态回收期8-12年 + IRR接近目标 |
| **不通过** | 静态回收期>12年 或 IRR<目标80% |

### T6：翻新改造卡 (适用 P4/P5)

**输入**：运营数据 + A组物业指标 + C组客群指标

**输出**：
- 改造策略 (轻改/中改/重改)
- 改造预算
- 调改后业态定位

**改造分级**：
```
轻改 (单房投资 3-8万)：
  - 软装更新 + 局部硬装
  - 适用：硬件评分 70-85 分
  - 业态不变 / 客群不变

中改 (单房投资 8-20万)：
  - 硬装翻新 + 局部机电更新
  - 适用：硬件评分 50-70 分
  - 业态不变 / 客群微调

重改 (单房投资 20-50万)：
  - 全拆重装 + 机电全换
  - 适用：硬件评分 < 50 分
  - 业态可升级 / 客群重定位
```

### T7：退出评估卡 (适用 P5)

**输入**：T5 + T6 输出

**输出**：
- 退出时机建议
- 退出方式推荐
- 估值区间

**退出方式决策树**：
```
是否在核心城市一线/新一线？
  ├─ 是 → REITs可行性？
  │    ├─ 高 → REITs退出 (估值溢价 20-40%)
  │    └─ 低 → 整体出售
  └─ 否 → 整体出售/股权转让

物业剩余年限是否>15年？
  ├─ 是 → 整体出售更优
  └─ 否 → 股权转让或经营贷置换
```

- 减少拍脑袋决策
