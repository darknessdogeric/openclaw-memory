## 二、需求结构分析

### 2.1 需求类型预测

```
需求类型      │ 占比预估 │ 方向  │ 驱动因素
─────────────┼─────────┼──────┼──────────
① 短途近郊游   │ 40-45%  │ 📈↑  │ 3天假期天然适合周边游
② 城市休闲     │ 20-25%  │ ➡️→  │ 城市商圈/夜市/演出经济
③ 学生/青年游  │ 10-15%  │ 📈↑  │ 高考前最后的"解放前出行"
④ 家庭亲子游   │ 5-10%   │ 📉↓  │ 高考前家长限制出行
⑤ 长线/跨省    │ 10-15%  │ 📉↓  │ 拼假弱 + 时间不够
⑥ 出境        │ 5%       │ ➡️→  │ 免签利好但时间受限
```

**关键结构特征**：
- **短途为主**：3天假期天然限制出行半径，300km内目的地是主力
- **"浪漫经济"接力**：520刚过，同程报告显示"旅行领证"火爆，端午或有延后效应
- **高考前最后窗口**：6/7前学生群体有短暂出行窗口（考完高考的考生要等到6/9）

## 三、酒店行业核心预测

### 3.1 全国酒店行业指标预测

| 指标 | 五一实际 | 端午预测 | 变动逻辑 |
|------|---------|---------|---------|
| 全国平均OCC | 72-78%（五一峰值） | **58-65%** | 假期短+高考前压制，远低于五一 |
| 全国平均ADR | 溢价10-15% | **溢价5-8%** | 需求结构偏短途，价格弹性低 |
| RevPAR同比 | +5-8%（vs 2025） | **+2-4%** | 基数效应减弱，真实需求温和 |
| 平均提前预订天数 | 7-10天 | **4-6天** | 短途为主，即兴出行比例高 |

> ⚠️ **核心判断**: 端午不是"小五一"。结构上看，端午的OCC/ADR将显著低于五一，更接近一个 **"加强版周末"** ，而非"压缩版假期"。

### 3.2 分档位预测

| 档位 | OCC预测 | ADR预测 | 总判断 |
|------|---------|---------|--------|
| 奢华/高端 | 65-72% | +5-8% | 需求稳定，受益于品质旅游趋势 |
| 中端/有限服务 | 72-80% | +3-5% | **最佳表现档位**（短途+性价比） |
| 经济型/民宿 | 70-78% | +8-12% | 短途+性价比需求最强，但供给过剩压制价格 |
| 青年旅社/青旅 | 65-70% | +5% | 学生出行有支撑但受高考抑制 |

**中端有限服务为最佳赛道的逻辑**：
- 安联报告：59%倾向国内游 → 中端酒店受益
- 汉庭4.0模型验证：RevPAR 350-400 + 高OCC → 经济型向上挤压中端空间
- 短途出行中，中端性价比最高

## 四、OTA渠道分析

|-----|------|------|
| **携程** | 门店519单日3.55亿创新高 | 线下渠道需求暴涨，"信任经济"持续深化→非标/高客单价产品受益 |
