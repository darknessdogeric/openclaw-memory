# 预测-复盘对比迭代框架 V1.0

> 创建: 2026-05-05 | 基于Eric指令
> 核心逻辑: 先预测，后复盘，对比找偏差，逐次迭代优化

---

## 一、核心原则

**Eric三定律**：
1. **先预测，后复盘** — 每次节假日必须有预测，不许空等复盘
2. **预测必须与复盘对比** — 复盘不是独立行为，必须逐项与预测对照
3. **逐次迭代，越预测越准** — 每次偏差都是下一次进步的燃料

---

## 二、预测精度进化三阶段

| 阶段 | 覆盖范围 | 数据基础 | 精度目标 |
|------|---------|---------|---------|
| **Phase 1: 公版** | 全国/城市分级/档次分级 | OTA+交通部+券商+酒店之家 | ±5% |
| **Phase 2: 区域版** | 具体区域/省份/城市群 | Phase1积累 + 区域OTA数据 + 地方统计局 | ±3% |
| **Phase 3: 集团/公司版** | 具体酒店集团/单体酒店 | Phase2积累 + 集团财报 + PMS直连数据 | ±1% |

**当前：Phase 1 公版阶段**

## 三、每次报告的标准结构

### 3.1 预测报告（节前 T-2）

每份预测报告必须包含：

```
1. 假期环境假设（天气/交通/出行意愿）
2. 核心指标预测值（ADR/OCC/RevPAR 区间）
3. 分级市场预测（一线/新一线/二线/三四线）
4. 区域预测（华北/华东/华南/华中/西南/西北/东北）
5. 高峰日预测
6. 风险提示（可能出现的偏差方向）
```

### 3.2 复盘报告（节后 T+7）— 必须对比预测

```
1. 实际值 vs 预测值（逐项偏差率）
2. 偏差归因分析（为什么偏差？方向对吗？）
3. 偏差分类：
   - ✅ 方向对，幅度差（预测正确但力度不准）
   - ✅ 方向对，幅度接近（预测准确）
   - ❌ 方向错（预判反向）
   - ⚠️ 数据源问题（使用了错误/过时的数据）
4. 核心教训（最多3条，写入迭代记录）
```

### 3.3 迭代记录（每次复盘后填写）

```
文件: memory/reports/预测精度迭代记录.md

格式：
## [节假日] [年份] 迭代记录

### 预测值 vs 实际值
| 指标 | 预测值 | 实际值 | 偏差率 | 方向 |
|------|--------|--------|--------|------|
| 全国ADR涨幅 | +6% | +7.2% | +1.2ppts | ✅ |
| 三亚OCC | 82% | 79% | -3ppts | ❌ |

### 核心偏差教训
1. [教训1]：[原因分析]
2. [教训2]：[原因分析]
3. [教训3]：[原因分析]

### 下次预测调整
- [具体调整：数据源/模型/假设条件]
```

## 四、对比分析标准维度

每次复盘必须覆盖以下对比：

| 对比维度 | 具体指标 |
|---------|---------|
| 全国总量 | ADR涨幅 / OCC / RevPAR涨幅 |
| 城市分级 | 一线 / 新一线 / 二线 / 三四线 |
| 档次分级 | 经济型 / 中档 / 高端 / 豪华 |
| 区域 | 华北 / 华东 / 华南 / 华中 / 西南 / 西北 / 东北 |
| 高峰日 | 哪几天最热？峰值ADR出现哪天？ |
| 渠道结构 | OTA占比变化 / 直销占比 |
| 客源结构 | 年龄代际 / 目的（商务/休闲/探亲） |

---

## 五、迭代信号触发规则

| 信号 | 触发条件 | 动作 |
|------|---------|------|
| 🟢 高精度 | 偏差<3%维度 ≥ 8/10 | 记录为"优秀预测"，纳入最佳实践 |
| 🟡 中精度 | 偏差3-5%维度 ≥ 7/10 | 记录教训，继续跟踪 |
| 🔴 低精度 | 偏差>5%维度 ≥ 3/10 | 触发模型复查，输出偏差分析报告 |
| 🔴 方向错 | 预测方向与实际相反 | 触发深度归因，更新数据源/模型假设 |
