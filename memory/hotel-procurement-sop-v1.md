## 三、采购SOP流程

```
需求收集流程:
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  Step 1: 需求发起                                          │
```

#### 3.2.2 供应商评估SOP

```
供应商年度评估:
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  评估维度:                                                  │
│  ├── 质量 (40%): 交货合格率/抽检合格率                   │
│  ├── 交付 (30%): 准时交付率/交货完整率                   │
│  ├── 价格 (20%): 价格竞争力/成本节约                      │
│  ├── 服务 (10%): 响应速度/配合度                          │
│                                                             │
│  评估等级:                                                  │
│  ├── A级 (90-100分): 优秀供应商，优先合作                │
│  ├── B级 (75-89分): 合格供应商，正常合作                 │
│  ├── C级 (60-74分): 待改进，限制合作                     │
│  ├── D级 (60分以下): 不合格，终止合作                     │
│                                                             │
│  评估频率: 年度评估 + 季度review                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 采购模式分类

```
采购模式:
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  1. 集中采购 (集团模式)                                   │
│     ├── 优点: 议价能力强、成本低、管理规范               │
│     ├── 适用: 通用物资(布草/易耗品/洗涤)                 │
│     └── 酒店: 华住/锦江/首旅如家                          │
│                                                             │
│  2. 分散采购 (单体模式)                                   │
│     ├── 优点: 灵活、快速、适应本地                        │
│     ├── 适用: 生鲜/本地特色/紧急物资                     │
│     └── 酒店: 独立单体酒店                                │
│                                                             │
│  3. 联合采购 (联盟模式)                                  │
│     ├── 优点: 集合多酒店需求、议价能力                   │
│     ├── 适用: 中小酒店联盟                               │
│     └── 酒店: 酒店联盟/采购平台                          │
│                                                             │
│  4. 战略采购                                              │
│     ├── 优点: 长期合作、优先供应、成本优化               │
│     ├── 适用: 大宗物资/核心供应商                        │
│     └── 酒店: 所有酒店                                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
