### 2.2 清算优先权（最关键条款）

```
清算情形：
- 公司被收购
- 公司清算
- 大规模出售资产

优先权类型：

【1x Non-Participating 最常见】
- 投资人优先获得1倍投资额
- 之后转为普通股
- 优点：平衡保护与激励

【Senior Preferred 有利息】
- 优先获得本金+年化利息（通常8-12%）
- 缺点：投资人保护最强

【Participating 最不利】
- 优先拿回本金
- 还能按比例分配剩余财产
- 创始人最不愿接受

案例对比：
A公司：1x Non-Participating，投资人获1倍退出
B公司：Participating，投资人可能拿走2-3倍
```

### 2.3 反稀释条款

```
【完全棘轮 Full Ratchet 最激进】
- 新一轮降价时，投资人股份重新计算
- 公式：新股数 = 旧股数 × (新股价 / 旧股价)
- 案例：¥1000万投了1元/股 → 下一轮1毛/股 → 投资人瞬间10倍股份
- 风险：严重打击后续融资积极性

【加权平均 Weighted Average 常用】
- 公式：调整后股价 = (新股价 × 新股数 + 调整后旧股价 × 旧股数) / 总股数
- 分母含所有已发行股+期权池

【Broad-based 更保护创始人】
- 分母包含所有已发行股票+期权+可转换债
- 比Narrow-based对创始人更友好
```

### 2.4 董事会条款

```
董事会组成模式：

【模式A：创始人控制】
- 创始人2席
- 投资人1席
- 独立董事1席
- 重大事项需董事会过半数通过

【模式B：投资人控制】
- 创始人1席
- 投资人2席
- 独立董事2席
- 重大事项需2/3通过
- ⚠️ 创始人丧失控制权

【模式C：平等席位】
- 各方1-2席
- 重大事项一致决
- 僵局风险高

关键权利：
- 日常经营：CEO决定
- 重大融资/并购：董事会决定
- 章程修改：股东会决定
```

### 2.5 保护性条款

```
投资人要求的重大事项否决权：

必须投资人同意的事项：
□ 下一轮融资（可能进一步稀释）
□ 公司被出售或重组
□ 发行新股（期权池除外）
□ 重大资产出售（>20%资产）
□ 关联交易（>一定金额）
□ 章程修改
□ 改变董事会结构
□ 并购、分拆

谈判策略：
- 尽量缩小"重大事项"范围
- 设置金额门槛（如>100万才需同意）
- 区分需投资人同意vs通知
```

### 5.2 早期项目估值模型

```
天使轮/Pre-A估值公式：

估值 = 团队系数 × 市场系数 × 产品系数 × 进度系数

【团队系数】（创始人背景溢价）
- 连续创业者：×2.0-3.0
- 大厂高管：×1.5-2.0
- 首次创业：×1.0
- 资深行业经验：×1.2-1.5

【市场系数】
- 大赛道（万亿级）：×2.0+
- 中赛道（千亿级）：×1.2-1.5
- 小赛道（百亿级）：×0.8-1.0

【产品系数】
- MVP已验证：×1.2
- 有收入：×1.5
- 收入增长快：×2.0+

【进度系数】
- 只有BP：×0.5-0.8
- 原型完成：×1.0
- 已有收入：×1.5-2.0
```

### 7.2 政策影响与板块选择

```
【科创板】（2019年推出）
- 定位：硬科技公司
- 门槛：预计市值≥10亿 + 核心技术上科创
- 优势：估值高、流动性好
- 适合：AI/半导体/生物医药

【北交所】（2021年推出）
- 定位：专精特新中小企业
- 门槛：市值≥2亿 + 收入/利润要求
- 优势：门槛低、新三板转板
- 适合：新三板创新层企业

【港股】
- 优势：离岸市场、融资便利
- 劣势：流动性差、估值低
- 适合：消费/餐饮/物业
```

### 7.3 产业资本vs财务资本

```
【产业资本】（战略投资人）
优势：
- 带来业务协同（客户/渠道/技术）
- 品牌背书
- 后续轮次支持

劣势：
- 可能要求排他合作
- 后续融资受限
- 估值不一定最高

典型案例：
- 腾讯投资京东 → 流量+钱包入口
- 阿里投资饿了么 → 被收购退出
- 美团投资酒旅 → 成了核心业务

【财务资本】
优势：
- 纯财务回报诉求
- 不干预运营
- 估值可能更高

劣势：
- 无业务协同
- 可能签对赌条款

选择建议：
- 早期 → 产业资本背书重要
- 成长期 → 财务资本估值更高
- 战略协同关键 → 选产业资本
```


### 8.2 退出时机选择

```
【最佳退出时机】
- 行业高峰期
- 公司增速最快时
- 估值倍数最高时
- 融资刚完成、子弹充足

【避免的时机】
- 行业下行周期
- 公司增长放缓
- 融资环境恶化
- 团队动荡期

【退出路径规划】
Pre-A时就考虑：
- 最终去哪个市场？
- 谁可能是收购方？
- 创始人愿不愿意被并购？
```

### 8.3 税务筹划

```
【中国股权税务】

个人持股：
- 转让所得 → 20%个人所得税
- 分红 → 20%股息红利税
- 持有满5年 → 免税（针对上市公司股票）

公司持股：
- 转让所得 → 25%企业所得税
- 分红回个人 → 20%个人所得税

【筹划方法】
- 通过有限合伙企业持股（避税+控制权）
- 利用地区税收优惠（海南自贸港等）
- 合理规划退出时机
- 咨询专业税务顾问
```
