## 一、度假酒店概述

### 1.1 度假酒店定义

```
度假酒店(Resort Hotel):
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  定义: 以休闲度假为核心，提供住宿+           │
│       娱乐+康养+体验的综合型目的地              │
│                                                             │
│  特征:                                                    │
│  ├── 目的地: 不是中转，而是目的地                   │
│  ├── 慢节奏: 放松、享受、度假                     │
│  ├── 配套全: 泳池/SPA/活动/餐饮               │
│  ├── 体验多: 活动/娱乐/文化/自然            │
│  └── 停留长: 2-5晚，而非1晚                       │
│                                                             │
│  vs 商务酒店:                                          │
│  ├── 商务: 效率、便捷、住宿功能                     │
│  ├── 度假: 放松、体验、目的地                     │
│  └── 差异: 住是开始，玩是核心                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
