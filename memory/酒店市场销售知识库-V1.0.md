## 一、协议客户开发与管理

### 1.1 协议客户开发体系

#### 传统协议客户开发痛点

| 痛点 | 数据 |
|------|------|
| 公域获客成本上涨 | 3年上涨47% |
| OTA佣金 | 20%+，净利润被压缩至5%以下 |
| 传统销售效率 | 人均日拜访客户不足3家 |
| 信息滞后 | 错失30%需求 |
| 会员复购率 | 次留率低于15% |
| 沉睡会员 | 占比高达60% |

#### AI赋能协议客户开发

**智能获客雷达**：
- 以酒店为中心划定3-5公里地理围栏
- 实时抓取周边企业、写字楼、会展中心的工商信息（参保人数、行业分类）
- AI信息提取：Bert-BiLSTM-CRF模型精准抽取关键联系人姓名、职位及联系方式
- 需求预测：参保人数>200人自动标记为"高差旅需求"

**自动化触达流程**：
```
新企业注册 → AI评分(0-100) → 自动生成开发方案 → 邮件/企微发送 → 销售跟进高意向
```

| 开发期 | 企业背景调查→需求预判→方案定制→签约 |

**会员运营核心指标**：

| 指标 | 定义 | 行业参考值 |
|------|------|-----------|
| 新会员转化率 | 新注册/总访客 | >5% |
| 首消率 | 首消/注册会员 | >60% |
| 次留率 | 复购会员/总会员 | >15% |
| 沉睡率 | 沉睡会员/总会员 | <60% |
| LTV | 会员生命周期价值 | 房价×天数×频次 |

**RFM模型应用**：
- R（Recency）：最近一次消费时间
- F（Frequency）：消费频次
- M（Monetary）：消费金额
- 基于RFM自动化分类，设计从新会员欢迎→首次消费奖励→沉睡会员唤醒的全自动化营销流程

## 四、OTA渠道策略

### 4.1 OTA运营核心指标

| 指标 | 说明 | 优化方向 |
|------|------|---------|
| 排名 | 携程/美团/飞猪综合排名 | 好评率+转化率 |
| 好评率 | 点评分数 | >4.7分 |
| 预付率 | 预付订单占比 | 提升优惠 |
| 转化率 | 浏览→下单转化 | 图片+价格+点评 |
| 间夜量 | OTA渠道间夜数 | 活动参与 |
| 客单价 | OTA平均房价 | 产品优化 |

### 4.2 多平台布局策略

**携程系**：高端客源为主，重视点评维护
**美团系**：本地客源强，重视性价比展示
**飞猪系**：年轻客源，注重内容营销
**抖音/小红书**：种草经济，内容即渠道

### 4.3 动态定价模型

AI算法实时分析：
- 市场趋势
- 竞争对手定价
- 本地事件
- 天气
- 航班信息

目标：秒级频率调整房价，实现RevPAR最大化
