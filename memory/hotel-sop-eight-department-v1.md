│                                                             │
│  Step 5: 房间清洁 (8分钟)                                  │
│     ├── 家具表面除尘                                       │
│     ├── 电器清洁                                           │
│     ├── 窗台/窗帘                                         │

│                                                             │
│  Step 6: 最后检查 (2分钟)                                  │
│     ├── 环视无遗漏                                         │

│                                                             │
