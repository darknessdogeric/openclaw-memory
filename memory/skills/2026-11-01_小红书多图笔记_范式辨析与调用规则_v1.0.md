## 三、技术 SOP（照抄，不要重造）

1. **CSS 不复制粘贴**：运行时从 `toolbox/geo_v4_mckinsey.py` 提取 `COMMON_CSS`，杜绝漂移
   ```python
   _g = Path(r"D:\B166ER-openclaw\workspace\toolbox\geo_v4_mckinsey.py").read_text(encoding="utf-8")
   COMMON_CSS = _g.split('COMMON_CSS = """', 1)[1].split('"""', 1)[0]
   ```
2. **渲染**：Edge headless 在本机返回 RC=0 但**不落 PNG** → 改用 **Playwright**（`--force-device-scale-factor=2` 等价 `device_scale_factor=2`）。范式是视觉规格与结构，浏览器不是范式本身。
3. **水印**：**PIL 视觉水印**（左上标签 + 右下戳 + 中心斜向浅水印）。**禁用 blind_watermark**（并发下会 hang，曾浪费 20+ 分钟）。
4. **交付**：`*_wm.png`（带水印）才是最终件。
