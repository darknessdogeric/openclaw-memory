## 第一部分: 外部清单必须逐条验证, 不可照单全收

### 为什么

外部 AI 生成的清单普遍含臆造成分。本次实测发现的真实问题：

| 臆造成分 | 实测 |
|---------|------|
| 域名不存在 | `openclawai.io`（真身是 `clawhub.ai`） |
| 安装命令语法混乱 | 同时出现 `openclaw skills install` / `openclaw skill install` / `npx skills add` / `npx clawhub install` 四种 |
| 精确 slug 幻觉 | 声称 `3d-model-generation`，真名是 `3d-model-generation-cellcog` |
| 安全等级被隐藏 | 多个 skill 在 ClawHub 官方扫描里是 `SUSPICIOUS / Warnings: yes` |
| 第三方镜像页混入 | `toolify.ai` / `skills.sh` / `clawskills.sh` / `getclawdbot.com` 都是聚合站，不是源 |

### 验证流程 (4 步)

```powershell
# 1. 存在性 + 元信息 (来源/作者/版本/许可证/更新时间)
clawhub inspect <slug>
clawhub search <query>          # 拿真实 slug, 确认拼写

# 2. 文件清单 + 官方安全扫描结论
clawhub inspect <slug> --files
# 输出含: Security: SUSPICIOUS / Warnings: yes / Changelog / Files + sha256

# 3. 拉源码 (不安装)
clawhub inspect <slug> --file <path>
# 或直接 node CLI: "D:\Program Files\nodejs\node.exe" ^
#   "C:\Users\ericz\AppData\Roaming\npm\node_modules\clawhub\bin\clawdhub.js" inspect ...

# 4. 扫描红旗 (见下)
```

1. **`clawhub` 是 .cmd/.ps1 包装器, Python subprocess 调不到** → 直接调 node CLI:

## 第二部分: 交互式 Skill 的 Windows UTF-8 调用范式

### 问题
交互式 skill 用 `input()` 读参数。PowerShell 管道喂进去会:
1. 中文被 GBK 破坏成 `????`
2. `float(input())` 拿到空串直接 `ValueError`

### 解法 (三件套)

```powershell
# 1. 环境变量
$env:PYTHONIOENCODING="utf-8"
$env:PYTHONUTF8="1"

# 2. 输入写成 UTF-8 文件, 用 TextIOWrapper 喂
python -c "
import sys, io
sys.stdout.reconfigure(encoding='utf-8', errors='replace')
sys.stdin = io.TextIOWrapper(open('_test_input.txt','rb'), encoding='utf-8')
exec(open('generate_fullplan.py', encoding='utf-8').read())
"
```

### 喂输入前必读源码确认顺序
`input()` 的**调用顺序**就是喂入顺序, 且**每个 `input()` 只吃一行** (哪怕提示写"换行结束")。
本次踩坑: 以为 `requirements` 是多行, 多喂了一个空行, 结果空行被 `float(input())` 吃掉 → ValueError。

```powershell
# 列出所有 input() 及其行号
Select-String -Path <script>.py -Pattern "^def |input\(" | ForEach-Object { "L" + $_.LineNumber + ": " + $_.Line.Trim() }
```

## 第三部分: 装完必须跑真实验证 (不可只装不验)

本次发现 `interior-fullplan` 装完直接跑会崩:
```
ValueError: not enough values to unpack (expected 4, got 3)
```
根因: `STYLE_PRESETS` 里「宋式美学」「工业风」各有一行材料只有 3 个字段(缺 spec), 而代码直接 `space, part, mat, spec = row`。

**修复** (已应用):
```python
# 兼容 3/4 字段
space, part, mat, spec = (list(row) + ["-"])[:4]
```
