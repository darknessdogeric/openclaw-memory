## 5 维评估 (按权重排序)

### 1. 信息密度 (40% 权重) — 最高优先级

**Eric 反复反馈**: "信息密度不够, 内容太精简, 阅读不易"

| 等级 | 表现 | 修正动作 |
|------|------|----------|
| ✅ 优秀 | 5 段, 每段 1 个核心论点 + 3+ 例子 | 保持 |
| ⚠️ 需改 | 3 段, 每段空洞 | 拆 5 段, 加 3 列/双列卡片 |
| ❌ 改 | 1-2 段, 大量留白 | 立即加 2-3 段 + 数字/对比表 |

**修正方法**:
- 段数: 3 → 5
- 每段字数: ≤ 50 字 → ≤ 80 字
- 例子数: 0 → 3+ 个具体例子 (数字/城市/年份)

### 2. 字体大小 (25% 权重) — 9:16 大画布字号

| 元素 | 9:16 (1920px) | 3:4 (1440px) | 1:1 (1080px) |
|------|---------------|---------------|---------------|
| h1 (大标题) | **88px** | 60px | 52px |
| h2 (段标题) | **38px** | 30px | 22px |
| body | **21px** | 18px | 13px |
| caption (标签) | 14px | 12px | 9px |

**修正方法**: 大画布字号同比例放大, 9:16 比 3:4 大 +30%。

### 3. 段间节奏 (15% 权重) — 紧凑不挤

**Eric 反馈**: "空隙大, 越下越挤" → 解决: content-driven height

| 维度 | 标准 | 修正 |
|------|------|------|
| 段数 | 5 段 (s1-s5) | 保持 |
| 总高 | 1920px (9:16) / 1440px (3:4) | 加 B 标底部 80px |
| 段 padding | **24px** (紧凑) | 32px → 24px |
| 段 gap (内) | **4px** (紧凑) | 10px → 4px |
| 段高 | **content-driven** | 不要固定 288px, 改为 auto |

**修正方法**: 每段按内容高度自适应, s1 短 (200-360px) / s2-s4 中 (280-440px) / s5 长 (460-480px)。

### 4. B 标位置 (10% 权重) — Eric 明确指定

**Eric 决策**: top-right (不是 top-left, 不是 bottom-right)

```css
.brand-top-right {
  position: absolute;
  top: 12px; right: 12px;
  width: 60px; height: 60px;
  /* 不能盖字, s1 padding-top 必须 ≥ 80px */
}
```

**修正方法**:
- 位置: top-right (60×60, 9:16) / (50×50, 1:1)
- 段 1 padding-top: ≥ 80px (留 B 标空间)
- B 标底部不盖字 = 找空白点

### 5. 战略植入 (10% 权重) — 隐性要求

**Eric 反馈**: "政策应该把一带一路加上" (第二次迭代要求)

**修正方法**:

- 1 处隐式植入: 标签 (#一带一路)
- 任何"政策"内容自动加 "一带一路节点城市"
