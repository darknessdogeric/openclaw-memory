## 一点五、⭐ 取精去糟铁律（2026-11-03 Eric 立规，永久生效）

> **Eric 原话**："我以后让你吸收的所有内容都应该秉承取其精华去其糟粕的精神。"
> 规则落点：`~/self-improving/rules.md` **R304** + `rules_信源与数据获取.md` **R-信源-04**

**任何吸收任务（历史报告/案例/数据/竞品/他人方案）必须同时输出五张表，缺一不可：**

| 清单 | 硬要求 |
|---|---|
| **① 精华表** | 逐项 + **具体怎么用**（进哪个交付物 / 支撑哪个论点 / 替代哪条现有内容）。不得只写"有参考价值" |
| **② 糟粕表** | 逐项 + **为什么不成立**（口径缺失 / 假设失真 / 数据过时 / 自相矛盾）+ 是否需**主动向上澄清** |
| **③ 口径差异表** | 历史材料 vs 本方实测，逐项列出差异与**倍数** |
| **④ 回填清单** | 每项进哪个文件哪个章节 + 优先级 |
| **⑤ 待复核清单** | 冲突项 + 责任方 + 时限 |

**⭐ 铁律**：材料结论与本方现行结论冲突时，**必须主动澄清，不能静默略过**。旧报告里的漂亮数字（回收期 / IRR / 盈亏平衡点）会变成内部质疑新方案的弹药。

**保留历史材料的劳动定位**：说明它是"当时条件下的合理工作"，问题在"口径缺失"而非"作者判断错误"。

**实战样本**（总府皇冠 2024 报告）：精华 9 类全盘继承（23 条事故实录 / 北龙汤泉案例 / 9 条消防技术论据 / OTA 量化 / **网评+0.1 分=900-1,000 间夜·年的不依赖 ADR 的收益口径** / 43 项分项报价）；糟粕 8 类全部拆掉并量化（ADR 假设是实测 2.01 倍 / 漏计四项成本 1.9–2.4 亿 / 隐含扩编 97 人 / "不考虑折现率却给 IRR"）。**回填方案书 23 处 + 清单 6 条。**

## 三、标准输出结构（固定七章，顺序不可变）

```
1  编制说明与数据等级标注（🟢业主实测 / 🟡品牌方口径 / 🔵行业基准 / 🟠本方案假设）
1.5 停业时长专题（三方向共用）★ 见 §四
2  方向一：定义 / 改造要求 / 停业时长 / 客房效果 / 配套功能效果 / 测算 / SWOT
3  方向二：同上
4  方向三：同上
5  横向对比（核心参数表 / 敏感性表 / 评分表）
6  综合结论（必答3问 / 建议组合 / 上会前闭环清单 / 数据待确认清单）
```

**每方向必须逐项写明（Eric 明确要求，不可省）**：
必要性 → 条件 → 困难 → 项目测算 → 费用预估 → 总成本 → 影响 → 时间 → 周期 → 客房效果 → 配套功能效果 → SWOT

**格式**: 标题 + 表格为主；数字加粗；等级用 emoji 标注；所有测算给区间不给单值。

## 四、⭐ 停业时长的三个硬认知（最易出错处）

### 4.1 隐蔽工程必然停业
消防/电气/机电的**隐蔽工程整改不可能不停业**。隐蔽工程 = 必须破除既有完成面才能施工的部分（吊顶内管线、井道、电缆桥架、冷媒管、消防管网、隔墙内管线、配电竖井）。
→ **不要提"不停业排险 / 最小整改"方案**，会被直接否掉。

### 4.2 工程下限按系统算，不按总包拍
| 系统 | 不可压缩部分 | 独立最短工期 |
|---|---|---|
| 冷源 | 非标机组整体更换，订造 8–10 月 | 6–7 月 |
| 配电 | 变压器逐台更换（需临时供电） | 6–7 月 |
| 消防 | 回路全换 + 改后重新报审验收 + 联动整体调试 | 7–9 月 |

**六个压缩杠杆**：报批与设计全前置(-3~4月)｜长周期设备停业前订造(-2~3月)｜竖井优先+楼层流水(-1.5~2月)｜装配化预制(-15~25%)｜双班作业(-10~15%)｜分区开业(缩短"完全营业"4~6月)
**压不动的三件事**：消防重新报审验收｜非标主机订造｜跨系统联动调试

### 4.3 ⭐ 设计出图节奏是唯一能压缩"停业前置期"的角色
其他合作方只影响停业**之内**；设计能让停业**从更晚开始**。
→ **硬要求：设计单位与方案在停业决策前 4–6 个月锁定。**
→ **进口厨房设备 6–9 月交期必须倒推到停业前 9 个月。**

### 4.4 三个时间口径（避免会上混用）
① 全面停业期（零收入）｜② 分区开业期（收入折算，**仍是亏损期**）｜③ 完全开业
**测算纪律**：停业损失按 ①+② 计列，只报①是虚高收入的手法。

## 六、品牌筛选（换牌方向的必做模块）

**四道筛**：① 排除目标集团内其他品牌（若定义为"换其他品牌方"）② 排除本地已有在营/已签约（避免自我蚕食）③ 排除规模调性不匹配（纯度假/民宿/大体量选址型）④ 必须国际联号 + 目标档位 + 有中国在营案例

**评估维度**：本地空白度｜目标客群与现状重叠度（重叠高→切换阻力小）｜房量匹配度｜客群天花板｜品牌在华扩张意愿（近两年新开数）｜本地项目进展（官宣 vs 实际动工，**杳无音信的要排除**）｜合作模式（管理合同 vs 特许经营）｜品牌方对老物业的接受度｜费率区间

⚠️ **必查**：本地项目是否只是业主单方面官宣；品牌在中国是否**还没开出第一家**（首店未开 = 不确定性极高）；品牌是否已退出本地。

## 七、必须如实上会的三条结论（模板）

1. **回收期结论**：先算清现状 GOP 率，再判断 IRR 是否成立。若 GOP 薄（<25%），**大概率三个方向都不成立** —— 必须让用户先定决策逻辑（合规 / 战略卡位 / 成本结构），再谈路径。
2. **敏感变量排序**：把"停业时长 × 月损失"与"造价优化"对比，说明哪个杠杆更值钱。通常停业时长更值钱。
3. **成败关键条款**：指向一个具体的合同/品牌条款，而非工程细节。

## 九、已知限制与避坑

| 坑 | 规避 |
|---|---|
| 用粗算口径（如客房均面积用总建面除房量） | 一律用实测；实测未到则标"待确认" |
| **合作方压成总数** | 逐项列，见 §五 |
| **漏开办费** | 单独列 E 类，方向三可达 3,000 万 |
| FF&E 与建安混在一起 | 财务决算口径不同，必须拆；方向二/三 FF&E 占比达 26%–29% |
| 建安与总包管理费重复计列 | 勾稽表注明"已并入建安"，不单列 |
| 只报全面停业期损失 | 按①+②计列 |
| 提"不停业排险"方案 | 不成立，隐蔽工程必然停业 |
| 用旧版 .doc / 加密 .xls | 需 Word COM 或让业主重新提交（总府项目 6 个文件失败） |
| edit 工具批量替换一处不匹配 | **整批回滚**（原子性）→ 拆成小批逐个试，或先 read 精确锚点 |
| exec 参数校验摇摆 | 同时给 `title` 与 `command`；python 用绝对路径 |
