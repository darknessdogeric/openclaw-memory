# 外部报告批判性吸收范式 v1.1

> **不照单全收，不全盘否定。目标是把一份外部材料拆成三层：可引用 / 需标注 / 不可用。**
> **v1.1 关键新增：在读任何一个数字之前，先问「谁写的、谁收钱」。**

## 一、执行流程（8 步，第 0 步不可跳过）

```
0. 作者身份取证（★ 不可跳过）
   报告由谁写的？他的商业模式是什么？他是不是数据/结论的出具方？
   - 查原始文件里的「评估机构 / 审计机构 / 财务顾问 / 承销商 / 原始权益人 / 咨询机构」
   - 查该机构在本次事项中的角色：出具方？中介？评论方？
   - 若报告作者 = 估值/评级/数据的出具方 -> 全文标注【利益相关】
     并在结论里写明：该材料是「执业观点/自我解读」，不是独立研究
   - 典型判例：某头部咨询机构出的《酒店行业投资洞察》，
     其实是它自己作为底层资产评估机构对自身估值工作的对外解读
     （4/4 只在审基金均聘其担任评估机构）

1. 落地全文（不灌进上下文）
   pymupdf 抽取 -> 落盘；先扫「每页首行 + 字数 + 图数」建结构图，再按章读
   token 纪律：正文 57K 字 != 一次读完；先结构图，再按章读

2. 建报告画像：PDF metadata / 页数 / 章节结构 / 数据来源标注

3. 定位「最贵的三个断言」优先核验
   政策法律前提 / 报告主结论的基线数据 / 署名最重的具体数字

4. 分级
   🟢🟢 可直接引用：来自一手披露（年报/募集说明书/公告），且已逐项核对
   🟡🟡 需标注口径：二手汇编、跨机构口径不同、时点不同
   🟠🟠 存疑/不可用：无法独立验证、或与外部量级明显冲突、或属贬抑性未证断言

5. 查内部自洽：报告自己的数字能不能对上？（自洽 != 正确，但不自洽 = 立刻降级）

6. 与我方知识库对撞：同一指标两份读数 -> 不是挑一份信，而是记下差在哪、为什么差

7. 找最容易被误读的一段：顾问报告几乎必有「数据中立 + 叙事有倾向」的段落
```

## 二、必查的 6 个陷阱（v1.1 新增第 6 条）

| 陷阱 | 识别方法 |
|---|---|
| **卖方叙事** | 章节结构本身带推销（专设一章论证「某某需重塑」）；看谁写的、他的商业模式是什么 |
| **★ 作者即数据出具方** | 查报告里的评估/评级/审计机构是不是同一家。**这是 v1.1 新增的头号陷阱** |
| **口径混用** | 「据不完全统计」= 样本有偏；法拍占比高 = 样本偏向不良资产 |
| **时点错配** | 年报 vs 季报；申报稿/封卷稿/询价时点 vs 上市后。**同一指标出现 3-4 个读数是常态** |
| **n=1 伪装成规律** | 21 个资产全来自同一基金 -> 是「单产品内差异」不是「市场规律」 |
| **同页表述张力** | 前后两段自相矛盾却紧邻 |

## 三、跨机构数字冲突的正确处理

```
看到 A 机构 151.04 亿 vs B 机构 167.8 亿 ——

错误做法 A：选一个信，另一个标假
错误做法 B：说「两家数据打架，无法判断」

正确做法：先拆口径（时间窗 / 含不含公寓 / 含不含资产包 / 是否仅已成交 /
          测算基准 / 是否加回资本性支出），
          再说清「差异来自口径差异还是真实分歧」，最后给可用/不可用判断
```

## 四、统计陷阱（做「相关」之前必做）

```
1. 先算解释变量的变异度。极差 2.23 年的变量 vs 极差 2.20pp 的因变量，
   谈「相关」没有统计意义。
2. 分清「跨项目」与「项目内」。前者是市场样本，后者是产品样本。
   两者混为一谈是最常见的表述错误。
3. 区分因果方向：若 X 与 Y 强负相关，先检查是不是有第三个变量 Z 同时驱动两者
   （例：土地年限与城市层级共线；折现率按城市层级分档）。
4. 报告给了回归/散点，必须做留一法敏感性。
   若去掉单个点 r 就从 -0.34 掉到 -0.14 -> 结论由单点驱动，不能用。
5. 同产品内的结构设计会吸收变量。
   （例：把 DCF 期限设为与土地剩余年限一致，则土地差异被制度性抹平，
     项目内必然观察不到土地效应 —— 不是数据问题，是结构设计）
```

## 五、提取方法选型（踩过的坑）

| 场景 | 正确方法 | 踩过的坑 |
|---|---|---|
| PDF 表格 | **`pymupdf.find_tables()`** | 正则 `([\d,]+)` 会贪婪吞并相邻数字（5,200 + 26.09% -> 5,20026），两列全错 |
| 散点/曲线图 | **回原件**（募集书/评估报告）| 裁像素常裁到图例区，检测到的点 y 恒定、无关键锚点 |
| 跨机构数字 | Tavily + 一手文档双证 | Tavily 的 answer 是**综合生成**，会串机构/串基金，**不可直接引用**，只用来找 URL |

## 六、检索核验的查询构造

| 类型 | 模板 |
|---|---|
| 政策前提 | 「<发文机构> <文件名> <日期> <是否含X>」|
| 精确数字 | 「<机构> <指标名> <精确数值>」|
| 数字冲突 | 「<指标> <年份> <数值> <机构名>」 |
| 媒体数据 | 「<机构> <指标> <期间>」+ 找到原始报告 -> 媒体转述一律标 🟠 |
| 文件直链 | 「<项目名> 招募说明书 pdf <域名>」—— 命中 static.sse.com.cn / cninfo 即可直下原件 |

## 七、强制输出项（每次研判必须给出）

```
□ 利益相关声明（作者身份 + 角色 + 结论）
□ 数据可信度三级分级表
□ 逐条交叉验证结果（含发现的不一致与口径冲突）
□ 最容易误读的一段（单独拎出）
□ 修正后的可操作判据（替代原文的表述）
□ 剩余缺口清单（关闭方式明确）
□ 过程诚实记录（哪条方法失败了、为什么放弃、换成什么）
```

## 九、v1.1 补充：自查自己做的工具（2026-10-31 22:25）

> **触发**：v1.4 交付了一份「红线体检表」，阈值是「缺口 > 10 年 = 红灯」。
> **这是我的判断，不是监管标准** —— 但如果不查清它的立论基础，
> 就等于把个人偏好包装成行业规则。

```
必做：交付任何带阈值的工具前，先回答

  1. 这个阈值是监管硬线，还是行业经验？
     -> 查监管指引/审核关注事项原文；查不到就明确标注「经验判断」

  2. 有没有制度性缓释机制？
     -> 例：REITs「存续期届满前经份额持有人大会决议可延长存续期」
        这条条款是所有缺口型资产能成立的结构性出口，必须写进工具

  3. 工具的每个数字是否都标了口径与来源？
     -> 阈值/系数/区间都要能追到原文；追不到就降级为假设
```

> **教训：批判性吸收的对象，也包括我自己做出来的东西。**
> 别人的报告要查作者身份、查数据、查口径；**自己的工具同样要查。**

## 十一、v1.1 补充：用二手数据构造的判断必须回原件（2026-10-31 22:25）

> **触发**：v1.3 用中伦白皮书的「温州和嵊州剩余 18 年」构造了「土地年限几乎相同、
> cap rate 差 3 个百分点」的反例来推翻报告的核心论断。
> 回原件（中金开元旅业招募说明书 1,262 页）后发现：**温州 31.82 年、嵊州 33.85 年**。
> **反例完全不成立，结论方向反转。**

```
新增规则：

  A. 用二手数据构造任何【反例 / 关键区分 / 支撑性对比】前，
     必须回原件验证该数据点 —— 尤其是：
       - 单一二手来源对多个资产的并列陈述（尤其「A 和 B 都是 X 年」）
       - 来自表格的数字（极易被转述错位）
     二手的并列陈述天然高风险：它掩盖了资产间的真实差异。

  B. 自我纠错必须显式留档：
     版本递进 + 「撤回声明」写明错在哪、错因、影响范围。
     禁止静默改写 —— 旧版留着，别人才能复核推理链。

  C. 抓到的原件要留档，让每个数字都可被第三方复核。
```
