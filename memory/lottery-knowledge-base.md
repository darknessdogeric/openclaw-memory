## 三、预测理论模型

### 3.1 统计学基础

#### 3.1.1 频率分析
- 统计每个号码在历史中出现的次数
- 区分"热号"（高频）和"冷号"（低频）
- 局限性：彩票是独立随机事件，历史频率不影响未来

#### 3.1.2 遗漏值追踪
- 记录每个号码距上次出现的期数
- 遗漏值越大，理论出现概率越高（但实际是独立的）
- 追踪"遗漏周期"用于参考

#### 3.1.3 区间分析
- 将35个前区号码分为5个区间（每区7个）
- 统计每个区间出现号码的个数
- 常见模式：2-2-1、3-1-1、2-1-2等

#### 3.1.4 奇偶比例
- 前区5个号码中奇数/偶数的比例
- 常见模式：3:2 或 2:3
- 统计分布：奇数占55%左右

#### 3.1.5 大小比例
- 以18为界，大数(19-35)/小数(1-18)
- 常见模式：3:2 或 2:3
- 统计分布：大致均衡

#### 3.1.6 和值分析
- 5个前区号码之和
- 理论范围：15-165
- 高频区间：80-110
- 常见和值：85-105

### 3.2 机器学习模型

#### 3.2.1 随机森林 (Random Forest)
- 使用历史数据训练多棵决策树
- 每棵树独立预测，综合投票
- 优点：抗噪声，处理非线性关系
- 适用场景：特征重要性分析

#### 3.2.2 LSTM/Transformer
- GitHub项目: `cpeoples/powerpredict`
- 使用长短时记忆网络捕捉序列模式
- 结合Markov链进行状态转移分析
- 注意：过拟合风险大

#### 3.2.3 ARIMA时间序列
- GitHub项目: `michaelkupfer97/Lotto-prediction`
- 自回归移动平均模型
- 适用于有趋势的数据，但对随机事件效果有限

### 3.3 博弈论视角

#### 3.3.1 期望值分析
```
期望值 = Σ(中奖概率 × 奖金)
当期望值 > 投注额时，才有正期望

实际：
一等奖概率: 1/21亿
二等奖概率: 约1/3500万
整体返奖率: 约50%

结论：长期来看，玩家必然亏损
```

#### 3.3.2 风险偏好与彩票
- 彩票利用"损失厌恶"心理
- 小概率大回报符合人性
- 理性决策：娱乐消费，而非投资

#### 3.3.3 博弈策略（理论）
- 不倍投（期望为负）
- 不追号（资金无限才能保证）
- 随机选号 > 守号

### 3.4 模糊数学模型

#### 3.4.1 隶属度
- 将号码归属"热/冷/温"程度用0-1表示
- 热号隶属度高，冷号隶属度低
- 模糊规则进行推理

#### 3.4.2 模糊聚类
- 将号码按特征聚类
- 每期号码组合形成模式
- 模式匹配预测

### 3.5 其他理论

#### 3.5.1 Benford定律
- 用于检测数据真实性
- 自然数据首位数字分布：1最多(30%)，9最少(5%)
- 可用于验证数据采集准确性

#### 3.5.2 混沌理论
- 彩票结果看似混沌，但可能有吸引子
- 庞加莱截面分析
- 相空间重构

## 六、大乐透预测SOP（更新版）

> 参见: `docs/大乐透预测SOP.md`

**核心原则**：
1. 彩票是随机事件，任何预测模型都不能提高中奖概率
2. 预测仅供娱乐，不能作为投注依据
3. 模型价值在于分析规律，而非准确预测
