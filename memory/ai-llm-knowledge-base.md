## 一、大模型基础原理

### 1.1 Transformer架构

**核心组件**：

| 组件 | 功能 | 关键参数 |
|------|------|----------|
| Self-Attention | 捕捉序列内依赖关系 | Query/Key/Value矩阵 |
| Feed Forward | 非线性特征提取 | 隐藏层维度 |
| Positional Encoding | 注入位置信息 | 正弦/旋转编码 |
| Layer Normalization | 稳定训练 | γ, β参数 |

**注意力机制公式**：
```
Attention(Q, K, V) = softmax(QK^T / √d_k) × V

其中:
- Q (Query): 查询向量
- K (Key): 键向量
- V (Value): 值向量
- d_k: 键向量维度
```

**Transformer优势**：
- 并行计算能力强（相比RNN）
- 捕获长距离依赖（相比CNN）
- 可扩展性强（参数越多能力越强）

### 6.2 LoRA原理

```
LoRA = Low-Rank Adaptation

核心思想:
- 冻结预训练权重
- 只训练低秩矩阵
- 参数量大幅减少

优势:
- 训练速度: 2-3倍提升
- 显存需求: 减少60%+
- 可切换: 多LoRA快速切换
- 效果: 接近全量微调

典型配置:
- r: 8/16/32 (秩的大小)
- alpha: 16/32 (学习率缩放)
- dropout: 0.05-0.1
- target_modules: q_proj/v_proj
```

### 6.3 RLHF流程

```
Reinforcement Learning from Human Feedback

Step 1: 收集人类偏好
- 成对比较 (A vs B)
- 收集数万条偏好数据
- 训练Reward Model

Step 2: 训练Reward Model
- 输入: (prompt, response)
- 输出: 奖励分数
- 目标: 预测人类偏好

Step 3: PPO强化学习
- 策略: SFT模型
- 奖励: Reward Model
- KL散度: 防止偏移过大

Step 4: 迭代优化
- 重复Step 1-3
- 逐步提升质量
```

### 6.4 强化学习新进展

**Kimi k1.5的RL突破**:

```
GRPO (Group Relative Policy Optimization):

原理:
1. 对同一问题生成多个响应
2. 计算相对排名
3. 相对优势估计
4. 策略更新

优势:
- 无需 Critic 模型
- 减少计算开销
- 稳定训练

PPO vs GRPO:
- PPO: 需要Actor+Critic
- GRPO: 只需要Reward Model
- 效果: GRPO在多项任务相当或更好
```
