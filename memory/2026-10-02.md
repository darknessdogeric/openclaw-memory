### 诊断

#### 问题 1：耗时长 + 耗大量 TOKEN

**根因**：
- 我用了**手写的 inline XML 拼装**（直接拼 `<w:p>`, `<w:t>` 标签）

- 每个 cell / 每行 / 每个粗体标记都要单独生成 XML 段
- 模板没有复用 → 每篇 MD 都从零开始重新解析 token / 拼 XML / 修缺漏
- 多次修正（`utf-8`/import/`while`/`while`/字符白名单/✅ 等）→ 每个修正都是一次 write → 一次读取 → 又一次写入

- 我**绕过了**已有的渲染管线（HTML + Playwright），改去拼 docx XML，**走了最远最笨的路**

**根因**：
- 我生成的 docx：title 用「⬛」Unicode 块字符、装饰符号残留（✅ → 删了又加 → 再删）、inline 表格 XML 没有合并单元格 / 没有跨页断页控制
