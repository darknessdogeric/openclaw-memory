## 一、收益管理数学模型深度

### 1.1 动态定价算法

#### 1.1.1 基础动态定价模型

**核心公式**: 
```
最优房价 = 基准价 × 需求系数 × 竞争系数 × 时间系数 × 渠道系数
```

**Excel公式模板**:
```excel
=基础房价*需求系数*竞争系数*时间系数*渠道系数
```

**变量详解**:

| 变量 | 计算方式 | 取值范围 | Excel公式 |
|------|---------|---------|-----------|
| 基准价 | 历史ADR × 通胀调整 | 固定值 | `=历史ADR*(1+通胀率)` |
| 需求系数 | 预订进度/预期进度 | 0.5-2.0 | `=实际预订数/预期预订数` |
| 竞争系数 | 竞品价格指数 | 0.8-1.5 | `=本店价格/竞品均价` |
| 时间系数 | 提前预订天数函数 | 0.7-1.3 | 见下文 |
| 渠道系数 | 渠道佣金调整 | 0.85-1.0 | `=1-渠道佣金率` |

**时间系数公式**:
```excel
=IF(提前天数>30, 0.85, IF(提前天数>14, 0.95, IF(提前天数>7, 1.0, IF(提前天数>3, 1.15, 1.3))))
```

#### 1.1.2 入住率驱动的阶梯定价

**五档定价策略**:

| 入住率区间 | 定价策略 | 调价幅度 | 触发条件 |
|-----------|---------|---------|---------|
| 0-40% | 促销价 | -15%~-25% | 提前7天预订<30% |
| 40-60% | 折扣价 | -5%~-15% | 竞争压力大于需求 |
| 60-75% | 标准价 | 基准价 | 正常运营区间 |
| 75-90% | 溢价 | +10%~+20% | 需求旺盛 |
| 90-100% | 超卖溢价 | +20%~+50% | 满房前3天 |

**Excel实现**:
```excel
=基准价*LOOKUP(入住率,{0,0.4,0.6,0.75,0.9,1},{0.75,0.9,1,1.15,1.3,1.5})
```

#### 1.1.3 竞品对标定价模型

**竞品价格采集矩阵**:

```
竞品A价格 × 权重30% + 竞品B价格 × 权重25% + 竞品C价格 × 权重20% + 竞品D价格 × 15% + 市场均价 × 10%
```

**Excel公式**:
```excel
=竞品A*0.3+竞品B*0.25+竞品C*0.2+竞品D*0.15+市场均价*0.1
```

**价格定位策略**:

| 酒店档次 | 目标定位 | 公式 |
|---------|---------|-----|
| 高端 | 市场领导者 | `=竞品均价×1.1` |
| 中高端 | 价格跟随 | `=竞品均价×0.95` |
| 中端 | 性价比 | `=竞品均价×0.85` |
| 经济型 | 渗透定价 | `=竞品均价×0.7` |

#### 1.1.4 需求弹性系数定价

**价格弹性公式**:
```
Ed = (需求量变化%)/(价格变化%)
```

**Excel计算**:
```excel
=((新销量-旧销量)/旧销量)/((新价格-旧价格)/旧价格)
```

**弹性区间与策略**:

| 弹性系数 | 需求特性 | 定价策略 |
|---------|---------|---------|
| Ed < -1 | 弹性大 | 降价增收入 |
| Ed = -1 | 单位弹性 | 价格最优 |
| -1 < Ed < 0 | 弹性小 | 提价增收入 |
| Ed > 0 | 吉芬商品 | 反常，需调研 |

### 1.2 需求预测模型

#### 1.2.1 时间序列预测法

**移动平均法**:
```excel
=AVERAGE(OFFSET(历史数据,COUNT(历史数据)-N,0,N,1))
```

**指数平滑法** (α=0.3):
```excel
=α*本期实际+(1-α)*上期预测
```

**季节性指数调整**:
```excel
=基础预测*季节性指数
```

**季节性指数计算**:
```excel
=本月平均/全年平均
```

**12个月季节性指数模板**:

| 月份 | 指数 | 适用场景 |
|-----|------|---------|
| 1月 | 0.85 | 春节后低谷 |
| 2月 | 0.90 | 元宵后回升 |
| 3月 | 1.05 | 春季回暖 |
| 4月 | 1.10 | 清明小高峰 |
| 5月 | 1.15 | 五一黄金周 |
| 6月 | 0.95 | 高考前淡季 |
| 7月 | 1.20 | 暑期旺季 |
| 8月 | 1.25 | 暑期高峰 |
| 9月 | 1.00 | 开学平季 |
| 10月 | 1.30 | 国庆黄金 |
| 11月 | 0.90 | 会展旺季 |
| 12月 | 0.95 | 年末商务 |

#### 1.2.2 机器学习预测模型

**多元回归模型**:
```
Y = β0 + β1X1 + β2X2 + β3X3 + ε
```

其中：
- Y = 预测需求量
- X1 = 历史同期入住率
- X2 = 提前预订天数
- X3 = 竞品价格水平
- β = 回归系数

**Excel回归分析步骤**:
1. 数据→数据分析→回归
2. Y值输入区域: 历史需求
3. X值输入区域: 影响因素
4. 输出选项: 新工作表

**ARIMA模型参数** (适用于Excel插件):
```
ARIMA(p,d,q) = ARIMA(1,1,1)
```

#### 1.2.3 预测准确度评估

**MAPE (平均绝对百分比误差)**:
```excel
=AVERAGE(ABS((实际-预测)/实际))*100
```

**MSE (均方误差)**:
```excel
=AVERAGE((实际-预测)^2)
```

**准确度等级**:

| MAPE范围 | 准确度 | 行动 |
|---------|-------|-----|
| <5% | 优秀 | 保持模型 |
| 5-10% | 良好 | 微调参数 |
| 10-20% | 一般 | 重新审视变量 |
| >20% | 较差 | 重建模型 |

### 1.3 渠道优化模型

#### 1.3.1 渠道贡献度分析

**渠道价值评估矩阵**:

```excel
渠道综合得分 = 流量权重×流量得分 + 转化率权重×转化得分 + 利润权重×利润得分 + 品牌权重×品牌得分
```

**权重分配建议**:
- 流量权重: 25%
- 转化率权重: 30%
- 利润权重: 30%
- 品牌权重: 15%

**渠道ROI计算**:
```excel
=渠道收入/渠道成本
```

**渠道利润贡献公式**:
```excel
=渠道收入*(1-佣金率-取消率)-渠道固定成本
```

#### 1.3.2 渠道组合优化

**线性规划模型**:
```
目标: 最大化总利润 = Σ(渠道i收入 × 渠道i净利率)
约束:
- 渠道i销量 ≤ 渠道i产能上限
- Σ渠道i销量 = 目标总销量
- 渠道i占比 ≥ 最低占比要求
```

**Excel Solver设置**:
1. 目标单元格: 总利润
2. 可变单元格: 各渠道分配量
3. 约束条件: 
   - 各渠道 ≤ 上限
   - 总和 = 目标
   - 各渠道 ≥ 最小值

#### 1.3.3 动态渠道配额管理

**分阶段释放策略**:

| 提前天数 | OTA配额 | 直销配额 | 协议配额 |
|---------|--------|---------|---------|
| >60天 | 30% | 50% | 20% |
| 30-60天 | 40% | 40% | 20% |
| 14-30天 | 50% | 30% | 20% |
| 7-14天 | 60% | 20% | 20% |
| <7天 | 70% | 15% | 15% |

**配额调整公式**:
```excel
=基础配额*需求系数*竞争系数
```

### 1.4 置换收益分析

#### 1.4.1 Upgrade收益分析

**Upgrade决策矩阵**:

| 当前房型 | Upgrade房型 | 升级成本 | Upgrade收益 | 净收益 |
|---------|------------|---------|------------|-------|
| 标准间 | 豪华间 | 30元 | 80元 | +50元 |
| 豪华间 | 套房 | 80元 | 200元 | +120元 |
| 套房 | 总统套 | 200元 | 500元 | +300元 |

**Upgrade概率模型**:
```excel
Upgrade接受率 = 1/(1+EXP(-(升级价差/原房价)*系数+截距))
```

**最优Upgrade时机**:
- 入住当天18:00后
- 高卡会员入住
- 特殊日期(生日/纪念日)
- 低房型满房时

#### 1.4.2 Walk-in收益分析

**Walk-in定价策略**:
```excel
Walk-in价格 = 当日最优可卖房价 × (1 + Walk-in溢价率)
```

**Walk-in溢价率参考**:

| 入住率 | 溢价率 | 原因 |
|-------|-------|-----|
| <60% | 0% | 竞争激烈 |
| 60-80% | 5-10% | 适度稀缺 |
| 80-95% | 10-20% | 房间紧张 |
| >95% | 20-50% | 稀缺溢价 |

**Walk-in vs 预留房间决策**:
```
如果: Walk-in期望收益 > 预留房间期望收益
则: 接受Walk-in
否则: 拒绝Walk-in，保留房间给高价渠道
```

#### 1.4.3 置换收益综合计算

**置换收益公式**:
```excel
净置换收益 = (Upgrade收入 - 原房收入 - 升级成本) + (Walkin收入 - 预留房期望收入)
```

**置换决策树**:
```
入住率 < 85%
├─ 是 → 自由Upgrade，接受Walk-in
└─ 否 → 进入精细计算
    ├─ Upgrade净收益 > 0?
    │   ├─ 是 → 执行Upgrade
    │   └─ 否 → 拒绝Upgrade
    └─ Walk-in报价 > 预留房期望收益?
        ├─ 是 → 接受Walk-in
        └─ 否 → 拒绝Walk-in
```

## 二、中国市场特色收益管理

### 2.1 OTA渠道博弈

#### 2.1.1 携程定价策略

**携程特性分析**:
- 流量最大，但佣金最高(15-25%)
- 黄金展示位竞价激烈
- 会员体系深度绑定
- 点评权重极高

**携程定价公式**:
```excel
携程挂牌价 = 底价/(1-佣金率-营销费率)*品牌系数
```

**佣金结构**:

| 酒店类型 | 基础佣金 | 营销包 | 总成本 |
|---------|---------|-------|-------|
| 经济型 | 10-12% | 3-5% | 13-17% |
| 中端 | 12-15% | 5-8% | 17-23% |
| 高端 | 15-18% | 8-12% | 23-30% |

**携程价格策略**:

| 场景 | 策略 | 操作要点 |
|-----|------|---------|
| 新店爬坡 | 低价冲量 | 前3个月ADR低于竞品15% |
| 稳定期 | 价格对标 | 维持在竞品±5%区间 |
| 旺季 | 溢价收割 | ADR可高于平时40% |
| 大促期间 | 阶梯让利 | 配合平台满减活动 |

#### 2.1.2 美团定价策略

**美团特性分析**:
- 本地生活流量优势
- younger客群占比高
- 闪住/钟点房需求旺盛
- 佣金相对较低(8-12%)

**美团定价公式**:
```excel
美团价格 = 底价/(1-佣金率)*活动系数*会员系数
```

**美团专属策略**:

| 产品 | 定价策略 | 注意事项 |
|-----|---------|---------|
| 钟点房 | 日房价×30% | 设置3/4/6小时档 |
| 闪住 | 标准价×95% | 免押金免查房 |
| 超级团购 | 标准价×70% | 控制库存和时段 |
| 直播价 | 标准价×65% | 限时限量 |

#### 2.1.3 飞猪定价策略

**飞猪特性分析**:
- 阿里生态流量
- 出境游/高客单价优势
- 会员通体系
- 套餐产品销售佳

**飞猪定价公式**:
```excel
飞猪价格 = 底价/(1-佣金率-积分成本)*套餐溢价系数
```

**飞猪特色产品定价**:

| 产品类型 | 定价公式 | 溢价空间 |
|---------|---------|---------|
| 房+票 | 房价×1.0 + 门票×0.8 | 5-10% |
| 房+餐 | 房价×1.0 + 餐饮×0.7 | 8-15% |
| 连住套餐 | 日均价×0.9×天数 | 通过连住换折扣 |
| 会员专享 | 标准价×0.85 | 88VIP专属 |

#### 2.1.4 多OTA价格一致性管理

**价格一致性公式**:
```excel
各平台税后价格差异 < 3%
```

**价差监控Excel模板**:
```excel
=IF(MAX(携程价,美团价,飞猪价)/MIN(携程价,美团价,飞猪价)-1>0.03,"价格不一致警告","价格正常")
```

**差异化定价合法策略**:
1. 产品差异化(含早/不含早)
2. 会员等级差异化
3. 套餐组合差异化
4. 预订条件差异化(预付/现付)

#### 2.2.3 渠道冲突管理

```
达标奖励: 年度完成>300间, 返利3%
超额奖励: 年度完成>500间, 超额部分返利5%
```

```excel

超额奖励 = IF(实际间夜>500, (实际间夜-500)×协议价×0.05, 0)
```


**变动成本预算**:
```excel
变动成本 = 收入 × 变动成本率
```

**固定成本预算**:
```excel
固定成本 = 上年实际 × (1 + 成本增幅) ± 调整项
```

### 5.3 KPI分解

#### 5.3.1 核心KPI体系

**一级KPI(酒店层面)**:
```
RevPAR = ADR × 入住率
GOPPAR = GOP / 可售房晚
```

**二级KPI(部门层面)**:
```
收益部: ADR完成率, 渠道贡献率
房务部: 入住率, 散客比
餐饮部: 餐饮收入, 人均消费
```

**三级KPI(岗位层面)**:
```
收益经理: 价格调整次数, 预测准确率
销售经理: 新客户开发, 协议额完成
```

#### 5.3.2 KPI计算公式

**ADR (平均房价)**:
```excel
ADR = 总房费收入 / 已售间夜数
```

**OCC (入住率)**:
```excel
OCC = 已售间夜数 / 可售间夜数 × 100%
```

**RevPAR (每可用房收入)**:
```excel
RevPAR = ADR × OCC 
= 总房费收入 / 可售间夜数
```

**GOPPAR (每可用房经营利润)**:
```excel
GOPPAR = GOP / 可售间夜数
```

**CPAR (每可用房佣金)**:
```excel
CPAR = 佣金总额 / 可售间夜数
```

## 七、STR数据在RM中的应用 🆕

### 7.1 STR核心指标体系

```
STR Global = 酒店行业最权威的对标数据源
覆盖: 全球68,000+酒店 / 中国1,500+酒店参与

四个标准指标:
  Occ%   = 已售间夜 / 可售间夜
  ADR    = 客房收入 / 已售间夜
  RevPAR = 客房收入 / 可售间夜  (= Occ% × ADR)
  GOPPAR = 经营毛利 / 可售间夜 (STR不直接提供，需推算)

三个指数 (竞品组对标):
  MPI = 本店Occ% / 竞品组Occ%    (Market Penetration Index)
  ARI = 本店ADR / 竞品组ADR      (Average Rate Index)
  RGI = 本店RevPAR / 竞品组RevPAR (Revenue Generation Index)
```

### 7.2 STR在RM决策中的五步法

**Step 1: 确定竞品组 (Comp Set)**
```
竞品组 = 5-8家酒店
选择标准:
  ✅ 同商圈 (半径3-5km)
  ✅ 同星级/档次
  ✅ 同规模 (±30%房间数)
  ✅ 同客源结构
  ❌ 不直接竞争的超高端或经济型

竞品组质量 = 覆盖面 + 可比性 + 数据可得性
```

**Step 2: 解读RGI信号**

| RGI值 | 含义 | RM策略 |
|-------|------|--------|
| >1.1 | 市场领先 | 维持，可小幅提价 |
| 1.0-1.1 | 略高于市场 | 防守，观察竞品动向 |
| 0.9-1.0 | 略低于市场 | 诊断: 流量不足还是定价偏低? |
| <0.9 | 市场落后 | 紧急: 降价+推广+产品改善 |

**Step 3: 拆分MPI vs ARI**
```
RGI < 1.0 时诊断:
  ├── MPI < 1.0 (入住率低于竞品) → 流量问题
  │     → 增加曝光/推广/降价引流
  ├── ARI < 1.0 (ADR低于竞品) → 定价偏低
  │     → 提价 (在有Occ支撑的前提下)
  └── 两者都低 → 全面竞争弱势
        → 需要产品升级或重新定位
```

**Step 4: 日维度 vs 周维度动态对标**
```
日维度: 比较本周三 vs 上周三 (工作日模式)
周维度: 比较本周 vs 上周 (消除日波动)
月维度: 比较本月 vs 上月/去年同月 (趋势判断)
年维度: YTD累计 vs 去年同期 (年度目标达成)

关键判断: 当RGI连降3周 → 系统性预警
```

**Step 5: 预测→实际偏差归因**
```
预测RevPAR 10,000 vs 实际RevPAR 9,200 (偏差 -8%)
  
  拆解: MPI偏差 -3% + ARI偏差 -3% + 交互效应 -2%
  
  MPI偏差原因: 竞品新增促销、天气影响、大型活动取消
  ARI偏差原因: 竞品降价、OTA佣金变动、客源结构变化
  
→ 下一周期修正策略
```

### 7.3 2026五一STR数据应用案例

**五一假期 (5/1-5/5) 全国概览** (方向性推算):
```
Occ:  同比 +2~5%  (微增，受益于五天假期)
ADR:  同比 -12%   (量稳价降新常态)
RevPAR: 同比 -8~10% (ADR下行拖累)

关键发现:
  - 县域高星消费首超一线城市 (⚡ 历史拐点)
  - 燃油成本传导未充分反映在定价中
  - 票根经济效应: 交通票+酒店套餐消费力更强
```

**STR口径的特殊性**:
- STR只统计参与样本酒店，非全量
- 新开业酒店不计入同比 (保证可比性)
- 节假日口径: STR按实际假期日统计，非固定周

### 7.4 STR vs 酒店之家 vs OTA 三源交叉验证

| 指标 | STR | 酒店之家 | OTA平台 |

### 8.1 从Excel到AI: RM技术演进

```
1.0 手工定价 (2000年前)
  → 收益经理凭经验调价
  → 问题: 主观、滞后、不可复制

2.0 Excel模型 (2000-2015)

  → 问题: 维护成本高、多酒店难统一

  → IDeaS/Duetto/OptiPrice
  → 问题: 黑盒、闭环调整慢

4.0 AI/ML模型 (2020-now)
  → 深度学习+强化学习
  → 优势: 自学习、多变量、实时优化
```

### 8.2 AI定价模型架构

**核心模型**:
```
输入层:
  ├── 历史数据: 过去2年日度ADR/Occ/RevPAR
  ├── 预订曲线: 未来90天预订Pickup进度
  ├── 竞品数据: 竞品组实时价格
  ├── 外部变量: 天气/节假日/大型活动/交通/经济指标
  └── 渠道信号: 各OTA搜索量/曝光量/转化率

模型层:
  ├── 需求预测: LSTM/Transformer时序模型
  ├── 价格弹性: 贝叶斯弹性估算
  ├── 竞品博弈: 多Agent强化学习
  └── 优化器: 约束优化 (max RevPAR s.t. 价格上下限)

输出层:
```

## 九、多OTA渠道利润优化 🆕

> 详细OTA运营策略见: `multi-ota-operations-knowledge-base-v1.md`
> 本节聚焦RM视角的渠道利润优化。

### 9.1 渠道利润率金字塔

```
渠道净利润率排序 (ADR ¥500 为例):

直销/官网:        ¥500 × 0%佣金  = ¥500/间  (利润率 100%基准)
会员直销:          ¥480 × 0%佣金  = ¥480/间  (让利换忠诚)
企业协议:          ¥450 × 0%佣金  = ¥450/间  (量换价)
微信小程序:        ¥490 × 1%手续费 = ¥485/间
美团:              ¥500 × 10%佣金 = ¥450/间
飞猪:              ¥500 × 10%佣金 = ¥450/间
携程:              ¥500 × 15%佣金 = ¥425/间
Booking:           ¥500 × 18%佣金 = ¥410/间
Expedia:           ¥500 × 20%佣金 = ¥400/间
```

**渠道利润优化第一原则**: 直销占比每提升1%，净利润率提升0.15%。

### 9.2 渠道间夜配比优化

**优化模型**:
```
目标: Maximize Σ(间夜量_i × 净利润_i)
约束:
  1. Σ间夜量_i ≤ 可售间夜
  2. 各渠道间夜量 ≥ 最低阈值
  3. OTA渠道不可为零 (维持可见度)
  4. 直销占比 ≥ 30% (健康指标)

优化方向:
  - 旺季: 压缩高佣金渠道占比 (OTA从50%→30%)
  - 淡季: 适度增加OTA (曝光换填坑)
  - 平日: 维持均衡
```

### 9.3 渠道切换弹性

```
渠道切换弹性 = (渠道A间夜变化%) / (渠道A vs 渠道B 价格差变化%)

例: 携程ADR涨5% vs 美团不变
    携程间夜 -8% / 美团间夜 +5%
    → 用户对¥25-50差价敏感
    → 不要对高佣金渠道过度让利
```

### 9.4 多平台最优ADR决策

**核心公式**:
```
最优ADR_渠道i = 市场基准ADR × (1 + 渠道佣金率) × 客流指数_渠道i

例: 如果市场基准ADR=500
  携程建议挂牌价 = 500 × 1.15 × 1.00 = 575
  美团建议挂牌价 = 500 × 1.10 × 0.95 = 523
  直销建议价      = 500 × 1.00 × 0.90 = 450
  
  → 携程挂高(含佣金) + 直销最低(让利) + 差异化产品
```

**⚠️ 价格一致性约束**: 实际执行中必须遵守各平台的价格一致性条款。产品差异化(含早/含接机/含景点)是绕过价格一致性的主要手段。
