## 一、什么是酒店项目定位

酒店项目定位是在项目启动前，通过系统的市场调研、竞争分析和数据论证，确定酒店的**类型、档次、客群、价格区间、功能配置和经营模式**的综合性决策过程。

**定位是所有后续工作的前提**：
- 定位决定设计：档次决定装修标准、面积指标、功能配置
- 定位决定投资：档次决定单房造价，总投资=单房造价×房间数
- 定位决定回报：档次和客群决定ADR和入住率，进而决定RevPAR和回报周期

## 二、酒店定位的八维框架

任何酒店定位都围绕以下八个维度展开：

| 维度 | 含义 | 示例 |
|------|------|------|
| **品质梯度** | 从奢华到经济型的纵向阶梯 | 奢华→豪华→中高端→中端→经济型 |
| **星级标准** | 国家旅游局星级评定体系 | 五星/四星/三星 |
| **服务模式** | 有限服务 vs 全服务 | 有限服务（仅客房+早）vs 全服务（含餐/会/娱） |
| **场景类型** | 酒店所在的功能区划 | 商务/度假/会议会展/城市度假/机场中转/景区配套 |
| **价格区间** | 目标客群的承受价格带 | 300-500元/500-800元/800-1200元 |
| **OTA钻级** | 携程/美团等平台的评级标准 | 钻石/金钻/金牌/银牌 |
| **品牌归属** | 国际品牌/国内集团/独立品牌 | 希尔顿/华住/独立精品 |
| **集团体系** | 加盟品牌对应的集团支持 | 锦江/华住/首旅/东呈/无集团 |

## 四、酒店项目定位全流程（五阶段）

### 阶段1：市场调研

**目标**：回答"这个市场容得下什么档次的酒店"

#### 1.1 宏观市场分析
- 全国/省/市酒店行业发展情况及分级分类趋势
- 当地旅游/商务客群的发展态势
- 政策环境（文旅局规划、土地性质、限高限容）

#### 1.2 城市酒店格局分析
- 全市酒店档次分布（经济型/中端/中高端/高端各占多少）
- 近年新开业酒店情况（档次/体量/经营数据）
- 城市酒店供需缺口分析

#### 1.3 交通口岸分析
- 机场/高铁站/火车站的客流量及增速
- 与核心景区的距离和通达性
- 周边商业/会展/政务流量

#### 1.4 客源结构分析（细分市场六宫格）

| 细分市场 | 分析内容 |
|---------|---------|
| **旅游客群** | 自由行/团队比、客单价、季节性、来源省份 |
| **商务客群** | 企业协议客户规模、差标水平、入住频次 |
| **政务客群** | 政府会议/公务接待需求量及季节性 |
| **会议会展** | MICE规模、场均人数、淡旺季分布 |
| **散客** | Walk-in/电话预订占比、ADR敏感度 |
| **渠道/批发商** | 团队房价、旅行社合作稳定性 |

#### 1.5 STR竞争群组分析
- 定义竞争集合（STR群组）：地理位置+档次+体量相近的竞品
- 收集竞品的OCC/ADR/RevPAR数据（历史3年+未来预测）
- 分析竞争群组的供需走势

---

### 阶段2：酒店定位（核心输出）

**目标**：回答"我们要开一家什么档次、什么客群、什么价格的酒店"

#### 2.1 类型定位
- 有限服务 vs 全服务
- 长住型 vs 短住型
- 单体酒店 vs 品牌加盟

#### 2.2 档次分级定位
- 目标星级（五星/四星/三星）
- 目标OTA钻级（钻石/金钻/金牌）
- 参照品牌（"参考某某酒店档次"）

#### 2.3 价格区间定位
- 目标ADR区间（参考STR竞品数据）
- 目标OCC（基于供需分析）
- 目标RevPAR = ADR × OCC

#### 2.4 客群定位（谁会来住）
- **地域属性**：本地/本省/全国/入境
- **年龄层**：25-35/35-45/45-55/55+
- **场景**：商旅出差/家庭度假/情侣/会议团队/本地餐饮
- **消费动机**：商务接待/旅游住宿/周末微度假/探亲访友

#### 2.5 功能定位（酒店里要有什么）
- 客房：面积/房型配比/特殊房型（亲子/套房）
- 餐饮：全日餐厅/中餐包间/大堂吧/宴会厅
- 会议：多功能厅/会议室数量
- 配套：健身房/游泳池/儿童活动区

#### 2.6 经营模式选择
- 自持经营 vs 部分分包 vs 全部分包
- 餐饮：自营 vs 外包 vs 保底+提成
- 会议：自营 vs 与婚庆公司合作
- 停车场：自营 vs 外包

---

### 阶段3：功能布局要求

**目标**：把定位翻译成空间指标，形成设计任务书输入

#### 3.1 前厅及大堂
- 大堂面积（与客房总量的比例）
- 前台柜台数量（基于高峰接待量）
- 大堂吧位置/面积/餐位数
- 礼宾区域布局

#### 3.2 客房区
- 总房间数（基于目标体量和地块条件）
- 房型配比：单间/标间/套房/亲子房比例
- 每种房型的面积指标
- 前后场配比（客梯/货梯/服务间）

#### 3.3 全日餐厅（ADD/FBR）
- 餐位数（基于客房数和餐饮定位）
- 餐厨比（前厅：后厨，通常1:0.8-1:1.2）
- 经营时段（早餐/午餐/晚餐/宵夜）

#### 3.4 宴会及会议
- 宴会厅面积/层高/无柱设计
- 会议厅数量/面积/容纳量（课桌/剧院/圆桌/鱼骨）
- 婚宴容量（最大单餐桌数）

#### 3.5 后场及后勤
- 员工区面积（基于编制定员）
- 仓库/收货区/布草房/工程部
- 垃圾房/洗衣房（自洗vs外洗）

---

### 阶段4：经营模式选择

**目标**：确定最优经营组合，计算各合作方的费用和收益

#### 4.1 经营业态组合
- 确定2-3种最适合项目的经营模式组合
- 例如：五星级全服务（客房+餐饮+会议+健身）

#### 4.2 自持与分包边界
- 明确自持经营与分包/租赁的边界线
- 餐饮：自营/整包/半包/保底提成的边界
- 停车场：自营/外包
- 店铺招商：招租业态和位置

#### 4.3 合作方类型
- 品牌加盟方（国际/国内集团）
- 管理公司（酒店管理公司派驻团队）
- 餐饮合作方（品牌餐饮/本地餐饮）
- 会议/婚庆合作方

---

### 阶段5：投资回报匡算

**目标**：回答"开这家酒店要多少钱、能赚多少、几年回本"

#### 5.1 投资构成

| 投资项 | 说明 |
|-------|------|
| 土地成本 | 购地款或租金折现 |
| 建设成本 | 土建/机电/精装的单方造价×总建筑面积 |
| 装修成本 | 客房/餐饮/公区装修单方造价×面积 |
| 设备成本 | 厨房设备/电梯/空调/家具 |
| 开办费 | 筹备期人员工资/营销推广/证照办理 |
| 流动资金 | 运营前3个月周转金 |

**单房造价参考**：

| 档次 | 单房造价范围（含公区分摊） |
|------|--------------------------|
| 五星 | 50-120万元/间 |
| 四星 | 25-50万元/间 |
| 中高端 | 15-25万元/间 |
| 中端 | 8-15万元/间 |
| 经济型 | 5-8万元/间 |

#### 5.2 经营预测

基于定位阶段的ADR和OCC预测：
- **客房收入** = ADR × OCC × 365 × 房间数
- **餐饮收入** = 餐位×翻台率×客单价×天数
- **其他收入** = 会议/健身/停车场等

#### 5.3 回报测算

| 指标 | 计算方式 | 参考标准 |
|------|---------|---------|
| GOP率 | 营业利润/GOP | 五星30-35%，中高端35-40% |
| GOP | 收入×GOP率 | — |
| 坪效 | 年营收/建筑面积 | — |
| 回本周期 | 总投资/GOP | 4-8年为健康区间 |
| NPV | 未来现金流折现 | IRR > 12%为可行 |

## 五、典型案例参照

### 案例：成都Vhotel精选酒店
- **体量**：8000㎡，单方造价1800元/㎡
- **筹建周期**：10个月
- **运营表现**：运营7年与预测偏差<5%
- **关键经验**：前期定位精准，设计和运营高度匹配

### 乐山市场背景（参考数据）
- 2024年乐山接待游客**首次突破1亿人次**（+14%）
- 旅游综合收入**突破1300亿元**（+13%）
- 市中区接待游客**3003万人次**，旅游收入**435亿元**
- 主要竞品：乐山锦诚酒店（246间）、希尔顿欢朋（180间）、全季（多店）
