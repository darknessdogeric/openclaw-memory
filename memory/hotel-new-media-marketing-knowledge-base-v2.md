### 2.2 TikTok/抖音营销

**论文: Going Viral: Analysis of Advertising on TikTok**
- 来源: arXiv (2024)
- 核心发现:
  - 短视频广告病毒式传播规律
  - 前3秒是关键
  - 音乐/节奏影响传播
  - 用户生成内容(UGC)效果优于广告

```
酒店抖音策略:
1. 前3秒必须抓住注意力
2. 使用热门音乐/话题
3. 鼓励用户模仿/二创
4. 本地化内容更容易传播
5. 真实感 > 精致感
```

### 2.3 内容传播算法

```
主流平台算法逻辑:

【抖音算法】
- 完播率 → 推荐量
- 互动率 → 推荐量
- 转粉率 → 权重提升
- 关键: 前3秒+价值+互动

【小红书算法】
- 收藏率 → 权重
- 评论率 → 权重
- 关键词 → 搜索排名
- 关键: 实用价值+美观

【微信算法】
- 打开率 → 推送权重
- 在看/收藏 → 二次传播
- 关键: 关系链+价值

【美团算法】
- 转化率 → 排名
- 评价分 → 权重
- 关键: 转化+口碑
```

### 4.2 内容创作公式

```
爆款内容公式:

【抖音爆款】
= 强情绪 × 真实感 × 实用价值 × 视觉冲击

公式拆解:
- 强情绪: 惊讶/搞笑/感动/震撼
- 真实感: 素人出镜/真实故事/第一视角
- 实用价值: 教程/攻略/避坑
- 视觉冲击: 颜值/奇观/对比

【小红书爆款】
= 高颜值 × 真实体验 × 实用攻略 × 情感共鸣

公式拆解:
- 高颜值: 滤镜/角度/构图/修图
- 真实体验: 第一视角/细节/感受
- 实用攻略: 教程/清单/对比
- 情感共鸣: 生活方式/价值观

【公众号爆款】
= 话题性 × 深度价值 × 情感连接 × 传播钩子

公式拆解:
- 话题性: 热点/争议/共鸣
- 深度价值: 方法论/洞察/数据
- 情感连接: 故事/角色/场景
- 传播钩子: 转发理由/社交货币
```

### 7.2 ROI计算方法

```
ROI计算公式:

ROI = (收入 - 成本) / 成本 × 100%

私域ROI计算:
ROI = (私域GMV × 利润率 - 运营成本) / 运营成本 × 100%

各渠道ROI参考:
├── 抖音: 1:2-5 (种草)
├── 小红书: 1:3-8 (转化)
├── 微信: 1:5-10 (私域)
├── 美团: 1:3-6 (本地)
└── 携程: 1:2-4 (OTA)

影响因素:
├── 行业特性
├── 酒店档次
├── 淡旺季
├── 内容质量
└── 运营能力
```
