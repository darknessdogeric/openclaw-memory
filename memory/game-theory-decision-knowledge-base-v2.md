## 一、行为经济学前沿

### 1.1 前景理论深化

```
卡尼曼&特沃斯基前景理论 (2002诺贝尔奖):

核心公式:
V = Σ w(p_i) × v(Δx_i)

其中:
- V: 选择总价值
- w(p): 概率权重函数
- v(Δx): 价值函数

价值函数特征:
┌─────────────────────────────────────────────────────────────────┐
│                        价值函数曲线                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  价值                                                                      │
│    ↑                                                          │
│    │     收益曲线 (凹)                                        │
│    │    /                                                     │
│    │   /                                                      │
│    │  /                                                       │
│    │ /                                                        │
│    │/_________________________→ 收益                          │
│    │\                                                         │
│    │  \                                                        │
│    │   \  损失曲线 (凸)                                       │
│    │    \                                                      │
│    │     \                                                     │
│    │      损失敏感度 > 收益敏感度                              │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

关键发现:
- 损失100元的不适感 ≈ 获得250元带来的愉悦感
- 损失厌恶系数: λ ≈ 2.0-2.5
```

│  ├── 禀赋效应: 高估自己拥有的东西                              │

## 二、机制设计理论

### 2.1 拍卖理论

```
2020诺贝尔奖: Milgrom & Wilson

核心问题:
如何设计拍卖机制，让卖家获得最高收益？

拍卖类型:

┌─────────────────────────────────────────────────────────────────┐
│                    拍卖类型矩阵                                  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│          单物品拍卖           多物品拍卖                        │
│       ┌──────────┐          ┌──────────┐                      │
│  公开 │ 英式拍卖 │          │  同时拍卖 │                      │
│       │(升价拍卖)│          │(多物品)  │                      │
│       ├──────────┤          ├──────────┤                      │
│  密封 │ 荷式拍卖 │          │  组合拍卖 │                      │
│       │(降价拍卖)│          │(组合优化)│                      │
│       └──────────┘          └──────────┘                      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

关键结论:
- 英式拍卖: 最优效率
- 密封拍卖: 防止串通
- 组合拍卖: 避免内耗
```

### 2.2 Vickrey拍卖

```
Vickrey拍卖 (1961, 1996诺贝尔奖):

原理:
- 密封报价
- 最高价者获胜
- 支付第二高价

优点:
- 激励兼容(IC)
- 显示原理(DS)
- 说真话是优势策略

酒店应用:
- 酒店房间拍卖
- 会议室拍卖
- 活动场地拍卖
```

### 2.3 机制设计核心

```
Myerson引理 (1980):

激励兼容(IC)条件:
- 直接揭示机制
- 优势策略激励兼容

参与约束(IR):
- 说真话不比退出好

核心原则:
- 让说真话成为最优选择
- 让不参与不如参与

酒店场景:
- 预订取消政策设计
- 会员积分机制
- 价格保证机制
```

### 3.2 博弈论实验

```
经典博弈实验:

【最后通牒博弈】
- 实验者: 两人分配100元
- proposer: 提出分配方案
- responder: 接受或拒绝
- 结果: 通常50:50或略高
- 解释: 公平偏好+社会规范

【公共品博弈】
- 四人各10元
- 投入公共池
- 池内资金翻倍平分
- 理性结果: 都不投入
- 实际结果: 40-60%投入
- 解释: 合作偏好+条件合作

【信任博弈】
- 博弈: 投资者→受托方→回报
- 理性结果: 不信任
- 实际结果: 约50%信任
- 解释: 社会偏好+互惠
```

## 四、谈判理论

### 4.1 谈判分析框架

```
Rubinstein讨价还价模型:

前提:
- 两个理性参与者
- 分割固定蛋糕
- 轮流报价

结论:
- 唯一子博弈完美均衡
- 先发优势
- 结果接近平分

关键洞见:
- 时间成本决定分割比例
- 耐心=谈判力

酒店应用:
- 长期协议谈判
- 战略联盟分配
- 并购条款设计
```

### 4.3 BATNA优化

```
BATNA = Best Alternative To Negotiated Agreement

BATNA建立步骤:

1. 列出所有替代方案
2. 评估每个方案的可行性
3. 确定最优替代方案
4. 计算底线
5. 决定接受/拒绝标准

酒店案例:

谈判前:
- 询问其他酒店报价
- 了解行业标准
- 准备离开选项

谈判中:
- 不首先让步
- 展示BATNA
- 创造紧迫感

谈判后:
- 记录条款
- 执行监控
- 关系维护
```
