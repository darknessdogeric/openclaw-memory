## 一、营销部的本质

```
┌──────────────────────────────────────────────────────────────────────┐
│  营销部的五维认知                                                 │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  【1️⃣ 历史沿革】                                                  │
│  ├── 1980s前: 接待所模式 → 等客上门，无营销概念                 │
│  ├── 1980s: 合资酒店引入 → 销售部概念，陌生拜访                 │
│  ├── 1990s: 协议客户体系建立                                  │
│  ├── 2000s: 会员体系+CRM初现                                    │
│  ├── 2010s: OTA崛起+数字营销                                   │
│  └── 2020s: 私域流量+内容营销+直播                             │
│                                                                      │
│  【2️⃣ 目前情况】                                                  │
│  ├── 渠道结构: OTA 40% / 直销 30% / 协议 20% / 其他 10%        │
│  ├── 营销费用率: 营收3-5%                                       │
│  ├── 会员贡献: 头部酒店会员订单占40%+                          │
│  ├── 数字化程度: 80%酒店有官网/小程序                          │
│  └── 内容营销: 小红书/抖音成为获客主战场                       │
│                                                                      │
│  【3️⃣ 原因分析】                                                  │
│  ├── 流量分散: 客人分散在各平台，营销需全域覆盖                 │
│  ├── 获客成本: OTA佣金高(10-20%)，私域成为必争之地            │
│  ├── 竞争加剧: 酒店数量增加，需主动获客                         │
│  └── 技术驱动: 数字化工具让精准营销成为可能                     │
│                                                                      │
│  【4️⃣ 未来预判】                                                  │
│  ├── 2025: 私域流量贡献将超50%                                │
│  ├── 趋势: AI智能投放+内容生成                                 │
│  └── 颠覆: 达人营销/用户共创成为主流                           │
│                                                                      │
│  【5️⃣ 底层逻辑】                                                  │
│  └── 营销本质: "注意力资源的争夺与转化"                        │
│      → 在碎片化的时代抢夺客人的注意力                          │
│      → 将注意力转化为预订意愿                                  │
│      → 将一次客人转化为终身客户                                │
│                                                                      │
└──────────────────────────────────────────────────────────────────────┘
```

## 二、OTA运营的五维解析

```
┌──────────────────────────────────────────────────────────────────────┐
│  OTA运营的五维认知                                                 │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  【1️⃣ 历史沿革】                                                  │
│  ├── 1999年: 携程创立 → 酒店在线预订萌芽                       │
│  ├── 2000s: 艺龙/去哪儿/同程 → 垂直搜索比价                    │
│  ├── 2010s: 美团崛起 → 本地生活OTA                             │
│  ├── 2015年: 携程去哪儿合并 → 寡头格局                       │
│  └── 2020s: 抖音/小红书 → 内容种草+交易闭环                   │
│                                                                      │
│  【2️⃣ 目前情况】                                                  │
│  ├── 携程: 高星酒店40%+，商旅用户强                          │
│  ├── 美团: 本地客群60%+，低星酒店强                          │
│  ├── 飞猪: 阿里系，会员/信用住                             │
│  ├── 抖音: 种草+交易，内容即货架                           │
│  └── 佣金率: 携程10-15% / 美团8-12% / 飞猪8-10%          │
│                                                                      │
│  【3️⃣ 原因分析】                                                  │
│  ├── 流量逻辑: OTA掌握海量用户流量                            │
│  ├── 习惯逻辑: 客人已习惯在OTA比价                            │
│  ├── 服务逻辑: OTA提供担保/客服/点评                         │
│  └── 依赖逻辑: 酒店对OTA既爱又恨，爱流量恨佣金               │
│                                                                      │
│  【4️⃣ 未来预判】                                                  │
│  ├── 2025: 抖音GMV超越携程                                  │
│  ├── 趋势: 内容即交易，种草-预订闭环成为主流               │
│  └── 颠覆: AI推荐替代搜索，本地生活一体化                  │
│                                                                      │
│  【5️⃣ 底层逻辑】                                                  │
│  └── OTA本质: "流量中介的垄断变现"                           │
│      → OTA是酒店和客人之间的"中间商"                        │
│      → 垄断流量后收取"过路费"(佣金)                         │
│      → 酒店是内容提供商，OTA是渠道商                        │
│      → 未来: 去中介化，内容平台直连酒店PMS                │
│                                                                      │
└──────────────────────────────────────────────────────────────────────┘
```
