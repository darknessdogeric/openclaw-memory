### 信号 1 · MCP + A2A 协议栈 = 双层通信基础设施
- **MCP**（Model Context Protocol，Anthropic 推出）= AI 与外部工具的"神经系统"/"通用插座"

  - **B166ER 映射**：MCP = 我们的"工具调用统一层"
- **A2A**（Agent-to-Agent Protocol，Google 主导）= Agent 之间的"社交网络"
  - 通过 Agent Card 机制解决能力发现
  - 跨平台/多模态 Agent 协作
  - 50+ 企业支持（Atlassian / Salesforce / **微软 Azure AI Foundry + Copilot Studio**）
  - **B166ER 映射**：A2A = AHL 多 Agent 协作的"通信骨架"
- **关键判断**：MCP（连接层）+ A2A（协作层）= Agent 时代完整的双层通信协议
  - **与 AHL 架构同构**：AHL 的 Hub-Leaf 模型 = 内部 MCP 风格 + A2A 风格融合
  - **未来机会**：AHL Leaf 域可以做成 A2A Agent Card，向开放生态暴露能力
