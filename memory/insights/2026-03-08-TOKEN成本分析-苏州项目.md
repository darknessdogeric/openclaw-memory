| 计费项 | 单价 |
|--------|------|

```
收费 = 基础费(¥2,000) + RevPAR提升分成(10-20%)
```

## 五、TOKEN成本管控建议

1. **分层模型策略**：简单查询用V3(便宜)，复杂分析用R1(精准)，比例8:2
2. **上下文压缩**：历史对话只保留摘要，省30-40% TOKEN
3. **缓存机制**：常见问题预生成答案
4. **本地部署**：用量极大时，一次性投入¥10-20万硬件，后续零TOKEN费
