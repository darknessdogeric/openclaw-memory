## 一、维 14 · 重大 Bug 修复（v5.0）

### Bug 现象
- v2.0 → v4.0 期间，Eric 持续反馈"文字灰色暗沉"
- 3 轮调整（改底色、改文字色、改字号）**均无效**
- 验证 v4.0 实际渲染颜色：**主文字色 #989898**（不是 CSS 写的 #000000）

### Bug 根因
```css
/* 模板里有这一行（之前用于"占位符未替换时显示淡色"） */
[data-pending] { opacity: 0.4; }
```

- 所有元素都加了 `data-pending` 属性
- 渲染脚本没有去掉这个属性
- **opacity 0.4 × 纯黑 = 中灰**：#000000 × 0.4 = #999999 视觉

### 修复
- 删除 `[data-pending] { opacity: 0.4; }` 规则
- 移除 `data-pending` 属性
- v5.0 渲染验证：**主文字 #000000 纯黑（4.1% 占比）**

### Eric 反馈闭环
- v1.0 米白 → v2.0 米白加深 → v3.0 高对比度 → v4.0 纯白纯黑 + 亮金 → **"还是灰色暗沉"** → 找到 bug → **v5.0 真正高清**
- **教训**：**用户反馈"还是 X"时，要回到根因重新诊断，不要继续调表面参数**
