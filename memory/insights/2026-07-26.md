## 洞见#1: TACO 认知论升级 — 从纯价格逻辑到博弈均衡

**触发场景**: 2026-07-25 Oil Scenario C 验证失败

**原预测**: Brent $100+ 持续 7 天 = 通胀自我实现锚定(纯价格逻辑链)
**实际观察**: Brent 触及 $100.28 → TACO 谈判牵引抛压 → 回吐至 $96.78(WTI $87.70,日跌 4.9%)

**理论升级**:

```
场景分类器 v1.0:
├─ 主动行为者不在场(自然/灾难/技术现象)
│   → 纯价格逻辑有效
│   → 历史外推 + 均值回归
└─ 主动行为者在场(政策/谈判/监管/特朗普)
    → 必须纳入博弈均衡
    → TACO/谈判拉力强度 > 价格惯性
```

**核心洞见**: 当链条中存在"会主动反悔/反扑的行为者"时,纯价格因果链失效——博弈均衡取代价格惯性成为主驱动。

**跨界应用(AHL/1244)**:
- 任何涉及企业决策者/谈判者/政策制定者的场景,不能套用纯效率逻辑
- AHL 智能降本场景:客户酒店业决策者是"主动行为者"时,纯效率逻辑预测会失真
- 1234 战略评估:优先识别"主动行为者位置"再选预测模型

**对 Eric 的价值**: 这是 2026-07-25 验证的实战发现——不是理论推演,是市场当日的实际反馈。

## 洞见#4: 主动行为者存在性 = 新场景分类变量

**观察**: 7/25 TACO 事件 + 摩尔线程反垄断 + 腾讯回购 = 三类事件,共同特征是"主动行为者在场"

**推断**: 一个高波动场景的**可预测性**,首先取决于"主动行为者是否存在",而非"数据噪声大小"

```
可预测性矩阵 v1.0:
                        主动行为者在场   主动行为者不在场
数据噪声 低              高                极高
数据噪声 高              极低(猜赌注)     中(均值回归)
```

**操作含义**: AHL 场景库设计应增加"主动行为者存在性"作为第一分类变量,而不是用"行业/规模/区域"作为第一分类。
