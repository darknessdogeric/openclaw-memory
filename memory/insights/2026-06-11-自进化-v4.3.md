### 贝叶斯推理 3 概念

1. **先验（Prior）**：未观察新证据前的判断
   - 例子：我对 Eric 给的"评估对象"的初始假设 = "AHL 可能从中受益"

2. **似然（Likelihood）**：新证据与假设的匹配度
   - 例子：仓库 README 内容与"对 AHL 有用"假设的匹配程度

3. **后验（Posterior）**：结合新证据后的判断
   - 例子：看到 awesome-mcp-servers 的 9000+ servers = "对 AHL"权重下降，"对 Eric 行业战略"权重上升
