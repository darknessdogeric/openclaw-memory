## 一、维 11 · 控制论 5 概念（v3.9 → v4.0 内化）

### 控制论 5 核心概念
1. **反馈回路（Feedback Loop）**：系统输出 → 反馈给输入 → 影响下一轮输出
2. **负反馈（Negative Feedback）**：缩小偏差 → 保持稳定
3. **正反馈（Positive Feedback）**：放大偏差 → 增长或失控
4. **延迟（Delay/Lag）**：反馈响应时间差 → 系统震荡或失效
5. **超调（Overshoot）**：反馈过强 → 越过目标 → 二次修正
