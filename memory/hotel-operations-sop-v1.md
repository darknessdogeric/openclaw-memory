### 2.2 客房清洁SOP

#### 2.2.1 走客房清洁(退房清洁)

```
走客房清洁流程 (标准时间: 30-40分钟/间):
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  Step 1: 进房准备 (2分钟)                                  │
│  ├── 按门铃3下+敲门"客房服务"                              │
│  ├── 等待3秒后刷卡进入                                      │
│  ├── 开窗通风                                               │
│  ├── 打开窗帘                                               │
│  ├── 检查遗留物品                                           │
│  └── 关闭不需要的电器                                       │
│                                                             │
│  Step 2: 撤除脏布草 (5分钟)                                │
│  ├── 撤床单+被套+枕套(放入布草袋)                          │
│  ├── 撤毛巾+浴巾+地巾(放入布草袋)                          │
│  ├── 清空垃圾桶                                             │
│  └── 分类: 布草/垃圾分别放置                               │
│                                                             │
│  Step 3: 铺床 (8分钟)                                      │
│  ├── 铺床单(包角45度，中线居中)                             │
│  ├── 套被套(四角对齐，开口朝床尾)                           │
│  ├── 套枕套(饱满均匀，开口向内)                             │
│  ├── 床尾巾(如有)                                          │
│  └── 检查床面平整                                           │
│                                                             │
│  Step 4: 卫生间清洁 (10分钟)                               │
│  ├── 清洁顺序: 镜子→台面→水龙头→马桶→浴缸→地面           │
│  ├── 使用专用清洁剂                                         │
│  ├── 擦干水迹                                               │
│  ├── 补充客用品(毛巾/牙刷/牙膏等)                          │
│  └── 检查排水通畅                                           │
│                                                             │
│  Step 5: 房间清洁 (8分钟)                                  │
│  ├── 家具表面除尘(从里到外)                                │
│  ├── 电器清洁(电视/空调/灯具)                              │
│  ├── 窗台/窗帘                                              │
│  ├── 地面吸尘/拖地                                         │
│  └── 补充客用品(茶包/矿泉水/便签等)                        │
│                                                             │
│  Step 6: 最后检查 (2分钟)                                  │
│  ├── 环视房间，确认无遗漏                                   │
│  ├── 检查设施设备是否正常                                   │
│  ├── 调节空调(22-24℃)                                      │
│  ├── 关闭门窗                                               │
│  ├── 关闭灯具(留廊灯)                                      │
│  └── 锁门+登记出房时间                                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**清洁质量检查标准**:
| 项目 | 标准 | 检查方法 |
|------|------|----------|
| 床品 | 无毛发、无污渍、平整 | 目视+触摸 |
| 卫生间 | 无水迹、无异味、五金光亮 | 目视+嗅闻 |
| 地面 | 无垃圾、无毛发、无污渍 | 目视 |
| 家具 | 无灰尘、无水渍 | 手摸 |
| 物品摆放 | 按标准位置 | 对照标准 |
| 空气 | 清新无异味 | 嗅觉 |
