```

  - 张实在投资人/竞争者/合作方前用这套
```

## 二、查理·芒格的100个思维模型（精简实战版）

### 2.1 逆向思维（反演法）

```
核心原则：正面想不通，倒过来想

芒格原话：
"我只想知道我会死在哪里，这样我就永远不去那里"

酒店业应用：
  问：怎样才能让一家酒店在3年内倒闭？
    答案：
      - 产品差+价格高
      - 团队不稳定，核心人走了
      - 和OTA关系搞砸，被下架
      - 现金流断裂
    避开这些，成功的概率自然提高

商业决策应用：
  问：怎样才能让这个创业项目失败？
    常见答案：
      - 创始人团队散了
      - 钱烧完了还没找到商业模式
      - 政策突然转向
      - 核心竞争壁垒没建起来
    然后问：我的项目有这些问题吗？我怎么提前化解？
```

### 2.2 第二层思维

```
第一层思维（普通人）：
  "这是一家好公司，买入！"

第二层思维（高手）：
  "所有人都知道这是好公司，所以估价已经很高了。
   如果我买入，支付的价格是否已经反映了一切？
   它的真实价值增长是否超过了我支付的价格？
   其他人可能低估了什么，高估了什么？"

酒店业应用：
  问：成都文旅推荐春熙宾馆试点——这是机会还是坑？
  
  第一层：AHL有试点机会，拿到就是胜利
  
  第二层：
    - 为什么是春熙宾馆？他们得到什么好处？
    - 他们的真实配合意愿有多高？
    - 如果失败，谁的责任最大？
    - 我的时间成本是否值得？
    - 如果换成另一家，成功的概率差多少？
```

### 2.3 概率思维（期望值计算）

```
核心公式：
  期望值 = 概率 × 结果

例子：
  赌局：50%概率赢¥1000，50%概率输¥500
  期望值 = 0.5 × 1000 + 0.5 × (-500) = ¥250
  → 值得参与

现实中更复杂：
  - 概率往往无法精确估算
  - 需要概率树（Tree Diagram）帮思考多种可能

酒店业应用：
  问：要不要接这个人寿保险的项目？
  
  场景A（高确定性）：
    概率70%成功，利润¥50万
    概率30%失败，损失¥10万
    期望值 = 0.7×50 + 0.3×(-10) = ¥32万
    → 值得做

  场景B（低确定性）：
    概率20%成功，利润¥500万
    概率80%失败，损失¥50万
    期望值 = 0.2×500 + 0.8×(-50) = ¥60万
    → 仍然值得，但需要控制最大损失
```

### 2.4 逆向归纳（从终局倒推）

```
核心原则：从最终目标倒推第一步行动

例子：从北京去西藏
  正推：打开地图，看路线，计算每段距离 → 复杂且容易迷路
  倒推：先到拉萨，再一步步规划 → 清晰简单

商业应用：
  问：5年后AHL值多少钱？
  
  假设：
    - 住宿业AI市场规模 >¥5000亿
    - AHL协议成为头部基础设施（5%市占率）
    - 年交易额 ¥250亿 × 2% = ¥5亿/年技术服务收入
    - 给10倍PE = ¥50亿估值
  
  倒推回来：
    - 要达到这个目标，3年后需要做到什么？
    - 2年后需要什么？
    - 1年后呢？
    - 6个月后呢？
    - **今天需要做什么？**
```

### 2.5 能力圈（知道自己不知道什么）

```
核心原则：只在自己的能力圈内做重大决策

巴菲特/芒格：
"如果你知道了能力圈的边界，你就已经比大多数人成功了"

能力圈判断：
  张实的能力圈：
    ✓ 酒店行业（24年，从基层到创业）
    ✓ 收益管理/定价策略
    ✓ OTA博弈/携程运营
    ✓ 酒店项目投资测算
    ✗ AI底层技术（LLM训练/向量数据库运维）
    ✗ 美国法律/税务细节
    ✗ 消费品牌营销

行动：
  - 重大决策先问：这是我的能力圈吗？
  - 如果不是，找有能力的合伙人/顾问
  - 不要用"我能学"的幻觉来忽视专业壁垒
```

### 2.6 激励效应（永远考虑激励机制）

```
芒格：
"每次你看到MBA或法学院考试出现激励机制的问题，你都应该仔细分析。
  问问自己：这个激励机制会如何扭曲决策？"

酒店业例子：
  OTA的销售激励机制：
    - 携程销售拿提成 → 拼命推高佣金率的房源
    - 结果：高佣金 ≠ 好房源，排名被扭曲
    - 这就是为什么低价高佣的房源总在前面
  
  酒店内部激励：
    - 前台拿开房提成 → 拼命卖高价房，哪怕客人需求低价
    - 销售拿签单提佣 → 降低协议价换签单量，收入质量差
    - 总经理拿GOP提成 → 压缩成本到影响服务质量

应用：
  每次看到一个问题，先问：
    "这个结果的激励是什么？谁因为什么得到了什么？"
```

## 三、认知偏见清单（决策陷阱）

### 3.1 常见的认知偏见

```
偏见1：确认偏见（Confirmation Bias）
  只看支持自己观点的信息，忽视相反的证据
  
  例子：买了某股票，只看利好的新闻
  酒店版本：签了一个合同，只想它的好处

偏见2：损失厌恶（Loss Aversion）
  失去¥100的痛苦 > 获得¥100的快乐
  
  实验：50%概率赢¥1000，100%概率赢¥500 → 大多数人选确定性的¥500
      50%概率输¥1000，100%概率输¥500 → 大多数人选赌一把

  酒店版本：
    "这个合作可能亏¥20万" → 损失厌恶 → 放弃 → 错过机会
    或者：
    "已经投了¥50万，如果现在停损失更大" → 沉没成本 → 继续投 → 亏更多

偏见3：锚定效应（Anchoring）
  第一个数字会锚定你的判断
  
  例子：原价¥1000打折到¥600，你会觉得便宜
      但如果原价本来是¥400，这就是贵
  
  酒店版本：谈判时谁先出价，谁就锚定了后面的讨价还价

偏见4：过度自信（Overconfidence）
  90%的司机认为自己的驾驶水平在前50%
  70%的创业项目认为自己会成功（实际<30%）
  
  酒店版本：
    "这个店的地理位置很好，肯定能火"
    "我做过这么多年酒店，这个项目肯定没问题"
    → 用数据验证，而不是直觉

偏见5：现状偏见（Status Quo Bias）
  改变现状的风险 > 维持现状的风险（心理上）
  
  酒店版本：
    "现在的OTA结构已经用了5年，换一个新的太麻烦"
    → 即使新结构明显更好，也倾向于维持
```

### 3.2 对抗认知偏见的工具

```
工具1：红队策略（Red Team）
  在决策前，故意找一个"唱反调"的人
  
  操作：
    决策前 → 找一个你认为最聪明、观点最独立的人
    要求他列出"这个决策失败的10个理由"
    认真对待每一条，不要反驳
    
工具2：预注册失败（Pre-Mortem）
  决策前，想象这个项目已经失败了
  
  操作：
    想象1年后，这个项目彻底失败了
    写下3个失败的最可能原因
    问自己：我现在能做什么来防止这些原因？

工具3：10-10-10法则（应对损失厌恶）
  10分钟后：这个决策感觉如何？
  10个月后：这个决策还重要吗？
  10年后：这个决策还有意义吗？
  
  帮助把情绪拉回到理性视角
```

## 四、决策流程实战

### 4.1 重大决策的checklist

```
第一步：问题定义（5分钟）
  □ 我要解决的核心问题是什么？（不是表面问题）
  □ 这个问题必须解决吗？不解决会怎样？
  □ 这是我的能力圈吗？

第二步：信息收集（不限时间，但设上限）
  □ 我需要什么信息？
  □ 谁有这些信息？
  □ 信息的可靠性如何？
  □ 哪些信息是多余的？（避免信息过载）

第三步：第二层思维分析（30分钟）
  □ 所有人都知道这个信息吗？
  □ 大多数人会怎么决策？
  □ 这个决策的激励是什么？
  □ 有什么风险是我没有考虑的？

第四步：概率和期望值（30分钟）
  □ 最好的3种结果是什么？概率多少？
  □ 最坏的3种结果是什么？概率多少？
  □ 期望值是正的吗？
  □ 我的最大损失能承受吗？

第五步：逆向归纳（30分钟）
  □ 5年后看这个决策，重要吗？
  □ 从终局倒推，我今天应该做什么？
  □ 是否有不可逆的步骤？（先做可逆的）

第六步：决策记录
  □ 写下我的决策和理由
  □ 设定检查点（什么时候回来看这个决策）
  □ 记录我的假设（哪些假设如果错了，决策就要改）
```

### 4.2 决策质量评分（事后复盘）

```
每次重大决策后，24小时内复盘：

评分维度（每项1-5分）：
  1. 信息质量：我的信息够全面吗？来源可靠吗？
  2. 分析质量：我用了第二层思维吗？
  3. 概率估计：我的概率判断准吗？
  4. 执行质量：我的执行计划清晰吗？

分数解读：
  - 12-15分：优秀决策
  - 8-11分：良好，但有改进空间
  - 4-7分：存在重大缺陷，需要学习
  - <4分：需要系统性改进决策流程

关键问题：
  - 哪些假设是错的？为什么我当时没发现？
  - 如果重来，我会做什么不同？
  - 这个错误以后如何避免？
```

## 五、跨学科核心模型速查

```
当你面对不熟悉的领域时，使用这些模型：

经济学模型：
  - 机会成本（做任何事都有替代选项的成本）
  - 边际思维（增量改变，而不是整体改变）
  - 规模效应（为什么大玩家有优势）

心理学模型：
  - 认知偏见清单（见3.1）
  - 社会认同（为什么从众不一定是错的）
  - 稀缺心智（越稀缺的东西越被高估）

物理学模型：
  - 熵增（系统自发走向混乱，需要能量维持秩序）
  - 临界质量（达到某个点后会自增强）
  - 平衡态（系统最终会趋向平衡）

生物学模型：
  - 适应度景观（一个解决方案好不好，取决于环境）
  - 路径依赖（历史决定现在，现在限制未来）
  - 生态位（找到自己的独特竞争优势）

工程学模型：
  - 冗余设计（关键系统需要备份）
  - 破窗效应（小问题不修会引来大问题）
  - 约减（把复杂问题简化到核心要素）
```

## 六、与博弈论的互补关系

```
博弈论适用场景：
  - 有明确对手（投资人/竞争者/合作方/员工）
  - 对方也在做决策（相互依存）
  - 信息不对称但可推断

Mental Models适用场景：
  - 无明确对手（自己在做战略选择）
  - 面对不确定性（不知道未来会怎样）
  - 认知陷阱（情绪/偏见干扰判断）

张实的决策地图：
  ┌─────────────────────────────────────┐
  │           没有对手，只有不确定性        │
  │              ↓                      │
  │      Mental Models（概率/逆向/能力圈） │
  │              ↓                      │
  │  ┌─────────────────────────────┐    │
  │  │     涉及人际博弈？            │    │
  │  └─────────────────────────────┘    │
  │         是 ↓         否 → 决策完成   │
  │         ↓                            │
  │   叠加博弈论（均衡/激励/承诺机制）     │
  │              ↓                       │
  │         决策完成                      │
  └─────────────────────────────────────┘
```
