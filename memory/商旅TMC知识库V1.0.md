## 一、TMC基础认知

### 1.1 什么是TMC

**TMC = Travel Management Company（差旅管理公司）**

```
定义: 专门为企业提供差旅管理服务的第三方公司

核心价值:
├─ 集中采购酒店、机票等资源
├─ 提供一站式预订和报销服务
├─ 差旅数据分析与优化建议
└─ 7×24小时人工服务
```

### 1.2 TMC vs 传统旅行社

| 对比项 | 传统旅行社 | TMC |
|--------|----------|------|
| **服务对象** | 散客/团队 | 企业客户 |
| **核心能力** | 资源整合 | 差旅管理 |
| **收费模式** | 佣金/服务费 | 管理费+佣金 |
| **数据能力** | 弱 | 强（差旅分析） |
| **技术对接** | 无 | OB四大TP（在线预订工具）|
| **服务时间** | 工作时间 | 7×24 |

### 1.3 TMC在中国的发展

```
2000前: 外资TMC进入（HRG、Amex）
       → 主要服务外资500强

2000-2010: 国内TMC萌芽
           → 阿里商旅、差旅天下等

2010-2020: 平台化发展
           → 滴滴企业、美团企业
           → TMC平台化、透明化

2020-现在: 数字化+AI转型
            → 在线签到、无接触服务
            → AI客服、数据分析
```

## 二、TMC商业模式

### 2.1 三种收费模式

```
┌─────────────────────────────────────────────────────────────┐
│                     TMC收费模式                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【模式1: 佣金模式（传统）】                                │
│  ├─ TMC从供应商（酒店/航司）获取佣金                        │
│  ├─ 企业无需额外付费                                       │
│  ├─ 风险: 佣金可能影响推荐客观性                          │
│  └─ 现状: 逐渐被取代                                      │
│                                                             │
│  【模式2: 管理费模式（主流）】                            │
│  ├─ 企业支付固定管理费或按交易收费                         │
│  ├─ TMC推荐最优化（不收佣金）                            │
│  ├─ 费率: 机票约30-50元/张，酒店约3-5%                   │
│  └─ 现状: 外资客户主流                                   │
│                                                             │
│  【模式3: 净价模式（新兴）】                             │
│  ├─ TMC以底价拿房，溢价卖给企业                          │
│  ├─ 企业获得透明价格                                      │
│  ├─ 差价=TMC利润                                        │
│  └─ 现状: 国内平台常用                                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 差旅管理价值链

```
企业差旅流程:
预订 → 出行 → 报销 → 数据 → 优化

各环节价值:
├─ 预订: 一站式预订（机票+酒店+用车）
├─ 出行: 7×24应急服务
├─ 报销: 自动化报销、对账
├─ 数据: 差旅成本分析、优化建议
└─ 优化: 供应商谈判、政策合规
```

### 2.3 酒店与TMC结算方式

```
【现付】
├─ 客人前台现付
├─ TMC与酒店月结
└─ 最常见模式

【预付】
├─ TMC提前支付
├─ 客人入住时无需付款
└─ 价格更优

【协议价结算】
├─ 酒店给企业协议价
├─ TMC按协议价结算
└─ 需签协议
```

## 三、RFP招标流程

### 3.1 什么是RFP

**RFP = Request for Proposal（招标邀请书）**

```
定义: 企业邀请TMC提交服务方案的正式流程

时机:
├─ 年度合同到期
├─ 新建差旅政策
├─ 现有TMC服务不满意
└─ 企业扩张、员工增加
```

### 3.2 RFP关键评估维度

```
┌─────────────────────────────────────────────────────────────┐
│                   TMC RFP评估维度                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【价格】30%                                                │
│  ├─ 服务费率                                               │
│  ├─ 酒店/机票折扣                                        │
│  └─ 隐藏费用（改签费等）                                  │
│                                                             │
│  【服务】25%                                                │
│  ├─ 响应速度（目标:<15分钟）                             │
│  ├─ 7×24可用性                                           │
│  └─ 专人vs客服中心                                        │
│                                                             │
│  【技术】25%                                                │
│  ├─ OBT易用性                                             │
│  ├─ 系统对接能力（ERP/OA）                               │
│  └─ 数据报表能力                                          │
│                                                             │
│  【资源】20%                                                │
│  ├─ 酒店覆盖                                             │
│  ├─ 航线资源                                             │
│  └─ 用车资源                                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.3 酒店应对RFP要点

```
【酒店作为TMC供应商的应对】

1. 了解TMC评估标准
   → 知道TMC用什么标准评估酒店

2. 准备资质文件
   → 营业执照、税务登记
   → 消防证明、特殊资质
   → 客房数量、会议室规格

3. 提供有竞争力价格
   → 给出TMC专属协议价
   → 佣金额外计算
   → 淡旺季价格政策

4. 承诺服务标准
   → 响应时间
   → 保留房保障
   → 取消政策
   → VIP接待

5. 提供数据支持
   → 历史入住数据
   → 客人评分
   → 竞品对比
```

## 四、OB4连接技术

### 4.1 什么是OB4

**OB4 = Online Booking Tool（在线预订工具）**

```
定义: 企业员工自助预订差旅产品的系统

组成:
├─ 差旅政策引擎（自动合规）
├─ 酒店/机票/用车预订
├─ 审批流程
└─ 报销对接

主流OB4:
├─ Concur (SAP旗下)
├─ 钉钉差旅
├─ 企业微信差旅
└─ 美团企业
```

### 4.2 酒店与OB4对接方式

```
【方式1: 直连TMC】
├─ 通过TMC接口直接对接
├─ 实时房态/价格
├─ 确认更快
└─ 技术成本较高

【方式2: 通过GDS】
├─ 通过Sabre/Amadeus/Galileo
├─ GDS覆盖广
├─ 但酒店需付GDS费
└─ 约15-25美元/间夜

【方式3: 通过聚合平台】
├─ 接入旅划算 hotelbeds等
├─ 库存聚合
├─ 技术简单
└─ 利润空间受限
```

### 4.3 直连技术要点

```
直连收益:
├─ 实时价格更新
├─ 即时确认
├─ 避免超售
├─ 数据可控

技术对接要素:
├─ API接口文档
├─ 酒店CRS/PMS支持
├─ 房型/价格代码对应
└─ 订单状态同步

TMC常见接口要求:
├─ AvailRQ (查询可用房)
├─ RatesRetrieveRS (价格查询)
├─ HotelResNotifRQ (订单确认)
├─ CancelNotifRQ (取消确认)
└─ ReadNotifRQ (入住/离店状态)
```

## 六、酒店-TMC合作实战

### 6.1 酒店如何获取TMC客户

```
【主动获取TMC】
1. 参加TMC供应商招募
   → 关注TMC官网供应商注册
   → 参加酒店采购展会

2. 准备供应商资料包
   → 酒店介绍PPT
   → 协议价格单
   → 服务承诺书
   → 资质文件清单

3. 谈判协议条款
   → 价格折扣
   → 佣金比例
   → 保留房数量
   → 取消政策
   → VIP接待标准

【被动接收TMC询价】
1. 收到RFP时
   → 按时提交完整资料
   → 价格有竞争力
   → 承诺可兑现

2. TMC临时询价
   → 快速响应
   → 提供最优价
   → 争取留下好印象
```

### 6.2 酒店协议模板要素

```
【酒店-企业协议核心条款】

□ 协议双方信息
  → 酒店名称、地址
  → 企业名称、联系人

□ 适用房型及价格
  → 豪华房协议价
  → 高级房协议价
  → 行政楼层协议价
  → 含早/不含早价格

□ 优惠条款
  → 折扣比例（如: 门市价8折）
  → 升级政策
  → 欢迎礼遇

□ 保留房政策
  → 保留房数量
  → 免费取消时限
  → 超额保留费

□ 结算条款
  → 现付/月结
  → 结算周期
  → 发票要求

□ 服务承诺
  → 响应时间
  → VIP接待
  → 投诉处理

□ 协议期限
  → 生效日期
  → 到期日期
  → 续约条款
```

### 6.3 酒店收益优化策略

```
【协议客户收益管理】

1. 协议定价策略
   ├─ 了解企业往年消费额
   ├─ 给予适当折扣（而非最低价）
   └─ 保留高价值客户高价空间

2. 淡旺季差异
   ├─ 旺季: 协议价接近前台价
   └─ 淡季: 协议价更优惠，拉动入住

3. 多店联动
   ├─ 集团内多店参与
   └─ 一站式服务，增加黏性

4. 数据驱动
   ├─ 分析企业入住数据
   ├─ 了解入住偏好
   └─ 主动推荐更适合的房型

5. 长期关系维护
   ├─ 年度拜访
   ├─ VIP接待
   └─ 新产品推荐
```

## 七、AI对TMC的冲击

### 7.1 TMC面临的挑战

```
【OTA平台冲击】
├─ 携程、美团直接预订更方便
├─ 价格透明度高
└─ TMC附加价值被质疑

【企业自建趋势】
├─ 大企业直接对接供应商
├─ 自建差旅系统
└─ 绕过TMC

【价格内卷】
├─ 酒店直接放协议价
├─ TMC议价能力下降
└─ 利润空间压缩

【技术迭代】
├─ 在线化冲击传统服务模式
└─ AI客服替代人工
```

### 7.2 TMC的应对

```
【数字化转型】
├─ 升级OB4平台
├─ 移动端优化
└─ 系统对接能力

【增值服务】
├─ 差旅咨询
├─ 数据分析
├─ 政策设计
└─ 合规审计

【垂直深耕】
├─ 行业专业化
├─ 地区深耕
└─ 特定客群服务

【AI赋能】
├─ AI客服（7×24）
├─ 智能推荐
├─ 自动化报销
└─ 预测性分析
```

### 7.3 酒店的机会

```
【TMC代理渠道之外的机会】

1. 直连企业
   ├─ 企业协议直销
   ├─ 企业官网/APP预订
   └─ 会员体系

2. OTA平台
   ├─ 携程企业版
   ├─ 美团商旅
   └─ 高德酒店

3. 新兴渠道
   ├─ 小程序预订
   ├─ 抖音/微信生态
   └─ 私域流量

4. AI Agent入口
   ├─ 未来可能通过AI管家预订
   ├─ 布局AI渠道
   └─ 数据对接
```
