## 一、TMC基础认知

### 1.1 什么是TMC

**TMC = Travel Management Company（差旅管理公司）**

```
定义: 专门为企业提供差旅管理服务的第三方公司

核心价值:
├─ 集中采购酒店、机票等资源
├─ 提供一站式预订和报销服务
├─ 差旅数据分析与优化建议
└─ 7×24小时人工服务
```

### 1.2 TMC vs 传统旅行社

| 对比项 | 传统旅行社 | TMC |
|--------|----------|------|
| **服务对象** | 散客/团队 | 企业客户 |
| **核心能力** | 资源整合 | 差旅管理 |
| **收费模式** | 佣金/服务费 | 管理费+佣金 |
| **数据能力** | 弱 | 强（差旅分析） |
| **技术对接** | 无 | OB四大TP（在线预订工具）|
| **服务时间** | 工作时间 | 7×24 |

### 1.3 TMC在中国的发展

```
2000前: 外资TMC进入（HRG、Amex）
       → 主要服务外资500强

2000-2010: 国内TMC萌芽
           → 阿里商旅、差旅天下等

2010-2020: 平台化发展
           → 滴滴企业、美团企业
           → TMC平台化、透明化

2020-现在: 数字化+AI转型
            → 在线签到、无接触服务
            → AI客服、数据分析
```

## 二、TMC商业模式

### 2.1 三种收费模式

```
┌─────────────────────────────────────────────────────────────┐
│                     TMC收费模式                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【模式1: 佣金模式（传统）】                                │
│  ├─ TMC从供应商（酒店/航司）获取佣金                        │
│  ├─ 企业无需额外付费                                       │
│  ├─ 风险: 佣金可能影响推荐客观性                          │
│  └─ 现状: 逐渐被取代                                      │
│                                                             │
│  【模式2: 管理费模式（主流）】                            │
│  ├─ 企业支付固定管理费或按交易收费                         │
│  ├─ TMC推荐最优化（不收佣金）                            │
│  ├─ 费率: 机票约30-50元/张，酒店约3-5%                   │
│  └─ 现状: 外资客户主流                                   │
│                                                             │
│  【模式3: 净价模式（新兴）】                             │
│  ├─ TMC以底价拿房，溢价卖给企业                          │
│  ├─ 企业获得透明价格                                      │
│  ├─ 差价=TMC利润                                        │
│  └─ 现状: 国内平台常用                                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 差旅管理价值链

```
企业差旅流程:
预订 → 出行 → 报销 → 数据 → 优化

各环节价值:
├─ 预订: 一站式预订（机票+酒店+用车）
├─ 出行: 7×24应急服务
├─ 报销: 自动化报销、对账
├─ 数据: 差旅成本分析、优化建议
└─ 优化: 供应商谈判、政策合规
```

### 2.3 酒店与TMC结算方式

```
【现付】
├─ 客人前台现付
├─ TMC与酒店月结
└─ 最常见模式

【预付】
├─ TMC提前支付
├─ 客人入住时无需付款
└─ 价格更优

【协议价结算】
├─ 酒店给企业协议价
├─ TMC按协议价结算
└─ 需签协议
```

## 三、RFP招标流程

### 3.1 什么是RFP

**RFP = Request for Proposal（招标邀请书）**

```
定义: 企业邀请TMC提交服务方案的正式流程

时机:
├─ 年度合同到期
├─ 新建差旅政策
├─ 现有TMC服务不满意
└─ 企业扩张、员工增加
```

### 3.2 RFP关键评估维度

```
┌─────────────────────────────────────────────────────────────┐
│                   TMC RFP评估维度                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【价格】30%                                                │
│  ├─ 服务费率                                               │
│  ├─ 酒店/机票折扣                                        │
│  └─ 隐藏费用（改签费等）                                  │
│                                                             │
│  【服务】25%                                                │
│  ├─ 响应速度（目标:<15分钟）                             │
│  ├─ 7×24可用性                                           │
│  └─ 专人vs客服中心                                        │
│                                                             │
│  【技术】25%                                                │
│  ├─ OBT易用性                                             │
│  ├─ 系统对接能力（ERP/OA）                               │
│  └─ 数据报表能力                                          │
│                                                             │
│  【资源】20%                                                │
│  ├─ 酒店覆盖                                             │
│  ├─ 航线资源                                             │
│  └─ 用车资源                                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.3 酒店应对RFP要点

```
【酒店作为TMC供应商的应对】

1. 了解TMC评估标准
   → 知道TMC用什么标准评估酒店

2. 准备资质文件
   → 营业执照、税务登记
   → 消防证明、特殊资质
   → 客房数量、会议室规格

3. 提供有竞争力价格
   → 给出TMC专属协议价
   → 佣金额外计算
   → 淡旺季价格政策

4. 承诺服务标准
   → 响应时间
   → 保留房保障
   → 取消政策
   → VIP接待

5. 提供数据支持
   → 历史入住数据
   → 客人评分
   → 竞品对比
```

## 四、OB4连接技术

### 4.1 什么是OB4

**OB4 = Online Booking Tool（在线预订工具）**

```
定义: 企业员工自助预订差旅产品的系统

组成:
├─ 差旅政策引擎（自动合规）
├─ 酒店/机票/用车预订
├─ 审批流程
└─ 报销对接

主流OB4:
├─ Concur (SAP旗下)
├─ 钉钉差旅
├─ 企业微信差旅
└─ 美团企业
```

### 4.2 酒店与OB4对接方式

```
【方式1: 直连TMC】
├─ 通过TMC接口直接对接
├─ 实时房态/价格
├─ 确认更快
└─ 技术成本较高

【方式2: 通过GDS】
├─ 通过Sabre/Amadeus/Galileo
├─ GDS覆盖广
├─ 但酒店需付GDS费
└─ 约15-25美元/间夜

【方式3: 通过聚合平台】
├─ 接入旅划算 hotelbeds等
├─ 库存聚合
├─ 技术简单
└─ 利润空间受限
```

### 4.3 直连技术要点

```
直连收益:
├─ 实时价格更新
├─ 即时确认
├─ 避免超售
├─ 数据可控

技术对接要素:
├─ API接口文档
├─ 酒店CRS/PMS支持
├─ 房型/价格代码对应
└─ 订单状态同步

TMC常见接口要求:
├─ AvailRQ (查询可用房)
├─ RatesRetrieveRS (价格查询)
├─ HotelResNotifRQ (订单确认)
├─ CancelNotifRQ (取消确认)
└─ ReadNotifRQ (入住/离店状态)
```

## 六、酒店-TMC合作实战

### 6.1 酒店如何获取TMC客户

```
【主动获取TMC】
1. 参加TMC供应商招募
   → 关注TMC官网供应商注册
   → 参加酒店采购展会

2. 准备供应商资料包
   → 酒店介绍PPT
   → 协议价格单
   → 服务承诺书
   → 资质文件清单

3. 谈判协议条款
   → 价格折扣
   → 佣金比例
   → 保留房数量
   → 取消政策
   → VIP接待标准

【被动接收TMC询价】
1. 收到RFP时
   → 按时提交完整资料
   → 价格有竞争力
   → 承诺可兑现

2. TMC临时询价
   → 快速响应
   → 提供最优价
   → 争取留下好印象
```

### 6.2 酒店协议模板要素

```
【酒店-企业协议核心条款】

□ 协议双方信息
  → 酒店名称、地址
  → 企业名称、联系人

□ 适用房型及价格
  → 豪华房协议价
  → 高级房协议价
  → 行政楼层协议价
  → 含早/不含早价格

□ 优惠条款
  → 折扣比例（如: 门市价8折）
  → 升级政策
  → 欢迎礼遇

□ 保留房政策
  → 保留房数量
  → 免费取消时限
  → 超额保留费

□ 结算条款
  → 现付/月结
  → 结算周期
  → 发票要求

□ 服务承诺
  → 响应时间
  → VIP接待
  → 投诉处理

□ 协议期限
  → 生效日期
  → 到期日期
  → 续约条款
```

### 6.3 酒店收益优化策略

```
【协议客户收益管理】

1. 协议定价策略
   ├─ 了解企业往年消费额
   ├─ 给予适当折扣（而非最低价）
   └─ 保留高价值客户高价空间

2. 淡旺季差异
   ├─ 旺季: 协议价接近前台价
   └─ 淡季: 协议价更优惠，拉动入住

3. 多店联动
   ├─ 集团内多店参与
   └─ 一站式服务，增加黏性

4. 数据驱动
   ├─ 分析企业入住数据
   ├─ 了解入住偏好
   └─ 主动推荐更适合的房型

5. 长期关系维护
   ├─ 年度拜访
   ├─ VIP接待
   └─ 新产品推荐
```

## 七、AI对TMC的冲击

### 7.1 TMC面临的挑战

```
【OTA平台冲击】
├─ 携程、美团直接预订更方便
├─ 价格透明度高

【企业自建趋势】
├─ 大企业直接对接供应商

【价格内卷】
├─ 酒店直接放协议价
├─ TMC议价能力下降
└─ 利润空间压缩

【技术迭代】
```

```
【增值服务】
├─ 差旅咨询
```

| **外国人在华入境** | 2026 年 1–8 月外国人入境 **6128.7 万人次**，同比 +19.5%；其中免签入境 2372 万人次，占入境外国人总量 **77.6%** | 国家移民管理局 |
| **机票退改专项团体标准** | 中国航协牵头制定，计划年内发布；要求售票平台与航司官方渠道在**支付前强制公示**退改费率、限制条件与免费退改场景 | 年内 |
| **市内交通费包干** | 财政部答复：单位人员到异地出差期间在固定场所办公、未实际产生交通费用的几天，**仍可按每人每天 80 元**领取市内交通费包干使用 | 2026-10 |

### 3. 供给侧：结构性碎片化是 TMC 最大痛点

**美运通（American Express GBT）视角**（商旅数字化峰会圆桌）：

- **机票端**：全球约 **75 家航司**获得 NDC 授权，虽有标准接口，但每家航司的接口、产品与售后都不同，TMC 接入并统一推送给企业客户难度很高。运通目前可供 22 家航司的 NDC，约 16000 家客户采用；国内已接入约 185 家 LCC 内容与 18 家航司 NDC 产品。
- **酒店端更散**：国际集团、各国本土集团、大量单体酒店 + Airbnb 等新型住宿，**并非所有集团都进 GDS**，在中国大量资源其实看不到。运通全球覆盖 200 多万家酒店；在中国与德比软件合作，经 Sabre 接入国际酒店、直连几十家中国酒店集团。
- **运通的定价体系逻辑**（值得 TMC 与酒店侧同时记住）：不是做酒店资源库，而是**以客户协议价为核心、以运通协议价和直连价补充、再以 OTA 价格加强**。

**上游 B2B 供应商浮现**：喜玩中国披露直采酒店达 **7.8 万家**、年销售间夜 2000 万以上、服务企业客户超 2 万家，定位 **TMC 上游的 B2B 库存与 API 直连供应商**。

**对 AHL 的直接含义**：碎片化正是去中心化网络能吃掉的部分——**"不进 GDS 的中国单体与区域集团资源"恰恰是 AHL 协议层的天然供给**。这不是锦上添花，而是 AHL 的核心战场定义。

### 4. 客户需求侧：从"向后报"到"向前管"

**Business Travel Show America**（2026-10-14~15，纽约 Javits Center）调研 200+ 家美洲企业差旅买家，TMC 数据供给缺口 Top 5：

| 数据缺口 | 占比 |
|---------|------|
| 预测与预测性洞察（forecasting / predictive）| **34.65%** |
| 旅客行为与偏好 | 32.67% |
| 合规与政策泄漏数据 | 28.71% |
| 供应商绩效 | 28.22% |
| 实时旅客追踪 | 23.76% |

- 仅 **16%** 的买家称其 TMC 提供了全部所需数据，**39%** 提供大部分，**42%** 对 TMC 提供的数据不完全满意。
- Zillow 高级差旅项目经理 Tami Pharr 的原话值得抄进 KB：「项目被要求**向前管理**，而不是向后汇报——这是完全不同的数据需求。」
- 她的第二层判断更关键：**数据质量**与数据类别同等重要——已有的数据若不干净、不一致、定义不统一，缺的那几类也不值钱。AI 放大后，分析层跑得比数据层快，缺口因此更刺痛。
- 展会同期主题为 AI 与数据治理，参展商含 Amadeus Cytric、Blockskye、Cerebri AI、Cirium、Clarasight、Grasp、Oversee、PredictX、Serko、Travelport 等。

**对 AHL 的直接含义**：TMC 的数据层普遍缺位，**这正是协议层可以沉淀"订单—行为—合规"数据流的位置**。谁掌握流量的底层数据，谁就掌握下一层的定价权。

### 5. 竞争格局

- **携程商旅**：覆盖全球 196 个国家，多语言服务、多币种结算，115+ 国家商务签证服务；产品分层为标准版 / 集采版 / 国际版 / 旗舰版；**AI 开放平台采用分层开放体系**（标准层—成长型企业快速验证 AI 价值，高级层—中型企业系统集成，定制层—大型企业/国央企/外资企业深度定制）；与钉钉、企业微信、飞书集成，支持基础数据、审批预订、财务对账三大类接口；与豆包办公等平台深化 AI 生态对接。定位从"差旅管理服务商"转为"**企业差旅 AI 生态构建者**"。
- **美运通**：NDC 深度建设 + 全球酒店资源整合 + 客户协议价体系。
- **中国航协**：退改标准制定者，扮演规则供给方角色。
- **酒店集团亲自下场**：锦江上半年商旅 GMV +31.5%，价格体系、房型体系、渠道体系同步重做，并加速向高成长性中小企业客群渗透。→ **酒店集团正在直做商旅渠道，AHL 要么成为其协议侧接口，要么被绕开。**

### 6. 成本侧变量

**2026-10-10 起国内航线燃油附加费上调**：800 公里（含）以下航段调整为 50 元（+10 元），800 公里以上调整为 90 元（+20 元）。对年出差 1000 次的企业，仅此一项年增支出 1–2 万元。企业侧应对：**建立提前预订机制避开票价高峰 + 把周期性调价节点纳入差旅预算模型**。

### 7. 对本 KB 框架的校准

| 原框架假设 | 2026-10 证据 | 校准 |
|-----------|--------------|------|
| 酒店资源统一进 GDS 即可解决 | 大量单体与区域集团**不进 GDS** | 碎片化是常态，**协议直连是长期基础设施** |
| 差旅管理的价值是"省钱" | 客户首要缺口是**预测**（34.65%），不是价格 | 价值主张上移到**预测与合规洞察** |
| TMC 报表能满足管理需求 | 42% 买家对 TMC 数据不完全满意 | 客户**自建分析层**，TMC 只提供管道 |
| 机票资源是核心壁垒 | NDC 已把 75 家航司标准化 | 机票壁垒在**航司直连与售后能力**，不在资源数量 |
| 酒店侧被动等待 TMC 接入 | 酒店集团自建商旅渠道（锦江 +31.5%）| 酒店必须**主动建协议侧能力** |
