## 1. 协议标准化窗口识别 → 新技能方向

**场景**: 在多个协议同时进入标准化加速期时，自动识别并输出"协议设计+协议竞赛"分析框架

**判断标准**（3 个指标同时满足）:
1. **数量指标**: N ≥ 2 个独立协议在 T ≤ 30 天内进入标准化阶段
2. **质量指标**: 至少有 1 个协议获得头部玩家（巨头/开源社区/标准组织）背书
3. **差异指标**: 各协议在 L 层（应用/语义/传输）有不同专注点

**用法**:
```python
# 当判断某领域进入"标准化加速期"时
def protocol_window_check(domains):
    """
    domains: [
        {"name": "AI Agent", "protocols": ["LangChain", "Agora", "SPG"]},
        ...
    ]
    """
    for domain in domains:
        std_count = count_protocols_in_standardization(domain.protocols)
        if std_count >= 2:
            return f"协议竞赛窗口开启: {domain.name}"
```

**应用实例**:
- 8/9 识别：AI Agent 领域 = LangChain Agent Protocol + Agora + SPG = **协议竞赛窗口开启**
- AHL Agent Protocol 应从 V0.1 升级到 V0.5（协议设计 + 行业语义层）
