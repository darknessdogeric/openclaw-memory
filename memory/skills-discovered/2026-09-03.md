### Skill-001：卖铲人-用铲人时滞门控方法（Pickaxe-Timing Mismatch Gate）

**问题域**：在 AI/技术基础设施爆发期，如何判断应用层入场时机？

**方法（三步决策树）**：

```
Step 1: 卖铲人业绩扫描
  ├─ 卖铲人（基础设施供应商）同比增速 > 100% 持续 2 个季度？
  │   ├─ ✅ YES → 进入 Step 2
  │   └─ ❌ NO → 等待，重复 Step 1
  │
Step 2: Gartner 曲线位置
  ├─ AI 智能体/应用层在"期望膨胀期"？
  │   ├─ ✅ YES（保守者场景）→ 等到"幻灭期"再入场
  │   ├─ ⚠️ YES（进取者场景）→ 立即启动 MVP
  │   └─ ❌ NO（在"幻灭期"或更早）→ 已晚 18 个月
  │
Step 3: 应用层头部估值信号
  ├─ 头部 AI 应用公司估值 6 个月内翻倍（如 Cursor $600亿、Cognition $470亿）？
  │   ├─ ✅ YES → 用户采纳信号确认，应用层爆发启动
  │   └─ ❌ NO → 还在卖铲人单边行情，应用层未启动
```

**当前信号（2026-09-03）**：
- Step 1：博通 +221%、戴尔翻3倍、浪潮 +270% ✅
- Step 2：AI 智能体在期望膨胀期（Gartner 9/3 曲线）⚠️ → **进取者场景**
- Step 3：Cursor $600亿 + Cognition $470亿 ✅

**AHL 决策矩阵**：
- 卖铲人 ✅ + 进取者场景 + 应用层头部 ✅ = **立即启动 MVP**（最激进）
- 卖铲人 ✅ + 保守者场景 + 应用层头部 ✅ = 等到幻灭期再启动（晚 6-12 个月）
- 卖铲人 ❌ + 任何场景 = 继续等待

**关键洞见**：R163 卖铲人-用铲人时滞 ≠ R162 AI 发现层元规则。
- R162 = 静态识别（"AI-native 平台入侵了什么品类"）
- R163 = 动态识别（"应用层 vs 基础设施层的时滞窗口")

**类比案例**：
- 2010 年 AWS 业绩爆发 → 2013-2015 SaaS 应用层爆发（3-5 年时滞）
- 2010-2012 提前布局 SaaS 的玩家 = 7-10 倍回报（如 Salesforce/Workday）
- 2014-2015 才入场 = 估值已高，回报降为 2-3 倍
- 2016+ 才入场 = 红海，无回报

**触发场景**：
- 每次面对"现在该不该启动 X 项目（应用层）"的决策时
- 每次听到"AI 卖铲人业绩爆炸"信号时
- 每次读到 Gartner 曲线更新时

**反例（不该触发）**：
- 卖铲人业绩下滑期（如 2023 半导体下行周期）
- 应用层已进入成熟期（如电商/外卖行业）
- 没有明确的"卖铲人-用铲人"对应关系（如消费品/服务业）
