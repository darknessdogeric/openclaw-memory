> 当前执行：B166ER 倾向「加权平均」或「多源并行」→ Eric 否定，应「最权威单源」。

**v1.1 子条款草案**：

```
R66 v1.1 单源优先原则（Single-Source Precedence）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
触发: 多源数据冲突时（≥2 源给出不同数值/结论）
默认执行: 最权威单源（非多源调和/加权平均）
权威源优先级（自上而下）:
  1. 财报（Eric 提供 / 上市公司公告）
  2. 工商登记 / 平台官方数据（携程 / 飞猪 / 美团）
  3. 行业基准 / 估算（仅作 fallback）
不适用:
  - 时间序列数据（必须多源验证趋势）
  - 主观判断类（仍需 Eric 拍板）
证据: 2026-09-16 R300 实战
验证状态: v1.1 草案，待 Eric 确认
```

**应用价值**：
- 节省 B166ER 在多源冲突时的反复纠结
- 与 R297 数据源三档优先级协同（R297 是数据「真实度」分级，R66 v1.1 是冲突时「优先级」）
