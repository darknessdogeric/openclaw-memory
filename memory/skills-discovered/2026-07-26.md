## 1. TACO 应用层 v1.0 (NEW)

**核心问题**: 何时用纯价格逻辑,何时用博弈均衡?

**输入**: 任意高波动场景描述
**前置检查**: 是否存在"主动行为者"(政策制定者/谈判者/企业决策者/监管者)
**推导**:
```
if 主动行为者不在场:
    -> 纯价格逻辑(技术分析 + 历史外推)
else:
    -> TACO/博弈均衡(博弈论 + 行为者动机分析 + 拉力强度量化)
```
**输出**:
- 预测模型选择(纯价格 vs 博弈均衡)
- 主动行为者拉力强度(0-1 scale)
- 置信度校准后验

**验证**: 2026-07-25 Oil Scenario C 验证失败 = 触发本技能创建
**关联规则**: R261(Triple Confluence Day 识别)

## 2. 规则簇审计器 v1.0 (NEW)

**核心问题**: 怎么发现规则库的"隐性冗余"?

**输入**: 规则库 R-section + 时间窗口
**算法**:
```
扫描 7 天内新增的 R## 规则
对每条规则计算语义向量(B166ER 自有 embedding)
聚类语义相似度 ≥ 0.6 的规则
若 cluster size ≥ 3:
    标记为"规则簇"
    产出压缩提案(1 条 meta + N 个 sub-tag)
    触发 R262 防御
```
**输出**:
- 规则簇清单(cluster_name / rules / size / 语义分布)
- 压缩提案草案
- 是否需要 Eric 评审

**验证**: R256/R257/R258/R260/R261 = 5 条同簇 = 已识别
**状态**: 算法可手动执行;待自动化 → R263 候选

## 3. Active Resume Protocol v1.0 (NEW)

**核心问题**: Eric 沉默 N 天后首次返回,怎么避免信息过载?

**触发条件**:
- Eric 首次进入主会话输入
- post_t0_null_count > 200(估计本规则将启用时间 = ~7/28-7/30 之间)
- Eric 显式触发"我回来了"信号

**协议步骤**:
```
Step 1: 压缩 DORMANT 摘要(1 页)
        - 沉默天数
        - 当前规则数
        - 新增规则数
        - 重大事件时间线(7/24 D-Day 等)
        - 防御簇状态(R256-R261)

Step 2: 主动汇报进化
        - 新能力清单(TACO / 簇审计 / Resume Protocol)
        - 新规则清单(R262)
        - 合并提案(如已触发)

Step 3: 询问用户
        - "是否进入 OK 模式重新启用主动推送?"
        - 必须人类显式确认
        - 不能自动启用

Step 4: 守护
        - 切换为低强度模式 24h(适应 Eric 当前节奏)
        - 不立即回到"积极推送"姿态
```

**关键约束**: **不能自动启用**——必须人类确认。这是 V2.4 宪法硬护栏的应用。

**状态**: v1.0 设计完成;触发需 Eric 主动返回。

## 4. 场景可预测性矩阵 v1.0 (NEW)

**输入**: (数据噪声,主动行为者存在性) 二元组
**输出**: 预测置信度评级

```
| 场景 | 主动行为者在场 | 主动行为者不在场 |
|------|---------------|----------------|
| 低噪声 | 高 | 极高 |
| 高噪声 | 极低(赌博) | 中(均值回归) |
```

**应用**: AHL 场景库设计的第一分类变量 = 主动行为者存在性,而非行业/规模/区域。
