04 / 07 · 现状 A

04现状 A：通用 vs 垂直（LLM / Agent）

维度通用大模型 / 通用 Agent垂直领域版
训练方式 互联网海量通用语料
预训练 + 通用对齐		 行业语料 + 私域数据
行业微调 / 继续预训练
能力边界 什么都懂一点
什么都不精		 单赛道深度领先
术语、流程、规则内行
数据合规 公开数据为主
无合规负担		 涉行业敏感数据
脱敏 / 私有化部署
商业价值 通用能力
差异化低、易被替代		 流程可固化
直接对接业务结果
判断：通用模型是"底座"，垂直模型/Agent 才是"收钱的那一层"——价值在行业深度，不在参数规模。
05 / 07 · 现状 B

05现状 B：云端 Agent vs 本地 Agent

维度云端 Agent（API）本地 Agent（私有化 / 端侧）
算力成本 按调用付费
规模上去后费用陡增		 一次性硬件投入
边际成本趋近于零
数据安全 数据出域 数据不出内网，可满足强监管
响应速度 受网络与排队影响
长任务中断风险		 低时延，离线可用
模型能力 最强前沿模型
持续自动升级		 受本地算力限制
需自行选型维护
判断：不是二选一，而是混合部署——通用推理走云端，敏感数据与关键流程留本地。
