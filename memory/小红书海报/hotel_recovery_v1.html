06底层逻辑：这不是周期上行

旧 范 式 · 增量时代
需求爆发 + 供给无序扩张
→ 普涨 → 过剩 → 价格战
→
新 范 式 · 存量时代
需求平淡 + 供给主动收缩
→ 出清更快 → K 型分化 → 头部集中
中国饭店协会《2026 酒店业发展报告》：K 型分化 —— 头部/中高端/生活方式酒店增长，非连锁单体承压。
所谓「中高端成主要增长驱动」，是低端产能退出后中高端相对份额被动上升，不是需求爆发。
