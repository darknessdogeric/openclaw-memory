02 / 06 · 概念谱系

026 个核心概念，一层层包上去

AI 人工智能 1956
让机器表现出"智能"的统称。1956 达特茅斯会议正式命名。
ML 机器学习 1980s
不手工写规则，改成"喂数据自己学规律"。AI 的第一次实用化。
DL 深度学习 2012
多层神经网络。AlexNet 一战成名，之后横扫图像与语音。
LLM 大语言模型 2020
千亿参数规模的文本模型，本质是"预测下一个词"。ChatGPT 让它出圈。
Agent 智能体 2023
会拆解任务、会调工具、能多步执行。从"回答问题"变成"替你做事"。
AGI 通用人工智能 ?
像人一样跨领域学习迁移。尚未实现，路径与时间点争议极大。
03 / 06 · 历史沿革

0370 年：从"机器能思考吗"到 Agent

1950
图灵测试
"机器能思考吗"——可证伪性的起点，AI 的哲学原点
1956
达特茅斯会议
"Artificial Intelligence"正式命名，学科诞生
2012
AlexNet 引爆深度学习
ImageNet 识别率碾压传统方法，AI 第二次春天
2017
Transformer 架构
注意力机制替代 RNN，可大规模并行——LLM 的技术母体
2020
GPT-3 涌现能力
1750 亿参数，少样本学习显能力涌现，LLM 路线确立
2022
ChatGPT 发布
两个月破 1 亿用户，AI 进入大众视野
2024+
Agent 时代
工具调用、多步执行、长程任务，从对话走向干活
04 / 06 · 当下现状

042026 现状：能力普及，可靠性待解

✓ 已兑现的
· LLM 能力商品化，不再是壁垒
· Agent 从 demo 进生产环境
· 多模态：文/图/音/视频一体
· 推理成本年降 10 倍级
✗ 仍未解决
· 长任务累积误差，可靠性不足
· 幻觉与事实核查仍是难题
· 训练数据时效性衰减
· 长上下文成本依然高
05 / 06 · 未来 5 年

052026 → 2031：四个方向

2027
Agent 自治化
从"每步指挥"到"目标交付"，长任务成功率是关键指标
2028
具身智能
AI 进入物理世界，机器人 + 大模型结合落地
2029
多智能体协作

2031?

核心判断：AI 的下半场不在"更聪明"，而在更可靠——可靠性、成本、可验证性，才是产业化的真门槛。
