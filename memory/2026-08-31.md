### 8. R295 / R299 双规则深化

**R295（行业基准双维度匹配）回顾**：
- 核心：行业基准必须匹配业态 + 地域
- 应用：国堰宾馆是温泉度假 → 必须用温泉度假基准（不是商务酒店基准）

**R299（通用基准陷阱）核心洞察**：
- 通用行业基准"看起来更权威" → 实际比没有基准更危险
- 给人虚假精确感：数字存在但与标的完全不匹配
- 无基准 = 知道自己不知道（可接受）
- 错基准 = 不知道自己不知道（不可接受）

**触发条件（满足任一则触发）**：
| 条件 | 危险等级 |
|------|---------|
| 业态不匹配（度假 vs 商务/城市）| 🔴 高 |
| 地域不匹配（川渝 vs 全国/华东）| 🔴 高 |
| 定位不匹配（高奢 vs 经济型）| 🔴 高 |
| 时间不匹配（2023 数据用于 2026）| 🟡 中 |
| 数据粒度不匹配（集团 vs 单店）| 🟡 中 |

**正确做法**：
1. 首先搜索 anyi-ops-kb 已有沉淀（地域/业态特定基准）
2. 其次搜索行业 KB（Hotel-Industry-KB/川渝/川西/度假）
3. 最后用通用基准（并明确标注"无特定基准，使用通用参考"）

**错误做法**：
- ❌ 直接用戴德梁行/STR 全国通用基准（无匹配度声明）
- ❌ 用通用基准让报告"看起来更权威"（虚假精确）
- ❌ 认为"有第三方数据" = "数据可信"（忽略了匹配度）

**验证记录**：
- ✅ v7.0 → v8.0：全国通用基准 → 川渝温泉度假特定基准（通用→特定）
