# 酒店总经理（GM）每日工作手册

> 定位：Eric的核心能力——知道一个GM每天在什么时间做什么、想什么
> 版本：v1.0 | 2026-04-09
> 原则：不是理论框架，是真实的一天，每个小时做什么

---

## 核心认知：GM的角色是什么

**GM不是经理，是"首席问题解决官"。**

```
酒店每天会发生无数件事，但只有一件事真正重要：
——今天有没有一件事，如果没有GM的介入，会变得更糟？

如果有，那件事就是GM今天必须做的事。
```

**GM的三个核心任务**：
1. **让昨天的问题不再发生**（运营管理）
2. **让明天的机会不被错过**（战略管理）
3. **让团队相信这件事值得做**（人的管理）

---

## 一天工作地图

```
06:00 早餐巡查 ← 开始感知今天
07:30 早会 ← 信息汇集
08:30 运营巡查 ← 走动管理
09:30 办公室处理 ← 决策和审批
11:00 重点客户跟进 ← 收入来源
12:00 午餐观察 ← 团队感知
14:00 重点事项 ← 战略时间
16:00 下午运营巡查 ← 晚高峰准备
17:00 VIP/特殊安排 ← 重要关系维护
18:00 晚餐/应酬 ← 外部关系
21:00 夜间巡查 ← 安全确认
22:00 复盘 ← 明天待办
```

## 06:00-07:30：早晨感知

### 06:00 起床后30分钟

**GM不看手机，先看这三样东西**：

```
1. 昨夜的入住记录（revenue report by night audit）
   - 实际入住多少间？OCC多少？
   - 有没有跑单/拒付？
   - 有没有重大投诉？

2. 今早的预抵名单
   - 有没有VIP？有没有长住客？
   - 预计入住多少间？ADR预期是多少？

3. 今早的气象/重大事件
   - 今天本地有什么重大活动/展览？
   - 今天天气如何？会影响本地客流吗？
```

**为什么这个顺序**：先知道昨天怎样，再看今天怎样，最后看外部环境。不是看财务报表，是感知"今天和昨天有什么不同"。

### 06:30 早餐出品巡查

**这是GM每天最重要的走动管理时间。**

```
巡查内容：
□ 自助餐出品：温度够不够？品种齐全吗？补货及时吗？
□ 餐厅环境卫生：地面干净吗？桌面整洁吗？气味正常吗？
□ 服务员状态：精神面貌如何？有没有打瞌睡的？
□ 客人满意度：有没有投诉的？有没有明显不满意的？
□ 客流量：7点和8点的客人数量差别大吗？（判断早高峰峰值）

发现问题的处理原则：
- 立即能改的，立即改（叫领班/厨师长过来）
- 不能立即改的，记录下来，7:30早会说
- 如果连续两天出现同一问题 → 这是管理问题，不是偶发问题
```

**为什么06:30而不是07:00？**
- 6:30是早餐高峰期前，还有时间调整
- 7:00之后GM出现，服务员会紧张，看到的是"紧张状态"而不是"正常状态"

### 07:30 每日早会

**这是酒店一天中最重要的信息汇集时刻。**

```
参会人员：值班经理 + 各部门经理/领班（站立会议，不超过15分钟）
主持：值班经理或GM
格式：不说废话，只说三件事

【第一部分】昨天怎么样（数据说话）
- 昨天OCC/ADR/RevPAR
- 昨天餐饮收入
- 昨夜的投诉（2分钟内说完）
- 昨夜的重大事件（跑单/投诉升级/设备故障）

【第二部分】今天要关注什么（预判风险）
- 今天预抵多少？VIP是谁？
- 今天有没有大型团队/会议？
- 今天本地有什么活动？
- 天气预报→会影响什么？（下雨→本地客流↑，商务客流↓）

【第三部分】今天必须完成的事（不超过3件）
- 优先级：P1 = 必须今天解决，P2 = 今天尽量解决
- 每个P1只能有1-2件，超过说明没有优先级
- GM布置的任务不能超过3件，多了下属会一件都做不好

早会的铁律：
- 不超过15分钟
- 不讨论解决方案（细节是部门经理的事）
- GM不代替部门经理做决定（除非是紧急的）
```

## 08:30-09:30：走动管理

### 08:30 客房楼层巡查

**GM每个月至少要有10次亲自上楼层巡查。**

```
巡查清单（抽查3-5间房）：
□ 房门：有没有灰尘？门牌清晰？
□ 进门：气味怎么样？（霉味/烟味/清新剂味）
□ 床铺：整洁度？床单有没有毛发？
□ 卫生间：毛巾够不够？有没有水渍？备品齐全吗？
□ 小冰箱：有价格表吗？有没有过期食品？
□ 窗户/阳台：干净吗？有没有安全隐患？

发现问题的处理：
- 立即拍照+时间戳（不是发朋友圈，是留证据）
- 发给客房部经理（不是服务员）→ "这间是几号？今天谁负责？"
- 客房部经理的回复速度和态度 = 这个经理的管理水平
```

**走动管理的核心目的**：不是发现问题，是通过问题看到**谁应该负责**，以及**那个人是否在状态**。

### 09:30 前厅/前台暗访

**GM每年至少有50次以"普通客人"身份去前台。**

```
暗访内容：
□ 进门时有没有员工主动问候？
□ 前台员工的精神面貌？（制服整洁/妆容/站姿）
□ 办理入住的速度？（行业标准：3分钟内）
□ 有没有使用"十字礼貌用语"？
□ 等待超过2分钟有没有致歉？

如果你是"暗访"的GM：
- 不要暴露身份（除非发现了重大问题）
- 离开后再联系前台经理反馈
- 反馈要具体：几点几分，谁，第几个窗口，发生了什么
```

## 09:30-11:00：决策时间

### 09:30-10:30 办公室处理

**这是GM最能创造价值的时间，也是最容易被干扰的时间。**

**保护决策时间的方法**：
```
- 这1小时不接非紧急电话
- 微信/钉钉消息在这1小时内不看
- 除非是安全问题，否则不打断

这个时间GM在做什么？

□ 审批文件（P&L/合同/人事）
□ 和财务对账（今天的收款/昨天的收入）
□ 和销售总监review本周的协议客户签约情况
□ 准备今天的VIP接待
□ 处理昨天留下的"未完成"事项
```

**Eric的核心洞察**：
> GM每天最大的敌人不是问题，是"时间碎片化"。
> 任何一个员工都能打断你，但只有你自己能保护你的决策时间。

### 10:30-11:00 大客户/重要关系跟进

**酒店收入的40-70%来自前10个协议客户。**

```
跟进内容：
□ 拜访/电话联系前5个重要客户（每月至少1次）
□ 跟进正在谈的协议合同（不要等合同到期才续签）
□ 处理客户的投诉（这是关系维护最重要的时刻）
□ VIP客人的抵离店安排（重要客人必须亲自迎接）

一个技巧：
- 不要只在客人"需要酒店"的时候联系
- 在客人不需要酒店的时候联系 = 真正建立关系
- 例如：问问客户公司最近怎么样，有没有什么需要提前安排的
```

## 11:00-14:00：中午运营

### 12:00 午餐观察

```
观察内容：
□ 餐厅上座率（和早餐比有变化吗？）
□ 翻台速度（中餐通常90分钟，翻台快=投诉少）
□ 服务质量（点菜/上菜/结账是否顺畅）
□ 有没有投诉的客人？（服务员能处理还是需要经理？）
□ 客人的表情（是享受还是忍耐？）

如果餐厅有投诉：
- GM要不要亲自去处理？→ 取决于投诉的严重程度
- 普通投诉：服务员/领班处理 → GM出现反而让客人有压力
- 升级投诉：客人说要找经理 → GM出面是尊重客人
- 严重投诉（食物中毒/人身伤害）→ GM必须出面
```

### 13:30 午间休息/保持精力

**酒店GM的精力管理是最被低估的能力。**

```
Eric的精力管理原则：
- 酒店工作时间是6am-10pm，中间没有真正的休息
- 但中午必须给自己30分钟"放空"时间
- 不是睡觉，是不看手机，不接电话，不处理工作
- 哪怕坐在车里发呆20分钟，也比连续工作6小时强

为什么：
- 下午2-4点是决策质量最低的时候（餐后困倦）
- 如果中午不充电，傍晚的决策质量会明显下降
- GM的每个决策都涉及几万/几十万的钱，不能在不清醒的时候做
```

## 14:00-17:00：战略时间

### 14:00-16:00 这2小时是酒店最重要的战略时间

**这个时间GM在处理最重要的事。**

```
□ 和业主/投资人的沟通
  - 每周至少1次正式沟通
  - 每月要有书面的经营报告
  - 遇到问题第一时间通报（不要等业主来问）

□ 团队管理
  - 和核心下属（销售总监/前厅经理/厨师长）1对1沟通
  - 不是开会，是谈心
  - "你最近遇到什么困难？""我能帮你做什么？"

□ 收益管理决策
  - 查看未来14天的预定量（是多了还是少了？）
  - 如果少了，原因是？（竞品？季节？价格？）
  - 今天要不要调价？要不要放特价？

□ 巡查问题跟进
  - 早上发现的问题有没有解决？
  - 解决了 → 记录，下次巡查时确认是否保持
  - 没解决 → 找原因（能力问题/态度问题/资源问题）
```

### 16:00 下午楼层巡查

```
这是晚高峰前最后的检查机会。

巡查内容：
□ 晚高峰的人员排班对了吗？
□ 餐厅准备好了吗？
□ 婚宴/会议有确认吗？
□ 工程设备运转正常吗？（电梯/空调/热水）

发现的问题：
- 如果影响今晚的收入 → 立即解决
- 如果不影响今晚 → 记录，明天早会说
```

## 17:00-22:00：晚间管理

### 17:00 VIP接待

```
VIP接待的核心：
- 重要客人 = 酒店未来收入的保障
- 亲自迎接 = 尊重 + 了解 + 维护关系

VIP接待SOP：
□ 提前了解：客人的喜好/习惯/忌口
□ 房间准备：欢迎信/水果/特殊要求
□ 迎接：至少大堂副理以上人员
□ 沟通：GM至少10分钟交谈（不是敷衍，是真的了解）
□ 跟进：离店后24小时内发感谢短信/微信
```

### 18:00-20:00 晚餐/应酬

```
酒店GM的社交时间大多在饭桌上。

应酬的原则：
- 不醉酒（GM在紧急情况必须清醒）
- 不收礼（这顿饭吃的是工作关系，不是私人友谊）
- 记录每个人的名字和公司（酒店销售必备技能）
- 每次应酬后写下：谁、什么时候、聊了什么、承诺了什么

Eric的观察：
- 会吃饭的GM，每年多签5-10个协议客户
- 不会吃饭的GM，吃完就吃完了，没有积累任何关系
```

### 21:00 夜间安全巡查

```
这是很多GM忽略的时间，但往往能发现问题。

巡查内容：
□ 大堂安保到位了吗？
□ 电梯运行正常吗？
□ 消防通道畅通吗？
□ 各区域的灯光正常吗？
□ 客房噪音（深夜有没有投诉？）
□ 夜班值班人员的精神状态

如果有夜班员工在打瞌睡：
- 立即叫醒 + 记录
- 如果连续2天出现同一员工 → 这个员工需要被处理
- 如果连续2天出现不同员工 → 排班/管理有问题
```

### 22:00 每日复盘

```
复盘不用写下来，但要想清楚：

□ 今天最重要的决定是什么？ → 做对了吗？
□ 今天最不应该发生的事情是什么？ → 谁应该负责？
□ 明天必须解决的一件事是什么？ → 只能有一件P0
□ 明天有客人需要特别注意吗？ → VIP/难缠的/重要的
□ 我今天对下属发过火吗？ → 发火之后有没有道歉？
□ 我今天做了一件让团队骄傲的事吗？ → 如果没有，明天做一件

复盘的意义：
不是自责，是知道明天怎么做得更好。
```

## GM年度核心KPI（不是给业主看的那个）

```
这个KPI不是为了完成任务，是真正衡量"酒店健康"的指标：

【月度核心指标】
□ OCC vs 去年同期（+2%以上才算健康）
□ GOP vs 预算（不低于预算的95%）
□ 会员复购率（>25%算良好）
□ 投诉解决满意度（>80%算良好）
□ 员工流失率（<3%/月算良好）

【季度核心指标】
□ 协议客户续约率（>70%算良好）
□ 新签协议客户数（每季度至少新增5个）
□ 会员新增数（每季度增长>10%）
□ OTA评分（携程>4.6，Tongcheng>4.5）
□ 员工满意度（每半年调查一次）

【年度核心指标】
□ 年度GOP vs 预算（反映整体经营能力）
□ 资本支出执行（翻新/维护计划完成率）
□ 品牌标准达标（如果是加盟品牌）
□ 团队稳定性（核心岗位流失率<15%）
```

## GM最重要的三件事（年度视角）

```
第一件事：让团队相信这个酒店值得付出

团队看到的是什么：
- GM每天几点到？（如果GM每天8点才出现，团队不会拼命）
- GM愿不愿意处理脏活累活？（还是只在漂亮的地方出现）
- GM对客人热情还是对上级热情？（团队都在看）

第二件事：让酒店有"性格"

客人为什么选你家而不是隔壁：
- 价格？品牌？位置？ → 这些都不是护城河
- "这家酒店的XX让我印象深刻" → 护城河

第三件事：在最好的时候卖掉

酒店的资产价值是有周期的：
- 开业1-3年：还在爬坡，不适合卖
- 开业5-7年：最佳状态，资产价值最高
- 开业10年+：设备老化，需要翻新，否则进入衰退期
- GM的任务：在第5-7年把酒店带到最佳状态
```

## GM每日时间分配参考

```
走动管理（巡查/观察）： 2-3小时
会议（早会/部门会/1对1）： 1.5-2小时
决策处理（文件/审批/邮件）： 1.5-2小时
客户关系（拜访/电话/应酬）： 1.5-2小时
危机处理（投诉/突发）： 不固定，平均1-2小时
战略规划（收益管理/团队）： 1小时

总计：8-12小时/天（酒店GM的现实）
```
