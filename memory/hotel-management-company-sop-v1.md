## 一、酒店管理公司本质

```

│                                                             │
│  盈利模式:                                                 │
```

## 三、委托管理模式SOP

### 3.1 委托管理本质

```
委托管理模式:
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  定义: 业主投资酒店，委托酒管公司管理                      │
│                                                             │
│  双方关系:                                                  │
│  ├── 业主: 投资、拥有产权                                  │
│  ├── 管理方: 专业运营、输出品牌                          │
│  └── 合同期: 通常10-20年                                 │
│                                                             │
│  管理方职责:                                                │
│  ├── 品牌使用                                               │
│  ├── 人员派驻                                               │
│  ├── 运营管理                                               │
│  ├── 质量标准                                               │
│  └── 客源输送                                               │
│                                                             │
│  收费模式:                                                  │
│  ├── 基本管理费: 营业收入的2-4%                           │
│  ├── 奖励管理费: 营业利润的5-10%                          │
│  ├── 系统使用费: 固定+按房间                             │
│  └── 采购佣金: 采购额的3-5%                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 八、委托vs特许经营对比

### 8.1 模式对比

| 维度 | 委托管理 | 特许经营 |
|------|---------|---------|
| 投资 | 业主全资 | 业主全资 |
| 品牌 | 输出品牌 | 授权品牌 |
| 经营 | 管理方负责 | 业主自主 |
| 人员 | 管理方派驻 | 业主自聘 |
| 风险 | 共担 | 业主承担 |
| 收益 | 基本+奖励 | 固定加盟费 |
| 合同期 | 10-20年 | 5-10年 |
| 管控深度 | 深度管控 | 监督管控 |

### 8.2 适用场景

```
委托管理适用:
├── 高端/奢华酒店
├── 新品牌打造
├── 业主无经验
└── 追求品牌价值

特许经营适用:
├── 经济型/中端酒店
├── 成熟品牌扩张
├── 业主有经验
└── 追求快速复制
```
