## 大乐透预测标准操作规程（SOP）

**规则制定时间**：2026-03-30
**触发指令**：「继续体彩大乐透」「给我预测号码」「预测大乐透」等

### 操作流程

1. **加载历史数据**
   - 数据文件：`workspace/tools/lotto_predictor_v11.py`
   - 预测脚本：`workspace/tools/lotto_xxxx.py`（每期新建，文件名含期号）
   - 最近10期历史开奖数据存储在脚本内 `RECENT_DRAWS` 列表

2. **执行预测命令**
   ```bash
   py tools/lotto_xxxx.py
   ```
   - 每次预测生成**5注**
   - 使用统计模型 V1.1（5区覆盖 + 冷热平衡 + 和值/跨度约束）

3. **输出格式**
   - 显示热号/冷号分析
   - 5注号码列表（含和值/跨度/奇偶/大小分析）
   - 声明：彩票为随机事件，理性购彩

4. **存档**
   - 预测结果自动保存到 `lotto_prediction_YYYYMMDD_HHMMSS.txt`
   - 脚本存档到 `tools/lotto_YYYYMMDD.py`

### 核心统计模型 V1.1

**约束条件**：
- 和值：80-120（理想区间70-130）
- 跨度：12-32
- 奇偶比：2:3 或 3:2
- 大小比：2:3 或 3:2（以18为界）
- 5区覆盖至少4区
- 连号不超过1组

**策略**：
- 5区强制覆盖（3区选热号，2区选冷号）
- 后区奇偶平衡策略
- 避免与最近5期重复
