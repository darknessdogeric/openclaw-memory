```

│  │ ├── 2000s: 爆发期 → 连锁品牌跑马圈地                         │ │
```

```
│  │ ├── 委托管理将向三四线下沉                                 │ │

│  │ └── 委托管理是"品牌溢价-运营能力-风险共担"的交易，          │ │
│  │     本质是让专业的人做专业的事，让资本获得匹配回报          │ │

│  │ 底层逻辑:                                                      │ │
│  │ └── 特许经营是"标准复制-本地适应-利益共享"的平衡，         │ │
```
