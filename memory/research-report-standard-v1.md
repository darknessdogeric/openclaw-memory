> 版本: V1.0
> 创建: 2026-04-14
> 来源: 综合分析25+份酒店行业研报 + 投行研报方法论
> 用途: 所有研究报告的标准格式模板
> 触发词: 研报/研究报告/行业报告/市场分析/调研报告

## 一、研报类型体系

### 1.1 四大研报类型

```
类型A：行业深度报告（Industry Deep Dive）
  - 最重量级，全面系统
  - 结构最完整，数据最详尽
  - 代表：毕马威《中国酒店业的韧性之路》/ JLL《酒店投资市场报告》

类型B：月度/季度追踪报告（Monthly Tracker）
  - 轻量级，持续追踪
  - 结构统一，高度格式化
  - 代表：迈点研究院月度发展报告

类型C：项目/标的可研报告（Due Diligence）
  - 针对单一标的
  - 财务/运营/风险三维度
  - 代表：仲量联行酒店资产尽调报告

类型D：竞品/品牌分析报告（Competitive Intelligence）
  - 横向对比
  - 多维度打分
  - 代表：各酒店集团对标分析
```

### 1.2 四大研报共用框架

```
┌─────────────────────────────────────────────┐
│                 执行摘要                      │
│  核心结论（3条以内）+ 关键数据 + 行动建议     │
├─────────────────────────────────────────────┤
│                 数据封面                      │
│  关键指标一览（5-8个核心数字）               │
├─────────────────────────────────────────────┤
│                 正文框架                      │
│  PEST宏观 → 行业现状 → 竞争格局 → 趋势判断  │
│                   ↓                          │
│               投资/运营建议                    │
├─────────────────────────────────────────────┤
│                 数据附录                      │
│  原始数据 / 附表 / 来源索引                  │
└─────────────────────────────────────────────┘
```

## 二、执行摘要标准写法

### 2.1 执行摘要的核心原则

```
原则1：3句话原则
  - 第1句：核心结论（市场机会/问题/趋势）
  - 第2句：支撑结论的关键数据（1-2个数字）
  - 第3句：行动建议（给谁看就为谁服务）

原则2：倒三角结构
  最重要的放最前面，不要铺垫

原则3：去形容词
  不用"显著/明显/稳步"等模糊词
  用具体数字和对比说话
```

### 2.2 执行摘要模板

```
【执行摘要】

核心发现：
1. [最大发现，用数字支撑]
2. [第二发现，用数字支撑]
3. [第三发现，用数字支撑]

关键数据：
  - [KPI 1]: XXX（同比+XX%）
  - [KPI 2]: XXX（环比-XX%）
  - [KPI 3]: XXX（较2019年+XX%）

行动建议：
  [受众]: [具体建议，动词开头]

数据来源: [机构名称] | 时间: [YYYY-MM]
```

## 三、数据封面标准

### 3.1 核心指标卡

每份研报必须有"数据封面"——让读者30秒内掌握核心数据。

```
┌──────────────────────────────────────────────────────┐
│           [报告名称] 关键指标速览                    │
├──────────┬──────────┬──────────┬──────────┬─────────┤
│ 指标1    │ 指标2    │ 指标3    │ 指标4    │ 指标5   │
│  X万间   │  X%      │  X元    │  X亿    │  X个月  │
│ 同比+X%  │ 环比-X%  │  较19年  │  预测值  │  变化   │
└──────────┴──────────┴──────────┴──────────┴─────────┘
```

### 3.2 时间标注规范

```
数据时效性标注（必须标注）：

  🟢 新鲜（<3个月）: 直接使用
  🟡 有效（3-12个月）: 标注"数据截至YYYY-MM"
  🔴 过时（>12个月）: 不使用，或标注"数据有延迟，需核实"

预测标注：
  实际数据: 字体正常
  预测数据: 加粗 + 标注"[预测]"
  估算数据: 加粗 + 标注"[估算]"
```

## 四、行业深度报告结构（PEST → 四象限）

### 4.1 完整结构（类型A：行业深度报告）

```
# [报告标题]

## 执行摘要
## 数据封面

## 一、宏观环境（PEST）
  1.1 政策（Policy）
  1.2 经济（Economic）
  1.3 社会（Social）
  1.4 技术（Technology）

## 二、行业现状（市场规模 + 结构）
  2.1 总量与增速
  2.2 档次分布
  2.3 区域分布
  2.4 连锁化率

## 三、竞争格局
  3.1 头部集团矩阵
  3.2 集中度（CR3/CR5）
  3.3 区域渗透率
  3.4 品牌竞争力排名

## 四、核心趋势（3-5条）
  趋势1：[标题] + 数据支撑 + 代表案例
  趋势2：[标题] + 数据支撑 + 代表案例
  ...

## 五、投资/运营建议
  5.1 机会识别
  5.2 风险提示
  5.3 行动建议

## 六、数据附录
```

### 4.2 宏观环境章节标准写法

```
PEST四维度，每维度：

Policy（政策）:
  - 主管部委：文旅部/商务部/发改委
  - 重要政策：十四五/促消费/文旅专项
  - 政策影响：正向/负向/中性
  - 数据支撑：补贴金额/规划目标/限制条款

Economic（经济）:
  - GDP增速/消费增速
  - 居民可支配收入
  - 旅游消费支出
  - 数据源：国家统计局/文旅部

Social（社会）:
  - 出游人次/旅游收入
  - 出行方式变化（商旅/休闲/本地）
  - 消费代际变化（Z世代/中产）
  - 数据源：文旅部/抽样调研

Technology（技术）:
  - 数字化渗透率
  - AI应用成熟度
  - 数据源：石基信息/第三方调研
```

### 4.3 市场规模章节标准写法

```
市场规模表述规范：

"总量 + 增速 + 同比基准" 三要素必须同时具备

示例（正确）：
  2024年中国酒店客房总数1,764万间
  同比增长4.1%，较2019年增长25.1%

  2025年市场规模约5,314亿元
  同比增长38.7%（疫后复苏反弹）

示例（错误）：
  酒店市场规模持续扩大（没有数字）
  表现良好（没有基准）

结构分析必备维度：
  1. 档次结构：经济型/中档/高档/奢华
  2. 区域结构：一线/新一线/二线/三四线
  3. 品类结构：酒店/民宿/公寓/露营
```

## 五、月度追踪报告结构（类型B）

### 5.1 月度追踪报告标准结构

```
# YYYY年M月中国酒店业发展报告

## 执行摘要（500字以内）
  - 本月核心变化（1句话）
  - 关键数据（3个数字）
  - 下月预判（1句话）

## 一、行业动态
  1.1 高管动态（任命/离职）
  1.2 集团动态（融资/并购/战略）
  1.3 政策动态

## 二、运营数据
  2.1 头部集团经营数据（表格）
      - 集团 | OCC | ADR | RevPAR | 同比
  2.2 供需指标（月度）

## 三、开业与签约
  3.1 本月新开业（列表+档次/品牌/地点）
  3.2 本月新签约（列表+数量统计）

## 四、资产交易（如有）
  4.1 挂牌/拍卖项目
  4.2 成交项目
  4.3 流拍项目

## 五、品牌指数
  （迈点MBI指数，当月各档次TOP10）

## 六、下月展望
```

### 5.2 月度数据表格标准格式

```
| 集团/品牌 | 类型 | 本月新开 | 累计开业 | 本月签约 | 储备项目 | 关键事件 |
|-----------|------|---------|---------|---------|---------|---------|
| 华住集团  | 综合 | 320家   | 12,400家 | 280家   | 3,200家 | 海外扩张 |
| 锦江酒店  | 综合 | 280家   | 13,513家 | 220家   | 2,800家 | 卢浮拖累 |
```

## 六、竞品分析报告结构（类型D）

### 6.1 竞品分析标准框架

```
# [竞品名称] vs [对标竞品] 对比分析

## 执行摘要
  - 核心差异（1句话）
  - 最大差距（1个数字）
  - 可借鉴点（1条）

## 一、规模对比
  1.1 门店数/客房数/覆盖城市
  1.2 规模增速对比

## 二、产品对比
  2.1 品牌矩阵（档次分布）
  2.2 产品标准化程度
  2.3 创新产品案例

## 三、运营对比
  3.1 OCC/ADR/RevPAR对比
  3.2 GOP Margin对比
  3.3 会员体系对比

## 四、财务对比
  4.1 收入/利润/增速
  4.2 估值倍数（上市可比）
  4.3 成本结构

## 五、战略对比
  5.1 扩张策略（加盟vs直营）
  5.2 数字化策略
  5.3 国际化策略

## 六、综合评分
  | 维度       | 竞品A | 竞品B | 权重 |
  |-----------|-------|-------|------|
  | 规模       |  8    |  7    | 20%  |
  | 运营效率   |  7    |  8    | 25%  |
  | 盈利能力   |  8    |  6    | 25%  |
  | 品牌力     |  7    |  9    | 15%  |
  | 数字化能力 |  9    |  7    | 15%  |
  | **加权总分** | **7.8** | **7.2** | 100% |
```

## 七、可研/尽调报告结构（类型C）

### 7.1 酒店资产尽调标准结构

```
# [酒店名称] 投资尽调报告

## 执行摘要
  - 资产价值判断（高于/低于报价）
  - 核心风险（1-2条）
  - 投资建议（可行/有条件/不建议）

## 一、资产概况
  1.1 位置与交通（地铁/商圈/竞争半径）
  1.2 建筑与房间数据（建筑面积/客房数/餐厅/会议）
  1.3 品牌与管理合同（品牌方/管理模式/合同年限）

## 二、运营数据（近3年）
  2.1 OCC/ADR/RevPAR（与市场指数对比）
  2.2 GOP Margin趋势
  2.3 客源结构（商务/休闲/OTA占比）
  2.4 在线评分（携程/美团/booking）

## 三、财务数据（近3年）
  3.1 收入明细（客房/餐饮/其他）
  3.2 成本明细（人工/能耗/物耗）
  3.3 NOI/GOP/EBITDA
  3.4 财务健康度（负债率/利息保障倍数）

## 四、估值分析
  4.1 Cap Rate估值（与可比交易对比）
  4.2 DCF估值（假设条件）
  4.3 可比交易倍数（EV/EBITDA）

## 五、风险评估
  | 风险类型 | 风险描述 | 影响程度 | 发生概率 | 应对措施 |
  |---------|---------|---------|---------|---------|
  | 竞争风险 | 半径3km内新增3家竞品 | 高 | 中 | 差异化定价 |
  | 合同风险 | 品牌合同2027年到期 | 中 | 中 | 提前谈判 |

## 六、投资建议
  6.1 投资亮点
  6.2 投资风险
  6.3 建议条件（价格/改造/合同调整）
```

## 八、写作规范

### 8.1 数字使用规范

```
必须使用：
  - 真实数字（注明数据源）
  - 同比/环比/相对2019年三种基准
  - 区间估计（用"约X亿"而非精确到个位）

禁止使用：
  - "显著提升/明显改善"（用具体百分比替代）
  - "表现良好/差强人意"（用数字替代）
  - 预测数字不加"[预测]"标注

数字呈现优先级：
  1. 绝对值（规模）
  2. 增速（增长质量）
  3. 占比（结构位置）
  4. 排名（竞争位置）
```

### 8.2 图表使用规范

```
必备图表类型：

1. 趋势图（时间序列）
   - 规模/增速变化
   - 格式：柱状+折线组合

2. 结构图（构成分析）
   - 档次分布/区域分布
   - 格式：饼图/环形图/堆叠柱状

3. 对比图（竞品/区域）
   - 多维度并列
   - 格式：分组柱状/雷达图

4. 热力图（矩阵分析）
   - 竞争格局/品牌矩阵
   - 格式：2x2矩阵/热力色块

图表规范：
  - 每张图必须有标题（"YYYY-MM至YYYY-MM中国酒店规模趋势"）
  - 每张图必须标注数据来源
  - 每张图必须有坐标轴单位和数值
  - 色块不超过5种颜色
```

### 8.3 引用和数据来源标注

```
来源分级（按权威性）：

T0（第一来源）:
  - 国家统计局/文旅部官方数据
  - 上市公司财报
  - 交易所公开文件

T1（权威机构）:
  - STR Global（酒店数据）
  - 仲量联行JLL/世邦魏理仕CBRE
  - 中国饭店协会
  - 迈点研究院（MBI指数）

T2（可参考）:
  - 券商研报（注明机构）
  - 咨询公司报告
  - 行业协会数据

T3（需核实）:
  - 媒体报道
  - 企业官方公众号
  - 第三方平台数据（携程/美团）

标注格式：
  数据来源: [机构] | 数据截止: YYYY-MM | 备注: [如有调整说明]
```

## 九、报告输出标准格式

### 9.1 文件命名规范

```
[类型]-[标的]-[时间]-[版本]

### 9.2 报告结构速查

```
□ 执行摘要（核心结论3条 + 关键数据）
