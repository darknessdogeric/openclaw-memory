## 生成方法（可复现）

1. `build2.py`（工作区 `.tmp/poster/`）程序化生成模板：颜色全走 token（`__BG__`/`__FG__`/`__ACC__` 等），替换顺序＝先正文后颜色，渲染前 assert 无占位符残留。
2. 版式预算**先量后定**：用浏览器量出每段自然高度 → 回填段高 → assert 段高和 == 画布高；放不下则字号整体二分缩放；图区高度在放得下的前提下自动撑到最大。
3. 1:1 单独用宽扁版 SVG（viewBox 980×256），否则 980×340 的图塞进扁槽会缩到 0.75×、标注缩到 9.8px 不可读。
4. 架构图为**手写 SVG**（结构/顺序/数量必须准确，AI 生图一定画错）。
5. 渲染后跑 `render-qa.py` 全套：段高预算 / SVG 槽位缩放 / DOM 级版式 / 底色像素校验 / WCAG 对比度 / 40px 缩略 / 圆形裁切 / 整图平面检测。

## 验证结果（2026-11-14）

1. 9 张全部 `PROBLEMS=0`：段高和 == 画布高、无文字溢出、无段落重叠、无内容超段、无元素出画布。
2. 底色像素校验全部 dist=0（该变体自身声明底色，无全黑/串色）。
3. WCAG 对比度：正文 fg 15.2-16.0:1、次要 dim 5.6-6.3:1、强调 accent 4.72-5.63:1，全部 ≥ 4.5:1。
4. 1:1 用宽扁 SVG 后 SVG 有效缩放达标（最小标注实际 ≥ 12.9px）。
5. 目视复验抓到并修掉 1 个机器查不出的缺陷：右侧「群论横切」竖条内两行竖排文字叠印 → 改为两列并排。
