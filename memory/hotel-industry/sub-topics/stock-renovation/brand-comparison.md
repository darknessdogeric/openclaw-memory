## 4. 加盟品牌选择决策树

```
你的物业在哪？
├─ 一线城市核心商圈
│   → 中高端品牌（亚朵/桔子/锦江都城）
│
├─ 一线城市非核心
│   → 中端品牌（全季/维也纳）
│
├─ 二三线城市
│   → 中端品牌（丽怡/星程/柏曼）
│
├─ 四线/县城
│   → 下沉品牌（尚客优/城市便捷）
│
└─ 5-6 线/乡镇
    → 不建议加盟 = 自营或转让
```

## 5. 品牌方"业绩对赌"谈判指南

### 5.1 谈判筹码

| 你的情况 | 谈判筹码 |
|----------|----------|
| 物业位置好 | 高 |
| 现金流充裕 | 高 |
| 团队稳定 | 中 |
| 物业位置差 | 低 |

### 5.2 谈判目标

- ✅ **业绩托底写入合同**（东呈是行业唯一）
- ✅ **解约条件放宽**（如 12 个月可解约）
- ✅ **数据归属**（运营数据归你，不归品牌方）
- ✅ **集采透明**（物料价格清单化）

### 5.3 谈判失败 = 不加盟

如果品牌方：
- ❌ 拒绝业绩对赌
- ❌ 解约条件苛刻（违约金 > 5 万）
- ❌ 数据归属不清
- ❌ 集采价格不透明

**→ 不加盟**（哪怕是知名品牌）

## 7. 行业级判断

### 判断 1：东呈"业绩托底"是行业破冰
- 业主应当**所有品牌都要求**业绩对赌
- 哪个品牌敢承诺 = 值得选
- 哪个品牌不敢 = 谨慎

### 判断 2：下沉市场是 2026 主战场
- 尚客优、柏曼、城市便捷是首选
- 一二线品牌不要硬挤
- 客源匹配比品牌知名度重要

### 判断 3：极速改造 = 节省 60-150 万损失
- 30 天 > 3 个月 > 6 个月
- 时间就是钱

### 判断 4：加盟 ≠ 一劳永逸
- 加盟只是"买了入场券"
- 团队 + 经营 + 现金流 = 业主自己的事
- 加盟失败案例远多于成功案例
