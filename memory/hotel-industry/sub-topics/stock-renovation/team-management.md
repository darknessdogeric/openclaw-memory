# 改造期团队管理

> 改造最大的隐性成本 = 团队
> 一个不稳定的团队 = 改造投入打水漂

---

## 1. 改造期团队的 4 大挑战

### 挑战 1：核心人员流失
- ❌ 改造期 GM 跳槽
- ❌ 主管被挖走
- ❌ 老员工集体辞职
- **原因**：员工对改造没信心 / 被挖角 / 拿到补偿

### 挑战 2：心态不稳
- ❌ "公司要关门了"传闻
- ❌ 担心失业
- ❌ 担心改造后裁员
- **原因**：信息不对称 + 不安全感

### 挑战 3：技能断档
- ❌ 不会用新设备
- ❌ 不会新流程
- ❌ 不会新工具（AI/PMS）
- **原因**：培训没跟上

### 挑战 4：服务断档
- ❌ 客户体验下滑
- ❌ 客诉激增
- ❌ 评分暴跌
- **原因**：人/流程/工具都变了

## 2. 改造前 60 天：锁定团队

### 关键动作

| 时点 | 动作 | 目的 |
|------|------|------|
| **T-60** | 改造项目启动会（含团队）| 透明信息 |
| **T-45** | 核心人员访谈（GM + 主管）| 了解担忧 |
| **T-30** | 团队激励方案发布 | 锁定核心 |
| **T-15** | 改造期工作分配 | 明确责任 |
| **T-0** | 改造启动 | - |

### 核心人员锁定方案

| 角色 | 激励 |
|------|------|
| **GM** | 改造完成奖金 5-10 万 + 期权 |
| **主管** | 改造完成奖金 2-5 万 + 加薪 |
| **关键员工** | 改造完成奖金 1-2 万 + 留任奖 |
| **全员** | 改造完成聚餐 + 奖金池 |

### 关键员工锁定话术（业主原话举例）

> "这次改造是公司的二次创业。你是核心成员。改造成功，你的价值翻倍；改造失败，你也跟着完蛋。所以我们必须一起扛过去。"

## 3. 改造期 90 天：稳定团队

### 关键动作

| 时点 | 动作 | 目的 |
|------|------|------|
| **T+0** | 改造启动仪式 | 团队参与感 |
| **T+15** | 第 1 次团队沟通会 | 信息透明 |
| **T+30** | 现场视察 + 团队慰问 | 凝聚力 |
| **T+60** | 第 2 次团队沟通会 | 解决新问题 |
| **T+90** | 改造完成 + 重开仪式 | 庆祝 |

### 改造期工作分配

| 角色 | 改造期工作 |
|------|-------------|
| **GM** | 总协调 + 业主汇报 + 品牌方对接 |
| **主管（客房）** | 协助施工 + 老客户沟通 |
| **主管（销售）** | OTA 维护 + 客户预热 |
| **前台** | 在线服务（接单/转单）+ 客户通知 |
| **客房** | 协助搬家/整理 + 培训 |
| **工程** | 现场监理 + 隐蔽工程验收 |

### 改造期薪资

| 角色 | 改造期薪资 | 改造后薪资 |
|------|-------------|------------|
| **GM** | 100% 底薪 + 0 提成 | 100% 底薪 + 提成 |
| **主管** | 100% 底薪 | 100% 底薪 + 提成 |
| **前台** | 100% 底薪 | 底薪 + 提成 |
| **客房** | 100% 底薪 | 底薪 + 提成 |

**关键**：改造期不降低底薪（避免员工流失）

## 4. 重开前 30 天：培训团队

### 培训 4 大模块

| 模块 | 内容 | 时长 |
|------|------|------|
| **新设备** | 智能客控/PMS 新功能/AI 工具 | 2 天 |
| **新流程** | 服务流程/客诉处理/应急 | 2 天 |
| **新客群** | 装修后客群可能变化（更年轻/更高端）| 1 天 |
| **心态重置** | 业主亲自讲话 + 团队誓师 | 1 天 |

### 培训形式

- ❌ 不只是"开会讲" = 没用
- ✅ 集中封闭培训 = 强制注意力
- ✅ 角色扮演 = 实战演练
- ✅ 老带新 = 经验传承
- ✅ 培训手册 + 视频 = 复习

## 5. 重开期 30 天：激励团队

### 重开期激励

| 角色 | 激励 |
|------|------|
| **GM** | 重开首月营收 5% 提成 |
| **主管** | 重开首月营收 3% 提成 |
| **前台** | 重开首月营收 1% 提成 |
| **客房** | 重开首月 0.5% 提成 |
| **全员** | 重开首月全员奖金池（5% 营收）|

### 重开关键战役

| 时点 | 战役 | 目标 |
|------|------|------|
| **重开首日** | 媒体宣传 + 客户邀请 | 声量 |
| **重开首周** | OCC 冲 80%+ | 数据 |
| **重开首月** | 评分稳 4.5+ | 质量 |
| **重开 3 月** | 营收超目标 | 信心 |

## 6. 团队稳定的关键数据

### 关键指标

| 指标 | 健康 | 危险 |
|------|------|------|
| **GM 任期** | > 3 年 | < 1 年 |
| **团队流失率** | < 10% | > 30% |
| **客诉率** | < 5% | > 15% |
| **客评分数** | > 4.5 | < 4.0 |
| **客户复购率** | > 30% | < 15% |

### 改造期关键监控

- **每周**：客诉数、OTA 评分
- **每月**：员工流失率、营收、OCC
- **每季**：GM/主管 1v1 谈话

## 7. 团队冲突处理

### 改造期常见冲突

1. **GM vs 业主**："改造预算超了" vs "必须完成"
2. **GM vs 员工**："加班赶工" vs "身体累"
3. **员工之间**："我负责的范围" vs "我不管"
4. **业主 vs 品牌方**："进度" vs "标准"

### 处理原则

- ✅ **业主拍板**：最终决策人
- ✅ **GM 执行**：上传下达
- ✅ **员工执行**：明确职责
- ❌ **老板亲力亲为**：变成员工

## 8. 团队文化重塑

### 改造期"二次创业"文化

| 维度 | 改造前 | 改造后 |
|------|--------|--------|
| **目标** | 维持现状 | 翻倍增长 |
| **节奏** | 慢 | 快 |
| **学习** | 被动 | 主动 |
| **客户** | 等客来 | 主动获客 |
| **数据** | 凭经验 | 数据驱动 |

### 文化重塑 4 步

1. **T-30**：业主讲话，宣布"二次创业"
2. **T+0**：启动仪式（团队宣誓）
3. **T+30**：第 1 次文化落地会
4. **T+90**：第 1 次文化评估 + 修正
