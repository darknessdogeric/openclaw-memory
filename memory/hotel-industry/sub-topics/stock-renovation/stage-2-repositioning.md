# 阶段 2：项目重新定位

> **核心问题**：动了之后，它要"变成什么"？
>
> ⚠️ **业主类型适配**：国央企 = 受集团战略约束 + 价住优先；民营/私营 = 灵活 + 差异化可大。

---

## 0. 业主类型对重新定位的影响

| 业主类型 | 定位自由度 | 典型定位 |
|----------|-----------|----------|
| **国央企** | 低（受集团战略约束）| 服务集团主业（如会议/差旅/养老）+ 标准化 |
| **民营/私营** | 高（可差异化）| 精品酒店 / 主题酒店 / 民宿 / 体验型 |

**国央企提醒**：
- 定位需与集团主业**强相关**（如差旅/会议/养老）
- 不能太"个性化"（怕违反巡视/纪检对"非主业"的要求）
- 位置需在"集团内网络"中考虑

**民营/私营提醒**：
- 可大胆做差异化（精品 / 主题 / 体验型）
- 目标客群可更窄（如"95 后女性"）
- 可加特色服务（24h管家 / 艺术空间 / 主题客房）

---

## 1. 重新定位的 5 个关键维度

| 维度 | 核心问题 |
|------|----------|
| **客群定位** | 谁是我的目标客群？（不能再"全客群"）|
| **价格定位** | 我的 ADR 该定多少？跟谁竞争？|
| **产品定位** | 应该提供什么服务和体验？|
| **品牌定位** | 是什么？中端/中高端/高端/主题/民宿？|
| **差异化** | 跟周边 3km 竞品相比，我独特在哪？|

## 2. 客群定位（3 步）

### Step 1：客群画像分析

| 客群 | 占比估计 | 消费力 | 入住目的 | 复购率 |
|------|----------|--------|----------|--------|
| 商旅客 | | | | |
| 旅游客 | | | | |
| 周边游 | | | | |
| 商务会议 | | | | |
| 其他 | | | | |

### Step 2：客群需求分析

| 客群 | 核心需求 | 附加需求 |
|------|----------|----------|
| 商旅客 | 高速WiFi + 工作桌 + 洗衣 | 会议室/机场接送 |
| 旅游客 | 好位置 + 干净 + 性价比 | 早餐/攻略/行李寄存 |
| 周边游 | 家庭房 + 停车 | 亲子设施/餐饮 |

### Step 3：客群定位决策

- ❌ 目标 = "全客群" → 谁都不满意
- ✅ 目标 = **1-2 个核心客群** + 1-2 个附加客群
- ✅ 核心客群决定**产品方向**、附加客群决定**收入补充**

---

## 3. 价格定位（对比周边竞品）

### 价格区间矩阵

| 定位 | ADR 目标 | RevPAR 目标 | 改造成本系数 |
|------|----------|------------|-------------|
| **经济型升级** | 200-250 | 150-200 | 1x |
| **中端** | 300-400 | 200-280 | 1.5x |
| **中高端** | 500-700 | 350-500 | 2-3x |
| **高端** | 800-1500 | 500-1000 | 4-6x |

### 决定价格的 3 个因素

1. **位置**（20%）：核心商圈 vs 居民区
2. **产品等级**（50%）：软硬件品质
3. **品牌溢价**（30%）：有无知名品牌加持

---

## 4. 产品定位（产品矩阵）

### 客房 + 公共设施 + 服务

| 定位 | 客房 | 公共设施 | 服务 |
|------|------|----------|------|
| 经济型 | 干净 + 基础 | 大厅 | 基础前台 |
| 中端 | 舒适 + 标准 | 大厅 + 早餐 | 标准前台 + 洗衣 |
| 中高端 | 精品 + 品质 | 大厅 + 餐饮 + 会议 | 全套服务 + 礼宾 |
| 高端 | 豪华 + 个性化 | 全套 + SPA/泳池 | 管家服务 |

### 产品定位的关键判断

- ❌ 不要盲目追求"高端"——投入巨大，难以回收
- ✅ 当前市场**需求最大**的是**中端**（性价比最佳）
- ✅ 中高端 = 当周边客群消费力高时才选

---

## 5. 品牌定位（定位声明）

### 定位声明模板

```
[酒店名称] 为 [目标客群] 提供 [核心价值] 的住宿体验。
与 [竞品] 不同，我们通过 [独特差异] 实现了 [核心优势]。
```

### 示例

**中端商务酒店**：
"为成都春熙路商旅客提供高效、干净、互联网化的工作住宿体验。与周边的经济型酒店不同，我们通过**AI 化运营**实现了**省时、省钱、不操心**。"

**中高端精品酒店**：
"为成都文殊院文化旅游客提供沉浸式文化体验。与周边的中端同级酒店不同，我们通过**成都本土文化体验**实现了**住在成都、感受成都**。"

## 6. 差异化（4 个突破口）

| 类型 | 做法 | 成本 |
|------|------|------|
| **服务差异化** | AI 客服/快速入住/免费洗衣 | 中 |
| **体验差异化** | 智能客房/文化体验/当地特色 | 中高 |
| **价格差异化** | 比竞品低 20% / 高 30%（精品）| 低（策略）|
| **渠道差异化** | 抖音/小红书/海外 OTA | 低 |

### 差异化策略 4 步

1. **列出周边 3km 所有竞品**（含它们的客群/价格/产品/品牌）
2. **找到竞品的"盲区"**（它们不做或做不好的）
3. **确定自己可以"做到极致"的 1-2 项**
4. **用"独特定位"来打包这 1-2 项**

---

## 7. 重新定位后验证（3 个测试）

### 测试 1："你给朋友推荐会怎么说？"
- 如果业主能**1 句话说清** = 定位 OK
- 如果说 5 句还说不清 = 定位需打磨

### 测试 2："改造后 3 个月，RevPAR 能到多少？"
- 给出 3 个场景数字 = 定位有数据
- 给不出数字 = 定位太模糊

### 测试 3："竞品看到你会怕吗？"
- 如果 3km 内竞品知道你要改造 → 会感到紧张 → 定位独特
- 如果竞品无所谓 → 定位太普通，跟别人一样

---

## 8. 常见定位误区

1. ❌ **定位 = 改个名字**——定位是产品 + 客群 + 价值主张
2. ❌ **定位 = 降价**——差异化 > 价格战
3. ❌ **定位 = 装修好**——产品是载体，不是定位本身
4. ❌ **定位不变 = 省钱**——改造只改装修不改定位 = 最多省 10%
