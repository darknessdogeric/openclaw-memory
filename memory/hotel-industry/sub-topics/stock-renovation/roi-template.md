> 配合 `decision-tree-extended.md` 使用

---

## 1. 基础公式

### 静态回本周期
```
回本周期 = 改造总投入 / 改造后年净现金流改善
```

### 动态回本周期（NPV）
```
NPV = Σ(年净现金流改善 / (1+r)^t) - 改造总投入
当 NPV = 0 时，t = 动态回本周期
r = 折现率（建议 8-10%）
```

### 投资回报率（IRR）
```
IRR = 使 NPV = 0 的 r 值
```

## 3. 实际项目案例的 ROI 对比

| 案例 | 投入 | 改造前 | 改造后 | 实际回本 |
|------|------|--------|--------|----------|
| 武侯祠锦里店（尚客优）| 6 万/间 | 61 元 | 180 元 | **1.25 年** |
| 石家庄 7 天 3.0 | 2.8 万/间 | - | OCC +25pct，营收 + 70% | **1.5-2 年** |
| 张焕柏曼（下沉）| 1.34 万/间 | - | RevPAR 最高 750 | **1-1.5 年** |
| 城市便捷（极速）| - | - | 30 天完工 | - |

**对比：我的测算 6-10 年 vs 实际 1-2 年——为什么差距大？**

**原因**：
- 我的模型用了"全成本"（含改造期损失 + 备用金）
- 实际项目"分批改造"减少了改造期损失
- 实际项目"边改造边营业"保留了部分营收
- 实际项目"集采降本"减少了改造投入

**修正建议**：
- 装配式改造 = 节省 30%+ 成本
- 分层改造 = 保留 30-60% 营收
- 集采 = 节省 20-30% 物料

## 4. 动态回本（NPV）模型

### 公式
```
NPV = Σ[(NCF_t) / (1+r)^t] - 投资

NCF_t = 第 t 年净现金流改善
r = 折现率 (8-10%)
t = 年份
```

### 实际项目 NPV 测算示例

```
投资 = 580 万
NCF_1 = 25 万 (爬坡 50%)
NCF_2 = 50 万 (爬坡 100%)
NCF_3 = 60 万 (稳定)
NCF_4 = 65 万
NCF_5 = 70 万
NCF_6-10 = 70 万/年

NPV (r=10%) = 
-5.8 + 25/1.1 + 50/1.21 + 60/1.331 + 65/1.464 + 70/1.611 + 70 × [1-1/1.611^5]/0.1/1.611^4
= -5.8 + 22.7 + 41.3 + 45.1 + 44.4 + 43.5 + 70 × 3.79 / 1.611^4
= -5.8 + 22.7 + 41.3 + 45.1 + 44.4 + 43.5 + 70 × 3.79 / 6.72
= -5.8 + 22.7 + 41.3 + 45.1 + 44.4 + 43.5 + 39.5
= 270.7 万

NPV = +270.7 万 = 投资可行 ✅
```

## 6. 业主决策关键问题

### 问题 1：你能等 10 年回本吗？
- ✅ 能等 = 投资可行
- ❌ 等不起 = 现金流紧张，不建议

### 问题 2：保守场景能撑住吗？
- ✅ 能 = 改造安全
- ❌ 不能 = 暂停决策

### 问题 3：有没有业绩托底？
- ✅ 有（东呈）= 风险降低
- ❌ 没有 = 风险全部自己担

### 问题 4：机会成本是什么？
- 不改造 = 维持现状
- 改造 = 投资改造
- 哪个 NPV 更高？
