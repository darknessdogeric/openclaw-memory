# 阶段 5：投资匡算 + 经营测算

> **核心问题**：花多少钱？多久回本？业主能承受吗？

---

## 1. 投资匡算框架

```
[总投入 = 改造投入 + 改造期损失 + 备用金]
[经营测算 = 营收 - 成本 = 净利]
[回本周期 = 总投入 / 改造后净利改善]
[NPV = 动态回本（考虑折现）]
[IRR = 内部收益率]
```

---

## 2. 改造总投入明细（8 大项）

| 项目 | 占总投入 | 必查 |
|------|----------|------|
| 1. 硬装施工 | 50-60% | 装修队 + 监理 |
| 2. 软装家具 | 15-20% | 床垫/布草/卫浴不能省 |
| 3. 智能化系统 | 5-10% | 同步布 vs 后期补 |
| 4. 标识导视 | 2-5% | 品牌方要求 |
| 5. 设计费 | 3-5% | 设计师选择 |
| 6. 监理费 | 1-2% | 第三方监理 |
| 7. 不可预见 | 5-10% | **必留**（业主方最常忽略）|
| 8. 备用金 | **5-10%** | **必留**（超支/意外）|

**备用金合计：10-20%**（不可预见 + 备用金 = 双保险）

---

## 3. 改造期损失测算

| 模式 | 改造期 | 营收损失 |
|------|--------|----------|
| 轻改 | 1-2 个月 | 1-2 个月营收 |
| 中改（分层） | 3-6 个月 | 1.2-2.4 个月营收（保 40-60%）|
| 中改（停业） | 3-6 个月 | 3-6 个月营收 |
| 重改 | 6-12 个月 | 6-12 个月营收 |

**经验法则**：**改造期损失 ≥ 50% 总投入**（这是隐性最大成本）

## 5. 实际项目测算示例

### 示例 1：80 间客房中端酒店

| 项 | 数值 |
|----|------|
| 改造模式 | 中改 |
| 单房 | 4.5 万 |
| 总投入 | 360 万 |
| 备用金 20% | 72 万 |
| 实际需要 | 432 万 |
| 改造期 4 个月损失 | 369,600 × 4 = 148 万 |
| **总成本 = 580 万** |

**改造前**：OCC 50% × ADR 280 = RevPAR 140
**改造后**（正常）：OCC 70% × ADR 360 = RevPAR 252

- 净利改善 = (252 - 140) × 80 × 30 × 10% = 26,880 元/月 = **32.3 万/年**
- 静态回本 = 580 / 32.3 = **18 年** ⚠️

**但**：装配式 + 分层改造（保 50% 营收）= 实际总成本 380 万
- 静态回本 = 380 / 32.3 = **11.8 年** ⚠️

**判断**：**保守场景 18 年不可接受**——必须用**装配式**或**业绩对赌**（东呈）才能 1.25-2 年回本。

### 示例 2：装配式 + 业绩对赌

| 项 | 数值 |
|----|------|
| 装配式中改 | 320 万 |
| 备用金 | 64 万 |
| 实际 | 384 万 |
| 改造期 2 个月损失 | 74 万 |
| **总成本 = 458 万** |
| 业绩对赌 | 集团 2 年回本承诺 |
| **静态回本** | **< 2 年** ✅ |

## 6. NPV 动态回本

### 公式

```
NPV = Σ[(NCF_t) / (1+r)^t] - 总投资
r = 折现率（建议 8-10%）
t = 年份
NCF = 净现金流改善
```

### 实际项目 NPV（80 间客房中端）

```
投资 = 580 万

NCF 1 = 25 万（爬坡 50%）
NCF 2 = 50 万（爬坡 100%）
NCF 3 = 60 万
NCF 4 = 65 万
NCF 5 = 70 万
NCF 6-10 = 70 万/年

NPV (r=10%) ≈ 270 万
```

**NPV > 0 = 投资可行** ✅

### 关键判断

- **5 年内**回本 = 激进
- **5-10 年**回本 = 正常
- **10+ 年**回本 = 不可接受
- **NPV > 0** = 数学上可行
- **NPV < 0** = 数学上不可行

## 7. 敏感性分析

### 关键变量

| 变量 | 影响 | -10% | +10% |
|------|------|------|------|
| OCC | 极大 | 60% | 80% |
| ADR | 极大 | 280 | 400 |
| 改造期 | 中 | 节省 1 个月 | 多 1 个月 |
| 总投入 | 中 | 节省 50 万 | 多 50 万 |

### 关键洞察

- **OCC 和 ADR 是最敏感变量**（决定净利改善）
- **改造期每缩短 1 个月** = 节省 X 万营收
- **总投入每超 10%** = 静态回本 +1 年

**不要为了省改造期而仓促**——仓促的代价是 OCC/ADR 提升不达预期。

## 8. 国央企 vs 民营 投资匡算差异

### 8.1 总投入差异（80 间客房中端酒店）

| 项 | 国央企 | 民营/私营 | 差异 |
|----|--------|----------|------|
| 设计费 | 1.5 倍 | 1.0 倍 | +50% |
| 施工费 | 1.3 倍 | 1.0 倍 | +30% |
| 物料费 | 1.2 倍 | 1.0 倍 | +20% |
| 监理费 | 1.5 倍 | 1.0 倍 | +50% |
| 改造期损失 | 1.5 倍 | 1.0 倍 | +50% |
| **总成本** | **+30-50%** | **基线** | |

### 8.2 经营测算差异

| 维度 | 国央企 | 民营/私营 |
|------|--------|----------|
| 改造后首年爬坡 | 慢（合规+流程长）| 快（业主驱动）|
| 2-3 年达到峰值 | 慢 | 快 |
| 长期稳定性 | 高（背靠集团）| 中（业主个人风险）|
| RevPAR 上限 | 中（受标准化限制）| 高（差异化空间大）|

### 8.3 回本周期差异

| 维度 | 国央企 | 民营/私营 |
|------|--------|----------|
| 静态回本 | 8-12 年 | 1.5-3 年 |
| NPV 回本 | 8-10 年 | 2-3 年 |
| 实际回本（装配式+对赌）| 5-7 年 | **1-2 年** |

**核心洞察**：
- **国央企**：靠"装配式 + 业绩对赌 + 长期持有"压缩回本
- **民营/私营**：靠"快速决策 + 装配式 + 灵活定价"压缩回本

## 10. 投资匡算的 5 大常见错误

### 错误 1：只算"理想情况"
- ❌ 假设 OCC 立刻 100% 满房
- ✅ 必须算 3 个场景

### 错误 2：忽略改造期损失
- ❌ 只算改造投入
- ✅ 改造期损失 = 隐性最大成本

### 错误 3：低估备用金
- ❌ 不留备用金
- ✅ 总投入 × 10-20% 作为备用金

### 错误 4：忽略集采溢价（国央企）
- ❌ 假设市场价
- ✅ 国央企集采加价 20-30%

### 错误 5：静态 vs 动态混淆
- ❌ 静态回本 = 真实回本
- ✅ 考虑 NPV 折现 + 爬坡期

## 11. 投资匡算检查清单

| # | 必过 |
|---|------|
| 1 | 3 场景测算完成 |
| 2 | 改造期损失 = 营收 × 月数 |
| 3 | 备用金 10-20% |
| 4 | 业主类型确认（国央企/民营）→ 投入差异 |
| 5 | 保守场景能撑住 |
| 6 | NPV > 0 |
| 7 | 敏感性分析 |
| 8 | 现金流缓冲（首 6 个月不盈利能撑）|
| 9 | 退出计划（5/10/20 年）|
| 10 | 业绩对赌条款（如加盟东呈）|

**10/10 通过 = 投资匡算完成**。
