# 阶段 8：运营方式 + 投后管理 + 退出计划

> **核心问题**：改造完了怎么运营？投后如何管理？什么时候（如何）退出？
> 这是全生命周期中**最长**的阶段——可能 5-20 年。
>
> ⚠️ **业主类型适配**：**退出是国央企 vs 民营差异最大的环节**——国央企需国资委批准，民营可市场化退出。

---

## 0. 业主类型对退出计划的关键影响

| 业主类型 | 退出方式 | 退出周期 | 价值实现 |
|----------|----------|----------|----------|
| **国央企** | **国资委批准 + 招拍挂 + 集团决策** | 12-24 个月 | 资产保值 + 集团战略 |
| **民营/私营** | **市场化退出**（转让/REIT/品牌方回购）| 3-6 个月 | 利润最大化 |

**国央企退出提醒**：
- ❌ 不能"业主一人决策"
- ✅ 必须"国资委批准 + 招拍挂 + 公开竞价"
- ❌ 不能"低于评估价转让"（涉及国资流失）
- ✅ 资产保值是底线，不追求"卖最高价"

**民营/私营退出提醒**：
- ✅ 完全市场化（业主决定）
- ✅ 可"卖给下家"（不需公示）
- ✅ 可"卖给基金/REIT"
- ✅ 追求"利润最大化"

## 1. 运营方式选择

### 1.1 运营方式 3 种

| 方式 | 业主角色 | 管理方 | 成本 | 适合 |
|------|----------|--------|------|------|
| **自运营** | 全掌控 | 自招 GM | 最低 | 经验业主 |
| **委托管理** | 监管 | 管理公司 | 10-15% 营收 | 无经验 |
| **加盟品牌** | 部分控制 | 集团派驻 | 4-8% 营收 | 中等 |

### 1.2 运营关键绩效指标（KPI）

| KPI | 经济型目标 | 中端目标 | 中高端目标 |
|-----|----------|----------|------------|
| **OCC** | 75%+ | 70%+ | 65%+ |
| **ADR** | 200-350 | 350-600 | 600-1000 |
| **RevPAR** | 150-250 | 250-420 | 420-650 |
| **GOP 率** | 45-50% | 40-45% | 35-40% |
| **中央预订率** | 40%+ | 50%+ | 60%+ |
| **OTA 评分** | 4.3+ | 4.5+ | 4.7+ |
| **复购率** | 20%+ | 25%+ | 30%+ |
| **人房比** | 0.12 | 0.15 | 0.18 |

### 1.3 运营方式的"3 个关键人"

| 角色 | 重要性 | 关键能力 |
|------|--------|----------|
| **GM** | ⭐⭐⭐⭐⭐ | 全能（运营+销售+财务+HR）|
| **销售/营销经理** | ⭐⭐⭐⭐ | OTA 运营+内容+获客 |
| **财务/会计** | ⭐⭐⭐ | 现金流+成本+报表 |

## 2. 投后管理（月度/季度/年度）

### 2.1 月度投后管理（业主必看）

| 指标 | 检查频率 | 目的 |
|------|----------|------|
| **OCC/ADR/RevPAR** | 每月 | 核心经营 |
| **现金流** | 每周 | 生存底线 |
| **OTA 评分** | 每月 | 质量监控 |
| **客诉数** | 每周 | 体验监控 |
| **员工流失率** | 每月 | 团队健康度 |
| **净利润** | 每月 | 盈利能力 |

### 2.2 季度投后管理（业主 + GM）

| 议程 | 内容 |
|------|------|
| **季度数据复盘** | OCC/ADR/RevPAR 对比上季度 + 同比 |
| **竞品动态分析** | 周边 3km 新开/关店/改造趋势 |
| **团队评估** | GM/主管 1v1 反馈 |
| **AI 工具 ROI 评估** | 哪些 AI 工具赚钱、哪些亏钱 |
| **下季度目标** | 数字目标 + 行动清单 |
| **品牌方反馈** | 加盟品牌方支持是否到位 |

### 2.3 年度投后管理（业主 + GM + 集团代表 + 外部顾问）

| 议程 | 内容 |
|------|------|
| **12 月数据复盘** | 全年 OCC/ADR/RevPAR/GOP 对比预测 |
| **战略评估** | 年初定位对了吗？需要调整吗？|
| **资产再评估** | 物业是否需要二次改造？|
| **团队结构** | 团队是否需要换血？|
| **AI 战略** | AI 工具升级还是降级？|
| **退出意向** | 是否考虑退出？|（可选）|

## 3. 退出计划（5 年/10 年/20 年）

### 3.1 退出方式 4 种

| 方式 | 流动性 | 价值 | 适合 |
|------|--------|------|------|
| **股权转让** | 中 | 中等 | 中型酒店 |
| **资产出售** | 高 | 低 | 急用钱 |
| **REIT 退出** | 高 | 中高 | 长期持有 |
| **品牌方回购** | 中 | 高 | 加盟品牌 |

### 3.2 退出时机的决策矩阵

| 条件 | 退出时机 |
|------|----------|
| **物业价值上升 + 市场好** | 理想退出点 |
| **RevPAR 连涨 3 年 + 物业估值高** | 黄金退出点 |
| **RevPAR 持平 2 年 + 物业估值平稳** | 可等 |
| **RevPAR 连跌 2 年 + 物业估值下降** | 应退出 |
| **现金流断裂** | **必须退出** |

### 3.3 退出前 5 项准备

| # | 准备 | 时限 |
|---|------|------|
| 1 | **财务审计** | 退出前 1 年 |
| 2 | **物业估价** | 退出前 6 个月 |
| 3 | **寻找买方渠道** | 退出前 1 年 |
| 4 | **律师准备合同** | 退出前 3 个月 |
| 5 | **税务规划** | 退出前 1 年 |

### 3.4 退出价值估算

| 方法 | 公式 | 适合 |
|------|------|------|
| **EBITDA 倍数法** | 估值 = EBITDA × 6-12 倍 | 最常用 |
| **收入倍数法** | 估值 = 营收 × 1.5-3 倍 | 粗略 |
| **资产净值法** | 估值 = 资产 - 负债 | 物业 |
| **现金流折现法** | DCF 模型 | 精确 |

**中国酒店行业 EBITDA 倍数参考**：
- 经济型：6-8 倍
- 中端：8-10 倍
- 中高端：10-12 倍
- 高端：12-15 倍

### 3.5 退出决策树

```
打算多久退出？
├─ 1-3 年 → 现在就开始准备
│   ├─ 物业估值处于高位 → 立即退出
│   ├─ 物业估值中位 → 6-12 个月观察
│   └─ 物业估值低位 → 等 1-2 年
│
├─ 3-5 年 → 建资产再投资计划
│   ├─ 再投 200-500 万 → 增加估值
│   └─ 维持现状 → 等时机
│
├─ 5-10 年 → 长期持有
│   ├─ 每 3 年一次软改 → 保持竞争力
│   └─ 每 5 年一次大改 → 增加资产价值
│
└─ 10-20 年 → 传代/转让
    ├─ 传给下一代 → 家族规划
    └─ 大宗退出 → 找机构买方
```

## 4. 退出前需要回答的 5 个问题

1. ❓ **你当初为什么投这个酒店**？（盈利？资产增值？情怀？）
2. ❓ **现在的估值后悔吗**？（比预期低？比预期高？）
3. ❓ **如果你不退出，3 年后会怎样**？
4. ❓ **退出后你要做什么**？（纯退出？再投资另一个？）
5. ❓ **谁是你的理想买方**？（个人？集团？基金？）

**如果 5 个问题都能清晰回答 = 可以启动了**

## 5. 投后与退出的完整时间线

```
[改造完成 重开]
    ↓
[运营期 1-3 年] ── 爬坡 + 稳定
    │  目标：OCC 70%+ / ADR 目标 + / GOP 率 40%+
    ↓
[运营期 3-5 年] ── 优化 + 微改
    │  目标：复购率提升 / AI 工具升级 / 团队培养
    ↓
[决策点 5 年] ── 是否退出？
    ├─ YES → [退出准备期 1 年] → [退出执行]
    └─ NO → [运营期 5-10 年] 或 [二次改造]
```

## 6. 运营方式的"AI 时代选择"

### 6.1 自运营 + AI 工具
- 月度成本 3000-5000 元
- 5-6 个 SaaS 工具（客评+客服+定价+排班+数据分析）
- 团队需要 AI 训练

### 6.2 加盟品牌 + AI 工具
- 品牌方自带 AI → 省心
- 但也失去一定灵活性
- 集团 AI 工具可能不合单酒店

### 6.3 全委 + AI
- 集团 AI = 最新
- 但数据不一定透明
