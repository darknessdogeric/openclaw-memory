## 1. 三大类别

```
明规则    = 公开的规则、合同、文件、法律
潜规则    = 行业内不公开但默认遵守的"行规"
灰度      = 处于"明规则边界"或"潜规则 vs 法律"冲突的地带
```

**三者的优先级**（Eric 在酒店业实战多年实战）：
1. **明规则**（底线，不可触碰）
2. **潜规则**（行业生存法则，触碰有风险但不致命）
3. **灰度**（高风险高回报区，需要 Eric 亲自判断）

## 2. 国央企的潜规则

### 2.1 决策链上的潜规则

| 潜规则 | 实质 |
|--------|------|
| **"一把手工程"** | 重大改造需一把手亲自推，否则难落地 |
| **"老领导态度"** | 退居二线的老领导对项目有隐性话语权 |
| **"集团办公厅"** | 办公厅是隐藏的关键节点（不是业务部）|
| **"财务总监签字"** | 财务总监有"事实否决权"（不是流程要求）|
| **"审计预留"** | 提前考虑审计/巡视组的检查视角 |

### 2.2 供应商选择潜规则

| 潜规则 | 实质 |
|--------|------|
| **"关系户"优先** | 集团内部关系户的供应商有"事实优先" |
| **"平衡照顾"** | 大单子分给多家供应商，避免"独大" |
| **"老客户保护"** | 长期合作的供应商有"小单优待" |
| **"集体决策"** | 评标委员会的决定受"集体意志"影响 |

### 2.3 团队管理潜规则

| 潜规则 | 实质 |
|--------|------|
| **"老人"话语权** | 编制内的"老资格"即使能力差也难调 |
| **"干部身份"** | 国企干部身份调动需"组织部"参与 |
| **"党管人才"** | 关键岗位需"党管"原则 |
| **"工会"参与** | 任何裁员/降薪必须走工会 |

## 3. 民营/私营的潜规则

### 3.1 业主决策潜规则

| 潜规则 | 实质 |
|--------|------|
| **"家庭决策"** | 重大决策需家庭成员同意（含配偶/子女）|
| **"朋友圈"资源** | 供应商/加盟品牌选择有"朋友圈"影响 |
| **"面子"考虑** | 装修档次要符合业主"面子"|
| **"关系"重要** | 地方政府/银行/品牌方的关系网重要 |

### 3.2 商业潜规则

| 潜规则 | 实质 |
|--------|------|
| **"账期"** | 上下游都有账期（30-90 天）|
| **"返点"** | 行业默认有返点（2-5%）|
| **"现金"优惠** | 现金交易有 5-10% 折扣 |
| **"个人卡"** | 业主用个人卡支付部分费用 |

## 4. 灰度地带（高风险区）

### 4.1 国央企的灰度

| 灰度 | 风险 |
|------|------|
| **"咨询费"** | 咨询费来源不明 → 审计/纪检风险 |
| **"考察费"** | 考察变成旅游 → 违反中央八项规定 |
| **"礼品"** | 业主给相关方礼品 → 廉政风险 |
| **"招待费"** | 招待费超标/虚假报销 → 审计风险 |
| **"挂名"** | 业主挂名不实际工作 → 取酬违规 |
| **"关联交易"** | 业主/亲属的关联公司参与 → 国资流失 |
| **"利益输送"** | 帮特定品牌方进入 → 利益输送 |

### 4.2 民营/私营的灰度

| 灰度 | 风险 |
|------|------|
| **"阴阳合同"** | 真实价格 ≠ 合同价格 → 偷税漏税 |
| **"挂单"** | 用员工/亲属名义持股 → 规避监管 |
| **"现金收入"** | 部分收入不入账 → 偷税 |
| **"关系工程"** | 装修/物料通过关系户 → 质量风险 |
| **"工资拆分"** | 基本工资 + 现金补贴 → 社保/公积金风险 |

## 5. Eric 给业主建议时的灰度判断

### 5.1 国央企业主

**可以做**：
- ✅ 公开招标（明规则）
- ✅ 集团集采（明规则）
- ✅ 第三方监理（明规则）
- ✅ 党建活动（明规则）
- ✅ "老专家顾问"（潜规则，但合规）

**不做**：
- ❌ 任何"咨询费/顾问费"给个人
- ❌ 任何"考察"变成旅游
- ❌ 任何关联公司参与
- ❌ 任何"挂名"取酬
- ❌ 任何"礼金/礼品"给决策人

### 5.2 民营/私营业主

**可以做**：
- ✅ 公开价格谈判
- ✅ 关系户供应商（不违法）
- ✅ 灵活的模式选择
- ✅ 商业返点（行业潜规则）

**不做**：
- ❌ 阴阳合同（违法）
- ❌ 大额现金交易（违法）
- ❌ 关联交易逃税（违法）
- ❌ 任何形式的"贿赂"（违法）

## 6. Eric 的"红线思维"

### 6.1 不可触碰的 5 条红线

1. ❌ **任何形式的国有资产流失**
2. ❌ **任何形式的关联交易**
3. ❌ **任何形式的偷税漏税**
4. ❌ **任何形式的商业贿赂**
5. ❌ **任何形式的虚假宣传/承诺**

### 6.2 灰度处理的 3 个原则

1. ✅ **公开透明**（明面上合规）
2. ✅ **可追溯**（任何决定有记录）
3. ✅ **不私拿**（任何收益不归个人）

## 7. 给 Eric 的服务建议

### 1v1 咨询时的"灰度判断"

| 业主类型 | 灰度处理 |
|----------|----------|
| **国央企** | 全部走明规则，潜规则辅助，灰度坚决不碰 |
| **民营/私营** | 明规则 + 潜规则灵活，灰度提示但不主导 |

### 知识付费产品的"灰度边界"

- ✅ 可以讲："加盟品牌如何选"（明规则）
- ✅ 可以讲："如何做加盟谈判"（明规则 + 潜规则）
- ❌ **不能讲**："如何绕过审计/纪检"（灰度）
- ❌ **不能讲**："如何关联交易逃税"（灰度）
- ❌ **不能讲**："如何拿回扣"（灰度）

## 8. Eric 风格的"明规则 + 潜规则 + 灰度"模板

### 给国央企业主的咨询模板

```
1. 【明规则】你的项目必须走三重一大 → 党委会决议
2. 【明规则】单笔超 50 万需公开招标
3. 【明规则】建议加党建活动 + 稳岗方案
4. 【潜规则】建议提前与集团办公厅沟通
5. 【潜规则】考虑集团内部老专家作为顾问
6. 【灰度提醒】任何"挂名"和"咨询费"坚决不做
```

### 给民营/私营业主的咨询模板

```
1. 【明规则】你的项目需要做工商/消防/卫生备案
2. 【明规则】加盟需要签正式合同（5 大必查条款）
3. 【潜规则】建议考虑朋友圈推荐的供应商
4. 【潜规则】退出计划 5 年内可以做
5. 【灰度提醒】任何形式的"挂单"和"阴阳合同"坚决不做
```

## 9. 关键洞察

> **Eric 在酒店业的实战经验经验的最大智慧**：
>
> **明规则**让你"活下来"
> **潜规则**让你"活得好"
> **灰度**可能让你"进去"
>
> **Eric 的核心判断**：
> - 给国央企方案 = **明规则 + 潜规则**
> - 给民营方案 = **明规则 + 潜规则 + 灵活灰度**
> - **永远不碰任何"灰度"**——这才是 多年不出事的原因

## 10. 知识库应用规则

**B166ER 给 Eric 建议时**：

**B166ER 写对外产品时**：

- 不写"如何绕过某规则"
