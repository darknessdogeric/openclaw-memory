## ⚠️ 根本性细分维度

> **在中国大陆，存量酒店资产归属分两类：国央企 vs 民营/私营。**
> **这两类操作方式完全不同**——所有 8 阶段的决策都受此影响。

**第一性原理**：
- 国央企 = **代理人决策**（追求安全+合规+无过错）
- 民营/私营 = **业主决策**（追求利润最大化）

**6 大决策差异**：
| 维度 | 国央企 | 民营/私营 |
|------|--------|----------|
| 决策速度 | 6-12 个月 | 1-3 个月 |
| 风险偏好 | 极度保守 | 灵活 |
| 资金来源 | 财政/授信/调拨 | 自有/民间 |
| 退出难度 | 国资委批准 | 市场化 |
| AI 接入 | 信创要求 | 灵活 |
| 总成本 | +30-50% | 基线 |

**详细对比**：`ownership-types.md` + `sov-private-differences.md` + `unspoken-rules.md`（内部文件）

**应用**：每个阶段的现有文件**都应标注"国央企适用/民营适用"**。

## 每个阶段的核心问题

### 阶段 1：物业评估 + 资产问题
**核心问题**：这个物业值不值得动？有什么资产隐患？

- 物业现状（建造年份、上次翻新、结构/水电/消防状态）
- **资产隐患**：产权/租约/抵押/纠纷/危楼/危化品
- **资产增值空间**：位置价值、周边配套、竞品对比

### 阶段 2：项目重新定位
**核心问题**：动了之后，它要"变成什么"？

- 客群画像（类型、消费力、需求）
- 市场空位（周边 3km 缺乏什么？）
- 品牌定位（中端/中高端/高端/精品/主题/民宿？）
- 差异化（跟周边竞品比自己独特在哪？）

### 阶段 3：经营模式选择
**核心问题**：**谁来运营**？是自营、加盟还是全委？

- 自营（酒店归业主，团队归自己）— 高自由、高风险
- 加盟（挂品牌，团队共建）— 中等
- 全委（集团全面管理）— 最高成本、最省心

→ 品牌取舍：选哪个品牌？为什么？

### 阶段 4：改造方式
**核心问题**：用哪种改造方式？

- 轻改 / 中改 / 重改
- 装配式 vs 传统
- 分层改造 vs 整体停业

### 阶段 5：投资匡算 + 经营测算
**核心问题**：花多少钱？多久回本？

- 改造总投入
- 3 场景经营测算（保守/正常/激进）
- NPV / IRR / 回本周期
- 现金流分析

### 阶段 6：供应商选择
**核心问题**：哪个装修队/设计/物料/监理？

- 设计公司选择
- 施工团队选择
- 物料供应选择
- 监理/顾问选择

### 阶段 7：团队去留
**核心问题**：改造期团队怎么管？

- 核心人员锁定
- 改造期工作分配
- 团队培训
- 改造后激励

### 阶段 8：运营方式 + 投后管理 + 退出计划
**核心问题**：改造完了怎么运营？什么时候退出？

- 运营方式（自运营 / 委托管理 / 加盟品牌）
- 投后管理（月度复盘、季度评估、年度战略）
- **退出计划**（5 年/10 年/20 年后怎么退出？）

## 各阶段之间的依赖关系

| 阶段 | 依赖的阶段 | 原因 |
|------|-----------|------|
| 1 物业评估 | - | **起点**——不评估不动 |
| 2 重新定位 | 1 | 评估完才能定"要变成什么"|
| 3 经营模式 | 2 | 定位了才能选模式 |
| 4 改造方式 | 1, 2 | 物业 + 定位 → 改多少 |
| 5 投资匡算 | 1, 2, 4 | 物业 + 定位 + 改造方式 → 成本 |
| 6 供应商 | 4, 5 | 改造方式 + 预算 → 选供应商 |
| 7 团队去留 | 2, 3 | 定位 + 模式 → 团队配置 |
| 8 运营+退出 | 2, 3, 5 | 定位 + 模式 + 投资 → 退出策略 |

**核心洞察**：**阶段 1-2 决定一切**。前 2 个阶段做对了，后面不容易出错。前 2 个阶段做错，后面怎么补救都有限。

## 业主视角的"决策路线图"

```
业主过来找 Eric：
  1. "你看我这酒店值不值得动？" → 阶段 1
  2. "要变成什么？" → 阶段 2
  3. "自己干还是找人干？" → 阶段 3
  4. "怎么改？轻改还是重改？" → 阶段 4
  5. "花多少钱？多久回本？" → 阶段 5
  6. "找谁来做？" → 阶段 6
  7. "团队怎么办？" → 阶段 7
  8. "以后怎么退出？" → 阶段 8
```

**这就是 Eric 在 1v1 咨询中的谈话顺序。**
