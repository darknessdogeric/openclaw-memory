# 阶段 7：团队去留

> **核心问题**：改造期团队怎么管？哪些人留、哪些人走？怎么激励？

---

## 1. 阶段 7 的特殊任务

**注意**：阶段 7 跟"持续团队管理"不同——**它的核心是"改造期 + 重开期"的去留决策**。

```
[阶段 7 核心任务]
├─ 改造期团队配置（保稳定 + 减流失）
├─ 核心人员去留决策（谁必须留/谁可以走）
├─ 改造期激励设计（GM + 主管 + 全员）
├─ 重开期团队重组（老员工/新员工/外包）
└─ 团队文化重塑（"二次创业"心态）
```

---

## 2. 改造期团队配置（80 间客房基线）

| 角色 | 人数 | 改造期工作 | 备注 |
|------|------|-------------|------|
| **GM** | 1 | 总协调 + 业主汇报 + 品牌方对接 | **必须留** |
| **主管（客房）** | 1 | 协助施工 + 老客户沟通 | **必须留** |
| **主管（销售）** | 1 | OTA 维护 + 客户预热 | **必须留** |
| **前台** | 2-3 | 在线接单 + 客户通知 | 至少留 1 个 |
| **客房** | 2-3 | 协助搬家/整理 + 培训 | 至少留 50% |
| **工程** | 1 | 现场监理 + 隐蔽工程验收 | **必须留**（或外聘）|
| **销售/营销** | 1 | 内容制作 + 渠道铺设 | 重开前 2 个月到位 |
| **AI 工具专员** | 0-1 | 智能化系统对接 | **新增**（或培训现有员工）|
| **总人数** | 9-13 | | 改造期可降至 50% |

---

## 3. 核心人员去留决策（"四类人"模型）

### 3.1 第一类：必须留（4 类）

| 类型 | 原因 | 激励 |
|------|------|------|
| **GM** | 总协调灵魂，缺了项目崩 | 改造完成奖金 5-10 万 + 期权 |
| **核心 GM 主管** | 团队稳定锚 | 改造完成奖金 2-5 万 + 加薪 |
| **老客户关系员工** | 复购率关键 | 改造完成奖金 1-2 万 |
| **工程/隐蔽专家** | 质量保障 | 改造完成奖金 1-3 万 |

### 3.2 第二类：可以调整（3 类）

| 类型 | 决定方式 |
|------|----------|
| **绩效中等的员工** | 改造期保 80%，重开期再评估 |
| **重复岗位员工** | 合并岗位（如前台+客服合一）|
| **新招聘员工** | 暂缓入职（除关键岗位）|

### 3.3 第三类：必须走（3 类）

| 类型 | 走法 |
|------|------|
| **绩效持续低**（1 年+ 低于平均）| 协商离职 + N+1 |
| **价值观不符**（消极怠工/破坏）| 立即解除 + 保留证据 |
| **团队毒药**（拉帮结派/传播负能量）| 立即解除 |

### 3.4 第四类：特殊处理（2 类）

| 类型 | 处理 |
|------|------|
| **工龄长但能力差**（"老人"）| 调岗降薪 + 培训期 3 个月 |
| **能力强但不稳定**（跳槽倾向）| 重金留 + 期权 + 竞业限制 |

---

## 4. 改造期团队激励设计

### 4.1 薪资结构（改造期）

| 角色 | 底薪 | 改造期 | 改造后 |
|------|------|--------|--------|
| **GM** | 1.5-2 万 | 100% 底薪 + 0 提成 | 100% 底薪 + 提成 |
| **主管** | 0.8-1 万 | 100% 底薪 | 100% 底薪 + 提成 |
| **前台** | 0.5-0.7 万 | 100% 底薪 | 底薪 + 提成 |
| **客房** | 0.4-0.6 万 | 100% 底薪 | 底薪 + 提成 |

**关键**：**改造期不降低底薪**——避免员工流失

### 4.2 改造期奖金池

```
总奖金池 = 改造投入 × 1-2%

分配：
├─ GM 30% （核心驱动）
├─ 主管 30%
├─ 关键员工 30%
└─ 全员聚餐 10%
```

**发放条件**：
- 改造按期完成（不延期）
- 改造质量验收通过
- 无重大客诉

### 4.3 重开期冲刺激励

| 角色 | 激励 |
|------|------|
| **GM** | 重开首月营收 5% 提成 |
| **主管** | 重开首月营收 3% 提成 |
| **前台** | 重开首月营收 1% 提成 |
| **客房** | 重开首月 0.5% 提成 |

**重开首月全员冲刺 = 数据上轨道**。

---

## 5. 重开期团队重组

### 5.1 重组方向

```
[改造期]  →  [重开前 30 天]  →  [重开后 3 个月]
   减员       培训+招聘             稳定
   9-13 人    11-13 人            11-15 人（增）
```

**关键**：**重开前 30 天是培训黄金期**——封闭培训 5 天 + 实战演练 25 天。

### 5.2 新增岗位（3 个）

| 岗位 | 作用 | 来源 |
|------|------|------|
| **AI 工具专员** | 智能化系统对接、数据监控 | 培训现有员工 / 外聘 |
| **内容运营** | OTA 描述、抖音/小红书、客评回复 | 外聘 / 外包 |
| **新媒体专员** | 短视频制作、私域运营 | 外包（前期）|

### 5.3 外包 vs 自建

| 任务 | 外包 | 自建 |
|------|------|------|
| OTA 描述 | ✅ | ⚠️ 后期 |
| 客评回复 | ✅（初期）| ✅ 后期 |
| 短视频 | ✅ | ⚠️ 后期 |
| AI 工具运营 | ❌ | ✅（核心）|
| 客户复购 | ❌ | ✅（核心）|

**判断**：**核心环节自建，营销环节外包**。

## 6. 团队文化重塑

### 6.1 改造前："二次创业"动员（业主亲自讲）

**动员讲话模板**：
```
这次改造不是"装修"。
这是公司的"二次创业"。

你的角色：
- 不是"打工者"——是"创业伙伴"
- 不是"维持现状"——是"重新开始"

改造成功 = 你的价值翻倍
改造失败 = 你也跟着完蛋

我们必须一起扛过去。
```

### 6.2 改造期：保持士气

| 动作 | 频率 | 目的 |
|------|------|------|
| 周会 | 每周 1 次 | 信息透明 |
| 团队聚餐 | 每月 1 次 | 凝聚力 |
| 业主视察 | 每月 1 次 | 关注感 |
| 庆功会 | 改造完成 | 阶段胜利 |

### 6.3 重开期：全新心态

| 旧心态 | 新心态 |
|--------|--------|
| 维持现状 | 翻倍增长 |
| 等客来 | 主动获客 |
| 凭经验 | 数据驱动 |
| 老板定 | 团队共创 |
| 慢 | 快 |

## 7. 国央企 vs 民营 团队管理差异

### 7.1 国央企的"编制 + 稳岗"约束

| 约束 | 含义 | 影响 |
|------|------|------|
| **编制固定** | 不能超编 | 重组空间小 |
| **薪酬限高** | 体系限制 | 奖金不能上不封顶 |
| **解雇困难** | 走劳动仲裁 | 末位淘汰几乎不能 |
| **稳岗要求** | 不能大规模裁员 | 改造期/重开期人员冗余 |
| **集团派驻** | GM 可能是集团调 | 业主无权直接选 |
| **党建/工会** | 必参加 | 时间成本 |
| **竞业限制** | 严格 | 留人难 |

**国央企团队管理核心**：
- ✅ "**不**开除人"是底线
- ✅ 用"调岗 + 培训"代替"开除"
- ✅ 奖金受薪酬体系限制
- ✅ 党建活动 + 工会活动 = 团队建设一部分

### 7.2 民营/私营的灵活性

| 优势 | 具体 |
|------|------|
| **编制灵活** | 业主自己定 |
| **薪酬灵活** | 业绩对赌上不封顶 |
| **解雇灵活** | 末位淘汰可执行 |
| **股权激励** | 给核心员工期权 |
| **新岗位快速补** | 招聘流程短 |
| **文化打造自由** | 无集团约束 |

**民营团队管理核心**：
- ✅ **业绩对赌**为核心激励
- ✅ 末位淘汰保持压力
- ✅ 期权 / 股权留住核心
- ✅ 团队文化完全由业主定

## 9. 团队管理常见错误

### 错误 1：信息不透明
- ❌ "公司要关门" 传闻
- ✅ 主动透明

### 错误 2：薪资不公
- ❌ 团队不知道奖金怎么算
- ✅ 公开公式

### 错误 3：核心人员没锁定
- ❌ 关键人跳槽
- ✅ 提前 60 天锁定

### 错误 4：改造期裁员
- ❌ 改造期裁人 = 双重打击
- ✅ 改造期保岗，重开期评估

### 错误 5：忽略文化重塑
- ❌ 改造完还是老心态
- ✅ "二次创业"动员
