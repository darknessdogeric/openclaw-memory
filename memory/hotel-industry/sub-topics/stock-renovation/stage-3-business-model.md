# 阶段 3：经营模式选择

> **核心问题**：**谁来运营**？是自营、加盟还是全委？
> 这是存量改造中最关键的决策之一
>
> ⚠️ **业主类型适配**：**这是阶段 3 中差异最大的决策**——国央企/民营/私营几乎走完全不同的路径。

---

## 0. 业主类型对经营模式的关键影响

| 业主类型 | 首选模式 | 原因 |
|----------|---------|------|
| **国央企** | **全委/集团内部品牌** | 稳/合规/省心/服务集团主业 |
| **民营/私营** | **自营/加盟品牌** | ROI/灵活/差异化 |

**国央企几乎不选加盟**（怕失去控制）→ 全委或集团内部品牌
**民营/私营几乎不选全委**（不愿出 10-15% 管理费）→ 自营或加盟

**模式选择 = 业主类型几乎 1:1 对应**

---

## 1. 三种经营模式对比

| 维度 | 自营 | 加盟品牌 | 全权委托 |
|------|------|----------|----------|
| **品牌** | 自创 | 集团品牌 | 集团品牌 |
| **运营团队** | 自招 | 集团+自招 | 集团派驻 |
| **管理费** | 0 | 营业额 4-8% | 营业额 10-15% |
| **自由度** | 最高 | 中等 | 最低 |
| **风险** | 最高 | 中等 | 最低 |
| **收益潜力** | 最高（无分享）| 中等 | 较低 |
| **适合** | 有经验业主+稳定团队 | 不想自建的业主 | 不想操心的业主 |
| **退出灵活度** | 最高 | 中等 | 最低（合同锁定）|
| **改造投入** | 自建品牌（中等）| 加盟标准（较高）| 集团标准（最高）|
| **AI 接入** | 自主选择 | 集团 AI（有限）| 集团 AI（全包）|

## 2. 自营 vs 加盟 vs 全委 详细分析

### 2.1 自营

**适合**
- ✅ 有 10 年+运营经验的业主
- ✅ 有稳定核心团队
- ✅ 在特定市场有强根（本地人脉+客源+渠道）
- ✅ 想做差异化定位（独特的品牌理念）

**不适合**
- ❌ 新入行/对酒店运营不熟
- ❌ 团队成员来自不同背景（文化冲突）
- ❌ 市场不确定性高（连锁品牌有数据支持）
- ❌ 想快速摊平风险

**风险评估**
- 高风险、高回报
- 经典失败案例：自营酒店 OCC 仅 30-40%
- 成功案例：成都某设计酒店 80%+ OCC（纯垂直定位）

---

### 2.2 加盟品牌

**适合**
- ✅ 有物业但没酒店运营经验
- ✅ 想获得集团背书（品牌 + 会员 + 数据）
- ✅ 愿意接受一定程度的标准化
- ✅ 以投资视角而不是"经营"视角

**不适合**
- ❌ 对品牌有极高独特性要求
- ❌ 不愿意被标准化限制

**关键分析**

| 优势 | 劣势 |
|------|------|
| 品牌知名度 → 客流更稳定 | 管理费占营业额 4-8% |
| 有会员池 → 客户获取成本低 | 品牌标准化 → 失去个性 |
| 运营支持 → 运营成本优化 | 数据不一定归属业主 |
| 集团 AI → 省事 | 退出机制不灵活 |

**品牌选择关键**：参见 `brand-comparison.md`

---

### 2.3 全权委托

**适合**
- ✅ 极度不想操心（有事业但无时间）
- ✅ 物业资产大、追求稳定现金流
- ✅ 愿意接受长期锁定（5-10 年合同）

**不适合**
- ❌ 现金流压力大（管理费高）
- ❌ 对自己的物业有感情/不想放弃控制
- ❌ 有经营野心

**关键分析**

| 优势 | 劣势 |
|------|------|
| 全托管 → 不操心 | 管理费 10-15% → 吃掉利润 |
| 集团派驻 GM + 核心人员 | 完全丧失控制权 |
| 品牌背书 → 稳定性高 | 合同锁定 5-10 年 |
| 专业运营 → 效率最高 | 退出成本高 |

## 3. 三种模式的选择决策树

```
你能自营吗？
│
├─ YES：你有 10 年+经验 + 稳定团队？
│   └─ YES → 自营（省管理费）
│   └─ NO → 考虑加盟或全委
│
├─ 你想品牌加持吗？
│   ├─ YES → 加盟品牌
│   └─ NO → 自营或全委
│
├─ 你想省事吗？
│   ├─ YES（极度想）→ 全委
│   └─ 还行 → 加盟或自营
│
├─ 现金流压力大吗？
│   ├─ YES → 自营（省钱）
│   └─ NO → 加盟或全委（追求品牌/保障）
│
└─ 你有长期退出计划吗？
    ├─ YES（5 年内想退出）→ 自营（灵活退出）
    ├─ 不确定 → 加盟（平衡）
    └─ NO（20 年长期）→ 全委（稳定性）
```

## 4. 加盟 vs 自营的财务对比

### 80 间客房，中端定位，年营收 1000 万

| 项 | 自营 | 加盟品牌 | 全委 |
|----|------|----------|------|
| **营收** | 1000 万 | 1000 万 | 1000 万 |
| **管理费** | 0 | 营业额 5% = 50 万 | 营业额 12% = 120 万 |
| **运营成本** | 600 万 | 580 万（品牌集采）| 560 万（集团优化）|
| **净利** | 400 万 | 370 万 | 320 万 |
| **净利率** | 40% | 37% | 32% |

### 5 年累计对比

| 项 | 自营 | 加盟 | 全委 |
|----|------|------|------|
| 5 年净利 | 2000 万 | 1850 万 | 1600 万 |
| 品牌溢价 | 无 | 有 | 有 |
| 退出价值 | 高 | 中 | 低（合同锁定）|

**粗判**：自营 5 年省 150-400 万 vs 加盟 → 但前提是"自营能做好"

### 关键对比

| 品牌 | 管理模式 | 业绩对赌 | 适配 |
|------|----------|----------|------|
| 东呈（柏曼/城市便捷）| 加盟 | **2 年回本** | ✅ 有保障 |
| 锦江（7天/锦江之星）| 加盟 | 无 | ⚠️ 需自行评估 |
| 华住（汉庭/全季）| 加盟 | 无 | ⚠️ 需自行评估 |
| 首旅（如家）| 加盟 | 无 | ⚠️ 需自行评估 |
| 亚朵 | 加盟 | 无 | 中高端首选 |

### 加盟品牌选择 5 问

1. ❓ 品牌力：周边 3km 有无同品牌门店？OCC 如何？
2. ❓ 业绩：有无业绩对赌（东呈有，其他无）？
3. ❓ 成本：5 年管理费 + 加盟费 + 集采溢价 = 多少？
4. ❓ 退出：解约灵活度如何？
5. ❓ AI：品牌方 AI 有多少？
