# 资产归属类型：国央企 vs 民营/私营

> Eric 2026-06-12 20:34：在中国大陆，存量酒店资产归属分两类——**国央企**和**民营/私营**。**这两类操作方式完全不同**。
>
> 本文件是知识库的根本性细分维度。**所有 8 阶段**的决策都受此影响。

---

## 1. 第一性原理（Eric 底层逻辑）

**国央企的根本特征**：
- 决策者 = **代理人**（不是 owner）
- 代理人追求：**安全 + 合规 + 无过错** > **利润最大化**
- 决策动机：**不被巡视/审计/纪检追责**

**民营/私营的根本特征**：
- 决策者 = **业主本人**（或家族）
- 业主追求：**利润最大化** > **安全**
- 决策动机：**自己的钱自己的资产**

**这一个根本差异，衍生出所有其他差异。**

---

## 2. 6 大决策差异

| 维度 | 国央企 | 民营/私营 |
|------|--------|----------|
| **决策速度** | 慢（党委会/三重一大/集体决策）| 快（业主一人决策）|
| **风险偏好** | 极度保守（审计红线）| 灵活（个人承受）|
| **资金来源** | 财政/银行授信/集团调拨 | 自有/银行/民间 |
| **改造投入** | 单笔大额需上报（如 500 万+）| 自主决定 |
| **退出** | 需国资委批准+招拍挂 | 市场化退出 |
| **团队/HR** | 编制+薪酬体系严格 | 灵活 |

**第一性原理**：**风险偏好**和**决策速度**是这两个类型最本质的差异。

---

## 3. 国央企的核心约束（不可变）

| 约束 | 含义 |
|------|------|
| **三重一大** | 重大事项必须集体决策 |
| **招投标** | 单笔超 50 万需公开招标 |
| **集中采购** | 物料/服务/装修 必须集采 |
| **审计追溯** | 所有支出可追溯 5-10 年 |
| **纪检红线** | 不能触碰（具体见 unspoken-rules.md）|
| **国资委审批** | 资产转让/大额投资 需上级批准 |
| **稳岗就业** | 不能大规模裁员 |
| **意识形态** | 党建/工会/团建活动 |

**这些约束让国央企的存量改造**：
- 决策周期 6-12 个月（民营 1-3 个月）
- 改造总成本高 20-30%（招标+集采溢价）
- 团队调整幅度小
- AI 接入必须**信创合规**

---

## 4. 民营/私营的核心优势（vs 国央企）

| 优势 | 具体 |
|------|------|
| **决策快** | 周级别决策 |
| **资金灵活** | 民间资金/银行/亲友借款 |
| **退出灵活** | 整体转让/分拆/REIT |
| **品牌选择自由** | 自创品牌/加盟/全委 |
| **AI 工具自由** | 海外/国产都可用 |
| **团队灵活** | 末位淘汰/绩效对赌 |
| **税务规划** | 灵活但需专业 |

## 5. 8 阶段中的差异速查

| 阶段 | 国央企 | 民营/私营 |
|------|--------|----------|
| **1 资产评估** | 重点查产权/历史纠纷/审计 | 重点查投资回报/灵活性 |
| **2 重新定位** | 受集团战略约束 | 灵活 |
| **3 经营模式** | 多用全委+集团内部品牌 | 灵活选择 |
| **4 改造方式** | 必须招标+审计追溯 | 商业谈判 |
| **5 投资匡算** | 需上级批准+风险评估 | 自决 |
| **6 供应商选择** | 必须公开招标 | 商业谈判 |
| **7 团队管理** | 编制+稳岗 | 灵活调整 |
| **8 退出** | 国资委批准 | 市场化 |

## 6. 业主咨询时的关键问题

### 接到国央企业主，先问 5 问：

1. ❓ 您是**集团总部**还是**地方公司**？（决策权不同）
2. ❓ 这个项目是否进**三重一大**？
3. ❓ 您们的**审计/纪检部门**对改造的态度？
4. ❓ 改造投入**上限**是 100 万 / 500 万 / 5000 万？
5. ❓ 改造后**是否需要保证就业**？

### 接到民营/私营业主，先问 5 问：

1. ❓ **自有资金**还是需要**融资**？
2. ❓ 业主**经营经验**多少年？
3. ❓ **风险承受**能力（最多亏多少能接受）？
4. ❓ **退出意向**（5 年内想卖？还是长期）？
5. ❓ 业主**个人偏好**（自营/加盟/全委）？

## 7. 给 Eric 的咨询建议

### 国央企业主（5 步）

```
Step 1: 帮业主判断"这项目值不值得做"（决策前评估）
Step 2: 帮业主准备"三重一大"决策材料
Step 3: 帮业主设计"合规方案"（招标+集采+审计）
Step 4: 帮业主监控"改造期合规"
Step 5: 帮业主做"投后复盘+稳岗方案"
```

### 民营/私营业主（5 步）

```
Step 1: 帮业主判断"改造 ROI"
Step 2: 帮业主选"经营模式"（自营/加盟/全委）
Step 3: 帮业主对接"供应商"
Step 4: 帮业主做"AI 接入"
Step 5: 帮业主做"长期退出计划"
```

## 关键洞察

> **Eric 在酒店业实战多年实战经验**：
> - 国央企 ≠ 民营 → 决策机制根本不同
> - 国央企的"安全"和"利润"经常冲突 → 业主需要"安全+合规"的方案
> - 民营/私营需要"ROI"和"灵活"的方案
>
> **如果 Eric 给国央企推荐了"快速决策"方案 = 灾难**
> **如果 Eric 给民营推荐了"三重一大合规方案" = 浪费时间**
