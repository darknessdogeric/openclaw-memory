# 32 项改造前检查清单（可打印）

> **用途**：Eric 1v1 咨询**实地碰面前/碰面时**用
> **目标**：**32 项必过** = 改造决策就绪
> **来源**：`pitfalls-with-cases.md` 32 个避坑（具象版）
> **结构**：**5 大类 + 32 项**

---

## 类别 1：物业资产（6 项）

| # | 检查项 | 必过 | Eric 验证 |
|---|--------|------|----------|
| 1 | 建造年份 + 上次翻新（< 15 年 + < 10 年内未翻新 = 红灯）| ☐ | |
| 2 | 结构安全（无裂缝/非危房/非加建）| ☐ | |
| 3 | 消防合规（验收证书 + 通道 + 喷淋）| ☐ | |
| 4 | 水电安全（容量足够 + 无老化 + 无违规）| ☐ | |
| 5 | 产权清晰 / 租约 ≥ 8 年 | ☐ | |
| 6 | 周边环境（无噪音/无污染/有停车/有交通）| ☐ | |

**红灯**：任 1 项不过 = 不建议重改；任 2 项不过 = 不建议改造。

---

## 类别 2：经营现状（6 项）

| # | 检查项 | 必过 | Eric 验证 |
|---|--------|------|----------|
| 7 | OCC 行业基线对比（不低于 50%）| ☐ | |
| 8 | ADR 行业基线对比（不低于竞品 -20%）| ☐ | |
| 9 | OTA 评分（≥ 4.3）| ☐ | |
| 10 | 客源结构清晰（不超过 5 个客群）| ☐ | |
| 11 | 复购率 ≥ 15%（基线）| ☐ | |
| 12 | 趋势向上或稳定（过去 12 个月）| ☐ | |

**红灯**：OCC 持续下滑 3 年 = 业主决策能力被质疑。

---

## 类别 3：财务健康（6 项）

| # | 检查项 | 必过 | Eric 验证 |
|---|--------|------|----------|
| 13 | 净利率 ≥ 5% | ☐ | |
| 14 | 现金流 ≥ 6 个月运营成本 | ☐ | |
| 15 | 改造期损失可承受（≤ 6 个月营收）| ☐ | |
| 16 | 改造总投入 ≤ 业主 2 年净利 | ☐ | |
| 17 | 备用金 ≥ 20% | ☐ | |
| 18 | 退出价值 ≥ 投入（5 年视角）| ☐ | |

**红灯**：现金流 < 3 个月 = 改造期间可能倒闭。

---

## 类别 4：组织能力（6 项）

| # | 检查项 | 必过 | Eric 验证 |
|---|--------|------|----------|
| 19 | GM 任期 ≥ 1 年 | ☐ | |

| 21 | 关键员工去留意向（至少 80% 留）| ☐ | |
| 22 | 团队流失率 ≤ 30%（年化）| ☐ | |

## 类别 5：决策与战略（8 项）

| # | 检查项 | 必过 | Eric 验证 |
|---|--------|------|----------|
| 25 | 业主类型已识别（国央企/民营/其他）| ☐ | |
| 26 | 项目进入决策流程（国央企三重一大 / 民营业主决策）| ☐ | |
| 27 | 加盟品牌选定（≥ 2 个备选 + 业绩对赌）| ☐ | |
| 28 | 改造方式选定（轻/中/重 + 装配式 / 传统）| ☐ | |
| 29 | 团队去留方案（4 类人决策）| ☐ | |
| 30 | 投后管理方案（月/季/年）| ☐ | |
| 31 | 退出计划（5/10/20 年）| ☐ | |
| 32 | 业绩对赌条款（如加盟东呈）| ☐ | |

**红灯**：业主 32 项不全部过 = 不建议启动改造。

## 国央企 vs 民营 重点差异

| 项 | 国央企重点 | 民营重点 |
|---|----------|----------|
| 1 建造/翻新 | 同 | 同 |
| 2-4 物理 | 同 | 同 |
| 5 产权 | **必查国有股 + 集团备案** | 业主自检 |
| 6 周边 | 同 | 同 |
| 7-12 经营 | 同 | 同 |
| 13-18 财务 | **必查集团审计追溯** | 业主自检 |
| 19-24 组织 | **必查稳岗可行性** | 必查业绩对赌 |
| 25 业主类型 | **必查集团总部 vs 地方** | 必查业主资金 |
| 26 决策 | **必查三重一大** | 必查业主一人决策 |
| 27 加盟 | **几乎不加盟** | 必查业绩对赌 |
| 28 方式 | 必查公开招标 | 必查装配式 |
| 29 团队 | 必查党建 | 必查股权激励 |
| 30 投后 | 必查集团考核 | 必查 KPI 体系 |
| 31 退出 | 必查国资委 | 必查市场化 |
| 32 对赌 | 极少有 | 必有 |

## 32 项的"反向使用"（避坑工具）

如果**任 1 项没通过**，**自动触发避坑**：

| 没通过 | 触发避坑 |
|--------|----------|
| #1 翻新超 15 年 | 触发"避坑 11"消防/合规预审 |
| #5 租约 < 8 年 | 触发"避坑 10"租约厘清 |
| #13 净利 < 5% | 触发"避坑 4"改造期损失计算 |
| #14 现金流 < 3 个月 | **改造期间会倒闭**——**强烈建议不改造** |
| #19 GM 即将离职 | 触发"避坑 9"团队锁定 |
| #25 业主类型未识别 | 触发"国央企 vs 民营"分流 |
| #27 无业绩对赌 | 触发"避坑 2"加盟谈判 |
| #31 无退出计划 | 触发"避坑 7"加盟费/管理费测算 |
