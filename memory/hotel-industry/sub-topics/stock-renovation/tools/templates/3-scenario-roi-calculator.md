# 3 场景 ROI 测算模板

> **用途**：1v1 咨询时给业主**算账**用
> **基于**：`stage-5-investment-estimation.md` + `roi-template.md`
> **3 场景**：保守 / 正常 / 激进（必备，避免"只算理想"）
> **配合**：`sov-private-differences.md`（国央企 +30-50% 成本）

| 指标 | 保守场景 | 正常场景 | 激进场景 |

| 新 OCC | % | % | % |
| 新 ADR | 元 | 元 | 元 |

| 净利改善 | 万/年 | 万/年 | 万/年 |

### Step 3：算回本周期

| 场景 | 静态回本 | NPV 回本（10% 折现）| 实际回本（含爬坡）|
|------|---------|----------------------|------------------|
| 保守 | ___ 年 | ___ 年 | ___ 年 |
| 正常 | ___ 年 | ___ 年 | ___ 年 |
| 激进 | ___ 年 | ___ 年 | ___ 年 |

**公式**：
- 静态回本 = 总成本 / 净利改善（年）
- 实际回本 = 静态回本 + 0.5-1 年（爬坡期）

### Step 4：算 NPV（10 年视角）

| 年份 | 净现金流 | 折现（10%）| 累计 NPV |
|------|----------|----------|----------|
| 1 | 万 | 万 | 万 |
| 2 | 万 | 万 | 万 |
| 3 | 万 | 万 | 万 |
| 4 | 万 | 万 | 万 |
| 5 | 万 | 万 | 万 |
| 10 | 万 | 万 | 万 |

**NPV > 0 = 投资可行**
**NPV < 0 = 投资不可行**

### Step 5：敏感性分析

| 变量 | -10% | -5% | 基线 | +5% | +10% |
|------|------|------|------|------|------|
| OCC | | | | | |
| ADR | | | | | |
| 总投入 | | | | | |
| 工期 | | | | | |

**最敏感：OCC 和 ADR**
**最不敏感：工期**

### Step 6：国央企/民营 调整

| 调整项 | 国央企 | 民营 |
|--------|--------|------|
| 总成本 | × 1.3-1.5 | × 1.0 |
| 工期 | × 1.5 | × 1.0 |
| 改造期损失 | × 1.5 | × 1.0 |
| 加盟费 | 极少 | 1.5-2 万/间 |
| 管理费 | 10-12% | 4-6% |
| 业绩对赌 | 极少 | 必有（东呈）|
| 回本周期 | 8-12 年 | 1.5-3 年 |

## Excel 模拟器公式

### Sheet 1：基础数据
```
A1: 房量
A2: 80

B1: 改造前 OCC
B2: 0.5

C1: 改造前 ADR
C2: 280

D1: 改造前 RevPAR (= B*C)
D2: =B2*C2

E1: 改造前月营收 (= D*30)
E2: =D2*A2*30

F1: 改造前净利率
F2: 0.05

G1: 改造前月净利 (= E*F)
G2: =E2*F2
```

### Sheet 2：3 场景
```
保守场景
新 OCC: 0.6
新 ADR: 320
新 RevPAR: =B5*C5
新月营收: =D5*A2*30
新净利率: 0.08
新月净利: =E5*F5
净利改善: =G5-G2
年改善: =H5*12

正常场景
新 OCC: 0.7
新 ADR: 360
...

激进场景
新 OCC: 0.8
新 ADR: 400
...
```

### Sheet 3：回本周期
```
静态回本（保守）= 总成本 / 年改善（保守）
= (D14 + D15 + D16) / H5

实际回本 = 静态回本 × 1.5（含爬坡）
```

### Sheet 4：NPV
```
NPV = SUM(NCF_t / (1+0.1)^t) - 总投资
= NPV(10%, 年现金流1:10) - 总投资
```

### Sheet 5：敏感性
```
对 OCC 敏感性：
净利改善(OCC=0.6) = (0.6*320 - 0.5*280) * 80 * 30 * 0.08
净利改善(OCC=0.7) = (0.7*360 - 0.5*280) * 80 * 30 * 0.1
...
```

## 模板使用 SOP

```
[Eric 1v1 咨询 - 现场算账]
   ↓
[Step 1] 业主提供基础数据（10 分钟）
   ↓
[Step 2] 套 3 场景假设（5 分钟）
   ├─ 保守：OCC +10pct, ADR +14%
   ├─ 正常：OCC +20pct, ADR +29%
   └─ 激进：OCC +30pct, ADR +43%
   ↓
[Step 3] 算回本（5 分钟）
   ├─ 静态回本
   └─ 实际回本
   ↓
[Step 4] NPV 测算（10 分钟）
   ↓
[Step 5] 敏感性（5 分钟）
   ↓
[Step 6] 国央企/民营 调整（5 分钟）
   ↓
[Step 7] 业主决策（10 分钟）
```

**总耗时 50 分钟**——可在咨询结束时直接给业主看 3 场景测算结果。

## 实际项目案例（基线对比）

### 案例 A：石家庄 7 天 3.0（民营）
| 项 | 数据 |
|----|------|
| 改造模式 | 轻改 |
| 单房 | 2.8 万 |
| 改造后 RevPAR | + 70% |
| 实际回本 | **1.5-2 年** |
| ROI | 3 场景均 > 0 |

### 案例 B：城市便捷 30 天（民营）
| 项 | 数据 |
|----|------|
| 改造模式 | 30 天极限轻改 |
| 改造期损失 | < 1 个月营收 |
| 实际回本 | **< 1.5 年** |
| ROI | 3 场景均 > 0 |

### 案例 C：国央企典型画像（200 间客房）
| 项 | 数据 |
|----|------|
| 改造模式 | 中改 |
| 单房 | 8-10 万（国央企高 30%）|
| 总成本 | 2800-3200 万 |
| 实际回本 | 8-10 年 |
| ROI | NPV 视角下可行 |

**国央企与民营的核心差异**：
- 国央企靠"战略协同 + 资产保值"算账
- 民营靠"快速回本 + 利润最大化"算账

## 测算结果的"业主解释"模板

### 解释保守场景
```
"按最保守估计（OCC 仅提升 10 个百分点，ADR 仅涨 14%），你的酒店 1.5 年回本。
这是个安全的下限——大部分真实项目实际都比这好。
"
```

### 解释正常场景
```
"按行业平均估计（OCC 提升 20 个百分点，ADR 涨 29%），你的酒店 1.2 年回本。
这是 7 天 3.0、城市便捷这些成功案例的基线。
"
```

### 解释激进场景
```
"按理想情况（OCC 提升 30 个百分点，ADR 涨 43%），你的酒店 0.8 年回本。
这是武侯祠锦里店、装配式 + 业绩对赌的最佳情况。
"
```

### 解释 NPV
```
"NPV 是 10 年视角下的'现在值'。如果 NPV > 0，说明这个项目长期看是赚的。
如果 NPV < 0，说明数学上亏钱——你不应该做。
"
```

## 测算结果的"决策建议"模板

| NPV | 回本 | 业主建议 |
|-----|------|----------|
| NPV > 0 + 正常回本 < 3 年 | ✅ 强烈建议改造 |
| NPV > 0 + 正常回本 3-5 年 | ⚠️ 视情况改造（看业主资金）|
| NPV > 0 + 正常回本 5-10 年 | ❌ 长期视角下可行，但短期压力大 |
| NPV < 0 | ❌ 不建议改造（数学上亏）|
| 保守场景 NPV < 0 | ❌ 强烈不建议改造 |

## 测算结果的"陷阱"提醒

| 陷阱 | Eric 提醒 |
|------|----------|
| "只看理想情况" | 必须看 3 场景，**保守能撑住才可行** |
| "忽略改造期损失" | 改造期损失 ≥ 50% 总投入 |
| "低估备用金" | 总投入 × 10-20% 备用金 |
| "忽略集采溢价"（国央企）| +20-30% |
| "静态 vs 动态混淆" | 考虑 NPV 折现 + 爬坡期 |
| "业主一相情愿" | 业主说"我愿意等 10 年"——但实际做不到 |

## 测算的"红线"

### Eric 必拒绝
- ❌ 业主说"我算 1 个月回本"——**明显不切实际**
- ❌ 业主只算"理想情况"——**拒绝给方案**
- ❌ 业主说"我有内部数据保证 100% 成功"——**不接**

### Eric 必警惕
- ⚠️ 业主"自我安慰"型（不愿面对现实）
- ⚠️ 业主"过度乐观"型（觉得一定能回本）
- ⚠️ 业主"赌徒心态"型（背水一战）

### Eric 必引导
- ✅ 让业主**自己算 3 场景**
- ✅ 让业主**自己判断保守场景**
- ✅ 让业主**自己决定是否签约**
