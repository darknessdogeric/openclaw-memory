## 一、前厅岗位SOP

### 1.1 前台接待员

```
前台接待员一日工作:
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  上班前准备:                                               │
│  ├── 更换制服，整理仪容                                   │
│  ├── 检查工作用品(房卡/早餐券/押金单)                  │
│  ├── 登录PMS系统，检查当班信息                           │
│  ├── 了解当日预订/VIP/特殊事项                          │
│  └── 参加晨会                                             │
│                                                             │
│  班中工作:                                                 │
│  ├── 迎接客人，微笑问候                                   │
│  ├── 办理入住: 确认预订→证件登记→收取押金→制作房卡   │
│  ├── 办理退房: 收回房卡→查房→结算→开发票→送别        │
│  ├── 回答问询: 交通/餐饮/旅游/设施等                  │
│  ├── 接听电话: 转接/预订/问询等                         │
│  ├── 处理投诉: 记录→安抚→解决/上报                     │
│  └── 特殊事项: VIP接待/紧急事项处理                      │
│                                                             │
│  班后交接:                                                 │
│  ├── 交接未完成事项                                       │
│  ├── 交接特殊客人/特殊需求                                │
│  ├── 交接遗留物品                                         │
│  └── 交接设备/钱款                                        │
│                                                             │
│  关键KPI:                                                  │
│  ├── 入住办理时间: <3分钟                                │
│  ├── 退房办理时间: <5分钟                                │
│  ├── 电话接听: 3声内接听                                 │
│  └── 客户满意度: >95%                                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 二、客房岗位SOP

### 2.1 客房清洁员

```
客房清洁员工作流程:
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  清洁前准备:                                               │
│  ├── 领取房卡/工作车/清洁用品                            │
│  ├── 检查工作车物品是否齐全                                │
│  └── 了解当日清洁任务(走房/住房/空房)                   │
│                                                             │
│  走客房清洁(30-40分钟):                                   │
│  ├── 进房: 按门铃/敲门→开门→开窗通风                     │
│  ├── 撤布草: 床单/被套/枕套/毛巾/浴巾/地巾               │
│  ├── 铺床: 铺床单→套被套→套枕套→整理                    │
│  ├── 清洁卫生间: 镜子→台面→马桶→浴缸→地面              │
│  ├── 清洁房间: 家具除尘→电器清洁→地面清洁               │
│  ├── 补充物品: 客房用品/茶包/矿泉水                       │
│  └── 检查: 环视房间→关闭门窗→锁门→登记                  │
│                                                             │
│  住客房清洁(15-20分钟):                                   │
│  ├── 敲门询问: "客房服务，请问可以清洁吗"               │
│  ├── 如不便: 记录时间，稍后再来                           │
│  ├── 如可: 快速整理                                       │
│  ├── 不换床单(除非客人要求)                               │
│  └── 物品补充，不动客人私物                               │
│                                                             │
│  退房检查:                                                  │
│  ├── 配合前台查房                                         │
│  ├── 检查物品有无损坏/缺失                                 │
│  └── 检查迷你吧/遗留物品                                   │
│                                                             │
│  关键KPI:                                                  │
│  ├── 走客房清洁时间: 30-40分钟                           │
│  ├── 清洁合格率: >95%                                     │
│  └── 查房返工率: <5%                                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
