## 二、携程 (Ctrip/Trip.com) 深度解析

### 2.1 携程排序算法

```
综合排名分 = P_Quality × 0.4 + P_Conversion × 0.3 + P_Service × 0.2 + P_Growth × 0.1

其中:
P_Quality (质量分): 基础分,相对稳定
P_Conversion (转化分): 实时变动,权重最高
P_Service (服务分): 投诉率/好评率
P_Growth (增长分): 平台扶持新动力
```

### 2.2 携程质量分解

```
P_Quality 构成:
├── 基础分 (静态, 30%)
│   ├── 酒店星级/档位
│   ├── 设施配置
│   └── 位置评分
│
├── 转化分 (实时, 35%) ⚠️最关键
│   ├── 详情页转化率
│   ├── 搜索-下单转化率
│   ├── 曝光-转化率
│   └── 影子转化率 (点击后是否最终成交)
│
├── 服务分 (月度, 25%)
│   ├── 好评分 (NPS调研)
│   ├── 投诉率
│   ├── 取消率
│   └── 违约率
│
└── 增长分 (动态, 10%)
    ├── GMV增长率
    └── 新客获取率
```

### 2.3 携程信息质量优化

**首图优化**:
```
规则: 首图点击率决定80%曝光价值

高点击率首图特征:
✅ 房间全景图 (有床/窗/光线)
✅ 无水印/无边框
✅ 暖色调为主 (黄色/橙色)
✅ 展示独特卖点 (海景/浴缸/露台)
❌ 酒店外观图 (转化率低)
❌ 卫生间特写 (过于私密)
❌ 多人合照 (显得拥挤)
```

**名字优化**:
```
携程酒店名规则:
[品牌名] + [位置/商圈] + [酒店] + [星级符号] + [特色标签]

示例:
"成都春熙路太古里亚朵酒店⭐⭐⭐⭐⭐"
"北京王府井希尔顿酒店"

名字优化策略:
1. 位置关键词前置 (携程用户先看位置)
2. 地标词要有 (太古里/国贸/西湖)
3. 品牌词要有 (亚朵/希尔顿)
4. 避免无意义符号
```

**标签体系**:
```
携程热门标签:
🔥 "豪华型" | "高档型" | "舒适型"
📍 "近地铁" | "近景区" | "近会展中心"
🏷️ "亲子友好" | "商务出行" | "浪漫情侣"
⭐ "4.8分高评" | "2023年新装修"
🍳 "含早餐" | "免费停车"

标签选择原则:
1. 选择有流量的大标签 (曝光多)
2. 选择与本店匹配的标签 (转化高)
3. 避免不相关的标签 (会被处罚)
```

### 2.5 携程合作模式

```
直连模式 (Hotel Connect):
- PMS直连,实时库存
- 佣金率: 10-20%
- 优势: 排名加权,实时促销
- 劣势: 价格管控难

代理模式 (Agency):
- 携程作为中间商
- 佣金率: 15-25%
- 优势: 流量大,转化高
- 劣势: 佣金高,管控弱

闪住/信用住:
- 免担保入住,离店扣款
- 提升转化率15-20%
- 有手续费0.5-1%
```

## 三、美团酒店深度解析

### 3.1 美团排序算法

```
美团排名 = 基础分 × 0.3 + 转化分 × 0.35 + 活动分 × 0.2 + 商户分 × 0.1 + 增长分 × 0.05

美团特点:
1. 转化分权重更高 (美团用户决策链路短)
2. 活动参与度影响大 (美团用户爱占便宜)
3. 团购基因强 (多人出行/餐饮打包)
```

### 3.2 美团流量入口

```
主要流量入口:
1. 搜索入口 (50-60%)
2. 频道入口 (20-30%)
   - 周边游/周末游
   - 酒店榜单
   - 限时秒杀
3. 推广入口 (10-15%)
   - 点金推广
   - 旺铺宝
```

### 3.3 美团酒店特殊规则

```
美团独有机制:
1. "黄金展位"
   - 搜索结果前3名
   - 按点击付费(CPC)
   - 起拍价: ¥2-5/点击

2. "今日特价"专区
   - 低于市场价的房源
   - 平台流量扶持
   - 要求: 折扣≥15%

3. "多店通"套餐
   - 酒店+景点+餐饮
   - 打包销售,提升客单价
   - 适合度假型酒店

4. "差旅酒店"专区
   - 企业客户专属
   - 需要企业认证
   - 定价需低于市场20%+
```

### 3.4 美团收益策略

```
高收益策略:
1. 参与限时秒杀
   - 折扣15-30%
   - 换取平台流量
   - 适合: OCC<60%时

2. 设置阶梯价
   - 提前14天: 9折
   - 提前7天: 95折
   - 当日: 正价
   - 提升提前预订率

3. 多店通打包
   - 酒店+早餐+景区
   - 提升客单价30-50%
   - 降低比价敏感度

4. 团购预售
   - 售未来6个月房间
   - 回笼资金
   - 需设置可退条款
```

## 五、OTA价格管控策略

### 5.1 价格一致性原则

```
核心规则: 各渠道价格差≤15%

价格管控矩阵:
                    官网/直销    携程    美团    飞猪
直连协议价(底价)      基准       -5%     -3%     -5%
会员价               基准×0.9    协议     协议    协议
OTA挂牌价            基准×1.1    最低     最低    最低

原则:
1. 任何渠道价格不能低于协议价
2. 官网价格应该是全网最低
3. OTA活动特价需要申请报备
```

### 5.2 渠道价格监控

```
监控工具:
1. 自己监控
   - 每天记录各平台价格
   - 建立价格数据库
   - 发现违规及时投诉

2. 第三方工具
   - 漫步者(ManyInputs)
   - 大数据房态管理系统
   - 众荟(ChinaHotelPay)

违规处理:
1. 首次: 沟通警告
2. 二次: 平台投诉
3. 多次: 减少库存配额
4. 严重: 暂停合作
```

### 5.3 佣金谈判策略

```
佣金优化原则:
1. 阶梯佣金
   - 月GMV<¥10万: 15%
   - 月GMV10-30万: 13%
   - 月GMV>30万: 10-12%

2. 年度框架协议
   - 承诺GMV目标
   - 换取更低佣金率
   - 争取更多资源位

3. 直连vs代理
   - 直连佣金: 10-15%
   - 代理佣金: 20-25%
   - 优先直连

谈判要点:
1. 展示竞品平台数据
2. 提供历史GMV证明
3. 承诺增长目标
4. 要求流量扶持
```

## 六、OTA与酒店的博弈论

### 6.1 囚徒困境

```
酒店与OTA的博弈:

          酒店配合         酒店违规
OTA配合   (10, 10)        (0, 15)  ← OTA配合但酒店违规,OTA受损
OTA违规   (15, 0)         (5, 5)   ← 双方互损

均衡点: 双方都违规 (5,5) ← 囚徒困境的纳什均衡
       但整体最优是双方配合 (10,10)
```

### 6.2 酒店的最优策略

```
混合策略 (不可预测性):
1. 30%时间配合平台活动
2. 50%时间维持价格稳定
3. 20%时间参与限时特价

这样做的好处:
- 保持排名,不触犯平台
- 维持收益,不完全依赖活动
- 保留余地,应对突发情况
```

### 6.3 平台最怕酒店做什么

```
平台最讨厌的行为:
1. ❌ 私下引流 (绕过平台交易)
2. ❌ 虚假评价 (刷单/删差评)
3. ❌ 恶意竞争 (价格战)
4. ❌ 频繁调价 (扰乱市场)
5. ❌ 无故取消订单 (损害用户体验)

酒店应该做:
1. ✅ 提升转化率 (帮平台赚钱)
2. ✅ 维护评分口碑
3. ✅ 参与平台活动
4. ✅ 发展私域流量
```

## 十、Python OTA分析工具

```python
class OTAPerformanceAnalyzer:
    """OTA表现分析工具"""

    def __init__(self):
        self.data = {}

    def add_platform(self, platform: str, exposure: int, click: int,
                    order: int, revenue: float, commission: float):
        """添加平台数据"""
        self.data[platform] = {
            'exposure': exposure,
            'click': click,
            'order': order,
            'revenue': revenue,
            'commission': commission
        }

    def calculate_metrics(self, platform: str) -> Dict:
        """计算单平台指标"""
        d = self.data[platform]
        ctr = d['click'] / d['exposure'] * 100 if d['exposure'] > 0 else 0
        cvr = d['order'] / d['click'] * 100 if d['click'] > 0 else 0
        exp_cvr = d['order'] / d['exposure'] * 100 if d['exposure'] > 0 else 0
        net_revenue = d['revenue'] * (1 - d['commission'])
        cpa = d['commission'] * d['exposure'] / d['order'] if d['order'] > 0 else 0

        return {
            '曝光数': d['exposure'],
            '点击数': d['click'],
            '订单数': d['order'],
            '收入': f"¥{d['revenue']:,.0f}",
            '净收入': f"¥{net_revenue:,.0f}",
            '佣金率': f"{d['commission']:.1%}",
            'CTR': f"{ctr:.2f}%",
            'CVR': f"{cvr:.2f}%",
            '曝光转化率': f"{exp_cvr:.3f}%",
            'CPA': f"¥{cpa:.2f}",
            'ROI': f"{d['revenue']/(d['commission']*d['exposure']):.1f}x" if cpa > 0 else "N/A"
        }

    def channel_contribution(self) -> Dict:
        """渠道贡献度分析"""
        total_revenue = sum(d['revenue'] for d in self.data.values())
        total_order = sum(d['order'] for d in self.data.values())

        result = {}
        for platform, d in self.data.items():
            result[platform] = {
                'GMV占比': f"{d['revenue']/total_revenue*100:.1f}%",
                '订单占比': f"{d['order']/total_order*100:.1f}%",
                '净收入': f"¥{d['revenue']*(1-d['commission']):,.0f}",
                '推荐': '⭐⭐⭐⭐⭐' if d['revenue']/total_revenue > 0.4 else
                       '⭐⭐⭐' if d['revenue']/total_revenue > 0.2 else '⭐'
            }
        return result

    def recommend_allocation(self) -> Dict:
        """推荐渠道分配"""
        total = sum(d['order'] for d in self.data.values())
        if total == 0:
            return {}

        # 基于订单量和净收入计算推荐分配
        scores = {}
        for platform, d in self.data.items():
            net = d['revenue'] * (1 - d['commission'])
            score = net / total if total > 0 else 0
            scores[platform] = max(0.1, min(0.6, score * 2))

        return scores

    def print_report(self):
        """打印完整报告"""
        print("=" * 70)
        print("OTA表现分析报告")
        print("=" * 70)

        for platform in self.data:
            print(f"\n【{platform}】")
            metrics = self.calculate_metrics(platform)
            for k, v in metrics.items():
                print(f"  {k}: {v}")

        print("\n" + "=" * 70)
        print("渠道贡献度")
        print("=" * 70)
        contrib = self.channel_contribution()
        for platform, data in contrib.items():
            print(f"\n{platform}:")
            for k, v in data.items():
                print(f"  {k}: {v}")

        print("\n" + "=" * 70)
        print("推荐分配")
        print("=" * 70)
        alloc = self.recommend_allocation()
        for platform, ratio in alloc.items():
            print(f"  {platform}: {ratio*100:.0f}%")
```
