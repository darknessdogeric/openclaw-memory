## 一、餐饮部的本质

```
┌──────────────────────────────────────────────────────────────────────┐
│  餐饮部的五维认知                                                 │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  【1️⃣ 历史沿革】                                                  │
│  ├── 古代: 驿站提供饮食 → 基本饱腹                             │
│  ├── 1860s: 租界西餐厅 → 洋餐进入中国                        │
│  ├── 1980s: 合资酒店引入 → 中西餐+宴会标准化                │
│  ├── 1990s: 高端餐饮崛起 → 燕鲍翅/商务宴                      │
│  ├── 2000s: 大众餐饮爆发 → 餐饮成为酒店标配                  │
│  ├── 2010s: 餐饮转型 → 从利润中心到体验中心                  │
│  └── 2020s: 疫情冲击+复苏 → 外卖/半成品/直播               │
│                                                                      │
│  【2️⃣ 目前情况】                                                  │
│  ├── 餐饮收入占比: 全服务酒店30-40%，经济型<10%             │
│  ├── 餐饮毛利率: 中餐50-60% / 西餐55-65% / 宴会60-70%       │
│  ├── 餐饮人工占比: 占餐饮收入35-45%                          │
│  ├── 餐饮点数率: 中餐1.5-2.0 / 西餐2.5-3.0                  │
│  └── 发展趋势: 从"吃的餐厅"到"体验的场所"                  │
│                                                                      │
│  【3️⃣ 原因分析】                                                  │
│  ├── 收益贡献: 餐饮是酒店第二大收入来源                     │
│  ├── 体验价值: 好的餐饮体验显著提升口碑                      │
│  ├── 竞争压力: 社会餐饮崛起，酒店餐饮需差异化               │
│  ├── 成本压力: 人工/租金/食材三大成本持续上升               │
│  └── 客群变化: 年轻客群更注重体验/颜值/社交                │
│                                                                      │
│  【4️⃣ 未来预判】                                                  │
│  ├── 2025: 酒店餐饮外卖化，堂食预约制普及                   │
│  ├── 2030: AI厨房/机器人服务员成为可能                      │
│  └── 趋势: "餐饮+体验+社交"三位一体                        │
│                                                                      │
│  【5️⃣ 底层逻辑】                                                  │
│  └── 餐饮本质: "舌尖上的信任建立"                           │
│      → 食物是进入身体的，安全是绝对底线                       │
│      → 美味是主观体验，满足基本需求                          │
│      → 体验是情感连接，创造超越期待                          │
│      → 社交是场景延伸，餐饮是关系催化剂                      │
│                                                                      │
└──────────────────────────────────────────────────────────────────────┘
```

## 六、餐饮SOP标准流程

### 6.1 中餐服务SOP

```
┌──────────────────────────────────────────────────────────────────────┐
│  中餐服务SOP标准流程                                              │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  【为什么要这样做-Why this SOP exists】                              │
│  ├── 保证出品稳定: 任何厨师出品都达到标准                       │
│  ├── 提升服务效率: 流程标准化减少等待                         │
│  ├── 控制成本浪费: 标准配比控制成本                           │
│  └── 建立服务规范: 服务有标准可循                             │
│                                                                      │
│  ┌──────────────────────────────────────────────────────────────┐  │
│  │                    中餐服务流程                              │  │
│  └──────────────────────────────────────────────────────────────┘  │
│                                                                      │
│  Phase 1: 餐前准备 (Why: 准备充分才能服务到位)                  │
│  ├── 环境: 摆台/灯光/空调/音乐                               │
│  ├── 餐具: 按菜单备餐具                                      │
│  ├── 菜品: 检查食材/预制部分                                │
│  ├── 人员: 仪容仪表/分工明确                              │
│  └── 开餐会: 主管通报今日特荐/沽清                        │
│                                                                      │
│  Phase 2: 迎宾 (Why: 第一印象决定服务基调)                    │
│  ├── 站位: 门口/电梯口迎接                                  │
│  ├── 问候: "中午好，欢迎光临"                               │
│  ├── 带位: 根据人数/预订安排座位                          │
│  └── 递茶: 第一杯迎客茶                                     │
│                                                                      │
│  Phase 3: 点单 (Why: 了解需求才能服务到位)                    │
│  ├── 递菜单: 女士优先                                       │
│  ├── 推销: 按客群特征推荐                                  │
│  │   ├── 商务: 推招牌/高价菜                             │
│  │   ├── 家庭: 推实惠/分量足                            │
│  │   └── 年轻: 推新菜/特色菜                            │
│  ├── 特殊: 过敏/宗教/忌口记录                           │
│  ├── 确认: 重述订单确认                                  │
│  └── 下单: 尽快输入PMS/厨房打印机                      │
│                                                                      │
│  Phase 4: 等餐 (Why: 等餐时间需要被关注)                    │
│  ├── 上冷菜: 10分钟内                                    │
│  ├── 添茶: 茶盅随时观察                                  │
│  ├── 催单: 超过标准时间主动跟进                        │
│  └── 致歉: 延误时主动致歉                               │
│                                                                      │
│  Phase 5: 上菜 (Why: 上菜顺序与节奏影响体验)                │
│  ├── 顺序: 冷菜→热菜→主食→水果                        │
│  ├── 报菜: "这是XX菜，请慢用"                          │
│  ├── 分菜: 公筷分菜(包间)                              │
│  ├── 撤盘: 吃完再撤，保持桌面                         │
│  └── 节奏: 与客人确认上菜节奏                         │
│                                                                      │
│  Phase 6: 结账 (Why: 买单是服务的收尾)                      │
│  ├── 核对: 账单核对无误                                 │
│  ├── 递交: 双手递上账单                                │
│  ├── 收款: 确认付款方式                               │
│  ├── 找零: 准确无误                                   │
│  └── 发票: 按需开具，发票双手递                      │
│                                                                      │
│  Phase 7: 送客 (Why: 送客是服务的延伸)                      │
│  ├── 感谢: "感谢光临，欢迎再来"                         │
│  ├── 送客: 送至电梯口                                  │
│  ├── 记客: 重要客人记入客史                            │
│  └── 翻台: 快速翻台准备下一轮                         │
│                                                                      │

│  ├── 上菜: ★★☆☆☆ 30% (需人工判断)                      │
│  ├── 结账: ★★★★★ 95% (已成熟)                          │
│  └── 送客: ★★☆☆☆ 20% (需人情味)                       │
│                                                                      │
```
