## 一、核心判断框架

### 1.1 量化交易是什么

```
定义：用数学模型和计算机程序系统性地执行交易策略

传统主观交易：
  人工分析 → 判断 → 执行（情绪干扰大，速度慢）

量化交易：
  数据 → 模型 → 信号 → 自动执行（纪律性强，可规模化）

核心优势：
  - 纪律性（不受情绪干扰）
  - 可规模化（一个策略可复制到多个市场）
  - 可回测（用历史数据验证策略有效性）
  - 处理海量信息（同时监控100+标的）
```

### 1.2 量化交易的适用边界

```
量化能做什么：
  ✓ 高频交易（日内大量交易，捕捉微小价差）
  ✓ 统计套利（寻找相关资产的价格偏离）
  ✓ 趋势跟踪（系统化执行趋势策略）
  ✓ 因子投资（量化选股，剥离风险因子）
  ✓ 风险对冲（系统性风险管理）

量化不能做什么：
  ✗ 预测黑天鹅事件
  ✗ 处理突发政策变化
  ✗ 理解"叙事"和"情绪"（但可以量化情绪指标）
  ✗ 彻底消除风险（只能管理风险）

张实的定位：
  - 不做高频/技术性量化
  - 做"低频有逻辑支撑的量化思维"
  - 大乐透预测 = 量化思维的娱乐化应用
  - 未来酒店投资决策 = 需要量化思维
```

## 二、量化交易基础体系

### 2.1 量化策略的分类

```
按时间维度：
  高频交易 (HFT):    毫秒~秒级持仓，日内成千上万次交易
  做市商策略:        赚买卖价差，提供流动性
  趋势跟踪:          日~周级持仓，顺势而为
  均值回归:          日~月级持仓，价格围绕价值波动
  价值投资:          月~年级持仓，量化选股

按方法论：
  技术面量化:        价格/成交量/技术指标
  基本面量化:        财务数据/估值/因子
  统计套利:          相关资产的价差/比率
  机器学习:          非线性模式识别（趋势减弱）
```

### 2.2 量化策略的核心要素

```
数据：
  - 价格数据（开盘/最高/最低/收盘/成交量）
  - 基本面数据（财务报表/估值指标）
  - 替代数据（舆情/卫星/消费记录）——前沿

信号：
  - 输入：原始数据
  - 处理：指标计算/因子暴露
  - 输出：买卖信号

仓位管理：
  - 仓位大小（全仓/半仓/1/3仓）
  - 风险管理（止损/止盈/分散）

执行：
  - 市价单（立即成交）
  - 限价单（等待价格达到）
  - 算法执行（VWAP/TWAP/冰山）
```

## 三、技术分析量化（最实用）

### 3.1 核心指标体系

```
趋势指标：
  - 移动均线 (MA): 5/10/20/60/120日
  - 指数移动均线 (EMA): 对近期价格更敏感
  - MACD: 12-EMA - 26-EMA + Signal(9)
  - ADX: 趋势强度，>25确认趋势

动量指标：
  - RSI: 0-100，>70超买，<30超卖
  - KD随机指标: %K和%D，交叉信号
  - CCI: 顺势指标，>100超买，<-100超卖
  - 动量(Momentum): N日价格变化率

波动率指标：
  - 布林带 (Bollinger Bands): MA±2个标准差
  - ATR: 平均真实范围，衡量波动
  - 历史波动率: N日收益率的标准差年化

量价指标：
  - 成交量加权平均价 (VWAP)
  - OBV: 能量潮，量先于价
  - 放量/缩量: 成交量的变化率
```

### 3.2 常见技术策略的量化逻辑

```
策略1：均线交叉
  买入信号：短期MA上穿长期MA（金叉）
  卖出信号：短期MA下穿长期MA（死叉）
  
  参数优化：
    快线 = 5日，慢线 = 20日 → 历史表现如何？
    快线 = 10日，慢线 = 60日 → 哪个夏普比率更高？

策略2：RSI超卖反弹
  买入信号：RSI < 30（超卖区）
  卖出信号：RSI > 70（超买区）
  
  优化：30/70换成20/80？加入趋势过滤？

策略3：布林带突破
  买入信号：价格触及下轨（超卖）
  卖出信号：价格触及上轨（超买）
  
  中轨 = 20日MA，可作为止损参考
```

### 3.3 技术分析的真实局限

```
有效市场假设：价格已经反映所有公开信息

技术分析的争议：
  - 被动型指数基金长期跑赢大多数主动基金
  - 技术分析在个股上比在大盘指数上更有效
  - 高频交易会"收割"使用技术分析的交易者

理性使用方式：
  - 技术分析 ≠ 预测工具，而是风险管理工具
  - 用技术分析设定止损位比预测方向更可靠
  - 多指标共振 → 信号可靠性提高

对大乐透的启发：
  - 彩票没有"技术分析"，因为每次开奖独立随机
  - 但量化思维（概率/期望值/风险管理）仍然适用
```

## 四、因子模型与量化选股

### 4.1 因子投资基础

```
因子（Factor）= 解释资产回报的系统性风险来源

价值因子：
  - 低PE/PB → 被低估 → 长期超额收益
  - EV/EBITDA → 更全面评估企业价值
  - 股息率 → 现金回报

动量因子：
  - 过去N月涨幅高的股票 → 继续涨
  - 过去N月跌幅大的股票 → 继续跌
  - 动量崩溃（momentum crash）= 极端反转风险

质量因子：
  - 高ROE/ROA → 盈利能力
  - 低负债率 → 财务健康
  - 高利润率 → 定价权

规模因子：
  - 小市值股票长期超额收益
  - 但也有"小市值陷阱"

趋势因子：
  - 52周新高 → 动量持续
  - 成交量放大确认趋势
```

### 4.2 多因子模型

```
Barra多因子模型（全球使用最广）：
  
  R_i = α_i + β_i1·F1 + β_i2·F2 + ... + ε_i
  
  R_i = 股票i的回报
  F1 = 市值因子（风险暴露）
  F2 = 价值因子
  F3 = 动量因子
  β_i1 = 股票i对因子F1的暴露程度
  α_i = 无法被因子解释的超额收益（选股能力）

Fama-French三因子模型：
  R_i - R_f = α + β_m·(R_m - R_f) + β_s·SMB + β_h·HML + ε_i
  
  (R_m - R_f) = 市场超额回报
  SMB = Small Minus Big（小市值溢价）
  HML = High Minus Low（价值溢价）
```

### 4.3 因子投资的实战步骤

```
Step 1: 选股池定义
  - 全市场？沪深300？创业板？
  - 行业专注？剔除流动性差的？

Step 2: 因子计算
  - 每个股票计算各因子暴露（PE/ROE/动量等）
  - 数据标准化（Z-score归一化）

Step 3: 因子组合
  - 等权组合？因子IC加权？
  - 避免因子拥挤（crowding）

Step 4: 回测
  - 历史5-10年数据测试
  - 考虑交易成本（佣金/滑点/冲击成本）
  - 剔除流动性差的股票

Step 5: 风险控制
  - 单股仓位上限（<5%）
  - 行业集中度控制
  - 最大回撤止损
```

## 五、回测：量化策略的试金石

### 5.1 回测的原理

```
回测 = 用历史数据模拟策略表现

如果策略在历史数据上表现好：
  → 有可能在未来也有效
  → 但不保证（过拟合风险）

如果策略在历史数据上表现差：
  → 未来大概率也差
  → 直接放弃
```

### 5.2 回测的关键指标

```
核心指标：

年化收益率 (CAGR):
  = (期末价值/期初价值)^(1/年数) - 1
  年化15%以上 = 优秀

最大回撤 (Max Drawdown):
  = 从峰值到谷底的最大跌幅
  >30% = 危险信号
  
夏普比率 (Sharpe Ratio):
  = (年化收益 - 无风险利率) / 年化波动率
  >1.5 = 良好
  >2 = 优秀

卡玛比率 (Calmar Ratio):
  = 年化收益 / 最大回撤
  >2 = 良好

胜率 (Win Rate):
  = 盈利交易次数 / 总交易次数
  趋势跟踪通常40-50%胜率
  均值回归通常60-70%胜率

盈亏比 (Profit/Loss Ratio):
  = 平均盈利 / 平均亏损
  趋势跟踪通常>1.5
```

### 5.3 过拟合：最大的敌人

```
过拟合 = 策略"记住"了历史噪音，而不是学到了真实规律

过拟合的信号：
  - 回测曲线完美（太漂亮的曲线通常是假的）
  - 参数在边界值上（23.7天均线刚好最好？可疑）
  - 样本外测试和样本内测试差异巨大
  - 策略复杂度高（10个参数）但数据点少

如何避免过拟合：
  1. 简单策略优先（Occam's Razor）
  2. 参数留有余地（不要刚好卡在最优值）
  3. 样本外验证（用没用过的数据测试）
  4. 蒙特卡洛模拟（随机打乱历史数据）
  5. Walk-forward分析（滚动窗口）
```

## 六、量化与大乐透

### 6.1 彩票为什么不是量化策略

```
彩票 vs 量化交易的核心区别：

         | 彩票         | 量化交易
---------|-------------|-------------
独立性    | 每期独立随机  | 前后相关（趋势/回归）
可预测性  | 理论上不可预测 | 部分可预测
期望值    | <0（庄家优势）| >0（理论上）
历史数据  | 无法预测未来  | 可以预测未来

彩票的关键事实：
  - 大乐透后区2个号码：每个号码是独立事件
  - 历史号码出现频率 ≠ 未来出现概率
  - "热号"只是心理错觉（赌徒谬误）
  - 庄家优势 = 销售佣金 + 奖金小于销售额
```

### 6.2 量化思维在彩票中的正确应用

```
虽然不能预测，但量化思维有用：

1. 资金管理（Kelly Criterion）：
   每次押多少？Kelly公式：f* = (bp - q) / b
   f* = 押注比例，b = 赔率-1，p = 胜率，q = 1-p
   
   大乐透：期望值为负 → Kelly告诉你要么不玩，要么极小注

2. 期望值计算：
   如果一等奖概率 = 1/21,425,850
   一等奖期望 = 1/21,425,850 × 500万 ≈ ¥0.023
   每张3元买的彩票，期望价值 ¥0.023（亏¥2.977）
   
3. 组合优化（不能提高胜率，但能改变奖池分配）：
   避开热门号码组合 → 万一中了，分到的奖更多
   这是唯一的"量化优势"

结论：彩票是娱乐消费，不是投资。量化改变不了胜率。
```

## 七、量化思维在酒店投资决策中的应用

### 7.1 酒店投资的风险量化

```
传统酒店投资决策：
  "这个位置好，人流量大，应该能赚钱"
  → 没有量化依据

量化思维决策：
  1. 收入端量化
     - 周边竞品的OCC/ADR/RevPAR历史数据
     - 季节性波动率（标准差）
     - 竞争格局变化（新增供给）
  
  2. 成本端量化
     - 固定成本占比（租金/人工）
     - 变动成本（水电/一次性用品）
     - 盈亏平衡点计算
  
  3. 风险量化
     - 压力测试：OCC降至50%时是否亏损？
     - 敏感性分析：ADR变化1%对利润的影响
     - 蒙特卡洛模拟：1000次随机模拟，5%分位数回报
```

### 7.2 酒店资产定价的量化模型

```
收益法估值：
  价值 = NOI / Cap Rate
  
  NOI = 营业收入 - 运营成本（不含利息/折旧/摊销）
  Cap Rate = 市场资本化率（根据位置/档次/年期调整）

Cap Rate参考（2024-2025中国市场）：
  - 一线城市核心位置：4.5-5.5%
  - 二线城市核心位置：5.5-6.5%
  - 三四线城市：6.5-8.0%
  - 经济型连锁：6.0-7.5%
  - 中高端连锁：5.5-6.5%

例子：
  年NOI = 500万
  Cap Rate = 6%
  估值 = 500/0.06 = 8333万
  
  如果报价1亿，Cap Rate = 5%，偏贵
  真实价值 = 500/0.05 = 1亿，刚好合理
```

### 7.3 酒店项目的量化决策框架

```
决策树：

1. 市场可行性
   - 半径3公里内人口密度/商务浓度
   - 竞品OCC是否 >65%？（低于则市场存疑）
   - 未来3年新增供给量

2. 财务可行性
   - GOP Margin是否 >35%？（运营能力门槛）
   - RevPAR index是否 >100？（相对市场溢价能力）
   - EBITDA是否是正是负？

3. 风险评估
   - 单情景IRR vs 压力情景IRR
   - 5年后退出估值（Cap Rate敏感性）
   - 资金成本 vs NOI增长
```

### 8.2 一个简单的均线交叉回测

```python
import akshare as ak
import pandas as pd
import numpy as np

# 1. 获取数据
df = ak.stock_zh_a_hist(symbol="000001", period="daily", start_date="20200101", end_date="20241231")

# 2. 计算均线
df['MA5'] = df['收盘'].rolling(5).mean()
df['MA20'] = df['收盘'].rolling(20).mean()

# 3. 生成信号
df['signal'] = 0
df.loc[df['MA5'] > df['MA20'], 'signal'] = 1  # 金叉买入
df.loc[df['MA5'] < df['MA20'], 'signal'] = -1  # 死叉卖出

# 4. 计算收益
df['returns'] = df['收盘'].pct_change()
df['strategy'] = df['signal'].shift(1) * df['returns']  # 信号延迟1天避免偷价

# 5. 评估
cumulative_return = (1 + df['strategy']).prod() - 1
annual_return = (1 + cumulative_return) ** (252/len(df)) - 1
sharpe = df['strategy'].mean() / df['strategy'].std() * np.sqrt(252)

print(f"年化收益: {annual_return:.2%}")
print(f"夏普比率: {sharpe:.2f}")
```

## 九、2026年量化交易趋势

### 9.1 当前时间点（2026-04）

```
市场状态：
  - AI/机器学习量化策略正在"卷死"传统统计套利
  - 高频交易被少数几家量化基金垄断
  - 个人量化（散户型）越来越难生存

关键趋势：
  1. 因子拥挤：传统因子（价值/动量）越来越难赚钱
  2. 另类数据：卫星/舆情/消费数据成为新alpha来源
  3. 机器学习：从线性模型转向非线性（但过拟合风险也更高）
  4. 合规收紧：程序化交易需要向交易所备案

对张实的启示：
  - 不做高频量化（没有技术优势）
  - 聚焦低频基本面量化（酒店投资决策辅助）
  - 量化思维比量化技术更重要
```

### 9.2 量化交易的哲学反思

```
有效市场 vs 阿尔法机会：

  有效市场假说(EMH): 价格已经反映所有已知信息，无法持续获得超额收益
  现实: 市场在大多数时候是有效的，但偶尔会有失效（错误定价）

量化的本质：
  不是"战胜市场"，而是"系统性执行一个逻辑支撑的策略"
  核心问题：这个策略有逻辑支撑吗？能承受失败吗？

最危险的人：
  - 懂一点量化，但不懂风险管理的"半吊子量化"
  - 用回测美化策略，忽视过拟合的"回测交易员"
```
