### 修复建议（下次升级时处理）

```python
# 错误写法（当前）
async def collect_hangyan_data(self):
    page = self.session.fetch(url)  # 同步 API
    
# 修复方案 A：同步函数
def collect_hangyan_data(self):
    page = self.session.fetch(url)

# 修复方案 B：异步函数 + AsyncFetcher
from scrapling.fetchers import AsyncStealthyFetcher
async def collect_hangyan_data(self):
    async with AsyncStealthyFetcher() as session:
        page = await session.fetch(url)
```
