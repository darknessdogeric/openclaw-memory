## 一、前厅部SOP&P&P

### 1.1 前厅部概述与定位

前厅部是酒店系统的"神经中枢"，是酒店的一线职能部门和"窗口"。它作为迎送客人、接待客人、推销客房及餐饮等产品的"计划、组织、指挥、协调职能的首席管理部门"，也是酒店经营的"执行与反馈"部门，以及"直接为客人提供各种综合服务的部门"。其服务氛围和质量是塑造客人第一印象的关键，直接影响酒店形象与经济效益。

**工作目标**：尽最大可能推销客房及酒店其他产品，协调各部门向客人提供满意的服务，使酒店获得理想的经济效益和社会效益。

**组织架构**：前厅部实行经理负责制，向驻店经理报告。部门内部实行四级管理：经理→主管→领班→员工。下设：宾客服务经理、前台、商务中心、宾客服务中心、礼宾部。

### 1.2 前台服务SOP（71项标准程序）

#### 入住服务流程

**欢迎问候客人**（FO-SOP-FD-001）
- 当客人接近前台时，面带微笑主动问候并有目光接触："早上/下午/晚上好，先生/女士，请问可以为您帮忙吗？"
- 如果是VIP/酒店常客，尽量以客人姓氏称呼；如知道职位，应以职位称呼（如朱总、张局长）
- 办理入住手续时，从拿到身份证件后全程以姓氏称呼客人
- 退房时确认房号后查询系统客人资料，以姓氏称呼

**无预订散客入住接待程序**
1. 热情问候并确认可售房型
2. 查验有效身份证件，填写入住登记单
3. 确认入住天数、人数、房型、房价、付款方式
4. 收取押金（现金需开收据，信用卡需做预授权）
5. 制作房卡，核对PMS系统信息
6. 介绍酒店设施、早餐时间、wifi等
7. 指明电梯方向，询问是否需要行李服务，祝客人入住愉快

**中旅集团员工预订入住程序**
- 需出示有效员工会员卡（必须本人），身份证籍贯不得与酒店属同一城市
- 员工优惠仅限预订1间房，但可连住多晚
- 不满足条件者按当日散客价处理
- 房价不包含早餐；未预定者不能享受员工优惠
- 员工优惠住房必须前台现付，不得转账

**心享会员入住接待程序**
1. 问候客人（按FO-SOP-FD-001）
2. 询问是否已是心享会员
3. 如为否定，对符合条件客人全力推介会员注册及权益卡
4. 在PMS系统使用Lookup功能查询客史档案（姓名+手机/邮箱）
5. 核对客人生日、证件号码、联络地址等信息确保准确性
6. 如已注册，告知并介绍会员权益，可推介付费权益卡
7. 完成后填写入住登记单、收取押金、制作房卡
8. 落实住客首次入会礼遇，第一时间通知客房、餐饮、客户关系部门
9. 将新注册会员登记单提交至酒店会籍经理处

**有预订宾客入住程序**
1. 问候客人，查询PMS系统确认预订
2. 核实预订信息：入住天数、人数、房型、房价、付款方式、特殊要求
3. 打印预订单与客人确认
4. 查验身份证件并填写入住登记单
5. 收取押金
6. 制作房卡，介绍酒店设施

**办理客人续住程序**
1. 查询系统确认房间状态
2. 与客人确认续住天数及房价
3. 调整押金（多退少补）
4. 更新PMS系统信息
5. 确认并告知续住房价及权益变化

#### 退房服务流程

**办理散客退房程序**
1. 主动问候，以姓氏称呼客人
2. 确认房号，请客人稍等
3. 核查房间消费（小酒吧、电话、洗衣等）
4. 打印账单请客人核对
5. 根据付款方式结账（现金/信用卡/公司账户）
6. 收回房卡，开具发票
7. 感谢客人入住，欢迎再次光临

**团队退房程序**
1. 提前与旅行社/会议组织方确认退房时间
2. 提前查房确认房间损坏及消费
3. 一次性打印全部账单，统一结算
4. 收回全部房卡
5. 协调行李寄存或托运服务

**长住客月结程序**
1. 每月固定日期进行月结
2. 打印长住客账单明细
3. 与客人核对确认
4. 办理结算并更新系统信息

#### 其他前台核心SOP

**交班会制度**
- 交接班会议设定在每个班次员工接班前10分钟开始
- 由前台接待主管/领班/代班主持，大堂经理、客户关系主任需参加
- 内容：当日会议情况、未完成工作、出租率、到店客人、团队情况、VIP情况
- 根据每周培训计划进行班前小培训并抽查效果

**外币兑换程序**
- 确认客人有效证件
- 查询当日外汇牌价
- 计算兑换金额，打印兑换单
- 请客人签名确认
- 交付现金并找零

**现金管理程序**
- 当班现金不得超出规定限额
- 投款需双人见证
- 备用金班班交接，签认记录

**叫醒服务**
- 记录客人姓名、房号、叫醒时间
- 设置系统自动叫醒
- 话务员人工电话再次提醒

**换房处理程序**
1. 了解客人换房原因
2. 查询可换房型
3. 征得客人同意后调整预订
4. 制作新房卡，回收旧房卡
5. 通知客房部做房
6. 更新PMS系统信息

**户籍登记规定**
- 严格执行身份证实名登记制度
- 境外客人需登记护照信息、签证有效期
- 及时上传公安系统

**会议团队接待程序**
1. 会前了解会议性质、人数、VIP、特殊要求
2. 提前分配房间、准备资料袋
3. 团队到达时快速办理入住
4. 会议期间跟进服务
5. 会后快速结账协调

**宾客投诉处理**
- 接受：仔细倾听，表示理解，必要时隔离吵闹客人
- 处理：主要负责人为宾客服务经理、前厅部经理、房务总监
- 补救措施：房价优惠、签单减免、鲜花/果篮、赠送小礼品
- 投诉由宾客服务经理负责（重大投诉由总经理处理）
- 禁止推诿和争执，应在独立空间处理
- 住店客投诉需24小时内处理，已离店客投诉72小时内处理
- 有效投诉率需低于0.2%

**VIP分级接待标准**

| 级别 | 宾客类型 | 礼遇标准 |
|------|---------|---------|
| VIP1 | 国家元首、省部级以上官员、总统套房客人、知名企业CEO | 最高规格：总经理审批、高层接待会议、机场接送、总经理引领入房、每日多次清洁、离店免查房、高层欢送 |
| VIP2 | 国际知名人士、副部级官员、套房客人、企业高级行政人员 | 较高规格：部门总监迎接、精心准备房间、赠送高端礼品 |
| VIP3 | 入住10次以上常客、连续入住一周客人、集团关联公司客人、在店过生日客人、新婚夫妇 | 标准VIP礼遇：鲜花/水果/红酒、专属欢迎卡、客房升级 |

### 1.3 前厅部P&P（政策与程序）

**员工行为规范——必须做到**：
- 准时到岗签到签离、保持出勤、服从上级指示
- 保持个人仪容与制服整洁
- 遵守工作用餐时间、使用员工通道
- 及时报告特殊事件（如遗失物品、客人生病等）
- 保持礼貌友善、节省能源、拾金不昧

**员工行为规范——严格禁止**：
- 替他人打卡、未经同意串岗
- 在更衣柜存放酒店财物、损毁酒店财物或偷拿客用品
- 索要小费、不当穿着制服、说粗言秽语
- 私自动用电器、使用客用设施、未经许可携带物品离店
- 打扰挂有"请勿打扰"牌的客房、在走廊喧哗
- 与客人小孩玩耍或触摸客人财物、与客人私换外币
- 陪同客人外出、上班阅读报刊、在客人专区坐立
- 未敲门进入客房、将废弃物投入马桶

**专业术语规范**
- 客房类型：SDT（标准双床房）、DS（豪华套房）、PS（总统套房）
- 房态：V/R（可售房）、OCC（住客房）、O.O.O.（维修房）、DUE OUT（预离房）
- 专用术语：VIP（贵宾）、C/I（入住）、C/O（退房）、STAY OVER（续住房）、E.B.（加床）

**会议制度（四级）**：
1. 酒店部门经理会议（总经理主持）
2. 前厅部早会（前厅部经理主持，接待经理、宾客服务经理、礼宾司等参加）
3. 部门周会（每周一前厅部经理主持）
4. 各岗位班前、班后会（交接班时进行）

## 二、客房部SOP&P&P

### 2.1 客房楼层SOP（59项标准程序）

#### 客房清洁程序（HK-SOP-FL-01）

**准备工作**：
- 准备不同颜色抹布：紫色（浴室台面/面盆/浴缸）、红色（马桶）、绿色（浴室地面/垃圾桶）、黄色（镜子/玻璃/电镀制品）、蓝色（家具表面）
- 专布专用，干净为前提

**敲门进房**：
- 确认无"请勿打扰"标识后，敲门或按门铃，报称"HOUSEKEEPING"或"客房服务员"
- 等待15秒，若无回应再敲三下
- 开门后报身份，记录进房时间
- 若客人在房，应道歉问候，询问是否可清洁

**撤床程序**：
- 将床由床头拉出，床单、被子逐一撤出（避免客人私人物品被卷入）
- 清空床保持通风
- 撤出布草放工作车内，不放地毯上
- 按季度翻床垫

**铺床标准**：
1. 铺床单：平均铺床，塞入床边，床头处留30cm
2. 铺被套：羽绒被两角与被套头部两角对齐，抖匀铺平
3. 床尾巾：平均铺在床尾
4. 枕头：小床2个，大床4个；硬枕竖放靠床头板，软枕放前面
5. 检查床整体外观是否整齐

**浴室清洁（HK-SOP-FL-17）**：
- 使用配制浓度250-1000mg/L含氯消毒液
- 按颜色区分抹布使用区域
- 浴室地面用绿色抹布，马桶用红色抹布

**补充客用品**：按标准配置及补充

**结束**：关闭电源，取下"正在清洁"牌，记录做房结束时间

#### 夜床服务程序（HK-SOP-FL-20）
- 敲门进房，报明身份
- 拉开窗帘，调节空调
- 撤除使用过的布草，更换新布草
- 摆放夜床用品（晚安卡、巧克力等）
- 补充客用品
- 抹尘、吸尘
- 关闭窗帘，检查房间

#### 客房安全程序

**"请勿打扰"处理（HK-SOP-FL-34）**：
- 如房态显示DND，每隔2小时再次确认
- 如超过14:00仍未取消，通知宾客服务经理电话联系确认
- 紧急情况可由管理层授权进入

**火警程序（HK-SOP-FL-42）**：
1. 发现火情立即报告保安部，说明部位、材质、火势
2. 未经总经理允许不得拨打119
3. 组织客人从"安全通道"撤离，不可乘坐电梯
4. 如火势小，使用就近消防设施灭火
5. 填写《意外事故报告》

**客人猝死处理（HK-SOP-FL-45）**：
1. 发现异常绝不推测死亡，视为重伤处理
2. 报告时说明身份、情况、地点
3. 值班经理和保安主管立即前往，保护现场，禁止进入
4. 救援人员到来前尽量救人，汇报总经理建议呼叫警方和救护车
5. 联系死者亲友，保护现场、评估、寻找证人
6. 设立事件控制室

### 2.2 客房部P&P（政策与程序）

**房务中心工作制度**：
- 客房办公室（房务中心）是客房部的调度指挥中心
- 早班：阅读交接日记、清点物品、分发器材钥匙、核对输入房态、接听电话、报送报表、关注VIP动态
- 中班：完成早班工作、输入维修信息、收回器材钥匙、联系晚间维修、核对房态、登记遗留物品

**楼层各班次工作程序**：
- 早班：房间→VIP房→挂牌清洁房→住房→长住房→走房→空房（紧张时优先清扫走房）
- 中班：清扫公共区域，检查并报修设施，协助早班做房，准备夜床服务
- 夜班：提供擦鞋、送冰块等服务，进行安全巡视，检查预离房酒水

**客房预防性维修（万能工）**：
- 工程总监建立综合检查表
- 每月对约8%房间进行维护，确保每年完成一轮次
- 维修后保持室内整洁

**布草管理**：
- 毛巾类：蓬松、柔软、洁白，折叠规范，打捆整齐
- 床单枕套被套：洁白无污迹，折叠正确，打捆整齐
- 台布口布小毛巾：洁白柔顺、熨压平整

**制服管理**：
- 员工配发两套制服，更换时必须一套换一套
- 脏制服需分类存放并检查后送洗

## 三、餐饮部SOP&P&P

### 3.1 中餐厅SOP

#### 预订服务（FB-CR-SOP-001）
- 电话三声内接听，超时须致歉
- 问候并报餐厅名，询问客人需求
- 明确记录：客人姓名、日期、时间、人数、电话、场地（包间/楼面）及特殊要求
- 结束前向客人重复预订内容确认
- 向客人致谢并期待其光临

#### 摆台标准
- 餐具、台布洁净无破损
- 转芯与转盘置于桌子中心，中心重合
- 展示盘与骨碟边缘距桌边1.5cm
- 汤碗置于骨碟左上方，味碟置于右上方，瓷勺置于汤碗中，勺把向左
- 筷子置于筷架上，距桌边1.5cm
- 玻璃杯具（水杯/红酒杯/白酒杯）摆放于汤碗与味碟上方，成45°角
- 茶杯置于茶碟上，放在筷子右侧
- 口布折花整齐统一，突出主人与副主人位
- 花瓶放于转盘中心，花朵盛开一面对向餐厅大门

#### 席间服务
**上菜顺序**：餐前水果→冷菜→热菜→汤→主食→点心

**上菜规范**：
- 传菜员将菜送至餐台边
- 整理出转盘上的上菜位置
- 双手端盘上桌，报菜名并介绍
- 需配勺的菜品，上菜前在菜品右侧放置服务勺
- 上菜动作需轻盈，严禁菜肴从客人头上越过
- 菜上齐后告知客人并祝用餐愉快

**更换骨碟**：
- 左手托盘，内置干净骨碟（叠放不超过10只）
- 骨碟内垃圾约占1/3时应及时更换
- 遵循女士优先、顺时针方向依次更换
- 客人正在食用时暂停更换

**巡台服务**：
- 勤换骨碟和毛巾（尤其食用带壳或汁多菜肴时）
- 及时添加酒水、饮料和茶水
- 使用礼貌用语，处理突发事件
- 控制上菜速度适中
- 主动询问宾客对菜品的意见

#### 结账与送客
- 准备账单，当面点清，提供发票或凭证
- 信用卡结账应主动回避客人输入密码
- 结账后双手递还发票、卡单，向客人表示感谢
- 送客至电梯口或楼梯口，微笑目送

### 3.2 餐饮部P&P（政策与程序）

**员工守则（FB-P&P-01）**：
- 按时上班并签到，衣着整洁，制服平整，配戴名牌
- 面对同事或顾客必须随时面带微笑
- 不允许与顾客发生争执甚至辱骂顾客
- 不准穿着工作服外出（除餐饮部总监允许）

**安全守则（FB-P&P-02）**：
- 托盘操作保持正常速度，禁止奔跑
- 全体员工熟知消防"三知三会"和"四个能力"
- 餐厅结束营业后检查关闭电器、燃气设备并做好检查记录

**固定资产管理（FB-P&P-03）**：
- 指定资产管理员，建立资产台账，做到"账实相符、责任清楚"
- 部门间调拨固定资产必须填写"资产调拨单"，部门经理签字后报财务总监批准

**库房管理（FB-P&P-05）**：
- 各营业点每日认真做好日报表工作
- 及时对使用物品和库存物品的数量进行盘点

**食品安全（FB-P&P-09）**：
- 所有厨房人员必须持健康证上岗
- 操作过程必须符合HACCP手册
- 冰柜存放食品做到生熟分开存放
- 进入冷菜间、裱花间工作须进行二次更衣，戴口罩和手套

**成本控制（FB-P&P-18）**：
- 制订标准材料配方和烹调法
- 按标准材料配方严格控制份量大小
- 计划制定菜单时考虑选择时令材料制作菜式

**醉酒客人应对（FB-P&P-23）**：
- 当客人被认为在酒店喝醉，必须停止提供酒类饮料服务
- 住店客人将被陪同到房间
- 为非住店客人叫出租车
- 尽一切努力不让客人自己驾车

## 四、工程部SOP&P&P

### 4.1 工程部SOP

**日常巡检**：
- 机房、泵房巡视：每隔2小时巡视一次
- 检查水箱水位、水泵压力、机组噪音、空调风机运行状况及跑冒滴漏
- 客观记录运行数据及异常情况，现场签到

**配电房巡检**：
- 高压侧：巡视直流屏、检查蓄电池、清洗电池组、监控变压器状态、检查电网电压与负载电流
- 低压侧：记录变压器输出、观察仪表、保证风机正常、保持清洁

**空调系统**：
- 启动时先启泵后启主机
- 运行中监控仪表、定期保养、勤于监视
- 停机顺序：主机→水泵→冷却塔→末端设备

**维修响应时效**：
- 紧急事件/安全事故：3分钟内到场
- 急修：3分钟内到场
- 一般维修：10分钟内到场

### 4.2 工程部P&P（政策与程序）

**安全制度**：
- 高压设备操作无论带电与否，值班人员不得单人工作，必须有监护人在场
- 电气设备停电后，在未拉开刀闸的情况下需设置遮拦
- 检修停电时必须做好验电、装设接地线等安全措施
- 严禁非电工人员从事电工作业

**动火作业许可**：
- 必须到工程部审批作业人员资质（特种作业操作证）
- 施工单位填写《动用明火申请表》
- 审批的施工时间仅为1天，超时需重新审批

**能源管理**：
- 电力每日读数，电气主管每日晨会汇报
- 水和气由机修工每日记录并汇报
- 每月计算能耗比（能源费/经营收入），与预算及历史同期对比

**节能制度**：
- 照明系统实行分组、定时、降亮度控制，推广LED光源
- 厨房设备随用随开，避免空转
- 会后及时关闭空调照明

**工具管理**：
- 个人工具由个人保管，公用工具经部门经理批准后由领班领用
- 工具因非正常使用损坏或遗失，需由责任人赔偿

## 五、安全部SOP&P&P

### 5.1 安全部SOP

**人员出入管理**：
- 晚间23点后禁止访客
- 大堂保安礼貌问候并询问客人身份
- 对住店客人查验房卡或引导至前台核实
- 对探访客人由前台联系被探访人获得同意，登记后方可进入

**物品出门管理**：
- 所有物品带出酒店必须经过物资所属部门总监/经理（正职）审核批准并签字
- 特殊情况可由值班经理或大堂副理批准

**火警应急**：
- 警报响起，员工须立即回岗位待命
- 发现小火立即扑灭
- 火势失控则关闭门窗，按疏散令带领客人从指定通道撤离

**电梯困人**：
- 若轿厢接近平层，可关闭电源后以专用钥匙开门救出
- 若轿厢位于两层之间，需专业人员盘车移动至平层
- 救援后电梯须经维保公司彻底检修并验收

### 5.2 安全部P&P（政策与程序）

**核心安保工作制度（SEC/P&P/001）**：
- 保安部是酒店一级行政部门，负责整个酒店的设施、财产、客人及全体员工的安全保卫工作
- 建立健全安全委员会组织，建立切实可行的各部门安全岗位责任制
- 定期进行安全检查，对安全隐患及时提出整改建议和措施

**重大接待活动应急处置（SEC/P&P/018）**：
- 保安部需保留最少两个班的保卫力量
- 爆炸案：安全员立即抢救伤员、疏散客人并注意可疑线索
- 可疑行为（六种）：立即报告安全人员并进行控制

**涉外案件处置（SEC/P&P/030）**：
- 原则：实事求是、及时报告、依法依规处理
- 外国人出丑/酗酒闹事：疏散人群、警告、送回客房、保护现场
- 外国人死亡事件：立即通知安保、保护现场、禁止无关人员进入、配合公安调查
