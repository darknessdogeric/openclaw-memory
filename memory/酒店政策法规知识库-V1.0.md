## 一、消防安全法规与制度

### 1.1 消防安全责任体系

**法规依据**：
- 公安部(85)公发23号文件《关于印发机关、团体、企业、事业单位保卫组织工作等细则》
- 《中华人民共和国消防法》
- 各地消防管理条例

**酒店消防安全责任**：
1. 建立健全消防安全组织，落实消防安全责任制
2. 制定灭火应急方案，印刷、张挂疏散图和防火制度
3. 定期进行安全检查，对安全隐患及时提出整改建议和措施
4. 培训义务消防队员，定期组织实施职工消防演练
5. 协助制定各部门防火制度并监督检查

**员工"三知三会"和"四个能力"**：
- 三知：知道岗位火灾危险性、知道消防设施位置、知道疏散通道
- 三会：会报警、会扑救初期火灾、会组织疏散
- 四个能力：检查消除火灾隐患能力、扑救初期火灾能力、组织疏散逃生能力、消防宣传教育能力

### 1.2 消防设施管理

**配置要求**：
- 灭火器：按面积配置，A类/B类/C类火灾分类选用
- 消火栓：位置明显，有明显标识，定期检查水压
- 自动喷淋：按规范设置，覆盖所有可燃区域
- 火灾自动报警系统：覆盖所有区域，联动控制
- 疏散指示标志：持续照明，间距≤20m

**检查维护**：
- 每月进行消防安全检查
- 每季度对消防设施进行功能测试
- 年度消防演习

### 1.3 厨房消防管理

**要求**：
- 厨房工作人员上岗前必须经过消防安全培训，通过消防安全考试
- 油炸食品和烘烤食品时不得离人
- 油锅温度不要过高，放油不宜过满
- 工作完毕后关闭电源、气源，熄灭明火
- 运水烟罩及油烟净化机定期清理

### 1.4 动火作业管理

**许可制度**：
- 动用明火施工作业必须到工程部审批
- 施工单位填写《动用明火申请表》
- 审批施工时间仅为1天，超时需重新审批
- 消防主管需到现场检查确认安全措施

## 二、卫生安全与食品安全

### 2.1 公共卫生管理制度

**法规依据**：
- 《公共场所卫生管理条例》
- 《中华人民共和国食品安全法》
- HACCP食品安全管理体系

**从业人员健康管理**：
- 必须持健康证上岗
- 每年按时参加健康体检
- 如有传染病症状，立即离岗就医

**客房卫生标准**：
- 杯具清洗消毒：一洗二刷三冲四消毒五保洁
- 床品更换：住客房按需更换（一般3天一次），离店房100%更换
- 卫生间消毒：便池2000mg/L含氯消毒剂，门把手等表面500-1000mg/L含氯消毒剂

**布草管理**：
- 脏布草分类存放（污染/普通）
- 洗涤温度≥70℃（含消毒）
- 洁净布草密封存放

### 2.2 食品安全管理（HACCP）

**关键控制点**：
- 原料验收：索证索票，冷链监控
- 储存：生熟分开，温度控制
- 加工：烧熟煮透，交叉污染预防
- 冷菜间/裱花间：二次更衣，戴口罩手套

**餐饮具消毒**：
- 化学消毒：有效氯250mg/L，浸泡30分钟
- 热力消毒：温度≥80℃，时间≥30秒

## 三、特种设备与工程安全

### 3.1 电梯安全管理

**法规依据**：
- 《特种设备安全法》
- 电梯使用管理与维护保养规则（TSG T5002）

**日常管理**：
- 直梯：每年定期检验，配备安全检验合格证
- 开启厅门前须确认轿厢停靠该层
- 维修保养前须悬挂警示牌、设置监护、断电
- 轿顶保养须佩戴安全帽，禁止开快车
- 机房管理：灭火器、钥匙专人保管、禁止无关人员进入与吸烟

**应急处置（电梯困人）**：
- 立即安抚被困客人
- 若轿厢接近平层，关闭电源后以专用钥匙开门
- 若轿厢位于两层之间，需专业人员盘车移动至平层
- 救援后电梯须经维保公司彻底检修并验收

### 3.2 锅炉与燃气安全

**锅炉安全**：
- 锅炉房门口设"机房重地，闲人免入"警示牌
- 操作人员必须持有效的锅炉操作证上岗
- 当班司炉工每小时巡检一次，填写运行记录
- 酒店按国家规定设立锅炉安全管理员

**燃气调压站**：
- 不能建在酒店主体建筑内
- 设"防火、防爆"标示，室内通风良好
- 周围严禁吸烟、带入明火
- 发现漏气立即关闭总阀门，设置警戒线

### 3.3 配电与电气安全

**高压配电**：
- 值班人员必须持证上岗
- 高压设备操作不得单人工作，必须有监护人
- 停电检修时操作手柄上悬挂"禁止合闸，有人工作"标志牌
- 严禁带负荷拉刀闸、带地线送电

**触电急救**：
- 切断电源
- 用绝缘物使触电者脱离电源
- 立即进行心肺复苏
- 拨打急救电话

## 四、安全生产与应急管理

### 4.1 安全生产责任制度

**"三责任"原则**：
- 谁主管，谁负责
- 谁在岗，谁负责
- 谁操作，谁负责

**事故隐患整改**：
- 记录、制定整改措施和期限
- 落实整改情况
- 工程部会同保安部复查
- 多次未整改问题召开专题会议

### 4.2 突发事件应急处置

**应急响应分级**：

| 级别 | 类型 | 处置原则 |
|------|------|---------|
| 一级 | 重大火灾/爆炸/恐怖事件 | 启动应急预案，全员疏散，立即报警 |
| 二级 | 一般火灾/治安事件 | 部门处置，保安部支援，及时上报 |
| 三级 | 设备故障/客人投诉升级 | 部门处置，30分钟内解决 |

**内部案件处理程序**：
1. 现场控制与通知
2. 现场勘查
3. 询问相关人员
4. 分析案件性质
5. 上报公安机关
6. 协助公安机关
7. 归档

**群体性事件处理**：
1. 安保部接到报告立即通知领导和相关部门赶赴现场
2. 带领上访代表（不超过5人）前往相关部门办公室
3. 对其余上访者进行劝导
4. 遇到强行进入者，劝阻并报警
5. 对滋扰、冲击行为立即报警并服从公安指挥

## 五、行业标准与品牌标准

### 5.1 酒店行业分类标准

**分类依据**：
- 按服务功能：全服务酒店/有限服务酒店/精品酒店/公寓酒店
- 按档次：经济型/中档/中高端/高端/奢华
- 按客源：商务酒店/度假酒店/会议酒店/机场酒店

**有限服务酒店特征**：
- 核心服务：住宿+早餐（少数含）
- 无大型餐饮/会议设施
- 人员配置精简
- 智能化程度高

### 5.2 中旅酒店品牌标准

**组织架构标准**：
- 总经理→部门总监→部门经理→主管→员工
- 各品牌有不同的部门配置和人员编制标准

**睿景品牌标准**：
- 客房面积≥25㎡
- 加盟费：8000元/间
- 技术服务费：80万标准店（120间以上每10间加收1万）
- 工程巡检费：8万元（含8次现场）

### 5.3 服务标准体系

**服务时效标准**：
- 前台入住办理：≤3分钟
- 前台退房办理：≤2分钟
- 紧急维修响应：≤3分钟
- 一般维修响应：≤10分钟
- 投诉处理（住店）：≤24小时
- 投诉处理（离店）：≤72小时

## 六、劳动法规与人力资源合规

### 6.1 劳动合同与社保

**法定要求**：
- 签订书面劳动合同（入职30日内）
- 试用期依法约定
- 社保（五险）足额缴纳
- 公积金（按当地规定）

### 6.2 工作时间与休息

**工时制度**：
- 标准工时制：每日8小时，每周40小时
- 综合工时制：需劳动行政部门审批
- 不定时工时制：适用于高管/特殊岗位

**休息休假**：
- 周休息日：≥1天
- 法定节假日：11天
- 年休假：按累计工龄

### 6.3 员工安全保护

**职业健康**：
- 入职体检
- 职业病防护
- 高温/噪音等特殊岗位保护

## 七、环保与节能法规

### 7.1 环境保护

**合规要求**：
- 排污许可证
- 油烟排放达标
- 噪声控制
- 固废分类处理

**绿色酒店标准**：
- 能源管理体系
- 水资源管理
- 垃圾分类
- 绿色采购

### 7.2 节能管理

**能源记录制度**：
- 电力每日读数，电气主管每日晨会汇报
- 水和气每日记录并汇报
- 每月计算能耗比（能源费/经营收入）
- 每月计算能源消耗强度及CO2排放量
