### 方法论沉淀（可复用）

1. **扫描件优先 rapidocr**（本机已装），比"渲染成图→view_image"省 90% token 且可全文检索——3 份 PDF 一次性搞定
2. **小红书 web 端取数三段式结论**：search（墙）→ profile 裸 URL（空）→ profile + xsec_token（可渲染）。**token 必须来自 feed/搜索** → 定向采集的前提是先解决"账号发现"
3. **表单型 docx 用 python-docx 直读表格**，比转 PDF 再解析快 10 倍
4. **分类器要处理"同上"占位**：desc="同上" 时 val 是真实值；val 只有账号名 = 已开通但无量级数据
5. **不推断未填字段**：采集表只写"已开通"→ 补采表认证状态填"待确认"，不填"蓝V企业号"
