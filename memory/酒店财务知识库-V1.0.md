## 一、核心指标体系

### 1.1 客房收入三大指标

| 指标 | 英文 | 计算公式 | 说明 |
|------|------|----------|------|
| **入住率** | OCC (Occupancy) | 已售间夜数 ÷ 可售间夜数 × 100% | 核心量指标 |
| **平均房价** | ADR (Average Daily Rate) | 客房收入 ÷ 已售间夜数 | 核心价指标 |
| **RevPAR** | Revenue Per Available Room | ADR × OCC 或 客房收入 ÷ 可售间夜数 | 综合指标，金标准 |

**实战公式**：
```
RevPAR = ADR × OCC%
     = (Σ各渠道收入) ÷ 可售间夜数
     = 竞品RevPAR × (1 ± RGI)
```

### 1.2 利润指标体系

| 指标 | 计算公式 | 行业参考值 |
|------|----------|-----------|
| **GOP** | 营业收入 - 营业成本 | 中高端酒店40-50万/年（150间） |
| **GOP率** | GOP ÷ 营业收入 × 100% | 35-45% |
| **GOPPAR** | GOP ÷ 可售间夜数 | $15-35/间夜 |
| **净利润** | GOP - 管理费 - 固定资产折旧 - 财务费用 | |
| **净利润率** | 净利润 ÷ 营业收入 × 100% | 5-15% |

### 1.3 STR指数体系

| 指标 | 全称 | 计算公式 | 解读 |
|------|------|----------|------|
| **MPI** | 市场渗透指数 | 本酒店RevPAR ÷ 竞品RevPAR × 100 | >100表示好于市场 |
| **ARI** | 平均房价指数 | 本酒店ADR ÷ 竞品ADR × 100 | >100表示溢价能力强 |
| **RGI** | 收益增长指数 | 本酒店RevPAR指数 ÷ 竞品RevPAR指数 | >1表示增长快于竞品 |

**实战解读**：
- MPI>100 + ARI<100：低价抢量，策略激进
- MPI<100 + ARI>100：高端定位，客户精准
- RGI>1：说明你的增长快于竞品

### 2.2 收入预算编制（客房部）

**第一步：确定基准年数据**
```
基准年OCC = 实际入住间夜数 ÷ 可售间夜数
基准年ADR = 客房收入 ÷ 入住间夜数
基准年RevPAR = 客房收入 ÷ 可售间夜数
```

**第二步：市场环境修正**
```
年度OCC预测 = 基准年OCC × (1 + 市场增长率) × (1 + 酒店竞争力修正)
```

| 市场类型 | 年度OCC趋势 | 节假日脉冲 |
|---------|------------|-----------|
| 一线城市商务 | 65-75% | 春节-30%，国庆+20% |
| 二线城市商务 | 60-70% | 春节-40%，五一+15% |
| 旅游城市 | 55-65% | 旺季+50-80%，淡季-50% |
| 会议型 | 50-60% | 展览期+100%+ |

**第三步：细分市场预算分解**

## 三、收益管理财务方法

### 3.1 动态定价公式

**基础定价公式**：
```markdown
当日房价 = 基准房价 × 需求系数 × 竞争系数 × 事件系数

其中：
需求系数 = 预测OCC% ÷ 目标OCC%
         = 预订进度指数（提前X天预订量 ÷ 历史同期）

竞争系数 = 竞品ADR ÷ 本店ADR（动态调整）

事件系数 = 节假日指数（春节1.5-2.0x，国庆1.3-1.5x）
```

**节假日脉冲系数**（中国参考）：
| 节假日 | OCC提升 | ADR提升 | 持续天数 |
|--------|---------|---------|---------|
| 春节 | +20-50% | -10~+30% | 7天 |
| 五一 | +30-50% | +20-40% | 3天 |
| 国庆 | +40-80% | +30-50% | 7天 |
| 清明/端午/中秋 | +10-30% | +10-20% | 3天 |

### 3.2 渠道成本核算

| 渠道 | 佣金率 | 结算周期 | 附加成本 |
|------|--------|---------|---------|
| 携程 | 15-18% | 月结 | 推广费3-5% |
| 美团 | 12-15% | 月结 | 推广费2-3% |
| 飞猪 | 10-15% | 月结 | 推广费2-5% |
| Booking | 15-18% | 月结 | 汇率损耗 |
| 官网直销 | 2-5% | 即时 | 运营成本 |
| 企业协议 | 5-8% | 月结 | 销售成本 |

**渠道ROI计算**：
```markdown
渠道贡献 = 渠道收入 - 渠道成本 - 附加成本

渠道利润率 = 渠道贡献 ÷ 渠道收入 × 100%

渠道优先级 = 贡献毛利 ÷ 可售间夜
```

## 四、投资测算模型

### 4.1 新建酒店投资测算

**典型投资结构**（以清凤时代城108间为例）：
| 投资项 | 单方造价/单价 | 数量 | 总价 |
|--------|------------|------|------|
| 装修费用 | ¥6,000/㎡ | 6,000㎡ | ¥36,000,000 |
| 开办费 | — | — | ¥2,000,000 |
| 前期指导费 | — | — | ¥1,000,000 |
| 设计费 | — | — | ¥1,000,000 |
| **总投资** | — | — | **¥40,000,000** |

**单位投资指标**：
```markdown
单房投资 = 总投资 ÷ 客房数
         = ¥40,000,000 ÷ 108间
         = ¥370,000/间

每平米投资 = 总投资 ÷ 建筑面积
           = ¥40,000,000 ÷ 6,000㎡
           = ¥6,667/㎡
```

## 八、附录：常用公式速查

### 8.1 收入指标
```markdown
ADR = 客房收入 ÷ 已售间夜数
OCC% = 已售间夜数 ÷ 可售间夜数 × 100%
RevPAR = ADR × OCC% = 客房收入 ÷ 可售间夜数
RevPAR增长率 = (本期RevPAR - 上期RevPAR) ÷ 上期RevPAR × 100%
```

### 8.2 利润指标
```markdown
GOP = 营业收入 - 营业成本
GOP率 = GOP ÷ 营业收入 × 100%
GOPPAR = GOP ÷ 可售间夜数
净利润 = GOP - 管理费 - 折旧 - 财务费用
```

### 8.3 渠道指标
```markdown
渠道贡献 = 渠道收入 × (1 - 佣金率)
渠道利润率 = 渠道贡献 ÷ 渠道收入 × 100%
OTA净房价 = OTA挂牌价 × (1 - 佣金率)
```

### 8.4 投资指标
```markdown
单房投资 = 总投资 ÷ 客房数
投资回报期 = 总投资 ÷ 年GOP
IRR = 使NPV=0的折现率
```

### 8.5 实际财务比率（重庆丽苑2024预算验证）

**成本结构验证（重庆丽苑全服务酒店，总收入4899万）**:
| 费用项 | 金额(万元) | 占营收比 | 行业参考 |
|--------|----------|---------|---------|
| 营业成本 | 3,502 | 71.5% | 65-75% |
| 其中：人工成本(变动) | 356 | 7.3% | 5-10% |
| 其中：人工成本(固定) | 879 | 17.9% | 15-20% |
| 其中：能耗 | 368 | 7.5% | 5-8% |
| 其中：餐饮成本 | 432 | 8.8% | 8-12% |
| 其中：佣金 | 174 | 3.5% | 3-5% |
| 其中：维修 | 164 | 3.3% | 3-5% |
| 税金及附加 | 244 | 5.0% | 4-6% |
| 销售费用 | 201 | 4.1% | 3-5% |
| 管理费用 | 1,179 | 24.1% | 20-30% |
| 财务费用 | 255 | 5.2% | 3-8% |
| **净利润** | **-481** | **-9.8%** | **盈亏平衡** |

> 重庆丽苑处于亏损状态（折旧¥1091万+财务¥255万导致净利润为负），GOP层面为正

**GOP层面测算**:
```markdown
GOP = 营业收入 - 营业成本 - 销售费用 - 管理费用(部分)
    = 4899万 - 3502万 - 201万 - (1179万 × 约50%)
    ≈ 4899万 - 3502万 - 201万 - 590万
    ≈ 606万 (GOP率约12.4%)

管理费用大部分为固定成本（折旧、租金、折旧摊销等），
实际酒店净利润通常在折旧+财务后为负，现金流层面仍可为正
```

### 8.6 快速测算速查表

**新项目投资测算（简化版）**:
```markdown
Step 1: 确定规模
  可售间夜 = 客房数 × 365天 × 80%（OCC假设）

Step 2: 收入测算
  客房收入 = 可售间夜 × OCC% × ADR

Step 3: 成本测算
  人力成本 = 客房数 × 人房比 × 人均年成本
           = 客房数 × 0.20 × ¥80,000
  能耗 = 客房收入 × 6%
  佣金 = 客房收入 × 12%
  租金 = 客房收入 × 18%（轻资产）

Step 4: GOP计算
  GOP = 客房收入 × (1 - 45%) = 客房收入 × 55%
      （简化估算，实际需分项计算）

Step 5: 净利润
  净利润 = GOP - 管理费(5%) - 折旧(8%) - 财务(3%)
```

**盈亏平衡测算**:
```markdown
固定成本 = 租金 + 人工固定部分 + 折旧 + 财务
变动边际贡献 = 收入 × (1 - 变动成本率)
盈亏平衡收入 = 固定成本 ÷ 边际贡献率

举例（有限服务酒店）：
  固定成本 = ¥300万（租金¥180万+人工¥80万+折旧¥40万）
  边际贡献率 = 1 - 45% = 55%
  盈亏平衡收入 = ¥300万 ÷ 55% = ¥545万/年

  需达到的收入OCC = ¥545万 ÷ (108间 × 365天 × ¥280 ADR)
                   = ¥545万 ÷ 11,046,000
                   = 49.3% OCC（即可盈亏平衡）
```

**日常维修费预算原则**:

1. 考虑单价上涨因素
2. 根据前三年的酒店总收入对比
3. 根据前三年的能耗比（参考2019年正常运营年度）

**智能能源监测系统（大象云电）**: 
- 自有酒店（除港澳、旅居）按大象云电框架协议取费标准
- 搭建费用约¥10-15万/每个酒店

**资本性支出标准**:
- 日常固定资产或软件支出预算总额 ≤ 年度营业收入总额的 **2%**

## 十四、附录：Excel财务公式模板

### 14.1 收入预算公式

```excel
= 客房数 × 365 × OCC% × ADR

= 可售间夜 × 平均房价
= SUMPRODUCT(各渠道间夜量, 各渠道平均房价)
```

### 14.2 GOP计算公式

```excel
= 营业收入 - 营业成本

= Total Revenue - (人力成本 + 能耗 + 餐饮成本 + 客房用品 + 洗涤 + 维修 + 佣金)
```

### 14.3 人工成本率公式

```excel
= (基本工资 + 加班费 + 津贴 + 奖金 + 社保 + 公积金 + 员工餐) / 营业收入

= Total Labor Cost / Total Revenue
```

### 14.4 RevPAR公式

```excel
= ADR × OCC%

= 客房收入 / 可售间夜数
```

### 14.5 折旧计算公式（直线法）

```excel
= (资产原值 - 残值) / 使用年限

= (¥9,462,500 - ¥0) / 5年 / 12月 = ¥157,708/月
```

### 14.6 投资回收期公式

```excel
= 总投资 / 年度GOP

= ¥14,491,700 / ¥2,825,200 = 5.13年
```

### 14.7 盈亏平衡公式

```excel
= 固定成本 / (1 - 变动成本率)

= ¥3,000,000 / (1 - 0.45) = ¥5,454,545
```
