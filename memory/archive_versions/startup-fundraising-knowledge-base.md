## 一、融资阶段全流程

### 1.1 融资阶段划分

```
融资阶段 = 概念验证 → 种子轮 → 天使轮 → A轮 → B轮 → C轮+

┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
│ 概念验证 │ → │  种子轮  │ → │  天使轮  │ → │   A轮   │ → │   B轮+   │
└─────────┘   └─────────┘   └─────────┘   └─────────┘   └─────────┘
   50-100万     100-500万    500-2000万   2000万+      5000万+

里程碑:    │          │           │            │
      商业计划书    MVP成型    产品验证    商业模式
```

### 1.2 各轮次特征

| 轮次 | 金额 | 估值 | 投资人 | 核心关注 |
|------|------|------|--------|----------|
| 预种子 | 10-100万 | - | 创始人自有/亲友 | 概念验证 |
| 种子轮 | 100-500万 | 500-2000万 | 天使/种子基金 | 团队+方向 |
| 天使轮 | 500-2000万 | 2000万-1亿 | 天使投资人 | 产品+市场 |
| A轮 | 2000万-1亿 | 1亿-5亿 | VC机构 | 商业模式 |
| B轮 | 1亿-5亿 | 5亿-20亿 | VC机构 | 增长+规模化 |
| C轮+ | 5亿+ | 20亿+ | PE/战略 | 退出准备 |

### 2.2 BP制作要点

```
优秀BP特征:

✅ 简洁有力
- 10-15页为宜
- 图表 > 文字
- 数据说话

✅ 逻辑清晰
- 痛点 → 方案 → 验证
- 问题回答要到位
- 每页一个核心信息

✅ 差异化突出
- 为什么是你们
- 为什么是现在
- 凭什么能赢

❌ 常见错误
- 太多废话
- 缺乏数据
- 过于乐观
- 忽视竞争
```

### 3.3 常见问题应对

```
高频问题及回答:

Q: 你们和OTA的区别是什么？
A: OTA是中心化平台，我们去中心化。酒店保留数据主权，我们收薄佣不收高佣。

Q: 为什么酒店要用你们？
A: 降低获客成本、提升收益、数据自主。算得清楚的账。

Q: 技术壁垒是什么？
A: 酒店行业Know-How+AI应用+网络效应。

Q: 团队不完整怎么办？
A: CTO正在招聘，有明确候选人。展示快速补齐能力。

Q: 如果大厂抄袭怎么办？
A: 我们专注单体酒店，大厂看不上这块。我们先跑通，等他们看懂我们已经领先。

Q: 估值怎么定的？
A: 基于市场同类交易+里程碑阶段+团队背景。

Q: 退出路径是什么？
A: 被酒店集团收购、战略并购、IPO。
```

### 4.2 估值方法

```
早期项目估值方法:

【方法1: 市场法】
参考同类交易
- 同类公司估值
- 行业平均倍数
- 投资机构偏好

【方法2: 里程碑法】
基于下轮融资前估值
- 种子轮: 500-2000万
- 天使轮: 2000万-1亿
- A轮: 1亿-5亿

【方法3: DSVP法】
Discounted Startup Value
- 估算5年后估值
- 折现率 25-40%/年
- 稀释比例

【方法4: 公式法】
估值 = 团队因子 × 市场因子 × 产品因子 × 进展因子

【AHL估值参考】
- 同类AI项目: 10-30x ARR
- 酒店科技: 5-15x ARR
- 早期项目: 里程碑驱动
- AHL合理估值: 3000-5000万
```

### 4.3 谈判策略

```
融资谈判策略:

【时机选择】
- 多家投资人同时谈
- 先拿标杆Term Sheet
- 制造稀缺感

【条款优先级】
必须争取:
- 董事会席位
- 保护性条款(合理范围)
- 期权池设置

可以妥协:
- 估值(在合理范围)
- 清算优先权(1x可接受)
- 股份兑现(4年标准)

避免条款:
- 过于aggressive的反稀释
- 过多否决权
- 创始人控制权过大稀释

【拒绝技巧】
- 礼貌但坚定
- 给出合理解释
- 保持关系
```
