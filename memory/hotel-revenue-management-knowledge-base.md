## 1. 核心KPI指标体系

### 1.1 基础指标

| 指标 | 英文 | 公式 | 说明 |
|------|------|------|------|
| **客房收入** | Room Revenue | `ADR × Sold Rooms` | 核心收入来源 |
| **可用房晚** | Avail | `Total Rooms - OOO` | 可售房间数 |
| **已售房晚** | Sold | 实际售出房间 | 入住房间数 |
| **入住率** | Occupancy (OCC) | `Sold / Avail × 100%` | 衡量市场占有率 |
| **平均房价** | ADR | `Room Revenue / Sold` | 每间房收入 |
| **RevPAR** | Revenue Per Available Room | `Room Revenue / Avail` 或 `ADR × OCC` | 每间可用房收入 |
| ** GOPPAR** | GOP Per Available Room | `GOP / Avail` | 每间房利润 |
| **RevPAC** | Revenue Per Available Customer | `Total Revenue / Avail Customers` | 客户价值 |

### 1.2 进阶指标

| 指标 | 英文 | 公式 | 应用场景 |
|------|------|------|----------|
| **NRevPAR** | Net RevPAR | `(Room Revenue - CAC) / Avail` | 考虑获客成本 |
| **EBITDA** | Earnings Before Interest, Taxes, Depreciation, Amortization | 税息折旧摊销前利润 | 整体盈利能力 |
| **RevPASH** | Revenue Per Available Seat Hour | `F&B Revenue / (Seats × Hours)` | 餐饮收益 |
| **TRevPAR** | Total RevPAR | `Total Revenue / Avail` | 综合收益 |
| **ARPA** | Average Rate Per Available | `Group Revenue / Group Room Nights` | 团队业务 |
| **Walk-in %** | Walk-in Rate | `Walk-in Rooms / Total Sold` | 散客比例 |

### 1.3 中国特色指标

| 指标 | 说明 | 数据来源 |
|------|------|----------|
| **华住会指数** | 会员复购率/会员贡献率 | 华住会系统 |
| **OTA占比** | 携程/美团/飞猪渠道占比 | OTA后台 |
| **协议客渗透率** | 企业协议客占比 | PMS系统 |
| **私域复用率** | 企业微信/小程序复购 | 私域平台 |
| **直播带货GMV** | 抖音/小红书直播转化 | 直播平台 |

## 2. 收益管理公式库

### 2.1 定价公式

#### 基础动态定价
```
动态价格 = 基准价格 × (1 + 需求系数) × (1 + 竞争系数) × (1 + 时间系数)

参数说明:
- 需求系数: 基于预订进度、入住率趋势 (范围: -30% ~ +50%)
- 竞争系数: 基于竞品价格对比 (范围: -20% ~ +30%)
- 时间系数: 基于提前预订天数/特殊日期 (范围: -15% ~ +100%)
```

#### 收益优化价格 (IDeaS模型)
```
最优价格 = 需求弹性价格 × 市场份额权重 × 竞争调整因子

其中:
需求弹性价格 = 基础价格 × (1 + 需求弹性系数 × 需求偏差率)
```

#### 中国市场调整
```
AHL智能定价 = 国际算法 × 中国市场因子 × 渠道权重

中国市场因子:
- 节假日: ×1.5~3.0 (春节/国庆/五一)
- 高考/中考: ×1.2~2.0
- 展会期间: ×1.3~2.5
- 极端天气: ×0.8~1.2
```

### 2.2 预测公式

#### 需求预测 (指数平滑法)
```
Forecast(t) = α × Actual(t-1) + (1-α) × Forecast(t-1)

参数:
- α: 平滑系数 (通常 0.3~0.7)
- t: 预测天数
```

#### ADR预测
```
预测ADR = 基线ADR × (1 + 季节因子) × (1 + 事件因子) × (1 + 竞争因子)
```

#### 入住率预测
```
预测OCC = 市场需求 / 可售房数
市场需求 = 历史同类日 × 同比增长率 × 事件影响系数
```

### 2.3 组合优化公式

#### 团队与散客优化
```
最大收益 = MAX(纯散客收益, 纯团队收益, 组合收益)

组合约束:
- 团队最低房间数: X间
- 团队最低ADR: Y元
- 散客保底量: Z间
```

#### 收益管理方程
```
Maximize: Σ(Pi × Qi) - Σ(Ci × Xi)

约束:
- ΣQi ≤ 可售房数
- Qi ≥ 0
- 渠道配比约束
```

## 3. 收益管理模型

### 3.1 经典模型

#### (1) BAR (Best Available Rate) 模型
```
BAR = 最低可接受价格
调整规则:
- 提前7天: +0%
- 提前14天: -10%
- 提前30天: -20%
- 库存紧张: +15~30%
```

#### (2) 容量控制模型 (Yield Management)
```
最佳库存分配:
- 高价渠道: X% → 收益最大化
- 中价渠道: Y% → 市场覆盖
- 低价渠道: Z% → 填充剩余
```

#### (3) 动态定价模型
```
价格 = f(需求, 库存, 竞品, 时间, 事件)

关键变量:
- 预订进度曲线
- 入住率趋势
- 竞品价格指数
- 特殊事件日历
```

### 3.2 AI/ML模型

#### (1) 需求预测模型 (神经网络)
```
输入特征:
- 历史入住率 (365天)
- 节假日标记
- 天气数据
- 展会/活动
- 竞品价格
- 渠道流量

输出:
- 未来30天每日需求预测
```

#### (2) 最优定价模型 (强化学习)
```
状态: (日期, 库存, 竞品, 事件)
动作: {提价5%, 提价10%, 维持, 降价5%, 降价10%}
奖励: 实际RevPAR - 基准RevPAR
```

#### (3) 客户价值模型 (RFM+)
```
RFM模型扩展:
- R (Recency): 最近入住距今天数
- F (Frequency): 入住频次
- M (Monetary): 累计消费金额
- P (Preference): 偏好房型/渠道/时段
- L (Loyalty): 会员等级/复购周期
```

### 3.3 中国特色模型

#### (4) OTA+私域混合模型
```
总收益 = OTA收益 + 私域收益 + 线下收益

私域定价优势:
- 免佣金: +15~30%利润空间
- 数据自主: 可进行精准营销
- 复购激励: 会员积分/专属优惠
```

#### (5) 节假日脉冲模型
```
中国节假日定价:
- 春节 (7天): 基准×2.0~3.0
- 国庆 (7天): 基准×1.8~2.5
- 五一/端午: 基准×1.3~1.8
- 周末: 基准×1.1~1.3
```

#### (6) 档口/民宿特色模型
```
民宿主需要关注:
- 淡旺季波动更大 (OCC: 20%~95%)
- 团队客占比低 (散客80%+)
- 体验性定价 (不只是住宿)
- 口碑评分权重高 (≥4.8分)
```

## 5. 中国酒店特色模型

### 5.1 渠道格局

```
中国酒店预订渠道:
├── OTA (70%):
│   ├── 携程 (45%) ← 绝对主导
│   ├── 美团 (15%)
│   ├── 飞猪 (8%)
│   └── 去哪儿 (2%)
├── 私域 (15%):
│   ├── 企业微信
│   ├── 小程序
│   └── 会员体系
└── 线下 (15%):
    ├── 上门客
    ├── 协议客
    └── 团队
```

### 5.2 中国特色KPI

| KPI | 理想值 | 说明 |
|-----|--------|------|
| OTA佣金率 | ≤15% | 携程15%, 美团8% |
| 会员复购率 | ≥40% | 华住会70%+ |
| 私域占比 | ≥30% | 目标 |
| 好评率 | ≥4.8分 | 携程评分 |
| RevPAR | 一线800+/二线400+ | 疫情后恢复中 |

### 5.3 中国市场定价特征

```
特殊性因素:
1. 节假日高度集中 → 脉冲式收益
2. 婚宴/寿宴影响 → 宴会优先
3. 政务出差限制 → 商旅波动大
4. 直播带货兴起 → 新兴渠道
5. 会员日活动 → 周期性促销
```

## 附录: 常用Excel公式模板

### RevPAR计算
```
=ADR × 入住率
```

### 需求指数
```
=当日需求 / (历史同期需求 × 同比增长率)
```

### 竞价阈值
```
=边际成本 + (目标RevPAR - 当前RevPAR) / 剩余可售房
```
