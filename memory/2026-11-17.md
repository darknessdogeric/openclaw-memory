→ **方案定位为"总图与并轨规则"，不是第七个立项。**

**三处修正（结论先行，也是本轮最大增量）**
1. **云租是对的，且优于自建**（与直觉相反，但是算式结果）：2026-11 公开挂牌 4090 24G ¥1.0–2.5/h（包月 ¥600–900）、A800 80G ¥5.5–8.0/h、H20 96G ¥6.2–8.0/h、A100 80G 垂直平台约 ¥6.7 vs 阿里云约 ¥34.7。TCO：自建 GPU 机房年 ¥2–3 万 vs 云租包月年 ¥0.84 万；且 2026 年 GPU 迭代周期已缩到 18–24 个月。**自建的理由不是省钱，是数据不出内网与自主 SLA**。真正的问题是"哪些数据不许出内网"，解法三档：本地小模型 / 云上租独享整机（租户隔离）/ 脱敏后上 API。
2. **微调不是起点，是终点**：内部办公瓶颈是知识检索与系统对接（RAG＋工作流），不是模型智力；微调只该用在四处——领域算法（AI-RMS）、蒸馏降本、窄任务分类抽取、格式/多模态适配。安逸语料是 RAG 原料不是微调原料。
3. **内部自用是省钱不是赚钱**：内部提效在集团会计上是成本节约，换不来独立预算；盈利必须走对外（AI-RMS 的 1.5%–2% 是第一笔），且要"内部结算价＋对外产能配额"，否则内部需求会吃掉对外产能（内部自用型 AI 平台最常见的死法）。

**关键算式（可复算）**
- 微调成本可忽略：7B/8B QLoRA 单次 2–6h ≈ ¥5–13；32B QLoRA（48G/80G，6–20h）≈ ¥20–125。真正的成本在标注与评估。
- 模型路由是省钱核心：内部办公典型对话（输入 3k/输出 1k）单次 deepseek-chat ≈ ¥0.0072（年 45 万次 ≈ ¥3.2 万）、deepseek-v3 ≈ ¥0.0129（¥5.8 万/年）、Qwen3 Max ≈ ¥0.0463（¥20.8 万/年）→ **走对路由 vs 全量走最贵模型，年成本差 5–6 倍**。
- 自建推理年成本（¥0.8–2.5 万）已接近 API 年成本 → **"自建=省钱"不成立，自建买的是数据与 SLA**。
- API 价（2026-11-17 核对，USD/M tokens）：deepseek-chat $0.23/$0.34–0.35、deepseek-v3 $0.23–0.32/$0.93–1.10、deepseek-v4-flash $0.24/$0.96、r1 $0.46/$1.86、Qwen3 Max $0.50/$5.00。
