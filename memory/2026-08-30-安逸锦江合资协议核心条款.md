## 一、合资公司基本信息

### 1.1 主体

| 项 | 内容 |
|---|---|
| 名称 | **锦安酒店管理有限公司**（暂定，最终以登记机关核准为准）|
| 类型 | 有限责任公司 |
| 注册地 | 以双方协商一致确认的最优地区（最终以实际登记地址为准）|
| 经营宗旨 | 利用先进的酒店品牌标准和管理经验，在中国境内运营、管理、拓展品牌 |
| 注册资本 | **1000 万元** |
| 出资方 | 锦江酒店 49%（490 万）+ 安逸酒店 51%（510 万）= 100% |

### 1.2 出资方式

- 双方均以**现金**出资
- **出资计划**：
  - 工商登记 + 开立基本账户后 **90 天内**，实缴 50%（各 50%）
  - 营业执照签发后 **5 年内**，实缴剩余 50%
  - 逾期超过 90 天 → 出资方可要求调整持股比例

### 1.3 法律性质

- 中国法人，受中国法律管辖
- 股东仅以认缴出资额为限承担有限责任
- 合资公司以其全部资产对其债务承担责任

## 二、关键商业模式条款（4.3 + 4.4 节）

### 2.1 运营模式（4.3 条）

```
委托管理 + 特许管理 + 特许经营
（合资公司向业主方输出品牌 + 管理）
```

**关键约束**：
- 管理协议模板需董事会决议通过
- 业主方必须同意合资公司**单方概括转让**管理协议给关联公司
- 特许经营需在首次合同后 15 日内向商务主管部门备案

### 2.2 收益分配（4.4 第 8 款）⭐ 关键

```
前期费用（加盟费 + 筹建服务费）：
   合资公司 → 留存 60% + 付给锦江酒店 40%（扣减签约成本和外包成本后）

管理服务费（酒店开业后）：
   合资公司 → 留存 60% + 付给锦江酒店 40%
```

**核心解读**：
- 安逸通过 51% 持股 → 间接通过合资公司获取**管理费 60%** 的留存收益
- 锦江虽持股 49%，但通过**"管理费分成 40%"** 获取品牌使用费收益
- 安逸实际控制合资公司，锦江通过品牌授权+管理支持参与

### 2.3 资金归集（4.4 第 7 款）

```
甲方同意由乙方按上级单位资金管理要求对合资公司资金进行归集。
```

→ **安逸对合资公司有资金归集权**（符合国企"上级单位"管理逻辑）

## 五、与新良大酒店双品牌试点的关系

### 5.1 Eric 8/30 00:43 反馈的事实

> "新良宾馆目前跟酒店经营方沟通后倾向于双品牌：楼上改为英迪格，楼下的部分可以选择安逸和深圳锦江合资公司推进的新品牌。比如可以是安逸新良丽芮"

### 5.2 逻辑闭环

```
新良大酒店（楼上）
   ├─ 楼上 → 英迪格（保留，国际高端品牌）
   └─ 楼下 → "安逸新良丽芮"（推测品牌名）
              ├─ 主体：安逸 × 锦江 合资公司
              ├─ 安逸 51%（控制权）
              ├─ 锦江 49%（品牌 + 管理支持）
              └─ 收入分配：
                 ├─ 管理费 → 合资公司留存 60%（即安逸通过 51% 控制间接获得）
                 └─ 品牌费 → 锦江 40%（即锦江通过品牌入股获得）
```

### 5.3 "丽芮" 品牌名来源（推测）

- 锦江酒店管理集团旗下有"丽芮"、"丽亭"、"丽柏"、"丽怡"等品牌
- "丽芮"作为锦江系新品牌 → 通过合资公司注入
- 安逸提供物业（楼下部分）+ 锦江提供品牌（丽芮）+ 合资公司提供运营 = 双品牌试点

## 六、对立项的影响

### 6.1 立项 1 维度 4（集团战略需求）

**新良大酒店双品牌试点** = 安逸通过"合资公司 + 英迪格楼上保留"的**轻资产模式**实现资产盘活

**战略意义**：
- 安逸不出让资产 → 用合资公司做"运营输出"
- 锦江提供品牌 → 安逸通过股权控制收益
- 这是"轻重分离"战略的**具体落地案例**

### 6.2 立项 1 维度 12（合规与利益分配）

**合资公司 = 国资（安逸 51%）+ 国资（锦江酒店 = 上海国资委）的合资**
- 不属于红绿灯禁区的"以干部身份做商业"——因为是公司行为，非个人
- 属于国资监管的"关联交易"范畴——需要走集团党委会审议
- 合作方锦江酒店是上海锦江国际全资子公司 → 也是省外国资

### 6.3 立项 1 维度 1（集团新媒体现状）

新良大酒店作为"代表性子公司"之一：
- 集团账号矩阵：可考虑专门为合资项目做"小而美"的新媒体账号（双品牌内容）
- 集团官号 + 合资公司独立账号 双层架构
