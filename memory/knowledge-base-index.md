## 七、知识库维护规则

```
新增知识库：
  1. 评估是否需要（是否有重复？）
  2. 命名规范：领域-具体内容-版本.md
  3. 更新本索引

版本更新：
  1. 旧版本移至archive/
  2. 新版本替换
  3. 更新索引

删除知识库：
  1. 确认无引用
  2. 移至archive/（不直接删除）
  3. 更新索引
```
