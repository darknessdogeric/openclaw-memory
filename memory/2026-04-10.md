## 晚间补充（22:16-22:34）

### Hermes 配置与问题排查

**Eric 完成了 hermes setup 配置**，但运行时遇到多个问题，逐步排查：

**问题 1：emoji/UTF-8 编码崩溃**
- 症状：`UnicodeEncodeError: 'gbk' codec can't decode byte 0x80`
- 原因：PowerShell 默认 GBK 编码，hermes 输出含 emoji
- 解决：设置 `$env:PYTHONIOENCODING = 'utf-8'`

**问题 2：NoConsoleScreenBufferError**
- 症状：hermes chat TUI 报错 `Found xterm, while expecting a Windows console`
- 原因：在 Git Bash (MinGW) 里运行 hermes，但 prompt_toolkit 想用 Windows 原生控制台 API
- 解决：**在 CMD.exe 里运行 hermes**，而非 Git Bash
  ```
  cmd
  hermes chat --yolo
  ```

**问题 3：fcntl 模块不存在**
- 症状：`No module named 'fcntl'`
- 原因：`tools/memory_tool.py` 直接 `import fcntl`，Windows 没有此模块
- 解决：修改 import 为 `try...except ImportError`，使其在 Windows 上可选
- 文件：`C:\Users\Administrator\hermes-agent\tools\memory_tool.py`
- 修复后：`memory` 工具显示 ✓ 可用

**问题 4：404 Not Found**
- 症状：初始化时某个 API 返回 404
- 状态：暂时忽略，非致命
