## 一、酒店项目定位体系

### 1.1 定位决策框架

酒店项目定位是决定投资成败的关键，需从市场、客群、产品三个维度综合考量。

**定位决策树**：

```
城市能级 → 竞争格局 → 客源结构 → 品牌档次 → 产品配置 → 价格体系
```

### 1.2 城市与市场定位

**城市分类标准（中旅酒店2024年）**：

| 城市类别 | 代表城市 | 物业要求 |
|---------|---------|---------|
| A类（一线/新一线） | 北京/上海/广州/深圳/成都/重庆/杭州/西安/武汉/苏州/郑州/南京/天津/长沙/东莞/宁波/佛山/合肥/青岛 | 高端配置 |
| B类（战略性城市） | 粤港澳大湾区/长三角/京津冀/省会城市主城区/年游客500万+5A景区附近 | 中高端配置 |
| C类（其他城市） | 地级市/县级市 | 有限服务配置 |

### 1.3 档次分级定位

| 档次 | 目标客群 | 价格区间 | 特征 |
|------|---------|---------|------|
| 经济型 | 基础商旅、学生 | 100-200元 | 功能型，标准化 |
| 中档 | 一般商务、区域旅游 | 200-400元 | 舒适型，有限服务 |
| 中高端 | 城市商务、会议 | 400-700元 | 品质型，增值服务 |
| 高端 | 商务精英、高端政务 | 700-1500元 | 豪华型，全服务 |
| 奢华 | 企业高管、外籍 | 1500元+ | 尊享型，管家服务 |

## 二、筹建流程全周期

### 2.1 筹建阶段划分

```
市场调研 → 可行性分析 → 品牌选择 → 设计招标 → 施工建设 → 验收开业
   ↓           ↓           ↓          ↓         ↓           ↓
  2-3月       1月         1月       3-6月     12-24月     1-3月
```

### 2.2 各阶段核心任务

#### 阶段一：市场调研与可行性（30工作日）

1. **市场调研**
   - 国内酒店业发展情况分析
   - 项目所在城市酒店类别情况分析
   - 周边竞对酒店情况（STR数据）
   - 交通口岸及客源吞吐量分析
   - 细分市场情况分析

2. **酒店定位**
   - 酒店类型定位
   - 档次分级定位
   - 价格区间定位
   - 功能定位
   - 市场位置定位
   - 客群定位

3. **投资回报匡算**
   - 确定经营模式（自营/分包/租赁）
   - 编制10年收益预测
   - 计算投资回报期

#### 阶段二：设计阶段（3-6个月）

1. **建筑设计调整**
   - 依据酒店定位和功能布局需求调整建筑方案
   - 与原设计单位充分沟通
   - 完善建设需求文件

2. **室内设计**
   - 固装设计深化（2-3个月）
   - 内装设计创意概念图
   - 初步施工图

3. **各专业设计协调**
   - 消防安全设计/机电设计
   - 弱电设计
   - 软装设计
   - 灯光照明设计
   - AV视听设计
   - VI导视系统设计
   - 景观设计

4. **合图**
   - 完成全部设计部分
   - 各专业协调会签

#### 阶段三：施工与验收

1. **样板间打造**
2. **整体装修推进**
   - 倒排计划表
   - 主材封样检查
   - 验收样板间
   - 中期检查/隐蔽工程检查
   - 开业检查
3. **项目移交**
   - 工程缺陷跟进
   - 约定最终整改项及完成时间

#### 阶段四：开业筹备（3个月）

1. 经营团队组建及培训
2. 经营物资采购
3. 经营系统搭建（PMS/财务/营销/餐饮/数字化）
4. 标准化SOP梳理及培训
5. 开业前期营销推广
6. 试营业（1-3个月）

## 三、功能布局标准

### 3.1 前厅及公共区域

**前厅面积标准**：

| 酒店规模 | 前厅面积参考 |
|---------|------------|
| 100间客房 | 150-250㎡ |
| 150间客房 | 250-400㎡ |
| 200间客房 | 400-600㎡ |

**大堂吧配置**：
- 可与前台合并设计
- 餐位数与酒店定位匹配
- 运营时段灵活配置

### 3.2 客房配置标准

**睿景品牌标准**：
- 客房面积最小25㎡
- 前后场功能面积合理配置
- 单标间配比根据市场定位

**房型分类**：

| 房型 | 面积参考 | 配置标准 |
|------|---------|---------|
| 标准间 | 25-30㎡ | 基础配置 |
| 豪华间 | 35-45㎡ | 升级配置 |
| 套房 | 50-80㎡ | 行政配置 |
| 总统套房 | 150㎡+ | 奢华配置 |

**客房层高要求**：
- 一般楼层：2.8-3.0m
- 客房净高：≥2.6m

### 3.3 餐饮功能配置

**全日餐厅（ADD）**：
- 餐位数：客房数的30-50%（视定位）
- 位置：尽量与前厅同层或临近
- 前后场配比：1:1至1:1.2

**中餐/宴会**：
- 包间数量与客房规模匹配
- 宴会厅容纳量：课桌式/剧院式/宴会式
- 传菜动线合理规划

**厨房配置**：
- 后厨面积与餐位数匹配
- 专间区域（冷菜/热菜/面点/粗加工）
- 燃气/排油烟/消防设施

### 3.4 后场配置

| 功能区 | 配置要点 |
|--------|---------|
| 行政办公 | 前台/后台分区，独立办公区 |
| 客房服务中心 | 楼层中心布位，减少跑动 |
| 布草间 | 每层配置或集中设置 |
| 消洗间 | 楼层配置洗涤/消毒设施 |
| 工程部 | 设备机房/维修间/仓储 |
| 员工区 | 更衣室/宿舍/食堂/活动室 |

## 四、装修标准与选材

### 4.1 改造项目装修标准（6-12F案例参考）

**改造范围**：125间客房+公区

**核心改造内容**：
1. 卫生间干湿分区改造
2. 房间全面翻新
3. 空调支管更换
4. 弱电线路更换
5. 公区翻新
6. 家具家电更换

**卫生间标准**：
- 干湿分区：淋浴间独立
- 防水：至少1.8m高度防水层
- 地漏：防臭型，低位排水
- 五金：防锈耐用

### 4.2 客房装修选材

| 部位 | 推荐材料 | 参考价格 |
|------|---------|---------|
| 地面 | 地毯（50OZ）或SPC地板 | 150-300元/㎡ |
| 墙面 | 墙纸或艺术涂料 | 80-150元/㎡ |
| 天花 | 乳胶漆/石膏板 | 50-100元/㎡ |
| 卫生间墙地砖 | 瓷质砖 | 100-200元/㎡ |
| 卫浴 | 科勒/TOTO/国产一线 | 5000-15000元/间 |
| 房门 | 实木复合门+电子门锁 | 2000-4000元/套 |
| 窗 | 双层中空玻璃 | 标准配置 |

### 4.3 节能与智能化

**智能化配置**：
- 客房控制系统（RCU）
- 智能门锁
- 智能语音控制
- 手机开房/开锁
- PMS直连

**节能措施**：
- LED灯具
- 感应控制
- 变频空调
- 节水器具
