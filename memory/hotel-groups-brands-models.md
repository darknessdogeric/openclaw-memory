### 4.2 主要管理模式

#### 委托管理 (Management Contract)

```
定义: 酒店业主委托管理公司经营，支付管理费

结构
├── 业主: 投资物业、承担风险
├── 管理公司: 派驻团队、收取费用
└── 费用: 基本管理费 + 激励管理费

代表
├── 国际品牌: 洲际/万豪/希尔顿
└── 模式优势: 专业管理、品牌背书
```

#### 特许经营 (Franchise)

```
定义: 品牌方授权使用品牌，自主经营

结构
├── 品牌方: 提供品牌、培训、预订
├── 加盟方: 投资经营、自负盈亏
└── 费用: 加盟费 +  royalty fee + 预订费

代表
├── 经济型: 如家/汉庭/7天
└── 模式优势: 轻资产、快速扩张
```

#### 软品牌 (Soft Brand)

```
定义: 独立酒店加入品牌联盟

代表
├── 联盟: Global Blue / Leading Hotels
├── 精选: 傲途格精选 / 设计师联盟
└── 特点: 保持独立 + 品牌背书 + 会员导流
```

## 五、经营模式类型

### 5.1 重资产 vs 轻资产

| 模式 | 特征 | 代表 |
|------|------|------|
| 重资产 | 自有物业、自营 | 地产系酒店 |
| 轻资产 | 品牌输出、委托管理 | 华住、锦江 |
| 混合 | 自营+加盟并行 | 大型集团 |

### 5.2 直营 vs 加盟

| 模式 | 特征 | 优势 | 劣势 |
|------|------|------|------|
| 直营 | 集团投资、集团管理 | 品质可控 | 投入大、慢 |
| 加盟 | 业主投资、业主管理 | 轻资产、快扩张 | 品质风险 |
| 托管 | 第三方专业管理 | 专业+独立 | 利益协调 |
