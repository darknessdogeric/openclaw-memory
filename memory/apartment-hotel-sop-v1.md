## 一、公寓酒店概述

### 1.1 公寓酒店定义

```
公寓酒店(Extended Stay Hotel):
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  定义: 提供长期住宿服务的酒店业态，           │
│       兼具酒店服务与居家功能               │
│                                                             │
│  特征:                                                    │
│  ├── 房型大: 40-150㎡，有独立卧室/客厅/厨房      │
│  ├── 设施全: 洗衣机/冰箱/灶具/餐具              │
│  ├── 服务好: 酒店式服务+居家便利               │
│  ├── 租期活: 天/月/年都可                              │
│  └── 价格优: 长住折扣，月租相当于房价6-7折           │
│                                                             │
│  vs 酒店:                                                │
│  ├── 酒店: 空间小、无厨房、适合短住               │
│  ├── 公寓: 空间大、有厨房、适合长住               │
│  └── 差异: 生活方式 vs 住宿需求                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 公寓类型

```
公寓分类:
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  1. 服务式公寓 (Serviced Apartment)                   │
│     ├── 特征: 酒店式服务+居家配置                    │
│     ├── 配套: 全套家私+酒店服务                      │
│     ├── 客群: 出差中转、企业派遣                     │
│     └── 品牌: 雅诗阁、辉盛阁、铂涛菲                 │
│                                                             │
│  2. 长住公寓 (Extended Stay)                         │
│     ├── 特征: 月租为主、简单服务                    │
│     ├── 配套: 基本家私、简单厨房                    │
│     ├── 客群: 学生、陪读、过渡期                    │
│     └── 品牌: 城家、窝趣、嘉定                       │
│                                                             │
│  3. 共享公寓 (Co-living)                           │
│     ├── 特征: 共享空间、独立卧室                    │
│     ├── 配套: 共享厨房/客厅、獨立卧室              │
│     ├── 客群: 年轻白领、创业者                       │
│     └── 品牌: 暂新型业态                             │
│                                                             │
│  4. 精品公寓 (Boutique Apartment)                 │
│     ├── 特征: 高端装修、精品服务                    │
│     ├── 配套: 豪华配置、管家服务                   │
│     ├── 客群: 高管、企业主                           │
│     └── 品牌: 泊逸、曦盛                           │
│                                                             │
│  5. 企业公寓 (Corporate Apartment)                  │
│     ├── 特征: 企业协议、批量入住                    │
│     ├── 配套: 企业协议价、专属服务                 │
│     ├── 客群: 企业外派、异地培训                    │
│     └── 品牌: 雅诗阁企业、辉盛阁企业               │
│                                                             │
│  6. 养老公寓 (Senior Living)                       │
│     ├── 特征: 养老服务、医养结合                    │
│     ├── 配套: 护理服务、健康管理                   │
│     ├── 客群: 退休老人                             │
│     └── 品牌: 泰康、亲和源                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
