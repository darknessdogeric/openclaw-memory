## 五、博弈论过滤规则

### 5.1 过滤表

| 类别 | 号码 | 处理 | 原因 |
|------|------|------|------|
| 生日高频区 | 01-12 | 降权，只选13+ | 超80%彩民用生日 |
| 7的倍数 | 7,14,21,28,35 | 降权 | 7被视为幸运数 |
| 日期相关 | 26,20,2,6 | 降权 | 2026年26被高频选 |
| 吉祥数字 | 8,6,9 | 降权 | 8在中国文化中吉利 |

### 5.2 最优反人群组合特征

```
✅ 包含13-18之间的低频号
✅ 包含2区(22-28)的热号作为托底
✅ 后区包含大遗漏号(4,6,9,11)
✅ 前区无连号（或有但不是热门连号）
✅ 和值在85-110之间
✅ AC值 >= 8
```

## 十一、注意事项

1. **彩票是随机事件**：任何预测方法数学上都不比随机选号强
2. **V5.0提升期望收益**：不是提升中奖概率，而是降低分红稀释+风险控制
3. **持续迭代**：每期预测后更新热冷号、遗漏值等指标
4. **官网数据为准**：开奖结果必须以官网为准
