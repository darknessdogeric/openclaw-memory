## 一、什么是酒店项目定位策划

### 1.1 定义

**酒店项目定位策划 = 把"物业 + 业主诉求 + 资金 + 市场环境"转化为"这家酒店应该做成怎样的酒店"的完整过程。**

输入：4 个客观条件
- **物业**（位置、面积、结构、硬件状态）
- **业主诉求**（为什么做酒店、退出预期、资源禀赋）
- **资金**（自有资金、融资能力、授信）
- **市场环境**（3km 内供给、客群结构、城市/区域趋势）

输出：**一份定位策划方案**，回答 5 个问题：
1. 这家酒店为**谁**服务？（客群）
2. 这家酒店提供**什么**产品？（业态 + 房型 + 设施）
3. 这家酒店呈现什么**风格**？（视觉 + 空间 + 文化）
4. 这家酒店卖**多少钱**？（价格带）
5. 这家酒店让客人感受到**什么**？（体验 + 情感）

### 1.2 与相关概念的区别

| 概念 | 范围 | 主角 | 时机 |
|------|------|------|------|
| **项目定位策划** | 单一项目的产品定义 | 业主 + 顾问 | **项目立项前** |
| **运营管理** | 项目投产后 | GM + 运营团队 | 投产后 |
| **存量改造** | 老酒店升级 | 业主 + 顾问 | 改造前 |
| **品牌加盟** | 选哪个品牌 | 业主 + 品牌方 | 立项中 |

**关键洞察**：**项目定位策划是酒店生命周期的"出生证明"——错了一切都没救**

### 1.3 Eric 的实战场景

远途创业期（2016-2020）的核心业务模式：

```
业主：「我有一栋楼/一块地/一个物业，我想做酒店，应该做成什么样的？」
   ↓
Eric 6 步法：
1. 物业诊断（2-3 天现场看）
2. 市场分析（3km 走访 + 数据）
3. 客群研究（潜在客户访谈）
4. 竞品对标（同档位对比）
5. 定位设计（5 维输出）
6. 方案交付（PPT + 测算）
   ↓
业主：「按你说的做」（或不按，Eric 收咨询费）
```

## 二、项目定位的 5 大维度

一个酒店项目定位的核心是回答 5 个 W：

```
1. WHO   —— 客群定位（为谁服务）
2. WHAT  —— 产品定位（提供什么）
3. STYLE —— 风格定位（呈现什么调性）
4. PRICE —— 价位定位（卖多少钱）
5. EXP   —— 体验定位（客人感受什么）
```

### 2.1 维度 1：客群定位（WHO）

**核心问题**：这家酒店为谁服务？

**客群分类**（按消费力 + 出行目的双重维度）：

| 客群 | 消费力 | 主要出行目的 | 核心需求 |
|------|--------|------------|---------|
| **超高端商务** | ADR 2000+ | 商务/政务 | 隐私+身份+极致服务 |
| **高端休闲** | ADR 1000-2000 | 度假/文化体验 | 体验+故事+稀缺性 |
| **新中产商旅** | ADR 600-1000 | 商务+休闲 | 品质+效率+调性 |
| **白领主流** | ADR 350-600 | 商旅+亲友 | 干净+舒适+性价比 |
| **大众消费** | ADR 200-350 | 商旅+探亲 | 干净+便宜+便利 |
| **下沉市场** | ADR < 200 | 县域商旅+本地 | 便宜+干净 |

**3 维客群画像**：
- **人口学维度**：年龄、性别、职业、收入
- **行为学维度**：出行频率、预订渠道、决策权重、复购率
- **心理需求维度**：核心痛点、隐性期待、价值观认同

### 2.2 维度 2：产品定位（WHAT）

**核心问题**：这家酒店提供什么样的住宿产品？

**产品形态决策树**：

```
酒店项目
├─ 标准住宿型
│  ├─ 商务酒店（标准间为主、会议设施）
│  ├─ 度假酒店（休闲设施、景观房）
│  ├─ 生活方式酒店（咖啡/书吧/社交空间）
│  └─ 主题酒店（IP/文化/场景）
├─ 非标住宿型
│  ├─ 精品酒店（小规模、独特设计）
│  ├─ 民宿（个性化、当地文化）
│  ├─ 公寓酒店（长住、设施齐全）
│  └─ 客栈（地域文化）
└─ 新型业态
   ├─ AI Agent 酒店
   ├─ 医养酒店
   ├─ 数字游民酒店
   ├─ 宠物友好酒店
   └─ 装配式酒店
```

**产品要素清单**：
- 房型组合（大床/双床/套房/亲子/无障碍）
- 客房面积（18-80㎡+）
- 公共设施（餐厅/酒吧/健身房/SPA/游泳池/会议）
- 配套服务（早餐/下午茶/接送/管家）

### 2.3 维度 3：风格定位（STYLE）

**核心问题**：这家酒店呈现什么视觉/空间/文化调性？

**风格谱系**（从抽象到具体）：

```
中国东方美学
├─ 中式古典（红木/水墨/对称）
├─ 中式现代（极简东方/留白）
├─ 新中式（宋韵/明韵/侘寂东方）
└─ 地域文化（川西/江南/岭南/西北）

西方现代
├─ 现代极简（黑白灰/几何线条）
├─ 工业风（裸露/金属/loft）
├─ 北欧（自然/温暖/木质）
└─ 美式（粗犷/舒适/复古）

生活方式
├─ W 酒店风（潮流/夜店/时尚）
├─ Ace Hotel 风（文艺/社区/混合）
├─ 安缦风（极致私密/极简/灵性）
└─ citizenM 风（科技/自助/高效）

地域特色
├─ 民宿在地化（地方材料/手工艺）
├─ 度假村自然风（融入景观）
└─ 城市精品（街景融合）
```

**Eric 的强项**：根据 SOUL.md（审美人格底色），Eric 在风格定位上有**天然直觉**——这是远途创业期差异化竞争的核心。

### 2.4 维度 4：价位定位（PRICE）

**核心问题**：这家酒店卖多少钱？

**定价逻辑**：

| 定价法 | 适用场景 | 优势 | 劣势 |
|--------|---------|------|------|
| **成本定价** | 经济型、标准商务 | 简单 | 忽略价值 |
| **价值定价** | 中高端、精品 | 利润高 | 需差异化 |
| **竞品定价** | 中端连锁 | 易理解 | 同质化 |
| **需求定价** | 旺季/会展 | 收入最大化 | 客诉风险 |
| **心理定价** | 全档位 | 引导决策 | 需测试 |

**Eric 的实战洞察**：
> 「定价不是越便宜越好，也不是越贵越好。是看你定位的客群，**他们愿意为你的差异化付多少钱**。」

**价位带设计**：
- 主力房型价位（占 60% 库存）
- 高端房型价位（占 20%）
- 入门房型价位（占 20%）
- 周末/节假日加价幅度
- 渠道价差（OTA vs 官网 vs 会员）

### 2.5 维度 5：体验定位（EXP）

**核心问题**：客人感受到什么独特价值？

**体验三层模型**：

```
体验层
│
├─ 表层（功能层）：床、淋浴、Wifi、空调、早餐
│   → 满足基本需求
│
├─ 中层（情感层）：温暖、惊喜、归属、被尊重
│   → 建立情感连接
│
└─ 深层（精神层）：认同、文化、价值观
    → 创造精神共鸣
```

**Eric 远途时期的差异化打法**（推断）：
- 不在表层做文章（基本功能各家都做）
- 重在情感层 + 精神层（这是定位的真正差异化）

**体验触点设计**：
- 抵店前（预约/接送/到达指引）
- 抵店时（欢迎/办理入住/带房）
- 在店中（餐饮/客房/设施/服务）
- 离店时（结账/送别/反馈）
- 离店后（会员维护/复购激活）

## 三、项目定位策划的 6 步流程

### Step 1：物业诊断（1-3 天）

**目标**：摸清物业的"硬件家底"

**核心动作**：
- 现场踏勘（位置、外立面、动线、结构）
- 资料收集（产权、规划、消防、竣工图）
- 物业评估（建造年份、上次翻新、结构/水电/消防状态）
- 改造可行性（哪些能动、哪些不能动）

**Eric 的物业评估表**（核心字段）：
```
位置 / 周边 3km 商圈 / 物业年龄 / 上次翻新 / 结构形式
层高 / 柱距 / 电梯 / 楼梯 / 客房数（最大潜力）
消防等级 / 环保等级 / 规划限制 / 物业产权
月租金 / 总投入预估 / 改造周期预估
```

**输出**：一份《物业诊断报告》（5-10 页）

### Step 2：市场分析（3-7 天）

**目标**：找到市场"缝隙"

**核心动作**：
- 3km 内竞品扫描（所有档次、所有业态）
- 竞品 OCC/ADR/RevPAR 对比
- 客群结构分析（OTA 客评关键词挖掘）
- 城市/区域趋势（产业、人口、政策）
- 供给侧变化（未来 1-3 年新开酒店）

**核心输出**：
- 3km 竞品分布图（档次 × 价位 × OCC/ADR 矩阵）
- 市场空位图（哪些客群被满足 / 哪些客群无产品）
- 城市/区域判断（蓝海/红海/海归）

**Eric 的方法论**：
> 「市场分析不是找'有什么'，是找'缺什么'。**找到空位才是定位的起点**。」

### Step 3：客群研究（5-10 天）

**目标**：找到最值得服务的"那一群人"

**核心动作**：
- 潜在客群访谈（10-20 位业主认为的目标客群）
- OTA 客评挖掘（目标竞品的真实客户反馈）
- 业主过往客群数据分析（如果有）
- 客群画像（人口+行为+心理三维）

**客群画像模板**：
```
基础画像：
- 年龄段、性别比、来源城市
- 职业分布（商务/政务/旅游/探亲）
- 收入水平
- 出行频次

行为画像：
- 预订渠道偏好（OTA/官网/线下）
- 决策权重（位置/价格/品牌/服务）
- 平均入住时长
- 复购率

心理画像：
- 核心痛点（这是最重要的洞察）
- 隐性期待（没说出口但想要的）
- 价值观认同（什么样的故事打动他们）
```

**输出**：1-2 个核心客群画像（每个 200 字 + 1 张画像卡）

### Step 4：竞品对标（1-3 天）

**目标**：找到差异化方向

**核心动作**：
- 选 3-5 个标杆竞品（同档次/同区域/同档期）
- 5 维对比（客群、产品、风格、价位、体验）
- 优劣矩阵（SWOT）
- 差异化方向（哪些维度可以做到不一样）

**Eric 的洞察**：
> 「**差异化不是'做不同'，是'做更好'**。先想清楚客户为什么选择你，而不是为什么不来你。」

### Step 5：定位设计（2-5 天）

**目标**：5 维同时给出"这家酒店应该是什么"

**核心动作**：
- 综合 1-4 步的所有输入
- 在 5 维上分别给出"我们的选择"
- 互相验证（5 维之间是否自洽）
- 落地性检查（物业/资金/团队能否支撑）

**5 维输出模板**：
```
客群（WHO）：_______________
产品（WHAT）：_______________
风格（STYLE）：_______________
价位（PRICE）：_______________
体验（EXP）：_______________
```

**关键自检问题**：
- 这 5 维之间互相一致吗？
- 这是"我能做到的最好"还是"业主想要的"？
- 这与 3km 内所有竞品都不一样吗？
- 业主的资金/团队能撑住吗？
- 5 年后还能站得住吗？

**输出**：「定位声明」一句话版本

### Step 6：方案输出（2-5 天）

**目标**：把定位变成可落地的方案

**核心动作**：
- 定位声明（5 维精炼）
- 物业改造建议（哪些动、哪些不动）
- 品牌/运营建议（自营/加盟/全委）
- 投资匡算（总投入 + 3 场景 ROI）
- 风险提示（可能踩的坑）
- 时间表（从动工到开业）

**输出形式**：
- 完整版：《项目定位策划方案》PPT（30-50 页）
- 简版：5 页摘要（决策用）
- 测算：3 场景 ROI + NPV 模型

## 五、典型应用场景

### 场景 1：新建项目（如 Vhotel）

```
业主：「我有 5000㎡ 商业用地，想做酒店」
Eric 6 步：
1. 物业诊断 → 区位优势/劣势
2. 市场分析 → 3km 内空白点
3. 客群研究 → 谁会来这个位置
4. 竞品对标 → 跟谁不一样
5. 定位设计 → 5 维精炼
6. 方案输出 → 含选址报告 + 投资测算 + 时间表
```

### 场景 2：存量改造前置

```
业主：「我有家 100 间客房老酒店，要不要改造？」
Eric 6 步 → 关键是「先定位再改造」
1. 物业诊断 → 老酒店现状
2. 市场分析 → 现在市场缺什么
3. 客群研究 → 重新定义目标客群
4. 竞品对标 → 跟现在同档位差什么
5. 定位设计 → 重塑后的 5 维
6. 方案输出 → 改造方案（按定位倒推）
```

### 场景 3：品牌加盟决策

```
业主：「我应该加盟哪个品牌？」
Eric 的项目定位视角：
- 这家物业适合什么档次的品牌？
- 业主的客群画像 vs 品牌的客群画像？
- 加盟后是否还能保留项目独特性？
- 5 年退出/转自主品牌的可能性？
```
