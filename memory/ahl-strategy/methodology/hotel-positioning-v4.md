## 一、定位的本质（一句话）

**酒店项目定位 = 在约束条件下，找出 5 维的最优组合。**

```
输入（约束条件）         →         输出（5 维最优组合）
                                          
物业（位置、状态、成本）              WHO  — 客群
资金（自有、融资、授信）       →     WHAT — 产品
市场（3km 竞品、客群规模）              STYLE — 风格
团队（自有、外聘、托管）              PRICE — 价格
时间（短期、中期、长期）              EXP  — 体验
```

## 二、定位的 4 步科学分析法

### Step 1：数据收集

收集 4 类客观数据：

**A. 物业数据**
```
- 位置（区位类型、3km 商圈评分 1-10）
- 面积（总建面、客房区最大潜力）
- 状态（建造年份、上次翻新、结构/水电/消防评分 1-10）
- 产权（自持 / 租赁剩余年限）
- 改造成本（业主可承受上限）
```

**B. 市场数据**
```
- 3km 内竞品清单（档次、ADR 区间、OCC、评分）
- 客群规模（日均潜在流量：商旅/旅游/本地/探亲）
- 城市/区域趋势（产业、人口、增长率）
```

**C. 资源数据**
```
- 资金（总预算、自有/融资比例、风险承受）
- 团队（GM 经验、核心人员稳定性、外援能力）
- 时间（立项→开业周期、业主耐心周期）
```

**D. 业主诉求**
```
- 为什么做酒店（投资/资产/情怀/政企/产业）
- 退出预期（<5 年 / 5-10 年 / 10-20 年 / 永续）
- 业主隐性诉求（嘴上说的 vs 心里想的）
```

### Step 2：约束建模

把数据转化为数学约束：

**物业上限公式**
```
物业得分 = 区位 × 0.4 + 状态 × 0.3 + 改造成本可行性 × 0.3
上限 = f(物业得分)
  - 9-10：可做高端
  - 7-8 ：可做中高端
  - 5-6 ：可做中端
  - < 5 ：不建议做酒店
```

**客群下限公式**
```
客群规模 = 3km 日均潜在流量 × 转化率(0.5-3%) × 可入住率
可行性 = 客群规模 / 客房数（70 间起算）
  - > 2 ：客群充足
  - 1-2 ：客群刚好
  - < 1 ：客群不足
```

**资金约束**
```
可投总额 = 自有 + 融资 + 授信
单房造价 = 可投总额 / 客房数
  - > 15 万/间：可做高端
  - 8-15 万 ：可做中高端
  - 4-8 万  ：可做中端
  - 2-4 万  ：可做经济型
  - < 2 万  ：轻改/软装为主
```

### Step 3：组合筛选

列出所有可行 5 维组合，过滤不合理项：

**过滤规则**（任一违反即排除）：
```
1. PRICE × 物业得分 不匹配（高端物业卖经济型价格 = 排除）
2. STYLE × PRICE 不匹配（奢华风格卖中端价格 = 排除）
3. WHAT × 资金 不匹配（要做高端，资金只够中端 = 排除）
4. WHO × 客群规模 不匹配（定位高端商务，但 3km 没有商旅 = 排除）
5. EXP × 团队 不匹配（要做管家服务，团队没经验 = 排除）
```

**评分排序**
```
组合得分 = (物业匹配 × 0.25 + 客群匹配 × 0.25 + 资金匹配 × 0.2
        + 差异化 × 0.2 + 团队匹配 × 0.1)
        × 100

差异化 = 1 - 与最相似竞品的相似度
```

### Step 4：方案输出

输出最优组合的完整 5 维定义 + ROI 测算 + 风险提示。

## 四、5 维输出模板（标准化）

**WHO 客群**：
- 客群标签（30 字内）
- 客群规模（日均潜在流量）
- 核心痛点（10 字内）

**WHAT 产品**：
- 业态（商务/度假/精品/民宿/新业态）
- 客房数 + 房型组合
- 核心设施清单（10 项内）

**STYLE 风格**：
- 风格标签（5 字内）
- 3 个差异化设计点
- 与 3km 内竞品的差异

**PRICE 价格**：
- ADR 区间
- 主力房型占比
- 加价策略

**EXP 体验**：
- 3 个核心体验触点
- 1 个差异化体验
- 1 个情感层设计
