> **核心定位**：纯粹的酒店项目定位方法论，不考虑任何特定应用场景

## 一、定位的本质（一句话）

**酒店项目定位 = 在约束条件下，找出 5 维的最优组合。**

```
输入（约束条件）         →         输出（5 维最优组合）
                                          
物业（位置、状态、成本）              WHO  — 客群
资金（自有、融资、授信）       →     WHAT — 产品
市场（3km 竞品、客群规模）              STYLE — 风格
团队（自有、外聘、托管）              PRICE — 价格
时间（短期、中期、长期）              EXP  — 体验
```

---

## 二、4 类输入条件

### A. 物业条件

```
- 区位类型（CBD / 商圈 / 景区 / 交通枢纽 / 高校医院 / 园区 / 县域）
- 区位评分（1-10）：3km 商圈商业活跃度
- 物业状态评分（1-10）：结构 / 水电 / 消防 / 上次翻新时间
- 建筑参数：层数、层高、柱距、客房潜力、电梯数
- 产权：自持 / 租赁（剩余年限）
- 改造成本上限（业主可承受）
```

### B. 资金条件

```
- 总预算（自有 + 融资 + 授信）
- 单房可投 = 总预算 / 客房数
- 退出预期（< 5 年 / 5-10 年 / 10-20 年 / 永续）
```

### C. 市场条件

```
- 3km 内竞品清单（档次、ADR 区间、OCC、评分、客户标签）
- 客群规模（日均潜在流量：商旅 / 旅游 / 本地 / 探亲）
- 城市 / 区域趋势（产业、人口、增长率）
- 供给侧变化（未来 1-3 年新开酒店）
```

### D. 资源与诉求

```
- 团队：GM 经验、核心人员稳定性、外援能力
- 时间：立项 → 开业周期、业主耐心周期
- 业主隐性诉求：嘴上说的 vs 心里想的
```

## 三、5 个输出变量（不变量）

5 维是**通用的输出框架**，任何酒店项目的定位都需回答这 5 个问题：

### 维度 1：WHO 客群
```
- 客群标签（30 字内）
- 客群规模（日均潜在流量）
- 核心痛点（10 字内）
- 决策权重（位置 / 价格 / 品牌 / 服务 / 体验）
```

### 维度 2：WHAT 产品
```
- 业态（商务 / 度假 / 精品 / 民宿 / 公寓 / 新业态）
- 客房数 + 房型组合（大床 / 双床 / 套房 / 亲子 / 无障碍）
- 核心设施（餐厅 / 酒吧 / 健身房 / SPA / 会议 / 其他）
```

### 维度 3：STYLE 风格
```
- 风格标签（5 字内）
- 3 个差异化设计点
- 与 3km 内竞品的视觉差异
```

### 维度 4：PRICE 价格
```
- ADR 区间
- 主力房型占比
- 周末 / 节假日加价幅度
- 渠道价差（OTA / 官网 / 会员）
```

### 维度 5：EXP 体验
```
- 3 个核心体验触点（抵店 / 在店 / 离店）
- 1 个差异化体验（区别于竞品）
- 1 个情感层设计（建立连接 / 文化认同 / 精神共鸣）
```

## 四、科学分析的 4 步法

### Step 1：数据收集

收集第 2 部分的 4 类数据。把感性认识转化为可计算的客观输入。

### Step 2：约束建模（3 个公式）

把数据转化为数学约束，限定可行解空间。

#### 公式 1：物业上限公式

```
物业得分 = 区位 × 0.4 + 状态 × 0.3 + 改造成本可行性 × 0.3

改造成本可行性 = 业主可投 / 行业基线 × 10（封顶 10）

上限解读：
  9-10：可做高端（ADR 1500+）
  7-8 ：可做中高端（ADR 800-1500）
  5-6 ：可做中端（ADR 350-800）
  3-4 ：可做经济型（ADR 200-350）
  < 3 ：不建议做酒店
```

#### 公式 2：客群下限公式

```
客群规模 = 3km 日均潜在流量 × 转化率（0.5-3%）× 可入住率

可行性 = 客群规模 / 客房数（70 间起算）

下限解读：
  > 2 倍：客群充足
  1-2 倍：客群刚好
  < 1 倍：客群不足
```

#### 公式 3：单房可投公式

```
单房可投 = 总预算 / 客房数

档次匹配：
  > 15 万/间：高端
  8-15 万/间：中高端
  4-8 万/间：中端
  2-4 万/间：经济型
  < 2 万/间：轻改 / 软装
```

### Step 3：组合筛选

#### 5 条过滤规则（任一违反即排除）

```
规则 1：PRICE × 物业得分 不匹配
   反例：高端物业卖经济型价格
   
规则 2：STYLE × PRICE 不匹配
   反例：奢华风格卖中端价格
   
规则 3：WHAT × 资金 不匹配
   反例：要做高端，资金只够中端

规则 4：WHO × 客群规模 不匹配
   反例：定位高端商务，但 3km 没有商旅

规则 5：EXP × 团队 不匹配
   反例：要做管家服务，团队没经验
```

#### 评分公式

```
组合得分 =
   物业匹配 × 0.25
 + 客群匹配 × 0.25
 + 资金匹配 × 0.2
 + 差异化 × 0.2
 + 团队匹配 × 0.1

差异化 = 1 - max(与任一竞品的 5 维相似度)

总分 = 上述 × 100
```

### Step 4：方案输出

输出得分最高的 5 维组合 + ROI 测算（用 3 场景模板）+ 风险提示（用 32 避坑）。

## 八、定位常见错误（避坑）

### 错误 1：业主一厢情愿型
- 表现："我要做五星豪华"
- 后果：物业 / 客群 / 资金不匹配，必败
- 修正：5 维必须基于客观约束

### 错误 2：竞品跟随型
- 表现："隔壁有全季，我也做全季"
- 后果：同质化，价格战
- 修正：差异化评分必须 > 0.3

### 错误 3：硬件主导型
- 表现："我装修豪华就行"
- 后果：忽略服务 / 营销 / 客群
- 修正：5 维必须平衡

### 错误 4：客群想象型
- 表现："白领都喜欢这种风格"
- 后果：3km 内无真实客群
- 修正：客群规模公式验证

### 错误 5：资金超载型
- 表现："先按高端做，钱不够再说"
- 后果：改造期资金断裂
- 修正：单房可投公式限定档次

### 错误 6：时间错位型
- 表现：行业拐点已过还在入场
- 后果：竞争失位
- 修正：进场前做时势判断

## 九、5 维自评工具

### 物业评分（每项 1-10）

| 项目 | 关键问题 | 评分标准 |
|------|---------|---------|
| 区位 | 3km 商圈商业活跃度？ | 顶级 9-10 / 良好 7-8 / 一般 5-6 / 差 3-4 |
| 物业状态 | 结构 / 水电 / 消防？上次翻新？ | 全新 10 / 5 年内 8 / 5-10 年 6 / > 10 年 3 |
| 改造可行性 | 外立面可改？机电可换？ | 完全可改 10 / 部分可改 7 / 受限 4 |
| 客房潜力 | 最大客房数？动线可行？ | > 120 间 10 / 80-120 8 / 50-80 6 / < 50 4 |
| 产权 / 租约 | 自持？租约剩余？ | 自持 10 / 租 > 15 年 8 / 租 10-15 年 6 / < 10 年 3 |

**总分 = 5 项平均**
**> 7：建议做酒店**
**5-7：可做（需深度分析）**
**< 5：建议转手或退出**

### 5 维匹配度评分（0-1）

| 维度 | 评估对象 | 评分依据 |
|------|---------|---------|
| 物业匹配 | 客群与物业匹配度 | 客群类型与物业区位是否一致 |
| 客群匹配 | 客群规模与设计匹配 | 客群规模与定位档次是否一致 |
| 资金匹配 | 单房可投与档次匹配 | 单房可投与目标档次是否一致 |
| 差异化匹配 | 5 维与竞品差异 | 与最相似竞品的相似度倒数 |
| 团队匹配 | 团队能力与定位匹配 | 团队经验是否支撑目标档次 |

## 十、方法论的适用边界

本方法论适用于：
- 新建酒店项目（综合体 / 单体 / 民宿）
- 存量酒店改造（重定位 / 升级）
- 品牌加盟决策（业主选品牌）
- 顾问交付方案（业主咨询）
- 投资决策（私募 / REIT 尽调）

本方法论**不**适用于：
- 已建成酒店的运营优化（属运营管理范畴）
- 单店单品设计（如单店 VI / 单点营销，属营销设计范畴）
- 跨业态多元业务（需另立多业态方法论）

## 结语

**酒店项目定位 = 在约束条件下，找出 5 维的最优组合。**

```
      4 类客观输入           5 个数学约束          5 个输出变量
      （数据）              （公式）              （决策）
            ↓                   ↓                    ↓
       数据收集  →→  约束建模  →→  组合筛选  →→  方案输出
        
            ├─ 物业数据        ├─ 物业上限公式      ├─ WHO
            ├─ 资金数据        ├─ 客群下限公式      ├─ WHAT
            ├─ 市场数据        ├─ 单房可投公式      ├─ STYLE
            └─ 资源数据        └─ 过滤 + 评分       ├─ PRICE
                                                     └─ EXP
```

**输入输出清晰：4 类客观数据，5 个数学约束，5 个输出变量。**

**任何酒店项目定位都可以套用这个框架。**
