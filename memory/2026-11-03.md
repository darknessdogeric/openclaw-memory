## 五、⭐ 合作方对停业周期的三类影响（这是本次最有价值的发现）

| 类别 | 是否在关键路径 | 机制 |
|---|---|---|
| **甲类 · 决定停业起点** | 🔴 是 | **出图与报批周期在停业之前** |
| **乙类 · 决定停业长度** | 🔴 是 | **进场即占用作业面** |
| **丙类 · 决定开业时点** | 🟡 半 | 可与停业期并行 |

| 甲类（决定停业起点） | 前置期 |
|---|---|
| 建筑设计院（改造 + 减房结构） | 4–6 月 |
| 消防专项设计单位 | 3–4 月 |
| 机电设计（冷源/配电） | 3–4 月 |
| 造价咨询 / 招标代理 | 2–3 月 |
| 政府审批（规划/人防/消防审查） | 3–4 月 |

| 乙类（决定停业长度） | 占用期 |
|---|---|
| 施工总承包商 | 11–19 月 |
| 消防工程（1996 回路全换 + 联动 + 重新报审验收） | 7–9 月（最长单项） |
| 3 改 2 结构改造 | 8–10 月（方向二/三真瓶颈） |
| 冷源系统（542 FCU + 29 层流水） | 6–7 月 |
| 配电（4 台变压器逐台换） | 6–7 月 |

| 丙类（决定开业时点） | 交期 |
|---|---|
| **进口厨房设备** | **6–9 月 🔴** |
| FF&E 家具（进口/定制） | 4–6 月 |
| 艺术品采购与策展 | 3–5 月 |
| 软装设计与样品 | 2–4 月 |
| 开办（招聘/培训/系统） | 3–5 月 |

⭐⭐ **本次最重要的结论**：
**设计单位的出图节奏是唯一能把"停业前置期"变成 0 的角色。** 其他所有合作方都只能影响停业**之内**的时长，只有设计能让停业**从更晚的时间点开始**。
📌 **硬要求：设计单位与设计方案必须在停业决策前 4–6 个月锁定** —— 这个动作的价值大于任何施工层面的工期压缩。
🔴 **进口厨房设备 6–9 月交期必须倒推到停业前 9 个月**，否则停业结束时厨房开不了。

## 🏛 18:55 GMT+8 Eric 指令：换牌后怎么满足国资委投资测算口径

**触发**: Eric "如果还是总府皇冠假日酒店，那么就是需要符合国资委现有的投资测算口径。但是如果是换洲际其他品牌以及其他非洲际奢牌的时候，怎么符合投资测算呢？需要怎样才能满足国资委的口径呢？如果不满足现有口径又有什么办法呢去证明其必要性和可行性呢？"

**产出**: `anyi-ops-kb/02_项目/总府皇冠假日/总府皇冠改造_国资委投资测算口径适配与合规论证路径_v1.0_2026-11-03.md`（44.7 KB）+ 桌面 Word（63.8 KB）

### ⭐⭐ 核心答案（一句话）
**换牌能不能满足国资口径，关键不在"收益够不够好"，而在"交易结构能不能把品牌溢价与现金流改善变成可确权的所有者权益增值"。**

### 四套口径
| 口径 | 依据 | 关键结论 |
|---|---|---|
| **A 投资项目** | 国资委令34号 | 🔴 **禁止类标准含"达不到投资项目最低预期收益"→ IRR 不达标可能直接不能上会** |
| **B 资产评估** | 国资委令12号（2005） | ✅ 改建/扩建/技术改造**应当评估**；核准制与备案制；股权投资项目须尽调 + 评估/估值 |
| **C 资产证券化** | 酒店 REITs 估值准则 | ⭐⭐⭐ **禁止乐观改善类假设 + 大额改造支出不予纳入测算 → 制度上强制"先改造、后评估"**；有限服务适配度最优（总府全服务餐饮是拖累） |
| **D 保值增值考核** | 《国有资本保值增值结果评价规程》 | ⭐ 保值增值率 =（年末国家所有者权益÷年初国家所有者权益）×100%；**考核的是权益不是利润**；评估增值进专项储备→增权益；第9条"剔除考核期因素"需确认 |

### ⭐ 换牌后不符合口径的四个机理
① **品牌不是国资的资产** → 溢价无法直接确权｜② **收益被合同切割** → 须用业主可分配现金流（非总营业收入）｜③ **特许费费用化** → 资产+X、利润−Y，不自动等于权益改善｜④ 🔴 **IRR 达不到 = 禁止类**（我们的回收期 20–79 年）

### ⭐⭐ 六条适配路径
1. ⭐ **换评估方法**：用「评估增值率 =(V1−V0)/I」替代 IRR。⭐ **实证**：华安锦江 21 个酒店资产平均增值率 **68.26%**，最高福州台江 225.80%、广州白云 159.62%、**最差江阴澄江 −29.81%（可为负仍有先例）**；单房价值均值 **54.6 万/间** → 总府 402 间约 **2.19 亿**参照
2. ⭐⭐ **换交易结构**：**SPV 穿透 + 引入外部投资人分担 + 与品牌方签长期可评估特许合同**（契合集团"轻重分离"）
3. ⭐⭐⭐ **拆两期投资**：一期用「刚性义务」论证（法律/安全/监管认定）→ 绕开 IRR 门槛；二期用「资产增值」论证。⭐ **集团制度明文支持分期**（"各年度新开工项目投资额占总投资额的合理比例"）
4. ⭐⭐ **改用"不改造的代价"**：① 人身与刑事责任 ② 处罚与停业整顿 ③ 品牌违约 ④ **资产持续贬值 + 失去 REITs 入池资格** ⑤ **2029 丽晶 + IHG 到期双时间窗的机会成本** ⑥ 折旧摊销刚性
5. ⭐⭐ **序列安排**：改造先行 → 跑稳定期 12–18 个月 → 以实际数据做基准现金流
6. ⭐ **政策资金**：文旅 REITs / 200 亿基金 / 补 30% / 城市更新

### ⭐ 关键先例（必须引用）
**《福州美伦大饭店评估报告书》（2006-07-31 公开原件）**：将饭店**无形资产（品牌与客户关系）**用**收益现值法**纳入评估，依据是特许经营协议中的"**系统和专有商标**"
→ ⭐⭐ **换牌后品牌可入国资评估**，但需四个前提：① 合同期限 ≥ 收益年期 ② 费率与考核机制可预测 ③ 评估基准日与合同有效期一致 ④ 品牌方同意用于评估披露
