# 酒店行业报告标准格式体系 V1.0

> **创建日期**: 2026-03-18  
> **适用范围**: 月报、季报、年报、节假日专项报告  
> **参考来源**: 迈点研究院、环球旅讯、STR、浩华、彭润、石基、中国旅游饭店业协会、携程、美团等权威机构  
> **存储位置**: `memory/hotel-report-templates.md`

---

## 一、报告体系架构

### 1.1 报告类型矩阵

| 报告类型 | 发布频率 | 核心用途 | 数据粒度 | 典型篇幅 |
|---------|---------|---------|---------|---------|
| **月报** | 每月 | 运营监控、趋势跟踪 | 月度数据 | 15-25页 |
| **季报** | 每季 | 业绩评估、策略调整 | 季度对比 | 30-50页 |
| **年报** | 每年 | 战略复盘、年度规划 | 全年总结 | 80-150页 |
| **节假日报告** | 节假日前后 | 专项分析、预测复盘 | 特定时段 | 20-40页 |
| **专题报告** | 按需 | 深度研究、白皮书 | 专项维度 | 40-80页 |

### 1.2 报告受众定位

| 受众类型 | 关注重点 | 数据需求 | 呈现方式 |
|---------|---------|---------|---------|
| **酒店集团高管** | 战略趋势、竞争格局 | 核心指标、对标分析 | 图表为主、结论前置 |
| **单店总经理** | 运营优化、本地市场 | 详细数据、实操建议 | 数据详实、案例丰富 |
| **投资人/业主** | 投资回报、风险评估 | 财务指标、市场预测 | 简洁明了、重点突出 |
| **行业研究者** | 深度分析、理论框架 | 完整数据、研究方法 | 学术规范、引用完整 |
| **政府/协会** | 行业全景、政策建议 | 宏观数据、区域分布 | 政策导向、建议明确 |

```python
# 数据清洗标准流程
def data_cleaning_pipeline(raw_data):
    """数据清洗标准流程"""
    # 1. 缺失值处理
    data = handle_missing_values(raw_data)
    
    # 2. 异常值检测
    data = detect_outliers(data)
    
    # 3. 数据标准化
    data = standardize_format(data)
    
    # 4. 重复值处理
    data = remove_duplicates(data)
    
    # 5. 逻辑校验
    data = validate_logic(data)
    
    return data

# 同比/环比计算标准
def calculate_yoy(current, last_year):
    """同比计算"""
    if last_year == 0:
        return None
    return (current - last_year) / abs(last_year) * 100

def calculate_mom(current, last_period):
    """环比计算"""
    if last_period == 0:
        return None
    return (current - last_period) / abs(last_period) * 100
```
