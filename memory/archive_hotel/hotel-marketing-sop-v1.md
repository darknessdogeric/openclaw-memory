## 一、营销SOP底层逻辑

### 1.1 酒店营销的本质

**为什么酒店需要营销SOP?**

```
酒店营销的困境:
├── 产品无形性: 看不到、摸不着
├── 不可储存性: 房间今晚不住就浪费
├── 季节波动性: 淡旺季落差大
├── 客户分散性: 决策者、使用者、付款者分离
└── 高竞争性: 同区域多选择

→ 必须通过标准化流程确保:
   ① 获客效率
   ② 转化确定性
   ③ 客户留存
   ④ 品牌一致性
```

### 2.3 OTA运营SOP

**底层逻辑**: OTA是流量采买，要最大化ROI

#### 2.3.1 携程运营SOP

```
携程运营核心指标:
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  流量指标:                                                  │
│  ├── 曝光量: 展示次数                                      │
│  ├── 浏览量: 点击次数                                       │
│  ├── 转化率: 浏览→预订 行业平均3-5%                        │
│  └── 排名: 综合排名=销量25%+转化率20%+好评15%+响应15%+      │
│           挂牌10%+活动10%+信息5%                            │
│                                                             │
│  收益指标:                                                  │
│  ├── GMV: 成交金额                                          │
│  ├── ADR: 平均房价                                          │
│  ├── RevPAR: 每房收入                                       │
│  └── 佣金率: 10-15%                                        │
│                                                             │
│  服务指标:                                                  │
│  ├── 确认时效: 30分钟内                                     │
│  ├── 点评回复率: 100%                                       │
│  ├── 差评解决率: >80%                                       │
│  └── 拒单率: <2%                                           │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**携程挂牌冲刺SOP**:

| 阶段 | 时间 | 目标 | 核心动作 |
|------|------|------|----------|
| 基础期 | 1-4周 | 挂牌上线 | 资料完善+首批好评 |
| 爬坡期 | 5-12周 | 提升排名 | 增加销量+优化转化 |
| 冲刺期 | 13-20周 | 争取挂牌 | 冲刺金牌/特牌 |
| 维护期 | 持续 | 保持等级 | 持续优化+维护关系 |

**具体动作**:

```
Week 1-4: 基础建设
├── 开通携程账号
├── 上传完整资料(25+标签)
├── 设置首批房源(首图+标题+房型)
├── 首批好评获取(邀请入住客人)
├── 价格对标(竞品调研)
└── 参与平台活动(新店扶持)

Week 5-12: 流量获取
├── 销量增长(促销/活动)
├── 好评增长(点评引导)
├── 响应速度(30分钟内)
├── 转化率优化(首图/价格)
├── 参与平台活动(秒杀/特惠)
└── 数据监控(每日)

Week 13-20: 挂牌冲刺
├── 销量门槛达成
├── 好评率>4.7
├── 点评数>100
├── DSR>4.5
├── 参与金牌/特牌评选
└── 维护BD关系
```

#### 2.3.2 美团运营SOP

**美团 vs 携程 差异**:

| 维度 | 携程 | 美团 |
|------|------|------|
| 客群 | 商旅为主 | 本地+年轻 |
| 优势 | 品牌背书 | 价格敏感 |
| 活动 | 酒店节 | 天天特价 |
| 佣金 | 10-15% | 8-12% |
| 排序 | 综合权重 | 销量+价格 |

**美团运营重点**:
```
1. 价格策略
   - 可比携程略低5-10%
   - 参加"天天特价"
   - 设置"连住优惠"

2. 活动参与
   - 必参加: 新客立减、会员日
   - 选参加: 节日促销、平台补贴

3. 榜单冲刺
   - 好评榜
   - 热销榜
   - 回头客榜
```

```
基础价格 = 挂牌价 × 市场需求系数 × 竞品系数 × 渠道系数

参数说明:
├── 市场需求系数
│   ├── 周内: 0.8-1.0

│
├── 竞品系数
│   ├── 高于竞品: 1.05-1.1

│   └── 低于竞品: 0.9-0.95
│
└── 渠道系数
    ├── 官网直销: 0.9 (鼓励直销)
    ├──  OTA: 1.0 (标准)
    ├── 协议客: 0.7-0.8 (低价)
    └── Walk-in: 1.2 (高价)
```
