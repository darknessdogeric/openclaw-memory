## 0. 收益管理概述

### 0.1 收益管理定义

**什么是收益管理？**

收益管理（Revenue Management，简称RM）是一种基于数据驱动的定价和库存管理策略，其核心目标是 **"在正确的时间、以正确的价格、将正确的产品销售给正确的客户"**，从而实现收入最大化的科学管理体系。

**学术定义**：
> 收益管理是一种运用数据分析、预测模型和动态定价来优化可用资源（通常是易逝性库存）的收入的管理哲学。它通过平衡供给与需求，在保持客户满意度的同时最大化企业收入。

**酒店收益管理的本质**：
- **易逝性资产**：酒店房间一旦未售出，当日价值即刻归零（无法存储到次日销售）
- **固定成本高**：酒店固定成本占比高达60-70%，边际成本极低
- **需求波动大**：受季节、节假日、会议、天气等多因素影响
- **竞争激烈**：同区域酒店存在直接替代关系

## 1. STR核心对标指标体系

### 1.1 三大核心指数 (STAR Report)

| 指标 | 英文 | 公式 | 含义 |
|------|------|------|------|
| **ADR指数** | ADR Index | `酒店ADR / 市场ADR × 100%` | 定价能力对标 |
| **OCC指数** | Occupancy Index | `酒店OCC / 市场OCC × 100%` | 市场份额对标 |
| **RevPAR指数** | RevPAR Index | `酒店RevPAR / 市场RevPAR × 100%` | 综合收益能力对标 |

**解读**:
- **> 100%**: 优于市场
- **= 100%**: 与市场持平
- **< 100%**: 落后于市场

### 1.2 细分指数体系

| 指标 | 英文 | 公式 | 应用场景 |
|------|------|------|----------|
| **ARI** | Average Rate Index | `我店ADR / 竞争群ADR` | 直接竞品对标 |
| **MPI** | Market Penetration Index | `我店OCC% / 市场OCC%` | 市场渗透率 |
| **RGI** | Revenue Generation Index | `我店RevPAR / 竞争群RevPAR` | 收益生成效率 |
| **ARI** | Achievement of Revenue Index | `实际RevPAR / 目标RevPAR` | 目标达成率 |

### 1.3 竞争群组分析 (Comp Set)

```
STR竞争群组定义:
├── 地理竞争群 (同一区域)
├── 产品竞争群 (同一档次)
├── 服务竞争群 (同一星级)
└── 综合竞争群 (多维度加权)
```

### 1.4 基准数据维度

| 维度 | STR数据 | 用途 |
|------|---------|------|
| **Daily** | 日数据 | 实时监控 |
| **Weekly** | 周数据 | 短期趋势 |
| **Monthly** | 月度数据 | 运营分析 |
| **Year-to-Date** | 累计数据 | 年度评估 |
| **Moving 12 Months** | 滚动12月 | 长期趋势 |

### 1.5 高级分析指标

| 指标 | 英文 | 公式 | 说明 |
|------|------|------|------|
| **Supply** | 供应量 | 可售房总数 | 市场供给 |
| **Demand** | 需求量 | 已售房总数 | 市场需求 |
| **RevPAR** | 每房收益 | Revenue / Supply | 收益效率 |
| **ADR** | 平均房价 | Revenue / Demand | 定价水平 |
| **Occ %** | 入住率 | Demand / Supply × 100% | 市场热度 |
| **Room Rev** | 客房收入 | ADR × Demand | 收入规模 |

### 1.6 细分市场指标

| 市场类型 | 关键指标 |
|----------|----------|
| **Transient** |散客市场|
| - Weekend OCC | 周末入住率 |
| - Weekday OCC | 工作日入住率 |
| - ADR | 散客房价 |
| **Group** | 团队市场 |
| - Group Room Nights | 团队房晚 |
| - Group Revenue | 团队收入 |
| - Group ADR | 团队房价 |
| **Contract** | 协议市场 |
| - Corporate Rate | 协议价 |
| - Account Penetration | 账户渗透率 |

## 2. 收益管理公式库

### 2.1 STR指数计算公式

#### ARI (Average Rate Index)
```
ARI = (酒店ADR / 竞争群组ADR) × 100%
```

#### MPI (Market Penetration Index)
```
MPI = (酒店OCC% / 市场OCC%) × 100%
```

#### RGI (Revenue Generation Index)
```
RGI = (酒店RevPAR / 竞争群RevPAR) × 100%
```

### 2.2 动态定价公式

```
P(t) = P₀ × [1 + α×D(t) + β×C(t) + γ×E(t) + δ×T(t)]

参数:
- P(t): t时刻最优价格
- P₀: 基准价格
- D(t): 需求系数
- C(t): 竞争系数
- E(t): 事件系数
- T(t): 时间系数
```

### 2.3 需求预测公式

#### 指数平滑法
```
Forecast(t) = α × Actual(t-1) + (1-α) × Forecast(t-1)
```

#### Holt-Winters
```
Level(t) = α×Y(t) + (1-α)×(Level(t-1)+Trend(t-1))
Trend(t) = β×(Level(t)-Level(t-1)) + (1-β)×Trend(t-1)
Forecast(t+k) = Level(t) + k × Trend(t)
```

### 2.4 库存分配公式

```
Maximize: R = R_s × Q_s + R_g × Q_g

约束:
- Q_s + Q_g ≤ Q_total
- Q_s ≥ Q_s_min
- Q_g ≥ Q_g_min
```

## 3. 收益管理模型

### 3.1 经典模型

#### 3.1.1 BAR模型
```
BAR = 最低可接受价格
调整规则:
| 提前天数 | 调价幅度 |
|---------|----------|
| 0-7天   | +15~30% |
| 7-14天  | +5~15%  |
| 14-30天 | 基准价   |
| 30-60天 | -5~10%  |
```

#### 3.1.2 容量控制模型
```
库存分配策略:
┌─────────┬─────────┬─────────┐
│ 渠道    │ 配额比例 │ 价格策略 │
├─────────┼─────────┼─────────┤
│ 直销/私域│ 30-40% │ 最低价  │
│ 企业协议 │ 20-30% │ 中等价  │
│ OTA     │ 20-30% │ 动态价  │
│ Walk-in│10-20% │ 最高价 │
└─────────┴─────────┴─────────┘
```

### 3.2 AI/机器学习模型

#### 3.2.1 需求预测神经网络 (LSTM)
```
输入: [历史OCC, 节假日, 天气, 竞品价, 渠道流量, 事件]
输出: 未来30天需求预测
```

#### 3.2.2 强化学习定价 (Q-Learning)
```
状态: [OCC, 剩余房, 竞品价, 距入住天数]
动作: {降价15%, 降价10%, 维持, 提价5%, 提价10%, 提价15%}
奖励: RevPAR_after - RevPAR_baseline
```

#### 3.2.3 RFM++客户价值模型
```
R: 最近入住距今天数
F: 年度入住频次
M: 年度累计消费
P: 偏好(房型/渠道/时段)
L: 会员等级/复购周期
```
