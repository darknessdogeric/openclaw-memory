## 一、核心指标公式

### 1.1 基础指标

| 指标 | 公式 | 说明 |
|------|------|------|
| **RevPAR** | `= ADR × OCC` 或 `= 总收入 / 可售间夜数` | 每间可用客房收入 |
| **OCC（入住率）** | `= 已售间夜数 / 可售间夜数 × 100%` | 基础效率指标 |
| **ADR（平均房价）** | `= 总客房收入 / 已售间夜数` | 定价能力指标 |
| **GOP** | `= 总收入 - 可控成本` | 毛营业利润 |
| **GOP%** | `= GOP / 总收入 × 100%` | 盈利能力百分比 |
| **GOPPAR** | `= GOP / 可售间夜数` 或 `(总收入-可控成本)/已售间夜` | 每间可用客房GOP |
| **TRevPAR** | `= 总收入（含餐饮/F&B/其他) / 可售间夜` | 总收入每可用房 |
| **NRevPAR** | `= 净客房收入 / 可售间夜` | 扣除佣金后 |
| **ARPA** | `= 总客房收入 / 总入住房间数` | 每间实际入住房收入 |
| **床位出租率** | `= 已售床位 / 可售床位 × 100%` | 床位维度 |

### 1.2 收入类指标

```
总收入 = 客房收入 + 餐饮收入 + 其他收入
净客房收入 = 客房总收入 × (1 - 佣金率)
每间可用客房收入增量 = (新ADR - 旧ADR) × 新OCC
收入潜力 = OCC% × ADR × 可售间夜数
```

## 二、动态定价模型

### 2.1 基础动态定价

```
最优房价 = 基准价 × 需求系数 × 竞争系数 × 时间系数 × 渠道系数

其中:
需求系数 = f(预订进度, 距入住天数, 特殊事件)
竞争系数 = 本店价格 / 竞争对手均价
时间系数 = g(距入住天数)
渠道系数 = 1 / (1 - 渠道佣金率)
```

### 2.2 需求弹性定价

```
价格弹性系数 (Ed) = (需求量变化%) / (价格变化%)

Ed = ((Q2 - Q1) / Q1) / ((P2 - P1) / P1)

决策规则:
- Ed < -1: 弹性大 → 降价增收入
- Ed = -1: 单位弹性 → 价格最优
- -1 < Ed < 0: 弹性小 → 提价增收入
- Ed > 0: 吉芬商品 → 需调研
```

### 2.3 竞争对标定价

```
价格指数 = 本店价格 / 竞品均价

加权竞品定价:
P = w1×A + w2×B + w3×C + w4×D + w5×M

其中:
A/B/C/D = 竞品价格
M = 市场均价
w1+w2+w3+w4+w5 = 1

定位策略:
- 高端: P = 竞品均价 × 1.1
- 中高端: P = 竞品均价 × 0.95
- 中端: P = 竞品均价 × 0.85
- 经济型: P = 竞品均价 × 0.7
```

### 2.4 收益管理天花板模型

```
价格上限 = 竞品最低价 × (1 - 最小差异化)
价格下限 = 边际成本 × (1 + 最小边际率)

约束条件:
价格上限 ≥ 最优价格 ≥ 价格下限
```

## 三、预测模型

### 3.1 时间序列模型

#### 3.1.1 简单移动平均 (SMA)
```
SMA_n = (X_{t-1} + X_{t-2} + ... + X_{t-n}) / n
```

#### 3.1.2 加权移动平均 (WMA)
```
WMA = w1×X_{t-1} + w2×X_{t-2} + ... + wn×X_{t-n}
其中 w1+w2+...+wn = 1
```

#### 3.1.3 简单指数平滑 (SES)
```
S_t = α × X_{t-1} + (1-α) × S_{t-1}

其中 α ∈ (0,1) 为平滑系数
α 越大，对近期越敏感
通常 α = 0.1 ~ 0.3
```

#### 3.1.4 Holt线性趋势指数平滑
```
Level: L_t = α(Y_t - T_{t-1}) + (1-α)(L_{t-1} + T_{t-1})
Trend: T_t = β(L_t - L_{t-1}) + (1-β)T_{t-1}
Forecast: F_{t+h} = L_t + h×T_t

其中:
α = 水平平滑系数 (通常0.1-0.3)
β = 趋势平滑系数 (通常0.1-0.3)
h = 预测期数
```

#### 3.1.5 Holt-Winters三次指数平滑（季节性）
```
Level: L_t = α(Y_t / S_{t-s}) + (1-α)(L_{t-1} + T_{t-1})
Trend: T_t = β(L_t - L_{t-1}) + (1-β)T_{t-1}
Season: S_t = γ(Y_t / L_t) + (1-γ)S_{t-s}

加法模型预测: F_{t+h} = (L_t + h×T_t) + S_{t+h-s}
乘法模型预测: F_{t+h} = (L_t + h×T_t) × S_{t+h-s}

其中:
α = 水平平滑系数
β = 趋势平滑系数
γ = 季节平滑系数
s = 季节周期 (月s=12, 周s=7)
```

### 3.2 ARIMA模型

```
ARIMA(p,d,q) = AR(p) + I(d) + MA(q)

AR(p): X_t = c + φ1×X_{t-1} + φ2×X_{t-2} + ... + φp×X_{t-p} + ε_t
I(d): d阶差分使序列平稳
MA(q): X_t = μ + ε_t + θ1×ε_{t-1} + ... + θq×ε_{t-q}

常见模型:
- ARIMA(1,1,1): X_t - X_{t-1} = φ1×(X_{t-1} - X_{t-2}) + ε_t + θ1×ε_{t-1}
- ARIMA(2,1,2): 包含2阶自回归和2阶移动平均
- SARIMA: 季节性ARIMA, 添加 (P,D,Q)_s 参数
```

### 3.3 多元回归模型

```
Y = β₀ + β₁X₁ + β₂X₂ + β₃X₃ + ... + βₙXₙ + ε

其中:
Y = 预测变量 (需求量/ADR/OCC)
X₁...Xₙ = 自变量 (价格/季节/事件/竞争等)
β = 回归系数
ε = 误差项

常用变量:
X₁ = 历史同期入住率
X₂ = 提前预订天数
X₃ = 竞品价格指数
X₄ = 季节指数
X₅ = 特殊事件哑变量 (0/1)
```

### 3.4 预测准确度评估

| 指标 | 公式 | 优秀 | 良好 | 一般 | 较差 |
|------|------|------|------|------|------|
| **MAPE** | `= (1/n) × Σ|实际-预测|/实际 × 100%` | <5% | 5-10% | 10-20% | >20% |
| **MSE** | `= (1/n) × Σ(实际-预测)²` | 越小越好 |
| **RMSE** | `= √MSE` | 越小越好 |
| **MAE** | `= (1/n) × Σ|实际-预测|` | 越小越好 |
| **Bias** | `= 平均值(预测-实际)` | 应接近0 |

```
MAPE = (1/n) × Σ|((Y_actual - Y_predicted) / Y_actual)| × 100
RMSE = √[(1/n) × Σ(Y_actual - Y_predicted)²]
MAE = (1/n) × Σ|Y_actual - Y_predicted|
```

### 3.5 季节性指数

```
季节指数 = 当期平均值 / 整体平均值

12个月季节指数模板 (中国市场):
1月: 0.85 (春节后低谷)
2月: 0.90 (元宵后回升)
3月: 1.05 (春季回暖)
4月: 1.10 (清明小高峰)
5月: 1.15 (五一黄金周)
6月: 0.95 (高考前淡季)
7月: 1.20 (暑期旺季)
8月: 1.25 (暑期高峰)
9月: 1.00 (开学平季)
10月: 1.30 (国庆黄金)
11月: 0.90 (会展旺季)
12月: 0.95 (年末商务)
```

## 四、超额预订模型

### 4.1 基础Newsvendor模型

```
目标: 最大化期望收益

定义:
C = 房间容量 (可售房间数)
x = 预订数量 (决策变量)
ξ = 实际出现数量 (随机变量, 服从分布F)
p = 房间售价
c_u = 超额预订成本 (walk-in补偿/赔偿)
c_o = 未利用成本 (机会成本)

期望收益:
E[Revenue(x)] = p × min(x, ξ) - c_u × E[max(0, ξ - x)] - c_o × E[max(0, x - ξ)]
```

### 4.2 最优超额预订量

```
临界条件 (Newsvendor公式):

P(ξ ≤ x*) ≥ c_u / (c_u + c_o)

其中:
c_u = 单位低估成本 (underage cost) = 房间机会成本
c_o = 单位高估成本 (overage cost) = 补偿成本

Excel求解:
= NORMINV(c_u/(c_u+c_o), μ, σ)

其中:
μ = 平均no-show数量
σ = no-show标准差
```

### 4.3 No-Show概率模型

```
设 N = 预订房间数
设 s = 预期no-show率
设 c = 容量

目标: 找到最大接受预订数 x*

P(no-shows ≤ x - c) = Cu / (Cu + Co)

或等价为:

x* = c + F⁻¹(Cu / (Cu + Co))

其中 F⁻¹ 为no-show分布的反函数
```

### 4.4 分步超额预订策略

```
步骤1: 计算基线超额量
OB_base = 预订数 - 容量

步骤2: 根据no-show率调整
OB_adjusted = OB_base × (1 + s)

步骤3: 根据取消率调整
OB_final = OB_adjusted × (1 + 取消率)

步骤4: 考虑walk-in转化率
最终预订上限 = 容量 + OB_final - walk-in预期数
```

## 五、渠道优化模型

### 5.1 渠道贡献度矩阵

```
渠道综合得分 = w₁×流量得分 + w₂×转化得分 + w₃×利润得分 + w₄×品牌得分

权重建议:
w₁ (流量) = 25%
w₂ (转化率) = 30%
w₃ (利润) = 30%
w₄ (品牌) = 15%
```

### 5.2 渠道ROI

```
渠道ROI = 渠道总收入 / 渠道总成本

渠道总成本 = 佣金支出 + 营销费用 + 取消损失 + 运营成本

渠道利润贡献 = 渠道收入 × (1 - 佣金率 - 取消率) - 固定成本
```

### 5.3 线性规划渠道分配

```
目标函数:
最大化 Z = Σᵢ (rᵢ × xᵢ)

约束:
1. 产能约束: Σᵢ xᵢ ≤ C (总可售)
2. 最低占比约束: xᵢ ≥ C × mᵢ (每个渠道最低占比)
3. 最高占比约束: xᵢ ≤ C × Mᵢ (每个渠道最高占比)
4. 非负约束: xᵢ ≥ 0

其中:
rᵢ = 渠道i的净收益率
xᵢ = 渠道i分配的间夜数
C = 总可售间夜数
mᵢ = 渠道i最低占比
Mᵢ = 渠道i最高占比
```

### 5.4 动态配额分配

```
分阶段释放策略 (OTA配额):

T > 60天: OTA配额 = 30%, 直销 = 50%, 协议 = 20%
30 < T ≤ 60天: OTA配额 = 40%, 直销 = 40%, 协议 = 20%
14 < T ≤ 30天: OTA配额 = 50%, 直销 = 30%, 协议 = 20%
7 < T ≤ 14天: OTA配额 = 60%, 直销 = 20%, 协议 = 20%
T ≤ 7天: OTA配额 = 70%, 直销 = 15%, 协议 = 15%

调整公式:
Q_t = Q_base × D_t × C_t

其中:
Q_t = 当期配额
Q_base = 基础配额
D_t = 需求系数 = 实际需求 / 预期需求
C_t = 竞争系数 = 本店价格 / 竞品均价
```

## 六、置换收益分析

### 6.1 Upgrade决策模型

```
Upgrade期望收益:
E[Upgrade] = P(接受) × (升级价差 - 升级成本)

Upgrade接受率模型 (逻辑回归):
P(接受) = 1 / (1 + e^(-z))

其中:
z = β₀ + β₁×(价差/原房价) + β₂×会员等级 + β₃×特殊日期

参数估计 (SPSS/Excel):
β₀ ≈ 截距
β₁ ≈ -2.5 (价差越大,接受率越低)
β₂ ≈ +1.2 (高卡会员更接受)
```

### 6.2 Walk-in定价

```
Walk-in最优价格 = 当日边际收益 × 需求弹性调整

基础公式:
P_walk = P_ota / (1 - 溢价率)

溢价率决策:
OCC < 60%: 溢价率 = 0%
60% ≤ OCC < 80%: 溢价率 = 5-10%
80% ≤ OCC < 95%: 溢价率 = 10-20%
OCC ≥ 95%: 溢价率 = 20-50%
```

### 6.3 置换收益计算

```
净置换收益 = (升级收入 - 原房收入 - 升级成本) + (Walkin收入 - 预留房期望收入)

置换决策树:
1. OCC < 85%? → 是 → 自由Upgrade, 接受Walk-in
2. OCC ≥ 85%? → 进入精细计算
   ├─ Upgrade净收益 > 0? → 执行Upgrade
   └─ Walk-in报价 > 预留期望收益? → 接受Walk-in
```

## 七、住宿时长优化(LOS)

### 7.1 最短入住夜数(MinLOS)决策

```
最优MinLOS = argmax Σ(ADR_i × OCC_i × prob_i)

其中:
ADR_i = i夜住宿的平均房价
OCC_i = 设置i夜后的入住率
prob_i = i夜住宿的概率

约束:
- MinLOS不能超过竞争对手
- 需要足够的2夜+预订支撑OCC
```

### 7.2 LOS分布分析

```
LOS分布指标:
- 平均LOS = Σ(n × f_n) / Σf_n
- 中位数LOS
- LOS标准差

LOS贡献度:
LOS贡献 = Σ(房间数 × 天数 × ADR) / 总收入 × 100%
```

### 7.3 住宿限制策略

```
Closed to Arrival (CTA): 禁止某天入住
Closed to Departure (CTD): 禁止某天离店
Minimum Stay Requirement (MinSR): 最低入住夜数
Maximum Stay Limit (MaxSL): 最高入住夜数
Night GapRestriction: 禁止中间某天不入住
One Night Only (ONO): 仅接受一夜预订
```

## 八、竞争分析模型

### 8.1 Comp Set STAR报告指标

```
STAR报告结构:
- Self: 本酒店表现
- Today: 今日/本周/本月
- STAR: 同比/环比分析
- Ranking: 在comp set中的排名

计算:
指数 = 本店值 / Comp Set平均值 × 100

Occupancy Index = 本店OCC / Comp Set平均OCC × 100
ADR Index = 本店ADR / Comp Set平均ADR × 100
RevPAR Index = 本店RevPAR / Comp Set平均RevPAR × 100

>100 表示优于市场
<100 表示落后于市场
```

### 8.2 市场份额模型

```
绝对份额 = 本店收入 / 市场规模 × 100%

相对份额 = 本店收入 / 主要竞争对手收入 × 100%

收入份额变化 = 本期份额 - 上期份额
```

### 8.3 竞争价格追踪

```
竞品价格指数 (CPI):
CPI_t = (1/n) × Σ(本店价格_t / 竞品价格_t)

指数 > 100: 本店定价高于竞品
指数 < 100: 本店定价低于竞品
```

## 九、预算与KPI模型

### 9.1 预算编制模型

```
目标RevPAR = 上期RevPAR × (1 + 增长率目标)

分解:
目标ADR = 目标RevPAR / 目标OCC
目标OCC = 目标RevPAR / 目标ADR

收入预算 = Σ(ADR_i × 可售间夜_i)
```

### 9.2 KPI分解模型

```
OCC贡献 = 客房间数 × 目标OCC × ADR_benchmark
ADR贡献 = 可售间夜数 × ADR增量 × 目标OCC
组合效应 = 客房间数 × ADR增量 × OCC增量
```

### 9.3 动态预算调整

```
预算修订触发条件:
1. OCC实际 vs 预算偏差 > 5%
2. ADR实际 vs 预算偏差 > 10%
3. 重大市场变化 (>10%市场波动)

调整公式:
修订预算 = 原预算 × (实际OCC/预算OCC) × (实际ADR/预算ADR)
```

## 十、高级量化模型

### 10.1 马尔可夫链状态转移

```
状态空间: {低需求, 中需求, 高需求, 满房}

转移概率矩阵 P:
        低   中   高   满
低    [p11  p12  p13  p14]
中    [p21  p22  p23  p24]
高    [p31  p32  p33  p34]
满    [p41  p42  p43  p44]

第n天状态 = 第0天状态 × P^n

应用: 预测未来需求状态分布
```

### 10.2 蒙特卡洛模拟

```
收益模拟步骤:

1. 定义变量分布:
   - 需求量: 正态分布 N(μ, σ)
   - 取消率: Beta分布
   - no-show率: 历史比例

2. 随机抽样 (N=10000次):
   for i in range(N):
       D_i = sample(需求量分布)
       C_i = sample(取消率分布)
       ...
       Revenue_i = f(D_i, C_i, ...)

3. 计算统计量:
   E[Revenue] = mean(Revenue_i)
   VaR_95 = percentile(Revenue_i, 5)
   CVaR_95 = mean(Revenue_i | Revenue_i ≤ VaR_95)

4. 决策: 选择期望收益最大化或风险最小的方案
```

### 10.3 排队论模型 (Walk-in)

```
M/M/1/K 排队模型:
- 到达: 泊松过程, 率λ
- 服务: 指数分布, 率μ
- 容量: K

关键指标:
利用率 ρ = λ / μ
平均等待时间 Wq = ρ / (μ - λ)
平均队列长度 Lq = ρ² / (1 - ρ)

决策: 当利用率 > 80% 时, 考虑扩容或提价
```

## 十一、附录: Excel公式速查

### 核心公式
```
RevPAR = ADR × OCC
GOP = 总收入 - 可控成本
GOPPAR = GOP / 可售间夜
TRevPAR = 总收入 / 可售间夜
NRevPAR = 净客房收入 / 可售间夜
```

### 预测公式
```
MAPE = AVERAGE(ABS((实际-预测)/实际))*100
RMSE = SQRT(AVERAGE((实际-预测)^2))
指数平滑 = α*本期实际 + (1-α)*上期预测
趋势 = β*(本期平滑-上期平滑) + (1-β)*上期趋势
```

### 定价公式
```
最优价格 = 基准价 × 需求系数 × 竞争系数 × 时间系数 × 渠道系数
需求弹性 = ((新销量-旧销量)/旧销量)/((新价格-旧价格)/旧价格)
弹性定价 = 边际成本 / (1 + 1/Ed)
```

### 渠道公式
```
渠道ROI = 渠道收入 / 渠道成本
渠道利润 = 收入×(1-佣金率-取消率)-固定成本
加权均价 = Σ(渠道价×权重)
```

### 超额预订
