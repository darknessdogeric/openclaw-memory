## 一、酒店新媒体全景

### 1.1 新媒体定义

```
新媒体 = 数字化、互动式、社交化的媒体形态

对比传统媒体:
| 维度 | 传统媒体 | 新媒体 |
|------|----------|--------|
| 渠道 | 电视/报纸/杂志 | 微信/抖音/小红书 |
| 传播 | 单向广播 | 双向互动 |
| 内容 | 专业生产 | UGC+PGC+AIGC |
| 覆盖 | 广撒网 | 精准触达 |
| 成本 | 高 | 低 |
| 效果 | 难量化 | 可追踪 |
```

### 1.3 酒店新媒体价值

```
新媒体对酒店的核心价值:

1. 获客 (Acquisition)
   - 曝光: 让更多人知道酒店
   - 种草: 激发用户兴趣
   - 转化: 引导预订

2. 品牌 (Brand)
   - 形象塑造
   - 用户认知
   - 口碑沉淀

3. 互动 (Engagement)
   - 用户沟通
   - 反馈收集
   - 关系维护

4. 复购 (Retention)
   - 会员沉淀
   - 复购引导
   - LTV提升
```
