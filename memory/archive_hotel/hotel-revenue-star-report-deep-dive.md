## 一、STR STAR报告概述

### 1.1 什么是STR STAR报告

Smith Travel Research (STR) 是全球酒店业最权威的 benchmarking 数据提供商。STAR报告是STR的核心产品，用于：

```
目的:
1. 衡量本店与竞争群的相对表现
2. 识别市场机会和威胁
3. 制定收益管理策略
4. 业主评估管理公司绩效
```

### 1.2 STAR报告核心KPI

STAR报告聚焦三大核心指标：

| 指标 | 公式 | 行业意义 |
|------|------|----------|
| **Occupancy (OCC)** | 已售客房 / 可售客房 × 100% | 市场收割能力 |
| **ADR** | 客房收入 / 已售客房 | 定价能力 |
| **RevPAR** | ADR × OCC 或 客房收入 / 可售客房 | 综合竞争力 |

---

## 二、STAR指数体系

### 2.1 三大指数计算

```
Occupancy Index (OCC Index) = 本店OCC / 竞争群平均OCC × 100
ADR Index = 本店ADR / 竞争群平均ADR × 100
RevPAR Index = 本店RevPAR / 竞争群平均RevPAR × 100
```

**解读规则**：
```
> 100 = 优于竞争群 (领先者)
= 100 = 与竞争群持平 (跟随者)
< 100 = 落后于竞争群 (挑战者)
```

### 2.2 指数组合分析矩阵

| OCC Index | ADR Index | 诊断 | 策略 |
|-----------|-----------|------|------|
| >100 | >100 | **双优** | 领导地位，保护溢价 |
| >100 | <100 | **量优价劣** | 提高低价房型质量 |
| <100 | >100 | **价优量劣** | 增加低价房型供给 |
| <100 | <100 | **双劣** | 全面检查，重建竞争力 |

### 2.3 实例计算

```
竞争群数据:
  Hotel A: OCC=75%, ADR=¥380
  Hotel B: OCC=68%, ADR=¥420
  Hotel C: OCC=72%, ADR=¥350
  Hotel D: OCC=70%, ADR=¥390

竞争群均值:
  平均OCC = (75+68+72+70)/4 = 71.25%
  平均ADR = (380+420+350+390)/4 = ¥385

本店数据:
  OCC=78%, ADR=¥370

本店指数:
  OCC Index = 78/71.25 × 100 = 109.5 (优于市场)
  ADR Index = 370/385 × 100 = 96.1 (略低于市场)
  RevPAR Index = (370×78)/(385×71.25) × 100 = 105.5

诊断: "量优价劣"型 — 应该提升ADR或优化客户结构
```

## 三、市场渗透指数 (MPI)

### 3.1 MPI定义与计算

```
MPI (Market Penetration Index) = 本店OCC / 市场平均OCC × 100

或者用竞争群替代市场:
MPI = 本店OCC / 竞争群平均OCC × 100
```

### 3.2 MPI等级

| MPI范围 | 等级 | 含义 |
|---------|------|------|
| MPI > 130 | 显著领先 | 极度强势地位 |
| 110 < MPI < 130 | 强势 | 领导市场 |
| 90 < MPI < 110 | 正常 | 与市场同步 |
| 70 < MPI < 90 | 弱势 | 需要改进 |
| MPI < 70 | 严重弱势 | 危机状态 |

### 3.3 MPI应用场景

```
场景1: 新开业酒店
  目标: MPI从60起步，逐年提升到90+

场景2: 改造后酒店
  目标: MPI提升15-20点

场景3: 竞争对手开业
  监控: MPI下降幅度，评估冲击程度
```

---

## 四、收入生成指数 (RGI)

### 4.1 RGI定义与计算

```
RGI (Revenue Generation Index) = 本店RevPAR / 竞争群RevPAR × 100
```

### 4.2 RGI与OCC Index + ADR Index的关系

```
RGI = (ADR_index × OCC_index) / 100

验证: RGI = 105.5 (来自2.3例)
     = (96.1 × 109.5) / 100 = 105.5 ✓
```

### 4.3 RGI优化路径

| 当前RGI | 目标 | 路径 |
|---------|------|------|
| <80 | 追赶到100 | 先提升OCC，再提升ADR |
| 80-100 | 追赶到110 | OCC和ADR均衡提升 |
| 100-120 | 巩固领导 | 保持溢价，提升OCC |
| >120 | 保护地位 | 防御策略，防止过度溢价流失 |

---

## 五、平均房价指数 (ARI)

### 5.1 ARI定义

```
ARI (Average Rate Index) = 本店ADR / 竞争群ADR × 100

注意: 与ADR Index相同，但STR中ARI特指房价指数
```

### 5.2 ARI与房价策略

```
ARI < 90: 酒店在用低价获取市场份额
ARI = 90-110: 酒店在合理竞争范围
ARI > 110: 酒店在保护溢价，可能流失客户
```

### 5.3 ARI与产品定位匹配

| 酒店定位 | 合理ARI范围 | 说明 |
|---------|-------------|------|
| 高端/奢华 | 115-150+ | 溢价定价，目标高端客群 |
| 中高端 | 95-115 | 略高于平均，与产品匹配 |
| 中端 | 85-105 | 与市场同步 |
| 经济型 | 65-90 | 低价策略，快销为主 |

## 六、竞争群(Comp Set)构建方法

### 6.1 Comp Set构建原则

```
基本要求:
1. 地理位置相近 (3-5公里范围内)
2. 档次/星级相近
3. 目标客群相似
4. 房间数相近 (本店房间数的0.5-2倍)
5. 同一细分市场
```

### 6.2 Comp Set成员选择

**正确选择**:
```
✅ 同区域同档次酒店
✅ 同一商圈内直接竞争对手
✅ 目标客群重叠的酒店
✅ 有OTA评星可比的酒店
```

**避免选择**:
```
❌ 地理位置过远的酒店
❌ 档次差距过大的酒店
❌ 新开业没有历史数据的酒店
❌ 非酒店业态(民宿/公寓)
```

### 6.3 Comp Set规模

| 酒店规模 | 建议Comp Set数量 |
|---------|-----------------|
| <100间 | 3-5家 |
| 100-300间 | 5-8家 |
| 300-500间 | 8-12家 |
| >500间 | 10-15家 |

### 6.4 动态调整Comp Set

```
季度审视:
1. 检查是否有新开业酒店加入竞争
2. 检查是否有酒店停业/改造
3. 评估现有成员是否仍然相关
4. 调整后记录并保持一致性

注意: STR报告要求Comp Set至少保持6个月稳定
```

## 七、STR数据采集与报告类型

### 7.1 数据采集方式

```
STR数据来源:
1. 酒店主动上报 (PMS系统对接)
2. STR调查问卷
3. 公开渠道验证
4. 合作PMS供应商数据

数据要求:
- 日度数据: 出租率、平均房价、收入
- 月度数据: 细分市场分解
- 年度数据: 翻新/改造信息
```

### 7.2 报告周期

| 报告类型 | 周期 | 主要用途 |
|---------|------|---------|
| Daily Flash | 每日 | 即时监控 |
| Weekly Report | 每周 | 短期调整 |
| Monthly Report | 每月 | 月度复盘 |
| Quarterly | 每季 | 策略调整 |
| Annual | 每年 | 年度规划 |

### 7.3 STR报告核心TAB

| TAB | 内容 | 关键指标 |
|-----|------|---------|
| Tab 1 | 月度概览 | OCC/ADR/RevPAR及指数 |
| Tab 2 | 竞争群表现 | 群内各酒店明细 |
| Tab 3 | 同比/环比 | vs去年同期/上期 |
| Tab 4 | 细分市场 | 散客/团队/企业细分 |
| Tab 5 | 渠道表现 | OTA/直销/协议分析 |
| Tab 6 | 长期趋势 | 12个月滚动 |

## 八、STAR报告实战解读流程

### 8.1 解读六步法

```
Step 1: 确认数据准确性
  - 检查是否有异常值
  - 确认数据口径一致
  - 核实特殊事件影响

Step 2: 计算本店指数
  - OCC Index
  - ADR Index
  - RevPAR Index (RGI)

Step 3: 分析指数组合
  - 识别是"量优价劣"还是"双优"
  - 与上期/上年同期对比

Step 4: 竞争群分解
  - 找出群内最强和最弱竞争对手
  - 分析差距原因

Step 5: 制定行动计划
  - 根据指数诊断确定策略
  - 设定改善目标

Step 6: 跟踪验证
  - 每月复盘指数变化
  - 验证策略有效性
```

### 8.2 常见诊断场景

**场景1: OCC Index持续下降**
```
可能原因:
- 竞争群新增客房
- 本店价格高于价值感知
- 竞争对手进行促销活动
- 本店口碑下降

应对策略:
1. 检查ADR Index是否过高
2. 评估竞品是否有新优势
3. 检查OTA排名和评分
4. 考虑适当的促销
```

**场景2: ADR Index下降但OCC Index上升**
```
可能原因:
- 酒店在用低价抢占市场份额
- 高价客户流失
- 产品定位下调

应对策略:
1. 检查是否是主动降价
2. 评估低价客户的长期价值
3. 重新审视产品-价格匹配
4. 防止陷入低价陷阱
```

**场景3: RevPAR Index低于OCC Index和ADR Index**
```
这通常意味着:
- 酒店依赖低价获取入住率
- 高中低房型组合不合理
- 高价房型销售不佳

应对策略:
1. 优化房型组合
2. 提升高价房型的吸引力
3. 加强溢价产品的销售培训
```

## 九、中国市场STAR应用

### 9.1 中国STR数据特点

```
数据覆盖:
- 一二线城市覆盖率较高
- 三四线城市覆盖率较低
- 精品酒店/民宿数据不完整

数据质量问题:
- 部分酒店数据上报不完整
- 佣金渠道数据难以核实
- 会有异常值需要清洗
```

### 9.2 中国特色Comp Set构建

```
传统做法:
  按星级(五星/四星/三星) + 地理位置构建

进阶做法:
  按目标客群细分:
  - 商务型酒店 Comp Set
  - 休闲度假型酒店 Comp Set
  - 会议型酒店 Comp Set
  - 长住型酒店 Comp Set

OTA时代做法:
  结合OTA评分和评论关键词:
  - 同一价格区间(¥300-500)
  - 同一评分区间(4.5-4.8)
  - 相似点评关键词(交通方便/设施新)
```

### 9.3 中国市场Benchmark

**2024年中国酒店业平均指标**:

| 档次 | OCC | ADR | RevPAR |
|------|-----|-----|--------|
| 经济型 | 65-75% | ¥120-180 | ¥80-130 |
| 中端 | 60-70% | ¥220-320 | ¥140-210 |
| 中高端 | 55-65% | ¥380-550 | ¥210-340 |
| 高端 | 50-60% | ¥600-1000 | ¥320-560 |
| 奢华 | 45-55% | ¥1200-3000+ | ¥600-1500 |

**中国市场特有指标**:
```
- 携程评分 (4.1-4.9)
- 美团评分 (3.5-5.0)
- 抖音热度 (0-100)
- 小红书笔记数
```

## 十、Python实现STR分析

```python
class STRAnalyzer:
    """STR STAR报告分析工具"""

    def __init__(self):
        self.comp_set = []
        self.self_data = None

    def add_competitor(self, name: str, occ: float, adr: float,
                      rooms: int = 100):
        """添加竞争群成员"""
        self.comp_set.append({
            'name': name,
            'occ': occ,
            'adr': adr,
            'rooms': rooms,
            'revpar': adr * occ / 100
        })

    def set_self(self, name: str, occ: float, adr: float,
                rooms: int = 100):
        """设置本店数据"""
        self.self_data = {
            'name': name,
            'occ': occ,
            'adr': adr,
            'rooms': rooms,
            'revpar': adr * occ / 100
        }

    def calculate_comp_avg(self):
        """计算竞争群均值"""
        if not self.comp_set:
            return {'occ': 0, 'adr': 0, 'revpar': 0}

        n = len(self.comp_set)
        return {
            'occ': sum(c['occ'] for c in self.comp_set) / n,
            'adr': sum(c['adr'] for c in self.comp_set) / n,
            'revpar': sum(c['revpar'] for c in self.comp_set) / n
        }

    def calculate_indexes(self):
        """计算本店指数"""
        if not self.self_data:
            return None

        comp_avg = self.calculate_comp_avg()

        occ_index = (self.self_data['occ'] / comp_avg['occ'] * 100) if comp_avg['occ'] > 0 else 0
        adr_index = (self.self_data['adr'] / comp_avg['adr'] * 100) if comp_avg['adr'] > 0 else 0
        revpar_index = (self.self_data['revpar'] / comp_avg['revpar'] * 100) if comp_avg['revpar'] > 0 else 0

        return {
            'occ_index': round(occ_index, 1),
            'adr_index': round(adr_index, 1),
            'revpar_index': round(revpar_index, 1),
            'mpi': round(occ_index, 1),
            'rgi': round(revpar_index, 1),
            'ari': round(adr_index, 1)
        }

    def diagnose(self):
        """诊断分析"""
        indexes = self.calculate_indexes()
        if not indexes:
            return "无数据"

        occ_i = indexes['occ_index']
        adr_i = indexes['adr_index']

        if occ_i > 100 and adr_i > 100:
            diagnosis = "双优 - 领导地位"
            strategy = "保护溢价，加强OCC维护"
        elif occ_i > 100 and adr_i < 100:
            diagnosis = "量优价劣 - 低价抢量"
            strategy = "优化客户结构，提升ADR"
        elif occ_i < 100 and adr_i > 100:
            diagnosis = "价优量劣 - 高价低量"
            strategy = "增加低价房供给，提升入住率"
        else:
            diagnosis = "双劣 - 全面落后"
            strategy = "全面检查，重建竞争力"

        return {
            'diagnosis': diagnosis,
            'strategy': strategy,
            'indexes': indexes
        }

    def print_report(self):
        """打印完整报告"""
        print("=" * 60)
        print("STR STAR报告分析")
        print("=" * 60)

        if not self.self_data:
            print("无本店数据")
            return

        comp_avg = self.calculate_comp_avg()
        indexes = self.calculate_indexes()
        diag = self.diagnose()

        print(f"\n【本店数据】{self.self_data['name']}")
        print(f"  OCC: {self.self_data['occ']:.1f}%")
        print(f"  ADR: ¥{self.self_data['adr']:.0f}")
        print(f"  RevPAR: ¥{self.self_data['revpar']:.1f}")

        print(f"\n【竞争群均值】({len(self.comp_set)}家)")
        print(f"  OCC: {comp_avg['occ']:.1f}%")
        print(f"  ADR: ¥{comp_avg['adr']:.0f}")
        print(f"  RevPAR: ¥{comp_avg['revpar']:.1f}")

        print(f"\n【STAR指数】")
        print(f"  OCC Index (MPI): {indexes['occ_index']}")
        print(f"  ADR Index (ARI): {indexes['adr_index']}")
        print(f"  RevPAR Index (RGI): {indexes['revpar_index']}")

        print(f"\n【诊断】{diag['diagnosis']}")
        print(f"【策略】{diag['strategy']}")

        print("\n【竞争群分解】")
        for c in sorted(self.comp_set, key=lambda x: x['revpar'], reverse=True):
            gap_occ = self.self_data['occ'] - c['occ']
            gap_adr = self.self_data['adr'] - c['adr']
            print(f"  {c['name']}: OCC差{ gap_occ:+.1f}pp, ADR差¥{gap_adr:+,.0f}")


# 使用示例
if __name__ == '__main__':
    analyzer = STRAnalyzer()

    # 添加竞争群
    analyzer.add_competitor('竞品A', occ=75, adr=380, rooms=120)
    analyzer.add_competitor('竞品B', occ=68, adr=420, rooms=150)
    analyzer.add_competitor('竞品C', occ=72, adr=350, rooms=100)
    analyzer.add_competitor('竞品D', occ=70, adr=390, rooms=130)

    # 设置本店
    analyzer.set_self('本店', occ=78, adr=370, rooms=110)

    # 生成报告
    analyzer.print_report()
```
