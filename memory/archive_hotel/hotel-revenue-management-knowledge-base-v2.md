## 1. STR核心对标指标体系

### 1.1 三大核心指数 (STAR Report)

| 指标 | 英文 | 公式 | 含义 |
|------|------|------|------|
| **ADR指数** | ADR Index | `酒店ADR / 市场ADR × 100%` | 定价能力对标 |
| **OCC指数** | Occupancy Index | `酒店OCC / 市场OCC × 100%` | 市场份额对标 |
| **RevPAR指数** | RevPAR Index | `酒店RevPAR / 市场RevPAR × 100%` | 综合收益能力对标 |

**解读**:
- **> 100%**: 优于市场
- **= 100%**: 与市场持平
- **< 100%**: 落后于市场

### 1.2 细分指数体系

| 指标 | 英文 | 公式 | 应用场景 |
|------|------|------|----------|
| **ARI** | Average Rate Index | `我店ADR / 竞争群ADR` | 直接竞品对标 |
| **MPI** | Market Penetration Index | `我店OCC% / 市场OCC%` | 市场渗透率 |
| **RGI** | Revenue Generation Index | `我店RevPAR / 竞争群RevPAR` | 收益生成效率 |
| **ARI** | Achievement of Revenue Index | `实际RevPAR / 目标RevPAR` | 目标达成率 |

### 1.3 竞争群组分析 (Comp Set)

```
STR竞争群组定义:
├── 地理竞争群 (同一区域)
├── 产品竞争群 (同一档次)
├── 服务竞争群 (同一星级)
└── 综合竞争群 (多维度加权)
```

### 1.4 基准数据维度

| 维度 | STR数据 | 用途 |
|------|---------|------|
| **Daily** | 日数据 | 实时监控 |
| **Weekly** | 周数据 | 短期趋势 |
| **Monthly** | 月度数据 | 运营分析 |
| **Year-to-Date** | 累计数据 | 年度评估 |
| **Moving 12 Months** | 滚动12月 | 长期趋势 |

### 1.5 高级分析指标

| 指标 | 英文 | 公式 | 说明 |
|------|------|------|------|
| **Supply** | 供应量 | 可售房总数 | 市场供给 |
| **Demand** | 需求量 | 已售房总数 | 市场需求 |
| **RevPAR** | 每房收益 | Revenue / Supply | 收益效率 |
| **ADR** | 平均房价 | Revenue / Demand | 定价水平 |
| **Occ %** | 入住率 | Demand / Supply × 100% | 市场热度 |
| **Room Rev** | 客房收入 | ADR × Demand | 收入规模 |

## 2. 收益管理公式库

### 2.1 STR指数计算公式

#### ARI (Average Rate Index)
```
ARI = (酒店ADR / 竞争群组ADR) × 100%

细分:
- ARI > 100%: 定价高于竞品
- ARI = 100%: 与竞品持平
- ARI < 100%: 定价低于竞品
```

#### MPI (Market Penetration Index)
```
MPI = (酒店OCC% / 市场OCC%) × 100%

或:
MPI = (酒店已售房晚 / 市场已售房晚) × 100%

解读:
- MPI > 100%: 市场份额增长
- MPI = 100%: 市场份额稳定
- MPI < 100%: 市场份额流失
```

#### RGI (Revenue Generation Index)
```
RGI = (酒店RevPAR / 竞争群RevPAR) × 100%

综合收益能力指标:
- RGI > 100%: 收益效率优于竞品
- RGI = 100%: 收益效率与竞品持平
- RGI < 100%: 收益效率落后于竞品
```

### 2.2 动态定价公式

#### 基础动态定价模型
```
P(t) = P₀ × [1 + α × D(t) + β × C(t) + γ × E(t) + δ × T(t)]

参数:
- P(t): t时刻最优价格
- P₀: 基准价格
- D(t): 需求系数 (基于入住率、预订进度)
- C(t): 竞争系数 (基于竞品价格)
- E(t): 事件系数 (节假日、展会)
- T(t): 时间系数 (提前预订天数)
- α, β, γ, δ: 权重系数
```

#### IDeaS G3 定价公式
```
最优价格 = 需求弹性价格 × 市场份额权重 × 竞争调整因子

需求弹性价格 = 基础价格 × (1 + λ × ΔD)

其中:
- λ: 需求弹性系数 (通常 0.5~1.5)
- ΔD: 需求偏差率 = (预测需求 - 基础需求) / 基础需求
```

#### AHL智能定价公式 (中国市场版)
```
P_AHL = P_base × F_demand × F_competitive × F_event × F_channel × F_customer

其中:
F_demand = e^(0.5 × OCC_deviation)
F_competitive = 1 + 0.3 × (P_mine - P_comp) / P_comp
F_event = 1 + Σ(Event_Impact × Event_Coeff)
F_channel = 1 - Commission_Rate × 0.5  (私域优惠)
F_customer = 1 + Customer_Tier_Coeff
```

### 2.3 需求预测公式

#### 指数平滑法 (Exponential Smoothing)
```
Forecast(t) = α × Actual(t-1) + (1-α) × Forecast(t-1)

参数:
- α: 平滑系数 (0.1~0.9)
- α 越大: 对近期数据越敏感
- α 越小: 趋势越平滑
```

#### Holt-Winters 三次指数平滑
```
Level(t) = α × Y(t) + (1-α) × (Level(t-1) + Trend(t-1))
Trend(t) = β × (Level(t) - Level(t-1)) + (1-β) × Trend(t-1)
Forecast(t+k) = Level(t) + k × Trend(t)

参数:
- α: 水平平滑系数
- β: 趋势平滑系数
- γ: 季节平滑系数 (如有季节性)
```

#### 回归预测模型
```
Demand = β₀ + β₁×Holiday + β₂×Weather + β₃×Event + β₄×DayOfWeek + ε

变量:
- Holiday: 节假日虚拟变量
- Weather: 天气状况
- Event: 重大活动
- DayOfWeek: 星期几
```

### 2.4 库存分配公式

#### 团队/散客最优分配
```
Maximize: R = R_s × Q_s + R_g × Q_g

约束:
- Q_s + Q_g ≤ Q_total
- Q_s ≥ Q_s_min (散客保底)
- Q_g ≥ Q_g_min (团队保底)
- Q_s, Q_g ≥ 0

其中:
- Q_s: 散客房晚数
- Q_g: 团队房晚数
- R_s: 散客房价
- R_g: 团队房价
```

#### 渠道配额模型
```
Q_i = Q_total × w_i × (1 + θ_i)

渠道i配额:
- w_i: 渠道权重 (基于转化率、佣金)
- θ_i: 渠道偏好系数
```

### 2.5 收益优化公式

#### RevPAR最大化
```
RevPAR = ADR × OCC
      = (P × D) / S

约束条件:
- 0 ≤ D ≤ S (需求不超过供应)
- P ≥ P_min (价格下限)
- P ≤ P_max (价格上限)
```

#### GOPPAR优化
```
GOPPAR = (RevPAR - GOP_Cost_per_Room)
       = ADR × OCC - (人工 + 运营 + 营销) / 可售房

成本细分:
- 人工成本: 15~25%
- 运营成本: 8~12%
- 营销成本: 5~10%
```

## 3. 收益管理模型

### 3.1 经典模型

#### 3.1.1 BAR (Best Available Rate) 模型

```
BAR = 最低可接受价格

定价规则:
| 提前天数 | 调价幅度 |
|---------|----------|
| 0-7天   | +15~30% |
| 7-14天  | +5~15%  |
| 14-30天 | 基准价   |
| 30-60天 | -5~10%  |
| 60天+   | -10~20% |
```

#### 3.1.2 容量控制模型 (Yield Management)

```
库存分配策略:
┌─────────┬─────────┬─────────┐
│ 渠道    │ 配额比例 │ 价格策略 │
├─────────┼─────────┼─────────┤
│ 直销/私域│ 30-40% │ 最低价  │
│ 企业协议 │ 20-30% │ 中等价  │
│ OTA     │ 20-30% │ 动态价  │
│ 上门/Walk-in│10-20%│ 最高价 │
└─────────┴─────────┴─────────┘
```

#### 3.1.3 住二付一/连住优惠模型

```
收益 = Σ(P_i × N_i) - Discount

优化目标:
- 入住天数↑ → 单位成本↓ → 利润↑
- 客户LTV ↑ → 获客成本摊薄
```

### 3.2 AI/机器学习模型

#### 3.2.1 需求预测神经网络 (LSTM)

```
输入特征 (X):
- 历史入住率 (T-365 ~ T)
- 节假日标记 (Holiday_1 ~ Holiday_n)
- 天气数据 (Weather)
- 竞品价格 (Comp_Price)
- 渠道流量 (OTA_Traffic)
- 活动事件 (Event)
- 星期/月份 (DayOfWeek, Month)

输出 (Y):
- 未来1-30天每日需求预测

模型结构:
- Input(12 features) → LSTM(64) → LSTM(32) → Dense(1)
```

#### 3.2.2 强化学习定价 (Q-Learning)

```
状态空间 S:
- 当前入住率 (OCC)
- 剩余可售房 (Remain)
- 竞品价格 (Comp_Price)
- 距入住天数 (Days_to_Arrival)
- 事件标记 (Event)

动作空间 A:
- {降价15%, 降价10%, 降价5%, 维持, 提价5%, 提价10%, 提价15%}

奖励函数 R:
- R = RevPAR_after_action - RevPAR_baseline

Q更新:
Q(s,a) ← Q(s,a) + α[R + γ × max Q(s',a') - Q(s,a)]
```

#### 3.2.3 客户价值模型 (RFM++)

```
RFM模型:
- R (Recency): 最近一次入住距今天数
- F (Frequency): 年度入住频次
- M (Monetary): 年度累计消费金额

RFM++扩展:
- P (Preference): 偏好房型/早餐/楼层
- L (Loyalty): 会员等级/复购周期
- S (Source): 首次预订渠道
- B (Behavior): 预订行为(提前天数/取消率)

客户分群:
┌──────────┬──────────┬──────────┐
│ 价值等级 │ RFM得分  │ 营销策略 │
├──────────┼──────────┼──────────┤
│ VIP      │ 4-5分   │ 专属优惠 │
│ 潜力    │ 3-4分   │ 升级激励 │
│ 保持    │ 2-3分   │ 唤醒活动 │
│ 流失风险│ 1-2分   │ 召回计划 │
└──────────┴──────────┴──────────┘
```

### 3.3 组合优化模型

#### 3.3.1 多渠道优化 (Linear Programming)

```
目标函数:
Maximize Z = Σ(p_i × x_i)

约束条件:
- Σx_i ≤ S (总可售房)
- x_i ≥ L_i (渠道最低配额)
- x_i ≤ U_i (渠道最高配额)
- p_i ≥ p_min (价格下限)

其中:
- x_i: 渠道i销量
- p_i: 渠道i价格
- S: 总供应量
```

### 6.2 STR对标模块

```python
# STR指数计算
class STRMetrics:
    def calculate_ari(self, hotel_adr, comp_adr):
        """ADR指数"""
        return hotel_adr / comp_adr * 100
    
    def calculate_mpi(self, hotel_occ, market_occ):
        """MPI指数"""
        return hotel_occ / market_occ * 100
    
    def calculate_rgi(self, hotel_revpar, comp_revpar):
        """RGI指数"""
        return hotel_revpar / comp_revpar * 100
    
    def generate_star_report(self):
        """生成STAR报告"""
        return {
            'ADR_Index': self.calculate_ari(),
            'OCC_Index': self.calculate_mpi(),
            'RevPAR_Index': self.calculate_rgi()
        }
```

## 7. 附录：Excel公式模板

### 7.1 RevPAR计算
```
=ADR × 入住率
```

### 7.2 STR指数计算
```
ARI = =酒店ADR / 竞争群ADR × 100
MPI = =酒店OCC% / 市场OCC% × 100
RGI = =酒店RevPAR / 竞争群RevPAR × 100
```

### 7.3 需求指数
```
=当日需求 / (历史同期需求 × 同比增长率)
```

### 7.4 竞价阈值
```
=边际成本 + (目标RevPAR - 当前RevPAR) / 剩余可售房
```

### 7.5 动态定价
```
=基准价格 × (1+需求系数) × (1+竞争系数) × (1+事件系数)
```
