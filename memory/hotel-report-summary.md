### 3. 核心指标体系 ✅

#### 经营指标 (KPIs)
- **OCC** (入住率): 实际售出客房数 / 可售客房数
- **ADR** (平均房价): 客房总收入 / 实际售出客房数
- **RevPAR** (每房收入): OCC × ADR
- **GOP率**: 营业毛利 / 营业收入

#### 分析维度
- 同比 (YoY): 与上年同期对比
- 环比 (MoM): 与上一周期对比
- 2019年对比: 疫情前基准对比

#### 细分维度
- 分档次: 奢华/高端/中高端/中端/经济型
- 分区域: 华北/华东/华南/华中/西南/西北/东北
- 分城市: 一线/新一线/二线/三线及以下

## 关键发现：权威报告格式特征

### 迈点研究院报告特点
1. **结构清晰**: 概况 → 结构特征 → 趋势预判 → 小结
2. **数据丰富**: 多源数据交叉验证 (STR + OTA + 集团数据)
3. **图表结合**: 关键数据可视化呈现
4. **观点鲜明**: 核心发现用加粗突出
5. **前瞻性强**: 不仅复盘，更重预测

### 环球旅讯报告特点
1. **深度分析**: 专题研究深入
2. **国际视野**: 全球对标分析
3. **案例丰富**: 企业案例剖析
4. **观点多元**: 专家访谈/观点

### STR报告特点
1. **数据权威**: 行业标准数据源
2. **指标专业**: OCC/ADR/RevPAR为核心
3. **对比全面**: 同比/环比/2019年对比
4. **细分详细**: 档次/区域/城市多维度

## 使用指南

### 快速开始

```bash
# 1. 安装依赖
pip install scrapling python-docx pandas matplotlib

# 2. 采集数据
python skills/hotel-report/data_collector.py --source all --output data_2026_02.json

# 3. 生成报告
python skills/hotel-report/report_generator.py --type monthly --data data_2026_02.json --output 2026年2月酒店行业月报.docx
```

### 手动创建报告

1. 打开 `memory/hotel-report-templates.md`
2. 选择对应报告类型的模板
3. 按章节填充数据
4. 使用质量检查清单审核
5. 导出为所需格式
