# 同程押注国际市场，拿下嘀嗒后重做顺风车

再造酒店板块后，同程又收购嘀嗒重做出行业务。

同程旅行;传统业务;换赛道

图片来源：视觉中国

> 界面新闻记者 | 陈怡轩

传统业务增长放缓，同程旅行(00780.HK)多元化转型迫切。

8月24日，同程旅行发布2026年中期业绩并举行电话会。上半年，该公司实现收入99.93亿元，同比增长10.5%；经调整净利润17.92亿元，同比增长14.6%。

业绩稳健的背后，同程旅行内部各项业务表现已发生变化。

今年上半年，该公司住宿预订收入28.45亿元，同比增长11.1%；交通票务收入39.62亿元，同比增长仅2.1%。这两项传统在线旅游平台(OTA)业务增速均有所放缓。

2023年旅游市场恢复初期，同程旅行两项传统业务曾经历一轮高速增长，当年交通票务、住宿预订收入分别同比增长78.5%和61.5%。此后增速逐年回落，今年上半年进一步下降。

这也与监管方持续规范OTA平台传统业务有关。酒店侧，监管重点涉及全网最低价、佣金及流量限制问题；交通侧，加速包、候补帮抢等火车票增值服务被要求整改下线。业内人士告诉界面新闻，这些变化都影响着OTA传统业务的变现空间。

变局之下，OTA正在寻找新的增长故事。携程将更多筹码押向国际市场，承接快速增长的入境需求；同程旅行则把目光瞄准自己做酒店和出行。

在經歷了一年的資產重組與戰略調整後，萬達酒店發展有限公司（00169.HK）交出了一份堪稱驚艷的年度成績單。3月26日，萬達酒店發展公布截至2025年12月31日止的全年業績報告。報告顯示，公司母公司擁有人應占溢利約17.77億港元，相較2024年同期約9.89億港元的虧損，實現了強勁的「V型」反轉。

甩賣萬達酒管回血20億

　在2024年仍面臨巨額虧損的萬達酒店發展，何以在短短一年內實現財務數據的徹底翻身？

　萬達酒店發展在公告中指出，股東應占溢利主要源於兩點：一是出售事項確認的巨額收益淨額；二是缺少了上一年度（2024年）因長期應收款項轉移確認的約10.45億港元減值虧損。

　2025年4月，萬達酒店發展與同程旅行（00780.HK）訂立協議，以約24.9億元人民幣（約合26.8億港元）的價格出售其全資持有的萬達酒店管理（香港）有限公司100%股權。該交易於2025年10月16日正式完成交割。根據財報披露，正是由於此次出售，公司確認了逾20億港元的收益淨額。這筆收益成為了本財年利潤的核心支柱。

　而作為買方，同程旅行在接手萬達酒店管理業務後，首年便實現了初步的協同效應。同程旅行2025年財報顯示，同程旅行包含酒店管理在內的「其他業務」收入在2025年達到30.95億元，同比增長34.4% 。萬達酒店及度假村在加入同程生態體系後，藉助冰雪旅遊等熱點，在長白山、阿勒泰等地區的入住率屢創新高。
