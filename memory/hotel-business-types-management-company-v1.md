## 二、酒店开展方式

### 2.1 自营模式

```
自营模式:
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  定义: 酒店业主自己投资、自己管理、自负盈亏              │
│                                                             │
│  特点:                                                    │
│  ├── 投资: 业主全额出资                                  │
│  ├── 管理: 业主自行组建团队管理                          │
│  ├── 风险: 经营风险全担                                 │
│  └── 收益: 利润全享                                     │
│                                                             │
│  优势:                                                    │
│  ├── 决策灵活                                           │
│  ├── 利润独享                                           │
│  ├── 品牌可控                                           │
│  └── 执行高效                                           │
│                                                             │
│  劣势:                                                    │
│  ├── 资金压力大                                         │
│  ├── 经验不足风险                                       │
│  ├── 人才招聘难                                         │
│  └── 品牌知名度低                                       │
│                                                             │
│  适用:                                                    │
│  ├── 有酒店管理经验的业主                               │
│  ├── 单一酒店                                            │
│  └── 区域深耕                                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 委托管理模式

```
委托管理模式:
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  定义: 业主投资酒店，委托酒管公司管理，支付管理费用      │
│                                                             │
│  特点:                                                    │
│  ├── 投资: 业主出资                                      │
│  ├── 管理: 酒管公司派驻团队                             │
│  ├── 品牌: 使用酒管公司品牌                             │
│  └── 合同期: 10-20年                                    │
│                                                             │
│  收费模式:                                                │
│  ├── 基本管理费: 营业收入的2-4%                        │
│  ├── 奖励管理费: 营业利润的5-10%                       │
│  ├── 系统使用费: 固定+按房间数                          │
│  └── 营销费: 营业收入的1-2%                           │
│                                                             │
│  优势:                                                    │
│  ├── 品牌输出                                            │
│  ├── 专业管理                                            │
│  ├── 客源输送                                            │
│  └── 培训支持                                            │
│                                                             │
│  劣势:                                                    │
│  ├── 管理成本高                                          │
│  ├── 决策受限                                            │
│  └── 利润分成                                            │
│                                                             │
│  适用:                                                    │
│  ├── 高端/奢华酒店                                       │
│  ├── 业主无管理经验                                     │
│  └── 追求品牌价值                                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 特许经营模式

```
特许经营模式:
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  定义: 业主使用酒管公司品牌，自主经营，支付加盟费用      │
│                                                             │
│  特点:                                                    │
│  ├── 投资: 业主出资                                      │
│  ├── 管理: 业主自主经营                                  │
│  ├── 品牌: 授权使用酒管公司品牌                        │
│  └── 合同期: 5-10年                                     │
│                                                             │
│  收费模式:                                                │
│  ├── 加盟费: 一次性30-300万                           │
│  ├── 版税(特许经营费): 营业收入的3-8%                  │
│  ├── 系统使用费: 固定+按房间数                          │
│  └── 保证金: 10-50万(可退)                           │
│                                                             │
│  优势:                                                    │
│  ├── 品牌背书                                            │
│  ├── 系统支持                                            │
│  ├── 会员输送                                            │
│  └── 成本较低                                           │
│                                                             │
│  劣势:                                                    │
│  ├── 品牌标准约束                                        │
│  ├── 经营自主权受限                                     │
│  └── 持续费用                                            │
│                                                             │
│  适用:                                                    │
│  ├── 经济型/中端酒店                                     │
│  ├── 业主有管理经验                                     │
│  └── 追求快速复制                                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.4 租赁经营模式

```
租赁经营模式:
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  定义: 酒管公司或运营商从业主手中租赁酒店，自主经营      │
│                                                             │
│  特点:                                                    │
│  ├── 物业: 业主提供                                      │
│  ├── 经营: 酒管公司/运营商独立经营                      │
│  ├── 品牌: 使用酒管公司或自有品牌                       │
│  └── 合同期: 5-15年                                     │
│                                                             │
│  租金模式:                                                │
│  ├── 固定租金: 每年固定金额                             │
│  ├── 浮动租金: 营业收入的固定比例                       │
│  ├── 保底+浮动: 两者取高                               │
│  └── 利润分成: 利润分成                                 │
│                                                             │
│  优势:                                                    │
│  ├── 轻资产扩张                                          │
│  ├── 快速规模化                                         │
│  └── 风险转移                                            │
│                                                             │
│  劣势:                                                    │
│  ├── 租金压力                                            │
│  ├── 利润波动                                            │
│  └── 合同风险                                            │
│                                                             │
│  适用:                                                    │
│  ├── 物业业主不愿自营                                   │
│  ├── 酒管公司快速扩张                                   │
│  └── 存量酒店改造                                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

```
│                                                             │
│  优势:                                                    │
│  ├── 轻资产                                              │
│  ├── 快速扩张                                            │
│  └── 风险低                                              │
│                                                             │
│  劣势:                                                    │
│  ├── 质量控制难                                          │
│  ├── 品牌风险                                            │
│  └── 收益有限                                            │
│                                                             │
│  适用:                                                    │
│  ├── 三四线城市                                          │
│  ├── 单体酒店升级                                        │
│  └── 品牌认知度低                                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 四、酒管公司收费模式详解

### 4.1 委托管理收费

```
委托管理收费结构:
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  1. 基本管理费 (Base Management Fee)                    │
│     ├── 计算: 营业收入的2-4%                             │
│     ├── 支付: 每月/每季度                                │
│     ├── 特点: 固定比例，与利润无关                        │
│     └── 作用: 覆盖基础管理成本                          │
│                                                             │
│  2. 奖励管理费 (Incentive Management Fee)             │
│     ├── 计算: 营业利润(GOP)的5-10%                       │
│     ├── 支付: 每季度/年度                                │
│     ├── 特点: 与业绩挂钩，激励管理方                    │
│     └── 作用: 激励提升经营业绩                          │
│                                                             │
│  3. 系统使用费 (System Fee)                           │
│     ├── 固定部分: 3-10万/年                             │
│     ├── 变动部分: 50-100元/间/年                        │
│     ├── 包含: PMS、会员系统、预订系统                   │
│     └── 作用: IT系统支持                                 │
│                                                             │
│  4. 营销费 (Marketing Fee)                              │
│     ├── 计算: 营业收入的1-2%                            │
│     ├── 包含: 品牌营销、会员营销                        │
│     └── 作用: 品牌推广                                  │
│                                                             │
│  5. 培训费 (Training Fee)                              │
│     ├── 计算: 固定或按人数                              │
│     ├── 包含: 人员培训、认证                            │
│     └── 作用: 人才培养                                  │
│                                                             │
│  6. 采购佣金 (Procurement Commission)                  │
│     ├── 计算: 采购金额的3-5%                            │
│     ├── 包含: 运营物资、客房用品                        │
│     └── 作用: 供应链服务                                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

```
租赁经营收费结构:

│     ├── 特点: 与业绩挂钩                                │
│     └── 作用: 激励经营方                                │
│                                                             │

│     ├── 固定保底: 较低                                  │
│     ├── 浮动部分: 较高                                  │
│     └── 作用: 双方利益平衡                             │
│                                                             │
│  4. 利润分成 (Profit Sharing)                          │
│     ├── 计算: 净利润的20-40%                           │
│     ├── 支付: 季度/年度                                │

│     └── 作用: 激励经营方提升利润                        │
│                                                             │
│  5. 运营成本                                            │
│     ├── 业主承担: 物业租金、税费、保险                 │
│     ├── 运营方承担: 人工、运营、营销                   │
│     └── 责任分摊明确                                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
