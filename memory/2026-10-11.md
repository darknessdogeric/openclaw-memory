### 工具经验（写入 self-improving 候选）
1. exec Code Mode 陷阱：嵌套 Python 源码里出现反引号字符会提前终止 String.raw 模板 → 必须用 chr(96) 或变量替代（本次 md2docx 脚本与本次记忆写入脚本均因此报 SyntaxError，同一坑踩了两次）
2. 表格构造函数须做列数自适应：cols = max(len(r) for r in data) + 补齐短行，否则行长短不一时 IndexError（月报生成器首跑失败根因）
3. PowerShell 直接跑递归全盘扫描（含大文件）易超时/丢输出 → 先落盘再读（recon 两次 value 为 null，改落盘后正常）
4. PPT 文案禁用 Markdown 星号 —— PowerPoint 不解析，双星号会原样显示
5. edit 工具是原子操作：一批 edits 中任一 oldText 不匹配则整体回滚；改前须核对确切原文（含档位前缀等易漏字符）
6. 交付约定：所有交付物统一「KB 主存 + 桌面副本」双备份；桌面只留最新版，KB 保留全部历史版本可回溯
7. memory flush 期间写入被限制到 memory/2026-10-11.md 单一路径，且仅 read/write 可用：须先读全文再整体写回追加段
