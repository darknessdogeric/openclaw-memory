## 一、跨境贸易全景

### 1.1 什么是跨境贸易

```
定义：货物/服务跨国销售，买家在境外，卖家在境内

分类：
├─ B2B (Business to Business)
│  └─ 企业对企业，大宗批发
├─ B2C (Business to Consumer)
│  └─ 企业对消费者，零售出口（电商主流）
├─ C2C (Consumer to Consumer)
│  └─ 个人对个人，二手交易
└─ S2b2c (Supply chain to Business to Consumer)
   └─ 供应链赋能小b，小b触达C端

我们的定位：B2C + S2b2c
- 制造端（星旗智造）→ S2b2c平台 → 美国小b/消费者
```

### 1.2 中美贸易大环境

```
贸易关系：
├─ 中国是美国最大进口来源（2024约18%）
├─ 美国对中国商品加征关税（2018起，税率7.5%-25%）
├─ 关税豁免：部分品类有豁免，需持续关注
└─ 趋势：脱钩压力下的供应链重构

行业现状（2026）：
├─ 跨境电商出口规模：约2.8万亿人民币（需验证）
├─ 美国市场占比：约35%
├─ 增速：年增15-20%（需验证）
└─ 政策：支持跨境电商综试区扩大

主要平台：
├─ 亚马逊 (Amazon) - 最大B2C平台
├─ 沃尔玛 (Walmart) - 增长快速
├─ eBay - 二手/收藏品为主
├─ Shein - 快时尚直采
├─ Temu - 拼多多海外，激进增长
└─ TikTok Shop - 社交电商崛起
```

## 二、市场准入

### 2.1 进入美国市场的前提条件

```
必须具备：
├─ 营业执照（出口资质）
├─ 进出口经营权
├─ 海关备案
├─ 外汇收支资质
└─ 产品合规认证

推荐具备：
├─ FDA注册（食品/药品/化妆品）
├─ FCC认证（电子产品）
├─ CPSC认证（儿童产品）
└─ EPA认证（化学品）
```

### 2.2 主要认证体系

```
| 认证 | 适用范围 | 周期 | 难度 |
|------|----------|------|------|
| FDA注册 | 食品/药品/化妆品 | 3-6月 | 高 |
| FCC认证 | 电子产品 | 2-4周 | 中 |
| UL认证 | 电气产品 | 4-8周 | 高 |
| CPSC | 儿童产品 | 4-6周 | 中 |
| EPA | 化学品 | 3-6月 | 高 |
| Prop65 | 加州65号提案 | 2-4周 | 中 |

⚠️ 警示：认证周期长，需提前布局
```

### 2.3 关税与税务

```
进口关税：
├─ MFN税率：大部分商品3-10%
├─ Section 301关税：额外7.5%-25%（中国产品）
├─ 关税豁免：部分品类可申请豁免
└─ 实际税率 = MFN + Section 301 + 贸易战附加

销售税：
├─ 美国无联邦消费税，各州不同（0-10%）
├─ 电商平台代扣代缴（亚马逊等）
└─ 自建站需自行申报

其他税：
├─ 进口环节：关税 + 海关代征增值税
└─ 企业所得税：联邦21% + 州税
```

## 三、物流体系

### 3.1 物流模式对比

```
| 模式 | 时效 | 成本 | 适合 | 风险 |
|------|------|------|------|------|
| 直邮小包 | 10-20天 | 低 | 试水期 | 关税/丢包 |
| 海外仓 | 3-7天 | 中 | 稳定销售 | 压货风险 |
| FBA | 2-5天 | 高 | 追求排名 | 成本高 |
| 专线 | 7-15天 | 中 | 大货 | 灵活性低 |

我们的策略建议：
├─ 初期：直邮小包测款
├─ 爆款：转海外仓/FBA
└─ 大货：专线
```

### 3.2 海外仓

```
定义：提前备货到美国仓库

类型：
├─ 平台仓（亚马逊FBA）
│  └─ 优点：平台流量加持
│  └─ 缺点：成本高，规则严
├─ 第三方海外仓
│  └─ 优点：灵活，可多平台
│  └─ 缺点：无平台流量加持
└─ 自建仓
   └─ 优点：可控
   └─ 缺点：投入大，门槛高

海外仓核心指标：
├─ 库存周转率（目标>8次/年）
├─ 仓储成本（目标<$3/立方英尺/月）
├─ 尾程配送（目标<$5/单）
└─ 退货处理（目标<5%）
```

### 3.3 清关

```
清关流程：
进口申报 → 海关审查 → 缴税 → 放行 → 提货

注意事项：
├─ 申报价值：真实，低报有风险
├─ 商品归类：HS编码要准确
├─ 收货人信息：要和美国收货方一致
└─ 关税预付：DDU vs DDP

常见问题：
├─ 查验率：约3-5%
├─ 查验周期：3-7天
└─ 扣货原因：仿牌/侵权/文件不全
```

## 四、支付与结算

### 4.1 主要收款方式

```
| 方式 | 适用平台 | 费率 | 周期 | 风险 |
|------|----------|------|------|------|
| 第三方支付 | 亚马逊等 | 1-2% | 14天 | 低 |
| PayPal | 自建站 | 3-4% | 即时 | 中（买家保护） |
| Wire Transfer | B2B大额 | $15-25/笔 | 3-5天 | 低 |
| Payoneer | 多平台 | 1-2% | 2天 | 低 |
| WorldFirst | 阿里系 | 1-1.5% | 2天 | 低 |

合规要求：
├─ 真实贸易背景
├─ 外汇收支申报
├─ 银行流水留存
└─ 税务备案
```

### 4.2 外汇管理

```
监管框架：
├─ 外管局：外汇收支申报
├─ 海关：贸易统计申报
├─ 税务：出口退税申报
└─ 人民银行：跨境支付许可

出口退税：
├─ 条件：一般纳税人，货物出口
├─ 退税率：商品不同（0-13%）
├─ 周期：1-3个月
└─ 关键：进项发票要齐全

资金回国路径：
├─ 平台直接结算 → 第三方支付 → 国内账户
├─ 境外账户中转 → 结汇回国
└─ 供应链金融
```

## 五、合规与风险

### 5.1 知识产权风险

```
高风险行为：
├─ 仿牌：使用他人商标/logo
├─ 盗版：销售盗版产品
├─ 外观侵权：外观专利相似
└─ 技术侵权：专利技术未授权

保护措施：
├─ 商标注册：USPTO（美国）
│  └─ 费用：$250-500/类
│  └─ 周期：8-12个月
├─ 专利申请：发明/外观
│  └─ 费用：$5000-15000
│  └─ 周期：2-3年
└─ 版权登记：Copyright Office

应对策略：
├─ 选品：避免侵权高风险品类
├─ 检索：上架前查专利/商标
├─ 保险：知识产权侵权险
└─ 律师：提前建立律师关系
```

### 5.2 平台规则风险

```
亚马逊常见封号原因：
├─ 刷单/操控评论
├─ 产品安全问题
├─ 知识产权投诉
├─ 绩效不达标
├─ 关联封号
└─ 违反 restricted products

预防措施：
├─ 了解规则：定期查看平台政策更新
├─ 合规运营：不做任何操纵行为
├─ 账号隔离：一个账号一个主体
├─ 绩效管理：保持高绩效指标
└─ 安全库存：多账号分散风险
```

### 5.3 政策与地缘风险

```
主要风险：
├─ 关税升级：贸易战反复
├─ 实体清单：特定企业受限
├─ 供应链审查：涉疆/涉港产品
└─ 数据安全审查：TikTok式审查

应对策略：
├─ 市场分散：不依赖单一市场
├─ 原产地多元化：东南亚/墨西哥布局
├─ 合规前置：提前满足各种审查
└─ 本地化：在目标市场建立实体
```

## 六、选品策略

### 6.1 选品原则

```
高潜力品类特征：
├─ 体积小/重量轻（降低物流成本）
├─ 标准化程度高（减少退货）
├─ 客单价适中（$20-100为主）
├─ 使用频率高（复购可能）
├─ 差异化空间大（非标品）
└─ 合规门槛可接受

高风险品类：
├─ 带电产品（认证复杂）
├─ 液体/粉末（运输受限）
├─ 食品（FDA门槛高）
├─ 儿童产品（CPSC严格）
└─ 奢侈品（品牌保护强）

推荐品类（需验证）：
├─ 家居用品：收纳/装饰/工具
├─ 3C配件：充电/线材/支架
├─ 户外运动：露营/健身/骑行
├─ 宠物用品：用品/食品（门槛低）
└─ 美妆工具：美甲/护肤/化妆工具
```

### 6.2 差异化策略

```
为什么差异化重要？
├─ 避免价格战
├─ 提高利润率
├─ 建立护城河
└─ 降低被跟卖风险

差异化路径：
├─ 产品差异化
│  ├─ 功能创新
│  ├─ 设计独特
│  └─ 定制化
├─ 品牌差异化
│  ├─ 品牌故事
│  ├─ 用户定位
│  └─ 视觉识别
└─ 服务差异化
   ├─ 售后承诺
   ├─ 个性化
   └─ 社群运营
```

## 八、供应链

### 8.1 采购与生产

```
采购模式：
├─ 工厂直采
│  └─ 优点：成本低，定制灵活
│  └─ 缺点：起订量高，账期难谈
├─ 贸易商采购
│  └─ 优点：灵活，账期支持
│  └─ 缺点：成本略高
└─ 混合模式
   └─ 爆款工厂直采，测款贸易商

关键指标：
├─ MOQ（最小起订量）
├─ 打样周期：7-15天
├─ 大货周期：15-45天
├─ 付款方式：TT/L/C
└─ 交货周期
```

### 8.2 质检体系

```
质检节点：
├─ 打样质检：确认样品符合要求
├─ 大货首件：确认批量生产没问题
├─ 装柜前检：确认出货数量和质量
└─ 到港抽检：确认运输无损

质检标准：
├─ 功能测试
├─ 外观检查
├─ 包装检查
├─ 安全检查
└─ 合规检查

质检公司推荐：
├─ SGS（国际）
├─ Bureau Veritas（国际）
└─ 启信检测（国内）
```
