## 一、民宿行业概述

### 1.1 民宿定义与特征

```
民宿特征:
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  定义: 利用自用住宅空闲房间，或闲置房屋，               │
│       结合当地文化、景观、资源，为游客提供              │
│       住宿体验的小型住宿设施                           │
│                                                             │
│  特征:                                                    │
│  ├── 规模小: 通常1-20间房                             │
│  ├── 有主人: 主人文化、人情味                          │
│  ├── 有特色: 当地文化、装修风格                       │
│  ├── 有体验: 当地生活、深度游                        │
│  └── 有温度: 个性化服务、情感连接                    │
│                                                             │
│  vs 酒店:                                                │
│  ├── 酒店: 标准化、规模化、工业化                     │
│  ├── 民宿: 个性化、小而美、有温度                    │
│  └── 差异: 服务由人驱动 vs 流程驱动                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 民宿类型

```
民宿分类:
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  1. 家庭民宿 (Homestay)                               │
│     ├── 特征: 主人自住部分房间出租                      │
│     ├── 规模: 3-10间                                   │
│     ├── 客群: 预算有限、体验当地生活                  │
│     └── 体验: 主人文化、家庭氛围                       │
│                                                             │
│  2. 精品民宿 (Boutique Homestay)                      │
│     ├── 特征: 高端装修、独特设计                       │
│     ├── 规模: 5-20间                                   │
│     ├── 客群: 追求品质、文艺青年                       │
│     └── 体验: 设计感、艺术性                           │
│                                                             │
│  3. 景区民宿 (Scenic Homestay)                        │
│     ├── 特征: 靠近景区、景观资源                       │
│     ├── 规模: 10-30间                                  │
│     ├── 客群: 旅游观光、深度游                        │
│     └── 体验: 景观、便利、主题化                      │
│                                                             │
│  4. 乡村民宿 (Rural Homestay)                         │
│     ├── 特征: 乡村环境、农耕文化                       │
│     ├── 规模: 5-15间                                   │
│     ├── 客群: 逃离城市、亲子体验                      │
│     └── 体验: 农耕、采摘、田园                        │
│                                                             │
│  5. 古城民宿 (Heritage Homestay)                       │
│     ├── 特征: 历史建筑、传统文化                       │
│     ├── 规模: 5-25间                                  │
│     ├── 客群: 文化爱好者、历史游                       │
│     └── 体验: 古建筑、慢生活                          │
│                                                             │
│  6. 海边民宿 (Seaside Homestay)                       │
│     ├── 特征: 海景资源、海洋文化                       │
│     ├── 规模: 10-40间                                  │
│     ├── 客群: 滨海度假、亲子                          │
│     └── 体验: 海景、赶海、渔家                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

┌─────────────────────────────────────────────────────────────┐
│                                                             │

│                                                             │

│     ├── 入住日期/退房日期                                │

│     └── 到达时间/交通方式                               │
│                                                             │
│  Step 3: 房型推荐                                       │
│     ├── 根据人数推荐合适房型                            │
│     ├── 介绍特色与差异                                 │
│     ├── 说明含早/不含早                                 │
│     └── 价格优惠策略                                    │
│                                                             │
│  Step 4: 预订确认                                       │
│     ├── 预订方式: 微信/支付宝/平台                     │

│                                                             │
