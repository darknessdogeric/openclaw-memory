# 唐宋诗词中的巴蜀

> **核心诗作**：李白、杜甫、苏轼、三苏、李商隐、陆游等在巴蜀的创作
> **品牌价值**：意境层最高级的内容资产，文人精神的"中国名片"
> **美学评价**：诗词是中国文化的"魂"，巴蜀诗词是"魂中的魂"

---

## 一、为什么唐宋诗词是"安逸品牌的精神底色"

### 1.1 三个关键洞察

```
洞察1：诗词是"意境"的最高表达
  - 三星堆给"震撼"
  - 三国给"故事"
  - 诗词给"意境"
  - 意境 = 品牌的灵魂层

洞察2：巴蜀是中国诗人的"灵感圣地"
  - 李白出生在江油（蜀中）
  - 苏轼一家是眉山人
  - 杜甫在成都写下"茅屋为秋风所破歌"
  - 李商隐在巴蜀写下"君问归期未有期"
  - 陆游在蜀写下"衣上征尘杂酒痕"

洞察3：诗词可以"反作用于酒店体验"
  - 客人看到"随风潜入夜，润物细无声"
  - 会立刻联想到"细雨、安静、舒适、入眠"
  - 诗词=体验设计的"金句库"
```

### 1.2 安逸酒店的精神主张

```
" 蜀中多仙山" ——李白
" 锦城虽云乐，不如早还家" ——李白
" 随风潜入夜，润物细无声" ——杜甫
" 人生如逆旅，我亦是行人" ——苏轼
" 此心安处是吾乡" ——苏轼

安逸酒店 = 让"心"找到"安"的地方
= "此心安处是吾乡"的实体化
```

## 三、可视化的"诗词意境"

### 3.1 意境分类与酒店应用

```
【雨夜意境】
  代表诗：杜甫《春夜喜雨》、李商隐《夜雨寄北》
  调性：安静、舒适、温暖、诗意
  应用：夜床服务、雨天问候、客房门牌、伴手礼包装

【山水意境】
  代表诗：李白《蜀道难》《峨眉山月歌》、杜甫《登高》
  调性：壮阔、悠远、人与自然
  应用：观景房、室外平台、灯具、纹样

【花草意境】
  代表诗：杜甫《绝句》、江畔独步寻花
  调性：生机、闲适、春日
  应用：花艺、绿植、庭院

【月夜意境】
  代表诗：李白《静夜思》、苏轼《水调歌头》
  调性：思乡、团圆、宁静
  应用：中秋活动、夜晚灯光

【怀古意境】
  代表诗：杜甫《蜀相》、苏轼《念奴娇·赤壁怀古》
  调性：深沉、感慨、敬仰
  应用：主题餐厅、武侯祠联名客房

【豁达意境】
  代表诗：苏轼《定风波》《饮湖上初晴后雨》
  调性：从容、乐观、超脱
  应用：商务客群、Slogan、激励文案
```

### 3.2 颜色与诗词

```
"白也诗无敌，飘然思不群"——李白（飘逸）
  → 色调：留白、水墨、淡雅
  
"花径不曾缘客扫，蓬门今始为君开"——杜甫（亲切）
  → 色调：暖黄、棕红、家的颜色
  
"竹杖芒鞋轻胜马，谁怕？一蓑烟雨任平生"——苏轼（豁达）
  → 色调：青绿、烟雨、朴素
  
"行到水穷处，坐看云起时"——王维（禅意）
  → 色调：水墨、留白、云雾
```

## 四、字体与书法

### 4.1 字体建议

- **楷书**：用于客房挂字（端正）
- **行书**：用于大堂氛围（流动）
- **草书**：用于装饰（奔放，但要克制）
- **隶书**：用于"蜀"字logo（古朴）
- **篆书**：用于印章（神秘）

### 4.2 字体来源

- 颜真卿（楷书典范）
- 王羲之（行书典范）
- 苏轼《黄州寒食诗帖》（文人书法典范）
- 黄庭坚（草书）
- 何绍基（晚清书法家，蜀人）

## 五、酒店落地清单

### 5.1 大堂

- [ ] 主背景书法：精选蜀中诗词（如《春夜喜雨》全诗）
- [ ] 接待台后："此心安处是吾乡"刻字
- [ ] 地面：诗词水印
- [ ] 茶艺区：以"茶+诗"组合

### 5.2 客房

- [ ] 床头挂字：精选3-5首蜀中诗词
- [ ] 客房门牌：以诗词命名（如"蜀道阁""春雨房"）
- [ ] 客房便签纸：诗词印刷
- [ ] 茶叶：配诗词卡片
- [ ] 文创：杜甫草堂字帖、苏轼诗集

### 5.3 餐厅

- [ ] 餐牌：以诗词命名菜品
- [ ] 餐盘装饰：诗词水印
- [ ] 主题包间：以诗人命名（太白厅、少陵堂、东坡居）
- [ ] 茶饮命名："将进酒""蜀相""夜雨"

### 5.4 体验活动

- [ ] "诗词夜话"读书会
- [ ] "蜀中诗人"研学（李白江油/杜甫草堂/三苏祠）
- [ ] 书法体验课（临摹苏轼《寒食帖》）
- [ ] 茶诗会（每茶配诗）
