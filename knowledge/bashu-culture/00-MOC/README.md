## 一、这个知识库的底层逻辑

### 1.1 为什么是"知识库"而不是"资料库"？

```
资料库：收集信息 → 回答"是什么"
知识库：组织洞见 → 回答"为什么重要"+"怎么用"

巴蜀文化主题酒店要回答三个问题：
  1. 巴蜀文化到底是什么？（认知层）
  2. 它为什么能让客人动容？（情感层）
  3. 它如何变成可触摸的体验？（应用层）

所以知识库必须三层贯通：知识 → 意境 → 应用
```

### 1.2 群论视角：巴蜀文化的"不变量"

穿越千年不变的东西，才是品牌真正的护城河：

| 不变量 | 内涵 | 案例 |
|--------|------|------|
| **山水相依** | 治水智慧、人与自然的契约 | 都江堰、青城山、峨眉 |
| **烟火从容** | 反焦虑的生活美学 | 茶馆、麻将、川菜 |
| **隐逸精神** | 入蜀则安的文人传统 | 杜甫草堂、李白、苏轼、张献忠避难 |
| **幽默豁达** | "雄起"精神的底色 | 川剧变脸、散打评书 |
| **兼容并蓄** | 多民族融合的开放性 | 藏羌彝汉 + 外来文化 |
| **神秘悠远** | 古蜀文明的未解之谜 | 三星堆、金沙 |

**这6条不变量，是安逸品牌差异化的根。**

### 1.3 时间×主题×空间的立方体结构

```
              时间轴
              古蜀→秦汉→三国→唐宋→明清→近现代→当代
              ↓
        主题层（横向）：神话/历史/文学/艺术/饮食/民俗/山水/建筑/宗教
              ↓
        空间层（纵深）：成都平原/川西高原/川南/川北/重庆/藏羌彝区
```
