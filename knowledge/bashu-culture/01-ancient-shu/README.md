# 古蜀文明 · 总览

> **时代跨度**：约公元前2800年 — 公元前316年（秦灭巴蜀）
> **核心遗址**：三星堆、金沙、宝墩、十二桥
> **品牌价值**：巴蜀文化最深、最神秘、最具差异化的源头IP

## 一、为什么古蜀文明是"安逸"品牌的核心抓手？

### 1.1 不可复制的差异化

```
全国酒店集团：
  - 万达/锦江/华住 → 中端商务，标准化
  - 亚朵 → 中端生活方式，"阅读+摄影"
  - 开元 → 江南文化主题
  - 君澜 → 度假/会议
  - 安逸 → ?（定位中）

如果安逸 = 巴蜀文化主题酒店 = 古蜀神秘 + 三国风云 + 川菜烟火 + 唐宋诗意
  ↓
  全国唯一，无直接竞品。
```

### 1.2 时代的"中国潮"红利

- 三星堆2020-2026年连续破圈（央视春晚、三星堆博物馆新馆、三星堆×王者荣耀联名）
- 国潮崛起：年轻人对"中国自己的神秘学"有强烈兴趣
- "沉睡三千年，一醒惊天下"——三星堆自带传播金句
- 三星堆IP衍生品、文创、跨界联名已经成为文旅爆款

**安逸如果把三星堆/金沙做成品牌母IP，等于站在文旅风口上。**

## 二、古蜀文明的时间轴

```
旧石器时代（数万年前）     古蜀先民岷江上游活动
    ↓
新石器时代晚期             宝墩文化（约前2800-前2000）
（约前2800年起）            成都平原出现最早城邦（芒城、双河、紫竹等）
    ↓
三星堆文化                  三星堆遗址（约前1700-前1200）
（约前1700年）               三星堆古城 + 青铜神树/面具/大立人
    ↓
三星堆→金沙过渡            十二桥文化
（前1200-前900）             古蜀文明中心转移
    ↓
金沙文化（前1200-前650）    太阳神鸟、黄金面具、玉琮
    ↓
晚期蜀文化（前650-前316）   开明氏王朝、都城迁郫邑
    ↓
秦灭巴蜀（前316）           巴蜀纳入华夏体系
```

**关键洞察**：古蜀不是单一文明，而是**至少3000年连续演化**的文明体系。这点比古埃及、古巴比伦只晚不早。

## 三、古蜀文明的"六大神秘"

这六大神秘，是酒店体验设计的"故事矿脉"：

### 3.1 起源之谜：谁创造了古蜀？
- 没有文字记载（甲骨文未涉及古蜀）
- 与中原商周几乎同时但独立发展
- 青铜冶炼技术突然高度成熟（无渐进过程）
- 主流假说：本土起源 + 外来文化融合

### 3.2 消失之谜：三星堆为何突然衰亡？
- 前1200年前后，三星堆古城被废弃
- 大量器物被砸毁、焚烧、掩埋
- 主流假说：洪水？战争？迁徙？
- **金沙继承**：三星堆人并未消失，而是迁都金沙

### 3.3 青铜之谜：技术从哪来？
- 青铜神树（高3.96米）—— 同时期世界最高青铜器
- 青铜大立人（高2.62米）—— 服饰纹饰极其精细
- 青铜面具（宽1.38米）—— 纵目、三角眼、超现实
- **无法解释的工艺水平**：与中原完全不同风格

### 3.4 沟通之谜：与谁交流？
- 海贝（来自印度洋）
- 玉琮（良渚文化风格）
- 青铜牌饰（中亚风格）
- 象牙（来自印度）
- → 古蜀是**早期丝绸之路的节点**？还是独立发展？

### 3.5 信仰之谜：崇拜什么？
- 太阳崇拜（太阳神鸟）
- 祖先崇拜（青铜大立人）
- 自然崇拜（神树、山川）
- 神权与王权合一？
- 面具的"纵目"是什么？蚕丛氏"其目纵"？

### 3.6 王朝之谜：蜀王世系
- 蚕丛 → 柏灌 → 鱼凫 → 杜宇（望帝）→ 鳖灵（丛帝）→ 开明
- 望帝"魂化杜鹃"传说（与"望帝春心托杜鹃"诗词相连）
- 李冰治水、鳖灵治水——蜀地治水史诗

## 四、可视化的"古蜀意象"

### 4.1 视觉符号（酒店可直接用）

| 元素 | 出处 | 调性 |
|------|------|------|
| **太阳神鸟** | 金沙 | 神圣、希望、生命循环 |
| **青铜神树** | 三星堆 | 通天、生命力、宇宙观 |
| **青铜纵目面具** | 三星堆 | 神秘、超现实、震撼 |
| **玉琮** | 金沙 | 礼器、天地沟通 |
| **黄金面具** | 三星堆/金沙 | 神权、王权 |
| **青铜大立人** | 三星堆 | 王者、祭祀 |
| **象牙** | 三星堆 | 神秘、远方 |

### 4.2 色彩体系（提取自文物）

```
主色（神秘深邃）：
  - 青铜绿 #4A5D3A
  - 玄铁黑 #1A1A1A
  - 暗金 #B8941F

辅色（生命神性）：
  - 朱砂红 #B23A48  （青铜神树花蕾）
  - 玉石白 #E8DCC4
  - 日光金 #FFD700  （太阳神鸟）

禁忌色：荧光色、塑料感色彩、电子科技色
```

### 4.3 空间意境

- **下沉式**：古蜀人对"地下"（墓葬、祭祀坑）的重视 → 下沉式中庭、地宫式前台
- **向上通天**：神树通天 → 高耸中庭、垂直天井
- **神秘光影**：祭祀坑的发现 → 暗空间 + 局部强光
