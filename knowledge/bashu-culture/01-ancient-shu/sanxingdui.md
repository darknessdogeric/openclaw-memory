# 三星堆 · 深度解析

> **遗址位置**：四川省广汉市三星堆镇（距成都约60公里）
> **核心年代**：商代至西周（约前1700-前1200）
> **1986年发现**：1号、2号祭祀坑
> **2019-2022年新发现**：3-8号祭祀坑
> **2023年**：三星堆博物馆新馆开放

## 二、三星堆的核心器物（酒店可借鉴的视觉资产）

### 2.1 青铜神树

**原型**：1986年2号祭祀坑出土
**规格**：通高3.96米，是同时期世界最大的青铜器
**造型**：三层九枝，枝头立神鸟，树侧攀龙
**内涵**：
  - 通天建木（沟通人神的宇宙树）
  - 与《山海经》《淮南子》记载的"扶桑""若木""建木"高度吻合
  - 太阳栖息的神树（十日神话）

**酒店应用方向**：
- 大堂中央悬挂（缩小版复制品，2-3米高）
- 客房电梯厅背景墙浮雕
- 灯饰设计灵感
- LOGO变形

### 2.2 青铜纵目面具

**原型**：2号祭祀坑出土多件
**规格**：宽1.38米，高0.66米
**特征**：双眼极度突出（"纵目"）、耳朵夸张、表情超现实
**内涵**：
  - 《华阳国志》载"蚕丛其目纵，始称王"
  - 蚕丛氏是古蜀第一代蜀王
  - 纵目可能是面具（祭祀时佩戴），也可能是形象夸张

**酒店应用方向**：
- 大堂背景墙（强IP、辨识度极高）
- 客房标识（神秘+反差萌）
- 周边衍生（冰箱贴、行李牌、钥匙扣）
- 服务员工牌（"蜀王守护者"人设）

### 2.3 青铜大立人

**原型**：2号祭祀坑出土
**规格**：高2.62米（含底座），人像高1.8米
**造型**：头戴高冠、双手环握（持物已失）、服饰三层
**身份**：学界推测为蜀王或大巫师（"群巫之长"）

**酒店应用方向**：
- 行政酒廊主题形象
- 礼宾司仪制服纹样
- 服务仪式（迎宾时"双手环握"致敬礼）

### 2.4 青铜太阳轮（太阳形器）

**原型**：2号祭祀坑出土
**规格**：直径85厘米
**造型**：正圆形中心放射五道光芒
**内涵**：太阳崇拜的具体表现
**与金沙太阳神鸟的延续关系**：金沙太阳神鸟 = 太阳轮的演化版

**酒店应用方向**：
- 大堂地坪圆形图案
- 灯池设计
- 圆形餐桌、装饰镜

### 2.5 青铜鸟脚人像（"小立人"）

**原型**：3号祭祀坑出土（2021年）
**造型**：鸟爪、人身、双手持物
**内涵**：人神之间的"使者"？巫觋？

**酒店应用方向**：
- 客房茶宠摆件
- IP卡通形象（亲和力更强）
- 儿童区装饰

### 2.6 青铜神坛（2022年出土）

**造型**：多层立体结构，人、神兽、祭坛组合
**价值**：首次立体呈现古蜀人的宇宙观（天-地-神三层）

**酒店应用方向**：
- 多层吊饰/立体装置
- "三星堆X层"楼层概念

### 2.7 玉璋、玉琮、黄金面罩

- 玉璋：礼器，作为祭祀用品
- 玉琮：与良渚文化相通
- 黄金面罩：贴于青铜人头像上

## 三、三星堆文化的"四大主题"（酒店体验设计方向）

### 主题1：神秘（Mystery）

```
故事脚本：
"在成都平原的某处地下，沉睡着一个超越我们想象力的文明。
三千年前，他们用青铜器讲述着人神共处的故事。
当这些面具在光影中苏醒，你会听见来自远古的呼唤。"

调性：暗光、低饱和、青铜锈色、神秘东方
```

### 主题2：通天（Connection）

```
故事脚本：
"古蜀人相信，神树是连接天地的通道。
太阳栖息在枝头，神鸟往来于人间与天界。
每一件青铜器，都是他们寄给天地的信。"

调性：垂直空间、高耸、天窗、光柱
```

### 主题3：祭祀（Ritual）

```
故事脚本：
"三千年前的某个夜晚，蜀王点燃神树前的祭坛，
将象牙、面具、玉器投入火中，祈祷来年风调雨顺。
当烈火熄灭，文明的记忆就此凝固。"

调性：火、光影、仪式感、慢节奏
```

### 主题4：苏醒（Revival）

```
故事脚本：
"沉睡三千年，一醒惊天下。
1986年的那个春天，当第一铲泥土翻开，
我们看到了一个从未在史书记载的文明。
如今，它在安逸酒店苏醒，等待与你相遇。"

调性：突破感、新生力量、光亮
```

## 四、设计语言提炼

### 4.1 色彩
```
主色：青铜绿 (#4A5D3A) + 玄铁黑 (#1A1A1A)
辅色：朱砂红 (#B23A48) + 暗金 (#B8941F) + 玉石白 (#E8DCC4)
光色：暖橘黄光（模拟火/烛）
禁忌：荧光色、糖果色、电子色
```

### 4.2 材质
```
主材：青铜色金属、做旧黄铜、青石板
辅材：竹木、丝麻、皮革
装饰：青铜纹样浮雕、拓片、鎏金
禁忌：塑料、不锈钢镜面、白色亚克力
```

### 4.3 纹样（可识别+有文化）
```
- 饕餮纹（青铜器经典）
- 云雷纹（商周通用）
- 太阳纹（古蜀特色）
- 神树纹（独有）
- 目纹（纵目变体）
- 鸟纹（太阳神鸟系列）
```
