## 二、新增信源（7 个）

### 新增 1｜E28 中国饭店协会 HCI（中国住宿业消费指数）
- **性质**：行业协会指数（与 A2 中国饭店协会同源，但独立发布产品）
- **构成**：平均房价指数／入住率指数／在线预订指数／酒店餐饮营收指数／信心指数 五因子
- **口径**：基于去哪儿、华客科技等大数据平台 + 全国 30 个酒店集团、约 110 家门店回收调研
- **价值**：目前**唯一覆盖"房价+入住率+在线预订+餐饮+信心"五因子**的行业月度指数
- **本月实证**：2026 上半年两高峰（2 月 105.6、5 月 101.8）；5/6 月在线上预订指数同比 +12.1%／+8.8%

### 新增 2｜C18 华客科技
- **性质**：住宿业大数据平台
- **价值**：HCI 指数的底层数据合作方之一，可作一手数据交叉验证
- **归属**：C 类国内行业研究

### 新增 3｜C19 上海盈蝶企业管理咨询
- **性质**：酒店行业统计与咨询
- **价值**：《中国酒店集团及品牌发展报告》联合编写方，提供集团与品牌规模统计
- **归属**：C 类国内行业研究

### 新增 4｜B12 香港理工大学酒店及旅游业管理学院（PolyU SHTM）
- **性质**：国际学术机构（酒店与旅游业管理）
- **价值**：中国饭店协会年度报告的学术联合编写方，提供方法论与基准
- **归属**：B 类国际权威研究

### 新增 5｜F31 《HOTELS》杂志
- **性质**：国际酒店业权威媒体
- **价值**：全球酒店集团排名（与国内协会榜单互为印证）
- **归属**：F 类本土/垂直研究（扩展为"垂直媒体"）

### 新增 6｜C20 蓝豆云
- **性质**：酒店绿色供应链／数字化服务平台
- **价值**：绿色低碳与 ESG 数据来源（对应行业"绿色化"主线）
- **归属**：C 类国内行业研究

### 新增 7｜G35 界面新闻／蓝鲸财经／中国经营报
- **性质**：财经与产业媒体
- **价值**：上市公司动态、行业整合与资本运作报道
- **归属**：G 类财经媒体

## 四、维度评估（建议新增 2 个）

### 新增维度 1：指数维度（HCI 五因子）
| # | 指数 | 说明 |
|---|---|---|
| X1 | 平均房价指数 | 房价景气 |
| X2 | 入住率指数 | 需求景气 |
| X3 | 在线预订指数 | 线上渠道景气 |
| X4 | 酒店餐饮营收指数 | 非房收入景气 |
| X5 | 信心指数 | 行业预期 |

**理由**：现有"运营指标维度"只有 OCC/ADR/RevPAR 等**结果指标**，缺少**行业景气先行指标**。HCI 提供月度前瞻。

### 新增维度 2：品牌价值维度（2026 首发）
| # | 因子 |
|---|---|
| V1 | 溢价能力 |
| V2 | 规模情况 |
| V3 | 品牌成长 |
| V4 | 会员体系 |
| V5 | 投资人评价 |
| V6 | 消费者评价 |
| V7 | 创新能力 |
| V8 | 中国元素 |

**理由**：2026 年中国饭店协会首次发布"品牌价值指数"，标志评价体系从"规模导向"转向"**价值导向**"；对品牌选择、授权估值有直接参考价值。

### 是否需删减维度
建议**不删减**。现有 10 大类（信源／时间／地理／档次／客群／运营指标／财务／政策／人口结构／行业趋势）已覆盖充分；新增 2 个维度属"补强"而非"替换"。
