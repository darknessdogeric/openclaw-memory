# 单店深度可行性 SOP v1.0

> **适用任务**：对某一具体酒店/民宿项目（已选址或待选址）做深度可行性
> **第一例**：可作为弥勒"湖泉周边 12 间民宿"的下一阶段研究
> **编订**：B166ER | 2026-07-23

---

## 与地区级 SOP 的差异

| 维度 | 地区级 SOP | 单店级 SOP |
|------|---------|-----------|
| **粒度** | 整城 / 整州 | 单一物业 |
| **数据** | 宏观 + 行业数据 | 微观 + 物业 + 工程 + 运营 |
| **输出** | 市场全景 + 项目可行性 | 工程清单 + 投资测算 + 运营手册 |
| **风险** | 结构性 + 政策性 | 工程性 + 运营性 + 退出 |
| **周期** | 30 天 | 90-180 天（含建设） |

## 6 步标准流程

### Step 1：物业尽职调查（DD）

**核心清单**：

```markdown
### 1.1 物业权属
- [ ] 产权清晰（无抵押/查封/纠纷）
- [ ] 集体土地租赁合规（≤20 年红线）
- [ ] 用途符合（建设用 vs 商服用 vs 宅基地）
- [ ] 证照齐全（房产证 / 土地证）

### 1.2 物理条件
- [ ] 房屋安全鉴定（JGJ125 标准）
- [ ] 结构承载（加层 / 加建 / 加固可行性）
- [ ] 水电容量（最大供电 + 上下水）
- [ ] 排污 / 燃气 / 通讯
- [ ] 交通可达性（自驾 / 公共交通 / 停车）

### 1.3 政策合规
- [ ] 当地民宿办证 6 证（卫生/工商/税务/特种/消防/食品）
- [ ] 消防验收（**最大瓶颈**）
- [ ] 特种行业许可（公安治安）
- [ ] 食品安全（如含餐）
- [ ] 环境保护（景区附近尤其严）

### 1.4 物业改造
- [ ] 改造预算粗算
- [ ] 设计单位资质
- [ ] 施工队伍考察
- [ ] 装修标准（中端 vs 高端）
```

**输出**：`reports/single_store_dd_report.md`

### Step 2：投资测算（财务模型）

**模板**：

```python
# 单店投资测算（输入参数）
inputs = {
    'region': '弥勒',
    'property_type': '民宿',
    'rooms': 12,
    'building_area_m2': 450,
    'land_cost_wan': 80,           # 土地成本
    'renovation_wan': 67.5,         # 硬装 1500 元/㎡
    'soft_renovation_wan': 30,      # 软装
    'design_wan': 8,
    'fire_safety_wan': 5,
    'infrastructure_wan': 15,
    'pre_op_wan': 10,
    'working_capital_wan': 30,
}

# 营收预测（保守/中性/乐观）
scenarios = [
    {'name': '保守', 'adr': 280, 'occ': 0.50, 'revpar': 140},
    {'name': '中性', 'adr': 350, 'occ': 0.58, 'revpar': 203},
    {'name': '乐观', 'adr': 420, 'occ': 0.65, 'revpar': 273},
    {'name': '路径A温泉', 'adr': 550, 'occ': 0.60, 'revpar': 330},
    {'name': '路径B长住', 'adr': 350, 'occ': 0.70, 'revpar': 245},
]

# 自动计算
for s in scenarios:
    annual_revenue = inputs['rooms'] * 365 * s['revpar'] / 10000
    s['annual_revenue_wan'] = round(annual_revenue, 1)
    s['net_margin'] = 0.29 if 'A温泉' not in s['name'] else 0.35
    s['annual_profit_wan'] = round(annual_revenue * s['net_margin'], 1)
    total_invest = sum([inputs[k] for k in inputs if isinstance(inputs[k], (int, float))])
    s['payback_years'] = round(total_invest / s['annual_profit_wan'], 1)

# 输出对比表
print(templates.finance_table(scenarios))
```

**输出**：`reports/single_store_finance_model.xlsx` + 文字描述

### Step 3：客群与产品定位

```markdown
## 客群定位（必填）

### 3.1 主要客群（占比推估）
| 客群 | 占比 | 单价 | 停留 | 优先级 |
|------|-----|------|------|--------|
| 休闲度假家庭 | 35% | ¥280-450 | 2-3 晚 | ⭐⭐⭐ |
| 旅居康养客 | 15% | ¥150-280 | 7-30 晚 | ⭐⭐⭐ |
| 自驾散客 | 30% | ¥200-380 | 1-2 晚 | ⭐⭐ |

### 3.2 产品配置
- 房型分布（标间 / 大床 / 套房 / 亲子房）
- 配套（早餐 / 下午茶 / 温泉 / 旅拍 / 健身房）
- 主题（温泉/艺术/在地文化/亲子/康养）
- 体验设计（泊车 / 接驳 / 周边游）

### 3.3 价格策略
- 平价价格（base）
- 周末溢价（+10-15%）
- 节假日溢价（五一+60% / 国庆+70% / 春节 2-3 倍）
- 长住折扣（-15% 至 -30%）
```

### Step 4：运营手册

```markdown
## 运营手册（核心 SOP）

### 4.1 组织架构
- 店长 / 主理人：1 人
- 管家 / 前台：2 人
- 客房阿姨：1-2 人
- 兼职 / 临时：1 人

### 4.2 日常 SOP
- 入住流程（线上+线下）
- 客房清洁标准（72 项 + 16 步铺床）
- 餐饮 SOP（早餐 / 在地特色）
- 投诉处理 SOP（金牌话术）

### 4.3 营销 SOP
- OTA 维护（携程/美团/抖音/小红书）
- 私域运营（微信群 / 公众号 / 小程序）
- 会员体系（积分 / 储值 / 黑卡）
- 长住客管理（北方候鸟定制套餐）

### 4.4 收益管理 SOP
- 每日 OCC/ADR/RevPAR 复盘
- 竞品价格监控（每日 2 次旺季 / 每日 1 次淡季）
- 价格动态调整（提前 7 天调整）
- 节假日系数定价
```

---

### Step 5：合规 + 融资

```markdown
## 合规清单

### 5.1 办证 6 证（依序申请）
1. 营业执照（工商）— **最先办**
2. 卫生许可证（卫健委）
3. 税务登记证
4. 特种行业许可证（公安治安）
5. 消防检查合格证（**最大瓶颈**）
6. 食品流通许可证（如含餐）

### 5.2 创业担保贷款申请（弥勒）
- 个人 / 小微企业：30 / 400 万
- 50% 财政贴息
- 通过云南省融资信用服务平台
- 申请条件：重点群体（失业/困难/退役/高校/返乡）

### 5.3 其他融资渠道
- 银行商业贷款（5-8% 利率）
- 亲友借款
- 民宿贷（部分银行有）
- 投资人入股
```

---

### Step 6：退出 + 风险预案

```markdown
## 退出方案

### 6.1 5 年退出预案
- 整体转让（60-90% 投资额回收）
- 品牌加盟（参考大乐之野/携程 67% 控股模式）
- 物业分层（物业转 / 运营换）

### 6.2 风险预案
- 行业小年（2014 全国 RevPAR -9.7%）→ 准备 2 年爬坡期
- 政策变化（如民宿条例升级）→ 保留合规升级预案
- 客源波动（季节性）→ 长住客平衡
- 团队稳定性 → 主理人 + 核心员工持股
```
