## 三、5 维可行性矩阵（强制模板）

```
5 维评分 + 评级 + 关键判断 + 5 个关键约束条件

### 1. 市场可行性
- 评级：[强/有条件/较弱] + 10 分制分数
- 关键判断：基于需求端数据
- 关键数据：游客数 / 花费 / OCC / 过夜率

### 2. 政策可行性
- 评级：同上
- 关键判断：基于办证流程 + 土地政策
- 关键数据：办证 6 证 + 宅基地年限

### 3. 财务可行性
- 评级：同上
- 关键判断：基于投资模型 + 回收期
- 关键数据：投资额 / RevPAR / 修正后回收期

### 4. 运营可行性
- 评级：同上
- 关键判断：基于人才 + 团队 + 供应链
- 关键数据：人力成本 / 标准化 SOP

### 5. 退出可行性
- 评级：同上
- 关键判断：基于退出路径
- 关键数据：转让 / 品牌加盟 / REITs
```

## 四、5 维评分标准

| 分数 | 评级 | 含义 |
|------|------|------|
| **8-10** | ✓ 强 | 这项完全可行，无需特殊努力 |
| **6-8** | △ 有条件 | 需要某些约束条件达成才可行 |
| **4-6** | ⚠ 较弱 | 需要更多努力或外部条件 |
| **<4** | ✗ 难 | 不建议，强行做风险高 |

**总体判断规则**：5 维中只要有 1 维 ≤5 分 = 整体"不可行"
3 维 ≥7 分 + 2 维 ≥6 分 = "有条件可行"
所有 5 维 ≥8 分 = "强可行"

## 五、5 个关键约束条件（每个报告必填）

```
1. [投资规模]：上限 + 原因
2. [合规底线]：必须满足的合规清单
3. [单店房量]：范围 + 原因
4. [客源分散]：OTA 占比上限 + 替代渠道
5. [退出机制]：预设路径
```

**5 约束必须全部满足才能"可行"**——这是反向校验。

## 六、财务模型标准公式

### 保守场景
```
ADR = 当地中端均价
OCC = 50%
年营收 = 客房数 × 365 × ADR × OCC + 餐饮 (15%)
净利率 = 29%
回收期 = 总投资 / 年净利
```

### 中性场景
```
ADR = 中端偏上
OCC = 60%
```

### 乐观场景
```
ADR = 高端入门
OCC = 65%+
```

### 修正路径
```
A = 客单价升级（温泉+康养） → +50% ADR
B = 私域+长住 → +10-15% OCC
C = 创业担保贷款 → -50% 利息
修正后回收期 ≤ 5 年 = "稳" 标准
```
